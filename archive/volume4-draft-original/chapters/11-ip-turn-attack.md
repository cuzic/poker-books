# 第11章　IPの攻撃 ─ ダブルバレル / 遅延CBet / チェックバック

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップCBet後のターンでIPが取る3つの選択肢（ダブルバレル・遅延CBet・チェックバック）を体系的に整理し、第7章のバレルスコアと第8章のα式を組み合わせた5秒判断フローを習得する。

---

## 11-1 3つの選択肢の整理

フロップでCBetを打ったIPは、ターンで3つの選択肢を持ちます。

```
選択肢 1: ダブルバレル
  フロップ CBet → ターンも続けてベット
  目的: 圧力継続、バリュー獲得、フォールドエクイティ活用

選択肢 2: チェックバック
  フロップ CBet → ターンでチェック
  目的: SDV保護 / トラップ / 攻撃の放棄

選択肢 3: 遅延CBet（Delayed C-bet）
  フロップ チェックバック → ターンでベット（OOPチェック後）
  目的: 強化されたハンドでの攻撃開始、フォールドエクイティ
```

「フロップでチェックバックして、ターンでベット」する遅延CBetは選択肢3として別枠に扱います。フロップのアクションによってレンジの意味が異なり、判断基準も変わるからです。

本章では選択肢1と2（フロップCBet後の判断）を中心に扱い、後半で選択肢3（遅延CBet）を詳述します。

### 3つの選択肢の前提条件

各選択肢が発生する文脈を整理しておきます。

| 選択肢 | フロップ | ターン（IP） | OOPの動き |
|---|---|---|---|
| ダブルバレル | CBet | ベット | チェックまたはコール後 |
| チェックバック | CBet | チェック | チェックまたはコール後 |
| 遅延CBet | チェックバック | ベット | OOPがチェックした後 |

「OOPがドンクベット（ターン先手ベット）してきた場合」は本章の対象外です。OOP側の応戦については第12章で扱います。

## 11-2 ダブルバレルの判断フロー ─ バレルスコアで5秒判断

ダブルバレルの可否判断には、第7章で学んだ**バレルスコア**を使います。

```
バレルスコア = FlopType係数 + TurnCard係数

FlopType係数:
  ドライ       = 8
  セミ         = 6
  スーテッド   = 4
  コネクテッド = 3

TurnCard係数:
  ペア             = 4
  オーバーカード   = 3
  ブランク         = 2
  フラッシュ       = 1
  コネクター       = 0

判定:
  バレルスコア ≥ 7 → 積極バレル（全レンジでCBet推奨）
  バレルスコア < 7 → ハンド依存（HandScoreで判断）
```

実戦での5秒フローはこのとおりです。

**ステップ1**: フロップを分類する（ドライ / セミ / スーテッド / コネクテッド）

**ステップ2**: ターンカードを分類する（ペア / OC / ブランク / フラッシュ / コネクター）

**ステップ3**: 足し算してスコアを出す

**ステップ4**: スコア ≥ 7 なら全ハンドでバレル、< 7 ならHandScoreで絞り込む

HandScoreによる絞り込みの基準（< 7ゾーン）:

| HandScore | アクション |
|---|---|
| 15以上 | バリューベット実行 |
| 8〜14 | セミブラフのみ実行 |
| 7以下 | チェックバック |

バレルスコアは「レンジ全体として打つべきか」を教えます。ハンドの強さはその後の調整です。GTO実測270シナリオで、この閾値（7）は全17セルでGTOの積極/消極バレル分類と一致しています（第7章参照）。

## 11-3 ダブルバレルのサイズ選択

バレルスコアが ≥ 7（積極バレルゾーン）と判定されたとき、次の問いはサイズです。

基本の考え方は**α式**から導きます。α = ベット額 ÷ (ポット + ベット額) です（第8章参照）。ベットサイズが大きいほどαが上がり、フォールドエクイティが増える一方で、コールされたときのリスクも増えます。

ターンでのサイズ選択の指針を整理します。

| サイズ | α値 | 使いどころ |
|---|---|---|
| 33%ポット | 約0.25 | 高頻度バレル（ドライ板・レンジ全体） |
| 50%ポット | 約0.33 | 標準バレル（バリュー〜セミブラフ） |
| 75%ポット | 約0.43 | ポラライズバレル（強ハンドとブラフの二極化） |
| 100%+ポット | 0.50以上 | ナッツアドバンテージが明確な局面のみ |

### フロップサイズとターンサイズの連動

フロップで33%ポット（1/3ポット）CBetをした後、ターンのサイズ選択には注意が必要です。

フロップ33%後にターンも33%を続けると、リバーに残るスタックが大きくなりすぎ、リバーでの圧力が弱まります。100BB スタックの標準ポットでは次の計算が参考になります。

```
フロップ前ポット: 6BB（100BB 6-max SRP想定）
フロップ33%CBet: BTN ベット2BB, BB コール → ターン前ポット 10BB

ターン50%ベット: 5BB → リバー前ポット 20BB
  リバー残スタック: 100 − 1 − 2 − 5 = 約92BB → SPR約4.6
  リバーでポット以下のオールインが可能

ターン33%ベット: 3.3BB → リバー前ポット 16.6BB
  残スタック: 約95BB → SPR約5.7
  リバーの打ち幅が限られる
```

フロップ33%後はターン50%が標準です。フロップ50%後はターンも50〜75%を使い、2ストリートでポットを膨らませます。

### ハンドタイプ別のサイズ指針

| ハンドクラス | ターンサイズ | 理由 |
|---|---|---|
| ナッツ〜準ナッツ（セット・2ペア以上） | 75%+ | ポットを大きくする、SPRを下げる |
| トップペア良キッカー（TPTK） | 50% | 薄バリュー取り、リスク管理 |
| セカンドペア〜ミッドペア | 33%またはチェック | SDV保護優先 |
| セミブラフ（OESD・FD） | 50〜75% | フォールドエクイティ最大化 |
| 純ブラフ（空振り） | バレルスコア ≥ 7なら50% | 高頻度局面のみ実行 |

## 11-4 ダブルバレルのハンドクラス別判断

バレルスコアで「積極バレルか否か」が分かっても、「どのハンドをバリューとして打つか」「どのハンドをブラフとして打つか」の判断はさらに必要です。

### ナッツ〜準ナッツ（HandScore ≥ 20）

バレルスコアの値に関わらず、ほぼ常にバリューベットです。相手がコールしてくれるほど利益が増えるため、積極的なサイズで打ちます。

ターンでセット・2ペア・完成ストレートを持つ場合、リバーに向けて「スタックの残り方」を意識します。ターン75%ベットで、リバーに中程度のオールインを仕掛けるラインが理想的です。

### トップペア系（HandScore 10〜18）

バレルスコアが ≥ 7（積極バレル）ならば打つのが基本です。ただしキッカーの強さとターンカードの種類によって、サイズを33〜50%に抑えることがあります。

バレルスコアが < 7（ハンド依存）のときは、HandScore ≥ 15 の強いトップペアのみ打ちます。セカンドペアやアンダーペアはチェックバックに移行します。

### セミブラフ（HandScore 8〜14）

ドロー系のハンドはバレルスコア ≥ 7のときに積極的に打てます。アウツ数でさらに絞ると次のとおりです。

| ドロー種別 | アウツ | 積極バレルゾーン | ハンド依存ゾーン |
|---|---|---|---|
| OESD（オープンエンドストレートドロー） | 8 | ベット推奨 | 検討 |
| フラッシュドロー | 9 | ベット推奨 | 検討 |
| ガットショット | 4 | 場合による | チェックバック基本 |
| バックドアドローのみ | 2〜3 | チェックバック多 | チェックバック |

OESD + オーバーカードなど複合ドローはHandScore 14以上になることが多く、ハンド依存ゾーンでも打てます。

### ショーダウンバリュー（HandScore 4〜8）

セカンドペア・弱いミッドペア・アンダーペアなど、ベットしても強いハンドのコールを誘うだけで、フォールドしてほしい相手は降りてくれないハンドです。バレルスコアが ≥ 7でも、これらはチェックバック候補です。

「バレルスコアが高いから全部打てる」という誤解が、このクラスで最も損失を生みます。

## 11-5 チェックバックの3用途

チェックバックは「失敗」ではありません。3つの明確な用途があり、それぞれで期待値（EV）がプラスになる状況があります。

### 用途1: SDV保護（ショーダウンバリュー保護）

中強度のハンドで、ベットして得られるバリューよりも「チェックでリバーへ持ち込む」方がEVが高い状況です。

典型例は「トップペアだが、ターンカードが相手のレンジを強化した」ケースです。ベットすれば強いハンドにコールされ、弱いハンドはすでにフォールドしているため「べットで得られるものが少ない」状態です。

```
例: K♣7♦2♠ フロップでIPがCBet → BB コール
   ターン A♥（OC）
   IPハンド K♠Q♦（ワンペア K's）

   バレルスコア: ドライ(8) + OC(3) = 11 → 積極バレルゾーン

   ただし: K♠Q♦はフロップのTPTK → ターンA♥でセカンドペアに格下げ
   A♥落ちでBBのAx（Aペア）が多数強化される
   ベットしてコールされる相手のほとんどがK♠Q♦を上回る

   → K♠Q♦はSDV保護のチェックバックが現実的な選択
```

バレルスコアは「レンジ全体の傾向」です。そのハンドが個別に不利な状況では、チェックバックの方が正解になります。

### 用途2: トラップ（スロープレイ）

ナッツまたはそれに近い強ハンドで、チェックバックして相手のブラフ・バリューを引き出す戦略です。

第2章で学んだCapped vs UncappedのUncappedの強みを使います。あなたのチェックバックレンジには「ナッツが隠れている可能性」があるため、BBはチェックバックを弱さのシグナルとして読みすぎるリスクがあります。

```
例: K♣7♦2♠ フロップでIPがCBet → BB コール
   ターン 7♥（ペアターン）
   IPハンド KK → ボード K♣,7♦,2♠,7♥ + K,K
   Ranks: K×3, 7×2 → フルハウス K's full of 7's

   フルハウスは「ベットして得る」より「チェックでBBを動かす」方が
   大きなポットを作れる局面がある

   → チェックバック → リバーでBBのブラフや薄バリューを誘う
```

ただしスロープレイには「相手がリバーで動いてくれない」リスクが伴います。相手のレンジがすでに弱いと判断される場合は、ターンでバリューベットする方がEVは高いことが多いです。

### 用途3: 攻撃の放棄

バレルスコア < 7（ハンド依存ゾーン）かつ HandScore < 8の場合、単純に攻撃を諦めるチェックバックです。空振りのブラフを続けることは損失を拡大するだけです。

リバーでショーダウンになった場合に「わずかに勝てる可能性」だけを残して、次のストリートへ移行します。

## 11-6 遅延CBet ─ フロップチェックバック後の攻撃

遅延CBetは「フロップでチェックバックしたIPが、ターンでOOPがチェックした後に先手でベット」するラインです。

通常のダブルバレルと何が違うのか。最大の違いは**レンジの意味**です。

```
ダブルバレルのIPレンジ:
  フロップCBet = 「ナッツもブラフも含む攻撃」
  ターンベット = 「依然として幅広いレンジ」
  → OOPは「IPは全体的に強い」と読む

遅延CBetのIPレンジ:
  フロップCB = 「中強度 / バックドアドロー / トラップ」が主体
  ターンベット = 「ターンカードで改善した、または改善したように見せる」
  → OOPは「IPはターンカードで強化された」と読む
```

このレンジの違いが、遅延CBetの「ストーリー整合性」の問題を生みます。

### 遅延CBetが有効なターンカード

フロップでチェックバックした理由にもよりますが、遅延CBetが最も有効なのは「OOPに不利なターンカード」と「IPが改善したターンカード」が重なった局面です。

**カテゴリA: OOPのレンジを弱化させるターンカード**

```
例: K♦7♣2♠ でフロップCBフォールバック後
   ターン A♥（OC）

   → BBのKx（フロップトップペア）がA落ちでセカンドペアに格下げ
   → BBはAを持ちにくい（BTN vs BBのSRPではBBのコールレンジにAx多いが、
     K72でコールしたBBのAx比率は中程度）
   → BBはA落ちでチェックしやすい状況に
   → IPのAx（遅延CBetの動機）が強化される
```

**カテゴリB: IPのバックドアドローが完成したターンカード**

フロップでバックドアドロー（フラッシュドロー / ストレートドロー）の2〜3アウツを持っていたIPが、ターンで本格的なドローに昇格した場合です。

```
例: A♠6♣3♦ でフロップCBフォールバック
   IPハンド T♠9♠（バックドアスペードFD）
   ターン 7♠（スペード3枚目）

   → T♠9♠はフラッシュドロー完成（ナッツに近い）
   → OOPのレンジにスペードが少ない局面では高いフォールドエクイティ
   → 遅延CBetセミブラフ有効
```

**カテゴリC: ペアターン（IPのドミナンス強化）**

ペアターンは通常、バレルスコアで見ると積極バレルゾーンに入ります。しかし遅延CBetでも有効な状況があります。

```
例: 8♠5♦2♣ でフロップCBフォールバック後
   ターン 5♥（ペアターン）
   IPハンド 8♣8♦（セット → フルハウス 8's full of 5's）

   → IPの88は8♠5♦2♣でフロップトリップスだったが、
     5♥落ちでフルハウスに昇格
   → 「チェックバックしたIPが突然強化された」ライン
   → 遅延CBetバリューベットが有効
```

**カテゴリD: OOPに有利なターンカード（遅延CBet不適）**

コネクターターンやフラッシュターンは、OOPのドロー系ハンドを強化します。遅延CBetを打っても、OOPにコールされやすい状況が生まれます。これらの局面では遅延CBetより、チェックバック継続が推奨です。

### 遅延CBetのハンド構成

遅延CBetに使うハンドを3クラスに分けます。

**バリュー目的（薄バリュー）**:
- ターンで強化されたトップペア以上（A落ちでトップペアになったAx等）
- バックドアドローからターンで昇格した中強度ハンド

**セミブラフ目的**:
- バックドアFD → ターンでFD完成
- バックドアストレートドロー → OESD / ガットショット昇格

**遅延CBetに適さないハンド**:
- 純粋に空振りのハンド（改善もなく、ドローもない）
- ナッツのスロープレイ（セット等）→ リバーまで引き付けるか、ターンでバリューベット

### 遅延CBetのサイズ選択

遅延CBetはフロップでチェックバックしているため、ポットがダブルバレルの場合より小さいことに注意します。

```
フロップCBet後のターン前ポット（BTN vs BB, 100BB, SRP）:
  プリフロップポット 6BB + フロップCBet 2BB + BBコール 2BB = ターン前 10BB
  ※ BTN 33%CBet想定

フロップチェックバック後のターン前ポット:
  プリフロップポット 6BB（チェック/チェックでポット変化なし）= ターン前 6BB
```

遅延CBetはポットが小さい状態から始まるため、50〜75%のポット比率で打つのが標準です。OBは「フロップでチェックバック → 突然オーバーベット」というストーリー崩壊を引き起こすため、原則として避けます。

| ハンドタイプ | 推奨サイズ |
|---|---|
| FD / OESD完成（セミブラフ） | 75〜100% |
| 中強度バリュー（TP以上） | 50〜75% |
| 薄バリュー（TP弱キッカー） | 33〜50% |

## 11-7 3選択肢の判断マトリクス

バレルスコアとハンドクラスを組み合わせた判断マトリクスを示します。フロップCBet後のターン判断（ダブルバレル vs チェックバック）に使います。

### フロップCBet後のターン判断

| バレルスコア | HandScore | 推奨アクション |
|---|---|---|
| ≥ 7（積極） | ≥ 20（ナッツ） | バリューベット（75%+） |
| ≥ 7（積極） | 15〜19（強TP） | バリューベット（50〜75%） |
| ≥ 7（積極） | 8〜14（セミブラフ） | セミブラフベット（50%） |
| ≥ 7（積極） | 4〜7（SDV） | チェックバック（SDV保護） |
| < 7（依存） | ≥ 15 | バリューベット（33〜50%） |
| < 7（依存） | 8〜14 | 強ドローのみベット |
| < 7（依存） | < 8 | チェックバック（攻撃放棄） |

### 遅延CBetの判断（フロップCB後）

| ターンカードの性質 | ハンドタイプ | 推奨アクション |
|---|---|---|
| OOP不利（OC / ペア） | FD / OESD完成 | 遅延CBet（75%） |
| OOP不利（OC / ペア） | 中強度バリュー | 遅延CBet（50〜75%） |
| 中立（ブランク） | 中強度バリュー | 選択的に遅延CBet（50%） |
| OOP有利（コネクター / フラッシュ） | 全ハンド | チェックバック継続 |

## 11-8 実戦例

### 実戦例1: ドライ板 × OCターンのダブルバレル

**状況**: BTN vs BB、100BB キャッシュ。プリフロップポット 6BB。

フロップ: K♣7♦2♠（ドライ）、BTN 33%（2BB）CBet → BB コール。ターン前ポット: 10BB。

ターン: A♥

**バレルスコア計算**:
- FlopType: ドライ → 係数 8
- TurnCard: A♥ = オーバーカード（K72の最高位Kを上回る） → 係数 3
- バレルスコア = 8 + 3 = **11** → 積極バレルゾーン

**ハンド別判断**（ボード: K♣7♦2♠A♥）:

IPハンド AK（A♠K♦）:
- カード確認: A♠, K♦ + K♣, 7♦, 2♠, A♥ → A×2, K×2, 7, 2
- 役: 2ペア A's & K's（A-A-K-K-7）
- 判断: 強2ペア → 75%バリューベット（7.5BB）

IPハンド KQ（K♠Q♦）:
- カード確認: K♠, Q♦ + K♣, 7♦, 2♠, A♥ → K×2, A, Q, 7, 2
- 役: ワンペアK's（A-K-K-Q-7）、フロップのTPTKがAターンでセカンドペアに格下げ
- 判断: SDV保護 → チェックバックが現実的な選択（バレルスコアは11でも、このハンドは弱体化）

IPハンド A5（A♣5♦）:
- カード確認: A♣, 5♦ + K♣, 7♦, 2♠, A♥ → A×2, K, 7, 5, 2
- 役: ワンペアA's（A-A-K-7-5）
- 判断: トップペア弱キッカー → 50%薄バリューベット（5BB）

**ナッツアドバンテージの確認**: A♥落ちでIPのAx（AK, AQ, AJ, AT...）が全て強化されます。BBのコールレンジにAx（K♣7♦2♠にコールしたBBのAx）は少なく、IPにナッツアドバンテージがあります。これがバレルスコア11の根拠です。

---

### 実戦例2: コネクテッド板 × コネクターターンのチェックバック（SDV保護）

**状況**: BTN vs BB、100BB キャッシュ。プリフロップポット 6BB。

フロップ: T♦9♣8♥（コネクテッド）、BTN 50%（3BB）CBet → BB コール。ターン前ポット: 12BB。

ターン: 6♠

**バレルスコア計算**:
- FlopType: コネクテッド → 係数 3
- TurnCard: 6♠ = コネクター（6-7-8-9-T の連続を強化） → 係数 0
- バレルスコア = 3 + 0 = **3** → ハンド依存ゾーン

**ボード確認**（K♣7♦2♠ではなくT♦9♣8♥6♠）:

T♦9♣8♥6♠上のストレート完成確認:
- 6-7-8-9-T: 7が必要 → 7を持つハンド（7X）でストレート完成
- ボード自体は T,9,8,6（T-9-8と6の間に7の欠け）

IPハンド A♥A♦:
- カード確認: A♥, A♦ + T♦, 9♣, 8♥, 6♠
- ストレート: A-T-9-8-7? 7なし。不成立
- 役: ワンペアA's（A-A-T-9-8）
- HandScore: アンダーペア(AA)は通常 HandScore 15程度だが、このウェットボードでは実質的に弱化
- 判断: HandScore < 15なので → バレルスコア3(ハンド依存) + ウェットボードの不利 → チェックバック推奨

**理由の詳細**: T98 + 6 のコネクテッドボードでは、BBのコールレンジに多数のドロー・ペア系が含まれています。6♠落ちでJ7、75など複数のストレート完成があり得ます（7でT-9-8-7-6完成）。AAでベットしてもコールされるレンジが強く、フォールドエクイティも期待できません。

**SDV保護の意味**: AAをチェックバックすることで、リバーでショーダウンを目指します。リバーカードによってはプロービングベットも検討します。

### 実戦例3: 遅延CBetの実践

**状況**: BTN vs BB、100BB キャッシュ。プリフロップポット 6BB。

フロップ: K♦7♣2♠（ドライ）、BTN **チェックバック** → BB チェック。ターン前ポット: 6BB（チェック/チェック）。

ターン: A♥（OOPに不利なOC）

OOPがターンでチェック → IPは遅延CBetの判断へ。

**遅延CBetの判断**:
- ターンカード: A♥ = OCで、K72のBBのKx（フロップトップペア）がセカンドペアに格下げ
- BBはAを持っていれば強化されるが、BB vs BTN SRPでK72にコールしたBBのAx比率は限定的
- OOPがチェックした事実: BBが先手ベットしなかった = BBもあまり強くない

IPハンド A♣J♣:
- カード確認: A♣, J♣ + K♦, 7♣, 2♠, A♥ → A×2, K, J, 7, 2（別スート確認: A♣とA♥は別カード）
- 役: ワンペアA's（A-A-K-J-7）
- フロップCBの理由: フロップでKがトップだったが、AJはAがなくワンペアもなし → チェックバック（中強度バリューではなくブロードウェイ系の投機）
- ターンA♥でAJ → トップペアに昇格（ターン改善）

**遅延CBet実行**: 50〜75%ポット（3〜4.5BB）

- 目的: トップペア（TA）でのバリュー取り + BBのKxをフォールドさせる
- ストーリー: 「フロップで様子見 → ターンAで強化した」は論理一貫

BBの後手スコア（第9章参照）計算例:
- BBがKQ（ワンペアK's → セカンドペアに格下げ）を持つ場合
- HandScore: セカンドペア ≈ 8
- 後手スコア = HandScore + A − 3 − C（50%ベット=5）= 8 + 2 − 3 − 5 = **2** → コール
- BBはKQでコール検討範囲、しかし薄い

### 実戦例4: ペアターンでの積極バレル（hand evolutionの確認）

**状況**: BTN vs BB、100BB キャッシュ。プリフロップポット 6BB。

フロップ: K♣7♦2♠（ドライ）、BTN 33%（2BB）CBet → BB コール。ターン前ポット: 10BB。

ターン: 7♥（ペアターン）

**バレルスコア計算**:
- FlopType: ドライ → 係数 8
- TurnCard: 7♥ = ペア（ボードK♣7♦2♠の7と同ランク） → 係数 4
- バレルスコア = 8 + 4 = **12** → 積極バレルゾーン（最高クラス）

**hand evolution の確認**（ボード: K♣7♦2♠7♥）:

IPハンド KK（K♠K♥）:
- 注意: K♠があるのでボードのK♣とは別カード（デッキ整合性OK）
- Ranks: K×3（K♠,K♥ + K♣）, 7×2（7♦,7♥）
- 役: フルハウス K's full of 7's（K-K-K-7-7）
- 判断: モンスターハンド → 75%バリューベット（7.5BB）

IPハンド AK（A♠K♦）:
- Ranks: A×1, K×2（K♦ + K♣）, 7×2（7♦,7♥）
- 役: 2ペア K's & 7's（A-K-K-7-7）
- 判断: 強2ペア → 75%バリューベット（7.5BB）

IPハンド A5（A♣5♦）:
- Ranks: A×1, K×1, 7×2, 5×1, 2×1
- 役: ワンペア 7's（A-K-7-7-5）
- 判断: ボードペアのみ = 弱い。HandScore < 8 → チェックバック or 純ブラフ検討

IPハンド 77（7♣7♠）:
- Ranks: 7×4（7♣,7♠ + 7♦,7♥）, K×1, 2×1
- 役: クワッズ 7's（7-7-7-7-K）
- 判断: ナッツ → トラップ（チェックバック）またはバリューベット

**ペアターンでのIP優位性**: 7♥落ちでIPの高位ポケットペア（KK, QQ）がフルハウスに昇格します。AKも2ペアに。BBのコールレンジは、フロップのK高位ボードに対して7x（セカンドペア系）のコールが少なく、IPがナッツアドバンテージを持つためバレルスコア12は正当です。

### 実戦例5: broadway完成の見落とし注意

**状況**: BTN vs BB、100BB キャッシュ。プリフロップポット 6BB。

フロップ: K♠Q♠T♠（スーテッド + コネクテッド複合）、BTN CBet → BB コール。ターン前ポット変動。

ターン: J♥（コネクター）

**バレルスコア計算**:
- FlopType: スーテッド（かつコネクテッド） → 係数は「スーテッド」= 4
- TurnCard: J♥ = コネクター（K-Q-J-T の連続を完成） → 係数 0
- バレルスコア = 4 + 0 = **4** → ハンド依存ゾーン

**ストレート確認（重要）**（ボード: K♠Q♠T♠J♥）:

このボードでは多くのハンドがブロードウェイ（broadway）またはK-high straightを完成させています。見落としに注意してください。

IPハンド A♣J♣:
- カード確認: A♣, J♣ + K♠, Q♠, T♠, J♥
- 注意: J♣とJ♥は別カード（デッキ整合性OK）
- ストレート確認: A-K-Q-J-T = **broadway 完成**（5連続）
- フラッシュ確認: ♣ = A♣, J♣ = 2枚。♠ = K♠, Q♠, T♠ = 3枚 → フラッシュ不成立
- 役: **ブロードウェイ straight**
- 判断: ナッツ straight → バリューベット最優先（HandScore ≥ 20）

IPハンド 9♣8♣:
- カード確認: 9♣, 8♣ + K♠, Q♠, T♠, J♥
- ストレート確認: K-Q-J-T-9 = **K-high straight 完成**（5連続）
- フラッシュ: ♣ = 9♣, 8♣ = 2枚。♠ = K♠, Q♠, T♠ = 3枚 → 不成立
- 役: K-high straight
- 判断: 強ストレート → バリューベット

このボードでは、A、9、8を持つ多くのハンドがストレートを完成させています。「J落ちでコネクター = 危険」という感覚だけで全チェックバックするのは過剰な慎重さです。

**フラッシュドローの注意**: ♠が3枚あり、♠のFDが多く存在します。A♠9♠は ♠ = A♠, 9♠, K♠, Q♠, T♠ = 5枚でロイヤルフラッシュになります。バレルスコア4のハンド依存ゾーンでも、ナッツ系ハンドはHandScore ≥ 20として積極的にベットします。

## 11-9 第12章への橋渡し ─ OOPの応戦

本章では「IPが攻撃を選ぶ基準」を学びました。ダブルバレル・遅延CBet・チェックバックの使い分けは、バレルスコアを軸にしつつ、個別ハンドの強さとボード上の役変化を確認して行います。

IPの攻撃が決まれば、次はOOP（BB）がどう応戦するかが問われます。第12章では後手スコア（第9章）を使い、OOPがコール / チェックレイズ / フォールドを判断する論理を扱います。

ここで本章との接点を一つ確認してください。遅延CBetを受けたOOPの視点では「IPのフロップCBレンジは中強度が中心でナッツが少ない（Capped）」という情報を活用できます。第2章で学んだCapped vs Uncappedの概念がここで生きてきます。

## ミニクイズ

### 問1

BTN vs BB、フロップ A♠8♦3♣（ドライ）でBTNがCBet、BBがコール。ターン T♦が落ちた。

BTNのハンドは Q♠J♦（ストレートドロー検討）。バレルスコアと推奨アクションは何ですか。

1. バレルスコア = 10（ドライ8 + OC3 = 11?）→ 積極バレル、ダブルバレル実行
2. バレルスコア = 10（ドライ8 + ブランク2 = 10）→ HandScore依存、QJのHandScoreを計算
3. バレルスコア = 11（ドライ8 + OC3 = 11）→ 積極バレル、ただしQJはチェックバック

### 問2

フロップ K♥8♦3♣（ドライ）でBTNがチェックバック、BBがチェック。ターン A♥が落ちて、BBがチェック。BTNは遅延CBetを検討している。最も適切な説明はどれですか。

1. フロップCBをしていないので、ターンでベットするのは「ストーリー崩壊」。遅延CBetは禁止
2. A♥落ちはBBのKx（フロップトップペア）をセカンドペアに格下げし、IPがAhを持つ可能性がある。遅延CBetが有効な局面
3. ターンA♥はOCなのでバレルスコアが高い。すべてのハンドでダブルバレル推奨

### 問3

BTN vs BB、フロップ J♠7♦5♣（セミ）でBTNがCBet、BBがコール。ターン T♠が落ちた。

BTNのハンドは 8♣6♣。バレルスコアとその判断を選んでください。

1. バレルスコア = 6（セミ6 + コネクター0 = 6）→ ハンド依存。8♣6♣のストレート確認が必要
2. バレルスコア = 9（セミ6 + OC3 = 9）→ 積極バレル。8♣6♣でダブルバレル
3. バレルスコア = 7（セミ6 + ブランク1? = 7）→ 境界値。チェックバック推奨

---

### 解答

- **問1**: 2（T♦はA♠8♦3♣にとってブランク。TはAより低く、フロップの最高位Aを上回らないため「オーバーカード」ではなくブランク扱い。ドライ8 + ブランク2 = 10 → 積極バレルゾーン。ただし手順として、TがOCかブランクかを正確に分類することが必要）

- **問2**: 2（フロップCBは「遅延CBet禁止」を意味しません。フロップCBをした理由（中強度 / バックドアドロー等）が有力で、ターンA♥がOOPに不利なOCとして機能している局面では遅延CBetは有効な攻撃手段。選択肢3が誤りなのは「チェックバックをしていたIPにはダブルバレルの概念が当てはまらない」ため）

- **問3**: 1（T♠はJ♠7♦5♣のコネクテッド板にとってコネクター。TはJ-T-9-8-7 のストレートを強化する可能性がある。セミ6 + コネクター0 = 6 → ハンド依存ゾーン。8♣6♣のHandScore計算: ボードJ7-5-TでOESD 8-7-6-5-4? 4アウツか → ガットショット確認が必要。9-8-7-6-5は9が必要。8-7-6-5: ボードに7と5あり、8と6はハンド。9でT-9-8-7-6またはJでJ-T-9-8-7? Jでストレート完成を狙えるOESDに近い状況 → セミブラフ検討余地あり）

---

> **本章まとめ**
>
> - IPのターン攻撃は「ダブルバレル / チェックバック / 遅延CBet」の3択
> - **ダブルバレル**: バレルスコア ≥ 7 → 全レンジで推奨。< 7 → HandScoreで絞り込み
> - **チェックバック**: SDV保護 / トラップ / 攻撃放棄の3用途。「失敗」ではなく戦略的選択
> - **遅延CBet**: OOPに不利なターンカード（OC / ペア）+ IPが改善した局面で有効
> - サイズ: フロップ33%後はターン50%が標準。強ハンドは75%+でポットを膨らませる
> - ペアターンは hand evolution の確認が必須（KK on K72 + 7 = フルハウス / AK = 2ペア K's & 7's）
> - broadway等の完成ストレートを見落とさない（KQTJ ボードでA / 9 を含むハンドは完成）

**【GTOとのズレ】**

バレルスコアは「レンジ全体の平均的な傾向」を示す式です。実際のGTOでは、同じ「積極バレルゾーン（スコア≥7）」でも、コンボ単位で異なるベット頻度が割り当てられます。たとえばAKはほぼ100%バリューベットで、88（アンダーペア）はチェックバック頻度が上がるという形で細かい調整が入ります。

実戦で最も多い「GTOとのズレ」は**チェックバックのし過ぎ**です。「ウェットボードだから」「ターンが悪いから」という感覚でチェックバックを選びすぎることで、フォールドエクイティを活用できる局面を損失しています。GTO実測270シナリオで、ターンCBet頻度が70%以上のシナリオは全体の67%を占めます。直感が「チェック」を示すときでも、バレルスコアで確認してから判断してください。

逆に「積極バレルゾーン=全部打てる」と解釈するのも誤りです。SDV保護が必要な中強度ハンド（セカンドペア・弱いトップペアなど）は、バレルスコアが高くても個別にチェックバックが正解の場合があります。スコアはレンジ全体への指針で、ハンドの強さとターンでの役変化を確認して最終判断を下してください。

遅延CBetについては、実戦で「フロップCBをしなかったから何もできない」と思い込むプレイヤーが多く見られます。フロップでの選択とターンでの選択を切り離して考えること。OOPに不利なターンカードが落ち、OOPがチェックしてきた局面では、遅延CBetが明確なEVプラスのアクションになり得ます。
