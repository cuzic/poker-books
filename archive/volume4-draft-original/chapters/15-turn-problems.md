# 第15章　ターン実戦例 20問

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 第6章〜第14章で学んだターンの概念・式・戦術を、20問の実戦形式で総復習する。バレルスコア・α式・後手スコア・ブロッカー論の計算プロセスを体に染み込ませる。

---

## 15-1 本章の使い方

第III部（第11章〜第15章）はターン戦略の習得を目的とした実戦演習パートです。本章はその最終章であり、20問を通じて知識を「行動に結びつける力」に変換します。

各問題は次の構成になっています。

```
状況設定（スタック・ポット・ポジション・フロップアクション）
→ ターンカード提示
→ 4択の設問
→ 解答（計算過程込み）
```

問題を見たらまず自分で考えてから解答を読んでください。計算式を暗算で回すことが目的です。答えが当たったかどうかよりも、「なぜその答えになるか」を計算で説明できるかどうかが重要です。

### 基本前提（全問共通）

```
形式: 6-max キャッシュゲーム、100BB
スタック: BTN 100BB、BB 100BB
プリフロップ: BTN 2.5BB オープン → BB コール
ポット（フロップ前）: 5.5BB
スタック残り: 97.5BB（各自）
```

問ごとにフロップアクションが異なります。ターン時点のポットとスタックは各問題に明示します。

### 式の早見表

演習中にいつでも参照できるように、本章で使う3つの式をまとめます。

```
バレルスコア（第7章）:
  = FlopType係数 + TurnCard係数
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0
  ≥7 → 積極バレル / <7 → ハンド依存

後手スコア（第9章、HU前提のためM=0）:
  = HandScore + A − 3 − C
  A: ドライ=3 / セミ=2 / ウェット=1
  C: 33%ベット=3 / 50%ベット=5 / 75%ベット=7
  ≥8 → CR検討 / 0〜7 → コール / <0 → フォールド

α式（第8章）:
  α = ベット額 ÷ (ポット + ベット額)
  後手下限確率 = 1 − α = ポット ÷ (ポット + ベット額)
```

## 15-2 第1部: IPのダブルバレル判断（問1〜5）

IP（BTN）がフロップでCBetを打った後、ターンで継続するかどうかをバレルスコアで判断します。バレルスコアは「板の方向性」を示しますが、最終判断は自分のハンドのクラスと組み合わせます。

---

### 問1

**状況**: BTN vs BB（HU）。フロップ K♣7♦2♠（ドライ板）でBTNが33%CBet（約1.8BB）、BBコール。

- ポット（ターン前）: 約9BB
- スタック残り: 約96BB

**ターンカード**: 3♥

**BTNのハンド**: A♠K♥（トップペア、Aキッカー）

フロップのCBetが通らずBBがコールした。ターン3♥は何も変えないブランクに見える。BTNはどう行動すべきか？

```
A. ダブルバレル（50%ポット、約4.5BB）
B. ダブルバレル（75%ポット、約6.75BB）
C. チェックバック（SDV保護）
D. ダブルバレル（33%ポット、約3BB）
```

**解答**

**正解: A. ダブルバレル（50%ポット、約4.5BB）**

**ボード読み確認**: A♠K♥ + K♣7♦2♠3♥ = A, K, K, 7, 2, 3。Kが2枚でトップペア（Aキッカー）。ストレートは最短でA-2-3-4-5（4が無い）、K-Q-J-T-9（QJが無い）。フラッシュなし。役はワンペア（K's、Aキッカー）。

**バレルスコア計算**:
- FlopType係数: K♣7♦2♠はドライ板（レインボー、連続なし）→ **8**
- TurnCard係数: 3♥はフロップの最低ランクより低く、ストレートもフラッシュも絡まないブランク → **2**
- バレルスコア = 8 + 2 = **10** → 積極バレル

**判断の根拠**: バレルスコア10は積極バレルゾーン。A♠K♥はこのボードでトップペアトップキッカー（TPTK）という明確なバリューハンドです。BBのコールレンジには K7、K2、セカンドペア（77、22）、各種ドロー（なし。ドライ板のため）などが残ります。3ターンはBBのレンジを強化しないため、バリューベットの環境が整っています。

**サイズ選択**: 50%ポット（約4.5BB）が標準。75%にするとBBの弱いKx（K6以下）がフォールドしやすくなり、バリューが取れる相手を逃します。33%は薄すぎて、後続のリバーで続けにくくなります。

**よくある誤り**: 「3が落ちてフロップと変わらないので、フロップと同じ判断で良い」という思考はターンの意味を軽視しています。ターンはポットが大きくなり、BBの守りにくさが増した分、バリューを取るチャンスです。

---

### 問2

**状況**: BTN vs BB（HU）。フロップ J♦9♣4♠（セミ板）でBTNが33%CBet（約1.8BB）、BBコール。

- ポット（ターン前）: 約9BB
- スタック残り: 約96BB

**ターンカード**: 6♦

**BTNのハンド**: K♠Q♠（オーバーカード2枚、スペードバックドアフラッシュドロー）

バレルスコアはいくつか。BTNはどう行動すべきか？

```
A. ダブルバレル（50%ポット）
B. チェックバック
C. ダブルバレル（75%ポット）
D. ダブルバレル（33%ポット）
```

**解答**

**正解: B. チェックバック**

**ボード読み確認**: K♠Q♠ + J♦9♣4♠6♦ = K, Q, J, 9, 4, 6。全て異なるランク。ストレートは5連続で確認: K-Q-J-T-9（Tなし）、Q-J-T-9-8（T,8なし）、J-T-9-8-7（T,8,7なし）→ 完成なし。スペード: K♠, Q♠, 4♠ = 3枚（5枚未満）。役はハイカード（Kハイ）。

**バレルスコア計算**:
- FlopType係数: J♦9♣4♠はセミ板（スートは複数、連続性はJ-9でギャップあり）→ **6**
- TurnCard係数: 6♦はコネクター（フロップの4♠と6♦で4-5-6の連続を部分的に作る）→ **0**
- バレルスコア = 6 + 0 = **6** → ハンド依存

**ハンドの評価**: K♠Q♠はこのボードで何もありません。フロップの役もなく、ターンでも役がつきませんでした。スペードバックドアフラッシュドローはターン6♦でスペード3枚止まり（リバーで1枚追加が必要）。バックドアは確率が低く（約4%）、セミブラフとして機能しません。

**判断の根拠**: バレルスコア6はハンド依存ゾーンです。このゾーンでは「強いセミブラフ（8アウツ以上のドロー）か強いバリュー」のみがバレルに値します。K♠Q♠は「何も持っていないハンド」に分類されます。チェックバックしてリバーを見ましょう。

**よくある誤り**: 「オーバーカードが2枚あるから打てる」という判断は誤りです。KやQのオーバーカードは各3枚がアウツになりますが（合計6アウツ）、このボードでは9や4などのミドルランクに当たるBBのハンドがコールを続けます。打っても期待値がわずかに負のことが多いです。

### 問3

**状況**: BTN vs BB（HU）。フロップ K♣7♦2♠（ドライ板）でBTNが33%CBet（約1.8BB）、BBコール。

- ポット（ターン前）: 約9BB
- スタック残り: 約96BB

**ターンカード**: 7♥（ペアターン）

**BTNのハンド**: J♥J♠（フロップではオーバーペア）

ターン7♥でボードがペアになった。JJはフロップで「K,7,2の全てに勝つオーバーペア」だったが、ターンでどう変化したか？

```
A. ダブルバレル（50%ポット）
B. チェックバック
C. ダブルバレル（75%ポット）
D. ダブルバレル（33%ポット）
```

**解答**

**正解: A. ダブルバレル（50%ポット）**

**ボード読み確認（ペアターン hand evolution）**: J♥J♠ + K♣7♦2♠7♥ = J, J, K, 7, 2, 7。ランクカウント: J=2, K=1, 7=2, 2=1。

フロップ時点ではJJはオーバーペア（K,7,2の全てに勝つ2番手の強さ）。ターン7♥でボードに7が2枚になる（7-7）。

ハンド役の確認:
- JJ（ポケット）: 2枚持っているJ + ボードの7-7
- Best 5: J-J-K-7-7 = **2ペア（J's & 7's、Kキッカー）**

JJはターンで「オーバーペア」から「2ペア（JJ & 77）」に昇格しました。

**バレルスコア計算**:
- FlopType係数: K♣7♦2♠はドライ板 → **8**
- TurnCard係数: 7♥はフロップの7♦と同ランク → ペア → **4**
- バレルスコア = 8 + 4 = **12** → 積極バレル

**判断の根拠**: バレルスコア12は積極バレルゾーンの上位。JJの2ペアは強力なバリューハンドです。BBのコールレンジには K7（フルハウス）や77（クワッズ）といった上位ハンドも含まれますが、それらは全体の一部です。JJに勝つBBのハンドは K7・K2・22・77と限定的であり、残りの多数（KJ以下のKx、ポケットペア中位以下）はJJに負けます。

50%ポットでバリューを取りながら、リバーへの圧力を維持する設計が最適です。

**よくある誤り**: 「ペアターンで相手も強くなった可能性があるのでチェックバック」という思考は誤りです。ペアターンはIPのオーバーペアを「2ペア」に昇格させ、むしろIPにとって有利に働くことが多い。第7章のデータでも、ペアターンのバレルスコアは最高係数（+4）を持ちます。

### 問4

**状況**: BTN vs BB（HU）。フロップ K♠9♠5♠（スーテッドスペード板）でBTNが33%CBet（約1.8BB）、BBコール。

- ポット（ターン前）: 約9BB
- スタック残り: 約96BB

**ターンカード**: A♠（フラッシュターン：スペード4枚目）

**BTNのハンド**: Q♥J♥（ハートのセミドロー、スペード無し）

ターンA♠でスペードが4枚になった。BTNはどう行動すべきか？

```
A. ダブルバレル（50%ポット）
B. チェックバック
C. ダブルバレル（75%ポット）
D. ダブルバレル（33%ポット）
```

**解答**

**正解: B. チェックバック**

**ボード読み確認**: Q♥J♥ + K♠9♠5♠A♠ = Q, J, K, 9, 5, A。スペード: K♠, 9♠, 5♠, A♠ = 4枚。Q♥J♥はスペードを1枚も持っていません。ストレートは: A-K-Q-J-T（Tなし）、K-Q-J-T-9（Tなし）→ 完成なし。役はハイカード（Aハイ）。

**重要なボード評価**: ボードにスペードが4枚並んでいますが、QJのハンドはスペードを持っていません。スペードを1枚持つプレイヤーのみがフラッシュ（5枚目の同スート）を持っています。Q♥J♥がフラッシュを持っているわけではありません。

**バレルスコア計算**:
- FlopType係数: K♠9♠5♠はスーテッド板（3枚同スート）→ **4**
- TurnCard係数: A♠はスペード4枚目（フラッシュドロー強化カード）→ フラッシュ → **1**
- バレルスコア = 4 + 1 = **5** → ハンド依存

**ハンドの評価**: Q♥J♥はこのボードで役がつきません（ハイカード）。ハートのバックドアフラッシュドローはリバー1枚では完成不可能（フロップ後は2枚必要、現在ターン後で残り1枚のみ）。セミブラフとして機能するアウツがほぼゼロです。

**チェックバックの理由**: ハンド依存ゾーン（バレルスコア5）で、かつQ♥J♥は何も持っていないハンドです。A♠が落ちたことでBBのAx♠（ナッツフラッシュ）が完成しており、バレルするとフラッシュを持つBBに強くコールされます。フォールドエクイティが極めて低い状況です。

**よくある誤り**: 「Aというオーバーカードが落ちたので打てる（OC効果）」という誤判断。A♠は確かにオーバーカードですが、スーテッドボードでのフラッシュターンです。TurnCard係数はOCではなくフラッシュ（+1）を適用します。

### 問5

**状況**: BTN vs BB（HU）。フロップ K♣7♦2♠（ドライ板）でBTNが33%CBet（約1.8BB）、BBコール。

- ポット（ターン前）: 約9BB
- スタック残り: 約96BB

**ターンカード**: A♥（オーバーカードターン）

**BTNのハンド**: 8♠8♦（フロップでアンダーペア）

バレルスコアを計算し、アンダーペアでダブルバレルするかどうかを判断せよ。

```
A. ダブルバレル（50%ポット）—セミブラフとして有効
B. チェックバック—SDV保護
C. ダブルバレル（33%ポット）—薄いバリューを取る
D. フォールド
```

**解答**

**正解: B. チェックバック（SDV保護）**

**ボード読み確認**: 8♠8♦ + K♣7♦2♠A♥ = 8, 8, K, 7, 2, A。ランクカウント: 8=2, A=1, K=1, 7=1, 2=1。ストレート: A-2-3-4-5（3,4,5なし）。役はワンペア（8's）。

**バレルスコア計算**:
- FlopType係数: K♣7♦2♠はドライ板 → **8**
- TurnCard係数: A♥はフロップの最高ランクKより高いオーバーカード → OC → **3**
- バレルスコア = 8 + 3 = **11** → 積極バレル

**なぜ積極バレルゾーンなのにチェックバックか？**

バレルスコア11は確かに積極バレルゾーンです。しかし「積極バレル」はレンジ全体のCBet頻度が高くなることを意味し、「全てのハンドでバレルする」という意味ではありません。

8♠8♦の問題点を整理します。

1. Aがターンで落ちると、BBのコールレンジにAx（AK, AQ, AJなど）が含まれ、これらは全て8♠8♦に勝ちます。
2. 8♠8♦はアンダーペア（K, 7, 2の全てに負ける）でした。Aが落ちても依然アンダーペアです。
3. セミブラフとして機能するためにはアウツが必要ですが、8は既にセットを狙うには6アウツ（残り2枚の8は3アウツ、計算ミス：残りの8は2枚）しかなく、かつBBのAx対してはセット（888）が必要で、それでも負ける可能性があります。

**正しい判断**: 8♠8♦はショーダウン価値（SDV）があります。BBがチェックしてくれればリバーで安くショーダウンへ持ち込めます。バレルするとBBのAx（現在トップペア）にコールされ続け、ショーダウンで負けます。

## 15-3 第2部: 遅延CBet / チェックバック判断（問6〜10）

フロップでチェックバックしたIPが、ターンでどう行動するかを問います。遅延CBetはフロップでトラップまたはSDV保護をした後、ターンで新たな優位性を得たときに用います。

---

### 問6

**状況**: BTN vs BB（HU）。フロップ J♣8♦4♥（セミ板）でBTNがチェックバック（遅延CBet狙い）、BBもチェック。

- ポット（ターン前）: 5.5BB（ベット無しのためフロップ前と同額）
- スタック残り: 97.5BB

**ターンカード**: J♠（ペアターン）

**BTNのハンド**: K♠J♦（フロップでトップペアをトラップ、ターンでトリップス完成）

OOPがターンでチェック。BTNはどう行動すべきか？

```
A. 遅延CBet（50%ポット）
B. 遅延CBet（75%ポット）
C. チェックバック（更なるトラップ）
D. 遅延CBet（33%ポット）
```

**解答**

**正解: A. 遅延CBet（50%ポット）**

**ボード読み確認（ペアターン hand evolution）**: K♠J♦ + J♣8♦4♥J♠ = K, J, J, 8, 4, J。ランクカウント: J=3（ハンド1枚＋ボード2枚）。

役の計算:
- 自分がJ♦を1枚持ち、ボードにJ♣とJ♠の2枚があるので、合計Jが3枚。
- Best 5: J-J-J-K-8 = **トリップス（J's、Kキッカー）**

フロップでのKJはトップペア（J♣がトップ）。J♠ターンでボードのJが2枚に増え、自分のJ♦を加えてトリップスに昇格しました。

**遅延CBetの正当性**: 遅延CBetはフロップで強いハンドを持ちながらチェックバックし、ターンでベットする戦術です（第11章参照）。KJトリップスはこのシナリオで最もバリューベットに適したハンドの1つです。

**サイズ**: 50%ポットが適切。75%は価値を最大化しますが、BBが「BTNがターンに突然打ってきた＝弱いハンドでのブラフか、逆に超強いハンド」と読んでフォールドしやすくなる懸念があります。50%は「普通のバリューベット」として機能し、BBの中強度ハンド（Jx弱い、8ペア、ポケット中位）からコールを引き出せます。

**トラップの継続検討**: ターンでも継続トラップが有効かを考えます。ターンでチェックすると、リバーでBBが何もベットしないと価値が取れません。トリップス（J's）のような中程度の強さ（クワッズ、フルハウスには負ける）は自分からベットして今確実に取るべきです。

### 問7

**状況**: BTN vs BB（HU）。フロップ J♥9♠8♦（コネクテッド板、ウェット）でBTNが33%CBet（約1.8BB）、BBコール。

- ポット（ターン前）: 約9BB
- スタック残り: 約96BB

**ターンカード**: 5♣（ブランク）

**BTNのハンド**: A♣J♦（フロップでトップペア、ターンで維持）

BBがターンでチェック。BTNはどう行動すべきか？

```
A. ダブルバレル（50%ポット）
B. チェックバック（SDV保護）
C. ダブルバレル（75%ポット）
D. ダブルバレル（33%ポット）
```

**解答**

**正解: B. チェックバック（SDV保護）**

**ボード読み確認**: A♣J♦ + J♥9♠8♦5♣ = A, J, J, 9, 8, 5。ランクカウント: J=2（1+1）。役: ワンペア（J's、Aキッカー）= TPTK（Jがトップ）。ストレート: J-T-9-8-7（T,7なし）、T-9-8-7-6（T,7,6なし）、9-8-7-6-5（7,6なし）、8-7-6-5-4（7,6,4なし）→ 完成なし。フラッシュなし。

**バレルスコア計算**:
- FlopType係数: J♥9♠8♦はコネクテッド板（J-9-8で2連続＋ギャップ）→ **3**
- TurnCard係数: 5♣はフロップのいずれとも連続しないブランク → **2**
- バレルスコア = 3 + 2 = **5** → ハンド依存

**SDV保護の理由**: バレルスコア5はハンド依存ゾーン。このゾーンでダブルバレルするためには強いバリュー（2ペア以上）か強いセミブラフが必要です。

AJはトップペアですが、J♥9♠8♦のコネクテッドボードには：
- ストレート完成ハンド（QT, T7, 76, 65など）
- 2ペア（J9, J8, 98）
- セット（JJ, 99, 88）

これらがBBのコールレンジに含まれています。AJでバレルすると、これらの強いハンドにコールされ続け、ショーダウンで敗北します。

**チェックバック後の戦略**: リバーでBBがブラフしてくれれば、コールで対応します。BBがチェックしてきたら、安全なリバーカード（コネクテッドでないカード）であれば薄いバリューベットを検討します。

### 問8

**状況**: BTN vs BB（HU）。フロップ A♣K♦Q♥（コネクテッド板）でBTNがチェックバック（トラップ）、BBもチェック。

- ポット（ターン前）: 5.5BB
- スタック残り: 97.5BB

**ターンカード**: J♠（コネクター：broadway完成）

**BTNのハンド**: A♠T♥（broadway：A-K-Q-J-Tナッツストレート）

BBがターンでチェック。BTNのブロードウェイは完成した。どう行動すべきか？

```
A. 遅延CBet（75%ポット）
B. チェックバック（スロープレイ継続）
C. 遅延CBet（50%ポット）
D. 遅延CBet（100%ポット）
```

**解答**

**正解: A. 遅延CBet（75%ポット）**

**ボード読み確認**: A♠T♥ + A♣K♦Q♥J♠ = A, T, A, K, Q, J。

ストレートチェック（5連続）:
- A-K-Q-J-T = 5連続 → **ブロードウェイ完成**（A♠T♥により確認）
- K-Q-J-T-9 → 9なし → NO

A♠は2枚目のAですが、ストレートのベストハンドはA-K-Q-J-Tを使います。役はストレート（ブロードウェイ）。

フラッシュ: 各スート（spades=A♠,J♠、hearts=T♥,Q♥、diamonds=K♦、clubs=A♣）にバラつきあり、5枚同スートなし。

**ナッツの確認**: A♠T♥のブロードウェイはこのボードのナッツ（最強の5枚）です。BBも同じAQやAT、KTを持てば同じブロードウェイですが、A♠T♥のコンボとしてのバリューは最高水準です。

**なぜ遅延CBetが最善か**:

1. **ナッツを持っているならベットして取る**: チェックバックでスロープレイすると、リバーで1ストリートしかバリューが取れません。ターンのベットがあれば2ストリートのバリューになります。

2. **BBのコールレンジが厚い**: A♣K♦Q♥J♠のボードはBBにも多くのストレートドロー（KT、QT、J9、T9など）があります。これらが「今コールしやすい状況」を作っています。

3. **75%サイズ**: ターンでの大きめのベットはリバーへの圧力を維持します。スタック97.5BBに対してターンポット5.5BB、75%のターンベット（約4BB）の後、リバーポット13.5BB。リバーで大きなバリューベットを入れる設計です。

**スロープレイが有効な局面**: 今回は有効ではありません。スロープレイはリバーでBBがブラフするかベットするかを期待する戦術ですが、AKQJ板ではBBもナッツを持てるため、お互いにチェックし合うシナリオになりがちです。今バリューを取りましょう。

### 問9

**状況**: BTN vs BB（HU）。フロップ K♣4♦2♠（ドライ板）でBTNがチェックバック（弱いハンドで見送り）、BBもチェック。

- ポット（ターン前）: 5.5BB
- スタック残り: 97.5BB

**ターンカード**: 5♥（コネクター：ストレートドロー進行）

**BTNのハンド**: 3♠3♦（フロップでウィークポケットペア、ターン5♥でOESD化）

BBがターンでチェック。3♠3♦はフロップでチェックバックしたウィークハンドだが、ターンで状況が変わった。どう行動すべきか？

```
A. 遅延CBet（50%ポット）—OESDを持つセミブラフ
B. チェックバック—SDVとして守る
C. 遅延CBet（33%ポット）—小さめのセミブラフ
D. オールイン
```

**解答**

**正解: A. 遅延CBet（50%ポット）**

**ボード読み確認**: 3♠3♦ + K♣4♦2♠5♥ = 3, 3, K, 4, 2, 5。ランクカウント: 3=2, K=1, 4=1, 2=1, 5=1。

OESDの確認: ボード + ハンドのランク = {K, 5, 4, 3, 2}。連続確認:
- 2-3-4-5 = 4連続（両端: A or 6で完成）→ **OESD（8アウツ）**
- ストレート完成: A-2-3-4-5は5連続だが、Aは無い → 未完成
役: 3-3 = ウィークポケットペア + OESD

**遅延CBetの根拠**: フロップのK♣4♦2♠で3♠3♦は「Kに負けるアンダーペア」として価値が薄く、チェックバックは正しい選択でした。しかしターン5♥により、2-3-4-5の4連続OESDが生まれました。

セミブラフとして打つ条件が整いました:
1. フォールドエクイティ: フロップでチェックバックした後のターンベットは「遅延CBet」として、BBに「BTNがターンで強化された」メッセージを送ります。
2. アウツ: OESDは8アウツ（残りAの4枚 + 6の4枚）。「Rule of 2 and 4」でリバー1ストリートで約16%の完成確率。
3. ポット: ターン前ポット5.5BBで50%CBet（約2.75BB）。コールされた場合のポット11BBに対して、アウツ確率16%は期待値でプラスに働きます。

**よくある誤り**: 「3ペアのSDVを守るためにチェックバック」という判断は理解できますが、3ペアのショーダウン価値は「BBが何もベットしない」前提でのみ有効です。BBのコールレンジにはK高めハンドが多く、ショーダウンで3ペアが勝てる確率は低い。むしろOESDとしてセミブラフを打つ方がトータルEVが高くなります。

### 問10

**状況**: BTN vs BB（HU）。フロップ 8♦7♠6♣（コネクテッド板）でBTNが33%CBet（約1.8BB）、BBコール。

- ポット（ターン前）: 約9BB
- スタック残り: 約96BB

**ターンカード**: J♥（オーバーカード）

**BTNのハンド**: A♥2♣（フロップで完全なエアー、ターンでもエアー）

BBがターンでチェック。BTNはどう行動すべきか？

```
A. ダブルバレル（50%ポット）—継続圧力
B. チェックバック—完全降伏
C. ダブルバレル（33%ポット）—小さめのブラフ
D. ダブルバレル（75%ポット）—大きいブラフで決着
```

**解答**

**正解: B. チェックバック（完全降伏）**

**ボード読み確認**: A♥2♣ + 8♦7♠6♣J♥ = A, 2, 8, 7, 6, J。ストレートチェック: J-T-9-8-7（T,9なし）、T-9-8-7-6（T,9なし）、9-8-7-6-5（9,5なし）。フラッシュ: ハートはA♥,J♥=2枚、クラブは2♣,6♣,8♣...待って、8♦はダイヤ。クラブ: 2♣, 6♣, 8♣ではなく6♣のみ+8♦ダイヤ。クラブは2♣,6♣=2枚のみ。役はハイカード（A高め）。

**バレルスコア計算**:
- FlopType係数: 8♦7♠6♣はコネクテッド板（連続3枚）→ **3**
- TurnCard係数: J♥はフロップの最高ランク8より高いオーバーカード → OC → **3**
- バレルスコア = 3 + 3 = **6** → ハンド依存

**ハンドの評価**: A♥2♣はフロップでもターンでも完全な役なし（エアー）。アウツもほぼゼロ（Aのトップペアを作る3アウツ、2のペアを作る3アウツがあるが、どちらのペアも8-7-6-J の4枚にそれぞれ劣る中位以下のペアにすぎない）。

**コネクテッド板でのブラフの危険性**: 8♦7♠6♣のコネクテッド板でBBがコールを続けているということは、BBはドローか完成ハンド（76、87、JT、T9など）を持っている可能性が高い。ターンJ♥でBBに「JなどのOCが助けた」ハンドが増えます。BBはフォールドしません。

**チェックバック後の展望**: エアーはリバーでブラフする機会を残します。安全なリバーカード（コネクテッドでないもの、BBのレンジを強化しないもの）が落ちれば、そのときに仕掛けます。今は撤退が正解です。

### 問11

**状況**: BB vs BTN（HU）。フロップ K♣9♦5♠（セミ板）でBTNが33%CBet（約1.8BB）、BBコール。ターンでBTNが33%ベット（約2.7BB）。

- ポット（ターン前）: 約9BB
- BTNのターンベット: 約3BB（33%ポット）

**ターンカード**: T♥（オーバーカード）

**BBのハンド**: A♠K♦（フロップでTTPK、ターンでも維持）

BBはBTNの33%ターンベットに対してどう応じるか？

```
A. コール
B. チェックレイズ（2.5倍程度）
C. フォールド
D. チェックレイズ（3倍以上）
```

**解答**

**正解: A. コール**

**ボード読み確認**: A♠K♦ + K♣9♦5♠T♥ = A, K, K, 9, 5, T。ランクカウント: K=2。役: ワンペア K's（Aキッカー、best5: A-K-K-T-9）。ストレートチェック: A-K-Q-J-T（Q,J なし）、K-Q-J-T-9（Q,J なし）→ 完成なし。フラッシュなし。役はTTPKのまま（ターンTは関係しない）。

**後手スコア計算（HU前提のためM=0）**:

HandScoreを推定します。AKはK♣9♦5♠T♥でトップペア（Kがトップ）+Aキッカー。巻2の基準では、トップペアトップキッカーのHandScoreは概ね18〜22程度です（役スコア：トップペア=15、Aキッカー加点=+3、参照値）。ここでは**HandScore ≈ 20**として計算します。

```
後手スコア = HandScore + A − 3 − C
           = 20 + 2 − 3 − 3
           （A=2：K♣9♦5♠はセミ板、C=3：33%ベット）
           = 16
```

後手スコア16 → **コール（0〜7がコール、8以上がCR検討）**

厳密にはスコア8以上でCRを「検討」します。スコア16はCRゾーンに入りますが、A♠K♦でCRするためには「チェックレイズして利益が出るか」を追加で判断します。

**CRが適切でない理由**: AKはトップペアとして強力ですが、K♣9♦5♠T♥のボードには、BTNのレンジにセット（99, 55）やAT, KTなどの2ペアが含まれます。CRして大きなポットを作ると、これらの強いハンドに捕まります。AKはコールで守りながらリバーを見る方が均衡しています。

**フォールドが誤りな理由**: 後手下限確率を確認します。33%ベットのαは 3÷(9+3)=0.25、後手下限確率=75%。BBは75%以上の頻度でコール（またはCR）する必要があります。AKは間違いなくその75%に入る強いハンドです。フォールドは大きな誤りです。

### 問12

**状況**: BB vs BTN（HU）。フロップ 9♥8♦2♣（セミ板）でBTNが33%CBet（約1.8BB）、BBコール。ターンでBTNが75%ベット（約6.75BB）。

- ポット（ターン前）: 約9BB
- BTNのターンベット: 約6.75BB（75%ポット）

**ターンカード**: 4♠（ブランク）

**BBのハンド**: 9♣8♣（フロップから2ペア継続）

BBはBTNの75%ターンベットに対してどう応じるか？

```
A. コール
B. チェックレイズ（2.5倍程度）
C. チェックレイズ（3倍以上）
D. フォールド
```

**解答**

**正解: B. チェックレイズ（2.5倍程度）または C. チェックレイズ（3倍以上）のどちらでも可**

本問の核心はCRをするかどうかです。CR比率（サイズ）は状況依存ですが、CRをする判断自体が重要です。

**ボード読み確認**: 9♣8♣ + 9♥8♦2♣4♠ = 9, 8, 9, 8, 2, 4。ランクカウント: 9=2, 8=2。役: 2ペア（9's & 8's）。best5: 9-9-8-8-4。フラッシュなし（クラブ: 9♣,8♣,2♣=3枚、5枚未満）。

**後手スコア計算（HU前提のためM=0）**:

9♣8♣の2ペアのHandScoreは高水準。巻2の基準では、2ペアの役スコアは概ね25〜30程度です。ここでは**HandScore ≈ 27**として計算します。

```
後手スコア = HandScore + A − 3 − C
           = 27 + 2 − 3 − 7
           （A=2：9♥8♦2♣はセミ板、C=7：75%ベット）
           = 19
```

後手スコア19 → **チェックレイズ検討（8以上でCR検討）**

**CRが適切な理由**: 9♣8♣の2ペアは9♥8♦2♣4♠で非常に強力なハンドです。このボードでBTNが75%という大きなベットを入れてきたことは、BTNが強いハンドまたは大きなブラフを表明しています。9♣8♣はBTNのバリューレンジ（99, 88, 22, T9, 9Xなど）の多くに対して有利です。

CRすることで:
- BTNのブラフをすぐにフォールドさせてポットを獲得する
- BTNの強いハンドから最大バリューを取る

**サイズの考え方**: 2.5倍CR（約16.9BB）は標準的なCRサイズで、BTNにコールかフォールドを強います。3倍以上のCRはより大きなポットを作り、BTNのブラフレンジをフォールドさせつつバリューを大きく取れますが、BTNの強いハンド（セット）にも乗られやすくなります。

### 問13

**状況**: BB vs BTN（HU）。フロップ A♦J♣7♠（セミ板）でBTNが50%CBet（約2.75BB）、BBコール。ターンでBTNが50%ベット（約5.5BB）。

- ポット（ターン前）: 約11BB
- BTNのターンベット: 約5.5BB

**ターンカード**: 5♥（ブランク）

**BBのハンド**: K♥Q♦（役なし、Kのバリューブロッカー保有）

BBはBTNの50%ターンベットに対してどう応じるか？

```
A. コール（ブロッカーを活用したコール）
B. チェックレイズ（ブロッカーCR）
C. フォールド
D. コール（ピュアコール、ブロッカーは関係ない）
```

**解答**

**正解: C. フォールド**

**ボード読み確認**: K♥Q♦ + A♦J♣7♠5♥ = K, Q, A, J, 7, 5。全て異なるランク。ストレートチェック: A-K-Q-J-T（Tなし）、K-Q-J-T-9（T,9なし）→ 完成なし。フラッシュなし。役はハイカード（Aがボード最高、KQはセカンド・サードのみ）。

**後手スコア計算（HU前提のためM=0）**:

K♥Q♦は役なしのハイカード。HandScoreは低い（ドロー加点なし、ブロッカー加点を考慮）。ハイカードのHandScoreは巻2基準で概ね3〜8程度。**HandScore ≈ 5**として計算します。

```
後手スコア = HandScore + A − 3 − C
           = 5 + 2 − 3 − 5
           （A=2：A♦J♣7♠はセミ板、C=5：50%ベット）
           = −1
```

後手スコア-1 → **フォールド（後手スコア<0でフォールド）**

**ブロッカーがあってもフォールドな理由**: K♥Q♦は確かにKを持つことで「BTNのAKのコンボ数を削る」ブロッカー効果があります（第10章参照）。しかし、ブロッカーはフォールドが基本のハンドをコールに変えるほどの効力はありません。

後手スコアが負の場合、ブロッカーの加点（+2〜+3）を加えても：

```
後手スコア（ブロッカー込み）= 5 + 2 − 3 − 5 + 3（ブロッカー加点）= 2
```

スコア2はコールゾーン（0〜7）に入りますが、これは「ピュアコール」の境界ライン付近です。実戦では、こうした薄いコールは期待値がほぼゼロか微負けになることが多く、プレイングの難易度（ターン後のリバー判断）も考えると、フォールドが最も安全な選択です。

**まとめ**: ブロッカーは重要ですが、「役なしのハンドをいつでもコールにする魔法」ではありません。後手スコアが明確に負であれば、ブロッカーがあってもフォールドが正解です。

### 問14

**状況**: BB vs BTN（HU）。フロップ K♠5♦3♥（ドライ板）でBTNが33%CBet（約1.8BB）、BBコール。

- ポット（ターン前）: 約9BB
- スタック残り: 約96BB

**ターンカード**: 4♣（コネクター）

**BBのハンド**: 7♥6♥（ストレート完成：3-4-5-6-7）

ターン4♣でストレートが完成した。OOPのBBはどう行動すべきか？

```
A. チェック → BTNのベットを待ってCR
B. ドンクベット（50%ポット）
C. チェック → BTNのチェックバックを防ぐためにオールイン
D. チェック → BTNのベットにコール（スロープレイ）
```

**解答**

**正解: B. ドンクベット（50%ポット）または A. チェック → CR**

本問のポイントはドンクベットが有効なシナリオを理解することです。どちらも正解ですが、本問ではドンクベットの意義を重視します。

**ボード読み確認**: 7♥6♥ + K♠5♦3♥4♣ = 7, 6, K, 5, 3, 4。ストレートチェック: 7-6-5-4-3 = 5連続 → **ストレート完成（ナッツ）**。フラッシュ: ハートはK♠なし、7♥,6♥,3♥=3枚（5枚未満）。

**ドンクベットが有効な理由**:

ドンクベットは「チェックを先読みしてOOPが先手を取る」戦術で、通常はIPとのナッツアドバンテージが逆転する局面（第12章参照）で使います。

ターン4♣は以下の条件を満たします:
1. BBのレンジに大きく恩恵をもたらすカード（7-6でナッツが完成）
2. BTNが「4はブランクに近い」と判断して薄いベットをしてくる可能性が高い
3. 逆にBTNがチェックバックすれば、次のリバーで価値を取るチャンスが減る

ナッツを持つBBがドンクベットすることで、BTNのブラフレンジをフォールドさせつつ、BTNの薄いバリュー（KxトップペアやA高めなど）からコールを引き出せます。

**CR（チェック→レイズ）との比較**: CRはBTNがベットしてくれることが前提です。コネクテッドなターンカードでBTNがバレルしてこない（チェックバックする）可能性がある場合、ドンクベットの方が確実に価値を取れます。実戦では両方の選択肢が成立しますが、「BTNがチェックバックするリスク」を考慮するとドンクベットが安全です。

### 問15

**状況**: BB vs BTN（HU）。フロップ Q♦T♠7♣（セミ板）でBBがチェックレイズ（2.5倍CR）、BTNがコール。ターンでBBがチェック。BTNが50%ベット（約8BB）。

- ポット（ターン前）: 約16BB（フロップCR後のポット）
- BTNのターンベット: 約8BB

**ターンカード**: 8♥（コネクター）

**BBのハンド**: J♥9♦（フロップでOESD、ターンでストレート完成）

ターン8♥でJ♥9♦のストレートが完成した。BBはどう応じるか？

```
A. コール（スロープレイ）
B. チェックレイズ（2倍程度）
C. チェックレイズ（3倍以上）
D. フォールド
```

**解答**

**正解: B. チェックレイズ（2倍程度）または C. チェックレイズ（3倍以上）**

本問の核心は「フロップでCRしたBBがターンでもCRすることを恐れない」という点です。

**ボード読み確認**: J♥9♦ + Q♦T♠7♣8♥ = J, 9, Q, T, 7, 8。ストレートチェック:
- Q-J-T-9-8 = 5連続 → **ストレート完成（Qハイストレート）**
- J-T-9-8-7 = 5連続 → **ストレート完成（Jハイストレート）**

Best 5はQ-J-T-9-8（Qハイストレート、より高い）。フラッシュ: ハートはJ♥,8♥=2枚、ダイヤはQ♦,9♦=2枚（5枚未満）。

**後手スコア計算（HU前提のためM=0）**:

J♥9♦がQ♦T♠7♣8♥でQハイストレートを持つ。HandScoreは最高水準（ナッツストレートに近い）。概ね**HandScore ≈ 40**として計算します。

```
後手スコア = HandScore + A − 3 − C
           = 40 + 2 − 3 − 5
           （A=2：Q♦T♠7♣はセミ板、C=5：50%ベット）
           = 34
```

後手スコア34 → **CR強推奨（スコアが高いほどCRの有利度が増す）**

**CRのサイズ**: ポット16BB + BTNベット8BB = ポット24BB。標準的なCRは2倍（16BB）。3倍以上（24BB以上）はより大きなスタックを入れます。

**スロープレイが有効でない理由**: フロップでCRを打って「OOPが強い」というシグナルをすでに与えています。BTNがターンにもベットしてきたことは、BTNが一定の強度（バリューまたはブラフ）を持つことを示します。ストレートを持つBBはCRして最大バリューを取るのが正解です。リバーに残すと、リバーがストレートを壊すカード（ペアボードになる等）が落ちる可能性があり、価値が減ります。

### 問16

**ボード**: K♠Q♣T♥ → J♦（ターン）

次のハンドの中で、このターンボードで「ブロードウェイ（A-K-Q-J-T）とK-highストレート（K-Q-J-T-9）の両方を同時に完成させているもの」はどれか？

```
A. A♥9♠
B. A♦J♠
C. Q♥J♣
D. K♦T♦
```

**解答**

**正解: A. A♥9♠**

**全カードの確認**:

**A. A♥9♠** + K♠Q♣T♥J♦ = A, 9, K, Q, T, J

ストレートチェック（全連続を確認）:
- A-K-Q-J-T = 5連続 → **ブロードウェイ完成**
- K-Q-J-T-9 = 5連続 → **K-highストレートも完成**

A♥9♠はブロードウェイとK-highストレートの**両方同時に完成**させています。Best 5はA-K-Q-J-T（ブロードウェイ、より高い）。

**B. A♦J♠** + K♠Q♣T♥J♦ = A, J, K, Q, T, J（J = 2枚）

ランクカウント: J=2（J♠ハンド + J♦ボード）、A=1、K=1、Q=1、T=1。
ストレート: A-K-Q-J-T = 5連続 → **ブロードウェイ完成**。しかしK-Q-J-T-9（9なし）→ NO。
K-highストレートは完成しません。ブロードウェイのみ完成（選択肢AとBは両方ブロードウェイ完成だが、K-highストレートまで持つのはAのみ）。

**C. Q♥J♣** + K♠Q♣T♥J♦ = Q, J, K, Q, T, J（Q=2, J=2）

ストレート: A-K-Q-J-T（Aなし）→ NO。K-Q-J-T-9（9なし）→ NO。
役: Q-Q + J-J = 2ペア（Q's & J's）。ストレートは完成しません。

**D. K♦T♦** + K♠Q♣T♥J♦ = K, T, K, Q, T, J（K=2, T=2）

ストレート: A-K-Q-J-T（Aなし）→ NO。K-Q-J-T-9（9なし）→ NO。
役: K-K + T-T = 2ペア（K's & T's）。ストレートは完成しません。

**まとめ**: K♠Q♣T♥J♦のターンボードは「broadway完成ゾーン」です。このボードにAが加わればブロードウェイ（Aハイストレート）が完成します。さらに9も持つ（A♥9♠）ことで、K-highストレート（K-Q-J-T-9）も同時に完成し、2本のストレートを保有する特別な状況になります。実戦でこのボードが出たら「ハンドにAまたは9が含まれていないか」を必ず確認しましょう。AKQ Jのようなコネクテッドターンは、手持ちのカードが完成役に化ける頻度が高いボードです。

### 問17

**ボード**: K♥7♠2♦ → 7♣（ターン、ペアターン）

**ハンド**: A♦K♣

フロップではAKのTTPK（トップペア、Aキッカー、Kがトップ）だった。ターン7♣が落ちてボードが K-7-2-7 になった後、AKの役は何か？

```
A. ワンペア（K's、Aキッカー）のまま
B. 2ペア（K's & 7's、Aキッカー）
C. トリップス（K's、A & 7 キッカー）
D. フルハウス（K's full of 7's）
```

**解答**

**正解: B. 2ペア（K's & 7's、Aキッカー）**

**ボード読み確認（hand evolution）**:

A♦K♣ + K♥7♠2♦7♣ = A, K, K, 7, 2, 7

ランクカウント: K=2（ハンドのK♣＋ボードのK♥）、7=2（ボードの7♠＋7♣）、A=1、2=1

**役の評価（5枚選択）**:
- ペア構成: K-K（2枚）、7-7（2枚）
- Best 5: A-K-K-7-7 = **2ペア（K's & 7's、Aキッカー）**

**各選択肢の確認**:

A（誤り）: ワンペアのまま → 誤り。7がボードに2枚揃うため、Kとのセカンドペアが自動的に加わり2ペアになります。

C（誤り）: トリップス → K♣1枚＋ボードのK♥1枚 = 合計K2枚のみ。3枚のKは存在しないのでトリップスではありません。

D（誤り）: フルハウス → フルハウスは「スリーカード + ペア」。K-K-K-7-7（KトリップスがあってはじめてKのフルハウス）か、7-7-7-K-K（7のトリップスが必要）です。どちらも成立しません。

**ペアターンの一般法則**: TTPKのハンド（Kx）は、ペアターンが「Kと同ランク」なら2ペアに昇格します（K-K＋ボードの同ランク2枚ではなく、Kxx + Kターンなら「ボードにKが増えてトリップスになる」）。本問は「7ターン」で7-7がボードに揃うため、「KペアとボードペアKがありますが7-7がボードペアのため」、AKは K's & 7's の2ペアになります。

**覚え方**: 「ペアターンは必ずハンドを昇格させる」。TPTK（AK on K高ボード）はペアターンで2ペアに、2ペアはフルハウスに、セットはクワッズに昇格するのが基本パターンです。

### 問18

**ボード**: T♠8♠4♠ → K♠（ターン、フラッシュターン）

このターン、ボードにスペードが4枚並んだ（T♠, 8♠, 4♠, K♠）。次のハンドの中でスペードフラッシュを完成させているものはどれか？

```
A. Q♦J♦（ダイヤモンド2枚）
B. 9♠7♦（スペード1枚）
C. A♠2♦（スペード1枚）
D. Q♦J♦はフラッシュなし、9♠7♦はフラッシュなし、A♠2♦がフラッシュ完成
```

**解答**

**正解: D**

ここで「フラッシュ完成」と「フラッシュドロー（未完成）」の区別を確認します。

**フラッシュの定義**: 同じスートのカードが5枚揃ったとき（ハンド＋ボード5枚の中から5枚選択）。

**ボードのスペード**: T♠, 8♠, 4♠, K♠ = **4枚**。

5枚目のスペードが必要です。この5枚目のスペードをハンドに持つプレイヤーだけがフラッシュ完成です。

**A. Q♦J♦**:

Q♦J♦ + T♠8♠4♠K♠ = Q, J, T, 8, 4, K（スペードカウント: T♠,8♠,4♠,K♠ = 4枚のみ）

スペードは4枚（ボードのみ）。Q♦J♦はダイヤモンドであり、スペードなし。スペードフラッシュなし。

ストレートチェック: K-Q-J-T-9（9なし）、Q-J-T-9-8（9なし）→ 完成なし。役はハイカード（Kハイ）。

**B. 9♠7♦**:

9♠7♦ + T♠8♠4♠K♠ = 9, 7, T, 8, 4, K（スペードカウント: 9♠, T♠,8♠,4♠,K♠ = **5枚**）

**スペード5枚 → フラッシュ完成（K-high flush）**。

ただしストレートも確認: K-Q-J-T-9（Q,J なし）、T-9-8-7-6（7あり,6なし）、9-8-7-6-5（6,5なし）。→ ストレートなし。役: スペードフラッシュ（K-T-9-8-4）。

**C. A♠2♦**:

A♠2♦ + T♠8♠4♠K♠ = A, 2, T, 8, 4, K（スペードカウント: A♠, T♠,8♠,4♠,K♠ = **5枚**）

**スペード5枚 → フラッシュ完成（A-high flush = ナッツフラッシュ）**。

**まとめ**: ボードに同スートが4枚並んだとき、フラッシュを持つのは「5枚目の同スートをハンドに持つプレイヤー」だけです。Q♦J♦はスペードなしのためフラッシュなし。9♠7♦はスペード1枚のためフラッシュ（K-high）。A♠2♦はスペード1枚のためフラッシュ（A-high flush = ナッツフラッシュ）。

**重要教訓**: 「ボードに4枚スペードがある＝自分もフラッシュ」という誤解が実戦で頻発します。ハンドに1枚のスペードが必要です。スペードを持たないプレイヤーは、「フラッシュに負けるリスク」を意識してディフェンスを調整する必要があります。

### 問19

**ボード**: K♦7♥2♠ → 7♦（ターン、ペアターン）

フロップはドライ板（K♦7♥2♠）でIPがCBetを打ち、BBがコール。ターン7♦（ペア）後に、次のBBのハンドはそれぞれ何の役になるか？

```
ハンド: A♠K♣
```

フロップでのA♠K♣の役と、ターン7♦後の役を答えよ。

```
A. フロップ: TPTK（ワンペアK）→ ターン: TTPKのまま変化なし
B. フロップ: TPTK → ターン: 2ペア（K's & 7's、Aキッカー）
C. フロップ: TPTK → ターン: フルハウス（K's full of 7's）
D. フロップ: TPTK → ターン: トリップス（K's、A & 7 キッカー）
```

**解答**

**正解: B. 2ペア（K's & 7's、Aキッカー）**

**ボード読み確認（hand evolution ─ 詳細計算）**:

**フロップ時**: A♠K♣ + K♦7♥2♠ = A, K, K, 7, 2。ランクカウント: K=2, A=1, 7=1, 2=1。
役: ワンペア（K's、Aキッカー）= **TPTK**。Best 5: A-K-K-7-2。

**ターン7♦後**: A♠K♣ + K♦7♥2♠7♦ = A, K, K, 7, 2, 7。ランクカウント: K=2, 7=2, A=1, 2=1。
役: K-K（ハンドK♣＋ボードK♦）とボードに7-7（7♥＋7♦）がある。
Best 5: A-K-K-7-7 = **2ペア（K's & 7's、Aキッカー）**。

**各選択肢の確認**:

A（誤り）: 「TTPKのまま変化なし」→ 誤り。ペアターンでボードにペアが追加されると、そのペアがBest 5に強制的に入ります。K-K（ハンド）とボードの7-7が合わさることで、自動的に2ペアに昇格します。

C（誤り）: フルハウス → フルハウスはスリーカード+ペアが必要。K-K-K + 7-7、または7-7-7 + K-Kが必要ですが、KはA♠K♣とK♦の合計2枚、7は7♥と7♦の合計2枚のみです。スリーカードになるにはさらに1枚が必要です。

D（誤り）: トリップス → トリップスは同ランク3枚が必要。K♣（ハンド）+K♦（ボード）= 2枚のみ。3枚目のKがないのでトリップスではありません。

**実戦での意義**: 「TTPKがペアターンで2ペアに昇格する」という認識は、後手スコアの計算に直結します。TPTK のHandScoreが約20なのに対し、2ペアのHandScoreは約27程度に上がります。ペアターンでのコール判断が変わるため、正確な役の判定が重要です。

### 問20

**ボード**: T♦9♣6♠ → 7♥（ターン、コネクターターン）

ターン7♥が落ちてボードが T♦9♣6♠7♥ になった。次の各ハンドについて、「ストレート完成」「OESD（8アウツ）」「ガットショット（4アウツ）」「役なし」のいずれかを答えよ。

```
ハンド1: J♠8♣
ハンド2: Q♥J♦
ハンド3: 8♠5♦
ハンド4: A♣3♣
```

**解答**

ボード: T♦9♣6♠7♥ = T, 9, 7, 6

まず、ボード上に存在するランクを確認します: {T, 9, 7, 6}。フラッシュ: ダイヤはT♦のみ1枚、クラブは9♣,6♠なし... 待って: スペードは6♠のみ1枚、クラブは9♣のみ1枚、ダイヤはT♦のみ1枚、ハートは7♥のみ1枚。各スート1枚ずつ。フラッシュドローなし（ハンドが同スート2枚あっても合計3枚どまり）。

**ストレート完成の候補（5連続）**:
- J-T-9-8-7 → J, 8が必要（T,9,7はボードにある）
- T-9-8-7-6 → 8が必要（T,9,7,6はボードにある）
- 9-8-7-6-5 → 8, 5が必要（9,7,6はボードにある）
- 8-7-6-5-4 → 8, 5, 4が必要
- 7-6-5-4-3 → 5, 4, 3が必要

**ハンド1: J♠8♣**

全カード: J, 8, T, 9, 7, 6。

5連続チェック:
- J-T-9-8-7 = J✓, T✓, 9✓, 8✓, 7✓ → **5連続完成**
- T-9-8-7-6 = T✓, 9✓, 8✓, 7✓, 6✓ → **5連続完成**

2本のストレートが同時に完成しています。Best 5はJ-T-9-8-7（Jハイストレート、より高い）。

**答え: ストレート完成（Jハイストレート）**

**ハンド2: Q♥J♦**

全カード: Q, J, T, 9, 7, 6。

5連続チェック:
- Q-J-T-9-8 → 8なし → NO
- J-T-9-8-7 → 8なし → NO
- Q-J-T-9-7 → 連続ではない（8が欠けている）→ NO

4連続チェック（OESD / ガットショット候補）:
- Q-J-T-9 = 4連続（Kまたは8で5連続完成）→ **OESD**（両端が開いている: K高またはT低の5連続が可能）
- J-T-9-7 = 4連続ではない（8が欠け、J-T-9 + 7はJ-T-9-8-7の8が欠ける）→ これはOESDとはならない

実際の連続: Q, J, T, 9 は4連続（8で5連続: J-T-9-8-7? いや Q-J-T-9-8も5連続: QがJより上, 8がQより3つ下で連続 = Q-J-T-9-8 = 5連続, 8があれば完成）。また K-Q-J-T-9 も5連続（Kがあれば完成）。

つまりQ♥J♦は K or 8 で完成するOESDを持っています。

**答え: OESD（8アウツ、K or 8待ち）**

**ハンド3: 8♠5♦**

全カード: 8, 5, T, 9, 7, 6。

5連続チェック:
- T-9-8-7-6 = T✓, 9✓, 8✓, 7✓, 6✓ → **5連続完成**
- 9-8-7-6-5 = 9✓, 8✓, 7✓, 6✓, 5✓ → **5連続完成**

J♠8♣と同様に2本のストレートが完成。Best 5はT-9-8-7-6（Tハイストレート）。

**答え: ストレート完成（Tハイストレート）**

**ハンド4: A♣3♣**

全カード: A, 3, T, 9, 7, 6。

5連続チェック:
- A-2-3-4-5 → 2,4,5なし → NO
- K-Q-J-T-9 → K,Q,J なし → NO

4連続チェック（OESD / ガットショット候補）:
- T-9-8-7 → 8なし（Aはここに入れない）→ NO（ハンドにAと3のみ）
- A-2-3-4 → 2,4 なし → NO
- 9-7-6-? → 連続していない（8が欠けて9-8-7-6が成立しない、ハンドに8なし）

**答え: 役なし（ハイカード、ストレートドローもなし）**

**まとめ表**

| ハンド | ボード（OESD含む） | 役の判定 |
|---|---|---|
| J♠8♣ | T♦9♣6♠7♥ | **ストレート完成**（J-T-9-8-7） |
| Q♥J♦ | T♦9♣6♠7♥ | **OESD**（Q-J-T-9、K or 8 待ち） |
| 8♠5♦ | T♦9♣6♠7♥ | **ストレート完成**（T-9-8-7-6） |
| A♣3♣ | T♦9♣6♠7♥ | **役なし** |

**OESDとストレートの違い**: J♠8♣とQ♥J♦の差は「8の存在」です。8が手元にあれば J-T-9-8-7 が完成し、なければ Q-J-T-9 のOESDにとどまります。コネクテッドターンのボードでは、ハンドに「完成に必要な最後の1枚（ここでは8）があるかどうか」が役の差を生みます。

## 15-6 第III部の総括と第IV部への橋渡し

20問を通じて見えてきた、ターン判断の核心をまとめます。

### 20問から導き出す3つのパターン

**パターン1: バレルスコアはレンジの方向性、ハンドは個別判断**

積極バレルゾーン（≥7）でも「何も持っていないハンド」はチェックバックが正解（問1-2、問5参照）。バレルスコアはレンジ全体の傾向を示します。自分のハンドの強度がスコアと噛み合ったときだけ、実際にバレルします。

**パターン2: ペアターンは「昇格の機会」を正確に読む**

問3・問17・問19が共通して示すように、ペアターンはハンドを昇格させます。オーバーペアが2ペアに、2ペアがフルハウスに昇格したとき、後手スコアは大きく上がります。ペアターンを「脅威」として見るのではなく、「昇格のチャンス」として捉えましょう。

**パターン3: コネクテッドターンでのストレート完成を見落とさない**

問15・問20が示したように、コネクテッドボードでは自分のOESDが「ターン1枚」でストレート完成に変わることがあります。完成したストレートはバリューベット、またはCRの対象です。「まだドロー」として過小評価しないよう注意してください。

### 第IV部（リバー）への接続

第III部では「ターン」の戦略を3つの式（バレルスコア・後手スコア・α式）で体系化しました。第IV部ではこれらがリバーでどう変化するかを扱います。

ターンとリバーで最も大きく変わるのは、「ドロー」という概念がなくなることです。リバーには次のストリートがありません。すべてのハンドが「完成した役か、ブラフか」として評価されます。α式（第8章）がリバーで中心的な役割を果たし、バリュー/ブラフの配分が焦点になります。

第16章（IPの攻撃─リバー）から第21章（リバー実戦例20問）まで、リバー戦略を丁寧に積み上げます。

- **問Q1**: **2. 8♠8♦**。バレルスコア11は積極バレルゾーンですが、8♠8♦はアンダーペアでアウツが少なく（セット完成の2アウツのみ）、Aが落ちてBBのAx（トップペア）が増えた状況でのバレルは期待値がマイナス。SDV保護のチェックバックが正解。選択肢1・3はバリューベット、選択肢4はセミブラフとして打てる余地があります。

- **問Q2**: **1. 後手スコア = 19（CRゾーン）**。計算: 27 + 2 − 3 − 7 = 19。8以上はCRゾーンです（問12と同一シナリオ）。

- **問Q3**: **2. OESD（8アウツ）**。ボードT♦9♣6♠7♥にQ♥J♦を加えると Q, J, T, 9, 7, 6。4連続のQ-J-T-9が存在し（K or 8で5連続完成）、両端が開いているためOESDです。ストレートが完成するためには8が必要ですが、Q♥J♦には8がありません。

> **本章まとめ**
>
> - バレルスコアはレンジの「方向性」。ハンドの強度と掛け合わせて初めて実行判断になる。
> - ペアターンはハンドを昇格させる。TTPKが2ペアに、2ペアがフルハウスに変わる。昇格後の強度で判断し直す。
> - 後手スコアの計算は「HandScore + A − 3 − C（HU前提）」。8以上でCR検討、0以下でフォールド。
> - フラッシュは5枚同スートが必要。ボードに4枚スペードがあっても、ハンドにスペードがなければフラッシュでない。
> - コネクテッドターンでは5連続を厳格に確認。J-T-9-8-7の完成にはJと8が両方必要。Q♥J♦のQ-J-T-9は8またはKで完成するOESD（ストレート完成ではない）。

**【GTOとのズレ】**

**バレルスコアの「積極バレル」は全ハンドでバレルする意味ではない**

バレルスコアが積極バレルゾーン（≥7）に入ると、GTO上では「レンジ全体のCBet頻度が高い（70%〜100%）」という状況が確認されています。しかし「全ハンドでベット」とは異なります。GTOソルバーを確認すると、同じ積極バレルゾーンでも役なしのハンドはチェックバック頻度が高く、役のあるハンドがバレルの主体を担っています。

人間プレイヤーがよく犯す誤りは、「スコアが高いからとりあえず打つ」という思考です。バレルスコアは「このボード×ターンカードの組み合わせで、レンジとして積極的に打てるか」を示すものであり、特定ハンドの個別判断は別に行う必要があります。問1（バレルスコア10、AKでバレル）と問5（バレルスコア11、88でチェックバック）の対比がこの点を明確に示しています。

**ペアターンでのCR率の過小評価**

問12（2ペアでの75%ベットへのCR）で確認したように、強い2ペアのハンドはペアターンでCRが有効です。しかし実戦では、「OOPが相手のターンベットにCRするのは怖い」という心理的バリアが働きます。特に大きいサイズのベット（75%）に対するCRは「相手も強いのではないか」と感じて、コールにとどまる傾向があります。

GTOの観点では、HandScoreが高い2ペア（問12のような9-9-8-8など）はCRが標準的な選択です。コールだけでは後手下限ラインを守れる一方、2ペアのような強いハンドをコールレンジのみに入れると、相手はバレル頻度を増やすことでエクスプロイトできます。2ペアはCRレンジに積極的に入れ、GTOの均衡に近づきましょう。

**ドンクベットの過少使用**

問14が示したように、コネクターターンでナッツを持つOOPはドンクベットが有効です。しかし実戦でのOOPのドンクベット率は、GTO上の推奨値より大幅に低い傾向があります。「OOPはチェックしてから行動する」というルールを無意識に適用してしまうためです。

GTOがOOPのドンクベットを推奨する局面は、「OOPのナッツアドバンテージが高いカード」「IPがチェックバックしやすいカード」の2条件が重なる場面です。この条件を意識的に確認し、ドンクベットの選択肢を引き出しに持っておくことが、リバー戦略にも波及する重要なスキルです。
