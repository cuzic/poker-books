# 第2章　ターンカードの5分類

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ターンカードを5つに分類し、それぞれのGTO CBet頻度を把握する。「ペアは低CBet」という誤解を解消する。

---

## 2-1 なぜターンカードを分類するのか

ターンカードは「誰のレンジをより強化するか」によって、ダブルバレルの推奨度が変わります。

GTO ソルバー実測 (270 シナリオ) では、同じフロップでもターンカードによって IP の CBet 頻度が **41% から 100%** まで幅広く変化しました。

この変化を予測するために、ターンカードを5分類で整理します。

---

## 2-2 ターンカード5分類の定義

| 分類 | 条件 | 代表例 (K72r ターン) |
|---|---|---|
| **ペア** | フロップカードと同ランク | Ks, Kd (K72r→KK) |
| **オーバーカード** | フロップの最高位より高いランク | As, Ac (K72r→KA) |
| **ブランク** | レンジに影響少ない中〜低ランク | Qs, 3c (K72r→KQ, K3) |
| **コネクター** | ストレートドロー完成・強化 | Js (J75r→J75J) |
| **フラッシュ** | 3枚目の同スート (フラッシュドロー発生) | 9s (987ss→987+9s) |

> **注**: 1枚のターンカードが複数に該当する場合 (コネクターかつフラッシュ等) は、より影響の大きい分類を優先します。

---

## 2-3 GTO データによるCBet頻度

GTO ソルバー実測 (30 フロップ × 各9ターンカード = 270 シナリオ) の結果です。

### 分類別 平均 CBet 頻度

| ターンカード分類 | 平均 CBet % | 最低値 | 最高値 | シナリオ数 |
|---|---|---|---|---|
| **ペア** | **91%** | 68% | 100% | 60 |
| **オーバーカード** | 76% | 53% | 98% | 53 |
| **ブランク** | 75% | 42% | 100% | 105 |
| **コネクター** | 70% | 41% | 100% | 42 |
| **フラッシュ** | 69% | 54% | 92% | 10 |

**重要な発見**: ペアカードが最も高い CBet 頻度を示します。これは多くのプレイヤーの直感「ペアは危険→チェックバック」と逆です。

---

## 2-4 分類別の詳解

### ペアカード (avg: 91%)

フロップのカードと同ランクのターンカードが落ちるとき、IP (BTN) は強く反応します。

**なぜ高いのか**: BTN はフルハウス・セット・2ペアなど「重い役」を豊富に持っています。K72r で Ks が落ちると、BTN の KK・K7・K2 などがすべて強化され、BTN のレンジが爆発します。

```
GTO 実測例:
  K72r + Ks → 100%  (BTN の K が圧倒的優位)
  K44 + Ks → 100%  (同上)
  K95r + Ks → 100%  (同上)
  K83r + Ks → 100%  (同上)
  AAK + As → 100%  (AA+A = 4 of a kind も)
```

**例外: AT7ss + 7c → 68%** (7 のセットは BTN・BB 両方が持つ。スーテッドボードで BB のドロー強化もある)

---

### オーバーカード (avg: 76%)

フロップ最高位より高いカードが落ちるとき。

**通常のパターン (高い)**: BTN は Ax・Kx を広くオープンします。BB の防御レンジには Ax が少ない傾向があります。

```
GTO 実測例 (高い):
  K72r + As → 86%  (BTN の Ax > BB の Ax)
  K72r + Ac → 83%
  K83r + As → 81%
```

**例外 (低い): K44 + As → 78%**

K44 ではフロップで BB は Ax を多く守ります (Ax は K44 でトップペア有利)。A ターンで今度は BB の Ax が 2 ペアになり、BB のレンジが大幅強化されます。

```
K72r + As → 86%  (BTN の Ax が BB の Ax より多い)
K44  + As → 78%  (BB が Ax で防御していたため、A 落ちで BB が強化)
```

**実用ルール**: 対称的な高カードボード (K44, A55 等) でオーバーカードが落ちる場合は、標準より低い CBet を想定する。

---

### ブランク (avg: 75%)

レンジへの影響が最も少ない中〜低ランクカード。

ドライ板ではブランクでも高い (80%+) のが特徴です。「何も変わらない → IP の優位が維持」という理由からです。

```
GTO 実測例:
  K72r + 3c (blank) → 88%  (ドライ板ではブランクでも高い)
  AAK  + 2c (blank) → 100%  (超ドライ板)
  JT9ss + 6h (blank) → 47%  (ウェット板ではブランクも低い)
```

---

### コネクター (avg: 70%)

ストレートドローを完成・強化するカード。

**注意**: ドライ超高位板 (KK9, AAK) では100%になることがあります。これは板が極端に IP 有利なため、どのカードが落ちても IP が勝ち続けるためです。

セミ〜ウェット板では、コネクターは OOP (BB) のドローを強化するため CBet が低下します。

```
GTO 実測例:
  J75r + Ts → 50%  (J75 に T が落ちると OESD/straight が BB のドローを強化)
  QJ9r + 7c → 52%  (QJ9 に 7 が落ちると 7-J ストレートが BB レンジを助ける)
  KK9 + Tc → 100%  (超ドライ板では全ても OK)
```

---

### フラッシュ (3枚目同スート) (avg: 69%)

スーテッド板で3枚目の同スートが落ち、フラッシュドローが強化される分類です。

フラッシュドローは BB の広い防御レンジに多く含まれることがあり、OOP のレンジを強化する傾向があります。

```
GTO 実測例:
  JT9ss + 8s → 57%  (フラッシュ+コネクター両方の強化)
  Q83ss + Js → 54%
  AT7ss + Ks → 92%  (K は IP のオーバーカード効果も重なって高い)
```

---

## 2-5 板タイプ × ターンカードのマトリクス

GTO ソルバー実測値を板タイプ別に整理します。

### GTO実測 CBet 頻度 (%)

| 板タイプ | ペア | オーバーカード | ブランク | コネクター | フラッシュ |
|---|---|---|---|---|---|
| **ドライ** (K72r, A72r 等) | **96%** | **84%** | 80% | (91%)† | - |
| **セミ** (J75r, KT5r 等) | **88%** | 76% | 75% | 61% | - |
| **スーテッド** (987ss 等) | **88%** | 75% | 66% | 62% | 69% |
| **コネクテッド** (T98r 等) | **84%** | 64% | 65% | 67% | - |

†ドライ板のコネクター91%は KK9・AAK などの超ドライ板が含まれるため高め。これらを除くと ~93%。

**読み方のポイント**:

1. **どの板タイプでもペアが最高**: ペアターンは積極的 CBet のシグナル
2. **ドライ板は全カテゴリで高い**: 板が乾いているほど、ターンカードに関わらずダブルバレル有利
3. **コネクテッド板のコネクター/ブランクは65%**: ハンドクラス次第

---

## 2-6 「真の決定因子」を理解する

分類の背後にある単一の原則があります。

> **ターン CBet が高い ↔ ターンカードが OOP よりも IP のレンジを強く改善する**

この視点で全分類を再解釈できます。

| 分類 | IP レンジへの影響 | OOP レンジへの影響 | 結果 |
|---|---|---|---|
| ペア (高位) | 大幅強化 (セット→FH, 2ペア→3カード等) | 小幅 | IP 圧倒的有利 → 高 CBet |
| オーバーカード (通常) | Ax・Kx が多い BTN が強化 | BB の Ax は少ない | IP 有利 → 高め |
| ブランク | 変化小 | 変化小 | フロップの優位が維持 |
| コネクター (セミ板以降) | OESD 完成等で強化 | BB の広い防御 OESD も強化 | OOP の強化が大きい → 低め |
| フラッシュ | IP のバックドアが一部完成 | BB の FD が強化 | OOP の強化が大きい → 低め |

---

## 2-7 実用的な暗記ルール

270 シナリオの分析から、実践で使えるルールをまとめます。

### ルール1: 「ペアターン = ほぼ常にダブルバレル」

ペアターンでの CBet 頻度は最低 68%。実質的に「常にベット」と判断して良い。

```
例外: AT7ss + 7c (68%) → スーテッドボードで BTN・BB とも 7x を持つ場合
     JT8ss + 8c (77%) → 同様
ただしこれらでも 68-77% ≥ 70% ラインなので、実戦ではベット推奨
```

### ルール2: 「ドライ板はターンカードに関係なく積極的」

ドライ板 (K72r, A72r, K44 等) ではどのターンカードでも CBet 頻度は 78-100%。

例外は K44 + A (78%) のみ。それでも 78% は高い。

**覚え方**: 「ドライ板のバレル = 全自動」

### ルール3: 「コネクター/フラッシュはセミ以降で注意」

セミ〜コネクテッド板でのコネクター・フラッシュターンは 60-70% 帯。

ハンド強度が標準以下の場合はチェックバックも検討。

---

## 2-8 バレルスコアで判断する実戦例

バレルスコア（FlopType係数 + TurnCard係数）で具体的に計算してみましょう。

```
バレルスコア = FlopType係数 + TurnCard係数
FlopType: ドライ=8, セミ=6, スーテッド=4, コネクテッド=3
TurnCard: ペア=4, オーバーカード=3, ブランク=2, フラッシュ=1, コネクター=0
閾値: ≥ 7 → 🟢 ダブルバレル推奨、< 7 → 🟡 チェックバック推奨
```

### 例1: K♣7♦2♠ → ターン 3♠（ドライ + ブランク）

```
FlopType: K72r = ドライ → 8
TurnCard: 3 = ブランク → 2
バレルスコア = 8 + 2 = 10 → 🟢 ダブルバレル
```

K72r はドライボードの典型例。3 というブランクが落ちても IP の優位は変わりません。ほぼ全ハンドでバレル推奨です。BTN が T♥9♥（空振り）を持っていても、相手のコールレンジを圧力で弾けるシチュエーションです。

### 例2: K♣7♦2♠ → ターン K♦（ドライ + ペア）

```
FlopType: K72r = ドライ → 8
TurnCard: K = ペア → 4
バレルスコア = 8 + 4 = 12 → 🟢 ダブルバレル（強）
```

K ペアターン。IP の KK・Kx がすべてフルハウスや強いトリップスに昇格します。OOP のコールレンジは相対的に弱体化。積極的なダブルバレルが正解です。

### 例3: J♥T♣5♣ → ターン 9♣（スーテッド + フラッシュ＆コネクター）

```
FlopType: JT5ss = スーテッド → 4
TurnCard: 9♣ = フラッシュ（優先）→ 1
バレルスコア = 4 + 1 = 5 → 🟡 チェックバック
```

JT5ss のボードにフラッシュかつコネクターの 9♣ が落ちました。OOP の BB は JT5ss フロップで多くのフラッシュドローとストレートドローをコールレンジに持っています。9♣ がその多くを完成させてしまいます。IP はバリューハンド（セット・2ペア）以外はチェックバックが推奨です。

### 例4: Q♥8♦3♠ → ターン J♠（セミ + コネクター）

```
FlopType: Q83r = セミ → 6
TurnCard: J = コネクター（J が落ちると JT・J9 等が OESD に）→ 0
バレルスコア = 6 + 0 = 6 → 🟡 チェックバック
```

Q83r に J が落ちると、BB のコールレンジに含まれる JT・J9・T9 などのドロー成分が大幅に強化されます。IP はバリューハンド以外はチェックバックが得策です。

### 例5: A♠5♥2♦ → ターン A♣（ドライ + ペア）

```
FlopType: A52r = ドライ → 8
TurnCard: A♣ = ペア → 4
バレルスコア = 8 + 4 = 12 → 🟢 ダブルバレル（最強クラス）
```

A ペアターンは IP に圧倒的有利。IP は Ax を広くオープンしており、AA・Ax のほぼ全てがトリップスに昇格。OOP のコールレンジ（主に 5x・2x・ドロー）は大幅に弱体化します。

---

## 2-9 ターンカードの「重複分類」の処理

1 枚のターンカードが複数の分類に該当する場合は、影響の大きい分類を選びます。

| 状況 | 例 | 優先分類 | 理由 |
|---|---|---|---|
| フラッシュ + コネクター | JT5ss + 9s | フラッシュ（1） | OOP の FD+SD が同時完成 → より大きく OOP を強化 |
| フラッシュ + オーバーカード | K83ss + As | オーバーカード（3） | A は IP の Ax を強化する効果が FD 強化を上回ることが多い |
| ペア + コネクター | JT5 + J（J+ストレート絡み） | ペア（4） | ペアの IP 優位は常に強い |

**実践上のアドバイス**: 重複分類で迷ったときは、「このカードで OOP のドローが完成するか」を優先的に考えましょう。ドローが完成するなら低めの係数（フラッシュ=1、コネクター=0）を選び、チェックバックに傾ける判断が安全です。

> **本章まとめ**
>
> - ターンカード5分類: ペア / オーバーカード / ブランク / コネクター / フラッシュ
> - 平均 CBet 頻度: ペア(91%) > オーバーカード(76%) ≈ ブランク(75%) > コネクター(70%) ≈ フラッシュ(69%)
> - 「ペアは高 CBet」が正解。「ペアは危険」という直感は誤り
> - ドライ板では全ターンカードで高 CBet (78-100%)
> - 真の決定因子は「誰のレンジをより強化するか」

## ミニクイズ

### 問1

BTN vs BB, フロップ 9♠8♣5♦（コネクテッド = 3）に対してターン 6♦ が落ちました。バレルスコアはいくつになりますか（ターンカード係数: コネクター=0）。

1. 3点
2. 6点
3. 9点

### 問2

フロップ K♥7♣2♦（ドライ = 8）→ ターン 7♠（ペア = 4）。バレルスコアは何点で、推奨アクションは何ですか。

1. 12点 → 🟢 ダブルバレル
2. 4点 → 🟡 チェックバック
3. 8点 → 🟡 チェックバック

### 問3

次のうち、チェックバックが最も推奨されるのはどの組み合わせですか。

1. ドライボード + ペアターン
2. スーテッドボード + フラッシュターン
3. セミウェットボード + オーバーカードターン

---

### 解答

- **問1**: 1（コネクテッド3 + コネクター0 = **3点** → 🟡 チェックバック。9-8-5-6 は OOP のストレート・ドローが豊富に完成）
- **問2**: 1（ドライ8 + ペア4 = **12点** → 🟢 ダブルバレル強）
- **問3**: 2（スーテッド4 + フラッシュ1 = 5点 → 🟡）

**【GTO とのズレ】**

本章の5分類は「IP/OOP のレンジバランス」を大まかに予測するものであり、GTO が実際に計算する「各コンボの EV 比較」とは異なります。

GTO ソルバーは、ターンカードの落ち方だけでなく「そのカードが落ちた後のリバー全カードにわたる EV 計算」を行います。本章の分類は「平均的な傾向」を捉えており、個別コンボでは逆転することがあります。

特に「ブランク」カテゴリは最も分散が大きく (42% 〜 100%)、板タイプ次第で大きく変わります。ドライ板のブランクは高く (80%)、ウェット/スーテッド板のブランクは低い (42-65%) という板依存性を忘れずに。
