# 第23章　ターンオーバーベット

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ターンでオーバーベット (100%+) を使うべき状況を理解し、リバー OB との使い分けを判断できるようになる。

---

## 23-1 ターン OB とリバー OB の違い

第13章でリバーオーバーベットを学びました。ターンでも同様のオーバーベットが使えますが、目的と条件が異なります。

```
リバー OB:
  目的: 「最後の1回で最大バリューを取る」
  条件: ポラライズ + ストーリー一貫 + リバーカードで強化
  結果: ショーダウンまで進む

ターン OB:
  目的: 「SPR を一気に下げてリバーをコミット状態にする」
       または「今すぐフォールドを引き出す (フォールドエクイティ)」
  条件: ナッツアドバンテージ + ドライボード + 相手が降りやすい状況
  結果: コールされるとリバーで SPR ≈ 1 = ほぼオールイン
```

---

## 23-2 ターン OB が有効な条件

### 条件 1: ナッツアドバンテージが圧倒的

```
IP がナッツに近いハンドを持ち、BB がナッツを持ちにくいボード:

例: ドライボード A♦K♣2♠ + ペアターン A♥
  IP (BTN): AA を持てる (フロップの CBet で AA をバレルしている)
  BB: AA はほぼ持てない (フォールドするか 3bet してプリフロで終わっている)
  
  IP の AK, AA, A2 (ツーペア、トリップス) は BB のレンジを圧倒
  → 大サイズ OB で BB の Kx, Ax (弱ハンド) をフォールドさせる
```

### 条件 2: SPR をリバーで「コミット状態」にしたい

```
ターン OB の設計:
  ターン 150% OB → コール後の SPR = 1 程度
  → リバーではどんなカードが来てもほぼオールイン確定
  
  これが有利な状況:
  - 自分がナッツ / 強いバリューを持つ
  - リバーのどのカードが来ても自分が有利
  - BB の「ドロー完成でのリバー逆転」リスクをなくしたい
```

### 条件 3: ドライボード + ブランクターン

```
ドライ + ブランクは「IP のレンジが最も強い」ターン:
  フロップからのバレルで IP のレンジが強化される
  BB のレンジは「Kx などの TP 以下」が多く残っている
  
  この状況での OB:
  - BB の Kx はコールできない (60% コストオッズ)
  - BB の 2ペア以上は降りにくいが少ない
  → フォールドを引き出す or コールされてもナッツで有利
```

---

## 23-3 ターン OB のサイズと数学

### ターン 150% OB の場合

```
ターンポット 20BB、スタック 80BB (SPR = 4)

150% OB = 30BB ベット

BB のコールオッズ: 30/(20+30) = 60%
→ BB のハンドが IP のレンジの 60% 以上に勝てなければ、BB のコールは EV−

コール後の状況:
  新ポット: 20 + 30 + 30 = 80BB
  残スタック: 80 - 30 = 50BB
  新 SPR: 50/80 = 0.625 ≈ ほぼオールイン状態
```

### ターン 200% OB (ポット 2倍)

```
ポット 20BB, 200% OB = 40BB

コールオッズ: 40/(20+40) = 67%
→ BB は 67% 以上の「BB が IP に勝てる割合」がないとコール EV−

コール後: スタック 40BB / ポット 100BB = SPR 0.4 = オールイン確定圏
```

## 23-4 ターン OB が有効なボードパターン

### パターン 1: ドライ板 + ペアターン

```
例: K♣7♦2♠ + K♥ターン

IP が K を持つ確率が高い (フロップ CBet した後 K ターン)
BB の K は少ない (BB のディフェンスレンジに K は限られる)

IP のナッツアドバンテージ:
  KK (ポケット): トリップス
  AK, KQ: 2ペア
  
  BB に K があれば KK or KA, KQ → IP と競合するが少ない
  
→ K ペアターンで IP が 125-150% OB: BB はほとんどフォールド
  コールしてくるのは BB の KK, K-A, セット程度
```

### パターン 2: ドライ板 + オーバーカードターン (A 落ち)

```
例: K♦7♣2♠ + A♥ターン

A が落ちて IP の Ax が大幅強化 (AK 2ペア, AA セット等)
BB の Kx は A 落ちで弱化 (K トップペアだったが 2番手に)

IP の OB:
  BB の Kx はコール困難 (60% コストオッズに Kx は耐えられない)
  BB の Ax のみコール可能 → IP は Ax に勝てるか確認必要
  
  IP が AK (2ペア) や AA (セット) なら OB 有効
  IP が A3 (1ペア) なら OB は過剰
```

### パターン 3: フラッシュ完成ターン (IP がナッツ保有)

```
例: K♥T♠5♦ + 2♥ターン (3枚目のハート)

IP がナッツフラッシュ (A♥K♥ 等) を持つ場合:
  フラッシュ完成でポラライズが起きる
  BB がフラッシュを持っているかどうかで二分

IP の 125% OB:
  BB がフラッシュなし: フォールド (コールオッズ 56% を満たさない)
  BB がフラッシュあり: コール → IP はさらに強いフラッシュかどうかで決まる
```

## 23-5 ターン OB に向かないパターン

### NG パターン 1: ウェット板でのターン OB

```
ウェット板 (T♠9♦8♣ + J♠):
  BB の コールレンジに強いハンドが多い (ストレート、フラッシュ等)
  IP の OB は BB の強手をコールさせる → IP がナッツでなければ損

  → ウェット板ではポラライズが難しい
  → 標準サイズが適切
```

### NG パターン 2: IP のバリューが薄い場合

```
IP がトップペアのみ (例: KQ on K72r + A ターン):
  KQ は A ターンで薄バリューに転落
  OB → コールされると IP の KQ が負けるケースが多い
  
  → 薄バリューでの OB は「コールされると損」
  → チェックバックかブロッキングベット (33%) が適切
```

### NG パターン 3: フロップでチェックバック後のターン OB

```
フロップ: IP チェックバック (弱さのシグナル)
ターン: IP が大きくベット

問題: ストーリーが崩れる
  「フロップで弱かった IP がターンで突然 OB」= ブラフに見える
  → BB がコールしやすくなる (IP のバランスが崩れている)
  
  → チェックバック後のターン OB はレアケースを除いて避ける
```

## 23-6 BB がターン OB を受けたときの対応

IP がターン 150%+ OB を打ってきた場合の BB の対応です。

### コールオッズ計算

```
ポット 20BB、IP の 150% OB = 30BB

コールコスト率 = 30/(20+30) = 60%
→ BB のハンドが IP のバリューレンジの 60% 以上に勝てるかを確認
```

### BB のコール基準

| ハンドクラス | ターン OB への対応 |
|---|---|
| ナッツ〜準ナッツ (セット、ストレート等) | コール or レイズ |
| 強い 2ペア | コール (慎重に) |
| トップペア | 基本フォールド (60% コストオッズは厳しい) |
| 1ペア以下 | フォールド |
| ドロー (ナッツドロー) | コール (エクイティあれば) |

### 実例: BB が K♥Q♦ (TPTK) を持ち IP に 150% OB された場合

```
ボード: K♣7♦2♠ + A♥ターン、ポット 20BB

IP の 150% OB (30BB):
  コールオッズ 60% = 「IP のレンジの 60% 以上に KQ が勝てるか」

  IP のバリューレンジ: AK (2ペア), AA (セット), KK (セット)
  IP のブラフレンジ: QJ (バックドアドロー等)

  KQ はこのレンジに:
    AK: 負け
    AA/KK: 負け
    ブラフ: 勝ち
  
  ブラフが 60% 以上 → コール有利
  ブラフが 60% 未満 → フォールド
  
  A♥ ターンで IP の OB = バリューヘビーが多い
  → フォールド推奨
```

## 23-7 ターン OB の使用頻度と実戦感覚

GTO でのターン OB 使用頻度は以下の傾向があります:

```
ターン OB が多い状況 (GTO 実測参考):
  - ドライ板 + ペアターン → IP のナッツアドバンテージ最大
  - ドライ板 + A オーバーカード → Ax が大幅強化
  
  頻度: 上記状況で 15-25% 程度のベットが 100%+ OB

ターン OB が少ない状況:
  - ウェット/コネクテッド板
  - フラッシュターン (両者がフラッシュ候補)
  - IP のバリューが薄い状況

実戦でのシンプルルール:
  「ドライ板でナッツを持ったとき、ターンで大きく打つ」
  それ以外は標準サイズ (50-75%) が安全
```

## ミニクイズ

### 問1

ドライ板 A♦K♣2♠ + A♥ターン で BTN が AK (2ペア) を持っています。ポット 22BB、スタック 88BB。ターン OB (150%) が有効な理由は?

1. AK は 2ペアで強いから何でも大きく打てる
2. A ターンで IP の Ax が強化、BB の K が弱化 → ナッツアドバンテージ最大 → OB が有効
3. 150% OB で BB の KK もフォールドさせられる

### 問2

IP がターンに 150% OB。BB のハンドはトップペアトップキッカー (TPTK)。コールオッズは 60%。最善は?

1. TPTK は強いので必ずコール
2. コールオッズ 60% = IP のレンジの 60% に勝てるか確認。ターン OB でバリューヘビーなら基本フォールド
3. フォールドは絶対損なので必ずコール

### 問3

「フロップチェックバック → ターン 150% OB」というラインの問題点は?

1. ターン OB は禁止されている
2. フロップの弱さのシグナルが「突然大きくなる」= ストーリーが崩れる → BB がコールしやすくなる
3. チェックバック後は大きく打てないというルールがある

---

### 解答

- **問1**: 2（A ターンで IP の Ax が強化し、BB の Kx が弱化。IP の AK は BB のほぼ全コールレンジに勝つ。このナッツアドバンテージ最大局面でのターン OB はポラライズを最大化する）
- **問2**: 2（60% コールオッズ = IP の 60% 以上がブラフでなければコール損。ターン OB = IP のバリューが強い場合が多く、TPTK は OB に対して多くの場合フォールドが正解）
- **問3**: 2（フロップのチェックバックは「弱さのシグナル」。直後のターン大ベットは「なぜ突然強くなった?」と BB に読まれる。ブラフならコールされやすくなり、バリューなら EV を取り逃がしていた可能性）

---

> **本章まとめ**
>
> - ターン OB はリバー OB と異なり「SPR をコミット状態にする」目的でも使う
> - 有効条件: ドライ板 + ナッツアドバンテージ最大 (ペアターン / A 落ち)
> - ターン 150% OB コールオッズ = 60% → BB は強いハンドのみコール
> - NG: ウェット板、薄バリュー、フロップチェックバック後
> - BB がターン OB を受けた場合: 1ペア以下は基本フォールド
> - 実戦シンプルルール: 「ドライ板でナッツを持ったとき大きく打つ」

---

**【GTO とのズレ】**

GTO でのターン OB はドライボードに集中しており、ウェットボードでのターン OB はほぼ見られません。実戦では「ターンでの強さ = 大きくベット」という直感からウェット板でも OB を打ちがちですが、これは相手のコールレンジが厚い状況でのミスになります。

また、GTO ではターン OB のブラフとして「ナッツブロッカーを持つ完全ブランク」を使います。「A を持っているから AA/AK をブロックできる + フォールドエクイティあり」でのターン OB ブラフは GTO では存在しますが、実戦で再現するには精度が要求されます。入門段階では「ターン OB = バリューのみ」で使い、ブラフ OB は中上級者のテクニックとして後回しにするのが安全です。
