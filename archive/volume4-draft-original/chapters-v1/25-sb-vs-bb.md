# 第25章　SB vs BB のターン・リバー

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: SB vs BB という「OOP かつアグレッサー」という特殊ポジションのターン・リバー戦略を理解し、BTN vs BB との違いを判断基準に組み込む。

---

## 25-1 SB vs BB の特殊性

本書でここまで扱ってきた BTN vs BB と SB vs BB は根本的に異なります。

```
BTN vs BB:
  BTN = IP (後手)、CBet アグレッサー
  BB = OOP (先手)、ディフェンス側
  → BTN が常に「情報有利」でベット/チェックバックを判断

SB vs BB:
  SB = OOP (先手)、かつ CBet アグレッサー
  BB = OOP ではないが、SB より後手 (相対的 IP)
  → SB は「レイズしたけど先手を打たないといけない」逆境
```

**SB の本質的な問題**: レイズ権があってアグレッサーだが、毎ストリートで先にアクションしなければならない (OOP)。この非対称性が SB の戦略を難しくします。

---

## 25-2 SB のレンジ特性

SB のオープンレンジは BB のディフェンスレンジと同様に広いですが、BTN のオープンレンジより弱めです。

```
BTN のオープンレンジ (参考): 約 45-50% のハンド
  強いハンドが豊富、ナッツアドバンテージが高い

SB のオープンレンジ: 約 40-45% のハンド
  BTN より少し弱め、AA/KK/AK 等は含まれるが中程度のハンドも多い

BB のディフェンスレンジ (SB レイズに対して): 約 50-55% でコール
  BB はポットオッズが良いため広くコールできる
```

### SB vs BB のレンジバランス

```
SB のアドバンテージ:
  + レイズ権 (アグレッション)
  + 先手 CBet の権利

SB のデメリット:
  - 毎ストリートで先手を打たないといけない (OOP)
  - BB は広くコールするため、SB の CBet に対して BB が多く残る
  - BB の後手優位が機能しやすい
```

---

## 25-3 SB のフロップ CBet 戦略

BTN と SB では CBet の判断が異なります。

### BTN vs SB の CBet 頻度比較

| ボードタイプ | BTN CBet頻度 (参考) | SB CBet頻度 |
|---|---|---|
| ドライ (K72r) | ~70% | ~60% |
| セミウェット (KT5ss) | ~60% | ~50% |
| ウェット (T98ss) | ~50% | ~40% |
| コネクテッド (987r) | ~45% | ~35% |

SB は OOP のため BTN より全体的に CBet 頻度が低い傾向があります。

### SB がドライボードで有利な理由

```
SB が CBet しやすい状況:
  - ドライボード + 高カード (A, K が多いボード)
  - SB のオープンレンジにはAx, Kx が多い → このボードで有利
  - BB の広いコールレンジは「中程度のハンド」が多い → ドライ板で弱い
  
  → ドライ高カードボードは SB に有利、CBet 有効
```

### SB がウェット/コネクテッドボードで不利な理由

```
SB が不利な状況:
  - コネクテッド板 (T98 等): BB のコールレンジにコネクターが多い
  - BB の広いコールレンジ = スーテッドコネクター等のドロー多数
  → ウェット板では BB が有利
  → SB の CBet 頻度が下がる
```

## 25-4 SB のターン戦略

SB はターンでも OOP でアグレッションを続けるか、チェックして BB のアクションを見るかを選択します。

### SB のダブルバレル判断

バレルスコアは BTN vs BB 用に設計されていますが、SB でも使えます。ただし **同じスコアでも SB は BTN より低い頻度でバレル** するのが GTO 的です。

```
SB のバレル頻度調整:
  バレルスコア ≥ 9 (ドライ × ペア等): 積極バレル (BTN と同様)
  バレルスコア 7〜8: SB は BTN より 10% 程度低い頻度でバレル
  バレルスコア < 7: チェック頻度が増える
  
  理由: SB は OOP のためバレルのコストが BTN より高い
```

### SB のチェック後の BB ドンクベット対応

SB がターンでチェックした後、BB がドンクベット (リード) してきた場合:

```
BB のドンクベットは「BB がターン強化」のシグナル:
  ドロー完成ターン → BB のフラッシュ/ストレートが完成
  ブランクターン → BB のバリューハンドがポットを取りに来た

SB の対応:
  コール: ドロー持ちまたは強いバリュー
  レイズ: ナッツ以上
  フォールド: ショーダウン価値なし
  
  特に SB はドンクベット後に 「チェックコール or フォールド」が多くなる
  (OOP でのレイズはリスクが高い)
```

---

## 25-5 SB のリバー戦略

### SB がリバーで先手ベット

SB がリバーまで続けてきた場合、先手ベットか チェックかの選択です。

```
SB のリバーベット基準 (BTN より厳しい):

SB がリバーでベットするなら:
  バリュー: 確実にコールされて勝てるハンド (相手のコールレンジの 60%+ に勝つ)
  ブラフ: ブロッカーを持ち、BB のコールレンジを削れる

SB がリバーでチェックする場面:
  - 薄いバリュー (1ペア) → チェックしてショーダウンを目指す
  - BB がドンクベットしてくれる期待のトラップ
  - バランス調整のためのチェックバック
```

### SB のリバー チェック後の対応

SB がリバーでチェックして BB がベットしてきた場合:

```
BTN vs BB と同じ基準が使えます:
  コールオッズ (α) = ベット / (ポット + ベット)
  BB のブラフ率 > α → コール有利

SB 固有の注意点:
  SB がここまで先手を打ってきてリバーでチェック
  → BB は「SB が弱い」と判断してブラフしやすい
  → SB のチェックレンジにトラップが多いとも言える
  → BB のブラフ率が BTN チェックバック後より高い場合がある
```

---

## 25-6 BB 視点: SB への対応 (ターン・リバー)

BB が SB のベットにどう対応するかです。

### BB の MDF は BTN より緩い

```
SB vs BB での BB の防御:
  SB のレンジは BTN より弱い (広いがナッツ密度が低い)
  → BB は SB のベットに対して広くコールできる

  例: ドライ板でのターン CBet に対して
  BTN vs BB: BB は MDF 57% (75% ベット) を守る
  SB vs BB: BB は同じ状況でやや広くコールできる (SB のバリューが薄いため)
```

### BB のチェックレイズが有効な状況 (SB vs BB)

```
SB vs BB で BB の CR が有効:
  SB のバレルレンジが広い (弱いハンドでも多くバレルする)
  → BB の CR のフォールドエクイティが高い
  
  BTN のバレルは「高品質」が多いが、SB のバレルは「広め」のため
  BB の BCR (ブラフ CR) が BTN vs BB より通りやすい

  実戦的判断:
    SB がドライ板でバレルした後:
    BB がセット/ストレート/フラッシュ → バリュー CR 有効
    BB がバストドロー+ブロッカー → BCR を BTN vs BB より積極的に検討
```

## 25-7 SB vs BB での実戦例

### 例 1: SB のダブルバレル判断

**状況**: SB 2.5BB open, BB call. フロップ K♦7♣2♠, SB 33% CBet, BB call.

**ターン: 9♦**

**SB のハンド**: A♠K♦ (TPTK)

```
バレルスコア: ドライ (8) + ブランク (2) = 10 → 🟢

SB のバレル判断:
  バレルスコア 🟢 だが SB は OOP → やや控えめに
  AK はトップペアなのでバリュー目的でバレル
  → 50% ベット (BTN なら 50-75% だが SB は 50% 程度)

目的: BB のKx (より弱いトップペア) や 2x, 7x を降ろす
      BB がコールした場合: リバーの判断へ
```

### 例 2: SB のリバーチェックと BB のブラフ対応

**状況**: SB がリバーで先手をチェック (AK のトップペアで SDV 保護)。BB が 75% ベット。

```
SB の計算:
  コールオッズ = 75/(100+75) = 43%
  BB のブラフ率推定: SB がチェック → BB は「SB が弱い」と判断してブラフが増える
  → BB のブラフ率が 43% を超える可能性が高い

  AK (トップペア) の勝率: BB のバリューに対して ~55%
  → コール EV+

  SB の AK: コール
```

## 25-8 BTN vs SB との違い (番外: SB が BTN を相手にする場合)

本書の主なシナリオは BTN vs BB / SB vs BB ですが、BTN が OOP (SB) に対して戦う「BTN vs SB」のケースも重要です。

```
BTN vs SB (例: SB からレイズ → BTN コール):
  SB = OOP アグレッサー
  BTN = IP ディフェンス
  
  BTN の立場: IP (後手) なのでターン/リバーで有利な情報を持てる
  SB がドライ板でダブルバレル → BTN はコールしやすい
  SB がチェック → BTN はベットまたはチェックバック
  
  判断基準は BTN vs BB と同じフレームワークが使えるが、
  SB のレンジが BTN (3bet などから呼ぶ場合) より弱いことを考慮する
```

## ミニクイズ

### 問1

SB vs BB で SB が OOP である理由はなぜですか。

1. SB はポジションが悪い (BTN より前) ため
2. SB はフロップ以降、先にアクションしなければならないため
3. SB のスタックが少ないため

### 問2

SB のバレルスコアが 🟢 (10) の状況です。SB は BTN と同じ頻度でダブルバレルすべきですか。

1. 同じ頻度でよい (バレルスコアは同じだから)
2. SB は OOP のためコストが高く、BTN より 10% 程度低い頻度が適切
3. SB は 🟢 でもダブルバレルしてはいけない

### 問3

BB 視点で「SB のバレルレンジは BTN より広い」とわかっています。これが BB の戦略に与える影響は?

1. 影響なし。BTN と同じ MDF で守る
2. SB のレンジが広い = バリュー密度が低い → BB はより広くコール/CR できる
3. SB が広いから BB は常にフォールドすべき

---

### 解答

- **問1**: 2（SB はプリフロップでラスト (ボタンの前に) アクションしますが、フロップ以降は最初にアクションします。この「ポストフロップでの先手」が OOP の本質で、IP (後手) より常に不利です）
- **問2**: 2（バレルスコアはレンジ平均の傾向を示すが、OOP では情報コストが追加される。SB は同じスコアでも BTN より少し控えめにバレルすることで SDV を保護できる）
- **問3**: 2（SB のレンジが広い = 弱いハンドでもバレルしている可能性が高い。BB は SB のバレルに対して BTN vs BB より広くコール / 積極的に CR を検討できる）

---

> **本章まとめ**
>
> - SB は OOP かつアグレッサーという特殊ポジション
> - SB のレンジは BTN より弱め (広いが強度が低い)
> - SB のバレルは BTN と同じバレルスコアでも 10% 程度低い頻度が適切
> - BB 視点: SB のバレルは広いため、コール/CR を BTN より積極的に検討できる
> - ドライ高カードボード: SB に有利 (Ax, Kx が SB に多い)
> - ウェット/コネクテッドボード: BB 有利 (BB のコールレンジが板に絡む)

---

**【GTO とのズレ】**

GTO では SB の CBet 頻度はボードによって大きく変わります。ドライ板ではほぼ BTN と変わらない頻度で CBet し、ウェット板では大きく下がります。

実戦での「GTO とのズレ」として最も多いのは、SB が「アグレッサーだから」という理由でウェット板でも高頻度でバレルし続けることです。SB の OOP デメリットを理解せずにバレルすると、BB の強いレンジに EV を大きく失います。

また、BB 側の「GTO とのズレ」は SB に対して BTN と同じ基準でフォールドしすぎることです。SB のバレルは広めのため、BB はより広くコールする余地があります。
