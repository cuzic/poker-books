# 第29章　アクション別レンジ遷移

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ベット・チェック・コール・レイズ・フォールドの各アクションが相手と自分のレンジをどう変化させるかを体系化し、「今このレンジは何を意味するか」をリアルタイムで追跡できるようにする。

---

## 29-1 レンジ遷移の基本原理

ポーカーの各アクションは「情報の開示」です。アクションをとるたびに、自分と相手のレンジが絞り込まれます。

```
プリフロップ前:
  両者のレンジ = 全ハンド (1326 コンボ)

アクションごとに縮小:
  BTN オープン → BTN レンジが約 45% に絞られる
  BB コール → BB レンジが約 45% に絞られる
  フロップ CBet → BTN レンジがさらに絞られる
  フロップ コール → BB レンジがさらに絞られる
  ...

→ ストリートが進むごとに両者のレンジが収束し、相手の「最もあり得るハンド」が読めてくる
```

レンジ遷移を追跡することで、現在の状況で「誰がどんなハンドを持っているか」が明確になり、正しいアクション選択につながります。

## 29-2 5つの基本アクションとレンジへの影響

### アクション1: ベット（攻撃開始）

```
効果: ベット側のレンジがポラライズ（強+ブラフ）または絞られる
     相手のレンジから弱ハンドを除去（フォールドを引き出す）

BTN がフロップ CBet:
  BTN: ナッツ + ブラフ (Uncapped/ポラライズ)
  BB: コールしなかったハンドがレンジから除外

バリューのみでのベット (バリューヘビー):
  BTN: ナッツ中心 → 相手はコールしにくい
  ただし: ブラフが少ない → 相手がコールしやすくもなる (逆説)

GTO の教訓:
  ベットレンジはバリュー + ブラフのバランスが必要
  一方に偏ると相手に搾取される
```

### アクション2: チェック（パス、あるいは罠）

```
効果: チェック側のレンジが「中強度 or ナッツ (トラップ)」に偏る
     チェックした = 「弱い」とは限らない

IP がフロップ チェックバック:
  IP: 中強度ハンド (SDV 保護) + トラップ (スロープレイ) + 一部ブラフ
  OOP: 「IP は CBet しなかった = やや弱い」と読む → ドンク or チェック

OOP がフロップ チェック → IP CBet:
  OOP: コールした = フォールドしなかった (弱すぎない)
  しかし: コールしただけ = レイズするほど強くない (Capped 寄り)

両者がチェック (両者 Capped):
  両者: ナッツが少ない、中強度主体
  次のストリートはベット権を「ターンカードで改善した側」が得る
```

### アクション3: コール（ついていく）

```
効果: コール側のレンジが「中強度」に収束
     ナッツ (→ レイズ) と弱ハンド (→ フォールド) が除外される

BB がフロップ CBet コール:
  BB: 中強度ハンド (TP〜セカンドペア、ドロー等)
  除外: AA, KK 等のナッツ (3bet 済 or CR するべき)
         空振りハンドの多く (フォールド)

コールが続くとさらに収束:
  フロップ コール → ターン コール:
  BB: 強い1ペア〜2ペア、完成ドロー、まれにセット等
  ナッツ (セット、ストレート) はどこかでレイズするはずが多い

  → コールが続く = 「中強度以上が残っている」という最低基準 + Capped
```

### アクション4: レイズ（強さの主張）

```
効果: レイズ側のレンジが「ナッツ + 一部ブラフ」にポラライズ
     コールしなかった弱ハンドが除外される

BB がフロップ チェックレイズ:
  BB: セット/ストレート/フラッシュ (ナッツ) + ブラフ CR
  除外: 中強度1ペア (CR しないでコールまたはフォールド)

→ BB の CR = Uncapped なポラライズレンジ

IP の 3bet (CR に対してレイズ):
  IP: ナッツ以上 + ブラフ
  除外: 中強度 (3bet するのは強すぎる/弱すぎるハンドのみ)

→ 3bet = 極端なポラライズ (IP の Uncapped 度が最大化)
```

### アクション5: フォールド（降りる）

```
効果: フォールドしたプレイヤーのレンジが「弱ハンド」であることを示す

逆に言うと:
  フォールドしなかった = 少なくとも最低強度を超えている

フォールド後の情報:
  フォールドしたプレイヤーは以降の判断に影響しない
  残ったプレイヤーのレンジは「フォールドしないだけの理由がある」ハンド
```

## 29-3 主要なアクションシーケンスとレンジ変化

### シーケンス A: CBet → コール → ターン

```
フロップ:
  BTN CBet (Uncapped): AA, KK, AK, セット, TP, ドロー, ブラフ
  BB コール (Capped): TP〜セカンドペア, ドロー, まれにセット

ターン前の状態:
  BTN: Uncapped (ナッツ保有可)
  BB: Capped (ナッツが少ない)
  → BTN がターンで有利な立場 (ダブルバレルまたはチェックバック)

ターンカードによる変化:
  ブランクターン: BTN のアドバンテージ維持
  OOP 有利ターン (コネクター等): BB の一部ハンドが強化 → 両者のナッツ差縮小
```

### シーケンス B: チェックバック → チェック → ターン

```
フロップ:
  BTN チェックバック (Capped): 中強度, バックドロー, 一部トラップ
  BB チェック (Capped 寄り): 先手打ちしなかった = 比較的弱いか待ちの姿勢

ターン前の状態:
  BTN: Capped (ただしターンで改善可)
  BB: Capped (ただしターンで改善可)
  → 両者 Capped → ターンカードで「改善した側」がベット権を持つ

ターンでのアクション展開:
  BB チェック → BTN 遅延 CBet: BTN のターン改善ハンドが攻撃
  BB ドンクベット: BB のターン改善ハンドが先手を取る (Uncapped 化)
  BB チェック → BTN チェックバック: 両者の強度が低い (リバーへ)
```

### シーケンス C: CBet → コール → ターン チェック → チェックバック → リバー

```
フロップ: BTN CBet → BB コール
ターン: BTN チェックバック (弱さのシグナル)
       BB チェック (待ちの姿勢)
リバー前の状態:
  BTN: 「フロップは Uncapped だったが、ターン CB = Capped 化」
       弱い1ペア、バックドロー失敗ハンドが多い
  BB: TP〜2ペアが残っている、強ドロー (完成したかどうか不明)

リバーで BB がドンクベット:
  BB: ドロー完成 or ストロングバリュー (ターンまでチェックしていた = トラップ的)
  → BB のリバー先手ベットは強いシグナル
  BTN: 強ハンドのみコール (BB のレンジが絞れている)

リバーで BB がチェック → BTN がベット:
  BTN: 中強度バリューベット or ブラフ (ターン CB からの遅延リバーブラフ)
  BB: コールオッズ確認 → TP 以上でコール、弱ければフォールド
```

### シーケンス D: CBet → チェックレイズ → コール → ターン

```
フロップ: BTN CBet → BB CR → BTN コール
ターン前の状態:
  BTN: Capped 気味 (CR に 3bet しなかった = ナッツの比率が下がった)
       コール = 強い2ペア、ドロー等の中強度
  BB: Uncapped (CR = ナッツ + ブラフのポラライズ)
  → BB が Uncapped を持つ珍しい状態 → BB がターンで先手を取りやすい

ターン展開:
  BB ベット: 強バリュー継続 or ブラフ継続
  BTN コール: 中強度継続 (セット等はリレイズ)
  BTN フォールド: CB の弱いハンドが消える
  BTN レイズ (リレイズ): BTN のナッツ (ドロー完成、強いセット等)
```

### シーケンス E: CBet → コール → ターンベット → コール → リバー

```
フロップ: BTN CBet → BB コール
ターン: BTN バレル → BB コール
リバー前の状態:
  BTN: Uncapped 継続 (2ストリートバレル = 強いレンジ)
       バリューヘビー (ブラフは2ストリート維持しにくい)
  BB: Capped だが相当に絞られている
       2ストリートコール = 強い中強度 (セット, 2ペア, ストロングドロー)
       弱ハンドはフロップかターンでフォールドしている

リバーの状況:
  BTN: バリューベット or チェックバック (ブラフは少ない = バリューヘビー)
  BB: BTN が 2 バレルした = バリューヘビー → コール基準を上げる
```

### シーケンス F: CBet → コール → ターン チェック → BB ドンクベット → ...

```
フロップ: BTN CBet → BB コール
ターン: BTN チェックバック → BB ドンクベット

ターン チェックバック後の BTN: Capped (ナッツなら打っていた)
BB のドンクベット: OOP が先手 = Uncapped 化のシグナル

→ BB のドンクベット: 強いバリュー (ターン改善ハンド) + 一部ブラフ
BTN の対応:
  コール: 中強度 (TP 等)
  レイズ: ナッツ (セット等、ターンでチェックバックしてトラップ)
  フォールド: 弱いハンド
```

|---|---|---|---|
| CBet → コール | Uncapped | Capped | BTN バレル or CB、BB 受け身 |
| チェックバック → チェック | Capped | Capped | 両者中強度、ターン改善側が主導 |
| CBet → CR → コール | Capped 気味 | Uncapped | BB がターン主導、BTN は受け身 |
| CBet → フォールド | — (ポット取得) | — | 決着 |

## 29-5 リバーのレンジ遷移一覧表

| ターンシーケンス | リバー前 BTN レンジ | リバー前 BB レンジ | リバーの主要展開 |
|---|---|---|---|
| バレル → コール | Uncapped/バリューヘビー | Capped/絞られた中強度 | BTN バリューベット or ブラフ |
| チェックバック → チェック | Capped 気味 | Capped 気味 | BB ドンク or 両者チェック |
| チェックバック → BB ドンク → コール | Capped | Uncapped/強バリュー | BB リバーベット、BTN コール基準高い |
| バレル → CR → コール | 中強度/絞られた | Uncapped 継続 | BB リバーベット、BTN コール基準高い |
| バレル → バレル → コール | バリューヘビー | 強中強度 | BTN バリュー、BBはブラフキャッチ基準高い |
| CB → CB (両者チェック) | ナッツは少ない | ナッツは少ない | 中サイズのベット合戦 |

## 29-6 「コール → コール → コール」はどのようなレンジか

3ストリートすべてコールしたプレイヤーのレンジは非常に特徴的です。

```
3ストリート全コールのレンジ:
  ナッツ (セット、ストレート、フラッシュ):
    通常はどこかでレイズしているはず
    → 全コールした場合: スロープレイ (罠) の可能性
    しかし: スロープレイの頻度は低い
  
  強い中強度 (TP top kicker, 2ペア, ドロー→完成):
    最も多いパターン。3回コールできる強度を持つ
    
  弱い中強度:
    「もう入れすぎた」感覚 (サンクコスト誤謬、ch24) でコールし続けた
    数学的には間違いだが、実戦では存在する

結論: 3全コール = 「強い中強度〜スロープレイナッツ」のレンジ
     → ブラフの比率は低い (3ストリートブラフは稀)
     → ショーダウンを求めている

相手が3全コールした場合のリバーブラフ:
  非常に困難 (相手はショーダウンバリューを持っている)
  → GTO ではほとんど存在しない
```

## 29-7 レンジ遷移を追跡するための実戦フロー

実戦でレンジ遷移を追跡するための4ステップフローを示します。

```
ステップ1: プリフロップのアクションからベースレンジを設定
  「BTN オープン = 約 45%」「BB コール = 約 45%」
  「3bet ポット = BTN の 3bet レンジ vs BB のコールレンジ」

ステップ2: フロップのアクションでレンジを更新
  CBet: BTN = Uncapped  /  BB コール後 = Capped 化
  チェックバック: BTN = Capped 化
  チェックレイズ: BB = Uncapped 化

ステップ3: ターンのアクションでさらに更新
  バレル: BTN の弱いブラフがレンジから減少
  コール: BB の弱ハンドがレンジから減少
  チェックバック: BTN のバリューの一部が「中強度トラップ」に組み替え
  ドンクベット: BB の Uncapped 化が進む

ステップ4: リバーで「残ったレンジ」で判断
  相手の残レンジを想像: 何が最もあり得るか
  自分のレンジを確認: 今のアクションはどう見えるか
  EV 比較: コール/フォールド/ベットのどれが最良か
```

## 29-8 実戦例：3ストリートのレンジ追跡

**状況**: BTN vs BB、100BB。ボード Q♦J♠5♥ → ターン 9♣ → リバー K♦。

```
プリフロップ:
  BTN オープン, BB コール
  BTN: 約 45% (QQ, JJ, AJ, KQ, T9s, 76s 等)
  BB: 約 45% (22+, A2s+, K7s+, Q7s+, J7s+, T8s+, etc.)

フロップ Q♦J♠5♥:
  BTN CBet 75%:
    BTN: QQ (セット), JJ (セット), AJ, KQ, AQ, T9 (OESD), Q5 (2ペア), etc. [Uncapped]
    BB コール:
    BB: QJ (2ペア), JJ (セット→CB しなかった = 稀), QQ (同様), T9 (OESD), AJ, KQ, etc.
    ただし BB は QQ, JJ の多くは 3bet/CB 済 → [Capped]

ターン 9♣:
  BTN バレル 60%:
    BTN のバレルレンジ: QQ (セット維持), QJ (2ペア), T9 (OESD→ストレート完成!), AJ, KQ
    T♠8♣ (OESD→ストレート完成!: K-Q-J-T-9 or T-9-8-...) は?
    → 9♣ が落ちて BTN の T8 はストレート完成 (J-T-9-8-7 の一部)
    
    BB コール:
    BB: QJ (2ペア), T9 (ストレート完成), K♣T♣ (FD 完成), AJ (TP)
    [Capped だが9♣ で一部強化]

リバー K♦:
  BTN・BB の残レンジ:
    BTN: QQ (セット), QJ (2ペア), KQ (2ペア強化), T8 (ストレート), ブラフ (少)
    BB: QJ (2ペア), T9 (ストレート), KQ (2ペア強化), KJ (2ペア強化)

K♦ 落ちで KQ, KJ が強化:
  BTN: KQ (2ペア) = 強化 → バリューベット
  BB: KQ, KJ (コールレンジにある) = 強化 → コールしやすい

BTN がリバー OB (125%):
  BTN のOBレンジ: QQ (セット), ストレート, KQ (2ペア)
  BB のコール基準: 40%+ (OB の場合、コールオッズ 56%)
    → BB の QJ, T9, KQ がコール候補

  → リバー K はナッツアドバンテージの再調整
    BTN の QQ, KQ が最強。BB の QJ, T9 は次点
    BTN がバリューベット (75-100%) で正解
```

## ミニクイズ

### 問1

BTN がフロップ CBet → BB コール → ターン BTN チェックバック という展開です。ターン後の各レンジの状態は?

1. BTN: Uncapped / BB: Capped のまま
2. BTN: Capped 化 / BB: Capped のまま (両者 Capped)
3. BTN: Capped / BB: Uncapped に逆転

### 問2

「3ストリート全コール」した BB のレンジで最も多いハンドカテゴリーは?

1. ナッツハンド (セット、ストレート等) がほとんど
2. 強い中強度 (TP top kicker、2ペア、完成ドロー等)
3. 弱い1ペア (サンクコストでコールし続けた)

### 問3

フロップ BTN CBet → BB チェックレイズ → BTN コール という展開後、ターンの主導権はどちらにありますか?

1. BTN (CBet したアグレッサーなので)
2. BB (CR で Uncapped 化したため、ターンで主導権あり)
3. 両者同等 (CBet と CR が相殺される)

---

### 解答

- **問1**: 2（BTN のターン チェックバック = 「ナッツなら打っていた」シグナル → Capped 化。BB はコールのまま変わらず Capped。両者 Capped になった場合、次のストリートは「ターンカードで改善した側」がベット権を持つ）
- **問2**: 2（3ストリートコールし続けるにはそれだけの強度が必要。ナッツは途中でレイズしているはずが多く、弱1ペアはどこかでフォールドしているはず。「強い中強度」が3全コールの主体）
- **問3**: 2（BB のチェックレイズ = ナッツ + ブラフのポラライズ = Uncapped 化。BTN はコールで止まった = Capped 気味。ターンでは BB がUncapped レンジを持つため、BB のドンクベットや先手攻撃が有効になる場面が増える）

---

> **本章まとめ**
>
> - 各アクションはレンジを変化させる: ベット→ポラライズ、コール→中強度化、チェック→中強度/トラップ、レイズ→Uncapped化
> - Capped/Uncapped はアクションの積み重ねで決まる
> - CBet → コール: BTN Uncapped / BB Capped（最も多いパターン）
> - チェックバック → チェック: 両者 Capped（ターン改善側が主導権を持つ）
> - CR → コール: BB Uncapped（ターンでは BB 主導になりやすい）
> - 3全コール: 強い中強度が主体（ブラフキャッチの必要性が低い）
> - 実戦フロー: プリフロップ → フロップ → ターン → リバーとアクションごとにレンジを更新し続ける

---

**【GTO とのズレ】**

GTO はすべてのアクションシーケンスで正確なレンジ遷移を計算して最適解を出します。実戦での最大の「GTO とのズレ」は、**レンジ遷移を追跡せずに「今の自分のハンドだけ」で判断すること**です。

例えば、BTN がフロップ チェックバック後のターンで「自分は KT で1ペア = 弱い」と感じてフォールドすることがあります。しかし、BTN のレンジ全体で見るとターン改善ハンドが多く含まれており、遅延 CBet または引き続きのチェックが適切な場合があります。

「自分のハンドの強さ」ではなく「今の自分のレンジ全体の性質」と「相手のレンジの性質」を比較して判断するのが GTO 的アプローチです。レンジ遷移の追跡を習慣にすることで、相手の行動が「何を意味するか」を正確に解釈できるようになります。
