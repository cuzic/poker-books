# 第18章　マルチストリート統合判断

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップ→ターン→リバーの 3 ストリートを一貫した戦略フレームで判断する「マルチストリート思考」を身につける。

---

## 18-1 各ストリートの判断が連動する

巻 2 (フロップ)、本書 (ターン・リバー) と学んできた各判断は、孤立したものではありません。

```
フロップの判断 → ターンの状況を規定
ターンの判断  → リバーの状況を規定
リバーの判断  → 3 ストリートの総結果
```

この連動を理解することで、「なぜそのアクションをしたか」の一貫性が生まれます。

---

## 18-2 「ストーリー」を作る意識

GTO 的な判断は、ハンドのすべての情報が「ストーリー」として整合するとき最も有効です。

### ストーリーとは

```
「自分がこのラインを取ると、相手はどう解釈するか」

例 (IP のバリューストーリー):
  フロップ → 33% CBet (通常の価値ベット)
  ターン → 50% CBet (ターン強化)
  リバー → 75% CBet (バリュー最大化)

このストーリーは「フロップから強いハンドを段階的に強化している」イメージ
→ OOP が全部コールするなら、IP のナッツ周辺で大きな EV 獲得
```

### ストーリーの崩れ

```
「ストーリーの崩れ」がある ← 搾取される

例:
  フロップ → 33% CBet
  ターン → チェックバック (弱さを示す)
  リバー → 150% オーバーベット

このストーリーは「ターンで弱かった IP がリバーで突然オーバーベット」
→ 相手に「ブラフではないか?」と思われやすい
```

## 18-3 SPR (Stack-to-Pot Ratio) の変化と計画

第 1 章で学んだ SPR の変化がマルチストリートの核心です。

### SPR の典型的な変化

| 段階 | ポット | スタック | SPR |
|---|---|---|---|
| フロップ前 (2.5x open + BB call) | 5.5BB | 97.5BB | 17.7 |
| フロップ 33% CBet + call 後 | 7.4BB | 94.6BB | 12.8 |
| ターン 50% CBet + call 後 | 11.1BB | 90.9BB | 8.2 |
| リバー前 | 11.1BB | 90.9BB | 8.2 |

**リバーで SPR ≈ 8**: リバーでオールインするには ~400% ポットオーバーベットが必要。

通常はリバーでオールインは稀で、50-75% ポットベットが多い理由は SPR の制約によります。

### ポットジオメトリ: 3 ストリートでスタックを溶かす計画

スタック全額を 3 ストリートで押し込む「ポットジオメトリ」の計算:

```
スタック 100BB、プリフロップポット 5.5BB (2.5BB オープン + BB コール)
目標: リバーまでにスタック ~90BB を全部コミット

必要な掛け率 (3回のベット×コール):
  各ストリートで x 倍のポットにする場合:
  最終 SPR = 1 ÷ (2x+1)^3 = 初期 SPR

  SPR 17 → SPR 1 にするには: 各ストリート約 75% ポットベット (×2.5 規模)
  
  実例:
    フロップ: pot 5.5BB → 75% ベット (4.1BB) → pot 13.7BB (スタック 95.9BB)
    ターン:  pot 13.7BB → 75% ベット (10.3BB) → pot 34.3BB (スタック 85.6BB)
    リバー: pot 34.3BB → 100% ベット (34.3BB) = コールでオールイン
```

これが「3 ストリートすべてでバリューを取る」標準的なポットジオメトリです。

### SPR が低い場合のマルチストリート

SPR が 4 以下 (ショートスタック等) の場合、3 ストリートの計画が変わります。

```
SPR 4 以下の場合:
  フロップでの「オールインかフォールドか」の判断が増える
  ターンとリバーのゲームが単純化 (ほぼオールインを前提)
```

## 18-4 3 ストリートの役割分担

各ストリートは異なる「役割」を担います。

### フロップの役割: レンジを絞る

```
フロップ CBet の主目的:
  - BB の弱いハンドをフォールドさせる
  - BB のコールレンジを「ある程度強いハンド」に絞る
  - 自分のレンジの優位を主張する

フロップでは「多くのハンドで小さくベット」が有効
```

### ターンの役割: 圧力を継続・増加

```
ターン (ダブルバレル) の主目的:
  - BBのコールレンジをさらに絞る
  - レンジの強化を示す
  - ドロー組をチェックレイズせずにコール状態に保つ

ターンでは「強いハンドと一部のドロー」でベット
```

### リバーの役割: EV を回収

```
リバーの主目的:
  - バリューを最大化する (コールを引き出す)
  - ブラフで残っているポットを取る

リバーでは「バリューかブラフかの明確な判断」が必要
```

## 18-5 バレルスコア + Alpha 式の統合フロー

本書の主要ツールを統合して使う実践フローです。

### 統合判断フロー

```
1. プリフロップでのポジション・ハンドクラスを把握
   (BTN/BB、ヘッズアップ、100BB スタート)

2. フロップ:
   a. 板の特性 (BoardScore: 巻 2 参照)
   b. 自分のハンドクラス (HandScore: 巻 2 参照)
   c. CBet = Yes/No の判断 (統合式: 巻 2 第 6 章)
   d. CBet サイズ: 33% (通常) / 50% (強め) / 100% (超ポラライズ)

3. ターン:
   a. 板タイプの再確認 (ドライ/セミ/スーテッド/コネクテッド)
   b. ターンカードの5分類 (第 2 章)
   c. バレルスコア = FlopType 係数 + TurnCard 係数 (第 4 章)
      → ≥ 7: 積極バレル / < 7: チェックバック基本
   d. ハンドクラス別の役割 (ナッツ/セミブラフ/SDV)

4. リバー:
   a. ハンドの最終評価 (バリュー/ブラフキャッチャー/ブラフ)
   b. ブラフ率 vs コールコスト率:
      Alpha = ベット / (ポット + ベット)
      コール有利: 相手ブラフ率 > Alpha
   c. V:B 比率の確認 (第 10 章)
   d. オーバーベットの検討 (第 13 章: ポラライズ条件を確認)
```

## 18-6 ハンドレビューの実例

実際の 5 枚ボードを通じてフローを確認します。

### 例 1: BTN vs BB、K♠7♥2♣ 9♦ 3♠

**プリフロップ**: BTN が 2.5BB オープン、BB コール (2.5+2.5 = 5BB ポット、97.5BB スタック)

**フロップ K♠7♥2♣**:
- BoardScore: K72r = 高位 + レインボー + 非コネクテッド → ドライ高頻度
- BTN のハンド: A♦K♦ (トップペア + トップキッカー)
- CBet 判断: ドライ板 × 強いトップペア → 33% CBet (3.3BB)
- BB コール → ポット 11BB、スタック 94.7BB (SPR ≈ 8.6)

**ターン 9♦**:
- 板タイプ: ドライ (K72r)
- ターンカード: 9 = ブランク (フロップ K より低い非関連カード)
- バレルスコア: ドライ(8) + ブランク(2) = 10 → 🟢
- BTN のハンド: AK は今もトップペア、9 は影響なし
- ダブルバレル 判断: 🟢 → ベット 50% (5.5BB)
- BB コール → ポット 22BB、スタック 89.2BB (SPR ≈ 4.1)

**リバー 3♠**:
- ブランク (スペードが 2 枚目、FD なし)
- BTN のハンド: AK (トップペア) = 薄いバリュー
- 相手の BB コールレンジ: Kx (同程度), 77/22 (セット), 9x-9 (2ペア)
  → AK が勝てるのは Kx の一部 (K8, K6 等)、あとはほぼ負ける
- 判断: バリューベットではなくチェックビハインド推奨
  (コールされると相手は AK を負かすハンドが多い)

**SPR 分析**: リバー前の SPR 4.1 は「ポット比でスタックがまだ残っている」。AK は薄バリューのためチェックビハインド。もし AK ではなく AA (セット以上) であれば 75-100% バリューベットが推奨。

**実際のGTOとの比較**: GTO では AK でも一定頻度ベット (≈30%) しますが、実戦では「チェックビハインドして守る」が無難です。

---

### 例 2: IP がオーバーベットを計画するライン

**ボード**: K♦T♠5♣ J♦ 9♦ (5枚)

**フロップ K♦T♠5♣**:
- セミウェットボード (スペード FD あり)
- IP のハンド: Q♦J♦ (ガットショット + フラッシュドロー)
- CBet: 50% ポット (セミブラフ)

**ターン J♦**:
- J でトップペアになりドロー継続
- ターンカード: J = フロップより低い OC に準ずる中ランク
- バレルスコア: セミ(6) + OC(3) = 9 → 🟢
- Q♦J♦ はターンでトップペア + フラッシュドロー → バリュー/セミブラフ
- ダブルバレル 75%

**リバー 9♦**:
- 9♦ でダイヤフラッシュ完成！
- Q♦J♦ → A♦なし、K♦なし、ナッツではないが強いフラッシュ
- ポラライズ条件: フロップ〜ターンのダブルバレル後 + フラッシュ完成 → ✓
- オーバーベット (150%) が検討できる状況

```
IP のオーバーベット判断チェックリスト:
  □ ポラライズしているか? → ターンまでバレルしてきた → YES
  □ ストーリーが一貫? → フロップからセミブラフ〜リバーでフラッシュ完成 → YES
  □ リバーカードで IP のレンジが強化? → フラッシュ完成 → YES
  □ BB のコールハンドに勝てるか? → 非フラッシュには勝てる
  
  → オーバーベット (125-150%) 検討
```

## 18-7 よくある「ストーリーの一貫性エラー」

### エラー 1: フロップ大ベット → ターン小ベット

```
フロップ: 100% CBet (ポラライズ)
ターン: 33% CBet (ブロック風)

問題: フロップでポラライズしたなら、ターンも強気を維持すべき
    ターンで小ベットすると「フロップのブラフが弱かった」シグナル
    
対策: フロップ 100% を使うのはナッツ+ブラフのポラライズ時のみ。
     「だいたい強い」ハンドでは 33-50% が安定。
```

### エラー 2: 全ストリートにわたる「過剰なバレル」

```
フロップ → ターン → リバーと全バレルするとき:
  OOP のコールレンジが「ストレートやフラッシュ」になっている可能性
  → リバーのバリューが大幅に薄い

「全部バレル = 全バリュー」ではない。最終的なバリューを常に確認

実例:
  9♠8♠7♣ → 6♠ → A♥ で BTN が A♦K♦ でトリプルバレル
  フロップ + ターンで BB のストレート候補が増加
  リバー A で BTN の AK は「2ペア」だが BB の T5 (ストレート) に負ける
  → バリューのようで実はブラフに近い状況
```

### エラー 3: ターンチェックバック → リバー過剰ベット

```
ターン: チェックバック (ショーダウンバリュー保護)
リバー: OOP のチェックに大きくベット

問題: IP のチェックバック → BB は「IP は弱い」と思う
    IP の大ベットを BB は「ブラフ?」と疑いコールしやすくなる
    → バリューなら良いが、ブラフなら逆効果

対策: チェックバック後のリバーベットは「インダクトベット」か「バリュー」に絞る。
     大きなブラフは IP のストーリーが崩れる。
```

### エラー 4: フロップ強気 → ターン弱気 → リバー強気

```
フロップ: 強くベット
ターン: チェックバック
リバー: 強くベット (バリュー or ブラフ)

問題: ターンで止まって「弱さを示した」後、リバーで強くベットしても
     「ターンが弱かったのになぜ?」と思われる

対策:
  - ターンでのチェックバックは「本当の SDV 保護」か「意図的なスロープレイ」のみ
  - リバーでの強ベットは「ターンのチェックバックが意図的だった」と見せるストーリー設計
  - 例: ターンでセットをチェックバック → リバーで BB のブラフに合わせてコールまたはレイズ
```

## 18-8 3ストリート戦略パターンの整理

### よく使う戦略パターン

| フロップ | ターン | リバー | ストーリー |
|---|---|---|---|
| 33% CBet | 50% バレル | 75% バリュー | 段階的なバリュー最大化 |
| 33% CBet | チェックバック | 50% バリュー | SDV 保護 → 薄バリュー回収 |
| 50% CBet (ドロー) | 75% バレル | オーバーベット | セミブラフ → バリュー転換 |
| 100% CBet | 大バレル | 大バリュー/折れ | ポラライズ戦略 |
| 33% CBet | チェックバック | 33% インダクト | トラップ誘導 |

### バレルスコア × Alpha 式の組み合わせ

```
ターン判断: バレルスコアで決める
  ≥ 7 → 積極バレル
  < 7 → チェックバック基本

リバー判断: Alpha 式で決める
  相手ブラフ率 > Alpha → コール有利
  V:B 比率で自分のベットレンジを設計

両方を組み合わせると:
  ターン: 🟢 + ハンドが強い → バレル + リバーでバリューを計画
  ターン: 🟡 + ハンドが SDV → チェックバック + リバーでインダクトまたはチェックビハインド
```

## ミニクイズ

### 問1

フロップ 33% CBet、ターンで相手コール後、リバーでブランクが落ちました。SPR ≈ 4。自分のハンドはトップペアトップキッカー。最適なリバー戦略はどれですか。

1. 100% オーバーベット (SPR が低くスタックを全部押し込む)
2. 50% バリューベット (標準的なバリュー回収)
3. チェックビハインド (1ペアはリバーで薄いバリュー)

### 問2

「フロップ → ターン → リバーでストーリーが崩れる」典型パターンはどれですか。

1. フロップ 33% → ターン 50% → リバー 75%
2. フロップ 33% → ターンチェックバック → リバー 150% オーバーベット
3. フロップ 50% (セミブラフ) → ターン 75% → リバーでフラッシュ完成しオーバーベット

---

### 解答

- **問1**: 2（トップペアトップキッカーはリバーでも「薄いバリュー」。50% バリューベットが最適。100% オーバーベットはコールされると逆選択が強い。チェックビハインドは EV を逃す。ただし「相手のコールレンジに何が多いか」を確認して最終判断）
- **問2**: 2（ターンチェックバックで「弱さ」を示した後、リバーで突然のオーバーベットは「ブラフ候補」に見える。相手はコールしやすくなり、ブラフとして成立しにくい。選択肢3は「フロップ〜ターンのストーリーを継続してリバーでバリューに転換」なので一貫性がある）

---

> **本章まとめ**
>
> - 各ストリートの判断は連動している (ストーリーの一貫性)
> - SPR の変化を把握してリバーのオールイン/ベットサイズを計画する
> - ポットジオメトリ: 3ストリートで各 75% ベットが標準的なスタック全押し込みライン
> - 統合フロー: フロップ (板特性) → ターン (バレルスコア) → リバー (V:B + ブラフ率)
> - ストーリーの崩れを避ける (大ベット後の急な小ベット、チェックバック後のOB等)
> - バレルスコア × Alpha 式の組み合わせでターン→リバーの戦略を一貫させる

---

**【GTO とのズレ】**

本章の「ストーリー一貫性」概念は GTO の近似です。GTO は必ずしも「一貫した大きなベット」を要求しません。

GTO では「各ストリートで最 EV なアクション」を選びますが、これは必ずしも「前ストリートと同じスタイル」でなくてよい。特に IP のターンチェックバック後リバーベットは、GTO でも頻繁に発生します (ターンでバランスを取るため)。

実戦での「ストーリー一貫性」は「自分のプレイが搾取されにくいか」の粗いチェックに有用ですが、GTO の精密な計算はストーリーではなくコンボ単位の EV 計算で行われます。また本章で示した「3ストリートで各 75% × 3回」のジオメトリは一例であり、実際には各ストリートの板特性とハンドクラスに応じてサイズを変えます。
