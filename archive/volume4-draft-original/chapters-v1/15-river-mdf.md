# 第15章　リバー MDF の実用的扱い

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバー MDF を「機械的に守る」ことの危険性を理解し、状況に応じた正しいディフェンス判断を身につける。

---

## 15-1 「MDF を守れば損しない」は誤り

巻 2・本書第 5 章で MDF を学びました。しかし、**リバーではMDF を機械的に適用することが損失につながります**。

### なぜリバーでの機械的 MDF が危険か

フロップやターンでは、コールして「次のカードで状況が変わる」可能性があります。しかしリバーでは:

1. **エクイティが確定している**: コールしてもカードは変わらない
2. **コールの唯一の価値はショーダウン**: 「もしかしたら相手がブラフかも」の読みだけ
3. **相手の各ハンドに対して固有の判断が必要**: レンジ全体の MDF ではなく、個々のハンドの勝率が重要

> **重要な概念転換**: リバーの「フォールド頻度」は MDF から計算するのではなく、「相手のベットレンジにおけるブラフ率」から逆算します。

---

## 15-2 正しいアプローチ: ブラフ率から計算する

### 計算式

```
コールが有利 ← 相手のブラフ率 > コールコスト / (ポット + コールコスト)
```

例: ポット 20BB、相手のベット 15BB (75% pot)

```
コールコスト率 = 15 / (20 + 15) = 43%
→ 相手のベットレンジの 43% 以上がブラフなら、コールが有利
```

これは「MDF は 57%」と同じ計算ですが、**発想が逆です**。

- MDF 発想: 「私は 57% コールしなければならない」→ 機械的に適用
- ブラフ率発想: 「相手のブラフが 43% 以上なら、私のブラフキャッチャーはコール有利」→ 相手依存

### ベットサイズ別のコールに必要なブラフ率

| ベットサイズ | コールコスト率 | 必要ブラフ率 | MDF (参考) |
|---|---|---|---|
| 33% pot | 25% | 25%以上 | 75% |
| 50% pot | 33% | 33%以上 | 67% |
| 75% pot | 43% | 43%以上 | 57% |
| 100% pot | 50% | 50%以上 | 50% |
| 150% pot (OB) | 60% | 60%以上 | 40% |

---

## 15-3 「薄いハンドはリバーでフォールドする」原則

### フロップ・ターンとリバーの違い

| ストリート | 薄いハンドの扱い |
|---|---|
| フロップ | 弱いセカンドペアでもコール (ドロー成分 + MDF) |
| ターン | ドロー成分が残るなら一部コール |
| **リバー** | **ショーダウン価値がなければ、フォールド or レイズのみ** |

「ショーダウン価値がない」= 相手のコールレンジの大部分に負ける状態

### フォールドすべきハンドの基準

```
リバーのコール判断:
  相手の (バリュー + ブラフ) レンジに対して、
  自分のハンドが「ブラフキャッチャー」として機能するかどうか

  機能する = 相手のブラフには勝てる (AND ブラフ率が十分高い)
  機能しない = 相手のバリューにも負ける (or ブラフ率が低い)
```

**具体例:**

ボード: K♣ 7♦ 2♠ A♠ J♥

あなたの手: Q♠ T♠ (何もない - ストレートドローも外れた)

相手の 75% ポットベットレンジ:
- バリュー: Ax (2ペア以上), KJ (2ペア), AK etc.
- ブラフ: バスタードドロー (Q9, 98 など), 空振りセミブラフ

QT はバリューレンジに全て負け、一部のブラフ (QJ などストレート完成したもの) にも負ける。

→ **フォールド推奨** (MDF を考えても QT でコールするのは誤り)

---

## 15-4 「守りすぎ」の具体的なパターン

以下のパターンは「リバー MDF を機械的に守ろうとする」落とし穴です。

### パターン 1: 全てのペアでコール

「ペアがあれば何かがブラフかもしれない」でコールする。

**問題点**: 相手のベットレンジがバリューヘビーな状況では、ミドルペアでも負け。

**正しい判断**: 相手のベット頻度と自分のハンドの相対強度を考える。

---

### パターン 2: 「MDF が 57% なので何か 57% の頻度でコールするハンドを探す」

MDF は「レンジ全体で」守る下限です。個々のハンドで 57% に当たりを付けるものではありません。

**正しい理解**: 強いハンド (KJ 以上など) は 100% コール、弱いハンドは 0% コール (フォールド)。レンジ全体の平均が MDF を下回らなければ良い。

---

### パターン 3: オーバーベットにもコール

「MDF = 40% だから 60% フォールドできる」は正しいですが、「40% の中に入れるハンドが実際に勝率 50% 以上か」を確認しないとコールが損。

---

### パターン 4: 「まだ勝てるかも」のウィッシュ・コール

「相手がブラフだといいな」という希望でコールするのは EV マイナスの典型です。コールには「相手のブラフ率 > コールコスト率」という論理的根拠が必要です。

```
ウィッシュ・コールの典型:
  - ハイカードのみで「一応コール」
  - 相手のレンジを分析せず感情でコール
  - 「もったいないからコール」(ポットが大きいからコール)
  
正しい思考:
  「相手のベットレンジのブラフ率は○○%、コールコスト率は○○%」
  → ブラフ率 > コールコスト率 なら EV+ → コール
  → そうでなければフォールド
```

---

## 15-5 実戦的なリバーディフェンス戦略

### ハンドの 3 分類に基づくルール

```
バリューハンド (コールされて 50%+ 勝てる):
  → ベット推奨。チェックコールでも OK。レイズも可。

ブラフキャッチャー (コールされると勝率 30-50%、ブラフには勝てる):
  → 相手のブラフ率を読んでコール or フォールド

ショーダウン価値なし (コールされてほぼ負ける):
  → フォールド (or レアケースでレイズブラフ)
```

### 相手のアグレッションに基づく調整

| 相手の特性 | 調整 |
|---|---|
| ブラフが多い (Loosey) | コール頻度を上げる。ブラフキャッチャーでもコール |
| タイトバリュー (Nit) | コール頻度を下げる。強いハンドのみコール |
| 未知 | GTO に近い判断 (MDF 近辺) |

## 15-6 ブロッカーによる調整

リバーでは、ブロッカー効果でコール/フォールドの閾値が変わります。(詳細は第11章)

**例**:

相手が A♦4♦ ボードでフラッシュ完成ターンにベット。

あなたが A♠ を持つ場合:
- 相手の Ax フラッシュ (A♥5♥ など) をブロック
- → 相手のバリューレンジが減り、ブラフ率が上がる
- → MDF より少し高い頻度でコールが有利

あなたが 5♥ を持つ場合:
- 相手の 5♥ 含むブラフドローをブロック
- → 相手のブラフが減り、バリュー率が上がる
- → MDF より少し低い頻度でコールが有利 (フォールドしやすい)

## 15-7 ポジション別のリバーディフェンス

ポジションによって「どのハンドでディフェンスするか」が変わります。

### IP (BTN) のディフェンス

IP は OOP のベットに反応するため、より広いディフェンスレンジを持てます。

```
IP のリバーコール基準:
  OOP がベット → IP には「コールするとショーダウン」の情報優位がある
  相手の弱いベットを見抜ける (相手がチェックしなかった = バリューorブラフ)

  → IP は OOP より若干広くコールできる
```

### OOP (BB) のディフェンス

OOP は先手で行動しており、IP に残すアクション権がある分、より慎重なコール判断が必要です。

```
OOP のリバーコール基準:
  先手ベット → コール = ショーダウン
  チェック → IP がベットした後のコール = 相手のベットに対して反応

  どちらも「相手のレンジのブラフ率がコールコスト率を超えるか」が基準
  ただし IP の後手ベットは「強さのシグナル」になりやすいため
  OOP は MDF より少し低い頻度でコールしても大丈夫なことが多い
```

## 15-8 リバーの「インディファレンス」点

GTO では各ハンドが「コールしても EV が変わらない」インディファレンスの状態になるよう設計されています。

### インディファレンスの意味

```
インディファレンス = コール EV = フォールド EV = チェックコール EV

この状態では「コールもフォールドも同じ」→ どちらでもよい

GTO ではインディファレンスのハンドが MDF の境界に位置する
```

### 実戦への応用

```
インディファレンスに近いハンドの判断:
  「相手がブラフなら儲かる、バリューなら損する」でほぼ五分五分なら
  → どちらでも大差なし (心理的に楽な方を選ぶ)
  
  ただし「確実に EV+」なら迷わずコール
  「確実に EV−」なら迷わずフォールド
  
  実戦での間違いは「インディファレンス境界の手を正確に判断しようとして
  明らかにコール/フォールドすべき手を逆にする」こと
```

## 15-9 ボードタイプ別のリバーディフェンス目安

### ドライボード (K72r → ランナー → A)

```
ドライボードリバー特性:
  相手のブラフ候補: 少ない (ドローがない)
  相手のバリュー: Ax, Kx 中心
  
  → ディフェンスは「バリューに勝てるハンド」のみ
  → ミドルペア以下はフォールドしやすい
  → MDF を「厳守」しようとするとコストが高くなる
```

### ウェットボード (987ss → 6 ターン → 5 リバー)

```
ウェットボードリバー特性:
  相手のブラフ候補: 外れたドロー多数
  相手のバリュー: ストレート, フラッシュ等
  
  → ディフェンスのブラフキャッチャーが機能しやすい
  → MDF に近い頻度でコールしてもコストが小さい
  → ただし「ドロー完成 = バリュー」と「外れドロー = ブラフ」が混在
  → 読みの精度が重要
```

### フラッシュ完成リバー

```
フラッシュ完成リバー特性:
  ブロッカー効果が非常に重要
  フラッシュスーツのブロッカーを持つ → コールしやすい
  フラッシュスーツのアンブロッカーを持つ → 相手のバリューが多い → フォールドしやすい
  
  例: ボード K♣T♣5♦ 2♠ 9♣
    自分が A♣ を持つ → ナッツフラッシュ (A♣X♣) をブロック → 相手のバリュー減少 → コール有利
    自分が 3♣ を持つ → 弱いクラブをブロック → 強いフラッシュの相手がコールしてくる → フォールド有利
```

## 15-10 実戦シミュレーション: MDF ディフェンスの正誤判断

以下の各状況で「コール」「フォールド」を判断してみましょう。

**シナリオ A**: ポット 25BB、相手 75% ポットベット (18.75BB ≒ 19BB)。相手のブラフ率: 40%。自分のハンドはミドルペア (コールされると相手のバリューの 80% に負ける、ブラフに勝てる)。

```
コールコスト率 = 19/(25+19) = 43%
相手のブラフ率 40% < コールコスト率 43%
→ コールは EV マイナス → フォールド
```

**シナリオ B**: ポット 30BB、相手 50% ポットベット (15BB)。相手のブラフ率: 45%。自分のハンドは弱い 2ペア (コールされると相手のバリューの 40% に負ける、ブラフに勝てる)。

```
コールコスト率 = 15/(30+15) = 33%
相手のブラフ率 45% > コールコスト率 33%
→ コールは EV プラス → コール
```

**シナリオ C**: ポット 20BB、相手オーバーベット 30BB (150%)。相手のブラフ率: 55%。自分はトップペア弱キッカー。

```
コールコスト率 = 30/(20+30) = 60%
相手のブラフ率 55% < コールコスト率 60%
→ コールは EV マイナス → フォールド
(オーバーベットに対してトップペア弱キッカーでコールするには 60%+ のブラフ率が必要)
```

## ミニクイズ

### 問1

ポット 20BB、相手が 10BB ベット (50%)。「MDF を守る」という観点から必要なコール頻度はいくつですか。また実際に「コールが EV+」になるために必要な条件は何ですか。

1. MDF = 67%。コールが EV+ の条件は相手のブラフ率が 33% 以上
2. MDF = 50%。コールが EV+ の条件は自分のペアが強いこと
3. MDF = 40%。コールが EV+ の条件は相手が攻撃的プレイヤーであること

### 問2

相手がリバーにオーバーベット (150% pot) してきました。MDF の観点では 40% 守れば十分です。40% の中に「弱い 2ペア」を含めるべきですか。

1. 40% の中に入れる (MDF を守るため)
2. 弱い 2ペアが相手のバリューに勝てるかで判断する
3. オーバーベットは常にフォールド

### 問3

あなたが Ax ブロッカーを持っている状態で、相手がフラッシュ完成リバーにベットしてきました。MDF の考え方から、どう調整しますか。

1. ブロッカーは無関係。MDF 通りにコール/フォールドを決める
2. Ax ブロッカー = 相手のナッツフラッシュ (Ax フラッシュ) をブロック → 相手のバリューが減る → MDF より高い頻度でコール検討
3. Ax = 強いハンドなのでコールは常に正当化される

---

### 解答

- **問1**: 1（MDF = 1 - 10/(20+10) = 1 - 33% = **67%**。コールが EV+ の条件は相手のブラフ率 > コールコスト率 33%。MDF は「レンジ全体の防御下限」でありコールの十分条件ではない）
- **問2**: 2（MDF は下限であり「40% に入れるハンドが適切かどうか」は別問題。弱い 2ペアが相手のバリューに 50% 以上勝てるかどうかで判断する）
- **問3**: 2（Ax ブロッカーは相手の Ax 系ナッツフラッシュを 1 枚減らす効果がある。相手のバリュー密度が下がった分、MDF より高めにコールを検討できる）

---

> **本章まとめ**
>
> - リバーでの MDF は「機械的に守る下限」ではなく、「コールの判断基準」として使う
> - 正しい問い: 「相手のブラフ率が○○% 以上なら私のコールは有利か」
> - 個々のハンドの勝率が最優先。薄いハンドは積極的にフォールドする
> - 「守りすぎ」のパターンを意識して避ける (ウィッシュコール、全ペアコール等)
> - ブロッカー効果でコール/フォールドの閾値を微調整する
> - ウェットボードは BCR/ブラフが多いためコール域が広く、ドライボードは狭い

---

**【GTO とのズレ】**

GTO は「確かに MDF の境界でコール/フォールドを決める」が、それはレンジ単位の話です。

実際の GTO ソルバー出力では、個々のコンボが「このハンドはコール、このハンドはフォールド」と細かく分かれています。一見すると「なぜこのハンドで?」と思うコールやフォールドも、レンジ全体の MDF を守るためのバランス調整です。

「MDF を満たす」ために弱いハンドをコールするのではなく、「強いハンドが十分あるか」を確認して MDF が自然に満たされる形を目指すのが正しいアプローチです。

また、GTO では「完全にインディファレンスになるハンド」が境界付近に存在します。実戦では「この手はどちらでも大差ない」と判断できる能力が、精度の高いディフェンスにつながります。
