# 第28章　レンジ強度と Capped/Uncapped 概念

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 「レンジが強い/弱い」「Capped/Uncapped」「タイト/ワイド」の概念を実戦判断に直結させ、「誰が大きく打てるか」を行動前に見極められるようにする。

---

## 28-1 レンジ強度とは何か

「レンジ強度」とは、あるプレイヤーのハンドの集合（レンジ）が**平均的にどれだけ強いか**を表す指標です。

```
レンジ強度を決める2つの軸:

軸1: レンジの「幅」（ワイド vs タイト）
  ワイド: 多くのハンドを含む (例: BB のプリフロップコールレンジ)
  タイト: 強いハンドに絞られている (例: UTG のオープンレンジ)

軸2: レンジの「最強ハンドの比率」（ナッツアドバンテージ）
  ナッツが多い: セット/ストレート/フラッシュが多く含まれる
  ナッツが少ない: 1ペア中心で最強ハンドが少ない
```

これら2軸を組み合わせると、実戦で出会うレンジの性質が見えてきます。

---

## 28-2 Capped レンジとは

「Capped レンジ」とは、**ナッツ (最強ハンド) が含まれていない、または非常に少ないレンジ**です。「上限が存在する」と理解するといい。

```
Capped レンジの例:

1. フロップ CBet に対してコールした BB:
   BB が QQ 以上でレイズしなかった場合、BB のレンジには QQ 以上が少ない
   (強すぎるハンドはプリフロップ 3bet やフロップ CR で消える)

2. IP がフロップをチェックバックした後:
   IP が AA や AK (ナッツ) を持っていれば多くの場合 CBet する
   チェックバックした = ナッツが少ない
   → IP のターンレンジは Capped

3. 3ストリート全コール (ショーダウン時):
   3回コールし続けたプレイヤーはナッツより中強度が多い
   (ナッツがあればレイズしている可能性が高い)
```

---

## 28-3 Uncapped レンジとは

「Uncapped レンジ」とは、**ナッツを含む可能性があるレンジ**です。

```
Uncapped レンジの例:

1. プリフロップのオープンレイザー:
   AA/KK/AK 等のナッツハンドを保有している可能性がある

2. フロップで CBet した IP:
   AA、AK、セット等を CBet している (ナッツ込みのレンジ)

3. ターン/リバーで大きくベットした側:
   OB など大サイズのベットはナッツとブラフのポラライズが前提

→ Uncapped レンジを持つ側は「大きくベットする権利」がある
→ Capped レンジの側は「大きくベットしにくい」
```

---

## 28-4 アクションが Capped/Uncapped を決める

各アクションはレンジの性質を変化させます。

### フロップのアクション別分類

| アクション | IP のレンジ | BB のレンジ |
|---|---|---|
| IP CBet → BB コール | Uncapped (ナッツ保有) | Capped (ナッツでレイズしなかった) |
| IP CBet → BB CR | Uncapped (ナッツ保有) | Uncapped (ナッツで CR) |
| IP チェックバック → BB チェック | Capped (ナッツなら打った) | Capped (ナッツなら CR か先手打ち) |
| IP チェックバック → BB ドンク | Capped (チェックバック側) | Uncapped (ドンクで強さ示す) |

この表を見ると、**両者がチェックした場合は両者ともに Capped になる**という重要な事実がわかります。

---

## 28-5 ナッツアドバンテージとは

「ナッツアドバンテージ」とは、**あるボードで自分のレンジの方がナッツを多く含んでいる状態**です。

```
ナッツアドバンテージが重要な理由:
  ナッツを含む側 = 大きくベットできる
  ナッツを含まない側 = コールしにくい (最悪ケースが怖い)

例: ドライボード K♦7♣2♠ でフロップ CBet した BTN:
  BTN のレンジに AA, KK, AK が多い (ナッツアドバンテージあり)
  BB のレンジには KK 以上はほぼない (コール時)

  → BTN がドライ板で高頻度 CBet できる根拠 = ナッツアドバンテージ

逆例: T♠9♦8♣ のコネクテッドボード:
  BB のコールレンジには 76, JT 等のストレート系ハンドが多い
  BTN は JT, QJ 等は持つが、BB も同様のドロー/完成を保有
  → ナッツアドバンテージが BTN に集中しない
  → BTN の高頻度 CBet が効きにくい
```

---

## 28-6 タイト vs ワイドとナッツアドバンテージの関係

レンジが「ワイド」であっても「Uncapped」とは限りません。

```
BTN のオープンレンジ (約 45%):
  AA-22, AK-A2s, KQ-K8s, QJ-Q8s, JT-J8s, T9-T7s, etc.
  ワイド かつ Uncapped (AA/KK/AK を含む)

BB のコールレンジ vs BTN (約 45%):
  22+, A2s+, K8s+, Q8s+, J7s+, T7s+, 96s+, etc.
  ワイド かつ Capped (強いハンドでは 3bet するため、コール側は中強度多め)

→ ワイドであっても BB のコールレンジはナッツが薄い = Capped 寄り

実戦での意味:
  BB は広くコールするが、ナッツが少ない → BTN に対して大きくベットしにくい
  BTN は AA/KK 等ナッツを含む → 大きくベット (CB) できる
```

## 28-7 ボード別の Capped/Uncapped 変化

ターンカードによって Capped/Uncapped のバランスが変わります。

### ターンカードで Uncapped が逆転するケース

```
フロップ: K♦7♣2♠ (BTN CBet → BB コール)
  BTN: Uncapped (AA, KK, AK 等を含む)
  BB: Capped (AA 以上はプリフロップ 3bet 済)

ターン: 7♥ (ペア)
  77 のセット: BTN 保有率が高い (BBはプリフロップ 3bet しない 77 を持てる)
               BB も 77 を保有できるが、数は限定的
  KK のフルハウス: BTN が多い
  72 のツーペア: BTN が K 上の手なら、これはない

  → ペアターンでも BTN のナッツアドバンテージは維持される
```

```
フロップ: T♠9♦8♣ (BTN CBet → BB コール)
  BTN: Uncapped だが、JT, QJ 等のストレートは BB も持てる

ターン: 7♦ (ストレート完成)
  76 → ストレート完成: BB のコールレンジに 76 が多い (ワイドコール)
  JT → ストレート完成: BTN のオープンレンジに JT が多い

  → J♥7♥ = QJT98 のストレート (BB が J♥7♥ を持てる) → BB も Uncapped 化
  → BTN のナッツアドバンテージが縮小

  → BTN の CBet 有効性が低下し、BB の CR やドンクベットが増加
```

## 28-8 Capped/Uncapped を実戦で活かす判断フロー

```
実戦チェックリスト:

ステップ1: 自分のレンジは Capped か Uncapped か？
  → 直前のアクション（チェックバック、コール等）がどちらを示唆するか確認

ステップ2: 相手のレンジは Capped か Uncapped か？
  → 相手の直前のアクションを同様に確認

ステップ3: ナッツアドバンテージはどちらにあるか？
  → ボードのナッツハンド（セット、ストレート、フラッシュ等）を
     どちらのレンジが多く含むか比較

ステップ4: 判断
  自分 Uncapped + 相手 Capped → 大きくベット可（ナッツアドバンテージ活用）
  自分 Capped + 相手 Uncapped → 大きくベットしにくい（コールに絞るか中サイズ）
  両者 Capped → 中サイズのベット合戦（大きなポラライズは難しい）
  両者 Uncapped → ナッツアドバンテージ比較で判断
```

## 28-9 ドンクベット：OOP の Uncapped レンジを活かす戦略

「ドンクベット（Donk Bet）」は、OOP（BB）がターンで IP（BTN）の CBet を待たずに先手ベットするアクションです。GTO では **OOP がターンで Uncapped または ナッツアドバンテージを持つ場合**に有効とされています。

```
ドンクベットが有効な条件:

1. ターンカードが OOP のレンジを強化する場合:
   例: フロップ K♦7♣2♠ (BB コール) → ターン 7♥

   BB のコールレンジに 77 (セット→フルハウス) や 72s (ツーペア) が含まれる
   BTN は 77 を CBet 後フォールドすることが多い (プリフロップ 3bet しなかったため数が少ない)

   → 7 ペアターンで BB は Uncapped 化
   → BB がドンクベット: BTN の Kx や Ax に対して FEQ が高い

2. ボードが OOP のレンジに合いすぎる場合:
   例: フロップ T♠9♦8♣ (BB コール) → ターン 6♠

   BB のコールレンジ: 76s, JTs, T9s 等のコネクターが多い
   6♠ で BB のストレート完成率が BTN より高い
   → BB がドンクベット: 強いバリュー + ブロッカー付きブラフ

ドンクベットは例外戦略:
  GTO での出現頻度は低く (特定ボード特定ターンで 20-40%)
  ほとんどのターンでは BB はチェックして IP のベットに反応する

  → ドンクベットを使う前に「このターンカードで自分が Uncapped になっているか」を確認
```

## 28-10 レンジ強度判断の実例3問

### 実例 1: フロップ CBet コール後のターン

**状況**: BTN CBet → BB コール。ボード Q♦J♣5♠、ターン K♥

```
フロップ後の状況:
  BTN: Uncapped (AA, KK, QJ, JJ, 55 等を含む CBet レンジ)
  BB: Capped (強ハンドは 3bet済 → コールレンジは QJ, JTs, 55, T9 等の中強度)

ターン K♥:
  BTN: AK (2ペア), KK (セット), KQ, KJ が強化
  BB: K を持つには... KQ, KJ, KTs が BB のコールレンジに含まれる (一定数)

ナッツアドバンテージ:
  KK (セット): BTN が多い (BB は KK で 3bet する)
  AK (2ペア): BTN が多い (BB は AK を一部コール)
  結果: BTN のナッツアドバンテージは K 落ちでも維持
  → BTN がターンでもバレル有効 (Uncapped が維持される)
```

### 実例 2: フロップ チェックバック後のターン

**状況**: BTN チェックバック → BB チェック。ボード K♦7♣2♠、ターン A♥

```
フロップ後:
  BTN: Capped (ナッツをチェックバックする理由は少ない = 中強度主体)
  BB: Capped (先手ベットしなかった = ナッツが少ない)

ターン A♥:
  BTN: Ax が強化 (A♠K♣ = 2ペア、AA = セット)
       → ターンで BTN が Uncapped 化
  BB: Ax のフラッシュ等が強化されるが、BB のレンジに Ax の頻度は?

ナッツアドバンテージ:
  AA (セット): BTN が CBet しなかったのは稀。BTN の チェックバックに AA は少ない
  AK (2ペア): BTN のチェックバックレンジに AK は一定数含まれる
  → BTN は Ax で遅延 CBet が有効だが、BB も Ax を持てるため Uncapped 差は小さい
  → BTN は 50-75% の遅延 CBet でバリュー取り
```

### 実例 3: BB のドンクベット判断

**状況**: BTN CBet → BB コール。ボード 8♥7♦5♣、ターン 6♠

```
フロップ後:
  BTN: Uncapped
  BB: Capped

ターン 6♠ (コネクター、ストレート完成):
  BB のコールレンジに 9♠8♠ (ストレート完成), 4♣3♣ (ストレート完成) が多い
  BTN のCBet レンジに 4♠3♠ はあるが、BBほど集中していない

ナッツアドバンテージの逆転:
  6♠ ターンで BB のストレート完成率が BTN より高い
  → BB が Uncapped 化する珍しいケース
  → BB のドンクベットが有効 (強バリュー + セミブラフドロー)
  
  BB のドンクベット:
    サイズ: 75% (OOP からの強さの主張)
    ハンド: ストレート完成 + フラッシュドロー + セット
```

## ミニクイズ

### 問1

BTN が K♦7♣2♠ でフロップ CBet、BB がコールしました。ターン前の各プレイヤーのレンジはどちらが Uncapped ですか?

1. BTN: Uncapped、BB: Capped
2. BTN: Capped、BB: Uncapped
3. 両者ともに Uncapped

### 問2

BTN が K♦7♣2♠ でフロップ チェックバック後、ターン A♥ で BB がチェック。BTN が遅延 CBet した場合の BB の対応で正しいものは?

1. BTN が Uncapped なので BB は基本フォールド
2. BTN のレンジは Capped (チェックバック主体) なので BB はより広くコール/CR 検討
3. 両者 Capped なので大きな差がない

### 問3

「ドンクベット」が有効なのはどのような状況ですか?

1. OOP が Capped で IP を混乱させたいとき
2. ターンカードが OOP のレンジを強化し、OOP が Uncapped 化するとき
3. IP がフロップ CBet してきたとき (カウンター戦術として)

---

### 解答

- **問1**: 1（BTN がフロップ CBet = AA/KK/AK 等ナッツを含む Uncapped。BB がコールで止まった = KK 以上はプリフロップ 3bet 済 → Capped 寄り。この非対称性が BTN のダブルバレル有効性の根拠）
- **問2**: 2（BTN のチェックバックは中強度/バックドア主体 = Capped。A♥ ターンで BTN の Ax が強化されても、全体レンジとしてはナッツが薄い。BB は BTN より広くコール/CR を検討できる = 第27章の「遅延 CBet への BB の対応」と連動）
- **問3**: 2（ドンクベットは OOP が特定ターンカードで Uncapped 化するときに有効。Capped 状態でのドンクベットは逆選択を招く。コネクターやペアターンで OOP のストレート/セットが強化される場合が典型例）

---

> **本章まとめ**
>
> - Capped = ナッツが少ないレンジ。大きくベットしにくい
> - Uncapped = ナッツを含む可能性があるレンジ。大きくベットできる
> - アクションが Capped/Uncapped を決める：チェックバック/コールは Capped 化、CBet/CR は Uncapped 維持
> - ナッツアドバンテージ: ボードのナッツをどちらが多く持てるかが「誰が大きく打てるか」を決める
> - ドンクベット: OOP がターンカードで Uncapped 化するときに有効な例外戦略
> - 実戦フロー: 「自分/相手のレンジが Capped か?」→ 「ナッツアドバンテージはどちら?」→ ベットサイズ決定

---

**【GTO とのズレ】**

GTO は Capped/Uncapped を正確に計算してベット頻度・サイズを決定します。実戦での「GTO とのズレ」は主に2種類あります。

1. **Capped なのに大きく打つ**: チェックバック後のターンで OB を使うなど、ストーリーと矛盾するサイズを使う。GTO では Capped レンジからの OB はレアケースに限定。
2. **Uncapped アドバンテージを活かさない**: BTN が K♦7♣2♠ + ペアターンで「弱そうだからチェック」するのは、ナッツアドバンテージを放棄している。GTO では Uncapped 側がこのターンで OB を含む大サイズで攻撃する。

Capped/Uncapped の概念を意識するだけで、「どこで大きく打つべきか」「どこで控えるべきか」が自然に見えてきます。
