## 付録 A　主要公式・定義集

### ポーカー基本公式

| 公式 | 定義 | 値例 |
|---|---|---|
| **MDF** | MDF = 1 - α (α = ベット / (ポット + ベット)) | 75%ベット時 MDF = 57% |
| **ポットオッズ** | コールコスト / (ポット + コールコスト) | 10BB call, 30BB pot → 25% |
| **V:B 比率** | α:(1-α) (バリュー:ブラフの最適比率) | 75%ベット → 43%ブラフ |
| **SPR** | スタック / ポット | 90BB / 10BB = SPR 9 |
| **ブレイクイーブン** | フォールド頻度 = コスト / ポット | 10BB bluff → 25% fold needed |
| **コールオッズ** | ブラフ率がコールコストを超えるか | コールコスト = ベット/(ポット+ベット) |

### バレルスコア (バレルスコア) — ダブルバレル暗算式

```
バレルスコア = FlopType 係数 + TurnCard 係数

FlopType: ドライ=8, セミ=6, スーテッド=4, コネクテッド=3
TurnCard: ペア=4, OC=3, ブランク=2, フラッシュ=1, コネクター=0

バレルスコア ≥ 7 → 🟢 全ハンドでバレル推奨
バレルスコア < 7 → 🟡 HandScore ≥15: ベット, 8〜14: セミブラフのみ, <8: チェック
```

| 板タイプ | ペア (+4) | OC (+3) | ブランク (+2) | フラッシュ (+1) | コネクター (+0) |
|---|---|---|---|---|---|
| **ドライ (8)** | 12 🟢 | 11 🟢 | 10 🟢 | — | 8 🟢 |
| **セミ (6)** | 10 🟢 | 9 🟢 | 8 🟢 | — | 6 🟡 |
| **スーテッド (4)** | 8 🟢 | 7 🟢 | 6 🟡 | 5 🟡 | 4 🟡 |
| **コネクテッド (3)** | 7 🟢 | 6 🟡 | 5 🟡 | — | 3 🟡 |

GTO 実測 270 シナリオ全 17 セルで 🟢/🟡 分類が一致。

## 付録 C　ベットサイズ別 V:B 比率

| ベットサイズ | α (コールコスト率) | V:B 最適比率 | ブラフ比率 | MDF |
|---|---|---|---|---|
| 25% pot | 20% | 80% : 20% | 20% | 80% |
| 33% pot | 25% | 75% : 25% | 25% | 75% |
| 50% pot | 33% | 67% : 33% | 33% | 67% |
| 75% pot | 43% | 57% : 43% | 43% | 57% |
| 100% pot | 50% | 50% : 50% | 50% | 50% |
| 125% pot | 56% | 56% : 44% | 44% | 44% |
| 150% pot | 60% | 60% : 40% | 40% | 40% |
| 200% pot | 67% | 67% : 33% | 33% | 33% |

> **注意**: 付録 B の「バリュー比率」はオーバーベット (150%+) のとき逆転し、バリューがブラフより「多く」なります (第13章 13-5 参照)。付録 C の表では「最適比率」は V:B ではなく「バリュー%:ブラフ%」の順。

## 付録 D　SPR と推奨ベットサイズ (ターン)

| ターン SPR | 33% ベット後 | 50% ベット後 | 75% ベット後 |
|---|---|---|---|
| SPR 10+ | リバー SPR ~8.5 | リバー SPR ~7.0 | リバー SPR ~5.5 |
| SPR 8 (標準) | リバー SPR ~6.5 | リバー SPR ~5.0 | リバー SPR ~3.0 |
| SPR 5 | リバー SPR ~3.8 | リバー SPR ~2.5 | リバー SPR ≈ 1 (オールイン近) |

**注意**: SPR 3 以下 = リバーでほぼオールイン。ターンでの大ベットはリバーとセット。

### SPR別 実戦方針

| SPR | 実戦方針 |
|---|---|
| SPR > 10 | 3ストリートでゆっくりバリューを積み上げる |
| SPR 6-10 | ターン・リバーの 2ストリートでメインバリュー |
| SPR 3-6 | ターンで決め打ちか、リバーオールイン目標 |
| SPR < 3 | ターンでオールインも検討 |

## 付録 E　板タイプ判定チート

```
ドライ判定: 以下をすべて満たす
  □ Rainbow (3スート以下)
  □ 最高位差 ≥ 5 (K と 7 など)
  □ コネクテッドでない (3連続なし)
  例: K72r, A52r, Q93r

セミ判定: ドライでもコネクテッドでもない
  例: J75r, K93r, T42r

スーテッド: 2スート以上が2枚以上
  例: J84ss (ハート2枚), 987ss (スペード2枚)

コネクテッド: 3枚が3スパン以内 (例: 876, T98)
  例: T98r, 876r, JT9

ウェット = スーテッド + コネクテッド
  例: JT9ss (最もウェット)
```

### 板タイプ別 CBet 基準サイズ

| 板タイプ | 推奨サイズ | 理由 |
|---|---|---|
| ドライ | 33% pot | 広いコール引き出し |
| セミ | 33〜50% pot | バランス重視 |
| スーテッド | 33% pot (FD有り) / 50% (FD無し) | FD保有量で調整 |
| コネクテッド | 50〜75% pot | ポラライズ気味 |

## 付録 F　境界ハンド集 (暗記推奨)

### ターン CBet の境界ハンド

| ボード + ターン | GTO CBet | 実戦判断 |
|---|---|---|
| K72r + Ks | 100% | 常にダブルバレル |
| K44 + As | 78% | ダブルバレル (例外的に低いが推奨) |
| J75r + Ts | 50% | チェックバック基本 (コネクター効果) |
| JT9ss + 6h | 47% | チェックバック (超ウェット板ブランク) |
| KQTss + Jh | 41% | チェックバック (最低値) |

### リバー バリューラインの境界

| ハンド | バリューか否か | メモ |
|---|---|---|
| セット以上 | バリュー (大) | 大サイズでバリュー最大化 |
| 2ペア以上 | バリュー | リバーバリューの最低基準 |
| トップペアトップキッカー | 薄いバリュー | 50%以下ベット or チェックバック |
| トップペア弱キッカー | ブラフキャッチャー | コールのみ |
| ミドルペア以下 | ブラフキャッチャー / フォールド | 相手ブラフ率次第 |
| バストドロー | ブラフ候補 | ブロッカー持ちなら積極的 |

### オーバーベット境界条件

```
オーバーベット推奨の条件:
  1. レンジがポラライズしている (ナッツ + ブラフ、ミドルなし)
  2. フロップ〜ターンのストーリーが一貫
  3. リバーカードが IP を強化
  4. BB のコールレンジに「厚み」がある

オーバーベット非推奨:
  - ターンでチェックバック後のオーバーベット
  - BB のドロー完成リバー (BB 側ポラライズ)
  - ミドルペア〜トップペア範囲
```

## 付録 G　使用ツール

本書の GTO データは以下で実測しました。

- **TexasSolver** (v1.x) - C++ CFR ソルバー
  - オープンソース: https://github.com/bupticybee/TexasSolver
  - 設定: accuracy 0.5%, max_iteration 200, thread 8
  - 対象: 30 フロップ × 9 ターンカード = 270 シナリオ
  - 場面: BTN vs BB, 100BB stack, 2.5x open + call, フロップ 33% CBet + call 後

### レンジ設定

**IP (BTN)**: AA〜22, AKs〜A2s, KQs〜K2s, QJs〜Q5s, JTs〜J7s, T9s〜T8s, 98s〜96s, 87s〜76s, 65s, AKo〜ATo, KQo〜KTo, QJo〜QTo, JTo

**OOP (BB)**: 上記 IP レンジ + 弱スーテッドコネクター + K8s〜K2s, Q8s〜Q2s, J8s〜J2s, T8s〜T2s, 98s〜93s + A9o〜A2o, K9o〜K5o 等、BB 防御レンジ全体

## 付録 H　用語集

| 用語 | 意味 |
|---|---|
| **CBet** | コンティニュエーションベット。プリフロップアグレッサーがポストフロップでベット |
| **ダブルバレル** | フロップ CBet 後、ターンでもベットを継続 |
| **トリプルバレル** | ダブルバレル後、リバーでも継続ベット |
| **チェックバック** | IP がチェックすること (OOP チェック後) |
| **ドンクベット** | OOP が先手でベットすること (通常は IP アグレッサーのターン) |
| **ブラフキャッチャー** | 相手のバリューに負けるが、ブラフには勝てるハンド |
| **ポラライズ** | ナッツとブラフの二極化したレンジ |
| **コンデンス** | ミドルハンドが多い中央化レンジ |
| **SPR** | Stack-to-Pot Ratio = スタック / ポット |
| **MDF** | Minimum Defense Frequency = 最低ディフェンス頻度 |
| **V:B 比率** | バリュー: ブラフの最適配分比率 |
| **α (Alpha)** | ポットオッズ比率 = ベット / (ポット + ベット) |
| **ブロッカー** | 自分のカードが相手の特定ハンドを除外する効果 |
| **アンブロッカー** | 相手の特定ハンド (コールハンド) を保有しない = 相手がコールしやすい |
| **ナッツ** | 最強のハンド (そのボードで誰も上回れない) |
| **セミブラフ** | ドローを持ちながらブラフする戦略 (リバーではなし) |
| **エクスプロイト** | 相手の GTO からの逸脱を利用した戦略 |
| **インダクトベット** | 弱く見せるベットで相手のレイズを誘う技術 |
| **オーバーベット** | ポットを超えるベット (100%+ pot) |
| **バレルスコア** | FlopType 係数 + TurnCard 係数のダブルバレル暗算式 |
| **後手スコア** | OOP がターンベットに反応するための判断指標 |
| **インディファレンス** | コールとフォールドの EV が同じ状態 |

## 付録 I　シリーズ構成と接続

```
巻 ①  プリフロップ
      → HandScore (ハンド価値), ポジション別レンジ

巻 ②  フロップ基礎
      → BoardScore, CBet統合式, MDF基礎

巻 ③  フロップ応用
      → BoardScore Level 2, マルチウェイ, GTO的応用

巻 ④  ターン・リバー (本書)
      → バレルスコア, V:B 比率, マルチストリート統合
```

本書は巻②の「CBet 統合式」と「MDF」の知識を前提とします。これらを未習の場合は巻②を先にお読みください。

### 各巻の主要式

| 巻 | 主要式 | 役割 |
|---|---|---|
| ① | HandScore = プリフロ手 強さ | プリフロップコール/フォールド |
| ② | BoardScore + CBet統合式 | フロップ CBet 判断 |
| ③ | BoardScore Level 2 + マルチウェイ | 応用フロップ |
| ④ (本書) | バレルスコア + Alpha式 | ターン・リバー判断 |

## 付録 K　実戦クイックリファレンスカード

本書のすべての判断を 1 枚のリファレンスにまとめました。実戦中に参照する場合は本付録を印刷してください。

### ターン CBet 判断

```
バレルスコア = FlopType + TurnCard
  FlopType: ドライ=8, セミ=6, スーテッド=4, コネクテッド=3
  TurnCard: ペア=4, OC=3, ブランク=2, フラッシュ=1, コネクター=0

≥ 7 → 🟢 基本的にダブルバレル
< 7 → 🟡 ハンドクラスで判断:
         強バリュー (HandScore ≥15) → ベット
         セミブラフ (ドロー) → ベット
         SDV (弱ペア等) → チェックバック
         ブラフ (ドローなし弱ハンド) → チェックバック
```

### リバー判断フロー

```
1. 自分のハンドは何?
   ├ バリュー (2ペア以上): ベット (サイズはSPRとポラライズで決定)
   ├ 薄いバリュー (TPTK 等): 小ベット (33%) or チェックバック
   ├ ブラフキャッチャー: 相手ブラフ率チェック → コール or フォールド
   └ ブラフ: 相手チェック時にベット or フォールド

2. 相手がベットしてきた場合:
   コールオッズ (α) = ベット / (ポット + ベット)
   コール有利: 相手ブラフ率 > α

3. オーバーベット判断 (自分がベットする側):
   □ ポラライズ (ナッツ+ブラフ)? YES →
   □ ストーリー一貫? YES →
   □ リバーで IP のレンジ強化? YES → オーバーベット検討
```

### チェックレイズ対応

```
BB がチェックレイズしてきた場合:
  コールオッズ = (CR額 - ベット額) / (ポット + ベット + CR額)
  コール基準: 相手ブラフ率 > コールオッズ
  
  ドロー完成リバー → BB のブラフが多い → コール基準緩む
  ブランクリバー   → BB のバリュー中心 → コール基準厳しい
  
  1ペア以下でのコールは通常 -EV
  2ペア以上でコールを検討
```

### Alpha 式クイック計算

| ベット (pot %) | α | コール基準ブラフ率 | MDF |
|---|---|---|---|
| 33% | 25% | 25%以上 | 75% |
| 50% | 33% | 33%以上 | 67% |
| 75% | 43% | 43%以上 | 57% |
| 100% | 50% | 50%以上 | 50% |
| 150% | 60% | 60%以上 | 40% |
