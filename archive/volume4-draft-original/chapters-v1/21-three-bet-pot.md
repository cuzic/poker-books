# 第21章　3bet ポットのターン・リバー

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 3bet ポットでは SPR が通常ポットの半分以下になることを理解し、バレルスコアに依存しない「コミット判断フロー」を使えるようにする。

---

## 21-1 3bet ポットとは何か

3bet ポットとは、プリフロップで「レイズ → 3bet → コール」の流れで生まれたポットです。

```
通常レイズポット:
  BTN 2.5BB open → BB call → ポット 5.5BB (SPR ≈ 17)

3bet ポット (例):
  BTN 2.5BB open → BB 3bet 9BB → BTN call → ポット 18.5BB (SPR ≈ 4.4)
```

**SPR が 4 台** というのは、フロップが始まった時点でスタックの約 4 倍のポットがある状態です。これはターン・リバーの戦略を根本的に変えます。

---

## 21-2 SPR の違いが戦略に与える影響

### SPR 比較表

| シチュエーション | フロップ SPR | ターン SPR (50% CBet後) | 特徴 |
|---|---|---|---|
| 通常 2.5xオープン + call | ≈ 17 | ≈ 8 | 3ストリートで積み上げ |
| 3bet (9BB) + call | ≈ 4.4 | ≈ 2.1 | ターン後スタックがほぼなくなる |
| 4bet pot (例: 22BB) | ≈ 1.8 | ほぼオールイン | フロップでほぼコミット |

### 3bet ポットの特性

```
通常ポット (SPR ≈ 8 ターン時):
  ターン: ベットしてもリバーにスタックが残る
  → 「ターンはバリューを積み上げる」

3bet ポット (SPR ≈ 2 ターン時):
  ターン 75% ベット後: リバー SPR ≈ 0.5
  → ターンのベットが実質的に「オールイン圏への突入」を意味する
  → 「ターンでポットに入れるかどうか = スタック全部使うかどうか」の決断
```

---

## 21-3 3bet ポットでの「コミット判断」

通常ポットではバレルスコアで「打つか打たないか」を決めます。3bet ポットでは **「コミットするかどうか」** が最初の判断になります。

### コミット判断フロー

```
Step 1: フロップの SPR を確認
  3bet ポット: SPR ≈ 4 前後

Step 2: 自分のハンドエクイティを評価
  コミット判断式:
    ハンドエクイティ ≥ ポットオッズ → コミット
    ハンドエクイティ < ポットオッズ → チェック/降りる方向

Step 3: SPR が 2 以下 (ターン後) になったら
  「コール確定かフォールドかの二択」
  中間 (「ベットしても追い続けない」) は損
```

### コミットの具体例

**ボード**: K♦7♠2♣ (フロップ、3bet ポット 18.5BB、スタック 81.5BB、SPR 4.4)

BTN のハンドが A♠K♠ (TPTK):

```
コミット判断:
  このボードで AK はほぼ最強クラス (AA は負けるが BB の 3bet レンジに AA が多い)
  SPR 4.4 → フロップ〜ターン〜リバーで全額入れる価値がある
  → コミット方向: フロップで 75%+ ベット、ターンで残りオールイン
```

BTN のハンドが Q♥J♥ (何もない、ガットショットのみ):

```
コミット判断:
  QJ はフロップで現時点バリューなし
  オールインエクイティ: QJ vs BB の 3bet レンジ ≈ 30% 程度
  ポットオッズ (フロップコール必要勝率) = bet/(pot+bet) 程度
  → コミットしない方向: ブラフCBetを打ってフォールドされなければ諦める
```

---

## 21-4 3bet ポットのバレル判断 (通常ポットとの違い)

通常ポットではバレルスコア (第4章) を使いました。3bet ポットでは SPR が低いため、バレルスコアの閾値判断より「コミット vs 降りる」の二択で考えます。

### 3bet ポットでの判断マトリクス

| ハンドクラス | フロップ CBet | ターン | リバー |
|---|---|---|---|
| ナッツ〜強バリュー (2ペア以上) | 75% CBet | オールインorほぼオールイン | — |
| トップペア (強キッカー) | 50-75% CBet | コミット判断 (SPRが2以下) | オールインもあり |
| トップペア (弱キッカー) | 50% CBet | チェックバック多め | 薄バリュー |
| ドロー (ナッツドロー等) | 75%+ セミブラフ | コミット or 諦め | — |
| ブランク/弱ハンド | 33% CBet or チェック | 諦め方向 | — |

**重要**: 3bet ポットでは「ターン 50% ベット後 SPR ≈ 2」となるため、ターンでのベットが実質的にリバーオールインとセットです。「ターンベット = 最後まで行く宣言」と考えて慎重に選択します。

---

## 21-5 3bet ポットでの典型的なライン

### ライン 1: バリューコミットライン (最も多いライン)

```
フロップ: 75% CBet (相手 call)
ターン: 75%+ ベット or オールイン

例: 3bet ポット 18.5BB, スタック 81.5BB
  フロップ 75% = 13.9BB → ポット 46.3BB, スタック 67.6BB (SPR ≈ 1.46)
  ターン: オールイン (67.6BB into 46.3BB ≈ 146% OB)
  
  → ターンでオールイン確定のため、フロップでの CBet は「オールインを見越した判断」
```

### ライン 2: フロップ 33% → ターン チェックバック → リバー判断

```
弱いバリュー (1ペア) での保守的ライン:
  フロップ: 33% CBet (コスト抑制)
  ターン: チェックバック (SDV 保護)
  リバー: 相手のアクション次第でコール or 薄バリューベット

このラインはオールインを「回避」する選択。
コミットしたくないハンドに使う。
```

### ライン 3: セミブラフ → スタックオフ

```
ドローを持つとき:
  フロップ: 75%+ CBet (フォールドエクイティ + ドロー)
  ターン: ドロー完成 → オールイン
       ドロー外れ → チェックバックかフォールド

例: BTN が K♠Q♠ on 9♠8♦4♠ (フラッシュドロー)
  フロップ 75% → ターン スペード落ち → オールイン バリュー
  フロップ 75% → ターン ブランク → チェックバック (スタックオフせず)
```

## 21-6 BB 視点: 3bet ポットでの防御

BB が 3bet してフロップに向かったとき、IP の CBet に対してどう防御するかです。

### BB の3bet コールレンジの特性

BB が 3bet (例: 9BB) に BTN がコールしてきた場合:

```
BTN のコールレンジ (通常例):
  AA, KK, QQ, JJ, TT, AK, AQ, AJs, KQs など
  → BTN は「強いが 4bet するほどでもないハンド」が多い

BB の 3bet レンジはポラライズ:
  バリュー: AA, KK, QQ, AK
  ブラフ: AXs, スーテッドコネクター (ブラフ3bet)
```

### BB のフロップ判断

```
フロップ CBet を受けた BB:

コール基準 (3bet ポット):
  通常ポットより「強いハンドのみコール」が求められる
  理由: 3bet ポットでコールを続けると、ターンでオールイン圏に入る
  
  3bet ポットでのコール基準:
    セカンドペア以上 + ドローがあれば → コール
    トップペアトップキッカー → コール
    バックドアドロー + 強いオーバーカード → コール
    純ブランク → フォールド (通常ポットよりフォールド頻度が高い)
```

### BB のチェックレイズ条件 (3bet ポット)

```
3bet ポットで BB がフロップ CR するとき:
  バリュー CR: セット以上 (SPR 低いので早いバリュー最大化)
  ブラフ CR: バックドアドロー + ブロッカー持ち (レアケース)
  
  注意: 3bet ポットの CR はほぼオールインを意味する
  CR してから「ベットされたらフォールド」は計算が合わない
  → CR = コミット確定で使う
```

---

## 21-7 3bet ポット vs 通常ポットの判断の比較

| 判断ポイント | 通常ポット (SPR≈8) | 3bet ポット (SPR≈4) |
|---|---|---|
| ターン CBet 判断 | バレルスコアで決定 | コミット判断 (ハンドエクイティ基準) |
| ターンでのチェックバック | SDV 保護として有効 | オールインを回避する選択 |
| リバーオーバーベット | ポラライズ+ストーリーで | ほぼ不要 (ターンで既にオールイン圏) |
| コール基準 | MDF 近辺 | より絞ったコール (スタックオフ前提) |
| ブラフ頻度 | バレルスコアで計算 | 低め (失敗すると大きく損) |

---

## 21-8 実戦例: 3bet ポットのハンド完全例

### ハンド A: BTN vs BB (BB が 3bet)

**プリフロップ**: BTN 2.5BB open → BB 9BB 3bet → BTN call (ポット 18.5BB, スタック 91BB → コール後 81.5BB)

**フロップ A♦K♠T♣**:
- BTN ハンド: Q♣J♣ (ナッツストレートドロー: AKQJT 完成まであと J or A)
  
  Wait、QJ on AKT = AKQJT 完成のストレートドロー? QJ はガットショット (Q-J-x-x-9 を狙う)。

  実際: Q♣J♣ on A♦K♠T♣ = QJT9 のストレートドロー (9 待ち) + Q high FD (クラブ)

```
BTN の判断:
  QJ = セミブラフ + ナッツドロー組み合わせ
  SPR ≈ 4.4 → コミット判断
  
  ドローエクイティ: ~50% (QJ vs BB の 3bet バリューレンジ)
  フォールドエクイティ: BB の 3bet ブラフレンジ (A5s, 76s 等) をフォールドさせる可能性
  
  → 75% CBet: BB が KK/AA/AK 以外でコールしにくい
  → BB がコールした場合: ターンで完成すればオールイン、外れれば諦め
```

**ターン 9♥** (ストレート完成):

```
QJ on AKT9: AKQJT → いや、QJ + AKT9 = ストレート: AKQJT (完成!)
  
BTN の判断: ナッツストレート完成
  SPR ≈ 2 → オールイン or 大ベット
  
  ターン: オールイン (約 56BB into 46BB ≈ 120%)
  → BB がコール = 全スタックがかかる
```

### ハンド B: ブランクターンでの諦め判断

**フロップ K♦7♠2♣** (同じ 3bet ポット 18.5BB)
**BTN ハンド**: A♥Q♦ (何もない)

```
BTN:
  AQ on K72 = バックドアフラッシュドロー + オーバーカード×2
  通常ポットなら CBet 33% が正解
  3bet ポットで CBet → BB がコール → SPR ≈ 2 → ターンで何もなければフォールド
  
  フロップ 33% CBet (小さく打ってフォールドエクイティを狙う)
  ターン: BB がコール → ブランク落ち → チェックバック (降りる方向)
  リバー: BB がベット → フォールド
  
  → 「フロップで一度揺さぶる、ターンで諦め」が正解
```

## ミニクイズ

### 問1

3bet ポット (フロップ SPR ≈ 4.4) で、ターンにベット 50% を打った後の SPR はいくつですか。

1. SPR ≈ 4.0
2. SPR ≈ 2.1
3. SPR ≈ 6.5

### 問2

3bet ポットでのターン判断として正しい考え方はどれですか。

1. バレルスコアを計算して 🟢/🟡 で判断する
2. 「コミットするか vs 降りるか」の二択で判断する
3. 通常ポットと同じ MDF 基準で判断する

### 問3

3bet ポットで BTN が強いドロー (フラッシュドロー) を持っています。ターン 75% ベットを打った後、ドローが外れました。最善の選択は?

1. リバーもブラフベットを継続
2. チェックバックして諦める
3. リバーオーバーベットでフォールドを狙う

---

### 解答

- **問1**: 2（ターン 50% ベット後: ポット × 1.5 / 残スタック。フロップ 18.5BB → CBet後 46.3BB→ ターン 50% (23.2BB) → ポット 92.7BB, スタック ≈ 45BB → SPR ≈ **2.1**。「ターンベット後はほぼオールイン圏」の確認）
- **問2**: 2（SPR ≈ 2 前後では「ターンベット = 実質リバーもオールイン」。バレルスコアは通常ポット用の判断式。3bet ポットでは「このハンドでスタック全部使う価値があるか」が基準）
- **問3**: 2（3bet ポットでドロー外れ後にリバーブラフを打つとほぼコールされる。BB は「コール確定ハンド」でフロップ〜ターンとコールし続けており、リバーブラフは成功率が低い。チェックバックが安全。）

---

> **本章まとめ**
>
> - 3bet ポットの SPR ≈ 4-5 は通常ポットの半分以下
> - ターン 50% ベット後は SPR ≈ 2 → ほぼオールイン圏に突入
> - 判断軸は「バレルスコア」でなく「コミットするか vs 降りるか」
> - 強バリュー / ナッツドロー: コミット (75%+ CBet → オールイン)
> - 弱ハンド / 外れドロー: 小ベット1回で諦め、ターンチェックバック
> - 3bet ポットでのブラフは失敗コストが大きいため頻度を下げる

---

**【GTO とのズレ】**

3bet ポットの GTO は通常ポットより「ベットサイズが大きい」傾向があります。SPR が低いため、小さいサイズでのバレルよりも「大きく一度打って終わり」が EV 最大になる場面が多いためです。

実戦では「3bet ポットでのチェックバック」を過剰に使うと EV を失います。相手も「チェックバック = 弱い」と読んで積極的にプローブしてくるため、バリューハンドは積極的にベットして SPR を下げることが重要です。

また、BB が 3bet して BTN がコールした場合の「BB のバレル (OOP バレル)」は GTO 上は非常に少ないです。BB は OOP のため、フロップでのドンクベットよりチェックを多用し、IP のベットに反応するのが基本です。
