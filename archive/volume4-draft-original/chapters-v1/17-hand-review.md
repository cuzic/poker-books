# 第17章　ソルバーによるハンドレビュー

> **本章のゴール**: ターン・リバーに特化したソルバーレビュー例題を通じて、本書の各式（バレルスコア・後手スコア）とGTOの差分を確認する。

> ソルバーレビューのワークフロー全般（ツール選択・EVロス計測・週次サイクル）は **巻3 第16章** で扱っています。本章はその知識を前提に、**ターン・リバーに特化した例題5つ**を提供します。

## 17-1 ソルバーレビューの基本フロー

本章の例題に入る前に、ターン・リバー特有のレビュー手順を確認します。

```
ターン・リバーのレビュー手順:

ステップ 1: シチュエーションを再現する
  - フロップ形状 (ドライ/セミ/ウェット)
  - ターンカード種別 (OC/ブランク/ペア/FD/コネクター)
  - リバーカード種別
  - ポットサイズとスタック残り

ステップ 2: 自分のアクションを記録する
  - 実際に選んだアクションと理由
  - 迷ったアクションがあれば記録

ステップ 3: ソルバーに入力して推奨アクションを確認
  - 自分のハンドの推奨アクション (頻度別)
  - EV 差を記録

ステップ 4: 差分を「式」で解釈する
  - バレルスコアとの一致・差異
  - 後手スコアとの一致・差異
  - GTO との差が生まれた「原因」を言語化
```

## 17-2 ハンドレビュー例 1: ターン判断

### 実戦ハンド

**シチュエーション**:
- BTN vs BB, 100BB
- フロップ K♦7♣2♠, BTN 33% CBet (3.3BB), BB コール
- ターン: J♠ 落ち
- ポット: 11BB, BTN スタック: 94BB

BTN は K♠Q♠ を持つ。ターンにてチェックバックした。

### バレルスコアで事前確認

```
FlopType: ドライ = 8
TurnCard: J = ブランク (フロップの K/7/2 と無関係なコネクター) → 2
  ※ J は OC ではない (K より低い) → ブランク扱い → 2
  ※ ただし J は BB の Jx を強化するため実質 OC に近い

バレルスコア = 8 + 2 = 10 → 🟢 (積極バレル域)
```

バレルスコア 10 は「ダブルバレル推奨」。KQ はトップペアなのでバリュー/セミブラフとして打つ方向が示唆されます。

### ソルバー確認結果 (仮)

```
KQ の推奨アクション:
  チェックバック: 60%
  ベット 33%: 30%
  ベット 50%: 10%

EV 差 (チェックバック vs ベット 33%): -0.8BB
```

### 分析

KQ は K72r ではトップペアですが、J ターンでは「J がボードに落ちたことで BB の Jx が強化」。KQ のバリューは薄れる。

ソルバーは 60% チェックバックを推奨 → 実戦のチェックバックは「正しい方向」。

ただし、30% ベット 33% の頻度もある → 「完全チェックバック」よりも「少しバレルする」が若干有利。

バレルスコア 10 が「積極バレル」を示しているのに対し、KQ 個別では薄バリューのため 60% チェックバックという差が出ました。これは「レンジ全体では積極バレルが有利」だが「KQ は薄バリューのためレンジ内で役割が変わる」ことを示しています。

**学習ポイント**: KQ 等の「薄いトップペア」はターンで 100% チェックバックより、一定頻度でブロッキングベット (33%) を混ぜるのが GTO に近い。バレルスコアは「レンジの平均傾向」であり、個々のコンボは強弱で役割が分かれる。

## 17-3 ハンドレビュー例 2: リバーのフォールド判断

### 実戦ハンド

**シチュエーション**:
- BTN vs BB
- ターンまでダブルバレル後、リバーはブランク
- ポット: 24BB, BTN スタック: 82BB
- BTN のハンド: J♠T♦ (セカンドペア)
- BB がリバーに 18BB ベット

BTN はフォールドした。

### Alpha 式での事前確認

```
BB のベット 18BB / (24 + 18) = 43%
→ BB のベットレンジの 43% 以上がブラフなら BTN のコールが有利
```

JT はセカンドペア。BB のバリューレンジ (Ax, KK, JJ 以上等) に全て負ける。ブラフキャッチャーとして「BB のブラフには勝てる」が、ブラフ率 43% 以上が必要。

### ソルバー確認結果

```
JT の推奨アクション:
  フォールド: 75%
  コール: 25%

コールオッズ: 18/(24+18) = 43%
BB のブラフ率が 43% 以上ならコール有利
```

### 分析

ソルバーは JT で 75% フォールドを推奨。実戦のフォールドは概ね正しい。

しかし 25% コールがある → 完全フォールドは「少しだけ EV を失う」。

BB のレンジが「バリューヘビー」な状況と「バランスが取れている」状況で判断が変わる。

**EV ロスの計算**:

```
ソルバー最適 EV: 0.75 × 0 (フォールド) + 0.25 × (コール EV) = 最適 EV
実戦 EV (完全フォールド): 0 × フォールド EV = 0

差分: もし BB のブラフ率が 43% ちょうどなら差はほぼゼロ
     BB のブラフ率が 50% なら JT のコール EV がプラス → 完全フォールドは少し損
```

**学習ポイント**: 「セカンドペアでリバーベットにフォールド」は通常正しいが、完全自動フォールドよりも「BB のブラフ率を読んで時々コール」する方が GTO に近い。特に BB がフォールドエクイティを狙うアグレッシブなプレイヤーの場合はコール頻度を上げる。

## 17-4 ハンドレビュー例 3: ブラフを打つタイミング

### 実戦ハンド

**シチュエーション**:
- BTN vs BB
- フロップ: A♠8♦3♣, ターン: K♠
- リバー: 7♣
- ポット: 20BB, BTN スタック: 85BB
- BTN のハンド: Q♦J♣ (何もない)
- BB がチェック

BTN はチェックバック (ブラフしなかった)。

### バレルスコアでの分析

```
FlopType: ドライ (A83) = 8
TurnCard: K = OC (フロップ最高カード A より低いが、十分高ランク) → 3
バレルスコア = 11 → 🟢 (積極バレル推奨)
```

リバーでは「BB のチェック = 弱さのシグナル」。BTN のブラフ候補として QJ は:
- Q ブロッカー: 相手の QQ (ポケット) を一部ブロック
- J ブロッカー: 相手の JJ を一部ブロック
- 全体的にブロッカー効果は中程度

### ソルバー確認結果

```
QJ (完全ブランク) の推奨:
  チェックバック: 70%
  ブラフ 50%: 30%

EV 差 (チェックバック vs ブラフ): +0.4BB (ブラフが若干有利)
```

### 分析

QJ は A♠K♠ のボードで「完全なブランク」。しかしソルバーは 30% ブラフを推奨している。

理由: BB がチェックすることで「BB のレンジが弱い」と判断できる。BTN のブラフは成功しやすい状況。

**実戦のミスは「チェックバック100%」**。ソルバーは 30% ブラフを推奨しており、チェックバックのみは EV を少し失っている。

**学習ポイント**: 「何もないハンドでのリバーブラフ」は EV プラスな場合がある。BB がチェックした状況でのブラフは、思った以上に有効な場面がある。ただしブラフするのは「ブロッカー + BB の弱さ」が重なる状況に限る。

## 17-5 ハンドレビュー例 4: オーバーベットの判断

### 実戦ハンド

**シチュエーション**:
- BTN vs BB, 100BB
- フロップ: K♥T♠5♦, ターン: 9♣
- リバー: J♦
- ポット: 28BB, BTN スタック: 78BB
- BTN のハンド: Q♦K♦ (ナッツストレート: KQJT9)
- BB がチェック

BTN は 75% ポット (21BB) でバリューベットした。

### ソルバー確認結果

```
QK の推奨:
  オーバーベット 150%: 55%
  ベット 75%: 35%
  チェックバック: 10%

EV 差 (75% ベット vs オーバーベット): -3.2BB
```

### 分析

このボードは K♥T♠5♦9♣J♦ で「ストレート完成リバー (J 落ち)」。BTN の QK は KQJT9 のナッツストレート。

ソルバーが 55% オーバーベットを推奨している最大の理由:

```
リバー J で BB が持てる強いハンド:
  フラッシュドロー (完成なし、ダイヤなし) → 少ない
  ストレート (QK, Q8, 等) → BB も持てる
  2ペア / トップペア → KJ, J9 等

BB のコールレンジには「ストレートやストロングハンドが多い」
= BTN のオーバーベットに対してコールしてくれる確率が高い
```

BTN の 75% ベットは正しい方向だが、EV -3.2BB はかなり大きい差。ナッツ + BB のコールレンジが厚い状況こそオーバーベットのチャンス。

**学習ポイント**: ストレート完成リバーでナッツを持つ場合は、オーバーベットが GTO の主アクション。「いつも 75% で打つ」という固定アプローチは大きな EV を逃す。

## 17-6 ハンドレビュー例 5: チェックレイズへの対応

### 実戦ハンド

**シチュエーション**:
- BTN vs BB
- リバーポット: 22BB
- BTN ハンド: A♣K♣ (2ペア: AK on A♣K♦5♠ 8♥ 3♦ ボード)
- BTN が 16BB ベット、BB が 44BB にチェックレイズ

BTN はフォールドした。

### コールオッズ計算

```
BTN の追加コスト = 44 - 16 = 28BB
コールするポット = 22 + 16 + 44 = 82BB
コールオッズ = 28/82 = 34%
→ BB のチェックレイズの 34% 以上がブラフなら BTN コール有利
```

AK 2ペアは非常に強いが、AA/KK/55/88/33 のフルハウスには負ける。

### ソルバー確認結果

```
AK (2ペア) の推奨:
  コール: 65%
  フォールド: 30%
  4bet オールイン: 5%

BB のチェックレイズブラフ率: 38% (コールオッズ 34% を上回る)
```

### 分析

ソルバーは AK 2ペアで 65% コールを推奨。実戦の「フォールド」は EV を大きく失っている。

理由: BB がリバーチェックレイズをするとき、A♣K♦5♠8♥3♦ の「ブランクリバー」では BB のブラフ候補:
- 外れたフラッシュドロー
- 完成しなかったストレートドロー
- バックドアドロー外れ

が存在し、BB のブラフ率が 38% (コールオッズ 34% を上回る) と推定される。

**BTN のフォールドは典型的な「チェックレイズ = 常にフォールド」の誤解**。

**学習ポイント**: リバーの BB チェックレイズに対して、AK 2ペアのような強いハンドは 65% コールが正解。「チェックレイズ = 常に強い = フォールド」という固定思考を排除し、ブラフ率をコールオッズと比較する。

## 17-7 ソルバーレビューの注意点

### 注意 1: ソルバーは GTO を計算するが相手は GTO ではない

ソルバーの推奨は「両プレイヤーが GTO を採用している」前提。

相手がブラフ多すぎる場合 → コール頻度を上げる方が実戦的に有利
相手がバリューのみの場合 → フォールド頻度を上げる方が有利

**ソルバーのアウトプットは「ベースライン」として使い、相手の傾向で調整する**。

### 注意 2: レンジ設定の影響が大きい

ソルバーに入力するレンジが実際と違うと、推奨アクションが大きく変わります。

特に:
- BB のディフェンスレンジ (どの手でコールするか)
- 相手の CBet 頻度 (どれくらいバレルしているか)

「標準的なレンジ」を使ったレビューは出発点として有効だが、特定の相手に対しては調整が必要。

### 注意 3: EV 差が小さい場合は「誤差の範囲」

EV 差が 0.5BB 以下の場合、実戦での差は無視できるほど小さい。

高 EV な選択 (+5BB 以上の差) を優先して学習し、細かい調整は後回しでよい。

## 17-8 ソルバーレビューの効率的な使い方

### 週1回の「重要ハンドレビュー」

毎日全ハンドをレビューするのは非現実的です。週1回、以下の条件のハンドを選んでレビューします。

```
レビュー対象ハンドの選択基準:
  1. 大きなポットが動いたハンド
  2. 自分が「本当にこれで良かったか?」と疑問を持ったハンド
  3. 相手のアクションが予想外だったハンド
  4. 負けたハンドの中で「判断ミスがあったかも」と感じたハンド
```

### 本章5例のEV差まとめ

| 例 | ミスの方向 | EV ロス (参考) |
|---|---|---|
| 例1 (KQ ターン) | 100% チェックバック → 30% ベット混合が正解 | -0.8BB |
| 例2 (JT リバーフォールド) | 完全フォールド → 25% コールが正解 | -0.2BB 程度 |
| 例3 (QJ ブラフ) | 100% チェックバック → 30% ブラフが正解 | -0.4BB |
| 例4 (QK オーバーベット) | 75% ベット → オーバーベットが正解 | **-3.2BB** |
| 例5 (AK vs CR) | フォールド → コールが正解 | 大きい (具体値は状況依存) |

最も大きな EV ロスは「例4 のオーバーベット判断ミス」と「例5 の CR フォールド」です。これらを優先して修正することが、実戦でのスコア向上につながります。

### ソルバー以外のリソース

- **GTOWizard**: 事前計算済みのソリューションを参照できる (課金必要)
- **TexasSolver (本書使用)**: オープンソース CFR ソルバー (カスタム設定可能)
- **PioSolver**: 高精度の商用ソルバー (プロ向け)

本書で使用したソルバー: TexasSolver v1.x (C++ CFR ソルバー)

## ミニクイズ

### 問1

バレルスコアが🟢 (積極バレル推奨) でも、特定のコンボで「チェックバックが 60% 推奨」になることがあります。その理由として正しいものはどれですか。

1. バレルスコアが間違っている
2. バレルスコアはレンジ全体の傾向で、個別コンボはその役割（薄バリュー等）で異なる
3. チェックバックしてはいけない

### 問2

ソルバーが「フォールド 75%、コール 25%」と示した状況で、実戦で「100% フォールド」した場合はどう評価できますか。

1. 大きなミス (フォールドしてはいけない)
2. 方向性は概ね正しいが、完全フォールドで微量のEVを失っている
3. 完璧な判断 (フォールドが正解)

---

### 解答

- **問1**: 2（バレルスコアは FlopType × TurnCard の積算でレンジ全体の傾向を示す。KQ のような薄バリューはレンジ内で「チェックバック多め」の役割になることが多い。バレルスコアが高いほど、ナッツ寄りのコンボが積極的にバレルし、薄バリューは休む傾向）
- **問2**: 2（ソルバーが 25% コールを示している = 完全フォールドは少し EV を失う。しかし「方向は正しい」。大きなミスではなく、磨くべき微調整）

> **本章まとめ**
>
> - ソルバーレビューは「自分のアクション vs 最適アクション」の差分を学ぶツール
> - 手順: シチュエーション特定 → 入力 → 推奨確認 → 差分分析
> - 注意: ソルバーは GTO ベースライン。相手の傾向で調整する
> - EV 差が大きい判断 (例4 のオーバーベット、例5 の CR フォールド) を優先学習する
> - バレルスコアはレンジ傾向、個別コンボは役割で分かれる点に注意
> - 週1回、重要ハンドを選んでレビューする習慣が効果的

**【GTO とのズレ】**

ソルバーレビューは「理論的な最善」を教えてくれますが、実戦での最善は必ずしも GTO と同じではありません。

特に低レートのゲームでは、相手が GTO から大きく外れているため、「相手の傾向に特化したエクスプロイト戦略」が GTO より高 EV になることが多い。

本書のアプローチは「GTO を理解した上でエクスプロイト」です。GTO を知ることで「どの程度相手から逸脱しているか」を把握し、その逸脱を利用する判断ができるようになります。

また、本章の EV 差数値はレンジ設定や対象ソルバーによって変わります。「絶対値」より「方向性 (プラスかマイナスか、大きいか小さいか)」を読み取ることが重要です。
