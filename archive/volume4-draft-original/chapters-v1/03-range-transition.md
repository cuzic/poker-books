# 第3章　フロップ→ターンのレンジ遷移

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップで相手がコールした後、相手のレンジがどう変化しているかを把握する。ターン判断の「入力」を正確にする。

---

## 3-1 コールはどのレンジを生き残らせるか

フロップで IP が 1/3 ポット CBet → OOP がコール。

このコールという行動から何が読み取れるでしょうか。

GTO 理論の基本原則として、コールのレンジは次の特徴を持ちます。

**強すぎないハンド + 弱すぎないハンド**

```
コールしないレンジ:
  - 強い: セット、2ペア → レイズが推奨
  - 弱い: 何もない完全なゴミ → フォールドが推奨

コールするレンジ:
  - トップペア（中程度のキッカー）
  - ミドルペア・ボトムペア（生き残りのポテンシャル）
  - 強いセミブラフドロー（OESD、フラッシュドロー）
  - 弱いセミブラフドロー（ガットショット、バックドアドロー）
  - オーバーカード（A・K などのブロッカーつき）
```

この「コールレンジ」を相手が持っているということが、ターン判断の前提です。

**重要な補足**: OOP のコールレンジは、フロップの CBet サイズによって変わります。

| IP の CBet サイズ | OOP のコールレンジの性質 |
|---|---|
| 1/3 ポット | 幅広い。弱いドロー・薄いペアまで含む |
| 2/3 ポット | 絞られる。強いドロー・強いペアが中心 |
| ポットサイズ | さらに絞られる。ナッツ級・強いセミブラフ中心 |

本書では「1/3 ポット CBet → コール」を主なシナリオとして扱います。

## 3-2 ドライボードでのコールレンジ（K72r）

### ボード例: K♣7♦2♠（K72r）

**BTN が 33% CBet → BB がコール後のコールレンジ**

| ハンドカテゴリ | 代表例 | コールレンジにいる理由 |
|---|---|---|
| トップペア弱キッカー | K9s, K8s, K6s | 1ペアだがそこそこ強い |
| セカンドペア | 7x（77 はレイズ多数） | 中程度の強さ |
| ボトムペア | 2x | 弱め、アウツ狙い |
| ガットショット | 98s, 65s, A3s | 弱いセミブラフ |
| オーバーカード | Ax（Aハイ） | ブロッカー＋改善期待 |

> **ドライボードの特徴**: フラッシュドローがない（rainbow）ため、コールレンジの強いセミブラフ成分が少ない。OOP がコールするのは主にトップペア〜ボトムペアと弱いドロー。相対的にバリューハンドの比率が高い。

### K72r ターンカード別のコールレンジ変化

| ターンカード | コールレンジへの影響 | 実戦での意味 |
|---|---|---|
| A（オーバーカード） | Ax が大幅強化（2ペアに） | BBが強くなる → IP は慎重に |
| 3（ブランク） | 変化最小 | フロップのコールレンジがほぼそのまま |
| K（ペア） | BB の Kx がトリップスに、ただし IP も同様 | IP が圧倒的に Kx を多く持つ → IP 有利 |
| J（ブランク上位） | BB のガットショット（A3・98・QJ等）が若干強化 | 軽微な変化 |

**実用ポイント**: K72r でブランクが落ちた場合、BB のコールレンジの強さはほぼ変わりません。IP はバレルスコア（ドライ8 + ブランク2 = 10）に従ってダブルバレルが合理的です。

## 3-3 ウェットボードでのコールレンジ（JT9ss）

### ボード例: J♣T♣9♦（JT9ss/r）

**BTN が 33% CBet → BB がコール後のコールレンジ**

| ハンドカテゴリ | 代表例 | コールレンジにいる理由 |
|---|---|---|
| ストレート完成 | KQ, Q8 | ナッツ級（多くはレイズするが一部コール） |
| セット | JJJ, TTT, 999 | 極強（多くはレイズするが一部コール） |
| 強いフラッシュドロー | A♣K♣, A♣Q♣ | 強セミブラフ |
| オープンエンドSD | KQ, Q8, 87 | 強セミブラフ |
| ガットショット | AQ（K落ちで直）, 87 | セミブラフ |
| トップペア | Jx | 中程度 |

> **ウェットボードの特徴**: ドロー成分が多く、コールレンジに多様なハンドが含まれる。ターンでドローが完成するかどうかが、戦略を大きく変える。

### JT9ss ターンカード別のコールレンジ変化

| ターンカード | コールレンジへの影響 | 実戦での意味 |
|---|---|---|
| 8（コネクター） | KQ・Q7・87・76 などのストレートが完成 | BB のレンジが爆発的に強化 → チェックバック推奨 |
| A（オーバーカード） | Ax が 2 ペアに、A♣x♣ がフラッシュドロー | BB の一部が強化 → IP のバリューが薄れる |
| J（ペア） | BB の Jx がトリップスに | IP も Jx を持つが、IP の有利は維持 |
| 2♣（フラッシュ） | BB のクラブドローが完成 | BB のレンジ大幅強化 → チェックバック推奨 |
| 4（ブランク） | 変化中程度 | ドロー未完成、ストレート未完成 → IP の優位がやや維持 |

## 3-4 セミウェットボードでのコールレンジ（KT5ss）

### ボード例: K♥T♥5♦（KT5ss）

このボードは「高位カード＋スーテッド」という中間的なテクスチャです。

**BTN が 33% CBet → BB がコール後のコールレンジ**

| ハンドカテゴリ | 代表例 | 強さ |
|---|---|---|
| トップペアトップキッカー | KQo, KJs | 強い |
| トップペア中キッカー | KT, K9, K8s | 中程度 |
| セカンドペア | Tx | 中程度 |
| フラッシュドロー | A♥Q♥, A♥J♥ | 強セミブラフ |
| バックドアドロー | QJ（バックドアストレート） | 弱いセミブラフ |
| ガットショット | A9s, J9s | 弱いセミブラフ |

### KT5ss ターンカード別のコールレンジ変化

| ターンカード | コールレンジへの影響 | バレルスコア |
|---|---|---|
| K（ペア） | IP の KK・Kx がフルハウス/トリップスに | スーテッド4+ペア4=8 → 🟢 |
| Q♥（フラッシュ+コネクター） | BB の AJ♥・J9♥ 等が FD 強化 | スーテッド4+フラッシュ1=5 → 🟡 |
| A（オーバーカード） | BB の Ax が強化 | スーテッド4+OC3=7 → 🟢（ギリギリ） |
| 9（ブランク下） | 変化小 | スーテッド4+ブランク2=6 → 🟡 |
| T（ペア） | IP・BB 両方の Tx がトリップスに | スーテッド4+ペア4=8 → 🟢 |

## 3-5 レンジ遷移のターンへの影響──2ステップ実践法

実戦でのターン判断に使える 2 ステップです。

### ステップ 1: 相手のフロップコールレンジを想定

```
相手のフロップコールレンジ ≈
  トップペア〜セカンドペア (ペア系)
  + 強いドロー（OESD, FD）      [ウェット板のみ]
  + バックドアドロー             [ウェット板のみ]
  + ガットショット               [すべての板で少量]
  + オーバーカード Ax            [低位板のみ]
```

### ステップ 2: ターンカードでフィルタリング

```
【例: J♣T♣9♦ → ターン K♦（オーバーカード）】

フィルタ後:
  残る  : Jx（トップペア）, Tx（セカンドペア）
  弱化  : 99（ゲームオーバー的に弱いわけではないが相対的に）
  強化  : KJ, KT（元からコールレンジにあった Kx が 2 ペアに昇格）
  ドロー: FD・OESD は未完成のまま

結論: BB のレンジはやや強化（Kx の 2 ペア）。IP は KQ 等のトップペアでは慎重にサイズを選ぶ。
```

```
【例: K♣7♦2♠ → ターン 3♦（ブランク）】

フィルタ後:
  変化なし: K72r のコールレンジがほぼそのまま維持
  
結論: IP のアドバンテージが維持。バレルスコア10 → ダブルバレル推奨。
```

## 3-6 コールレンジの「強さの分布」を視覚化する

OOP のコールレンジを「ナッツ側 / ミドル / ブラフ側」に分類して、ターン後の変化を把握します。

### ドライボード K72r → ターン A

```
フロップコールレンジ:
  ナッツ側: Kx（トップペア）
  ミドル  : 7x, 2x, ガットショット
  ブラフ側: 空振り Ax（ブロッカー）

ターン A 後:
  ナッツ側: Ax（2ペアに昇格）, Kx（トップペア維持）  ← 増加
  ミドル  : 7x, 2x（変化なし）
  ブラフ側: 減少（Ax がバリューに昇格）
```

**解釈**: A ターン後は BB のナッツ側ハンドが増えます。IP がバリューベットするには TPTK 以上が必要。KQ・KJ などの「2番手トップペア」はチェックバックが安全な局面が増えます。

### ウェットボード JT9ss → ターン 8

```
フロップコールレンジ:
  ナッツ側: KQ, Q8, 777, TTT（多くがレイズ済み、コール組が残存）
  ミドル  : Jx, A♣x♣（FD）
  ブラフ側: ガットショット、空振りドロー

ターン 8 後:
  ナッツ側: KQ（ストレート完成）, Q7（ストレート完成）, 87（ストレート完成） ← 爆増
  ミドル  : FD が未完成のままのもの、Jx
  ブラフ側: ほぼ消滅（ドローが完成 or 弱体化）
```

**解釈**: 8 ターン後は BB のナッツ側が急増します。IP は強いハンド（セット・2ペア）以外はベットが難しい状況です。

## 3-7 ポットジオメトリ: フロップからリバーまでの設計

ターン戦略を考える上で「3 ストリートをどう設計するか」の視点が重要です。

### ポットジオメトリの考え方

スタックをリバーまでに効率よく使う「幾何学的なベットサイズ」があります。

```
幾何学的ベット比率 ≈ ((目標ポット / 現在ポット) ^ (1/N) − 1) / 2

N = 残りストリート数
```

**実戦用の近似値（100BB, フロップ SPR ≈ 14）**

| フロップ開始 SPR | 推奨ベットサイズの目安 |
|---|---|
| ~14（100BB 標準） | フロップ: 1/3〜1/2, ターン: 3/4〜1x, リバー: 1x〜1.5x |
| ~7（50BB スタック） | フロップ: 1/2, ターン: 1x, リバー: オールイン |

> **キーポイント**: フロップで小サイズ（1/3 ポット）を打つ場合、ターン以降は大きくしないと「残スタックが大きくなりすぎる」問題が起きます。ターンはフロップより大きいサイズを選ぶ傾向があります。

### SPR の変化早見表（1/3 pot フロップ CBet 後）

| フロップ開始 SPR | ターン開始時 SPR | ターンの性質 |
|---|---|---|
| 14（100BB） | ~8 | 標準的なターン戦略 |
| 10（75BB） | ~5.5 | ターンで半コミット |
| 7（50BB） | ~3.5 | ターンでほぼコミット |
| 4（30BB） | ~1.8 | ターンで事実上コミット |

**注意点**: SPR が 3 以下になると「ターンにベットすればリバーはオールイン」という状況です。この場合、ターンのベット判断はリバーのオールインを受け入れる意思決定になります。強いハンド（H2 以上）以外はチェックバックが安全です。

## 3-8 巻 2・巻 3 との連続性

> **巻 3 との接続**: フロップアクション（CBet サイズ・チェック）から**相手のレンジを推論**する方法は巻3 第7章「フロップアクションによる絞り込み」で扱っています。本章はその推論結果を受けて、レンジが**ターンに向けてどう形を変えるか**（レンジの構造変化）を扱います。

### フロップの 9 マスマトリクス（巻 3 参照）

巻 3 では「強い / 弱い × ボード高 / 低」の 9 マスでフロップ判断を整理しました。

ターンでは、このマトリクスが「シフト」します。

```
例: フロップ K72r で Jx（セカンドペア程度）の場合

フロップ: 「弱いハンド × ドライボード」→ コールのレシーバー
ターン A 落ち: Jx の相対強度がさらに下がる → 守備的に
ターン 2 落ち: Jx の相対強度は変わらず → フロップと同じ判断継続
```

この「マトリクスシフト」のパターンを理解することで、ターンカードが来た瞬間に「自分のハンドが強くなった / 変わらない / 弱くなった」を即座に判断できるようになります。

---

> **本章まとめ**
>
> - フロップのコールレンジは「強すぎず弱すぎない」ミドルゾーン
> - ドライボード: コールレンジがシンプル（ペア系 + 弱いドロー）
> - ウェットボード: コールレンジが多様（ドロー系が豊富）
> - ターンカードが OOP のコールレンジをフィルタリングする
> - ポットジオメトリを意識すると、フロップからリバーまでの設計ができる
> - SPR が 3 以下のターンベットは実質オールインの意思決定

## ミニクイズ

### 問1

BTN vs BB, フロップ K♣7♦2♠。BTN が 33% CBet、BB がコール。BB のコールレンジに「最も含まれにくい」ハンドはどれですか。

1. K8s（トップペア弱キッカー）
2. 66（アンダーペア）
3. セット（77, 22）

### 問2

フロップ J♣T♣9♦ → ターン 8♦。BB のコールレンジはどう変化しますか。

1. ほぼ変化なし
2. ナッツ側ハンド（ストレート完成）が急増する
3. BB のレンジが弱体化する

---

### 解答

- **問1**: 3（セットは強くてレイズが推奨 → コールレンジに残りにくい。66 は弱いアンダーペアでコールより多いがセットほど顕著ではない）
- **問2**: 2（8 が落ちると KQ・Q7・87 などのストレートが完成し、BB のナッツ側が急増）
