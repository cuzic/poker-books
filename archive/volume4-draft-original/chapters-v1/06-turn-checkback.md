# 第6章　チェックバック・プロービングの技術

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ターンでのチェックバックとプロービングベットを適切に使い分けるルールを習得する。

---

## 6-1 「全部バレル」では搾取される

第4章で「ダブルバレルは積極的に」と学びました。しかし 100% ダブルバレルには問題があります。

**全部バレルの欠点**:

1. **OOP のチェックレイズに弱い**: バレルしたとき、BB がチェックレイズしてくると対応できない
2. **弱いハンドでバリューを押し出す**: 強いハンドでもバレルで BB を降ろすと EV が下がる
3. **バランスが崩れる**: 全バレルだと BB は「コールかチェックレイズで反撃」で簡単に対応

GTO はダブルバレルを推奨しながら、同時に「チェックバックでバランスを取る」ハンドも持ちます。

---

## 6-2 チェックバックの 3 つの用途

### 用途 1: ショーダウンバリュー保護

「ベットしなくても現在の勝率で勝てる」ハンドはチェックバックが最善なことがあります。

```
例: K♣7♦2♠ A♠ (ターン) で自分が K♥Q♦ を持つ場合
  フロップ → Kx (トップペア) でコールが多い
  ターン → A が落ちて BB の Ax が強化
  K♥Q♦ でのベットは BB の Ax に対して弱い

→ チェックバックでショーダウンを目指す
```

### 用途 2: 強いハンドのスロープレイ

モンスターハンドでチェックバックして、リバーで大きく動く戦略です。

```
例: K♣7♦2♠ K♠ (ターン) で自分が K♥K♦ (4 of a kind) を持つ場合
  → 毎回ベットするより、チェックバックしてリバーでベット誘導
```

ただし、この戦略は「リバーで BB がブラフしてくれる」状況限定です。BBに引き続きアグレッシブルーティンが残る場合のみ有効。

### 用途 3: 🟡 ゾーンでの弱ハンド制御

バレルスコア が 🟡 (< 7) のとき、HandScore < 8 の弱いハンドはチェックバックが最善です。

---

## 6-3 チェックバック後の「プロービング」

チェックバックした後、BB が何もなくチェックしてきたリバーで **プロービングベット** する選択肢があります。

### プロービングベットとは

IP がターンでチェックバックした後、リバーでベットすること。

```
フロップ: IP → CBet, OOP → コール
ターン: OOP → チェック, IP → チェックバック
リバー: OOP → チェック, IP → ベット (プロービング)
```

### プロービングが有効な状況

1. **リバーカードが IP レンジを強化した**: ブランクからセカンドペアに変化等
2. **チェックバックで「弱いイメージ」を作った**: BB が「IP は弱い」と思ってチェックする
3. **BB のチェックレンジが弱い**: BB がチェックするということは、バリューハンドが少ない

```
例: J♠7♦5♣ (フロップ) → T♦ (ターン) → 2♣ (リバー)
  ターン: IP が T♦ で Tx を持つ可能性があるがチェックバック
  リバー: 2♣ はどちらにも影響しない → BB はチェックしやすい
  IP がプロービング: BB のチェックレンジから利益を得る
```

---

## 6-4 BB のチェックレイズへの対応

ターンでダブルバレルしたとき、BB がチェックレイズしてきた場合の対応です。

### チェックレイズの意味

BB のチェックレイズは強いシグナルです。

```
BB のターン チェックレイズレンジ:
  バリュー: セット、2ペア、ストレート
  セミブラフ: 強いフラッシュドロー + ペア、OESD + オーバーカード
  純粋ブラフ: まれ (ターンは高コスト)
```

### 対応の基準

| 自分のハンド | チェックレイズへの対応 |
|---|---|
| セット以上 | 4bet/コール |
| ストレート・フラッシュ | コール (スロープレイ) or 4bet |
| 2ペア | コール (スタックサイズ次第) |
| トップペア | 基本フォールド (例外あり) |
| セカンドペア以下 | フォールド |
| 強いドロー (15 アウト以上) | コール or 4bet ブラフ |

> **実戦的ルール**: ターンのチェックレイズに対して「トップペアでコール」は通常 -EV です。BB はターンにチェックレイズするとき、相当な強さのレンジを示しています。

---

## 6-5 「チェック → チェック」からのリバー戦略

ターンでお互いにチェックした後のリバー判断は特殊です。

### 何が起きているか

```
フロップ: IP → CBet, OOP → コール
ターン: OOP → チェック, IP → チェックバック
リバー: 両者が判断
```

IP がチェックバックした意味: 
- IP のバレルレンジは「ある程度強いが全力ではないハンド」が中心
- モンスターハンドか、チェックバックした中程度ハンド

BB の視点からは「IP は弱い可能性が高い」→ プロービングベットを試みることがある

### IP のリバー判断

| IP の手牌 | リバー判断 |
|---|---|
| 大幅強化 (リバーでストレート完成等) | ベット (ターンのチェックバックで偽装完了) |
| 中程度の維持 (トップペア等) | 状況次第 (BB のプロービングに備える) |
| ターンより弱化 (OOP のドロー完成等) | チェック or フォールド |

---

## 6-6 OOP のプロービングベット (リード)

OOP (BB) がターン・リバーでチェックせずに自らベットする「プロービング/リードベット」も重要です。

### BB がリードする状況

1. **IP のチェックバックでウィーク判断**: 「IP は弱い、今なら取れる」
2. **OOP がリバーで強化**: ドローが完成等
3. **ブラフポイント**: BB がバランスを取るためのリードブラフ

### IP のリードへの対応

```
BB のリードを見たとき:
  相対的に強いハンド → レイズかコール
  ブラフキャッチャー → コール (MDF ベース)
  弱いハンド → フォールド
```

BB のリードはゲームツリーを複雑にしますが、基本は「相手の示すハンドへの対応」と同じです。

---

> **本章まとめ**
>
> - チェックバックは「ショーダウンバリュー保護」「スロープレイ」「弱ハンド制御」に使う
> - チェックバック後のプロービングは「ターン偽装 → リバーで動く」の 2 ステップ
> - ターン チェックレイズへのコールは「2ペア以上」が基準 (トップペアは基本フォールド)
> - OOP のリードに対しても標準 MDF の範囲内で対応する

## 6-7 具体的なシナリオ演習

### シナリオ A: ドライボード、ターンでチェックバックすべきか

**状況**: BTN vs BB, フロップ K♣7♦2♠ で BTN が 1/3 pot CBet、BB がコール。ターン J♠。BTN は Q♠T♠ を持つ（ガットショット、何もない）。

- バレルスコア: ドライ8 + ブランク2 = 10 → 🟢（ドライ板なら基本バレル）
- HandScore: ガットショット = 6程度
- バレルスコア 🟢 だが HandScore < 8

**判断**: バレルスコアが 🟢 のときは「そのハンドでのバレルが理にかなうか」も考えます。QT（ガットショット）でベットすれば：
- BB がコールする場合、BB は KQ・KJ等の強いハンド → QT は後手
- BB がフォールドする場合のみ利益

GTO はこの状況で QT を「30〜40% バレル」に設定します。純ブラフとして一定頻度バレルしてバランスを取りますが、多数派はチェックバックです。

### シナリオ B: セミボード、チェックバックからプロービング

**状況**: BTN vs BB, フロップ J♠8♦5♣ で BTN が CBet、BB がコール。ターン 3♦。BTN がチェックバック。リバー 2♣。BB がチェック。

BTN は A♠J♣（トップペア）を持つ。

- ターンのチェックバック: バレルスコア セミ6+ブランク2=8 → 🟢 だが A♠J♣ は中程度のバリュー → ショーダウン保護でチェックバックも有効
- リバー: BB がチェック → BB は弱い可能性
- プロービング: A♠J♣ でバリューベット（50% ポット）が合理的

このシナリオでは「ターンでチェックバック → リバーでプロービングバリューベット」が GTO に近い選択肢です。

### シナリオ C: チェックレイズへの対応

**状況**: BTN vs BB, ターンで BTN がダブルバレル → BB がチェックレイズ（ポットサイズ）。BTN は K♥Q♦（トップペア）を持つ。

- ターンの BB チェックレイズ: 強いシグナル
- BTN のトップペア vs BB のレイズレンジ（セット・2ペア・ストレート・強FD）
- KQ は基本的に 負けている可能性が高い

**判断**: フォールドが推奨。KQ でコールするとリバーでさらに大きなベットに直面し、EV が低下します。

## ミニクイズ

### 問1

BTN vs BB, フロップ K♥8♦2♠ で BTN が CBet、BB がコール。ターン 9♦ 落ち。BTN は J♠T♥（ガットショット）を持つ。どの判断が最も GTO に近いですか。

1. ダブルバレル（バレルスコア高いのでベット）
2. チェックバック（ガットショットは HandScore 低いため）
3. オールイン（ドローがあるので積極的に）

### 問2

ターンでチェックバックした後、リバーでプロービングベットが最も合理的なのはどの状況ですか。

1. リバーで BB が強いポットサイズベットをしてきた
2. リバーで BB がチェックし、自分は中〜強程度のハンドを持つ
3. リバーで自分のドローが外れた

---

### 解答

- **問1**: 2（バレルスコア: ドライ8+ブランク2=10 → 🟢 だが JT はガットショット HandScore≈6 < 8 → チェックバックが多数派）
- **問2**: 2（BB のチェックは弱さのシグナル → 自分の中〜強ハンドでプロービングが有効）

---

**【GTO とのズレ】**

GTO ではチェックバックとバレルの比率がコンボ単位で精密に計算されています。

例えば「トップペア with キッカー A」は 100% バレルで「トップペア with キッカー K」は 60% バレルという細かい差があります。本章の「ハンドクラス基準」はこの細かい差を平均化したものです。

実戦での最大の学習ポイントは「相手のチェックレイズに対してトップペアをフォールドできるか」です。GTO ではトップペアでのコールが過剰になることが多く、これは実質的な損失源です。
