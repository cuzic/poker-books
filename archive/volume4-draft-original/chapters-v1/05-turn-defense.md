# 第5章　ターンディフェンス

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 相手のターンベットに対して、どれだけの頻度でコール/レイズすべきかを理解する。フォールド過多とコール過多の両方を避ける。

---

## 5-1 MDF をターンで使う

巻 2 で学んだ **MDF (Minimum Defense Frequency: 最低防御頻度)** は、ターンでもそのまま使えます。

### MDF の公式 (復習)

```
MDF = 1 - α
α (alpha) = ベット / (ポット + ベット)
```

例: ターン ポット 12BB に対して 9BB ベット (75% ポット)

```
α = 9 / (12 + 9) = 9/21 = 0.429 (≈ 43%)
MDF = 1 - 0.429 = 0.571 (≈ 57%)
```

→ 相手の 75% ポットベットに対して、少なくとも **57% の頻度**でコールまたはレイズしなければなりません。

### よく使うベットサイズ別 MDF

| ベットサイズ | α | MDF (最低防御%) |
|---|---|---|
| 25% pot | 20% | **80%** |
| 33% pot | 25% | **75%** |
| 50% pot | 33% | **67%** |
| 75% pot | 43% | **57%** |
| 100% pot | 50% | **50%** |
| 150% pot (OB) | 60% | **40%** |

> **ポイント**: 相手のベットが大きいほど、MDF は下がります (フォールドしても良い頻度が増えます)。

---

## 5-2 ターンでのコール vs レイズの選択

フロップと違い、ターンでは「コールではなくレイズ」で防御する選択肢が重要になります。

### コールで防御するケース

1. **ブラフキャッチャー**: 自分がショーダウンバリューを持ち、相手のブラフを捕まえたい
2. **リバードローが完成する可能性がある**: ターンでコールして、リバーで逆転を狙う
3. **ポット規模を抑えたい**: ナッツでないが相手が打ち続けるリスクを下げたい

### チェックレイズで防御するケース

1. **ナッツアドバンテージがある**: 自分だけがフルハウス/ストレートを持てるケース
2. **大きなベットに対して**: 75% pot 以上のベットには、コールだけでは不十分
3. **相手のバレルを止めたい**: チェックレイズで「ここは強い」シグナルを送る

### ベットサイズ別の防御バランス

| 相手ベットサイズ | コール割合 | チェックレイズ割合 |
|---|---|---|
| 33% pot | 大部分コール | チェックレイズ少なめ |
| 75% pot | コール + 一定比率のレイズ | 15〜25% レイズ |
| 150% pot | コール + 高いレイズ比率 | 25〜35% レイズ |

---

## 5-3 ターンのフォールドが合理的になるケース

フロップと比較して、ターンではフォールドが合理的になるケースが増えます。

### フォールドが増える理由

1. **ポットが大きくなった**: コールのコストが増えた
2. **ハンドの相対強度が下がった**: ターンカードが自分に不利だった
3. **アウツが減った**: セミブラフのドローが「当たらなくなった」

### 具体的なフォールド判断基準

| ハンドの状態 | ターンでの推奨アクション |
|---|---|
| ナッツ/セット/2ペア | コール or チェックレイズ (基本フォールドしない) |
| トップペア (強キッカー) | コール基本。相手のサイズ次第 |
| トップペア (弱キッカー) | ミックス (コール 50〜70%) |
| ミドルペア | ミックス (コール 30〜60%): ブラフキャッチャーとして |
| ウィークドロー (ガット) | 多くはフォールド。ポットオッズが良い場合のみコール |
| 何もない (エアー) | フォールド |

---

## 5-4 後手スコアでターン防御判断を数値化

MDF はレンジ全体の防御頻度を示しますが、「この手でコール/CR/フォールドのどれか」という個別判断には巻2 第13章の **後手スコア** が使えます。

### 後手スコアの式（フロップと同じ）

```
後手スコア = HandScore + A − 3 − C

A（ボード値）: ターン後の4枚ボードで評価
  ドライ(ペアボード・散開rainbow) = 3
  セミウェット = 2
  ウェット(コネクテッド/2-tone以上) = 1

C（ベット負担）: 33%=3、50%=5、75%=7

閾値:
  後手スコア ≥ 8 → チェックレイズ
  後手スコア 0-7 → コール
  後手スコア < 0 → フォールド
```

ターンでは A を「4枚のボード全体」で評価し直すことがポイントです。フロップでドライだったボードも、ターンカードがコネクターやフラッシュカードなら A が下がります。

### 計算例

**例: K♣7♦2♠A♠（ターン A）、75% ベット（C=7）**

ターン後の4枚ボードは散開 rainbow → A=3（ドライ維持）

- KJ（TP、HandScore≈18）: 後手スコア = 18+3−3−7 = **11** → コール
- 77（セカンドペア、HandScore=8）: 後手スコア = 8+3−3−7 = **1** → コール（弱いが MDF 範囲）
- 空振り（HandScore=0）: 後手スコア = 0+3−3−7 = **−7** → フォールド

後手スコアは MDF のレンジ論と個別ハンドの橋渡し役です。計算が面倒なときは「H3 → CR候補、H2 → コール、H1 → フォールド寄り」という 3 バケツ分類だけで代用できます。

## 5-5 実戦例: ターンディフェンスの判断

### 例 1: ドライボード、大きなターンベット

**状況**:
- ボード: K♣ 7♦ 2♠ A♠
- 相手 (IP、BTN) がフロップ 1/3 ポット CBet → あなた (OOP、BB) がコール
- ターン A♠。相手が 75% ポット (≈ 9BB) ベット

**あなたの手**: K♠ J♣ (トップペアセカンドキッカー)

**計算**:
- MDF = 1 - 9/(12+9) = 1 - 0.429 ≈ 57%
- K♠J♣ は A 落ちで相対的に弱化 (相手に Ax が増えた)
- しかし KJ はトップペアを維持

**判断**: コール推奨 (MDF の 57% に含まれる)

> Ax (2ペア+) を持つ相手に対して KJ でショーダウンを目指す。ただし相手がオーバーベット (150%) してきたら、フォールド検討の境界線上。

---

### 例 2: ウェットボード、ターンフラッシュ完成

**状況**:
- ボード: J♣ T♣ 9♦ → ターン 5♣ (3 枚目のクラブ)
- 相手が 60% ポットベット

**あなたの手**: Q♦ 8♦ (オープンエンドSD、クラブ無し)

**計算**:
- MDF = 1 - 0.6/(1+0.6) = 1 - 0.375 = 62.5%
- あなたはフラッシュなし (弱い位置)
- しかしストレートドローが残る

**判断**: ミックス判断。ストレートアウツ 8 枚 (リバーで Q か 6 が来れば直)。コール EV ≈ 8/46 ≈ 17%。相手のブラフキャッチとしての価値も込みで、コール率 40〜60% が目安。

---

## 5-6 ターン MDF で「守りすぎない」注意

MDF は「最低この頻度で防御する」という下限です。守りすぎ (コールしすぎ) も搾取されます。

### 守りすぎのサイン

- 相手のすべてのサイズに対して反射的にコール
- ドロー完成後も「せっかくドローがあったから」とコール継続
- 相手のサイズが上がるたびに「もう少しで」と乗り続ける

### 防ぐ方法: ハンド別役割の割り当て

フォールドするハンドを事前に決めておくことが、MDF を適切に守るコツです。

```
例: ポット 12BB、相手が 9BB ベット (MDF = 57%)

コールするハンド (57% の内訳):
  - ナッツアドバンテージ: 100%
  - トップペア強キッカー: 90%
  - トップペア弱キッカー: 60%
  - セカンドペア: 40%
  - ドロー (OESD): 80%
  - ドロー (ガット): 30%

フォールド: ボトムペア以下、ドロー無し
```

## 5-7 ターンレイズの使い方

チェックレイズはターンで特に有効です。

### ターンレイズのタイミング

1. **相手が弱いベットをした (33% 以下)**: 相手のブラフへの対抗
2. **自分がストレート/フラッシュ/2ペア以上**: 最大バリューを取る
3. **ターンカードが自分に有利**: 相手が諦めるボードでレイズ

### ターンレイズのサイズ

通常: 2.5 倍〜3 倍 (例: 相手が 6BB ベット → 15BB〜18BB レイズ)

小さすぎるレイズ (2倍未満) は相手のコールを簡単にし、大きすぎるレイズはブラフが通りにくい。

---

## 5-8 ターンカード別の防御方針

ターンカードの種類によって OOP の防御難易度が変わります。

### オーバーカード落ち（Aが落ちた場合）

BBは Ax を広くコールしているため、A 落ちは BB のコールレンジを強化します。一方で IP も Ax を多く持ちます。

**BB の対応:**
- Ax（2ペアに昇格）: 積極的にコール。強い場合はレイズ
- Kx（トップペアが2番手に）: サイズ次第でコール〜フォールド
- 7x, 2x（役無し）: 基本フォールド

```
後手スコア計算例（ターン A、75% ベット）:
  A♠7♦（2ペア） HandScore=22: 22+3−3−7 = 15 → チェックレイズ検討
  K♠J♦（TP）  HandScore=15: 15+3−3−7 =  8 → コール（ギリギリ）
  7♥6♥（2P小） HandScore=8:  8+3−3−7  =  1 → コール（弱い）
  空振りAx      HandScore=0:  0+3−3−7  = −7 → フォールド
```

### フラッシュ完成カード落ち

OOP がフラッシュドローをコールレンジに多く持っていた場合、フラッシュ完成は BB のレンジを劇的に強化します。

**BB の対応:**
- フラッシュ完成ハンド: 強気のコール・レイズ
- フラッシュなし強ハンド（2ペア等）: コール
- ドロー空振り: フォールド

IP は往々にしてこのターンでチェックバックします。もし IP が打ってきた場合は「IP がフラッシュを上回るバリューを持っているか IP のブラフ」と判断し、フラッシュ持ちならコール〜レイズが有効です。

### ボードペア（7が落ちたK72r）

```
例: K72r → 7♠ターン

BB のコールレンジへの影響:
  77（セット）: 実質フルハウスに。強い（ただし多くはフロップでレイズ済み）
  7x（2ペア）: K7・87・76等が 2 ペアに昇格 → 強い
  Kx（トップペア）: 相対的に弱化（相手の7xに負ける）
```

ボードペアターンは IP が高頻度でバレルします（バレルスコア: ドライ8+ペア4=12）。BB の 7x を持つハンドは積極的なコール・レイズが有効で、Kx は慎重なコールが基本です。

---

## 5-9 フォールド判断の明確化

「折りたたむ基準」を持つことで、判断スピードが上がります。

### フォールドするべきハンドの特徴

1. **後手スコア < 0**: 数値上フォールドが最善
2. **アウツが 4 以下のドロー**: ガットショット単独は多くの場合フォールド
3. **ターンカードで弱体化した**: フロップではコールできた強さが、ターンで標準以下になった
4. **相手のサイズが75%以上 + 自分の HandScore が 8 未満**: 双方の条件が重なった場合

### フォールドしてはいけないハンドの特徴

1. **後手スコア ≥ 0**: ギリギリでもコール域
2. **セカンドペア以上 + アウツあり**: 複合的な強さ
3. **ナッツドロー**: フラッシュドロー・OESDは相手サイズが 100% でも多くコール有効

## ミニクイズ

### 問1

BTN vs BB, フロップ K♦7♣2♠ でフロップが進み、ターン A♥ 落ち。ポット 12BB、BTN が 9BB ベット（75%ポット）。BB は 7♥6♥（セカンドペア）を持つ。後手スコアはいくつになりますか（HandScore=8, A=3 ドライ維持, C=7）。

1. 後手スコア = 8 → コール
2. 後手スコア = 1 → コール（ギリギリ）
3. 後手スコア = −3 → フォールド

### 問2

上記の状況でフォールドが合理的になるのはどのハンドですか（後手スコア < 0）。

1. KJ（トップペア）
2. 88（アンダーペア, HandScore=6）
3. A♠9♠（2ペアに昇格, HandScore=22）

### 問3

フロップ J♣T♣9♦ のウェットボードに 5♣ が落ちた（フラッシュ完成）。ポット 15BB、BTN が 10BB ベット。BB は K♣8♣（ナッツフラッシュ完成）。どう対応すべきですか。

1. チェックレイズ検討（ナッツで積極的に）
2. コールのみ（フラッシュを隠す）
3. フォールド（ターンフラッシュは危険）

---

### 解答

- **問1**: 2（HandScore=8, A=3, ポジション=−3, C=−7 → 8+3−3−7 = **1** → コール範囲）
- **問2**: 2（アンダーペア 88 は HandScore≈6 → 6+3−3−7 = **−1** → フォールド。KJ は後手スコア15+3−3−7=8、A9 は 22+3−3−7=15 でいずれもコール以上）
- **問3**: 1（ナッツフラッシュはチェックレイズで最大バリューを取る。コールのみは EV を逃す）

---

> **本章まとめ**
>
> - MDF = 1 − α は、ターンでもそのまま使える
> - 相手のベットが大きいほど、MDF は下がる（フォールドが許容される）
> - 後手スコア = HandScore + A − 3 − C：≥8 でチェックレイズ、0〜7 でコール、<0 でフォールド
> - ターンカード別に防御方針が変わる（A落ち / フラッシュ完成 / ボードペア）
> - 大きなベットに対してはコールだけでなくチェックレイズを組み込む
> - フォールドしていいハンド（アウツ少・HandScore低・後手スコア負）を事前に決めておく
