# 迷わないポーカー④ ターン・リバー ―連鎖で勝つ2ストリート判断―

## 企画概要

### 本書の位置づけ

『迷わないポーカー②フロップ[基礎]』『③フロップ[応用]』の読者を対象に、ターン・リバーの判断を体系化した一冊。フロップで確立した BoardScore・HandScore を軸に、**バレルスコア**（ダブルバレル暗算式）と **Alpha 式**（リバー価値/ブラフ配分）を新たに導入し、2ストリートを一貫した論理で判断できるようにする。

### 本書の特徴

- **バレルスコア**: FlopType 係数 + TurnCard 係数 の加算で「ダブルバレルすべきか」を即判定
- **Alpha 式**: リバーのバリュー/ブラフ配分とブロッカー選択の数理的根拠
- GTO ソルバー実測 270+ シナリオに基づく係数設定
- 各章末に【GTO とのズレ】コラム
- ミニクイズ + 総合ドリル 50 問

### 想定読者

- 巻2/3 を読了し、フロップ判断を身に付けた中級者
- ターン・リバーで「ダブルバレルすべきか」「コールすべきか」に迷う人
- GTO の感覚を暗算フレームワークで実戦に落としたい人

## 本書の中核：2つの式

### バレルスコア（ダブルバレル判断式）

```
バレルスコア = FlopType 係数 + TurnCard 係数

FlopType 係数:
  ドライ      (A72r 等)  : 8
  セミウェット (KT5ss 等) : 6
  スーテッド  (T85s 等)  : 4
  コネクテッド (987r 等)  : 3

TurnCard 係数:
  ペアカード (フロップと同ランク) : 4
  オーバーカード (フロップ最高位超) : 3
  ブランク                     : 2
  フラッシュ (3枚目同スート)    : 1
  コネクター (ストレート完成)    : 0

判定閾値:
  バレルスコア ≥ 7 → 🟢 積極バレル
  バレルスコア < 7 → 🟡 慎重 (ハンドクラス依存)
```

### Alpha 式（リバー価値/ブラフ配分）

```
α = ベット額 / (ポット + ベット額)   ← コールオッズ = 損益分岐点

ブラフ率の上限: α (これを超えるとブラフ EV−)
バリュー率:    1 − α

リバーのバランス確認:
  バリュー:ブラフ = (1−α) : α
  例 75% ベット → α = 43% → バリュー 57% : ブラフ 43%
```

## 数値の一貫性メモ

- **100BB、6-max キャッシュゲーム**を基本想定
- バレルスコアの全17セル一致率：GTO 🟢/🟡 と100%一致（270シナリオ実測）
- Alpha 式：ブラフ損益分岐は α = ベット/(ポット+ベット)
- SPR 目安：通常ポット ≈ 17、3bet ポット ≈ 4-5
- ターンCBet基準：≥70% 積極推奨、40-70% ハンド依存、<40% チェック基本
