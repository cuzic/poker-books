# 第3章　アクションとレンジ遷移

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ベット・チェック・コール・レイズ・フォールドの各アクションがレンジをどう変化させるかを体系化し、フロップからターンへの「レンジ遷移」を実戦でリアルタイムに追跡できるようにする。

---

## 3-1 アクションは情報の開示である

第2章では Capped と Uncapped というレンジの状態を学びました。本章ではその状態が「どのアクションによって決まるか」を体系化します。

ポーカーの各アクションは、単なる意思決定ではありません。アクションを選ぶたびに、自分のレンジが相手に開示されます。逆に、相手のアクションから相手のレンジを絞り込むことができます。

この「アクション = 情報開示」という視点を持つことが、ターン・リバー判断の出発点です。

プリフロップでは両者のレンジは広い状態から始まります。

```
プリフロップ前: 両者のレンジ = 全ハンド (1326 コンボ)

BTN オープン  → BTN レンジが約 45% に絞られる
BB コール     → BB レンジが約 45% に絞られる

フロップ CBet → BTN レンジが「強 + ブラフ」に絞られる
フロップ コール → BB レンジが「中強度」に絞られる

ターン CBet  → BTN レンジがさらに絞られる
ターン コール → BB レンジがさらに絞られる
```

ストリートが進むほどレンジが収束し、相手の「最もあり得るハンド群」が浮かび上がってきます。この収束プロセスを「レンジ遷移」と呼びます。

---

## 3-2 5つのアクションとレンジへの影響

### アクション1: ベット（攻撃開始）

ベットを打つと、ベット側のレンジは「バリューハンド + ブラフ」にポラライズ（二極化）します。同時に、相手の弱いハンドがフォールドしてレンジから除外されます。

```
BTN がフロップ CBet:
  BTN のレンジ: バリュー（セット・トップペア等）+ ブラフ → Uncapped 状態
  BB のコールしなかったハンド: レンジから除外
```

GTO の観点では、ベットレンジはバリューとブラフのバランスが必要です。バリューだけでベットすると相手はフォールドしやすくなり、ブラフだけになると相手にコールで搾取されます。この均衡点が GTO ベットレンジの構造を決めます。

### アクション2: チェック（パスまたは罠）

チェックは必ずしも弱さを意味しません。チェックを選んだプレイヤーのレンジには「中強度」と「トラップ（スロープレイ）」が混在します。

```
IP がフロップ チェックバック:
  IP のレンジ: 中強度（1ペア等でショーダウン志向）+ 一部スロープレイ
  OOP の解釈: IP はやや弱い → 次のストリートで先手を取りやすくなる

OOP がフロップ チェック → IP が CBet:
  OOP がコールした場合: フォールドするほど弱くない（最低強度を超えている）
  ただしレイズしなかった: ナッツが少ない → Capped 寄り
```

両者がチェックした場合、双方のレンジに強いハンドが少ない（両者 Capped）状態になります。このとき次のストリートの主導権は「ターンカードで改善した側」が得ます。

### アクション3: コール（ついていく）

コールはレンジを「中強度」に収束させます。強いハンド（ナッツ → レイズが推奨）と弱いハンド（フォールドが推奨）の双方がレンジから除外されるためです。

```
BB がフロップ CBet にコール:
  BB のレンジ: トップペア〜セカンドペア、強いドロー、弱いドロー
  除外: ナッツ（セット等、通常はチェックレイズが推奨）
  除外: 完全な空振り（フォールドが推奨）
```

コールが続くと中強度がさらに絞り込まれます。フロップコール → ターンコールと重なると、「ターンまでコールし続けられる強度を持つハンド」のみが残ります。コールは Capped 状態を維持するアクションです。

### アクション4: レイズ（強さの主張）

レイズはレンジを「ナッツ + 一部ブラフ」にポラライズし、Uncapped 状態を生み出します。

```
BB がフロップ チェックレイズ（CR）:
  BB のレンジ: セット・強い2ペア・強ドロー（ナッツ級）+ ブラフ CR
  除外: 中強度1ペア（CR しないでコールまたはフォールドが推奨）

→ BB の CR = Uncapped なポラライズレンジ
```

チェックレイズを受けた IP がコールで返した場合、IP のレンジは「3bet するほどは強くない中強度以上」に絞られます。CR 後は BB が Uncapped、IP が Capped 気味という非対称状態になります。

### アクション5: フォールド（降りる）

フォールドはそのプレイヤーがハンドを持ち続けないため、レンジ遷移としての直接効果は終了します。しかし残ったプレイヤーの観点では、「相手がフォールドしなかった = 最低強度を超えている」という情報が常に蓄積されています。

## 3-3 Capped / Uncapped 状態遷移の整理

第2章で学んだ Capped / Uncapped の概念を、アクションのシーケンスとして整理します。

| フロップのアクションシーケンス | BTN の状態 | BB の状態 |
|---|---|---|
| CBet → コール | Uncapped | Capped |
| チェックバック → チェック | Capped | Capped |
| CBet → チェックレイズ → コール | Capped 気味 | Uncapped |
| CBet → チェックレイズ → 3bet → コール | Uncapped | Uncapped |

最も頻繁に起きるのは「CBet → コール」のパターンです。このとき BTN が Uncapped、BB が Capped という非対称状態でターンに入ります。これがターン戦略の出発点であり、第4章で詳しく扱います（リバーの特殊性は巻5 第1章へ）。

---

## 3-4 主要なアクションシーケンス

フロップからターン・リバーへの代表的な流れを4パターンで整理します。

### シーケンス A: CBet → コール → ターン（最頻パターン）

```
フロップ:
  BTN CBet → BB コール
  BTN: Uncapped（ナッツ保有可）
  BB: Capped（ナッツが少ない）

ターン:
  BTN のアドバンテージが継続
  → BTN はダブルバレルまたはチェックバックを選択
  → BB は受け身（コールまたはフォールド）
```

ターンカードの種類によって BTN のアドバンテージの大きさが変わります。BB のレンジを改善しないターンカード（ブランク・ペア）では BTN のアドバンテージが維持されます。BB のレンジを改善するターンカード（コネクターなど）ではナッツの差が縮まります。具体的な判断方法は第6章のバレルスコアで扱います。

### シーケンス B: チェックバック → チェック → ターン

```
フロップ:
  BTN チェックバック → BB チェック
  BTN: Capped（チェックバック = ナッツ率が低下）
  BB: Capped（先手を打たなかった）

ターン:
  両者 Capped → ターンカードで改善した側が主導権を得る
  → BB のドンクベット: BB のターン改善ハンドが先手
  → BTN の遅延 CBet: BTN のターン改善ハンドが攻撃
```

両者がチェックした場合、ターンカードが「どちらにとって有利か」を判断するのが鍵です。

### シーケンス C: CBet → チェックレイズ → コール → ターン

```
フロップ:
  BTN CBet → BB CR → BTN コール
  BTN: Capped 気味（CR に 3bet しなかった = ナッツ率が低下）
  BB: Uncapped（CR = ナッツ + ブラフのポラライズ）

ターン:
  BB が Uncapped を持つ珍しい状態
  → BB のドンクベットや先手攻撃が有効な場面が増える
  → BTN は受け身（ナッツ以外はコールや降りを検討）
```

このシーケンスではターンで BB が主導権を持ちます。詳細は第10章（OOPの応戦）で扱います。

### シーケンス D: CBet → コール → ターンバレル → コール → リバー

```
フロップ: BTN CBet → BB コール
ターン:   BTN バレル → BB コール
リバー前の状態:
  BTN: Uncapped を維持（2ストリートバレル = 強いレンジ）
       ただしブラフは2ストリート維持しにくいため、バリューヘビー
  BB: Capped だが相当に絞られている
       2ストリートコール = 強い中強度（2ペア・強ドロー等）
       弱ハンドはフロップかターンでフォールドしている

リバー:
  BTN のバリューベットが有効
  BB の 3ストリートコール基準はより高くなる
```

## 3-5 フロップコールレンジの構造

ターンの判断は、フロップのコールレンジの構造を理解した上で始まります。コールレンジは「強すぎず弱すぎない」中強度ゾーンです。

```
フロップコールレンジの基本構造:
  強すぎてコールしない: ナッツ（セット等）→ チェックレイズが推奨
  弱すぎてコールしない: 完全な空振り → フォールドが推奨

コールするレンジ（中強度ゾーン）:
  ペア系: トップペア（中程度のキッカー）、セカンドペア、ボトムペア
  ドロー系（ウェット板のみ）: 強いセミブラフドロー（OESD、フラッシュドロー）
  ドロー系（全板で少量）: 弱いセミブラフドロー（ガットショット）
  バックドアドロー: 強化の可能性を持つハンド
  オーバーカード: Ax 等（ブロッカー + 改善期待）
```

ボードのテクスチャによってコールレンジの構成が変わります。

### ドライ板（K♣7♦2♠）のコールレンジ

フラッシュドローが発生しない rainbow ボードです。コールレンジからドロー成分が少なく、ペア系ハンドの比率が高くなります。

| ハンドカテゴリ | 代表例 | コールレンジにいる理由 |
|---|---|---|
| トップペア弱キッカー | K9s、K8s | 1ペアでそこそこ強い |
| セカンドペア | 7x | 中程度の強さ |
| ボトムペア | 2x | 弱め、改善期待 |
| バックドアストレートドロー | 98s（7-8-9の3連続）、65s（5-6-7の3連続） | 弱いセミブラフ |
| オーバーカード | Ax（Aハイ） | ブロッカー + 改善期待 |

K♣7♦2♠上では、98s（9-8とボードの7で3枚連続）や65s（6-5とボードの7で3枚連続）は**バックドアストレートドロー**です。4枚連続の中抜けであるガットショットではありません。真のガットショット（4枚連続の内1枚欠け）はこのボードではほとんど存在しません。

ドライ板のコールレンジは「ペア系が主体 + バックドアドロー少量」のシンプルな構造です。

### ウェット連結板（J♣T♣9♦）のコールレンジ

フラッシュドロー + ストレートドローが豊富なウェット板です。このボードでは、KQ・Q8・87といったハンドが**フロップ時点でストレートを完成**しています（KQ: K-Q-J-T-9、Q8: Q-J-T-9-8、87: J-T-9-8-7）。

| ハンドカテゴリ | 代表例 | コールレンジにいる理由 |
|---|---|---|
| フロップ完成ストレート | KQ、Q8、87 | ナッツ（多くはCRだが一部コールでスロープレイ） |
| セット | JJ、TT、99 | ナッツ（多くはCRだが一部コールでスロープレイ） |
| 強いフラッシュドロー | A♣Q♣、A♣K♣ | 強いセミブラフ |
| OESD | AQ（K落ちで K-Q-J-T-9 完成、8落ちで Q-J-T-9-8 完成） | 強いセミブラフ |
| トップペア | Jx | 中程度 |

AQはJT9上でOESDです。AとQを持ち、ボードのJ-T-9と合わせると Q-J-T-9の4連続があり、Kが来れば K-Q-J-T（実際はAKQJTという別のストレート）、8が来れば Q-J-T-9-8が完成します。Kまたは8の2方向に引けるため、8 outsのOESDです。

ウェット板のコールレンジは「スロープレイのナッツ + 強いドロー + ペア系」という多様な構造です。ターンカードがドローを完成させるかどうかで、BB のレンジの強さが劇的に変わります。

## 3-6 ターンカードがコールレンジをフィルタリングする

ターンカードが落ちると、フロップのコールレンジが「フィルタリング」されます。各ハンドがターンカードでどう変化するかを把握することが、ターン判断の核心です。

### ドライ板 K♣7♦2♠ → ターン A

```
フィルタ前（フロップ後）:
  ナッツ側: Kx（トップペア）
  ミドル: 7x、2x
  バックドアドロー: 98s、65s（バックドアストレートドロー）
  オーバーカード: Ax（まだ何も完成していない）

ターン A 後:
  ナッツ側: Ax（トップペアに昇格）、Kx（維持）← 増加
  ミドル: 7x、2x（変化なし）
  バックドアドロー: 98s、65s（バックドアストレートドローは維持）
  オーバーカード: 消滅（Ax がバリューに昇格）
```

A ターン後は BB のナッツ側ハンドが増加します。特にAx が2ペアや1ペアとして強化されるため、IP が KQ や KJ 等の「2番手トップペア」でバリューベットするには慎重なサイズ選択が必要になります。

### ウェット連結板 J♣T♣9♦ → ターン 8

このターンカードはコネクターです。

```
フィルタ前（フロップ後）:
  フロップ完成ストレート: KQ（J-T-9-Q-K）、Q8、87（スロープレイでコール）
  強いドロー: AQ（OESD）、A♣Q♣（FD+OESD）

ターン 8 後（8が落ちる）:
  コールレンジにあったAQ: 8落ちで Q-J-T-9-8 が完成 → ストレート完成
  A♣Q♣: Q-J-T-9-8 のストレート完成 + フラッシュドロー継続
  フロップでスロープレイしていた KQ・Q8・87: 既に完成していたため変化なし
  ナッツ側: 急増（OESD が次々と完成）
```

8 ターン後は BB のナッツ側が急増します。特にフロップで「強いドローを持ってコールしていた」ハンドが完成し、BB の強さの分布が大きく偏ります。IP はこの局面では強いハンド（セット・強い2ペア等）以外のバレルは難しくなります。

### K♣7♦2♠ → ターン 3（ブランク）

```
ターン 3 後:
  変化: ほぼなし
  BB のコールレンジが維持されたまま

結論: IP のアドバンテージが維持される
     第6章で学ぶバレルスコア（ドライ8 + ブランク2 = 10）は
     ≥7 の条件を満たすため、積極バレルが推奨される
```

## 3-7 3ストリート全コールの意味

3ストリートすべてコールしたプレイヤーのレンジは特徴的な構造を持ちます。

```
3ストリート全コールのレンジ:

最も多いカテゴリ: 強い中強度
  トップペア（トップキッカー）、2ペア、完成ドロー
  → 3回コールし続けられる強度を持つハンド

稀なカテゴリ: スロープレイのナッツ
  セット、ストレートをスロープレイした場合
  → 3全コールだが、これは罠の可能性（ただし頻度は低い）

少ないカテゴリ: 弱い中強度
  「もう入れすぎた」感覚で続けたハンド
  → 数学的には誤りだが、実戦では存在する
```

3ストリート全コールに対するリバーブラフは GTO 的にはほぼ機能しません。相手はショーダウンバリューを求めてコールしているため、ブラフに反応してフォールドする可能性が低いからです。

## 3-8 実戦でのレンジ追跡フロー（4ステップ）

ここまでの内容を実戦で使うための4ステップフローです。

```
ステップ1: プリフロップのアクションからベースレンジを確認
  「BTN オープン = 約 45%」「BB コール = 約 45%」
  「3bet ポット = BTN の 3bet レンジ vs BB のコールレンジ」

ステップ2: フロップのアクションで Capped / Uncapped を更新
  CBet:           BTN → Uncapped
  BB コール後:    BB → Capped
  BB チェックレイズ後: BB → Uncapped、BTN コール後 → Capped 気味
  チェックバック: BTN → Capped

ステップ3: ターンのアクションでさらに更新
  BTN バレル:    BTN の弱いブラフが減少（バリューヘビー化）
  BB コール:     BB の弱ハンドが減少（中強度に収束）
  BTN チェックバック: BTN の Capped 化が進行
  BB ドンクベット: BB の Uncapped 化が進行

ステップ4: リバーで「残ったレンジ」で判断
  相手の残レンジ: 何が最もあり得るか
  自分のレンジ: 今のアクションは相手にどう見えるか
  EV 比較: コール / フォールド / ベットのどれが最大 EV か
```

このフローを実戦で回す習慣をつけることが、ターン・リバーの判断精度を上げる最短ルートです。具体的にどのアクションを選ぶかは第III部（第9章〜第13章）で扱います。

## ミニクイズ

### 問1

BTN が フロップ CBet → BB コール → ターン BTN チェックバック という展開です。ターン後の各レンジの状態として正しいものはどれですか。

1. BTN: Uncapped のまま / BB: Capped のまま
2. BTN: Capped に変化 / BB: Capped のまま（両者 Capped）
3. BTN: Capped に変化 / BB: Uncapped に逆転

### 問2

フロップ J♣T♣9♦ で BB がコールした場合、BB のコールレンジについて正しい記述はどれですか。

1. KQ・Q8・87 はフロップ時点でストレートが完成しているため、BB のコールレンジにはほぼ入らない
2. KQ・Q8・87 はフロップでは OESD であり、コールレンジの主力を占める
3. KQ・Q8・87 はフロップでストレートが完成しているが、多くはスロープレイでコールするため BB のコールレンジに含まれうる

### 問3

BTN CBet → BB チェックレイズ → BTN コール という展開後、ターンの主導権はどちらにありますか。

1. BTN（CBet のアグレッサーだから）
2. BB（チェックレイズで Uncapped 化したため）
3. 両者同等（アクションが相殺されるから）

---

### 解答

- **問1**: 2（BTN のターンチェックバックは「ナッツなら打っていた」というシグナルです。CBet は Uncapped でしたが、チェックバックで Capped に変化します。BB はコールのまま Capped が継続します。両者 Capped になると、次のストリートの主導権はターンカードで改善した側が持ちます）
- **問2**: 3（KQ は K-Q-J-T-9のストレート、Q8 は Q-J-T-9-8のストレート、87 は J-T-9-8-7のストレートとして、フロップ時点ですでに完成しています。OESD ではありません。ただし、ナッツを即チェックレイズせずにコールでスロープレイするプレイヤーもいるため、BB のコールレンジに含まれうるのが実態です）
- **問3**: 2（BB のチェックレイズはナッツ + ブラフのポラライズ = Uncapped 化です。BTN はコールで返した時点で「3bet するほど強くない」と開示されるため、Capped 気味になります。ターンでは Uncapped レンジを持つ BB が先手攻撃やドンクベットを有効に使える立場です）

---

> **本章まとめ**
>
> - 各アクションはレンジを変化させる: ベット→ポラライズ、コール→中強度化、チェック→中強度またはトラップ、レイズ→Uncapped 化
> - Capped / Uncapped の状態はアクションの積み重ねで決まり、各ストリートで更新される
> - 最頻パターン「CBet → コール」では BTN: Uncapped、BB: Capped でターンに入る
> - チェックバック → チェックで両者 Capped になると、ターン改善した側が主導権を持つ
> - フロップのコールレンジはボードテクスチャで構造が変わる: ドライ板はペア系主体、ウェット板はドロー系が豊富
> - ターンカードはフロップのコールレンジをフィルタリングする: 連結カードやフラッシュカードは BB を強化し、ブランク・ペアは IP のアドバンテージを維持する
> - 4ステップの実戦フローでレンジ遷移を追跡する習慣をつける

---

**【GTOとのズレ】**

GTO はすべてのアクションシーケンスで精密なレンジ遷移を計算します。実戦での最大の「GTOとのズレ」は、**レンジ遷移を追跡せずに自分の手牌の強さだけで判断すること**です。

典型例を挙げます。BTN がフロップでチェックバックし、ターンでも BB がチェックした状況を想像してください。「自分は KT で1ペア = 弱いからフォールド」と判断してしまうプレイヤーがいます。しかし GTO 的には、この状況では BTN のレンジ全体に中強度が多く残っており、遅延 CBet やチェックバック継続が適切な場合があります。

もう一つの典型的なズレは、「フロップのコールレンジには強いハンドがない」という思い込みです。実際には、コールレンジにはスロープレイのセットや完成ストレートが含まれています。特にウェット板では、BB のコールレンジにナッツ級のハンドが一定数潜んでいます。この点を過小評価すると、ターンでのオーバーベットやブラフが不適切に多くなります。

「相手が今どのレンジを持っているか」を4ステップで継続的に更新する習慣が、GTO との差を縮める最も重要なスキルです。この習慣を身につけると、次章（第4章）で学ぶターンの位置づけをより深く理解できます。
