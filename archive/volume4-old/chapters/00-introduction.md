> 「ターンは、リバーで何が起きるかを見越して打つストリートです。リバーの α 値、リバーで効くブロッカー、リバーまでのコミット閾値 ─ これらをすべて『これから起きること』として頭に置きながら、目の前のターンカードに向き合う。本書はその総合判断を、暗算で扱える形に圧縮します」

---

## 本書の位置づけ

本書は『迷わないポーカー』シリーズ**第4巻、ターン編**です。

| 巻 | タイトル | 状態 |
| --- | --- | --- |
| ① | プリフロップ — 覚えなくていいレンジの考え方 | 既刊 |
| ② | フロップ[基礎] — 秒で決まるボード判断 | 既刊 |
| ③ | フロップ[応用] — 相手のレンジを読んで搾取する | 既刊 |
| ⑤ | リバー — 配分と確定で収支を積む | 既刊 |
| **④** | **ターン — リバーから逆算するターン総合判断（本書）** | **ポストフロップの最終総合書** |
| ⑥ | トーナメント — ICM とM値で迷わないトーナメント判断 | 既刊 |

シリーズの**推奨読書順序は 1 → 2 → 3 → 5 → 4 → 6** です。巻番号の順ではない理由は、本書（ターン編）が**シリーズ最大の総合判断章**だからです。

リバー（巻5）は「将来カードがない確定ゲーム」で概念がクリーンです。α 式、後手スコア（リバー版）、ブロッカー論を独立した形で習得できます。  
ターン（本書）は「**リバーで何が起きるかを予測してターンを決める**」backward induction（後ろ向き帰納）が本質です。リバーの式を**既出概念**として活用してこそ、ターンの真の難しさを正しく扱えます。

---

## 本書の主題 ─ 「リバーから逆算する」

ターンとリバーの最大の違いは、ターンには**まだ将来のカードが1枚残っている**ことです。

ターンでベットするとき、頭の中で次が動いています。

- リバーで自分は何を value として打つか
- リバーで自分は何を bluff として打つか
- リバーで相手の call/fold ラインはどこか
- リバーで効くブロッカーは何か
- リバーまでのコミット閾値はどこにあるか

これらの問いに答えるには、**リバーの式（α 式・後手スコア・ブロッカー論）が頭に入っていなければなりません**。本書はそれを前提として、ターンの判断を「リバーから逆算する」形で展開します。

```
ターン: いまの判断 = リバーで起きることの予測 + ターンカードの影響
リバー: いまの判断 = いまのハンド価値（確定）
```

ターンが本書の主役。リバーの知識は道具として使います。

---

## 本書で導入する暗算式

### バレルスコア（本書 第6章）

```
バレルスコア = FlopType係数 + TurnCard係数
```

ダブルバレルの推奨度を 0〜12 で数値化します。フロップのボード分類とターンカードの種類から即座に計算できます。**ターン攻撃の唯一の新規式**であり、本書の中核です。

### 後手スコア（ターン版、本書 第7章）

```
後手スコア = HandScore + A − 3 − C − M
```

巻2 で確立した式の骨格はそのまま。ターンでは「**まだ将来カードが残っている**」ぶん、係数の解釈を調整します。リバー版（巻5 第7章既出）との違いは、ターン特有の「ドロー加点が生きる」点です。

### ブロッカー論（ターン視点、本書 第8章）

巻5 第5章・第8章で確立したブロッカー論を、ターン文脈で活用します。「**リバーでブロッカーになるハンドをターンで残す**」という backward induction の典型例です。

## 巻5 から継承する概念（既出として扱う）

本書では以下を**説明済みの道具**として参照します。

- **α 式**（巻5 第6章既出）: α = ベット ÷ (ポット + ベット)、後手下限確率 = 1 − α
- **後手スコア（リバー版）**（巻5 第7章既出）: HandScore + A − 3 − C − M、リバー特有の C 拡張（100%=9、150%=11）
- **ブロッカー論**（巻5 第5章・第8章既出）: バリューブロッカー・ブラフブロッカーの選別
- **ナッツアドバンテージ**（巻5 第3章既出）: ストリート横断のレンジ遷移
- **ポットコミットメント**（巻5 第13章既出）: SPR と降りられない状況の識別

これらが頭に入っている読者を想定しています。**自信がない方は、先に巻5 を読了してください**。

---

## 想定読者

本書は次のような読者を想定しています。

**巻5（リバー編）を読了した読者**。α 式・後手スコア（リバー版）・ブロッカー論を実戦で使える方は、本書のターン判断にスムーズに入れます。

**ポストフロップの「総合判断」を強化したい中級〜上級者**。ターンは将来カードと現在価値の両方を扱う最も複雑なストリートです。本書はこの複雑性を正面から扱います。

**ソルバーの「なぜターンでこの判断をするのか」が腑に落ちない方**。ソルバーは出力を返しますが、その背後にある「リバーからの逆算ロジック」を直感的に理解する助けになります。

## 巻1〜3 と巻5 との接続

本書は以下を既習として進みます。不安な方は括弧内の参照先を先に確認してください。

**巻2 で習得済みとして扱う概念**:
- 簡易レンジスコア（フロップの CBet 頻度予測）
- HandScore（ハンドの強さ 0〜50）
- 後手スコア = HandScore + A − 3 − C − M（フロップ版）
- A係数（ドライ=3 / セミ=2 / ウェット=1）
- C係数（33%=3 / 50%=5 / 75%=7）
- M係数（HU=0 / 3-way=3 / 4-way以上=6）
- Rule of 2 and 4

**巻3 で習得済みとして扱う概念**:
- 精密レンジスコア（外れ値ボードの補正）
- ブロッカー・ディスブロッカーの定量評価

**巻5 で習得済みとして扱う概念**:
- α 式（α = ベット ÷ (ポット + ベット)、後手下限確率 = 1 − α）
- 後手スコア（リバー版、C 拡張 100%=9 / 150%=11）
- ブロッカー論（バリュー / ブラフブロッカーの選別）
- ナッツアドバンテージとレンジ遷移
- ポットコミットメント
