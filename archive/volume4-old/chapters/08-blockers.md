## 8-1 ブロッカーとは何か ─ 物理的な除外効果

デッキは52枚です。あなたが2枚のホールカードを持っている時点で、その2枚は相手のハンドに存在しません。この「自分が持っているから相手は持てない」という物理的な制約が**ブロッカー**です。

巻2の第9章でHandScoreを学んだ際、ブロッカー加点（+2〜+3）として登場しました。本章ではその概念をリバー戦略に拡張します。

具体例で確認します。

```
ボード: K♥7♦2♣ A♠ 9♥（リバー）
あなたのハンド: A♣Q♦

→ あなたがA♣を持つ → 相手はA♣を持てない
→ 相手がAKを持つには、A♥・A♦・A♠ + Kの組み合わせのみ
→ A♣が絡むAKのコンボ（A♣K♥、A♣K♦、A♣K♠、A♣K♣の4通り）が
  相手のレンジから物理的に消える
```

このように、ブロッカーはレンジを「確率的に削る」のではなく、「物理的に除外する」効果を持ちます。この違いが重要です。

ブロッカーの重要性は特にリバーで増します。フロップやターンでは、ブロッカーの影響を相殺する「カードが変わる可能性」がありました。リバーはそれがない。したがって、手元に持つカードの種類が、そのまま相手のレンジの構成に影響し続けます。

## 8-2 2つのブロッカータイプ

ブロッカーには**どのレンジを削るか**によって2種類があります。この区別を最初に理解することが、ブロッカー論全体の土台です。

### バリューブロッカー

**定義**: 相手の強いハンド（バリューベットするハンド）を削るブロッカー。

ブラフを打つ側にとって有利に働きます。相手のコールレンジが弱まるため、ブラフの成功率が上がります。

```
あなた: ブラフをしようとしている（IP）
相手: K♥フラッシュ完成ボードで、ナッツフラッシュ（Ax♥）をコール基準に入れている

→ あなたがA♥を持つ → 相手のA♥x♥（ナッツフラッシュ）が物理的に消える
→ 相手のコールレンジからナッツが脱落
→ ブラフに対して相手がコールしてくる頻度が下がる
→ ブラフの期待値が上昇
```

バリューブロッカーは「攻撃する側の武器」です。自分のブラフに対して相手が降りやすくなります。

### ブラフブロッカー（アンブロッカーとの関係）

**定義**: 相手のブラフハンドを削るブロッカー。

コールする側にとって不利に働きます。相手のベットレンジからブラフが脱落するため、自分のコールが弱まります。

```
あなた: コールしようとしている（OOP）
相手: 外れたフラッシュドロー（A♥x♥）がブラフとしてベットしてくる

→ あなたがA♥を持つ → 相手のA♥x♥（ブラフ候補）が物理的に消える
→ 相手のベットレンジからブラフが脱落
→ 相手のベットがよりバリューに偏る
→ コールの期待値が低下
```

したがって同じ「A♥を持つ」という状況でも、それが「バリューブロッカー」として機能するか「ブラフブロッカー」として機能するかは**文脈次第**です。

攻撃側でブラフを打つ場面では、バリューブロッカーを持つコンボが優秀です。守備側でコールするかどうか迷う場面では、ブラフブロッカーを持つコンボはコールに慎重になるべきです。

## 8-3 ブロッカー計算の基礎

ブロッカーの強さを数値で把握するために、基本的な計算方法を理解します。ただし実戦では暗算の速さが求められるため、正確な計算より「どのカードが強いブロッカーか」という感覚を身につけることを優先します。

### コンボ数の削減率

フラッシュを例に考えます。ハートが3枚のボードで、相手のナッツフラッシュ（Ax♥）の候補を数えます。

```
ボード: K♥7♥2♣ T♥ 9♦（リバー：ハート3枚）
ナッツフラッシュ = A♥ + 他のハート1枚

ハートは全部で13枚。ボードに3枚（K♥、7♥、T♥）。
残りのハートは10枚（A♥含む）。

あなたがA♥を持つ場合:
  相手のナッツフラッシュの構成は「A♥ + 他のハート（9枚）= 9通り」
  → ただしあなたがA♥を持つため、相手はA♥を持てない
  → ナッツフラッシュのコンボがゼロになる（A♥が前提条件のため）

あなたがA♣を持つ場合:
  相手のナッツフラッシュ = A♥ + 残りハート（9枚）= 9通り
  → A♣はハートのブロッカーにならない
  → 相手のナッツフラッシュが9通り残る
```

この例でわかるとおり、A♥を持つことで相手のナッツフラッシュをゼロに削れますが、A♣を持っても削れません。同じAでも、スートが一致するかどうかで効果は天と地ほど違います。

### ポケットペア・セット系のブロッカー

セット系の計算は比較的シンプルです。

```
ボード: K♥7♦2♣ A♠ 9♥（KKKがセット）
相手のKKのコンボ数:

K♥K♦、K♥K♣、K♥K♠、K♦K♣、K♦K♠、K♣K♠ = 6通り
（ボードのK♥を除く場合はK♦、K♣、K♠の3枚が残る → 3通り）

あなたがK♦を持つ場合:
  相手のKKからK♦が絡むコンボが消える（K♦K♣、K♦K♠ = 2通り削減）
  3通りのうち2通り = 約67%のブロック率
```

実際のブロッカー強度は、削れるコンボの元の数に対する削減割合で表せます。

| ブロック対象 | 元のコンボ数 | 削減コンボ数（1枚ブロック時） | ブロック率 |
|---|---|---|---|
| ナッツフラッシュ（Ax♥を自分がA♥保持） | 9通り | 9通り（完全削除） | 100% |
| セット（相手のAAを自分のAで） | 3通り（ボードにAが1枚の場合） | 2通り | 約67% |
| ストレート1枚キー（Tのボードで相手のTを） | 4通り | 3通り | 約75% |
| フラッシュドロー（スートの1枚保持） | 約45通り | 約9通り | 約20% |

## 8-4 ブラフ選択にブロッカーを使う ─ 実例

第6章のバレルスコアと巻5 第6章のAlpha式で「ブラフを打つ方針」が決まった後、具体的にどのコンボを選ぶかにブロッカーが機能します。

### 基本原則: 同じ強度のコンボ群の中から選ぶ

ここが最も重要な点です。ブロッカーは「弱いコンボを良いコンボに変える魔法」ではありません。

```
正しい使い方:
  バレルスコアが閾値以上（積極バレル方針）→ 複数のブラフ候補コンボが存在する
  → その中で「バリューブロッカーが強いもの」を優先選択

誤った使い方:
  バレルスコアが閾値未満（ハンド依存方針）
  → 「でもバリューブロッカーがあるから打とう」← これは禁止
```

ブロッカーは**第6章・第7章・巻5 第6章の判断で決まった方針をコンボ単位で微調整する**ものです。方針を覆す根拠にはなりません。

### 実例: フラッシュ完成リバーでのブラフ選択

```
ボード: K♥7♦2♣（フロップ）A♥（ターン）9♥（リバー）

リバーでハートのフラッシュが完成。
Alpha式で計算すると、50%ポットサイズでブラフを打てる方針。

ブラフ候補ハンド（いずれもショーダウン価値なし）:
  候補A: A♣Q♦（Aのブロッカーあり、ハートなし）
  候補B: A♠Q♣（Aのブロッカーあり、ハートなし）
  候補C: K♣Q♦（KとQのブロッカーあり）
  候補D: J♦T♣（ブロッカーほぼなし）
```

フラッシュが完成したリバーで相手のバリューレンジの中心は「ハートのフラッシュ」です。ナッツフラッシュはA♥x♥です。

- 候補A（A♣Q♦）: A♣はナッツフラッシュA♥を「ブロックしない」。しかし自分がAを持つことで、相手のAK（トップ2ペア）やAx系の非フラッシュバリューをブロックできる。フラッシュボードではフラッシュ保有者がコールするため、Aの非フラッシュブロックは限定的。
- 候補B（A♠Q♣）: 候補Aとほぼ同等。
- 候補C（K♣Q♦）: KはフロップのK♥をブロックする。相手のKxトップペア系をブロックするが、K♥はボードにあるため効果は限定的。
- 候補D（J♦T♣）: 特定のブロッカーなし。相手のフラッシュコールに対して最も脆弱。

この比較では、A♣Q♦やA♠Q♣が最も良いブラフ候補です。ただし、A♥Q♣であれば「A♥を持つことでナッツフラッシュを完全にブロック」できます。

### 実例: ナッツフラッシュブロッカーの最強ケース

```
ボード: K♥7♦2♣ A♥ 9♥（リバー：ハート3枚）

あなたのハンド: A♥Q♣（ナッツフラッシュのA♥を自分が保有）

→ 相手のナッツフラッシュ（A♥x♥）のコンボがゼロになる
→ 相手のフラッシュコールレンジは「ナッツ未満のフラッシュ」のみ
→ あなたのブラフに対して相手が「確信を持ってコール」できない
→ ブラフの期待値が大幅に上昇
```

A♥を持つブラフはこのボードで際立った優位性を持ちます。

## 8-5 コール判断にブロッカーを使う ─ 守備側の視点

第7章の後手スコア（MDF + ハンドクラス）でコールの基準が決まった後、ブロッカーは「そのハンドクラスの境界付近のコンボをどうするか」を微調整します。

### コールに有利なブロッカー（バリューブロッカー）

```
状況: 相手がリバーで75%ポットサイズのベット
後手スコアで「ブラフキャッチャーとしてコール圏内」と判断

→ さらにブロッカーチェック:
  自分が相手のバリューレンジをブロックしているか？
  → YES（バリューブロッカー）: 相手のバリュー密度が下がる → コールを強化
  → NO: 標準的な後手スコアに基づくコール
```

具体例を示します。

```
ボード: J♠T♣5♦ A♣ 2♠（リバー）
相手がポットベット。後手スコアで「ブラフキャッチャー」クラス。

自分のハンド: A♦8♦（Aのペア）

→ 自分がA♦を持つ → 相手のAx（AJ、AT等のバリュー）をブロック
→ 相手のバリューベット候補の一部が消える
→ 相手のベットがよりブラフに偏る傾向
→ A♦8♦でのコールが、ブロッカーなしのハンドより若干有利
```

### コールに不利なブロッカー（ブラフブロッカー）

逆のケースもあります。自分が相手の「ブラフになりやすいハンド」のキーカードを持つ場合、相手のブラフ率が下がります。

```
ボード: J♠T♣5♦ A♣ 2♠（リバー）
相手がポットベット。

自分のハンド: Q♦9♦（外れたOESD）

→ 相手の外れたストレートドロー（Q9等）の一部がブラフ候補
→ 自分がQ♦と9♦を持つ → 相手のQx・9xのドロー外れブラフが減少
→ 相手のベットがよりバリューに偏る
→ Q♦9♦でのコールが、ブロッカーなしのハンドより若干不利
```

ブラフブロッカーを持つ場合は、後手スコアの基準から見てコールが「ギリギリ」な場面では、フォールドに傾ける要因となります。

## 8-6 ダブルブロッカーの強力さ ─ 複合効果

1枚のカードで複数のブロッカー効果を同時に持つコンボを**ダブルブロッカー**と呼びます。これはリバー戦略で特に強力です。

### 例: 2スーテッドボードでのブラフ選択

```
ボード: K♥9♥4♣ 7♠ 2♦（リバー、ハート2枚で 4-flush 不成立、フラッシュ完成なし）

相手のバリューレンジ:
  ナッツ近辺: KK・99・44（セット）、K9・K4（ツーペア）
  強バリュー: AK・KQ（トップペア良キッカー）

あなたのハンド候補（いずれも「外れたフラッシュドローや弱ハンド」）:
  候補1: A♥J♥（ハートのフラッシュドロー外れ、A は kicker のみ）
    → A: 相手のAK等のバリューをブロック
    → J: 特に効果なし（ボードに J はない）
    → ショーダウン価値: A high のみ（HandScore 0）
  
  候補2: K♠T♣（K のブロッカー、ただし自分も Kペア）
    → K: 相手のKK・AK等をブロック
    → ショーダウン価値: K の 1 ペア（ボードに K あり）→ ブラフではなくバリュー
    → 注意: ブラフ候補にはせず、バリューベット
  
  候補3: A♣Q♦（A と Q のダブルブロッカー、ボードに絡まない）
    → A: 相手の AK 等のバリューをブロック
    → Q: 相手の QQ・KQ をブロック
    → ショーダウン価値: A high のみ（HandScore 0）
```

候補3の A♣Q♦ は「A と Q の両方でバリューブロッカー効果を発揮」する点でダブルブロッカーです。AK や KQ といった相手の主要バリューをそれぞれ削れます。さらに本ハンドはショーダウン価値ゼロ（A high のみ）で、ブラフに使うのに望ましい特性を持ちます。

逆に候補2の K♠T♣ は K のブロッカー効果はあっても、自分が K のペアを作っているため「バリューハンド」として評価すべきで、ブラフ候補には不適切です。「バリューを持つハンドをブラフに使う」のは EV を捨てる行為です。

### ダブルブロッカーの選択基準

ダブルブロッカーを持つコンボを同じ強度のコンボ群の中から選ぶ際は、次を確認します。

1. 2枚のカードが、異なる種類の相手のバリューをブロックしているか
2. 自分のハンドにショーダウン価値がないか（バリューをブラフにしない）
3. ブロックしているバリューが、相手のコールレンジの中心かどうか

## 8-7 ブロッカー判断の全体フロー ─ 4ステップ

第6章・第7章・巻5 第6章の判断を経た後、ブロッカーは「最終層」として機能します。この階層構造を4ステップで整理します。

```
ステップ1（第6章）: バレルスコアを計算して「打つか否か」を決める
  バレルスコア = FlopType係数 + TurnCard係数
  ≥7 → 積極バレル（方針確定）
  <7 → ハンド依存（強いハンドのみ）

ステップ2（巻5 第6章）: Alpha式でバリュー/ブラフの「比率」を決める
  Alpha = ベット ÷ (ポット + ベット)
  → 打つコンボの数（バリューN個 + ブラフM個）を設計

ステップ3（第7章）: 後手スコアで「コール/CR/フォールド」を決める
  後手スコア = MDFベース + ハンドクラス補正
  → 守備側がどの強度のハンドでコールするかを決定

ステップ4（本章）: 同強度のコンボ群の中からブロッカーで最終選択する
  → ブラフ候補: バリューブロッカーが強いコンボを優先
  → コール候補: バリューブロッカー保持は強化、ブラフブロッカー保持は抑制
```

この4ステップはあくまでも独立した判断です。ステップ4が影響するのは「同じ強度のハンドが複数ある場面」です。強度に大きな差があるなら、ブロッカーより強度が優先されます。

```
誤解の例:
  「弱い2ペアより外れたフラッシュドロー（ナッツブロッカー持ち）の方が
   ブロッカーが強いから、外れたドローをバリューとしてベットすべき」
   → 完全な誤り。強度の違いを無視している

正しい考え方:
  「同じ外れたドロー4通りのうち、どれをブラフとして選ぶか」という
   コンボ選択の場面でのみブロッカーが機能する
```

## 8-8 ブロッカーの限界 ─ 過信しないための視点

ブロッカーは有力な補助ツールですが、過信すると判断を誤ります。3つの限界を把握してください。

### 限界1: ブロッカーはレンジの一部しか削れない

フラッシュボードでA♥を持つことで、相手のナッツフラッシュはゼロになります。しかし相手のコールレンジはナッツフラッシュだけではありません。

```
相手のコールレンジ（フラッシュボード）:
  ナッツフラッシュ（A♥x♥）: あなたのA♥でブロック済み → 0
  セカンドナッツフラッシュ（K♥x♥）: ブロックされていない → 残存
  中位フラッシュ（Q♥x♥〜6♥x♥）: ブロックされていない → 残存
  セット・2ペア等の非フラッシュバリュー: ブロックされていない → 残存
```

ナッツをブロックしても、相手の他のコールハンドは残ります。「A♥があるからブラフ成功」という単純な思考は危険です。

### 限界2: 自分がバリューを持つ場合のアンブロッカー効果

あなたがAx（強いバリュー）を持つ時、相手のAx系ブラフも削れます。これは「コールした時に相手のブラフが少ない」ことを意味するため、実は相手のベットがよりバリューに偏っている可能性を示します。

バリューが強い時は素直にバリューとして扱い、「ブロッカーがあるからさらに強い」という二重の判断は必要ありません。

### 限界3: ストーリーの整合性がブロッカーより重要

フロップ・ターンのアクションと一貫したストーリーがないと、ブロッカーがあっても相手はコールしてきます。

```
例:
  フロップでチェック、ターンでチェック、リバーで突然大きなブラフ
  → A♥を持つ良いブロッカーでも、相手はストーリーの非一貫性から「ブラフ臭い」と感じる
  → コールされやすい状況になる

ブロッカーが最大限機能するのは、ストーリーが一貫している時だけ。
```

## 8-9 実戦でのブロッカー判断 ─ 5秒フロー

実戦では長時間の計算は不可能です。5秒以内で判断するための簡略フローを示します。

### ブラフ選択の5秒フロー

```
Q1: 複数のブラフ候補コンボがあるか？
  → NO（1種類しかない）: そのコンボでブラフ
  → YES（複数ある）: Q2へ

Q2: 相手のバリューの中心は何か（フラッシュ？セット？2ペア？）
  → 3秒で特定

Q3: その「相手のバリュー中心」をブロックするコンボはどれか？
  → ブロックしているコンボを選ぶ
```

この3問を5秒以内で処理します。Q2の「相手のバリュー中心の特定」が最も重要で、これが明確であれば自然にQ3の答えが出ます。

### コール判断の5秒フロー

```
Q1: 後手スコアで「コールが近い」ハンドか？（ボーダーラインのコンボか？）
  → NO（明確にコールまたはフォールド）: 後手スコアに従う
  → YES（ボーダーライン）: Q2へ

Q2: 自分は相手のバリューをブロックしているか？
  → YES: コールを強化（若干コールしやすい）
  → NO: 後手スコアの標準に従う

Q3: 自分は相手のブラフをブロックしているか？
  → YES: フォールドを強化（相手のベットがよりバリューに偏る）
  → NO: 後手スコアの標準に従う
```

Q2とQ3を同時に確認します。バリューブロッカーとブラフブロッカーを同時に持つ場合は、どちらの効果が相手のベットレンジに対してより大きいかを直感的に判断します。

---

## 8-10 第III部以降への橋渡し ─ 具体的な活用場面

本章で整理したブロッカーの概念は、第III部（ターン戦略）と第IV部（リバー戦略）の各章で実践的に登場します。

- **第9章（IPの攻撃）**: ダブルバレルのブラフ候補選択でバリューブロッカーを活用
- **第10章（OOPの応戦）**: コールかチェックレイズかの判断にブロッカーを加味
- **巻5（IPのリバー攻撃）**: リバーのブラフ選択でナッツブロッカーを優先する具体例
- **巻5（OOPのリバー応戦）**: MDFを満たすコール選択にブロッカーが寄与する場面

各章では「第6章・第7章・巻5 第6章の判断 → 第8章のブロッカーによるコンボ選択」という4ステップを実際のハンドで追います。第III部以降に進む前に、本章の4ステップ構造を確認しておいてください。

## ミニクイズ

### 問1

ボード K♥9♥2♣ T♥ 7♣（ハート 3 枚、フラッシュが完成している可能性のあるリバー）で、あなたはブラフを打つ方針（α 式で計算済み）。次の 2 つのブラフ候補コンボのうち、ブロッカー観点で優れているのはどちらで、その理由は何ですか（両者ともショーダウン価値はほぼゼロ）。

1. A♣Q♦（A と Q、ハートなし）
2. A♥Q♣（A♥ を保有、A♥ で相手のナッツフラッシュをブロック）

### 問2

後手スコアで「コール圏内のボーダーライン」と判断したハンドが2つあります。ブロッカー観点でどちらを選ぶか判断してください。

ボード A♠K♦Q♣ J♠ 2♣（リバー）。相手が75%ポットをベット。

1. Q♥T♦（Qの保有：Qxバリューをブロック、Tでストレートの一部をブロック）
2. 8♥7♦（ブロッカーなし）

### 問3

次の記述のうち、ブロッカーの使い方として正しいものはどれですか。

1. ブロッカーが強ければ、バレルスコアが閾値未満でもブラフを打てる
2. 同じ強度のコンボ群から選ぶとき、バリューブロッカーが強いコンボを優先してブラフとして選ぶ
3. コール判断では、ブロッカーはMDFの計算結果を大幅に覆す根拠になる

---

### 解答

- **問1**: 2（A♥Q♣ がブロッカー観点で優れる。ボードのハート 3 枚（K♥, 9♥, T♥）に対し、A♥ を自分が保有することで、相手の「A♥x♥」ナッツフラッシュコンボが物理的にゼロになる。一方、A♣Q♦ は A の非フラッシュペアブロッカーとして機能するが、ハート 3 枚ボードでは相手のコール基準は「フラッシュ」が中心であり、A の非フラッシュブロッカー効果は限定的。両者ともショーダウン価値が薄く、ブラフ候補として成立するが、ナッツフラッシュをブロックできる A♥ の効果が決定的に大きい）

- **問2**: 1（Q♥T♦を選ぶ。Qを保有することで相手のQx系バリュー（AQ、KQ等）をブロックし、Tでブロードウェイストレート（AKQJT）の一部をブロックする。相手のバリューが削れることで、相手のベットレンジ中のブラフ比率が相対的に上がる。8♥7♦はこのボードで特定のブロッカー効果を持たない）

- **問3**: 2（「同じ強度のコンボ群の中からバリューブロッカーで選ぶ」が正しいブロッカーの使い方。選択肢1はバレルスコアを無視した誤り。選択肢3はMDFを「大幅に覆す」とあるが、ブロッカーはあくまで微調整であり、MDFを根拠から変える力はない）

---

> **本章まとめ**
>
> - ブロッカーとは「自分が持つカードが相手のハンドを物理的に除外する」効果であり、リバーで特に重要度が増す
> - バリューブロッカーは攻撃側に有利（相手のコールレンジが弱まり、ブラフが通りやすくなる）
> - ブラフブロッカーは守備側に不利（相手のベットレンジからブラフが脱落し、コールの価値が下がる）
> - ブロッカーは「同じ強度のコンボ群の中から選ぶ最終層」。バレルスコア・Alpha式・後手スコアの判断結果を変えるものではない
> - ダブルブロッカー（2枚のカードが異なる種類の相手バリューを同時にブロック）は特に強力
> - 限界: ブロッカーはレンジの一部しか削れない。ストーリーの整合性・相手のレンジ全体の把握がより重要

---

**【GTOとのズレ】**

GTOは各コンボの期待値を個別に計算してブロッカー効果を正確に取り込んでいますが、人間が実戦で同じ精度を再現するのは不可能です。本章のブロッカー判断は「どのカードが相手のどのバリューを消すか」という方向性の把握を目標としており、数値の精確さよりも使える速さを優先しています。

実戦でGTOから外れやすいのは2点です。一点目は「ブロッカーがあるから打てる」という本末転倒の思考です。GTOはバレルスコアやAlpha式に相当する方針判断を先に完了させた上でブロッカーを活用します。方針なきブロッカー選択は、単なるギャンブルです。二点目は「ブラフブロッカー」の見落としです。コール判断でバリューブロッカーの有無は意識しやすい一方、自分が相手のブラフを削っているケース（ブラフブロッカー）は気づきにくく、過剰コールの原因になります。外れたフラッシュドローや外れたストレートドローのキーカードを自分が持つ場合、相手がそれらをブラフとして使えないことを意識してください。

また、ブロッカー効果は「相手がGTO的にプレイしている場合」に最大化します。相手がブラフをほとんどしない（タイトなバリューベットのみ）プレイヤーに対しては、ブロッカーを使ったブラフキャッチは機能しません。相手のプレイスタイルに合わせてブロッカーの有効性を調整することが、GTOから搾取的なアプローチへの橋渡しとなります。
