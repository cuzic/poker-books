# 第15章　3betポットのターン・リバー

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 3betポットではSPRが通常ポットの3分の1以下になることを理解し、バレルスコアと後手スコアを「3betポット補正込み」で使えるようにする。コミット判断の境界ハンドを状況別に整理する。

---

## 15-1 3betポットとは何か

プリフロップで「オープンレイズ → 3bet → コール」の流れが成立したポットを**3betポット**と呼びます。6-maxキャッシュゲームで典型的な数値を確認しましょう。

```
通常レイズポット（SRP）の例:
  BTN 2.5BB open → BB call
  フロップ開始時ポット: 5.5BB（スタック 97.5BB）
  フロップ SPR ≈ 17.7

3betポットの例:
  BTN 2.5BB open → BB 9BB 3bet → BTN call
  フロップ開始時ポット: 18.5BB（スタック 91BB）
  フロップ SPR ≈ 4.4
```

SPRが**約4**という数値は、本書 第13章で学んだ「SPR別コミット基準」でいえば「コミット検討ゾーン（SPR 3〜5）」に最初から突入している状態です。SRPではターン後にようやく「コミット検討ゾーン」に差し掛かるところを、3betポットではフロップ開始時点からそのゾーンにいます。

この違いが、ターン・リバーの戦略をどう変えるかが本章のテーマです。

---

## 15-2 SPRとストリート進行の構造

3betポットと通常ポットでは、各ストリートを経るたびのSPR推移が根本的に異なります。

### SPR推移の比較表

| ストリート | SRP（SPR推移） | 3betポット（SPR推移） |
|---|---|---|
| フロップ開始 | SPR ≈ 17.7 | SPR ≈ 4.4 |
| フロップ 50%CBet後 | SPR ≈ 8.0 | SPR ≈ 2.0 |
| フロップ 75%CBet後 | SPR ≈ 5.5 | SPR ≈ 1.4 |
| ターン 50%CBet後 | SPR ≈ 3.0〜4.0 | SPR ≈ 0.6〜0.9 |
| ターン 75%CBet後 | SPR ≈ 2.0〜3.0 | SPR ≈ 0.4〜0.7 |

3betポットでフロップ75%CBetが成立した後、ターンのSPRはすでに1.4です。ここからターンで50%ベットを打てば、リバーのSPRは0.6前後になります。**ターンのベットがほぼ「リバーオールイン宣言」と同義**になるわけです。

SRPでは「ターンで積み上げて、リバーで最終判断」という3ストリート戦略が成立しました。3betポットでは「フロップでコミットするかどうかを決め、ターンで完結」という2ストリート戦略に変わります。

### なぜ3betポットはコミット判断が早まるか

本書 第13章のコミット計算式（勝率 ≥ ポットオッズ）は3betポットでも同じように機能します。変わるのは「ポットオッズが計算上、各ストリートで変化する速度」です。

SRPではフロップの50%CBetに対するポットオッズは33%（= 1.75÷5.25 ≈ 33%）です。3betポットで同じ50%CBetに対するポットオッズも33%で変わりません。同じベットサイズなら同じポットオッズ。計算式は共通です。

違いはその後です。3betポットでコールを続けると、次のストリートでのポットはSRPより大きく、相手のベット額も（ポット比率が同じなら）絶対値が大きくなります。コールを続けるほど早いタイミングで「フォールドのコスト」が増大します。この構造が「3betポットでは判断を1ストリート前倒し」を要求します。

## 15-3 3betポットでのバレルスコア活用

バレルスコア（巻4 第6章）はSRP想定で設計されていますが、3betポットでも活用できます。ただし活用の仕方が異なります。

### SRPでのバレルスコア活用法

SRPでは「バレルスコア ≥ 7 → 積極バレル」という判定がそのままターンCBet頻度の方向性を示します。フロップ板タイプとターンカードの組み合わせだけで判断できます。

### 3betポットでのバレルスコア活用法

3betポットでバレルスコアを使うときは、スコアの閾値判断の**前に**コミット判断を挟みます。

```
3betポットのバレル判断フロー:

Step 1: コミット確認
  「このハンドでスタックを全額使ってよいか？」
  YES → Step 2へ（バレルスコアは補助として確認）
  NO  → チェックバック方向（積極的なバレルは避ける）

Step 2: バレルスコアの活用（コミット確定ハンドで、ベットサイズを決める参考に）
  スコア ≥ 7 → 大きめベット（75%〜）でバリューを最大化
  スコア < 7 → 小さめベット（33〜50%）またはチェックバックで均衡
```

コミット判断がYESのハンドは、バレルスコアが高ければ大きく打ち、低ければ小さく打って後のストリートに余地を残します。コミット判断がNOのハンドは、バレルスコアが高くても大きなバレルは打ちにくい状況です（負けた場合の損失が大きい）。

### バレルスコアが特に有効な場面

3betポットでも、**バレルスコアがブラフバレルの可否を教えてくれる**場面があります。

バレルスコアが高いということは、IP側のレンジ優位が大きく、ブラフを交えても相手が守りにくいことを示します。3betポットでドライ板（FlopType係数8）にOCターン（+3）= スコア11は、ブラフが成立しやすいボードです。逆にスコアが3〜5の場合、ブラフバレルは相手のコールレンジが広く成功しにくい状況を示します。

## 15-4 3betポットでのコミット判断

本書 第13章の「SPR別コミット基準」を3betポットに当てはめると、境界ハンドの位置が通常ポットと比べて大きく変化します。

### コミット判断の早見表（3betポット / フロップSPR ≈ 4.4）

| ハンドクラス | 3betポットでのコミット判断 | SRPでの判断（参考） |
|---|---|---|
| セット以上 | 即コミット | 即コミット |
| フラッシュ/ストレート（ナッツ） | 即コミット | 即コミット |
| 2ペア（トップ2） | コミット方向 | 状況依存 |
| 2ペア（弱め） | ポットオッズ確認（コミット寄り） | 慎重（フォールドも） |
| TPTK（AK, AQ等） | コミットの境界（状況依存） | 基本コール |
| TPGK（KQ, KJ等） | 慎重（状況依存） | SDV保護寄り |
| TPWK（KT以下） | フォールド寄り | フォールド/SDV保護 |
| 1ペア以下（弱ハンド） | フォールド方向 | フォールド/SDV保護 |

3betポットで最も注意が必要なのは**TPTK（トップペア・トップキッカー）**のコミット判断です。SRPではTPTKはほぼコール範囲ですが、3betポットではSPRが低いため「コールすると実質コミット」になります。ボードのナッツ構造と相手のレンジ次第でコミット判断が逆転します。

### TPTK のコミット条件

3betポットでTPTKをコミット方向に傾ける条件:

1. **ボードがドライ**: 相手がナッツ以上を持ちにくい。K72r上のAKはコミット寄り
2. **相手が3betレンジのブラフコンポーネントを多く持つ**: 相手の3betがポラライズされている場合、ブラフを多く含む
3. **ターンカードがIPに有利**: OCやペアが落ちてIPのレンジが強化された場合

逆に、3betポットでTPTKをフォールド/慎重方向に傾ける条件:

1. **ボードがウェット**: 相手がツーペア・セット・ドローを多く持てる
2. **相手が3betでバリューヘビー**: リーキーな相手でなく、強いハンドのみ3betしてくる場合
3. **ターンカードがOOP有利**: フラッシュ完成やコネクターでOOPのレンジが強化された場合

## 15-5 3betポットでの典型的なライン

SPRが低い3betポットでは、とるべきラインがSRPよりシンプルになります。

### ライン1: バリューコミットライン（最頻ライン）

強バリュー（2ペア以上）でのスタックオフを狙うラインです。

```
フロップ: 75%CBet（相手コール）
  → ポット ≈ 32.4BB、スタック ≈ 77.6BB → SPR ≈ 2.4

ターン: 75%ベット（スタックの30%強）
  → ポット ≈ 81BB、スタック ≈ 53BB → SPR ≈ 0.65

リバー: オールイン（53BB into 81BB ≈ 65%ベット）
  → ポットオッズ: 53÷134 ≈ 40%
  → 相手のコール要求勝率: 約40%
```

このラインは「フロップで意思決定を完了する」ことを前提にしています。フロップで75%CBetを打つ時点で、「ターンとリバーも打ち続ける」ことを前提とした判断になります。

### ライン2: 小ベット保守ライン（SDV保護）

1ペアの弱いバリューを守りながらショーダウンを目指すラインです。

```
フロップ: 33%CBet（コスト抑制）
  → ポット ≈ 24.4BB、スタック ≈ 84.6BB → SPR ≈ 3.5

ターン: チェックバック（オールインを回避）
  → SPRを維持したまま次へ

リバー: 薄いバリューベット（33〜50%）またはチェックバック
```

3betポットでこのラインをとるのは「スタックを全部使うほど強くない、でもショーダウンに価値はある」ハンドです。TPGK（トップペア・グッドキッカー）以下が対象になります。ただし相手がターンやリバーで大きくベットしてきた場合、コミット計算が必要になります。

### ライン3: セミブラフコミットライン

ナッツドロー（FD+OPD等）でスタックオフを狙うラインです。

```
前提: エクイティが40〜50%以上あるナッツドロー複合ハンド

フロップ: 75%CBet（フォールドエクイティ + ドロー価値）
ターン: 完成 → オールイン（ナッツバリューに転換）
      外れ → チェックバック（スタックオフを回避）

注意: 3betポットでは単純なFD（エクイティ約35%）だけでのセミブラフコミットは
      EV計算上難しい（本書 第13章の計算を参照）。複合ドロー（FD + OESD 等）が推奨。
```

## 15-6 BB視点での防御 ─ 後手スコアの3betポット補正

BB（OOP）として3betポットに入った後、IPのCBetに対する防御判断を後手スコアで行います。3betポット特有の補正を加える必要があります。

### 後手スコアの確認

```
後手スコア = HandScore + A − 3 − C − M

（HU前提のためM=0）

A（ボード値）: ドライ=3 / セミ=2 / ウェット=1
C（ベット負担）: 33%=3 / 50%=5 / 75%=7

後手スコア ≥ 8 → チェックレイズ（CR）検討
後手スコア 0〜7 → コール
後手スコア < 0 → フォールド
```

### 3betポットでの後手スコアの解釈変化

後手スコアの式自体は変わりませんが、3betポットでは**コールした後のSPRが極端に低い**ため、判断の「重み」が変わります。

SRPで後手スコア3がコール範囲だとしても、3betポットで同じ後手スコア3でコールすると、ターンでオールイン圏に入ります。後手スコアが示す「コール」は「スタックをどれだけ使うことを許容するか」まで含めて解釈する必要があります。

**3betポット版 後手スコアの実践ガイドライン:**

| 後手スコア | SRPでの行動 | 3betポットでの行動 |
|---|---|---|
| ≥ 8 | CR検討 | CR確定（SPR低いのでCR=コミット） |
| 5〜7 | コール（余地あり） | コール（ただしターンのコミット計算を要）|
| 0〜4 | コール（SDV保護） | 慎重コールまたはフォールド |
| < 0 | フォールド | フォールド（3betポットでは損切りを早く）|

### 3betポットでのCR判断

3betポットでのチェックレイズはほぼオールインを意味します。巻4 第10章で学んだ「CRのコスト計算」以上に、3betポットではCRの後に必ずコミットが確定します。

CR可能な条件は絞られます:

- セット以上（勝率が高く、コミットの正当性が明確）
- ナッツドロー複合（フォールドエクイティ + エクイティ）
- トップ2ペア（ボードがドライ、かつIPのレンジ上ナッツが少ない場合）

SRPでCRできていたミドルペア+バックドアドロー等は、3betポットでのCRに使うには弱すぎます。CRして相手にコールされると、コミット計算が大幅に不利になります。

## 15-7 3betポットvs通常ポット 判断比較

3betポットと通常ポットの判断の違いを整理します。

| 判断ポイント | 通常ポット（SRP / SPR≈17） | 3betポット（SPR≈4.4） |
|---|---|---|
| バレルスコアの使い方 | 直接ターンCBetの可否判断 | コミット判断の後に補助的に活用 |
| TPTK のコール | ほぼコール範囲（SDV保護） | 「コール = コミット開始」と認識。状況依存 |
| 2ペアのコール | コール（まだ余地あり） | コミット方向が自然 |
| セットのコール | コミット確定 | コミット確定（かつ早い） |
| フォールド基準 | TPWK以下が目安 | TPGK以下がフォールド候補に入る |
| チェックバックの意味 | SDV保護（有効な選択） | オールインを「意図的に回避」する選択 |
| ブラフバレルの頻度 | バレルスコアが示す通り | バレルスコアが示すより低め（失敗コストが大きい）|
| リバーオーバーベット | ポラライズ戦略として有効 | SPR的にほぼ不要（ターンでほぼ決着） |

特に重要なのは「チェックバック」の意味の変化です。3betポットでのチェックバックは「オールインを意図的に回避する戦略的選択」です。相手はチェックバックを「弱いハンド」のシグナルとして読みやすく、プローブベットで攻めてくるリスクがあります。バリューハンドのチェックバックは最小限にとどめ、バリューは積極的に積み上げる方が長期EVは高くなります。

## 15-8 実戦例

### 実戦例1: AAターンオールイン圏の判断

**セットアップ**: BTN vs BB。BTNが2.5BBオープン、BBが9BB 3bet、BTNがコール。ポット18.5BB、スタック91BB（SPR≈4.9）。

**フロップ**: K♥7♣2♦（ドライ）
- BTNハンド: A♠A♦
- ボード+ハンド確認: A♠, A♦（ハンド）+ K♥, 7♣, 2♦（ボード）= 5枚。Aが2枚（ハンド）+K1枚+7+2。役: ポケットAAのオーバーペア（ベスト5: A♠-A♦-K♥-7♣-2♦）。
- コミット判断: AAはK72rでほぼ最強のオーバーペア。相手BBの3betバリューレンジ（AA/KK/QQ/AK）に対して負けるのはKKのセットのみ。→ コミット方向

- BTN 75%CBet（13.9BB）→ BBコール
- ポット ≈ 46.3BB、スタック ≈ 77.1BB（SPR ≈ 1.67）

**ターン**: A♣
- ボード+ハンド更新確認: A♠, A♦（ハンド）+ K♥, 7♣, 2♦, A♣（ボード）
- Aのカウント: A♠（ハンド）+ A♦（ハンド）+ A♣（ボード）= 3枚 → セット of Aces（ポケットAAに同ランクA♣がボードに追加）
- ベスト5: A♠-A♦-A♣-K♥-7♣ = スリーカード（セット of Aces）
- ただしフルハウスではない（K1枚のみ）
- フラッシュ確認: クラブ A♣のみ、各スートに5枚なし → フラッシュなし
- ターンカード: A♣はOCターン（フロップ最高位Kより高い）。バレルスコア計算: ドライ(8) + OC(3) = 11 → 積極バレル確定。ただし3betポットのため、まずコミット判断。

- コミット判断: セット of Acesは最強クラス。相手のK72dターンA♣での勝率は圧倒的。SPR ≈ 1.67 → ターンで大きくベットしてリバーオールイン圏に持ち込む。

- BTN 75%ベット（34.7BB）→ BBコール（仮定）
- ポット ≈ 115.7BB、スタック ≈ 42.4BB（SPR ≈ 0.37）

**リバー**: 5♦（ブランク）
- ボード5枚確認: K♥, 7♣, 2♦, A♣, 5♦
- フラッシュ確認: ダイヤ 2♦, 5♦ = 2枚 → フラッシュなし
- ストレート確認: A-K-7-5-2 → 連続なし
- SPR ≈ 0.37 → BTNがオールイン（約42.4BBを約115.7BBポットに）
- BB視点でのポットオッズ: 42.4 ÷ (115.7 + 42.4) ≈ 27%
- BB側は27%以上の勝率があればコール（ほとんどのハンドでコール）

**学習ポイント**: 3betポットでフロップ75%CBet後、ターンで75%ベットを打つと、リバーSPRが0.37になりオールインは小さなベット比率です。BBはこのポットオッズ（27%）に対してほぼコールせざるを得ない状況になります。強バリューは早めに積み上げることが重要です。

### 実戦例2: TPTKのコミット判断（BB視点）

**セットアップ**: BB が BTN の 2.5BB open に 9BB 3bet。BTNコール。ポット18.5BB、スタック91BB（SPR≈4.9）。

**フロップ**: K♥7♣2♦（ドライ）
- BBハンド: A♣K♦（TPTK）
- ボード+ハンド確認: A♣, K♦（ハンド）+ K♥, 7♣, 2♦（ボード）
- Kのカウント: K♦（ハンド）+ K♥（ボード）= 2枚 → Kのペア（トップペア）
- A♣はエース（Kより高いが、ボード上にはAなし）= Aキッカー
- ベスト5: A♣-K♦-K♥-7♣-2♦ = トップペア・トップキッカー（TPTK）

- BBはチェック、BTNが50%CBet（9.25BB）→ BBのコール判断
- C = 50% → 5。A = ドライ（3）。HandScore（TPTK、A キッカー）= 18（巻2 正典）。
- 後手スコア = 18 + 3 − 3 − 5 − 0（HU） = **13** → コール範囲（CR 検討も視野）

- BBコール。ポット ≈ 37BB、スタック ≈ 81.75BB（SPR ≈ 2.2）

**ターン**: A♥
- ボード更新確認: K♥, 7♣, 2♦, A♥（4枚）
- ハンド+ボード全カード: A♣（ハンド）+ A♥（ボード）= Aが2枚 → Aのペア
- Kのカウント: K♦（ハンド）+ K♥（ボード）= 2枚 → Kのペア
- ベスト5の確認: A♣（ハンド）, A♥（ボード）, K♦（ハンド）, K♥（ボード）, 7♣（ボード）
  - = A♣-A♥-K♦-K♥-7♣ = 2ペア（Aces and Kings）with 7 kicker
  - A♥ペアターンによりTPTKが2ペア（AA & KK）に昇格。K♦（ハンド）+ K♥（ボード）のKペアも引き続き残る

- BTNがターン 75%ベット（27.75BB）
- C = 75% → 7。A = ドライ(3)。A♥ターンはOCカードで板がKドライのまま → 引き続きドライ。
- HandScore（2ペア, AA & KK、トップ2ペア）= 30（巻2 のセット以上区分）
- 後手スコア = 30 + 3 − 3 − 7 − 0 = **23** → CR 検討（≥ 8）

- しかし、SPR = 2.2 でターン 75% ベットにコールすると:
  - ポット ≈ 92.5BB、スタック ≈ 54BB → SPR ≈ 0.58 → リバーはオールイン圏

- BTNのレンジ考察: BTNの3betコールレンジ（AA/KK/QQ/JJ/TT/AKs/AQs/KQs等）でA♥ターンにここまで攻撃的なベットを打てるのは、AK（2ペアに昇格）、AA（既にセット）、あるいはKKなど。
  - A♥ターンで相手が2ペア（AK）や強いハンドを多く持つ可能性: BB の A♣が K♥7♣2♦+A♥ ボードの Aをブロック（A♣でAのコンボを減らす）
  - ブロッカー効果: BBが A♣を持つことで、BTNのAKのコンボ数が減少（本書 第5章参照）

- **コミット判断**: 2ペア（AA & KK）は非常に強い。SPR 0.58のリバーオールインに対するポットオッズは低くなる（コールしやすい）。コール → リバーコミット方向が正解。

**学習ポイント**: A♥ターンはTPTKをトップ2ペアに昇格させます。3betポットでも2ペア（AA & KK）は十分コミット圏に入ります。「ターンカードがハンドをどう変化させるか」を毎回確認することが重要です。

### 実戦例3: ペアターンでのhand evolution（IP視点）

**セットアップ**: BTN vs BB。3betポット18.5BB、スタック91BB（SPR≈4.9）。

**フロップ**: K♣Q♣2♠（スーテッド: クラブ2枚）
- BTNハンド: K♠Q♦（2ペア：KsとQs）
- ボード+ハンド確認:
  - Kのカウント: K♠（ハンド）+ K♣（ボード）= 2枚 → Kペア
  - Qのカウント: Q♦（ハンド）+ Q♣（ボード）= 2枚 → Qペア
  - ベスト5: K♠-K♣-Q♦-Q♣-2♠ = 2ペア（K's & Q's）
- FlopType: クラブ2枚（K♣Q♣）→ スーテッド（係数4）
- コミット判断: 2ペア（KK & QQ）→ コミット方向。ただしSPR≈4.9でまだ余裕あり

- BTN 75%CBet（13.9BB）→ BBコール
- ポット ≈ 46.3BB、スタック ≈ 77.1BB（SPR ≈ 1.67）

**ターン**: Q♥（ペアターン）
- ボード更新: K♣, Q♣, 2♠, Q♥
- ハンド+ボード全カード: K♠, Q♦（ハンド）+ K♣, Q♣, 2♠, Q♥（ボード）
- Kのカウント: K♠（ハンド）+ K♣（ボード）= 2枚
- Qのカウント: Q♦（ハンド）+ Q♣, Q♥（ボード）= **3枚** → Qのトリップス（ハンド1枚+ボード2枚）
- **ベスト5 更新**: Q♦-Q♣-Q♥-K♠-K♣ = **フルハウス（Q's full of K's）**
  - 3枚のQ（トリップス） + 2枚のK（ペア） = フルハウス確定
- ストレート確認: K-Q-Q-K-2 → 連続なし。フラッシュ確認: クラブ K♣, Q♣（ボード）= 2枚 → なし
- **ターン前後の手の変化**: 2ペア（KK & QQ） → フルハウス（Q's full of K's）

- バレルスコア: スーテッド(4) + ペア(4) = **8 → 積極バレル**。加えてコミット確定（フルハウス）。

- BTNがターン 75%ベット（34.7BB）→ SPR ≈ 0.37（リバーオールイン圏）

**学習ポイント**: Q♥ペアターンで2ペアがフルハウスに昇格しました。「K♠Q♦のまま」と思わず、ターンごとにhand evolutionを確認することが重要です。バレルスコアも積極バレル（8）を示しており、コミット判断とスコア判断が一致しています。

### 実戦例4: ブラフバレルの境界（スーテッド板+コネクターターン）

**セットアップ**: BTN vs BB。3betポット18.5BB、スタック91BB（SPR≈4.9）。

**フロップ**: T♠9♠8♣（コネクテッド: スペード2枚 → スーテッド/コネクテッドの重複）
- 分類: スペード2枚（T♠9♠）→ スーテッド優先（係数4）
- BTNハンド: A♦K♦（何もない。オーバーカード2枚のみ）
- ボード+ハンド確認: A♦, K♦（ハンド）+ T♠, 9♠, 8♣（ボード）
- ストレート確認: A-K-T-9-8 → 連続なし（K-T間にQJが必要）。5枚連続なし。
- ベスト5: A♦-K♦-T♠-9♠-8♣ = ハイカード（AK）
- コミット判断: AKに何も当たっていない。3betポットでブラフCBetを打てるか → 慎重

- BTNが33%CBet（6.2BB）→ BBコール（仮定）
- ポット ≈ 30.9BB、スタック ≈ 84.8BB（SPR ≈ 2.7）

**ターン**: J♠（コネクター + フラッシュの重複）
- ボード確認: T♠, 9♠, 8♣, J♠（4枚）
- J♠の分類: J♠はT-9-8-J → J-T-9-8 の4連続でOESD完成またはストレート完成を確認
  - Q+J-T-9-8 = ストレートドロー（Q待ち）
  - J-T-9-8+7 = ストレート完成（7待ち、8-9-T-J でOESD）
  - すでに J-T-9-8 で4枚連続 → 7かQでストレート完成 → OESD（コネクターターン）
  - さらに J♠でスペード3枚目（T♠, 9♠, J♠）→ フラッシュドロー成立
  - 優先順位: フラッシュ > コネクター → **フラッシュターン（係数1）**
  - バレルスコア: スーテッド(4) + フラッシュ(1) = **5 → ハンド依存**

- BTNのハンド（A♦K♦）: ターン確認
  - A♦, K♦（ハンド）+ T♠, 9♠, 8♣, J♠（ボード）
  - ストレート確認: A-K-J-T-9-8 = 6枚の中でK-J-T-9-8 → K-J間にQが必要。連続なし。
    - J-T-9-8: 4連続 → QかKでは完成？ K = J-T-9-8-K？ KはJより高い → K high straight（K-J-T-9-8）を確認: K(A), K, J, T, 9, 8 → 5枚連続: K-J-T-9-8 はK-Q-J-T-9... KとJの間はQ → 連続ではない
    - 正確に: K=13, Q=12, J=11, T=10, 9=9, 8=8。5連続は13-12-11-10-9、12-11-10-9-8 など。
    - 手持ちランク: A(14), K(13)。ボード: T(10), 9(9), 8(8), J(11)
    - 全ランク: 14, 13, 11, 10, 9, 8
    - 5連続の試み: 14-13-12-11-10 → 12なし。13-12-11-10-9 → 12なし。11-10-9-8-7 → 7なし。10-9-8-7-6 → 7,6なし。
    - → ストレートなし。フラッシュ確認: ダイヤ: A♦, K♦ = 2枚のみ → なし。
  - ベスト5: A♦-K♦... 実際の最善5枚: J♠-T♠-9♠-8♣ + A♦ = ハイカード（A high, ストレートドロー）
  - **AKはブランクのまま。スペードFDも保有していない。**

- 3betポットでのブラフバレル判断:
  - バレルスコア: 5 → ハンド依存（弱いハンドはチェックバック）
  - AKに何も当たっていない（役なし、ドローなし）
  - SPR ≈ 2.7 → ここでバレルを打ってBBにコールされるとオールイン圏に突入
  - **推奨: チェックバック。ブラフバレルは諦める。**

- リバー: BBがプローブベット → BTNはフォールド

**学習ポイント**: 3betポットのスーテッド板でコネクター+フラッシュターンが来た場合、バレルスコアは5（ハンド依存）を示します。役のないハンドでのブラフバレルは、SRPより慎重に判断する必要があります。3betポットでブラフが失敗するコストはSRPの3倍以上です。

### 実戦例5: セット対決のコミット計算

**セットアップ**: BTN vs BB。3betポット18.5BB、スタック91BB（SPR≈4.9）。

**フロップ**: K♣7♦2♠（ドライ）
- BTNハンド: 7♥7♠（セット: 7♥, 7♠のポケット + ボード7♦）
- ボード+ハンド確認:
  - 7のカウント: 7♥, 7♠（ハンド）+ 7♦（ボード）= **3枚 → セット of Sevens**
  - ベスト5: 7♥-7♠-7♦-K♣-2♠ = セット（Three of a Kind, Sevens）
- FlopType: K72r → ドライ（係数8）
- コミット判断: セット of Sevens → 即コミット

- BTN 75%CBet（13.9BB）→ BBがチェックレイズ（3bet）
- BB CR to 42BB（例）→ BTN のコール判断
- ポット ≈ 102.5BB、スタック ≈ 49BB（SPR ≈ 0.48）→ 実質オールイン圏

**ターン**: 7♣（ペアターン）
- ボード更新: K♣, 7♦, 2♠, 7♣
- ハンド+ボード全カード: 7♥, 7♠（ハンド）+ K♣, 7♦, 2♠, 7♣（ボード）
- 7のカウント: 7♥, 7♠（ハンド）+ 7♦, 7♣（ボード）= **4枚 → クワッズ（Four of a Kind）**
- ベスト5: 7♥-7♠-7♦-7♣-K♣ = クワッズ of Sevens

- コミット判断: クワッズ → コミット確定。即オールイン。

**実戦での数値**:
- ターン前ポット仮定: BTN コールのみで進んだとして、フロップ後ポット ≈ 46.3BB、スタック ≈ 77.1BB
- 7♣ペアターンで BTN がオールイン 77.1BB（into 46.3BB ≈ 166% オーバーベット）
- BB視点のポットオッズ: 77.1 ÷ (46.3 + 77.1) ≈ 63%
- BBが 63% 以上の勝率を持つハンドでのみコール正当化。クワッズ相手にそのようなハンドはほぼ存在しない。

**学習ポイント**: フロップでセットを持っている場合でも、ペアターンによりクワッズに昇格します。ハンドの強度が一気に増し、オールインが明確に正解になります。3betポットでは「フロップでコミット → ターンで最大化」という流れが自然に機能します。

### 解答

- **問1**: 1（フロップ75%CBet = 13.9BB → ポット46.3BB、スタック77.1BB。ターン後SPR = 77.1 ÷ 46.3 ≈ 1.67 ≈ 約1.4〜1.7の範囲。「SPR ≈ 1.4」が最も近い。ターン後はオールイン圏であることを認識する）

> **本章まとめ**
>
> - 3betポットのSPR≈4.4はフロップ開始時点から「コミット検討ゾーン」。フロップ75%CBet後のターンSPRは約1.4〜1.7
> - バレルスコアは3betポットでも活用できるが、「コミット判断（コミットするかどうか）→ スコア確認（どう打つか）」の順に使う
> - コミット基準はSRPより1段階早くなる: SRPでコールだったTPTKが、3betポットでは状況依存の境界ハンドになる
> - ペアターン等でのhand evolutionはSRPと同じく毎回確認。ターン後は「何の役」かを7を再確認することで判断の精度が上がる
> - 3betポットでのチェックバックは「オールインを意図的に回避する選択」。バリューハンドのチェックバックは最小限に
> - BBのCRは3betポットではほぼコミット確定。セット以上またはナッツドロー複合のときのみ使用

**【GTOとのズレ】**

3betポットでGTOが実際に採用するバレル頻度は、SRPより全体的に高い傾向があります。理由はSPRが低いため、「ベットして失敗してもリバーでの損失が限定的」かつ「フォールドエクイティの獲得効率が高い」からです。実戦ではSRPよりチェックバックを増やしてしまう傾向があり、3betポットでのバリューEVを取り逃がしています。

後手スコアの誤用もよく起きます。3betポットでBBが「後手スコアが5だからコール」と判断すると、コール後にリバーでオールイン圏に入ってしまい、さらに弱いハンドを続けることになります。後手スコアの数値だけでなく「コールした後のSPRと次のストリートのコミット計算」まで含めた判断が必要です。

コミット判断の境界ハンドとして最も難しいのはTPTK（例: AK on K高ドライ板）です。GTOではSPRに応じてTPTKをコミットする頻度が変化し、3betポットではSRPよりコミット頻度が高くなります。実戦では「TPTK=コールはするがコミットはしない」という感覚が染みついているため、3betポットで相手が大きく打ってきたときにフォールドしすぎる傾向が生まれます。SPRを確認してからコミット計算を行う習慣をつけることが改善の第一歩です。

**第16章への橋渡し**

本章では3betポット（BTN vs BB の構造）を主に扱いました。次の第16章では**SB vs BB**という特殊なポジション関係を扱います。SBとBBはともにブラインドポジションであるため、両者がOOPとなる要素が混在します。また、SBがリンプやオープンレイズをした場合のポットサイズや、BBが3betする頻度も異なります。3betポットの概念を引き継ぎながら、ポジション関係が複雑な場面での判断フローを学びます。
