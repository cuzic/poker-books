# 第9章　IPの攻撃 ─ バリューベットとブラフ

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバーでIPが持つ3つの選択肢（バリューベット・ブラフ・チェックバック）を体系化し、本書 第6章のα式と第5章のブロッカー論を組み合わせたリバー攻撃の判断フローを習得する。

---

## 9-1 リバーIPの3選択肢

巻4 第9章でターンのIPは「ダブルバレル・チェックバック・遅延CBet」という3つの選択肢を持つことを学びました。リバーでも同じく3つです。ただし、その内容は根本的に異なります。

本書 第1章で確認したとおり、リバーではセミブラフが消滅しています。ドローは完成したか失敗したかのどちらかです。ターンでは「セミブラフ」というドローとフォールドエクイティの複合が存在しましたが、リバーでその余地はありません。

```
リバーIPの3選択肢:

選択肢1: バリューベット
  コールされても高い確率で勝てるハンドでのベット
  目的: 相手の弱いコールから利益を搾り取る

選択肢2: ブラフ
  コールされると負けるが、フォールドさせれば利益になるベット
  目的: 相手の中程度のハンドをフォールドさせる

選択肢3: チェックバック（チェック）
  バリューを出せるほど強くなく、ブラフにも向かない中間ハンド
  目的: 安全にショーダウンに持ち込む／強いハンドでのトラップ
```

ターンでは「SDV保護」という第3のロールがありました。「チェックでリバーを安く見る」という価値がターンには存在したからです。リバーにはそのストリートがありません。チェックバックはそのままショーダウンか、相手の次のアクションへの対応になります。

リバーでの「中間ハンド」は、ターンのSDVとは役割が異なります。ターンのSDVはリバーに向かう「道中の保護」でしたが、リバーのチェックバックは「配分の最終判断」です。バリューを出せるかどうか、ブラフが機能するかどうかを自問した上で、どちらにも当てはまらない場合にチェックを選ぶという判断です。

## 9-2 バリューベットの判断 ─ 50%の法則

バリューベットの成否を決める核心は、「コールされて勝てるか」です。

本書 第6章で確認した50%の法則をここで実戦に適用します。

**バリューベットの必要条件: 相手のコールレンジに対して50%以上の確率で勝てること**

この基準はベットサイズに関係なく一定です。相手がコールしてきたとき、その相手のハンド群と比較して自分が勝ち越せるかどうかが判断軸です。

### ハンドを3層に分類する

リバーに到達した時点で、自分のハンドを次の3層に振り分けます。

```
層1（強バリュー）: コールレンジに対して70%以上の確率で勝てる
  → 75%〜100%ポットの大きなベット
  例: ナッツまたは準ナッツクラス、2ペア以上

層2（標準バリュー）: コールレンジに対して55〜70%程度で勝てる
  → 33%〜50%ポットの標準ベット
  例: トップペア強キッカー (TPTK)、良い2ペア

層3（薄いバリュー / チェックゾーン）: コールレンジに対して50〜55%前後の境界
  → 小さなベット（33%以下）、またはチェックバック
  例: トップペア弱キッカー、ミドルペア
```

「コールレンジに対して50%以上勝てるか」という基準を守る限り、ベットは利益になります。50%を下回る場面でバリューとして打つと、自分が損をしているのに利益だと思い込む誤りが発生します。

### バリューベットのサイズ選択

サイズは「相手のコールレンジの強さ」と「自分のハンドの強さのバランス」で決まります。

| ハンドの強さ | ベットサイズ | 理由 |
|---|---|---|
| ナッツ〜準ナッツ（セット以上など） | 75%〜100%pot または OB | 相手のコールレンジに広く勝てる。サイズを上げてもバリューが成立する |
| 強バリュー（強い2ペア、TPTK） | 50%〜75%pot | コールレンジの一定部分に負けるが、大半に勝てる |
| 標準バリュー（TPTK、弱い2ペア） | 33%〜50%pot | コールレンジの構成次第。小さなサイズで薄バリューを取る |
| 薄バリュー境界（50%台前半） | 33%以下またはチェック | 大きなサイズは逆効果。コールレンジが絞られ勝率が下がる |

大きなサイズのベットは「相手のコールレンジを絞り込む」効果があります。相手が75%ベットにコールするハンドは、33%ベットにコールするハンドより強いです。自分のハンドが「薄いバリュー」の場合、大きなサイズを選ぶと相手のコールレンジに対する勝率が下がります。薄バリューには小さなサイズが適切な理由はここにあります。

## 9-3 ブラフの判断 ─ α式からコンボ数を設計する

ブラフはコールされると負けるベットです。フォールドさせることで初めて利益になります。

本書 第6章で学んだα式を実戦で使います。

```
α = ベット額 ÷ (ポット + ベット額)
```

αは「ブラフの損益分岐点となるフォールド率」です。相手がαより高い頻度でフォールドすれば、ブラフはプラスEVです。

ただし実戦では「相手がどれくらいフォールドするか」を正確に読むことは難しいです。そこで均衡的な視点から「バリューとブラフの比率を正しく保つ」ことでブラフを設計します。

### V:B比率とブラフ上限の計算

本書 第6章の早見表を引用します。

| ベットサイズ | α（ブラフ比率上限） | 後手下限確率 | V:B比率 |
|---|---|---|---|
| 33% pot | 0.25（25%） | 0.75（75%） | 3:1 |
| 50% pot | 0.33（33%） | 0.67（67%） | 2:1 |
| 75% pot | 0.43（43%） | 0.57（57%） | 約4:3 |
| 100% pot | 0.50（50%） | 0.50（50%） | 1:1 |
| 150% pot（OB） | 0.60（60%） | 0.40（40%） | 2:3 |

バリューコンボの数が決まれば、ブラフの上限数を逆算できます。

```
ブラフ上限数 = バリューコンボ数 × α / (1 − α)

暗算の簡略版（V:B比率から直接計算）:
  33%ベット → バリューの1/3がブラフ上限
  50%ベット → バリューの1/2がブラフ上限
  75%ベット → バリューの3/4がブラフ上限（≒ 0.75倍）
  100%ベット → バリューと同数がブラフ上限
  150%ベット → バリューの1.5倍がブラフ上限
```

例: 75%ポットベット、バリューコンボ8個の場合。  
ブラフ上限 = 8 × (0.43 / 0.57) = 8 × 0.75 ≈ 6個。  
バリュー8個＋ブラフ6個以下が均衡的なベットレンジです。

## 9-4 ブラフ候補の優先順位 ─ ブロッカー論の適用

本書 第5章のブロッカー論で学んだとおり、同じ強度のコンボ群が複数あるときにどれを選ぶかがブロッカーの役割です。

ブラフ候補を選ぶ際の優先順位は次のとおりです。

| 優先度 | ブラフ候補のタイプ | 理由 |
|---|---|---|
| 最優先 | ナッツブロッカーを持ち、ショーダウン価値がほぼゼロ | 相手のコールレンジを物理的に削り、ブラフ成功率が上がる |
| 高 | 外れたフラッシュドロー（特にナッツスートのAハイ） | ショーダウン価値が低い。バリューブロッカー効果も期待できる |
| 中 | 外れたストレートドロー | ショーダウン価値が低い。フォールドしやすい相手向き |
| 低 | 弱いミドルペア（あわよくばショーダウン勝ちを狙える） | チェックバックの方がほとんどの場合EV優位 |
| 非推奨 | ショーダウン価値がある中程度のハンド | バリューを捨てる行為になる |

本書 第5章で確認した重要な原則を再掲します。

```
正しい使い方:
  α式でブラフを打つ方針が決まった → 複数のブラフ候補コンボが存在する
  → その中でバリューブロッカーが強いものを優先選択

誤った使い方:
  「バリューブロッカーがあるからブラフを打つ」
  → 方針判断（α式・レンジ分析）なしにブロッカーだけを根拠にする
```

ブロッカーはバレルスコア・α式の判断で決まった方針を「コンボ単位で微調整する」最終層です。方針を覆す根拠にはなりません。

### ブラフとして使ってはいけないコンボ

ショーダウン価値のあるコンボをブラフとして打つと、本来チェックバックで得られたはずのEVを失います。

```
例: ミドルペア（HandScore 10〜15程度）を75%ポットでブラフ
  → コールされた場合: 中程度の強さのコールハンドに負けるケースが多い
  → フォールドされた場合: もしチェックバックしていれば、相手がブラフしてくれて
    コール勝ちできた可能性がある
  → どちらに転んでもEVのロスが発生しやすい
```

ブラフに向くのは「コールされてもチェックバックでもショーダウン価値がほぼゼロ」のハンドです。

## 9-5 3バレルの設計 ─ フロップからリバーへの一貫性

3バレル（フロップCBet → ターンバレル → リバーバレル）はリバー攻撃の中でも最も強い形です。3ストリート連続して圧力をかけることで、相手のコールレンジは大きく絞られています。

### 連続性がもたらすナッツアドバンテージ

フロップでCBet、ターンでダブルバレルをした時点で、IPのレンジにはある傾向が生まれています。

- フロップで弱いブラフの多くはターンで消去されている（ターンで降りた、または断念している）
- リバーに到達したIPのベットレンジは「強いバリュー」と「強いブラフ候補（ブロッカーを持つもの）」に絞られている

本書 第2章で学んだUncappedレンジの概念がここで機能します。3ストリートを通じてベットし続けたIPは、リバーの時点で「大きく打てる権利」の裏付けを持っています。OOPは3ストリートのコールを経て、強いハンドか粘り強いブラフキャッチャーのどちらかでリバーに臨んでいます。

### バリューとブラフ比率のストリート推移

3バレルを75%ポットのサイズで統一する場合、各ストリートでの均衡比率は異なります。

```
フロップ: ブラフがバリューの約2倍（継続性を確保するため、ブラフが多め）
ターン:   ブラフとバリューがほぼ同比率（ドローの完成/外れで自然に絞られる）
リバー:   バリューがブラフの約1.3倍（α = 0.43、V:B ≈ 4:3）
```

フロップから順に「ブラフを絞っていく」イメージです。フロップでは多くのハンドに継続権を持たせ、ターンでドロー成分が整理され、リバーで確定的な配分になります。

### リバーに持ち込むべきハンドの選択

ターンバレルを打った後、リバーで継続するかどうかの判断は次の基準を使います。

```
継続の条件（バリュー）:
  リバーのボードで相手のコールレンジに50%以上勝てる → バリューとして継続

継続の条件（ブラフ）:
  (1) α式でブラフを混ぜられる余地がある
  (2) ブロッカーが有効（相手のコールレンジを削れる）
  (3) ストーリーの一貫性（フロップ・ターンのアクションと矛盾しない）

チェックバックへの転換:
  バリューとしては弱い（コールレンジに50%未満）
  ブラフとしても不適格（ブロッカーなし、ストーリー不整合）
```

ターンでバレルを打ったが、リバーでチェックバックに変更することはよくあります。これは「負け」ではなく、適切な配分判断です。

## 9-6 チェックバックの3用途

チェックバックには3つの明確な目的があります。これらを区別することで、「チェックは諦め」という誤解を防げます。

### 用途1: 薄バリューの保護

コールレンジに対して50〜55%程度しか勝てない「薄いバリュー」ハンドは、大きなサイズでのベットに向きません。チェックバックを選ぶことで2つの利点が得られます。

**利点A**: 自分が薄バリューのハンドをチェックバックすることで、相手はリバーのブラフをしにくくなります。「IPがチェックしたから弱い」と判断した相手が仕掛けてきたとき、中程度のハンドでコールして利益を得られる場合があります。

**利点B**: 相手のリバーベットに対して「チェックバックのレンジ」の保護になります。チェックバックするレンジが広ければ、相手は「IPがチェックした後の弱さ」を利用しにくくなります。

### 用途2: トラップ（遅延バリュー）

ナッツ級のハンドであえてチェックバックし、相手のブラフを誘う戦略です。

```
トラップが有効な条件:
  (1) 自分のハンドがナッツに近い（コールされても安全）
  (2) 相手がリバーでブラフベットしてくる傾向がある
  (3) チェックバック後に相手のアクションを待てるポット設計
```

ただしトラップは「相手がベットしてくれる」という前提に依存します。相手がチェックバックしてしまえば、大きなサイズでベットした場合と比べてポットは小さいままです。トラップは相手が攻撃的なプレイヤーの場合に有効性が増します。

### 用途3: 攻撃の放棄（ミスフィット）

バリューベットもブラフも適切でないと判断したとき、チェックバックは「現在のポットを守る」選択です。

```
攻撃の放棄が適切な状況:
  - 中程度の強さのハンド（ミドルペア、弱い2ペア）
  - 相手のコールレンジに対して50〜65%程度しか勝てず、薄いバリューでもない
  - ブラフとして打つブロッカー効果も弱い
  → チェックバックで「今のポット」を確保
```

## 9-7 サイズ選択フロー ─ α・ボード・ハンドから決定

バリューベット・ブラフ・チェックバックの方針が決まったら、次はサイズ選択です。

以下のフローで判断します。

```
Step 1: ハンドの役割を決める
  コールレンジに50%以上勝てる？
  → YES → バリューベット
  → NO → ブラフ候補かチェックか

Step 2（バリューベット): 勝率に応じてサイズを選ぶ
  70%以上 → 75%〜100%pot（またはOB）
  55〜70% → 33%〜50%pot
  50〜55% → 33%以下またはチェック

Step 3（ブラフ): α式でブラフを打てるか確認
  バリューコンボ数 × α / (1 − α) > 0 → ブラフ枠がある
  → ブロッカーで最良のコンボを選ぶ
  → サイズはブラフの目的（フォールドさせたい相手のハンド強度）で選ぶ

Step 4（サイズの微調整）: ボードのポラライズ度でサイズ調整
  ドライ板（静的）→ 33%〜50%（相手は弱いコールも多い、大サイズ不要）
  ウェット板（動的）→ 75%〜OB（ナッツアドバンテージを活かす）
```

### ドライ板とウェット板でのサイズ選択の違い

ドライ板では相手の全レンジに幅広く打てます。フラッシュもストレートも少ないため、相手は「負けていても降りにくい」コールを持ちやすいです。33%〜50%ポットで薄くバリューを取る戦略が機能しやすいです。

ウェット板ではナッツアドバンテージを持つ側が大きなサイズで圧力をかけます。フラッシュ完成やストレート完成が絡むリバーでは、相手のコールレンジが強い（フラッシュ保有者のみが残る）ため、自分がナッツを持つ場面での75%〜オーバーベットが機能します。

## 9-8 実戦例

### 例1: 標準バリューベット（75%ポット）

**状況**: BTN（IP）vs BB（OOP）。100BBキャッシュゲーム、6-max。

ボード: K♠T♥7♣（フロップ）+ 5♣（ターン）+ 2♦（リバー）  
最終ボード: K-T-7-5-2（スート: ♠♥♣♣♦、フラッシュなし）

ボード読み確認:
- フラッシュチェック: ♣ がボード上に 7♣, 5♣ = 2 枚。ハンドの K♣ を加えても 3 枚 → フラッシュ不成立（5 枚必要）
- ストレートチェック: ランク K-T-7-5-2。5連続を探す → K-T-7（gap多い）、T-7-5（gap）、7-5-2（連続性なし）→ ストレートなし
- ペアボード: すべてのランクが1枚ずつ → ペアボードなし

IPハンド: K♣Q♠  
ハンド + ボード: K♣, Q♠, K♠, T♥, 7♣, 5♣, 2♦  
役: K が 2 枚（K♣ + K♠）→ **トップペア、Q キッカー（TPGK：good kicker、Q ≥ Q）**

**判断プロセス**:

OOPがターン・リバーとチェックした想定（フロップCBetにコール、以降チェック）。

BBのコールレンジ（リバー到達）の推定:
- 強いハンド: KJ、KT（2ペア）、77、TT（セット系）、55、22（ターン/リバーでのセット）
- 中程度: KQ（TPTK、IP側のKQ自身がブロック）、T7（2ペア）
- 弱めのコール: AT、AK（強さあるがKを持つIPがブロック）

TPTK（K pair、Qキッカー）でのコールレンジに対する勝率の概算:
- 勝てる相手: AT、Tx系弱キッカー、Ax系（AはボードになくIPには有利）など
- 負ける相手: KT（2ペア）、77（セット）、TT（セット）、55（セット）、22（セット）

KQの場合、KTやKJにはKペア対決でQキッカーが機能する場面もあります。コールレンジに対して概ね60〜70%程度の勝率が見込める場合、**50%〜75%ポットのバリューベット**が成立します。

**選択**: 75%ポットベット

K♣Q♠はQキッカーがトップペアとして機能するため、BBがKをブロックしているハンド（KJ、KT）を除くと、Qキッカーが相手のKハンドを上回ることが多い。強バリューと判断。

---

### 例2: 薄バリューでのチェックバック

**状況**: BTN（IP）vs BB（OOP）。同上。

ボード: A♣K♦7♠（フロップ）+ 9♥（ターン）+ 2♣（リバー）  
最終ボード: A-K-9-7-2（スート: ♣♦♠♥♣、♣が2枚 → フラッシュなし）

ボード読み確認:
- フラッシュチェック: ♣が2枚（A♣, 2♣）→ フラッシュ不成立（5枚必要）
- ストレートチェック: A-K-9-7-2。AKQJT（broadway）はQJTが不足。9-7は9-8-7-6-5等もどれも5連続なし → ストレートなし
- ペアボード: すべてのランクが1枚ずつ → ペアボードなし

IPハンド: A♠5♠  
ハンド + ボード: A♠, 5♠, A♣, K♦, 7♠, 9♥, 2♣  
役計算:
- ♠ = A♠, 5♠, 7♠ = 3 枚 → フラッシュ不成立（5 枚必要）
- ランク: A=2, K=1, 9=1, 7=1, 5=1, 2=1
- best 5 = A-A-K-9-7（A ペア + ボードの K-9-7 が kicker、5 と 2 は使われない）
- 役: **A のペア（1 pair）、effective kicker は board の K**

重要: 5 は best 5 に入らない（ボードの K, 9, 7 の方が高い）。A5 のような low 弱キッカーペアでは、自分のキッカー（5）はほぼ機能せず、ボードカードがそのまま kicker になります。

**判断プロセス**:

A♠5♠ = A ペアは成立するが、effective kicker はボードの K まで。BB のコールレンジには AK（2 ペア）、AQ・AJ・AT（A ペア + ハンドのキッカーが Q/J/T のもの）が含まれます。これらは best 5 で K より高いキッカー（Q/J/T も A5 の 5 より高い）を持つため、A5 はキッカー負けします。

コールレンジに対する勝率:
- 勝てる相手: 77（セット → A-K-7のフロップで3ベット以降もコール残存）、KxやQx系の中程度のハンド、8x、6x
- 負ける相手: AK（2ペア）、A9（2ペア、ターン9でAとの2ペア）、A7、A2（ターン/リバーで2ペア化）、AQ・AJ・AT（同じトップペアでもキッカー負け）

このボードでA♠5♠のコールレンジに対する勝率は50%を大きく上回らない場合があります。「薄いバリュー」の境界に近い判断です。

- 33%ポットの小さなベットを試みることもできますが、コールしてくる相手（AK系2ペアなど）に対して勝率が低下するリスクがあります
- チェックバックにより安全にショーダウンを目指す選択が合理的です

**選択**: チェックバック

5というキッカーはAペアとしてコールされた場合、多くのAハイ系ハンドに負けます。薄いバリューとして33%ポットの小さなベットも選択肢ですが、相手が弱いコールをしてくれる確証が薄い場合、チェックバックでショーダウン価値を確保する判断が機能します。

### 例3: α式＋ブロッカー連動のブラフ

**状況**: BTN（IP）vs BB（OOP）。フラッシュ完成リバー。

ボード: K♥7♦2♣（フロップ）+ Q♥（ターン）+ 9♥（リバー）  
最終ボード: K♥, 7♦, 2♣, Q♥, 9♥  
スート確認: ♥ = K♥, Q♥, 9♥ = 3枚、♦ = 7♦ = 1枚、♣ = 2♣ = 1枚 → フラッシュ不成立（5枚必要）

ボード読み確認:
- フラッシュチェック: ♥3枚（K♥, Q♥, 9♥）。5枚同スートには♥があと2枚必要 → フラッシュ不成立。相手が♥を2枚持てばフラッシュが完成するため、フラッシュドロー保有者がコールレンジに残っている
- ストレートチェック: K-Q-9-7-2。K-Q（gap）、Q-9（gap）、9-7（gap）。5連続なし → ストレートなし
- ペアボード: 全ランク1枚ずつ → ペアボードなし

IPハンド: A♦J♣（Aのブロッカー、ショーダウン価値: Aハイのみ）

ハンド + ボード: A♦, J♣, K♥, 7♦, 2♣, Q♥, 9♥  
役計算:
- ♦: A♦, 7♦ = 2枚（フラッシュ不成立）
- ランク: A-K-Q-J-9-7-2。best5 = A♦, K♥, Q♥, J♣, 9♥ → **Aハイ（ペアなし）**
- ショーダウン価値: Aハイのみ（非常に限定的）

**ブラフの判断**:

ポットを60BBとします。フロップCBet → ターンバレルで積み上がった状況。リバーでブラフを打つかを検討します。

```
ベットサイズ候補: 75% pot = 45BB ベット
α = 45 / (60 + 45) = 45 / 105 ≈ 0.43

バリューコンボの推定（KK・QQ・77・22のセット、KQ・K9・Q9の2ペア等）: 8個とする
ブラフ上限 = 8 × 0.75 ≈ 6個
→ ブラフ枠が6個ある
```

A♦J♣はブラフ候補として適しているか？

**ブロッカー効果の確認**:

A♦を保有することで、相手のAx系バリュー（AK、AQ = このボードで2ペア）を削れます。A♦を保有するため相手のA♦を含むAKやAQのコンボが消えます。Aは4枚のうちA♦を自分が持つため、相手のAKのコンボは A♥K, A♣K, A♠K のみ（A♦Kが消える）に限定されます。

J♣を保有することで、JQや J9 系のブラフ候補（このボードでも限定的）を削ります。

このボードで相手の主なコールレンジは「セット、2ペア、フラッシュドロー保有者（♥2枚組）」です。A♦でAK・AQのコンボをある程度削れることは有効ですが、ハートをブロックしないためフラッシュドロー保有者のコールは削れません。

**ブラフ候補の比較**:

```
A♦J♣: Aブロッカーあり、ショーダウン価値ほぼゼロ → ブラフとして有効
J♦T♣: ブロッカーほぼなし → 相対的に劣る
5♦4♦: ブロッカーなし → 最も劣る

→ A♦J♣を選択
```

このシナリオでは、α式でブラフ枠が確保でき、かつA♦によるAx系バリューブロッカーが機能します。A♦J♣でのブラフは合理的な選択です。

**選択**: 75%ポット（45BB）ブラフ、コンボはA♦J♣を優先

ブラフが通れば60BBのポットを獲得。コールされてもAハイ程度のショーダウン価値であり、この「コールされると負ける」という性質がブラフの前提です。

**教訓**: ハートフラッシュ完成ボードでブラフを打つなら、ハートのキーカード（理想はA♥）を持つコンボが最強のブラフ候補です。A♥がなければK♥等でも一部のフラッシュをブロックできます。

### 例4: 3バレル設計（broadway 罠の回避）

**状況**: BTN（IP）vs BB（OOP）。フロップCBet → ターンバレル → リバー判断。

フロップ: K♦Q♣T♥（コネクテッド、3 ランク連続）  
ターンカード: J♠（4 連続 K-Q-J-T が成立、ストレートドロー大幅進行）  
リバーカード: 5♣（ブランク、5 連続にならないカード）

最終ボード: K♦, Q♣, T♥, J♠, 5♣

ボード読み確認（重要）:
- ストレートチェック: ボード単体のランク K-Q-J-T-5 → **4 連続（K-Q-J-T）+ 孤立した 5**。5 連続の straight にはハンドに **A か 9 が必須**
- ボード単体では straight 不成立
- フラッシュチェック: ♣ = Q♣ + 5♣ = 2 枚、♦ = K♦ = 1、♥ = T♥ = 1、♠ = J♠ = 1 → フラッシュ不成立
- ペアボード: 全ランク 1 枚ずつ → ペアボードなし

**重要**: ボード K-Q-J-T-5 は「broadway minus A」型。A を持つハンドは A-K-Q-J-T で broadway を完成させ、9 を持つハンドは K-Q-J-T-9 で K-high straight を完成させる。これらに勝つにはフラッシュ、フルハウス、クワッズ、または同じ broadway しかない。

**各ハンドの役**:

| ハンド | best 5 | 役 |
|---|---|---|
| A♥K♣ | A-K-Q-J-T | **broadway（ナッツ）** |
| A♣8♦ | A-K-Q-J-T | broadway（8 は使われない、A のみで成立） |
| 9♣8♦ | K-Q-J-T-9 | K-high straight（セカンドナッツ） |
| K♥K♣ | K-K-K-Q-J | trips K's（ストレートに負ける） |
| Q♣J♣ | Q-Q-J-J-K | 2 pair（Q's & J's、K kicker。ストレート不成立） |

注: K♥K♣ は K のセット（trips）だが、5 連続が成立しない（A も 9 もハンドにない）ため straight に負ける。ポーカーの役順では straight > trips。

**IP ハンド: A♥K♣（ナッツ broadway）の判断**:

A♥K♣ でリバー 5 が落ちると:
- best 5: A-K-Q-J-T = broadway（このボードでのナッツ）
- 相手も 9 を含むハンドで K-high straight を持つ可能性 → 相手はセカンドナッツでコールしてくる

**ナッツを持つ IP の選択**: バリューベット（75%〜100% pot）または OB。

セカンドナッツ K-high straight が相手のコールレンジに含まれるため、相手は大きなサイズでもコールしやすい。ナッツを持つ IP は最大サイズで最大限のバリューを引き出します。

**選択**: 100% pot（またはそれ以上のオーバーベット）

**broadway 完成ボードと混同しない**

仮にリバーが A だった場合（ボード K-Q-T-J-A）はボード単体で broadway 完成し、**全プレイヤー broadway = チョップ**になります（フラッシュやフルハウス可能性がない限り）。今回のボード K-Q-J-T-5 は **A も 9 もボードにない** ため、ハンドが straight 完成に貢献し、ナッツアドバンテージが意味を持ちます。リバーカードが「broadway 完成カード」か「broadway 補助カード」かでチョップとナッツが分かれる点に注意してください。

**ブラフ候補の選択**:

このボードでブラフを打つ場合、「ナッツ（broadway）と セカンドナッツ（K-high）をブロックするコンボ」が最良です。
- A を持つ → A 経由の broadway コンボを削る
- 9 を持つ → K-high straight コンボを削る

最強のブラフ候補は A9（broadway と K-high の両方をブロック、ショーダウン価値はハイカードのみ）。次点は A-X（X はストレートに無関係）や 9-X。

### 例5: フラッシュの5枚厳格判定

**状況**: BTN（IP）vs BB（OOP）。フラッシュ完成の判定確認。

フロップ: 9♥6♥3♣（ハート2枚でフラッシュドロー発生）  
ターンカード: 2♥（ハート3枚目）

ターン時点のボード: 9♥, 6♥, 3♣, 2♥  
ハートの枚数: 9♥, 6♥, 2♥ = 3枚 → **ターン時点ではフラッシュ不成立**（5枚中3枚。相手が♥2枚を持てばフラッシュ完成するが、相手のレンジにはフラッシュドローが多い段階）

**リバーカード: 7♥（4枚目のハート）**

リバー後のボード: 9♥, 6♥, 3♣, 2♥, 7♥  
ハートの枚数: 9♥, 6♥, 2♥, 7♥ = 4枚

4枚同スートでのフラッシュ判定:  
ボードに4枚ハートがある → **相手が♥を1枚でも持てばフラッシュが成立する**（ボード4枚 + 相手1枚 = 5枚同スート）  
逆に相手が♥をまったく持っていなければ、ボードの4枚のみ → フラッシュは相手のベスト5に入らない（同スートのカードは相手の手札にない）

実際には: **相手が♥を1枚でも持つならフラッシュ完成**。ただしそれは相手の手札依存であり、「4枚ボードがあるからフラッシュ完成」とは異なります。

**重要な概念の整理**:

| ボードの状況 | フラッシュ成立条件 |
|---|---|
| ハート2枚（フロップ） | 手持ちに♥2枚+ターン・リバーで♥1枚が必要（フロップ2+手持ち2=4枚のみではフラッシュ不成立） |
| ハート3枚（ターン） | 手持ちに♥2枚あればフラッシュ完成（ボード3+手持ち2=5枚同スート） |
| ハート4枚（リバー） | 手持ちに♥1枚あればフラッシュ完成（ボード4+手持ち1=5枚同スート）← **この状況** |

リバーに4枚目のハートが落ちた時点で、「♥を1枚でも持つハンド」がフラッシュを完成させています。

**IPの判断（A♠K♠を持つ場合）**:

ハンド + ボード: A♠, K♠, 9♥, 6♥, 3♣, 2♥, 7♥  
役: ♠はA♠とK♠の2枚のみ（フラッシュ不成立）。ランク: A-K-9-7-6-3-2 → best5 = A-K-9-7-6 = Aハイ（ペアなし）

A♠K♠はフラッシュを持たない。相手がハートを1枚でも持てばフラッシュに負けます。

**選択**: チェックバック（攻撃の放棄）

Aハイのみでこのボードにベットするとフラッシュ保有者にほぼ全員コールされます。ショーダウン価値はAハイのみ（非常に限定的）。チェックバックが合理的です。

もし A♥ を持っていた場合（例: A♥K♠）:  
ハンド + ボード: A♥, K♠, 9♥, 6♥, 3♣, 2♥, 7♥  
♥の枚数: A♥ + 9♥ + 6♥ + 2♥ + 7♥ = 5枚 → **ナッツフラッシュ（Aハイフラッシュ）完成**  
→ 大きなバリューベット（75%〜100%pot）が最適

この例が示すのは「4枚のハートが落ちたリバーでは、自分が♥を1枚持つかどうかで判断が180度変わる」という事実です。

## 9-9 リバー攻撃の5秒判断フロー

実戦でリバーに到達したとき、判断を5秒以内に完了させるためのフローをまとめます。

```
Step 1: 自分のハンドのリバー役を確定する
  → ハンド + ボード5枚で役を計算。ストレート・フラッシュは必ず5枚確認

Step 2: バリューかブラフかチェックか
  → 相手のコールレンジに50%以上勝てる？
    YES → バリュー（Step 3へ）
    NO → ブラフかチェック（Step 4へ）

Step 3（バリュー）: サイズ選択
  → 70%以上勝てる → 75%以上のサイズ
  → 55〜70% → 33〜50%のサイズ
  → 50〜55% → 33%以下またはチェック

Step 4（ブラフ/チェック）:
  → α式でブラフ枠がある？ → ブロッカー確認 → 最良コンボでブラフ
  → ブラフに不向き → チェックバック
```

## ミニクイズ

### 問1

ポット60BB、リバーで45BBベット（75%ポット）しようとしています。バリューコンボが10個ある場合、均衡的なブラフの最大数として最も近いものはどれですか。

1. 3個
2. 5個
3. 7個
4. 10個

### 問2

ボード A♥K♦Q♣J♠T♦（リバー、ボード単体で broadway 完成）で、IP がハンド 9♠8♣ を持っています。このハンドの役として正しいものはどれですか。

1. ストレートドロー（あと1枚でストレート）
2. K-high straight（K-Q-J-T-9、9 を使う）
3. broadway（A-K-Q-J-T、9 と 8 は使わない）
4. ペアなし（A ハイ）

### 問3

リバーでのブラフ候補として、ブロッカー観点から最も優先度が高いのはどれですか。フラッシュ完成ボード（ハート4枚）を前提とします。

1. K♦Q♣（Kとクラブのキッカー、ハートなし）
2. A♥2♣（A♥でナッツフラッシュをブロック、ただしA♥2♣はナッツフラッシュ保有者）
3. A♦J♣（Aのブロッカー、ハートなし、ショーダウン価値ほぼゼロ）
4. 8♦6♦（ブロッカーなし）

---

### 解答

- **問1**: 3（α = 45/(60+45) = 45/105 ≈ 0.43。ブラフ上限 = 10 × (0.43/0.57) = 10 × 0.75 ≈ 7.5個 → 約7個。75%ベットのV:B ≈ 4:3から、バリュー10個に対してブラフは7〜8個が上限）

- **問2**: 3（ハンド 9♠8♣ + ボード A♥K♦Q♣J♠T♦ の 7 枚: 9♠, 8♣, A♥, K♦, Q♣, J♠, T♦。ボード単体で A-K-Q-J-T = broadway が成立している点に注意。best 5 は最も高いストレートを取るため、A-K-Q-J-T（broadway） vs K-Q-J-T-9（K-high）では broadway が高い → best 5 = A-K-Q-J-T。手持ちの 9♠ と 8♣ は使われない。これは「board itself plays」の典型例で、すべてのプレイヤーが broadway を持つチョップボードになる。フラッシュやフルハウスの可能性がない限り、勝負はチョップになる）

- **問3**: 3（A♦J♣。A♦はAハイのハートフラッシュボードで相手のAx系バリューをブロックする効果があり、ショーダウン価値がAハイのみで低い。正解2（A♥2♣）はA♥を持つため実際にはナッツフラッシュが完成しており「バリューハンド」であってブラフ候補ではない。正解1（K♦Q♣）はブロッカー効果が弱い。正解4はブロッカーなし）

**【GTOとのズレ】**

本章で示したサイズ選択（勝率70%以上なら75%pot以上、など）は実戦の目安であり、GTOソルバーは各コンボのEVを全ハンドレンジとの相互作用で計算するため、人間の直感と異なる結果が出ることがあります。

最も典型的なズレは「強バリューを一種類のサイズに集める」という単純化による損失です。GTOでは同じナッツクラスのハンドでも、異なるサイズを混合することがあります。例えばセットを75%と150%の両方のサイズに割り当てることで、相手のコール判断を難しくします。人間が「ナッツ = 大きいサイズ」と単純化すると、相手はサイズからハンドを読みやすくなります。

もうひとつのズレは「薄バリューのラインの設定」です。「コールレンジに50%以上勝てるか」という基準は正しいですが、実際の相手のコールレンジを正確に推定するのは困難です。特に相手の混合戦略（一定頻度でコールと同時にフォールドを混ぜる）を想定すると、「50%」という数字は動的に変化します。GTOはこの相互作用を全て計算した上でのサイズ別の混合頻度を出力しますが、人間にとっては「相手のコールレンジを大まかに読んで50%を判定する」という近似で十分実用的です。

また、ブラフ候補の選択においても、GTOは本章で示した「ブロッカーで選ぶ」という優先順位以外の理由（混合バランスの維持、レンジの形を整えるため）でコンボを選ぶことがあります。全てのコンボを精密に計算したブロッカー効果の積み上げではなく、「全体のバランスを保つ」という観点から選ばれることも多いため、ブロッカー一辺倒の選択は過剰最適化になる場合があります。本章のブロッカー論は「複数の候補がある場合の微調整」として使い、方針判断（α式・レンジ分析）なしに適用しないことが重要です。
