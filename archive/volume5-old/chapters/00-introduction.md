## 本書の主題 ─ 「配分と確定」のゲーム

リバーはターンと似ているようで、根本的に異なります。

ターンではまだ1枚カードが残っています。フラッシュドローが完成する可能性があり、ストレートドローの当たりを期待できます。弱いハンドでも「将来価値」を持つため、ベットの目的にブラフ継続（セミブラフ）が加わります。

リバーでは、この将来価値が消えます。

```
ターン: ハンドの現在価値 + 将来価値（ドロー成分）
リバー: ハンドの現在価値のみ
```

すべてのハンドがここで役として確定し、「勝っているか負けているか」の二択になります。これがリバーの確定性です。確定性は戦略を単純化するように見えて、実は精密さを要求します。

リバーでの判断はつぎの2つに集約されます。

**配分** ─ 攻撃側（先手）は、どのハンドをバリューベット、どのハンドをブラフ、どのハンドをチェックに振り分けるかを決める必要があります。この比率はベットサイズによって数学的に決まります。その答えを暗算で出すのが、本書 第6章で導出する**α式**です。

**確定** ─ 守備側（後手）は、ベットに対してコールすべきかフォールドすべきかを確定させなければなりません。その判断基準が、本書 第7章で示す**後手スコア（リバー版）**です。

本書はこの2つの軸（配分と確定）をリバーの全戦術に貫きます。

## 本書で導入する3つの暗算式

本書は単独で読めるよう、リバーで使う3つの暗算式を本書の中で完全に定義します。

### α式（本書 第6章）

```
α = ベット額 ÷ (ポット + ベット額)
後手下限確率 = 1 − α
```

リバーでのバリューとブラフの最適比率を決めます。本書ではこのα式が全章の中心に置かれます。ベットサイズを変えればαが変わり、バリューとブラフの配分が変わる。この連動関係がリバー戦術の核心です。

### 後手スコア（本書 第7章）

```
後手スコア = HandScore + A − 3 − C − M
```

巻2で導入した後手スコアの式を、リバー用に再校正します。リバーではドロー加点が消え、C 値が拡張されます（100% = 9、150% = 11）。後手スコアが0以上ならコール、0未満ならフォールドが目安です。

### ブロッカー論（本書 第5章 基礎、第8章 実戦）

```
バリューブロッカー: 相手のバリューを削る
ブラフブロッカー:   相手のブラフを削る
```

特定のコンボを選ぶ「最終層」として機能します。同じ強度のハンド群があるとき、ブロッカーで最良のコンボを選別します。リバーで真価を発揮する概念です。

## 想定読者

本書は次のような読者を想定しています。

**シリーズ読者で、リバーの戦術を体系化したい方**。巻2（フロップ[基礎]）で学んだ HandScore・後手スコアの基本式を理解していれば、本書はスムーズに読めます。

**「リバーだけ強くなりたい」中級者**。巻4（ターン）を読まなくても、本書は単独で完結する設計です。リバー特化の本として手に取れます。「バリューベットをどのくらいの強さから打つべきか」「ブラフはどれだけ混ぜるべきか」「相手のベットにコールすべきか」という問いに、数値ベースで答えたい方に向けています。

**ブロッカーの真価をリバーで活かしたい方**。本書 第5章 ブロッカー基礎と第8章 ブロッカー実戦で、特定のコンボを選ぶ際に、どのハンドがブラフとして機能し、どのハンドがバリューとして機能するかの精密な選択を学べます。

## 読書ルートの推奨

### 標準ルート（推奨）

第1章から順に読み進めてください。リバー判断の土台（第I部）→暗算式（第II部）→リバー戦術（第III部）→応用シナリオ（第IV部）→統合と運用（第V部）の順で、理解が積み上がります。

### 暗算式が既知の方（巻4 既読、または巻2 後手スコアを使いこなしている方）

第I部・第II部は復習として軽く読み流し、第III部（第9章）から本格的に読み始めてください。第III部以降は α式と後手スコアを「すでに使える」前提で書かれています。

### リバー特化したい方

第I部の概念を読み、第6〜8章で式を確認したら、第III部の戦術編に進んでください。第IV部 応用シナリオは余裕があれば取り組む形でも構いません。

## 巻1〜4 との接続

本書は以下の概念・式を既習として進みます。不安な方は括弧内の参照先を先に確認してください。

**巻2で習得済みとして扱う概念**:
- 簡易レンジスコア（フロップのCBet頻度予測指標）
- HandScore（ハンドの強さ 0〜50）
- 後手スコア = HandScore + A − 3 − C − M（フロップ版）
- 後手下限の概念（後手下限ライン / 後手下限確率 / 後手下限スコアの3系統）
- Rule of 2 and 4（アウツからエクイティ計算）
- A係数（ドライ=3 / セミ=2 / ウェット=1）
- C係数（33%ベット=3 / 50%=5 / 75%=7）
- M係数（HU=0 / 3-way=3 / 4-way以上=6）

**巻4（ターン）の前提知識（本書では概念のみ参照、ターン戦術自体は不要）**:
- Capped vs Uncapped（レンジ強度の概念。本書 第2章で再導入）
- ナッツアドバンテージ（本書 第3章で再導入）

巻4（ターン）を読了している方は、本書 第I部・第II部はスムーズに進めます。未読の方も本書だけで概念と式を完成できる構成です。
