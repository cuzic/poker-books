# 第13章　ポットコミットメントとオールイン判断

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 「もうフォールドできない状態」を計算で判断し、コミット判断を感覚ではなく数値で下せるようにする。サンクコストの誤謬を排除し、「これからのコールEV」だけで判断する技術を習得する。

---

## 13-1 ポットコミットメントとは

ポーカーの実戦では、「もうこれだけポットに入れたから降りられない」と感じる場面があります。この感覚がポットコミットメントです。しかし感覚のままにコールを続けると、EV（期待値）上は損な判断を繰り返すことになります。

本章では**ポットコミットメントを数学的に定義し**、「コールすべき状態」と「フォールドすべき状態」を計算で判断します。

### コミット状態の定義

「ポットコミット状態」とは、次の不等式が成立している状態です。

```
コールEV ≥ フォールドEV

フォールドEV = 0（今のポットはあきらめ、それ以上の損益はゼロ）
コールEV = 勝率 × (ポット + コール額) − (1 − 勝率) × コール額
```

コールEVがゼロ以上であればコールが正しく、ゼロ未満であればフォールドが正しい判断です。

### 判断の主体は「これから」の損益

重要なのは、ポットコミットメントの判断に「これまでに入れた額」は一切関係しないという点です。フロップとターンで合計50BBを投入していたとしても、その50BBは「過去の損失」として確定しています。

リバーでフォールドしたとき、50BBは戻ってきません。しかし追加でコールする額に対する損益は、そこから先の数値だけで決まります。この区別が「コミット判断の鉄則」です。

## 13-2 コミット閾値の計算式

コールEV ≥ 0 の条件を数学的に整理すると、明確な閾値が導出されます。

### 数学的導出

```
コールEV ≥ 0
⟺ 勝率 × (ポット + コール額) − (1 − 勝率) × コール額 ≥ 0
⟺ 勝率 × ポット + 勝率 × コール額 − コール額 + 勝率 × コール額 ≥ 0
⟺ 勝率 × ポット − コール額 × (1 − 2 × 勝率) ≥ 0
⟺ 勝率 × (ポット + コール額) ≥ コール額
⟺ 勝率 ≥ コール額 ÷ (ポット + コール額)
```

最後の式の右辺は、巻1で学んだ**ポットオッズ**です。

```
コミット条件: 勝率 ≥ ポットオッズ（= コール額 ÷ (ポット + コール額)）
```

これで「コミット状態かどうか」の計算が完結します。ポットと相手のベット額がわかれば、コールに必要な最低勝率が即座に計算できます。

### ポットオッズの典型値

実戦でよく登場するベットサイズと、対応するポットオッズを確認しておきます。

| ベットサイズ（対ポット比） | コールに必要な最低勝率 |
|---|---|
| 33%（1/3ポット） | 25% |
| 50%（1/2ポット） | 33% |
| 75%（3/4ポット） | 43% |
| 100%（ポット相当） | 50% |
| 150%（1.5倍） | 60% |

たとえばポット相当ベットに対するコールは、勝率50%以上が必要です。この数値を「コミット閾値」として使います。

### 計算手順

実戦での計算手順は以下の3ステップです。

```
Step 1: ポットオッズを計算する
        ポットオッズ = コール額 ÷ (ポット + コール額)

Step 2: 自分のハンドの勝率を推定する
        相手のレンジに対して何%勝てるか（Rule of 2×2/4×4 も活用）

Step 3: 比較する
        勝率 > ポットオッズ → コールEV+（コミット状態）
        勝率 ≤ ポットオッズ → フォールドEV+（フォールド）
```

## 13-3 サンクコストの誤謬

数学的には明確なコミット計算ですが、実戦では感情的なバイアスが判断を歪めます。最も頻繁に起きるバイアスが「サンクコストの誤謬」です。

### サンクコストとは

「サンクコスト（sunk cost）」とは、すでに支出してしまって回収不能になったコストを指します。日常でも「もったいないから続ける」という判断ミスとして知られています。

ポーカーでは次のような形で現れます。

```
間違った思考:
「フロップとターンで合計 30BB 入れた。今さらフォールドしたら 30BB の無駄になる」

正しい思考:
「30BB は既にポットに入っており、コールしてもフォールドしても戻ってこない。
 今の判断基準は、これから追加でコールする額に対して勝率がポットオッズを超えるかどうかだけ」
```

### 数値で見るサンクコスト

具体的な例で確認します。

```
状況:
  これまでに投入: 30BB（サンクコスト）
  現在のポット: 80BB
  相手のリバーオールイン: 40BB

ポットオッズ: 40 ÷ (80 + 40) = 33%

自分のハンドの推定勝率: 28%

→ 勝率 28% < ポットオッズ 33% → フォールドが正解
```

「30BB 入れた」という事実は、この計算のどこにも登場しません。登場するのは「今からコールする40BB」と「ポット80BB」だけです。

### 「ポットが大きいほどコールしたくなる」症状

ポットが大きくなると、人間はコールに引き寄せられる傾向があります。「このポットを諦めるなんて」という感覚です。しかし**ポットの大きさはポットオッズを通じてすでに計算に反映されています**。

ポットが100BBあれば、相手が50%ベット（50BB）したとき、ポットオッズは50÷150≒33%です。ポットが200BBあれば、相手が50%ベット（100BB）したとき、ポットオッズは100÷300≒33%です。ポットが大きくても小さくても、ベットサイズが同じなら必要勝率は変わりません。

感情ではなく計算が判断を決めます。

## 13-4 SPRによるコミット判断の目安

実戦では毎回ポットオッズを精密計算する余裕がない場面もあります。そこで**SPR（スタック・ポット・レシオ）**を使った簡易判断が有効です。

SPRは「残りスタック ÷ ポット」で表される指標です。SPRが低いほど、次のベットでオールインに近づきます。

### SPR別のコミット基準

| ターン時点のSPR | 状況の性格 | コミット判断の目安 |
|---|---|---|
| SPR > 5 | スタックが十分 | コミット不要。バレルスコアとハンドクラスで判断 |
| SPR 3〜5 | ターンベット後がオールイン圏 | 2ペア以上でコミット検討。1ペア以下はSDV保護かチェックバック |
| SPR 1〜3 | ほぼオールイン状態 | セット以上でコミット確定。2ペアはポットオッズ確認。1ペア以下は基本フォールド |
| SPR < 1 | オールイン圏内 | ポットオッズと勝率の比較のみで判断 |

### SPR 2のターンを例に

```
状況:
  ポット 30BB, スタック 60BB（SPR = 2）
  IP が 75% ベット（22.5BB）→ ポット 75BB, スタック 37.5BB

リバーで相手がオールイン（37.5BB into 75BB = 50%ベット）:
  ポットオッズ: 37.5 ÷ (75 + 37.5) = 33%

OOP が 33% 以上の勝率があればコール EV+
  → セット: 約70〜80% → コール確定
  → ストレート/フラッシュ: 約75〜85% → コール確定
  → トップペア(TPTK): 約50〜55% → コール（33%を上回る）
  → 弱い2ペア（相手のレンジに多くのトップエンドがある場合）: 約45〜55% → 要確認
```

SPRが2のとき、1ペア以上のほとんどのハンドは「コール寄り」になることがわかります。この直感的な理解が実戦では重要です。

### SPR < 1のシナリオ

```
状況:
  ポット 80BB, スタック 80BB（SPR = 1）
  IP がオールイン 80BB（100% ポットベット）

ポットオッズ: 80 ÷ (80 + 80) = 50%

→ 勝率が 50% 以上あればコール EV+
→ 1ペア（推定勝率 40〜45%）: フォールド
→ 2ペア（推定勝率 55〜65%）: コール
→ セット以上（推定勝率 70%+）: コール確定
```

## 13-5 ターンでのオールイン判断（バリュー側）

ここからは「自分が強いハンドを持って相手のオールインに応じるかどうか」の判断を扱います。これをバリュー側のオールイン判断と呼びます。

### バリューオールインの条件

相手がオールインしてきた場合、コール判断はシンプルです。

```
コールすべき条件: 自分の勝率 ≥ ポットオッズ
```

実戦で注意すべきは「セットが勝率何%か」という具体的な数値の推定です。以下に典型的な勝率の目安を示します（6-max, 100BB, BTN vs BB のSRP想定）。

| ハンドクラス | 典型的な状況 | 推定勝率の目安 |
|---|---|---|
| ストレートフラッシュ・クワッズ | ほぼ全ての状況 | 95%以上 |
| セット（ドライ板） | K72r + ターンブランク | 約75〜85% |
| セット（ウェット板） | 987ss + フラッシュターン | 約60〜70% |
| ストレート/フラッシュ（ナッツ） | ほぼ全ての状況 | 約75〜85% |
| ストレート（非ナッツ） | 上位のストレートが存在する状況 | 約50〜65% |
| トップ2ペア | ドライ板でのターン | 約50〜60% |
| トップペア(TPTK) | セミウェット板でのターン | 約45〜55% |

### セットのオールインコール例

```
状況:
  ターン: A♠K♦Q♣7♥（フロップ A♠K♦Q♣ + ターン 7♥）
  ポット 25BB, 相手がオールイン 75BB

ポットオッズ: 75 ÷ (25 + 75) = 75%

自分のハンド: 77（セット of Sevens）
  ボード: A♠, K♦, Q♣, 7♥
  自分の手: 7, 7（ポケット） + 7♥（ボード） = セット of Sevens（best 5: 7-7-7-A-K）
  ※ 7♥はターンカード。ポケット77 + ボード7♥ = セット（ポケットペア + ボードで同ランク）。
  ※ 「トリップス」はハンド1枚 + ボード2枚同ランクの場合。ここはセットが正しい表記。

  このボードではKKがセット of Kings（K-K-K-A-Q）、QQがセット of Queens（Q-Q-Q-A-K）を持つ可能性がある。
  AAはセット of Aces（A-A-A-K-Q）最強クラス。
  AKや AQは2ペア。KQ は2ペア。
  77のセットは KK/QQ/AA のセット（いずれもランクが高い）に負けている。
  相手のオールインレンジ全体に対しては約40〜50%の勝率になる。

→ ポットオッズ 75% > 推定勝率 40〜50% → フォールドが EV+
```

このケースでは、セットであっても相手のオールインレンジが強く、フォールドが正解になります。「セットだからコミット」とは限りません。**ボードのナッツ強度と相手のレンジを加味した勝率**が判断基準です。

## 13-6 ターンでのセミブラフ・オールイン判断（ドロー側）

ドローを持ってオールインを検討する場面、すなわちセミブラフオールインの判断です。

### セミブラフオールインのEV計算

ドローでオールインする場合、EVは「フォールドエクイティ」と「コールされたときのエクイティ」の2成分で構成されます。

```
セミブラフOI のEV =
  FEQ × P              （相手がフォールドすれば現在のポットを獲得）
  + (1 − FEQ) × Eq × (P + B)  （コールされたとき、エクイティ×最終ポット）
  − B                  （ベット額のコスト）

FEQ: フォールドエクイティ（相手がフォールドする確率）
Eq:  コールされたときの自分の勝率
P:   現在のポット
B:   自分のオールイン額
```

### 計算例：ナッツフラッシュドロー（FD）でのオールイン

```
状況:
  ポット 30BB, 自分のスタック 60BB
  自分のハンド: A♥2♥（ナッツフラッシュドロー）
  ターン時点のFDエクイティ（リバーで完成確率）: 約20%（9アウト × Rule of 2）

FEQ = 40%（相手が40%フォールドすると推定）
Eq  = 25%（コールされたとき、FD + その他で約25%の勝率）

EV = 0.40 × 30 + 0.60 × 0.25 × (30 + 60) − 60
   = 12 + 13.5 − 60
   = −34.5BB → EV マイナス
```

単純なFDでのセミブラフオールインは、よほど高いフォールドエクイティがないと成立しません。

### フォールドエクイティが高い条件

セミブラフオールインが機能するのは、次の条件が重なるときです。

- 相手が明らかに弱いCBetをした（絞った1ペアコールレンジ）
- ドライボードで相手のコールレンジが狭い
- 自分のブラフ範囲が相手に読まれていない

FEQが60%に上昇しても、上記の例ではEVが改善します。

```
FEQ = 60%, Eq = 25%の場合:
EV = 0.60 × 30 + 0.40 × 0.25 × 90 − 60
   = 18 + 9 − 60
   = −33BB → まだマイナス
```

ナッツFDのリバーエクイティ約20%では、ほとんどの状況でセミブラフオールインはEVマイナスになります。セミブラフオールインが成立するのは、エクイティが50%前後あるナッツドロー複合ハンド（ナッツFD + OPD + バックドアST等）か、相手が高頻度でフォールドする場面に限られます。

## 13-7 コミットラインの実戦的な引き方

実戦で使いやすい「コミットライン」を整理します。

### SPR別コミット基準（実戦早見表）

```
SPR > 5:
  → コミット不要。バレルスコアとハンドクラスで判断
  → 2ペア以上: バレルスコアに従いベット
  → 1ペア以下: SDV保護またはチェックバック

SPR 3〜5（「コミット検討ゾーン」）:
  → 2ペア以上: コミット方向でベット（またはコールレイズ）
  → 1ペア（TPTK）: ポットオッズを確認してコール or フォールド
  → 1ペア以下（TPWK 以下）: チェックバックかフォールド

SPR 1〜3（「コミット圏」）:
  → セット以上: コミット確定（コールまたはレイズ）
  → 2ペア（トップ2）: コミット方向
  → 2ペア（弱め）: ポットオッズを計算して判断
  → 1ペア以下: 基本フォールド

SPR < 1（「オールイン計算のみ」）:
  → ポットオッズを計算し、勝率と比較するだけ
  → ハンドクラスの「感覚値」は補助にとどめる
```

### ハンド別コミット判断（ターン / 100BB ゲーム）

| ハンド | SPR 4 | SPR 2 | SPR 1 |
|---|---|---|---|
| ナッツ（SF, クワッズ） | コミット | コミット | コミット |
| セット | コミット | コミット | コミット |
| ストレート / フラッシュ | コミット | コミット | コミット |
| 2ペア（トップ2） | 状況依存 | コミット方向 | コミット |
| 2ペア（弱め） | 慎重（フォールドも） | 状況依存 | ポットオッズ確認 |
| トップペア（TPTK） | 基本コール | ポットオッズ確認 | ポットオッズ確認 |
| 1ペア以下（TPWK以下） | SDV保護 | ほぼフォールド | フォールド |

### TPTK のSPR別判断を数値で

TPTK（例：AK on KQ7r）の実戦的なEV計算を示します。

```
仮定:
  ハンド: A♦K♣（トップペア + トップキッカー）
  ボード: K♥Q♦7♣（ターン）

SPR 1の場合（ポット 80BB、スタック 80BB）:
  相手がオールイン 80BB → ポットオッズ 50%
  TPTK のレンジ勝率推定: 約52〜58%（相手のオールインレンジによる）

  勝率 55% > ポットオッズ 50% → コール EV+（わずかにプラス）
  ただしこれはレンジ推定が正確な場合。相手がバリューヘビーであれば逆転する。
```

SPR 1ではTPTKでもコールが正当化されうると理解しておきます。ただし「ほぼコミット圏」はあくまで勝率推定が前提で、相手の実際のレンジ次第で逆転します。

## 13-8 実戦例：コミット計算を実際に行う

### 実戦例1：ターンのフラッシュドロー vs オールイン

**状況:** BTN vs BB のSRP。フロップ T♥8♥6♣、BBがコール。ターン K♥。IPがオールイン。BBの手はJ♥9♥。

```
ボード確認（ターン4枚）: T♥, 8♥, 6♣, K♥
BBのハンド: J♥, 9♥

役の確認:
  スート別カウント:
    ハーツ: J♥, 9♥（ハンド）+ T♥, 8♥, K♥（ボード）= 5枚
    → ハーツ5枚 → フラッシュ完成（K-J-T-9-8 ハーツ）
  ストレート確認: J-T-9-8（4枚連続）+ K = ストレートなし
  → best 5: K♥-J♥-T♥-9♥-8♥ → ナッツ（ほぼ）フラッシュ

ナッツフラッシュ完成ハンドでのコール判断:
  ポット（例）30BB、スタック 70BB → SPR = 70/30 ≈ 2.3
  IPがオールイン 70BB（into 30BB = 233% オーバーベット）

  ポットオッズ: 70 ÷ (30 + 70) = 70%

  ナッツフラッシュの勝率（ターン完成済み）:
  相手がフルハウス/クワッズを持つ可能性を確認する。
  ボード: T♥-8♥-6♣-K♥ はペアが存在しない（4枚全て異なるランク）。
  KK on T♥-8♥-6♣-K♥: ポケットKK + ボードK♥ = セット of Kings（K-K-K-T-8 best 5）。
  ペアボードでないのでフルハウスは成立しない。
  TT/88/66 はそれぞれセットだが、やはりフルハウスにはならない。
  → 相手がフルハウスより上を持つ確率は低い
  → ナッツフラッシュの推定勝率: 約80〜90%

  勝率 85% > ポットオッズ 70% → コール EV+（コミット）
```

この例ではターンでフラッシュが完成しており、コミットが正解です。ドローのまま（フラッシュ未完成）でこのポットオッズに対峙するのと、完成後とでは判断が全く異なることに注意してください。

### 実戦例2：サンクコストの誤謬を見抜く

**状況:** BTN vs BB のSRP。フロップ A♠J♣8♦でBBがチェックコール。ターン Q♥でBBがチェックコール。リバー 2♦でIPがオールイン。BBの手はJ♥8♥（2ペア）。

```
ボード確認（リバー5枚）: A♠, J♣, 8♦, Q♥, 2♦
BBのハンド: J♥, 8♥

役の確認:
  J♥（ハンド） + J♣（ボード）= ジャック2枚
  8♥（ハンド） + 8♦（ボード）= エイト2枚
  → 2ペア（JJ と 88）
  best 5: A♠-J♣-J♥-8♦-8♥ = 2ペア（J's & 8's, A kicker）

  ストレート確認: A-Q-J-8-2 → 連続なし → ストレートなし
  フラッシュ確認: ハーツ J♥, 8♥(手)+スートを合わせたボードはA♠J♣8♦Q♥2♦
    ハーツ: J♥, 8♥, Q♥ = 3枚 → フラッシュなし（5枚必要）
    → ダイヤ: 8♦, 2♦ = 2枚 → フラッシュなし
  → best 5: A♠-J♣-J♥-8♦-8♥ = 2ペア（JJ and 88）

状況:
  フロップとターンで合計 30BB 投入（サンクコスト）
  リバーポット 60BB、IPがオールイン 60BB（ポット相当）

  ポットオッズ: 60 ÷ (60 + 60) = 50%

  2ペア（JJ and 88）のリバー勝率推定:
  IPのオールインレンジ = バリュー（A-Kハイの2ペア以上、セット、ストレート）+ ブラフ
  ブラフが少ないと仮定（典型的低レート）→ 勝率 約35〜40%

  勝率 37% < ポットオッズ 50% → フォールドが EV+

間違った思考: 「30BB も入れたからコールしよう」
正しい思考: 「30BB はサンクコスト。今からコールする60BB に対して37%の勝率では割に合わない」
```

### 実戦例3：SPR 1でのTPTKコール判断

**状況:** BTN vs BB のSRP。フロップ K♥Q♦4♣でBTNがCBet、BBコール。ターン 3♦でIPがターンベット。BBの手はA♠K♣（TPTK）。BBがコールするとポット80BB、残スタック40BB（SPR ≈ 0.5）。IPがリバーでオールイン。

```
ボード確認（リバー5枚）: K♥, Q♦, 4♣, 3♦, ??? (リバー未確定。ここではオールイン場面を設計)

状況:
  リバー：K♥Q♦4♣3♦7♠（例）
  ポット 80BB, IPがオールイン 40BB

ポットオッズ: 40 ÷ (80 + 40) = 33%

BBのハンド: A♠K♣
ボード: K♥, Q♦, 4♣, 3♦, 7♠

役の確認:
  K♣（ハンド） + K♥（ボード）= キング2枚 → トップペア（TPTK）
  A♠（ハンド）は Aキッカー
  ストレート確認: A-K-Q-7-4-3（手 + ボード）→ K-Q-7-4-3 = 5連続なし
  フラッシュ確認:
    スペード: A♠, (K♠?) → A♠ のみ → 1枚
    ダイヤ: Q♦, 3♦ = 2枚 → なし
    → フラッシュなし
  best 5: A♠-K♣-K♥-Q♦-7♠ = 1ペア（K's, A-Q-7 kickers）

TPTK のリバー勝率（ポット80BB時）:
  IPのオールインレンジ: 強バリュー（2ペア以上）+ ブラフ
  相手がブラフを混ぜているなら勝率は上がる
  一般的に33%のポットオッズは「コール要求勝率が低い」状況

  SPR ≈ 0.5 の少額コールだからこそ、33%という低いポットオッズになっている。
  TPTK の推定勝率: 約40〜50%

  勝率 45% > ポットオッズ 33% → コール EV+（コミット）
```

SPR < 1の状況でベット額が小さくなると、ポットオッズも下がります。TPTK程度のハンドでもコールが正当化される数値になりやすいのが、SPR < 1の特徴です。

### 実戦例4：セミブラフオールインの成否

**状況:** BTN vs BB のSRP。フロップ 9♥8♥7♣でBBがドンクベット、BTNがコール。ターン A♦。BBがオールイン50BBを打つ（ポット40BB）。BBの手は6♥5♥。

```
ボード確認（ターン4枚）: 9♥, 8♥, 7♣, A♦
BBのハンド: 6♥, 5♥

役の確認:
  ストレート確認: 9-8-7-6-5 = 5枚連続 → **ストレート完成**（9ハイストレート）
  フラッシュ確認:
    ハーツ: 6♥, 5♥（ハンド）+ 9♥, 8♥（ボード）= 4枚 → リバーなら完成可能、ターン時点では4枚
    → ターン時点でストレート + バックドアFD

  best 5（ターン）: 9♥-8♥-7♣-6♥-5♥ = ストレート（9-high straight）

この場合、BBの手はナッツストレート（6♥5♥ on 9-8-7 board）。
「セミブラフ」ではなく「ナッツバリュー」でのオールインが正解。

コミット判断:
  ポット 40BB, BBがオールイン 50BB
  BTNのコールオッズ: 50 ÷ (40 + 50) = 55%
  BTN がコールするには勝率 55% 以上が必要

  BB（6♥5♥）の視点: ナッツストレートを持ち、BTNにコールを求める。
  BTN が T6 を持てば T-9-8-7-6 = テンハイストレートで BBを上回る（頻度は低い）。
  ただし、それ以外の相手ハンドに対しては BBのナッツ（9-high straight）が勝つ。
  → BTN がコールしてもBBの勝率は高い → BBはオールインすべき
```

この例は「セミブラフと思いきや実はナッツバリュー」のケースです。手牌とボードを精確に確認してからオールインを打つ、という原則の重要性を示しています。

## ミニクイズ

### 問1

ポット 40BB、相手がオールイン 40BB。自分の推定勝率は 42%です。コールすべきですか。

1. ポットオッズ 50%、勝率 42% < 50% → フォールドが EV+
2. ポットオッズ 33%、勝率 42% > 33% → コールが EV+
3. ポットオッズ 40%、勝率 42% > 40% → コールが EV+（わずかにプラス）

### 問2

フロップとターンで合計 45BB 投入済み。リバーでポット 90BB、相手がオールイン 45BB（50%ベット）。自分の手はブロックされたストレート（勝率推定 38%）。コールすべきですか。

1. 45BB 入れたのでコールすべき（もったいない）
2. ポットオッズ 33%、勝率 38% > 33% → コールが EV+
3. ポットオッズ 50%、勝率 38% < 50% → フォールドが EV+（45BB は無関係）

### 問3

SPR 1.5 のターン。自分のハンドはセット（J♠J♦ on J♥K♦8♣ → ターン 4♥）。相手がオールイン。ポットオッズは 40%。セットの推定勝率は 70% です。どうすべきですか。

1. ポットオッズ 40% < 勝率 70% → コール EV+（コミット）
2. セットは強いがコールに慎重になるべき
3. SPR 1.5 なら自動フォールド

---

### 解答

- **問1**: 1（コールオッズ = 40 ÷ (40 + 40) = **50%**。勝率 42% < 50% → フォールドが EV+。選択肢2・3はポットオッズの計算が間違っています）
- **問2**: 2（ポットオッズ = 45 ÷ (90 + 45) ≈ **33%**。勝率 38% > 33% → コールが EV+。45BB 投入済みはサンクコストで判断に無関係。ただし「ブロックされたストレート」は実際のレンジ上の勝率が変わりうるため、相手レンジを精査すべきです）
- **問3**: 1（J♠J♦ on J♥K♦8♣-4♥でターン。セット of Jacksの確認: ハンドJ♠J♦+ボードJ♥=3枚のジャック → セット確定。4♥はブランクでボードを壊さない。ポットオッズ 40% < 勝率 70% → コールEV+）

---

> **本章まとめ**
>
> - コミット判断の基準は「勝率 ≥ ポットオッズ（= コール額 ÷ (ポット + コール額)）」の1式だけ
> - サンクコスト（これまでに入れた額）は判断に一切関係ない。今からのコールEVのみで決める
> - SPR < 1ではポットオッズと勝率の計算だけで判断。SPR 1〜3ではセット以上がコミット圏
> - セミブラフOIはFEQが非常に高い場合を除きEVマイナスになりやすい。ナッツドロー複合ハンドに限定するのが安全
> - 「ポットが大きいからコールしたい」感情を排除し、計算結果だけを信頼する

---

**【GTOとのズレ】**

GTOでは「勝率 ≥ ポットオッズ」というコミット閾値は正確に機能します。しかし実戦でGTOとのズレが生じる原因は主に3点あります。

第1に、相手のオールインレンジの推定精度です。GTOは「レンジ vs レンジ」で計算しますが、実戦では相手のオールインレンジを正確に読むことが難しい。低レートでは相手がバリューヘビーにオールインすることが多く、「GTOではコールEV+」でも実戦ではEVマイナスになるケースが頻発します。GTOのコミット閾値を使う場合、相手のレンジをどう読むかで大きく結果が変わります。

第2に、セミブラフOIの判断です。GTOソルバーはFEQを正確に計算した上でセミブラフの最適頻度を出します。人間が感覚でFEQを見積もると過大評価しがちで、「フォールドしてくれると思ってオールインしたらコールされた」が繰り返されます。計算上のEVを都度確認する習慣が必要です。

第3に、ポットコミットの「空気感」への依存です。「SPR 1だからコールが当然」という思考停止は危険です。SPRはあくまで目安であり、実際のコール判断はポットオッズと勝率の数値比較が正確です。SPRが低くても、ポットオッズを超えない勝率のハンドはフォールドが正解です。「SPR低い＝コミット」という等式は成立しません。
