# 序章　GTOの外側で稼ぐ

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> 相手が偏っているなら、こちらも偏っていい。
> 大事なのは、偏りの方向と量を間違えないことだ。

---

## 「負けない戦略」と「稼ぐ戦略」は別物である

ポーカーを真剣に学び始めたとき、多くのプレイヤーは「GTO」という言葉に出会います。GTO（ゲーム理論最適、Game Theory Optimal）とは、相手がどんな戦略を取ってきても搾取されない均衡戦略です。言い換えれば、GTO は「負けない戦略」です。

しかし「負けない」と「稼ぐ」は同じではありません。

GTO は相手が均衡戦略を完全に実行していることを前提に設計されています。GTO 対 GTO の対戦では双方のEVはゼロサムになります。そのため GTO を完璧に実行できても、期待利益はゼロです。収益が生まれるのは、相手が GTO から逸脱したときだけです。

現実のテーブルに座る相手は、ほぼ全員が GTO から大きく逸脱しています。コールしすぎる相手、降りすぎる相手、ブラフしすぎる相手——これらの偏りを無視して GTO で返し続けることは、稼げる機会を自ら捨てていることに等しいのです。

エクスプロイト（exploit）とは、相手の偏りを観察し、その偏りに乗じて EV（期待値、Expected Value）を最大化する戦略です。偏りが大きい相手ほど、エクスプロイトで得られるリターンは大きくなります。

GTO Wizard の実測データによれば、相手の偏りに合わせて戦略を最適化することで、ハンドあたり 0.8〜1.4bb の追加 EV が得られます。小さな数字に見えるかもしれませんが、6-max テーブルで 1 時間あたり 30〜40 ハンドをこなすライブゲームでは、この差がセッション全体の利益を左右します。月単位で積み重なれば、エクスプロイトの有無が黒字プレイヤーと赤字プレイヤーを分ける分岐点になります。

## 式の閾値は「均衡値」である

『迷わないポーカー』シリーズを読んだ方は、以下の式と閾値を覚えているはずです。

```
プリフロップスコア = H + L + ボーナス + ブロッカー − ペナルティ
```

T_open（オープンレイズの閾値）は、UTG=24、HJ=22、CO=20、BTN=18、SB=22 と定められています。フロップでは HS（ハンドスコア）と B（ボードスコア）を組み合わせた T1/T2/T3 の 3 ティアで CBet の判断を行います。T1（HS≥65）は常時 CBet、T2（HS≥20、B≥58）はボードが良ければ CBet、T3（HS<20、B≥62）はブラフ CBet の範囲です。

これらの数値は何を意味しているのでしょうか。

答えは「均衡値」です。GTO に近い相手に対して、搾取されずに戦えるよう設計されたパラメータです。しかし相手が均衡から外れているなら、こちらも外れていい——いや、外れるべきです。

たとえばコーリングステーション（広くコールする相手）が多いテーブルでは、BTN の T_open を 18 から 15〜16 に下げ、バリューハンドの参加範囲を広げることで追加 EV を取れます。逆にマニアック（ほぼ全ベット・全参加の相手）が左隣にいる場合は、T_open を 18 から 26〜28 まで引き上げ、強いハンドのみで参加する戦略が最適になります。

フロップでも同様です。コーリングステーションが相手なら T3（ブラフ CBet）は使わず、T2 の B 閾値を下げてバリューの網を広げます。ニット（降りすぎる相手）が相手なら、T3 の B 閾値を B≥62 から B≥55 まで緩め、ブラフの頻度を高めます。

本書はこの「閾値の移動」を体系的に扱います。どのタイプに対して、どの方向に、どれだけ移動させるか——それが本書全体の核心です。

## エクスプロイトの核心：方向と量を間違えない

閾値を動かすこと自体は難しくありません。難しいのは、方向と量を正確に判断することです。

**方向の誤りは、何もしないより損です。**

同じ「コールしすぎる相手」に対しても、間違った方向に調整すると損失になります。コーリングステーションに対してブラフを増やすのは誤った方向への調整です。相手はコールしてくれるからこそ、ブラフは成立しません。正しい方向はバリューベットを増やし、ブラフをゼロに近づけることです。

間違えた方向への調整——たとえばコーリングステーション相手にブラフを多用すること——は、GTO を忠実に守るよりも大きな損失をもたらします。間違えたエクスプロイトは「正しいエクスプロイトをしないこと」よりも悪い結果を招くのです。

**量の過剰調整も危険です。**

GTO Wizard の分析によれば、相手のコール頻度が 2% 変化するだけでブラフの最適頻度は劇的に変わります。これは「少しの偏りでも大きな調整が正当化される」ことを意味しますが、同時に「調整しすぎると今度は自分が搾取される側に回る」ことも意味します。

たとえばニット相手にスチールを増やすことは正しい方向への調整です。しかし T_open を 18 から 8 まで下げると、ニットが参加してきた場合のハンドレンジが弱すぎてポストフロップで機能しません。適切な調整幅は −3〜−5 程度です。

本書では各章の末尾に「やりすぎ注意」のコーナーを設け、過剰調整の落とし穴を具体例と数値で明示します。エクスプロイトは「相手の偏りの大きさに比例して調整する」ものです。偏りを確認する前に大幅な調整をするのは、地図なしで山に入るようなものです。

## 会話：タイプを知ることが先決だと気づいた瞬間

ある夜のライブゲームでのことです。

🔰 **真田**は BTN でポケットナインを持ってオープンしました。BB の 🎯 **岡田**がフラットコールし、フロップは A♠K♦7♣。岡田がチェックすると、真田は迷わず 3/4 ポットの CBet を打ちました。岡田はコールします。

「ハンドスコアは…HS=30、ボードスコアは B=67。T3 のブラフ CBet 条件は HS<20 だから、T2 で考えるべきだった。でも打ってしまった」と真田は内心で後悔しながら、ターンの 2♥ を見ます。岡田がまたチェックします。

真田は続けてセカンドバレルを打ちました。岡田はまたコールします。リバーで A♥ が落ちると、岡田が大きくベットしてきました。真田は長考した末にフォールドしました。

セッション後、真田は隣にいた 💻 **林**に話しかけました。

「あの場面、HS と B を計算して打ったんですが…フロップの判断は合っていたんでしょうか？」

林は少し考えてから言いました。「計算の前に、岡田さんがどんなプレイヤーかを確認するべきでした。あの時間帯、岡田さんはずっとコールを繰り返していましたよね。レイズは一度もなかった。」

真田はハッとしました。確かにそうでした。岡田は着席してからの 1 時間、ほとんどすべてのハンドでコールしていました。

林が続けます。「コーリングステーションが相手なら、T3 のブラフ CBet は使いません。相手はコールしてくれるんです。打つとしたらバリューだけです。A♠K♦7♣ のフロップで 99 はバリューではないので、チェックバックが正解でした。」

岡田が聞いていて笑いながら言いました。「正直に言うと、私は今日ずっとコールしていました。理由はどうでもよくて、コールしていた、それが事実です。それを 1 周で読み取れれば、式を当てはめる前に答えが出ます。」

真田は静かに頷きました。

「式を知っている。閾値も覚えている。でもその前に、相手が誰かを知らなければ、式を向ける方向が分からない…。」

そのことに、真田はそのセッションで初めて気づいたのでした。

## エクスプロイトの流れ：4 ステップ

本書が提案するエクスプロイトの実行フローを整理します。

```
ステップ 1：観察（行動・サイズ・ライン・ショーダウン）
         ↓
ステップ 2：タイプ分類（ニット / CS / TAG / LAG / マニアック）
         ↓
ステップ 3：偏りの特定（コールしすぎ / 降りすぎ / ブラフしすぎ）
         ↓
ステップ 4：閾値調整（T_open / T3 / CR 閾値 / ベットサイズ）
```

ステップ 1〜3 が「診断」に当たります。本書の第 1 部（第 1〜4 章）で扱います。ステップ 4 が「エクスプロイト実行」です。第 2 部（第 5〜10 章）でタイプ別に詳述します。

この 4 ステップは順番が重要です。ステップ 3（偏りの特定）をスキップして即座に閾値を調整することは、分析なしに薬を処方するようなものです。相手の偏りを特定できていれば、閾値の調整値は自然と決まります。

また、ステップ 4 は一度決めたら終わりではありません。ショーダウンや行動の変化によって偏りの推定が更新されたら、閾値もその都度調整し直します。エクスプロイトは「設定して忘れる」ものではなく、セッションを通じて継続的に更新していくプロセスです。

## エクスプロイトと GTO を使い分ける

GTO を捨ててエクスプロイトだけで戦えばいいか、というと、そうではありません。エクスプロイトと GTO は目的に応じて使い分けるものです。

相手のタイプが分からない序盤、あるいは相手が TAG でほぼ GTO 近似の行動をしている場合は、GTO に近い均衡戦略が最善です。相手の偏りが特定できていないのに閾値を動かすのは、誤った方向への調整を招くリスクがあります。

相手のタイプが確認でき、偏りが明確になった時点から、エクスプロイトに切り替えます。ニット相手が確認できた BTN では T_open を 18 から 13〜14 まで下げ、コーリングステーション相手が確認できたポストフロップでは T3 ブラフをゼロにする——このように、相手ごとに設定を変えていきます。

6-max テーブルでは 6 人それぞれが異なるタイプであることがほとんどです。実際のテーブルでは、左隣がニット、右隣がコーリングステーション、正面がマニアックということも起こります。それぞれの相手に対して個別の閾値を設定し、ハンドごとに「今の相手は誰か」を確認してから式を当てはめていく作業が、エクスプロイトの実体です。

## 本書の使い方：タイプを診断してから該当章を開く

本書は診断から始まります。エクスプロイトは「相手のタイプが分かってから始まる」ものです。タイプを確認せずに調整を始めると、方向を誤るリスクが高まります。

本書の構成は以下の通りです。

**第 1 部「診断」（第 1〜4 章）** では、5 つのプレイヤータイプを定義し、ライブとオンラインでの見分け方を解説します。Tell（行動・サイズ・ライン・身体・会話）の信頼度を整理し、早期分類の危険（第 4 章）まで扱います。観察の精度が、エクスプロイトの精度を決めます。

**第 2 部「タイプ別エクスプロイト」（第 5〜10 章）** が本書の中核です。タイプ別に、プリフロップスコアの閾値をどう動かすか、フロップの T1/T2/T3 の判断をどう変えるか、ターン・リバーのサイズをどう選ぶかを、具体的な数値と実例で示します。各章は独立して読めます。

**第 3 部「状況別エクスプロイト」（第 11〜14 章）** では、プリフロップ・フロップ・ターン・リバーのストリート別の調整をまとめます。

**第 4 部「テーブル全体の EV 管理」（第 15〜17 章）** では、席選び・アイソレート・ゲームの環境維持という、1 ハンドを超えた視点を扱います。

**第 5 部「精度向上と実戦」（第 18〜21 章）** では過剰調整の罠、オンライン特有のエクスプロイト、実戦クイズ、観察ノートテンプレートを収録します。

タイプが特定できている場合は第 2 部の該当章から直接読み始めてください。タイプが分からない場合は第 1 章から読み進め、診断精度を上げてから第 2 部へ進んでください。

## 観察ノートを手元に置いて読む

本書を最も効果的に使う方法は、実際のセッションと並行させることです。

読書中に「このタイプに似たプレイヤーが昨日テーブルにいた」と思ったら、そのプレイヤーについて記録してみてください。以下の 3 点を書くだけで十分です。

1. そのプレイヤーの仮タイプ（ニット / CS / TAG / LAG / マニアック）
2. 自分が実施したエクスプロイト（T_open を何に変えたか、CBet したかどうかなど）
3. 結果：機能したか、しなかったか、分類を修正すべきか

この記録が積み重なると、自分の分類精度の傾向が見えてきます。「自分は CS を過剰に TAG と分類している」「ニットの CBet を尊重しすぎている」といった自分固有のバイアスを発見することが、精度改善の出発点です。

本書の第 21 章に「観察ノートのテンプレート」を収録しています。タイプ別チェックリストと式の歪め方早見表は 1 ページにまとめてあります。セッション中の参照に使ってください。

エクスプロイトは知識ではなく習慣です。本書を読んで「なるほど」と思っても、実戦で繰り返し使わなければ定着しません。10 ハンドに 1 回でいいので「今の相手のタイプは何か」「閾値を動かすべきか」と自問する習慣をつけてください。

## 本書の位置づけ：シリーズ内での役割

**本書の前提**:
本書は Vol2 (Cash Postflop + Light UCBS/DCBS) または Vol3 (MTT Postflop + Full UCBS-v2) で扱う **GTO ベースの計算式** を出発点に、相手のプレイヤータイプに応じて exploit する書です。CBS / HP / DP / UCBS-v2 / DCBS などの用語は Vol2/Vol3 で定義済みです。

本書（Vol4）はシリーズの締めくくりとして、Vol1〜Vol3 で学んだ式と閾値を「均衡値」として活用しながら、実際のプレイヤーの偏りに合わせて調整する方法を体系化しています。

- **Vol1 Preflop** を読んでいれば、プリフロップスコア式・T_open 閾値・3bet/4bet の考え方は既知です。
- **Vol2 Cash Postflop** を読んでいれば、T1/T2/T3 のフロップ判断・C 値・DCBS の概念は既知です。
- **Vol3 MTT Postflop** を読んでいれば、UCBS-v2・ICM 補正・Push/Fold 判断は既知です。

**本書のみを読む場合**：Vol1〜Vol3 のいずれも未読でも、巻末の付録 B「シリーズ式のおさらい」で全式を参照しながら読み進めることができます。ただし、式の導出背景や GTO 理論の詳細は Vol1〜Vol3 を参照してください。

## 本書が前提とすること

本書は『迷わないポーカー』シリーズの締めくくりとなる第 4 巻です。以下の概念は既知として扱います。

- プリフロップスコア式と T_open 閾値（各ポジション）
- フロップの T1/T2/T3 ティア と CBet 判断
- CBet サイズ C 値（33%→12 / 50%→17 / 75%→22 / 100%→25 / 150%→30）
- SPR 別 CR 閾値（SPR≥6→HS≥40 / SPR3〜5→HS≥60 / SPR<3→HS≥75）
- フォールド閾値（33%ベットに対して HS<15 / 50%に対して HS<25 / 75%に対して HS<35）

シリーズを読んでいない方は、巻末の付録 B「シリーズ式のおさらい」で全式をまとめています。本書を読みながら都度参照してください。

本書の想定ゲーム環境はシリーズ全体と同じく、6-max、100BB 深さ、キャッシュゲームです。トーナメント特有の ICM 調整や Push/Fold 判断は Vol3 MTT Postflop + Full UCBS-v2 を参照してください。

## まとめ

- GTO は「搾取されない」戦略であり、「最大限稼ぐ」戦略ではない
- 相手が GTO から逸脱しているなら、こちらも逸脱することで追加 EV を得られる（ハンドあたり 0.8〜1.4bb の実測値）
- 本書のスコア閾値は「均衡値」——タイプに応じて意図的に動かす
- エクスプロイトの核心は「方向」と「量」を誤らないこと。方向を誤ると何もしないより損になる
- 実行は 4 ステップ：観察 → タイプ分類 → 偏り特定 → 閾値調整
- 本書はタイプを診断してから該当章を読む設計になっている
- 観察ノートと組み合わせて、実戦と読書を並行させること

次章では 5 つのプレイヤータイプを定義し、オンラインとライブそれぞれでの識別方法を解説します。
