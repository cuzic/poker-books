# 第2章　ライブでのタイプ診断：行動編

*対象: 🔰🎯*

---

## はじめに：行動は嘘をつかない

ライブポーカーでは、相手がどのプレイヤータイプかを数ハンドで見極めなければなりません。
しかしHUDも履歴もない環境で、どうやって診断すればいいのでしょうか。

答えはシンプルです。「行動を観察する」ことです。

プリフロップで何回参加するか、コールかレイズかどちらで入るか、フロップでベットを継続するかチェックするか。
これらの行動パターンは、長年のプレイ習慣から生まれた「無意識のルーティン」です。
意識的にコントロールするよりずっと難しく、だからこそ信頼できる診断材料になります。

本章では、プリフロップ・ポストフロップ・タイミング・ショーダウンの4つの観察ポイントで、相手のタイプを絞り込む方法を解説します。

---

## 1. プリフロップで分類する

プリフロップは、タイプ診断の最初の窓口です。
ベットやショーダウンに比べて隠しにくく、ハンド数が多いため統計が早く貯まります。

### 1-1. オープン頻度：何ハンドに1回参加するか

テーブルに座ったら、まず「この人は何ハンドに1回オープンするか」を数えましょう。

| 参加頻度の目安 | 推定タイプ |
|------------|---------|
| 10ハンドに1〜2回（10〜20%） | ニット / TAG |
| 10ハンドに2〜3回（20〜30%） | TAG / LAG |
| 10ハンドに4〜5回（40〜50%） | コーリングステーション |
| 10ハンドに6〜7回以上（60%+） | マニアック |

正確なVPIPを計算する必要はありません。
「頻繁に参加している」「ほとんど参加しない」という感覚的な区別だけで、最初の仮分類は十分です。

### 1-2. リンプ頻度：コールかレイズかで受動性を見る

オープン方法に注目してください。
リンプ（コール）が多いプレイヤーは、ルースパッシブ（コーリングステーション）かニットのどちらかである可能性が高くなります。

- **リンプが多い（全参加の50%以上がリンプ）**：ルースパッシブ（LP / コーリングステーション）
- **リンプがほぼない（ほぼ全てレイズかフォールド）**：ニット、TAG、LAG、マニアック

リンプ率は「受動性の指標」です。
オープンレイズとリンプの比率を見るだけで、アグレッシブかパッシブかを素早く区別できます。

### 1-3. 3ベット頻度：アグレッシブさの証明

他プレイヤーのオープンに対して3ベットを打つ頻度を観察します。

| 3ベット頻度の目安 | 推定タイプ |
|--------------|---------|
| ほぼなし（10ハンドに0〜1回） | ニット / コーリングステーション |
| 時々あり（10ハンドに1〜2回） | TAG |
| 頻繁にあり（10ハンドに3〜4回） | LAG |
| 非常に多い | マニアック |

3ベットはコストが大きいため、パッシブなプレイヤーはほとんど打ちません。
「この人はあまり3ベットしない」と分かった時点で、LAGやマニアックの可能性をほぼ排除できます。

### 1-4. フォールドの速さ：即フォールドはタイプを語る

フォールドするときのスピードにも注目してください。

- **即フォールド（1〜2秒）**：事前にフォールドを決めていた。プリフロップレンジが狭い。ニット / TAG
- **少し考えてフォールド**：ボーダーラインのハンドを持っていた可能性がある
- **長考してフォールド**：コールを検討した。やや広いレンジだが降りを選んだ

即フォールドの多いプレイヤーは、スタートハンドの選択が厳しいニットかTAGです。
「この人はほぼ毎回すぐフォールドする」と気づいたら、スチールの対象として記録しておきましょう。

## 2. ポストフロップで分類する

プリフロップで仮分類したタイプを、ポストフロップの行動で検証・修正します。
ポストフロップはプリフロップより複雑ですが、より精度の高い情報が得られます。

### 2-1. CBet頻度と継続性：T1/T2/T3のどこで止まるか

コンティニュエーションベット（CBet）の頻度と、何ストリートまで打ち続けるかを観察します。

本シリーズ読者に馴染みの深いCBetの3ティアを使って整理すると、タイプの違いが鮮明になります。

| CBetパターン | よくあるタイプ |
|-----------|------------|
| ほぼ毎回CBetし、3ストリートとも打ち続ける（T1〜T3全て使用） | LAG / マニアック |
| フロップだけCBet、ターン以降はチェック | ニット / TAG |
| ほとんどCBetしない | コーリングステーション |
| 不規則（ある時は打ち、ある時はチェック） | TAG（均衡型） |

「T3まで打つ」——つまりバリューが低い（HS<20）ハンドでもボードカバレッジ（B）が高ければCBetを続ける——行動が見られたら、LAGかマニアックを強く疑ってください。
逆に「フロップCBetを見たが、ターンでチェックした」なら、ニットかTAGである可能性が高くなります。

### 2-2. 圧力をかけられたときの反応：チェックレイズするか

相手が自分のCBetに対してチェックレイズ（CR）を打ってくるかどうかも重要な分類ポイントです。

- **CRがほぼない**：コーリングステーション / ニット（受け身型）
- **CRを時々打つ**：TAG（バリューCRが中心）
- **CRを頻繁に打つ**：LAG（ブラフCRを含む）

コーリングステーションは「コール」が主な武器のため、CRは基本的に使いません。
「一度もCRが来なかった」という観察が積み重なれば、コーリングステーションの仮説を強く支持する証拠になります。

### 2-3. ドンクベットの有無：パッシブの逆説

フロップで相手（OOP）がCBetを待たずに自分からベットする「ドンクベット」は、特殊な行動です。

- **ドンクベットをほぼしない**：GTOに近いTAGか、受け身なニット
- **ドンクベットを時々する（弱いサイズで）**：コーリングステーション（弱い手やドローでの試し打ち）
- **ドンクベットを頻繁にする（不規則なサイズで）**：LAG / マニアック

コーリングステーションのドンクベットは通常弱く、小サイズであることが多いです。
LAGのドンクベットはトラップの可能性もあるため、タイプによって対応が変わります。

## 3. タイミングで分類する

アクションのスピードは、その場での思考プロセスを反映します。
これはオンラインでも機能する信頼度の高い指標です。

### 3-1. 即アクション・ベット：確信の表れ

ベットを素早く打った場合、事前に「打つ」という決断を済ませていた可能性が高いです。
特にプリフロップとフロップでの即ベットは、「このハンドは打つ」と決めていたことを示します。

**意味するもの：**
- 強いバリューハンドで迷わず打った
- または、このハンドをブラフする計画を事前に立てていた

どちらの意味かはタイプで判断します。
ニットやTPが即ベットなら強いバリューである可能性が極めて高くなります。
LAGが即ベットなら、ブラフも含む幅広い意味を持ちます。

### 3-2. 即アクション・チェック：弱さのシグナル

ベットではなくチェックを即座に行った場合は、「打てるハンドがない」と即判断したことを示します。

**意味するもの：**
- バリューがないと判断した（弱い手）
- チェックしてから相手のアクションを待つ計画ではない（トラップではない）

即チェックの後にコールを繰り返すコーリングステーションは特に典型的なパターンです。
「フロップ即チェック → 相手CBetにコール → ターン即チェック → コール」という流れは、ドローか弱いメイドハンドを持ったコーリングステーションの特徴です。

### 3-3. 長考してベット：迷いか演技か

長考の後のベットは、2つの解釈があります。

- **本物の迷い**：ボーダーラインのハンドで、打つかチェックか判断に迷った
- **意図的な演技**：「迷っているように見せる」ための時間稼ぎ（上級者に多い）

初心者・中級者のライブプレイヤーの場合、長考は本物の迷いであることが多いです。
「このプレイヤーはいつもスムーズにアクションしているのに、今回だけ長考した」というように、普段との比較で判断することが重要です。

タイプ別に補足すると、ニットが長考してベットした場合は「迷いつつもバリューを確認した」意味合いが強くなります。
LAGが長考してベットした場合は、ブラフの可能性も含めて判断してください。

## 4. ショーダウンを記録する

ショーダウンで見せた手は、それまでのどんな観察よりも価値ある情報です。
「相手がどのハンドでどのアクションをしたか」という確定情報が手に入るからです。

### 4-1. 見せた手が最大の証拠

ショーダウンが発生したときは、必ず以下を記録（または記憶）してください。

- ハンド：何を持っていたか
- プリフロップ行動：どのポジションでどのアクションをしたか
- ポストフロップ行動：CBetしたか、コールを繰り返したか、CRしたか
- 結果：バリューだったかブラフだったか

特に注目すべきは「コールの手」です。
相手が「どのハンドまでコールしているか」を知ることで、その相手のコール基準が分かります。

### 4-2. コーリングステーションの確認方法

ペアのみ（トップペア弱キッカー、セカンドペア、ボトムペア）でのコールを見た場合、コーリングステーションの可能性が大幅に高まります。

- **例：A♥2♠でリバーまでコール → Aハイのペアのみでのコール**：コーリングステーション確定に近い
- **例：J♠6♦でフロップ・ターン・リバーコール → ボードはK♣J♦2♠-9♥-7♣**：セカンドペアでリバーコールはCSの典型

こうした「弱いハンドでのコール」をショーダウンで確認したら、その相手に対するブラフを即刻停止してください。
そして次にバリューハンドが来たときには、より大きなサイズでベットする計画を立てます。

### 4-3. ニットのショーダウン確認

ニットのショーダウンは逆のケースです。
「ベットやレイズに対してコールした手を見た」ときに注目します。

- レイズに対してコールした相手がセットを見せた → ニット確定
- フロップCRをした相手がAA/KKを見せた → ブラフCRなし、ニット/TAG型

ニットのショーダウンを1回でも見れば、その後のニットからのアグレッシブアクションを素直に尊重できるようになります。

## 実戦エピソード：真田（A）の誤診断と修正

> 🔰 真田（A）のエピソード

ライブ5ヶ月目の真田は、あるハンドで対戦相手を「コーリングステーション」と仮分類していました。
その相手は頻繁にテーブルに参加し、フォールドをあまりしなかったからです。

フロップでTPTK（トップペアトップキッカー）を持った真田は、ポットの50%でCBetを打ちました。
相手がコールし、ターンもコール。
真田は「コーリングステーションだから続けよう」とリバーでも75%のベットを打ちました。

ところが相手はレイズしてきました。真田は困惑してコールを選択。
相手はフロップからのセットを見せ、真田はポットを失いました。

この経験から真田が学んだことは何だったでしょうか。

「参加頻度が高い」だけでコーリングステーションと決めつけたのが誤りでした。
ショーダウンが来て初めて、その相手が「LAGに近い、広くプレイするがバリューラインも持つ」タイプだったと分かりました。

翌セッションから真田は「参加頻度」「リンプ/レイズの比率」「CRの有無」「ドンクベットの有無」を組み合わせて観察するようにしました。
3ストリートのCBetに対してCRしてくる相手は、コーリングステーションではないと早期に判断できるようになったのです。

また、ショーダウンを見るたびに心の中で「このハンドでこのアクションをした」と記録するクセもつきました。
その相手が次にアグレッシブアクションをとったとき、「あのショーダウンの手ならバリューが多い」という判断ができるようになりました。

## 診断チェックリスト：着席後10ハンドで確認すること

10ハンドが経過したら、以下のチェックリストで仮分類を確定させましょう。

| 観察項目 | ニット | TAG | LAG | CS | マニアック |
|---------|-------|-----|-----|-----|---------|
| 参加頻度 | 低（10〜20%） | 中（20〜25%） | 高（25〜35%） | 非常に高（40%+） | 最高（50%+） |
| リンプ率 | 低 | 低 | 低 | 高 | 低〜中 |
| 3ベット頻度 | ほぼなし | 時々 | 多い | ほぼなし | 非常に多い |
| CBet継続性 | T1のみ | T1〜T2 | T1〜T3 | ほぼなし | T1〜T3 |
| CRの有無 | ほぼなし | 時々 | 多い | ほぼなし | 多い |
| 即フォールド率 | 高 | 高 | 中 | 低 | 低 |

**判断のルール：**
1. 1つの指標だけで決めつけない
2. 「参加頻度が高い」だけではコーリングステーションかLAGかマニアックか分からない。リンプ率とCBet継続性で区別する
3. 仮分類後も新しい証拠（特にショーダウン）で随時更新する

## まとめ：行動観察の4ステップ

本章で扱った行動観察のポイントを4ステップで整理します。

**ステップ1（プリフロップ）**：参加頻度・リンプ率・3ベット頻度・フォールドの速さで第一印象を作る

**ステップ2（ポストフロップ）**：CBet継続性（どのティアまで打つか）・CRの有無・ドンクベットの有無で仮説を検証する

**ステップ3（タイミング）**：即ベット・即チェック・長考の意味をタイプと照らし合わせて解釈する

**ステップ4（ショーダウン）**：見せた手を記録し、コール基準・ブラフ頻度・バリューレンジを確定させる

第3章では、行動に加えて「サイズ・タイミング・ベッティングライン・身体・会話」という5種類のTellを扱います。
信頼度の高い順に整理し、何に重点を置くべきかを明確にします。
