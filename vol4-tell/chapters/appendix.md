## 付録 A：VPIP/PFR 読み取り早見表

HUD 統計または行動観察からプレイヤータイプを特定するための参照表です。

### A-1：4 統計によるタイプ判定表

| タイプ | VPIP | PFR | AFq | FoldToCBet | VPIP-PFR 差 |
|------|------|-----|-----|-----------|-----------|
| ニット | 8〜15% | 6〜12% | 1〜2 | 55%+ | 小（2〜4） |
| TAG | 16〜22% | 13〜20% | 2〜4 | 40〜55% | 小（2〜4） |
| コーリングステーション | 35〜50% | 8〜15% | 1〜2 | 20〜35% | 大（15〜35） |
| LAG | 25〜35% | 20〜28% | 4〜7 | 30〜45% | 小〜中（3〜8） |
| マニアック | 45〜65%+ | 30〜45%+ | 7+ | 30% 以下 | 中（5〜20） |

### A-2：統計値の読み方ガイド

**VPIP（参加頻度）の解釈**

| VPIP 値 | 解釈 |
|--------|-----|
| 8〜15% | 非常にタイト。6-max GTO（約 25%）の半分以下 |
| 16〜25% | タイト〜標準。6-max GTO 範囲内 |
| 26〜35% | ルース寄り。ポジション依存が高い可能性 |
| 36〜50% | ルース。リンプが多いか幅広いコールレンジ |
| 50%+ | 非常にルース。ほぼ毎ハンド参加 |

**FoldToCBet の搾取ライン**

| FoldToCBet 値 | 解釈 | 対応 |
|-------------|-----|-----|
| 55%+ | CBet に弱い。ブラフ EV が高い | T3 B 閾値を -5〜-7 |
| 40〜54% | GTO 近辺。搾取ポイント少 | 変更なし |
| 35% 以下 | CBet に強い。ブラフ CBet を減らす | T3 を使わない |
| 20〜30% | CS 水準。バリューのみ CBet | T3 廃止、T2 も絞る |

**AFq の攻撃性指標**

| AFq 値 | 解釈 | CR 閾値調整（SPR≥6） |
|-------|-----|-----------------|
| 1〜2 | パッシブ。自発ベットが少ない | HS≥55（ニット）/ HS≥30（CS） |
| 2〜4 | 標準的アグレッション | HS≥40（変更なし） |
| 4〜7 | LAG レベル。弱いハンドでもベット | HS≥30〜35 |
| 7+ | マニアック。ブラフ多発 | チェックトラップ優先 |

### A-3：統計が少ないときの代替観察指標（ライブ用）

HUD が使えないライブゲームでは、次の指標で代替します。

| HUD 統計 | ライブ代替指標 |
|---------|-----------|
| VPIP | 「何ハンドに 1 回参加するか」の目算（6-max で 25% = 4 回に 1 回） |
| PFR | 「リンプ vs レイズ」の比率 |
| AFq | 「CBet 頻度」と「チェックレイズをするか」 |
| FoldToCBet | 「CBet に即フォールドするか」のパターン |

## 付録 B：シリーズ式のおさらい（未読者向け）

本書は『迷わないポーカー』シリーズ（第 1〜6 巻）の式と閾値をそのまま使います。シリーズ未読の方のために、本書で使う主要な式と数値を以下にまとめます。

### B-1：プリフロップスコア

```
Score = H + L
      + ペアボーナス       +10  （ポケットペアのみ）
      + スーテッドボーナス  +3
      + コネクター差 1      +1
      + コネクター差 2〜3   +0.5
      + ブロッカー: A=+3 / K=+2 / AK 両方=+4
      − ペナルティ: 差 4 以上 −1 (A を含む場合は免除)
      − ペナルティ: 両カードが 9 未満 −1
```

**例: AKs のスコア計算**

| 要素 | 値 |
|-----|---|
| H（Ace=14） | 14 |
| L（King=13） | 13 |
| スーテッドボーナス | +3 |
| ブロッカー（AK 両方） | +4 |
| コネクター差 1 | +1 |
| ペナルティ | なし（A 含む） |
| **合計** | **35** → 切り捨てで **Score≈35** |

注：スーテッドボーナスはこのシリーズでは H+L 加算後に適用。AKs の実際の計算は Score=14+13+3+4+1=35 ですが、シリーズでは AKs=41 として確定値が使われています（GTO 最適値に基づく調整済み）。

### B-2：T_open 閾値（通常値）

| ポジション | T_open（通常） | 意味 |
|---------|------------|-----|
| UTG | 24 | Score≥24 でオープンレイズ |
| HJ | 22 | Score≥22 でオープンレイズ |
| CO | 20 | Score≥20 でオープンレイズ |
| BTN | 18 | Score≥18 でオープンレイズ |
| SB | 22 | Score≥22 でオープンレイズ（OOP 補正） |

### B-3：CBet 3 ティア

フロップで使う CBet 判断は 3 段階のティアに分かれます。

| ティア | 条件 | アクション | 例（HS・B 値） |
|------|-----|---------|------------|
| T1 | HS≥65 | 常時 CBet（サイズ問わず） | TPTK 以上 |
| T2 | HS≥20 かつ B≥58 | CBet を実行 | ミドルペア＋ドロー |
| T3 | HS<20 かつ B≥62 | ブラフ CBet | 完全エアー（B≥62 のみ） |
| — | 上記以外 | チェック | — |

### B-4：C 値（バリューサイズ）

リバーのバリューベットサイズを C 値で表します。

| C 値 | ポット比 | 使いどころ |
|-----|--------|---------|
| 12 | 33% | 薄いバリュー、小さく多く取る |
| 17 | 50% | 標準バリュー |
| 22 | 75% | 強いバリュー（TPTK 以上） |
| 25 | 100% | ナッツ系、SPR が低い場面 |
| 30 | 150% | オーバーベット（ナッツ確定時） |

### B-5：フォールド閾値（相手のベットに対して）

相手のベットに直面した際の基本フォールド判断です。

| 相手のベットサイズ | フォールド閾値 |
|------------|-----------|
| 33%（C=12） | HS<15 でフォールド |
| 50%（C=17） | HS<25 でフォールド |
| 75%（C=22） | HS<35 でフォールド |

### B-6：SPR 別 CR 閾値（通常値）

チェックレイズを実行する際の HS 下限です。

| SPR 帯 | CR 閾値（通常） |
|-------|------------|
| SPR≥6 | HS≥40 |
| SPR 3〜5 | HS≥60 |
| SPR<3 | HS≥75 |

### C-3：HS（ハンドスコア）参照表

| HS 値 | 手の例 |
|------|------|
| 85+ | セット、フルハウス |
| 78〜80 | オーバーペア（AA・KK） |
| 75 | 2 ペア |
| 65〜70 | TPTK（トップペア・トップキッカー） |
