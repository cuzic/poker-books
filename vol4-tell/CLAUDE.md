## 執筆方針

### 文体
- ですます調で統一
- 1文150字以内、読点3個以内
- 専門用語は初出時に簡易定義を併記

### 章の標準構造（第2部タイプ別章）

1. **タイプの本質**（太字でリード）
2. **見分け方**
3. **プリフロップ：式をどう歪めるか**（T_open/T_3bet の閾値変化表）
4. **フロップ：式をどう歪めるか**（T1/T2/T3 の閾値変化、具体例表）
5. **ターン・リバー**
6. **⚠️ やりすぎ注意**

### 品質基準

- 閾値変化は必ず表形式で示す（通常値 → 歪め後の値 → 変化量）
- 具体的な手（例：A♠J♦）とボード（例：J♣8♦5♠）を使う
- HS・B値・C値を具体的な数値で示す
- 各章末に【GTOとのズレ】コラムは不要（別書籍）

## 核心式（『迷わないポーカー』シリーズ準拠）

### プリフロップスコア

```
Score = H + L
      + ペアボーナス   +10  （ペアのみ）
      + スーテッドボーナス +3
      + コネクター差1  +1   / 差2-3 +0.5
      + ブロッカー: A=+3 / K=+2 / AK 両方=+4
      − ペナルティ: 差4以上−1 (A 含むと免除) / 両カード 9 未満 −1
```

- T1: HS≥65 → 常時CBet
