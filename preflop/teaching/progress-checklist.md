# 進捗チェックリスト

各項目を生徒が理解・実行できるかを段階的に確認します。

## ステップ1：基本概念（第1〜2章）

- [ ] ハンドランキング（ロイヤルフラッシュ〜ハイカード）を即答できる
- [ ] ポジション名（UTG、MP、CO、BTN、SB、BB）を即答できる
- [ ] H（高いカード）と L（低いカード）の数値（A=14〜2=2）を即答できる
- [ ] スーテッド・コネクター・ギャップの定義を答えられる

## ステップ2：基本スコア式（第5〜6章）

- [ ] `Score = H + L + ボーナス − ペナルティ` の各要素を説明できる
- [ ] ペア +10、スーテッド +3、コネクター +1、ギャップ 2 以内 +0.5 を即答できる
- [ ] ギャップ 3 以上 −1、両方 9 未満 −1 のペナルティを即答できる
- [ ] 代表 10 ハンド（AA、KQs、77、98s、A5o 等）のスコアを 10 秒以内に算出できる

## ステップ3：ポジション別判断（第7章）

- [ ] 各ポジションのしきい値（UTG=24、MP=22、CO=21、BTN=18、SB=22）を即答できる
- [ ] スコアとしきい値の比較でオープン判断を出せる
- [ ] 付録F の境界ハンド12選（補助ルール）を 3 個以上説明できる

## ステップ4：ポットオッズと実現率（第9〜10章）

- [ ] `必要勝率 = コール額 ÷ コール後の最終ポット` を計算できる
- [ ] 実現率（IP ≈ 1.0、OOP ≈ 0.6〜0.8）の補正を加えた「実効勝率」を出せる
- [ ] OOP での必要勝率 +5〜7% 上乗せの意味を説明できる

## ステップ5：プリフロップスコア（第12章）

- [ ] `Score = H + L + ペアボーナス(+10) + スーテッド(+3) + コネクター(差1=+1/差2-3=+0.5) + ブロッカー(A=+3/K=+2/AK=+4) − ペナルティ` の各要素を説明できる
- [ ] ブロッカー項（A+3、K+2、AK+4）を即答できる
- [ ] 代表ハンド（A5s、KTs、QJs、JTo）のスコアを 10 秒以内に計算できる
- [ ] 対ポジション別二段しきい値（対BTN: T_3bet=32/T_call=28、対UTG: T_3bet=32/T_call=24）を即答できる

## ステップ6：第21章ルール（R1〜R5）

- [ ] R1 の 3 バンド化（強バンド ≥ T+3 / 混合ゾーン T±2 / 弱バンド ≤ T−3）を適用できる
- [ ] R2 のスート判定（♠♥ → アクション / ♣♦ → 受動）を機械的に実行できる
- [ ] R3 の補正（対 UTG/HJ = +2、対 CO/SB = 0、対 BTN = −2）をポジションで即答できる
- [ ] R5 のチェック（コール）レンジ保護（AA〜QQ の ♣♦ スートをコール）を実行できる

## ステップ7：マルチウェイ・ICM 補正（第17章）

- [ ] M 補正（3-way = −3、4-way+ = −5）を人数別に適用できる
- [ ] ICM の ChipEV との違いを 1 文で説明できる
- [ ] バブル直前しきい値補正（+2〜+3）とバブル後（−1〜−2）を適用できる
- [ ] スタック別の ICM プレッシャー（ビッグ −1 / 平均 0 / マージナル +3 / ショート +1）を答えられる
- [ ] MTT 用しきい値式（基本 T + ICM 補正 + M 補正）を使って 1 例を計算できる
