『プリフロップは計算で勝つ』を生徒に教えるインストラクター向けの補助資料集です。以下のマテリアルを自由にコピー・改変して使用してください。

## 収録内容

- **worksheet-level1.md**：Level 1（基本スコア式）の生徒用ワークシート（10 問）
- **worksheet-level2.md**：Level 2（3bet スコア式 + R1〜R5）の生徒用ワークシート（10 問）
- **worksheet-level3.md**：Level 3（第21章完全適用）の生徒用ワークシート（5 問）
- **progress-checklist.md**：生徒の習熟度進捗チェックリスト（7 ステップ）
- **faq-for-instructors.md**：生徒から頻出する質問と回答例（15 問）

## 本資料の使い方

1. **最初に progress-checklist.md を確認**し、生徒がどのステップにいるかを把握します。
2. **ステップに対応するワークシート**を印刷または画面共有し、問題を解いてもらいます。
3. 詰まった問題は **faq-for-instructors.md** を参照し、本書の定義に沿った回答をします。
4. 全ステップ完了後、GTO Wizard 等のソルバーへの移行を推奨します（本書第20章参照）。

## 各ワークシートの対応章

| ファイル | 対応章 | 内容 |
|--------|-------|-----|
| worksheet-level1.md | 第5〜7章 | 基本スコア式（Score = H + L + ボーナス − ペナルティ）でオープン判断 |
| worksheet-level2.md | 第12〜13章、第21章 | 3bet スコア式と R1〜R5 の適用 |
| worksheet-level3.md | 第21章 | マルチウェイ・ICM 補正を含む完全統合 |

## ライセンス

本資料は『プリフロップは計算で勝つ』書籍本文と同じライセンスで公開されています。教育目的での複製・改変は自由です。
