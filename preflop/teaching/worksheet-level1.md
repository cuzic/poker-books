# Level 1 ワークシート（基本スコア式）

<!-- markdownlint-disable MD036 MD040 MD056 MD060 -->
<!-- textlint-disable preset-ja-technical-writing/no-exclamation-question-mark -->
<!-- textlint-disable preset-ja-technical-writing/no-mix-dearu-desumasu -->

**指示**：各問題で `Score = H + L + ボーナス − ペナルティ` を計算し、ポジションのしきい値と比較してオープン判断を出してください。

**基本スコア式**

```text
Score = H + L + ボーナス − ペナルティ

ボーナス:
  ペア           +10（ペア時は H = L、L は片方の数値）
  スーテッド      +2
  コネクター(差1) +1
  ギャップ2以内   +0.5

ペナルティ:
  ギャップ3以上  −1
  両方9未満     −1
```

**しきい値**

| ポジション | しきい値 |
|---------|---------|
| UTG | 24 |
| MP | 22 |
| CO | 20 |
| BTN | 18 |
| SB | 20 |

---

## 問1

- ハンド：A♠A♦（ポケットエース）
- ポジション：UTG

**計算欄**

- H = ___（高いカードの数値）
- L = ___（低いカードの数値）
- ボーナス = ___
- ペナルティ = ___
- スコア = ___
- しきい値 = ___
- 判定：オープン / フォールド

**解答**：H = 14、L = 14（ペアなので両方同値）、ボーナス = +10（ペア）。ペナルティ = 0。スコア = 14 + 14 + 10 = **38**。UTG しきい値 24 を大幅に超えるため → **オープン**

---

## 問2

- ハンド：K♥Q♠（オフスーツ）
- ポジション：UTG

**計算欄**

- H = ___
- L = ___
- ボーナス = ___
- ペナルティ = ___
- スコア = ___
- しきい値 = ___
- 判定：オープン / フォールド

**解答**：H = 13（K）、L = 12（Q）、差 = 1 → コネクター +1。スーテッドなし。ペナルティ = 0。スコア = 13 + 12 + 1 = **26**。UTG しきい値 24 を超えるため → **オープン**

---

## 問3

- ハンド：A♠J♣（オフスーツ）
- ポジション：UTG

**計算欄**

- H = ___
- L = ___
- ボーナス = ___
- ペナルティ = ___
- スコア = ___
- しきい値 = ___
- 判定：オープン / フォールド

**解答**：H = 14（A）、L = 11（J）、差 = 3 → ギャップ 2 以内のため +0.5。スーテッドなし。ペナルティ = 0（ギャップ 3 だが「ギャップ 3 以上ペナルティ」は差が 3 超のとき適用）。スコア = 14 + 11 + 0.5 = **25.5**。UTG しきい値 24 を超えるため → **オープン**（ただし境界ハンド、付録F参照）

## 問5

- ハンド：A♠5♠（スーテッド）
- ポジション：MP

**計算欄**

- H = ___
- L = ___
- ボーナス = ___
- ペナルティ = ___
- スコア = ___
- しきい値 = ___
- 判定：オープン / フォールド

**解答**：H = 14（A）、L = 5、差 = 9 → ギャップ 3 以上のため −1。スーテッド +2。ペナルティ = −1（ギャップ 3 以上）。スコア = 14 + 5 + 2 − 1 = **20**。MP しきい値 22 を下回るため → **フォールド**（BTN ならしきい値 18 を超えるためオープン可）

## 問10

- H = ___
- L = ___
- ボーナス = ___
- ペナルティ = ___
- スコア = ___
- しきい値 = ___
