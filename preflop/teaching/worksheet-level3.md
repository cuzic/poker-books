# Level 3 ワークシート（第21章完全適用）

**指示**：各問題で基本スコアまたは 3bet スコアを計算し、第21章の R1〜R5 と MTT/ICM 補正を含めた完全判断を出してください。

**完全統合式（プリフロップ用）**

```text
オープン用：
  修正スコア = 基本スコア + ICM 補正 + M 補正

3bet 用：
  修正後 3bet スコア = 基本 3bet スコア + R3（レンジアドバンテージ）

判定：修正スコア ≥ しきい値 → アクション、< しきい値 → 受動
```

**ICM 補正（第17章）**

| 状況 | ICM 補正 |
|-----|---------|
| キャッシュゲーム / MTT 序盤 | 0 |
| MTT 中盤（バブル遠い） | 0 |
| バブル直前（賞金圏 150〜120%） | +2 |
| バブル直前（賞金圏 110〜105%） | +3 |
| バブル後（直後） | −1〜−2 |
| ビッグスタック | −1 |
| マージナルスタック（バブル直前） | +3 |
| ショートスタック | +1 |

**M 補正（第17章）**

| 参加人数 | M 補正 |
|--------|-------|
| ヘッズアップ（2人） | 0 |
| 3-way | −3 |
| 4-way 以上 | −5 |

## 問1

**状況**：キャッシュゲーム、6-max 100BB。UTG で AQo を持っている。

- ハンド：A♠Q♦（オフスーツ）
- ポジション：UTG
- ゲーム：キャッシュ、100BB、ヘッズアップ想定

**計算欄**

| 項目 | 値 |
|-----|---|
| 基本スコア（H + L + ボーナス − ペナルティ） | ___ |
| ICM 補正 | ___ |
| M 補正 | ___ |
| 修正スコア | ___ |
| しきい値（UTG） | 24 |
| 判定 | ___ |

**解答**

| 項目 | 値 |
|-----|---|
| 基本スコア | 14 + 12 + 0.5 = **26.5** |
| ICM 補正 | 0（キャッシュゲーム） |
| M 補正 | 0（ヘッズアップ想定） |
| 修正スコア | **26.5** |
| しきい値 | 24 |
| 判定 | **オープン** |

→ AQo は UTG でオープン対象。ただし GTOでは UTG AQo はほぼ全頻度オープンだが、AJo は境界なので混同しないこと。

## 問2

**状況**：MTT バブル直前（残り 22 人、上位 20 人賞金圏）。自分はマージナルスタック（平均の 85%）。BTN で K♣T♣（スーテッド）を持っている。

- ハンド：K♣T♣（スーテッド）
- ポジション：BTN
- スタック：マージナル（平均の 85%）
- フィールド：バブル直前（賞金圏まで残り 2 人）

**計算欄**

| 項目 | 値 |
|-----|---|
| 基本スコア | ___ |
| ICM 補正（マージナルスタック、バブル直前） | ___ |
| M 補正 | ___ |
| 修正スコア | ___ |
| しきい値（BTN） | 18 |
| 判定 | ___ |

**解答**

| 項目 | 値 |
|-----|---|
| 基本スコア | 13 + 10 + 2 + 0.5 = **25.5**（K + T + スーテッド + ギャップ2以内） |
| ICM 補正 | +3（マージナルスタック、バブル直前） |
| M 補正 | 0（ヘッズアップ想定、まだフルテーブルでも基本ロールアップ） |
| 修正しきい値 | BTN 18 + ICM 3 = **21** |
| 判定 | **オープン**（スコア 25.5 > 修正しきい値 21） |

→ ICM 補正後もスコアが十分高く、オープン継続が合理的。ただし 3bet されたら慎重に。

## 問3

**状況**：MTT バブル直前（同条件）。マージナルスタック。UTG で A♦8♠（オフスーツ）を持っている。

- ハンド：A♦8♠（オフスーツ）
- ポジション：UTG
- スタック：マージナル（バブル直前）

**計算欄**

| 項目 | 値 |
|-----|---|
| 基本スコア | ___ |
| ICM 補正 | ___ |
| M 補正 | ___ |
| 修正しきい値（UTG 基本 24 + ICM） | ___ |
| スコア vs 修正しきい値 | ___ |
| 判定 | ___ |

**解答**

| 項目 | 値 |
|-----|---|
| 基本スコア | 14 + 8 − 1 = **21**（A + 8 + ギャップ 6 → ペナルティ −1） |
| ICM 補正 | +3（マージナルスタック、バブル直前） |
| 修正しきい値 | UTG 24 + 3 = **27** |
| 判定 | **フォールド**（スコア 21 < 修正しきい値 27） |

→ 通常キャッシュなら A8o の UTG はフォールド（スコア 21 < しきい値 24）だが、バブル ICM でさらに締めるため差が広がる。

## 問4

**状況**：キャッシュゲーム、6-max 100BB。BTN オープン後、BB で Q♠J♠（スーテッド）を持ち 3bet を検討している。相手（BTN）はタイト（推定 VPIP 18%）。

- ハンド：Q♠J♠（スーテッド）
- 立場：BB から BTN に 3bet 検討
- 相手タイプ：タイト（しきい値 +2 の調整対象）

**計算欄**

| 項目 | 値 |
|-----|---|
| 基本 3bet スコア（Score₃ = H + 0.5L + B + S + C − G − R） | ___ |
| R3 補正（対 BTN） | ___ |
| R3 補正後スコア | ___ |
| T（対 BTN）= 18 → タイト相手補正 +2 → 修正 T | ___ |
| R1 バンド判定 | ___ |
| 最終判定 | ___ |

**補足**：タイト相手に対して 3bet しきい値を +2 にするのは「ブラフ 3bet の通りにくさ」の考慮。第14章参照。

**解答**

| 項目 | 値 |
|-----|---|
| 基本 3bet スコア | 12 + 0.5 × 11 + 0 + 2 + 1 = 12 + 5.5 + 2 + 1 = **20.5**（Q + J + スーテッド + コネクター） |
| R3 補正（対 BTN） | −2 |
| R3 後スコア | 18.5 |
| 修正 T（タイト +2） | 18 + 2 = 20 |
| バンド判定 | スコア 18.5 < T 20 → 弱バンド |
| 最終判定 | **コール**（タイトな BTN への 3bet は控えめ）|

→ 相手がタイトなため 3bet のフォールドエクイティが低く、QJs でもコールが合理的。

## 問5

**状況**：MTT バブル後（賞金圏に入って 2 人脱落済み）。ビッグスタック（平均の 200%）。UTG で J♦J♣（ポケットジャック）を持っている。

- ハンド：J♦J♣（ポケットジャック）
- ポジション：UTG
- スタック：ビッグスタック（バブル後）

**計算欄**

| 項目 | 値 |
|-----|---|
| 基本スコア（ペア） | ___ |
| ICM 補正（ビッグスタック、バブル後） | ___ |
| M 補正 | ___ |
| 修正しきい値（UTG 基本 24） | ___ |
| 判定 | ___ |

**解答**

| 項目 | 値 |
|-----|---|
| 基本スコア | 11 + 11 + 10 = **32**（ペアボーナス）|
| ICM 補正 | −1（ビッグスタック）+ （−1〜−2）（バブル後） = **−2** |
| 修正しきい値 | UTG 24 + （−2） = **22** |
| 判定 | **オープン**（スコア 32 >> 修正しきい値 22） |

→ バブル後のビッグスタックは積極的にオープン。JJ は UTG でも問題なく開く。3bet に対しては 4bet も検討（JJ は QQ+ のバリューレンジ寄りに扱う）。
