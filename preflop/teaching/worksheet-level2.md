# Level 2 ワークシート（3bet スコア式と R1〜R5）

<!-- markdownlint-disable MD036 MD040 MD056 MD060 -->
<!-- textlint-disable preset-ja-technical-writing/no-exclamation-question-mark -->
<!-- textlint-disable preset-ja-technical-writing/no-mix-dearu-desumasu -->

**指示**：各問題で 3bet スコアを計算し、R1〜R5 を適用して最終判断（3bet / コール / フォールド）を出してください。

**3bet スコア式**

```text
Score₃ = H + 0.5L + B + S + C − G − R

B: Aを含む +3、Kを含む +2、AK両方 +4
S: スーテッド +2
C: コネクター（差1）+1、ギャップ2以内 +0.5
G: ギャップ3以上 −1
R: 両方9未満 −1

しきい値: 対UTG=23, 対MP=21, 対CO=19, 対BTN=18
```

**R1 バンド定義（3バンド化、第21章）**

- 強バンド：スコア ≥ T+2（100% 3bet）
- 混合ゾーン：T−2 ≤ スコア ≤ T+1（R2 でスート判定）
- 弱バンド：スコア ≤ T−3（100% コールまたはフォールド）

**R2 スート判定**：混合ゾーンでは高いランクのカードのスートを見る。♠/♥ → 3bet、♣/♦ → コール

**R3 レンジアドバンテージ補正（3bet 版）**

| 相手のポジション | R3 補正値 |
|--------------|---------|
| 対 UTG / MP | **+2** |
| 対 CO / SB | **0** |
| 対 BTN | **−2** |

修正後スコア = 基本 3bet スコア + R3。修正後スコアを T と比較してバンド判定します。

**R5 強ハンドの一部チェック（コール）保護**

- AA〜QQ のオフスーツ：♣♦ スートのもの → コール候補（スロープレイ）
- AKo：50% コール（スート判定近似：Aが ♣♦ ならコール）

## 問1

- 相手オープン：UTG
- あなたのハンド：A♥5♥（スーテッド）
- あなたのポジション：BTN

**計算欄**

- H = ___（高いカード）
- 0.5L = ___
- B = ___（A を含む → +3）
- S = ___（スーテッド → +2）
- C = ___（差 9 → ギャップ 3 以上 → G のみ）
- G = ___（ギャップ 3 以上 → −1）
- R = ___（両方 9 未満？）
- 基本 3bet スコア = ___
- R3 補正（対 UTG）= ___
- 修正後スコア = ___
- T（対 UTG）= 23
- R1 バンド = ___
- R2 判定（混合ゾーンの場合）= ___
- 最終判定：___

**解答**：H = 14、0.5L = 0.5 × 5 = 2.5、B = +3（A あり）、S = +2（スーテッド）、G = −1（差 9 → ギャップ 3 以上）、R = 0（A は 14 なので 9 以上あり両方 9 未満はなし）。スコア = 14 + 2.5 + 3 + 2 − 1 = **20.5**。R3 対 UTG = +2。修正後 = 22.5。T = 23。混合ゾーン（T−2〜T+1 = 21〜24 → 22.5 は混合ゾーン）。R2：A♥ → ♥ なので **3bet**

## 問2

- 相手オープン：UTG
- あなたのハンド：A♦5♣（オフスーツ）
- あなたのポジション：BTN

（問1 と同じハンド、スートのみ違う）

**計算欄**

- 基本 3bet スコア = ___（スーテッドなしで再計算）
- R3 補正（対 UTG）= ___
- 修正後スコア = ___
- R2 判定（A のスート = ♦）= ___
- 最終判定：___

**解答**：H = 14、0.5L = 2.5、B = +3、S = 0（オフスーツ）、G = −1。スコア = 14 + 2.5 + 3 − 1 = **18.5**。R3 = +2。修正後 = 20.5。T = 23 の混合ゾーン（21〜24）。R2：A♦ → ♦ なので **コール**

## 問3

- 相手オープン：BTN
- あなたのハンド：K♠Q♠（スーテッド）
- あなたのポジション：BB

**計算欄**

- H = ___
- 0.5L = ___
- B = ___（K を含む → +2）
- S = ___
- C = ___（差 1 → コネクター +1）
- G = ___
- R = ___
- 基本 3bet スコア = ___
- R3 補正（対 BTN）= ___
- 修正後スコア = ___
- T（対 BTN）= 18
- R1 バンド = ___
- 最終判定：___

**解答**：H = 13（K）、0.5L = 0.5 × 12 = 6、B = +2（K あり）、S = +2、C = +1（差 1）、G = 0、R = 0。スコア = 13 + 6 + 2 + 2 + 1 = **24**。R3 対 BTN = −2。修正後 = 22。T = 18 の強バンド（T+2 = 20 以上 → 22 は強バンド）→ **3bet 確定**

## 問4

- 相手オープン：CO
- あなたのハンド：J♠J♣（ポケットジャック）
- あなたのポジション：BTN

（ペアハンドの 3bet 判断。本書の 3bet スコア式はペアに直接適用しない。QQ+ は自動 3bet、88 以下はコール寄り、JJ/TT は境界として扱う）

**計算欄**

- ハンドランク：JJ
- 本書の判断：QQ+ → 自動 3bet、JJ → 境界（付録F 境界⑧参照）
- 対 CO の特例：___
- 最終判定：___

**解答**：JJ はペアのため基本 3bet スコア式の範囲外。付録F 境界⑧より「対 UTG では JJ コール、対 CO 以降は 3bet」。BTN から CO に 3bet は **3bet 推奨**

## 問5

- 相手オープン：MP
- あなたのハンド：K♦T♦（スーテッド）
- あなたのポジション：CO

**計算欄**

- H = ___
- 0.5L = ___
- B = ___（K を含む → +2）
- S = ___
- C = ___（差 3 → ギャップ 2 以内 → +0.5）
- G = ___（差 3 → ギャップ 3 以上 → −1 ※差 3 は「ギャップ 2 以内」の +0.5 か「ギャップ 3 以上」の −1 か）
- 基本 3bet スコア = ___
- R3 補正（対 MP）= ___
- 修正後スコア = ___
- T（対 MP）= 21
- 最終判定：___

**補足**：差 = K（13）− T（10）= 3。本書定義では「ギャップ 2 以内」は差が 1〜2 なので、差 3 は対象外。ギャップ 3 以上（差が 4 以上）のペナルティに該当するかは差 3 なので該当しない（差 3 = ギャップ 2）。よって C = +0.5（ギャップ 2 以内）。

**解答**：H = 13（K）、0.5L = 0.5 × 10 = 5、B = +2、S = +2、C = +0.5（差 3 → ギャップ 2 以内）。スコア = 13 + 5 + 2 + 2 + 0.5 = **22.5**。R3 対 MP = +2。修正後 = 24.5。T = 21 の強バンド（T+2 = 23 以上）→ **3bet 確定**（付録F 境界⑦参照：KTs は対 UTG では混合、対 MP 以降は 3bet 推奨）

## 問6

- 相手オープン：BTN
- あなたのハンド：A♣K♦（オフスーツ）
- あなたのポジション：BB

R5 のチェック（コール）保護を考慮してください。

**計算欄**

- 基本 3bet スコア（AK の強度はほぼ自動 3bet 対象）= ___
- R5 考慮（AKo、A のスート = ♣ → コール候補）= ___
- 最終判定：___

**解答**：AKo は 3bet スコアが高く（B = +4）本来 3bet 対象。しかし R5 により「AKo の 50% はコール（スート判定：A♣ → ♣ なのでコール側）」。最終 → **コール**（R5 適用によるスロープレイ混ぜ）

## 問7

- 相手オープン：CO
- あなたのハンド：Q♦Q♠（ポケットクイーン）
- あなたのポジション：BTN

R5 のチェック（コール）保護を考慮してください。

**計算欄**

- QQ は自動 3bet かどうか（本書の規則）= ___
- R5 考慮（QQ のオフスーツ、高い方の Q のスート = ♦ → コール候補?）= ___
- 最終判定：___

**解答**：QQ は自動 3bet 対象ハンド（QQ+ は基本常に 3bet）。R5：QQ のスート判定で「♣♦ ならコール候補」。左手の Q♦ → ♦ なのでコール候補。最終 → **コール（R5 でスロープレイ選択）**。ただし初心者は単純に 3bet でも OK。

## 問8

- 相手オープン：BTN
- あなたのハンド：7♣7♦（ポケットセブン）
- あなたのポジション：SB

（ペアの 3bet 判断：88 以下の境界ハンド）

**計算欄**

- ハンドランク：77
- 対 BTN での 77 の推奨（付録F 境界⑩参照）= ___
- SB（OOP）の考慮事項 = ___
- 最終判定：___

**解答**：77 は付録F 境界⑩より「88・77 は対 BTN では 3bet かコールの好み。IP なら 3bet、OOP ならコール寄り」。SB は常に OOP なので → **コール寄り（またはフォールド）**。SB は「3bet かフォールド」が基本なので、コールよりフォールドが多い場面もある。最終 → **フォールド（SBの特殊性：第15章参照）**

## 問9

- あなたのハンド：K♥J♥（スーテッド）
- あなたのポジション：CO

**計算欄**

- H = ___
- 0.5L = ___
- B = ___（K を含む → +2）
- S = ___
- C = ___（差 2 → ギャップ 2 以内 → +0.5）
- G = ___
- R = ___
- 基本 3bet スコア = ___
- R3 補正（対 UTG）= ___
- 修正後スコア = ___
- T（対 UTG）= 23
- R1 バンド = ___
- R2 判定（混合ゾーンの場合）= ___
- 最終判定：___

**解答**：H = 13（K）、0.5L = 0.5 × 11 = 5.5、B = +2（K）、S = +2、C = +0.5（差 2）。スコア = 13 + 5.5 + 2 + 2 + 0.5 = **23**。R3 対 UTG = +2。修正後 = 25。T = 23。強バンド（T+2 = 25 以上）→ **3bet 確定**

## 問10

- 相手オープン：BTN
- あなたのハンド：J♠T♣（オフスーツ）
- あなたのポジション：BB

**計算欄**

- H = ___
- 0.5L = ___
- B = ___（A も K も含まない → 0）
- S = ___
- C = ___（差 1 → コネクター +1）
- G = ___
- R = ___（両方 9 未満？ → J と T はどちらも 9 以上）
- 基本 3bet スコア = ___
- R3 補正（対 BTN）= ___
- 修正後スコア = ___
- T（対 BTN）= 18
- R1 バンド = ___
- 最終判定：___

**解答**：H = 11（J）、0.5L = 0.5 × 10 = 5、B = 0（A も K もなし）、S = 0、C = +1（差 1）、G = 0、R = 0。スコア = 11 + 5 + 1 = **17**。R3 対 BTN = −2。修正後 = 15。T = 18。弱バンド（T−3 = 15 以下 → 15 はちょうど境界）。→ **コール**（フォールド or コールの境界。BB なので後手下限を考慮してコール寄り）
