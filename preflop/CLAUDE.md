# 『迷わないポーカー① プリフロップ』執筆プロジェクト

## プロジェクト概要

書籍『迷わないポーカー① プリフロップ ―覚えなくていいレンジの考え方―』の執筆を管理するプロジェクトである。

## 本書の特徴

- **プリフロップ判断に特化**：フロップ以降は扱わない
- **計算式アプローチ**：169ハンド × 6ポジションのレンジ表暗記を「計算式」で代替
- **GTOとの差分を明示**：各部末に専用章＋全章末に【GTOとのズレ】コラム（案C）
- **実戦ドリル**：20問で身体化、1枚チートシートで日常運用

## 本書の構成

全20章＋付録。詳細は `toc.md` を参照。

### 5部構成

- 第I部（1〜4章）：基礎。判断を数値化する
- 第II部（5〜8章）：オープンレイズの簡易式
- 第III部（9〜13章）：対オープンのアクション
- 第IV部（14〜17章）：補正と応用
- 第V部（18〜20章）：実戦定着と次への橋渡し

## 執筆方針

### 文体
- ですます調で統一
- 1文150字以内、読点3個以内
- 専門用語は初出時に簡易定義を併記（例：VPIP（Voluntarily Put In Pot、自発的に賭けに参加した割合））

### 章の標準構造

各章は以下の構造に従う。

1. **章タイトル + つかみ**：章の狙いを一段落で
2. **本文**：H2で複数セクションに分割
3. **具体例**：必ず1つ以上
4. **【GTOとのズレ】コラム**：案Cの必須要素
5. **章のまとめ**：箇条書き
6. **ミニクイズ**：1〜3問、解答付き

### 品質基準

- 数値は具体的に（「多い」ではなく「約70%」）
- 出典URLを `knowledges/` に明記
- 式は枠囲みで目立たせる

## 計算式の中核

本書で扱う主要な式は `preflop.txt` の原案を出発点とする。

### オープンレイズ（スコア式）

```
Score = H + L + ボーナス − ペナルティ

H: 高い方のカード値（A=14, K=13, ... 2=2）
L: 低い方のカード値
ボーナス: ペア+10, スーテッド+3, コネクター+1, ギャップ2以内+0.5
ペナルティ: ギャップ4以上−1, 両方9未満−1

しきい値（6-max）:
UTG≥23, MP≥22, CO≥20, BTN≥18, SB≥22

※ ポジションは Score を補正しない。Score 値はどのポジションでも同じ、しきい値だけが違う。
※ SB は混合戦略（raise + limp）の raise レンジに合わせて MP 並みの 22。
※ CO は GTO RFI 27.8% に整合させて 20。
※ 「ポジション補正値（UTG -2 ~ BTN +2）」概念は廃止（旧版用語）。
```

### 3betスコア（ブロッカー強化版）

```
Score₃ = H + 0.5L + B + S + C − G − R

B: Aを含む+3, Kを含む+2, A・K両方+4
その他は基本スコア式と同様

しきい値:
対UTG≥23, 対MP≥21, 対CO≥19, 対BTN≥18
```

### ポットオッズ

```
必要勝率 ≈ コール額 ÷ 最終ポット
実効勝率 ≈ 生勝率 × 実現率（〜0.6 OOP時）
```

### セットマイニング

```
コール額 × 15 ≤ 相手スタック
```
