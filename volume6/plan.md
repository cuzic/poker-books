## 本書の3つの核心式

### 1. ICM equity（ICM 換算）

```
ICM equity = ICM 計算による「あなたのスタックの賞金期待値」
        ≈ 賞金プール × ICM補正された取り分比率

簡易版（暗算用）:
  ICM equity ≈ 自分のチップ比率 × 賞金プール − ペイアウト構造の補正

実質的な特徴:
  - 大スタックほど 1 チップ当たりの価値が低い（限界価値逓減）
  - 小スタックほど 1 チップ当たりの価値が高い（生存価値プレミアム）
  - 残プレイヤー数が少ないほどペイ構造の影響が大きい
```

### 2. ICM 補正（リスクプレミアム）

```
ICM 補正 = トーナメント命を賭けるための「上乗せ必要エクイティ」

ステージ別目安:
  序盤・中盤（フィールドの 50%以上残）: 0-10%（cEV ≈ $EV）
  バブル直前（残 1.5x ITM）         : 20-40%
  バブル中（残 1.1x ITM）           : 30-50%（最大圧力）
  ITM 後                          : 0-10%（リスクプレミアム解放）
  ファイナルテーブル（pay jumps 大） : 20-40%（ペイジャンプごとに再強化）

実戦の判定:
  通常 50% 勝率必要 → ICM 圧力下では 60-65% 勝率必要
  この差が「ICM 補正」
```

### 3. M値（ステージ判定）

```
M = スタック ÷ (SB + BB + アンテ合計)
  = 「あと何周ハンドを待てるか」

ゾーン分類（Harrington 系譜）:
  Green Zone (M ≥ 20)   : 余裕、深スタック戦略
  Yellow Zone (M 10-20) : 標準的MTT
  Orange Zone (M 6-10)  : 積極ショブ域
  Red Zone (M ≤ 5)      : プッシュ/フォールド完結
```
