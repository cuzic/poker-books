# 第16章　サテライト戦略 ─ 上位 N 名一律

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 「上位 N 名が一律に参加権を得る」というサテライト固有の賞金構造が、ICM 補正に何をもたらすかを理解する。大スタック・中スタック・ショートスタックそれぞれに異なる戦術方針を、具体的な BF 実測値とともに身につける。

---

## 16-1 サテライトという特殊な世界

通常のトーナメントでは、賞金は上位入賞者ほど多くもらえます。1位が最も多く、2位・3位と順を追って減っていきます。この構造は「逓減型の賞金曲線」を生み、第13章のバブルで確認したような ICM 圧力を生み出します。

サテライトは根本的に異なります。

サテライトとは「上位 N 名が次のトーナメントの参加権（チケット）を獲得し、それ以下は賞金ゼロ」というトーナメントです。参加権の額は全員で同じです。たとえば $30 で参加するサテライトで上位 10 名が $300 のメインイベント参加権を得る、という形が典型例です。

賞金構造を図示すると「階段」ではなく「断崖」のように見えます。上位 N 名は全員が同じ賞金（チケット）を受け取り、N+1 位以下はゼロです。数学的には「ステップ関数」と呼ばれる形状です。

```
通常 MTT の賞金曲線:
1位 ────────────── 最大
2位 ──────────
3位 ──────
  ...（なだらかに減少）
N位 ─
N+1位以下 0

サテライトの賞金曲線（上位N名一律型）:
1位〜N位 ──── 一律（チケット）
N+1位以下 0（断崖）
```

この「断崖」が、サテライトの戦術を通常のトーナメントから根本的に変える原動力です。

---

## 16-2 サテライト ICM の性質 ─ なぜ線形か、なぜ断崖か

サテライトの ICM を理解するうえで重要な観察があります。

上位 N 名全員が「一律賞金」を受け取る構造では、通常トーナメントで生じていた「1位 vs 2位の賞金差」がゼロになります。1位でも N 位でも同じチケットをもらえるため、「少しでも上位に入りたい」という通常の ICM 圧力は、N 位圏内の人々の間では発生しません。

その代わり、極端な圧力が特定の場面に集中します。それが「N+1 位がゼロ」という断崖の前後です。

```
サテライトの ICM 圧力が集中する場面:
  残りプレイヤーが N+1 人になった瞬間（バブル突入）
  → 1人が脱落すれば全員チケット確定
  → この「1人」になることを極限まで嫌う
```

`scripts/icm_calc.py` で実測してみます。

**シナリオ: 5人残り、上位 N=1 名のみ通過（最もシンプルな例）**

```
スタック: P1=5000, P2=2500, P3=1000, P4=1000, P5=500
賞金: 1位のみ $100、他は $0
```

```
| Player | Stack | Chip% | $EV  | ICM% |
| P1     | 5000  | 50%   | $50  | 50%  |
| P2     | 2500  | 25%   | $25  | 25%  |
| P3     | 1000  | 10%   | $10  | 10%  |
| P4     | 1000  | 10%   | $10  | 10%  |
| P5     | 500   |  5%   |  $5  |  5%  |
```

`（scripts/icm_calc.py 実測）`

ICM% がチップ% と完全に一致しています。上位 1 名通過の構造では、「1位以外は全員ゼロ」のため ICM がチップ比率に比例する線形構造になります。チップを持てば持つほど直接的に $EV が増え、バブルファクター（BF）は全員 1.0 です。ICM 圧力がほぼ存在しません。

では、「残りプレイヤー数が通過枠の N+1 人」まで減ったとき、状況は激変します。

## 16-3 サテライトバブル ─ 断崖の前に立つ瞬間

サテライトの最大の緊張場面は「残りプレイヤー数 = 通過枠 + 1 人」の状況です。誰か1人が脱落すれば全員チケット確定、しかし今この1人が自分である可能性があります。

以下のシナリオで実測します。

**シナリオ: 4人残り、上位 3 名が $300 メインイベント参加権を獲得**

```
スタック: P1=4500, P2=3000, P3=1500, P4=1000（合計 10000）
賞金: 1〜3位 各 $100、4位 $0
```

```
| Player | Stack | Chip% | $EV    | ICM%   |
| P1     |  4500 | 45%   | $94.59 | 31.53% |
| P2     |  3000 | 30%   | $88.49 | 29.50% |
| P3     |  1500 | 15%   | $67.97 | 22.66% |
| P4     |  1000 | 10%   | $48.95 | 16.32% |
```

`（scripts/icm_calc.py 実測）`

注目すべき点は、P1 がチップ 45% を持っているにもかかわらず ICM% は 31.53% しかないことです。P4 はチップわずか 10% ですが ICM% は 16.32% あります。「通過がほぼ確定していても上積みがない」というサテライト ICM の性質が数値に現れています。

次に BF を全員分実測します。

| Hero | Villain | BF | 必要 equity |
| :--- | :--- | ---: | ---: |
| P1（45%） | P2（30%） | 3.958 | 79.8% |
| P1（45%） | P3（15%） | 1.597 | 61.5% |
| P1（45%） | P4（10%） | 1.301 | 56.5% |
| P2（30%） | P1（45%） | **9.437** | **90.4%** |
| P2（30%） | P3（15%） | 1.784 | 64.1% |
| P2（30%） | P4（10%） | 1.345 | 57.4% |
| P3（15%） | P1（45%） | 4.641 | 82.3% |
| P3（15%） | P2（30%） | 4.085 | 80.3% |
| P3（15%） | P4（10%） | 1.285 | 56.2% |
| P4（10%） | P1（45%） | 2.257 | 69.3% |
| P4（10%） | P2（30%） | 2.034 | 67.0% |
| P4（10%） | P3（15%） | 1.366 | 57.7% |

`（scripts/icm_calc.py 実測。必要 equity = BF ÷ (BF + 1)）`

際立っているのは P2 が P1 に対して持つ BF = **9.437**（必要 equity **90.4%**）です。

第13章のバブルで確認した通常 STT バブル（同じスタック構成、50/30/20 払い）でのP2 vs P1 の BF は 2.902（必要 equity 74.4%）でした。サテライトバブルでは同じスタック構成でも BF が約 3.2 倍に跳ね上がります。これがサテライトの「断崖」の正体です。

## 16-4 大スタックの戦術 ─ 過剰タイトの正体

第13章のバブルでは「大スタック（チップリーダー）は攻撃的になれる」と説明しました。サテライトバブルでは、この原則が修正されます。

**サテライトバブルでのリーダー（P1）の立場**

P1 の平均 ICM 補正を計算すると約 1.285 です。第13章の通常 STT バブルでの P1 の ICM 補正は 0.270 でした。サテライトバブルのリーダーは通常バブルのリーダーより約 5 倍の ICM 補正を背負っています。

その理由は BF 行列に現れています。P1 が P2 に攻めるときの BF が 3.958（必要 equity 79.8%）に達します。通常 STT バブルでの P1 vs P2 の BF は 1.53（必要 equity 60.5%）でした。リーダーであっても、同等〜やや下のスタックに対して大きな勝負を仕掛けることは $EV を大きく傷つけます。

```
【大スタック戦術の根拠】
サテライトバブル（4人残り、Top3通過）P1 の BF:
  vs P2（3000chip）: BF = 3.958 → 必要 equity 79.8%（AA/KK のみ）
  vs P3（1500chip）: BF = 1.597 → 必要 equity 61.5%（AQ, QQ 以上）
  vs P4（1000chip）: BF = 1.301 → 必要 equity 56.5%（AT, 88 以上）
```

リーダー P1 にとって、P2 との勝負は「AA/KK でなければコール禁止」の水準です。P3 や P4 との勝負は通常バブル並みの圧力にとどまります。

つまりサテライトバブルの大スタックは「過剰タイト」ではなく、「相手スタックを選んだ戦術的タイト」が正解です。

**大スタックの具体的な行動方針**

```
リーダー P1 のサテライトバブル行動方針:
  ① P2 との大型衝突は AA/KK のみ受ける
  ② P3・P4 には通常バブル並みの水準で攻め続ける
  ③ スティール対象は「自分より大幅に小さいスタック」に絞る
  ④ フロップでポットが大きくなったら中スタックに対しては特に注意する
```

「リーダーだから何でも攻める」は通常バブルの正解であって、サテライトバブルでは誤りです。チケットをほぼ手中に収めているリーダーが中スタックと大型衝突して脱落するのは、最も避けるべき事態です。

## 16-5 中スタックの戦術 ─ 極限の板挟み

サテライトバブルで最も ICM 補正が高いのは中スタックです。

P2（チップ 30%）の ICM 補正（平均）は **3.189**、P3（チップ 15%）の ICM 補正（平均）は **2.337** です。第13章の通常 STT バブルでの P2 は 0.784、P3 は 0.825 でした。サテライトバブルでは ICM 補正が 3〜4 倍に拡大しています。

P2 が P1 に対してオールインを受けるとき、必要 equity は **90.4%** です。AA の vs ランダムレンジ equity は約 85% です。つまり **AA ですら P1 のプッシュを受けるのがギリギリ**、もしくは P1 のプッシュレンジによっては不可のラインです。KK（vs ランダム equity ≈ 82%）は明確にフォールドが正解です。

これがサテライトバブルの「断崖」の実態です。通常バブルでは「AA/KK はコール可、QQ/AKs はボーダー」でしたが、サテライトバブルでは「AA のみボーダー、KK 以下はフォールド」という水準に変わります。

**中スタックのコール基準**

| Hero | 対戦相手 | BF | 必要equity | コール可能なハンド |
| :--- | :--- | ---: | ---: | :--- |
| P2（30%） | P1（大） | 9.437 | 90.4% | AA のみ（ボーダー） |
| P2（30%） | P3（中小） | 1.784 | 64.1% | QQ/AK 以上 |
| P2（30%） | P4（ショート） | 1.345 | 57.4% | AT, TT 以上 |
| P3（15%） | P1（大） | 4.641 | 82.3% | AA のみ |
| P3（15%） | P2（中） | 4.085 | 80.3% | AA/KK のみ |
| P3（15%） | P4（ショート） | 1.285 | 56.2% | A9, 88 以上 |

`（scripts/icm_calc.py 実測。コール可能ハンドは vs ランダムレンジ equity での目安）`

**中スタックの行動方針**

```
中スタック（P2・P3）のサテライトバブル行動方針:
  ① リーダー（P1）との大型衝突は AA のみ（ただしボーダーライン）
  ② 中スタック同士の衝突は AA/KK のみ
  ③ ショートとの衝突は比較的通常の基準で判断可能
  ④ オープン頻度を大幅に絞る（リーダーに 3bet されると逃げ場がない）
  ⑤ できるだけ「何もしない」戦術を基本として、ショートの脱落を待つ
```

中スタックが自分から動くインセンティブはほとんどありません。ショートが脱落するのを待つ「不戦の通過」が最も高い $EV を生む場面が多いです。

## 16-6 ショートスタックの戦術 ─ 失うものが少ない自由

P4（チップ 10%）の ICM 補正（平均）は **0.886** です。通常 STT バブルでのショートの ICM 補正（0.529）より高いですが、中スタック（3.189）より遥かに低い水準です。

ショートは「失えるチップが少ない」ため、オールインで負けた場合の $EV 損失も小さくなります。P4 の $EV は 48.95 です。P4 がオールインで脱落すると $0 になるため損失は $48.95 ですが、P2 がオールインで脱落すると $88.49 を失います。ショートの方が「賭けに乗るコスト」が絶対値で小さいのです。

**ショートのコール基準**

P4 が直面する BF は以下の通りです。

```
P4（10%） vs P1（大スタック）: BF = 2.257 → 必要 equity 69.3%
P4（10%） vs P2（中スタック）: BF = 2.034 → 必要 equity 67.0%
P4（10%） vs P3（小スタック）: BF = 1.366 → 必要 equity 57.7%
```

P3（通過圏に近い小スタック）に対するコール基準は 57.7% と比較的低く、AT 以上や 88 以上でコール可能な水準です。大スタックや中スタックに対しては 67〜69% と高めになりますが、通常バブルの中スタックほど극端な制約はありません。

**ショートの行動方針**

ショートの戦術は二極化します。

第一は「積極的なプッシュ」です。ブラインドが積み上がってチップが減れば M 値も下がります。M 値が 6 以下になれば第10章のプッシュ/フォールド戦略が主軸になります。サテライトバブルのショートは、中スタックや大スタックが「何もしない」間に積極的にブラインドを奪うことができます。中スタックは ICM 圧力で身動きが取れないため、ショートのプッシュに対して相手のコール基準も高くなっています。

第二は「ターゲットの選択」です。可能な限り P3（他のショート）を狙い、P1 や P2 との全面対決は避けます。P4 が P3 を脱落させれば自分の通過確率が大幅に上がります。P1 との勝負はリスクに見合わない場面が多いです。

```
ショートのサテライトバブル行動方針:
  ① M 値 ≤ 6 ならプッシュ/フォールドに完全移行
  ② プッシュ対象は中スタック（コール基準が高いため）か他のショート
  ③ 大スタックへのプッシュは AJ, TT 以上が目安（BF = 2.257 → 必要 equity 69.3%）
  ④ 他のプレイヤーがオールイン勝負を始めたら一旦待機して状況を見極める
  ⑤ 自分以外のショートが脱落すればボーナス（「不戦の通過」を狙う）
```

## 16-7 サテライトと通常バブルの比較

第13章のバブルと本章のサテライトバブルで、中スタック（P2）の立場がどう変わるかを並べて確認します。

**同一スタック構成（4500/3000/1500/1000）での比較**

| 比較項目 | 通常 STT バブル（50/30/20 払い） | サテライトバブル（100/100/100/0 払い） |
| :--- | ---: | ---: |
| P2 の ICM 補正 | 0.784 | 3.189 |
| P2 vs P1 の BF | 2.902 | 9.437 |
| P2 vs P1 の必要 equity | 74.4% | 90.4% |
| P2 vs P1: KK でコール可能か | ギリギリ可 | 不可 |
| P2 vs P1: AA でコール可能か | 可 | ボーダーライン |
| P1 の ICM 補正 | 0.270 | 1.285 |

`（scripts/icm_calc.py 実測）`

ICM 補正が 0.784 から 3.189 へ約 4 倍になります。KK が「ギリギリコール可」から「明確にフォールド」に変わります。この変化が「サテライトでいつも通りプレーすると負ける」の正体です。

**本質的な違い**

通常バブルは「少しでも上位に入りたい」という圧力が中スタックにかかります。サテライトバブルは「少しでも上位に入っても意味がない（N 位内なら全員同じ）、ただし N+1 位だけは絶対に嫌」という全く異なる構造です。

この非対称性が「断崖の前の全員停止」を生みます。通常バブルでも全員が守備的になりますが、サテライトバブルではその度合いが質的に異なります。

## 16-8 サテライト暗算チェックリスト

実戦でサテライトに参加したとき、以下のステップで即座に判断します。

```
ステップ 1: サテライト確認
  上位 N 名が一律賞金（参加権）かどうかを確認する
  通常の MTT と見誤らないこと

ステップ 2: バブルに入ったかを確認する
  残りプレイヤー数が N+1 人になったら「サテライトバブル突入」
  この瞬間から ICM 補正が激変する

ステップ 3: 自分のスタック位置を判定する
  チップ 35% 以上   → 大スタック（中スタックとの衝突は AA/KK のみ）
  チップ 15〜35%    → 中スタック（大スタックとの衝突は AA のみ、ほぼ動かない）
  チップ 15% 未満   → ショート（ターゲットを選んでプッシュ）

ステップ 4: 対戦相手のスタックを確認する
  相手が大スタック → 必要 equity が激増（AA 以外は原則フォールド）
  相手が中スタック → 中程度の圧力（大スタックへの感覚より緩い）
  相手がショート   → 通常バブル並みの圧力（比較的広い基準でコール可）

ステップ 5: 「不戦の通過」を意識する
  他のプレイヤーが脱落するのを待つ戦略が、特に中スタックで高 $EV になる
  残りプレイヤーが N+1 人のとき、自分が何もしなくても誰かが脱落する確率がある

ステップ 6: バブルブレイク後は即座に切り替える
  誰かが脱落して全員チケット確定後は ICM 補正がゼロになる
  残りプレイヤーが全員通過確定なら、チップ争いは意味をなさない（引き分けで可）
```

## 16-9 ミニクイズ

### 問1

4 人残り、上位 3 名が $300 メインイベント参加権を獲得するサテライトです。スタックは P1=4500、P2=3000、P3=1500、P4=1000 です。あなたは P1（チップリーダー）です。P2（3000chip）が SB からオールインプッシュしてきました。あなたは BTN から AKo を持っています。コールしますか。

1. コールする（AKo はプレミアムハンド。チップリーダーなら余裕がある）
2. フォールドする（P1 vs P2 の BF = 3.958 → 必要 equity 79.8%。AKo の vs プッシュレンジ equity は 65% 程度 → 不足）
3. コールする（チップリーダーはサテライトバブルでも攻撃的でよい）

### 問2

同じ 4 人残り、上位 3 名通過のサテライトです。スタックは P1=4500、P2=3000、P3=1500、P4=1000 です。あなたは P2（チップ 30%）です。P1（4500chip）が BTN からオールインプッシュしてきました。あなたは BB で QQ を持っています。コールしますか。

1. コールする（QQ はプレミアムハンド。vs ランダムレンジ equity は 73% あり十分）
2. フォールドする（P2 vs P1 の BF = 9.437 → 必要 equity 90.4%。QQ の equity は届かない）
3. コールする（フォールドするとスタックが減ってショートに近づいてしまう）

### 問3

同じサテライト、P4（ショート、1000chip）の立場です。P3（1500chip）が CO からオールインプッシュしてきました。あなたは BB で A9s を持っています。コールしますか。

1. フォールドする（サテライトバブルでは何もしないのが基本）
2. コールする（P4 vs P3 の BF = 1.366 → 必要 equity 57.7%。A9s の equity は十分）
3. フォールドする（ショートは大スタックを避けるだけでよく、中スタックとも戦う必要はない）

---

### 解答

- **問1**: 2が正解（フォールド）。サテライトバブルでのリーダー P1 が P2 に対して持つ BF は 3.958 です。必要 equity = 3.958 ÷ (3.958 + 1) ≈ 79.8% です。AKo の vs 典型的プッシュレンジ equity は約 60〜65% 程度であり、79.8% の閾値には大きく届きません。「チップリーダーだから攻める」という通常バブルの発想は、サテライトバブルでは中スタックとの衝突に限って通用しません。P1 が P2 と衝突して負ければ大スタックが崩れ、自分が通過できないリスクが生じます。AKo でもフォールドが明確な正解です。

- **問2**: 2が正解（フォールド）。P2 が P1 のプッシュを受けるときの BF = 9.437 です。必要 equity = 9.437 ÷ (9.437 + 1) ≈ 90.4% です。QQ の vs ランダムレンジ equity は約 73%、vs 典型的プッシュレンジでも 70% 程度であり、90.4% には届きません。「フォールドするとスタックが減る」という心理的抵抗は理解できますが、コールしてオールインで負けた場合の $EV 損失の方が遥かに大きいです。P2 は現状でも ICM equity の $88.49 を保有しており、QQ でコールして脱落すれば $0 になります。フォールドしてスタックが小さくなっても P4 が脱落すれば通過できます。待つことが最善です。

- **問3**: 2が正解（コール）。P4 が P3 のプッシュを受けるときの BF = 1.366 です。必要 equity = 1.366 ÷ (1.366 + 1) ≈ 57.7% です。A9s の vs 典型的ショートのプッシュレンジ equity は十分に 57.7% を超えます。サテライトバブルでは「何もしないのが基本」と思いがちですが、それは中スタックの戦術です。ショートはブラインドが積み重なれば自然とスタックが減り、通過から遠ざかります。P3 という同等以下のスタックとの勝負は BF が低く、積極的に受けて良い場面です。P3 を脱落させれば自分の通過確率が大幅に高まります。

> **本章まとめ**
>
> - サテライトは「上位 N 名が一律賞金（チケット）、それ以下はゼロ」というステップ関数型の賞金構造。通常のなだらかな賞金曲線とは根本的に異なる。
> - N+1 人が残った瞬間（サテライトバブル突入）に ICM 補正が激増する。中スタックの ICM 補正は通常バブルの 4 倍に達することがある（例: 0.784 → 3.189）。
> - 大スタックも中スタックとの衝突は AA/KK のみに絞る。中スタック vs 大スタックの必要 equity が 90% を超える場面では、AA すらボーダーライン。
> - 中スタックは「ほぼ動かない」「不戦の通過を狙う」が基本方針。ショートの脱落を待つことが最も高い $EV を生む場面が多い。
> - ショートは ICM 補正が相対的に低く、他のショートや中スタックへのプッシュに積極的に取り組む。大スタックへのコールはタイトに絞る。
> - バブルブレイク後（全員通過確定）は ICM 補正がゼロになり、残りのプレイヤー間では「引き分け」と同義。チップ争いに意味はなくなる。

**【GTOとのズレ】**

ICMIZER や HRC などの ICM ソルバーは、サテライト専用モードを持つものがあります。本章の BF 実測値と、それに基づくコール基準は `scripts/icm_calc.py` による計算に基づいており、ソルバーの出力と定性的な方向性は一致しています。「中スタックが大スタックに対して AA/KK ですらフォールドすることがある」という結論は、ソルバーが返す極端な結果と整合します。

実戦でのズレは主に2つの場面で生じます。

第一は「通常のトーナメントの感覚でプレーする」ことです。サテライトバブルでのBFが通常バブルの 3〜4 倍に達することを知らないプレイヤーは、QQ や AK で当然のようにコールします。本章の数値が示す通り、これは $EV を大幅に損失する判断です。「サテライトはいつものトーナメントと違う」という認識の切り替えが最初のステップです。

第二は「大スタックが攻撃的すぎる」ことです。通常バブルではリーダーが積極的に仕掛けることが正解でしたが、サテライトバブルではリーダーも中スタックとの衝突は AA/KK のみに絞る必要があります。「チップリーダーだから余裕がある」という感覚が、サテライトでは命取りになります。ソルバーはリーダーのプッシュレンジを中スタックに対して著しく絞った出力を返しますが、直感的には受け入れにくい結果です。実戦の誤りとソルバーの理想の乖離が最も大きい場面のひとつです。
