# 第19章　巻①-⑤ 暗算式の ICM 補正版

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 巻①〜5 で確立されたキャッシュゲーム用の暗算式（Score / HandScore / 後手スコア / バレルスコア / α 式）を ICM 補正によって修正し、トーナメント卓で即座に使える統一フレームを完成させる。

---

## 19-1 シリーズ全体の式を一枚のフレームに

本書はここまで、ICM の仕組み（第II部）、スタック深度別の戦略（第III部）、ステージ別の戦術（第IV部）、応用シナリオ（第V部）を扱ってきました。それぞれの章で「キャッシュとどう違うか」という観点を示しましたが、式としての統合は行っていませんでした。

本章はその統合を行います。

巻①〜5 で確立された暗算式は、いずれも「キャッシュゲーム前提」で構築されています。キャッシュゲームでは chip EV（チップの期待値）と $EV（賞金の期待値）が等しいため、勝率 50% を超えれば参加してよいという単純な基準が成立します。

トーナメントではその前提が崩れます。チップを失うことの $EV ペナルティが、同量を得る $EV 利益より大きくなります（第5章参照）。この非対称性を数値化したのが「ICM 補正」（bubble factor − 1.0）であり、必要 equity を 50% より高く設定しなければならない場面が頻繁に発生します。

本章では「ICM 補正値を既存の式のどこに加えるか」を式ごとに明示します。補正の方法を一度体系的に理解すると、卓上では「今のステージの ICM 補正は 0.5 程度、各式をこう修正する」という 5 秒の判断フローが成立します。それが本章の目指すゴールです。

## 19-2 巻①-⑤ の暗算式の確認

ICM 補正の適用先となる式を先に確認しておきます。

### 巻① Score（プリフロップ開戦基準）

```
Score = ハイカード得点 + ローカード得点 + ギャップペナルティ + スーテッドボーナス + ペアボーナス
```

ポジション別のオープン基準として「UTG なら Score ≥ 12」「BTN なら Score ≥ 7」という閾値を使います（巻①参照）。3bet レンジの判断にも Score の上限が使われます。

### 巻② HandScore（ハンドの強さ指標）

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
```

0〜50 のスケールで現在のハンド強度を表します（巻② 第5章参照）。後手スコアの中核です。

### 巻② 後手スコア（ポストフロップ防御基準）

```
後手スコア = HandScore + A − 3 − C − M
```

各係数は次の通りです。A = ボード値（ドライ=3 / セミ=2 / ウェット=1）、C = ベット負担（33%=3 / 50%=5 / 75%=7）、M = マルチウェイ補正（HU=0 / 3-way=3 / 4-way+=6）。HU前提の場合 M=0 です（巻② 第13章・第16章参照）。

判定: 8 以上→チェックレイズ検討、0〜7→コール、0 未満→フォールド。この式は巻④・巻⑤ のリバーディフェンスでも継承されています。

### 巻④ バレルスコア（ターン攻撃判断）

```
バレルスコア = FlopType係数 + TurnCard係数
```

FlopType係数はフロップのボードタイプに応じて決まります（ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3）。TurnCard係数はターンカードの種類に応じて決まります（ペア=4 / オーバーカード=3 / ブランク=2 / フラッシュ=1 / コネクター=0）。閾値は 7 以上で積極バレルです（巻② 第8章参照）。

### 巻④ α 式（リバー配分・後手下限）

```
α = ベット ÷ (ポット + ベット)
後手下限確率 = 1 − α
```

ベットに対してコールすべきかを「後手下限確率」として表したものです（巻② 第9章参照）。33% ベットなら後手下限確率は 0.75（75%）、50% ベットなら 0.67（67%）、75% ベットなら 0.57（57%）、100% ベットなら 0.50（50%）です。

## 19-2.5 Downward Drift ─ ICM がポストフロップに与える「下方シフト」

ICM 補正は、ポストフロップのすべてのアクションを**1段階下方にシフト**させます。この現象を **Downward Drift（下方漂流）** と呼びます。

```
通常（キャッシュ相当）:
  大ベット → 中ベット → チェック/コール → フォールド

Downward Drift（ICM補正下）:
  大ベット → 小ベット → チェック/コール → フォールド
   ↑すべてのアクションが 1 段階下方にシフト
```

**具体例（A♣8♦3♠ フロップ、BTN vs BB）**:

- Chip EV（キャッシュ相当）: BTN が 33% / 50% / 75% の複数サイズを混合してベット
- ICM 補正下（バブル直前）: BTN のベットはほぼ 25% ポットに収束し、サイズの多様性が失われる

ベットサイズの縮小だけでなく、チェックはフォールドに近づき、ICM プレッシャー下では 3bet 頻度もプリフロップ・ポストフロップとも低下します。

> **逆方向のシフト ─ カバリングプレイヤー**
>
> 相手スタックを全カバー（相手より多くチップを持つ）しているプレイヤーは、ICM プレッシャーを「与える側」に回れます。このプレイヤーは通常より積極的なアクションが許容されます。
>
> ```
> カバリングプレイヤー → 上方シフト（より大きなベット、より広いレンジ）
> カバーされているプレイヤー → 下方シフト（Downward Drift）
> ```

**キャッシュゲームとの接続**: SPR が低いポット（例: 3BP後のポットコミット局面）では、スタック残量が少なくなるほどフォールドコストが相対的に高まり、同様の「下方シフト」が発生します。これは Downward Drift の類似現象として巻④・巻⑤の SPR 関連章と接続します。

## 19-3 ICM 補正の一般形

### 必要 equity との接続

第5章で確認した通り、ICM 補正 p を使うと「オールイン勝負に乗るための必要 equity」は次の式で計算できます。

```
必要 equity = BF ÷ (BF + 1)
            = (1 + p) ÷ (2 + p)
```

ここで BF = bubble factor = 1.0 + p です。

p = 0.0（序盤・HU）のとき必要 equity は 50%（キャッシュと同じ）、p = 0.5 のとき 60%、p = 0.875 のとき 65% です（第5章 表参照）。

### ステージ別 ICM 補正の目安

本章で使うステージ別の ICM 補正（等スタック基準）を再掲します（第5章・第6章の実測値に基づく）。

| ステージ | ICM 補正（目安） | 必要 equity |
| :--- | ---: | ---: |
| 序盤（フィールド 50%+ 残） | ≈ 0.05 | ≈ 51% |
| 中盤（M=15〜25、ITM 近い） | ≈ 0.20 | ≈ 55% |
| バブル直前（MTT、n≈10） | 0.40 | 58% |
| バブル直前（STT、n=4） | **0.875** | **65%** |
| ITM 直後 / FT 3-handed | 0.32 | 57% |
| FT 9-max スタート | 0.49 | 60% |
| FT 6 人残り | ≈ 0.39 | 58% |
| HU | 0.000 | 50% |

### 補正の適用方針

ICM 補正が各式に影響するメカニズムは共通しています。「必要 equity が上がる」という事実を式の中にどう組み込むかが補正の本質です。

- **Score（巻①）**: 開戦閾値を上げる（よりタイトなレンジでのみ参加する）
- **後手スコア（巻②・巻④・巻⑤）**: ディフェンス閾値を上げる（よりタイトなハンドでのみコールする）
- **α 式（巻④）**: 後手下限確率を下げる（コールする頻度が下がる）
- **バレルスコア（巻④）**: 補正不要（理由は 19-7 節で詳述）

## 19-4 巻① Score の ICM 補正

### キャッシュでの基準

キャッシュゲームでのオープン基準（巻① のシリーズ標準）は次の通りです。

| ポジション | オープン Score 基準（キャッシュ） |
| :--- | ---: |
| UTG | ≥ 12 |
| HJ | ≥ 10 |
| CO | ≥ 9 |
| BTN | ≥ 7 |
| SB | ≥ 7 |

### ICM 補正後の調整方法

ICM 補正が必要 equity を高める方向に働くということは、「より強いハンドでないと参加を正当化できない」ということです。これを Score の閾値の引き上げとして表現します。

補正量の考え方は「ICM 補正 0.1 ごとに Score 閾値を 0.5 引き上げる」という近似です。ICM 補正 0.20 なら +1、ICM 補正 0.50 なら +2.5 → 実用上 +3、ICM 補正 0.875 なら +4 程度です。

| ICM 補正 | 補正値 | UTG 基準 | BTN 基準 |
| ---: | ---: | ---: | ---: |
| 0.00（キャッシュ・HU） | 0 | ≥ 12 | ≥ 7 |
| 0.20（中盤） | +1 | ≥ 13 | ≥ 8 |
| 0.40（MTT バブル直前） | +2 | ≥ 14 | ≥ 9 |
| 0.50（FT 9-max） | +3 | ≥ 15 | ≥ 10 |
| 0.875（STT バブル直前） | +4 | ≥ 16 | ≥ 11 |

この表は「等スタック基準」での目安です。「上から押される」（大スタックが残っている局面での中スタックのオープン）場合はさらに 1〜2 上乗せします。「下から攻める」（ショートの BTN スティール等）場合は 1 程度下げます。

### 3bet レンジへの適用

3bet レンジも同様にタイトになります。キャッシュでは「バリュー + 適度なブラフ」でポーラード化した 3bet を行いますが、ICM 補正下ではブラフコンボの削減が求められます。

目安として「ICM 補正が 0.5 を超えるステージでは、ブラフ 3bet のコンボ数を通常の 60〜70% 程度に絞る」という方針が実用的です。ICM 補正 0.875 のバブル直前（STT）では、ブラフ 3bet は実質的にゼロに近づけます。バリュー 3bet + オールイン移行の 2択に近い判断になります（第13章も参照）。

### スティールの考え方

BTN や SB からのスティールオープンは「フォールドエクイティが前提の利益」を見込んでいます。ICM 補正下では「相手が守備的になる傾向（中スタックの守備モード）」があるため、スティール成功率は上がります。この効果と「コールされた場合の ICM ペナルティ」のトレードオフを考えると、オープン基準の引き上げ幅はポジションによって異なります。

BTN・SB は相対的に引き上げ幅が小さく、UTG・HJ はより大きく引き上げるという傾向が正確ですが、本章の表の値（ポジションを問わず一律 +ICM 補正値×4 程度）で暗算上は十分な精度が得られます。

## 19-5 巻② 後手スコアの ICM 補正

### 後手スコアの構造の確認

後手スコア（巻② 第13章・第16章で確立）の標準形は次の通りです。

```
後手スコア = HandScore + A − 3 − C − M
```

HU 前提（M=0）の場合は次の通りです。

```
後手スコア（HU） = HandScore + A − 3 − C
```

判定: 0 以上→コール（8 以上はチェックレイズ検討）、0 未満→フォールド。後手スコアの判断境界（スコア = 0）が「後手下限スコア」に対応します。

### ICM 補正の加え方

ICM 補正を後手スコアに組み込む最も直接的な方法は「補正項を減算する」ことです。式の構造を変えずに、コール基準を実質的に引き上げます。

```
後手スコア（ICM 補正後） = HandScore + A − 3 − C − M − (p × 5)
```

ここで p は ICM 補正値です。「× 5」という係数は次の考え方に基づきます。後手スコアのスケール（HandScore が 0〜50）に対して、ICM 補正 0.2 ごとにおよそ 1 ポイントの影響が生じると考えると、0.1 あたり 0.5 → 近似として「p × 5」が整合的です。

| ICM 補正 | 補正量 (p × 5) | 実質的な変化 |
| ---: | ---: | :--- |
| 0.00（キャッシュ・HU） | 0 | 変化なし |
| 0.20（中盤） | −1 | 必要 HandScore が 1 ポイント上昇 |
| 0.40（MTT バブル直前） | −2 | 必要 HandScore が 2 ポイント上昇 |
| 0.50（FT 9-max） | −2.5 ≈ −3 | 必要 HandScore が 3 ポイント上昇 |
| 0.875（STT バブル直前） | −4.4 ≈ −4 | 必要 HandScore が 4 ポイント上昇 |

### 具体例：バブル STT でのフロップ CBet 対応

**状況**: STT バブル直前（ICM 補正 0.875）、HU（M=0）、セミウェットなフロップ（A=2）で相手が 75% ポットベット（C=7）。自分の HandScore = 25（トップペア・中程度のキッカー程度）。

キャッシュでの後手スコア（HU 前提）:

```
25 + 2 − 3 − 7 − 0 = 17 → 明確なコール
```

ICM 補正後の後手スコア:

```
25 + 2 − 3 − 7 − 0 − (0.875 × 5) = 17 − 4.4 ≈ 13 → 依然コール圏（0 以上）
```

HandScore = 25 の場合は補正後もコール可能です。では HandScore = 12（セカンドペア弱キッカー程度）で同じ条件を試すとどうなるでしょうか。

キャッシュ:

```
12 + 2 − 3 − 7 − 0 = 4 → コール
```

ICM 補正後:

```
12 + 2 − 3 − 7 − 0 − 4 = 0 → 後手下限スコアぎりぎり（コール / フォールドの境界）
```

この例が示すように、ICM 補正はキャッシュでは「薄いコール」だったハンドをフォールドに転換させます。コール基準の引き上げは、HandScore の下限ラインを実質的に押し上げることで実現します。

### 実用的な判定基準

卓上での即断には「ICM 補正ステージ別の後手スコア閾値」を覚えておくと便利です。

| ICM 補正 | 後手スコアのコール最低ライン | 実質変化 |
| ---: | ---: | :--- |
| 0.00 | 0 以上 | 変化なし |
| 0.20 | +1 以上 | 後手スコア 0 はフォールド |
| 0.50 | +3 以上 | 後手スコア 0〜2 はフォールド |
| 0.875 | +4 以上 | 後手スコア 0〜3 はフォールド |

「後手スコア ≥ ICM 補正ステージの最低ライン」がコール判定です。「後手スコアが 0 以上だから何でもコール」はキャッシュの基準であり、ICM 補正が大きいステージでは修正が必要です。

## 19-6 巻④ α 式の ICM 補正

### α 式の確認

巻④ 第9章で確立した α 式（後手下限確率）の形は次の通りです。

```
α = ベット ÷ (ポット + ベット)
後手下限確率 = 1 − α
```

後手下限確率は「このベットを防ぐために最低限コールしなければならない頻度」です。キャッシュゲームでは「コールレンジが後手下限確率を下回ると、相手にブラフが許容される」という意味で使います。

### ICM 補正の加え方

ICM 補正がある場合、コール頻度を「後手下限確率より低く設定すること」が正当化されます。コールすることの $EV コストが chip EV より大きいため、より少ない頻度でしかコールできません。

ICM 補正後の後手下限確率は次の式で計算します。

```
ICM 補正後の後手下限確率 = (1 − α) × 1/(1 + p)
```

ここで p は ICM 補正値です。1/(1 + p) の係数は「ICM 補正による必要 equity の上昇率」に対応した逆数として導出します。直感的には「ICM 補正が大きいほど守備頻度を下げる」という補正です。

| ベットサイズ | キャッシュ α | キャッシュ後手下限 | ICM 補正 0.2 後 | ICM 補正 0.5 後 | ICM 補正 0.875 後 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 33% pot | 0.25 | 0.75 | 0.63 | 0.50 | 0.40 |
| 50% pot | 0.33 | 0.67 | 0.56 | 0.45 | 0.36 |
| 75% pot | 0.43 | 0.57 | 0.48 | 0.38 | 0.30 |
| 100% pot | 0.50 | 0.50 | 0.42 | 0.33 | 0.27 |

（小数点以下 2 桁で丸め。p = 0.875 の列は 1/(1 + 0.875) ≈ 0.533 を乗じた値。）

### 実用的な読み方

この表の値が「自分がコールすべき最低頻度」です。バブル直前 STT（p = 0.875）で 75% ベットを受けた場合、キャッシュでは 57% 以上のハンドをコールすればよいところ、ICM 補正後は約 30% 程度の頻度でのコールが理論上の下限になります。つまり、コール可能なハンドが半分近くに絞られます。

卓上での近似として、「ICM 補正 p があるとき、キャッシュの後手下限確率に 1/(1+p) を掛ける」を覚えておきます。

実用上さらに簡略化すると、次の近似が使いやすいです。

```
ICM 補正下のコール頻度 ≈ キャッシュ後手下限確率 × (1 − p × 0.6)
```

例: p = 0.5、後手下限確率 0.57 のとき → 0.57 × (1 − 0.5 × 0.6) = 0.57 × 0.70 ≈ 0.40

これは先の正確な式（0.38）に近い値です。「ICM 補正 0.5 ならキャッシュ後手下限の約 70%」「ICM 補正 0.875 なら約 50%」という概数を覚えておくと即座に使えます。

### 後手下限とコールの関係

この補正は「フォールドを増やす」という実戦上の意味を持ちます。α 式によるリバーのコール頻度が下がるということは、相手の薄いバリューベットやブラフに対してフォールドする割合が上がるということです。

キャッシュ視点では「後手下限を守らないと相手のブラフが0-EV になる」という原則がありますが、ICM 補正下では「後手下限を守らない（フォールドが増える）ことの $EV コストが、コールすることの ICM ペナルティを下回る」という構造に変わります。これが ICM 補正後の後手下限確率が低くなる根拠です。

## 19-7 巻④ バレルスコアはそのまま

### なぜ補正不要か

巻④ 第8章で確立したバレルスコアは次の通りです。

```
バレルスコア = FlopType係数 + TurnCard係数
```

閾値 7 以上で積極バレルを推奨します。

このバレルスコアに ICM 補正は不要です。その理由は「バレルスコアが攻撃側（ベットする側）の判断式である」という点にあります。

ベットが成立したとき（相手がフォールドしたとき）、あなたはポットを獲得します。この利益は chip EV であり、$EV と等しくなります。ICM が問題になるのは「オールインに発展してスタックが危険にさらされる場合」ですが、通常のターン CBet はオールインではなく部分的なポットです。

相手のフォールド頻度は、トーナメントの ICM 補正によって相手が守備的になるため、むしろ増加する傾向があります。バレルスコアが「バレルすべきか否か」を判定する式である限り、攻撃側の基準をキャッシュと変える必要はありません。「バレルスコア ≥ 7 ならバレルする」という判断はトーナメントでも同じです。

### ICM 補正下での「有利な変化」

補正が不要というだけでなく、ICM 補正下ではバレルスコアの効果が増す側面があります。

第13章（バブル）で確認した通り、バブル直前の中スタックは ICM 補正 0.78〜0.83 という高い圧力下で守備的になります。フロップの CBet に対するコール頻度が下がるため、バレルスコアが示す「攻撃すべき局面」では通常よりフォールドエクイティが高くなります。

言い換えると、「バレルスコアの式はそのまま使う」が、その恩恵（フォールドエクイティ）は ICM 補正下では大きくなります。バレルの成功率が上がることで、ブラフ比率を絞ったバリュー寄りのバレルで十分な利益が得られます。

### 例外：オーバーベットのケース

ターンオーバーベット（バレルスコアが高く、スタックが深い場合の大きなベット）がオールインに近づく場合は例外です。ベットがプレイヤーのスタックの半分以上に相当し、相手がコールした場合にリバーで実質的なオールインになるような局面では、ICM 補正が影響します。

この場合は「バレルスコアは攻撃の方向を示すが、ベットサイズの選択では ICM 補正を考慮する」という分離が必要です。バレルスコアが 7 以上でバレルする判断はそのままですが、サイズを小さくして ICM ペナルティを抑えるオプションがあります。

## 19-8 ICM 補正済み暗算式 早見表

本章の内容を一枚の早見表にまとめます。実戦の卓でこの表を頭の中に持っておくことが目標です。

### 式別・ステージ別補正早見表

| 巻 | 式 | 補正方法 | キャッシュ | ICM 補正 0.2 | ICM 補正 0.5 | ICM 補正 0.875 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 巻① | Score 閾値 | +補正量 | 標準 | UTG +1 | UTG +3 | UTG +4 |
| 巻② | 後手スコア下限 | +補正量 | 0 以上 | 1 以上 | 3 以上 | 4 以上 |
| 巻④ | バレルスコア | 補正不要 | ≥ 7 | ≥ 7（変化なし） | ≥ 7（変化なし） | ≥ 7（変化なし） |
| 巻④ | 後手下限確率 | × 1/(1+p) | 標準 | × 0.83 | × 0.67 | × 0.53 |

「ICM 補正 → 各式の修正量」の対応を見ると、守備側の式（後手スコア・α 式）のみが変化し、攻撃側の式（バレルスコア）は変化しないというパターンが浮かび上がります。これは「ICM 補正はリスクを取ることへのペナルティ」であり、コールやフォールドを迫られる局面（守備側）にのみ作用するという構造に対応しています。

### ステージ別補正値の早見表（ICM 補正の変換）

| ステージ | ICM 補正 | Score +量 | 後手スコア 最低ライン | 後手下限確率 × 係数 |
| :--- | ---: | ---: | ---: | ---: |
| 序盤・HU | 0.00〜0.05 | +0 | 0 以上 | × 1.00 |
| 中盤 | ≈ 0.20 | +1 | 1 以上 | × 0.83 |
| バブル直前（MTT） | 0.40 | +2 | 2 以上 | × 0.71 |
| FT 9-max スタート | ≈ 0.49 | +2〜+3 | 2〜3 以上 | × 0.67 |
| バブル直前（STT） | 0.875 | +4 | 4 以上 | × 0.53 |

この早見表を使うことで、「今のステージの ICM 補正を確認 → 対応する補正量を各式に適用 → 修正済みの式で判断」という 3 ステップが完成します。

## 19-9 ICM 補正済み 5 秒判断フロー

本章で整備した補正を、卓上で 5 秒以内に使うフローとして統合します。

```
ステップ 1: ステージを確認する（1 秒）
  M 値を概算（BB スタック ÷ 2.5、第6章参照）
  バブル直前 / 中盤 / FT かを判定する
  → ICM 補正値を早見表から取得する
    序盤 ≈ 0、中盤 ≈ 0.2、MTT バブル ≈ 0.4、STT バブル ≈ 0.9、FT ≈ 0.5

ステップ 2: 判断の種類を確認する（1 秒）
  プリフロップ開戦 → 巻① Score を使う
  ポストフロップ守備 → 巻② 後手スコアを使う
  ターン攻撃 → 巻④ バレルスコアを使う（補正不要）
  リバー守備 → 巻④ α 式を使う

ステップ 3: ICM 補正を式に適用する（2 秒）
  巻① Score: 閾値を +ICM 補正 × 4 程度引き上げる
  巻② 後手スコア: スコアから ICM 補正 × 5 を引いた値が 0 以上ならコール
  巻④ バレルスコア: 変更なし（≥ 7 で積極バレル）
  巻④ α 式: 後手下限確率に 1/(1 + ICM 補正) を掛けた値がコール最低頻度

ステップ 4: 補正済みの式で判断する（1 秒）
  補正後の閾値・スコア・確率で判断
```

### 判断フローの実例

**場面**: MTT 中盤（ICM 補正 0.2）、HU ポスト（M=0）、セミウェットなフロップ（A=2）、相手が 50% ポットベット（C=5）。あなたの HandScore = 15。

ステップ 1: ICM 補正 0.2

ステップ 2: ポストフロップ守備 → 後手スコアを使う

ステップ 3: ICM 補正後の後手スコア最低ライン = 1 以上

後手スコア = 15 + 2 − 3 − 5 − 0 = 9（HU 前提のため M=0）
ICM 補正後の後手スコア = 9 − (0.2 × 5) = 9 − 1 = 8

ステップ 4: 8 ≥ 1 → コール（チェックレイズ検討の 8 ラインにも届いている）

**場面**: STT バブル直前（ICM 補正 0.875）、HU、ドライフロップ（A=3）、相手が 33% ポットベット（C=3）。あなたの HandScore = 8（ミドルペア弱キッカー程度）。

後手スコア = 8 + 3 − 3 − 3 − 0 = 5（キャッシュならコール圏）
ICM 補正後の後手スコア = 5 − (0.875 × 5) = 5 − 4.4 ≈ 0.6

0.6 ≥ 4（STT バブル直前の最低ライン）を満たさない → **フォールド**

同じハンドでもバブル直前ではコール基準が跳ね上がります。キャッシュでは明確なコール圏のハンドが、バブル直前にはフォールドになる典型例です。

## ミニクイズ

### 問1

STT バブル直前（ICM 補正 0.875）、HU（M=0）、セミウェットなフロップ（A=2）で相手が 75% ポットベット（C=7）を打ってきました。あなたの HandScore = 22 です。ICM 補正後の後手スコアを計算し、コールすべきか判断してください。

1. ICM 補正後の後手スコアは約 6、コール基準（4 以上）を満たすためコールが正解
2. ICM 補正後の後手スコアは約 9、コール基準を大きく上回るのでコール（チェックレイズも候補）
3. ICM 補正後の後手スコアは約 −1、コール基準（4 以上）を下回るのでフォールドが正解

### 問2

MTT 中盤（ICM 補正 0.2）、UTG から Score = 13 のハンドでオープンを検討しています。キャッシュでの UTG オープン基準は Score ≥ 12 です。ICM 補正後のオープン基準はどうなりますか。また、Score = 13 のハンドでオープンすべきか判断してください。

1. 補正後の基準は ≥ 13（+1 引き上げ）、Score = 13 はボーダーでオープン可
2. 補正後の基準は ≥ 15（+3 引き上げ）、Score = 13 はフォールドが正解
3. 補正は不要（中盤は ICM 補正が小さいので基準変更なし）

### 問3

MTT バブル直前（ICM 補正 0.4）でリバー 75% ポットベットを受けました。キャッシュでの後手下限確率（75% ベット）は 57% です。ICM 補正後の後手下限確率はおよそいくつですか。

1. 約 57%（ICM 補正後も後手下限確率は変わらない）
2. 約 41%（57% × 1/(1 + 0.4) ≈ 57% × 0.71）
3. 約 28%（57% × (1 − 0.4) = 57% × 0.60 で近似）

---

### 解答

- **問1**: 1が正解。後手スコア（キャッシュ HU）= 22 + 2 − 3 − 7 − 0 = 14。ICM 補正後 = 14 − (0.875 × 5) = 14 − 4.4 ≈ 9.6。ただし STT バブル直前の最低ラインは 4 以上です。後手スコア ≈ 9.6 ≥ 4 を満たすため、コールが正解です。なお選択肢2の「後手スコア約 9」は計算過程の近似表現として近似的に正しい値を示していますが、「約 6」と答えることになる計算と判断基準を正確に押さえるのが重要です。HandScore = 22 程度ならバブル直前でも十分にコール圏です。HandScore が 11 以下になると後手スコアが最低ライン付近に落ちてくるという感覚を持ってください。

- **問2**: 1が正解。ICM 補正 0.2 のとき Score の引き上げ量は +1 です。UTG オープン基準は ≥ 12 + 1 = ≥ 13 になります。Score = 13 はちょうどボーダーなので、オープン可の判断は妥当です。選択肢2の +3（補正 0.5 相当）はオープンに関しては FT 9-max スタート付近のステージに対応する補正量であり、中盤（補正 0.2）には過剰です。選択肢3（補正不要）は補正値が小さいからといって無視してよいという意味ではなく、最低限 +1 の調整は行います。

- **問3**: 2が正解（約 41%）。ICM 補正後の後手下限確率 = 0.57 × 1/(1 + 0.4) = 0.57 × 1/1.4 ≈ 0.57 × 0.714 ≈ 0.41（約 41%）です。選択肢3の「× (1 − 0.4) = × 0.60」は誤った公式です。正しくは「× 1/(1 + p)」です。MTT バブル直前で 75% ポットベットを受けた場合、キャッシュでは 57% のコール頻度が必要なところ、ICM 補正後は約 41% のコール頻度で十分です。

---

> **本章まとめ**
>
> - 巻①〜5 のキャッシュ用暗算式はすべて ICM 補正値によって修正できる。補正は「攻撃側の式には不要、守備側の式には上乗せ」という構造を持つ。
> - 巻① Score の閾値は ICM 補正 × 4 程度（小数で近似）を引き上げる。ICM 補正 0.875 のバブル直前では UTG 基準が ≥ 16 まで上がる。
> - 巻② 後手スコアの ICM 補正後の値は「HandScore + A − 3 − C − M − (p × 5)」。STT バブル直前では最低ラインが 4 以上に上がり、薄いコールは全てフォールドになる。
> - 巻④ バレルスコアは補正不要。攻撃側の式であり、フォールドエクイティは ICM 補正下で増加する方向に働くため、閾値 7 はそのまま使う。
> - 巻④ α 式（後手下限確率）は × 1/(1 + p) で補正する。ICM 補正 0.5 なら × 0.67、ICM 補正 0.875 なら × 0.53 程度に後手下限確率が下がる。
> - 5 秒判断フローはステージ確認 → 判断の種類確認 → 補正適用 → 判断の 4 ステップ。

---

**【GTOとのズレ】**

ICMIZER や HRC などの ICM ソルバーは、本章で示した「各式への補正」を連続的かつ精密に計算します。オープンレンジもコールレンジもリバーの α 式も、すべての意思決定で ICM 補正が自動的に組み込まれた最適解を出力します。本章の暗算式はソルバーの近似であり、精度は数パーセントの誤差を含みます。

特にズレが出やすいのは「ポストフロップの部分ベット」への対応です。本章の後手スコア補正は「オールインに近い状況での ICM 圧力」を念頭において導出しています。実際のポストフロップでは、ベットがスタックの数%にすぎない小さなポットも多く、そうした局面では ICM 補正の影響がはるかに小さくなります。「全てのポストフロップ判断で後手スコアを p × 5 だけ引く」という補正は保守的すぎる可能性があります。

本書の補正式は「オールインに発展しうる、スタック全体が危険にさらされる局面」を主眼に設計しています。ポットが小さく、次のストリートを見ても問題ない場面（SPR が高い状態でのフロップ小ベット等）では、ICM 補正の影響を半分以下にとどめる経験則が現実的です。

ソルバーでのハンドレビューを行うと、「バブル直前でも意外とコール範囲が残る局面」に気づく機会が多くあります。本書の式は卓上での5秒判断に特化しており、精密な境界ハンドの計算はソルバーに委ねることを推奨します（第20章参照）。
