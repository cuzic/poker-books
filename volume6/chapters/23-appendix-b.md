## B-2 アルファベット順用語

### BB アンテ（Big Blind Ante）

現代のトーナメントで標準化されたアンテ徴収方式。毎ハンドのアンテをビッグブラインドのプレイヤーが一括して支払います。個別アンテ（全員が少額ずつ払う旧方式）と比べてゲーム進行が速く、1周あたりのコストも計算しやすくなります。M 値の計算でアンテ合計に含めます。詳細は第1章・第6章参照。

### bubble factor（BF、バブルファクター）

「同量のチップを失う $EV 損失」と「同量のチップを得る $EV 利益」の比率。

```
BF = |Δ$EV（チップを失う場合）| ÷ |Δ$EV（同量のチップを得る場合）|
```

BF = 1.0 なら Chip EV と $EV が一致（圧力なし）。BF > 1.0 なら「負けたときの損失が勝ったときの利益より大きい」状態です。ICM 補正の計算出発点であり、BF 行列を使うとスタック別の非対称性が確認できます。詳細は第5章参照。

### chip EV（チップ EV、cEV）

チップ量で測った期待値。キャッシュゲームでは chip EV = $EV ですが、トーナメントでは両者が乖離します。「この勝負はチップ的に正しい」という直感は cEV の計算であり、ICM の圧力を無視しています。詳細は第2章参照。

### $EV（ダラーイーブイ）

賞金期待値で測った期待値。トーナメントの判断基準はすべて $EV の最大化です。chip EV が正でも $EV が負になる局面があり、その差がトーナメント戦略の核心です。詳細は第2章参照。

### FT（Final Table、ファイナルテーブル）

最後の1テーブルに参加者が絞り込まれた段階。通常は9人（または6人）でスタートします。全員が ITM 済みですが、賞金の傾斜が急なため ICM 圧縮が強く再燃します。「FT に出たら楽になる」という直感は誤りで、等スタック ICM 補正 0.488 は中盤（0.20）の2倍以上です。詳細は第14章参照。

### HRC（Holdem Resources Calculator）

トーナメントに特化した ICM ソルバーの一つ。プッシュ/フォールドの均衡解と ICM 補正を加えたコール/フォールド判断を計算できます。本書の暗算フロー（第6章）をソルバーで検証するときに活用します。

### HU（Heads-Up、ヘッズアップ）

2人対決。HU では ICM 計算が線形になり、bubble factor は 1.0（ICM 補正 = 0.00）になります。Chip EV = $EV が成立するため、キャッシュゲームと同じ判断基準で動けます。詳細は第15章参照。

### ICM（Independent Chip Model）

チップ量から賞金期待値（$EV）を算出するモデル。Harville（1973）の競馬着順確率モデルを Malmuth（1987）がポーカーに適用したもので、「各プレイヤーが特定の順位に到達する確率はチップ比率に比例する」という1つの仮定から導かれます。スキル差・ポジション・ブラインド進行を無視した理論値ですが、トーナメント判断のベースラインとして広く使われています。詳細は第4章参照。

### ICM equity（ICM エクイティ）

本書の3核心式の1つ目。ICM 計算によるあなたの賞金期待値です。

```
ICM equity = 賞金プール × ICM%
ICM%       ≈ チップ% + ステージ補正値
```

チップ比率（Chip%）より常に小さくなる（限界価値逓減）のが特徴です。大スタックほど ICM% がチップ% を大きく下回ります。詳細は第4章・第6章参照。

### ICM%（ICM パーセント）

あなたの ICM equity を賞金プールで割った比率。「賞金プールのうち何% があなたの取り分か」を示します。Chip% とは一致せず、チップが多いほど差が広がります。たとえばバブル直前（n=4）でチップ 50% を持っていても ICM% は 37% にとどまります（`scripts/icm_calc.py` 実測）。詳細は第4章・第6章参照。

### ICM 圧縮

大スタックのチップ価値が ICM の計算構造によって目減りする現象。チップ量の関数として ICM equity を描くと上に凸の曲線（凸関数）になるため、チップが増えるほど追加1チップが生む $EV が小さくなります。ICM 圧縮は「大スタックが守備的になる」「小スタックが積極的にプッシュする」の数学的根拠です。詳細は第4章参照。

### ICM 補正（リスクプレミアム）

本書の3核心式の2つ目。トーナメント命を賭けるために必要な「上乗せ必要エクイティ」。Chip EV ベースなら勝率 50% で正の期待値になりますが、ICM 補正がある局面では追加の勝率が必要になります。

```
ICM 補正 = BF − 1.0
必要 equity = BF ÷ (BF + 1)
```

ステージ別の目安値（等スタック基準、`scripts/icm_calc.py` 実測）:

| ステージ | ICM 補正 | 必要 equity |
| :--- | ---: | ---: |
| 序盤 | ≈ 0.05 | ≈ 51% |
| 中盤 | ≈ 0.20 | ≈ 55% |
| バブル直前 STT（n=4） | 0.875 | 65% |
| バブル直前 MTT（n=10） | 0.40 | 58% |
| FT 9-max スタート | 0.488 | 60% |
| HU | 0.000 | 50% |

詳細は第5章・第6章参照。

### ICMIZER

ICM ベースのプッシュ/フォールド計算に特化したオンラインツール。bubble factor・必要 equity・均衡レンジを計算できます。本書の暗算フロー（第6章）のソルバー検証に使えます。

### ITM（In The Money）

賞金圏内に到達している状態。「マネーイン」「バブルブレイク後」とも言います。ITM 直後はバブル直前（ICM 補正 0.875）から急落して 0.32 程度になるため、プレイスタイルを攻撃方向に切り替える節目です。詳細は第14章参照。

### Malmuth-Harville（マルムース・ハービル）

ICM の計算アルゴリズムの正式名称。各プレイヤーの着順確率をチップ比率の積として再帰的に計算します。n 人なら n! 通りの完了順を網羅するため、手計算は困難ですが概念の理解に3人計算が有効です。詳細は第4章参照。

### MTT（Multi-Table Tournament）

数百〜数千人規模の大型トーナメント。複数テーブルで同時進行し、人数が減るにつれてテーブルが統合（バランシング）されます。本書が主に想定する形式です。詳細は第1章参照。

### M 値（M ratio、エム値）

本書の3核心式の3つ目。「あと何ハンド、ノーアクションでブラインドだけ払い続けられるか」を数値化したステージ判定指標。Harrington が提唱した概念です。

```
M 値 = スタック ÷ (SB + BB + アンテ合計)
     ≈ BB スタック ÷ 2.5（9-handed、BB アンテ標準）
```

ゾーン分類:

| ゾーン | M 値 | BB スタック目安 | 戦略モード |
| :--- | ---: | ---: | :--- |
| グリーン | ≥ 20 | 50BB 以上 | 深スタック戦略 |
| イエロー | 10〜20 | 25〜50BB | MTT 標準中盤 |
| オレンジ | 6〜10 | 15〜25BB | 積極スティール・プッシュ準備 |
| レッド | ≤ 5 | 12BB 以下 | プッシュ/フォールドのみ |

詳細は第6章参照。

### Push/Fold ゲーム（プッシュフォールドゲーム）

スタックが極端に短い（M ≤ 5 = レッドゾーン）ときに行う、オールインかフォールドかの2択に完結した戦略。フロップを見る余裕がなく、プリフロップのオールイン判断がすべてになります。ナッシュ均衡解に従うことが最も合理的です。詳細は第10章参照。

### SnG（Sit and Go、シットアンドゴー）

参加人数が固定された小規模トーナメントで、席が埋まり次第スタートします。通常は1テーブル（6〜10人）で行われ、賞金構造・ブラインドレベルが安定しているため ICM 学習の教材として最適です。STT（Single Table Tournament）とほぼ同義です。詳細は第1章参照。

### STT（Single Table Tournament）

1テーブルで行われる小規模トーナメント。SnG とほぼ同義です。本書では SnG と STT を同義として使っています。

### 本文中の重要用語（簡易定義）

以下は B-2 のアルファベット順ではなく、本文で頻出する日本語用語です。B-2 の補完として記載します。

**限界価値逓減**（げんかいかちていげん）  
チップが増えるほど、追加1チップが生む ICM equity（$EV）が小さくなる性質。ICM equity をチップ量の関数として描くと上に凸の曲線（凸関数）になるため、この性質が生まれます。大スタックほど「守ることの価値が高い」の数学的根拠です。詳細は第4章参照。

**凸関数**（とつかんすう）  
ICM equity のチップ量に対する関数の形状。グラフが上に凸の曲線を描き、傾きが右に行くほど緩やかになります。チップが少ないときは追加チップの価値が高く、多いときは低い（限界価値逓減）ことを視覚化した概念です。詳細は第4章参照。

**サテライト**  
上位 N 名が一律で次のトーナメントへの参加権を得る特殊な形式。通常の ICM と異なり「N+1 位以下はすべてゼロ」というステップ関数的な賞金構造を持ちます。「入賞圏に入れば同じ」という性質から、生存を最優先にして不必要なリスクを避ける戦略が支配的になります。詳細は第16章参照。

**ステップ関数（サテライト）**  
サテライトの賞金構造を数学的に表現した概念。N 位以内なら等価（全員が同じ賞金）、N+1 位以下はゼロ、という急峻な「段差」を持つ関数です。通常の傾斜型賞金構造と比較して ICM の計算が大きく変わります。詳細は第16章参照。

**フリーズアウト**  
バイインが1回限りのトーナメント形式。バストしたら終わりという緊張感があり、ICM 圧力がクリーンな形で機能します。詳細は第1章参照。

**リバイ**  
ゲーム開始後の一定時間（リバイピリオド）内に追加バイインでチップを補充できるトーナメント形式。リバイピリオド中は ICM 圧力が下がります。詳細は第1章参照。

**リエントリー**  
バストアウト後に新規バイインで再参加できるトーナメント形式。現代のライブ MTT やオンラインの大型トーナメントで主流です。詳細は第1章参照。

**ペイジャンプ**  
順位が1つ上がることで賞金が大きく増加する節目。FT 内や特定の順位（例: 10位 → 9位でファイナルテーブル入り）で発生します。ペイジャンプ直前は ICM 圧縮が局所的に最大化します。詳細は第14章参照。

**バブル / バブルブレイク**  
「バブル」は賞金圏（ITM）に入る直前の状態で、次の脱落者が ITM 入賞を全員に確定させる局面を指します。「バブルブレイク」はバブルが解消された瞬間（最後の賞金圏外者が脱落した瞬間）です。バブル直前は ICM 圧力が最大化（等スタック STT で必要 equity 65%）し、バブルブレイクで急落します。詳細は第13章参照。

**序盤 / 中盤 / 後半**  
トーナメントのステージ分類。本書では M 値とチップ数の変化を基準にします。序盤はフィールドの 50% 以上が残り ICM 圧力が低い段階（ICM 補正 ≈ 0.05）、中盤は M 値 10〜25 程度で ICM 補正が 0.20 前後に高まる段階、後半はバブル直前まで ICM 圧力がじわじわと上昇する段階です。詳細は第3章・第11〜12章参照。

**持ち分 / 取り分**  
ICM equity を「あなたが賞金プールから受け取れる期待額」として表現した呼び方。「持ち分」はスタックに基づく ICM equity のことを指し、「取り分」も同義です。本書では文脈に応じて使い分けます。詳細は第4章参照。

**ターボ / ハイパー**  
ブラインド進行の速いトーナメント形式。ターボは1レベル5〜10分、ハイパーは3分以下です。スタート直後からショートスタック戦略（プッシュ/フォールド）が主体になります。詳細は第1章・第17章参照。

**ミディアムスタック**  
スタック深度の中間層（概ね M 値 10〜20、BB スタック 25〜50BB）。バブル直前ではミディアムスタックが ICM 圧縮の最大値を受けます（大スタックからも小スタックからも BF が高い状態）。詳細は第5章・第8章参照。

**ティルト**  
感情的な乱れによって判断能力が低下した状態。トーナメントではバストアウト後のリエントリー判断やバブル脱落後の後悔がティルトを引き起こしやすい。本書ではサンクコスト（バイイン分の「元を取りたい」心理）とセットで扱います。詳細は第18章参照。

## B-4 巻①-⑤ 用語の継承

巻⑥ ではキャッシュゲーム向けに確立した巻①-⑤ の用語・式を「ICM 補正を加えて拡張する」という使い方をします。定義は巻①-⑤ から変更していません。巻⑥ で特に頻出するものを以下に再掲します。

### 簡易レンジスコア（巻①-③）

フロップのレンジ全体の CBet 頻度を 0〜10 で予測するマクロモデル。ストレート要素・フラッシュ要素・ハイボードリスクを入力とし、ドライ / セミウェット / ウェットの分類を出発点にします。巻⑥ では第7章（ディープスタック）でキャッシュ同様に適用し、スタック深度が浅くなるにつれて適用頻度が下がります。巻②・巻④ 参照。

### 精密レンジスコア（巻③）

簡易レンジスコアを精密化した CBet 頻度予測モデル。外れ値ボード（通常の分類で合わないボード）を吸収します。巻⑥ では深スタック（M ≥ 20）のポストフロップ判断でのみ参照します。巻③ 参照。

### HandScore（ハンドスコア）（巻②）

ハンドの強さを 0〜100（自分の equity %）で数値化した指標。後手スコアの中核を構成します。

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
```

巻⑥ では後手スコアを通じて引き継ぎます。ICM 補正による「コール基準の引き上げ」は HandScore ではなく必要 equity 側に反映します。巻⑥ 参照。

### 後手スコア（巻④・巻⑤）

フロップ・ターン・リバーでのディフェンス（コール / フォールド / CR）判断式。

```
後手スコア = HandScore + A − C − M_multiway
（HU 前提のとき M_multiway = 0）

後手スコア ≥ 40 → チェックレイズ検討
後手スコア 20〜39 → コール
後手スコア < 20  → フォールド

A（ボード値）: ドライ=12 / セミウェット=6 / ウェット=0
C（ベット負担）: 33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30
M（マルチウェイ）: HU=0 / 3-way=12 / 4-way+=22
```

巻⑥ の第19章では、コール基準（後手スコア 20 のライン）を ICM 補正に応じて引き上げる補正を扱います。巻④・巻⑤ 参照。

### バレルスコア（巻④）

ターンで IP が CBet（バレル）を打つかどうかを判定する暗算式。

```
バレルスコア = FlopType係数 + TurnCard係数

FlopType係数: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
TurnCard係数: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0

≥ 7 → 積極バレル（レンジ全体）
< 7 → ハンド依存
```

巻⑥ では第19章でバレルスコアはそのまま（ICM 補正なし）と説明しています。バレル打つかどうかはチップ EV に基づく判断であり、ICM の影響が限定的なためです。巻④ 参照。

### α 式（巻④）

先手がブラフを打ったとき、ブラフが利益になるための最低フォールド率（α）と、そこから派生するリバーのバリュー・ブラフ配分の設計式。

```
α = ベット額 ÷ (ポット + ベット額)
後手下限確率 = 1 − α
```

巻⑥ の第19章では、ICM 補正がある局面でコール基準が上がる（後手下限確率が高くなる）ことを扱います。α 式そのものは変わらず、ICM 補正が「コールに必要な equity」を追加で引き上げます。巻⑥ 参照。

### ブロッカー論（巻④）

相手のナッツを構成するカードを自分が保有することで、相手のナッツ確率が下がり、ブラフの成功率が上がるという戦略的考え方。リバーのバリュー・ブラフ配分設計に使います。巻⑥ では深スタック局面（第7章）で言及します。巻⑥ 参照。

### 後手下限（巻①-③・巻④・巻⑤）

先手のベットに対して後手が守らなければならない最低防御水準の概念。本シリーズでは「MDF」という表記を使わず、文脈に応じて以下の3通りで使い分けます。

| 用語 | 用途 |
|---|---|
| **後手下限ライン** | しきい値・境界として語るとき |
| **後手下限確率** | 具体的な % 数値として語るとき |
| **後手下限スコア** | 後手スコアの式における判断境界（スコア = 20 のライン、新スケール 0-100） |

巻⑥ の ICM 補正は「後手下限ライン」を引き上げる（フォールドしてよい範囲が広がる）効果として機能します。詳細は第19章参照。
