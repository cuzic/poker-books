## 本書の主題 ─ 「ICM 圧縮」のゲーム

トーナメントとキャッシュの違いを一文で示すと、こうなります。

> トーナメントのすべての判断は、**チップを賞金に換算するときの「圧縮率」が刻々と変わる**ことに帰着する。

キャッシュゲームではチップの価値は線形です。1000チップを持つプレイヤーは500チップの2倍の価値を持ちます。勝ったチップはそのまま現金として取り出せます。

トーナメントではこの線形性が崩れます。

```
キャッシュ:     チップ価値 ∝ チップ数（線形）
トーナメント:   チップ価値 ∝ ICM equity（凸関数、逓減）
```

全体チップの50%を持つプレイヤーが得る賞金期待値は、賞金プールの50%ではありません。実際は38〜43%程度になります。これが「ICM 圧縮」です。チップが増えるほど、追加の1チップが生む賞金価値は小さくなる。この性質がトーナメント全体の戦略を変えます。

本書の判断軸はこの ICM 圧縮を扱う3つの概念に集約されます。

**ICM equity** ─ あなたのスタックが現在いくら相当かを示す賞金期待値です。チップ数そのものではなく、賞金構造を通じた換算後の$EVです。残りプレイヤー数とスタック分布によって決まります（第4章）。

**ICM 補正** ─ ICM 圧力の下でオールインを正当化するために必要な「上乗せ勝率」です。キャッシュなら50%で勝率均衡のところ、バブル直前では60〜65%の勝率が必要になることがあります。この「必要な追加勝率」が ICM 補正です（第5章）。

**M 値** ─ あと何周ブラインドを払えるかを示すスタック深度指標です。Harrington が体系化した概念で、ステージ別の戦略を切り替える基準になります（第6章）。

## 本書で導入する3つの暗算式

本書は単独で読めるよう、トーナメントで使う3つの中核概念を本書の中で完全に定義します。

### ICM equity（本書 第4章）

```
ICM equity ≈ ICM 計算による「あなたのスタックの賞金期待値」

簡易暗算の考え方:
  チップ比率 → ICM equity 比率（限界価値逓減で補正）
  → 賞金プール × ICM equity 比率
```

チップ比率が同じでも、残りプレイヤー数・スタック分布・ペイアウト構造によって ICM equity は変動します。第4章では Malmuth-Harville アルゴリズムの仕組みを理解し、第6章で暗算可能な近似式を導出します。

### ICM 補正（本書 第5章）

```
ICM 補正 = bubble factor − 1.0

目安:
  序盤・中盤（フィールド 50%以上残）: 0〜10%（cEV ≈ $EV）
  バブル直前（残 1.5倍ITM人数）    : 20〜40%
  バブル中（残 1.1倍ITM人数）      : 30〜50%（最大圧力）
  ITM 突破後                       : 0〜10%（プレッシャー解放）
  ファイナルテーブル（大きなペイジャンプ）: 20〜40%
  ヘッズアップ                     : 0%（線形回復）
```

「通常50%で勝率均衡のところ、ICM 圧力下では何%の勝率が必要か」をこの補正値が示します。巻②・5 の後手スコアの C 項に上乗せする形でキャッシュ用式を拡張します。

### M 値（本書 第6章）

```
M 値 = スタック ÷ (SB + BB + アンテ合計)

ゾーン分類（Harrington 系譜）:
  Green Zone  (M ≥ 20)  : 深スタック、キャッシュ寄りの判断
  Yellow Zone (M 10-20) : 標準的 MTT、小幅 ICM 調整
  Orange Zone (M 6-10)  : 積極ショブ域、3bet シャブを多用
  Red Zone    (M ≤ 5)   : プッシュ/フォールド完結
```

M 値は「今どのステージにいるか」を即座に数値化します。スタックの絶対量ではなくブラインドとの比率で測るため、ブラインドが上がるにつれて M 値は自動的に下がります。これがステージ別の戦略切り替えの基準になります。

## 想定読者

本書は以下のような読者を想定しています。

**シリーズ読者でトーナメントに挑戦したい方。** 巻①〜5 で積み上げたキャッシュゲームの体系が、トーナメントではどう変わるかを知りたい方に向けています。ICM という補正がどこにどう加わるかを整理します。

**キャッシュゲーム経験者でトーナメントへ移行したい方。** 「トーナメントはキャッシュと何が違うのか」という問いに、数値ベースで答えたい方に向けています。感覚論ではなく、式を使って補正量を把握できます。

**「ICM とは何か」を一度きちんと理解したい方。** 名前は聞いたことがあるが、計算の仕組みや実戦への影響を体系的に学んでいない方に向けています。第4章で ICM の正式な計算方法から始め、暗算用の近似式まで段階的に導きます。

**Push/Fold チャートを暗記ではなく原理から導きたい方。** M 値・ICM 補正・ナッシュ均衡の関係を理解すれば、チャートを丸暗記しなくても合理的なプッシュ/フォールド判断ができます。第10章でその仕組みを示します。

## 本書の構成

本書は6部21章と付録で構成されています。

### 第I部　トーナメントとキャッシュの違い（第1〜3章）

トーナメントの「外形」と「なぜキャッシュとは違うのか」を3章で扱います。トーナメントの形式・ブラインド構造・ペイアウト構造を確認し（第1章）、チップを賞金に換算する ICM の概念を導入し（第2章）、ステージ別の ICM 圧力の変動を全体像として示します（第3章）。

| 章 | タイトル |
| --- | --- |
| 第1章 | トーナメントの構造と進行 |
| 第2章 | chip EV vs $EV ─ ICM の概念 |
| 第3章 | ステージ別戦略の全体像 |

### 第II部　ICM equity の暗算（第4〜6章）

本書の3核心式を導出します。ICM の正体（第4章）、リスクプレミアムとしての ICM 補正（第5章）、暗算可能な ICM equity 近似式（第6章）の順で、計算の仕組みから実戦で5秒で使える形まで段階的に進みます。

| 章 | タイトル |
| --- | --- |
| 第4章 | ICM equity とは ─ ICM の正体 |
| 第5章 | ICM 補正（リスクプレミアム） |
| 第6章 | ICM equity の暗算式と M 値 |

### 第III部　スタック深度別戦略（第7〜10章）

スタック深度（M 値のゾーン）によって戦略がどう変わるかを4章で扱います。100BB 以上のディープスタックではキャッシュ的判断が有効で（第7章）、スタックが減るにつれて ICM 補正と M 値の比重が増します（第8〜9章）。15BB 以下では Push/Fold が完結した戦略になります（第10章）。

| 章 | タイトル |
| --- | --- |
| 第7章 | ディープスタック（100BB+） |
| 第8章 | ミディアムスタック（40〜100BB） |
| 第9章 | ショートスタック（15〜40BB） |
| 第10章 | プッシュ/フォールド（15BB 以下）─ M 値圏 |

### 第IV部　ステージ別戦術（第11〜15章）

序盤・中盤・バブル・ITM 後・ヘッズアップというステージ別に、戦術の焦点を変えて解説します。ICM 補正がほぼゼロの序盤（第11章）から最大圧力のバブル（第13章）、そしてヘッズアップで線形に戻る（第15章）まで、ステージごとの判断の変化を追います。

| 章 | タイトル |
| --- | --- |
| 第11章 | 序盤戦術 |
| 第12章 | 中盤戦術（アンテ導入後） |
| 第13章 | バブル戦略 |
| 第14章 | ITM 後・ファイナルテーブル |
| 第15章 | ヘッズアップ |

### 第V部　応用シナリオ（第16〜18章）

標準的なフリーズアウト以外の特殊形式を扱います。賞金構造が極端に非線形なサテライト（第16章）、ブラインド上昇速度が早いターボ・ハイパー（第17章）、サンクコストやペイジャンプの誘惑といったトーナメント特有の心理（第18章）を扱います。

### 第VI部　統合と実戦（第19〜21章）

巻①〜5 の全暗算式に対して ICM 補正を適用した統合版を示し（第19章）、トーナメント特有のハンドレビュー方法を解説し（第20章）、総合ドリル50問で定着を図ります（第21章）。

### 付録（A〜C）

- **付録A**：実戦クイックリファレンスカード（ICM 補正早見表・M 値ゾーン早見表・Push/Fold チャート）
- **付録B**：用語集（ICM equity、ICM 補正、bubble factor、M 値など巻⑤ 新規用語）
- **付録C**：シリーズ全体の式の継承関係（キャッシュ式 → ICM 補正版 対応表）

## 読書ルートの推奨

### 標準ルート（推奨）

第1章から順に読み進めてください。トーナメントの外形（第I部）→ 3核心式（第II部）→ スタック深度別戦略（第III部）→ ステージ別戦術（第IV部）→ 応用シナリオ（第V部）→ 統合と実戦（第VI部）の順で理解が積み上がります。

### ICM の仕組みを既知の方

第I部をざっと読み流し、第II部（第4〜6章）で本書の式の形式を確認してから第III部へ進んでください。第II部は「仕組み」より「どう暗算するか」に重点を置いているため、概念を知っている方でも読む価値があります。

### トーナメント特化したい方

第1〜6章で土台を固め、第IV部（ステージ別戦術）から重点的に読んでください。特にバブル（第13章）とファイナルテーブル（第14章）は、実戦でよく直面する場面に対応します。

## 巻①〜5 との接続

本書は巻①〜5 のキャッシュ用式を ICM 補正で拡張します。以下の関係を押さえておくと、本書を読む際の地図として機能します。

```
巻① Score（オープン/3bet 判断）
  → 巻⑥ では ICM 補正でショートスタック時のオープン基準を引き上げる
    小スタックで ICM 圧力が高い場面ほど、必要勝率が上がる

巻② 後手スコア = HandScore + A − 3 − C − M
  → 巻⑥ では C 項に ICM 補正を上乗せしてコール基準を厳しくする
    バブル直前では 20〜40%分のエクイティ要求が追加される

巻④ バレルスコア（ターンの攻撃判断）
  → 巻⑥ では補正不要
    「このボードでバレルできるか」はキャッシュと同じ判断でよい

巻④ α 式（リバー配分）
  → 巻⑥ では ICM 補正でコール基準が上がる
    コールに必要なエクイティが上昇し、フォールドがより正当化される
```

この拡張全体を第19章でまとめます。本書を読み終えた後、付録Cで式の継承関係を一覧できます。
