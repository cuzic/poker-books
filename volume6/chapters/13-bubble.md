# 第13章　バブル ─ ICM 補正のピーク

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: バブル局面における ICM 補正の最大圧力を理解し、大スタック・中スタック・ショートスタックそれぞれの正しい戦術方針を実戦で即座に選べるようにする。

---

## 13-1 バブルという極限状態

第3章のステージ別全体像で、ICM 補正は山型のグラフを描くと説明しました。その山の頂点がバブルです。

バブルとは「あと1人（MTT では複数）脱落すれば全員が賞金圏（ITM）に入る」というステージです。この局面では、1チップを失うことの $EV ペナルティが最大化します。第5章で確認した通り、STT（9-max、Top 3 払い）のバブル直前では ICM 補正が 0.875 に達します。これは「チップを失うことの $EV 損失が、同量を得るときの $EV 利益の約 1.9 倍」を意味します。

この非対称性は、バブルを他のすべてのステージから質的に異なるものにします。必要 equity が 50% から 65% に跳ね上がるだけではありません。スタックの大小によって正解が全く逆になるという「ゲームの分岐」が生まれます。

大スタックは攻撃的になれます。中スタックは極端に守備的にならざるを得ません。ショートスタックは「失うものが少ない」という逆説的な自由を持ちます。同じバブルのテーブルに座っていても、自分のチップ量によって正解のアクションは真逆になることがあります。

本章では、この三者の非対称性を bubble factor 行列から定量的に読み解き、それぞれの戦術方針を具体的に示します。

---

## 13-2 バブルの定義とパラメータ

### バブルの識別方法

バブルに入ったかどうかの判定基準は「ITM ライン（賞金圏入り最低順位）まで何人残っているか」です。

```
バブル判定の目安:
  残りプレイヤー数 ÷ ITM 入賞人数 ≤ 1.5 → バブル圏内
  残りプレイヤー数 ÷ ITM 入賞人数 ≤ 1.1 → バブル直前（最大圧力）
```

具体例で確認します。

**STT バブル（STT の典型例）**: 9人テーブル、Top 3 払い。残り4人になった瞬間がバブル直前です。4 ÷ 3 = 1.33 倍で、バブル圏内の基準 1.5 を下回ります。誰か1人が脱落すれば全員 ITM 確定となります。

**MTT バブル**: 参加者 100 人、Top 15 払い。残り約 20〜22 人が「バブル圏」、残り 16〜17 人が「バブル直前」です。MTT ではバブルに入る瞬間が段階的で、15人に近づくほど ICM 補正が高まっていきます。

> **核心式：バブルファクター（BF）**
>
> ```
> BF = 失う $EV ÷ 得る $EV
> コールに必要なエクイティ = BF ÷ (BF + 1)
> ```
>
> BF = 1.0（キャッシュゲーム水準）なら必要エクイティは 50%。BF = 2.90（中スタックがリーダーのオールインに対峙するバブル直前）なら必要エクイティ = 2.90 ÷ 3.90 ≈ **74%** に跳ね上がる。BF は「失うリスクが得る機会より何倍大きいか」を直接表す指標であり、スタック別の非対称性を一つの数値で表現する。
>
> **スタック別の傾向**: 中間スタックの BF が最高（最大 2.90）になり、ビッグスタック・ショートスタックは低い（1.11〜1.73）。「中間スタックが最もバブルを恐れる」ことを BF が定量化している。PKO（プログレッシブノックアウト）ではバウンティエクイティがリスクを上回る場合、BF < 1.0 になることもある。

### バブルの基本パラメータ

```
バブル直前（STT n=4、Top 3 払い）:
  等スタック ICM 補正 : 0.875
  必要 equity         : 65%
  bubble factor（平均）: 1.875

バブル直前（MTT、Top 60% 払い）:
  等スタック ICM 補正 : 0.40
  必要 equity         : 58%
  bubble factor（平均）: 1.40
```

（`scripts/icm_calc.py` 実測値。第5章の表に準拠。）

STT と MTT でバブルの圧力に大きな差があることを確認してください。STT バブルは「1人脱落で全員 ITM」という急な崖があるため、補正が飛び抜けて高くなります。MTT は賞金圏に入れない人数が多く残っているため、圧力がやや分散します。

バブル戦術は「どの種別のバブルか」によって目盛りを変える必要があります。本章では主に STT バブル（最大圧力の条件）を軸に説明し、MTT バブルとの差異を補足します。

### スタック構成の典型例（本章の軸）

本章では以下のスタック構成を基準として使います。第5章・第6章と同じ実測シナリオです。

```
9-max STT バブル（4人残り、賞金 50/30/20）
  P1: 4500 chip（チップ 45%）── チップリーダー
  P2: 3000 chip（チップ 30%）── 中スタック上位
  P3: 1500 chip（チップ 15%）── 中スタック下位
  P4: 1000 chip（チップ 10%）── ショートスタック
  合計: 10000 chip
```

各プレイヤーの平均 ICM 補正は以下の通りです（`scripts/icm_calc.py` 実測）。

| プレイヤー | Chip% | 平均 ICM 補正 | 必要 equity（平均） |
| :--- | ---: | ---: | ---: |
| P1（リーダー） | 45% | 0.270 | 57% |
| P2（中スタック上位） | 30% | 0.784 | 64% |
| P3（中スタック下位） | 15% | 0.825 | 65% |
| P4（ショート） | 10% | 0.529 | 61% |

この非対称性が、本章の3つの戦術方針の根拠になります。

## 13-3 大スタックの戦略 ─ 圧力をかける側

### リーダーの ICM 補正が意外に低い理由

チップリーダー（P1、チップ 45%）の平均 ICM 補正は 0.270 です。直感的には「一番失うものが多いリーダーが一番守備的になるべき」と思えますが、数値は逆を示しています。

その理由は bubble factor 行列にあります。

| Hero \ Villain | P1 (45%) | P2 (30%) | P3 (15%) | P4 (10%) |
| :--- | ---: | ---: | ---: | ---: |
| **P1** | — | 1.53 | 1.17 | 1.11 |
| **P2** | 2.90 | — | 1.29 | 1.16 |
| **P3** | 2.25 | 2.04 | — | 1.19 |
| **P4** | 1.73 | 1.60 | 1.25 | — |

P1 が他のプレイヤーに対して仕掛けるとき、BF は 1.11〜1.53 という比較的低い値にとどまります。これは P1 が「攻める側」に立つと、相手を脱落させることで自分も含めた残全員が ICM 利得を得るためです。一方で P2・P3・P4 が P1 に対して仕掛けるときの BF は 1.73〜2.90 と跳ね上がります。「上から押される」側は激烈に不利になります。

つまりリーダーは BF が低い側に回ることができる唯一のポジションです。これがリーダーに攻撃的な戦術が許される定量的根拠です。

### リーダーの具体的な戦術

**オープン頻度を引き上げる**

バブル直前では中スタックがフォールドしやすくなります。ICM 補正 0.784〜0.825 に縛られた中スタックは、コールして大きな勝負に入ることを極度に嫌います。リーダーはこの守備的な傾向を利用して、スティール頻度を大幅に上げます。

```
リーダーのオープン頻度の目安（バブル直前）:
  BTN: 60〜70%（通常の中盤 55〜60% より引き上げ）
  CO:  50〜60%
  SB:  50〜60%
```

**3bet ブラフを混ぜる**

中スタックがオープンしてきたとき、リーダーは 3bet ブラフを通常より高頻度で混ぜます。中スタックは BF = 2.90（P2 から見た P1 へのリスク）という極端な圧力下にあるため、3bet に対して 4bet シャブを選びにくくなります。バリューハンドでなければ中スタックはフォールドせざるを得ません。3bet ブラフのフォールドエクイティが通常より高い状態です。

**薄い value も拾いに行く**

中スタックは守備的なので、リーダーがポストフロップでベットすると中程度の強さのハンドでもフォールドします。フロップのセカンドペアやトップペアでの薄いバリューベットが通常より高頻度で通ります。ただしオールインの勝負に発展する場合は必要 equity 57%（BF ≈ 1.27）の基準を守ります。

### 「上から押す」の実戦展開

以下のような展開がバブル直前のリーダーに典型的に訪れます。

```
リーダー（P1）が BTN から 2BB にオープン。
中スタック（P2）が BB でコール。
フロップ: K-7-2 レインボー。
P2 がチェック。P1 が 3BB にベット。P2 がフォールド。
```

P2 は K-7-2 でトップペアを持っていても、ICM 補正 0.784 という圧力下ではポットが育つことを恐れます。P1 のベットに対して「コールしてさらにチップを失うリスク」を嫌い、フォールドを選びやすくなります。P1 は中スタックの守備的傾向を利用して、フロップの CBet 成功率を高めることができます。

中盤なら合理的なコールになる場面も、バブル直前では ICM 補正がコール判断を歪め、フォールドに向かわせます。リーダーはその「歪み」を利益として受け取る立場です。

## 13-4 中スタックの戦略 ─ 最も苦しい立場

### なぜ中スタックが最も苦しいか

バブル直前における ICM 補正の序列は「中スタック > ショート > リーダー」です。中スタックが最も高い補正（0.784〜0.825）を背負います。

この非対称性の理由は第5章で確認しました。中スタックは「現在の ICM equity が最もペイジャンプに近い状態」にあります。オールインで負ければ一気に脱落または最低レベルのショートになり、賞金を逃します。勝っても次のリーダーになれるだけで、ICM 的な限界価値は低下します。失う $EV が得る $EV を大きく上回る、これが中スタックの構造的な苦しさです。

P2（チップ 30%）が P1（チップ 45%）のオールインを受ける場面で、BF = **2.90** です。必要 equity は 2.90 ÷ (2.90 + 1) ≈ **74%** に達します。KK 対 任意レンジでおよそ 80% 程度の equity があるとして、やっと余裕のある勝負になる水準です。AK や QQ ですら BF = 2.90 の壁を越えるのは厳しくなります。

### コール基準の大幅な引き上げ

中スタックの戦術の核心は「コール頻度を大幅に削減する」ことです。

平均 ICM 補正 0.784 は必要 equity 64% を意味します。これは「ランダムな相手に対して KK 以上に近い equity がないとコールできない」水準です。実戦ではオールインを受けた相手のレンジが絞られているため、個別の計算が必要ですが、全般的な方針として「コール基準を大幅に引き上げる」ことが正解です。

```
中スタックのコール判断の目安（バブル直前 STT）:
  BF = 2.90（vs リーダー）: 必要 equity 74% → コールは AA/KK のみ
  BF = 2.04（vs 同格中スタック）: 必要 equity 67% → コールは KK+ / AK
  BF = 1.16（vs ショート）: 必要 equity 54% → コールはやや広め
```

コール可能なハンドの水準が「対戦相手のスタックサイズ」によって大きく変わることに注目してください。リーダーのプッシュに対しては極端に絞り、ショートのプッシュに対しては比較的広く対応します。

### オープン・3bet の戦術

コール基準が跳ね上がるということは、受け身の判断が難しくなるということです。一方で「自分がオープンして相手をフォールドさせる」という戦術は、相手も守備的になっているため一定の有効性を保ちます。

```
中スタックのアクション方針（バブル直前）:
  オープン: バリューハンド中心に絞る（ブラフオープンは控えめ）
  3bet: バリュー中心（ブラフ 3bet は極力排除）
  コール: 相手別の BF で必要 equity を計算し、基準を厳守
```

オープンを絞る理由は「コールされてリーダーと大きな勝負になるリスク」を避けるためです。BTN から広いレンジでオープンして、リーダーが SB から 3bet してきた場合、中スタックは 4bet シャブも困難、コールも困難、フォールドしかない状況に追い込まれます。オープンレンジを絞ることで、この板挟みに入る頻度を下げます。

**3bet シャブによる spot 作り**は例外的に有効です。ショートスタックがオープンしてきた場合、中スタックが 3bet シャブを仕掛けると、ショートは BF = 1.25（ショート vs 中スタック）の水準で判断します。一方中スタックは BF = 1.29 程度で仕掛ける側に回れます。リーダーが参加していない 2 人の勝負に絞ることで、ICM 圧力を最小化した勝負の場を作れます。

### 「下から賭けられない」の実戦展開

```
中スタック（P2）が CO から 2.5BB にオープン。
リーダー（P1）が SB から 8BB に 3bet。
P2 の選択肢:
  ① コール  → SPR が低いポットで P1 と戦う（ICM 的に不利）
  ② 4bet シャブ → AK/QQ 以上がないなら $EV マイナスになりやすい
  ③ フォールド → 最も合理的
```

P2 がブラフの 3bet や弱いバリューハンドでオープンしていた場合、P1 の 3bet に対して応手がありません。「コールも難しい、シャブも難しい、フォールドするしかない」という板挟みが、バブル直前に中スタックが陥る典型的な状況です。

この状況を避けるためにも、中スタックはオープンレンジをバリュー寄りに絞り、「コールされても戦える」「3bet されてもシャブに切り替えられる」強さのハンドを中心に参加します。

## 13-5 ショートスタックの戦略 ─ 失うものが少ない自由

### ショートの ICM 補正が中スタックより低い理由

P4（チップ 10%）の平均 ICM 補正は 0.529 です。中スタック（P2: 0.784、P3: 0.825）より低く、リーダー（P1: 0.270）よりは高い水準です。

なぜショートの補正が低いのでしょうか。ショートはすでに「失えるチップが少ない」状態にあります。オールインで負けても失う $EV は小さく、ICM ペナルティも小さくなります。生存価値は一定ありますが、それほど大きな ICM equity を現在持っているわけではないため、「失って当然の小さなプレミアム」しか積まれていないのです。

この性質が、ショートに相対的な自由を与えます。

### ショートの戦術方針

**積極的なオールインプッシュ**

M ≤ 5 のショートになれば push/fold ゲームに完全移行します（第10章参照）。バブル直前であっても、ショートにとって「プッシュする」ことの ICM ペナルティは中スタックほど大きくありません。BF ≈ 1.53 の水準（P4 が P1 にプッシュ）であれば、必要 equity は 1.53 ÷ 2.53 ≈ 60% です。vs 任意レンジで AT 以上、88 以上程度がコール圏になります。

M が 6〜10 のオレンジゾーンであっても、3bet シャブ（オープンレイズに対するオールインリレイズ）が主要な武器です。バブル直前では相手が中スタックなら BF = 1.25（P4 が P3 にシャブ）で、必要 equity 56% と比較的低い基準になります。ショートは「相手が中スタック以下の勝負」に絞ってプッシュすることで、ICM 圧力を最小化できます。

**コールは極めてタイト**

自分がプッシュする側でなく、コールを求められる側に回るときは基準が異なります。リーダーや中スタックのプッシュに対してコールすると、ショートが脱落する可能性が高くなります。この場合の必要 equity は BF から計算します。

```
P4 がコールを求められる場合の BF と必要 equity:
  vs P1（リーダー）のプッシュ: BF = 1.73 → 必要 equity 63%
  vs P2（中スタック上位）のプッシュ: BF = 1.60 → 必要 equity 62%
  vs P3（中スタック下位）のプッシュ: BF = 1.25 → 必要 equity 56%
```

コールの基準もバブルの影響を受けますが、「プッシュする基準」よりは広い水準です。ショートがコールしてリーダーに負けた場合の $EV 損失は、中スタックの同じ場面より小さいためです。

**より小さなスタックを狙う**

bubble factor 行列の最も重要な教訓は「自分より小さなスタックを狙え」です。P4（10%）の視点では、P3（15%）との勝負の BF は 1.25、P2（30%）との勝負の BF は 1.60 です。小さなスタックを狙うほど BF が低く、攻めやすくなります。

ただしバブル直前のショートにとって「P3 が脱落すれば自分も ITM」というインセンティブが働くことも覚えておきます。P3 がオールインして成功してくれれば、P4 は何もせずに ITM に近づきます。闇雲にプッシュするよりも、他の脱落を待ちながらタイミングを計ることも戦術のひとつです。

## 13-6 Bubble factor 行列の活用

### 行列の読み方

本章の軸となる bubble factor 行列を改めて整理します。

| Hero \ Villain | P1 (45%) | P2 (30%) | P3 (15%) | P4 (10%) |
| :--- | ---: | ---: | ---: | ---: |
| **P1** | — | 1.53 | 1.17 | 1.11 |
| **P2** | 2.90 | — | 1.29 | 1.16 |
| **P3** | 2.25 | 2.04 | — | 1.19 |
| **P4** | 1.73 | 1.60 | 1.25 | — |

行（Hero）が自分のスタック、列（Villain）が対戦相手のスタックです。セルの値が BF、必要 equity は BF ÷ (BF + 1) で計算します。

### 戦術的読み方：3つの鉄則

**鉄則1: 大きなスタックとのオールインは避ける**

P2（中スタック）から見て P1（リーダー）との BF は 2.90 です。必要 equity は 74% に達し、AA を除いてほぼコールできる手がありません。「大きなスタックとの全面対決はバブル直前に割に合わない」を数値で確認してください。

P3（中スタック下位）から見ても P1 に対する BF は 2.25、必要 equity 69% です。AK や QQ でも届かない水準です。

**鉄則2: 小さなスタックを積極的に狙う**

P1 から見た P4 の BF は 1.11、必要 equity 53% です。リーダーがショートのオールインを受けるコスト（ICM 的）はほぼゼロに近い水準です。リーダーは広いレンジでショートのプッシュを受けられます。同様に P3 から見た P4 の BF は 1.19、必要 equity 54% です。

**鉄則3: 中スタック同士の勝負は意外に高い**

P2 から見た P3 の BF は 1.29（必要 equity 56%）、P3 から見た P2 の BF は 2.04（必要 equity 67%）です。小さい方（P3）から大きい方（P2）に仕掛けるときの BF が高くなっています。中スタック同士でも「上から下に攻める」と「下から上に攻める」では BF が大きく異なります。

### 暗算の近似手順

卓上でリアルタイムに全セルを計算するのは現実的ではありません。以下の近似を使います。

```
バブル直前の暗算近似:
  1. 自分 vs 相手のスタック比を確認する
  2. 相手が自分より「大きい」か「小さい」かを判断する
  3. 「大きい相手」とのオールイン: ICM 補正を最大区分（STT なら 0.875 以上）に設定
  4. 「小さい相手」とのオールイン: ICM 補正を最小区分（0.1〜0.3）に設定
  5. 必要 equity = BF ÷ (BF + 1) で判断
```

等スタックの場合は STT バブル等スタック ICM 補正 0.875（必要 equity 65%）を基準にします。

## 13-7 バブルブレイクの瞬間

### ICM 補正の急落

バブルブレイクとは、1人（MTT では複数）が脱落して全員が賞金圏に入ることです。この瞬間、ICM 補正の値が劇的に変化します。

```
STT 9-max バブル前後:
  バブル直前（n=4）: ICM 補正 0.875（必要 equity 65%）
  バブルブレイク後（n=3、3-handed）: ICM 補正 0.32（必要 equity 57%）
```

（第5章の実測値に準拠。）

ICM 補正が 0.875 から 0.32 へと約 1/3 に落ちます。必要 equity が 65% から 57% に下がります。コール判断において「8ポイント分の幅」が一気に解放されます。

この変化は非常に急速で、1ハンドで完結します。脱落者が出た瞬間にゲームのルールが変わると理解してください。

### バブルブレイク後の戦術的シフト

バブル直前の「極端に守備的な全員」から、バブルブレイク後の「再び積極的な全員」への転換は必然的に起こります。

```
バブルブレイク後の即時シフト:
  コール基準: 65% → 57%（約 8 ポイント緩和）
  オープン頻度: やや絞っていた状態 → 中盤水準に戻す
  ブラフ 3bet: 抑制していた状態 → 通常頻度に戻す
```

特にリーダーはバブル直前に「圧力をかける側」にいたため、バブルブレイク後も引き続きアグレッションが基本方針です。ただし ICM 補正が下がるため「攻撃の根拠が BF ではなく Chip EV に近づく」という変化があります。

中スタックとショートはバブルブレイクで「生存達成」という安堵が生まれますが、再び積極的なアクションに切り替えることが $EV を最大化します。「ITM に入れたから慎重に」ではなく「ICM 補正が下がったから再び動く」が正しい解釈です。

### バブルブレイクを狙う判断

プレイヤーが4人残っているとき、他のプレイヤーがオールイン勝負を始めた場合は「脱落を待つ」という選択肢が生まれます。特にショートスタックのプレイヤーは「今プッシュするより、他の対決を待つ方が $EV が高い」という局面があります。

バブルブレイクを他人の力で達成する「不戦の ITM」は、自分がリスクを取らずに賞金圏を確保する最高の結果です。ただしフォールドしながら待てる時間はブラインドの上昇とともに短くなります。M 値 ≤ 3 になれば待つ余裕はなく、プッシュしなければチップが溶け続けます。

## 13-8 バブル暗算チェックリスト

実戦でバブルを迎えたとき、以下のステップで即座に判断します。

```
ステップ 1: バブル確認
  残りプレイヤー ÷ ITM 入賞人数 ≤ 1.5 → バブル圏
  ≤ 1.1 → バブル直前（最大圧力モード）

ステップ 2: ICM 補正を設定する
  STT バブル直前 → ICM 補正 0.875、必要 equity 65%
  MTT バブル直前 → ICM 補正 0.40、必要 equity 58%

ステップ 3: 自分のスタック位置を判定する
  チップ 35% 以上 → リーダー（攻撃モード）
  チップ 15〜35%  → 中スタック（守備モード）
  チップ 15% 未満 → ショート（プッシュ・待機のどちらか）

ステップ 4: 対戦相手との BF を確認する
  相手が自分より大きい → BF 高い → 必要 equity を上の区分に設定
  相手が自分より小さい → BF 低い → 必要 equity を下の区分に設定
  等スタック基準: STT なら BF ≈ 1.875 → 必要 equity 65%

ステップ 5: 立場別の行動方針を適用する
  リーダー → スティール拡大、3bet ブラフを混ぜる、薄い value を拾う
  中スタック → コール基準を大幅引き上げ、オープンはバリュー寄り
  ショート → 小スタックへのプッシュを軸に、大スタックのコールはタイト

ステップ 6: バブルブレイク後は即座にシフトする
  ICM 補正 0.875 → 0.32 の急落を認識
  必要 equity が 65% → 57% に緩和
  全員が再びアグレッシブになることを前提に自分も切り替える
```

## 13-9 ミニクイズ

### 問1

STT バブル直前（4人残り）。スタックは P1: 4500、P2: 3000、P3: 1500、P4: 1000 です。あなたは P3（1500 chip）で、P1（4500 chip）が SB から全員にオールインプッシュしてきました。あなたは A-T を持っています。コールしますか。

1. コールする（AT は強いハンド。バブルでも十分な equity がある）
2. コールする（ショートに近いスタックだから ICM 補正は低いはず）
3. フォールドする（BF = 2.25、必要 equity 69%。AT の vs P1 の広いプッシュレンジに対する equity は約 55%、基準に届かない）

### 問2

STT バブル直前。あなたは P1（リーダー、4500 chip）でBTN ポジションです。P3（1500 chip）がCO から 3BB にオープンしました。SB はフォールド。あなたが 3bet するとしたら、どのハンドまでブラフ 3bet の候補になりますか。

1. A5s のみ（バブルだから 3bet ブラフは最小限に）
2. A5s・K9s・QTs 程度（中スタック P3 の守備的傾向から、フォールドエクイティが高い。BF = 1.17 でリスクは低い）
3. 全ハンド（リーダーはバブル直前に何でも 3bet できる）

### 問3

STT バブルがブレイクしました（4人→3人）。あなたはチップリーダーで全チップの 55% を保有しています。バブルブレイク直前と比較して、コール基準はどう変わりますか。

1. 変わらない（ITM に入っても賞金構造の影響は続く）
2. 必要 equity が 65% から 57% 程度に下がり、コール基準が緩和される（ICM 補正が 0.875 から 0.32 へと急落する）
3. 必要 equity が 50% まで下がる（全員 ITM なので Chip EV = $EV になる）

---

### 解答

- **問1**: 3が正解（フォールド）。P3 が P1 のオールインを受けるときの BF = 2.25 です。必要 equity = 2.25 ÷ (2.25 + 1) ≈ 69% になります。AT の vs 任意レンジの equity は約 56% 程度であり、69% の閾値には大きく届きません。さらに P1 の「SB からの全員へのプッシュ」はある程度のバリューが含まれており、実際の相手レンジはランダムよりも絞られています。AT の equity は 69% どころか届かない可能性が高く、フォールドが明確に正解です。

- **問2**: 2が正解（A5s・K9s・QTs 程度）。P1 が P3 に 3bet するときの BF = 1.17 であり、必要 equity は 1.17 ÷ 2.17 ≈ 54% です。P1 にとって P3 との勝負は ICM 的にほぼノーリスクに近い状態です。P3 は ICM 補正 0.825 を背負い、4bet シャブを極度に嫌います。この組み合わせから、P1 の 3bet ブラフのフォールドエクイティは非常に高くなります。A5s にとどまらず、一定の強さ（フラッシュドロー素地や連結性）を持つ投機的なハンドまで 3bet ブラフの候補に入ります。ただし「全ハンド」（選択肢3）は過剰です。P3 がシャブで応じた場合に equity を保てないハンドは除外します。

- **問3**: 2が正解（必要 equity が 65% から 57% 程度に下がる）。バブルブレイクにより残り3人（3-handed）になると、ICM 補正は 0.875 から 0.32 へと急落します。BF で言えば 1.875 から 1.32 程度への変化です。必要 equity = 1.32 ÷ 2.32 ≈ 57% になります。65% → 57% という 8 ポイントの緩和はコール範囲を大きく広げます。選択肢3の「50%（Chip EV = $EV）」は HU（2人）まで人数が減らないと成立しません。3人では依然として賞金構造が非線形であり、ICM 補正はゼロになりません。

---

> **本章まとめ**
>
> - バブルは ICM 補正が最大化するステージ。STT 直前で 0.875（必要 equity 65%）、MTT 直前で 0.40（必要 equity 58%）が目安。
> - 大スタック（リーダー）は ICM 補正 0.270 と低く、攻撃的なスティール・3bet ブラフが正当化される。中スタックの守備的傾向を利用する。
> - 中スタックは ICM 補正 0.784〜0.825 と最高水準に達する。コール基準を大幅に引き上げ（vs リーダーの BF = 2.90 → 必要 equity 74%）、オープンはバリュー寄りに絞る。
> - ショートは ICM 補正 0.529 と中スタックより低く、相対的な自由がある。小スタックを狙って積極的にプッシュし、大スタックへのコールは必要 equity を厳守する。
> - bubble factor 行列の3鉄則: 大きなスタックとのオールインを避ける、小さなスタックを積極的に狙う、中スタック同士でも方向（上から下か下から上か）で BF が異なる。
> - バブルブレイクで ICM 補正が 0.875 → 0.32 へ急落する。必要 equity 65% → 57% に緩和。脱落の瞬間に即座に戦術を切り替える。

**【GTOとのズレ】**

ICMIZER や HRC などの ICM ソルバーはバブル局面を最も精密に計算できます。本章で示した bubble factor 行列と各プレイヤーの ICM 補正は `scripts/icm_calc.py` の実測値に基づいており、ソルバーの出力と整合しています。大スタックが積極的に攻める、中スタックが守備的になる、という定性的な方向性はソルバーと一致しています。

ズレが生じるのは「等スタック基準の ICM 補正を使うことの近似誤差」です。本章では STT バブル直前の等スタック ICM 補正を 0.875 として説明していますが、実際の卓では全員のスタックが異なります。本章の軸となるシナリオ（4500/3000/1500/1000）でも、プレイヤー別の平均 ICM 補正は 0.270〜0.825 と大きく散らばっています。「バブル直前は必要 equity 65%」という単一の目安を全プレイヤーに適用するのは誤りであり、自分のスタックポジションに応じた補正値（本章の表）を使う必要があります。

また、本章の BF 行列は「オールインの勝負」を想定しています。実際のバブル局面ではオールインでなく CBet やフラットコールなど部分的なポットが多く、それらへの ICM 補正の適用は単純な BF 計算とは異なります。「オールインの BF」はあくまで上限の圧力を示す指標であり、ポスト-フロップの小さなベットへの ICM 補正の影響は本章の計算より小さくなります。この点でソルバーは部分的なポットを含むすべての意思決定に精密な ICM 計算を適用しており、本書の暗算より正確な判断を提供します。

実戦の卓ではソルバーを参照できません。「大スタックは攻め、中スタックは守備、ショートは小スタックを狙う」という3軸の方針と、BF 行列の3鉄則を頭に入れておくことで、精密な計算なしにバブルの主要な判断を近似することができます。精度の誤差は概ね数パーセント程度にとどまり、実戦判断には十分な精度です。
