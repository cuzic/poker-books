# 第18章　トーナメント特有の心理

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ICM 計算の知識があっても発生するトーナメント特有の心理的罠を理解し、バイインの呪縛・ペイジャンプの誘惑・ティルト・リエントリー判断を冷静に対処できるようにする。

---

## 18-1 なぜ正解を知っていてもミスするのか

本書の第II部では ICM equity の暗算式を学びました。第III部ではスタック深度別の戦略を、第IV部ではステージ別の戦術を身につけました。しかし現実のトーナメントでは、これらの知識を正確に持つプレイヤーでも繰り返しミスをします。

その原因は、**心理的な歪み**です。

ICM 計算は感情のないツールです。正確に計算すれば常に正解を示してくれます。しかし人間のプレイヤーは感情を持ちます。バイインに払った金額への執着、賞金ジャンプへの誘惑、連続した不運への怒り、これらが判断を曲げます。

本章は「戦術の改善」ではなく「心理の安定」を扱います。第V部の最終章として、応用シナリオをひとつの完成形に収めるテーマです。戦術知識（第1〜17章）と心理コントロール（本章）の両方が揃ったとき、初めて「迷わないトーナメント」が機能します。

## 18-2 サンクコスト ─ バイインの呪縛

### サンクコストとは

**サンクコスト**（sunk cost / 埋没費用）とは、すでに支払われて取り戻せない費用のことです。$300 トーナメントに参加した瞬間に、その $300 は消滅します。テーブルに座っている時点で、バイイン金額は「判断に影響しない数字」になるべきです。

しかし多くのプレイヤーはトーナメント中に次のような思考に陥ります。

```
「$300 払ったのだから、せめて $300 以上は取り戻したい」
「$300 無駄になるのは悔しい。早く元を取らなければ」
「5時間かけてここまで来た。今折れてはいけない」
```

これらはすべて、サンクコストが判断を支配している状態です。ICM 計算上、あなたの現在の $EV はバイイン金額と無関係です。現在の $EV は「あなたの現在のスタック量とペイアウト構造」だけで決まります。

### サンクコストが引き起こす判断の歪み

サンクコストへの固執は、特定のパターンで判断を歪めます。

**過剰なアグレッション**: 「元を取らなければ」という焦りが、必要 equity 基準を下回るオールインや薄いコールに向かわせます。第5章で確認した ICM 補正の計算を無視して、チップを積み上げようとする衝動が生まれます。

**脱落への過剰な恐れ**: 逆に、「$300 をただ失いたくない」という心理が、勝てる勝負でもフォールドさせることがあります。「もう少し生き延びたい」という気持ちが、正しいプッシュ判断のタイミングを遅らせます。

**時間コストの混入**: 「5時間かけてここまで来た」という投下時間も、サンクコストです。現在のスタックが M = 3 のレッドゾーンであれば、5時間の積み上げとは無関係にプッシュ/フォールドに完全移行する必要があります（第10章参照）。

### 正しい思考フレーム

サンクコストの罠から抜け出すための思考フレームは単純です。

```
「いま、このスタックで、この状況で、最も $EV が高いアクションは何か？」
```

この問いには「バイイン金額」も「ここまでかけた時間」も入りません。現在のスタック、相手のスタック、ペイアウト構造、これだけが変数です。判断の入力として使える情報だけを使い、使えない情報（サンクコスト）は意識から切り離します。

## 18-3 ペイジャンプの誘惑

### ペイジャンプの構造と ICM

第14章で確認した通り、トーナメントのペイアウトは階段構造を持ちます。「次のジャンプまで 1 人」の状況では ICM 補正が局所的に上昇し、バブルに準じた守備的な戦術が要求されます。

この構造自体は問題ではありません。ICM 補正が上がれば守備的になることは、$EV を最大化する正しい判断です。

問題が生まれるのは、「ペイジャンプの心理的圧力が、ICM 計算の結果を超えて判断を歪める」ときです。

### 心理的な過剰補正

次のペイジャンプが目前に迫ると、次のような内部対話が生まれます。

```
「あと1人だ。この賞金さえ確保すれば...」
「絶対にここで消えたくない。AKs でもフォールドしよう」
「せっかくここまで来たのに。薄い勝負は避けよう」
```

これは「ペイジャンプの誘惑」です。ICM 補正によって必要 equity が 60% に上昇しているところを、心理的な圧力がさらに 80% や 90% まで引き上げます。

結果として、本来コールすべきハンドでフォールドが増えます。本来プッシュすべき M 値でもブラインドを流し続けます。この過剰補正は、ICM 的には負けの判断です。

### 「ICM 補正以上に動かない」原則

ペイジャンプ前後の正しい思考は、ICM 計算の結果に従うことです。

```
ステップ 1: 次のジャンプまで何人必要かを確認する
  → 「1人」なら ICM 補正は高い。「3人以上」なら現状維持。

ステップ 2: ICM 補正から必要 equity を計算する
  → 「ICM 補正 0.4 → 必要 equity 58%」と数値で設定する。

ステップ 3: 「心理的に要求している equity」と比較する
  → 「フォールドしたい気持ちがある。なぜか」を点検する。
  → 「ICM 計算では 58% あれば十分なのに、80% を要求していないか」を確認する。

ステップ 4: ICM 計算の結果に従う
  → 心理的な圧力を感じても、数値が判断の主人になるようにする。
```

「ペイジャンプの誘惑」に気づいたら、一度立ち止まって「ICM 計算が示す必要 equity はいくつか」を問い直す習慣が、過剰補正を防ぎます。

### ペイジャンプを正しく恐れる

誤解のないように補足します。ペイジャンプ直前でのコール基準の引き上げは、ICM 計算が示す範囲では**正しい判断**です。問題は「ICM 計算の範囲を超えた引き上げ」だけです。

心理的な不快感があっても、ICM 計算が「コール」を示せばコールします。ICM 計算が「フォールド」を示せばフォールドします。心理の役割は「ICM 計算の代わりに判断すること」ではなく、「ICM 計算の邪魔をしないこと」です。

## 18-4 ティルト管理

### ティルトとは何か

**ティルト**とは、感情的な興奮や動揺によって判断精度が低下した状態を指します。ポーカープレイヤーならこの状態を一度は経験しているはずです。

キャッシュゲームでもティルトは起こりますが、トーナメントには特有の増幅要因があります。

```
トーナメント特有のティルト増幅要因:

  1. 脱落 = 終わり
     キャッシュなら「次のハンド」がある。トーナメントは一度のオールイン負けで
     全てが終わる。「終わり」という取り返しのつかなさが感情を揺さぶる。

  2. 短期間に大きな金額が動く
     バブル付近で「$0 vs $500」が決まるようなオールインが続く。
     1ハンドで感じる価値の変動が、キャッシュゲームより大きくなりやすい。

  3. 観客がいる（FT、ライブトーナメント）
     ファイナルテーブルや配信テーブルでは観客がいる。
     感情的な失敗が「見えてしまう」という自意識がプレッシャーを増す。

  4. 長時間の疲労
     MTT は 8〜12 時間かかる場合もある。疲労そのものが感情コントロールを弱める。
```

### ティルトの代表的なパターン

実際のトーナメントでティルトが引き起こすアクションには、以下のパターンがあります。

**bad beat 直後の過剰アグレッション**: AA vs KK でバッドビートを受けた直後に、「取り返したい」という衝動から次のハンドで必要 equity を下回るオールインを仕掛ける。

**バブルブレイク失敗後の自暴自棄**: バブルで脱落した直後にリエントリーし、冷静になれていない状態でルーズなプレイを続ける。

**チップリーダーが連続してスティールを成功させた後の感情的対抗**: 「あいつにだけは負けたくない」という個人的な感情が、ICM 計算を歪める。

**長時間 ITM で賞金が上がらない焦り**: 5時間以上 ITM にいても賞金が変わらない局面での「そろそろ大きく動きたい」衝動。

### ティルトを認識する方法

ティルト状態は自分ではわかりにくいという特性があります。冷静な判断をしているつもりでも、実際には感情で判断している場合があります。以下のチェックが、ティルトの自己検知に役立ちます。

```
ティルト自己チェック（3ハンドルール）:

  直近の 3〜5 ハンドを振り返る:
    1. ICM 計算をスキップして直感で判断していないか
    2. 「取り返したい」「あいつに勝ちたい」という感情が判断に入っていないか
    3. バリューが薄いのに積極的に動いていないか
    4. コールすべき場面でフォールドしていないか（怖さからの逃げ）

  YESが 2 つ以上 → ティルト状態の可能性が高い
```

### ティルト時の具体的な対処

ティルト状態に気づいたら、以下を実行します。

**短い休憩**: トーナメントによっては席を外せないルールもありますが、可能であれば 5〜10 分の休憩をとります。冷却時間を挟むことで、感情的な高揚が下がります。

**「直前のハンドとは無関係」を唱える**: bad beat を受けたハンドと次のハンドは、確率的に無関係です。「さっき KK に負けたから次は勝てる」も「さっき AA を潰されたから今度は厳しく行く」もどちらも誤りです。次のハンドは独立した確率事象です。

**ICM 補正の数値を再確認する**: 感情が高ぶっているときは、具体的な数値に注意を向けることが冷静化につながります。「今の ICM 補正はいくつか、必要 equity はいくつか」と機械的に問い直します。

**最悪の場合は離席してリエントリーを検討する**: ティルトが制御できない状態なら、無理に続けることが $EV を最大化しません。リエントリーが可能なトーナメントであれば、バストアウトを待つのではなく自分で「クールダウン判断」をすることも選択肢です。ただし次節で説明する通り、リエントリー自体も冷静な判断が必要です。

## 18-5 リエントリー判断

### リエントリーとは

**リエントリー型トーナメント**とは、バストアウト後に新たなバイインを支払って再参加できる形式です。同じ大会に複数回バイインすることになります。

リエントリーの可否と条件はトーナメントごとに異なります。一般的には「レイトレジストレーション期間内」に限り、何度でもリエントリー可能という形式が多く見られます。

### リエントリーの $EV 判断

リエントリーするかどうかは、基本的に期待値の問題です。

```
リエントリーの期待値計算（概念）:

  リエントリーの純 $EV = (残り時間・フィールドでの期待賞金) − バイイン額

  リエントリーが有利な条件:
    1. フィールドが弱い（スキルエッジが大きい）
    2. レイトレジ期間がまだ長い（スタックが平均以上でスタートできる）
    3. 自分のスキルと精神状態が正常（ティルトしていない）
```

フィールドの強弱やスキルエッジの正確な推定は困難ですが、「参加価値がある大会かどうか」という大まかな判断は可能です。最初のバイインが期待値プラスの参加判断だったなら、同じフィールドでのリエントリーも基本的には期待値プラスになります。

### ティルトとリエントリーの危険な組み合わせ

リエントリーが問題になるのは、「感情的な状態のまま即座にリエントリーする」ケースです。

bad beat や不運なバストアウトの直後は、感情が高ぶっています。この状態でリエントリーしても、$EV を最大化するプレイはできません。サンクコスト（「$300 無駄にした悔しさ」）とティルトが重なった状態でリエントリーすると、最初のバイインより劣った $EV のプレイを繰り返すことになります。

```
「取り返したい」→ リエントリー → ティルト継続 → さらに失う

このスパイラルが、リエントリー型トーナメントの最大の罠です。
```

### リエントリーの判断基準

リエントリーを検討するときは、以下の基準を使います。

```
リエントリー判断フロー:

ステップ 1: 冷却期間を置く
  バストアウト直後はリエントリーしない。
  最低でも 10〜15 分、できれば席を離れる。

ステップ 2: 感情チェック
  「取り返したい」「悔しい」「あいつのせいだ」が主な動機なら NO。
  「この大会の期待値は十分ある」「スタートスタックで戦える」が主な動機なら検討する。

ステップ 3: 状況確認
  残りのレイトレジ時間は十分あるか（残り少なければリエントリーの価値が下がる）。
  残りフィールドのスキルレベルは変わっていないか。
  自分の精神状態は通常に近いか。

ステップ 4: 経済的確認
  そのバイイン額を失っても問題のない資金管理の範囲か。
  リエントリーはバイインの追加であり、「元を取る義務」は生まれない（サンクコスト参照）。

全ステップが問題なければリエントリーを検討する。1つでも引っかかれば見送る。
```

### リエントリーとバンクロール管理

リエントリーを繰り返すと、1大会あたりの投資額が膨らみます。バンクロール管理の観点から、1大会への最大投資額を事前に決めておくことを推奨します。「バイイン × 最大 3 回まで」のような上限を設けることで、感情的なスパイラルへの歯止めになります。

## 18-6 心理と戦術の区別

本書の第1〜17章では、ICM 計算、bubble factor、必要 equity、プッシュ/フォールドチャートなど、計算に基づく判断ツールを積み上げてきました。本章が扱うのは、それとは層が異なる「心理」です。

```
戦術判断: ICM 計算、必要 equity、M 値、bubble factor
  → 「何をするか」を決める計算ツール

心理運用: サンクコスト無視、ペイジャンプの誘惑への耐性、ティルト管理、リエントリー判断
  → 「計算を正しく使えるか」を左右する土台
```

心理が不安定なプレイヤーは、ICM 計算のツールを持っていても使えません。感情が判断の主人になる局面で、計算は脇に追いやられます。

逆に、心理が安定していれば、第II部の暗算式は常に最適に働きます。ICM 補正 0.875 の場面で必要 equity 65% を正確に適用し、サンクコストを除外し、ペイジャンプへの誘惑を ICM 計算の範囲に収め、ティルトのないフラットな状態で判断する。この状態が「迷わないトーナメント」の完成形です。

心理コントロールは「才能」ではなく「技術」です。本章で示した各チェックリストを繰り返し実戦で使うことで、徐々に自動化されていきます。

## 18-7 心理運用チェックリスト

実戦のトーナメントで心理の安定を保つための暗算チェックリストです。

```
心理運用チェックリスト（各ハンド前に 5 秒で確認）:

ステップ 1: 直前のハンドの結果を切り離す
  「さっきのハンドとこのハンドは無関係」
  感情が残っていることに気づいたら、一度息を吐く。

ステップ 2: バイイン金額を判断から除外する
  「バイインはすでに消えた。今の $EV はスタックだけで決まる」

ステップ 3: ペイジャンプの心理圧力を確認する
  「ペイジャンプが近い？ ICM 補正から必要 equity を計算した。
   心理的に要求している equity がその数字を超えていないか？」

ステップ 4: ティルト兆候を確認する（3〜5 ハンド単位）
  「直近のハンドで感情的な動機で判断していないか？
   2 つ以上 YES なら休憩を検討する」

ステップ 5: リエントリーはバストアウト後に冷却時間を置く
  「バストアウト直後のリエントリーは原則しない。
   感情が主な動機なら見送る」

ステップ 6: ICM 計算を機械的に適用する
  「今の ICM 補正は？ 必要 equity は？
   この 2 つの数字が判断の軸」
```

## 18-8 ミニクイズ

### 問1

$300 のトーナメントに参加し、開始 40 分で AA vs KK のオールインで敗れてバストアウトしました。「$300 を取り返したい」という気持ちが強く、すぐにリエントリーしようとしています。この判断をどう評価しますか。

1. 正しい（AA でバストアウトしたのは運が悪かっただけ。次のスタックでも同じ期待値が得られる）
2. 問題なし（レイトレジ期間内ならリエントリーは戦略的な選択肢）
3. 要注意（「取り返したい」という動機はサンクコストとティルトの組み合わせ。冷却期間を置き、感情が主な動機でなければリエントリーを検討すべき）

### 問2

バブル直前（残り 4 人、Top 3 払い）、あなたは中スタックです。「次の賞金さえ確保できれば」という気持ちが強く、AKs を持っているのにショートスタックのプッシュに対してフォールドが脳裏をよぎっています。第13章の計算を思い出すと、中スタック vs ショートのBF は 1.16 です。この場面の正しい思考は何ですか。

1. フォールドする（バブルでは生存が最優先。ペイジャンプ確保は正しい動機）
2. BF = 1.16 から必要 equity は約 54%。AKs の vs ショートの広いプッシュレンジに対する equity はそれを上回る可能性が高い。ICM 計算が示すならコールするのが正しい
3. コールする（AKs は強いハンド。バブルでも迷わずコール）

### 問3

ファイナルテーブルで、大スタックのプレイヤーに連続してスティールを成功させられています。「あいつだけには負けたくない」という感情が芽生え、次にそのプレイヤーがオープンしてきたら必要 equity を下回ってもコールしようかと考えています。この思考の問題点を説明してください。

1. 問題ない（FT では積極的なアクションが重要。感情を動力にしてもよい）
2. 「特定のプレイヤーへの対抗心」は ICM 計算と無関係。感情的な動機によるコールは必要 equity を無視したティルトアクション。FT の ICM 補正下ではより大きな $EV 損失につながる
3. 大スタックに対してはコールが正しい（FT では相手のリーダーを止めることが全体の $EV を上げる）

---

### 解答

- **問1**: 3が正解（要注意）。「取り返したい」という動機は、サンクコスト（$300 はすでに消えた費用）への執着とティルトが組み合わさっています。AA でのバストアウトは運悪く負けたに過ぎず、その悔しさが判断を歪めている可能性があります。リエントリー自体は期待値次第で正当化できる選択肢ですが、それは感情が落ち着いた後の判断です。選択肢1は「次も同じ期待値」が正しい点はあるものの、「感情的な動機のまま今すぐ」という点が問題です。冷却時間を置き、感情が主な動機でなければリエントリーを再検討します。

- **問2**: 2が正解（ICM 計算に従う）。BF = 1.16 から必要 equity は 1.16 ÷ (1.16 + 1) ≈ 54% です。AKs のショートの広いプッシュレンジに対する equity は概ね 60% 前後になることが多く、必要 equity 54% を上回ります。「ペイジャンプを確保したい」という心理は理解できますが、ICM 計算が示す必要 equity を超えて基準を引き上げることは過剰補正です。選択肢1はペイジャンプの心理的誘惑に引きずられた過剰フォールドの例です。選択肢3は必要 equity の計算を省略した判断です。ICM 計算の結果に従う選択肢2が正解です。

- **問3**: 2が正解。特定のプレイヤーへの対抗心は、ICM 計算に入力できる変数ではありません。「あいつに負けたくない」という感情が必要 equity の基準を変える根拠はなく、これはティルトの一形態です。FT では ICM 補正が 0.39〜0.49 程度（第14章）かかっており、必要 equity を下回るコールは $EV を直接損ないます。選択肢3の「相手のリーダーを止めることが全体の $EV を上げる」は一見もっともらしく聞こえますが、自分の $EV を下げてまで相手を止めることは一般に正当化されません。自分の $EV 最大化が唯一の指針です。

> **本章まとめ**
>
> - サンクコスト（バイイン額、投下時間）は判断に入力できない変数。「今のスタックで最も $EV が高いアクションは何か」だけを問い続ける。
> - ペイジャンプの心理的圧力は ICM 補正が示す必要 equity を超えて判断を歪める。ICM 計算が許す範囲での守備は正解だが、計算の範囲を超えた過剰補正は $EV を損ねる。
> - ティルトはトーナメント特有の要因（脱落の取り返しのなさ、短時間の大額変動、疲労）で増幅する。「直近 3〜5 ハンドの振り返り」でティルト自己検知を行い、必要なら休憩を入れる。
> - リエントリーはバストアウト直後に感情的な動機で行わない。冷却期間を置き、期待値と感情状態を確認した上で判断する。
> - 戦術知識（第1〜17章）と心理コントロール（本章）の両方が揃って初めて「迷わないトーナメント」が完成する。心理運用は才能ではなく技術であり、チェックリストの反復練習で習得できる。

**【GTOとのズレ】**

ソルバー（ICMIZER、HRC 等）は感情のないエージェントとして計算します。バイイン金額への執着もなく、ペイジャンプへの誘惑もなく、ティルトもなく、すべての判断が ICM 計算のみに基づきます。これがソルバー出力と人間プレイヤーの最も根本的なズレです。

本章で挙げたサンクコスト・ペイジャンプ誘惑・ティルトは、全てソルバー値からの逸脱を引き起こします。$300 のバイイン額を念頭に置いたプレイは、バイイン額をゼロとして計算するソルバー値とは異なる判断を生みます。ペイジャンプへの過剰反応は、ソルバーが示す ICM 補正に上乗せした守備的な判断を生みます。ティルト状態のアグレッションは、ソルバーが示す必要 equity を無視した攻撃的な判断を生みます。

これらの「心理由来のズレ」は、戦術の理解を深めても解消されません。ソルバー値に近づくための唯一の方法は、心理的な安定を高めることです。実戦での本章のチェックリスト活用を繰り返し、「感情が主人ではなく計算が主人」という状態を平常にすることが、長期的なトーナメント成績を改善します。

ソルバーより優れた人間プレイヤーは存在しませんが、「ソルバーとのズレを最小化した人間プレイヤー」は実現できます。その差の大半は心理コントロールが生み出します。トーナメントで長期的に収益を上げるプレイヤーは、計算能力だけでなく感情管理においても突出した安定性を持っています。本章がそのための具体的な習慣を提供することを願っています。
