# 第2章　chip EV vs $EV ─ ICM の概念

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: チップの獲得・損失がそのまま賞金の増減にならない理由を数値で確認し、ICM（Independent Chip Model）という換算モデルの概念を理解する。chip EV と $EV の乖離を「ICM 圧縮」という言葉で掴み、なぜトーナメントのすべての判断がこの乖離に帰着するかを言語化する。

---

## 2-1 100ドル札とポイントカード

財布に100ドル札が10枚入っているとします。その1,000ドルの価値は疑いようがありません。1枚は100ドル、10枚は1,000ドルです。枚数に対して価値は完全に線形です。

景品交換用のポイントカードを想像してください。1,000ポイントを持っています。これが何ドルになるかは、ポイントカードの規約だけで決まらず、あなたが交換するタイミングと残りポイントの合計にも依存します。

キャッシュゲームのチップは前者に近い存在です。100BBスタックは常に100BB相当の現金価値を持ち、チップを勝てばその分がそのまま利益になります。

トーナメントのチップは後者に近い存在です。1万チップが何ドルになるかは、賞金構造と残りプレイヤーのスタック分布によって決まります。同じ1万チップを持っていても、ライバルが全員2万チップ持ちの状況と、全員5千チップ持ちの状況では、あなたのチップが生む賞金期待値が違います。

この章では、この「ポイントカード問題」を数式と数値例で解きほぐします。

---

## 2-2 chip EV と $EV の定義

まず2つの用語を正確に定義します。

**chip EV（cEV）** とは、あるアクションが期待値でどれだけのチップを生むかを示す指標です。たとえば「コールすると期待値でチップが200増える」という計算が chip EV の世界です。

**$EV（ドルEV）** とは、あるアクションが期待値でどれだけの賞金（現金）を生むかを示す指標です。「コールすると期待値で賞金が12ドル増える」という計算が $EV の世界です。

キャッシュゲームでは、cEV と $EV は完全に比例します。1チップが1セントの価値を持つなら、chip EV が200増えれば $EV も2ドル増えます。換算レートは固定であり、状況によって変わることはありません。

トーナメントでは、この比例関係が崩れます。チップを得ても、そのチップが生む $EV は状況によって大きく異なります。チップを大量に持つリーダーが追加で1チップを得るときの $EV 増加と、ほぼ脱落寸前のショートスタックが1チップを得るときの $EV 増加は、同じではありません。

この違いを生むのが賞金構造の傾斜配分です。次節でその仕組みを掘り下げます。

---

## 2-3 なぜチップの価値は線形にならないのか

3人残りのトーナメントで、賞金は1位 $50、2位 $30、3位 $20とします。賞金プール合計は $100です。

3人が均等にチップを持つ状況から始めましょう。各プレイヤーが10,000チップを持ち、合計30,000チップです。

この状況で、各プレイヤーの「公平な取り分」はいくらでしょうか。全員が同じスタックで同じ勝率を持つなら、直感的には均等分配が公平です。$100 ÷ 3人 = 約 $33.33が各人の期待値になります。

ここで問いを変えます。もし1人がチップを全て勝ち取って30,000チップを独占したとき、その人の賞金はいくらになるでしょうか。答えは $50です。全チップを持っても、1位の賞金 $50 が最大値です。賞金プールの100%ではなく、50%しか取れません。

この事実に含意を考えてみましょう。

全チップの50%（15,000チップ）を持つプレイヤーが「さらに1チップを得た」としても、その1チップが生む $EV の増分は非常に小さくなります。なぜなら、そのプレイヤーはすでに1位になる確率が高く、1位の賞金 $50 という「上限」に近いところにいるからです。追加で1チップを得ても、賞金の上限が変わるわけではありません。

一方、全チップの5%しか持たないショートスタックが「1チップを得た」とき、その $EV の増分は相対的に大きくなります。少ないチップしか持たないプレイヤーは脱落リスクが高く、1チップが「もう少し生き残れる」という確率を上げます。生き残れれば最低でも3位の $20 を確保できる可能性が高まります。

これが「**チップ価値の限界価値逓減**」です。チップが多いほど、追加の1チップが生む $EV は小さくなります。チップが少ないほど、追加の1チップが生む $EV は大きくなります。

この性質は賞金構造の「傾斜」から必然的に生まれます。賞金に上限（1位の賞金）と下限（最低賞金または $0）が存在する以上、チップと $EV の関係は非線形にならざるを得ません。

---

## 2-4 ICM の登場 ─ Malmuth と Harville

チップを $EV に変換する標準モデルが **ICM（Independent Chip Model、独立チップモデル）** です。

ICM の数学的な根拠は2つの先行研究に由来します。競馬の着順確率を計算した Harville（1973）の手法と、ポーカートーナメントへの適用を体系化した Malmuth（1987）の論文です。Mason Malmuth は著書 _Settling Up in Tournaments_ でこのモデルをポーカー界に紹介しました。

ICM は次の単純な仮定を置きます。

**「各プレイヤーが特定の順位に到達する確率は、そのプレイヤーのチップ量に比例する」**

全チップが10,000で、あなたが5,000チップ（50%）を持つなら、あなたが1位になる確率は50%です。残りの2人が2,500チップずつ（各25%）なら、それぞれ1位になる確率は25%です。2位の確率は「1位が誰かに決まった後、残りのチップ比率に比例する」という同じルールで再帰的に計算します。

この仮定はシンプルです。スキル差を無視し、ポジションを無視し、ブラインド進行も無視します。それでも ICM は「チップ → $EV 変換」の標準ベースラインとして機能します。

ICM 以前は、トーナメントの途中でプレイヤーが話し合い（チョップ）をするとき、「感覚」や「交渉力」で賞金を分けていました。ICM の登場で、客観的・数学的に「公平な分配額」を算出できるようになりました。現在では GTO ソルバーも ICM を基準として使用しており、本書の第4章で ICM の正式な計算アルゴリズムを詳しく扱います。

---

## 2-5 3-handed の数値例 ─ 「ICM 圧縮」の正体

具体的な計算で確認します。3人残り、賞金 $50 / $30 / $20、スタックが5,000 / 2,500 / 2,500（合計10,000）の状況を使います。

### 各プレイヤーの1位確率

チップ比率が1位確率になります。

- P1（5,000チップ）: 5,000 ÷ 10,000 = **50%**
- P2（2,500チップ）: 2,500 ÷ 10,000 = **25%**
- P3（2,500チップ）: 2,500 ÷ 10,000 = **25%**

### P1 の $EV を計算する

P1 が $EV を得るパターンは5通りあります。

**P1 が1位のケース（確率50%）**
$50 の1位賞金を得ます。  
貢献額 = 50% × $50 = **$25.00**

**P2 が1位、P1 が2位のケース**  
P2 が1位（25%）になった後、残りのチップは P1:5,000 と P3:2,500の合計7,500です。P1 が2位になる確率は 5,000 ÷ 7,500 ≈ 66.7%です。  
貢献額 = 25% × 66.7% × $30 = **$5.00**

**P2 が1位、P3 が2位、P1 が3位のケース**  
P2 が1位（25%）、P3 が2位（残りチップ7,500のうち2,500 = 33.3%）の後、P1 は必然的に3位です。  
貢献額 = 25% × 33.3% × $20 = **$1.67**

**P3 が1位、P1 が2位のケース**  
P3 が1位（25%）になった後、残りは P1:5,000 と P2:2,500の合計7,500です。P1 が2位になる確率は 5,000 ÷ 7,500 ≈ 66.7%です。  
貢献額 = 25% × 66.7% × $30 = **$5.00**

**P3 が1位、P2 が2位、P1 が3位のケース**  
P3 が1位（25%）、P2 が2位（2,500 ÷ 7,500 = 33.3%）の後、P1 は3位です。  
貢献額 = 25% × 33.3% × $20 = **$1.67**

### 合計と比較

P1 の $EV = $25.00 + $5.00 + $1.67 + $5.00 + $1.67 = **$38.33**

P2 と P3 の $EV も同様に計算すると、各 **$30.83** になります。

| Player | Stack | Chip% | $EV | ICM% |
| ---: | ---: | ---: | ---: | ---: |
| P1 | 5,000 | 50.00% | $38.33 | 38.33% |
| P2 | 2,500 | 25.00% | $30.83 | 30.83% |
| P3 | 2,500 | 25.00% | $30.83 | 30.83% |

合計 $38.33 + $30.83 + $30.83 = **$100.00**（賞金プール全体に一致）

### ここがクライマックス

P1 はチップの **50%** を持っているのに、$EV は **38.33%** しか取れません。差は約 **11.7 ポイント**です。

残りの11.7ポイント分の $EV は P2 と P3 が受け取っています。P2 と P3 はチップ比率（各25%）より高い $EV 比率（各30.83%）を持っています。

これが「**ICM 圧縮**」です。大スタックが本来チップ比率で取るべき $EV が、ショートスタック側に「圧縮（redistribution）」されています。本書を通じて繰り返し登場する核心的な現象です。

---

## 2-6 ICM 圧縮がなぜ起きるか ─ 賞金の「天井と床」

ICM 圧縮の根本原因は、賞金に「天井」と「床」があることです。

天井は1位の賞金（今の例では $50）です。チップをいくら積んでも、獲得できる賞金の最大値は1位の賞金を超えません。チップが増えるほど、「天井への余地」が小さくなります。

床は最低賞金または0ドルです。チップをどれだけ失っても、賞金が0ドルを下回ることはありません。チップが少ないほど、「床への距離」は近いですが、「少し増やすだけで大きく生存確率が上がる」という価値が生まれます。

数学的には、チップと $EV の関係は「凸関数（上に凸の曲線）」になります。

```
$EV

 50 |..........┌──────────── （天井：1位賞金 $50）
    |       ╱
    |     ╱    ← $EV の増加は逓減する
 20 |   ╱
    | ╱
  0 +──────────────────────────
    0    5k   10k              Chip
```

横軸がチップ量、縦軸が $EV です。チップが少ない左側では曲線の傾きが急で、チップ1枚当たりの $EV 増加が大きい。チップが多い右側では傾きが緩く、チップ1枚当たりの $EV 増加が小さい。

キャッシュゲームではこの曲線が直線です。チップ量に対して $EV が完全に線形に増加します。トーナメントでは賞金構造によってこの曲線が非線形になります。これがトーナメントとキャッシュの根本的な数学的違いです。

---

## 2-7 ICM 圧縮の戦術的含意 ─ なぜ守るのか

ICM 圧縮は、トーナメントの最適戦略をキャッシュゲームから大きく乖離させます。

チップを大量に持つプレイヤー（大スタック）の視点で考えましょう。大スタックが追加のチップを得ても、$EV の増加は小さくなります（天井への余地が小さい）。一方、チップを失うと $EV の損失は相対的に大きい（凸関数の左側は傾きが急）。つまり、「得る喜び」より「失う痛み」が大きい状況です。

これがキャッシュゲームと根本的に違います。キャッシュでは、得るチップと失うチップは対称です。100ドル勝つことの価値と100ドル負けることの痛みは等価です。トーナメントの大スタックにはこの対称性がありません。

ショートスタックの視点では逆のことが起きます。チップを少し増やすだけで $EV が大きく上がります（凸関数の左側は傾きが急）。一方、チップを失っても「元々少なかった」ので、失う $EV は相対的に小さい。つまり、「得る喜び」が「失う痛み」より大きい状況です。

この非対称性が、スタック別の最適戦略を決定します。

**大スタック: 守備的インセンティブが働く。** チップを増やすリターンが小さく、失うリスクが大きいため、不確実なオールインコンフロンテーションを避けるインセンティブがあります。

**小スタック: 積極的インセンティブが働く。** チップを増やすリターンが大きく、失っても「どうせ近いうちに脱落」なので、積極的にチップを集めるインセンティブがあります。

キャッシュゲームでは「大スタックは守備的、小スタックは積極的」という非対称は生まれません。ポーカーの基本を学んだプレイヤーがトーナメントで最も混乱しやすいのが、この直感との乖離です。

スタック深度別の具体的な戦略は第7〜10章で扱います。ステージ別の ICM 圧力の変動は第3章で概観します。

## 2-8 ICM の限界 ─ 単純化の代償

ICM が強力なベースラインになる一方、いくつかの重要な限界があります。これを理解しないと、ICM を過信して判断を誤るリスクがあります。

**スキル差を無視する。** ICM は全プレイヤーが同じ実力を持つと仮定します。実際には、腕前が上のプレイヤーは ICM が示す値より高い実 $EV を持ちます。強いプレイヤーが多い卓にいれば ICM 値より低い、弱いプレイヤーが多い卓にいれば ICM 値より高い実 $EV になります。

**ポジションを無視する。** ICM はチップ量のみを入力とします。ブラインドポジションにいるか、ボタンにいるかは考慮されません。実戦では、残りハンドでのポジション優位が $EV に影響します。

**ブラインド進行を無視する。** ICM の計算はチップ量から静的に計算されますが、実際にはブラインド上昇によって残りプレイ時間が決まります。ブラインドが速いトーナメントでは、チップ量よりも「残り何ハンドプレイできるか」の方が重要になる場面があります。

これらの限界は ICM を「無効」にするものではありません。ICM は「スキル・ポジション・ブラインドを除いた、純粋なチップ分布から来る $EV」の計算ツールです。ベースラインとして強力であり、そこに実戦補正を加える形で使います。

本書では ICM をそのまま使う場面と、補正が必要な場面を章ごとに明示します。第19章では巻�〜5 の暗算式に ICM 補正を加える方法を体系的に示します。

## ミニクイズ

### 問1

5人プレイヤー全員が均等スタック（各2,000チップ、合計10,000チップ）の状況で、賞金は1位 $50、2位 $30、3位 $15、4位 $5、5位 $0です。この5人の ICM equity（$EV）はそれぞれいくらになるか。

1. 全員 $20（賞金プール $100 を5等分）
2. 全員 $25（5人の平均賞金）
3. 均等スタックでも人数が多いほど差が出るため、1位の ICM% が大きくなる

### 問2

次の状況での ICM 圧縮の大きさはどちらが大きいか。

**状況A**: 3人残り（50/30/20賞金）、リーダーがチップ50%保有  
**状況B**: 3人残り（90/10/0賞金）、リーダーがチップ50%保有

1. 状況Aの方がICM圧縮が大きい
2. 状況Bの方がICM圧縮が大きい
3. 同じになる

### 問3

ヘッズアップ（2人対戦）で、賞金が1位 $70、2位 $30のとき、P1 が7,000チップ（70%）、P2 が3,000チップ（30%）を持っています。ICM によると、P1 と P2 の $EV はそれぞれいくらか。

1. P1: $70、P2: $30（チップ70%なので全額獲得）
2. P1: $58、P2: $42（チップ比率に応じて配分）
3. P1: $65、P2: $35（別の計算式が必要）

---

### 解答

- **問1**: 1が正解（全員 $20）。全員のスタックが均等なら、ICM の対称性によって全員の $EV も均等に分配されます。$100 ÷ 5人 = $20 です。各人の1位確率も2位確率も3位確率も同じなので、計算上も $20 になります。「チップ均等 = $EV 均等」は ICM の対称性から導かれる結果です。

- **問2**: 2が正解（状況Bの方が大きい）。賞金の傾斜が急なほど、ICM 圧縮は大きくなります。状況Bでは1位が賞金プールの90%を独占し、2位が10%、3位はゼロです。この極端な傾斜のため、チップ50%を持っても $EV は50%より大きく下回ります。状況A（50/30/20）のように下位にも賞金が分散していると、大スタックが「天井に当たる」効果が比較的小さくなります。賞金傾斜が急であるほど ICM 圧縮は強まります。

- **問3**: 2が正解（P1: $58、P2: $42）。ヘッズアップでは ICM 計算が特に単純です。P1 が1位（勝利）する確率は70%、P2 が1位（勝利）する確率は30%です。P1 の $EV = 70% × $70 + 30% × $30 = $49 + $9 = **$58**。P2 の $EV = 30% × $70 + 70% × $30 = $21 + $21 = **$42**。ヘッズアップではチップ比率 ≠ $EV 比率ですが、ICM 圧縮は3人以上の場面より小さくなります（賞金構造が単純なため）。

> **本章まとめ**
>
> - キャッシュゲームでは chip EV と $EV は完全に比例する。トーナメントではこの比例関係が崩れ、チップ量によって1チップの $価値が変わる。
> - 賞金構造に「天井（1位賞金）」と「床（最低賞金）」があるため、チップと $EV の関係は凸関数（上に凸）になる。チップが多いほど追加の1チップが生む $EV は小さく（限界価値逓減）、チップが少ないほど大きい。
> - ICM（Independent Chip Model）はチップ量に比例して順位確率が決まると仮定し、チップ → $EV 変換を可能にする標準モデルである。Malmuth（1987）によってポーカーに導入された。
> - 3人残り（50% / 25% / 25%スタック、賞金50/30/20）の数値例では、P1（チップ50%）の $EV は38.33%しかない。この約12ポイントの乖離が「ICM 圧縮」である。
> - ICM 圧縮により、大スタックは守備的インセンティブを持ち、小スタックは積極的インセンティブを持つ。この非対称性がキャッシュゲームとの根本的な戦略の違いを生む。
> - ICM はスキル差・ポジション・ブラインド進行を無視する。実戦ではベースラインとして使い、必要に応じて補正する。

**【キャッシュゲームとのズレ】**

キャッシュゲームを主戦場にするプレイヤーが ICM 概念でつまずきやすいのは、「同じ手牌なのに、勝率50%超でもコールすべきでない場面がある」という感覚です。キャッシュでは期待値がプラスならコールが正解です。トーナメントでは、コールによる chip EV がプラスでも $EV がマイナスになることがあります。

この乖離が起きる理由は本章で説明した通りです。大スタックにとって、コールして失うチップが生む $EV の損失は、コールして得るチップが生む $EV の利益より大きい。この非対称性を無視してキャッシュ的なEV計算だけで判断すると、バブル前後でオールインコールを過剰に呼びすぎることになります。

逆に、ICM を過剰に意識しすぎると今度はフォールドが多すぎる問題が出ます。トーナメントの序盤（フィールドの50%以上が残っている時点）では、ICM 圧力はほぼゼロで chip EV と $EV はほぼ一致します。序盤から「ICM 圧縮があるから」と過剰に守備的になるのは、攻撃機会を逃すミスです。

ICM 圧縮は「常にある」のではなく、「残りプレイヤー数・スタック分布・賞金構造の組み合わせで強くなったり弱くなったりする」ものです。このダイナミックな変動を第3章で全体像として示します。
