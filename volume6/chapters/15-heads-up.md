# 第15章　ヘッズアップ ─ ICM 補正がゼロの世界

> **本章のゴール**: ヘッズアップ（2人対戦）では ICM 補正がゼロになり、純粋なチップ EV 勝負に戻ることを理解する。BTN = SB というHU 特有の構造を把握し、広いレンジ・積極的なアクションで勝率を最大化する技術を習得する。

## 15-1 第IV部の完結点

第IV部はトーナメントの各ステージを順番に追ってきました。序盤の ICM 補正ゼロ（第11章）、中盤のアンテ導入後（第12章）、バブルの最大圧力（第13章）、そして ITM 後からファイナルテーブルの段階的な ICM 低下（第14章）。この旅の最終地点が本章のヘッズアップです。

FT の3人から2人（HU）へ移行する瞬間に ICM 補正はゼロへと消えます。本書の主役だった ICM 補正が解除されることで、あなたは純粋なポーカープレイヤーとして相手と向き合います。

ヘッズアップの戦術は一言で言えます。「**巻1〜5のキャッシュ用暗算式を、そのままフルスロットルで使う**」。本章では HU 特有の構造と、その中での暗算式の活かし方を示します。

## 15-2 ICM 補正がゼロになる仕組み

なぜ HU で ICM 補正が完全に消えるのか、数式で確認します。

2人残りのとき、賞金は「1位：W1」「2位：W2」の2択です。自分の $EV は次の式で表せます。

```
HU の $EV = W2 + チップ比率 × (W1 − W2)
```

この式はチップ比率に対して**完全に線形**です。チップが増えれば同じ割合で $EV が増え、「大スタックほど 1チップが軽い」という ICM 特有の非線形が消えます。

数値例を確認します。賞金が W1 = $10,000、W2 = $5,000 の場合、チップ 30% なら $EV = $5,000 + 0.30 × $5,000 = **$6,500**、チップ 70% なら $EV = **$8,500** です。1チップパーセントが一定の $50 の価値を持ち続ける、これが線形関係です。

`knowledges/volume6/04_bubble_factor.md` の実測によると、チップ分布が 50/50 でも 70/30 でも 90/10 でも、HU の bubble factor は常に **1.000** です。ICM 補正 = bubble factor − 1 = 0.000 となり、必要 equity は50%、キャッシュゲームとまったく同じ計算に戻ります。

ICM 補正のステージ全体を振り返ります。

```
ICM 補正のステージ別変動（代表値）:

  序盤（フィールド 50% 以上残）:  0.000〜0.100
  バブル直前（n=4 STT）:          0.875     ← 最大
  ITM 直後（3人残り）:            0.320
  FT 9-max 開始:                  0.488
  FT 3人残り:                     0.320
  HU（2人）:                      0.000     ← ゼロへ消失
```

バブルのピーク 0.875 から出発し、FT の段階的な低下を経て、HU でゼロに戻ります。この弧の終点が本章です。

## 15-3 HU の基本構造

### BTN = SB という特殊ルール

2人対戦ではポジションが3つから2つに減ります。その結果、BTN（ボタン）が SB（スモールブラインド）を兼ねるルールが適用されます。

```
HU の構造:

  BTN (= SB): ポストフロップは IP（先手）
              プリフロップはアクション後手（BB が先）

  BB:         ポストフロップは OOP（後手）
              プリフロップはアクション先手
```

「プリフロップとポストフロップでポジションが逆転する」この構造が HU を独特にしています。ポストフロップでは BTN が IP を持つため、巻4・巻5の IP 戦術が機能します。

### 必要 equity は 50%

ICM 補正ゼロということは、すべての判断基準がキャッシュと同じ「50%」に戻ります。バブルで要求された「equity 65%」「equity 60%」という上乗せがすべて消えます。コールレンジが大幅に広がり、「薄いバリューベット」も積極的に打てる環境になります。

## 15-4 HU のレンジは広い

ICM 補正がゼロで、相手が 1 人だけという事実が組み合わさり、HU のレンジは多人数戦とは比べ物にならないほど広くなります。

### BTN (= SB) のオープンレンジ

標準的な HU では BTN オープン率は **80〜90%** 程度です。22以上のポケットペア、A2s以上のすべてのエース（スーテッドもオフスートも）、K2s以上・K7o以上、Q5s以上・Q9o以上、J7s以上・JTo以上、さらに T8s・97s・86s・75s・65s・54sなどのスーテッドコネクタを含みます。

相手が 1 人だけのため、フォールドされる確率が高く、コールされてもポストフロップ IP を保てる BTN は有利な立場を維持できます。

### BB のディフェンスレンジ

BTN が最小レイズ（2BB）してきた場合、BB のポットオッズは約 29% です。ICM 補正ゼロのため、コール equity が 29% 以上あれば chip EV でコールが正当化されます。この条件を満たすハンドは非常に広く、BB のディフェンス率は **70〜80%** になります。

多人数戦のバブルでは必要 equity が 65〜70% に達し、フォールドを強いられたハンドが、HU では「コール可能」になります。ICM 補正がなくなることで、ポットオッズだけでコールを判断できる状態に変わります。

## 15-5 スタック深度別の戦術

### ディープ HU（50BB 以上）

巻5の式をフルに活用する局面です。

- **α 式**（巻5第6章）：リバーのバリュー/ブラフ配分。ICM 補正なしでキャッシュ式をそのまま使えます。
- **後手スコア**（巻2・4）：OOP の BB 側でのコール判断。`後手スコア = HandScore + A − 3 − C`（HU 前提で M=0）。
- **ブロッカー論**（巻5第8章）：相手が 1 人で広いレンジを持つため、ナッツブロッカーの相対的価値が高まります。ブロッカーを持つ場合にブラフ頻度を上げ、ない場合は抑えます。

### ミディアム HU（20〜50BB）

3bet シャブ（3bet してオールイン）と 4bet 応酬が頻繁に発生する深度です。ICM 補正がゼロなため、chip EV でプラスになるレンジであれば積極的にシャブを入れます。コミット判断（巻5第13章）が早い段階から機能する深度です。

### ショート HU（20BB 以下）

push/fold 戦略に完全移行します。第10章のプッシュ/フォールドチャート「SB vs BB HU」の列を参照します。HU の push/fold は chip EV Nash チャートをそのまま使えます。ICM 補正によるチャートの絞り込みは不要です。

```
HU push/fold 代表値（第10章の SB vs BB HU チャート）:

  SB（= BTN）プッシュレンジ:
    10BB → 約 18%（33+、A2s+、ATo+、KTs+、KJo+、QJs）
    8BB  → 約 22%（22+、A2s+、A9o+、KTs+、KJo+、QJs）
    5BB  → 約 33%（22+、A2s+、A8o+、K9s+、KTo+、Q9s+ など）

  BB コールレンジ（vs SB push）:
    10BB → 約 16%（33+、A6s+、ATo+、KJs+）
    8BB  → 約 18%（33+、A5s+、ATo+、KTs+）
    5BB  → 約 25%（22+、A2s+、A9o+、KTs+、KJo+）
```

## 15-6 チップカウントの流動性

HU はチップの動きが激しく、リードの入れ替わりが頻繁に起こります。この流動性を受け入れ、適切なモード切替ができるかどうかが HU 勝率を左右します。

### チップリーダーは攻め続ける

HU でリードを持ったとき「守りに入る」誘惑を感じることがあります。しかし ICM 補正ゼロの HU では、消極的な守備は chip EV を最大化しません。スティール頻度を広く維持し、ポストフロップでは積極的にバレルを打ちます。バレルスコア（巻4第7章）が「FlopType係数 + TurnCard係数 ≥ 7」を示すボードでは、二連バレルを積極的に実行します。

### ショートになっても反撃する

チップ比率が 20〜30% になっても、ICM 的な「生存の優先」は機能しません。HU での勝ちは「相手のチップをすべて取ること」だけです。ショートになれば push/fold に移行し、積極的にプッシュして chip up を狙います。

重要なのは「現在の決断が chip EV でプラスか」だけを判断基準に保つことです。これは巻5第13章（ポットコミットメント）で学んだサンクコスト回避と同じ考え方です。過去のチップの動きではなく、今のハンドで正しい判断を下せるかが HU の本質です。

## 15-7 巻5リバー戦術の最大活用場

ヘッズアップは、本シリーズの巻1〜5で積み重ねてきた技術が最もダイレクトに活きる場面です。

**α 式**（巻5第6章）は HU でそのまま機能します。相手が 1 人のため、ブロッカーの有無や相手のコーリングレンジの読みがより精密にできます。α 式 + ブロッカー論（巻5第5・8章）の組み合わせがリバーの意思決定を支えます。

**後手スコア**で OOP（BB）でのコール判断を下します。HU では M=0 を代入します。後手スコアがゼロ以上ならコール（またはチェックレイズ検討）、ゼロ未満ならフォールドです。ICM 補正がないため、「薄いコール」も後手スコアがプラスであれば実行できます。

**ポットコミットメント**の判断は巻5第13章の式をそのまま使います。`equity ≥ コール額 ÷ (ポット + コール額)` を満たすならコール。HU では ICM 補正がないため、この equity はチップ勝率として直接計算します。

## 15-9 ミニクイズ

### 問1

ヘッズアップ。あなたのチップは 30%、相手は 70%。賞金は1位 $10,000、2位 $5,000。あなたの現在の $EV はいくらですか。また、次のハンドでオールインに勝ちチップが 40% になった場合、差はいくらですか。

1. 現在 $6,500 → 40% で $7,000、差は $500。線形関係のため 1チップパーセントが一定の $50 の価値を持つ
2. HU でも ICM 非線形のため、チップ比率だけでは $EV を計算できない
3. 現在 $7,000 → 40% で $7,500、差は $500

### 問2

HU、自分 8BB、相手 92BB。自分は BTN (= SB) で K♥Q♦ を持っています。プッシュすべきですか。

1. ICM 補正はゼロでも M が低いため KQo はフォールドが安全
2. プッシュする。M=8 の SB push Nash チャートで KQo は push レンジに含まれ、HU はチャートをそのまま使える
3. リンプして相手の反応を見てから判断する

### 問3

HU、ディープ（各 100BB）のリバーで、あなたは IP（BTN）。ボードは K♣8♦3♥J♠2♣。A♠K♠（AK）を持ちます。相手（OOP）がチェックしました。ICM 補正がゼロであることは、バリューベットの判断にどう影響しますか。

1. バリューベットを打つ。HU では相手コーリングレンジが広く、AK（2ペア K's & J's）はバリューが機能する。ICM 補正なしで「薄いバリュー」まで積極的に打てる
2. チェックバックする。AK はリバーでは弱く、HU でも守備的に
3. ICM 補正がゼロでも判断は変わらないため、ベット/チェックのどちらも同等

---

### 解答

- **問1**: 1が正解。HU の $EV = W2 + チップ比率 × (W1 − W2) = $5,000 + 0.30 × $5,000 = **$6,500**。40% なら $5,000 + 0.40 × $5,000 = **$7,000**、差は $500。1チップパーセントあたり一定の $50 の価値があり、これが線形の意味です。選択肢2の「非線形のため計算できない」は誤りです。HU に限り ICM の非線形性が消え、chip 比率で直接 $EV を計算できます。選択肢3は初期 $EV の計算が誤りです。

- **問2**: 2が正解。第10章の SB vs BB HU チャート（M=8）では push レンジ約 22% に「22+、A2s+、A9o+、KTs+、KJo+ など」が含まれます。KQo は KJo 以上に強く、push レンジに明確に含まれます。HU は ICM 補正ゼロのため、チャートをそのまま適用できます。選択肢1は ICM 圧力がある多人数戦の発想を誤って HU に持ち込んでいます。選択肢3のリンプは 8BB という浅いスタックでは push/fold が標準であり、リンプからのポストフロップ判断は効率が落ちます。

- **問3**: 1が正解。AK（A♠K♠）on K♣8♦3♥J♠2♣のリバー。全カード：A♠, K♠, K♣, 8♦, 3♥, J♠, 2♣。ランク別カウント：K×2、そのほか各1枚。best 5 = A-K-K-J-8 = **2ペア（K's & J's、A キッカー）**。フラッシュチェック：スペードは A♠, K♠, J♠ の3枚のみ（不成立）。ストレートチェック：A-K-J-T-9 → T・9 なし、K-J-T-9-8 → T・9 なし（不成立）。OOP のチェックでナッツ相当のハンドが少なくなり、2ペアはショーダウン価値があります。ICM 補正がゼロなため「薄いバリュー」のリスクが ICM 的に増幅されず、積極的なバリューベットが正当化されます。選択肢2は役の評価（2ペア）を誤っています。選択肢3は ICM 補正の影響を無視しており、「ゼロである」ことが積極性につながるという含意を捉えていません。

> **本章まとめ**
>
> - HU では bubble factor = 1.000、ICM 補正 = 0.000 となり、$EV がチップ比率に完全に線形になる。ICM 思考はここで完全に放棄し、chip EV の最大化だけを追求する。
> - HU の構造は BTN = SB。プリフロップは BB が先手、ポストフロップは BTN が IP という逆転構造を把握する。
> - BTN オープンは 80〜90%、BB ディフェンスは 70〜80% という広いレンジが理論的に正しい。ICM 補正がないため、ポットオッズだけでコールを判断する。
> - スタック深度で戦術を切り替える。ディープは巻5の式フル活用、ミディアムはシャブ応酬、ショートは push/fold 完全移行（第10章の HU チャートをそのまま）。
> - チップリードでは攻め続け、ビハインドでも積極的に反撃する。ICM 的な「生存優先」は HU では機能しない。
> - 巻5の α 式・後手スコア・ポットコミット計算はすべてそのまま適用できる。本シリーズの集大成として HU を純粋なポーカー技術で戦う。

**【GTOとのズレ】**

ヘッズアップはソルバー研究が最も進んだ領域のひとつです。HU 専用ソルバー（GTO+、PioSOLVER の HU モードなど）では、各ボードでの正確なフロップ・ターン・リバー戦略が完備されています。本章の「BTN オープン 80〜90%」「BB ディフェンス 70〜80%」は標準的な代表値であり、実際のスタック深度やブラインド構造によって精密な値は変わります。

最も注意が必要なのはエクスプロイト調整の部分です。本章の数値は GTO ベースですが、実際の HU では相手のプレイスタイルに応じた偏りが大きな EV 改善をもたらします。タイトな相手にはスティール頻度を上げ、コールが広い相手にはブラフ頻度を下げる調整が、純粋な GTO 戦略を上回ることがあります。プッシュ/フォールドチャートも、相手のコールレンジが Nash 均衡から外れている場合はプッシュレンジを大幅に広げる余地があります。

暗算式は「GTO 的に正しい方向性を把握する」ツールです。実戦の HU では相手の傾向を数ハンド観察してからエクスプロイト調整を加えると、暗算式の精度をさらに高められます。ICM 補正がゼロの HU だからこそ、エクスプロイトの価値が chip EV に最も直接的に反映されます。
