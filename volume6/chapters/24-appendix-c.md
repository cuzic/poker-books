## C-1 シリーズ全体マップ

『迷わないポーカー』シリーズは、テキサスホールデムの意思決定を「暗算で5秒以内に出せる体系」として再設計した全6巻です。巻①〜5はキャッシュゲームを前提としており、本書（巻⑥）がトーナメント編として完結を担います。

| 巻 | タイトル | 主題 | 核心式 |
| :--- | :--- | :--- | :--- |
| **①** | プリフロップ ─ 覚えなくていいレンジの考え方 | プリフロップ参加・非参加の判断 | Score（オープン / 3bet） |
| **②** | フロップ[基礎] ─ 秒で決まるボード判断 | フロップのCBet頻度・サイズ・ディフェンス | Board Score B × T1/T2/T3 / HandScore（0-100 equity %） / 後手スコア |
| **③** | フロップ[応用] ─ 相手のレンジを読んで搾取する | レンジ推定・精密化・相手への搾取 | レンジ優位（精密分析） |
| **④** | ターン ─ バレルスコアで攻撃の判断を暗算する | ターンの攻防とバレル判断 | バレルスコア |
| **⑤** | リバー ─ 配分と確定で収支を積む | リバーの配分設計とブロッカー活用 | α 式 / ブロッカー論 |
| **⑥** | トーナメント ─ ICM equity とM 値で迷わないトーナメント判断（本書） | トーナメント特有の調整 | ICM equity / ICM 補正 / M 値 |

各巻の関係を一言で示すと、巻①〜5はキャッシュゲームで完結する「コア体系」であり、巻⑥はその体系に「ICM 補正」という差分を加えることでトーナメントに対応させる「拡張書」です。

### 式の継承ラインを追う

6巻を通じて式は積み上がる関係にあります。どの巻の式も「前巻の概念を入力として受け取る」という設計思想で統一されています。

```
【巻①】 プリフロップの開戦基準
  Score = H + L + ボーナス − ペナルティ
  → どのハンドでフロップに進むかを決定する

【巻②】 フロップの攻防
  Board Score B（9ルール、50〜83） → T1/T2/T3 分類 → A 係数（ドライ=12 / セミ=6 / ウェット=0）
  HandScore = 役スコア + ドロー加点 + ブロッカー加点（0〜100、equity %）
  後手スコア = HandScore + A − C − M
  → フロップで何をするかを決定する

【巻③】 フロップの搾取
  レンジ優位（精密分析）（ナッツアドバンテージ＋エクイティアドバンテージ）
  → 相手レンジを読んで搾取する方法を追加する

【巻④】 ターンの攻防
  バレルスコア = FlopType係数 + TurnCard係数
  → ターンの攻防を体系化する

【巻⑤】 リバーの確定
  α 式（後手下限確率 = 1 − α）
  後手スコア（巻②と同じ式をリバーに適用）
  ブロッカー論
  → リバーの配分設計と3ストリート統合を完成させる

【巻⑥】 トーナメント補正（本書）
  ICM equity / ICM 補正 / M 値
  → 巻①〜5の全式にICM 補正を加えてトーナメント対応する
```

巻②の後手スコアは、巻④・巻⑤・巻⑥でも同じ式の形のまま使います。ストリートが変わっても式を覚え直す必要はなく、HandScoreの入力値（ターン・リバーカードによる役の変化）を更新するだけです。

## C-2 キャッシュ式 → トーナメント補正式 対応表

本書の最大の貢献は、巻①〜5のキャッシュ用暗算式を「ICM 補正版」として拡張したことです。第19章で導出した補正の対応関係を一枚の表にまとめます。

| 巻 | キャッシュ式 | トーナメント補正版（本書 第19章） | 補正の方向 |
| :--- | :--- | :--- | :--- |
| 巻① | Score閾値（例: UTG ≥ 12） | 閾値 + ICM 補正 × 4 程度（例: バブル直前UTG ≥ 16） | タイト化 |
| 巻② | HandScore = 役スコア + ドロー加点 + ブロッカー加点（0-100） | 補正不要（ハンド評価のみ） | 変化なし |
| 巻② | Board Score B（CBet頻度予測） | 補正不要（フロップ分類用） | 変化なし |
| 巻② | 後手スコア = HandScore + A − C − M | 後手スコア − (ICM 補正 × 20) ≥ 20 でコール | フォールド増加 |
| 巻③ | レンジ優位（精密分析） | 補正不要 | 変化なし |
| 巻④ | バレルスコア = FlopType係数 + TurnCard係数 | 補正不要（攻撃側） | 変化なし |
| 巻④ | 後手下限確率 = 1 − α | 後手下限確率 × 1/(1 + ICM 補正) | コール頻度減少 |

### 補正が「守備側のみ」に集中する理由

表を見ると、ICM 補正が加わるのは開戦基準（Score）と守備判断（後手スコア・後手下限確率）であり、攻撃側の式（バレルスコア・Board Score B・レンジ優位・HandScore）は変化しないという構造が浮かび上がります。

ICM 補正とは本質的に「チップを失うことのペナルティが、同量を得る利益より大きい」という非対称性です。コールしてオールインに発展する可能性のある守備的判断にこそ、この非対称性は影響を与えます。攻撃側（ベットを打つ側）が成功すれば相手がフォールドしてポットを獲得するだけであり、チップを大量に危険にさらす局面にはなりません。そのため「攻撃の式には補正不要、守備の式にのみ上乗せ」という非対称な結論が導かれます（第19章参照）。

### ステージ別の補正量一覧

| ステージ | ICM 補正値 | Score 引き上げ | 後手スコア 最低ライン | 後手下限確率 × 係数 |
| :--- | ---: | ---: | ---: | ---: |
| 序盤・HU（cEV ≈ $EV） | ≈ 0.00 | +0 | 20 以上 | × 1.00 |
| 中盤（M=15〜25） | ≈ 0.20 | +1 | 24 以上 | × 0.83 |
| バブル直前（MTT） | ≈ 0.40 | +2 | 28 以上 | × 0.71 |
| ファイナルテーブル（9人） | ≈ 0.49 | +2〜+3 | 30 以上 | × 0.67 |
| バブル直前（STT） | ≈ 0.875 | +4 | 38 以上 | × 0.53 |
| HU（線形回復） | 0.00 | +0 | 20 以上 | × 1.00 |

## C-3 読書ルートの推奨

あなたがどのような目的でこのシリーズに取り組んでいるかによって、最適な読書ルートが変わります。5つのルートを示します。

### ルートA: シリーズ全巻読破（推奨）

```
巻① → 巻② → 巻③ → 巻④ → 巻⑤ → 巻⑥（本書）
```

最も確実な学習ルートです。各巻が次巻の土台になっているため、概念の積み上がりが滑らかで「なぜこの式になるのか」という理解が深まります。目安は2〜3ヶ月です。このシリーズを競技ポーカーの体系的な教科書として使う方に向いています。

### ルートB: キャッシュゲーム特化

```
巻① → 巻② → 巻③ → 巻④ → 巻⑤
```

巻⑥（本書）は省略できます。キャッシュゲーム専門でトーナメントに参加する予定がない場合、巻①〜5で体系は完結しています。巻⑤まで読み終えた段階で、必要になれば本書を加えてください。

### ルートC: トーナメント特化（最短ルート）

```
巻① → 巻② → 本書（巻⑥）
```

巻①〜5を省略して本書へ進むルートです。巻②まででHandScore・後手スコア・Board Score B の基礎を身につけてから本書を読めば、ICM 補正の議論には十分ついていけます。短期間でトーナメントの実戦に投入したい方に向いています。目安は4〜6週間です。

### ルートD: 暗算式の集中習得

各巻の核心式が詰まった章だけを読むルートです。

```
巻① 第4〜5章（Scoreの導出）
  → 巻② 第5章・第9章（HandScore）／第8章（簡易レンジスコア）／第10章（9マスマトリクス）
  → 巻② 第13章（ポットオッズ・MDF）／第16章（後手スコア フロップ版）
  → 巻④ 第6章・第8章（ターンカード5分類 / バレルスコア）
  → 巻④ 第7章・第9章・第11章（ブロッカー基礎 / α 式 / 後手スコア リバー版）／巻⑤ 第5章（ブロッカー実戦選択）
  → 本書 第4〜6章（ICM equity / ICM 補正 / M 値の暗算式）
  → 本書 第19章（補正済み統一フレーム）
```

1週間程度で各式の骨格を把握できます。後は実戦でドリルを繰り返しながら定着させます。

## C-4 シリーズの構築意図

本シリーズはなぜ「暗算式」にこだわったのでしょうか。

テキサスホールデムのGTO解析はソルバーによって精密化が進み、理論上の最善手はコンピュータが出力できる時代になりました。しかしソルバーの出力は膨大であり、卓上の意思決定に直接使える形ではありません。「このハンドでCBetすべきか、何%で打つか、相手がベットしてきたらどうするか」という判断を、5秒以内に自信を持って下せるようにする——これが本シリーズの出発点です。

**暗算で回せる計算式**。Chen FormulaやSklansky Hand Groupsという先人の知恵を現代GTOデータで再設計し、精度と実用性を両立させることを目指しました。完璧な式ではなく、実戦での誤差が許容範囲に収まる「十分に良い近似」を各章の「GTOとのズレ」コラムで率直に示しています。

**境界暗記のハイブリッド**。式で9割の判断を自動化し、境界ハンド（フォールドとコールが拮抗するハンド）だけを暗記する方式を採用しています。全ハンドを丸暗記するのではなく、判断の構造を理解することで未知の局面にも対応できます。

**シリーズを通じた一貫性**。巻②で導入したHandScoreと後手スコアは、巻⑤のリバーでも、本書（巻⑥）のICM 補正後の式でも、そのままの形で使われます。新しい巻を読むたびに式を覚え直すのではなく、同じ式が「より深い文脈」で使われる体験を重ねることで、理解が積み上がるよう設計しました。

## C-5 「迷わないポーカー」の完結地点

本書（巻⑥）をもってシリーズは完結します。

シリーズ全6巻を読み終えた今、あなたは次の7つの道具を持っています。

1. **Score**（巻①）: プリフロップの開戦基準
2. **HandScore**（巻①）: ハンド強度の数値化
3. **後手スコア**（巻①〜5）: ポストフロップ守備の統合判断
4. **バレルスコア**（巻④）: ターン攻撃の判断
5. **α 式**（巻④）: リバー配分と後手下限
6. **ICM equity / ICM 補正**（本書）: チップを賞金に換算した判断基準
7. **M 値**（本書）: ステージ別の戦略切り替え基準

これら7つは独立した7つの暗記事項ではありません。Score → HandScore → 後手スコア → バレルスコア → α 式という流れで、各式が前の式の出力を受け取りながら積み上がっています。ICM 補正とM 値は、この体系全体に「トーナメントというゲームの構造」を加える補正項です。

「迷わない」とは、何も考えないことではありません。判断の構造が明確なため、「今この局面では何を計算すればよいか」がわかる状態を指します。その計算を卓上で5秒以内に終わらせる体系が、このシリーズの7つの式です。

シリーズの完結地点は本書ですが、実戦での磨きに終わりはありません。今後はこの体系を実戦に持ち込み、第20章で示したハンドレビューの手順で自分の判断を継続的に点検してください。ICMIZERやHRCといったソルバーとの比較を繰り返すことで、式の精度と自分の判断精度の両方が上がっていきます。

## C-6 学習ロードマップ

シリーズ完了後の学習の見通しを示します。

```
【初級〜中級への移行】
  巻① → 巻② を読了（3〜4週間）
  実戦でScore / HandScore / 後手スコアを使う
  ↓

【中級者の定着】
  巻① → 巻② → 巻③ を読了（1.5〜2ヶ月）
  バレルスコア / α 式 / ブロッカー論を実戦に追加
  ↓

【トーナメント参戦】
  巻⑥（本書）を読了（3〜4週間）
  ICM 補正 / M 値 / Push/Foldを実戦に追加
  ↓

【ソルバー学習との統合】
  ICMIZER, HRC, PioSolver, GTO+ を活用（3ヶ月以降）
  自分の式の精度をソルバーで検証・更新する
  ↓

【継続的な実戦磨き】
  ハンドレビュー → 式の更新 → 実戦投入
  （永続）
```

ソルバーは本シリーズの「敵」ではなく「精度向上のパートナー」です。暗算式で大まかな方針を決め、ソルバーで境界ハンドの精度を検証する——この組み合わせが最も効率的な実力向上ルートです。
