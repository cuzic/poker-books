## 概要

- データポイント: 4,193件（11シナリオ × 24ボード × 各ハンド/ドロータイプ）
- 目標変数: フロップCBet%（0-100%）
- 最良式: **F2_RAS_Gate** (WRMSE=17.4%, R²=0.565)

## 2. F2_RAS_Gate — 最良モデルの詳細

### 式

```
gate = sigmoid(k × (RAS - t))
p_low = sigmoid(a×DE + b×hand + c×sbr_n + d×pf3bp + e×plimp + f)
CBet% = gate × 95% + (1 - gate) × p_low
```

### 最適パラメータ（1000試行後）

| パラメータ | 値 | 意味 |
|-----------|-----|------|
| k = +4.72 | 急峻性 | ゲートの切れ味（大きいほど急） |
| t = +0.55 | 閾値 | RAS=55%でゲート50%に |
| a = +3.52 | DE係数 | ドロー効果（正→ドロー多いほどベット増） |
| b = +3.68 | hand係数 | ハンド強度（正→強いほどベット増） |
| c = -1.31 | sbr_n係数 | SBR効果（負→SBR高いほどベット減） |
| d = -6.55 | p3bp係数 | 3BP（負→3BPでベット大幅減） |
| e = +0.33 | plimp係数 | リンプ（小さい正） |
| f = -2.73 | 定数項 | ベースライン抑制 |

### ゲートの実際の挙動

| RAS% | gate値 | 解釈 |
|------|--------|------|
| 30% | 0.23 | ローRAS → hand/DE依存 |
| 50% | 0.44 | ボーダー |
| 55% | 0.50 | **閾値** |
| 70% | 0.67 | ハイRAS → 広くベット |
| 90% | 0.84 | 超ハイRAS → ほぼ全域 |

## 5. 書籍向け実用フレームワーク（3ゾーン）

### ボード別RAS閾値に基づくCBet指針

```
ハイRASボード (RAS > 65%):  型1・型7 + BTN/CO開き
→ ベット幅 広: バリュー(top pair+) + セミブラフ + エアー約40%

ミドルRASボード (RAS 45-65%):  型2・型3・型5・型6
→ ベット幅 中: バリュー + 強ドロー + エアーはポジ次第

ローRASボード (RAS < 45%):  SBリンプ、型3(KJT系) + OOP
→ ベット幅 絞る: top pair+・ナットドローのみ
```

## 6. 残差分析

WRMSE 17.4% の残差の主因：

1. **セット/フルハウスのスロープレイ**（予測+15〜+20%の過大推定）
2. **KJTボードのLIMP時の超低RAS**（予測精度低下）
3. **ボード固有のドローブロッカー効果**（モデル外）
4. **SPR境界付近の不連続性**（コミット圏移行）

→ 残差17%はモデルの限界ではなく、GTO戦略の本質的な混合戦略性（randomization）による。
