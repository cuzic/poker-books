## 4. ハンドタイプ別 CBet% — キーポイント

### セットはトップペアより低い (SBR=25)

| ハンドタイプ | SBR=25 (IP平均) | SBR=100 (IP平均) |
|---------|--------------|--------------|
| top_pair | 74% | 47% (UTG/HJ/BTN) |
| two_pair | 71% | 69% |
| set | **43%** | **84%** |
| overpair | 83% | 71% |
| second_pair | 49% | 38% |
| no_made_hand | 50% | 43% |

**SBR=25でセット低い理由**: SPR≈8でセットはリバーまで置いておける = スロープレー。SPR≈18 (SBR100) ではバリューを今すぐ積み上げるほうが得。

### SBはIPと挙動が大きく異なる

- SBはOOP: 型1ドライボードでは`IP+10〜15%`の過剰CBetがある (自分がレンジアドを持つとき)
- 型2/3/5のコネクテッド系では`IP-15〜25%`の低CBet (OOPで不利)

## 5. 実務ルール (書籍用)

### SBR≤50: ボード型テーブルのみで決定

| ボード型 | フロップCBet目安 |
|---------|--------------|
| 型1 (A-highドライ) | 56〜58% |
| 型2 (K/Q-high連) | 43〜50% |
| 型3 (コネクテッド) | 31〜39% |
| 型5 (K/Q/J-highドライ) | 47〜51% |
| 型6 (ローコネクテッド) | 42〜49% |
| 型7 (ペア板) | 53〜61% |

**ポジション調整: 不要 (SBR≤50)**

### SBR=100: CO特別ルール

- CO vs BB: A/K/Q-highドライ → ほぼレンジベット (90%+)
- UTG/HJ/BTN: 通常テーブル適用 (SBR=50と同程度)

### SBR≥200: ポジション効果が顕在化

- UTG/HJ: ドライボードで高CBet (タイトレンジがA/K/Q-highに強い)
- BTN/SB: コネクテッドボードで低CBet (ワイドレンジで不利な側面も)
- データ不足のため詳細は継続調査要

## 6. GTO Wizard MTT6mSImpleの実装特性

**確認された挙動**:
- SBR≤50: 共有テンプレート (UTG=HJ=CO=BTN)
- SBR=100: COのみ独自ソリューション; UTG=HJ=BTNは共有
- SBR=200: 全ポジション独立ソリューション

この特性はデータの解釈に影響するが、実戦上の結論 (SBR≤50はポジション無関係) は有効。
