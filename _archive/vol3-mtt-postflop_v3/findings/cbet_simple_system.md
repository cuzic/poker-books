# フロップCBet 暗算スコア方式（CBS方式）— v3

## 設計思想と精度評価の結論

GTO Wizardデータ（6,367件: BTN/SB/LIMP/CO/3BP×複数SBR×全ボード×全ハンド×ドロー）の実測から：

1. **ゾーン数が増えるほど精度が下がる**（逆説）

| 判定方式 | 理論上限（オラクル） |
|---------|-----------------|
| 2値（50%閾値: ベット/チェック） | **73.1%** |
| 3値（20/80閾値） | 66.3% |
| 3値（35/65閾値） | 55.2% |
| 4値（20/50/80） | 46.3% |

理由: ボードテクスチャによる分散（σ≈25%）がノイズフロアを形成し、閾値境界が増えるほど誤分類が増える。

2. **正しい設計方針**: 50%を境界とした二値判定（ベット気味 vs チェック気味）で最高精度

3. **3BPは別システム**: CBS v3はSRP（シングルレイズポット）専用。3BPは低SPRのため単調性が崩れており、CBSが機能しない（精度53%）。

| 手牌 | HP | 実測BTN | 実測SB | 変更 |
|------|----|----|----|----|

| Aハイ | **5** | 55% | 31% | — |

| ローペア | **2** | 34% | 1% | — |
| サードペア | **3** | 46% | 31% | — |

| アンダーペア | **5** | 53% | 54% | — |
| セット | **5**（スロープレイ補正） | 58% | 45% | — |
| トップペア / オーバーペア | **7** | 80% | 65% | — |

| ドローなし / BDFD | **0** |

| コンボドロー | **+3** |

## ノーメイドハンドの「エアー逆説」【実測で完全確認】

**BTNでエアーハンドはドローがない方がCBetを打ちやすい**：

| BTN エアー + ドロー | 実測CBet% | CBS | 理由 |
|-------------------|---------|-----|------|
| ドローなし | **78%** | 5 | 今ベットしなければポットを諦めるだけ |
| onecard BDFD | 74% | 5 | ほぼ同様 |
| twocards BDFD | 68% | 5 | — |
| ガットショット | 55% | 6 | ドローエクイティ→チェックバック選択肢 |
| FD | 58% | 7 | — |
| **OESD** | **40%** ← 逆転 | **3** | 強エクイティを守るためチェックバック |
| コンボドロー | 56% | 8 | ドロー強くても混合 |

### DP補正の特例（エアーのみ）

ノーメイドハンド + OESD の場合: HP=5 から **−2 補正** → 実効CBS=3

## シナリオ別閾値【v3確定版】

| シナリオ | 閾値 | 判定 | 精度 |
|---------|------|------|------|
| **BTN/CO先手** | CBS **< 5** → チェック気味 / **≥ 5** → ベット | 69-77% |
| **SB先手（SRP）** | CBS **< 7** → チェック気味 / **≥ 7** → ベット | 71% |
| **リンプ先手** | CBS **< 7** → チェック気味 / **≥ 7** → ベット | 79% |
| 3BP | **CBS非対応** → 第11章のSPRコミットラインを参照 | 53% |

### ベット強度の目安

| CBS | BTN | SB |
|-----|-----|----|
| ≥ 9 | ベット（強：80%+） | ベット気味（70-80%） |
| 7-8 | ベット（70-80%） | ベット気味（60-70%） |
| 5-6 | ベット気味（55-65%） | チェック気味（40-55%） |
| 3-4 | チェック気味（35-50%） | チェック（20-40%） |
| ≤ 2 | チェック気味（35-40%） | チェック（1-15%） |

## 判定フロー（30秒で計算）

```
①シナリオ判定
  BTN/CO先手? → ②へ（BTN閾値5）
  SB先手?     → ②へ（SB閾値7）
  リンプ?     → ②へ（LIMP閾値7）
  3BP?        → 第11章のSPRコミット表を参照

②ノーメイドハンド？
  YES → BTN: ドローなし/GS/FD → ベット気味  OESD → チェック気味
        SB:  BDFD/コンボ → ベット気味  その他 → チェック気味
  NO  → ③へ

③CBS = HP + DP を計算

④閾値と比較
  CBS ≥ 閾値 → ベット（CBS高いほど強ベット）
  CBS < 閾値 → チェック気味（CBS低いほど純チェック）
```

## 精度検証【v3実測値ベース】

実測データ（6,367件）による実際の精度（50%を境界とした二値判定）：

| シナリオ | 精度 | 備考 |
|---------|------|------|
| BTN | **69.3%** | — |
| SB | **70.9%** | — |
| LIMP | **78.6%** | — |
| CO | **77.4%** | BTNより良い（レンジ絞り効果） |
| **全体（SRP）** | **~72%** | 3BP除く |
| 3BP | 53.3% | CBS非対応 |

### RMSE比較

| システム | RMSE | 改善率 |
|---------|------|------|
| ベースライン（定数） | 30.2% | — |
| **CBS v3（本提案）** | **26.5%** | **−12.4%** |
| オラクル（手タイプ平均） | 23.8% | −21.1% |

### 残差の主因（改善不可能な誤差）

ボードテクスチャによる分散（σ≈25%）が全体変動の50.6%を占める。
どんな公式でも約26%の誤差は不可避。

## 書籍向け最終まとめ（CBet判断カード v3）

```
CBS = HP + DP

HP: ローペア=2 / サードペア=3 / Aハイ・Kハイ=5 / セカンドペア・アンダーペア=5
    セット=5(スロープレイ) / FH・クアッズ=2-3(極スロープレイ)
    トップペア・オーバー=7 / 2ペア・ストレート・トリップス=9
    エアー（ノーメイド）=5（ただしOESD時は実効CBS=3）

DP: なし/BDFD=0 / GS=+1 / FD・OESD=+2 / コンボ=+3

判定:
  BTN/CO開き: CBS<5=チェック気味、CBS≥5=ベット
  SB開き:     CBS<7=チェック気味、CBS≥7=ベット
  リンプ開き: CBS<7=チェック気味、CBS≥7=ベット
  3BP:        CBS非対応→SPRコミット表を使用

エアー特別ルール（BTN）:
  ドローなし → ベット（今しかない）
  OESD     → チェック気味（強エクイティ→守れる）
  その他ドロー → ベット気味
```
