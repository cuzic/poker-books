## F27_narrow_iwp — 最良式の詳細

### 式の構造

```
# ゲートの閾値を手牌強度で動的調整
ta_eff = ta + w_adj × (1 - hand_norm)   ← 弱い手はより高いRASが必要

gate_A = sigmoid(ka × (RAS - ta_eff))   # バリューゲート
gate_B = sigmoid(kb × (RAS - tb))       # セミブラフゲート（ドロー用）
gate_C = sigmoid(kc × (RAS - tc))       # ピュアブラフゲート（エアー用）

p_val  = gate_A × sigmoid(va×hand + ba + cs×sbr_n + cp×p3bp)
p_semi = gate_B × sigmoid(vb×draw + bb)
p_bluf = gate_C × sigmoid(vc×is_air + bc) × is_air  # is_air: hand<0.15 & draw=0

base = max(p_val, p_semi, p_bluf)

# 補正
is_weak_pair_nodraw = (0.24 ≤ hand ≤ 0.46) & (draw < 0.05)   ← narrowペナルティ
is_slowplay = hand ∈ {set, trips}

result = clip(base - wp_pen × is_weak_pair_nodraw - sp_p × is_slowplay, 0, 1)
```

### 最適パラメータ

| パラメータ | 値 | 意味 |
|-----------|-----|------|
| ka=5.64, ta=0.059 | バリューゲート急峻性・基準点 | 基本RAS閾値5.9% |
| **w_adj=0.541** | **手牌強度によるRAS調整** | 弱手はRAS+54%が必要 |
| kb=3.68, tb=0.507 | セミブラフゲート | ドローRAS≥50.7%で活性化 |
| kc=16.23, tc=0.668 | ピュアブラフゲート | エアーRAS≥66.8%で活性化 |
| va=3.84, ba=0.08 | バリュー強度係数 | topPair(h=0.60)→91% |
| vb=0.87, bb=2.83 | ドロー係数 | ドロー時~95%のセミブラフ意欲 |
| cs=-0.82 | SBR係数 | SBR25でやや引き締め |
| **cp=-3.48** | **3BP係数** | 3BPカラーは大幅縮小 |
| **sp_p=0.255** | **スロープレイ補正** | セット/トリップス -25.5% |
| **wp_pen=0.103** | **弱ペアペナルティ** | ドローなし弱ペア -10.3% |

## 実用判断フロー（最終版）

```
Step 1: RAS判定（ノードロー集計ベット率）
  RAS ≥ 65% → 「BTN/CO方針」: ほぼ全ベット
  RAS 40-65% → 「SB方針」: 閾値ルール適用
  RAS < 40%  → 「LIMP方針」: タイト閾値

Step 2: HS計算（vol2HS + ドローボーナス）

Step 3: 閾値判定
  [BTN/CO]  HS ≥ 50 → ベット（ほぼ全ベット）
  [SB SRP]  HS ≥ 65 → ベット推奨、HS < 45 → チェック推奨
  [LIMP]    HS ≥ 75 → ベット推奨、HS < 30 → チェック推奨

Step 4: ペアゾーン補正（SB/LIMP向け）
  ドローなし + pair(lowP〜2ndP): 上記閾値より-10%方向
  = 「2ndPまではドローなしでチェック推奨」

Step 5: スロープレイ考慮
  セット/フルハウス: ベット率を-25%程度下げてミックス戦略
```

## GTO逸脱度の内訳

WRMSE 16.3%の主な残差源：

1. **フルハウス/クアッズのスロープレイ** (-26/-11%): GTO固有の極端混合戦略
2. **セット過大スロープレイ補正** (+11%): sp_p=0.255が大きすぎる
3. **RASブレット変動** (board-specific): モデル外の個別ボード効果
4. **3BP構造の非線形性**: cp=-3.48で全手牌が平坦化

WRMSE 16.3%はGTO固有のrandomization（混合戦略）による理論的限界に近い。
