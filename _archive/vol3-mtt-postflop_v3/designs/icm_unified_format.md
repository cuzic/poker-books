# ICM/SBR 補正の統一フォーマット（required_equity ベース）

*Task #11 / 設計フェーズ / 2026-05-22 / 統一フレームワーク改訂版*

本書全体で **ICM 補正と SBR 補正を `required_equity` への上乗せとして統一** するための仕様書。`designs/framework.md` の核心式 `hand_equity ≥ α(b) + ICM補正` を全章で再利用することで、読者の認知負荷を最小化します。

---

## 1. 設計思想の転換

### 1-1. 旧フォーマット（HS 閾値への +10 補正）

```
コミット閾値HS = SPR別ベースHS + ICM補正値（HS）
バブル時 +10HS、FT 時 +15HS
```

→ HS は equity の近似だが、ベットサイズによる **required_equity の変動** を反映できなかった。

### 1-2. 新フォーマット（required_equity への ICM 上乗せ）

```
required_equity = α(bet_size) + ICM補正(equity)
                = α + {序盤:0%, 中盤:3%, バブル:12%, FT:20%}

hand_equity ≥ required_equity → コール/コミット
```

→ **サイズ × ステージ × ポジション** が全部 equity 単位で統一される。

## 2. 標準テーブル（全シナリオ共通）

### 2-1. ステージ別 ICM 補正

| ステージ | ICM補正 | 適用条件 |
|---------|---------|---------|
| 序盤    | **0%**  | SBR≥25、残りプレイヤー ≥ ITM × 2 |
| 中盤    | **+3%** | SBR 15〜25、残り ≤ ITM × 2 |
| バブル  | **+12%**| 残り ≤ ITM × 1.2 |
| FT      | **+20%**| FT 到達後 |

> **検証根拠**: framework.md §1 検証 3 で `中盤 SBR20 の OOP fold% は SBR25 比 +3.6%` を確認。バブル/FT は推定値。

### 2-2. ステージ × ベットサイズ クロステーブル（required_equity 早見表）

| ステージ | ICM補正 | 1/3 pot (b=0.33) | 1/2 pot (b=0.50) | 2/3 pot (b=0.67) | pot (b=1.0) |
|---------|---------|------------------|------------------|------------------|-------------|
| 序盤    | 0%      | **20%** | **25%** | **29%** | **33%** |
| 中盤    | +3%     | **23%** | **28%** | **32%** | **36%** |
| バブル  | +12%    | **32%** | **37%** | **41%** | **45%** |
| FT      | +20%    | **40%** | **45%** | **49%** | **53%** |

> **これが本書の正本表**。各章はこの表の **該当ステージ × サイズの 1 セル** を抜粋する。

### 2-3. ポジション補正

| ポジション | 補正 | 理由 |
|-----------|------|------|
| IP | **-2%** | 実現 equity が高い（位置の利） |
| OOP | **+2%** | 実現 equity が低い（チェック強制） |

### 2-4. 最終 required_equity 式

```
required_equity = α(b) + ICM補正 + ポジション補正

α(b): 1/4=17%  1/3=20%  1/2=25%  2/3=29%  3/4=30%  pot=33%
ICM:  序盤 0%  中盤 +3%  バブル +12%  FT +20%
POS:  IP -2%  OOP +2%
```

## 3. ステージ判定の標準フロー

```
1. 残り人数 / ITM 人数を比較
   - 残り > ITM × 2          → 序盤
   - ITM × 1.5 < 残り ≤ ITM × 2 → 中盤
   - ITM × 1.2 < 残り ≤ ITM × 1.5 → 中盤後期（ICM補正 +6% へ移行）
   - 残り ≤ ITM × 1.2          → バブル
   - 残り ≤ FT 人数            → FT

2. 自分のスタックを平均と比較
   - 平均の 1.5 倍以上 → ビッグスタック（ICM 攻め側、ブラフ +）
   - 平均の 0.5〜1.5 倍 → ミドルスタック（標準補正）
   - 平均の 0.5 倍未満  → ショートスタック（コミット側、ICM 受け流す）
```

## 5. ブラフ頻度補正（攻撃側の調整）

### 5-1. ICM ステージ × ブラフ係数

```
ブラフ採用率 = 標準ブラフ頻度 × ステージ係数
```

| ステージ | ブラフ係数 | 理由 |
|---------|----------|------|
| 序盤 | 1.00 | 標準 |
| 中盤 | 0.95 | わずかにタイト |
| バブル | 0.70 | コール側 required eq が +12% で fold 増 → ブラフ採算は維持されるが分散リスク回避で減 |
| FT | 0.50 | 同上、最大リスク回避 |

> **注**: 理論的にはバブル/FT は「ブラフをむしろ増やすべき」（コール側が降りる）だが、**分散リスクと自身の生存価値** を考慮してブラフは減らす。これは「攻める側も ICM 圧を受ける」原理。

### 5-2. ビッグスタックの例外

ビッグスタック（平均の 1.5 倍以上）は ICM プレッシャーをかける側のため **ブラフ係数 +0.2**：

| ステージ | 通常 | ビッグスタック |
|---------|-----|--------------|
| バブル | 0.70 | 0.90 |
| FT | 0.50 | 0.70 |

## 6. ディフェンス頻度補正（MDF 補正）

```
MDF実効 = MDF理論 × ディフェンス係数
```

| ステージ | ディフェンス係数 | 理由 |
|---------|--------------|------|
| 序盤 | 1.00 | 標準 MDF |
| 中盤 | 0.95 | わずかにタイト |
| バブル | 0.80 | required_eq 上昇で fold 圏拡大 |
| FT | 0.70 | 同上、極度のタイト |

> **MDF（Minimum Defense Frequency）**: ベット = b ポットに対し `MDF = 1 - b/(1+b)` を必要最小限フォールド以下に保つ理論値。ICM 補正で「降りすぎが正解」となる。

## 9. 「+12 equity」の暗算根拠（バブル）

バブル時の ICM 補正は **+12% equity** で統一：

- バブル ICM の典型的トーナメント価値計算（Independent Chip Model）では、降りた場合のエクイティ保持 vs コールしてバストするリスクの差が **必要 chip equity を 10〜15% 引き上げる**
- 検証データ（findings/mtt_*_SBR20.json）では SBR25→20 で OOP fold% +3.6% → 線形外挿で バブル（SBR ≈ 10-12）+10〜15%
- 本書では **+12%** で統一（中盤 +3%、バブル +12%、FT +20% の指数的増加カーブ）

旧フォーマットの「+10 HS ≈ +10% equity」と互換だが、**ベットサイズに応じて required_eq が変動する** ことを明示できるのが新フォーマットの利点。

## 10. 旧 HS 閾値との対応表

旧表の **コミット閾値 HS** は新フレームでは **required_equity の最大値（pot 比）に到達したときの hand_equity** に相当：

| 旧 HS 閾値 | 新カテゴリ | required_eq での対応 |
|-----------|----------|---------------------|
| HS≥65 (TPTK) | Nutted の下限 | pot 比でも対応可（req=33-38%） |
| HS 50-64 (TPMK) | Thin value | 1/2 pot 以下（req≤30%） |
| HS 35-49 (2nd pair) | SDV ↔ Thin 境界 | 1/3 pot まで（req≤25%） |
| HS<35 + 強FD | Semi-bluff | required_eq 計算で個別判定 |
| HS<35 | Air | required_eq に届かず |

### コミット閾値の再導出

旧表「SPR ≥ 8 → HS≥65」「SPR 5-6 → HS≥55」は、新フレームでは：

```
コミット閾値 hand_equity ≈ α(残スタック/pot) + ICM補正
```

- SPR≥8 → all-in 相当が pot 比 4 連発 → 平均 α ≈ 27% + 中盤 3% + OOP 2% ≈ **32%**
  - hand_equity ≥ 32% に Nutted（70%+）/ Thin value（50-65%）が該当
  - 旧 HS≥65 はその下限近辺
- SPR 5-6 → all-in 相当が pot 比 3 連発 → α ≈ 30% + 5% ≈ **35%**
  - 旧 HS≥55 は equity 55% で **コール側 SDV ボーダー** に相当

> 旧 HS 閾値は「3 軸統合の暗算ショートカット」として保持可。**本書では新フォーマット（required_eq 表）を主、HS 閾値を副** とする。
