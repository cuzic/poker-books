# 第13章　ソルバーによるハンドレビュー

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 実戦ハンドを本書の3つの暗算式で振り返るフローを3例で体験し、「式の示す方向」と「GTO推奨」のズレを自分で言語化できるようになる。

---

## 13-1 レビューの4ステップ

ハンドレビューは次の4ステップで完結します。

1. **記録**: ポジション・ボード（スート込み）・アクション・「迷った箇所」をメモする
2. **再現**: そのストリートのポット・スタック・先手後手を整理する
3. **式で計算**: バレルスコア／α 式／後手スコアで「方向」を確認する
4. **差分の言語化**: 式の示す判断と実際のアクションがずれた原因を1文で書く

ステップ4で「なぜずれたか」を書く習慣が、感覚を校正する最短ルートです。

---

## 13-2 週次改善サイクル

レビューは「毎回すべてのハンドを見直す」より「重要ハンドを3〜5件選ぶ」方が定着します。選択基準は次の3つです。

- 大きなポットが動いたハンド
- 「本当にこれでよかったか」と疑問を持ったハンド
- 相手の予想外のアクションに対応したハンド

EV 差の重大度別に優先順位をつけます。−2BB 以上のミスを最優先改善し、−0.5BB 未満は「混合戦略の誤差範囲」として記録にとどめます。同じパターンのミスが3回以上出たら、条件反射で回避できる水準まで繰り返し練習します。

---

## 13-3 例1: ターンバレル判断の検証

### 実戦ハンド

- BTN vs BB（HU）、SRP、100BB
- フロップ K♥7♦2♣（ドライ）。BTN が 33%CBet（2BB）、BB コール
- ターンカード: A♥。ポット 10BB、スタック残り 94BB
- BTN ハンド: K♦Q♠（フロップ TPTK → ターンでセカンドペアに降格）
- 実際のアクション: 75%ポット CBet（7.5BB）

### ボード検証

K♦Q♠ on K♥7♦2♣A♥ → カード: K×2、A×1、Q×1、7×1、2×1。役 = ワンペア（K's）。A がオーバーカードとなりフロップの TPTK はセカンドペアに降格。

### バレルスコアで確認

```
FlopType = ドライ → 係数 8
TurnCard = OC（A はフロップ最高ランクの K を上回る）→ 係数 3
バレルスコア = 8 + 3 = 11 → 積極バレル域（閾値 7 以上）
```

スコア 11 はレンジ全体として積極的なバレルが有効な状況を示します。ただし K♦Q♠ はレンジ内の薄バリュー（セカンドペア）です。バレルスコアは「レンジ全体の傾向」であり、個別コンボの強さは別に確認が必要です。

### 学習ポイント

バレルスコアが積極バレル域でも、セカンドペアの薄バリューには小ベット（33%）かチェックバックが適切な場面があります。「スコアが高い＝全コンボで大ベット」は誤りです。ナッツ寄りのコンボが大ベットを担い、薄バリューは引いてバランスを保ちます。

## 13-4 例2: リバーのバリュー／ブラフ判断

### 実戦ハンド

- BTN vs BB（HU）、100BB
- リバーボード K♥7♦2♣A♥9♦（5枚）。ポット 30BB
- BTN ハンド: A♣J♣。BB チェック後、BTN が 75%ポット（22.5BB）でブラフを試みた

### ボード検証

A♣J♣ on K♥7♦2♣A♥9♦ → A×2、K×1、J×1、9×1、7×1、2×1。Best 5 = A♣A♥KJの1ペア（A's）。ストレートチェック: A-K-J-9-7 は5連続なし。A♣J♣ はブラフではなくトップペア（薄バリュー）。

### α 式で確認

```
α = 22.5 ÷ (30 + 22.5) ≒ 0.43
後手下限確率 = 1 − 0.43 = 0.57（BB は 57% 以上コール必要）
```

### 学習ポイント

A♣J♣ はリバーで Aペアを持つ薄バリューです。ブラフではなく 33%ポットの薄バリューベットで Kペアや9ペアからコールを引き出す方向が、GTOに近い判断です。α 式でブラフ設計を組む前に「自分のハンドはバリューかブラフか」を確認してください。

## 13-5 例3: 後手スコアの境界判断

### 実戦ハンド

- BB vs BTN（OOP）。フロップ K♥9♦4♣（ドライ）。BTN が 33%CBet（2BB）
- BB ハンド: 8♣7♣（役なし、ガットショットドロー）
- 実際のアクション: フォールド

### ボード検証

8♣7♣ on K♥9♦4♣ → K,9,8,7,4。ストレートチェック: 9-8-7-6-5（6が未）→ ガットショット（6待ち、4 アウツ）。8♣7♣ は2枚クラブ + ボード4♣1枚 → バックドアフラッシュドロー。

### 後手スコアで確認

```
HandScore = 役スコア 10（空振り） + ドロー加点 16（GS×4 = Rule of 4） = 26
後手スコア = HandScore + A − C = 26 + 12 − 12 = 26
（A = ドライ 12、C = 33%ベット 12、M = HU のため 0）
```

後手スコア 26 はコール域（20〜39）に入ります。実戦のフォールドは式から外れたミスです。

### 学習ポイント

33%ポットへの後手下限確率は 75%（α = 0.25）と非常に高く、BBはほぼ全レンジでコールが必要です。後手スコアが境界値付近（17〜22）でも、ベットサイズが 33%以下なら「コールの誤差範囲」として扱います。C 係数が小さいほどコールバイアスをかけることが有効です。

## ミニクイズ

### 問1

バレルスコアが 11（ドライ + OCターン）を示す局面で、セカンドペアの 75%ポット CBet は適切ですか。

1. 適切。バレルスコアが閾値以上なので全コンボで大ベットを打つ
2. 不適切。バレルスコアはレンジ全体の傾向であり、薄バリューは小ベットかチェックバックが適切な局面がある
3. スコアに関係なく、ポジションが IP なので大ベットが基本

### 問2

リバーで A♣J♣（Aペア）を持つとき、75%ポットのブラフは何が問題ですか。

1. ブラフ自体が問題ない。相手がフォールドすれば EV はプラス
2. A♣J♣ はブラフではなく薄バリューであり、33%の薄バリューベットが適切
3. Aを持っているのでブラフ効果が高く、むしろオーバーベットすべき

### 問3

後手スコア 26、相手ベット 33%（C = 12）のとき、適切な判断はどれですか。

1. 後手スコアが 40 未満なのでフォールドを検討する
2. コール域（20〜39）に入るのでコール。33%ベットは後手下限確率が 75% と高く、境界値付近でもコールが基本
3. チェックレイズ（後手スコアが 40 以上の場合のみ可能）

---

### 解答

- **問1**: 2（バレルスコアはレンジ全体傾向を示します。スコア 11 でも薄バリューのセカンドペアは小ベットかチェックバックの役割を担います）
- **問2**: 2（A♣J♣ は Aペアの薄バリューです。33%の薄バリューベットで Kペアや9ペアからコールを引き出す方が GTO に近い判断です）
- **問3**: 2（後手スコア 26 はコール域。33%ベットへの後手下限確率は 75% と高く、境界値付近でもコールが基本です）

> **本章まとめ**
>
> - レビューの4ステップ: 記録 → 再現 → 式で計算 → 差分の言語化
> - バレルスコアはレンジ全体の傾向。薄バリューはスコアが高くても小ベット・チェックバックが適切な場面がある
> - ブラフ設計前に「自分のハンドはバリューかブラフか」を確認する
> - 後手スコア境界値付近（17〜22）でも、33%ベットならコール優先

---

**【GTO とのズレ】**

本章の3例はいずれも「式を形だけ使って中身を理解していない」状態で起きやすいミスです。GTO と暗算式がずれる根本的な理由は、式が「レンジ平均の挙動」を近似しているのに対し、GTO は「個別コンボの役割分担」を最適化するからです。式で方向を決め、個別コンボの強さを確認するという二段構えが本書の推奨アプローチです。
