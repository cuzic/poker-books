## C-2 各巻の暗算式マップ

シリーズを貫く「1式の連鎖」を示します。上位の式が下位の式に情報を渡し、より精密な判断へと発展します。

### 巻①の暗算式（プリフロップ）

```
プリフロップスコア（共通式、全シーンで使用）:
  Score = H + L + ボーナス + ブロッカー − ペナルティ
  H: 高い方のカード値（A=14, K=13, …, 2=2）
  L: 低い方のカード値
  ボーナス: ペア+10, スーテッド+3, コネクター差1=+1, 差2-3=+0.5
  ブロッカー: A=+3, K=+2, AK 両方=+4
  ペナルティ: 差4以上=−1（A 含むと免除）, 両方9未満=−1
  T_open（6-max）: UTG≥24 / HJ≥22 / CO≥20 / BTN≥18 / SB≥22
  T_3bet/T_call（BTN vs UTG 例）: 32/28（二段閾値）
  T_4bet=33, T_5bet=39（全ポジ共通）

セットマイニングの目安:
  コール額 × 15 ≤ 相手スタック
```

巻①の出力「どのハンドでフロップに進むか」が forward 軸の出発点となります。

---

### 巻②の暗算式（フロップ基礎）

```
Board Score B（9ルール、50〜83）: T1/T2/T3 ティアと組み合わせてCBet判断に使用:
  B値の計算は9ルールに従い、T1（HS≥65）/T2（HS 20-64）/T3（HS<20）で閾値を設定
  B≥67: ドライ / B 59〜66: セミウェット / B≤58: ウェット
  → A 係数（ドライ=12, セミ=6, ウェット=0）に変換して後手スコアに入力

HandScore（手の強さ 0〜100、equity % 相当）:
  HandScore = 役スコア + ドロー加点 + ブロッカー加点
  役スコア: セット以上=88 / OP=72-78 / TPTK=70 / 2pair=78 / TPGK=66（42+Q×2）/ TPMK=50 / TPWK=45 / Aハイ=25 / 役なし=8-15 …
  ドロー加点（フロップ・Rule of 4）: FD=+36 / OESD=+32 / ガットショット=+16 / BDFD=+5 / BDSD=+2
  ブロッカー加点: +2〜+5

CBet統合式（フロップ）:
  CBet スコア = HandScore − レンジ補正（高=0/中=20/低=40）+ ポジション係数（IP=+20/OOP=0）
  判定: ≥60→75%CBet / 30〜59→33%CBet / <30→チェック

先手スコア（IPのCBet判断）:
  先手スコア = HandScore + A − M
  A: ドライ=12 / セミ=6 / ウェット=0
  M: HU=0 / 3-way=12 / 4-way+=22
  ≥ 60: 大ベット / 40〜59: 標準ベット / 20〜39: 小ベット / < 20: チェック

後手スコア（ディフェンス判断）:
  後手スコア = HandScore + A − C − M
  C: 33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30
  ≥ 40: CR検討 / 20〜39: コール / < 20: フォールド

MDF（＝ 1 − α）:
  α = ベット額 ÷ (ポット + ベット額)
  MDF = 1 − α
```

巻②の後手スコアの式は**巻④・巻⑤でもそのまま継承**されます。式の形は変わらず、適用するストリートとHandScoreの入力値が変わるだけです。

---

### 巻③の暗算式（フロップ応用）

```
レンジ優位（精密分析）: ナッツアドバンテージ + エクイティアドバンテージ（巻③）:
  外れ値ボードを吸収したCBet判断の精密化
  T1/T2/T3 × B 閾値フローを用いたCBet判断フロー
  Board Score B では捉えきれないボードの特殊性を補正

HandScore精密化:
  巻②のHandScoreを相手レンジ・ポジション・SPRを加味して補正
  Board Texture Fit（ボード相性）を係数で反映
```

巻③は巻②の簡易版を「相手レンジを読んで搾取する」精密版に拡張しています。forward 軸における相手レンジ推定の精度を高める役割を担います。

---

### 巻④の暗算式（ターン・リバー基礎）

```
バレルスコア（ターン攻撃の式）:
  バレルスコア = FlopType係数 + TurnCard係数
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=+4 / OC=+3 / ブランク=+2 / フラッシュ=+1 / コネクター=+0
  ≥ 7: 積極バレル（全レンジCBet推奨）/ < 7: ハンド依存

α 式（リバー配分の式）:
  α = ベット額 ÷ (ポット + ベット額)
  MDF = 1 − α
  V:B 比率上限 = (1 − α) : α

後手スコア（ターン版）:
  HandScore + A − C − M
  ドロー加点あり（Rule of 2: アウツ × 2） / A値はターン4枚で再評価

後手スコア（リバー版）:
  HandScore + A − C − M
  ドロー加点 = 0（役スコアのみ） / C拡張（100%=25, 150%=30）
```

巻④で初めて「ターンとリバーを個別に扱う式」が登場します。バレルスコアは current 軸の中心ツール、α 式はbackward軸でリバー設計に使います。

---

### 巻⑤の枠組み（ターン・リバー応用・本書）

```
3軸統合（新規枠組み）:
  ターン判断 = forward軸（過去レンジ）× current軸（ターンカード）× backward軸（リバー予測）
  式の形ではなく「3つの軸を同時に評価する思考習慣」として定義

backward induction（新規）:
  リバーから逆算してターン判断を設計する5ステップフロー
  Step 1: リバーシナリオ列挙
  Step 2: 各シナリオのリバーEV概算
  Step 3: ターンアクションとEVの対応付け
  Step 4: ターン判断の決定
  Step 5: リバーSPRへの影響確認

ブロッカー実戦選択（巻④ブロッカー論の実戦展開）:
  α 式と後手スコアが示した「方針」の中で、
  コンボ単位の最終選択のみをブロッカーで決定する
  ブラフ候補: バリューブロッカーが強いコンボを優先
  コール候補: バリューブロッカー保持→コール価値UP / ブラフブロッカー保持→コール価値DOWN
```

巻⑤は「式を新たに追加する」というより、「巻④の4式を3軸統合という枠組みでつなぎ、マルチストリートの設計能力を高める」ことを目的としています。

---

### 巻⑥の暗算式（トーナメント・既刊）

```
持ち分スコア（ICM equity 近似）:
  トーナメントチップをキャッシュ価値に換算する指標
  ICM計算の簡易近似式

持ち分プレミアム（ICM 補正）:
  現在のスタックに対して「チップを失うリスク」が「増やす期待値」より大きい補正
  コールレンジを絞り、プッシュレンジを広げる方向に機能

M 値（トーナメント版）:
  ブラインドとアンティを合計したポット1周分に対するスタック倍率
  M = スタック ÷ (BB + SB + アンティ合計)
  M < 5: プッシュ / フォールド判断が支配的
  M 5〜10: コール・3-betの選択肢あり
  M > 10: 通常のキャッシュゲーム近似が可能
```

巻⑥はトーナメント固有の「チップ価値の非線形性（ICM）」を体系化します。巻①〜5で学んだキャッシュゲームの式を、ICM 補正として「巻⑥で上書き」するイメージです。

## C-3 式の継承関係図

```
【巻①】 オープンスコア
  ↓ 「どのハンドでフロップに入るか」を決定（forward 軸の起点）

【巻②】 Board Score B・HandScore → A 係数
        HandScore（役スコア + ドロー加点 + ブロッカー加点）
        CBet統合式 / 先手スコア / 後手スコア
        MDF（= 1 − α）
  ↓ 「フロップでどう動くか」を決定
  ↓ HandScore と後手スコアの式は巻④・巻⑤で変形なく継承

【巻③】 レンジ優位（精密分析）・T1/T2/T3 × B 閾値フロー
  ↓ 「相手レンジを読んで搾取する方法」を追加
  ↓ レンジ優位（精密分析）は巻⑤の forward 軸（レンジ推定精度）に寄与

【巻④】 バレルスコア（FlopType係数 + TurnCard係数）
        α 式（= ベット額 ÷ (ポット + ベット額)）
        後手スコアターン版（ドロー加点あり・A値ターン再評価）
        後手スコアリバー版（ドロー加点=0・C値拡張）
  ↓ 「ターン・リバーの基礎式」を確立
  ↓ バレルスコア → current 軸の核心ツール
  ↓ α 式 → backward 軸でリバー設計に使用

【巻⑤（本書）】 3軸統合（forward × current × backward）
                backward induction（5ステップ逆算設計）
                ブロッカー実戦選択（コンボ単位の最終判断）
  ↓ 「マルチストリートを1ラインとして設計する能力」を確立
  ↓ シリーズのキャッシュゲーム編の完結点

【巻⑥（既刊）】 持ち分スコア / 持ち分プレミアム / M 値（トーナメント版）
  ↓ 「ICMを加味したトーナメント特有の補正」を体系化
  ↓ 巻①〜5のキャッシュゲーム式を「補正する形」で上書き
```

## C-4 式が「変わった部分」と「変わらない部分」

シリーズを通じて同じ式が使われている部分と、拡張・補正された部分を整理します。

### 変わらない部分（巻②から全巻共通）

| 式 / 係数 | 登場巻 | 変化の有無 |
|---|---|---|
| HandScore の基本形 | 巻② | 変化なし（式の形は同一） |
| 後手スコアの式 | 巻② | 変化なし（式の形は同一） |
| MDF = 1 − α | 巻② | 変化なし（α 式と等価） |
| A 係数（ドライ=12/セミ=6/ウェット=0） | 巻② | 巻②で定義 |
| M係数（HU=0/3-way=12/4-way=22） | 巻② | 巻②で定義 |

### 拡張・精密化された部分

| 式 / 係数 | 巻②の値 | 巻④・巻⑤の拡張 | 理由 |
|---|---|---|---|
| ドロー加点（HandScore） | フロップに適用（Rule of 4: アウツ × 4） | ターンは Rule of 2（アウツ × 2）、リバーは = 0 | ストリートごとの残カード数に対応 |
| C 係数（ベット負担） | 33%=12 / 50%=17 / 75%=22 | 100%=25 / 150%=30 を追加 | ターン・リバーのオーバーベット対応 |
| A値の更新タイミング | フロップで固定 | ターン4枚・リバー5枚で毎回再評価 | ボードテクスチャが変化するため |

### 巻④・巻⑤で新規追加された概念

| 概念 | 登場巻 | 役割 |
|---|---|---|
| バレルスコア | 巻④ | current 軸の定量評価（FlopType係数 + TurnCard係数） |
| ターンカードの5分類 | 巻④ | current 軸の分類基準 |
| 3軸統合 | 巻⑤ | マルチストリート設計の枠組み |
| backward induction | 巻⑤ | リバーから逆算してターンを設計するフロー |
| ブロッカー実戦選択 | 巻⑤ | コンボ単位の最終選択（α 式・後手スコアの補完） |
| ハンドエボリューション追跡 | 巻④・巻⑤ | ペアターン等での役変化を毎回確認する習慣 |

## C-6 用語の変遷と統一（シリーズ全体）

シリーズを通じて用語が精密化された箇所を一覧します。

| 概念 | 巻②での表記 | 巻④・巻⑤での表記 | 変更の理由 |
|---|---|---|---|
| 最低ディフェンス頻度 | MDF | MDF（MDFライン / MDF / 後手スコアの境界値） | 文脈に応じた3系統に精密化 |
| ボード評価指標 | Board Score B（9ルール） | Board Score B（FlopType係数として引き継ぎ） | IPのナッツアドバンテージを直接数値化するモデルに統一 |
| 精密版ボード評価 | レンジ優位（精密分析） | レンジ優位（forward軸の精密化） | ナッツADV+エクイティADVの2軸概念に発展 |

「MDF」は3通りに使い分けます。

- **MDFライン**: しきい値・境界として語るとき（「ラインを下回ると守れていない」）
- **MDF**: 具体的な%数値を語るとき（「75%ベット時のMDFは57%」）
- **後手スコアの境界値**: 後手スコアの式の判断境界を語るとき（「後手スコア≥後手スコアの境界値ならコール」）

いずれも同じ概念の、文脈に応じた表現です。数値は常に「MDF = 1 − α」から計算できます。

> **付録Cまとめ**
>
> - シリーズは巻①〜巻⑤の積み上げ構造。各巻の式が次巻の入力になる。
> - 後手スコアの式（HandScore + A − C − M）は巻②から変わらず、ターン・リバーで同一形を使う。変わるのは「ドロー加点の有無」と「A値の更新タイミング」のみ。
> - 巻⑤の新規追加は「式」ではなく「枠組み」。3軸統合・backward induction・ブロッカー実戦は、巻④の4式をつなぎマルチストリート設計能力を高める枠組みです。
> - 巻⑤の読了でキャッシュゲーム編が完結。巻⑥でトーナメント特有のICM 補正が加わります。
