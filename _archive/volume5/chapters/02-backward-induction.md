# 第2章　リバーから逆算するターン設計（backward induction）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバーの主要シナリオを先読みし、その結果からターンのアクションを逆算する「backward induction」を手順化する。巻④で学んだα 式・後手スコア・ブロッカーを組み合わせて、ターン判断に奥行きをもたせる。

---

## 2-1 backward induction とは

ゲーム理論に「backward induction（逆向き帰納）」という標準的な分析手法があります。「最終局面で何が最善かを先に決め、そこから逆算して現在の行動を選ぶ」という考え方です。チェスのエンドゲーム分析でも、企業の価格競争の分析でも使われる普遍的な手法です。

ポーカーへの適用は直感的です。リバーが最終ストリートです。リバーで何が起きるかを先読みし、「そのリバーシナリオに向けてターンでどう準備するか」を逆算すればよい。

```
通常の思考（forward）:
  ターンで今のハンドは強いか? → 強ければベット → リバーで考える

backward induction:
  リバーでこのハンドは何になるか? → バリューになれるか?
    → ターンでどう準備するか? → ターンのアクションを決める
```

「今強いか」ではなく「リバーで何になるか」を起点に判断を設計する思考法がbackward inductionです。

ターンが「3軸の交差点」であることは第1章で確認しました。3軸のうち backward 軸（リバー予測）が実際にどう機能するかを本章で具体化します。backward 軸は「リバーを先読みする」という方向性の概念でしたが、本章ではその先読みを5つのステップに分解し、実際の計算に落とし込みます。

## 2-2 リバーの主要シナリオを想定する

### リバーカードの5分類

リバーで落ちるカードは48枚のデッキ残りから1枚です。完全に予測できません。しかし、巻② 第6章で学んだターンカードの5分類は、リバーカードにも同じ枠組みで適用できます。

```
ペア:    ボード上にある既存のランクと同ランクが落ちる
OC:     現在のボードトップより高いランクが落ちる
ブランク: 既存のストレート・フラッシュの形成に関与しない安全なカード
フラッシュ: 同スートが3枚以上になり、フラッシュが完成する（または可能性が高まる）
コネクター: ストレートを完成させる、またはドローを進行させるカード
```

このうちどのカテゴリが実際に落ちるかを事前に確率的に想定します。ただし「全5種を均等に予測する」必要はありません。

### 主要シナリオを2〜3個に絞る

実戦での先読みは2〜3個の代表的シナリオに絞ることが合理的です。

絞る基準は「そのシナリオが落ちる確率が相対的に高いか、または自分のアクション判断が大きく変わるか」です。以下の優先順位で選びます。

```
優先1: フラッシュ完成シナリオ（ウェットボードの場合）
  → 自分と相手のレンジが大きく変化するため、先読みの価値が高い

優先2: ペアシナリオ
  → ボードのナッツアドバンテージが変化するため重要

優先3: ブランク/OCシナリオ
  → 現在のレンジ状態がほぼ維持されるため、比較的予測しやすい
```

コネクターは確率的に低く、かつ影響が複雑なため、入門段階では「コネクターはブランクに近い」として扱い、詳細な計算は省略して問題ありません。

### シナリオ想定の実例

ターン終了時点でのボードが K♠8♣3♥8♠（ペアターン後）だとします。リバーで何が落ちうるかの主要シナリオを考えます。

ボードに K・8・3・8 の4枚があります。フラッシュ要素はスペードが2枚（K♠・8♠）のみで、リバーにスペードが落ちてもスペード3枚止まりです（フラッシュ不成立）。この場合フラッシュシナリオの影響は限定的です。

```
シナリオA: ブランク（2〜7のスペード以外）
  → 最も高頻度で落ちる。ターン後のレンジ状態が維持。

シナリオB: OC（A・Q・J・T・9のうちKより高ランク= A）
  → Aの落ちはKのTPTKをセカンドペアに格下げする。

シナリオC: ボードペア（K、3、8の落ち）
  → ボードがトリプル化。フルハウス・クワッズ絡みで大きな変化。
```

このような主要シナリオを先に立てることが backward induction の出発点です。

## 2-3 リバーアクションを各シナリオで決める

### 各シナリオでの自分のハンドを確認する

シナリオ別に「リバーでの自分のハンドの強さ」を確認します。ハンドの役はリバーカードによって変化します。ターン段階でのハンドをリバーシナリオ別に計算し直すことが必要です。

具体例を挙げます。ターン後のボードが K♠8♣3♥8♠ で、自分のハンドが K♥Q♦（トップペア・セカンドキッカー）だとします。

| リバーシナリオ | リバーボード | ハンドの役 | HandScore目安 |
|---|---|---|---|
| ブランク（例: 5♦） | K♠8♣3♥8♠5♦ | K-K-8-8（2ペア・top+bottom）| 約72 |
| OC（A） | K♠8♣3♥8♠A♦ | A-K-K-8（トップペア格下げ・2ペア維持）| 約72（ただし相手レンジのAが怖い） |
| ペア（K） | K♠8♣3♥8♠K♦ | K-K-K-8（フルハウス）| 約92 |
| ペア（3） | K♠8♣3♥8♠3♦ | K-K-8-8-3（2ペア維持）| 約72 |

上記の役判定を確認します。ハンドK♥Q♦ + ボードK♠8♣3♥8♠の5枚では、ランク別にK=2枚（K♥・K♠）、8=2枚（8♣・8♠）、Q=1枚、3=1枚。best 5はK-K-8-8-Q（2ペア、Qキッカー）です。

リバーにK♦が落ちる場合、ボードはK♠8♣3♥8♠K♦の5枚。ランク別にK=3枚（K♥・K♠・K♦）、8=2枚。ハンドK♥Q♦のK♥を含めるとK=4枚ですが、K♥はハンドの1枚でありボードに3枚です。K♥（手）+ K♠K♦（ボード）+ 8♣（ボード）+ 8♠（ボード）= K-K-K-8-8のフルハウスです。best 5としてはフルハウス（K's full of 8's）になります。

### バリュー候補を決める

リバーシナリオ別に「バリューベットを打てるか」を判断します。基準は「コールされて期待値がプラスになる強さか」です。

```
バリューベット候補の基準（目安）:
  相手のコールレンジの過半数に対して勝てる → バリュー候補
  相手のコールレンジのうち勝率が50%未満 → バリューは薄い
```

相手のコールレンジを精密に計算することは実戦では困難です。後手スコア（巻④ 第11章）の逆算で近似します。「相手が後手スコア ≥ 20 でコールしてくる場合、相手のコールラインのHandScoreはいくつか」を計算し、それより自分のHandScoreが高ければバリューとして機能します。

### ブラフ候補を決める

リバーシナリオ別に「ブラフの材料があるか」を確認します。

ブラフ候補の第1条件は「ショーダウン価値がほぼゼロ」です。価値のあるハンドをブラフに使うことはバリューを失います。

ブラフ候補の第2条件は「バリューブロッカーを持つか」（巻② 第7章）です。バリューブロッカー（相手の強いコールコンボを削るカード）を持つ弱いハンドがブラフの優先候補です。

```
ブラフ優先度:
  高: バリューブロッカーあり + ショーダウン価値ゼロ
  中: バリューブロッカーあり + ショーダウン価値わずか
  低: バリューブロッカーなし + ショーダウン価値ゼロ
  不可: ショーダウン価値が十分あるハンド（バリューとして使うべき）
```

### α 式でベットサイズと配分を確認する

バリュー候補とブラフ候補が揃ったら、α 式（巻④ 第9章）でベットサイズと配分の適切性を確認します。

```
α = ベット額 ÷ (ポット + ベット額)

ベット配分の確認:
  ブラフ上限数 = バリューコンボ数 × α ÷ (1 − α)

例: 75%ポットベット（α ≈ 0.43）でバリュー8コンボ
  ブラフ上限 = 8 × (0.43 ÷ 0.57) ≈ 6コンボ
```

ブラフ候補がブラフ上限に満たない場合は、ベットサイズを小さくしてブラフ上限を減らすか、チェックに回して配分を整える選択があります。

## 2-4 リバーから逆算するターン判断

### 逆算の3ルール

シナリオ別のリバーアクション（バリュー/ブラフ/チェック）を決めた後、ターンに戻ります。ターンでのアクションは次の3ルールで逆算します。

**逆算ルール1: リバーでバリューになれる手 → ターンでバリューとして打つ**

リバーの主要シナリオのほとんどでバリューベットを打てる強さがあるなら、ターン段階でもバリューベットを打ちます。ポットを積み上げることでリバーのバリューベット額を増やし、期待値を最大化します。

```
例: K♥Q♦ on K♠8♣3♥（フロップ）+ 8♠（ターン）
  → リバーの主要シナリオ（ブランク・OC等）でKのトップペア〜2ペアとして
    バリューが通る → ターンでダブルバレル推奨
```

**逆算ルール2: リバーでブラフになれる手 → ターンでセミブラフまたはブラフとして打つ**

リバーで外れが確定した場合のブラフ候補（ドロー系・バリューブロッカー持ちの弱いハンド）は、ターン段階でもセミブラフとして積極的に打てます。ターンで打つことで相手にフォールドエクイティを得られ、万一リバーでも完成しなかった場合のブラフの文脈（ストーリー）を維持できます。

```
例: フラッシュドロー（FD）保有で、リバーでFD完成なら強バリュー、
    FD外れなら相手のナッツをブロックするバリューブロッカー的ブラフ
  → ターンでセミブラフとして打てる

例: バリューブロッカーを持つ弱い手（例: ナッツブロッカーを持つ
    ハイカード）がリバーでブラフ候補
  → ターンで温存するか、小さいベットで圧力をかけておく
```

**逆算ルール3: リバーで何もできない手 → ターンでチェック**

リバーのどのシナリオでもバリューにもブラフにもならない手は、ターンでベットする理由がありません。チェックにすることで守備的なポジションを維持し、見せ札的な情報流出を防ぎます。

```
例: 完全なショーダウン価値のみのハンド（中程度のワンペア等）で、
    リバーでは相手のコールレンジに負けることが多い
  → バリューにならず、ブラフ候補にも適さない
  → ターンでチェックバック
```

### 逆算の統合フロー

3つのルールをまとめると、ターン判断は次のフローになります。

```
Step 1: ターン後のボードから主要リバーシナリオ（2〜3個）を立てる
Step 2: 各シナリオでハンドの役を確認する（ドロー加点の変化を追う）
Step 3: 各シナリオでバリュー候補かブラフ候補かを判断する
Step 4: α 式でベット配分を確認する
Step 5: 逆算ルール1〜3でターンアクションを決める
```

このフローは「5ステップ backward induction」として実戦で適用します。1ストリートあたりの考慮時間は実戦では限られますが、主要シナリオを2個に絞れば、Step 1〜3を合わせて10〜15秒程度で処理できます。Step 4と5は直感的に速く処理できるようになります。

## 2-5 backward induction の実例

5ステップを具体的な局面で実演します。

### 状況設定

- 場面: BTN vs BB、シングルレイズポット（SRP）、100BB、6-max
- フロップ: T♠9♦4♣（セミウェット）でBTNがCBet（33%）、BBがコール
- ターン: 8♥が落ちた（ボード: T♠9♦4♣8♥）
- ターン後のポット: 約24BB（両者の投資額の累積）、残りスタック: 約76BB
- BTNのハンド: A♠K♦（ハンドは完全なオーバーカード2枚。ボードに当たっていない）

まず役を確認します。A♠K♦ + T♠9♦4♣8♥の5枚のランクを確認します。A・K・T・9・4・8。5連続を確認します。A-K-Q-J-T（ブロードウェイ）: Q・Jがなく不成立。K-Q-J-T-9: QとJがなく不成立。T-9-8-7-6: 7と6がなく不成立。A-K-T-9-8: 連続していない（Kから先が途切れる）。ストレート不成立。フラッシュ: スペードはA♠・T♠の2枚、ダイヤはK♦・9♦の2枚、いずれも5枚に届かず不成立。役なし（Aハイ）。HandScore = 25。

BTNはノーペア・ノードロー（完全にボードを外したハンド）でターンを迎えています。

### Step 1: 主要リバーシナリオを立てる

ボードはT♠9♦4♣8♥（4枚）です。

フラッシュ要素: スペード2枚（T♠）とハート1枚（8♥）のみ。リバーにスペードが落ちてもスペード3枚止まり（フラッシュ不成立）。フラッシュシナリオの影響は低い。

ストレート要素: T・9・8の連続があります。7が落ちると8-9-T-7の4連続、6が落ちると6-7か。.. 確認すると現在ボードにT・9・8があります。7が落ちると T-9-8-7の4連続（J・6を引けば5連続）。Jが落ちるとJ-T-9-8の4連続（Q・7を引けば5連続）。7やJは「コネクター」系のリバーカードです。

```
シナリオA: ブランク（A・K・Q以外のOC、またはドロー非完成のカード。例: 2♦・5♣）
  → ボードの連続性は進行しない。相手のレンジは変化なし。

シナリオB: ストレート完成系（7または Jのいずれか）
  → T-9-8-7またはJ-T-9-8のストレートが多数完成。レンジが大きく変化。

シナリオC: OC（A・K・Q）
  → ボードにオーバーカードが落ちる。相手のAペアやKペアが進化。
```

BTNのA♠K♦から見て、シナリオCが最も重要なシナリオです。AまたはKが落ちればトップペアに昇格します。

### Step 2: 各シナリオでハンドの役を確認する

| シナリオ | リバーカード例 | BTNのA♠K♦の役 | HandScore |
|---|---|---|---|
| A（ブランク） | 2♦ | ハイカード（Aハイ） | 25 |
| B（コネクター7） | 7♣ | ハイカード（Aハイ）※ストレート不成立確認 | 25 |
| C（OC: A） | A♦ | トップペア（Aのペア）、Kキッカー（TPTK相当） | 70 |
| C（OC: K） | K♣ | Kのペア（T on board より下）、Aキッカー（TPTK相当、42+A×2=70） | 70 |

シナリオBの役確認: A♠K♦ + T♠9♦4♣8♥7♣の5枚ボード。ランク: A・K・T・9・4・8・7。5連続: T-9-8-7-6（6なし）、9-8-7-6-5（6・5なし）。A・Kは連続の末端: K-Q-J-T-9（Q・J なし）。ストレート不成立を確認。役なし（ハイカード）です。

なお7が落ちた場合、7-8-9-Tのストレートを完成させるために6またはJが必要ですが、リバーカードは7の1枚のみ追加されます。つまりシナリオBでBTNのA♠K♦はストレートを完成させません。

### Step 3: バリュー候補かブラフ候補かを判断する

シナリオAおよびBでは、BTNのA♠K♦はHandScore = 25のハイカード（Aハイ）です。リバーでバリューベットは打てません。シナリオCでのみトップペアに昇格し、バリュー候補になります。

ブラフ候補の判断: A♠K♦はA♠を持ちます。ボードT♠9♦4♣8♥にはAが含まれません。相手のレンジにはAペア（AK・AQ・AJ等のオーバーカードのコール）が残っているため、A♠はA絡みのバリューコンボを削る「バリューブロッカー」として機能します。ただしK♦はボードのKを削れる程度の効果です。

よってBTNのA♠K♦は「シナリオCではバリュー候補、シナリオA・Bではブラフ候補（A♠のバリューブロッカー持ち）」という評価になります。

### Step 4: α 式でベット配分を確認する

リバーで打つ想定ベットサイズを50%ポット（α ≈ 0.33）とします。ポットを100に正規化し、50%ベット = 50 として計算します（実額: ポット24BB × 50% = 12BB）。

```
α = 50 ÷ (100 + 50) ≈ 0.33
V:B = (1 − α) : α = 2 : 1
ブラフ上限 = バリューコンボ数 × 0.33 ÷ 0.67 ≈ バリューコンボ数 × 0.5
```

シナリオCでトップペアになれるハンドがBTNのレンジに何コンボあるかを概算します。BTNのオープンレンジでAx・Kx系のコンボは多数ありますが、フロップ・ターンを経て残っているコンボに絞ります。ここでは簡略化して「バリュー候補が複数コンボある」と仮定し、ブラフ上限がバリューの半数程度と理解します。A♠K♦はそのブラフ枠の1コンボとして機能します。

### Step 5: ターンアクションを逆算する

BTNのA♠K♦の評価をまとめます。

- シナリオA（ブランク、最頻度）: リバーでハイカードのままブラフ候補
- シナリオB（コネクター、中程度）: リバーでハイカードのままブラフ候補（ストレート完成で相手レンジが変化する可能性あり）
- シナリオC（OC: AまたはK、一定頻度）: リバーでトップペアとしてバリュー候補

リバーで「バリューになれる可能性がある」かつ「バリューブロッカー持ちのブラフ候補にもなれる」という状況です。

逆算ルールを適用します。シナリオCでバリューになれる → ルール1（ターンでバリューとして打つ可能性）。シナリオA・Bでブラフ候補になれる → ルール2（ターンでセミブラフとして打てる可能性）。

ただし、ここでハンドの実態を再確認します。現時点でA♠K♦はノーペア・ノードローです。ターンでのバレルスコア（巻④ 第8章）を補助として考えると、ハンドの現在価値がゼロに近い中で打つことはブラフそのものです。

**ターン判断の結論**:

A♠K♦はリバーでバリューになれるシナリオC（OC）のためにターンでベットしてポットを積み上げる動機があります。同時にブラフとしての文脈（ストーリー）を作るためにもターンベットは有効です。一方、現在価値がゼロに近いため、大サイズのベットは相手に強いコールレンジを呼び込むリスクがあります。

backward induction の判断: 「リバーのOCシナリオでバリューになれるため、ターンで小〜中サイズのベットを打つことで、OC完成時のポットを積み上げる。リバーのブランク・コネクターシナリオではブラフとして継続する選択肢を持つ」

バレルスコアと3軸統合での最終判断は第4章の統合実例で行いますが、backward 軸からの示唆は「ターンでの適度なベットは合理的」という方向性です。

## 2-6 backward induction の限界と実戦的な近似

### ソルバーと人間の差

GTOソルバーは「リバーに落ちうる全カード × 全アクションシーケンス」をゲームツリーとして展開し、期待値を正確に計算します。この計算は何百万ものノードを含み、人間が実時間で再現できません。

backward induction はその完全な計算を「2〜3個の代表的シナリオへの先読み」で近似します。これは意図的な近似です。完全な計算への道ではなく、「完全な計算の方向性を短時間で掴む」ための実戦ツールです。

### 近似の誤差がどこで生じるか

近似の誤差は主に2点で生じます。

**誤差1: シナリオの見落とし**

「ブランク」「ペア」「OC」という代表シナリオに絞ることで、稀だが影響の大きいシナリオ（例: 特定のコネクターでナッツアドバンテージが逆転する）を見落とす場合があります。特にボードが非常に連続性が高い場合は、コネクター系のリバーカードの影響を過小評価しないよう注意が必要です。

**誤差2: 相手のレンジ推定の粗さ**

「相手のコールレンジ」を精密に把握できないと、バリューかブラフかの判断がずれます。forward 軸（第1章・第3章）で学ぶ過去レンジの評価を組み合わせることで、この誤差を縮小できます。

### 近似を最小化する3つの習慣

実戦での近似精度を高めるための習慣を3点示します。

**習慣1: 最高影響シナリオを必ず含める**

自分のレンジにとって「最も判断が変わるシナリオ」を常に主要シナリオに含めます。例えばフラッシュドローを抱えている場合、フラッシュ完成シナリオを必ず評価対象に入れます。

**習慣2: 役の変化を毎回計算する**

リバーカードが落ちると、ターン時点の役から変化します。「ターンでKのトップペアだからリバーでも強い」ではなく、各シナリオでのリバー後の役を毎回確認します。特にペアシナリオ（ボードペア化）とOCシナリオ（ランク昇降）が影響します。

**習慣3: シナリオ別の判断をターン前に揃える**

ターンで打つ前に「リバーシナリオA/B/Cで何をするか」をざっくり決めておきます。「バリュー打つ予定」「ブラフ打つ予定」「チェック予定」が揃っていると、リバーでの判断が速くなります。これが backward induction の実戦的な価値の核心です。

## 2-7 SPR と backward induction の連動

### SPR がターン判断の幅を決める

backward induction でターンのアクションを逆算する際に、もう1つ考慮すべき変数があります。SPR（スタックポット比率）です。

```
SPR = 残りスタック ÷ ポット
```

SPRが高い状態（例: SPR ≥ 6）では、リバーまでに複数回のベット/コールが入る余地があります。ターンで打ったベットがリバーのポットを積み上げ、リバーのバリューベット額も増えます。backward induction でのリバーのシナリオ別「理想ポットサイズ」が達成しやすいです。

SPRが低い状態（例: SPR ≤ 3）では、ターンでベットするとリバーではほぼポットコミットメント状態になります。逆算の結果が「ターンで打つとリバーがほぼオールイン相当」という場合、ターンのアクションがリバーの全ベット額を決定してしまいます。

```
SPR別のターン判断への影響:
  SPR 6以上: ターンのバレルがリバーへの橋渡し。サイズを調整する余地あり。
  SPR 3〜6: ターンのベットがリバーのコミットを強く意識させる。
  SPR 3未満: ターンでオールインの検討が入る。backward induction のリバーシナリオが
            「オールイン」と「フォールド」の2択に単純化される。
```

SRP（シングルレイズポット）のターン開始時、SPRは約8前後です（フロップでCBetコールを経た状態）。この段階ではターンバレルがリバーを「ポットコミット圏に近い」状態に近づけますが、まだオールインではありません。backward inductionでは「ターンで75%ポットを打つと、リバー開始SPRは約3〜4になる」という計算を念頭に置きます。

### リバーで打ちたいサイズから逆算するターンサイズ

backward induction の応用として「リバーで打ちたいベット額から逆算してターンサイズを決める」という手順があります。

```
目標: リバーで50%ポットを打ちたい
現状: ターン開始ポット = 24BB、残りスタック = 76BB

ターンで仮にx BBのベット額を打つとすると:
  ターンコール後のリバーポット ≈ 24 + 2x BB
  リバーで打てる50%ポット額 ≈ (24 + 2x) × 0.5

リバーで打てる額がリバー残りスタックの50%以内に収まるよう逆算:
  リバー残りスタック = 76 − x（ターンでのベット分を除く、コール側は同額投資）

実際の計算は複雑ですが、感覚として:
  ターンで中程度（33〜50%ポット）のサイズを打てば、
  リバーで中程度（50〜75%ポット）のサイズが打てる範囲のSPRが残る
```

この逆算は「ターンをどのサイズで打てば、リバーで希望サイズが打てるか」という問いへの近似回答です。詳細な計算は第4章（マルチストリート統合判断）で扱います。

## ミニクイズ

### 問1

backward induction をポーカーに適用した場合の説明として最も正しいものを選んでください。

1. 現在のターンハンドの強さだけを評価し、強ければベット、弱ければチェックする思考法
2. リバーで何をするかを先に決めてから、ターンでどう準備するかを逆算する思考法
3. 過去のフロップでのアクション履歴を振り返り、相手のレンジを再評価する思考法
4. GTOソルバーと同じ完全な期待値計算を手計算で再現する思考法

### 問2

ターンでブラフ候補のハンドを選ぶ際に、backward induction の観点から最も優先すべき条件を選んでください。

1. ターン時点のHandScoreが高い（中程度以上のペアなど）
2. リバーでバリューブロッカーとして機能し、かつショーダウン価値がほぼゼロ
3. フロップでCBetを受けてコールした中強度のハンド
4. 相手がフォールドしやすい心理的プレッシャーがある場面

### 問3

BTN vs BB（HU）、SRP、100BB。ターン後のボードがA♠K♦7♣3♦（4枚）。BTNのハンドがQ♥J♦（役なし：A・K・Q・J・7・3のランクでストレート不成立、フラッシュ不成立）。リバーで50%ポットのベットを予定する場合（α ≈ 0.33）、このハンドの逆算による評価として最も適切なものを選んでください。

1. Q♥J♦はターン時点で役なしなので、チェックしてリバーで判断すべき
2. Q♥J♦は主要リバーシナリオ（ブランク等）でも強くならないため、ブラフとしての材料が何かあるか確認してからターンアクションを決める
3. リバーで役なしになることが確定しているため、ターンでオールインして圧力をかけるべき
4. Q♥J♦はショーダウン価値があるため、バリューベットとしてターンで打つ

---

### 解答

- **問1**: 2（backward induction は「最終局面（リバー）で何が最善かを先に決め、そこから逆算して現在（ターン）のアクションを決める」手法です。選択肢1は「現在の強さのみ評価」であり backward induction ではありません。選択肢4は完全な計算の再現を目指すものですが、backward induction は人間が使える近似として「代表的なリバーシナリオへの先読み」で完全計算を近似します）

- **問2**: 2（backward induction の観点では、ブラフは「リバーで相手のコールレンジを削れる（バリューブロッカーあり）」かつ「自分自身にショーダウン価値がほぼない（チェックしても意味が薄い）」ハンドが優先候補です。選択肢1はハンドが強すぎてバリューとして使うべきです。選択肢3は現時点の中強度ハンドの説明であり、ブラフ優先度は低い。選択肢4はGTO的なブラフ選択の根拠にはなりません）

- **問3**: 2（Q♥J♦はターン時点で役なしで、リバーの主要シナリオ（ブランク・ペア等）でも役に変化がほぼありません。バリュー候補にはなれません。しかしブラフ候補としての適性を確認する必要があります。Q♥J♦はQとJを持ちますが、このボード（A♠K♦7♣3♦）でのバリューブロッカー効果は限定的です（A・Kのキーカードを持たない）。そのためブラフとしての優先度も高くなく、ターンでのベットは慎重に判断すべきです。チェックの選択肢も十分あります。選択肢1の「チェックしてリバーで判断」も合理的ですが、選択肢2の「ブラフとしての材料を確認してから決める」がより正確な手順です）

> **本章まとめ**
>
> - backward induction とは「リバーで何をするかを先に決め、ターンでどう準備するかを逆算する」手法。ゲーム理論の標準的な分析手法をポーカーに適用したもの。
> - リバーの主要シナリオは2〜3個に絞る（ブランク・OC・フラッシュ完成・ペア等から状況に応じて選択）。全シナリオの完全予測は人間には不可能であり、代表シナリオへの近似で十分に実用的。
> - 各シナリオでハンドの役を確認し（ターン段階から変化する）、バリュー候補かブラフ候補かを判断する。α 式（巻④ 第9章）でベット配分を確認する。
> - 逆算の3ルール: リバーでバリューになれる手→ターンで打つ / リバーでブラフになれる手→ターンでセミブラフ / リバーで何もできない手→ターンでチェック
> - SPRとの連動: ターンのベットサイズはリバーのSPRを決める。「リバーで打ちたいサイズから逆算してターンサイズを決める」という方向で使える。
> - backward induction は完全計算の近似ツール。誤差は「シナリオの見落とし」と「相手レンジ推定の粗さ」から生じる。forward 軸（第3章）との組み合わせで精度を高める。

**【GTOとのズレ】**

GTOソルバーが行う backward induction は本章の5ステップよりはるかに精密です。ソルバーはリバーに落ちうる全44枚（ターン終了後の残りデッキ）について、それぞれのリバーカード上でのゲームツリーを完全に解きます。各リバーカードでの期待値を正確に求めた後、その加重平均でターンでの最適アクションを決定します。「2〜3個の代表シナリオへの近似」とは次元が異なります。

人間が backward induction を適用するときに生じる最大のズレは「シナリオ選択の偏り」です。自分に都合のよいシナリオ（例: ドローが完成して強くなるシナリオ）を優先的に想定し、都合の悪いシナリオ（例: ブランクが続いて何も変化しない）を軽視しがちです。GTOはすべてのシナリオを均等に処理します。自分が不利になるシナリオを意図的に主要シナリオに含めることが、近似精度を高める最も効果的な習慣です。

次のズレは「ブラフ候補の過剰な温存」です。backward induction を学ぶと「リバーでブラフになれるハンドはターンでチェックして温存しよう」という判断が増えます。しかし GTOではセミブラフ（ドロー系）はターンで積極的にベットするよう設計されていることが多いです。理由は、セミブラフのターンベットには「フォールドエクイティ（相手を今フォールドさせる価値）」と「ドロー完成後のバリュー」の両方が含まれるからです。「リバーのために温存する」という思考が、ターンのフォールドエクイティを損なうことに注意が必要です。

また、「役なしのオーバーカード2枚でターンバレル」という判断は、backward induction の観点では「リバーでOCが落ちればバリューになる」という合理的な根拠があります。しかしGTOでの実際の頻度を確認すると、ボードやスタックサイズによっては、このラインはチェックが推奨される場合があります。本章の逆算はあくまでも「方向性を示す近似」であり、バレルスコア（巻④ 第8章）との組み合わせによる定量確認が実戦での精度を支えます。
