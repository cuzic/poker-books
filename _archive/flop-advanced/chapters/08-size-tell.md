# 第08章　サイズ・テル

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> IP（イン・ポジション）がどのサイズでベットしてくるかは、そのレンジの形を推測する手がかりになります。
> 「サイズ・テル」とは、ベットサイズからレンジ構成を読む技術です。
> 本章ではサイズ別のレンジ傾向を学び、OOP（アウト・オブ・ポジション）での適切な対応に活かします。

---

## 8-1　サイズ・テルとは何か

ポーカーで「テル」といえば、体の動きや表情から手の強さを読む行為を指します。
オンラインポーカーではそうした身体的なテルは使えませんが、ベットサイズそのものが重要な情報源になります。

**サイズ・テル**（Size Tell）とは、相手が選んだベットサイズからレンジ傾向を推測することです。
GTO（ゲーム理論最適）の観点では、理想的な均衡プレイヤーはすべてのサイズを同じ頻度で使い、サイズからレンジが読めないようにします。
しかし現実のプレイヤーはサイズ選択に偏りがあることが多く、その偏りを利用できます。

### サイズとレンジの関係

Vol2（フロップ基礎）でCBetの基本を学んだとき、フロップのボードスコア（B）に応じてサイズを選ぶ考え方を扱いました。
ここではその逆方向、「相手のサイズ選択からボードへの対応とレンジ形状を推測する」視点を身につけます。

---

## 8-2　33% ベットが示すもの

IP が 33% ポットというスモールベットを選ぶとき、そのレンジはどのような形をしているでしょうか。

### ワイドレンジ維持のシグナル

33% CBet の代表的な意図は、**ワイドレンジ（広い範囲のハンド）を全体としてベット**することです。
T1（強いハンド）・T2（中程度のハンド）・T3（弱いハンド）が入り混じった状態で、全体のレンジを小さなコストで維持します。

```
33% CBet のレンジ傾向:
  - T1 / T2 / T3 が混在した「ワイドレンジ」
  - 個々の手は弱くても、レンジ全体として利益を出す
  - 相手に安いポットオッズを提示して守備を強制する
```

GTO 実測データ（TexasSolver、BTN vs BB、100BB、SRP、6ボード集計）によると、ドライ rainbow ボードでは IP の CBet の約 55〜66% が 33% サイズに集中します。
ウェット 2トーンボードではさらに顕著で、約 69〜73% が 33% に集中することが確認されています。

### 2トーンボードで 33% が特に多い理由

ウェット 2トーンボード（例: J♣8♣4♦）では、OOP（BB）がフラッシュドローや OESD を多く持ちます。
こうしたボードで IP が大きなサイズを使うと、OOP はドローに対してポットオッズが合いやすくなり、IP の EV が低下します。
したがって IP は小さなサイズでレンジ全体をベットし、OOP の守備コストを最小限に抑えながらエクイティを主張します。

---

## 8-3　75% ベットが示すもの

IP が 75% ポットという大きなサイズを選ぶとき、そのレンジは 33% とは大きく異なります。

### ポーラー（二極化）レンジのシグナル

75% CBet が示す典型的なレンジは「**ポーラー（二極化）レンジ**」です。
これは、非常に強いハンド（T1 上位）と、純粋なブラフ（T3）が混在し、中間的な T2 ハンドが少ない状態です。

```
75% CBet のレンジ傾向:
  - 強いバリューハンド（セット・2ペア・TPTK以上）: 75% でポットを大きくする
  - 一部のブラフ（T3、乾燥ボードで相手のフォールドが期待できる）
  - T2 ハンドの多くは 33% か、あるいはチェックバック
  - 結果: 「ナッツか空振り」の二極構造
```

ドライ K-high ボード（例: K♣7♦2♠）では、GTO 実測で IP の約 45% が 75% ベットを選ぶことが示されています。
このボードでは IP のナッツアドバンテージが大きいため、強いハンドを大サイズで押し込む戦略が成立します。

### サイズ別レンジ分布の比較

以下の表は、代表的なボードでの IP のサイズ選択分布を示しています（TexasSolver、BTN vs BB、100BB、SRP 実測、本書独自集計。実際のソルバー設定によって値は異なる場合があります）。

| ボード | B値 | テクスチャ | 33% 比率 | 75% 比率 |
|:---|:---:|:---|:---:|:---:|
| K♣7♦2♠ | 62 | ドライ rainbow | 約55% | 約45% |
| K♣4♦4♠ | 83 | ペアボード | 約61% | 約39% |
| A♣7♦2♠ | 62 | ドライ rainbow | 約66% | 約33% |
| Q♣5♦3♠ | 58 | ドライ rainbow | 約59% | 約37% |
| Q♣8♣3♦ | 50 | 2トーン | 約73% | 約24% |
| J♣8♣4♦ | 50 | 2トーン | 約73% | 約20% |
| A♣T♣7♦ | 56 | 2トーン | 約67% | 約23% |
| T♣9♣8♦ | 50 | ウェット | 約70% | 約21% |

この表からわかることは、ウェット系ボードほど IP が 33% に集中し、ドライ系ボードほど 33%/75% の比率が拮抗するという傾向です。

## 8-4　サイズ別の OOP 対応

サイズ・テルを活かした OOP 側の対応策を整理します。

### IP が 33% ベットしてきた場合

IP のレンジがワイドである（T1/T2/T3 混在）という情報をもとに、OOP は守備範囲を広げます。

Vol2 で学んだ後手下限ラインの考え方では、33% ベットに対して OOP はレンジの約 75% をディフェンスする必要があります（後手下限確率 = 75%）。
フォールド閾値（HS 値）の目安は以下の通りです。

```
IP が 33% CBet:
  - 後手下限確率: 約75%（フォールドできるのはレンジの25%まで）
  - フォールド閾値目安:
      ドライ rainbow:      HS ≥ 15 でコール
      ウェット 2トーン:    HS ≥ 20 でコール（+5 補正）
      モノトーン:          HS ≥ 10 でコール（-5 補正）
      ペアボード:          HS ≥ 5 でコール（-10 補正）
```

HS ≥ 15（ドライ rainbow 基準）はあくまで目安です。実際の後手下限確率 75% と HS 分布の対応はボード・レンジに依存するため、上表の補正値も含めて参考値として扱ってください。

IP のレンジが広いということは、それだけ多くの弱いハンドが含まれています。
そのため OOP は「コールして将来のターンで優位に立てるハンド」を広めに守ります。

### IP が 75% ベットしてきた場合

IP のレンジがポーラーである（強いバリュー + ブラフの二極）という情報をもとに、OOP は守備を絞ります。

75% ベットに対するコストは大きく、ポットオッズは約 30%（コール額 4.5bb ÷ 最終ポット 15bb）になります。
この状況での防御基準は次のようになります。

```
IP が 75% CBet:
  - 後手下限確率: 約57%（フォールドできるのはレンジの43%まで）
  - フォールド閾値目安:
      ドライ rainbow:      HS ≥ 35 でコール（T1 中心）
      ウェット 2トーン:    HS ≥ 40 でコール
  - T2 下位（HS 20〜34 程度）は多くフォールドを検討
  - TPWK（トップペア弱キッカー）単独ではフォールドが有力
```

IP がポーラーレンジを示しているということは、IP の弱いハンド（T2）が少ないことを意味します。
こちら（OOP）が T2 でコールしても、IP の強いハンド（T1）に対してエクイティが低い状況が多くなります。

## 8-5　OOP の CR（チェックレイズ）とサイズ

OOP が CR を打つとき、そのサイズも重要なサイズ・テルになります。
第4章（チェックレイズ詳細）で扱った CR に関して、サイズ・テルの視点を加えます。

### CR サイズからレンジを読まれる

OOP として CR を打つ場合、3× IP ベットが標準です（第4章参照）。
しかし 2× ほどの小さな CR は「弱い可能性がある」という情報を相手に与えてしまいます。

```
OOP の CR サイズのシグナル:
  3× IP bet (標準CR): バランスの取れた CR。バリューとブラフが混在
  2× IP bet (アンダーサイズCR): 弱い。IPが再レイズで対応しやすい
  4〜5× または オールイン: 非常に強いバリュー確定のシグナル
```

実戦では 2× の小さな CR は相手に「弱いかも」という読みを与え、IP が再レイズや将来の攻撃でエクスプロイトしやすくなります。
CR サイズは均一に 3× を基準とすることで、サイズ・テルを消すことができます。

---

## 8-6　サイズ・テルのバランスと活用

完全にバランスを取ったプレイヤーはどのサイズでも強弱両方のハンドを混ぜているため、サイズからレンジが読めません。しかし実際の対戦相手はアンバランスであることがほとんどです。

### バランスを取った場合（参考）

```
GTO 的サイズ混合（例: ドライ K-high ボード）:
  - 33% でも強いハンドとブラフを両方ベット
  - 75% でも強いハンドとブラフを両方ベット
  - どちらのサイズでも T1/T3 が混在している
  → 相手はサイズだけではレンジを特定できない
```

これを「**バランスを取ったサイズ選択**」と呼びます。
全サイズに強いハンドとブラフを混ぜることで、相手はどのサイズに対しても一定の割合でコールし続けなければならなくなります。

### 実戦でのアンバランスを利用する

実際の相手は完全なバランスを取っていないことが多いです。
「この相手は大きいときに強い」「小さいときはいつもブラフ混じり」といったパターンを読めれば、より精度の高い判断ができます。

```
相手のサイズ・テルのチェック:
  - この相手は 75% を何度か使ったとき、ショーダウンで何を持っていたか
  - 33% のあとのショーダウンは T1/T2/T3 が混在していたか
  - CR のサイズが毎回同じか、あるいは手によって変えているか
```

セッションを通じてこのパターンを集積することが、相手エクスプロイトの土台になります。

## ミニクイズ

### 問1

SRP フロップ（pot=6bb）で IP が 75%（4.5bb）CBet してきました。
IP のレンジ傾向として最も正しい説明はどれですか？

1. T1/T2/T3 が均等に混在するワイドレンジで、全般的にベットしている
2. 強いバリューハンド（T1上位）と一部のブラフ（T3）で構成されるポーラーレンジ
3. T2 が中心で、セットや 2ペアはあまり含まれない

### 問2

ウェット 2トーンボード（J♣8♣4♦）で IP が 33%（2bb）CBet してきました。
OOP としてコールを検討する際の正しいフォールド閾値はどれですか？

1. HS ≥ 35（ドライボードと同じ）
2. HS ≥ 20（2トーン補正 +5 を適用）
3. HS ≥ 10（2トーンはウェットなので補正 -5 を適用）

### 問3

OOP が IP の 33% CBet（2bb）に対して 2× の CR（4bb）を打ちました。
このサイズ選択が持つ問題点として最も適切な説明はどれですか？

1. CR サイズが大きすぎて IP のポットオッズが低くなりすぎる
2. 小さすぎる CR は「弱い可能性がある」というシグナルを与え、IP に再レイズで対応されやすい
3. 2× CR は GTO 均衡において最も望ましいサイズです

---

### 解答

- **問1**: **2. ポーラーレンジ** が正解。75% ベットは強いバリュー（T1 上位）と一部のブラフが二極化した形が典型です。T2 のほとんどは 33% ベットかチェックバックを選ぶため、75% ベットに T2 は少なくなります。
- **問2**: **2. HS ≥ 20** が正解。2トーンボードは OOP がドローを多く持てるため守備しやすく、フォールド閾値に +5 の補正をかけた 20 が目安です。HS ≥ 20 のハンドはコールの検討対象となります。
- **問3**: **2. 弱いシグナルを与える** が正解。2× の小さな CR は相手に「強くない」という読みを与えます。IP は再レイズ（4-bet）や将来のストリートで積極的に対応しやすくなります。CR サイズは 3× を標準として均一化することでサイズ・テルを消せます。

---

> **本章まとめ**
>
> - 33% CBet は T1/T2/T3 が混在するワイドレンジのシグナル。OOP は守備範囲を広く保つ（後手下限確率 75%）。
> - 75% CBet はポーラーレンジ（強いバリュー＋一部ブラフ）のシグナル。OOP は T1 中心に絞って守る（HS ≥ 35 以上）。
> - ウェット 2トーンボードでは IP が 33% に集中（約70%）し、ドライ K-high ボードでは 33%/75% が拮抗（約55%/45%）する。
> - OOP の CR サイズも情報になる。2× の小さな CR は弱さを示すシグナルになるため、3× を標準とする。
> - GTO ではすべてのサイズに T1/T3 を混ぜることでサイズ・テルを消すことが理想。実際の相手は偏りがあることが多い。

---

**【GTO とのズレ】**

本章で示したサイズ別レンジ傾向は「傾向」であり、GTO では 33%/75% どちらにも強弱両方のハンドを混ぜてバランスを取ります。
実際の GTO 均衡では 33% の T1 ハンドも一定数あり、75% の T3 ブラフも存在するため、サイズだけで手の強さを断定できません。
サイズ・テルは「レンジの重心」を推測する補助情報として使い、過信は禁物です。
