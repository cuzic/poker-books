# 第10章　ブラフ選択原則

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> フロップでのブラフは「当てずっぽう」ではありません。
> 成功するブラフには「相手がフォールドしやすい条件」と「失敗したときのバックアップ」が必要です。
> 本章ではブラフ選択の 3 原則と、純粋なブラフ・セミブラフの使い分けを学びます。

---

## 10-1　ブラフが成立する条件

ブラフとは「現在の手では勝てないが、相手をフォールドさせることで利益を得ようとするベット」です。
ブラフが利益を生むためには、次の条件が必要です。

### フォールドエクイティ

**フォールドエクイティ**とは、ベットしたときに相手がフォールドする確率から得られる期待利益です。
相手が全くフォールドしない（フォールド率 0%）であれば、強い手がないブラフは常に損失になります。

```
ブラフの期待値（EV）:
  EV(ブラフ) = フォールド率 × ポット − (1 − フォールド率) × ベット額

例: K♣7♦2♠（ドライ rainbow）でポット 6bb に 33%（2bb）CBet:
  OOP のフォールド率（実測）: 約 46%
  EV = 0.46 × 6 − 0.54 × 2 = 2.76 − 1.08 = +1.68bb（プラス）

例: Q♣5♦3♠でポット 6bb に 33%（2bb）CBet:
  OOP のフォールド率（実測）: 約 19%
  EV = 0.19 × 6 − 0.81 × 2 = 1.14 − 1.62 = −0.48bb（マイナス）
```

K-high ドライボードでは OOP が約 46% フォールドし、33% ブラフは利益になります。
しかし Q-high では約 19% しかフォールドしないため、同じブラフが損失になります。

### 損益分岐点のフォールド率（α）

ベットが利益になるための最低フォールド率を計算できます。

```
α（最低フォールド率）= ベット額 ÷ （ポット + ベット額）

33% ベット（2bb、pot=6bb）の α:
  α = 2 ÷ (6 + 2) = 25%

75% ベット（4.5bb、pot=6bb）の α:
  α = 4.5 ÷ (6 + 4.5) ≈ 43%
```

33% ベットなら相手が 25% 以上フォールドすれば利益、75% ベットなら 43% 以上のフォールドが必要です。

## 10-2　ブラフ選択の 3 原則

成功するブラフを選ぶための 3 つの原則を優先順位の高い順に紹介します。

### 原則 1：ブロッカー

**ブロッカー**とは、相手の強いハンド（ナッツ）を構成するカードを自分が持っている状態です。

```
ブロッカーの効果:
  フラッシュボード（例: K♣8♣4♣）でブラフする場合:
    - A♣を持っていれば、相手がナッツフラッシュ（A♣高いフラッシュ）を持つ可能性が下がる
    - ブロッカーあり → 相手がコールで返すナッツを持つ確率が低下
    - → 相手のフォールド率が実質的に上昇する

  ブロッカーがないブラフ:
    - 相手がナッツを持っている可能性が相対的に高い
    - コールされたときに大きな損失になりやすい
```

### 原則 2：エクイティ（セミブラフ）

ブラフしながら「もし相手がコールしても、ターン・リバーで改善して勝てる可能性」があるハンドを**セミブラフ**と呼びます。

```
セミブラフの例:
  FD（フラッシュドロー）: 9 アウト = 約 36% ターン + リバー改善率
  OESD（オープンエンドストレートドロー）: 8 アウト = 約 32%
  GS（ガットショット）: 4 アウト = 約 17%（それ単独ではセミブラフとして弱め）

  NFD（ナッツフラッシュドロー）: 最強のセミブラフ。コールされても約 36% で勝てる
```

セミブラフは、ブラフとして機能しながらも「呼ばれたときのバックアップ」が存在します。
純粋なブラフ（エクイティ 0%）より大幅に安全です。

```
セミブラフ EV（簡略計算）:
  EV = フォールド率 × ポット − (1 − フォールド率) × ベット額 + コール時のエクイティ

  例: NFD セミブラフ（FD=36%）、フォールド率 25%、ポット 6bb、ベット 2bb:
    コール後ポット = 6+2+2 = 10bb
    = 0.25 × 6 − 0.75 × 2 + 0.75 × 0.36 × 10 ≈ 1.5 − 1.5 + 2.7 ≈ +2.7bb
    コールされてもエクイティ分が加算されるためプラスになりやすい
```

### 原則 3：ポジション

IP（イン・ポジション）からのブラフは、OOP（アウト・オブ・ポジション）からのブラフより成功しやすいです。

> **補足 — 実際の優先度**: EV への影響という点では、エクイティ（ドローの有無）がブロッカーよりも大きな役割を果たします。FD 単独（ブロッカーなし）の方がブロッカー単独の純粋ブラフより EV が高い場合がほとんどです（§10-5 の優先リスト参照）。「①ブロッカー ②エクイティ」という順序は「ブロッカーを持つなら選びやすい」という意味合いであり、ブロッカーなしのセミブラフを否定するものではありません。

```
IP ブラフの利点:
  - ターン・リバーでの継続打ちかどうかを後から決められる
  - 相手が先にチェックすればブラフをやめてタダで次のカードを見られる
  - 情報が多い状態で判断できる

OOP ブラフの難点:
  - 先に行動しなければならない
  - 相手のリアクションを見てから調整できない
  - コールされた後、ターンで守りにくい
```

OOP からのブラフ（ドンクベット）は第6章で扱った通り、特定のボードテクスチャに限定されます。

## 10-3　純粋ブラフが有効なボード

**純粋ブラフ**とは、現在も将来も改善が期待できないハンドでのブラフです。

### 乾燥ボードでのみ有効

Vol2 で学んだ T3 ブラフのルールを思い出してください。
B ≥ 62（ドライ rainbow K/A-high ボード）の場合のみ T3 ブラフが有効でした。B=62 は巻②の 9 ルールで「rainbow × top A/K」に対応します。Q-high 以下では B=58 程度に低下するためフォールド率が下がり T3 ブラフが成立しなくなります。

```
純粋ブラフが有効な条件:
  - B ≥ 62（乾燥ボード）
  - OOP のフォールド率がα（25%）を超える

実測データ:
  K♣7♦2♠（B=62）: OOP フォールド率 ≈ 46% → T3 ブラフ有効（46% > 25%）
  Q♣5♦3♠（B=58）: OOP フォールド率 ≈ 19% → T3 ブラフ無効（19% < 25%）
```

ウェット系ボードや Q-high 以下のボードでは、OOP が守備できるハンドが多く純粋ブラフが通りません。

## 10-4　バリュー対ブラフの比率

GTO 均衡では、バリューベットとブラフのバランスが取れていることが重要です。

### 黄金比の考え方

コールの「ポットオッズ」を相手に与えたとき、相手が「コールしても損、フォールドしても損」な状態（無差別条件）を作ることが理想です。

```
33% ベット（pot=6bb、bet=2bb）:
  相手のポットオッズ = 2 ÷ (6+2+2) = 2/10 = 20%（コールして必要なエクイティ）
  均衡: バリュー対ブラフ比 ≈ 4:1 が目安（相手のコールEVを0にする）

75% ベット（pot=6bb、bet=4.5bb）:
  相手のポットオッズ ≈ 4.5/15 = 30%
  均衡: バリュー対ブラフ比 ≈ 2.3:1 が目安

実戦の簡易目安:
  33% ベット: バリュー 4 対 ブラフ 1（均衡の 4:1 をそのまま使う）
  75% ベット: バリュー 2 対 ブラフ 1（均衡 2.3:1 を切り捨て）
```

ブラフを打ちすぎると相手はコールし続けるだけでよく、バリューハンドで返されます。
ブラフが少なすぎると相手は常にフォールドして良くなり、バリューベットが通らなくなります。

## 10-5　具体的なブラフ候補の選び方

ブラフ候補を選ぶ際の実践的な手順を示します。

### セミブラフを優先する

同じブラフを打つなら、「ドロー付きのセミブラフ」を優先します。

```
ブラフ候補の選択肢（優先順位順）:
  1. ナッツFD（NFD）+ ブロッカーあり: 最強のブラフ候補
  2. OESD + FD（コンボドロー）: 非常に強いセミブラフ
  3. FD 単独（非ナッツ）: 通常のセミブラフ
  4. OESD 単独: 通常のセミブラフ
  5. ガットショット + ブロッカー: やや弱いセミブラフ
  6. 純粋ブラフ（B ≥ 62 限定）: エクイティなし、ボード限定

例: J♣8♣4♦（2トーン）でのブラフ候補:
  優先: A♣5♣（FD + ブロッカー A♣）
  次点: Q♣T♣（FD + OESD = コンボドロー）
  通常: K♣3♣（FD のみ、ブロッカー薄い）
  避ける: 7♠6♠（ドローなし、このボードでは純粋ブラフが通りにくい）
```

### ドライボードでの純粋ブラフ候補

乾燥ボードでは FD/OESD が少ないため、純粋ブラフも候補になります。

```
K♣7♦2♠（ドライ rainbow、B=62）でのブラフ候補:
  - 6♠5♣（ガットショット: 4 アウト）: セミブラフとして最低限機能
  - J♠T♣（役なし、現時点でのドローなし）: 純粋ブラフの候補。ただし Q がターンに来ると OESD に昇格する潜在性あり
  - Q♠J♦（2 オーバーカード）: 若干のショーダウン価値あり、ブラフ候補

  このボードでは OOP フォールド率が約 46% と高いため、
  T3 ハンドの純粋ブラフも EV がわずかにプラス
```

## 10-6　状況別 T3 ブラフ B閾値まとめ

T3（HS < 20）の純粋ブラフが有効なボードスコア（B）の閾値は、状況によって変わります。

| 状況 | T3 ブラフ有効な B 閾値 | 備考 |
|:---|:---:|:---|
| SRP（通常ポット、SPR ≈ 16） | B ≥ 62 | Dry A/K-high rainbow のみ |
| vs Nit（fold_rate ≥ 65%） | B ≥ 55 | フォールドエクイティが高い |
| 3-bet ポット（SPR ≈ 5） | B ≥ 55 | コール側がコミットしにくい |
| マルチウェイ（3way 以上） | 原則禁止 | 全員フォールドが必要 |
| 4-bet ポット（SPR ≈ 2） | 原則禁止 | SPR が低くコール側がコミット |

SPR が低いほど、または相手のフォールド率が高いほど閾値が緩和されます。逆にプレイヤーが増えるほどブラフの成功に必要な条件が厳しくなります。

## ミニクイズ

### 問1

ポット 6bb で IP が 33%（2bb）CBet します。
このベットのブレイクイーブン・フォールド率（α）はいくつですか？

1. α = 43%（フォールド率が 43% 以上必要）
2. α = 33%（ベットサイズがそのままフォールド率）
3. α = 25%（フォールド率が 25% 以上必要）

### 問2

フラッシュドロー（FD）を持つセミブラフを打ちました。
相手がコールしてきたとき、この状況の説明として最も正しいものはどれですか？

1. コールされたため、このハンドは 100% 損失になる
2. FD が約 36% の確率で改善するため、コールされても一定の EV が残る
3. FD はコール後に価値がなくなるため、すぐにフォールドすべき

### 問3

Q♣5♦3♠（B=58）のボードで、役なし（T3）のハンドで 33% ブラフを打とうとしています。
この判断は正しいですか？

1. 正しい。33% は小さいサイズなのでどのボードでも T3 ブラフが有効
2. 誤り。このボードの OOP フォールド率は約 19% で α（25%）を下回るため、T3 ブラフは期待値マイナスになりやすい
3. 正しい。Q-high ボードは OOP のコール率が低い

---

### 解答

- **問1**: **3. α = 25%** が正解。α = ベット額 ÷ (ポット + ベット額) = 2 ÷ (6 + 2) = 25%。33% ベットなら相手が 25% 以上フォールドすれば利益になります。
- **問2**: **2. FD は約 36% の改善率がある** が正解。FD（9 アウト）はターンで約 19%、ターン+リバー合計で約 36% の改善確率があります。コールされても「フォールドしてもらえなかっただけ」ではなく、エクイティ分の価値が残っています。
- **問3**: **2. 期待値マイナスになりやすい** が正解。Q-high ボード（B=58）では OOP が多くのハンドでコールできるためフォールド率が低い（実測約 19%）です。α = 25% を下回るため T3 純粋ブラフは期待値がマイナスになります。T3 ブラフが機能するのは B ≥ 62 の乾燥ボードのみです。

---

> **本章まとめ**
>
> - ブラフの期待値 = フォールド率 × ポット − (1 − フォールド率) × ベット額。
> - 損益分岐点のフォールド率 α: 33% ベット → 25%、75% ベット → 43%。
> - ブラフ選択の 3 原則: ①ブロッカー ②エクイティ（セミブラフ）③ポジション（IP 優位）。
> - 純粋ブラフ（役なし・ドローなし）は B ≥ 62 の乾燥ボードのみ有効。Q-high（B=58）では期待値マイナス。
> - セミブラフ（FD/OESD）はコールされても約 32〜36% の改善率があり、純粋ブラフより大幅に安全。
> - バリュー対ブラフ比率: 33% ベット → 約 4:1（均衡値）、75% ベット → 約 2:1（均衡 2.3:1 を切り捨て）。

---

**【GTO とのズレ】**

本章のブラフ計算（EV、α、バリュー対ブラフ比率）は実戦的な近似値です。

①**逸脱量**: GTO の実際のバリュー対ブラフ比率はボード・レンジによって 3:1〜6:1 の幅があります。本書の「33% → 4:1」は中央値に近い目安ですが、ドライボード（BB フォールド率 ≈ 46%）では 5:1 程度に増えることがあります。

②**最も差が出るボード**: ウェット 2トーン（Q83fd 等）では BB のドロー保有率が高く、IP のブラフ成功率が低下します。このボードで 4:1 を厳守すると「ブラフが多すぎる」状態になりがちです。GTO では 2トーンウェットボードの IP ブラフ比率を 3:1 程度に抑える傾向があります。

③**本書の簡易化で損するシナリオ**: 4:1 の目安を機械的に使うと、「強いドロー（コンボドロー）がバリューとブラフのどちらにカウントするか」が曖昧になります。コンボドローは「高エクイティのセミブラフ」なのでブラフカウントに入れるのが適切ですが、過剰に入れると比率が崩れます。
