## 今回の相談事項

以下の5点について、ご意見をいただきたいです。

---

### 相談① 「まず1ハンドで全体像を見る」（Vol2 ch01）の内容

この章の役割は、「計算ルールを教える前に、完成形を1例で見せる」ことと理解しています。

想定している内容は次の通りです。

> **例題**  
> Board: K♣-7♦-2♠（レインボー、K-high、dry）  
> Hand: A♣K♦（TPTK）  
> Pot: 6bb、Stack: 94bb、IP（BTN）
>
> **答え**  
> Board Score B = 62（rainbow_AK）  
> Hand Score HS = 65（TPTK）  
> Tier: T1 → 常にCBet  
> Size: B < 70 → 33%  
> → **CBet 2bb**
>
> **次の局面（OOP視点）**  
> 同じBoard、Hand: Q♠J♣（セカンドペアなし、ガットショット）  
> HS = 32 + 12 = 44（弱ペア+GS）  
> OOP: vs33% → threshold=15 → HS=44 ≥ 15 → call  

この章で、読者が「B、HS、Tier、threshold という4つが主役だ」と分かるようにしたいです。

**質問：** この例題の難易度と内容は適切ですか？  
特に、**最初の例でOOP視点まで同じ章に入れるべきか、IPのみに絞るべきか**、ご意見をください。

---

### 相談② 「なぜVol2の式では足りないのか」（Vol3 ch01）の書き方

橋渡し章の役割は理解しています。ただ、内容をどう具体化するかで悩んでいます。

たとえば次の2つのアプローチが考えられます。

**案A：同じHandで判断が変わることを見せる**

> K♣7♦2♠ board、Hand: A♠Q♦（2OC）  
> Vol2の式では：HS=24（2OC bonus）→ T2 → B=62 ≥ 58 → CBet  
> しかしGTOでは：BTNがA♠Q♦でCBetする率は約95%  
> → 式とGTOはほぼ一致する  
>
> では、いつ乖離するのか？  
> → 相手のレンジが普通でないとき（3-bet pot、レンジ読みが必要な場面）

**案B：「レンジ」という概念そのものを先に教える**

> Vol2はあなたの手だけを見る  
> Vol3は「IP全体が何を持っているか」から考える  
> 同じCBetでも、レンジが違えばサイズも頻度も変わる

**質問：** 案Aと案Bのどちらが橋渡し章として機能しますか？  
または、この2つを組み合わせる構成が良いですか？

---

### 相談③ 「チェックレンジを作る」（Vol3 ch05）の具体的な中身

前回の指摘通り、「打たない = 弱い」という誤解を防ぐ章です。

現在考えている内容は以下の3つです。

1. **SDVハンドのチェックバック**（IP: TPTK on dry boardなど）  
2. **トラップ（遅延ベット）候補**（IP: セット on wet board）  
3. **将来のブラフ候補として残す**（IP: air with backdoor draw）

OOP視点からは、

4. **MDF以上を守るためのチェックコール候補**  
5. **位置的に不利なためチェックチェックにする中位ハンド**

**質問：** このチェックレンジの説明は5項目で完結できますか？  
それとも、Vol3 ch05は「IPのチェックレンジ」のみに絞り、OOPのチェックコール戦略はch06（OOPコーリングレンジ）と分けた方がすっきりしますか？

### 相談④ プローブベット と Delayed CBet を同じ章に入れることについて

Vol4 ch09 として「プローブベットとdelayed CBet」を1章にまとめる案です。

両者の関係はこうです。

| 状況 | アクション |
|------|----------|
| フロップ：BTN check back → ターン：BB (OOP) が先にベット | **プローブベット** |
| フロップ：BTN check back → ターン：BB check → BTN がベット | **Delayed CBet** |

この2つは「フロップチェックバック後のターン」という同じ前提から派生します。なので同じ章にまとめる方が文脈が続く気がしています。

ただし、読者から見ると「IP視点（delayed CBet）」と「OOP視点（probe）」が同じ章に混在することになります。

**質問：**  
- 同じ章にまとめた方が良いですか？それとも分けますか？
- 分ける場合、どちらを先に扱うべきですか？（IP視点先 / OOP視点先）

### 相談⑤ Vol5 のタイトルと書名について

現状の書名は「ターン・リバー[応用]」ですが、改訂後の内容はほぼリバー完結です。

候補は次の3つです。

**案A：「リバー完全攻略」**  
→ 内容と一致。でも「完全」という言葉が約束しすぎ。

**案B：「ターン・リバー[応用]」（現状維持）**  
→ ターンOBをVol4へ移したのでやや不一致。でもシリーズの対称性は保たれる。

**案C：「リバー判断体系」**  
→ 内容を正確に示す。中上級者向けの印象が強くなる。

また、Vol4 に「ターンオーバーベット入門」を移した結果、Vol4 の書名「ターン・リバー[基礎]」はリバー基礎も含むはずなのに、リバー内容がほぼ「リバーを逆算する」1章だけになっています。

**質問：**
- Vol5 の書名は案A/B/Cのどれが良いですか？
- Vol4 の書名「ターン・リバー[基礎]」はこのままで良いですか？それとも「ターン基礎とマルチストリート」のような名称に変えるべきですか？

## 参考：核心式は変更なし

改訂は構成のみです。核心式（Board Score B / Hand Score HS / Tier / MDF / VMB）は変更しません。

```
CBet 判断:
  T1 (HS≥65) → always CBet
  T2 (HS 20-64) → CBet if B ≥ 58
  T3 (HS < 20) → CBet if B ≥ 62

OOP フォールド閾値:
  フロップ vs33%: base=15   ターン vs33%: base=20   リバー vs33%: base=35
  vs75%:         base=35              base=40              base=50
  補正: paired=-10, 2tone=+5, mono=-5

リバー VMB:
  V ≥ 70 → ベット推奨
  M 35-69 → IP: ベット / OOP: チェック
  B < 35 → チェック or ブラフ

リバーブラフ均衡:
  bluff_freq = α / (1 - α)
  33%bet → 3バリュー: 1ブラフ
  50%bet → 2バリュー: 1ブラフ
  100%bet → 1バリュー: 1ブラフ
```
