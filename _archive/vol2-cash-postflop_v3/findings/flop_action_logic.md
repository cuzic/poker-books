### D. 型別ロジック詳説

#### 型6 ペア高（KKx, AAx）— SRP最高頻度
```
SRP_IP: ~77% ベット（ほぼ全カテゴリ）
  → 全カテゴリ同等のベット率（V=84%, Air=79%, BC=70%）
  → IPがトリップスをほぼ独占 → レンジアドバンテージ最大
  → サイズ: 小(R1.8)

3BP_IP: ~33% ベット（大幅減）
  → KhKd8c型では3BPコーラーにKK少ない → equity逆転
  → AsAcKd型は中程度維持
```

#### 型1/2 ハイドライ/ハイウェット — 均一高頻度
```
SRP_IP: ~64-68% ベット
  → V/BC/WD/Air とも60-80%の均一ベット
  → BTNがA/K/Qハイカードを多く持ちレンジアドバンテージ
  → サイズ: 小(R1.8)

3BP_IP: ~47% ベット（減少）
  → 3BPも同様にハイカード有利だがSPR低く慎重
  → WD/Air のベット率が大幅低下（-21〜31%）
  → V は3BP_IPでも68%維持（差が小さい）
```

#### 型3 ロードライ — チェック主体・オーバーベット
```
SRP_IP: ~32% ベット（X主体=68%）
  → ベットするならオーバーベット(R6.4 ≈ 115%)
  → BCはほぼ絶対にベットしない(13%)
  → Dが最優先(55%) → V(47%) → WD(39%) → Air(31%)
  → 理由: OOPのBBもドローを多く持ち防御可→BCベット不要
          ブラフはポーラライズ（ドロー or ナッツ）

3BP_IP: ~35% ベット（SRPと近似）
  → 超大ベット(R11.5 ≈ 200%)に移行
  → V = 70%（SRPより+23%）← AA/KK/QQがローボードで強い
  → BCはやや上昇(22%)するが依然低め
```

#### 型4 ローウェット — 中程度・BCは抑制
```
SRP_IP: ~45% ベット
  → V/D/WD中心、BCは30%程度
  → コネクテッドはOOPも相性よくチェックバックも有効
  → サイズ: 小(R1.8)

3BP_IP: ~28% ベット（大幅減）
  → BCは8%以下（ほぼなし）
  → 超大ベット(R11.5)にシフト → ポーラライズ
  → WD/Air も20-27%程度と低い
```

#### 型5 モノトーン — SRP/3BPで完全逆転
```
SRP_IP: ~36% ベット（チェック主体=64%）
  → WD(50%)とD(41%)が中心
  → BC(23%)は低め
  → 理由: OOPもフラッシュドロー持ちで防御しやすい

3BP_IP: ~65% ベット（全逆転！）
  → 全カテゴリ高頻度: V=74%, BC=68%, WD=85%, Air=62%, D=70%
  → 3betterがナッツフラッシュドロー（A♥K♥等）を独占
  → サイズ: 中(R3.9 ≈ 67%)
```

## III. 簡易ルールまとめ（実践用）

### IPフロップCBet ディシジョンツリー

```
Step1: ボード型を判定
Step2: シナリオ確認（SRP or 3BP）

【SRP_IP ルール】
型6 ペア高(SRP):   → 高頻度ベット(75%+) 全カテゴリ均等 サイズ小
型1/2 ハイ系(SRP): → 中高頻度ベット(65%+) V/BC/WD均等 サイズ小
型7 ペア低(SRP):   → 中頻度ベット(55%) V/BC優先 サイズ小
型4 ローウェット(SRP): → 低中頻度(45%) BCは抑制 サイズ小
型5 モノトーン(SRP):  → 低頻度(36%) WD/D優先・BCはパス サイズ小
型3 ロードライ(SRP):  → 低頻度(32%) BCはほぼパス・D/V中心 オーバーベット

【3BP_IP での補正（SRPからの差分）】
型5: 逆転 → 高頻度(65%) 全カテゴリ サイズ中(R3.9)
型6(KKx): 逆転 → 低頻度(21%) ポーラライズ オーバーベット
型1/2: 頻度低下(-18%前後) WD/Air が特に低下 サイズ中(R3.9)
型3: 変化小 V のみ上昇(+23%) サイズ極大(R11.5)
型4: 頻度低下(-17%) BC激減(8%) サイズ極大(R11.5)
```

### BCのベットルール

```
BCをベットすべき状況:
✓ 型6 ペア高 SRP (70%): IPがトリップス独占 → BC もフォールドエクイティ
✓ 型5 モノトーン 3BP (68%): フラッシュドロー資産があるため
✓ 型1/2 ハイ系 SRP (60%): レンジアドバンテージで全体的に高頻度

BCをほぼベットしない状況:
✗ 型3 ロードライ (13%): OOPのドローが多く防御可→スクイーズ不可
✗ 型4 ローウェット 3BP (8%): コネクテッドOOPの強い防御
✗ 型4 ローウェット SRP (30%): BCはチェックバックで2ストリート見る
```

### サイズ選択の原則

```
SRP 小サイズ(R1.8 ≈ 33%)が有効: 型1/2/4/5/6/7（レンジ広くベット可）
SRP オーバーベット: 型3のみ（ポーラライズ = ドローorバリュー二択）
3BP 中サイズ(R3.9 ≈ 67%): 型1/2/5（ドローボードで価値）
3BP 大サイズ(R11.5 ≈ 200%): 型3/4/7（SPR低い＋ポーラライズ）
```
