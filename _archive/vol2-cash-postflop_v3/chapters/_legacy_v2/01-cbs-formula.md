# 第01章 TV の式 — MV + DV

TV (Combined Board Score) = MV + DV の計算方法を習得します。
MV テーブル (16 手 → 6 バケット) と DV テーブル (4 段階) を理解し、任意のハンドの TV を暗算で即算できる状態にします。
TV を 5 段階のバンド (air/weak/mid/strong/nut) に分類すれば、次章の 25 セル表と連携して cbet 判断ができるようになります。

## TV とは何か

TV (Combined Board Score) は「フロップでのハンドの総合的な強さ」を表す整数スコアです。
TV = MV + DV という 2 段階の加算式で計算します。

MV (Hand Power) はフロップでの役の強さを 6 段階の整数 (2/3/5/7/8/9) で表します。現時点の役だけが反映され、将来の改善可能性は含みません。DV (Draw Power) はドローの期待価値を 4 段階 (0/1/2/3) で表します。現在の役ではなく将来の改善可能性のみを反映します。

例えば「トップペア + フラッシュドロー」は MV=7 + DV=2 = TV=9 (nut バンド) です。「OESD のみ (役なし)」は MV=2 + DV=2 = TV=4 (weak バンド) です。TV が高いほど強いハンドですが、同じ TV でも役の性質が異なる点に注意が必要です。

## MV テーブル — 役の強さを 6 段階で表す

### MV バケット一覧 (16 hand → 6 バケット)

| HP | 含まれる役 |
|---:|---|
| 2 | ノーペア, Aハイ, Kハイ, ロー・ポケットペア |
| 3 | アンダーペア, サードペア |
| 5 | セカンドペア |
| 7 | トップペア, オーバーペア |
| 8 | セット, トリップス |
| 9 | ツーペア, フラッシュ, ストレート, フルハウス, クアッズ |

MV テーブルには 16 種類のハンドタイプがあり、6 つのバケットに集約されます。暗記のコツは「エアー=2・弱ペア=3・中ペア=5・トップ=7・セット=8・怪物=9」という 6 段階の言葉です。

**MV=2 (エアー系)** には 4 種類が含まれます。no_made_hand (完全な空振り)、ace_high (A ハイで役なし)、king_high (K ハイで役なし)、low_pair (ポケットペアがボード全カードより弱い状態) です。4 種類まとめて MV=2 と覚えます。

**MV=3 (弱ペア系)** は underpair と third_pair です。underpair はポケットペアがボードの最高カードより低いペアです。third_pair はボードの 3 番目のカードとペアになった状態です。

**MV=5 (中ペア)** は second_pair のみです。ボードの 2 番目に高いカードとペアになっています。

**MV=7 (強ペア)** は top_pair (ボード最高カードとのペア) か overpair (ポケットペアがボード全カードより高い) です。実戦で最も重要なバケットです。

**MV=8 (セット系)** は set と trips です。set はポケットペアとボードの同ランクカードで作る 3 枚同ランクです。trips はボードのペアに自分のハンドを 1 枚加えた状態です。

**MV=9 (怪物系)** は two_pair / flush / straight / fullhouse / quads の全てです。これらは TV 計算上は同値として扱います。

## DV テーブル — ドローの価値を 4 段階で表す

### DV テーブル (4 段階)

| DP | ドロー種別 |
|---:|---|
| 0 | ドローなし, BDFD |
| 1 | ガットショット |
| 2 | OESD, フラッシュドロー |
| 3 | コンボドロー |

DV=0 は「実質的なドローなし」です。ドローが全くない場合だけでなく、twocards_bdfd (バックドアフラッシュドロー) のみの場合も DV=0 です。バックドアドローはターンでフラッシュドローを拾う必要があるため、期待値が低すぎてスコアに加算しません。

DV=1 は gutshot (腹打ちストレートドロー) です。4 枚のカードでストレートを完成できる状態ですが、完成確率はターンで約 11% と低めです。

DV=2 は oesd (両面ストレートドロー) か fd (フラッシュドロー) のどちらかです。OESD はターンで約 17%、FD はターンで約 19% の完成率です。

DV=3 は combo_draw で、OESD と FD の両方を持つ強力なドローです。ターンでの改善確率が 40%+ になります。

## TV バンド — 5 区分への分類

TV = MV + DV を計算したら、5 つのバンドに分類します。バンドの境界値を覚えることがポストフロップ判断の出発点です。

| バンド | TV 範囲 | 意味 |
|---|---:|---|
| air | 0-2 | 完全な空振り・実質ドローなし |
| weak | 3-4 | 弱ペア / gutshot どまり |
| mid | 5-6 | 中ペア / 強いドロー |
| strong | 7-8 | トップペア以上 / セット |
| nut | 9+ | 2 ペア以上の怪物 |

バンド境界の覚え方: 3 が weak の下限、5 が mid の下限、7 が strong の下限、9 が nut の下限です。

## 計算例 — 実践で TV を暗算する

### TV 計算例 (A モデルでの判定)

**例**: トップペア (top_pair) + ドローなし on Cash 100bb

1. HP = **7** (top_pair のバケット)
2. DP = **0** (ドローなし)
3. CBS = HP + DP = 7 + 0 = **7**
4. CBS バンド: 強ペア (TV 7-8)
5. base = LIGHT_V2_BASE[cash][strong] = **60%**
→ **連続 bet 頻度 ≈ 60%**

**例**: アンダーペア (underpair) + ドローなし on Cash 100bb

1. HP = **3** (underpair のバケット)
2. DP = **0** (ドローなし)
3. CBS = HP + DP = 3 + 0 = **3**
4. CBS バンド: 弱ペア (TV 3-4)
5. base = LIGHT_V2_BASE[cash][weak] = **40%**
→ **連続 bet 頻度 ≈ 40%**

**例**: セカンドペア (second_pair) + ガットショット on Cash 100bb

1. HP = **5** (second_pair のバケット)
2. DP = **1** (ガットショット)
3. CBS = HP + DP = 5 + 1 = **6**
4. CBS バンド: 中ペア (TV 5-6)
5. base = LIGHT_V2_BASE[cash][mid] = **40%**
→ **連続 bet 頻度 ≈ 40%**

**例**: ノーペア (no_made_hand) + コンボドロー on Cash 100bb

1. HP = **2** (no_made_hand のバケット)
2. DP = **3** (コンボドロー)
3. CBS = HP + DP = 2 + 3 = **5**
4. CBS バンド: 中ペア (TV 5-6)
5. base = LIGHT_V2_BASE[cash][mid] = **40%**
→ **連続 bet 頻度 ≈ 40%**

**例**: ツーペア (two_pair) + ドローなし on Cash 100bb

1. HP = **9** (two_pair のバケット)
2. DP = **0** (ドローなし)
3. CBS = HP + DP = 9 + 0 = **9**
4. CBS バンド: ナッツ (TV 9+)
5. base = LIGHT_V2_BASE[cash][nut] = **60%**
→ **連続 bet 頻度 ≈ 60%**

## low_pair の特別扱い

low_pair (例: 22 on A73) は MV=2 で air バンドに分類されます。しかし実戦上は、他の MV=2 ハンド (ace_high など) より明らかに打ちにくいハンドです。ベットしても相手の任意のペアハンドのチェックレイズに対応できず、showdown value も極めて低いためです。

このため A モデルでは low_pair に対して LIGHT_V2_OFFSET として -10pt の追加補正を加えます。例えば Cash context の air バンドが 45% のとき、low_pair は 45% - 10% = 35% となります。35% < 50% なのでチェック推奨と判断します。

注意: low_pair 補正は MV タイプが low_pair のときのみ適用します。gutshot などのドローが加わって TV が 3 以上になった場合は、low_pair 補正ではなく通常のバンドで判断します。

### low_pair 補正の例

**例**: ロー・ポケットペア (low_pair) + ドローなし on Cash 100bb

1. HP = **2** (low_pair のバケット)
2. DP = **0** (ドローなし)
3. CBS = HP + DP = 2 + 0 = **2**
4. CBS バンド: エアー (TV 0-2)
5. base = LIGHT_V2_BASE[cash][air] = **45%**
6. low_pair の例外 offset: -10pt
→ **連続 bet 頻度 ≈ 35%**

**例**: ロー・ポケットペア (low_pair) + ドローなし on 3-bet pot IP

1. HP = **2** (low_pair のバケット)
2. DP = **0** (ドローなし)
3. CBS = HP + DP = 2 + 0 = **2**
4. CBS バンド: エアー (TV 0-2)
5. base = LIGHT_V2_BASE[3bp][air] = **45%**
6. low_pair の例外 offset: -10pt
→ **連続 bet 頻度 ≈ 35%**

## ハンドカテゴリ — slowplay / trash / premium の区別

### ハンドカテゴリ一覧

| カテゴリ | 含まれる役 |
|---|---|
| slowplay | ツーペア, フラッシュ, ストレート, セット, トリップス, フルハウス, クアッズ |
| trash | ロー・ポケットペア |
| premium | アンダーペア, オーバーペア |
| default | ノーペア, Aハイ, Kハイ, サードペア, セカンドペア, トップペア |

A モデルでは主に MV/DV バンドと low_pair 補正を使いますが、旧 5 軸モデル ではさらに「ハンドカテゴリ」による追加補正があります。

**slowplay** カテゴリ (set, fullhouse, quads) は、強すぎる手なのでチェックで誘うことが最適な場面があります。旧 5 軸モデル ではこれに -offset を加えますが、A モデルでは nut バンドの 60% に吸収されています。

**trash** カテゴリ (no_made_hand, low_pair) は弱すぎる手です。low_pair の -10pt 補正はこの考え方に基づきます。

**premium** カテゴリ (top_pair, overpair, set, trips) は積極的なバリューベットが最適な手です。A モデルの strong/nut バンドでの 60-75% という数値はこれを反映しています。

## GTO とのズレ — TV の精度限界

TV 計算は「暗算 5 秒」と引き換えに、いくつかの精度的な限界を持ちます。

第 1 の限界は MV の均一化です。MV=7 の top_pair と overpair を同値として扱いますが、実際には状況によって bet freq に差が出ます。例えば K72r での KQ (TPTK) と AA (overpair) では GTO 上の bet freq が異なる場合があります。

第 2 の限界はボード依存性の省略です。同じ TV=7 でも A-high ボードのトップペアと low ボードのトップペアでは、相手のコールレンジの構成が異なります。A モデルは context (型1-7 との連携) でこの差を一部吸収しますが、完全ではありません。

A モデルの Cash 100bb での精度は WRMSE 約 19% で、旧 5 軸モデル (16.43%) より約 2-3pt の誤差増です。「暗算 5 秒」との交換代として許容できる精度差です。
