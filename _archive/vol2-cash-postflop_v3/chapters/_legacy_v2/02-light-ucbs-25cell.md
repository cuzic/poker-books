# 第02章 Light UCBS の 25 セル表

5 context × 5 CBS バンドの 25 セル表を完全に習得します。
context の切り替え条件と各セルの意味を理解することで、フロップ cbet の判断を暗算で完結させられるようになります。
特に Cash context の 5 値と low_pair 例外補正 (-10pt) を重点的に習得します。

## 25 セル表の全貌

### Light UCBS v2 — 5 context × 5 バンドのベット頻度目安

| Context | エアー | 弱ペア | 中ペア | 強ペア | ナッツ |
|---|:-:|:-:|:-:|:-:|:-:|
| Cash 100bb | 45% | 40% | 40% | 60% | 60% |
| MTT 25-50bb | 40% | 30% | 35% | 60% | 75% |
| MTT 100-200bb | 40% | 40% | 40% | 60% | 60% |
| 3-bet pot IP | 45% | 50% | 60% | 70% | 60% |
| Turn 2nd barrel | 5% | 5% | 10% | 30% | 40% |

**例外**: `low_pair` -10pt (context 共通)

25 セル表の行が context (5 種類の状況)、列が CBS バンド (5 段階の強さ) です。行と列の交点にあるパーセント値が「その状況・強さでのベット頻度の目安」です。

判断の基準は 50% です。セル値が 50% 以上ならベット推奨、50% 未満ならチェック寄りと解釈します。この切り分けで「打つか打たないか」を 1 ビットの判断に落とし込みます。

表を眺めると、右に行くほど (強くなるほど) 値が高くなる傾向があります。ただし nut バンドが strong より低い場合 (3bp の 60% vs 70%) があります。これはナッツのスローイング (slowplay) を考慮しているためです。

## 5 context の定義と切り替えフロー

context は「どの状況にいるか」を決める 5 分類です。実戦でまず「今は何 context か」を確認します。

**cash context** は Cash ゲームの 100bb SRP (シングルレイズポット) です。BTN が open して BB が call した後のフロップが典型例です。本書のメイン context で、全 12 章の大半はここを扱います。pot=6bb / stack=97bb が標準状況です。

**mtt_short context** は MTT (トーナメント) の 25-50bb スタックのフロップです。ショートスタックではポットコミットが近いため、強いハンドをプッシュする戦略が強くなります。nut バンドが 75% と高めなのはこのためです。

**mtt_deep context** は MTT の 100bb 以上のフロップです。深スタックでは Cash と同様の戦略が適切で、Light UCBS v2 上では cash と全値が同じです。

**3bp context** は 3-bet pot のフロップです。SPR (Stack-to-Pot Ratio) が約 5 前後と低く、コミット判断が近くなります。このため weak バンド (50%) と mid バンド (60%) もベット推奨に変わります。

**turn context** はターンでの 2nd barrel 判断です。フロップで cbet を打った後、ターンでもベットするかどうかを判断する際に使います。全バンドが大幅に低い値になっており、strong でも 30%、nut でも 40% です。

## context 切り替えフロー (3 ステップ)

実戦でどの context を使うかは以下の順で確認します。

**ステップ 1**: ターンの 2nd barrel か? → Yes なら turn context を使う。

**ステップ 2**: 3-bet pot (SPR ~5) か? → Yes なら 3bp context を使う。

**ステップ 3**: スタックサイズで分類する。Cash 100bb または MTT 100bb 以上 → mtt_deep/cash のどちらか (ほぼ同値)。MTT 50bb 以下 → mtt_short。

Cash context か mtt_deep context かの区別は Light UCBS v2 では数値が同じなため、どちらを選んでも判断に影響しません。

## Cash context を深く理解する

Cash context (Cash 100bb SRP) は本書のメインです。5 値を確実に覚えます。

| バンド | freq | 判断 |
|--------|-----:|------|
| air    | 45%  | チェック寄り |
| weak   | 40%  | チェック推奨 |
| mid    | 40%  | チェック推奨 |
| strong | 60%  | ベット推奨 |
| nut    | 60%  | ベット推奨 |

air (45%) がチェック寄りなのは、ブラフとして打つことが完全に禁止されているわけではないためです。「45% の頻度でレンジ全体のこのバンドをベットする」という意味です。

mid バンドが 40% (チェック推奨) という点は意外に感じるかもしれません。second_pair や combo_draw は一見そこそこ強い手です。しかし GTO 上では、これらのハンドはチェックバックして後のストリートで判断するのが最適な場合が多く、40% はそれを反映しています。

strong と nut が同値 (60%) なのも特徴的です。2 ペア以上の怪物でもトップペアと同じ頻度でベットするのは、slowplay 戦略が最適な場面があるためです。

### Cash context — 各バンド代表例

1. HP = **7** (top_pair のバケット)
2. DP = **0** (ドローなし)
3. CBS = HP + DP = 7 + 0 = **7**
4. CBS バンド: 強ペア (CBS 7-8)
5. base = LIGHT_V2_BASE[cash][strong] = **60%**
→ **連続 bet 頻度 ≈ 60%**

## 3bp context — SPR 低下で判断が変わる

3-bet pot context は Cash context と比べて大きく異なる値を持ちます。cash との差分は以下の通りです。

| バンド | cash | 3bp | 差分 |
|--------|-----:|----:|-----:|
| air    | 45%  | 45% | ±0   |
| weak   | 40%  | 50% | +10  |
| mid    | 40%  | 60% | +20  |
| strong | 60%  | 70% | +10  |
| nut    | 60%  | 60% | ±0   |

最も大きな変化は mid バンドの +20pt (40% → 60%) です。second_pair や combo_draw が 3bp ではベット推奨に転じます。SPR が約 5 と低いため、コミット判断が近く、中程度の強さのハンドも積極的に進めることが最適になります。

air と nut が Cash と同値 (45% / 60%) なのは、どの context でも「完全なブラフ頻度」と「怪物ハンドのスローイング割合」は大きく変わらないことを示しています。

## turn context — フロップの 2nd barrel は慎重に

turn context は 5 つの中で最も保守的な値を持ちます。フロップで cbet を打った後、ターンで strong (30%) や nut (40%) でもチェック寄りになるのは、フロップで既に一度ベットしているためです。

フロップ → ターン → リバーと 3 ストリートにわたってベットし続けることは、スタックの大半をコミットすることを意味します。ターンではよほど良いハンドか有利な状況でない限り、チェックバックを選ぶのが GTO に近い戦略です。

air (5%) と weak (5%) はほぼ常にチェック推奨です。フロップでブラフとして打った air ハンドが、ターンでも継続するのはよほど良いブロッカーや状況がない限り推奨されません。ターン 2nd barrel の詳細は ch09 で扱います。

## low_pair 例外補正 — -10pt の適用

low_pair (例: 22 on A73) は HP=2 で air バンドに分類されます。しかし Light UCBS v2 では、low_pair に対して context 問わず -10pt の補正を加えます。

なぜ low_pair だけ特別扱いするのでしょうか。第 1 の理由は「showdown value がない」ことです。ace_high や king_high はリバーまでチェックしてショーダウンに持ち込めば勝てることがあります。しかし low_pair は相手のハンドレンジのほぼ全てに負けており、showdown value が極めて低いのです。

第 2 の理由は「チェックレイズに弱い」ことです。low_pair でベットすると、相手の任意のペアハンドのチェックレイズに対応できません。

適用例: Cash context の air バンドが 45%、low_pair は 45% - 10% = 35% → チェック推奨。

注意: low_pair 補正は HP タイプが low_pair のときのみ適用します。gutshot などのドローが加わって CBS が 3 以上になった場合は、low_pair 補正ではなく通常のバンドで判断します。

## 暗算ヒューリスティック — 5-7 秒で決断するコツ

25 セル表を全暗記しなくても、以下のヒューリスティックで大半の状況を処理できます。

**「mid 以下はチェック、strong 以上はベット」の基本ルール**: Cash context では mid バンド (40%) はチェック、strong バンド (60%) はベット。3bp context では weak バンド (50%) からベット。この切り替えを覚えるだけで多くの判断をカバーできます。

**「ターンは全体的に大幅チェック寄り」**: turn context は全バンドが低いため、「ターンではよほど強くない限りチェック寄り」と覚えます。strong (30%) でもチェックが多く、nut (40%) でやっとベットを考えます。

**「MTT short はナッツを積極的に」**: mtt_short で nut バンド (75%) は高め。短スタックでナッツに近いハンドは積極的にプッシュします。

実戦での手順は次の通りです。CBS を計算 → バンドを判定 → context を確認 → 50% を超えるかチェックする。この 4 ステップを繰り返すことで、5-7 秒の判断が身につきます。

## GTO とのズレ — 25 セル表の精度限界

25 セル表 (Light UCBS v2) は Full UCBS-v2 の 13 context を 5 context に圧縮しています。この圧縮によって生じる精度差を理解しておくことが重要です。

精度の目安 (WRMSE): Cash 100bb は約 19% (Full v2: 16.43%)、MTT 25bb は約 18% (Full v2: 15.46%)、3bp は約 12% (Full v2: 8.62%)、turn は約 20% (Full v2: 16.11%) です。+2-4pt の誤差は「暗算 5 秒」と引き換えに許容できる範囲です。

最も誤差が大きい場面は「型5 モノトーンボード」と「ストレート完成ボード」です。これらはボード特有のダイナミクスが強く、平均的な 25 セル表の値から大きくずれることがあります。実戦でこれらのボードに当たった場合は、25 セル表の値を参考にしつつ「通常より控えめに」と調整することを推奨します。
