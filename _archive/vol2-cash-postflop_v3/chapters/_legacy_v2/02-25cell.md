# 第02章 A モデルの 25 セル表

5 context × 5 TV バンドの 25 セル表を完全に習得します。
context の切り替え条件と各セルの意味を理解することで、フロップ cbet の判断を暗算で完結させられるようになります。
特に Cash context の 5 値と low_pair 例外補正 (-10pt) を重点的に習得します。

## 25 セル表の全貌

### A モデル — 5 context × 5 バンドのベット頻度目安

| Context | air (TV 0-2) | weak (3-4) | mid (5-6) | strong (7-8) | nut (9+) |
|---|---:|---:|---:|---:|---:|
| Cash 100bb | 44% | 37% | 42% | 57% | 62% |
| MTT 25-50bb | 37% | 30% | 35% | 58% | 73% |
| MTT 100-200bb | 42% | 41% | 41% | 58% | 61% |
| 3-bet pot IP | 46% | 50% | 61% | 70% | 58% |
| Turn 2nd barrel | 6% | 6% | 3% | 7% | 7% |

25 セル表の行が context (5 種類の状況)、列が TV バンド (5 段階の強さ) です。行と列の交点にあるパーセント値が「その状況・強さでのベット頻度の目安」です。

判断の基準は 50% です。セル値が 50% 以上ならベット推奨、50% 未満ならチェック寄りと解釈します。この切り分けで「打つか打たないか」を 1 ビットの判断に落とし込みます。

表を眺めると、右に行くほど (強くなるほど) 値が高くなる傾向があります。ただし nut バンドが strong より低い場合 (3bp の 58% vs 70%) があります。これはナッツのスローイング (slowplay) を考慮しているためです。

## 5 context の定義と切り替えフロー

context は「どの状況にいるか」を決める 5 分類です。実戦でまず「今は何 context か」を確認します。

**cash context** は Cash ゲームの 100bb SRP (シングルレイズポット) です。BTN が open して BB が call した後のフロップが典型例です。本書のメイン context で、全 12 章の大半はここを扱います。pot=6bb / stack=97bb が標準状況です。

**mtt_short context** は MTT (トーナメント) の 25-50bb スタックのフロップです。ショートスタックではポットコミットが近いため、強いハンドをプッシュする戦略が強くなります。nut バンドが 73% と高めなのはこのためです。

**mtt_deep context** は MTT の 100bb 以上のフロップです。深スタックでは Cash と類似の戦略が適切で、A モデル上では cash と全値がほぼ同じです (mid/strong/nut で 1-3pt 程度の差)。

**3bp context** は 3-bet pot のフロップです。SPR (Stack-to-Pot Ratio) が約 5 前後と低く、コミット判断が近くなります。このため weak バンド (50%) と mid バンド (61%) もベット推奨に変わります。

**turn context** はターンでの 2nd barrel 判断です。フロップで cbet を打った後、ターンでもベットするかどうかを判断する際に使います。全バンドが大幅に低い値になっており、strong でも 7%、nut でも 7% です。

## context 切り替えフロー (3 ステップ)

実戦でどの context を使うかは以下の順で確認します。

**ステップ 1**: ターンの 2nd barrel か? → Yes なら turn context を使う。

**ステップ 2**: 3-bet pot (SPR ~5) か? → Yes なら 3bp context を使う。

**ステップ 3**: スタックサイズで分類する。Cash 100bb または MTT 100bb 以上 → mtt_deep/cash のどちらか (ほぼ同値)。MTT 50bb 以下 → mtt_short。

Cash context か mtt_deep context かの区別は A モデルでは数値が同じなため、どちらを選んでも判断に影響しません。

## Cash context を深く理解する

Cash context (Cash 100bb SRP) は本書のメインです。5 値を確実に覚えます。

| バンド | freq | 判断 |
|--------|-----:|------|
| air    | 44%  | チェック寄り |
| weak   | 37%  | チェック推奨 |
| mid    | 42%  | チェック推奨 |
| strong | 57%  | ベット推奨 |
| nut    | 62%  | ベット推奨 |

air (44%) がチェック寄りなのは、ブラフとして打つことが完全に禁止されているわけではないためです。「44% の頻度でレンジ全体のこのバンドをベットする」という意味です。

mid バンドが 42% (チェック推奨) という点は意外に感じるかもしれません。second_pair や combo_draw は一見そこそこ強い手です。しかし GTO 上では、これらのハンドはチェックバックして後のストリートで判断するのが最適な場合が多く、42% はそれを反映しています。

strong (57%) と nut (62%) で nut の方がやや高いですが、その差は 5pt 程度です。2 ペア以上の怪物でもトップペアと近い頻度でベットするのは、slowplay 戦略が最適な場面があるためです。

## 各 context の代表的な計算例

### Cash context — 各バンド代表例

**例**: トップペア (top_pair) + ドローなし on Cash 100bb

1. MV = **7** (top_pair)、DV = **0** (ドローなし)
2. TV = MV + DV = 7 + 0 = **7** → band: 強ペア (TV 7-8)
3. base = 25cell[cash][strong] = **57%**

→ **連続 bet 頻度 ≈ 57%**

**例**: セカンドペア (second_pair) + ドローなし on Cash 100bb

1. MV = **5** (second_pair)、DV = **0** (ドローなし)
2. TV = MV + DV = 5 + 0 = **5** → band: 中ペア (TV 5-6)
3. base = 25cell[cash][mid] = **42%**

→ **連続 bet 頻度 ≈ 42%**

**例**: Aハイ (ace_high) + フラッシュドロー on Cash 100bb

1. MV = **2** (ace_high)、DV = **2** (フラッシュドロー)
2. TV = MV + DV = 2 + 2 = **4** → band: 弱ペア (TV 3-4)
3. base = 25cell[cash][weak] = **37%**

→ **連続 bet 頻度 ≈ 37%**

**例**: ツーペア (two_pair) + ドローなし on Cash 100bb

1. MV = **8** (two_pair)、DV = **0** (ドローなし)
2. TV = MV + DV = 8 + 0 = **8** → band: 強ペア (TV 7-8)
3. base = 25cell[cash][strong] = **57%**

→ **連続 bet 頻度 ≈ 57%**

### 3bp context — SPR 低下で判断変化

**例**: アンダーペア (underpair) + ドローなし on 3-bet pot IP

1. MV = **3** (underpair)、DV = **0** (ドローなし)
2. TV = MV + DV = 3 + 0 = **3** → band: 弱ペア (TV 3-4)
3. base = 25cell[3bp][weak] = **50%**

→ **連続 bet 頻度 ≈ 50%**

**例**: セカンドペア (second_pair) + ガットショット on 3-bet pot IP

1. MV = **5** (second_pair)、DV = **1** (ガットショット)
2. TV = MV + DV = 5 + 1 = **6** → band: 中ペア (TV 5-6)
3. base = 25cell[3bp][mid] = **61%**

→ **連続 bet 頻度 ≈ 61%**

**例**: トップペア (top_pair) + ドローなし on 3-bet pot IP

1. MV = **7** (top_pair)、DV = **0** (ドローなし)
2. TV = MV + DV = 7 + 0 = **7** → band: 強ペア (TV 7-8)
3. base = 25cell[3bp][strong] = **70%**

→ **連続 bet 頻度 ≈ 70%**

### turn context — 2nd barrel は慎重に

**例**: ノーペア (no_made_hand) + ドローなし on Turn 2nd barrel

1. MV = **2** (no_made_hand)、DV = **0** (ドローなし)
2. TV = MV + DV = 2 + 0 = **2** → band: エアー (TV 0-2)
3. base = 25cell[turn][air] = **6%**

→ **連続 bet 頻度 ≈ 6%**

**例**: トップペア (top_pair) + ドローなし on Turn 2nd barrel

1. MV = **7** (top_pair)、DV = **0** (ドローなし)
2. TV = MV + DV = 7 + 0 = **7** → band: 強ペア (TV 7-8)
3. base = 25cell[turn][strong] = **7%**

→ **連続 bet 頻度 ≈ 7%**

**例**: セット (set) + ドローなし on Turn 2nd barrel

1. MV = **9** (set)、DV = **0** (ドローなし)
2. TV = MV + DV = 9 + 0 = **9** → band: ナッツ (TV 9+)
3. base = 25cell[turn][nut] = **7%**

→ **連続 bet 頻度 ≈ 7%**

## 3bp context — SPR 低下で判断が変わる

3-bet pot context は Cash context と比べて大きく異なる値を持ちます。cash との差分は以下の通りです。

| バンド | cash | 3bp | 差分 |
|--------|-----:|----:|-----:|
| air    | 44%  | 46% | +2   |
| weak   | 37%  | 50% | +13  |
| mid    | 42%  | 61% | +19  |
| strong | 57%  | 70% | +13  |
| nut    | 62%  | 58% | -4   |

最も大きな変化は mid バンドの +19pt (42% → 61%) です。second_pair や combo_draw が 3bp ではベット推奨に転じます。SPR が約 5 と低いため、コミット判断が近く、中程度の強さのハンドも積極的に進めることが最適になります。

nut が cash よりやや低い (58% vs 62%) のは、3bp ではナッツのスローイング比率が高いためです。SPR が低いため、ベットしなくてもポット全体をコミット可能で、トラップから多くの value を取り易い構造になっています。

## turn context — フロップの 2nd barrel は慎重に

turn context は 5 つの中で最も保守的な値を持ちます。フロップで cbet を打った後、ターンで strong (7%) や nut (7%) でもチェック寄りになるのは、フロップで既に一度ベットしているためです。

フロップ → ターン → リバーと 3 ストリートにわたってベットし続けることは、スタックの大半をコミットすることを意味します。ターンではよほど良いハンドか有利な状況でない限り、チェックバックを選ぶのが GTO に近い戦略です。

air (6%) と weak (6%) はほぼ常にチェック推奨です。フロップでブラフとして打った air ハンドが、ターンでも継続するのはよほど良いブロッカーや状況がない限り推奨されません。ターン 2nd barrel の詳細は ch09 で扱います。

## low_pair 例外補正 — -10pt の適用

low_pair (例: 22 on A73) は MV=2 で air バンドに分類されます。しかし A モデルでは、low_pair に対して context 問わず -10pt の補正を加えます。

なぜ low_pair だけ特別扱いするのでしょうか。第 1 の理由は「showdown value がない」ことです。ace_high や king_high はリバーまでチェックしてショーダウンに持ち込めば勝てることがあります。しかし low_pair は相手のハンドレンジのほぼ全てに負けており、showdown value が極めて低いのです。

第 2 の理由は「チェックレイズに弱い」ことです。low_pair でベットすると、相手の任意のペアハンドのチェックレイズに対応できません。

適用例: Cash context の air バンドが 44%、low_pair は 44% - 10% = 34% → チェック推奨。

注意: low_pair 補正は MV タイプが low_pair のときのみ適用します。gutshot などのドローが加わって TV が 3 以上になった場合は、low_pair 補正ではなく通常のバンドで判断します。

## 暗算ヒューリスティック — 5-7 秒で決断するコツ

25 セル表を全暗記しなくても、以下のヒューリスティックで大半の状況を処理できます。

**「mid 以下はチェック、strong 以上はベット」の基本ルール**: Cash context では mid バンド (42%) はチェック、strong バンド (57%) はベット。3bp context では weak バンド (50%) からベット。この切り替えを覚えるだけで多くの判断をカバーできます。

**「ターンは全体的に大幅チェック寄り」**: turn context は全バンドが 10% 未満のため、「ターンでフロップ cbet 後に続けて打つのは例外」と覚えます。詳しい判断は ch09 で扱います。

**「MTT short はナッツを積極的に」**: mtt_short で nut バンド (73%) は高め。短スタックでナッツに近いハンドは積極的にプッシュします。

実戦での手順は次の通りです。TV を計算 → バンドを判定 → context を確認 → 50% を超えるかチェックする。この 4 ステップを繰り返すことで、5-7 秒の判断が身につきます。

## GTO とのズレ — 25 セル表の精度限界

25 セル表 (A モデル) は 旧 5 軸モデル の 13 context を 5 context に圧縮しています。この圧縮によって生じる精度差を理解しておくことが重要です。

精度の目安 (WRMSE): Cash 100bb は約 21% (A モデル: 16.4%)、MTT 25bb は約 36% (A モデル: 15.5%)、3bp は約 13% (A モデル: 12%)、turn は約 22% (A モデル: 16.1%) です。+2-4pt から +20pt 程度の誤差が生じる context もあります。

最も誤差が大きい場面は「型5 モノトーンボード」と「ストレート完成ボード」、および「MTT 短スタック」です。これらは平均的な 25 セル表の値から大きくずれることがあります。Vol3 では context 別補正 α / β、板分類 ε などで誤差を半減させますが、本書では「暗算 5 秒」を優先し、25 セル表のみで実戦に出る方針を採っています。実戦でこれらのボードに当たった場合は、25 セル表の値を参考にしつつ「通常より控えめに」と調整することを推奨します。
