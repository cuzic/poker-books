# 第04章 ボード読み — 型1-7 で 3 秒判定

フロップ 7 分類を 3 秒で見抜く「型1-7 判定ルーチン」を習得します。
「トップカード高さ」「テクスチャ (spread)」「ペア有無」の 3 要素で即判定し、ナッツアドバンテージ (SB 有利 / BB 有利 / 境界) を確定します。
この型判定が A モデルの信頼度補正 (型6 up / 型5 down) と直結し、ch03 の Cash cbet 判断をより精度よく行えるようになります。

## ボード 7 分類 — 3 要素で決まる

フロップボードを「ドライ vs ウェット」の 2 分類で扱うと情報が粗すぎます。例えば同じ「ウェット」でも A♠K♠Q♠ のモノトーンと T♠9♠8♦ のローコネクテッドでは、SB と BB のレンジ優位が全く異なります。型1-7 の 7 分類はこの問題を解消します。

7 型は以下の 3 要素で決まります。

**要素 1: トップカード高さ** — top≥Q (Q 以上) なら "High"、top<Q (J 以下) なら "Low" に分類します。

**要素 2: テクスチャ** — spread (最高ランク - 最低ランク) と スーツ数で判断します。rainbow (3 種スーツ) かつ spread>3 なら "Dry"、それ以外 (2-tone 以上、または spread≤3) なら "Wet" です。

**要素 3: ペア有無** — ボードにペアがあれば型6/型7 に優先分類します。

## 型1-7 一覧表

| 型 | 名称 | 条件 | ナッツアドバンテージ | 代表例 |
|---|---|---|---|---|
| 型1 | ハイドライ   | top≥Q + rainbow + spread>3 | SB 有利 | K♠7♦2♣ |
| 型2 | ハイウェット | top≥Q + (2-tone or spread≤3) | SB 有利 | Q♠8♦3♠ |
| 型3 | ロードライ   | top<Q + rainbow + spread>3 | BB 有利 | J♦7♠5♣ |
| 型4 | ローウェット | top<Q + (2-tone or spread≤3) | BB 有利 | T♠9♠8♦ |
| 型5 | モノトーン   | 3 枚同スーツ | 境界 | A♥K♥Q♥ |
| 型6 | ペア高       | ペア rank≥Q | SB 有利 | A♠A♣K♦ |
| 型7 | ペア低       | ペア rank<Q | 中立 | 7♠7♣2♦ |

## 3 秒判定ルーチン — 3 問で型を確定する

フロップを見た瞬間に以下の 3 問に答えます。Q1 → Q2 → Q3 の順に確認することで、全 7 型を 3 問以内に絞り込めます。

**Q1. ペアボードか?**
→ Yes: ペアのランクが Q 以上なら型6。Q 未満なら型7。確定、終了。

**Q2. 3 枚同スーツか?**
→ Yes: 型5 (モノトーン)。確定、終了。

**Q3. トップカードは Q 以上か + Dry か?**
→ top≥Q + Dry (rainbow かつ spread>3) → 型1 (ハイドライ)
→ top≥Q + Wet → 型2 (ハイウェット)
→ top<Q + Dry → 型3 (ロードライ)
→ top<Q + Wet → 型4 (ローウェット)

**spread の数え方**: spread = 最高ランク - 最低ランク (A=14, K=13, Q=12, J=11, T=10, 2-9 はそのまま)。例: K72 → 13-2=11 > 3 → Dry。T98 → 10-8=2 ≤ 3 → Wet。

## 型1 — ハイドライ

代表例: K♠7♦2♣, A♠7♦2♣, Q♠8♦2♣

ハイドライボードは SB のオープンレンジが最も有利な型です。SB は A/K/Q 系のブロードウェイカードが中心のレンジでオープンしており、型1 ボードではトップペア以上を多く保有します。BB のコールレンジには K72r にヒットする手が少なく、SB がナッツアドバンテージを持ちます。

A モデルでの判断: Cash context の 5 値をそのまま適用します。strong/nut バンド (TV≥7) は 60% でベット推奨です。type1 ではベットサイズを大きくできる傾向があります (polarize ボード候補)。サイズ選択の詳細は ch05 で扱います。

## 型2 — ハイウェット

代表例: Q♠8♦3♠, A♥J♥5♦, K♠T♠4♦

ハイウェットボードは SB 有利ですが、型1 ほどのナッツアドバンテージではありません。2-tone または spread≤3 のため、BB のコールレンジにフラッシュドローやストレートドローが多く含まれます。

A モデルでの判断: Cash context の標準値を使います。strong バンド (60%) でベット推奨。mid バンド (40%) はチェック寄りですが、FD を持つ mid バンドハンドはセミブラフとしてベットを検討できます。

## 型3 — ロードライ

代表例: J♦7♠5♣, T♦6♠2♣, J♠8♦3♣

ロードライボードは BB 有利です。BB のコールレンジには J75 / T62 などのローコネクターやスーテッドが多く含まれており、セット・2 ペア・ストレートドローを多く保有しています。SB は型3 ボードでナッツアドバンテージがなく、mid バンドのベットは慎重にすべきです。

A モデルでの判断: Cash context の標準値を使いますが、「strong/nut バンドでもベット頻度は型1 より抑えめにする」という補正意識を持つことを推奨します。特に mid バンド (40%) のチェックバックは型3 では積極的に選びます。

## 型4 — ローウェット

代表例: T♠9♠8♦, 9♠8♠7♦, J♠T♥9♠

ローウェットボードは BB 有利が最も顕著な型です。BB のコールレンジにコネクターが多く、2 ペア・ストレート・セットを多く保有します。GTO 分析ではこの型で BB のチェックレイズ頻度が約 25-35% に達することが確認されています。

A モデルでの判断: Cash context の標準値を使いますが、IP は mid バンド以下のチェックバックを積極的に選択します。ウェットボードで IP がアグレッシブにベットし続けると、BB のチェックレイズに悩む局面が多くなります。

## 型5 — モノトーン

代表例: A♥K♥Q♥, T♠9♠8♠, 7♦6♦2♦

モノトーンボードは特殊な扱いが必要です。3 枚同スーツのため、フラッシュドローが完成している可能性が非常に高く、IP も OOP もフラッシュを持つレンジが豊富です。ナッツアドバンテージが読みにくい状態です。

A モデルでの判断: Cash context では型5 ボードでは freq を -1 段階 down する補正を推奨します。strong バンド (60%) を mid バンド相当 (40%) に下げるイメージです。フラッシュ (MV=9, TV=9, nut) を持っている場合は 60% 維持でベット推奨ですが、slowplay (チェック) も選択肢になります。

## 型6 — ペア高

代表例: A♠A♣K♦, K♠K♣7♦, Q♠Q♣2♣

ペア高ボードは SB 有利です。SB はポケットペアをオープンレンジに多く含んでおり、AA/KK/QQ のようなペア高ボードではセットを保有する確率が BB より約 20% 高くなります。

A モデルでの判断: 型6 では Cash context の freq に +1 段階 up の信頼度補正を加えます。mid バンド (通常 40%) を strong バンド相当 (60%) に上げるイメージです。strong バンドは 60% → ほぼ常にベット推奨と解釈できます。

実践的には「型6 ボードでは mid バンドでも積極的にベット」という判断ルールとして覚えます。

## 型7 — ペア低

代表例: 7♠7♣2♦, 5♠5♣9♦, 3♠3♣K♦

ペア低ボードは中立です。BB のコールレンジにも低いポケットペアが含まれており、特定の有利はどちらにもありません。

A モデルでの判断: 型7 では補正なしで Cash context の標準値を使います。strong バンド (60%) でベット推奨、mid バンド以下はチェック寄りです。ペア低ボードでは trips (MV=8) の評価が特に重要で、TV=8 (strong) として 60% でベット推奨となります。

## ナッツアドバンテージの読み方と A モデル への接続

7 つの型とナッツアドバンテージの関係をまとめます。

**SB 有利型** (型1・型2・型6): SB は strong/nut バンドで積極的にベット。mid 以下もボード次第でベット検討。

**BB 有利型** (型3・型4): IP の mid バンド以下はチェックバックを積極的に選ぶ。BB のチェックレイズに備える。

**境界型** (型5・型7): 標準値を参考にしつつ、型5 (cash) では -1 段階の控えめ補正を加える。

ナッツアドバンテージを読む習慣をつけると、A モデルの信頼度補正が自然に適用できるようになります。型判定に 3 秒、TV 計算に 4 秒、合計 7 秒以内で判断を完了することが目標です。

2. DP = **0** (ドローなし)

## GTO とのズレ — 型判定の限界

型1-7 の判定は 3 要素 (トップカード・テクスチャ・ペア) で決まりますが、実際のボード評価はより複雑です。

第 1 の限界は「キッカー依存の省略」です。例えば型1 ボードでも K♠7♦2♣ と A♠7♦2♣ では、SB の top_pair の強さが異なります。A-high ボードの top_pair はキッカーが常に弱く、GTO 上は bet freq が低めになる場合があります。型判定ではこの差を省略しています。

第 2 の限界は「スーツの組み合わせ省略」です。型2 (ハイウェット) の中でも、ナッツフラッシュドローを IP が持ちやすいボード vs BB が持ちやすいボードでは判断が変わります。型判定は平均的な近似です。

これらの限界を理解した上で、型判定を「3 秒で大枠を確定する道具」として使うことが重要です。細かな調整は経験と Vol3 (旧 5 軸モデル) で補完します。
