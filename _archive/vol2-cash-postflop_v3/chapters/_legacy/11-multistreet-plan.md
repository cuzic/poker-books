# 第11章　マルチストリートプランの設計

フロップのCBet判断を「1手ごとの選択」として捉えると、全体の設計が崩れます。
ポストフロップはフロップ・ターン・リバーの連続した3ストリートであり、最初の一手がその後の展開を決める「設計図」を必要とします。
本章では、GTO Wizardのデータを使ってマルチストリートプランを設計する方法と、プリフロップの状況が設計にどう影響するかを体系化します。

## 11-1　GTO Wizardでマルチストリートを調べる方法

GTO Wizardのスポットソリューションは、フロップ・ターン・リバーを別々に調べる形になっています。
マルチストリートの設計をするためには、「フロップで何が起きたか」をAPIに伝えてターンを調べる、という連鎖クエリが必要です。

### APIパラメーターの連鎖構造

| パラメーター | フロップ調査 | ターン調査 | リバー調査 |
|------------|-----------|---------|---------|
| `board` | `Ks7d2c`（3枚） | `Ks7d2cTh`（4枚） | `Ks7d2cThAs`（5枚） |
| `flop_actions` | `X`（BBチェック後BTN） | `X-R1.8-C`（CBet→コール） | `X-R1.8-C`（同） |
| `turn_actions` | ― | `X`（BBチェック後BTN） | `X-R{size}-C`（バレル→コール） |
| `river_actions` | ― | ― | `X`（BBチェック後BTN） |

重要な点が3つあります。第一に、`board`パラメーターにターンカードを追加することで、そのターンカードが出た前提のソリューションが返ります。第二に、`flop_actions`は過去に起きたフロップでのアクションをそのまま引き継ぎます。第三に、アクションコードは実際にAPIが返したコードを使う必要があります（例: 33%ベットは`R1.8`、116%ベットは`R6.4`）。

### 効率的なマルチストリート調査の手順

実際の調査では次の手順が効率的です。

**Step 1: フロップ先手（IP）の戦略を確認する**

```
board=Ks7d2c, flop_actions=X
→ BTNのCBet率・使用サイズ・hand_category別ベット率を記録
```

**Step 2: フロップ後手（OOP）の応答を確認する**

```
board=Ks7d2c, flop_actions=X-R1.8
→ BBのFold/Call/Raise率をhand_category別に記録
```

**Step 3: ターンカード別のIP戦略を確認する**

```
board=Ks7d2cTh, flop_actions=X-R1.8-C, turn_actions=X
→ BTNのターンバレル率をhand_category別に記録
（複数のターンカードで繰り返す）
```

**Step 4: OOPのターン戦略を確認する**

```
board=Ks7d2cTh, flop_actions=X-R1.8-C, turn_actions=
→ BBのターン先手行動（リード/チェック）をhand_category別に記録
```

このStepを3〜4ターンカードで繰り返すと、そのフロップ上でのIP・OOP双方のマルチストリートプランが見えてきます。

### トークン制限への対処

GTO WizardのAPIトークンは通常15分で期限切れになります。
14ボード（各型2ボード）×4ターンカード×2ストリーム（IP・OOP）= 約112クエリが必要で、1秒/クエリとして約2分かかります。
1トークン15分の制約内でも十分収まりますが、「フロップ戦略確認（7クエリ）→フロップ守備確認（7クエリ）→ターンクエリ（残り時間）」という優先順位で進めるのが安全です。

## 11-2　BBコールレンジの正体：フロップ守備データから読む

マルチストリート計画で最も重要な情報は「フロップで相手がコールしたとき、相手のレンジは何か」です。
GTOデータからBBのフロップコールレンジを分析すると、ボード型によって大きく性質が変わります。

### 型1ハイドライ（Ks7d2c）: 上位ハンドは消える

BTNが33%でCBetした後、BBのコール率は次のようになります。

| hand_category | コンボ | Fold% | Call% | Raise% |
|--------------|-------|------|------|-------|
| set（セット） | 5.8 | 0% | 25% | **75%** |
| two_pair | 2.0 | 0% | 0% | **100%** |
| top_pair | 44.3 | 0% | **94%** | 6% |
| second_pair | 29.3 | 0% | **97%** | 3% |
| third_pair | 24.4 | 0% | **99%** | 1% |
| ace_high | 83.6 | 19% | **74%** | 7% |
| no_made_hand | 117.7 | **65%** | 24% | 11% |

セット・2ペアはほぼ全てレイズで除去されます。BBのコールレンジは「トップペア主体 + ミドルペア + 一部エースハイ」という構成です。
BBがコールしたとき、相手がセット・2ペアを持つ可能性は極めて低いのです。

**ターンへの含意:** BTNはBBのコールレンジがトップペア以下であると分かった上でターンに進みます。BBを2ndペアや3rdペアが大量に占めており、これらはほとんどのターンカードで改善しません。

### 型4ローウェット（Th9s8d）: 上位ハンドが残る

| hand_category | コンボ | Fold% | Call% | Raise% |
|--------------|-------|------|------|-------|
| set | 5.5 | 0% | **65%** | 35% |
| straight | 16.6 | 0% | **70%** | 30% |
| two_pair | 8.7 | 0% | **84%** | 16% |
| top_pair | 38.2 | 0% | **96%** | 4% |
| second_pair | 38.4 | 0% | **97%** | 3% |
| third_pair | 27.7 | 2% | **95%** | 3% |
| low_pair | 32.3 | **71%** | 29% | 0% |
| ace_high | 53.4 | 47% | **49%** | 4% |

型4では、セット・ストレート・2ペアがコールで残ります。BBのコールレンジは型1より強く、かつ多様です。
ストレートドロー（未完成）も大量に含まれており、ターンカードによっては一気に完成します。

**ターンへの含意:** BBのコールレンジに「隠れた強いハンド」が存在するため、BTNはターンでのバレルを慎重に選択する必要があります。連続するターンカード（例: 6が来てストレート完成）ではBBのレンジが大幅に強化されます。

### 型3ロードライ（Jd7s5c）: ビッグベットが守備レンジを絞る

型3では116%（R6.4）のビッグベットを使用します。その結果、BBのコールレンジが大きく絞られます。

| hand_category | Fold% | Call% | Raise% |
|--------------|------|------|-------|
| set | 0% | 33% | **67%** |
| two_pair | 0% | 41% | **59%** |
| top_pair | 0% | **92%** | 8% |
| second_pair | 3% | **86%** | 11% |
| underpair | **46%** | 54% | 0% |
| ace_high | **96%** | 4% | 0% |
| no_made_hand | **58%** | 32% | 11% |

エースハイが96%フォールドし、アンダーペアも46%フォールドします。BBのコールレンジは「トップペア + セカンドペア + 一部のナッツドロー」に絞られています。
ビッグベットサイズが相手を強制的に選別するため、ターンに残るBBのレンジは質が高いのです。

**ターンへの含意:** ビッグベットで相手を絞った後は、ターンでバレルしても相手のコールレンジが強固です。型3でのターン戦略は「フォールドエクイティが低い」前提で設計します。

## 11-3　フロップ→ターン：ボード型別IPマルチストリートプラン

フロップCBetの結果とBBのコールレンジを踏まえて、ターンの方針を定めます。

### 型1ハイドライ：攻撃的なターンバレル

フロップCBet後、BBのコールレンジはトップペア（KQ/KJ等）中心です。

**ターンバレルの原則:**

| ターンカード | BBへの影響 | IP方針 | 判定 |
|-----------|----------|-------|-----|
| 7h（2ndペアペア） | BBのKxは改善しない | バレル継続 | **TA+** |
| 2c（3rdペアペア） | BBのKxは改善しない | バレル継続 | **TA+** |
| Ah（オーバーカード） | BBのA-highが改善（→Aトップペア） | チェック | **TA-** |
| Th（ブランク高め） | 若干BBのQTなどが改善 | チェック気味 | **TA-** |
| Kh（1stペアペア） | BBのKxが強化される | チェック | **TA-** |

型1でBBがコールした最大の理由はKxトップペアです。2ndカード（7）や3rdカード（2）がペアになっても、KxはKxのままです。一方、Aceターンはエースハイでコールしていたハンドがトップペアに化けるため、BBのレンジが全体的に強化されます。

**ハンド別ターン計画:**
- **バリュー（HS≥65）**: TA+でもTA-でもバレル（ターンでも優位）
- **マージナル（HS 35-64）**: TA+のみ薄いバレル、TA-はチェックバック（SDV）
- **エアー（HS<35）**: TA+でのみブラフバレル候補、TA-は諦め

### 型4ローウェット：慎重なターン管理

BBのコールレンジにセット・ストレート・2ペアが含まれているため、型4のターンは特に注意が必要です。

**危険なターンカード（TA-）:**

- **ストレート完成ターン**: 6（7-6-5ストレート）や5（9-8-7ストレート等）
  → BBの大量のドローが完成。BTNは降りるか小サイズで値踏み
- **フラッシュ完成ターン**: フロップに2トーンがある場合、フラッシュスーツのカード
  → BBのフラッシュドローが完成。BTNはほぼチェック

**有利なターンカード（TA+）:**

- **オフスーツブランク（例: Ac）**: 新しいドローが生まれず、BBの未完成ドローが焦る
  → BTNは中程度のバレル
- **ペアターン（例: Th）**: T9s8dでTが出ると、BBのセット以外は改善しない
  → BTNはバリューで継続

型4の基本方針は「ブランクターンでのみ継続、ドロー完成ターンは諦め」です。

### 型7ペア低：独特なマルチストリート

型7（7s7d2c等）ではBBがマージナル（アンダーペア・セカンドペア）でも頻繁にレイズします（42%）。
これはBBが「7のない状態でアンダーペアを持つ = 実質的に有利」と判断するためです。

| BBのaction | 意味 |
|-----------|-----|
| Raise（42%マージナルで） | BBはオーバーペアや強いフォールドエクイティを主張 |
| Call（58%マージナルで） | BBはセカンドペア・アンダーペアでショーダウン狙い |

BTNのターン計画では、BBのレイズが多かったため「コールレンジは中程度のハンドで占められている」と推測します。
ターンのバレルは、型1同様TA+中心で継続します。

## 11-4　フロップ→ターン：OOPのマルチストリートプラン

BBがフロップCBetをコールした後、ターンでの行動方針を設計します。

### OOPターン行動の3択

| アクション | 条件 | 目的 |
|----------|-----|-----|
| **リードベット** | ターンで大きく改善した（ドロー完成、2ペア化等） | バリューの獲得・BTNのチェックバックを防ぐ |
| **チェック-コール** | 中程度のハンドを維持（トップペア等） | ショーダウンバリューの確保 |
| **チェック-レイズ** | ターンで最強ハンドに改善 | プロテクション + バリュー |
| **チェック-フォールド** | ターンでも改善なし、エクイティ低下 | 損失の最小化 |

### ボード型別OOPターン方針

**型1（Ks7d2c）でコール後のOOP:**

BBのコールレンジはトップペア（Kx）主体です。ターンカードによって次のように変わります。

- **TA+ターン（7h等）**: BTNがバレルしてきたら、Kxトップペアでチェック-コール。BBのKxはターンでも維持。ドローは少ないが、コールして粘る。
- **TA-ターン（Ah等）**: エースハイでコールしていたBBは一気にトップペアに格上げ。チェック-コールではなくチェック-レイズを検討（→改善したことを行動で示す）。

**型4（Th9s8d）でコール後のOOP:**

BBはストレート・2ペア・ドローを持っています。ターンが完成系なら強気に出ます。

- **ドロー完成ターン**: ストレートやフラッシュが完成 → リードベットでポットを膨らませる。BTNはチェックバックすることが多いため、リードが有効。
- **ブランクターン**: 改善なし → チェック-コールで維持。BTNのバレルにはコールで付き合い、リバーを見る。

### OOPリードベットの条件

OOP（BB）がターンでリードベットを選ぶのは次の条件が揃ったときです。

1. **ドロー完成**: フロップのドローがターンで完成した（フラッシュ・ストレート）
2. **トリップスへの改善**: ペアボードでトリップスに化けた
3. **BTNのチェックバックが予想される**: TA-のターンでBTNがチェックすると読める場合
4. **ポットを大きくしたい**: コールよりリードの方が期待値が高い強いハンド

型4・型5ではOOPリードが有効になるケースが多く、型1・型6ではOOPがリードする機会は少なくなります。

## 11-5　プリフロップ状況別の設計図

ポストフロップ戦略はプリフロップ状況によって大きく変わります。同じフロップでも、自分のポジションと行動履歴で使えるレンジが異なるからです。

### ① IP先手（自分がレイズして相手がコール）

最も一般的なパターン（BTN open vs BB call等）です。

- **フロップ**: レンジアドバンテージ大 → レンジベット型（型1/2/6/7）で全レンジ33%CBet
- **ターン**: TA+のみバレル、TA-はSDVチェックバック
- **リバー**: バリュー（HS≥65）でベット、ブラフは第9章αで選別

**期待するターンバレル率の目安（SRP型1）:**
- TA+ターン（2ndペアペア等）: 約60%バレル
- TA-ターン（オーバーカード）: 約5%以下のバレル

### ② IP後手（コールドコールして後から選択権を得た）

例: CO open → BTN cold call。BTNはIPだがレンジアドバンテージがない（COのレンジと重なる部分が多い）。

- **フロップ**: レンジアドバンテージが不明瞭 → チェックバック率が上がる
- 型1・型2でも全レンジCBetにはならず、バリュー中心のCBetに近づく
- **ターン**: IPの優位は残るため、チェックバック後の改善ターンでのプローブが有効

コールドコール後のIPは「ポジションを活かす」戦略が中心です。フロップで相手のチェックを誘い、ターンで改善したときにベットするプランが成立します。

### ③ OOP後手（BBとして先手IPのCBetに対応）

第6章のディフェンス体系（MDF・HS閾値）の延長線上です。

- **フロップ**: Fold（HS<閾値）/ Call（HS≥閾値）/ CR（ナッツ帯）
- **ターン**: コール後は本章のOOPターンプランを適用
- 改善したらリードベット、維持ならチェック-コール、改善なしでチェック-フォールド

**SRP 33%CBetに対するOOPフォールド閾値（ボード型別）:**

| ボード型 | フォールド基準 | 根拠 |
|---------|-------------|-----|
| 型1ハイドライ | HS < 20（エアーの65%をフォールド） | MDF 75%を概ね満たす |
| 型2ハイウェット | HS < 20 | ドロー含むため実質やや緩い |
| 型3ロードライ | HS < 40（マージナルも一部フォールド） | 116%ビッグベットのためMDF 50%基準 |
| 型4ローウェット | HS < 25（low_pairをフォールド） | ドロー多いため実質コール帯が広い |
| 型5モノトーン | HS < 20 | フラッシュドローが実質コール帯 |
| 型6ペア高 | HS < 20（no_made_handを多くフォールド） | AAKでは純エアーが多い |
| 型7ペア低 | HS < 20（king_high以上は概ねディフェンス） | ペアボードでのエアー処理 |

## 11-6　マルチストリート研究の継続方法

本書のデータは代表ボード各1枚から得たものです。実戦ではより多くのボード・状況を研究することが重要です。

### 自主研究のチェックリスト

GTO Wizardで1つのフロップを完全に研究するには、次のステップを踏みます。

**フロップ研究（約5分）:**
- [ ] `flop_actions=X` でIPのCBet戦略を確認（全hand_category別ベット率）
- [ ] `flop_actions=X-R{code}` でOOPの守備戦略を確認（Fold/Call/Raise率）
- [ ] CBet率・使用サイズ・ナッツ帯の行動を記録

**ターン研究（約10分）:**
- [ ] `board={flop}+{turn_blank}` でブランクターンのIP戦略を確認
- [ ] `board={flop}+{turn_TA+}` でTA+ターンのIP戦略を確認
- [ ] `board={flop}+{turn_danger}` で危険ターン（ドロー完成等）のIP戦略を確認
- [ ] OOPのターン先手行動（turn_actions="")も同様に確認

**リバー研究（約10分）:**
- 第9章のαを計算し、バリュー/ブラフ比率をGTO実測と比較

合計25分で1フロップのマルチストリート戦略が完成します。7型×代表1ボード = 7回分で書籍の基礎データが完成します。

---

### まとめ

- GTO Wizardのマルチストリート調査は「`flop_actions`の引き継ぎ + `board`にターンカード追加」で実現できる
- BBのフロップコールレンジはボード型によって大きく異なり、ターン計画の基礎になる
- 型1・2ドライ系: BBコールはトップペア主体 → TA+ターンのみバレル
- 型4・5ウェット系: BBコールに強いハンドが残る → ドロー完成ターンは危険
- OOPは「改善したらリード、維持はチェック-コール、改善なしはフォールド」の3択
- プリフロップ状況（IP先手/IP後手/OOP後手）でフロップのアプローチが変わる

---

### 【GTOとのズレ】

本章で示したターンバレル率（型1 TA+で60%、TA-で5%以下）は代表ボード1枚から得たものです。
実際のターンバレル率はフロップ上のコールレンジの具体的な構成によって±10〜15%ブレます。
特に「2ndカードが何か」によってTA+の強度が変わります（K-**7**-2のような場合の7ターン vs K-**9**-2の9ターンでは、9の方がBBに刺さりやすい）。
OOPリードベットの判断は、本書のリードベット条件（ドロー完成・トリップス改善等）を目安にしつつ、特定ボードでのGTO実測との差を研究で補完してください。
