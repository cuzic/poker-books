# 第10章　バリュー/ブラフ配分

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバーでのバリュー/ブラフの最適比率を公式で理解し、暗算で使えるようにする。Alpha 式でブラフ頻度を決定できるようになる。

---

## 10-1 リバーの根本原理

リバーは「エクイティが確定する」ストリートです。

フロップやターンでは「ドローがあるから戦える」がありました。リバーでは、手を見せた瞬間に勝ち負けが決まります。

この性質から、リバーのベットは純粋に 2 種類しかありません:

```
バリューベット: 相手の弱いハンドにコールしてもらう
ブラフ:        相手の強いハンドを降ろす
```

「薄いバリュー」「スロープレイ」「インダクション」は全てこの 2 種類のどちらかです。

---

## 10-2 Alpha 式: ブラフの損益分岐点

### Alpha の定義

```
α (alpha) = ベット / (ポット + ベット)
```

Alpha は「ブラフが利益を出すための最低フォールド頻度」です。

相手が α より高い頻度でフォールドするなら、ブラフは利益が出ます。
相手が α より低い頻度でフォールドするなら、ブラフは損です。

### ベットサイズ別 Alpha 値

| ベットサイズ | Alpha (最低フォールド必要率) | MDF (相手の最低コール率) |
|---|---|---|
| 25% pot | 20% | 80% |
| 33% pot | 25% | 75% |
| 50% pot | 33% | 67% |
| 75% pot | 43% | 57% |
| 100% pot | 50% | 50% |
| 125% pot (OB) | 56% | 44% |
| 150% pot (OB) | 60% | 40% |

> **実戦的解釈**: 相手がフォールドする頻度が alpha より高ければ、どんなハンドでもベットが有利。相手が全くフォールドしないなら、バリューハンドだけがベット対象。

---

## 10-3 最適バリュー/ブラフ比率

### 公式

```
最適ブラフ比率 = α = ベット / (ポット + ベット)
最適バリュー比率 = 1 - α = ポット / (ポット + ベット)
```

### ベットサイズ別 V:B 比率表

| ベットサイズ | バリュー % | ブラフ % | V:B 比率 |
|---|---|---|---|
| 33% pot | 75% | 25% | 3:1 |
| 50% pot | 67% | 33% | 2:1 |
| 75% pot | 57% | 43% | 1.3:1 |
| 100% pot | 50% | 50% | 1:1 |
| 150% pot (OB) | 40% | 60% | 2:3 |

> **重要ポイント**: ベットサイズが大きいほど、ブラフが多くなります。オーバーベット (150% pot) では、ブラフがバリューより多い比率になります。

---

## 10-4 「50% の法則」: バリューベットの基準

**バリューベットは「コールされても 50% 以上の確率で勝てるとき」に成立します。**

これはベットサイズに関わらず一定です。

例:
- AK でトップペアトップキッカー → 相手のコールレンジの多くに勝てる → バリューベット OK
- Q♦J♦ でミドルペア → 相手のコールレンジの半分以下にしか勝てない → ブラフまたはチェック

### 「薄いバリュー」の判断

「コールされたとき 50〜60% 勝てる」ハンドは「薄いバリュー」です。

薄いバリューは:
- 小サイズ (33% pot) で有効
- 大サイズ (100% pot) では非推奨 (相手のコールレンジが絞れる)

---

## 10-5 3 ストリート マルチバレルの設計

フロップ → ターン → リバーで同じサイズを継続する場合、各ストリートで必要なバリュー/ブラフ比率は変化します。

### 75% ポットで 3 ストリート継続する場合

| ストリート | バリュー比率 | ブラフ比率 |
|---|---|---|
| フロップ | 34% | 66% |
| ターン | 49% | 51% |
| リバー | 70% | 30% |

> **実戦的意味**: フロップではブラフがバリューの 2 倍。ターンでほぼ同比率。リバーではバリューがブラフの 2 倍以上。ブラフを絞っていくイメージです。

### 計算例 (100BB, 標準的な 1/3 → 2/3 → ポット ライン)

```
フロップ pot = 7BB, CBet 1/3 (2.3BB) → pot = 11.6BB
ターン CBet 2/3 (7.7BB) → pot = 27BB
リバー pot = 27BB, stack ≈ 80BB 残
```

リバーでオールイン (30BB 弱のポットに 27BB ベット ≈ 100% pot) なら:
- バリュー 50%, ブラフ 50% が均衡

## 10-6 ボードタイプ別のバリュー/ブラフ戦略

### ドライ・スタティックボード (K72r → turn → river)

**特徴**: 相手のコールレンジがシンプル。フラッシュドローなし。

**推奨戦略**:
- 主ベットサイズ: 33〜50% ポット
- バリュー比率: 70〜80%
- ブラフ: 純ブラフ (完全空振り) のみ

**理由**: ドライボードでは相手の弱いコールが取れる。大サイズは相手がフォールドしすぎてブラフしか得しない。

---

### セミウェット (KT5ss → turn → river)

**特徴**: フラッシュドロー完成あり。バックドアドロー完成あり。

**推奨戦略**:
- 主ベットサイズ: 50〜75% ポット
- バリュー比率: 57〜67%
- ブラフ: 失敗したドロー系

**理由**: ドロー完成ハンドのバリューが大きい。完成しなかったドローはブラフになる。

---

### ウェット・連結ボード (987ss → turn → river)

**特徴**: ストレート・フラッシュが多く完成。誰が「最強」か分かりにくい。

**推奨戦略**:
- 主ベットサイズ: 75〜150% ポット (オーバーベット含む)
- バリュー比率: 40〜57% (オーバーベットでは低い)
- ブラフ: ブロッカーを持つ強ブラフ

**理由**: ナッツアドバンテージがある側がオーバーベットで圧力をかける。

---

## 10-7 リバーの「チェック → レイズ」分析

チェックレイズはリバーで特に効果的です。

### バリューチェックレイズ

**条件**:
1. 相手が必ずベットしてくる確信がある
2. 自分がナッツ以上のハンドを持つ

**計算例**:
- ポット 20BB、自分チェック → 相手 12BB ベット → 自分チェックレイズ 30BB
- 自分のリターン: コールされれば 30+12+12 = 54BB 獲得 (20BB から 2.7 倍)
- チェックベットより大きいポットが作れる

### ブラフチェックレイズ

**条件**:
1. 自分のハンドが相手のバリューレンジのブロッカーを持つ
2. 相手がベットレンジを多くのブラフで構成している

**注意**: ブラフチェックレイズは難易度が高い。必要なのは相手のベットへの正確なリードです。

## 10-8 ポラライズレンジの組み立て方

### ステップ 1: バリューハンドを確定する

リバーで「コールされて勝てる」ハンドをリストアップします。

```
例: ボード K♥T♠5♦ A♣ 2♠

バリューハンドの候補:
  ナッツ〜準ナッツ: AA（セット）, AK（2ペア）, KK（セット）, KA（同）
  強バリュー: AT（2ペア）, AK（トップ2ペア）
  薄バリュー: KQ, KJ（トップペア強キッカー）

「50%ルール」チェック:
  AK の 2ペア: BB のコールレンジに負ける手が何%? → ほぼ AA セットのみ → 99%+ 勝ち → バリュー確定
  KQ: BB のコールレンジに AK・AT・AA が多い場合 → 勝率 60% 程度 → 薄バリュー
```

### ステップ 2: ブラフ候補を選ぶ

リバーで完成しなかったドローや完全に負けているハンドの中から、「ブロッカー効果」で有効なものを選びます。

```
ブラフ候補の評価基準:
  1. ブロッカー効果: 相手のナッツハンドを阻害するか
  2. アンブロッカー効果: 相手の弱いコールハンドを「アンブロック」するか
  3. 役の可能性: 弱い役（ミドルペア等）は「ブラフ」ではなく「チェック」が多い

例: ボード K♥T♠5♦ A♣ 2♠ での良いブラフ候補
  QJ（完成したストレートドローが外れた）: Q・J でキッカー弱い → ブラフとして合理的
  JT（ミドルペア）: ベットすると強いハンドのみコールされるリスク → チェックバック推奨
  6♦5♦（バスタード FD）: A2 でダイヤFD 外れ → アンブロックして BB の弱いコールを引き出す
```

### ステップ 3: V:B 比率を確認する

```
例: ポット 20BB, ベット 15BB（75% ポット）
  Alpha = 15/(20+15) = 43% → ブラフ: 43%、バリュー: 57%

バリューハンド 7 コンボ + ブラフ 5 コンボ = 合計 12 コンボ
比率: 7:5 ≈ 58%:42% ≈ 均衡に近い

→ OK（多少のズレは許容範囲）
```

## 10-9 ブラフ候補の優先順位

すべての「負けハンド」がブラフになるわけではありません。優先度をつけます。

| 優先度 | ブラフ候補のタイプ | 理由 |
|---|---|---|
| **最優先** | ナッツブロッカー持ち（Aハイ等でボードの最強ランクをブロック） | 相手のコールが減る |
| **高** | 外れたフラッシュドロー（特にナッツFD外れ） | 「ブラフとしての説得力」がある |
| **中** | 外れたストレートドロー | フォールドしてくれやすい |
| **低** | 弱いミドルペア（あわよくばショーダウン勝ちを狙える）| チェックバックの方が多くの場合 EV+|
| **非推奨** | 「なんとなく弱い」ブランクハンド | 機能するシナリオが少ない |

**実践ポイント**: リバーのブラフは「相手の強いハンドをブロックしつつ、相手の弱いコールをアンブロックする」ハンドが最高です（詳細は第11章のブロッカー論）。

## 10-10 実戦計算: Alpha 式の暗算トレーニング

以下の各状況で「ブラフが有利か不利か」を暗算してみましょう。

**問題 A**: ポット 24BB、ブラフで 12BB ベット（50%ポット）。相手がフォールドする頻度を 40% と推定。ブラフは有利か？

```
Alpha = 12/(24+12) = 33%
相手のフォールド率 40% > Alpha 33% → ブラフ有利（EV+）
```

**問題 B**: ポット 30BB、ブラフで 30BB ベット（100%ポット）。相手フォールド率 45% と推定。

```
Alpha = 30/(30+30) = 50%
相手のフォールド率 45% < Alpha 50% → ブラフ不利（EV−）
→ チェックか、サイズを 75% 以下に下げる
```

**問題 C**: ポット 15BB、ブラフで 22BB ベット（150%ポット = OB）。相手フォールド率 65% と推定。

```
Alpha = 22/(15+22) = 59%
相手のフォールド率 65% > Alpha 59% → ブラフ有利（EV+）
→ オーバーベットブラフが成立する
```

## ミニクイズ

### 問1

ポット 20BB、相手が 10BB ベット（50%ポット）。MDF（相手の最低防御頻度）はいくつですか。

1. 40%
2. 50%
3. 67%

### 問2

75% ポットサイズでバリューベットするとき、最適な V:B 比率（バリュー:ブラフ）はどれですか。

1. 3:1（バリュー 75%、ブラフ 25%）
2. 1.3:1（バリュー 57%、ブラフ 43%）
3. 1:1（バリュー 50%、ブラフ 50%）

---

### 解答

- **問1**: 3（Alpha = 10/(20+10) = 33%, MDF = 1 - 0.33 = **67%**）
- **問2**: 2（75%ポットの Alpha = 75/(100+75) = 43% → バリュー 57%、ブラフ 43% → 比率 **1.3:1**）

---

> **本章まとめ**
>
> - Alpha = ベット / (ポット + ベット) がブラフの損益分岐点
> - MDF = 1 - Alpha が相手の最低防御頻度
> - バリューベットの必要条件: コールされて 50% 以上の確率で勝てること
> - V:B 比率はベットサイズが大きいほどブラフが増える (OB では B > V)
> - マルチバレルでは、リバーに進むほどバリュー比率が上がる

---

**【GTO とのズレ】**

本章で示した V:B 比率は「均衡ブラフ頻度」の理論値です。

実戦では:
- 相手がフォールドしすぎていれば、ブラフを増やす (搾取)
- 相手が全くフォールドしなければ、ブラフを減らしバリューに絞る

GTO は「均衡点を知る」ためのベースライン。実戦では相手の傾向を読んでデビエートします。
