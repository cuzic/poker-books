# 第26章　マルチウェイポットのターン・リバー

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 3人以上のマルチウェイポットでのターン・リバー戦略を理解し、ヘッズアップとの違いを判断基準に組み込む。

---

## 26-1 マルチウェイとは何か

マルチウェイポットとは、3人以上のプレイヤーがフロップ以降も参加しているポットです。

```
ヘッズアップ (HU): 2人 → 本書の第1〜25章で扱った
3way: 3人 → 本章の主対象
4way+: 4人以上 → さらに調整が必要 (本章では 3way を中心に解説)
```

6-max キャッシュゲームでは、フロップを 3way 以上で迎えることは全体の 20-30% 程度あります。ヘッズアップと同じ判断をすると大きなミスにつながります。

---

## 26-2 マルチウェイでバリューラインが上がる理由

### 複数の相手とのハンド強度の関係

```
ヘッズアップ (HU):
  相手 1 人のレンジに対して 50% 以上勝てるか → バリューベット

3way:
  相手 2 人のレンジに対して「最強」である確率が必要
  P(HU バリュー) = 50%
  P(3way バリュー) = P(AよりもBに勝つ) × P(AよりもCに勝つ)
                  ≈ 50% × 50% = 25% (独立とした場合の粗い計算)

  → 実際には相関があるが、マルチウェイはバリューの「閾値が上がる」
```

### 実践的なバリューライン

| プレイヤー数 | 最低バリューライン | 大ベットライン |
|---|---|---|
| HU | トップペア (状況依存) | 2ペア以上 |
| 3way | 2ペア以上 | セット以上 |
| 4way+ | セット以上 | ストレート/フラッシュ以上 |

> **シンプルルール**: プレイヤーが増えるほど、バリューベットには1段階強いハンドが必要になる。

---

## 26-3 マルチウェイでブラフ頻度が下がる理由

ヘッズアップではブラフが有効ですが、マルチウェイでは成功率が低下します。

### ブラフの成功率計算

```
ブラフ成功 = 全員がフォールドすること

HU (相手 1 人がフォールド確率 60%):
  成功率 = 60%

3way (各相手が 60% フォールドする場合):
  成功率 = 60% × 60% = 36%

4way:
  成功率 = 60% × 60% × 60% = 21.6%
```

「1人ずつが 60% フォールドしてくれる」状況でも、3way だと成功率が 36% まで下がります。ブラフのコストが同じなら EV が下がります。

### マルチウェイでのブラフの基準

```
HU のブラフ: フォールドエクイティがコストを超えれば有効
3way のブラフ: 全員フォールドの確率 × ポット ≥ ベット額

実戦的判断:
  3way 以上でのピュアブラフ (ドローなし) は基本的に避ける
  セミブラフ (ドロー + ブラフ) は一定有効 (完成すれば全員に勝てる)
```

---

## 26-4 マルチウェイのポジション影響

マルチウェイではポジションがさらに重要になります。

### 3way でのポジション関係

```
例: CO、BTN、BB の 3way

CO: OOP (先手) → 毎ストリートで最初にアクション
BTN: 中間 (CO 後、BB 前) → CO のアクション後に判断
BB: OOP (先手、ポジションは最悪) → フロップ以降は最初か2番目

BTN が最も有利: CO と BB の両方のアクションを見てから判断できる
```

### IP (BTN) の 3way CBet 戦略

```
3way で BTN が CBet する場合:

  CO がチェックした後 BTN がベット: 1人だけチェックした = 比較的安全
  CO もベットしてきた場合: BTN は強いハンドでのコールorレイズに絞る

  BTN のマルチウェイ CBet 頻度:
    HU: ~65% (ドライ板)
    3way: ~45% (同じドライ板)
    
    → 3way では CBet 頻度が下がる。弱いハンドでの「とりあえず CBet」は損
```

---

## 26-5 3way でのチェックとベットの使い分け

### チェックが多くなる状況

```
マルチウェイでのチェック増加:

1. 薄いバリュー (トップペア等):
   → 2人のコールレンジに「自分に勝てるハンドが多い」
   → ベットすると逆選択が起きやすい

2. ドロー系ハンド:
   → 3way ではドローを引き続けているプレイヤーが複数いる可能性
   → セミブラフのコストが増える

3. ブラフキャッチャー:
   → 2人のベットレンジを読むのが難しい
   → チェックで様子を見る
```

### ベットが有効な状況

```
マルチウェイで積極的にベット:

1. 強いバリュー (セット以上):
   → 複数のコールを取れる可能性がある
   → ポット保護 (ドローに安くは見せない)
   
2. ナッツドロー (フラッシュドロー + OESD 等):
   → 完成すれば全員に勝てる可能性
   → セミブラフとして機能

3. フォールドエクイティが高い場面:
   → 全員が弱そうな状況 + 自分のブロッカーが機能する場合
```

---

## 26-6 マルチウェイのリバー判断

### リバーバリューラインの確認

```
3way リバーでの判断:

バリューベット (小-中サイズ):
  2ペア以上 → コールを引き出せる確率が高い
  
バリューベット (大サイズ / OB):
  セット以上 → 1人だけのコールでも大きいポットを取れる

チェックバック:
  トップペア 1 ペア以下 → バリューベットとしては弱すぎる

ブラフ:
  基本的に避ける (全員フォールドの確率が低い)
```

### 3way リバーでのコール基準

```
相手 (または複数の相手) がリバーベット:

コールの基準:
  1人がベット: HU と同じ計算 (ブラフ率 > コールオッズ)
  2人がベット (1人ベット + 1人コール): コールしてくる相手は強い
    → バリューレンジが非常に絞れる
    → より強いハンドでのみコール

「ダブルバレルを 3way でコール→コール→コールした」:
  相手は確実にショーダウンバリューがある
  → リバーのブラフキャッチはほぼ不要 (相手のブラフ率が低い)
```

---

## 26-7 マルチウェイでよくある失敗パターン

### 失敗 1: 3way で 1ペアで大きくベット

```
HU では「トップペアで 75% バリューベット」が正解でも、
3way では逆選択が二重に働く。

例: 3way で KQ on K72r でのベット
  1人がコール → その1人の Kx の多くは KQ より良いキッカー
  もう1人もコール → さらに強い
  → KQ はコールレンジのほとんどに負ける

  → 3way でのトップペアはチェックバック or 33% ブロッキングベット
```

### 失敗 2: 3way でのブラフバレル

```
HU ではブラフが有効でも 3way では:
  全員フォールド確率 = 60% × 60% = 36%
  
  ブラフコスト: ポット × ベット率
  期待値: 成功率 36% × ポット − 失敗率 64% × ベット額
  
  多くの場合で EV マイナス
  → 3way でのピュアブラフは避ける
```

### 失敗 3: マルチウェイで全員のアクションを無視する

```
1人の相手の「コール」は弱さのシグナルにならない (もう1人がいる)
2人の「コールコール」は非常に強いシグナル

3way でのプレイ中に「この相手はどう読むか」に集中しすぎて
もう1人の情報を見落とすことがある

→ 全員のアクションを常に追跡すること
```

## 26-8 3way 実戦例

### 例 1: BTN の強バリューベット

**ボード**: K♦7♣2♠ (3way: CO, BTN, BB)
**ターン**: A♥
**BTN ハンド**: A♠K♠ (2ペア)

```
3way でのターンバレル:

バリュー候補:
  AK はこのボードでトップ2ペア
  CO, BB のレンジに対してほとんど勝てる (AA のみ負け)

  3way では 2ペアは十分なバリュー → ベット
  サイズ: 50-75% (全員からコールを引き出したい)

  ただし AA が怖い場合は 50% に控えめにして様子見
```

### 例 2: 3way でのチェックバック選択

**ボード**: J♠T♦9♣ (3way: SB, BTN, BB)
**ターン**: 8♣ (コネクター: ストレート多数)
**BTN ハンド**: T♥9♦ (2ペア)

```
3way のウェット板でのバレル:

T9 = 2ペア だが、J-T-9-8 のボードはストレートが豊富:
  Q-J (ストレート = QJT98)
  K-Q (ストレート = KQJT9)
  7-6 (ストレート = 6789T)
  
  SB と BB の両方がストレートを持てる
  BTN のT9 はストレートに全て負ける
  
  → 3way ではチェックバックが安全
    (HU なら一部ベットも検討できるが、3way では 2人のストレートリスクが高い)
```

## ミニクイズ

### 問1

3way ポットでのリバーバリューベットの最低基準はどれですか。

1. トップペア以上 (HU と同じ)
2. 2ペア以上
3. セット以上

### 問2

3way でのブラフ成功率 (各相手が 60% でフォールドする場合) はいくつですか。

1. 60%
2. 36%
3. 20%

### 問3

3way でのフロップ CBet 頻度は HU と比べてどうなりますか。

1. HU と同じ
2. HU より低くなる
3. HU より高くなる

---

### 解答

- **問1**: 2（3way ではバリューラインが1段階上がる。HU でトップペアがバリューでも、3way では 2ペア以上が最低基準。2人のコールレンジに対して「よく勝てる」ためにはより強いハンドが必要）
- **問2**: 2（成功率 = 60% × 60% = **36%**。1人ずつが 60% フォールドしてくれても、全員フォールドの確率は大幅に下がる。これがマルチウェイでのブラフが非効率な数学的根拠）
- **問3**: 2（3way では CBet に対して「弱いコールレンジ」が残る確率が下がる。また、相手のコールレンジ全体が HU より広くなるため、CBet の EV が下がり頻度も下がる）

---

> **本章まとめ**
>
> - マルチウェイでバリューラインが上がる: HU トップペア → 3way 2ペア → 4way セット
> - マルチウェイでブラフが非効率: 全員フォールド確率 = 各フォールド率の積
> - CBet 頻度は 3way で HU の約 70% 程度に下がる
> - リバーのブラフキャッチ: 相手が 3way でコールし続けた = 強いレンジ → ブラフ率低い
> - ポジションはさらに重要: BTN が後手有利、CO/BB は先手の不利が増える

---

**【GTO とのズレ】**

マルチウェイの GTO は特に複雑で、各プレイヤーのレンジ構成が相互に依存するため単純なヘッズアップ理論の拡張では不十分です。

最も重要な「GTO とのズレ」は、マルチウェイで「ヘッズアップの感覚」を使い続けることです。1ペアでのバリューベット、広いブラフ、薄いコールはすべてマルチウェイでは EV が大幅に落ちます。

実戦での安全な方針: **マルチウェイでは「強いハンドのみアグレッション、迷ったらチェック/コール」** を基本にして、慣れてから細かい調整を加えていくことが推奨されます。
