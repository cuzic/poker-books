# 第11章　ブロッカー論

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ブロッカーの概念を理解し、リバーでの「ブラフ選択」と「コール判断」にブロッカー効果を組み込む。

---

## 11-1 ブロッカーとは何か

**ブロッカー** とは、自分の手牌が「相手の特定のハンドを物理的に除外する」効果です。

52 枚のデッキの中で、自分が持っているカードは相手には持てません。

```
例: 自分が A♠ を持つ場合
  → 相手は A♠ を持てない
  → 相手の AA (ポケットエース) の可能性が 1/6 に削減
  → 相手の Axs の可能性が全体的に減る
```

この「相手のレンジを削る」効果がブロッカーです。

---

## 11-2 ブロッカーが重要な 2 つの場面

### 場面 1: ブラフを選ぶとき

リバーでブラフをするとき、**相手のコールレンジをブロックできるカード**を持つハンドがより良いブラフになります。

```
なぜか:
  相手のコールレンジをブロック
  → 相手がコールしてくる確率が下がる
  → ブラフの成功率が上がる
```

**例**: K♦9♦ ボードで K♦ フラッシュが完成し、IP がブラフを検討。

候補ハンド A: A♦5♦ (フラッシュドロー外れ) → Aを持つ
候補ハンド B: 6♦5♦ (フラッシュドロー外れ) → 特定ブロッカーなし

```
A♦5♦: A♦ を持つことで相手の A♦K (ナッツフラッシュ) をブロック
→ 相手の「コールするナッツ」が減る → ブラフ成功率 UP

6♦5♦: 特定のブロッカー効果なし
→ 相手のコールレンジが標準的
```

→ **ブラフには A♦5♦ の方が有利**

### 場面 2: コールするかどうかを決めるとき

相手がバリューベットしてきたとき、**自分が相手のバリューハンドをブロックしていれば、相手のバリュー確率が下がる = ブラフ率が上がる = コールしやすくなる**。

```
例: A♠ ボードで相手が大きくベット。
  自分が A♥ を持つ → 相手の AA をブロック
  → 相手のバリューレンジ (AAを含むナッツ) が削減
  → 相手のベットにブラフが相対的に増える
  → コールが有利になる可能性

逆に、自分が 4♥ を持つ (4 がボードにない場合)
  → 特定のブロッカーなし
  → 相手のバリューレンジに影響なし
  → 標準的なコール判断
```

---

## 11-3 ブロッカー計算の基礎

### ナッツブロッカーとは

「相手がナッツを持つ確率を削減するカード」がナッツブロッカーです。

**ボード: A♠K♦Q♣ J♥ (4枚目まで) リバー待ち**

ナッツ (最強手) はストレート AT で AKQJT。

自分が T♦ を持つ → 相手の AT (ナッツ) は T♦ と T♥/T♠/T♣ の組み合わせのみ
通常 4 通りある相手の Tx が 3 通りに減少 (T♦ を除く)。

「25% ブロック率」という計算になります (1/4 をブロック)。

### 実用的なブロッカー強度の目安

| 状況 | ブロッカー効果 | 注意 |
|---|---|---|
| ナッツの 1 枚を持つ | ナッツ確率が 25-33% 削減 | 1 枚カード系のナッツに対して |
| フラッシュスートの 1 枚を持つ | フラッシュ確率が ~12% 削減 | フラッシュ可能コンボを減らす |
| ボードカードと同ランクを持つ | セット確率が ~33% 削減 | 相手の Kx (K on board) 等 |
| スーテッドコネクターのキー牌 | ストレート確率が ~25% 削減 | 特定ストレート 1 枚 |

---

## 11-4 ブロッカーを使ったブラフ選択

リバーでブラフする際、以下の条件を満たすハンドを優先します。

### 理想的なブラフ候補の条件

```
1. ショーダウン価値なし (コールされると負ける)
2. 相手のコールレンジ (バリューハンド) をブロック
3. 相手のブラフレンジをブロックしない (ブラフ過密を避ける)
4. 適切なベットストーリー (フロップ/ターンのアクションと整合)
```

### 具体例

**ボード: A♥K♠Q♦ J♠ 2♦**

BTN が IP でブラフを検討。フラッシュドロー (スペード) 外れのハンドが多い。

```
ハンド A: T♠9♠ (ストレートドロー + スペードドロー外れ)
  ブロッカー: T でストレート (AT や KT, QT 等) の一部をブロック
  ショーダウン価値: なし
  → 良いブラフ候補

ハンド B: 8♠7♠ (スペードドロー外れ)
  ブロッカー: 87 はこのボードでストレートに絡まない
  ショーダウン価値: なし
  → ブロッカー弱めのブラフ

ハンド C: K♦K♣ (ポケットキング、Kx でトリップス持ち)
  ブロッカー: K を 2 枚 → 相手の KK (クワッズに近い) をブロック
  ショーダウン価値: ある (Kx で 2ペアかトリップス)
  → バリューで出すべきハンド (ブラフにしない)
```

## 11-5 ブロッカーを使ったコール判断

相手のベットに対してコールするかどうかにもブロッカー効果を組み込みます。

### 「ナッツブロッカーコール」の判断フロー

```
1. 相手のバリューレンジのナッツを特定する
2. 自分がそのナッツの 1 枚をブロックしているか確認
3. ブロックしている場合: 相手のバリュー確率 ×0.75 ほどに削減
4. 標準コールオッズより若干コールしやすくなる
```

**例**:

ボード: 5♠6♦7♣ 8♥ (4枚)、リバー待ち

相手のナッツ: 4x (45678 ストレート) や 9x (56789 ストレート)

自分が 4♦ を持つ → 相手の 4x ストレート (4-8) をブロック
→ 相手のナッツが削減 → コールオッズ改善

自分が 9♦ を持つ → 相手の 9x ストレート (5-9) をブロック
→ 同様に改善

どちらも持たない場合 → 標準的なコール判断

---

## 11-6 「ダブルブロッカー」の強力な効果

2 つのブロッカーを同時に持つ場合は、ブラフとコール両方が改善します。

```
ボード: A♠Q♦J♣ 9♣ (ターン終了)

相手のナッツ: Kx (AKQJ ストレート), QQ/JJ/AA (セット系)

自分が K♣Q♣ を持つ:
  K → ストレート (KT等) をブロック
  Q → QQ (相手の強いセット) をブロック  ← ダブルブロッカー
  
→ 相手のバリューレンジが大幅削減
→ ブラフ効率が高い + コールしやすい
```

---

## 11-7 ブロッカーの限界

ブロッカーは **相対的な効果** であり、絶対的ではありません。

### 限界 1: ブロッカーが少しある = バリューも少し減る

自分が A♥ を持てば相手の AA が減りますが、自分が AQ 等の有力なバリューを持てない可能性も示します。

### 限界 2: ブロッカーのみでブラフを正当化しない

ブラフは「相手がフォールドする可能性が十分あるとき」のみ有効です。ブロッカーがあっても、相手のレンジが非常にバリューヘビーな場合はブラフ EV が下がります。

### 限界 3: 「デブロッカー」に注意

逆に「相手のブラフ牌を持っている」場合は、相手のブラフが減り、バリュー率が上がります。

```
相手のブラフ候補牌を自分が持つ = 「デブロッカー」
→ コール基準を上げる
```

## 11-8 実戦でのブロッカー判断フロー

### ブラフを打つかどうかを決めるとき

```
ステップ 1: 自分のハンドはショーダウン価値があるか？
  ある → ブラフよりチェックバック or 薄バリューを検討
  ない → ステップ 2 へ

ステップ 2: 自分のハンドは相手のナッツをブロックしているか？
  強くブロック → ブラフ候補として優先
  ブロックなし → ブラフとしての効率が落ちる

ステップ 3: ブラフの「ストーリー」は一貫しているか？
  フロップ/ターンのアクションとリバーのブラフが矛盾しない → ブラフ成立
  矛盾する → 相手に見抜かれやすい
```

### コールするかどうかを決めるとき

```
ステップ 1: 相手のバリューハンドは何か？
  ナッツは何か（フラッシュ？ストレート？セット？）

ステップ 2: 自分はそのナッツをブロックしているか？
  している → 相手のバリュー率がやや下がる → コール閾値を少し下げる
  していない → 標準的なコール判断

ステップ 3: 全体のポットオッズが合うか？
  MDF ベースで計算して最終判断
```

## 11-9 ブロッカー活用の実戦例 3 選

### 例 1: フラッシュボードでのブラフ選択

**ボード**: K♥9♥7♥ T♦ 2♥（リバー: 4 枚目のハート）

BTN は以下のどちらでブラフするか:
- ハンドA: A♥5♦（ナッツFD外れ）
- ハンドB: J♣T♣（空振りコネクター）

**分析**:
- ハンドA: A♥ を持つことで相手のナッツフラッシュ（A♥X♥）の組み合わせを大幅ブロック。ブラフとして優秀。
- ハンドB: ハートなし。相手のフラッシュに対してブロッカー効果なし。ブラフ効率が低い。

**結論**: ハンドAがブラフ候補として優先。

### 例 2: ストレートボードでのコール判断

**ボード**: 8♠9♠T♠ J♦ Q♥（ボードにストレート完成）

相手が大きなバリューベット。自分は K♠J♦（ブロードウェイ一枚 + ストレート一枚）を持つ。

**分析**:
- 相手のナッツは A♠K♠（ナッツフラッシュ）か、K で KQJT98 ストレートの一部
- 自分の K♠ は相手の A♠K♠ をブロック（ナッツフラッシュのブロッカー）
- コール判断が標準より若干有利になる

### 例 3: ブロッカーの「罠」

**ボード**: A♦K♦Q♦ J♦ 5♥（フラッシュ完成ボード）

自分は 2♦3♦（最弱フラッシュ）を持つ。相手が大きくベット。

**分析**:
- 「自分がフラッシュを持っている → 相手もフラッシュを持ちにくい」は確かに正しい
- しかし相手は2♦・3♦以外のフラッシュを全て持てる（A♦〜4♦、6♦〜K♦）
- 自分の最弱フラッシュは相手の強フラッシュに負ける
- ブロッカー効果で「コールしやすい」と感じるが、実際はフォールドが合理的な局面

**教訓**: ブロッカーの過信に注意。フラッシュを持っていても、それが「最弱」なら相手のバリューベットに対してブロッカーはほとんど機能しません。

## ミニクイズ

### 問1

リバーでブラフを打つとき、最も効果的なブロッカーを持つのはどのハンドですか。ボードは A♥K♦Q♠J♣T♦（ストレートボード）。

1. 2♠3♠（何もない）
2. A♦K♣（相手のナッツをブロック）
3. 9♦8♦（ストレート下端方向に近い）

### 問2

ブロッカーが「コール判断に有利に働く」のはどの状況ですか。

1. 自分が相手のバリューハンドをブロックしている
2. 自分が相手のブラフハンドをブロックしている
3. 自分がポットオッズに合ったハンドを持っている

---

### 解答

- **問1**: 2（AK はボードのナッツ＝AKQJTのロイヤルストレートに絡むランクをブロック。相手がコールに来る強ハンドを持ちにくくする）
- **問2**: 1（相手のバリューをブロックすることで、相手のベットレンジ中のブラフ比率が相対的に上がる → コール有利になる）

---

> **本章まとめ**
>
> - ブロッカーは「相手の特定ハンドを物理的に除外」する効果
> - ブラフ選択: 相手のコールレンジ (バリュー) をブロックするハンドを優先
> - コール判断: ナッツブロッカーがあれば標準より少しコールしやすくなる
> - ダブルブロッカーは特に強力 (複数のナッツを同時にブロック)
> - 限界: ブロッカー単独でアクションを決定しない (全体のレンジ構造と組み合わせる)

---

**【GTO とのズレ】**

GTO のブロッカー活用は本章より精緻です。GTO は各コンボの「ナッツ率」「ブラフ率」「コール率」を完全に計算した上でブロッカー調整を行います。

本章の「ブロッカーがあれば少しコールしやすい」は正しい方向ですが、GTO では例えば「A♦ でのコール頻度が A♣ より 3% 高い」といった精密な計算があります。

実戦での最も重要な教訓は「相手がフラッシュなら私が 1 枚のフラッシュカードを持つことで相手のフラッシュを 12.5% 削減できる」という計算を頭に入れ、それをコール/フォールド判断の微調整に使うことです。ブロッカーは「決定因子」ではなく「調整因子」として扱うのが正しいアプローチです。
