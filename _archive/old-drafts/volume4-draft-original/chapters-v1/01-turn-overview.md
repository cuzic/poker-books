# 第1章　ターンの位置づけ

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップとターンで何が変わるか、ターン判断の骨格（バレルスコア・後手スコア）がどう組み合わさるかを理解する。

---

## 1-1 フロップとターンの根本的な違い

フロップで CBet を打ちました。相手はコールしました。

次に来るのがターンです。

フロップとターンで判断の構造は似ているように見えますが、実は**3つの重要な変化**が起きています。この変化を正確に把握しないと、フロップの感覚のまま打ってしまい「なぜ利益が出ないのか」と悩み続けることになります。

### 変化 1: SPR が下がり、判断の「重さ」が増す

フロップで pot × 1/3 ベットして相手がコールした場合の変化を計算してみましょう。

```
【例: 100BB, BTN vs BB, BTN が CBet】
プリフロップ後の pot:       7 BB (3BB + 3BB + 1BB ante 等)
フロップ CBet (1/3 pot):   2.3 BB
BB コール:                  2.3 BB
─────────────────────────────
ターン開始時の pot:         11.6 BB ≈ 12 BB
BTN の残りスタック:          97 − 2.3 ≈ 94.7 BB
```

SPR (Stack-to-Pot Ratio) はこう変化します。

```
フロップ開始時 SPR = 97 / 7   ≈ 13.9
ターン開始時   SPR = 94.7 / 12 ≈ 7.9
```

SPR が 13.9 から 7.9 に下がることには、実戦的に大きな意味があります。

**SPR 7〜8 の世界では、トップペアがコミットハンドに近くなります。**

たとえば BTN が K♠Q♦ を持ってボードが K♣7♦2♠ の場合、フロップでは「トップペアだが SPR が高いので少額ベット → 様子見」が合理的でした。しかしターン開始時 SPR 7.9 では、ターンに 75% ポットをベットすると残りスタックがポットとほぼ同額になります。実質「ターンで打ったらリバーはオールイン」に近い状況です。

| ターン開始時 SPR | 含意 |
|:---:|---|
| > 10 | 余裕あり。標準的なサイズ選択でよい |
| 6〜10 | 判断が重くなる。ターンサイズがリバー設計を決める |
| 3〜6 | ターンベットで事実上コミット。H2以上でないとベットしにくい |
| < 3 | コミットゾーン。強いハンドはターン or リバーオールイン |

### 変化 2: フロップ行動から情報が増える

ターンでは、両プレイヤーのフロップ行動がすでに確定しています。

| プレイヤー | フロップ行動 | 読み取れること |
|---|---|---|
| IP (BTN) | CBet した | それなりに強い or ブラフ。弱い空振りの一部も含む |
| OOP (BB) | コールした | ミドルレンジ以上 + 強いドロー。ナッツ系はほぼレイズ済み |

**OOP のコールレンジの構造**が、ターン判断で最も重要です。

OOP がコールするのは基本的に「強すぎず弱すぎない」ゾーンです。セット・2ペアはほぼレイズで返してきます。完全な空振りはフォールドします。残るのは：

- トップペア中〜弱キッカー
- セカンドペア〜ボトムペア
- 強いセミブラフ（OESD、フラッシュドロー）
- 弱いセミブラフ（ガットショット、バックドアドロー）

このレンジに対して「ターンカードが誰のハンドを強化したか」を問うのがターン判断の出発点です。

### 変化 3: ターンカードがボードを再定義する

ターンカードが 1 枚加わることで、ボードテクスチャが変わります。

```
【例 A: ドライボード + ブランク】
フロップ: K♣7♦2♠ → ターン: 3♠
→ 依然ドライ。OOP のコールレンジへの影響が最小

【例 B: ドライボード + オーバーカード】
フロップ: K♣7♦2♠ → ターン: A♠
→ OOP の Ax が強化。BTN の KQ・KJ は相対的に弱化

【例 C: セミウェット + フラッシュ完成カード】
フロップ: K♥T♥5♦ → ターン: 9♥
→ OOP のフラッシュドローが完成。BTN のバリューハンドが圧迫される
```

**キーコンセプト**: ターン判断の本質は「このカードは自分と相手、どちらにとって良いか」を即座に判断することです。

## 1-2 ターンにおける 3 つのハンドロール

ターンでは、自分のハンドを以下の 3 つの役割に分類して考えます。フロップとの違いは、「ショーダウンバリュー」がより重要な概念になることです。

### ロール 1: バリューハンド

ターンでベットして相手からコールを取れるハンドです。

**基準**: 相手のコールレンジに勝てる頻度が高い。

具体例：
- セット・2ペア（ほぼ常にバリュー）
- トップペアトップキッカー（ボードによる）
- フラッシュ/ストレート完成（完成ストリートで強化）

**重要**: バリューベットは「相手が弱いハンドでコールしてくれる状況」でのみ有効です。ターンでボードが相手に有利になった場合（フラッシュ完成など）、昨日のバリューハンドが今日は「ショーダウン狙い」に変わることがあります。

### ロール 2: セミブラフ

現時点では弱いが、ターンまたはリバーでより良いハンドに化けうるハンドです。

**基準**: アウツ数 × 2〜4% 程度の改善確率がある。

具体例：
- フラッシュドロー（9アウツ ≒ リバーで18%改善）
- OESD（8アウツ ≒ リバーで16%改善）
- ガットショット（4アウツ ≒ リバーで8%改善）

**ターン特有の考え方**: フロップでセミブラフだったハンドが、ターンで完成すれば「バリュー」に昇格します。逆に完成しなければ「ブラフ」または「フォールド」候補になります。ターンでのセミブラフは「ドロー残量」を常に確認することが重要です。

### ロール 3: ショーダウンバリュー（SDV）ハンド

ベットして相手に降りてほしいほど強くはないが、チェックダウンすれば勝てる可能性があるハンドです。

**基準**: 中程度の強さで、ベットすると弱いハンドが降り、強いハンドがコールしてくる状況。

具体例：
- セカンドペア（ボードによっては SDV）
- 弱いトップペア（ターンで上を抜かれた場合）
- アウツが少なくなったドロー

**なぜ SDV が重要か**: ターンでベットすることで「強いハンドをコールさせ、弱いハンドを逃がす」のが最悪の結果です。SDV ハンドでチェックバック（IP）またはチェック（OOP）する選択肢を持つことで、リバーでも選択肢が残ります。

## 1-3 バレルスコアと後手スコア──本書の2つの指標

ターンでの IP/OOP 判断を数値化するために、本書では 2 つのスコアを使います。

### バレルスコア（IP がダブルバレルするか）

```
バレルスコア = FlopType係数 + TurnCard係数

FlopType係数: ドライ=8, セミ=6, スーテッド=4, コネクテッド=3
TurnCard係数: ペア=4, オーバーカード=3, ブランク=2, フラッシュ=1, コネクター=0

閾値: ≥ 7 → 🟢 ダブルバレル推奨
     < 7 → 🟡 チェックバック推奨
```

**なぜこの式で判断できるか**: ドライボードでターンにブランクが来た場合、相手のコールレンジに大きな変化がなく、IP がアドバンテージを維持しています（バレルスコア 8+2=10 → 🟢）。逆にウェットボードにフラッシュ完成カードが来た場合、OOP のフラッシュドローが完成しており IP のバリューが薄れます（バレルスコア 3+1=4 → 🟡）。

### 後手スコア（OOP がターンCBetを受けてどうするか）

```
後手スコア = HandScore + A − 3 − C

HandScore: 自分のハンドの強さ（巻2参照）
A: レンジアドバンテージ補正（有利+2, 中立0, 不利−2）
3: ポジションディスアドバンテージ補正（OOP は常に−3）
C: 相手ベットサイズ補正（33%=2, 50%=4, 75%=6）

閾値: ≥ 8 → チェックレイズ検討
     0〜7 → コール
     < 0 → フォールド
```

**2つのスコアの使い分け**: IP（通常 BTN/CO）はバレルスコアで判断し、OOP（通常 BB）は後手スコアで防御方針を決めます。どちらも第 4・5 章で詳しく扱います。

## 1-4 ターン全体のベット頻度──GTO 実測データ

GTO ソルバー実測によると、フロップ CBet 後のターン CBet（ダブルバレル）頻度は次の通りです。

| フロップタイプ | ターン平均 CBet 率 | ターンカードによる変動幅 |
|---|:---:|:---:|
| ドライ rainbow（K72r 等） | 80〜100% | 小さい（±10%程度） |
| セミウェット（KT5ss 等） | 50〜75% | 中（±20%程度） |
| ウェット連結（987ss 等） | 25〜55% | 大きい（±30%以上） |

**注目点 1**: ドライボードでは、ほぼ全ターンカードで高頻度ダブルバレルになります。IP が圧倒的なレンジアドバンテージを持つためです。

**注目点 2**: ウェット〜セミウェットボードでは、ターンカードの種類によって CBet 頻度が大きく変動します。「フラッシュ完成 vs ブランク」で 30% 以上差が出ることもあります。バレルスコアが最も役立つのがこの領域です。

**注目点 3**: ドライボードでもターンカードが「ペア」の場合は CBet 率が若干上がる傾向があります（相手のコールレンジのセカンドペア・ボトムペアが弱体化するため）。

## 1-5 ターン判断フロー──実戦で使う 4 ステップ

実戦では次の 4 ステップで考えます。

```
【ステップ 1】フロップ行動の確認
  - IP が CBet した → ダブルバレル判断へ（第4章）
  - IP がチェックバックした → 遅延 CBet 判断へ（第6章）

【ステップ 2】ターンカードの分類（5種）
  - オーバーカード / ブランク / ペア / フラッシュ / コネクター
  （第2章で詳述）

【ステップ 3】自分のハンドロールの確認
  - バリュー / セミブラフ / ショーダウンバリュー の 3 種

【ステップ 4】スコアで決定
  - IP: バレルスコア ≥ 7 → ベット、< 7 → チェックバック
  - OOP: 後手スコア ≥ 8 → CR 検討、0〜7 → コール、< 0 → フォールド
```

## 1-6 ターンで起きやすい 4 つのミス

実戦でよく見られるターンのミスパターンを紹介します。

### ミス 1: フロップと同じ感覚でダブルバレルする

フロップで 1/3 ポットの「レンジベット」をした後、ターンでも同じサイズで打ち続けるのは誤りです。ターンではサイズを大きくしないと「残りスタックが多すぎる」問題が生じます。

**対策**: ターンは 50〜75% ポット以上が基本。1/3 ポットのダブルバレルは特殊な状況（ドライボード＋ブランクの超高頻度ベット時）に限ります。

### ミス 2: ターンカードを無視してバリューベットし続ける

「フロップでトップペアだったから」という理由だけでターンも打ち続けると、フラッシュ完成・オーバーカード落ちなどで相手のレンジが強化された局面でバリューをもらいにくくなります。

**対策**: バレルスコアを計算して 🟡 なら積極的にチェックバック。後手スコアを計算して相手が強い場合はサイズを下げるかチェックに切り替えます。

### ミス 3: SDV ハンドで無駄にベットする

セカンドペアや弱いトップペアでターンベットすると、弱いハンドが降り（本来フォールドしてほしくない）、強いハンドだけコールまたはレイズしてきます。これは「逆選択」と呼ばれる最悪の状態です。

**対策**: SDV ハンドはターンでチェックを優先し、リバーで相手のベットに対応する方が EV が高いことが多いです。

### ミス 4: ターン CR を過剰に恐れる

OOP の相手が強いハンドを持っている可能性を過大評価して、バリューハンドでもチェックバックしすぎるのは EV を失います。

**対策**: 後手スコアで相手が CR しにくいシチュエーションを判断し、バリューハンドは適切なサイズでベットします。相手のチェックレイズ頻度はボードや状況によって大きく異なります。

## 1-7 巻 2・巻 3 からのブリッジ

ターン判断の骨格はフロップと同じです。

```
ボードの評価 → 自分のハンドの強さ → アクション決定
```

ただし、ターンでは「**フロップ行動履歴**」と「**ターンカード分類**」という 2 つの新情報が加わります。

巻 2・巻 3 で学んだ以下のスキルはターンでもそのまま使えます。

- **BoardScore**: ボードの乾燥度を素早く評価する（ターンではフロップ分類として使用）
- **HandScore**: 自分のハンドポジションの把握（ターンでも役スコアの基盤）
- **SPR**: 緊急度の判断（ターン開始時 SPR でオールイン距離を把握）
- **MDF**: 最低ディフェンス頻度の計算（ターン・リバーでも適用）
- **先手スコア / 後手スコア**: ターンでも同じ式を使い、A係数・C係数で調整

これらをターン用に「アップグレード」した式が、バレルスコアと後手スコアです。

---

> **本章まとめ**
>
> - ターンではフロップより SPR が低くなり、判断の「重さ」が増す
> - フロップ行動履歴から相手のコールレンジ（強すぎず弱すぎない）が読める
> - ターンカードが「誰のレンジを強化したか」がダブルバレル判断の核心
> - ハンドを「バリュー / セミブラフ / ショーダウンバリュー」の 3 役割に分類する
> - IP はバレルスコア、OOP は後手スコアで数値判断する
> - ドライボードでは全ターンカードで高頻度バレル。差が出るのはウェット〜セミウェット
> - よくある 4 つのミス（同サイズ継続 / カード無視 / SDV ベット / CR 過剰恐怖）を避ける

## ミニクイズ

### 問1

BTN vs BB, 100BB。フロップ K♣7♦2♠ で BTN が 33% CBet、BB がコール。ターン A♠ が落ちた。BTN は K♥Q♥ を持つ。バレルスコアは何点か（FlopType係数: ドライ=8、TurnCard係数: オーバーカード=3）。

1. 8点
2. 11点
3. 4点

### 問2

上記の状況で BTN のとるべき行動として GTO に近いのはどれか。

1. チェックバック（バレルスコアが低いため）
2. ダブルバレル（バレルスコアが高い）
3. A が来たのでフォールドする選択肢を考える

---

### 解答

- **問1**: 2（ドライ8 + オーバーカード3 = 11点）
- **問2**: 2（バレルスコア11 ≥ 7 → 🟢 ダブルバレル。ただし KQ はトップペアが落ちた手ではなく、A が落ちて *相手のレンジが強化された* ので、サイズを 50% 以下に抑えるのが実践的）
