# 第19章　総合ドリル 50 問

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 巻 4 全体の知識を 50 問で確認する。ターンとリバーの判断を横断的にテストする。

---

> **問題の前提**: 6-max キャッシュ、100BB、BTN vs BB (ヘッズアップ)。  
> 各問は選択肢から最善アクションを選ぶ形式。

## Part 1: ターン CBet 判断 (問 1〜20)

### 問 1

ドライ板 K♣7♦2♠ でフロップ CBet、ターン: **Ks (ペア)**

あなたの手牌: J♠T♠ (何もない)

```
A. ダブルバレル  B. チェックバック
```

<details><summary>解答</summary>

**A. ダブルバレル**

バレルスコア: ドライ (8) + ペア (4) = **12** → 🟢。ただしJTは弱い。
ただし！96%は「レンジ全体」の平均。JTのような弱いハンドはチェックバックが多い。

**正解: B. チェックバック**

レンジ平均は高くても、JT 単体では改善なし。ショーダウン価値もほぼない。

</details>

### 問 6

スーテッド板 9♠8♠7♣ でフロップ CBet、ターン: **6♠ (フラッシュ + コネクター)**

あなたの手牌: K♠Q♠ (ナッツフラッシュ完成)

```

```

大サイズは BB をフォールドさせすぎて EV を逃す。

</details>

### 問 17

ドライ板 K♠Q♦2♣ でフロップ CBet、ターン: **K♥ (ペア)**

あなたの手牌: Q♥Q♣ (フルハウス: QQQ over KK)... いや QQQ on KK2 where K turns = KK over QQ?

待って: ボード K♠Q♦2♣, ターン K♥ → ボード K-Q-2-K。
Q♥Q♣ のハンド → ベストハンドは K♠K♥Q♦Q♣ (KKQQ? いや 5枚選択) → KKQQx = フルハウス KK over QQ? いや、ハンドは Q♥Q♣ で ボードは K-K-Q-2。
QQ + KK (board) = フルハウス KK over QQ (ボードの K が 2 枚でトップ) → ただし KK がボードにあるので誰でも KK ペアを使える。Q♥Q♣ の best hand = K+K+Q+Q+? = KKQQ2 (2 がキッカー)... これは full house KK over QQ ではなく、KK over QQ (2 ペア) か?

5枚中最強の組み合わせ: Q♥Q♣ + K♠K♥Q♦ → K♠K♥Q♦Q♥Q♣ (5枚) = フルハウス (QQQ+KK) ではなくクワッズ? いやQ は 3 枚 (手牌 2 枚 + ボード 1 枚) + K は 2 枚 → フルハウス (Q フル K)。

正解: Q♥Q♣ のベストハンド on K♠K♥Q♦2♣ (turn K♥) は Q-Q-K-K-Q = QQQxKK... いや手牌 2 枚 + ボード 3 枚で作る 5 枚ポーカー。

Q♥Q♣ (hand) + K♠,Q♦,2♣,K♥ (board 4 枚) から 5 枚選択:
Best = Q♥+Q♣+Q♦+K♠+K♥ = フルハウス (QQQ over KK) = クワッズ-1 の超強ハンド

あなたの手牌: Q♥Q♣ → on K♠K♥Q♦2♣ → QQQ + KK = **フルハウス (クィーン フル キング)**

```
A. ダブルバレル  B. チェックバック
```

<details><summary>解答</summary>

**A. ダブルバレル (大サイズ)**

QQQ+KK のフルハウスはこのボードの最強手候補。
バレルスコア: ドライ (8) + ペア (4) = **12** → 🟢。ナッツ近辺で積極的大バリューベット。

</details>

### 特によく間違える問題の解説

#### 問 1 の注意点

バレルスコア 12 (🟢) でも、JT という「弱いハンド」ではチェックバックが正解。**バレルスコアはレンジ全体の傾向**であり、個別コンボはその強弱で役割が分かれます。「スコアが高い = 全ハンドでダブルバレル」という誤解が最も多い。

#### 問 6 の注意点

ナッツフラッシュでも **フラッシュターンは 33% ポット** が GTO 主流。「強いハンドで大きくベット」の直感が「フラッシュ落ちで 75%+」につながりますが、実測では 33% 主流です。理由: BB のフラッシュコール範囲が広くなるため、小サイズで多くを引き出す。

#### 問 32 の注意点

A5342 のボードで 66 はストレートになれない (6 を含む 23456 はあるが、ボードに 2-3-4-5 が全部ある → BB がストレートを持ちやすい)。66 は完全なブラフキャッチャー以下。BB のベットに対して「一応ペアがある」でコールするのは典型的なウィッシュコール。

#### 問 39 (オーバーベット判断) の注意点

150% オーバーベットのコールオッズ 60% = BB のブラフ率が 60% 以上必要。ドライボードでのオーバーベットに対して、BB は「コールするには相手のバリューを上回れるハンド」が必要。トップペア以下でのコールはこの基準を満たさないことが多い。

### 公式早見表 (ドリル用)

```
バレルスコア:
  FlopType: ドライ=8, セミ=6, スーテッド=4, コネクテッド=3
  TurnCard: ペア=4, OC=3, ブランク=2, FD=1, コネクター=0
  閾値: ≥7 → 🟢 (積極バレル), <7 → 🟡 (SDV中心)

Alpha 式:
  α = ベット / (ポット + ベット)
  ブラフ有利: 相手フォールド率 > α
  コール有利: 相手ブラフ率 > α

V:B 比率:
  バリュー% = 1 - α
  ブラフ% = α
  (ベットが大きいほどブラフが多い)

MDF:
  MDF = 1 - α
  リバーでは「MDF を守る」ではなく「ブラフ率 > α」で判断

SPR:
  SPR = スタック / ポット
  SPR 高 (>10): 段階的バレルが有効
  SPR 低 (<4): オールインかフォールドの判断が増える
```
