# 第4章　ダブルバレルの論理

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップ CBet 後のターン判断を **バレルスコア** で暗算し、ダブルバレルの可否を即座に判定する。

---

## 4-1 ダブルバレルとは何か

**ダブルバレル** とは、フロップで CBet した後、ターンでも続けてベットすることです。

フロップで BTN が CBet し、BB がコールしてターンへ進んだとき:
- **ダブルバレル**: ターンでもベット (圧力継続)
- **チェックバック**: ターンでチェック (圧力停止)

この判断の誤りは「直感」に頼ることから生まれます。本章では GTO ソルバー実測データに基づく暗算式を学びます。

---

## 4-2 バレルスコアの考え方

ダブルバレルの成否は、主に 2 つの要因で決まります。

```
要因 1: フロップでの IP 優位度 (板タイプ)
  ドライ板 (K72r 等)   → IP の優位が大きい → 高 Turn CBet ベース
  コネクテッド板 (T98r) → IP の優位が小さい → 低 Turn CBet ベース

要因 2: ターンカードが誰を強化するか (ターンカード分類)
  ペア (IP の高位ペア) → IP を大幅強化
  コネクター・フラッシュ → OOP を強化する場合も
```

この 2 要因をそれぞれ **係数** に変換し、足し算で判定するのが **バレルスコア** です。

---

## 4-3 バレルスコアの計算式と係数表

### 計算式

```
バレルスコア = FlopType 係数 + TurnCard 係数

FlopType 係数:
  ドライ       = 8
  セミ         = 6
  スーテッド   = 4
  コネクテッド = 3

TurnCard 係数:
  ペア       = 4
  オーバーカード = 3
  ブランク   = 2
  フラッシュ = 1
  コネクター = 0

判定:
  バレルスコア ≥ 7 → 🟢 全ハンドでダブルバレル推奨
  バレルスコア < 7 → 🟡 HandScore 依存 (下記参照)
```

### 🟡 ゾーンでの HandScore 判断

🟡 (バレルスコア < 7) のとき、手持ちの HandScore で判断します。

| HandScore | アクション |
|---|---|
| **≥ 15** | ベット (バリューハンド) |
| **8〜14** | セミブラフのみベット |
| **< 8** | チェックバック |

### バレルスコア全体像

| 板タイプ | ペア (+4) | OC (+3) | ブランク (+2) | フラッシュ (+1) | コネクター (+0) |
|---|---|---|---|---|---|
| **ドライ (8)** | **12** 🟢 | **11** 🟢 | **10** 🟢 | — | **8** 🟢 |
| **セミ (6)** | **10** 🟢 | **9** 🟢 | **8** 🟢 | — | **6** 🟡 |
| **スーテッド (4)** | **8** 🟢 | **7** 🟢 | **6** 🟡 | **5** 🟡 | **4** 🟡 |
| **コネクテッド (3)** | **7** 🟢 | **6** 🟡 | **5** 🟡 | — | **3** 🟡 |

閾値は **7**。スコア 7 以上なら 🟢、6 以下なら 🟡 です。

### GTO 実測値との対応

参考として、GTO ソルバー実測の Turn CBet 頻度を示します。

| 板タイプ | ペア | OC | ブランク | フラッシュ | コネクター |
|---|---|---|---|---|---|
| **ドライ** | 96% 🟢 | 84% 🟢 | 80% 🟢 | — | 91% 🟢 |
| **セミ** | 88% 🟢 | 76% 🟢 | 75% 🟢 | — | 61% 🟡 |
| **スーテッド** | 88% 🟢 | 75% 🟢 | 66% 🟡 | 69% 🟡 | 62% 🟡 |
| **コネクテッド** | 84% 🟢 | 64% 🟡 | 65% 🟡 | — | 67% 🟡 |

バレルスコアの 🟢/🟡 分類は全 17 セルで GTO 実測と一致します。

## 4-4 実戦での判断フロー

### ステップ 1: 板タイプの確認

フロップで CBet した板を分類します。

```
ドライ判定: rainbow かつ最高位差が 5 以上 (K72r, A52r 等)
コネクテッド判定: 3 枚が 3 スパン以内 (T98r, 876r 等)
スーテッド判定: 2 枚以上の同スートがある板
セミ: 上記に当てはまらない中間
```

### ステップ 2: ターンカードの分類

落ちたターンカードを 5 分類します (第 2 章参照)。

### ステップ 3: バレルスコアを計算して判定

```
バレルスコア = FlopType 係数 + TurnCard 係数

バレルスコア ≥ 7 → 🟢 ダブルバレル
バレルスコア < 7 → 🟡 ステップ 4 へ
```

### ステップ 4: 🟡 のとき HandScore で判断

HandScore ≥ 15 → ベット。8〜14 → セミブラフのみ。< 8 → チェックバック。

---

## 4-5 バレルスコアの実戦例

### 例 1: ドライ板 × オーバーカードターン (🟢)

**状況**: BTN vs BB、K♣7♦2♠ フロップで 1/3 pot CBet。BB コール。ターン: Q♠

- FlopType: ドライ → 8
- TurnCard: Q = オーバーカード → +3
- **バレルスコア = 8 + 3 = 11** → 🟢

**判断**: 全ハンドで基本ベット。Q はドライ板のレンジ優位をほぼ崩さない。

---

### 例 2: セミ板 × コネクターターン (🟡)

**状況**: BTN vs BB、J♠7♦5♣ フロップで 1/2 pot CBet。BB コール。ターン: T♠

- FlopType: セミ → 6
- TurnCard: T = コネクター (J-T でストレートドロー生成) → +0
- **バレルスコア = 6 + 0 = 6** → 🟡

**判断**: HandScore で判断。

```
手持ちが JT (2ペア) → HandScore ≥ 15 → ベット
手持ちが A♠K♠ (フラッシュドロー + OC) → HandScore ≒ 12 → セミブラフでベット可
手持ちが 66 (ポケットペア 6th) → HandScore < 8 → チェックバック
手持ちが K5 (セカンドペア) → HandScore < 8 → チェックバック
```

---

### 例 3: スーテッド板 × フラッシュターン (🟡)

**状況**: BTN vs BB、9♠8♠7♣ フロップで CBet。ターン: 6♠

- FlopType: スーテッド (2 スペード) → 4
- TurnCard: 6♠ = フラッシュ (3 枚目のスペード) → +1
- **バレルスコア = 4 + 1 = 5** → 🟡

**判断**: HandScore で判断。

```
手持ちが A♠T♠ (ナッツフラッシュ) → HandScore ≥ 15 → ベット (バリュー)
手持ちが K♠Q♠ (キングハイフラッシュ) → HandScore ≥ 15 → ベット
手持ちが T♠5♠ (弱いフラッシュ) → HandScore < 8 → チェックバック
手持ちが 6♣5♣ (ストレート完成, フラッシュなし) → HandScore ≥ 15 → ベット
```

## 4-6 ダブルバレルの大局観

### 「迷ったらベット」が GTO の方向性

GTO 実測 270 シナリオ中、Turn CBet ≥ 80% (=🟢 ゾーン相当) のシナリオは **45%**。70% 以上は **67%** です。

**実戦的な意味**: 迷ったら「ベット」の方が正しいケースが多い。「慎重にチェック」を選びすぎるのが最大の損失源です。

### 「チェックバックすべき状況は限定的」

全 270 シナリオで Turn CBet < 55% となるのは以下のみです。

| 板 + ターン | CBet | 理由 |
|---|---|---|
| KQTss + Jh (connector) | 41% | 超ウェット板で J が全ドロー強化 |
| Q83ss + Jh, Th (blank) | 42-43% | スーテッド板でオーバーカードが OOP を助ける |
| JT9ss + 6h (blank) | 47% | 超コネクテッド板でブランクも安定しない |

これらは全て「超ウェット/スーテッド + 最悪のターンカード」という複合条件です。バレルスコア では全て 🟡 ゾーンとなり、HandScore による絞り込みが働きます。

---

## 4-7 ハンドクラス別ダブルバレル戦略

バレルスコアは「打つか打たないか」の方向性を示しますが、ハンドの性質によってベットの「意味」が変わります。

### ナッツ〜準ナッツ（HandScore ≥ 20）

**方針**: 🟢🟡 問わず、ほぼ常にバリューベット。

ターンでセット・2ペア・完成ストレートを持つ場合、ターンでサイズを大きくしてポットを膨らませます。リバーで残スタックがポット以下になるよう設計するのが理想です。

```
例: K72r → A♠ターン、BTN が AK（トップ2ペア）
  バレルスコア: ドライ8 + OC3 = 11 → 🟢
  HandScore: A2ペア = 20+
  推奨: ターン 75% ポットでバリューベット
  理由: A 落ちで BB の Ax が 2 ペアになったとしても、AK の 2 ペアは優位
```

### トップペア系（HandScore 10〜18）

**方針**: 🟢 なら打つ、🟡 なら注意。

トップペアでのダブルバレルは、バレルスコアが 🟢（≥ 7）ならば基本的に推奨です。ただしキッカーの強さと相手の想定レンジによって、サイズを 33〜50% に抑えることがあります。

```
例: K72r → 3♦ターン、BTN が KJ（TP 良キッカー）
  バレルスコア: ドライ8 + ブランク2 = 10 → 🟢
  HandScore: TPGK = 15 程度
  推奨: ターン 50% ポットでバリューベット
  理由: 相手の Kx は KQ・KJ のみ（KK より多い）、KJ は優位

例: KT5ss → 9♥ターン（コネクター）、BTN が KQ（TP 良キッカー）
  バレルスコア: スーテッド4 + コネクター0 = 4 → 🟡
  HandScore: TPGK = 15
  推奨: HandScore ≥ 15 なのでベット。ただしサイズは 33% 以下に
  理由: スコアは 🟡 だが強ハンドなのでバリューは取りたい。小サイズでリスク管理
```

### セミブラフ（HandScore 8〜14、ドロー系）

**方針**: 🟢 ならドロー×ブランク空振りの組み合わせでベット。🟡 なら強いドローのみ。

セミブラフのダブルバレルはドローの強さによって分けます。

| ドロー種別 | アウツ | 🟢 での方針 | 🟡 での方針 |
|---|---|---|---|
| OESD（8アウツ） | 8 | ベット推奨 | ベット検討 |
| フラッシュドロー（9アウツ） | 9 | ベット推奨 | ベット検討 |
| ガットショット（4アウツ） | 4 | 場合による | チェックバック基本 |
| バックドアのみ | 2〜3 | チェックバック多 | チェックバック |

### ショーダウンバリュー（HandScore 4〜8）

**方針**: 🟡 ゾーンでは原則チェックバック。🟢 でも慎重に。

セカンドペア・弱いトップペア・アンダーペアなど、ベットして得られるバリューよりもベットによる「逆選択リスク」が大きいハンドです。

```
例: K72r → J♠ターン（ブランク）、BTN が 7♠6♠（セカンドペア）
  バレルスコア: ドライ8 + ブランク2 = 10 → 🟢
  HandScore: セカンドペア = 8 程度
  推奨: スコアは 🟢 だが HandScore が境界。チェックバックが多数派の GTO 推奨
  理由: ベットして BB の強いハンドのコールを誘うよりも、チェックでリバーへ持ち込む方が EV 高い
```

## 4-8 ダブルバレルのサイズ選択

🟢 ゾーンでのバレルでも、サイズの選択が重要です。

| サイズ | 使いどころ |
|---|---|
| 33% ポット | 高頻度バレル（ドライ板ブランク等）。幅広いレンジで打つ |
| 50% ポット | 標準的なターンバレル。バリュー〜セミブラフに |
| 75% ポット | ポラライズしたい局面。ナッツ + ブラフの二極化 |
| 100%+ | オーバーベット。ナッツアドバンテージが強い局面のみ |

**フロップ 1/3 ポット後のターン推奨サイズ**

フロップで小サイズ（1/3 ポット）を打った場合、ターンは 50〜75% が基本です。ターンも 1/3 ポットにすると「リバーに残スタックが大きすぎる」問題が生じ、リバーでのアクションが制約されます。

## 4-9 よくある誤解

### 誤解 1: 「ターンでブランクが落ちたら安全なのでチェックバック」

ドライ板のブランクは バレルスコア = 10 → 🟢 (GTO 80%)。「安全 = チェック」は逆です。ブランクは「現状維持 → IP の優位が続く」のです。

### 誤解 2: 「ペア板は相手も強くなるのでチェック」

ペアターンはどの板タイプでも バレルスコア ≥ 7 → 🟢。IP (BTN) は OOP より「高位ペア」の恩恵を受けます。

**例**: K72r + Ks 落ち。あなたが K♣J♦ (2ペア) を持っているなら、BB の K は K72 フロップで既に消えています。KJ でもベットできます。

### 誤解 3: 「ウェット板ではダブルバレルは危険」

コネクテッド板 × ペアターンで バレルスコア = 7 → 🟢 (GTO 84%)。最低の 🟡 組み合わせでも HandScore が高ければベットが正解です。「ウェット板 = チェック」という公式はありません。

## ミニクイズ

### 問1

BTN vs BB, フロップ A♠8♦3♣（ドライ）で BTN が CBet、BB がコール。ターン T♦ が落ちた。バレルスコアはいくつで、推奨アクションは何ですか。

1. スコア 10 → 🟢 ダブルバレル
2. スコア 6 → 🟡 HandScore 依存
3. スコア 8 → 🟢 ダブルバレル

### 問2

フロップ 9♠8♠7♣（コネクテッド=3）→ ターン J♦（コネクター=0）。BTN は K♣Q♣（ハイカード、HandScore ≈ 5）。どうすべきですか。

1. バレルスコア 3 → 🟡 → HandScore < 8 → チェックバック
2. KQ はオーバーカードなので打てる
3. バレルスコア 7 → 🟢 → ダブルバレル

---

### 解答

- **問1**: 1（ドライ8 + ブランク2 = **10** → 🟢 ダブルバレル。T は A83r に対してブランク扱い）
- **問2**: 1（コネクテッド3 + コネクター0 = **3** → 🟡 → HandScore5 < 8 → チェックバック）

---

> **本章まとめ**
>
> - **バレルスコア = FlopType 係数 + TurnCard 係数** で暗算判定
> - FlopType: ドライ=8、セミ=6、スーテッド=4、コネクテッド=3
> - TurnCard: ペア=4、OC=3、ブランク=2、フラッシュ=1、コネクター=0
> - バレルスコア **≥ 7 → 🟢** 全ハンドでバレル推奨
> - バレルスコア **< 7 → 🟡** HandScore ≥15: ベット、8〜14: セミブラフのみ、<8: チェック
> - 「迷ったらベット」が GTO の方向性。チェックバックが正解な場面は限定的

---

**【GTO とのズレ】**

バレルスコア は「レンジ全体の平均 Turn CBet 頻度」を板タイプ別に示したものです。実際の GTO では各コンボに異なるベット頻度が割り当てられます。

特に 🟡 ゾーンでは「全コンボで 65% ベット」ではなく「強いコンボ 100% + 弱いコンボ 0% の混合で平均 65%」が正しい理解です。

バレルスコアの 🟢 判定でも、極端に弱いハンド (底ペア以下) ではチェックバックがあり得ます。逆に 🟡 判定でも、特定のナッツドローや 2 ペア以上では迷わずベットが最善です。

GTO との本質的なズレは「平均値での判断 vs コンボ単位の最適化」の差です。実戦ではこのズレを許容しながらも、大局的な方向性 (ダブルバレル推奨か否か) は バレルスコア で正確に把握できます。
