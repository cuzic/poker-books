# 第8章　ターン実戦例 20 問

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 第1〜7章で学んだターン判断を 20 問の実戦形式で確認する。

---

> **問題の前提**:
> - 6-max キャッシュゲーム、100BB
> - BTN (IP) vs BB (OOP)、フロップ後
> - BTN が 2.5BB オープン、BB コール (ポット 5.5BB、スタック 97.5BB)
> - フロップで BTN が CBet し BB がコール

---

## 問題 1

**ボード**: K♣7♦2♠ (フロップ) → A♠ (ターン)

BTN のハンド: Q♦J♦

フロップで 33% CBet 後、ターン A が落ちた。BTN はどう行動すべきか？

```
A. ダブルバレル (例: 50% pot)
B. チェックバック
```

<details><summary>解答</summary>

**B. チェックバック**

バレルスコア: ドライ (8) + OC (3) = **11** → 🟢 ですが、これは「レンジ全体として高頻度でバレルする」意味であり、「全ハンドでベット」ではありません。

QJ は K72r でも A 落ちでも何も持っていません。バレルしても:
- BB がフォールドすれば利益（しかし K72r の BB コールレンジは中強度 → フォールドしにくい）
- BB がコールすれば後手に回る

セミブラフとして機能するのは「ドロー = アウツ」があるとき。QJ にはアウツがほぼありません。

**よくある誤答**: 「バレルスコア 🟢 だからベット」→ 🟢 は方向性。自分のハンドが何も持っていないときはチェックバックが正解です。

</details>

## 問題 2

**ボード**: K♣7♦2♠ (フロップ) → A♠ (ターン)

BTN のハンド: A♠K♦ (2ペア = AA+KK)

```
A. ダブルバレル (例: 50% pot)
B. チェックバック (スロープレイ)
```

<details><summary>解答</summary>

**A. ダブルバレル**

AK は A ターンで 2ペアに昇格した最強クラスのバリューハンドです。

バレルスコア: ドライ (8) + OC (3) = **11** → 🟢。AK は「バリューの核」なのでベットが最善。

BB のコールレンジには K7・K2・ガットショットなどが残っており、これらから「コール料」を取れます。特に A ターン後は BB の Ax（2ペア化）もコールしてくれる可能性があり、バリューベットの効果が最大化します。

**よくある誤答**: 「A が来て相手も強くなったかもしれない → チェックバックでスロープレイ」→ AK の 2ペアより強いのは AA か KK のみ。ほぼ常にバリューベットが正解です。

推奨サイズ: 50〜75%（ターンで大きくしてリバーも続けられる設計にする）

</details>

## 問題 3

**ボード**: J♠7♣5♦ (フロップ) → T♦ (ターン)

BTN のハンド: K♦Q♦ (バックドアフラッシュ + ブロードウェイドロー)

```
A. ダブルバレル (例: 50% pot)
B. チェックバック
```

<details><summary>解答</summary>

**A. ダブルバレル**

バレルスコア: セミ (6) + コネクター (0) = **6** → 🟡

🟡 ゾーンのため HandScore で判断します。KQ のアウツを数えましょう。

- K か Q でオーバーカード: 各3枚ずつ = 6アウツ
- バックドアダイヤフラッシュドロー: 2〜3アウツ相当
- T 落ちで KQJT9 ストレートドロー: 9アウツ（リバーで A or 8 or 9 で直る）

合計 HandScore ≈ 12（セミブラフ強）→ 🟡 ゾーンでもベット有効。

**よくある誤答**: 「バレルスコアが 🟡 だからチェック」→ 🟡 は HandScore 次第。KQ のような多アウツのセミブラフはバレルが推奨です。

</details>

## 問題 4

**ボード**: T♦9♠8♣ (フロップ) → 6♥ (ターン)

BTN のハンド: A♠K♣

```
A. ダブルバレル (例: 33% pot)
B. チェックバック
```

<details><summary>解答</summary>

**B. チェックバック**

バレルスコア: コネクテッド (3) + コネクター (0) = **3** → 🟡 → HandScore 次第。

AK の HandScore: オーバーカード 2 枚 = 約 6〜8。HandScore < 8 の場合はチェックバック推奨。

T98 + 6 のボードは最もコネクテッドなウェット板で、BB のコールレンジにはストレート（JT・QJ・65・75）が多数含まれます。AK でバレルしても BB は強いハンドでコールし続けます。

**よくある誤答**: 「AK はオーバーカードなので打てる」→ アウツが A・K 合わせて 6 枚でも、BB のレンジが圧倒的に強い状況ではセミブラフとして機能しません。

</details>

## 問題 5

**ボード**: 9♠8♠7♦ (フロップ) → 9♦ (ターン)

BTN のハンド: 9♥9♣ (クワッズ)

```
A. ダブルバレル (例: 50% pot)
B. チェックバック (スロープレイ)
```

<details><summary>解答</summary>

**A. ダブルバレル が多くの場合最善**

バレルスコア: コネクテッド (3) + ペア (4) = **7** → 🟢（ギリギリ）

クワッズは最強ハンド。ターンで 50% ベットが推奨される理由:
1. 9♠8♠7♦ のウェットボードでは BB にドローが多い → コールしてくれる
2. 99 ターンで BB のセット（999）や 2 ペアが弱体化 → まだコールレンジが残っている間にバリューを取る

スロープレイは「リバーで BB がブラフする」を期待するが、ウェット板ではリバーがブランクになった場合 BB はチェックしてしまうことが多い。

**よくある誤答**: 「クワッズだからスロープレイで更に大きく取る」→ ウェット板ではスロープレイよりバリューベットで確実に取る方が EV 高いことが多い。

</details>

## 問題 6

**ボード**: A♠5♦2♣ (フロップ) → A♣ (ターン)

BTN のハンド: 5♠5♦ (セット)

```
A. ダブルバレル (例: 50% pot)
B. チェックバック (トラップ)
```

<details><summary>解答</summary>

**A. ダブルバレル 推奨**

バレルスコア: ドライ (8) + ペア (4) = **12** → 🟢

555 (セット) はフルハウスになっていますが、A のターンで AA が BTN にも BB にも可能。
BB の Ax が A の落ちで 2ペア → 3 カードになることも。

セットのスロープレイは強いですが、「BB がこのボードで何もないハンドを持っている」確率は低い (A52 は BB がコールしやすいボード)。バリューベットで今のうちに取る方が期待値高い。

</details>

## 問題 7

**ボード**: K♦9♣3♠ (フロップ) → 2♥ (ターン)

BTN のハンド: K♠Q♣ (トップペア)

BB のラインが「フロップチェックコール → ターンチェック」

```
A. ダブルバレル (33% pot)
B. チェックバック
```

<details><summary>解答</summary>

**A. ダブルバレル (33% pot)**

バレルスコア: セミ (6) + ブランク (2) = **8** → 🟢

KQ はトップペアトップキッカーに近い。BB のチェックから「弱い」と判断。
2 のターンは BB のレンジを強化しない。
→ 33% ポットの薄いバリューベットで BB の Kx 下位やポケットペアから抽出。

チェックバックするとリバーでの価値獲得のチャンスを失う。

</details>

## 問題 8

**ボード**: J♣T♠9♦ (フロップ) → K♥ (ターン)

BTN のハンド: A♣Q♣ (ナッツストレート)

```
A. ダブルバレル (大サイズ: 100% pot)
B. チェックバック (スロープレイ)
```

<details><summary>解答</summary>

**A. ダブルバレル**、サイズは状況次第

バレルスコア: コネクテッド (3) + OC (3) = **6** → 🟡

AQ は JT9K でナッツストレート。ただし BB もナッツストレート (AQ) を持てる。

バリューベットする場合: K (オーバーカード) ターンで BB の Kx が強化されている可能性あり → コールしやすい環境
→ 大きなバリューベット (75-100%) が有効

スロープレイする場合: BB にもナッツがあるため、リバーでの再投資を狙う戦略も成り立つ

**実戦推奨**: バリューベット (75% pot)。完成したナッツはチェックよりベットで今取る。

</details>

## 問題 9

**ボード**: 7♦7♠2♣ (フロップ) → 7♥ (ターン)

BTN のハンド: K♠K♦ (ポケットキング)

```
A. ダブルバレル
B. チェックバック
```

<details><summary>解答</summary>

**B. チェックバック が若干推奨**

バレルスコア: コネクテッド（最初の 777 ボードはドライに近い）→ ドライ(8) + ペア(4) = 12 → 🟢

ただし KK は「7777 ボードではフルハウス」という状況。このボードの特殊性:
- BB がコールするハンドが極めて少ない（77 = クワッズ以外、ほぼ負け確）
- ベットしても BB がフォールドするだけ → バリューが取れない
- KK でチェックバックして BB の A ハイや小ポケットのブラフを誘う

GTO 的には KK でのバレルも一定頻度必要（バランスを保つため）。しかし「多くのコールを得られる」という前提がないため、チェックバックが主流選択です。

**よくある誤答**: 「バレルスコア 🟢 だからベット」→ 7777 のボードではバリューベットが機能する BB のコールレンジが極端に薄い。スコアの数値より「誰がコールしてくれるか」を考えましょう。

</details>

## 問題 10

**ボード**: A♦8♠5♥ (フロップ) → Q♠ (ターン)

BTN のハンド: 7♣6♣ (オープンエンドストレートドロー)

```
A. ダブルバレル (例: 50% pot)
B. チェックバック
```

<details><summary>解答</summary>

**A. ダブルバレル**

バレルスコア: ドライ (8) + OC (3) = **11** → 🟢

76 は 4-5-6-7-8 のストレートドロー (アウト 8 枚)。

強いセミブラフ。ドローを持っている状況でのバレルは:
- フォールドさせれば勝ち
- コールされてもアウト 8 枚で完成の可能性

バレルスコア の 🟢 判定 + 強いドロー → 積極的バレル。

</details>

## 問題 11

**ボード**: Q♣J♦9♠ (フロップ) → 2♣ (ターン)

BTN のハンド: K♠T♠ (ストレート完成)

```
A. ダブルバレル
B. チェックバック (スロープレイ)
```

<details><summary>解答</summary>

**A. ダブルバレル**

KT は QJ9 + 2 = KQJT9 でナッツ (ロイヤルストレートなし)。

2 はブランクですが、ストレート完成でバリューを今取る。
チェックバックすると「KT はストレートを持っていない」シグナルになる可能性。

バリューを今取る: ベット推奨。サイズは 75% ポット程度。

</details>

## 問題 12

**ボード**: 8♦7♠6♣ (フロップ) → J♥ (ターン)

BTN のハンド: A♥A♣ (オーバーペア)

```
A. ダブルバレル
B. チェックバック
```

<details><summary>解答</summary>

**B. チェックバック**

バレルスコア: コネクテッド (3) + OC (3) = **6** → 🟡

876 + J → TJQK 等のストレートドロー、9T でストレート完成済み。

AA は 876J では「オーバーペア」ですが、BB のレンジには 9T (ストレート)、98 (ストレート)、5T (ストレートドロー) が多い。

AA でバレルしても BB がコールするのはAA に勝つハンドが多い。
→ チェックバックでショーダウン価値を守る。

</details>

**ボード**: K♦T♣5♠ (フロップ) → K♥ (ターン)

BTN のハンド: K♠Q♠ (トリップス)

```
A. ダブルバレル (大サイズ)
B. チェックバック (スロープレイ)
```

<details><summary>解答</summary>

**A. ダブルバレル (中サイズ: 50-75%)**

バレルスコア: セミ (6) + ペア (4) = **10** → 🟢

KQ (トリップス) は非常に強い。ペアターンで 🟢 判定。

スロープレイも有力ですが、KT5 のようなセミウェット板では BB に Tx (10ペア) やコネクタードローが残っており、バリューを今取る方が有利なことが多い。

中サイズで抽出しながらスタックを深めていく。

## 問題 17

**ボード**: K♦3♣2♠ (フロップ) → K♣ (ターン)

BTN のハンド: A♠K♥ (トリップス = カードキッカー A のトップトリップス)

BB はフロップコール後ターンもチェック。

```
A. ダブルバレル (75% pot)
B. チェックバック (トラップ)
```

<details><summary>解答</summary>

**A. ダブルバレル (75% pot) が推奨**

バレルスコア: ドライ (8) + ペア (4) = **12** → 🟢

AK トリップス (A キッカー = トップトリップス) は非常に強い。

BB がチェック → BB は弱い可能性が高い。バリューを今取る。
75% ポットで BB の Kx (トリップス下位) or ポケットペア (フルハウス候補) から抽出。

スロープレイはリバーカードが BB を強化しない場合に損失リスクがある。

</details>


ドライ板でコネクターターン → バレルスコア = 8 → 🟢。しかも強いドロー付き。

## 問題 20

**ボード**: J♥9♠8♦ (フロップ) → 4♦ (ターン)

BTN のハンド: J♠J♦ (セット)

BB のライン: フロップ → チェックレイズ → BTN がコール

```
A. ターンベット (BTN から)
B. チェックバック
```

<details><summary>解答</summary>

**A. ターンベット**

BB がフロップでチェックレイズ → BB は強いハンド (2ペア、ストレート、強いドロー) を示している。

しかし BTN の JJ はセット。BB の最強ハンド (ストレート等) には負けるが、それ以外のほとんどに勝つ。

4 はブランク (J98 + 4)。BB のレンジを大きく変えない。

→ セットはターンでバリューを継続。大きなサイズで抽出。

BB のチェックレイズ後 BTN がコール → BTN が先手を取り積極的なダブルバレルが正しい。

**よくある誤答**: 「BB がフロップでチェックレイズした = 相手は強い → チェックバックで守る」→ BTN の JJ セットは BB の多くのハンドに勝ちます。相手が強いことを理由にチェックバックすると、バリューを大量に失います。

</details>

---

> **まとめ: 20 問の共通パターン**
>
> - 🟢 ゾーン (ドライ板 or ペアターン) でも「何もないハンド」はチェックバック
> - 🟡 ゾーンでのバレルはセミブラフ (アウトあり) か強いバリューが必要
> - ドローが完成した手はバリューを今取る (スロープレイは特殊ケース)
> - コネクテッド板でのオーバーペアバレルは慎重に (BB のストレートが多い)
