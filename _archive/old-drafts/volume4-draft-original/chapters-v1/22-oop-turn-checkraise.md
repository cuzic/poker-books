# 第22章　OOP ターンチェックレイズの組み立て

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: BB 視点で「いつターン CR するか vs チェックコールか」を判断できるようになる。CR が有利な条件、サイズ選択、ブラフ CR の組み立てを体系化する。

---

## 22-1 「チェックコールとチェックレイズのどちらか」問題

第5章 (ターンディフェンス) では「IP のベットに対する BB の対応」を扱いました。しかしその章では「コール or フォールド」の判断が中心で、**「チェックレイズすべきかどうか」** が体系化されていませんでした。

本章はその穴を埋めます。

### 3 つの選択肢

```
IP がターンでベットしてきた場合の BB の選択:

1. チェックコール: ポットに参加し、リバーへ進む
2. チェックレイズ: 追加の EV を取るか、IP をフォールドさせる
3. チェックフォールド: 諦める
```

チェックコールは「守り」、チェックレイズは「攻め」です。どちらが有利かは状況によって変わります。

---

## 22-2 チェックレイズが有利な条件 (バリュー CR)

### 条件 1: IP がほぼ確実にベットする場面

```
IP のベット頻度が高い (🟢 ゾーン = バレルスコア ≥ 7) では:
  → IP がベットしてくれる確率が高い
  → BB はチェックしてから CR を狙える

例: ドライ板 K♦7♣2♠ + ペアターン Kh
  バレルスコア = 12 (🟢) → IP は高頻度でベット
  BB が 77 (セット) を持つ場合: チェックしてから CR が最大 EV
```

### 条件 2: 自分がナッツ〜準ナッツを持つ

```
バリュー CR の条件:
  □ 自分のハンドが IP のベットレンジの大部分に勝てる
  □ IP にコールしてもらえるだけの「見かけの強さ」がある

例:
  OK: セット、ストレート、フラッシュ完成 → CR でナッツバリュー
  NG: トップペアのみ → IP の強いバリューに負ける可能性高い
```

### 条件 3: ポットをより大きくすることで EV が上がる

```
チェックコールより CR がよい理由:
  コール: ポット P + IP ベット B → P+2B がショーダウンまでに積み上がる上限
  CR: ポット P + IP ベット B + CR サイズ → さらに大きなポットに

  ナッツで IP がコールすれば大きいポットを取れる
  → CR の EV > コールの EV
```

## 22-3 チェックコールが有利な条件

CR よりコールが適切な状況もあります。

### 条件 1: IP の 3bet (リレイズ) リスクが高い

```
IP が 3bet できるハンドを多く持つ状況:
  → BB が CR → IP が 3bet → BB は大きなプレッシャーを受ける

例: ウェットボード (T♠9♠8♦ + J♠) で BB が CR
  IP が Q♠J♦ (ナッツストレート) を持てば → 3bet オールイン
  BB のフルハウス以下は追い詰められる

  → BB がフルハウスなどでない場合は コールで安全に進む方が良い
```

### 条件 2: 自分のハンドが SDV (ショーダウンバリュー) 的

```
コール向きのハンド:
  - トップペア弱キッカー: CR で 3bet されると困る
  - 2ペア (ボードペア系): セットに負ける
  - ドロー中程度: CR で巻き込まれるとリスクが高い
  
  「チェックコールして安全にリバーへ」が有利
```

### 条件 3: ボードが OOP のレンジ不利

```
IP に「ナッツアドバンテージ」があるボード (ドライ板 K72r 等):
  IP が KK を持てる確率が BB より高い
  → BB の CR は IP のナッツにぶつかるリスクが高い
  → チェックコールで守る
```

## 22-4 ブラフ CR の組み立て

ブラフ CR (BCR) は「IP をフォールドさせてポットを取る」目的です。

### BCR の 3 要件

```
要件 1: ショーダウン価値がない
  「コールして見せても負ける」ハンドが対象
  ドロー外れ、完全空振り

要件 2: ブロッカー効果がある
  IP のバリューレンジをブロックしているか
  例: Ax を持つことで IP の AA/Ax フルハウスを一部ブロック

要件 3: フォールドエクイティがある
  IP がフォールドする可能性 > CR のコスト
  条件: IP のバレルレンジにブラフが多い、またはボードが IP に不利
```

### BCR の具体例

**ボード**: 8♠7♦6♣ ターン: **5♥** (コネクター)
**BB のハンド**: A♣4♣ (ストレートドロー完成: A-4-5-6-7-8? いや 4567 のストレートは 4だとA2345かA-4-5-6-7 ではなく、ここは A4 on 8765... A4 は 4-5-6-7-8 ではなく A-4 = A高ストレートドロー?)

実際: A♣4♣ on 8♠7♦6♣ 5♥:
- 4567 = 4-5-6-7 まで + 8でストレート = 45678 完成! A4 の 4 がコネクター
- A♣4♣ = ストレート完成 (4-5-6-7-8) + バックドアフラッシュ

```
A♣4♣ はストレート完成 (バリュー CR 候補)
→ これはバリュー CR

BCR 例として: T♠9♠ on 8♠7♦6♣ 5♥
  T9 = 9高ストレートドロー (完成には J or 4 必要) + スペードFD
  ストレートが外れた T9s: 
    T♠9♠ on 87654 = 5678910 ストレートが T-9 で不完成? 
    
    87654: 8-7-6-5-4 から T9 は... 678910 = 9-8-7-6-5 = 56789 完成!
    T9 on 87654: 5-6-7-8-9 のストレートが完成 (Tは使わない)! 
    → これもバリューに近い
```

BCR の本質的な例:

**ボード**: K♦T♠5♣ ターン: **9♦** (ブランク/コネクター)
**BB のハンド**: J♦8♦ (バックドアフラッシュドロー + OESD がやや弱い)

```
J8 on KT59:
  J8 = J-T-9-8 でストレートに近いが K が邪魔
  実際: 8-9-T-J で 7-8-9-T-J のストレートドロー
  J♦8♦ = ダイヤFD + ストレートドロー

BCR が有効か:
  ブロッカー: J♦ でダイヤフラッシュを一部ブロック
  フォールドエクイティ: IP がドライ板で 75% バレルをよく打つなら、
                       BB のCR で IP がフォールドしやすい (IP のブラフが多い)
  
  判断: IP のバレルにブラフが多い状況 → BCR が有利
        IP のバレルがバリュー中心 → チェックコール
```

## 22-5 チェックレイズのサイズ選択

### 小 CR (2.5x 以下)

```
用途:
  - インダクト (弱く見せて IP の追加ベットを誘う)
  - トップペアなどで「大きい CR は怖い」状況

リスク:
  IP が続けやすい (小 CR = 安く続けられる)
  → バリュー CR なら OK、BCR では IP にコールされやすくなる
```

### 標準 CR (3x 前後)

```
用途:
  - 大多数のバリュー CR
  - BCR の標準サイズ

計算例:
  IP ベット 15BB (ポット 20BB 時)
  BB チェックレイズ 45BB (3x)
  IP 追加コスト: 30BB
  コールするポット: 20 + 15 + 45 = 80BB
  IP のコールオッズ: 30/80 = 37.5%
  → BCR はブラフ率 37.5% 以上なら BB がコール有利 (IP 視点)
     IP が「BCR の 37.5% がブラフ」と思えばコールする
```

### 大 CR (4x+ / オールイン)

```
用途:
  - 絶対ナッツ (セット、ストレート、フラッシュ) での最大バリュー
  - SPR が低く、オールイン狙い

リスク:
  IP がフォールドしやすくなる (大 CR = 強いシグナル)
  → IP のコールレンジが非常に絞れる
  → ナッツなら OK、準ナッツでは過剰
```

## 22-6 ターン CR 後に IP が 3bet した場合の対応

BB がターン CR → IP が 3bet (再レイズ) してきたとき。

### 対応基準

```
IP の 3bet を受けた BB の判断:
  コール継続: BB のハンドが IP の 3bet レンジに勝てる
  フォールド: IP の 3bet レンジに負ける

  実戦の目安:
    ナッツ (ストレート、フルハウス等): コール or 4bet (オールイン)
    準ナッツ (セット、フラッシュ): コール
    2ペア以下でのバリュー CR: フォールド検討 (IP の 3bet はほぼナッツ)
    BCR でのブラフ CR: フォールド (IP が 3bet = バリューの可能性大)
```

### BCR 後の IP 3bet

```
BB が BCR → IP が 3bet:
  IP が「BB のブラフを見抜いた」か「ナッツを持っている」
  
  BB はフォールドが正解 (BCR はフォールドされることを想定)
  IP の 3bet に BCR ブラフでコールするのは二重に間違い
  
  BCR のコストは「CR 額」であり、IP が 3bet してきたら損切り
```

## 22-7 ボード別のチェックレイズ vs チェックコール ガイド

### ドライボード (K72r)

```
ドライボード (IP に有利):
  IP のバレルスコア高い → IP が多くベット
  BB の CR はリスクが高い (IP が強い手を持ちやすい)
  
  BB のバリュー CR: セット以上 (準ナッツ以上)
  BB のチェックコール: 2ペア以下
  BB の BCR: 希少 (ドライ板でブラフ CR は成功しにくい)
```

### ウェットボード (T♠9♦8♣ + J♠)

```
ウェットボード (両者が強い手を持てる):
  BB の CR: ストレート、フラッシュ (完成) → 有利
  BB のチェックコール: 2ペア、強いドロー
  BB の BCR: バストドロー + ブロッカー (J 落ちでストレート外れ = BCR 候補)
  
  ウェットボードは BCR も比較的有効 (IP のバレルにブラフが多い)
```

### フラッシュ完成ターン

```
フラッシュ完成ターン:
  BB がフラッシュ: バリュー CR 有力
  BB がフラッシュなし:
    チェックコール (IP がフラッシュかどうか見てから判断)
    BCR は「自分がフラッシュのブロッカーを持つ場合」のみ検討
```

## 22-8 実践フロー: BB ターン CR 判断

```
IP がターンでベット → BB はどうするか

Step 1: 自分のハンドはバリュー CR 候補か?
  セット、ストレート、フラッシュ → バリュー CR を検討
  2ペア以下 → チェックコール基本

Step 2: IP の 3bet リスクはどのくらいか?
  ウェットボード + 自分がナッツでない → CR は危険 → コール
  IP のバレルレンジが広い → CR のフォールドエクイティあり

Step 3: BCR 候補か?
  ショーダウン価値なし + ブロッカーあり → BCR 検討
  ブロッカーなし → チェックフォールド

Step 4: CR サイズ選択
  バリュー CR: 3x 標準 (小SPRならオールイン)
  BCR: 3x 標準 (大きくすると IP がフォールドしすぎる)
```

## ミニクイズ

### 問1

BB が K♦7♣2♠ + K♥ターン でポケット 77 (セット: 777) を持っています。IP が 50% ポットベット。BB はどうすべきですか。

1. チェックコール (セットなのでゆっくり)
2. チェックレイズ 3x (バリュー最大化)
3. フォールド

### 問2

BB が T♠9♠8♦ + J♠ターン で Q♣5♣ (ストレートドロー外れ、ブランク) を持っています。IP が 75% バレル。BCR の有効性はどう判断しますか。

1. Q♣ ブロッカーと IP の広いバレルレンジを考えると BCR 有効
2. Q5 はショーダウン価値がないため必ずフォールド
3. Q5 は強いので CR してバリューを取る

### 問3

BB がバリュー CR を打ったところ、IP が 3bet してきました。BB のハンドは 2ペア (トップ2ペア)。最善の対応は?

1. 2ペアは強いのでコール
2. IP の 3bet はほぼナッツ (セット以上) → フォールド検討
3. オールイン 4bet で圧力をかける

---

### 解答

- **問1**: 2（777 はセットで非常に強い。K♥ターンでドライ板 + ペアターン = バレルスコア 12 → IP は高頻度ベット。BB の CR は「IP がベットしてくれる」ことが確実。バリュー CR でポットを大きくする）
- **問2**: 1（Q♣ でフラッシュやストレートをブロック。IP が広くバレルする状況で BCR = IP のブラフへのプレッシャー有効。ただし IP が 3bet したらフォールド確定）
- **問3**: 2（IP がターン CR に対して 3bet するのは GTO 上ほぼナッツ (セット、フルハウス等)。2ペアは多くの IP 3bet レンジに負ける。フォールドが安全。「2ペアは強い」は相対的なもので、IP の 3bet レンジには負ける）

---

> **本章まとめ**
>
> - ターン CR vs チェックコールの判断軸: ナッツ近辺 → CR、SDV 範囲 → コール
> - バリュー CR の条件: IP がほぼ確実にベット + 自分がナッツ近辺 + CR でポットが大きくなる
> - BCR の条件: ショーダウン価値なし + ブロッカーあり + IP のフォールドエクイティあり
> - CR サイズ: 3x 標準。SPR 低い場合はオールイン検討
> - IP の 3bet への対応: バリュー CR は準ナッツ以上でコール、BCR はフォールド
> - ドライボードは BCR 非推奨、ウェット/フラッシュ完成は BCR が有効なケースあり

---

**【GTO とのズレ】**

GTO では BB のターン CR 頻度は「IP のバレル頻度と CR 後の継続率」のバランスで決まります。IP が積極的にバレルするほど BB の CR のフォールドエクイティが増え、BCR の価値が上がります。

実戦で最もよくある「GTO とのズレ」は **CR するべきでないハンドで CR してしまう** ことです。特に「2ペアで大きく CR」は IP に 3bet されると壊滅的な EV ロスになります。GTO でも 2ペアは CR より チェックコールが多い傾向があります。

また、BCR の頻度は思ったより低いです。「何もないからブラフ CR」ではなく「ブロッカーがあって IP のバレルにブラフが多い状況」に限定することで BCR の精度が上がります。
