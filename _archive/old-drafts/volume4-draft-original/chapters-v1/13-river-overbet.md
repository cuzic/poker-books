# 第13章　リバーオーバーベット

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: オーバーベット (100%+) がいつ最適になるかを理解し、実戦でのバリュー/ブラフ配分を把握する。

---

## 13-1 オーバーベットとは何か

**オーバーベット** とはポット以上の額をベットすることです。

```
標準サイズ: 50-75% pot
オーバーベット: 100%+ pot (125%, 150%, 200%, アリイン)
```

標準ベットが「多くのコールを引き出す」のに対し、オーバーベットは「コールを絞る代わりに 1 回のコールで大きな利益を得る」戦略です。

---

## 13-2 オーバーベットの数学的基礎

### コール条件の変化

コールコスト率 = ベット / (ポット + ベット)

| ベットサイズ | コールコスト率 | MDF |
|---|---|---|
| 50% pot | 33% | 67% |
| 75% pot | 43% | 57% |
| 100% pot | 50% | 50% |
| 150% pot | 60% | 40% |
| 200% pot | 67% | 33% |

オーバーベットほど相手の MDF が下がります。つまり、「コールしなくていいハンドが増える」。

### オーバーベットが有利な条件

```
通常ベット: ポットオッズ 33% → より多くのハンドがコール → 薄いバリューも取れる
オーバーベット: ポットオッズ 50-60% → コールするのは「確信があるハンド」のみ

オーバーベットが有利 ← レンジが「ナッツ多数 + ブラフ多数」のポラライズ構成
```

---

## 13-3 「ポラライズ」という概念

オーバーベットは、IP のレンジが **ポラライズ (二極化)** しているときに最大 EV になります。

### ポラライズとは

```
ポラライズレンジ: 
  ナッツ (非常に強い) + ブラフ (非常に弱い) の二極構成
  ミドルハンドが少ない状態

vs.

コンデンス (中央化) レンジ:
  ミドルハンドが多数、ナッツとブラフが少ない
```

### なぜポラライズでオーバーベットが有効か

```
ポラライズレンジでオーバーベット:
  - ナッツで大きいコールを取る
  - ブラフでフォールドを強要 (MDF が低くなる)
  - ミドルハンドがないのでチェックバックのコストが低い

コンデンスレンジでオーバーベット:
  - ミドルハンドはコールされると損する
  - バランスが取りにくい
  → 標準サイズの方が適切
```

---

## 13-4 いつ IP はポラライズするか

リバーに来るまでに、IP のレンジはポラライズする傾向があります。

### ポラライズが起きやすい状況

1. **フロップ・ターンでの積極的バレル後**: 弱いハンドは早いストリートで降りており、IP にはナッツかブラフが残る
2. **フラッシュ完成リバー**: フラッシュを持つか持たないかが明確に分かれる
3. **ストレート完成リバー**: ストレートを持つか持たないかが明確

### 実戦例

**ボード**: 9♠8♠7♣ 6♠ A♥ (5枚ボード)

フロップからダブルバレルした後、リバーは A♥。

IP のレンジ:
- バリュー: A♠T♠ (フラッシュ+ストレート), T♠5♠, 強いストレート完成
- ブラフ: 完成しなかった K♠Q♠ (キングハイのフラッシュドロー外れ), 6♣5♣ (ブラフバストド)

このレンジはポラライズ。A♥ のオーバーベットで BB の 2ペア等をフォールドさせる。

---

## 13-5 V:B 比率とオーバーベット

第 10 章の V:B 比率はオーバーベットでも適用されます。

### オーバーベット時の V:B 比率

150% ポットベットのとき:

```
α = bet/(pot+bet) = 1.5/(1+1.5) = 0.6 (コールコスト率)
V:B = α:(1-α) = 0.6:0.4 = 3:2 ≒ 60% バリュー: 40% ブラフ
```

標準ベットより「バリュー比率が高い」ことが分かります。

| ベットサイズ | コールコスト | バリュー比率 | ブラフ比率 |
|---|---|---|---|
| 50% pot | 33% | 67% | 33% |
| 75% pot | 43% | 57% | 43% |
| 100% pot | 50% | 50% | 50% |
| 150% pot | 60% | 60% | 40% |
| 200% pot | 67% | 67% | 33% |

**注意**: オーバーベット時はブラフを「減らす」必要があります。「オーバーベット = ブラフが多い」という直感は数学的に誤りです。

---

## 13-6 BB のオーバーベットへの対応

相手 (IP) がオーバーベットしてきた場合の対応です。

### 計算例

ポット 20BB, IP が 30BB にオーバーベット (150% pot)

```
コールコスト = 30BB
コールするポット = 20 + 30 = 50BB
コールオッズ = 30/50 = 60%
→ IP のレンジの 60% 以上がバリューなら、ほぼコールできないハンドの方が多い
```

実は、オーバーベットに対して BB がコールできるのは「IP のバリューを上回れるハンド」だけです。

### 対応の実戦的基準

```
IP の 150% オーバーベット:
  MDF = 1 - 0.6 = 40% (40% のハンドでコールすれば損しない)
  
  しかし「40% のハンド」の質を考える:
    IP のバリューに勝てるか?
    ブラフキャッチャーとして機能するか?
  
  ブロッカーを持つ強いブラフキャッチャー → コール
  ミドルペア以下 → フォールド推奨
```

## 13-7 OOP (BB) のオーバーベット

BB がリバーで先手のオーバーベットをすることもあります (ドンクオーバーベット)。

### BB がオーバーベットする状況

1. **ドロー完成で IP が弱い**: IP がターンでチェックバックした → IP は弱いと判断
2. **ボードが BB に非常に有利**: BB のレンジが大幅強化されるリバー

### IP の対応

```
BB のオーバーベットに対する IP:
  MDF = 40% (150% pot の場合)
  
  コールできる 40% のハンド = IP のナッツ付近
  → フォールドが多くなるのは正常
```

## 13-8 オーバーベットが有効なボードパターン

オーバーベットはどんな状況でも有効なわけではありません。具体的なボードパターンで整理します。

### パターン 1: ドライボード＋ランナーランナー完成

```
例: K♣7♦2♠ → 3♦ターン → A♣リバー

フロップ〜ターンでドライボードをバレルした IP は K72・A を経て「Ax が大幅強化」。
BB のコールレンジは主に Kx・7x・2x で、A 落ちで大幅弱体化。

IP が A♠K♦（2ペア）を持つ場合:
  オーバーベット（150%）でポラライズ。BB の Kx は降りやすい。
  BB のコールハンドは Ax（2ペア化）中心 → IP の AK はこれに勝つ。
```

### パターン 2: フラッシュ完成リバー

```
例: K♥T♥5♦ → 8♥ターン → J♥リバー

4枚目のハートでナッツフラッシュ完成。IP のレンジは:
  バリュー: A♥Q♥ / K♥Q♥ 等のフラッシュ完成
  ブラフ: 外れたスペード/ダイヤのドロー

ポラライズ成立 → オーバーベットの条件が整う。
ただし BB にもフラッシュが完成している場合は「同じフラッシュ = チェックバック」が多い。
```

### パターン 3: ストレート完成リバー（コネクター板）

```
例: T♠9♦8♣ → 6♥ターン → J♠リバー

J で TJQKK 等のストレートが完成。IP のナッツ（QJ、KQ）vs BB のコールレンジ。
IP がストレートを持つ場合はオーバーベットで BB の 2ペア・セットを降ろせる。
```

### オーバーベットが向かないパターン

```
NGパターン:
  - フロップ/ターンで弱いハンドでチェックバックしたのにリバーでオーバーベット
    → ストーリーが崩れる（なぜ突然大きく？）
  - BB がリバーで大幅に強化されるカード（BB のドロー完成リバー）
    → ポラライズしているのは BB 側
  - ミドルペア〜トップペア範囲でオーバーベット
    → コンデンス（中央化）レンジにはオーバーベットは不適切
```

---

## 13-9 実戦でのオーバーベット判断チェックリスト

```
□ 自分のレンジはポラライズしているか？（ナッツ + ブラフ、ミドル少）
□ フロップ/ターンのアクションとリバーのストーリーが一貫しているか？
□ リバーカードは IP（自分）のレンジを強化したか？
□ BB がコールしてくるハンドに自分は勝てるか？
□ MDF（~40%）相当のハンドで BB がコールしてくることを許容できるか？

全部 YES → オーバーベット検討
1 つでも NO → 標準サイズ（75%以下）に戻す
```

## ミニクイズ

### 問1

リバーでオーバーベット（150%ポット）をする際、V:B 比率（バリュー:ブラフ）として最も正確なのはどれですか。

1. バリュー 60%、ブラフ 40%
2. バリュー 40%、ブラフ 60%
3. バリュー 50%、ブラフ 50%

### 問2

次のうち、オーバーベットが最も有効なシナリオはどれですか。

1. フロップでチェックバック → ターンでチェックバック → リバーで強いハンド
2. フロップ〜ターンとダブルバレルした後、リバーでフラッシュが完成し自分がナッツフラッシュを持つ
3. リバーで 2 ペアを持ち、相手が弱そうな状況

---

### 解答

- **問1**: 1（150%ポットの Alpha = 1.5/(1+1.5) = 60% → バリュー **60%**、ブラフ **40%**）
- **問2**: 2（フロップ〜ターンのバレル後 → ポラライズ形成済み。フラッシュ完成でストーリー一貫。ナッツフラッシュ = バリューの核 → オーバーベット最適）

---

> **本章まとめ**
>
> - オーバーベットは「ポラライズレンジ × 大きいコール 1 回」の構造
> - ポラライズ条件: フロップ/ターンでの積極的プレイ後、ドロー完成/不完成が明確に分かれるリバー
> - V:B 比率はオーバーベットほど「バリューが多い比率」になる (ブラフが多いわけではない)
> - BB のオーバーベット対応: MDF は 40% 程度。ミドルペアはフォールド推奨

---

**【GTO とのズレ】**

「オーバーベットはいつ使うか」は GTO でも状況依存度が高く、単純なルール化が難しい部分です。

本章の「ポラライズ」概念は正しい方向ですが、実際の GTO では:
- フロップのベットサイズ選択がリバーのオーバーベット使用と連動している
- 特定のコンボ (例: 特定のスートのコンボ) だけオーバーベットする
- ボードのすべての将来カードにわたってバランスを調整する

「リバーで強いと思ったらオーバーベット」という単純なアプローチは、GTO の方向性とは異なります。実戦では「フロップからのストーリーが一貫しているか」を確認してからオーバーベットを使うのが安全です。
