# 第24章　ポットコミットメントとオールイン判断

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 「もうフォールドできない状態」を計算で判断し、コミット判断を感覚ではなく数値で下せるようにする。

---

## 24-1 ポットコミットメントとは

「ポットコミット状態」とは、**フォールドより コール が EV 上回る状態**です。

```
コール EV = 勝率 × (ポット + コール額) - 負率 × コール額
フォールド EV = 0 (今のポットはあきらめる)

コール EV ≥ フォールド EV のとき = コミット状態
```

感覚で「もう降りられない」と思っていても、数式で確認すると実は EV マイナスのフォールドのほうが良いことも多く、逆に「降りるべき」と感じていても数値はコール EV+のことがあります。

---

## 24-2 コミットメント閾値の計算式

### 基本公式

```
コール EV = 勝率 × (ポット + コール額) - 負率 × コール額
         = 勝率 × ポット + 勝率 × コール額 - (1-勝率) × コール額
         = 勝率 × ポット - コール額 × (1 - 2×勝率)

コール EV ≥ 0:
  勝率 × ポット ≥ コール額 × (1 - 2×勝率)
  → 解いていくと: 勝率 ≥ コール額 / (ポット + コール額)
```

**結論**: コール EV ≥ 0 の条件 = **勝率 ≥ ポットオッズ**

これは第9章で学んだ「コールオッズ」と同じです。

```
ポットオッズ (コールが必要な勝率) = コール額 / (ポット + コール額)
```

### コミット判断チャート

```
計算手順:
1. ポットオッズを計算: コール額 / (ポット + コール額)
2. 自分のハンドの勝率を推定: 相手のレンジに対して何%勝てるか
3. 比較: 勝率 > ポットオッズ → コール EV+
         勝率 < ポットオッズ → フォールド EV+
```

---

## 24-3 SPR によるコミット状態の目安

実戦では「勝率を計算する時間がない」ため、SPR を使った簡易判断が有効です。

### SPR と コミット判断の関係

| ターン SPR | 状況 | 判断目安 |
|---|---|---|
| SPR > 4 | スタックが十分残っている | バレルスコアで判断、SDV 保護も有効 |
| SPR 2〜4 | ターンベット後はオールイン圏 | 「コミットか諦めか」の二択に近い |
| SPR 1〜2 | ほぼオールイン状態 | 十分なエクイティがあればコール確定 |
| SPR < 1 | オールイン圏 | ポットオッズと勝率の比較のみで判断 |

### SPR 別のコミット実例

**SPR = 3 (ターン前):**

```
ポット 20BB, スタック 60BB (SPR = 3)
IP が 75% ターンベット (15BB) → ポット 50BB, スタック 45BB, SPR ≈ 0.9

→ リバーポット 50BB, 残スタック 45BB
  リバーオールイン: ポットオッズ = 45/(50+45) = 47%
  
  BB に 47% 以上の勝率があれば: コールが EV+
  → セット、ストレート、フラッシュ = コール
  → トップペア ≈ 50〜55% 勝率 → ほぼコミット
```

**SPR = 1 (ターン直前のオールイン):**

```
ポット 80BB, スタック 80BB (SPR = 1)
IP がオールイン (80BB into 80BB = 100% OB)

BB のコールオッズ: 80/(80+80) = 50%
BB が 50% 以上の勝率 → コール EV+

  → コミット基準: 勝率 ≥ 50%
  → 1ペア (勝率 40%): フォールド
  → 2ペア (勝率 60%): コール
  → セット以上 (勝率 70%+): コール
```

## 24-4 「コミット感」の罠

実戦では「もうこんなに入れたから降りられない」という感覚でコールし続けることがあります。これは「サンクコストの誤謬」です。

### サンクコストの誤謬

```
間違った考え方:
「フロップとターンで 30BB 入れた。今さらフォールドは損だ」

正しい考え方:
「過去に入れた 30BB はどうやっても取り戻せない (サンクコスト)
 今の判断基準は『これからのコールが EV+ かどうか』だけ」

例:
  ポット 60BB, 残スタック 40BB, 相手のリバーベット 40BB (オールイン)
  コールオッズ: 40/(60+40) = 40%
  自分のハンドの推定勝率: 35%
  
  過去に 30BB 入れていても: 勝率 35% < コールオッズ 40% → フォールドが EV+
```

### 「降りたくない」という感情

```
ポットが大きくなるほど「コールしたくなる」感情が強くなります。
しかし正しい判断基準は:
  「今から入れる額に対して、勝率がポットオッズを超えるか」
  
これだけです。ポットの大きさはコール判断に直接影響しません。
```

## 24-5 ターンでのオールイン判断 (バリュー側)

自分が強いハンドを持っていて、相手のオールインに応じるかどうかの判断です。

### バリューオールインの条件

```
ターンオールインを受けた側の判断:
  コールオッズ ≤ 自分の勝率 → コール
  コールオッズ > 自分の勝率 → フォールド (例外的)

実例:
  ターン: ポット 25BB, 相手がオールイン 75BB (総額)
  コールオッズ: 75/(25+75) = 75%
  
  自分のハンドの勝率が 75% 以上 → コール EV+
  セット on ドライ板: 勝率 ≈ 80-90% → コール
  フラッシュドロー: 勝率 ≈ 35% → フォールド
  ナッツフラッシュドロー (アウト多数): 勝率 ≈ 45% → フォールド (75% に届かない)
```

---

## 24-6 ターンでのセミブラフ・オールイン判断 (ドロー側)

ドローを持っていてオールインを検討する場面です。

### セミブラフ・オールインのコスト便益

```
セミブラフ・オールインの EV:

EV = FEQ × ポット + (1 - FEQ) × エクイティ × (ポット + ベット) - ベット

FEQ = フォールドエクイティ (相手がフォールドする確率)
エクイティ = コールされたときの勝率

例: ポット 30BB, 自分がオールイン 60BB
    FEQ = 40% (相手が 40% フォールドすると推定)
    エクイティ = 35% (コールされたときの勝率)
    
    EV = 0.4 × 30 + 0.6 × 0.35 × (30+60) - 60
       = 12 + 18.9 - 60 = -29.1BB → EV マイナス
    
    FEQ が低ければセミブラフ・オールインは損
```

### フォールドエクイティが高い状況でのセミブラフ

```
FEQ が高い状況:
  - ドライボード (相手のコールレンジが狭い)
  - 相手が弱い CBet 後 (大きい IP ベット = フォールドを狙う)
  - 相手が「おそらく 1ペア以下」と読める場面

FEQ を 60% と仮定した場合:
  EV = 0.6 × 30 + 0.4 × 0.35 × 90 - 60
     = 18 + 12.6 - 60 = -29.4BB → それでも損

  → ナッツドロー (エクイティ 50%+) でないとセミブラフ OI は EV マイナスになりやすい
```

## 24-7 「コミットライン」の実戦的な引き方

実戦でわかりやすい「コミットライン」の引き方:

### SPR ベースのコミットライン

```
ターンの SPR 別コミット基準:

SPR > 5: コミットせず。バレルスコアとハンドクラスで判断
SPR 3〜5: 「強バリュー (2ペア以上) でコミット検討」
           「1ペア以下は SDV 保護かチェックバック」
SPR 1〜3: 「セット以上でコミット確定」
           「2ペアはコールオッズ確認」
           「1ペア以下は基本フォールド」
SPR < 1:  「ポットオッズ ≥ 勝率の確認のみ」
```

### 手持ちハンド別コミット判断 (ターン / 100BB ゲーム)

| ハンド | SPR 4 | SPR 2 | SPR 1 |
|---|---|---|---|
| ナッツ (SF, クワッズ) | コミット | コミット | コミット |
| セット | コミット | コミット | コミット |
| ストレート / フラッシュ | コミット | コミット | コミット |
| 2ペア (トップ2) | 状況依存 | コミット方向 | コミット |
| 2ペア (弱め) | 慎重 | 状況依存 | ポットオッズ確認 |
| トップペア (TPTK) | 基本コール | ポットオッズ確認 | ポットオッズ確認 |
| 1ペア以下 | SDV 保護 | ほぼフォールド | フォールド |

## 24-8 実戦例: コミット判断の計算

### 例 1: ターンのドロー vs オールイン

**状況**: ポット 24BB, BTN が 16BB ベット。BB がナッツフラッシュドロー (FD) を持つ。

```
コールオッズ: 16/(24+16) = 40%
ナッツ FD のターンエクイティ: ~40% (9アウト × 2 = 18%... ではなく、ターン 9アウト × 2 ≈ 18%)

ターンでの FD エクイティ:
  リバー完成確率 = 9/46 ≈ 20%
  フォールドエクイティ = 0% (ここではコールの判断)

コールオッズ 40% vs 勝率 20% → コールは EV マイナス
→ フォールド (または CR でフォールドエクイティを付加)
```

### 例 2: ターンのセット vs オーバーベット

**状況**: ポット 20BB, BTN が 30BB (150% OB) ベット。BB が 88 (セット) を持つ。

```
コールオッズ: 30/(20+30) = 60%
88 のセット on ドライ板の勝率: ~75% (IP の AK, Ax, Kx 等に勝てる)

コールオッズ 60% vs 勝率 75% → コール EV+
→ コミット (コール or レイズ)
```

### 例 3: リバーのオールイン判断

**状況**: ポット 50BB, BTN がオールイン 50BB (100%)。BB がトップペアを持つ。

```
コールオッズ: 50/(50+50) = 50%
トップペアの勝率: 相手のオールインレンジに対して ~45%
  (BTN の OI レンジ = バリューヘビー: 2ペア以上 + ブラフ少数)

コールオッズ 50% vs 勝率 45% → フォールドが EV+
→ フォールド推奨
```

## ミニクイズ

### 問1

ポット 30BB, 相手がオールイン 30BB。コールオッズは何%ですか。また、自分の推定勝率が 40% の場合、コールは EV+ ですか。

1. コールオッズ 50%、勝率 40% < 50% → フォールドが EV+
2. コールオッズ 33%、勝率 40% > 33% → コールが EV+
3. コールオッズ 25%、勝率 40% > 25% → コールが EV+

### 問2

「もうポットに 30BB 入れたから降りられない」という判断は正しいですか。

1. 正しい (サンクコストを考慮すべき)
2. 間違い (サンクコストは判断に関係ない、今からのコール EV だけを見る)
3. 状況によっては正しい

### 問3

SPR が 1 のターン。相手がオールイン。自分のハンドはトップペアトップキッカー (TPTK、勝率推定 55%)。コールオッズが 50% の場合、どうすべきですか。

1. TPTK は弱いのでフォールド
2. 勝率 55% > コールオッズ 50% → コール EV+
3. SPR 1 だからコールは絶対

---

### 解答

- **問1**: 1（コールオッズ = 30/(30+30) = **50%**。勝率 40% < 50% → フォールドが EV+。ポットがいくら大きくても勝率がポットオッズを下回れば降りることが正しい）
- **問2**: 2（過去に入れた額 (サンクコスト) は「今コールするか」の判断に無関係。判断基準は「これからコールする額に対して勝率がポットオッズを超えるか」のみ）
- **問3**: 2（勝率 55% > コールオッズ 50% → コール EV+。SPR が低いからといって自動フォールドは損。数値で確認してコール）

---

> **本章まとめ**
>
> - コミット判断の基準: 勝率 ≥ ポットオッズ (= コール額 / ポット + コール額)
> - サンクコストは判断に関係ない。今から入れる額と勝率のみで判断
> - SPR < 1: ポットオッズと勝率の計算だけで判断
> - SPR 1〜3: セット以上でコミット、1ペア以下は基本フォールド
> - セミブラフ OI はフォールドエクイティが高い + ナッツドロー級でないと EV マイナス
> - 「もう入れたから」「ポットが大きいから」は判断基準にならない

---

**【GTO とのズレ】**

GTO では「コミットラインを超えたらコール」という明確な閾値があります。しかし実戦では「相手のレンジが GTO と異なる」ため、GTO のコミットラインがずれます。

特に低レートでは相手のオールインレンジが非常にバリューヘビー (強いハンドのみ OI) な場合が多く、GTO コミットラインより高いエクイティが必要になります。「GTO ではコール EV+」でも実戦では EV マイナスになるケースは多いです。

逆に相手がブラフ OI を多用するプレイヤーに対しては、GTO より広くコールすることで EV を稼げます。相手のレンジ推定精度がコミット判断の EV に直結します。
