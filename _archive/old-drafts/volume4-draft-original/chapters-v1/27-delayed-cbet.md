# 第27章　IP の遅延 CBet

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップでチェックバックした IP がターンで攻撃する「遅延 CBet」の条件・ハンド構成・サイズ・OOP の対応を理解し、2ストリートのライン設計に組み込む。

---

## 27-1 遅延 CBet とは何か

「遅延 CBet（Delayed C-bet / Turn Stab）」とは、**フロップでチェックバックした IP がターンで先手ベットを打つ**ラインです。

```
通常の CBet ライン:
  フロップ: IP がベット (CBet)
  ターン: IP が再びベット (ダブルバレル)

遅延 CBet ライン:
  フロップ: IP がチェックバック ← 弱さのシグナル
  ターン: OOP がチェック → IP がベット ← 「遅延」攻撃
```

通常バレルと遅延 CBet は「IP がいつ攻撃を開始するか」が違うだけですが、**レンジの意味が大きく異なります**。

---

## 27-2 なぜフロップでチェックバックしたのか

遅延 CBet を理解するには、まず「IP がフロップでチェックバックを選んだ理由」から出発します。IP がチェックバックする主な理由は3つです。

```
IP のフロップ CB 理由:
  1. 中強度ハンド (SDV 保護):
     例) KQ on K72r: トップペアで SDV を守る
         88 on A52r: アンダーペアで安全確認

  2. バックドアドロー中心の投機ハンド:
     例) T9 on A63r: BDFD + バックドアストレートドロー

  3. トラップ (ナッツ):
     例) AA on K72r: スロープレイ目的
```

このうち、遅延 CBet に最もよく使われるのは **「1.中強度ハンド」と「2.バックドアドロー完成ハンド」**です。トラップ (3) はリバーまで待つかターンでスロープレイを続けることが多いです。

---

## 27-3 遅延 CBet が有効なターンカード

フロップ CB 後、どのターンカードで遅延 CBet が有効かを分類します。

### カテゴリ A: IP に有利なターンカード（遅延 CBet 有効）

```
パターン 1: IP のバックドアドロー完成

  例: A♠6♣3♦ でチェックバック (T♠9♠ 保有 = バックドア FD + BD ストレート)
      ターン: 7♠ (スペードが3枚目 = ナッツ FD 完成)

  → T♠9♠ はターンでナッツ FD を持つ
  → OOP のレンジに FD がなければ遅延 CBet でフォールドエクイティが高い

パターン 2: OOP のレンジを弱化させるターンカード

  例: K♦7♣2♠ でチェックバック
      ターン: A♥ (オーバーカード)

  → OOP の K (トップペア) が A 落ちで「セカンドペア」に格下げ
  → IP の A ハンド (A8、AT 等) は強化
  → OOP の Kx はベットしにくい → チェック → IP の遅延 CBet が有効

パターン 3: ペアターン (IP のドミナンス強化)

  例: 8♠5♦2♣ でチェックバック (IP が 88/55/22 をトラップ)
      ターン: 5♥ (ペア)

  → ペアターンで IP の 55 はフルハウスに、88 はトップセット維持
  → OOP の 5x はほぼトリップス = 強いが IP に劣る可能性
  → IP が強いペアターンで遅延攻撃
```

### カテゴリ B: 両者に中立なターンカード（選択的）

```
ブランクターン (例: K72r + 4):
  IP: チェックバックのレンジが「全体的に中強度」
  OOP: レンジはそれほど変わらない

  → バランス次第。IP は中強度ハンドで選択的に遅延 CBet
  → SDV 保護目的でチェックバック継続も有効
```

### カテゴリ C: OOP に有利なターンカード（遅延 CBet 不適）

```
コネクターターン (例: K72r + 6 or J):
  OOP のコネクター (KJ、76 等) が強化される
  → 遅延 CBet は OOP のコールレンジを増やすだけ

フラッシュターン (例: K♦7♣2♠ + Q♦):
  OOP のフラッシュドローが完成/進行
  → 遅延 CBet に対してコールされやすい
```

---

## 27-4 遅延 CBet に使うハンドの構成

フロップ CB 後の IP のレンジは「幅広い中強度ハンド」が主体です。ここからターンの遅延 CBet に使うハンドを選別します。

### バリュー目的の遅延 CBet

```
中強度バリューハンド:
  - トップペア (良キッカー以上): 薄バリューだが打てる
  - セカンドペア以上: ターンカードによって強化された場合
  - バックドアドロー → ターン強化ハンド

例: K♦7♣2♠ でチェックバック後、ターン A♥
  IP ハンド A♠T♦: トップペアに昇格 → 遅延 CBet でバリュー
  IP ハンド A♠4♦: 低キッカーだが A ハイトップペア → 慎重なサイズで打てる
```

### ブラフ目的の遅延 CBet（セミブラフ）

```
ターンでドロー強化されたハンド:
  - バックドアドロー → フラッシュドロー完成
  - バックドアドロー → OESD/ガットショット完成

例: A♠6♣3♦ + ターン 7♠
  IP ハンド T♠9♠: ナッツ FD + バックドアストレート → セミブラフ遅延 CBet

例: K♦7♣2♠ + ターン 5♣
  IP ハンド 6♣4♣: 両端ストレートドロー + クラブFD → セミブラフ
```

### 遅延 CBet に適さないハンド

```
フロップ CB の理由が「トラップ」のナッツハンド:
  - AA / KK のスロープレイ: リバーまで引き付けるかターンベット
  - セット: 遅延 CBet より通常バレルで取る方が多い

空振りハンド（SDV ゼロ）:
  - ナッツドロー以外のドロー = ターンベットは過剰
  - ピュアブラフは遅延 CBet でも EV マイナスが多い
```

## 27-5 遅延 CBet のサイズ選択

フロップ CB をしていないため、**ポットが通常の CBet 後よりも小さい**ことに注意します。

```
フロップ CBet 後のポット:
  フロップ前ポット 10BB + BTN CBet 7BB + BB コール 7BB = ターン前 24BB

フロップ チェックバック後のポット:
  フロップ前ポット 10BB + チェック/チェック = ターン前 10BB

→ 遅延 CBet はポットが小さい状態から始まる
```

### サイズガイドライン

| ハンドタイプ | 推奨サイズ | 理由 |
|---|---|---|
| バックドアドロー完成 (セミブラフ) | 75-100% pot | FEQ を最大化、コールオッズを上げる |
| 中強度バリュー (TP 等) | 50-75% pot | バリューを取りつつリスク管理 |
| ウィーク バリュー (TP 弱キッカー) | 33-50% pot | ブロッキングベット、SDV 保護 |

---

## 27-6 ストーリー整合性：通常バレルとの違い

遅延 CBet のストーリーは**フロップ CB と矛盾しない**ことが必要です。

```
通常バレルのストーリー:
  フロップ CBet = 「強いレンジで攻撃開始」
  ターン バレル = 「引き続き強い = バレル継続」
  → OOP は「IP がずっと強い」と読む

遅延 CBet のストーリー:
  フロップ CB = 「中強度または弱いハンドで安全確認」
  ターン ベット = 「ターンカードで強化された」
  → OOP は「IP がターンカードで改善した」と読む

問題になるケース:
  フロップ CB = 「弱さのシグナル (ドロー、空振り)」
  ターン OB (150%+) = 「突然強い」← ストーリー崩壊
  → OOP がコールしやすくなる (ch23 でも言及)

  → 遅延 CBet のサイズはストーリーに合わせて中程度 (50-75%) が基本
     ターン OB を遅延 CBet で使うのは「ナッツが完成した場合のみ」
```

---

## 27-7 OOP がターンでドンクベットしてきた場合

フロップ CB 後、OOP がターンで先手ベット（ドンクベット）してきた場合、遅延 CBet の計画は崩れます。

```
OOP のドンクベットの意味:
  1. バリュー: ターンカードで OOP が強化（2ペア、セット等）
  2. セミブラフ: ドローを完成させたい
  3. プロービング: IP の遅延 CBet を防ぐための先制

IP の対応:
  強ハンド (セット/ストレート/フラッシュ): コールまたはレイズ
  中強度 (TP 等): ポットオッズ次第でコール、過剰に大きければフォールド
  弱ハンド (ドロー)/空振り: フォールドまたは CR (強ドローのみ)

ドンクベットのサイズが重要:
  小ドンク (33-50%): OOP がバランスを保ちながら探っている
    → IP は広くコールまたは CR
  大ドンク (75%+): OOP がバリュー目的
    → IP は強ハンドのみコール
```

---

## 27-8 OOP の遅延 CBet への防御（BB 視点）

BB（OOP）は IP のターン遅延 CBet に対してどう守るか。

### OOP のターン チェック後の遅延 CBet 対応

```
BB がフロップ コール後、ターンでチェック → BTN が遅延 CBet:

前提: BTN のフロップ CB = 中強度/バックドア多数
     → BTN の遅延 CBet レンジは「ナッツ比率が低い」(capped)

BB の対応:
  コール: TP 以上 or 強ドロー
  チェックレイズ: ナッツ / ナッツドロー (BTN がフォールドしやすい = FEQ が高い)
    → 遅延 CBet レンジは通常 CBet より弱いため、BB の CR フォールドエクイティが上がる

  例:
    BTN 遅延 CBet 75% (ポット 10BB → ベット 7.5BB)
    BB: セット → CR 3x = 22-25BB (大きなポットを作る)
    BB: TP + FD → コール
    BB: TP 弱キッカー → 状況次第でコール or フォールド
```

### BB のチェックレイズが特に有効な状況

```
遅延 CBet のサイズが 50%+:
  BTN のレンジは中強度が主体 (ナッツが少ない)
  BB の CR に対して BTN がフォールドしやすい

ボードが BB に有利なターンカード:
  例: K72r + 6 (コネクター) → BB のドロー系ハンドが強化
  BB がターンで CR しやすい = BTN の遅延 CBet を牽制できる
```

## 27-9 遅延 CBet の頻度と実戦感覚

GTO での遅延 CBet の使用頻度の目安:

```
頻繁に遅延 CBet:
  - バックドアドロー → ターンで完成: 80-100%
  - OOP に不利なターン (OC、ペア等) + 中強度ハンド: 50-70%

選択的に遅延 CBet:
  - ブランクターン + 中強度ハンド: 25-50%
  - ブランクターン + TP (薄バリュー): 30-50%

遅延 CBet を避ける:
  - OOP に有利なターン (コネクター、FD 完成): 10-20%
  - 空振りハンド (ナッツドロー以外): ほぼ 0%

実戦シンプルルール:
  「フロップ CB した理由が『バックドア』または『中強度バリュー』なら、
   OOP に不利なターンカードで遅延 CBet を積極的に使う」
```

## 27-10 実戦例

### 例 1: バックドアドロー → FD 完成での遅延 CBet

**状況**: BTN vs BB、ポット 10BB。ボード A♠6♣3♦。BTN が K♠Q♠ でチェックバック (BDFD)。
**ターン**: 9♠（スペード3枚目）

```
ターン前ポット: 10BB

K♠Q♠ のターン強化:
  スペードが3枚目 → K♠Q♠ はナッツ FD になった
  (A♠ のみ上位 FD、BB は持てない可能性が高い)

BTN の遅延 CBet:
  サイズ: 75-100% = 7.5-10BB
  目的: セミブラフ (リバーでフラッシュ完成を狙う)
  FEQ: BB がA♠ を持たない場合、多くフォールド

  → 遅延 CBet 実行 (10BB ベット)

BB のコールレンジ:
  A♠xh: コール (トップペア + フラッシュアドバンテージなし)
  2ペア以上: コール
  下位 FD: 状況次第

→ BTN の遅延 CBet は EV+
```

### 例 2: オーバーカードターンでの中強度バリュー遅延 CBet

**状況**: BTN vs BB、ポット 10BB。ボード K♦7♣2♠。BTN が J♠T♦ でチェックバック (弱い1ペアなし)。
**ターン**: A♥

```
ターン前ポット: 10BB

ターン A♥ の意味:
  BB の Kx (トップペア): セカンドペアに格下げ
  BB の Ax: 強化されたが、BB のレンジに Ax は少ない (コール時)
  BTN の J♠T♦: A が落ちてもオープンエンドドロー (OESD) が強化される？
    → J, T のどちらも A より下 → ストレートドロー価値あり
    ただし T♦J♠ のハイカードエクイティは低い

BTN の遅延 CBet:
  目的: BB の Kx (セカンドペア) をフォールドさせる
  サイズ: 50-75% = 5-7.5BB (ブランク目的)
  
  BTN が J♠T♦ を持つ場合:
  → BB の Kx が 50% 以上フォールドすれば EV+
  → A♥ ターンは「BTN が Ax を持つ可能性」を BB に感じさせる

  遅延 CBet実行 (6BB = 60%)
```

## ミニクイズ

### 問1

BTN がフロップ K♦7♣2♠ でチェックバックし、ターン A♥ で BB がチェック。BTN のハンドは A♠T♦ (TP)。遅延 CBet の適切なサイズは?

1. 100%+ オーバーベット (突然大きく打って圧力)
2. 50-75% の標準サイズ (バリュー目的)
3. チェックバック継続 (フロップ CB のレンジと矛盾するから打てない)

### 問2

BTN がフロップ 8♦5♣2♠ でチェックバック (T♠9♠ 保有 = バックドア両端)。ターン 6♠ (スペード3枚目かつコネクター)。遅延 CBet は有効ですか?

1. 有効 (FD が完成したから積極的に打つ)
2. やや有効 (FD 完成は○だがコネクターターンは OOP にも有利)
3. 無効 (フロップ CB のレンジと矛盾する)

### 問3

BB 視点: BTN がフロップ チェックバック後のターンで 75% 遅延 CBet。BB はセットを持っている。最善は?

1. コール (セットは強いが CR のリスクが高い)
2. チェックレイズ (BTN の遅延 CBet レンジは中強度中心 = ナッツ少ない = CR FEQ が高い)
3. フォールド (75% は大きいサイズなので降りる)

---

### 解答

- **問1**: 2（フロップ CB 後の遅延 CBet でのオーバーベットはストーリー崩壊を引き起こしやすい。AhT♦ はバリューハンドだが、遅延 CBet のレンジは中強度主体なので OB は過剰。50-75% でバリューを取るのが適切）
- **問2**: 2（FD 完成は遅延 CBet の良いトリガーだが、コネクター 6♠ は BB のストレートドローも強化している。両面を考慮して「やや有効」。ナッツ FD + セミブラフとして打つなら有効だが、サイズを少し抑えめにする）
- **問3**: 2（BTN のフロップ CB = 中強度/バックドア主体。遅延 CBet レンジはナッツが少ない (capped)。BB のセットに対して BTN がフォールドしやすいため、CR のフォールドエクイティが高い。チェックレイズでポットを作るのが最大 EV）

---

> **本章まとめ**
>
> - 遅延 CBet = フロップ CB 後にターンで IP が攻撃するライン
> - 有効なターンカード: バックドアドロー完成 / OOP に不利な OC / ペアターン
> - 使うハンド: バックドアドロー強化ハンド (セミブラフ) + 中強度バリュー
> - サイズ: 通常の CBet と同じ 50-75%。OB はストーリー崩壊リスク
> - OOP が遅延 CBet を受けた場合: BTN のレンジは capped (ナッツ少ない) → CR フォールドエクイティが高い
> - 遅延 CBet を避ける場面: OOP 有利ターン（コネクター・FD 完成）、空振りハンド

---

**【GTO とのズレ】**

GTO では遅延 CBet はターンカードと IP のレンジによって大きく変動します。バックドアドローが完成したターンでは GTO でも高頻度で遅延 CBet が現れ、逆に OOP に有利なターンでは GTO は IP をほぼチェックバックに追い込みます。

実戦での「GTO とのズレ」として最も多いのは、**フロップ CB 後に「引き続き弱い」と感じて何もしないパターン**です。OOP がチェックしてきたターンで、IP に有利なカードが落ちていれば遅延 CBet は EV+ になります。フロップ CB したレンジとターンでのアクションを切り分けて考えることが重要です。

逆に「フロップ CB したら何でも遅延 CBet で打てる」と思うのも誤りです。OOP に有利なターンカードでの遅延 CBet は、強いコールレンジに EV を差し出す結果になります。
