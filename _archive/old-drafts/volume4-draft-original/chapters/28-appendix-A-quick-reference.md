# 付録 A　実戦クイックリファレンスカード

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **この付録の使い方**: 本書 Ch 1〜27 の核心を 1 枚に集約した早見表です。実戦直前に見直すだけで、バレルスコア・α式・後手スコアの三本柱を即座に呼び出せます。

---

## A-1 3つの暗算式

### 式1：バレルスコア（ターン攻撃）

```
バレルスコア = FlopType係数 + TurnCard係数

≥ 7 → 積極バレル（レンジ全体でダブルバレル推奨）
< 7 → ハンド依存（強いハンドのみダブルバレル）
```

**詳細 → 第7章**

### 式2：α式（リバー配分）

```
α = ベット額 ÷ (ポット + ベット額)

α = ブラフ比率の上限（ベットレンジに占めるブラフの割合）
後手下限確率 = 1 − α（後手の最低防御率）
V:B比率 = (1−α) : α = ポット : ベット額
```

**詳細 → 第8章**

### 式3：後手スコア（ディフェンス判断）

```
後手スコア = HandScore + A − 3 − C − M

≥ 8  → チェックレイズ（CR）検討
0〜7 → コール
< 0  → フォールド
```

HU 前提のときは M = 0 として省略できます。

**詳細 → 第9章**

| セット以上（含むフルハウス・クワッズ） | 30 | 代表値 |

| ストレート | 25 | ─ |
| TPTK（トップペアトップキッカー） | 18 | 例: AK on A72 |
| TPGK（トップペアグッドキッカー） | 15 | 例: KQ on K72 |
| TPWK（トップペアウィークキッカー） | 10 | 例: K5 on K72 |

- フラッシュドロー（FD）: +13

## A-4 A・C・M 係数早見表（後手スコア用）

### A 係数（ボード値・ドライ度）

| ボード評価 | A値 | 判断基準 |
|---|---|---|
| ドライ（ペアボード・レインボー不連続） | **3** | フラッシュドローなし・ストレートドロー薄い |
| セミウェット | **2** | 中程度のコネクト性またはスート集中 |
| ウェット（コネクテッド / フラッシュドロー強） | **1** | OESD多数 or フラッシュドロー成立しやすい |

ターンでは4枚ボードで再評価します（フロップA値をそのまま引き継がない）。

### C 係数（ベット負担）

| ベットサイズ（ポット比） | C値 | 後手下限確率 |
|---|---|---|
| 33% | **3** | 75% |
| 50% | **5** | 67% |
| 75% | **7** | 57% |
| 100%（ポットサイズ） | **9** | 50% |
| 150%（オーバーベット） | **11** | 40% |

C=9, C=11 はリバー専用の拡張値です。

### M 係数（マルチウェイ補正）

| プレイヤー数 | M値 |
|---|---|
| HU（2名） | **0** |
| 3-way | **3** |
| 4-way以上 | **6** |

## A-5 α 早見表（ベットサイズ別）

| ベットサイズ | α（ブラフ上限） | 後手下限確率 | V:B比率 |
|---|---|---|---|
| 33% pot | 0.25（25%） | 0.75（75%） | 3 : 1 |
| 50% pot | 0.33（33%） | 0.67（67%） | 2 : 1 |
| 75% pot | 0.43（43%） | 0.57（57%） | 約 4:3 |
| 100% pot | 0.50（50%） | 0.50（50%） | 1 : 1 |
| 125% pot | 0.56（56%） | 0.44（44%） | 約 4:5 |
| 150% pot | 0.60（60%） | 0.40（40%） | 2 : 3 |
| 200% pot | 0.67（67%） | 0.33（33%） | 1 : 2 |

V:B比率 =「ベットレンジ中のバリューコンボ数 : ブラフコンボ数」の上限比率。実際には全バリューをベットしない場面もあるため、あくまで上限として使います。

## A-6 判断フローまとめ

### ターン（IPが攻撃する場面）

```
ステップ1: フロップ板タイプを確認
  ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3

ステップ2: ターンカードを分類
  ペア=+4 / OC=+3 / ブランク=+2 / フラッシュ=+1 / コネクター=+0

ステップ3: バレルスコアを計算
  FlopType係数 + TurnCard係数

ステップ4: 判定
  ≥ 7 → 積極バレル（レンジ全体でダブルバレル）
  < 7 → ハンド依存（強バリュー・セミブラフのみダブルバレル）
```

### ターン（OOPが応戦する場面）

```
ステップ1: ターン後の4枚でA値を再評価
ステップ2: ベットサイズからC値を確認
ステップ3: HandScoreを評価（役+ドロー加点）
ステップ4: 後手スコア = HandScore + A − 3 − C − M
  ≥ 8  → CR検討
  0〜7 → コール
  < 0  → フォールド
```

### リバー（IPが攻撃する場面）

```
ステップ1: ハンドを3層に分類
  強バリュー（70%以上勝てる） → 75%〜100%ベット
  標準バリュー（55〜70%勝てる）→ 33%〜50%ベット
  中間 / チェックバックゾーン → チェック

ステップ2: ブラフ選択
  α = ベット額 ÷ (ポット + ベット額) でブラフ上限を確認
  ブロッカー評価（相手のナッツレンジを削るカードを優先）
  ストーリーの一貫性確認（フロップ→ターン→リバーの語り）

ステップ3: オーバーベット検討条件
  □ レンジがポラライズしている（ナッツ + ブラフ、ミドルなし）
  □ フロップ〜ターンのストーリーが一貫している
  □ リバーカードがIPのレンジを強化している
```

### リバー（OOPが応戦する場面）

```
ステップ1: リバーのHandScoreを評価（ドロー加点ゼロ、役スコアのみ）
ステップ2: A値（4枚 + リバー = 5枚ボードで再評価）
ステップ3: 後手スコア = HandScore + A − 3 − C − M
  ≥ 8  → CR検討（ナッツ近辺のみ現実的）
  0〜7 → コール
  < 0  → フォールド
ステップ4: ブラフブロッカー確認
  相手のブラフ候補カードを自分が持っていないか確認
  → 持っていると相手ベットはよりバリューに偏る（コール価値低下）
```

## A-7 5秒判断フロー

### ターン CBet 判断（5秒）

```
板タイプ確認（1秒）→ ターンカード分類（1秒）→ スコア計算（1秒）→ 判定（1秒）

例: セミ板 (6) + OC (+3) = 9 → 積極バレル
例: コネクテッド板 (3) + コネクター (+0) = 3 → ハンド依存（ほぼチェック）
```

### リバーバリュー判断（5秒）

```
「コールされて50%以上勝てるか？」（1秒）
→ YES: ベット（サイズはV:Bバランスで選択）
→ NO: チェックバック（or ブラフ候補に昇格）
```

### リバーブラフ判断（5秒）

```
α確認（1秒）→ ブロッカー評価（1秒）→ ストーリー確認（1秒）
→ 3条件OK → ブラフ実行
→ 条件不足 → チェック or フォールド
```

## A-8 実戦で意識するチェックリスト

**ターン前**

- [ ] フロップ板タイプを3分類で即答できるか
- [ ] ターンカードを5分類で即答できるか
- [ ] バレルスコアを足し算で計算したか
- [ ] スコア < 7のとき、自分のハンドクラスを評価したか

**リバー前**

- [ ] ターンでのアクション履歴を把握しているか
- [ ] 自分のハンドが「バリュー / チェックゾーン / ブラフ候補」のどれかを決定したか
- [ ] ベットするならサイズに対応するα値とV:B比率を確認したか

**相手ベットへの応戦前**

- [ ] 後手スコアを暗算したか（HandScore + A − 3 − C − M）
- [ ] リバーではドロー加点をゼロにしたか
- [ ] ブラフブロッカーの有無を確認したか（持っているとコール価値が下がる）
- [ ] CR判断はスコア8以上かつナッツ近辺のみを対象にしたか

**マルチウェイ（3名以上）**

- [ ] M値を加算したか（3-way: M=3、4-way以上: M=6）
- [ ] ブラフ頻度を大幅に下げたか（マルチウェイでブラフは低EV）

## A-9 板タイプ判定クイックガイド

```
ドライ判定（すべて満たす）:
  □ レインボー（3スート以下）
  □ 最高位と最低位のランク差 ≥ 5（例: K と 7）
  □ 3枚連続なし
  例: K72r, A52r, Q93r

コネクテッド判定（いずれか）:
  □ 3枚がスパン3以内（例: 876, T98）
  例: T98r, 876r, JT9

スーテッド判定:
  □ 同スートが2枚以上（フラッシュドロー可能）
  例: J84ss（ハート2枚）, T63ss

セミ = ドライでもコネクテッドでもない中間
  例: J75r, K93r, T42r
```

> **本書の3つの核心**
>
> - **バレルスコア**: ターン攻撃を足し算1回で判断
> - **α式**: リバーのバリュー / ブラフ配分を数値で設計
> - **後手スコア**: ディフェンスの可否をスコアで判断
>
> この3式はひとつの思想から生まれています。「GTOの複雑な計算を、人間が暗算で回せる精度に圧縮する」。実戦テーブルで迷わなくなることが、本書の唯一の目標です。
