## 1-1 ソルバーの答えは実戦で使えない

ポーカーのGTO（Game Theory Optimal：ゲーム理論的最適戦略）は、ソルバーと呼ばれる計算ソフトで算出できます。現在ではPioSolverやGTO Wizardといったツールが普及し、プロプレイヤーの多くが毎日のようにソルバー学習を行っています。

しかし、ここで一つの根本的な問いがあります。

> ソルバーで答えを見ても、実戦では同じ判断ができない。なぜか。

理由は単純です。ソルバーの出力は、人間の認知容量をはるかに超えているからです。

典型的なターン局面のGTOソルバー出力を想像してください。ボードはK♠7♦2♣、ターンがA♥。ソルバーはこの局面に対して、数十〜数百のハンドコンボごとにベット頻度・チェック頻度を計算します。「AA は高頻度ベット、KK は混合戦略（ベットとチェックを混ぜる）、AK は高頻度ベット、K9 は混合戦略……」という具合に、ハンドごとに微細に最適頻度が分かれます。

実戦では相手がベットを打ってから自分がアクションを返すまで、数秒しかありません。数百のコンボ頻度を記憶して実行することは、人間には不可能です。

ではプロプレイヤーはどうしているのか。実は彼らも、ソルバーの細部をすべて記憶しているわけではありません。「このボードタイプではこう動く」という**パターン認識**をソルバー学習から抽出し、それを実戦で使っています。

本書が提供するのも、その「パターン認識」を誰でも使えるよう整理した**暗算式**です。

## 1-2 GTOの判断は3つの軸でほぼ決まる

ソルバーが複雑に見えても、その背後にある判断ロジックは実はシンプルです。GTO的な判断は、大きく3つの軸で説明できます。この3軸を理解するだけで、ソルバーが複雑な計算の末に出力する答えの「なぜ」が見えてきます。

### 軸1: レンジ強度（Capped vs Uncapped）

「レンジ」とは、あるプレイヤーが取りうるハンドの集合です。「レンジ強度」とは、そのレンジが平均的にどれだけ強いかを示す指標です。

重要な概念が **Capped（キャップド）** と **Uncapped（アンキャップド）** です。

- **Uncapped レンジ**: ナッツ（最強ハンド）を含む可能性があるレンジ
- **Capped レンジ**: ナッツが含まれていない、または非常に少ないレンジ

例えば、フロップでCBetを打ったIPプレイヤーのレンジはUncappedです。ナッツのセットや強いトップペアを含んでいます。一方、フロップのCBetにコールしただけのOOPプレイヤーのレンジは、フロップチェックレイズをしなかった時点でナッツが薄い、Cappedに近いレンジになります。

ターンに進んだとき、どちらのレンジが「強い側」かを判断することが、すべての戦略の出発点です。Uncappedのレンジを持つ側は大きくベットできます。Cappedのレンジしか持たない側はそれができません。この非対称性がターン・リバーの戦略構造を生み出しています。これは第2章でさらに詳しく扱います。

### 軸2: ナッツアドバンテージ

レンジ強度の中でも特に重要なのが、**ナッツアドバンテージ**です。これは「どちらのプレイヤーが、このボードで最強ハンド（ナッツ）を持ちやすいか」を表します。

例えば K♠7♦2♣ というドライボードでは、BTN（ボタン）のオープンレンジに KK（セット）が含まれますが、BB（ビッグブラインド）のコールレンジには KK は通常含まれません（プリフロップで 3-bet するため）。この時点で BTN にナッツアドバンテージがあります。さらに A♥ が落ちると、BTN は BB のコールレンジに比べて AK や AA を多く含むため、A を絡める最強ハンド系の優位がさらに広がります。

ナッツアドバンテージが高い側は、大きくベットする権利を持ちます。ナッツアドバンテージが低い側は、ベットサイズを抑えざるを得ません。これが「なぜこのボードでは大きくベットするのか、小さくベットするのか」の根本的な理由です。

ナッツアドバンテージはフロップで一度決まりますが、ターンカードが落ちるたびに更新されます。「このターンカードは誰のレンジを改善するか」を考える習慣が、ターン判断の核心です。

### 軸3: α（アルファ）— コールオッズとブラフ損益分岐点

3つ目の軸は **α（アルファ）** です。これは先手側（ベット側）にとってのブラフ損益分岐点を表します。

式で書くと次のようになります。

```
α = ベット額 ÷ (ポット + ベット額)
```

例えばポットが100、ベットが75の場合、α = 75 ÷ 175 ≈ 43%です。これは「先手のブラフが43%以上の確率でフォールドを取れれば、ブラフはプラスになる」という意味です。

後手側（ディフェンス側）から見ると、αは「相手に43%以上フォールドさせないためには、少なくとも57%の頻度でコール or レイズしなければならない」という後手下限確率（1 − α）に対応します。

α式は、ターン・リバーでの戦略を分析する中核ツールです。特にリバーでは「このサイズのベットに対して何コンボのブラフが損益分岐点を超えるか」の計算に直接使います。詳しくは第8章で扱います。

### 3軸がつながる「文脈」

3つの軸は独立した話ではなく、互いに連動しています。

レンジ強度（軸1）はどちらが攻めやすいかの土台を決めます。ナッツアドバンテージ（軸2）はその上で「このターンカードは攻める側の優位をさらに広げるか、狭めるか」を更新します。α（軸3）は「その局面での具体的なベットサイズとバリュー/ブラフ比率をどう設計するか」を決めます。

この3段階の思考が、GTOソルバーが自動的に行っている判断を人間的に再構築した流れです。

## 1-3 巻2からの橋渡し ─ フロップの延長線上にある

巻2（フロップ基礎編）でみなさんは次の3つのツールを身につけました。

| ツール | 用途 |
|--------|------|
| 簡易レンジスコア | フロップでIPのレンジ全体が何%程度CBetするかを0〜10で予測する |
| HandScore | 自分のハンドの強さを数値化する（役スコア + ドロー加点 + ブロッカー加点） |
| CBet統合式・9マスマトリクス・先手スコア／後手スコア | ボード特性（A 係数）と HandScore を組み合わせて個別ハンドのアクションを決定する |

さらに巻2の後半では、これらを使って**先手スコア（CBetするかどうか）**と**後手スコア（CBetに対してどう応じるか）**を算出する方法を学びました。

```
後手スコア = HandScore + A − 3 − C − M
  ≥ 8 → チェックレイズ検討
  0〜7 → コール
  < 0 → フォールド
```

（A はボード値（ドライ度の数値化、ドライ=3 / セミ=2 / ウェット=1）、C はベット負担（33%=3 / 50%=5 / 75%=7）、M はマルチウェイ補正係数。HU 前提では M=0）

このフレームワークはフロップ一ストリートを対象にしていました。「フロップが配られた瞬間に、レンジスコアとHandScoreを見て、CBetするかコールするかチェックレイズするかを決める」という構造です。

本書はこのフレームワークを**ターンとリバーに拡張**します。フロップで学んだ「レンジ強度を評価してハンド強度と組み合わせる」という構造は変わりません。ただし、ターンとリバーにはフロップとは異なる要素が加わります。

**ターンで新たに考えること**: フロップ後にもう1枚カードが落ちます。このターンカードが「誰のレンジを改善するか」によって、フロップで優位だったプレイヤーの立場が逆転することさえあります。またフロップでCBetを打った後にターンでも打つ（ダブルバレル）かどうかという、新しい選択肢が生まれます。バレルスコアはこの判断を解決します。

**リバーで新たに考えること**: リバーにはこれ以上カードが落ちません。ドロー手がドローのまま終わり、強い手は強いまま確定します。この「確定ゲーム」の特性から、バリューベットとブラフを最適な比率で配分することが主要課題になります。α式はこの配分を解決します。

フロップの学習が基礎として機能し、ターン・リバーの暗算式がその上に積み重なる構造を意識しながら読み進めてください。

## 1-4 本書の3つの暗算式

ターン・リバーの判断を実戦で実行可能にするため、本書は3つの暗算式を提供します。

### 式1: バレルスコア ─ ターン攻撃の判断式

```
バレルスコア = FlopType係数 + TurnCard係数
```

ダブルバレル（ターンCBet）を打つかどうかを、2つの係数の足し算で決定します。

- **FlopType係数**: フロップのテクスチャ（ドライ度）を係数で表す
- **TurnCard係数**: 落ちたターンカードの種類を係数で表す

これは巻2の簡易レンジスコア（フロップのレンジCBet頻度を0〜10で予測する式）の自然な延長です。巻2ではフロップのレンジCBet頻度を予測しました。本書では「フロップのレンジ特性 + ターンカードの影響 → ターンのバレル判断」を計算します。

係数の詳細とGTOデータによる検証は第7章で扱います。

### 式2: α式 ─ リバー配分の判断式

```
α = ベット額 ÷ (ポット + ベット額)
```

リバーでバリューベットとブラフをどの比率で配置するかを、αを使って決定します。これはすでに巻2の後手下限（最低防御頻度）の裏面として学んだ概念です。

- 後手下限確率 = 1 − α
- αは「先手のブラフ損益分岐点」
- 1 − αは「後手の最低防御率」

リバーではエクイティが確定しているため、バリューとブラフの比率をαから計算することができます。詳しくは第8章で扱います。

### 式3: 後手スコア ─ ディフェンスの判断式

```
後手スコア = HandScore + A − 3 − C − M
  ≥ 8 → チェックレイズ検討
  0〜7 → コール
  < 0 → フォールド
```

これは巻2で確立した式と同じ構造です。ただし、ターン・リバーではC（ベットコスト係数）の値がフロップとは異なります。また、ターンとリバーそれぞれの局面でA（ボードアドバンテージ係数）の計算法が変わります。

式の構造は巻2の読者にはなじみ深いものです。変わるのは「係数の値」と「どのアドバンテージを計算するか」です。詳しくは第9章で扱います。

## 1-5 3つの圧縮軸と3つの暗算式の対応

3軸と3式は次のように対応しています。

| 圧縮軸 | 対応する暗算式 | 主な適用場面 |
|--------|--------------|------------|
| レンジ強度 (Capped vs Uncapped) | バレルスコアのFlopType係数 | ターン攻撃の土台判断 |
| ナッツアドバンテージ | バレルスコアのTurnCard係数 | ターンカードによる攻撃力の更新 |
| α（コールオッズ） | α式 + 後手スコア | リバー配分とディフェンス判断 |

バレルスコアがターン攻撃（先手側）の判断式であるのに対し、α式と後手スコアはそれぞれリバー配分とディフェンス（後手側）の判断式です。

フロップで学んだ簡易レンジスコアは「フロップのレンジCBet頻度」という一次元の予測でした。ターンはそこに「どのカードが落ちたか」という時間軸が加わります。バレルスコアはこの2次元を2係数の足し算で表現します。

リバーはさらに「引けない」という確定性が加わります。α式はこの確定性を利用して、バリュー/ブラフの最適比率を計算します。

## 1-6 GTO完全再現を目指さない

ここで一つ大切なことを宣言しておきます。本書の暗算式はGTOを**完全に再現することを目標にしていません**。

完全再現を目指すなら、ソルバーを持ち込むのが最も確実です。しかし実戦のテーブルではそれはできません。

本書の目標は「GTOの主要な判断の方向性を、実戦の数秒間で計算できる精度で再現すること」です。GTO実測データとの検証では、バレルスコアは270シナリオで「積極バレル推奨かどうか」という二値分類と100%一致しています。これは「GTO的なダブルバレル判断の大枠は、2係数の足し算で再現できる」ことを示しています。

ただし、個々のハンドレベルでは誤差があります。境界付近のハンドでは、GTOが混合戦略（同じハンドでも時々違うアクション）を採用することがあります。本書の暗算式はそうした境界を「一方向に丸める」設計です。誤差が生じる場面や、式の限界については各章末の【GTOとのズレ】コラムで率直に説明します。

「本書の暗算式で大枠を押さえ、必要に応じてソルバーで個別の精緻化を行う」という学習スタイルが本書の想定する使い方です。

### 問3

α式（α = ベット額 ÷ (ポット + ベット額)）と、巻2で学んだ後手下限確率の関係はどれですか。

1. α と後手下限確率は同じ値である
2. 後手下限確率 = α であり、αが大きいほど守りやすい

### 解答

- **問1**: 2（ソルバーはコンボ別に数百の頻度を出力する。実戦の数秒ではそれを参照・実行する時間はない）

- **問3**: 3（αは先手のブラフ損益分岐点。1 − αが後手の最低防御率、すなわち後手下限確率。両者は表裏の関係）

**【GTOとのズレ】**

本書の3式はGTOソルバーの出力と高い一致率を示しますが、本章の段階で正直に言っておくべきことがあります。

まず、バレルスコアの「270シナリオ100%一致」というのは、「積極バレルか否か」という二値分類の一致です。バレルスコアが7以上か未満かでGTOの主要判断方向と一致するという意味であり、個々のハンドの頻度（「KQは73%バレル」など）をそのまま再現するわけではありません。境界付近のバレルスコア（6〜8付近）では、GTOが混合戦略を採用することが多く、本書の式は「どちらか一方に丸める」ので誤差が生じます。

次に、後手スコアはフロップ版から係数を変えながら継承しますが、ターンとリバーではポットサイズとSPRが変化しているため、フロップで覚えた感覚との乖離が生じる場面があります。特にポットがすでに大きくなっているターン・リバーでは「ここでのコールオッズは思ったより良い」という感覚的な修正が必要です。

α式は数学的に正確ですが、リバーでのブラフ配分の実際はブロッカーや相手のレンジの形状に大きく依存します。「αから計算した理論的ブラフ数」より相手のコール頻度を意識した実戦的な調整が常に必要であることを、読み進める中で意識してください。
