## 本書の位置づけ

本書は4巻シリーズ『迷わないポーカー』の**第4巻、ターン・リバー編**です。

| 巻 | タイトル | 状態 |
| --- | --- | --- |
| ① | プリフロップ — 覚えなくていいレンジの考え方 | 既刊 |
| ② | フロップ[基礎] — 秒で決まるボード判断 | 既刊 |
| ③ | フロップ[応用] — 相手のレンジを読んで搾取する | 既刊 |
| **④** | **ターン・リバー — 引きと脅しの使い分け（本書）** | **3つの暗算式でGTO風判断を実現** |

前3巻でフロップ判断の土台を築きました。本書はその先、**ターンとリバーの2ストリート**を扱います。ポーカーにおいて最大の意思決定が集中するのがこの2ストリートです。ここでの判断精度が、収支の大部分を決めます。

本書は、巻2で習得した簡易レンジスコア・HandScore・後手スコアの各式を、ターン・リバーへと自然に拡張します。式の骨格は同じです。ターンとリバーでどう係数が変わるかを理解すれば、新しい暗算式はすぐに使いこなせます。

## 本書の主題 — GTOを3つの暗算式に圧縮する

ターン・リバーのGTO判断は複雑に見えます。しかし、本書の研究では、270のシナリオを分析した結果、判断の根幹は次の3つの要素に集約されることが分かりました。

### レンジ強度（Capped vs Uncapped）

フロップのアクション履歴が、ターン・リバーのレンジ構造を決定します。ナッツ級のハンドを持てるかどうか（Uncapped）、それとも強いハンドに上限がある状態か（Capped）。この非対称性が、ベットとチェックの方針を根本的に規定します。

### ナッツアドバンテージ

最強のハンドがどちらのレンジに多く存在するかを示します。ナッツアドバンテージがある側は、大きなベットでポットを構築できます。ない側は守りを優先しなければなりません。

### α（コールオッズ / バランス）

先手がブラフを損益分岐にするコールオッズの逆数です。後手下限確率（1 − α）を下回る頻度でしか守らないと、ブラフが無限に機能します。この数値が、リバーのベット配分を直接決定します。

この3要素を計算式に圧縮したものが、本書の核となる**3つの暗算式**です。

---

## 3つの暗算式

### バレルスコア（ターン攻撃の判断式）

```
バレルスコア = FlopType係数 + TurnCard係数
```

フロップのボード構造とターンカードの種類を組み合わせて、ダブルバレルの推奨度を0〜12で数値化します。スコア7以上なら積極的なバレルが正当化されます。この式は、巻2の簡易レンジスコアを「ターン全体の攻撃判断」へ拡張したものです。

詳細は第7章で解説します。

### α 式（リバー配分の判断式）

```
α = ベット額 ÷ (ポット + ベット額)
後手下限確率 = 1 − α
```

リバーでベットしたとき、相手に何%以上の頻度で守らせなければブラフが成立しないかを求めます。この逆数から、バリューベットとブラフの適切な比率が決まります。巻2で学んだ後手下限の概念を、リバーのベット配分に直接応用したものです。

詳細は第8章で解説します。

### 後手スコア（ターン・リバー版ディフェンスの判断式）

```
後手スコア = HandScore + A − 3 − C − M
```

巻2で導入した式と同じ形です。ターン・リバーでは係数の解釈と適用条件が変わりますが、式の骨格は継承します。スコア0以上でコール、0未満でフォールドが目安です。

詳細は第9章で解説します。

## 想定読者

本書は次のような読者を想定しています。

**巻2/3を読了した中級者**。簡易レンジスコア・HandScore・後手スコアを実戦で使っている方は、本書の式をすぐに理解できます。巻2の式が土台になっているため、全く新しい概念を覚える必要はほとんどありません。

**GTOソルバーを使ったが実戦判断に活かせない方**。ソルバーは個別ハンドの最適解を出しますが、なぜその解になるかの直感が育たないことがあります。本書は「なぜそうなるか」の論理を、暗算可能な式に落とし込みます。

**暗算でGTO風判断をしたい方**。テーブルで数秒で結論を出す必要があります。本書の3つの式は、現実的な暗算速度で実行できるよう設計されています。

一方、以下の読者には先に他の準備をお勧めします。フロップ判断に自信がない方は、巻2を先に読んでください。ソルバーの操作方法を学びたい方は、GTO Wizardの公式ドキュメントを参照してください。

## 本書の構成 — 6部27章 + 付録3本

本書は4つのレイヤーで構成されています。「なぜ」から始めて「何をするか」「どう改善するか」の順に積み上げます。

### 第I部　GTOを暗算式に圧縮する（第1〜5章）

「なぜターン・リバーはフロップと違うのか」という概念的な土台を築きます。レンジ強度のCapped/Uncapped、アクションとレンジの遷移、ターンとリバーがそれぞれ持つ特殊性を扱います。

### 第II部　3つの暗算式（第6〜10章）

本書の中核である3つの式を導出・定義します。ターンカードの5分類（第6章）、バレルスコア（第7章）、α式（第8章）、後手スコアのターン・リバー版（第9章）、ブロッカー論（第10章）を順に扱います。

### 第III部　ターンの戦略（第11〜15章）

第II部の式を使って、ターンでの具体的な戦術判断を行います。IPの攻撃（ダブルバレル・遅延CBet・チェックバック）、OOPの応戦（コール・チェックレイズ・ドンク）、ベットサイズ選択、オーバーベット、実戦例20問を扱います。

### 第IV部　リバーの戦略（第16〜21章）

リバー特有の判断を扱います。バリューベットとブラフの配分、後手下限とブラフキャッチ、チェックビハインドとリバーチェックレイズ、オーバーベット、ポットコミットメント、実戦例20問を扱います。

### 第V部　応用シナリオ（第22〜24章）

3-betポット、SB vs BB、マルチウェイという3つの特殊状況を扱います。標準のSRPと何が変わり、どの係数を修正するかを具体的に示します。

### 第VI部　統合と運用（第25〜27章）

ターン→リバーの連続した2ストリート判断をひとつの意思決定の流れとして統合します。ソルバーを使ったハンドレビューの方法（第26章）と、総合ドリル50問（第27章）で定着を図ります。

### 付録

- **付録A**：式の早見表と係数一覧（テーブルで参照できるチートシート）
- **付録B**：用語集（巻1〜4を通じた共通定義）
- **付録C**：シリーズ全体の式の継承関係（巻2/3から巻4への移行早見表）

## 読書ルートの推奨

### 標準ルート（推奨）

第1章から順に読み進めてください。概念（第I部）→式（第II部）→戦術（第III/IV部）→応用（第V部）→統合（第VI部）の順で、理解が自然に積み上がります。

### 急ぎのルート

「とにかく式だけ覚えて実戦投入したい」という場合は、第7章（バレルスコア）と第8章（α式）から読み始めてください。第9章（後手スコア）を加えれば、3つの式がすべて揃います。その後、必要に応じて第III部・第IV部の戦術章に戻ってください。

### 復習目的のルート

既にターン・リバー戦略をある程度理解している方は、第27章の総合ドリル50問から始めることをお勧めします。解けない問題の参照先章番号を使って、必要な章だけを読む方法が効率的です。

## 巻1〜3との接続

本書は巻2/3の続編として設計されています。以下の概念・式は、既に習得済みとして本書では再説明しません。不安な方は巻2/3を先に復習してください。

**巻2で習得済みとして扱う概念**:
- 簡易レンジスコア（ボードのCBet頻度予測指標）
- HandScore（ハンドの強さ 0〜50）
- 後手スコア = HandScore + A − 3 − C − M（フロップ版）
- 先手スコア = HandScore + A − M（フロップ版）
- 後手下限の概念と計算（コールすべき最低頻度）
- 9マスマトリクスによるアクション決定
- Rule of 2 and 4（アウツからエクイティ計算）
- A係数（ドライ=3 / セミ=2 / ウェット=1）
- C係数（33%ベット=3 / 50%=5 / 75%=7）
- M係数（HU=0 / 3-way=3 / 4-way以上=6）

**巻3で習得済みとして扱う概念**:
- 精密レンジスコア（外れ値ボードの補正）
- ブロッカー・ディスブロッカーの定量評価
- Capped/Uncappedの基本概念

巻2/3との用語の一貫性については、付録Cにシリーズ全体の式の継承表を掲載しています。「後手下限」「簡易レンジスコア」など本書固有の表記については付録Bの用語集を参照してください。

## 読書前のチェック

次の問いに答えて、本書の準備が整っているか確認してください。

1. 簡易レンジスコアを使ってボードのCBet頻度帯（高/中/低）を即座に判定できますか？

3. 後手スコア = HandScore + A − 3 − C（フロップ版、HU前提）を計算できますか？
4. 後手下限確率の計算式（コール額 ÷ 最終ポット）を実戦で使えますか？

3つ以上「はい」であれば、本書の読者として準備が整っています。不安な問いがあれば、対応する巻2の章を先に復習してください。
