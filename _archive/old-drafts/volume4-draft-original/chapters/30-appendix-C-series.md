## C-1 シリーズ全体の構造

『迷わないポーカー』シリーズは、テキサスホールデムの意思決定をストリートごとに体系化しています。各巻は独立した一冊として読めますが、概念と式が巻をまたいで継承・拡張される関係にあります。

| 巻 | タイトル | 中心テーマ | 状態 |
|---|---|---|---|
| **巻1** | プリフロップ | プリフロップでの参加・非参加の判断 | 既刊 |
| **巻2** | フロップ[基礎] | フロップのCBet頻度・サイズ・ディフェンス | 既刊 |
| **巻3** | フロップ[応用] | レンジ推定・精密化・相手への搾取 | 既刊 |
| **巻4** | ターン・リバー（本書） | バレルスコア・α式・後手スコアの統合 | 本書 |

## C-2 各巻の暗算式マップ

各巻が提供する暗算式を一覧にします。本書（巻4）の式は、すべて巻2・巻3の式の延長として設計されています。

### 巻1の暗算式

```
オープンスコア = H + L + ボーナス − ペナルティ
  H: 高い方のカード値（A=14, K=13, …, 2=2）
  L: 低い方のカード値
  ボーナス: ペア+10, スーテッド+3, コネクター+1, ギャップ2以内+0.5
  ペナルティ: ギャップ4以上−1, 両方9未満−1

  判定しきい値（6-max）: UTG≥23 / MP≥22 / CO≥21 / BTN≥18 / SB≥20

3betスコア（ブロッカー強化版）:
  Score₃ = H + 0.5L + B + S + C − G − R

ポットオッズ:
  必要勝率 ≈ コール額 ÷ 最終ポット

セットマイニングの目安:
  コール額 × 15 ≤ 相手スタック
```

### 巻2の暗算式

```
簡易レンジスコア（0〜10, CBet頻度予測）:
  BoardScore = 10 − ストレート要素 − フラッシュ要素 − ハイボードリスク
  ≥7: ドライ / 4〜6: セミウェット / ≤3: ウェット

HandScore（手の強さ 0〜50）:
  HandScore = 役スコア + ドロー加点 + ブロッカー加点
  役スコア: セット以上=30 / OP=20 / TPTK=18 / TP良キッカー=15 …
  ドロー加点: アウツ数 × 1.5（上限+15）
  ブロッカー加点: +2〜+3

CBet統合式:
  CBet スコア = HandScore + (BoardScore − 5) + ポジション係数
  判定: ≥20→CBet75% / 13〜19→CBet33% / 7〜12→チェック / <7→チェック

先手スコア（IPのCBet判断）:
  先手スコア = HandScore + A − M
  A: ドライ=3 / セミ=2 / ウェット=1
  M: HU=0 / 3-way=3 / 4-way+=6
  ≥7: ベット（33%基準） / <7: チェックバック

後手スコア（ディフェンス判断）:
  後手スコア = HandScore + A − 3 − C − M
  C: 33%=3 / 50%=5 / 75%=7
  ≥8: チェックレイズ検討 / 0〜7: コール / <0: フォールド

後手下限確率:
  α = ベット額 ÷ (ポット + ベット額)
  後手下限確率 = 1 − α
  （例: 75%ベット → α=0.43 → 後手下限確率=57%）
```

> **用語注記**: 巻2では「MDF（Minimum Defense Frequency）」という表記を使っていましたが、巻4では「後手下限」体系（後手下限ライン・後手下限確率・後手下限スコア）に統一しています。概念は同じです。

### 巻3の暗算式

```
精密レンジスコア（簡易レンジスコアの精密化版）:
  外れ値ボードを吸収したCBet頻度予測モデル
  9マスマトリクス（H1/H2/H3 × ドライ/セミ/ウェット）に直結

HandScore精密化:
  巻2のHandScoreを相手レンジ・ポジション・SPRを加味して補正
  ボード相性（Board Texture Fit）を乗算係数で反映
```

### 巻4の暗算式（本書）

```
バレルスコア（ターン攻撃の式）:
  バレルスコア = FlopType係数 + TurnCard係数
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0
  ≥7: 積極バレル（全レンジCBet推奨）/ <7: ハンド依存

α式（リバー配分の式）:
  α = ベット額 ÷ (ポット + ベット額)
  後手下限確率 = 1 − α
  最適バリュー比率（上限） = 1 − α
  最適ブラフ比率（上限） = α

後手スコア（ターン・リバー版）:
  後手スコア = HandScore + A − 3 − C − M
  ※巻2と同じ式をターン・リバーに適用
  ※巻4ではターンカードによるHandScoreの更新方法を詳説
```

## C-4 読書ルートの推奨

### ルートA: シリーズ順に読む（推奨）

```
巻1（プリフロップ）
  ↓ ハンド評価の基礎・ポットオッズを習得
巻2（フロップ基礎）
  ↓ 簡易レンジスコア・HandScore・CBet統合式・後手スコアを習得
巻3（フロップ応用）
  ↓ 精密レンジスコア・レンジ推定・搾取を習得
巻4（ターン・リバー）← 今ここ
  バレルスコア・α式を使ったストリート統合判断
```

このルートが最も滑らかです。各巻の概念が次巻の土台になっているため、前巻の式に迷うことなく本書を読み進められます。

### ルートB: 巻4から始めたい場合

巻4から読む場合、最低限必要な前提知識は以下のとおりです。

**巻2（フロップ基礎）から必要な概念**（必須）:

- **HandScore**: 手の強さを数値化する式（役スコア + ドロー加点 + ブロッカー加点）
- **簡易レンジスコア**: ボードのドライ度を0〜10で評価する式
- **後手スコア**: 相手のベットに対するコール/CR/フォールドの判断式
- **ポットオッズ**: コール額 ÷ 最終ポットで計算する必要勝率
- **Rule of 2 and 4**: アウツ数から勝率を概算する方法（× 2 で 1 ストリート分）
- **SPR（スタック/ポット比）**: コミット判断の基準

**巻3（フロップ応用）から必要な概念**（推奨）:

- **精密レンジスコア**: 外れ値ボードの補正方法
- **9マスマトリクス**: ハンドクラスとボードタイプを掛け合わせた判断表

巻3は必須ではありませんが、第14章（ターンオーバーベット）・第22章（3betポット）では巻3の「レンジポラライゼーション」の概念が背景にあります。

## C-5 シリーズの暗算式の連鎖

巻1〜4の式は、より精密な判断へと連鎖する構造を持っています。どの巻の式も「入力を単純化して出力を出す」という設計思想は共通しています。

```
【巻1】 プリフロップ判断
  オープンスコア / 3betスコア / セットマイニング目安
     ↓ 「どのハンドでフロップに進むか」を決定
     
【巻2】 フロップ判断（基礎）
  簡易レンジスコア → A係数（ドライ/セミ/ウェット）
  HandScore（役スコア + ドロー加点 + ブロッカー加点）
  CBet統合式 / 先手スコア / 後手スコア
     ↓ 「フロップでどう動くか」を決定
     
【巻3】 フロップ判断（応用）
  精密レンジスコア（外れ値補正）
  9マスマトリクス（ハンドクラス × 板タイプ）
     ↓ 「相手のレンジを読んで搾取する方法」を追加
     
【巻4】 ターン・リバー判断（本書）
  バレルスコア（= FlopType係数 + TurnCard係数）
  α式（= ベット額 ÷ (ポット + ベット額)）
  後手スコア（巻2と同じ式をターン・リバーに適用）
     ↓ 「3ストリートを貫くライン設計」の完成
```

巻2の後手スコアと本書の後手スコアは**同じ式**です。式の形は変わらず、適用するストリートとHandScoreの入力値（ターンカードによる役の変化を反映させる）が変わります。これは式を覚え直す必要がなく、巻2で学んだ判断フローがそのままターン・リバーに通用することを意味します。

## C-6 用語の変遷と統一

シリーズを通じて用語が精密化されてきた箇所があります。本書を読む際に参考にしてください。

| 概念 | 巻2での表記 | 巻4での表記 | 変更の理由 |
|---|---|---|---|
| 最低ディフェンス頻度 | MDF | 後手下限確率 | 「守る」文脈・「頻度」文脈・「スコア」文脈で使い分けるために3系統化 |
| ボード評価指標 | BoardScore | 簡易レンジスコア | CBet頻度予測モデルとしての本質を名称に反映 |
| 精密版ボード評価 | BDM v5 | 精密レンジスコア | 簡易との対比を明確にするため |

「後手下限」は巻4内で3通りに使い分けます。

- **後手下限ライン**: しきい値・境界として語る場合（「ラインを下回ると...」）
- **後手下限確率**: 具体的な%数値を語る場合（「75%ベット時の後手下限確率は57%」）
- **後手下限スコア**: 後手スコアの式の出力と比較する場合（「後手スコアが後手下限スコアを超えればコール」）

いずれも同じ概念の、文脈に応じた表現です。数値は常に「後手下限確率 = 1 − α」から計算できます。

> **付録Cまとめ**
>
> - シリーズは巻1（プリフロップ）→巻2（フロップ基礎）→巻3（フロップ応用）→巻4（本書）の順に積み上がる。
> - 巻4の暗算式（バレルスコア・α式・後手スコア）はすべて巻2の式の継承・拡張であり、式を覚え直す必要はない。
> - 巻4から読み始める場合は、巻2のHandScore・簡易レンジスコア・後手スコア・ポットオッズ・SPRを事前に把握しておくと理解が大幅に速まる。
> - 「後手下限」は巻2の「MDF」と同じ概念を3系統の表現に整理したものである。
