# 第8章　α式 ─ リバー配分の式

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: α式を完全に導出し、ベットサイズからバリューとブラフの最適比率を暗算で求められるようになる。先手（ベット側）の視点から、リバーの「配分設計」を数学的に理解する。

---

## 8-1 第5章の続き ─ 「バリューかブラフか」の二択に戻る

第5章でリバーの根本的な特性を確認しました。リバーではセミブラフが存在しない。エクイティは二値に収束する。ハンドは「バリューベット」「ブラフ」「チェック」の三択に振り分けられる。

本章ではその三択の中の「バリューとブラフをどう配分するか」という問いを数学的に解きます。

リバーでバリューとブラフを組み合わせてベットする場面を想像してください。相手は、あなたのベットに対してコールかフォールドかを選択します。ここで次の問いが生まれます。

**「相手がコールしても損せず、フォールドしても損しないためには、バリューとブラフをどんな比率で混ぜればよいか？」**

この問いへの答えがα式です。

α式は数学的に確定した式です。ソルバーで「だいたいこの辺」と推定するものではありません。ベットサイズが決まれば、最適な比率は式から一意に決まります。本章ではその式の導出を丁寧に追い、次章（第9章）の後手スコアへの橋渡しまでを完成させます。

---

## 8-2 α式の定義

まずα式を定義します。

```
α = ベット額 ÷ (ポット + ベット額)
```

αは「先手がブラフを打ったとき、それが利益になるための最低フォールド頻度」です。言い換えると、「ブラフの損益分岐点となるフォールド率」です。

相手がフォールドする頻度がαを上回れば、ブラフはプラスEVになります。下回れば、ブラフはマイナスEVです。

そしてここから、4つの関係式が導出されます。

```
α = ベット額 ÷ (ポット + ベット額)          ← ブラフの損益分岐点フォールド率
後手下限確率 = 1 − α                         ← 後手（コール側）の最低防御率
最適バリュー比率（コンボ上限）= 1 − α        ← ベットレンジ中のバリューの割合の上限
最適ブラフ比率（コンボ上限）= α              ← ベットレンジ中のブラフの割合の上限
```

この4つの関係は、ひとつの式から派生します。覚えるのはαだけで十分です。

---

## 8-3 数学的導出 ─ インディファレンス点の証明

なぜαでブラフ比率が決まるのか。数学的な根拠を追います。

### ブラフのEV計算

先手がブラフをベットするとします。相手がフォールドする確率をf、コールする確率を(1−f)とします。ポットをP、ベット額をBとします。

```
ブラフのEV = f × P − (1−f) × B
```

- 相手がフォールドすれば現在のポットPを獲得
- 相手がコールすれば、ブラフがコールされるため負けてB（ベット額）を失う

ブラフのEVがゼロになる（損益分岐点の）条件を求めます。

```
f × P − (1−f) × B = 0
f × P = (1−f) × B
f × P = B − f × B
f × P + f × B = B
f × (P + B) = B
f = B ÷ (P + B)
```

これがαです。

```
α = B ÷ (P + B) = ベット額 ÷ (ポット + ベット額)
```

相手がフォールドする確率がαを超えれば、ブラフはプラスEVです。下回れば、マイナスEVです。

### バリュー/ブラフ比率の導出

次に「相手がコールすべき最低頻度（後手下限確率）」から、先手のブラフ比率を逆算します。

相手が均衡的に振る舞うとき、コールしてもフォールドしてもEVが同じになる状態（インディファレンス）が成立します。

相手がコールを選ぶことで利益を得るためには、先手のベットレンジに「十分なブラフが含まれている」必要があります。逆に先手はブラフを「ちょうど相手がインディファレントになる比率」に留めれば、相手のコール/フォールドの選択によって搾取されません。

その均衡比率が、ベットレンジに占めるブラフの割合として「α」です。バリューの割合は「1 − α」です。

つまり、ベットレンジ中のバリューコンボとブラフコンボの比率は次のようになります。

```
バリュー : ブラフ = (1 − α) : α = ポット : ベット額
```

これが「V:B比率」の正体です。ポット対ベット額の比率が、そのままバリュー対ブラフの比率になります。

## 8-4 巻2の後手下限との関係

巻2（フロップ編）第13章で、後手下限という概念を学びました。後手下限とは「相手のブラフが利益にならないよう、コール側が確保すべき最低防御率」です。

ここで本章のαとの関係を明確にします。

```
後手下限確率 = 1 − α = ポット ÷ (ポット + ベット額)
```

この式は巻2で示したものと数値的に完全に等価です。表記や立場が違うだけで、同じ関係を表しています。

**立場の違い**

| 視点 | 概念 | 式 | 意味 |
|---|---|---|---|
| 先手（ベット側） | α | B ÷ (P + B) | ブラフの損益分岐フォールド率 |
| 後手（コール側） | 後手下限確率 | P ÷ (P + B) = 1 − α | 最低防御率（コール率の下限） |

αと後手下限確率は同じ硬貨の表と裏です。ポット50、ベット50の場面では、α = 50/(50+50) = 0.50、後手下限確率 = 1 − 0.50 = 0.50 です。

巻2ではコール側（後手）の視点から「どのくらいコールすべきか」を学びました。本章では先手側の視点から「ブラフをどのくらい混ぜるべきか」を学んでいます。どちらも同じ均衡点を、異なる角度から見ています。

この同値性を意識することで、巻2で身についた後手の感覚を、本章の先手設計に直接転用できます。

## 8-5 ベットサイズ別α早見表

αの値はベットサイズが決まれば即座に計算できます。よく使われるベットサイズについて、事前に計算しておきます。

| ベットサイズ | 計算式 | α（ブラフ比率上限） | 後手下限確率 | V:B比率 |
|---|---|---|---|---|
| 33% pot | 33/(100+33) | 0.25（25%） | 0.75（75%） | 3:1 |
| 50% pot | 50/(100+50) | 0.33（33%） | 0.67（67%） | 2:1 |
| 75% pot | 75/(100+75) | 0.43（43%） | 0.57（57%） | 約4:3 |
| 100% pot | 100/(100+100) | 0.50（50%） | 0.50（50%） | 1:1 |
| 125% pot | 125/(100+125) | 0.56（56%） | 0.44（44%） | 約4:5 |
| 150% pot | 150/(100+150) | 0.60（60%） | 0.40（40%） | 2:3 |
| 200% pot | 200/(100+200) | 0.67（67%） | 0.33（33%） | 1:2 |

（ポット = 100 を基準として計算。αはベットサイズ比率のみで決まるため、絶対額は不問）

この表は巻2の「ポットオッズ早見表」と整合しています。巻2で示した「50%ベットに対する必要勝率25%」は、後手下限確率の残余（コール側が確保すべき最低率）と同じ考え方から導かれています。

### 読み方のポイント

1. **ベットが小さいほどブラフは少なくなる**: 33%ベットではブラフ25%しか許されない。相手は75%という高いコール率を持つため、ブラフを多く混ぜても「すぐ捕まる」
2. **ベットが大きいほどブラフが増える**: 150%ベット（オーバーベット）では60%がブラフでよい。相手のコール率が40%まで下がるため、ブラフを多く打っても相手は捕まえきれない
3. **ポットサイズベットがちょうど50:50**: 直感的な均衡点として覚えやすい

## 8-6 バリュー：ブラフ比率の実例

早見表を実際の手牌設計に応用する例を示します。

### 例1: 50%ポットベット（α = 0.33）

ポット100、ベット50の場面。

```
α = 50 / (100 + 50) = 0.33
後手下限確率 = 1 − 0.33 = 0.67
V:B比率 = 0.67 : 0.33 ≈ 2:1
```

バリューコンボが10個あるなら、混ぜてよいブラフは最大5個（10個の半分）。10:5 = 2:1の比率です。

### 例2: 75%ポットベット（α = 0.43）

ポット100、ベット75の場面。

```
α = 75 / (100 + 75) = 0.43
後手下限確率 = 1 − 0.43 = 0.57
V:B比率 = 0.57 : 0.43 ≈ 4:3
```

バリューコンボが12個あるなら、混ぜてよいブラフは最大9個（12 × 43/57 ≈ 9個）。

### 例3: 150%ポットベット（オーバーベット、α = 0.60）

ポット100、ベット150の場面。

```
α = 150 / (100 + 150) = 0.60
後手下限確率 = 1 − 0.60 = 0.40
V:B比率 = 0.40 : 0.60 = 2:3
```

オーバーベットではブラフがバリューを上回ります。バリューコンボが8個あるなら、混ぜてよいブラフは最大12個（8 × 60/40 = 12個）。この数値は、一見するとブラフが多すぎるように感じますが、相手は150%ベットに対して40%しかコールしないため、ブラフが捕まる頻度も低くなります。

## 8-7 インディファレンスの意味 ─ なぜ均衡が重要か

「インディファレンス」とは、相手がコールしてもフォールドしてもEVが変わらない状態です。

なぜこの点が重要なのでしょうか。

相手が最適に振る舞っているとき、先手のベットレンジが均衡比率（V:B = (1−α):α）を満たしていれば、相手はコールとフォールドのどちらを選んでも同じEVになります。この状態では、相手はどちらを選んでも先手を搾取できません。

逆に、先手がこの比率を崩すとどうなるか。

**ブラフを増やしすぎた場合（ブラフ > α）**

相手は常にコールすることで利益を得られます。ブラフが多い場合、コールEVがフォールドEVを上回るからです。相手の最適な反応は「コールし続ける」であり、先手のブラフは機能しなくなります。

**バリューを増やしすぎた場合（ブラフ < α）**

相手は常にフォールドすることで利益を得られます。バリューが多い場合、フォールドEVがコールEVを上回るからです。相手の最適な反応は「フォールドし続ける」であり、先手はバリューからの最大利益を得られなくなります。

均衡比率を守ることは、相手がどちらを選んでも搾取されないための「防衛線」です。実戦では完全な均衡は不要ですが、大きく崩れると相手に明確な搾取機会を与えます。

この均衡の感覚は、相手の傾向に応じた「意図的な崩し」の前提にもなります。フォールドしすぎる相手にはブラフを増やし、コールしすぎる相手にはバリューを増やす。その「崩し幅」を意識するためにも、まず均衡比率を知っておくことが出発点です。

## 8-8 逆算用法 ─ バリューから「ブラフの枚数」を計算する

実戦では「何枚のブラフを混ぜるか」を決める方向でα式を使います。この逆算用法を練習します。

### 逆算の手順

1. リバーでのベットサイズを決める
2. そのベットサイズからαを計算する
3. バリューコンボの数を数える
4. ブラフ上限数 = バリューコンボ数 × α / (1 − α) で計算する

### 計算例

ポット100、ベット75（75%ポット）の場面で考えます。

```
ステップ1: ベットサイズ = 75% pot
ステップ2: α = 75 / (100 + 75) = 75 / 175 ≈ 0.43
ステップ3: バリューコンボを数える → 例えば7個（ナッツ〜強バリュー）
ステップ4: ブラフ上限 = 7 × 0.43 / 0.57 = 7 × 0.75 ≈ 5個
```

バリュー7個に対して、ブラフは最大5個まで。実際には枚数がぴったり合うことはまれですが、「バリュー7個に対してブラフ5個程度」という感覚が設計の出発点になります。

### 暗算の簡略化

V:B比率から直接ブラフ数を求める方法が実戦では速いです。

```
33%ベット → V:B = 3:1 → バリューの1/3がブラフの上限
50%ベット → V:B = 2:1 → バリューの1/2がブラフの上限
75%ベット → V:B ≈ 4:3 → バリューの3/4がブラフの上限
100%ベット → V:B = 1:1 → バリューと同数がブラフの上限
150%ベット → V:B = 2:3 → バリューの1.5倍がブラフの上限
```

この「バリューの●倍がブラフの上限」という感覚を持っておくと、実戦でのレンジ設計が速くなります。

## 8-9 実践計算例 ─ ポット100、ベット75

本章の例題として、具体的な計算を一問やります。

**状況**: ポット100、ベット75（75%ポット）。バリューコンボは9個。

**問い**: α、後手下限確率、最大ブラフ枚数を求めてください。

```
α = 75 / (100 + 75) = 75 / 175 ≈ 0.43

後手下限確率 = 1 − 0.43 = 0.57

最大ブラフ枚数 = 9 × (0.43 / 0.57) = 9 × 0.75 ≈ 7個
```

つまり、このシナリオでは「バリュー9個、ブラフ7個以下」がバランスのとれたベットレンジです。ブラフを8個以上混ぜると、相手にコールし続ける動機を与えます。ブラフを3個以下にすると、相手にフォールドし続ける動機を与えます。

## 8-10 次章（後手スコア）への橋渡し

α式は「先手（ベット側）の視点」で設計された式です。ベットサイズを決め、バリューを数え、ブラフの上限を計算する。この流れが先手の仕事です。

一方、コールを受ける後手側には別の判断が必要です。相手のベットに対して「どのくらいコールすべきか」「どのハンドでコールし、どのハンドでフォールドするか」という問いです。

第9章の後手スコアは、この後手側の問いに答える式です。

α式と後手スコアは表裏の関係にあります。

```
α式（先手視点）: ベットサイズ → ブラフ比率の上限を設計する
後手スコア（後手視点）: ベットサイズ + ハンドクラス → コール/フォールドを判断する
```

α = 0.43（75%ベット）なら、後手下限確率 = 0.57。後手は57%以上のコール率を維持しなければなりません。後手スコアは、この57%というコール率を「どのハンドでコールし、どのハンドでフォールドするか」に変換する計算式です。

α式でリバーの「配分」を理解したら、第9章で「守り方」を学びます。攻撃と防御、同じ均衡点を双方向から捉えることで、リバーの判断が立体的に理解できます。

## ミニクイズ

### 問1

ポット 80、ベット 40（50%ポット）の場面でα（ブラフの損益分岐フォールド率）はいくつですか。

1. 0.25（25%）
2. 0.33（33%）
3. 0.40（40%）
4. 0.50（50%）

### 問2

150%ポットのオーバーベットをするとき、バリューとブラフの最適比率（V:B）として正しいものはどれですか。

1. バリュー75%、ブラフ25%（3:1）
2. バリュー67%、ブラフ33%（2:1）
3. バリュー40%、ブラフ60%（2:3）
4. バリュー50%、ブラフ50%（1:1）

### 問3

リバーで75%ポットのベット（α = 0.43）をするとき、バリューコンボが12個あります。混ぜてよいブラフの最大数として最も近いものはどれですか。

1. 4個
2. 6個
3. 9個
4. 12個

---

### 解答

- **問1**: 2（α = 40 / (80 + 40) = 40 / 120 ≈ 0.33。後手下限確率は1 − 0.33 = 0.67で、相手は67%以上コールすべき）
- **問2**: 3（150%ベットのα = 150 / (100 + 150) = 0.60。ブラフ比率の上限が60%、バリューが40%。V:B = 40:60 = 2:3。オーバーベットではブラフがバリューを上回る）
- **問3**: 3（α = 0.43なのでV:B ≈ 4:3。ブラフ上限 = 12 × (0.43/0.57) = 12 × 0.75 = 9個。バリュー12個に対してブラフ9個）

---

> **本章まとめ**
>
> - α = ベット額 ÷ (ポット + ベット額) が「ブラフの損益分岐フォールド率」
> - 後手下限確率 = 1 − α は巻2で学んだ概念と数値的に等価。立場（先手/後手）が違うだけ
> - バリュー比率の上限 = 1 − α、ブラフ比率の上限 = α
> - ベットが大きいほどブラフの比率が上がる（150%ベットではブラフがバリューを上回る）
> - 逆算: ブラフ上限数 = バリューコンボ数 × α / (1 − α)
> - α式は先手の設計ツール。後手側の判断ツールが第9章の後手スコア

**【GTOとのズレ】**

α式が示すV:B比率は「均衡状態での上限値」です。実戦では2つの大きなズレが起きやすいです。

ひとつ目は「バリューコンボの過剰カウント」です。自分がバリューとして数えたハンドが、実際には相手のコールレンジに対して55%程度しか勝率がない場合があります。こうした「薄いバリュー」はGTOでは小さなサイズのベットにのみ組み込まれることが多く、75%以上のベットサイズではチェックに回ることもあります。バリュー候補を「コールされて勝つ確率が高いハンド」に絞り込む習慣が必要です。

ふたつ目は「ブラフの質の無視」です。α式は「ブラフ枚数の上限」を示しますが、「どのハンドをブラフにするか」には触れていません。実戦では、ブラフに使うハンドの選択が大きく結果を左右します。ナッツブロッカーを持つハンドのブラフは相手のコール率を下げ、逆にナッツをアンブロックするハンドのブラフは相手が多くコールしてきます。ブラフの「枚数」と「質」は別の問題です。ブロッカー選択の詳細は第10章で扱います。

また、α式は「相手が均衡的にコールする」という前提で成り立ちます。コールしすぎる相手（フィッシュ）に対してはブラフを減らし、フォールドしすぎる相手に対してはブラフを増やす搾取調整が必要です。式はバランスの基準点であり、出発点にすぎません。
