# 第4章　ターンの位置づけ ─ リバーから逆算する

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ターンが「リバーで何が起きるかを予測してから判断するストリート」である理由を理解し、巻5で習得した α 式・後手スコア（リバー版）・ポットコミットメントをターン判断の予測材料として使えるようになる。

---

## 4-1 ターンの本質 ─ 将来カードがある最後のストリート

本書はここまで、第1章でシリーズ全体の圧縮哲学を、第2章でレンジ強度の概念を、第3章でフロップからターンへのレンジ遷移を扱ってきました。本章では「ターンというストリートそのものが持つ構造的な特性」を整理します。

ポーカーの全ストリートの中で、ターンは特異な位置にあります。

```
プリフロップ: 全カード未知、確率分布が支配
フロップ:     3枚のボードが確定、2枚が残る
ターン:       4枚目が確定、リバーの1枚を予測する段階
リバー:       全カードが揃い、純粋な現在価値の勝負
```

リバーは「将来カードがない確定ゲーム」です。巻5 第1章で確認したとおり、ドローが完成または失敗し、エクイティが確定します。先手がすることは「バリューベット・ブラフ・チェックへの配分」であり、後手がすることは「コールかフォールドの二択」です。構造がシンプルだからこそ、α 式という単一の式でリバー全体の配分設計が成立しました。

ターンはそのリバーの1枚手前にあります。将来カードがまだ1枚残っているため、判断は「現在価値だけ」では完結しません。

```
ターン判断 = 現在のハンド価値 + リバーで起きることの予測
リバー判断 = 現在のハンド価値のみ
```

この式の差が、ターンをポーカー全ストリートの中で最も「重い」判断ストリートにしています。フロップでもリバーでも必要でない「リバー全体を見越した設計」が、ターンには要求されます。

---

## 4-2 リバーから逆算する ─ 4つの問い

ターン判断の核心は、ベットを打つ前に「リバーで何が起きるか」を頭の中で概算することです。これを backward induction（後ろ向き帰納）と呼びます。ゲーム理論では、最終局面から逆算して現在の判断を確定させる手法です。

ターンでベットする前に、以下の4問いに答えてください。

```
問1. リバーで自分は何を value bet するか？
     → バリューとして機能するハンドが残っているか

問2. リバーで自分は何を bluff するか？
     → ブラフとして機能するハンドが残っているか

問3. リバーで相手の call/fold ラインはどこか？
     → 相手が何を打ってくるか、それに対してどう応じるか

問4. リバーまでにコミットしてしまうか？
     → ターンベット後のSPRが「降りられない」閾値を越えないか
```

各問いは、巻5で習得した暗算式に直結します。

| 問い | 対応する概念 |
|---|---|
| 問1・問2（バリュー/ブラフの配分） | 巻5 第6章で見た **α 式** |
| 問3（相手のコール/フォールドライン） | 巻5 第7章で見た **後手スコア（リバー版）** |
| 問4（コミット閾値） | 巻5 第13章で見た **ポットコミットメント** |

この4問いを 5秒で頭の中で通過できれば、ターンのベット判断は「理由のあるベット」になります。逆に4問いをすっ飛ばして直感でベットすると、「なぜこのベットを打ったのか」が後で再現できなくなります。

**理由なきベットはターンでは特に痛い**ことを覚えておいてください。リバーと違い、ターンのベットは「次のストリートも想定している」という意思表示です。その意思の裏付けとなるリバー予測がなければ、ベットの根拠がありません。

## 4-3 問1・問2 ─ α 式でリバーのバリュー/ブラフ配分を予測する

巻5 第6章で導出した α 式を振り返ります。

```
α = ベット額 ÷ (ポット + ベット額)
後手下限確率 = 1 − α
```

α は「先手がブラフを打ったとき、それが利益になるための最低フォールド頻度」です。相手が後手下限確率以上の頻度でコールすれば、先手のブラフはマイナス EV になります。これにより、バリューとブラフを最適比率で混ぜたベットレンジが成立します。

ターンでこの式を使うのは、「リバーで何を打てるか」を予測するためです。

たとえばリバーに 50BB のポットが出来上がる想定があるとします。リバーでハーフポット（25BB）ベットを打てば α = 25 ÷ 75 ≈ 0.33 で、後手下限確率は 67% です。この場合、リバーのベットレンジ中にバリューが 2、ブラフが 1 の比率（2:1）でなければバランスが崩れます。

ターンでベットするとき、あなたはリバーに持ち越すハンドを選んでいます。バリューに分類できるハンドが十分あるか、ブラフに分類できるハンドが適切な比率であるか、これをα 式から逆算して確認してから打つのがターンの判断です。

具体的な α 式の使い方は第6章（バレルスコア）と第7章（後手スコア・ターン版）で扱います。本章では「ターン判断でリバーの α 式を予測材料として使う」という関係性だけ押さえてください。

## 4-4 問3 ─ 後手スコア（リバー版）で相手のコールラインを推定する

巻5 第7章の後手スコア（リバー版）を振り返ります。

```
後手スコア = HandScore + A − 3 − C − M

後手スコア ≥ 8 → チェックレイズ検討
後手スコア 0〜7 → コール
後手スコア < 0 → フォールド
```

ターンでこの式を「相手の目線で」使います。

相手は今どんなハンドを持っているか。それに対してあなたがターンでベットした場合、相手は後手スコアを（意識的・無意識的に）計算して行動を選択します。相手の後手スコアが低ければフォールドする頻度が高まり、高ければコールまたはチェックレイズが増えます。

ターンでベットを選ぶとき、「相手は何を持っているか、そのハンドは後手スコアがどの水準か」を推定することで、ターンベットの期待値を概算できます。

ただし、ターンとリバーの後手スコアには違いがあります。最大の違いは「ドロー加点が残るかどうか」です。ターンでは、相手がフラッシュドローや OESD を持っている場合、そのドロー加点がコール方向に働きます。この点が「リバーで相手は何をコールするか」を予測することよりも難しい部分です。

ターン版の後手スコアの詳細は第7章で扱います。本章では「ターンで打つベットは、リバーでの相手のコールラインを変化させる」という概念的なつながりを確認してください。

## 4-5 問4 ─ SPR の低下とコミット閾値

巻5 第13章のポットコミットメントは「コール EV がゼロ以上になる状態」の計算でした。

```
コミット条件: 勝率 ≥ ポットオッズ（= コール額 ÷ (ポット + コール額)）
```

ターンに入るとき、SPR（Stack-to-Pot Ratio：残スタックとポットの比率）はフロップから大きく変化しています。

```
【例: 100BB, BTN vs BB, フロップ CBet 1/3 ポット後】

プリフロップ後のポット:   約 7BB
フロップ CBet:            約 2.3BB（1/3 ポット）
BB コール:                約 2.3BB
──────────────────────────────
ターン開始時のポット:      約 12BB
BTN の残りスタック:        約 95BB

フロップ開始時 SPR = 97 ÷ 7   ≈ 14
ターン開始時   SPR = 95 ÷ 12  ≈ 8
```

SPR が 14 から 8 に低下しました。この低下が意味することは、「コミット閾値が近づいた」という事実です。

```
SPR と「残り何回打てるか」の目安:

SPR 8: ハーフポットを 2 回で SPR 約 2 → コミット圏
SPR 8: ポット相当を 1 回で SPR 約 4 → 次でコミット圏
```

巻5 第13章で見た SPR < 1 はコミット確定のラインは、ターンのベット選択を通じて「いつそこに到達するか」が決まります。

問4の問い「リバーまでにコミットしてしまうか」は、ターンベット後のポットと残スタックを試算することで確認できます。強いバリューハンドなら、意図的にコミット軌道に乗せることが最大 EV になる場合があります。弱いハンドでは、意図せずコミット圏に入ることを避けるためにベットサイズを抑える判断が生じます。

| ターン開始時 SPR | 判断の特性 |
|:---:|---|
| 10 以上 | 余裕あり。ターンのサイズ選択の自由度が高い |
| 6〜10 | 重要な帯。ターンのサイズがリバーの残額と連動する |
| 3〜6 | コミット圏が迫っている。弱いハンドのベットは危険 |
| 3 未満 | 事実上コミット圏。強いハンドはターンまたはリバーでオールインを見据える |

SPR 6〜10 の帯が実戦で最も判断が難しい領域です。ターンベット後に相手がコールまたはレイズしてくると、リバーの選択肢が大きく変わります。この帯ではターンのサイズを決める前に、リバーの残額を先に計算することをおすすめします。

## 4-6 ターンカードがレンジを動かす ─ 予測コストが最も高いストリート

問1〜4 を回答するうえで、重要な前提があります。ターンカードが落ちることで双方のレンジが更新されることです。

ターンカードは次の 5 種類に大別されます（詳しくは第5章）。

| ターンカード種別 | 代表的な影響 |
|---|---|
| ペアリング | ツーペアやフルハウスが急増。ナッツの分布が大きく変化する |
| オーバーカード | それまでのトップペアが格下げになる。レンジ全体の強度が揺れる |
| フラッシュ完成 | フラッシュドローが完成し、一部ハンドの価値が急騰する |
| コネクター | ストレートが完成し、ナッツアドバンテージが変わる場合がある |
| ブランク | 上記のどれにも当たらず、レンジの変化が小さい |

ターンでのリバー予測が「リバー判断そのもの」より難しいのは、ターンカードの種類によって 4 問いの答えがすべて変わるからです。

具体的に考えてみます。フロップ K♣7♦2♠ で BTN が CBet し、BB がコールした状況でターンを迎えます。

ターンに J♥（オーバーカード）が落ちた場合。BB がフロップでコールし続けたハンドの中には、フロップではセカンドペアや弱いドローだった J♥ を含むハンドがあります。そのハンドがターンでトップペアに昇格します。「問3: 相手のコールラインはどこか」の答えが変わります。

ターンに 7♥（ペアリング）が落ちた場合。フロップのボードは K-7-2 となり、7 がペアになります。BTN が KK を持っていればフルハウス（K's full of 7's）、77 を持っていればクワッズ（4 7's）に昇格します。BB が AK を持っていればツーペア（K's & 7's）になります。「問1: リバーで何をバリューベットするか」の候補が変わります。

このように、ターンカードが変わるたびに 4 問いの答えも更新されます。リバーには将来カードがないため「次に何が落ちるか」を予測する必要はありません。ターンにはそれが必要です。これが「予測コストが最も高いストリート」という表現の中身です。

## 4-7 ターン判断の起点 ─ 3 つのチェックリスト

4 問いを回答するためには、以下の 3 つを毎局面で確認してください。

**チェック 1: フロップからのレンジ遷移**

第3章で体系化したレンジ遷移を確認します。

- 自分のレンジは Capped か Uncapped か
- 相手のレンジは Capped か Uncapped か

「CBet した = Uncapped、チェックバックした = Capped」「コールした = Capped、チェックレイズした = Uncapped」という基本を起点に、フロップのアクション履歴から現時点のレンジ性質を確定させます。

**チェック 2: ターンカードがどう動かしたか**

ターンカードが 5 分類のどれに当たるかを判断します（第5章で詳細）。

- 自分のレンジを強化したか、弱めたか
- 相手のレンジを強化したか、弱めたか
- ナッツアドバンテージはどちらが持つか

チェック 1 で確定したレンジの非対称性が、チェック 2 によって更新されます。

**チェック 3: リバー予測**

4 問いを頭の中で通過します。

- リバーで自分は何をバリューベットするか（α 式を逆算）
- リバーで相手のコールラインはどこか（相手の後手スコアを推定）
- リバーまでコミットするか（SPR とポットオッズを試算）

3 つのチェックを経て、はじめて「ターンでベットするかチェックするか」の判断に進みます。

## ミニクイズ

### 問1

ターンでベットする前に「リバーで何が起きるか」を予測してから判断する思考法を何と呼びますか。

1. フォワードインダクション（forward induction）
2. バックワードインダクション（backward induction）
3. ゲームツリーの再帰探索

---

### 問2

BTN vs BB、100BB。フロップ K♣7♦2♠ で BTN が 1/3 ポットの CBet を打ち、BB がコールしました。ターン開始時の SPR として最も近い値はどれですか（プリフロップポット約 7BB、フロップ CBet 約 2.3BB）。

1. SPR 約 14
2. SPR 約 8
3. SPR 約 4

---

### 問3

リバーのポットが 50BB になる想定で、あなたはリバーにハーフポット（25BB）ベットを打つ計画を立てています。巻5 第6章で見た α 式によると、このベットに対してベットレンジ中のバリューとブラフの比率はどうなりますか。

1. バリュー 1 : ブラフ 1（1:1 の比率）
2. バリュー 2 : ブラフ 1（2:1 の比率）
3. バリュー 3 : ブラフ 1（3:1 の比率）

---

### 解答

- **問1**: 2（ターン判断では最終ストリートであるリバーの結果を先に概算してから、現在のターンの判断を確定させます。これがバックワードインダクション、後ろ向き帰納法です）
- **問2**: 2（ターン開始時のポットは約 12BB、残スタックは約 95BB。SPR = 95 ÷ 12 ≈ 8。フロップ開始時の SPR 約 14 から大きく低下しています）
- **問3**: 2（α = 25 ÷ (50 + 25) = 25 ÷ 75 ≈ 0.33。バリューとブラフの最適比率はバリュー（1−α）: ブラフ α = 0.67 : 0.33 ≈ 2 : 1 です。相手が後手下限確率 67% 以上でコールすれば、ブラフの EV はゼロになります）

> **本章まとめ**
>
> - ターンは「将来カードがある最後のストリート」であり、判断は「現在のハンド価値 + リバーで起きることの予測」で成立する
> - backward induction（後ろ向き帰納）として、リバーの結果を先に概算してからターンのアクションを選ぶ
> - ターン判断の核心は 4 問い：リバーのバリュー候補、リバーのブラフ候補、相手のコールライン、コミット閾値
> - 4 問いの答えは巻5 第6章の α 式・第7章の後手スコア（リバー版）・第13章のポットコミットメントから得られる
> - フロップ→ターンの SPR 低下（約 14 → 約 8）により、コミット閾値がターンベットの射程に入ってくる
> - ターンカードが双方のレンジを更新するため、5 分類（第5章）を使って 4 問いの前提を毎局面で更新する

---

**【GTOとのズレ】**

GTOソルバーはターン判断において、本章で示した 4 問いを事実上「リバー全体のゲームツリーをすべて計算してから出力」する形で実行します。すべての可能なリバーカードに対するレンジの反応を計算し、その期待値の平均を取ってターンのベット頻度を決定します。これは人間が暗算で再現できる水準ではありません。

本書の暗算式が行うのは、その計算の「主要なシナリオだけを頭に置く」近似です。リバーカードの全種類を考慮する代わりに、「ナッツ候補のリバーカード」「最も影響の大きいリバーカード」だけを想定して α 式とポットコミットの計算をします。この近似によって 90% 程度の判断精度をカバーし、残りは実戦後のハンドレビューで補います。

実戦でGTOとのズレが最も生じる場面は、ターンカードが「どちらのレンジにも影響が小さい」ブランクカードのときです。ブランクターンでは「何も変わっていないからフロップと同じ感覚で打てばいい」と考えがちですが、GTOはブランクターンにおいても SPR の低下と相手の精密なコールレンジを計算したうえでベット頻度を調整しています。フロップのサイジング感覚のままターンを打ち続けると、特に SPR 6〜10 の帯で資金効率が下がります。

また、ドローが残っている相手のコールラインを過小評価するズレもよく見られます。後手スコアのドロー加点は、相手がコールを正当化する根拠になっています。相手のフラッシュドローを「どうせ外れる」と見切って過小ベットを選ぶと、相手のコールに有利なポットオッズを与える結果になります。ターンでの相手のドロー加点は、常に過小評価より過大評価を選ぶ方が安全です。
