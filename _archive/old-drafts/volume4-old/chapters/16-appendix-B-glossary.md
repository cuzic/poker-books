## A　3つの暗算式

### バレルスコア

ターンでIPがCBet（バレル）を打つかどうかを判定する暗算式。フロップの板タイプを示す**FlopType係数**とターンカードのレンジへの影響を示す**TurnCard係数**の足し算で求める。

```
バレルスコア = FlopType係数 + TurnCard係数
```

FlopType係数: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
TurnCard係数: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0

270シナリオのGTOソルバー実測から導出された係数であり、全17セルのGTO判定と一致する。Ch 6 参照。

### 積極バレル

バレルスコアが7以上のとき適用される判定。レンジ全体（ハンドを選ばず）でターンCBetを推奨する状態を指す。バレルスコアが6以下の場合は**ハンド依存**となり、HandScoreによる個別判断に切り替える。Ch 6 参照。

### α（アルファ）

先手（ベット側）がブラフを打ったとき、そのブラフが利益になるための最低フォールド率。「ブラフの損益分岐点フォールド率」とも言い換えられる。

```
α = ベット額 ÷ (ポット + ベット額)
```

ベットサイズが決まれば式から一意に決まる数学的に確定した値である。αを中心にバリュー比率・ブラフ比率・後手下限確率の4つの関係が派生する。巻5 Ch 6 参照。

### α 式

α の計算式全体を指す呼称。リバーのバリューとブラフの最適配分を設計するために使う。「Alpha 式」という表記は本書では使わない。巻5 Ch 6 参照。

### 後手下限

先手のベットに対して後手（コール側）が守らなければならない最低防御水準の概念。文脈に応じて3通りに使い分ける。

| 用語 | 用途 |
|---|---|
| **後手下限ライン** | しきい値・境界として語るとき |
| **後手下限確率** | 具体的な % 数値として語るとき |
| **後手下限スコア** | 後手スコアの式における判断境界として語るとき |

```
後手下限確率 = 1 − α = ポット ÷ (ポット + ベット)
```

75%ベットなら後手下限確率 ≈ 57%、50%ベットなら ≈ 67%、33%ベットなら ≈ 75%。巻5 Ch 6（α式）参照。本書では「MDF」という表記を使わない。

### 後手スコア（ターン・リバー拡張版）

巻2で導入した後手スコアの式をターン・リバーのボードテクスチャに合わせて再校正したもの。式の形は巻2から継承する。

```
後手スコア = HandScore + A − 3 − C − M

A（ボード値）: ドライ=3 / セミウェット=2 / ウェット=1
C（ベット負担）: 33%=3 / 50%=5 / 75%=7 / 100%=9 / 150%=11
M（マルチウェイ補正）: HU=0 / 3-way=3 / 4-way以上=6

後手スコア ≥ 8  → チェックレイズ（CR）検討
後手スコア 0〜7 → コール
後手スコア < 0  → フォールド
```

ターン・リバーではHandScoreをターンカードで更新すること、A値もターン4枚のテクスチャで評価し直すことが重要。Ch 7 参照。

### C値の拡張（100%・150%）

巻2の後手スコアではC値はベット33%=3 / 50%=5 / 75%=7 の3種類だった。巻4ではターン・リバーのオーバーベットに対応するため、100%ポット=9 / 150%ポット=11 を追加している。これにより後手スコアのCの定義域が広がり、オーバーベットへのディフェンス判断にも式が適用できる。Ch 7・Ch 12（ターンOB）・巻5（リバーOB）参照。

## B　ターンカードの5分類

### ペアターン

ターンカードのランクがフロップ3枚のいずれかと一致するカード。フロップで既にそのランクを持っていたプレイヤーのハンドが「昇格」（セット→クワッズ、2ペア→フルハウス等）するため、IPのナッツアドバンテージが強化される。TurnCard係数=4（最大値）。Ch 5 参照。

### ペアボードでのハンドエボリューション

ペアターンが落ちた後、各ハンドの役がどう変化するかを追跡すること。例として K-7-2 フロップにターン 7♥ が落ちた場合: AK（TPTK）→ 2ペア（K's & 7's）、77（セット）→ クワッズ（4 7's）、K7→ フルハウス（7's full of K's）。「AKがTPTKのまま」という誤認は典型的な落とし穴である。Ch 5・Ch 7 参照。

### オーバーカード（OC）ターン

ターンカードがフロップの最高ランクより高いカード。主にA・K・Qがこれに該当する。プリフロップのオープンレイザー（IP）のレンジにはAKQが豊富に含まれるため、OCターンはIPのレンジをより強化する傾向がある。TurnCard係数=3。Ch 5 参照。

### ブランクターン

ペア・OC・フラッシュ・コネクターのいずれにも当てはまらないカード。フロップ時点のナッツアドバンテージ関係が維持される。「ボードが変わったように見えて何も変わっていない」ターンカードで、フロップの優位をそのまま引き継ぐ。TurnCard係数=2。Ch 5 参照。

### フラッシュターン

3枚目の同スートが落ちることで、フラッシュドローが完成するターンカード。OOPのコールレンジにはフラッシュドローが多く含まれるため、フラッシュターンはOOPのレンジを強化し、IPの継続ベットを抑制する。TurnCard係数=1。Ch 5 参照。

### コネクターターン

ストレートドローを完成させる、またはストレート形成に大きく寄与するターンカード。ストレート系のコンボが完成・強化されるため、レンジ両者に影響し、IPの単独優位が薄れる。TurnCard係数=0（最小値）。Ch 5 参照。

### 5分類の優先順位（判定フロー）

ターンカードを分類するとき、次の順に確認する。

```
1. ペアか？     → フロップのいずれかのランクと一致する
2. OCか？      → フロップ最高ランクより高い
3. フラッシュか？ → 3枚目の同スートが揃う
4. コネクターか？ → ストレートドローを大きく強化する
5. ブランク      → 上記4条件のいずれにも該当しない
```

Ch 5 参照。

## C　戦略概念

### ダブルバレル

フロップでCBetを打ったIPが、ターンでも続けてベットするアクション。「2連続バレル」を意味する。バレルスコアを使ってハンド選択なし（積極バレル）かハンド依存かを判定する。Ch 9 参照。

### 遅延CBet（Delayed C-bet）

フロップでチェックバックしたIPが、ターンでOOPのチェックを受けて初めてベットに出る戦略。フロップのレンジ優位がターンカードで強化された際（特にOCやペアのターン）や、ポジション優位を活かした中長期的な戦略として用いる。Ch 9 参照。

### チェックバック（ターンの3用途）

フロップCBet後にIPがターンでチェックを選ぶ行為。巻4ではその目的を3つに分類して使い分ける。

```
用途1: SDV保護（ショーダウンバリューの確保）
  バリューにはわずかに足りないハンドをリスクなくショーダウンに持ち込む

用途2: トラップ（スロープレイ）
  強いハンドで相手のブラフを誘い、リバーでCRまたはコールして利益を最大化する

用途3: レンジバランス
  バレルスコアが低い局面でバリュー側のハンドをチェックに回し、
  ブラフのチェックバックと組み合わせてレンジを均衡させる
```

Ch 9・巻5 参照。

### ドンクベット

OOP（アウトオブポジション）のプレイヤーが、IPのアクションを待たずに先手でベットするアクション。「ドンクベット」という名称はGTOの観点では正当な戦略として再評価されており、特定の条件下（Cappedなレンジを持つIPへの圧力、レンジ優位が逆転した場面）で有効となる。Ch 10 参照。

### インダクトベット（罠張りチェック）

強いハンド（ナッツ〜準ナッツ）で相手のベットを誘うためにあえてチェックを選ぶ戦略。トラップ（スロープレイ）に似るが、「相手が特定のアクションを取りやすいボードテクスチャ」を意図的に選んで仕掛ける点で区別される。相手がブラフしやすい状況でチェックを入れ、ベットが来たらCRまたはコールで利益を最大化する。巻5 参照。

### ブラフチェックレイズ（BCR）

バリューではなくブラフとしてチェックレイズを打つ戦略。フォールドエクイティを利用してIPをフォールドさせることを主目的とし、必要最低限のアウツ（セミブラフ性）を持つハンドで実行することが多い。純ブラフのCRはリバーに限定される。Ch 10 参照。

## D　ハンドエバリュエーション用語

### TPTK / TPGK / TPWK

トップペアのキッカー強度による3分類。

| 略語 | 正式名 | 定義 |
|---|---|---|
| **TPTK** | Top Pair Top Kicker | トップペア + そのボードで最強のキッカー（例: KKボードのAKs等） |
| **TPGK** | Top Pair Good Kicker | トップペア + 中程度以上の強いキッカー（例: KKボードのQK, JK） |
| **TPWK** | Top Pair Weak Kicker | トップペア + 弱いキッカー（例: KKボードの2K, 5K） |

バリューベットライン・コールレンジを決める際にこの3分類で強度を整理する。Ch 7・巻5 参照。

### ハンドエボリューション

ターンカードやリバーカードが落ちることで、ハンドの役が変化すること。例として「フロップでAKがTPTKだったが、ターンのペアカードでボードがペアになりAKが2ペアに昇格する」など。「フロップ時点の役がそのまま続く」という思い込みを排除し、ストリートごとに役を更新して評価することが基本。Ch 5・Ch 7・巻5 参照。

### board itself plays（ボードイットセルフプレイズ）

ボードの5枚が既に完成ハンドを形成しており、全プレイヤーがそのボードの役（ストレートやフラッシュ）を共有している状態。例として A-K-Q-J-T の5枚連続ボードでは全員がブロードウェイストレートを持つため、チョップ（ポット折半）になりやすい。役が完全にボードに依存しているため、追加のバリューベットは機能しにくい。巻5（リバー特殊性）参照。

## E　応用シナリオ関連

### 3betポット

プリフロップで3bet（リレイズ）とそのコールが行われたポット。通常のシングルレイズドポット（SRP）と比較してポットが約3倍大きく、フロップ開始時のSPR（スタック対ポット比）は約4〜5に下がる。SPRが低いため、コミット判断が早く訪れ、セット以上の強いハンドがなくても「全スタックを失うリスク」が生じやすい。巻5 参照。

### マルチウェイバリューライン

3人以上のマルチウェイポットでバリューベットとして機能するための最低ハンド強度。HUと比べて1段階以上高い強度が必要になる。

```
HU  : トップペア（状況依存）でもバリューベット可
3way: 2ペア以上が最低バリューライン
4way+: セット以上が大ベットのライン
```

巻5 参照。

### M補正係数（マルチウェイ補正）

後手スコアの式に含まれるマルチウェイ用の係数。HU=0、3-way=3、4-way以上=6。プレイヤー数が増えるほど「最強ハンドである確率」が下がるため、ディフェンス閾値を引き上げる効果を持つ。HU前提で式を使う場合は M=0 として省略できるが、その際は「HU前提のため M=0」と必ず注記する。Ch 7・巻5 参照。

## F　運用関連

### gto_query.py

本書のGTOデータ参照に使用するコマンドラインツール。v7b蒸留モデル（TexasSolver互換）を使って特定のボード・レンジ・ストリートにおける推奨アクションとEVを実測できる。主なパラメータはボード・IP/OOPレンジ・ポット・スタック・ストリート・アクティブプレイヤー。出力はコンボごとのFOLD / CHECK_CALL / BET_SMALL / BET_LARGE / ALLIN の頻度と推奨アクション。誤差は数%程度のため、実測値を使う際は「v7b蒸留モデル実測」と出典を明記する。巻5 参照。

### EV差の判断基準

ソルバーレビューで推奨アクションと実際のアクションのEVを比較した際の差分。本書では次の目安で重要度を分類する。

```
EV差 < 0.1BB  → 誤差の範囲（混合戦略の差異が多い）
EV差 0.1〜0.5BB → 軽微なミス（ただし積み重なると大きな損失になる）
EV差 0.5〜1.5BB → 明確なミス（原因を特定して修正が必要）
EV差 > 1.5BB  → 重大なミス（判断の根本を見直す）
```

巻5 参照。

### ボード読み検証フロー

ハンド + ボードの組み合わせを書く・判断する際に踏む確認手順。以下の順で逐次確認することで、役の誤認・ストレートの見落とし・フラッシュの誤判定を防ぐ。

```
Step 1: ハンドカードとボードカードを全て列挙する
Step 2: ランク別にカウントしてペア・トリップス・クワッズを確認する
Step 3: 5枚連続をチェックしてストレートの有無を確認する
Step 4: スート別に5枚以上集まっているかチェックしてフラッシュを確認する
Step 5: ペアボードならボードペアがbest 5に入ることを確認する
```

特にペアターン後の役更新（TPTK→2ペア昇格等）の確認は必須。ターンカードを見てから手持ちのハンドの役を再計算しないことが最も多い誤りである。Ch 5・巻5 参照。

## G　レンジ概念（巻4 拡張分）

### Uncapped レンジ（アンキャップド）

ナッツ（そのボードで最強のハンド）を含む可能性があるレンジ。プリフロップのオープンレイザー、フロップのCBet打者、フロップのチェックレイズ打者のレンジは原則としてUncappedである。Uncappedなレンジを持つプレイヤーはオーバーベットを含む攻撃的なラインを実行できる。Ch 2 参照。

### Capped レンジ（キャップド）

ナッツが含まれていない、または非常に少ないレンジ。アクション上の理由でナッツが別のアクションに振り分けられた結果として生まれる。典型的な発生パターンは「フロップCBetをコールしたOOP」や「チェックバックしたIP」。Cappedなレンジはオーバーベットへの対応が困難であり、相手から搾取されやすい。Ch 2 参照。

### ナッツアドバンテージ

両者のレンジを比較したとき、一方が最強ハンド（ナッツ）をより多く保有している優位性。ナッツアドバンテージを持つ側は大きいベットサイズを使いやすく、相手にとってはコールの判断が難しくなる。ターンカードが落ちるたびにナッツアドバンテージが更新される。Ch 2・Ch 5 参照。
