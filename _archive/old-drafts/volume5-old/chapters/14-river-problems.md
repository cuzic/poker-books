# 第14章　リバー実戦例 20問

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 本書 第9章から第13章で学んだリバーの戦術を20問のドリルで定着させる。α式・後手スコア・ブロッカー論・ボード読みの検証を組み合わせて、リバー判断の精度を高める。

---

## 14-1 ドリルの目的と使い方

リバー戦略の学習は「原則を理解すること」と「実戦で即座に適用できること」の間に大きな溝があります。本章の20問は、その溝を埋めるためのドリルです。

各問題には次の3つの目的があります。

**目的1: 計算の定着**
α式・後手スコア・V:B比率は頭で理解しても、実戦では「咄嗟に使えない」状態が多いです。問題形式で繰り返すことで、計算を素早く回せるようにします。

**目的2: ボード読みの精度**
リバーでは「ボードが何を意味するか」の読み違いが判断ミスの根本原因です。ブロードウェイ（5枚連続ストレート）、フラッシュ（5枚同スート）、ペアボードでのハンド評価を具体例で確認します。

**目的3: 典型的な罠の認識**
「ポットが大きいからコール」「一応ペアがあるからベット」「オーバーペアだから守る」という感情的な判断パターンを、論理的に検出して修正します。

### ドリルの使い方

- 解答を見る前に自力で答えを出す
- 正解だった場合も「なぜその答えか」を言語化できるか確認する
- 不正解だった場合は「どの計算ステップで誤ったか」を特定する
- 第2部・第3部・第4部のどのカテゴリが苦手かを把握する

### 前提条件

- 6-max キャッシュゲーム、100BB スタック
- BTN（IP）vs BB（OOP）の heads-up（HU）でリバーに到達
- ポット・スタックは問題ごとに指定
- HU 前提のため、後手スコアの M=0（マルチウェイ補正なし）

## 14-2 第1部: IPのリバー攻撃判断（問1〜5）

α式とブロッカー論を使って、IPがバリューベット・ブラフ・チェックバックのどれを選ぶかを判断します。

---

### 問1

**状況**: BTN が フロップCBet → ターンバレルを打ち、リバーに到達。

**ボード**: K♥7♦2♣ Q♠ 4♥（5枚完成）
**ポット**: 22BB、BTN スタック: 88BB
**BTN のハンド**: A♦K♦（トップペア・トップキッカー）

BB がリバーでチェック。BTN はどうする?

```
A. バリューベット（75%ポット ≈ 16BB）
B. バリューベット（33%ポット ≈ 7BB）
C. チェックバック
D. ブラフ（75%ポット）
```

---

**解答: B（バリューベット 33%ポット）**

ボード読みの確認を先にします。

```
手札: A♦ K♦
ボード: K♥ 7♦ 2♣ Q♠ 4♥（5枚）
全カード: A♦ K♦ K♥ 7♦ 2♣ Q♠ 4♥

ランクカウント:
  K: 2枚（K♦ K♥）→ ペア
  A: 1枚
  Q: 1枚
  7: 1枚
  2: 1枚
  4: 1枚

ストレート確認:
  A-K-Q-J-T → J・T なし → 不成立
  K-Q-J-T-9 → J・T なし → 不成立

best5: A♦ K♦ K♥ Q♠ 7♦ → 2ペア（K's & ——）？
 → KK（ペア）+ AQが残る → 実際は A-K-K-Q-7 → 1ペア（KK）with A・Q kicker
 → より正確には: KK ペア（2枚）+ ボードにQ・4がある
 → AK はトップペア（K on K♥board）+ Aキッカー → TPTK
   ただし Q♠ が落ちているのでQ以上はOOPのコールレンジに含まれる
```

A♦K♦ はこのボードで「KKのペア（2枚）＋Aキッカー」です。5枚ボードで手札K♦がK♥とペアを作ります。TPTK（トップペア・トップキッカー）の強さがあります。

ただし Q♠ がリバーで落ちたことで、OOPのコールレンジの評価が変わります。

```
Q♠落ち後のOOPコールレンジ（想定）:
  強バリュー: KQ（2ペア K's & Q's）、QQ（セット）
  標準バリュー: Kx（トップペア、弱キッカー）
  ブラフキャッチャー: ポケットペア（JJ以下）

BTN の A♦K♦（TPTK）の勝率:
  KQ（2ペア）に負け、QQ（セット）に負ける
  KJ・KT・K9 等には勝つ
  ポケットペア（JJ以下）には勝つ
```

75%ポットの大きなバリューベットを打つと、コールしてくる OOP は主に KQ 以上の強いハンドになります。TPTK は KQ に負けるため、大きなサイズは「逆選択」になります。

**33%ポットの小さなベット**なら、KJ・KT・Kx 弱キッカーや JJ 以下のポケットペアからバリューを取れます。薄バリューには小さなサイズが適切です。

チェックバックはOOPに無料でショーダウンを与えます。A♦K♦はコールレンジの相当数に勝てるため、薄バリューとして小さなベットを選ぶのが正解です。

### 問2

**状況**: BTN が フロップCBet のみ打ち（ターンチェックバック）、リバーに到達。

**ボード**: 9♣8♦3♠ 2♥ K♠（5枚完成）
**ポット**: 14BB、BTN スタック: 92BB
**BTN のハンド**: K♥J♦（リバーでトップペア・弱キッカー）

BB がリバーでチェック。BTN はどうする?

```
A. バリューベット（75%ポット ≈ 10BB）
B. バリューベット（33%ポット ≈ 5BB）
C. チェックバック
D. ブラフ（100%ポット ≈ 14BB）
```

---

**解答: C（チェックバック）**

ボード読みの確認です。

```
手札: K♥ J♦
ボード: 9♣ 8♦ 3♠ 2♥ K♠（5枚）

ストレート確認:
  K-J: K-Q-J-T-9 → Q・T なし
  9-8: 9-8-7-6-5 → 7・6・5 なし（ただし 2がある: 2-3-8-9? 連続でない）
  A-5 ストレート: A-2-3-4-5 → A・4・5 なし

ランクカウント: K=2枚（K♥ K♠）→ K♥ で K♠ とペア
best5: K♥ K♠ J♦ 9♣ 8♦ → 1ペア KK、Jキッカー
```

K♥J♦ はこのボードで「KK ペア＋Jキッカー」です。TPWK（トップペア・ウィークキッカー）相当で、Jキッカーは弱い部類に入ります。

重要なのは **ターンをチェックバックした文脈**です。BTN がターンをチェックバックしたという情報を OOP は見ています。BTN のレンジは「強いバリューを欠く」と OOP に読まれています。

このとき BB がリバーでチェックを選ぶということは、BB のレンジも「強くない」か「誘っている」かどちらかです。

```
K♥J♦ の問題点:
  コールレンジに KQ・KT（より強いキッカー）が含まれる
  → KJ はトップペアだが、KQ・KK 等に負ける
  バリューとして打てる強さ: コールレンジの過半数に勝てるか？
  → K♥J♦ はコールレンジの KQ 以上のポーション（一定数存在）に負ける
  → 小サイズでも「コールレンジ全体に50%超勝てる」が成立するか不明瞭
```

ターンチェックバック後の BTN のレンジは弱化しています。K♥J♦ でのリバーベットは「ストーリーの不整合」も生み出します。ターンをパスした後にリバーでベットすると、OOP に「トップペアなら打つはず、なぜターンでパスした?」という疑念を与えません（むしろ警戒させます）。

チェックバックでショーダウン価値を守るのが正解です。

### 問3

**状況**: BTN がフロップCBet → ターンダブルバレルを打ち、3バレル設計でリバーに到達。

**ボード**: K♠8♥3♥ J♥ A♥（5枚完成）
**ポット**: 26BB、BTN スタック: 84BB
**BTN のハンド**: A♣T♥（リバーでトップペア + ブロッカー）

BB がリバーでチェック。BTN はどうする?

```
A. バリューベット（75%ポット ≈ 19BB）
B. ブラフ（75%ポット ≈ 19BB）
C. チェックバック
D. バリューベット（33%ポット ≈ 9BB）
```

---

**解答: C（チェックバック）**

このボードでまずフラッシュの確認が最重要です。

```
手札: A♣ T♥
ボード: K♠ 8♥ 3♥ J♥ A♥（5枚）

スート別カウント:
  ハーツ（♥）: T♥ 8♥ 3♥ J♥ A♥ = 5枚 → フラッシュ完成！
  スペード: K♠ = 1枚
  クラブ: A♣ = 1枚

T♥ はハーツフラッシュに参加。
A♣ はクラブのため、ハーツフラッシュには参加しない。

best5のフラッシュランク:
  ハーツ5枚: A♥ J♥ T♥ 8♥ 3♥ → A-high flush（A♥が最高位）
  ただし A♣T♥ のうち T♥ はハーツ、A♣ はクラブ
  → A♣ はフラッシュ不参加
  → best5 = A♥ J♥ T♥ 8♥ 3♥ → Aハイフラッシュ（ボードのA♥が最高位）

BTN の A♣T♥ でのフラッシュ役:
  T♥（ハーツ）+ ボードのA♥J♥8♥3♥ = 5枚ハーツ → Tハイフラッシュ
  ナッツではない（A♥はボードにあるが、BTN は A♣ = クラブ）
  セカンドナッツ相当（A♥を持っている人が最強）
```

A♣T♥ はリバーで「T-high flush（ハーツ）」です。ナッツはボードにある A♥ を含むハンド（例: A♥x♥、または K♥x♥ がK-high flush）です。

BTN のフラッシュは OOP の A♥x♥ には負け、8♥x♥・J♥x♥ のフラッシュには勝ちます。A♣ のブロッカーは「A♥ を持った OOP の A-high flush」を削る効果がありますが、完全には消えません（A♥ が3枚あるので）。

```
A♣ のブロッカー効果:
  OOPのナッツフラッシュ候補: A♥x♥
  A♣ を持つことで A♣ が絡む A♣x♥ のコンボは消えるが、
  OOP の A♥x♥（A♣ではなく A♥ が必要）は消えない
  → A♣ はここでは A♥系のブロッカーにならない

T♥ のアンブロッカー効果:
  T♥ を BTN が持つ → OOP は T♥ を持てない
  → OOP の T♥x♥（T-high flush）が消える
  → OOP のコールレンジは「BTN より強いフラッシュ」(A♥・K♥・Q♥・J♥ + x♥) のみ
```

バリューベットとして打てるか: OOP のコールレンジ（フラッシュ保有者）の過半数に BTN が勝てるかどうか。OOP はフロップからハーツを持っていれば多くがコールレンジに残っています。A♥・K♥・Q♥・J♥ 系のフラッシュは全て BTN の T-high flush に勝ちます。

**チェックバックが正解**です。ナッツ・準ナッツでないフラッシュは、フラッシュ完成ボードでバリューとして打ちにくいです。ショーダウン価値を守ります。

### 問4

**状況**: BTN がフロップCBet → ターンダブルバレル後、リバーに到達。

**ボード**: A♥K♠J♣ 8♦ T♦（5枚完成）
**ポット**: 24BB、BTN スタック: 86BB
**BTN のハンド**: Q♠T♠（リバーのストレート判定を確認）

BB がリバーでチェック。BTN はどうする?

```
A. バリューベット（75%ポット ≈ 18BB）
B. バリューベット（100%ポット ≈ 24BB）
C. チェックバック
D. ブラフ（50%ポット ≈ 12BB）
```

---

**解答: B（バリューベット 100%ポット）**

このボードは「ブロードウェイ（broadway）」の確認が核心です。

```
手札: Q♠ T♠
ボード: A♥ K♠ J♣ 8♦ T♦（5枚）

ストレート確認:
  全カードのランク: A K Q J T 8 T（T が2枚）
  → ユニークランク: A K Q J T 8

  Broadway（A高ストレート）: A-K-Q-J-T
    A: あり（A♥）
    K: あり（K♠）
    Q: あり（Q♠ 手札）
    J: あり（J♣）
    T: あり（T♠ 手札 + T♦ ボード）
    → A-K-Q-J-T = ブロードウェイ完成！

  Q♠T♠ + A♥K♠J♣ + T♦ → Q♠ と T♠ を使ったブロードウェイ:
    A♥ K♠ Q♠ J♣ T♠ = 5連続 → ストレート完成

スート確認（フラッシュ）:
  スペード: Q♠ T♠ K♠ = 3枚 → フラッシュ不成立
  ダイヤ: T♦ 8♦ = 2枚
  ハーツ: A♥ = 1枚
  クラブ: J♣ = 1枚

best5: A♥ K♠ Q♠ J♣ T♠（または T♦） = ブロードウェイ（A-high straight）
```

Q♠T♠ はリバーでブロードウェイを完成させています。「ストレートドローが外れた」ではなく、「**ナッツストレート（ブロードウェイ）が完成**」しています。

ただし重要な注意があります。ボードには A♥K♠J♣T♦ の4枚があります。これらのカードを持つプレイヤーは全員がブロードウェイを形成できます。**Q を持つプレイヤーだけがナッツブロードウェイに参加できる**状況です。

```
ナッツの確認:
  ブロードウェイ A-K-Q-J-T は Q を必要とする
  → Q♠T♠ はナッツブロードウェイ
  → OOP も Q を持っていればタイ（チョップ）

チョップの可能性:
  OOP が Q♥x や Q♦x を持つ → ブロードウェイでタイ
  Q♠ を BTN が持つ → Q♣ のみ OOP が使えるが、Q♣ + ボード4枚でブロードウェイ成立
  → チョップの可能性あり

それでもバリューベット:
  OOP がブロードウェイを持たない場合（Qを持たない場合）は BTN が勝つ
  OOP のコールレンジに Qx が含まれていてもチョップ（損失なし）
  → バリューとして打つのが正しい
```

ナッツ（またはナッツタイ）での大きなバリューベットが正解です。100%ポットで OOP の強いハンドからバリューを取ります。

### 問5

**状況**: BTN がフロップCBet → ターンチェックバック後、リバーに到達。

**ボード**: Q♥J♦T♠ 7♣ A♠（5枚完成）
**ポット**: 18BB、BTN スタック: 91BB
**BTN のハンド**: A♣9♥（ブロッカーを使ったブラフ検討）

BB がリバーでチェック。α式を使って BTN の判断を決める。

```
A. バリューベット（50%ポット ≈ 9BB）
B. ブラフ（75%ポット ≈ 13BB）
C. チェックバック
D. ブラフ（33%ポット ≈ 6BB）
```

---

**解答: C（チェックバック）**

まずボードの評価が必要です。

```
手札: A♣ 9♥
ボード: Q♥ J♦ T♠ 7♣ A♠（5枚）

ストレート確認:
  A-K-Q-J-T → K なし（A♠ と Q♥ J♦ T♠ はある）
  Q-J-T-9-8 → 9♥（手札！）があるが 8 なし
  K-Q-J-T-9 → K なし
  A-2-3-4-5（ホイール） → 2・3・4・5 なし

  9♥ + ボード: Q♥ J♦ T♠ 9♥ A♠ 7♣
    Q-J-T-9-8: 8 なし
    → ストレート不成立（9 はガットショット外れ）

ランクカウント:
  A: 2枚（A♣ A♠）→ ペア

best5: A♣ A♠ Q♥ J♦ T♠ → 1ペア AA（Qキッカー）
  ただし Q♥ J♦ T♠ のボード接続も考慮
  → AA ペアが最強の役
```

A♣9♥ はリバーで「AA のペア（Qキッカー）」です。バリューとしては強い部類（オーバーペア）ですが、OOP のコールレンジと比較する必要があります。

```
Q♥J♦T♠ A♠ ボードのOOPコールレンジ:
  ストレート完成者（K8? → K と 8 が必要。K9 → K-Q-J-T-9 不成立。K 系が絡む場合）
  実際にOOPがストレートを持てるか:
    K♣9♣ → K-Q-J-T-9 → K なし → 不成立（Kはデッキに残っているがボードにない）
    K が含まれるなら KQJT + A で broadway... K がボードにない
    → ストレートは K を必要とするものが多く、OOP が K を持てばブロードウェイ
    AK → A-K-Q-J-T = Broadway 完成！

  OOP が AK を持つ場合: A♣（BTN が持つ）でブロック → A♣K 系が減る
  → A♣ のバリューブロッカーが機能する場面
```

しかし、A♣9♥ の AA ペアは「ターンをチェックバックした」文脈です。ターンをパスした IP がリバーで A を引いてトップペアになった状況でのベットは、OOP に「なぜターンをパスしてリバーだけベット?」と疑問を与えます。ストーリーの一貫性が弱いです。

さらにブラフとして打つ場合、A♣ のバリューブロッカー効果は確かにあります（OOP の AK ブロードウェイを削る）。しかし 9♥ にはブロッカー効果がありません。

**α式でのブラフ判断:**

```
75%ポットブラフの α = 0.75 × 18 ÷ (18 + 0.75 × 18)
                    = 13.5 ÷ 31.5 ≈ 0.43

OOP がフォールドすべき頻度: 43% 以上
  → OOP のハンドの43%以上がフォールドしてくれれば利益

このボード（QJTA 落ち）でOOPがフォールドする頻度:
  ストレート・2ペア以上の保有者は多い
  ターンをコールしたOOPには強いハンドが多い傾向
  → 43%フォールドは実現しにくい
```

チェックバックが最善です。ターンパス後のリバーブラフはストーリーが弱く、OOP のコールレンジも絞られた状態で強いため、ブラフの成功率が低いです。

## 14-3 第2部: OOPのリバーディフェンス（問6〜10）

後手スコアを計算し、コール・CR・フォールドを判断します。HU前提（M=0）で使います。

---

### 問6

**状況**: BTN がフロップ → ターン → リバーと3バレルを打った。

**ボード**: J♣T♦9♥ 4♠ K♠（5枚完成）
**ポット**: 28BB、BB スタック: 82BB
**BB のハンド**: K♥Q♦（リバーの役を確認）

BTN が 20BB ベット（ポットの約70%）。BB はどうする?

```
A. コール（後手スコアを計算してコール域）
B. チェックレイズ（後手スコアが8以上）
C. フォールド（後手スコアがマイナス）
D. コール（計算なし、感覚で）
```

---

**解答: B（チェックレイズ）**

まずボード読みです。

```
手札: K♥ Q♦
ボード: J♣ T♦ 9♥ 4♠ K♠（5枚）

ストレート確認:
  K-Q-J-T-9:
    K: あり（K♥ 手札 + K♠ ボード）
    Q: あり（Q♦ 手札）
    J: あり（J♣）
    T: あり（T♦）
    9: あり（9♥）
    → K-Q-J-T-9 = 5連続 → ストレート完成！

  Broadway A-K-Q-J-T → A なし → 不成立

best5: K♥ Q♦ J♣ T♦ 9♥ → K-high straight（ストレート）
```

K♥Q♦ はこのボードで K-high straight（K-Q-J-T-9）を完成させています。

後手スコアを計算します。

```
後手スコア = HandScore + A − 3 − C − M

HandScore（ストレート）:
  役スコア（ストレート）= 30
  ドロー加点 = 0（リバー）
  ブロッカー加点 = 0（特に有効なブロッカーなし）
  → HandScore = 30

A（ボード値）:
  5枚ボード: J♣T♦9♥4♠K♠
  コネクテッドでウェット → A = 1

C（ベット負担）:
  ポット28BBに対して20BBベット = 71% ≈ 75% → C = 7

M（マルチウェイ補正）: HU = 0

後手スコア = 30 + 1 − 3 − 7 − 0 = 21
```

後手スコアが21と非常に高く、チェックレイズ（CR）域の「8以上」を大幅に超えています。

ただしストレートでのCRには注意点があります。このボードで BTN が3バレルで押してくる場合、BTN もストレート（AQ 等でブロードウェイ、または K8でK-9ストレート等）を持っている可能性があります。チェックレイズすると BTN がAQ broadway 等でリレイズしてくる局面もあります。

実戦では「相手がナッツを持っていても最低限チョップ」の判断が必要です。K♥Q♦ は K-high straight で、より上位のストレート（A が絡む broadway）には負けます。このボードでの最強は broadway（AQ 保有者）です。

```
K-high straight vs broadway:
  AQ → A-K-Q-J-T → broadway（上位ストレート）→ K♥Q♦ に勝つ
  K♥Q♦ は対 AQ でリバーオールインになると負け

CR のリスク:
  BTN が AQ（broadway）を持つ → BTN がリレイズ → BB はコールかフォールドを迫られる
  K-high straight は負けるストレートが存在する

推奨:
  ポット70%ベットへのCRは合理的（スコア21）
  ただし BTN がリレイズしてきた場合はフォールドを検討
```

後手スコアが高いため、CR が最善です。BTN の3バレルレンジにブラフが含まれている確率も高く、CR でブラフを潰しながら強いバリューでポットを膨らませます。

### 問7

**状況**: BTN がリバーで 10BB ベット（33%ポット）。

**ボード**: 8♣6♦2♠ 5♥ A♣（5枚完成）
**ポット**: 30BB、BB スタック: 80BB
**BB のハンド**: 8♥7♥（リバーの役と後手スコアを計算）

```
A. コール
B. チェックレイズ
C. フォールド
D. チェックレイズ（オールイン）
```

---

**解答: A（コール）**

```

  A-2-3-4-5（ホイール）→ 3・4 なし → 不成立
  6-5-4-3-2: 4・3 なし → 不成立

ランクカウント:
  8: 2枚（8♥ 8♣）→ ペア（トップペア on this board: 8はA・6・5・2・8の中で最高位ではない→ A が最高位、8はセカンド）
  実際のボード最高位: A♣ が最高位
  → 8♥ = 2番目のランク（8♣ と合わせてセカンドペア）

  いや、A♣ はボードにあるので、ハンドの8♥はボードの8♣とペアを作る
  → 8♥ + 8♣ = ペア8 = セカンドペア（Aがトップランク）

ランク再確認:
  ボード: A♣ 8♣ 6♦ 5♥ 2♠（ランク順）
  → トップペア = A に当たるハンド
  → 8 はセカンドランク（ボードの8♣とペア）

best5: 8♥ 8♣ 7♥ A♣ 6♦ → 1ペア(88) with A・7・6 kicker
  → セカンドペア（8s）
```

8♥7♥ はリバーで「8のセカンドペア」です（A がトップランク、8 が2番目）。HandScore を計算します。

```
HandScore（セカンドペア）:

  ドロー加点 = 0（リバー）
  ブロッカー加点 = 0
  → HandScore = 10

A（ボード値）:

  → セミウェット〜ウェット判定: A = 2（セミウェット）

C（ベット負担）: 33%ポット → C = 3

後手スコア = 10 + 2 − 3 − 3 − 0 = 6
```

後手スコアが6で「コール域（0〜7）」です。

33%ポットの小サイズベットへの後手下限確率は75%です。BB はハンドの75%以上でコールが必要です。後手スコア6はその範囲内です。

セカンドペアは BTN のブラフレンジ（Kハイ、Qハイ等のワンペアなし）に勝てます。33%ポットの小ベットに対してコールが正解です。

### 問9

**状況**: BTN がリバーで 15BB ベット（50%ポット）。

```
手札: A♠ 5♦

ストレート確認:
```

後手スコア5で「コール域（0〜7）」ですが、このボードの特殊性を考慮します。A♥K♣Q♦J♠ というブロードウェイ形成4枚連続のボードでは、BTN の50%ベットは「T保有者（broadway）」か「2ペア以上の強バリュー」が主体になりやすいです。

### 問10

**状況**: BTN がリバーで 25BB オーバーベット（125%ポット）。

**ボード**: A♣K♠Q♣ 2♦ 4♥（5枚完成）
**ポット**: 20BB、BB スタック: 80BB

```
手札: J♦ T♦
ボード: A♣ K♠ Q♣ 2♦ 4♥（5枚）

ストレート確認:
  A-K-Q-J-T:
    A: あり（A♣）

best5: A♣ K♠ Q♣ J♦ T♦ → ブロードウェイ（A-high straight）
```

broadway はナッツのため、BTN が何を持っていても（チョップを除き）コールが安全です。コール・CRどちらも有力ですが、設問の選択肢として **A（コール）** が最も確実で適切です。

### 問13

**状況**: BTN（IP）がリバーで大きなベットを検討。

**ボード**: 9♠8♣7♣ J♣ K♣（5枚完成）
**ポット**: 22BB、BTN スタック: 86BB
**BTN のハンド**: A♣2♣（リバーの役を確認）

```
D. ブラフ（50%ポット ≈ 11BB）
```

---

**解答: A（OB 150%ポット）**

クラブのフラッシュ確認が最重要です。

```
手札: A♣ 2♣
ボード: 9♠ 8♣ 7♣ J♣ K♣（5枚）

スート別カウント:
  クラブ（♣）: 2♣ 8♣ 7♣ J♣ K♣ = 5枚 → フラッシュ完成！
  スペード: 9♠ = 1枚

クラブフラッシュのランク（高い順）:
  K♣ J♣ 9♠...待って
  クラブ5枚: 2♣（手札）8♣ 7♣ J♣ K♣（ボード）
  ランク順: K♣ J♣ 8♣ 7♣ 2♣
  → K-high flush（クラブ）

  A♣（手札）もクラブ！
  クラブ6枚: A♣ 2♣（手札）8♣ 7♣ J♣ K♣（ボード）
  best5フラッシュ: A♣ K♣ J♣ 8♣ 7♣ → A-high flush = ナッツフラッシュ

  9-8-7-6-5: 6・5 なし
  J-T-9-8-7: T なし
  K-Q-J-T-9: Q・T なし
  → ストレート不成立

best5: A♣ K♣ J♣ 8♣ 7♣ → ナッツフラッシュ（A-high クラブ）
```

A♣2♣ はリバーでナッツフラッシュ（A-high クラブ）を完成させています。ナッツです。

OBが最善の根拠を確認します。

```
α式（OB 150%ポット）:
  α = 33 ÷ (22 + 33) = 33 ÷ 55 = 0.60
  後手下限確率 = 1 − 0.60 = 0.40（40%）

V:B比率 = 1 : 1.5（バリュー1に対してブラフ1.5が均衡）

ナッツフラッシュでOBが有効な理由:
  このボードはクラブフラッシュ完成ボード（クラブ4枚→ J♣が3枚目、K♣が4枚目）
  → OOPはフラッシュドローを持っていればコールしてくる
  → OOPのコールレンジが「クラブフラッシュ保有者（セカンドナッツ以下）」で厚い
  → ナッツでOBを打つことでセカンドナッツから大きなバリューを取れる
```

OOP のコールレンジに（フラッシュを保持する）強いハンドが多い局面ほど、ナッツでの OB は効果的です。150%OB で OOP からフラッシュ保有者を最大限にコールさせて EV を高めます。

### 問14

**状況**: BTN がリバーでオールインを検討。スタックが短い。

**ボード**: Q♠J♦T♣ A♦ 8♣（5枚完成）
**ポット**: 55BB、BTN スタック: 30BB
**BTN のハンド**: K♠9♠（リバーの役を確認）

BB がチェック。BTN はオールイン（30BB ≈ ポットの54%）を検討。SPR を確認してポットコミット判断。

```
A. オールイン（ポットコミット状態）
B. 標準ベット（50%ポット）
C. チェックバック
D. フォールド
```

---

**解答: A（オールイン）**

まずボード読みを確認します。

```
手札: K♠ 9♠
ボード: Q♠ J♦ T♣ A♦ 8♣（5枚）

ストレート確認:
  A-K-Q-J-T（broadway）:
    A: あり（A♦）
    K: あり（K♠ 手札）
    Q: あり（Q♠）
    J: あり（J♦）
    T: あり（T♣）
    → broadway 完成！

  K-Q-J-T-9（K-high straight）:
    9: あり（9♠ 手札）
    → K-Q-J-T-9 = K-high straight も完成！

BTN の best5:
  Broadway: A♦ K♠ Q♠ J♦ T♣ → 5連続（A-high straight）
  K-high: K♠ Q♠ J♦ T♣ 9♠ → 5連続（K-high straight）
  どちらが強い？: Broadway（A-high）がK-high より上位

  K♠9♠ での best5: A♦ K♠ Q♠ J♦ T♣ → Broadway（K♠ を使う）
```

K♠9♠ はリバーでブロードウェイ（A-high straight）を完成させています。さらに K-high straight も形成できます（best5はbroadwayを選択）。

SPR（スタック・ポット比）を確認します。

```
SPR = スタック ÷ ポット
    = 30 ÷ 55 ≈ 0.55

SPR < 1 → ポットコミット状態
```

SPR が1を下回る場合、ポットコミットです。残りスタックがポット以下になっているため、フォールドすることはポットへの「投資の損失確定」を意味します。コールのEVがほぼ確実にフォールドのEVを上回ります。

Broadway というナッツ（またはナッツタイ）の状態で、かつ SPR<1 のポットコミット。オールインが最善です。チェックバックでは EV を大きく失います。

### 問15

**状況**: BTN がリバーでフォールドを検討。

**ボード**: 7♦6♣5♥ 2♠ 9♣（5枚完成）
**ポット**: 40BB、BTN スタック: 35BB
**BTN のハンド**: A♥8♥（ストレートドロー外れ）

BB が 35BB ベット（87%ポット ≈ オールイン相当）。BTN はどうする?

```
A. コール（すでに多くを投資したから）
B. フォールド
C. レイズ（オールイン）
D. コール（ポットオッズが良いから）
```

---

**解答: B（フォールド）**

これはサンクコスト（埋没費用）の罠を検出する問題です。

```
手札: A♥ 8♥
ボード: 7♦ 6♣ 5♥ 2♠ 9♣（5枚）

ストレート確認:
  8-7-6-5-4: 4 なし → 不成立
  9-8-7-6-5: 9♣（ボード）8♥（手札）7♦6♣5♥ = 5枚連続 → ストレート完成！

9♣ がリバーで落ちた！
  → 9-8-7-6-5 = 5連続 → ストレート完成

A♥ の役:
  ストレートに参加しない（Aはストレートの別端: A-2-3-4-5 等）

best5: 9♣ 8♥ 7♦ 6♣ 5♥ → 9-high straight（8♥ 使用）
→ A♥ は best5 に入らない
```

A♥8♥ はリバーで9-high straight（9-8-7-6-5）を完成させています。

このストレートの問題点は「ストレートの中で弱い部類」ということです。ボードに 7♦6♣5♥9♣ があり、上位のストレート（T-9-8-7-6 → T が必要、J-T-9-8-7 → J・T が必要）は形成できませんが、OOP が 3-4（A2345 等）や別のコンビネーションを持つ場合の相性を確認します。

```
BB の35BBオールイン（87%ポット）への評価:

α = 35 ÷ (40 + 35) = 35 ÷ 75 ≈ 0.467
後手下限確率（BTN がコールすべき最低頻度）= 1 − 0.467 = 0.533（53.3%）

BTN のコールEVが正になる条件:
  BB のベットレンジの46.7%以上がブラフ
  → BB が87%ポットをオールインで打つ場合、BB はバリューヘビーなレンジ

7♦6♣5♥2♠9♣ のボードで BB がオールインを打つ強いハンド:
  セット（77・66・55・22・99）
  ストレート（3-4 → 2-3-4-5-6 ブロードウェイ下位, 4-8, T-8等）
  
BB の9-high straight（T8 → T-9-8-7-6）は T を必要とする

BTN（A♥8♥）の9-high straight は、より上位のストレートに負ける:
  T8（T-9-8-7-6）> 98（9-8-7-6-5）
```

コールの根拠として「すでに投資したポット（40BB）が惜しい」という感情は誤りです。フォールドの代償は「これ以上の損失を防ぐ」ことです。コールの代償は「さらに35BB を失うリスク」です。

BB のオールインレンジに十分なブラフが含まれていない限り、フォールドが最善です。サンクコスト（これまでの投資額）はフォールドとコールの選択に関係しません。

## 14-5 第4部: ボード読みの典型例（問16〜20）

ボードそのものの読み方、特に「board itself plays」（ボードが役を形成する）・broadway チョップ・フラッシュの枚数判定・ペアボードの評価を確認します。

### 問16

**状況**: BTN と BB がリバーに到達。BTN がベットを検討。

**ボード**: A♠K♥Q♦J♠T♣（5枚完成 — リバーまで到達した5枚がこのボード）
**ポット**: 32BB
**BTN のハンド**: 9♦8♣（このハンドでの役を確認）

BB がチェック。BTN はどうする?

```
A. オーバーベット（200%ポット）で強引にポットを取りにいく
B. 75%ポットでバリューベット
C. チェックバック（チョップの可能性を認識）
D. 33%ポットでブラフ
```

---

**解答: C（チェックバック）**

これは「board itself plays」の典型例です。

```
ボード: A♠ K♥ Q♦ J♠ T♣（5枚）

ストレート確認（ボード単体）:
  A-K-Q-J-T = broadway（A-high straight）
  ボードの5枚だけで broadway が完成している！

手札: 9♦ 8♣

ストレート確認（ハンド込み）:
  9-8-7-6-5: 7・6・5 なし → 不成立
  K-Q-J-T-9: 9♦（手札）K♥Q♦J♠T♣ → K-Q-J-T-9 = K-high straight 完成
  Q-J-T-9-8: 8♣（手札）Q♦J♠T♣9♦ → Q-J-T-9-8 = Q-high straight 完成

  best5（最大の役）: ボードのbroadway A♠K♥Q♦J♠T♣ vs ハンドを使ったストレート
    Broadway A-K-Q-J-T vs K-Q-J-T-9 → broadway が上位
    → 9♦8♣ を使った場合の best5 は K-Q-J-T-9 か Q-J-T-9-8
    → ただし board の broadway（A-K-Q-J-T）を使う方が強い

  「board を使う」とは:
    best5 = 5 cards からなる最強の手
    9♦8♣ + A♠K♥Q♦J♠T♣:
      broadway 候補: A-K-Q-J-T → ボードの5枚だけで完成
      手札 9♦8♣ を使わなくても broadway 完成
      → ハンドカードは best5 に入らない（ボードの broadway が最強）
```

A♠K♥Q♦J♠T♣ というボードは、5枚それ自体でブロードウェイを形成しています。全員の best 5 が「A♠K♥Q♦J♠T♣」になります。つまり、このリバーでは**全員がチョップ（タイ）**です。

```
チョップの確認:
  BTN（9♦8♣）の best5: A♠ K♥ Q♦ J♠ T♣（ボードのみ）
  BB のあらゆる hand の best5: A♠ K♥ Q♦ J♠ T♣（ボードのみ）
  → 全員タイ、ベットしてもフォールドさせた場合だけ利益

BB がブラフを持っていれば、BTN がベットするとBBがフォールドしてBTN が利益を得ます。しかし BB がどんな手を持っていてもチョップになる（BTN がベットしなければ）。

BTN がベットすることのコスト:
  BB がコール → チョップ（ベット額を失い、ポットをスプリット）
  → ベットはEVマイナス（コールされれば損）

チェックバックが最善:
  ポットをスプリットしてお互いに得る
  ベットはBBがフォールドしたときだけ意味があるが、BBはチョップを知っていればフォールドしない
```

board itself plays の典型です。「チェックバック→チョップ」が最善の対応です。

### 問17

**状況**: BTN がリバーで 8BB ベット（50%ポット）。

**ボード**: 2♣2♦7♠ 8♣ A♥（5枚完成）
**ポット**: 16BB、BB スタック: 88BB
**BB のハンド**: A♦K♣（リバーでの役を正確に評価）

BTN が 8BB ベット（50%ポット）。BB はどうする?

```
A. コール（AA のトップペア強い）
B. チェックレイズ
C. フォールド
D. コール（後手スコアを計算）
```

---

**解答: D（コール、後手スコアを計算した結果）**

ペアボードでのハンド評価が鍵です。

```
手札: A♦ K♣
ボード: 2♣ 2♦ 7♠ 8♣ A♥（5枚）

ランクカウント:
  2: 3枚（2♣ 2♦ ボード + ...）
    待って: 2♣ 2♦ はボードに2枚
    手札に2はない
    → 2はボードに2枚（ペア2）

  A: 2枚（A♦ 手札 + A♥ ボード）
  K: 1枚（K♣）
  7: 1枚（7♠）
  8: 1枚（8♣）

best5 の計算:
  手札 A♦K♣ + ボード 2♣2♦7♠8♣A♥
  全カード: A♦ K♣ 2♣ 2♦ 7♠ 8♣ A♥

  ペア確認:
    A: 2枚（A♦ A♥）
    2: 2枚（2♣ 2♦）
    → 2ペア（Aces & Twos）

  2ペアでの best5:
    A♦ A♥ 2♣ 2♦ K♣ → 2ペア（A's & 2's、Kキッカー）
```

A♦K♣ はリバーで「2ペア（A's & 2's）＋Kキッカー」です。よくある誤解は「TPTK（Aのトップペアにトップキッカー）」として評価することです。正しくはペアボード上の2ペア（AA & 22）です。

```
HandScore（2ペア AA & 22）:
  役スコア（2ペア）= 20
  ドロー加点 = 0
  ブロッカー加点: A♦ がAブロッカー → +2
  → HandScore = 22

A（ボード値）: 2♣2♦7♠8♣A♥ → ペアボード、ドライ系 → A = 3

C（ベット負担）: 50%ポット → C = 5

後手スコア = 22 + 3 − 3 − 5 − 0 = 17
```

後手スコアが17で「CR域（8以上）」を超えています。ただし、A♦K♣ の「2ペア AA & 22」に対してCRが有効かを検討します。

```
2♣2♦7♠8♣A♥ のボードで強いハンド:
  クワッズ（4枚の2）: 2♠2♥ → 99のポケットペアかつボードに2が2枚 = クワッズ
  フルハウス: AA（手札）+ 2ペア（ボード）= A-A-2-2-A の組み合わせは...
    A♦A♥（手札2枚）+ 2♣2♦（ボード2枚）→ 4Aと4Tの4枚確認
    実際: 手札Aは1枚、ボードAは1枚 → 合計A=2枚
    「AAA」= 3Aにはならない（A is 2 only）
    → 2ペア確定（AA & 22）、フルハウスにはなれない

  より強いハンド候補:
    22（ポケットペア）→ クワッズ（4枚の2）: BB の相手にあれば BTN に勝てない
    A7・A8・A2: ボードで更なる組み合わせ
    78（2ペア 7 & 8）: 8♣7♠ ボードで2ペア → AA & 22 より下位

  A♦K♣ の2ペア（AA & 22）は強い部類
  CRは BTN がフォールドしてくれる場合のみ有効
```

後手スコアは高いですが、2ペアでのCRはリスクがあります（BTN がクワッズや強いフルハウスを持っている場合）。コールが堅実な選択です。スコア17という高さは、この状況でコールが十分正当化されることを示しています。

### 問18

**状況**: BTN がリバーで 14BB ベット（50%ポット）。

**ボード**: J♥8♥5♣ T♥ 3♥（5枚完成）
**ポット**: 28BB、BB スタック: 78BB
**BB のハンド**: K♥7♦（ハーツの枚数を正確に確認）

BTN が 14BB ベット（50%ポット）。BB はどうする?

```
A. コール（K♥ があるからフラッシュ持ち）
B. フォールド
C. CR（強いハンドとして）
D. コール（後手スコアを計算）
```

---

**解答: D（コール — ただしフラッシュではなく1ペアとして）**

フラッシュの判定が核心です。

```
手札: K♥ 7♦
ボード: J♥ 8♥ 5♣ T♥ 3♥（5枚）

スート別カウント:
  ハーツ（♥）: K♥（手札）J♥ 8♥ T♥ 3♥（ボード）= 5枚

5枚ハーツ → ハーツフラッシュ完成！

best5フラッシュ（ランク高い順）:
  K♥ J♥ T♥ 8♥ 3♥ → K-high flush（ハーツ）
  ナッツは A-high flush（A♥x♥保有者）

よくある誤解:
  「4枚のハーツがボードにある、K♥でフラッシュ」は一見正しいが...
  実際にカウントすると K♥（手札）+ ボード4枚ハーツ = 合計5枚ハーツ
  → フラッシュ成立（5枚同スート）

HandScore（K-high フラッシュ）:
  役スコア（フラッシュ）= 27
  ドロー加点 = 0
  → HandScore = 27

A（ボード値）: フラッシュ完成ボード → A = 1（ウェット）

C: 50%ポット → C = 5

後手スコア = 27 + 1 − 3 − 5 − 0 = 20
```

後手スコア20で、CR域（8以上）を大幅に超えています。ただし A♥ を持つプレイヤーにはナッツフラッシュで負けます。

**問題の設問における落とし穴:**

この問題の意図は「K♥ 1枚でフラッシュが成立するか」の確認です。答えは「K♥（手札）＋ボードのハーツ4枚 = 計5枚のハーツでフラッシュ成立」です。「フラッシュは5枚同スート」という基本を、ハンドとボードを合わせて判定します。

選択肢 A は「K♥があるからフラッシュ持ち」という表現ですが、実際にはフラッシュ成立の確認として正しいです。問題はそのコールの根拠（後手スコアの計算なし）として選択肢 D の方が正確です。

コールが最善ですが、後手スコア20であればCRも有力です。

### 問19

**状況**: BTN が 15BB ベット（75%ポット）。

**ボード**: K♠Q♦J♥T♣ 9♣（5枚完成）
**ポット**: 20BB、BB スタック: 82BB
**BB のハンド**: A♥6♦（リバーの役を確認し、コール/フォールドを判断）

BTN が 15BB ベット（75%ポット）。BB の A♥6♦ での最善行動を選んでください。

```
A. フォールド（broadway があってもチョップになるので無意味）
B. コール（後手スコアを計算した結果）
C. チェックレイズ（ナッツ級だから）
D. フォールド（Aハイカードで5枚ボードでは弱い）
```

---

**解答: B（コール — 後手スコアを計算した結果）**

ボードの全体像を確認します。

```
手札: A♥ 6♦
ボード: K♠ Q♦ J♥ T♣ 9♣（5枚）

ストレート確認（ボード単体）:
  K-Q-J-T-9 = 5連続 → K-high straight がボード単体で完成！
  → A♥6♦ を使わなくても BB の best5 はボードの K-high straight

broadway 確認（手札 A♥ を加える）:
  A: あり（A♥ 手札）
  K,Q,J,T: ボードにあり
  → A-K-Q-J-T = broadway 完成

6♦ の役割:
  Q-J-T-9-8: 8 なし → 不成立
  → 6♦ はストレートに不参加

best5 の比較:
  A♥ 使用: A♥ K♠ Q♦ J♥ T♣ → broadway（A-high straight）
  ボード plays: K♠ Q♦ J♥ T♣ 9♣ → K-high straight
  broadway > K-high straight → A♥ を使った broadway が best5
```

A♥6♦ のリバー役は「broadway（A-K-Q-J-T）」です。ボード単体で K-high straight が完成していても、A♥ を持つことで broadway（上位ストレート）を形成できます。

A♥ ブロッカーの評価を続けます。

```
BTN のベットレンジ分析:
  BTN が A を持つ場合:
    broadway → BB の A♥broadway とチョップになる可能性
    ただし BB が A♥ を持つ → BTN は A♥ を使えない
    → BTN の broadway は A♣・A♦・A♠ を使うコンボのみ

  BTN が A を持たない場合:
    best5 = K♠Q♦J♥T♣9♣（K-high straight）
    → BB の broadway に負ける → BB が勝つ

  BTN がブラフ: BB の broadway が勝つ

後手スコア計算:
  HandScore（broadway）= 30
  A（ボード値）: K♠Q♦J♥T♣9♣ → 極めてウェット連続 → A = 1
  C（75%ポット）= 7
  後手スコア = 30 + 1 − 3 − 7 − 0 = 21
```

後手スコア21でコール域（0〜7）を大きく超えており、CR域（8以上）に入っています。コールまたは CR が論理的な選択です。

選択肢 A の「チョップになるから無意味」は誤りです。チョップになるのは BTN も broadway を持つ場合だけです。BTN が broadway を持たない（A を持たない）場合は BB が勝ちます。BB が A♥ を持つことで BTN の A♥broadway コンボを物理的に削るブロッカー効果もあります。

コールが最善です（後手スコア21の高さから CR も有力ですが、このボードで CR に対して BTN のバリューが続くリスクも考慮してコールが堅実）。

### 問20

**状況**: ボードが K♠Q♦J♥T♣ の4連続。リバーで8♠が落ちた。

**ボード**: K♠Q♦J♥T♣ 8♠（5枚完成）
**ポット**: 22BB、BB スタック: 84BB
**BTN のハンド**: A♣9♦（ストレートの判定）

BB がチェック。BTN はどうする?

```
A. バリューベット（75%ポット）
B. チェックバック
C. バリューベット（100%ポット）
D. ブラフ（75%ポット）
```

---

**解答: B（チェックバック）**

ボード読みが勝負です。

```
手札: A♣ 9♦
ボード: K♠ Q♦ J♥ T♣ 8♠（5枚）

ストレート確認:
  A-K-Q-J-T（broadway）:
    A: あり（A♣ 手札）
    K: あり（K♠）
    Q: あり（Q♦）
    J: あり（J♥）
    T: あり（T♣）
    → broadway 完成

  K-Q-J-T-9:
    9: あり（9♦ 手札）
    K,Q,J,T: あり
    → K-high straight 完成

  Q-J-T-9-8:
    8: あり（8♠ ボード）
    Q,J,T,9: あり
    → Q-high straight 完成

  A♣9♦ の best5:
    broadway: A♣ K♠ Q♦ J♥ T♣（A♣ を使う、9♦ は不参加）
    K-high: K♠ Q♦ J♥ T♣ 9♦（9♦ を使う、A♣ は不参加）
    どちらが強い？: broadway > K-high straight

  最終 best5: A♣ K♠ Q♦ J♥ T♣ → broadway
```

A♣9♦ はこのボードでブロードウェイを完成させています。加えて K-high straight・Q-high straight も形成できます（best5はbroadway）。

問題は「board itself plays の評価」です。

```
K♠Q♦J♥T♣8♠ のボード単体:
  K-Q-J-T-8: 連続か？ K-Q-J-T-8 → T と 8 の間に 9 が欠ける → 不連続
  → ボード単体では broadway / K-high straight は完成しない（T♣ と 8♠ が連続でない）

  T♣ を使った最長連続:
    K-Q-J-T（4連続）→ さらに 9 があれば K-high straight
    Q-J-T-8（Q-J-T と8の間に9が抜けている）→ ガットショット的

  ボード単体の評価: board itself plays はしない（4連続止まり）

A♣9♦ 保有者の評価（再確認）:
  broadway（A♣使用）: A♣ K♠ Q♦ J♥ T♣ → 完成
  K-high（9♦使用）: 9♦ がT♣と連続 → K-Q-J-T-9 → 完成

BB の best5（BB のハンド不明だが分析）:
  BB が A を持つ → broadway（チョップ）
  BB が 9 を持つ → K-high straight
  BB が A も9も持たない → K-Q-J-T-8 は連続でないのでストレート不成立
    BB の best5 = K♠ Q♦ J♥ T♣ 8♠（K-high board）
    K-high ハイカード = broadway に負ける
```

A♣9♦ でのブロードウェイは強力です。しかし：

```
8♠ リバー落ちの影響:
  9-T-J-Q-K（K-high）: BB が 9 を持てば成立（9 はデッキに多数ある）
  A-K-Q-J-T（broadway）: BTN が A♣ を持つ → 相手の A♣ 使用コンボは物理的に消える
    ただし A♥・A♦・A♠ を使った broadway（相手の A♥KorQ 等）は依然存在

チェックバックの理由:
  OOP が broadway を持つ → チョップ（べット損）
  OOP が K-high straight を持つ → BTN が broadway で勝つ
  OOP が何も持たない → BTN がチェックバックしてもショーダウン勝ち

  OOP の強いハンド（K-high straight・broadway）が厚いと想定される場合:
    KQJT ボードでリバーまで来た OOP は、ストレートドロー完成を持つ可能性が高い
    チェックバックは「チョップリスクを避け、OOP のブラフをインデュースする」効果もある
```

厳密には A♣9♦ の broadway は非常に強く、バリューベットも検討できます。ただし、OOP のコールレンジに broadway（タイ）が含まれる割合が高いと見込まれる場合、チェックバックがリスク回避になります。この問題の学習ポイントは「4連続ボード + リバーカード = 複数のストレートが完成する場合の評価」です。

### よくある誤りと修正

**誤り1: broadway を見落とす**

KQJT が4枚並ぶボードに A または 9 を持つとき、「まだストレートがない」と思い込む誤りです。A があれば broadway（A-K-Q-J-T）、9 があれば K-high straight（K-Q-J-T-9）が完成しています。

```
チェック手順:
  ボードのランクと手札のランクを合わせて5連続を確認
  A-K-Q-J-T / K-Q-J-T-9 / Q-J-T-9-8 の順で確認する
```

**誤り2: 「4枚同スート = フラッシュ」の誤認**

フラッシュは5枚同スートが必要です。ボードに4枚の同スートがあり、手札に1枚の同スートがあれば「計5枚」でフラッシュ成立です。

```
フラッシュ判定:
  スート別にカウント（ハンド + ボードの全カード）
  特定スートが5枚以上 → フラッシュ成立
  4枚 → フラッシュドロー（ターンまで）またはフラッシュ不成立（リバーで4枚のみ）
```

**誤り3: ペアボードで「TPTK のまま」と評価する**

A♦K♣ on 2♣2♦7♠8♣A♥ は「TPTK（AA のトップペア）」ではなく「2ペア（AA & 22）」です。ボードにペアがある場合、そのペアを含む best 5 を再計算します。

```
ペアボードの評価手順:
  手札 + ボード全カードのランク別カウント
  ランクが2枚以上のものがペア候補
  「ボードペア + 手札のトップペア」→ 2ペア
```

**誤り4: サンクコストでコール**

フロップ・ターンに多くのチップを投資したから「もったいなくてフォールドできない」という判断は誤りです。現時点の「コールのEV」だけを計算します。過去の投資は回収できません。

```
フォールドの判断基準:
  「これ以上コールすることのEV」 vs 「フォールドのEV（=0）」
  過去の投資額は計算に入れない
```

**誤り5: 33%小サイズへの過剰フォールド**

33%ベットへの後手下限確率は75%です。OOP は全ハンドの75%でコールが必要です。「小さなベットだから大した問題ではない」とフォールドすると、相手のブラフが常に利益になります。

```
33%ベットの対応:
  後手スコアが 0 以上 → コール
  スコア −3 程度までのハンドを一部コールに混ぜて75%を確保
```

ボード 7♠6♦5♣ 8♥ 2♣ で、あなたは OOP として Q♥J♠ を持っています。BTN が 75%ポットベット。後手スコアを概算して最善行動を選んでください。

```
1. コール
2. チェックレイズ
```

### 問C

ボード K♥Q♣J♦ 9♣ 5♠（5枚完成）で、あなたは OOP として A♠T♣ を持っています。BTN が 50%ポットベット。最善行動を選んでください。

```
1. フォールド（AペアだけでKQJボードでは弱い）
2. コール（ストレートがあるから強い）
3. チェックレイズ（ナッツだから）
4. フォールド（相手がブラフのはずがない）
```

---

### 解答

**問A: 3（チェックバック）**

A♥K♦Q♠J♣T♠ のボード5枚がブロードウェイ（A-K-Q-J-T）を形成しています。5♦4♦ の best5 もボードのブロードウェイになります（board itself plays）。全員がチョップのため、ベットはコールされた場合に損になります。チェックバックが最善です。

**問B: 3（フォールド）**

ボード 7♠6♦5♣8♥2♣ で Q♥J♠ の役を確認します。ストレート: Q-J-T-9-8 → T・9 なし。ランクカウント: Q=1 J=1 → 役なし（ハイカード）。HandScore ≈ 0。A=1（ウェット）。C=7（75%ポット）。後手スコア = 0 + 1 − 3 − 7 − 0 = −9。フォールド域（マイナス）。フォールドが正解です。

**問C: 2（コール）— ただしストレートとして評価（チェックレイズも有力）**

K♥Q♣J♦9♣5♠ に A♠T♣: A-K-Q-J-T = broadway 完成！ A♠T♣ はブロードウェイ保有者です。HandScore=30、A=1（ウェット連続形）、C=5（50%）。後手スコア = 30 + 1 − 3 − 5 − 0 = 23。CR域（8以上）を大幅に超えます。コールまたはCRが最善。チェックレイズは BTN のブラフをコールに変換しながらポットを膨らませる有力な選択肢です。

> **本章まとめ**
>
> - α式で「ブラフの損益分岐フォールド率」と「V:B比率」を計算し、バリューとブラフの配分を設計する
> - 後手スコア = HandScore + A − 3 − C（HU前提・M=0）で個別ハンドのコール/CR/フォールドを判断する
> - 「5枚連続」でストレート判定し、ブロードウェイ（A-K-Q-J-T）を手札とボードの組み合わせで確認する
> - フラッシュは「手札 + ボードで計5枚同スート」が必要条件であり、4枚は成立しない
> - ペアボードでは「ボードペア + 手札のトップペア」で2ペアになる（TPTK のままではない）
> - 33%小サイズへの後手下限確率は75%であり、過剰フォールドは相手のブラフを永続的に利益にする
> - サンクコストはコール/フォールドの判断に入れない（現時点のEVのみを計算する）

**【GTOとのズレ】**

本章のドリルで扱った「α式でV:B比率を計算し、後手スコアでコール域を決める」というフローは、GTOソルバーの均衡解を大幅に単純化したものです。実際のGTOでは次のような要素が考慮されています。

まず、相手のレンジ全体のコンビネーションを考慮した「コンボ単位のV:B設計」が行われます。本章では「バリューN個に対してブラフM個」という大枠でしか計算していませんが、実際のGTOは特定のコンボが「何%の頻度でベット、何%でチェック」という混合戦略を取ります。特に中程度の強さのハンド（2ペア・TPTK）は純粋な「バリュー」でも「チェック」でもなく、一定の頻度で両方を選択します。

次に、ボードテクスチャの影響がV:B比率を動的に変化させます。コネクテッドボード（問6のJT9ボード等）ではIPのバリューレンジが厚くなるため、OOPは後手スコアが低めのハンドもコールに混ぜる必要があります。ドライボード（K72等）ではIPのブラフが多くなるため、OOPはスコアが正の値なら積極的にコールします。本章の後手スコアはこのダイナミクスを固定のA係数で近似しているため、実際の均衡とはずれる場合があります。

最後に、「board itself plays」の局面（問16・問A のbroadway完成ボード）では、GTOソルバーはほぼベット頻度ゼロを示します。このような局面でベットすることは「ブロードウェイを持っていないことを示す情報の提供」にもなります。本章の「チェックバック」という答えはGTOと概ね一致しますが、理由は「チョップだから損」という損失回避だけでなく、「情報提供を避ける」という側面も含まれています。
