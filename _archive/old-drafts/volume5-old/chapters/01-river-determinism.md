# 第1章　リバーが「確定ゲーム」である意味

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバーが「もうカードが落ちない」確定ゲームであることを理解し、本書全体を貫く3つの暗算式がなぜリバーを解く鍵になるかを把握する。

---

## 1-1 本書のアプローチ ─ リバー判断を3つの暗算式で

テキサスホールデムのリバーは、ポーカーの中で最も要求レベルが高いストリートです。ターンまでのすべての判断が積み重なった末に、チップをめぐる最終決断を迫られます。それでいてリバーの判断は、他のストリートよりもずっとシンプルな論理で成立しています。

本書が提供するのは、その論理を3つの暗算式に圧縮した実戦ツールです。

```
式1: α式（アルファ式）　─ リバーでのバリュー/ブラフ配分を決める
式2: 後手スコア　　　　 ─ 相手のベットに対してコールかフォールドかを決める
式3: ブロッカー論　　　 ─ 手持ちカードが相手レンジにどう干渉するかを評価する
```

これらは難解な数式ではありません。巻2（フロップ基礎編）で学んだ HandScore や後手スコアの骨格を受け継ぎ、リバーという確定ゲームに特化して再調整した式です。本書を読む前に、巻2で学んだ HandScore・後手スコア・簡易レンジスコアの概念がある程度頭に入っていると、各章の理解がスムーズになります。

巻2・巻3（フロップ応用編）を読んでいない方も、本書は単独で読めるよう設計されています。必要な概念はその都度本書内で定義します。ただし、より深く理解したい方は、フロップ編の後手スコアおよび簡易レンジスコアの章を参照してください。

## 1-2 ポーカーの4つのストリートとリバーの位置

テキサスホールデムは4つのベッティングラウンドで構成されます。

```
プリフロップ → フロップ → ターン → リバー
（手札配布）　（ボード3枚）（ボード4枚目）（ボード5枚目）
```

各ストリートでは、プレイヤーはベット・コール・フォールド・チェック・レイズという選択を行います。ポットはストリートが進むごとに大きくなり、残っているスタックとの比率（SPR: スタック対ポット比）は小さくなっていきます。

リバーは最終ストリートです。ここで5枚目のボードカードが開かれ、以後はカードが追加されません。この事実がリバーを他のストリートとは根本的に異なるものにします。

フロップではボードが3枚、残り2枚のカードが落ちる可能性があります。ターンではボードが4枚、残り1枚が残っています。リバーではボードが5枚、手札2枚と合わせた7枚の中からベスト5を使った最終的な手役が決定します。これ以上役が変わることはありません。

この「もうカードが落ちない」という事実が、リバーを確定ゲームにします。

## 1-3 エクイティが二値化する

フロップやターンでは、ハンドの価値は「現在の強さ」だけでなく「将来強くなる確率」も含みます。

巻2 第6章で学んだ Rule of 2 and 4（アウツ × 2 で 1 ストリート分の勝率を概算する手法）を思い出してください。フラッシュドローは残り 1 ストリートで約 19%（9アウツ × 2）の確率で完成します。オープンエンドストレートドロー（OESD）は約 17%（8アウツ × 2）です。ターンでこれらのドローを持っているプレイヤーは、ショーダウンでは現在負けていても、リバーが来ることで勝ちに転じる可能性があります。この「将来性」が、ターンでのドローの価値を支えています。

リバーではこの計算がまったく変わります。

リバーが来た瞬間、すべてのドローは「完成した」か「完成しなかった」かのどちらかに確定します。フラッシュドローは完成か失敗か、ストレートドローは完成か失敗か。中間はありません。

```
ターン時点のエクイティ = 現在の勝率 + ドロー改善の期待値（流動的）
リバー時点のエクイティ = 現在の勝率のみ（確定的）
```

この変化を「エクイティの二値化」と呼びます。ハンドの価値が「勝てるか、勝てないか」にほぼ収束するのです。

エクイティの二値化は判断を単純化する一方で、単純さゆえの精度要求を高めます。「将来性があるから継続する」という逃げ道がなくなり、「今このハンドで正しいアクションは何か」を正面から問われます。

## 1-4 セミブラフが消滅する理由

ターンで重要な役割を果たすのがセミブラフです。セミブラフとは、現在は相手に負けているが、ドローが完成すれば勝てるハンドでのベットです。

セミブラフには二重の価値があります。まず、相手がフォールドすれば今すぐポットを獲得できます。次に、コールされてもドローが完成すればリバーで勝てます。この「フォールドエクイティ」と「ドローエクイティ」の複合が、セミブラフを収益性の高いプレイにします。

ターンでセミブラフが有効なのは、この「ドローエクイティ」がまだ生きているからです。フラッシュドロー保有者がターンでベットするとき、コールされてもリバーで約 19% の確率で勝ちがあります。この 19% が「フォールドさせる必要がない分のEV」として機能します。

リバーではこの構造が完全に崩れます。

リバーでドローが外れたプレイヤーがベットする場合、相手がコールすれば必ず負けます。「コールされても将来的に勝てる」という成分がゼロです。

```
セミブラフ = フォールドエクイティ + ドローエクイティ
リバーでのドロー外れ = フォールドエクイティ + 0（ドローエクイティなし）
```

後者は純粋なブラフです。セミブラフという概念は、リバーでは存在しません。

このことはリバーでのベット判断を根本的に変えます。ターンでは「ドローを持ちながら打つ」という第三の選択がありました。リバーではすべてのベットが「バリューベット（コールされても勝てる）」か「ブラフ（コールされると負ける）」かのどちらかに分類されます。

## 1-5 ハンドの3層への収束

セミブラフが消滅したリバーでは、すべてのハンドが3つの層に収束します。

### 第1層: バリュー層

コールされても十分な頻度で勝てるハンドです。フルハウス・フラッシュ・ストレート・強いツーペアなどが典型です。バリューベットの候補になります。

バリュー層の判断基準は「相手のコールレンジの過半数に勝てるか」です。相手のコールレンジの 50% 以上に勝てれば、バリューベットはプラスになります。50% を下回る場合は「薄いバリュー」であり、ベットするかチェックするかの判断が必要になります。

### 第2層: ブラフ候補層

コールされると負けるが、フォールドさせれば利益になるハンドです。外れたフラッシュドロー・外れたストレートドロー・ブロッカーを持つ弱いハンドなどが典型です。

ブラフ候補がブラフとして機能するには、相手をフォールドさせる確率が損益分岐点を上回る必要があります。この計算が第6章で扱うα式です。

### 第3層: チェック層

バリューを出せるほど強くなく、ブラフとして機能するほど弱くもない中間のハンドです。弱めのトップペア・中程度の2ペアなどが典型です。

チェック層のハンドでベットしても、強いコールを取り込んでバリューを生むことも難しく、フォールドを引き出してブラフとして機能することも難しい状況が多い。チェックを選んでショーダウンバリューを守るか、相手のブラフを誘う方が合理的です。

```
リバーのハンドロール:
  第1層（バリュー）: コールされても勝てる → ベット候補
  第2層（ブラフ候補）: コールされると負ける → α式で数を管理してベット
  第3層（チェック）: 中間の強さ → チェック
```

## 1-6 ポラライズの強制

ハンドが3層に収束するとき、リバーのベットレンジは自然とポラライズします。

ポラライズとは、レンジを「非常に強いハンド（バリュー）」と「非常に弱いハンド（ブラフ候補）」の両端に集中させることです。中間の層（チェック層）はベットに向かいません。

なぜ中間をベットしないのか。中程度のハンドでリバーにベットすると、次のような問題が起きます。強いハンドを持つ相手はコールします。弱いハンドを持つ相手はフォールドします。これは「弱い相手のコールを取る（バリュー）」機能も「強い相手をフォールドさせる（ブラフ）」機能も果たしていません。コストをかけてEVがほぼゼロという最悪の結果です。

一方、ポラライズされたベットレンジは機能します。バリューベットは相手の弱いコールからチップを得ます。ブラフは相手の中〜弱いハンドをフォールドさせてポットを得ます。バリューとブラフが適切な比率で混在するとき、相手は「コールしてもフォールドしても正解がわからない」というジレンマに陥ります。

このポラライズの論理は、リバーに特有です。ターンでは「セミブラフ」がポラライズとチェックの中間を埋めていました。リバーではその中間がなくなり、ポラライズが強制されます。

## 1-7 本書の3つの暗算式 ─ 何を解くか

リバーの確定ゲームとしての特性から、実戦で解くべき問いは3つです。本書の暗算式は、それぞれに対応します。

### 問い1: 自分がベットするとき、バリューとブラフをどう配分するか

これがα式（アルファ式）が答える問いです。

```
α = ベット額 ÷ (ポット + ベット額)
```

α はベットサイズに応じた「先手のブラフ損益分岐点」です。相手がαの確率でフォールドすれば、ブラフのEVはゼロになります。これを裏から見ると、バリューとブラフの最適比率が導けます。ベットサイズが決まれば、混ぜるべきブラフの数が自動的に計算できます。

α式は巻2で学んだ後手下限の概念の表側です。後手下限確率（守り側が最低限コールしなければならない頻度）は 1 − α で表され、攻め側のα と表裏の関係にあります。詳細は第6章で扱います。

### 問い2: 相手のリバーベットにコールするかフォールドするか

これが後手スコアが答える問いです。

```
後手スコア = HandScore + A − 3 − C − M
  ≥ 0 → コール（または状況によりチェックレイズ検討）
  < 0 → フォールド
```

この式は巻2 第13・16章で学んだフロップ版後手スコアと同じ骨格です。リバー版での係数の扱い方は第7章で詳しく解説します。

### 問い3: 手持ちカードが相手レンジにどう影響するか

これがブロッカー論が答える問いです。

たとえばナッツフラッシュの A♠ を手に持っていれば、相手がナッツフラッシュを持っている確率は大幅に下がります。これを「A♠ がナッツフラッシュをブロックしている」と言います。ブロッカーの働きは、α式や後手スコアの調整項として機能します。第5章・第8章で詳しく扱います。

## 1-8 巻1〜3の読者へ ─ 前提の確認

本書は巻2・巻3の読者が持っているいくつかの概念を土台に展開します。ここで確認しておきます。

**HandScore（ハンドスコア）**: ハンドの強さを0〜50の数値で表す指標です。役スコア + ドロー加点 + ブロッカー加点の3項目で構成されます。巻2 第5章で導入されました。リバーでは「ドロー加点」の意味が変わりますが、基本的な役スコアの構造はそのまま使います。

**後手スコア（巻2 第13・16章）**: 相手のベットへの応答を判断するスコアです。リバー版では係数の扱いを調整しますが、式の骨格は同じです。

**簡易レンジスコア（巻2 導入）**: フロップのボード特性からレンジのCBet頻度を0〜10で予測する指標です。本書では直接使う場面は少ないですが、ボードの「ドライ度」を表すA係数（ドライ=3・セミ=2・ウェット=1）はリバーの後手スコアにも引き継がれます。

**後手下限**: 相手のベットに対して最低限コールしなければならない頻度（後手下限確率）のことです。具体的な数値は後手下限確率（1 − α）で表します。「MDF」という用語は本書では使いません。

巻1〜3を読んでいない方は、これらの概念を本書で定義するたびに確認しながら読み進めてください。

## ミニクイズ

### 問1

リバーでセミブラフが存在しない理由として最も正確なものはどれですか。

1. リバーではポットが大きくなりすぎてリスクが高いから
2. リバーではドローが完成か失敗で確定しており「コールされても将来的に勝てる」という成分がなくなるから
3. リバーではGTOがブラフを禁止しているから
4. リバーでのブラフはフォールドエクイティがゼロだから

### 問2

リバーで「ポラライズ」が起きる根本的な理由はどれですか。

1. リバーはポットが大きいため、強いハンドしかベットしてはいけないルールがあるから
2. エクイティが確定しており、中程度のハンドでベットしてもバリューもブラフの機能も果たせないから
3. リバーでは相手が必ずコールするので、ブラフは意味がないから
4. GTOがリバーのベットをバリューのみに制限しているから

### 問3

α式（α = ベット額 ÷ (ポット + ベット額)）と後手下限確率の関係はどれですか。

1. α と後手下限確率は同じ値である
2. 後手下限確率 = α であり、αが大きいほど守りやすい
3. 後手下限確率 = 1 − α であり、両者は表裏の関係にある
4. α と後手下限確率は無関係である

---

### 解答

- **問1**: 2（セミブラフは「フォールドエクイティ + ドローエクイティ」の複合だが、リバーではドロー改善が残っていないため、ドローエクイティがゼロになる。よって純粋なブラフとなり、セミブラフという役割が存在しない）
- **問2**: 2（中程度のハンドでリバーにベットすると、弱い相手のコールを引き出せず、強い相手をフォールドさせることもできない。エクイティが確定した確定ゲームでは、中途半端なベットのEVが低くなり、強いバリューとブラフ候補への分極が合理的になる）
- **問3**: 3（αは先手のブラフ損益分岐点。1 − αが後手の最低防御率すなわち後手下限確率で、両者は表裏の関係にある）

---

> **本章まとめ**
>
> - リバーは「もうカードが落ちない」確定ゲームであり、ハンドのエクイティが二値化する
> - セミブラフはリバーに存在しない。すべてのベットはバリューかブラフに分類される
> - リバーのハンドは「バリュー層 / ブラフ候補層 / チェック層」の3層に収束する
> - 中間層のハンドがベットしても機能しないため、ポラライズが強制される
> - 本書の3つの暗算式（α式・後手スコア・ブロッカー論）がリバーの3つの問いにそれぞれ答える
> - α式と後手下限確率は表裏の関係（後手下限確率 = 1 − α）にある

**【GTOとのズレ】**

本章で説明したポラライズの論理は概念的には正確ですが、実際のGTOソルバー出力では完全な二極化よりも「ブロッキングベット」と呼ばれる小サイズの混合ベットが出ることがあります。IPがリバーで小さなサイズ（ポットの25〜33%程度）でベットするとき、バリューもブラフ候補も混在した、いわゆるマージナルなレンジでベットすることがあるのです。これは相手のチェックレイズや大きなカウンタープレーを抑制するための設計です。本章のポラライズ論はあくまで「標準的な中〜大サイズのベットレンジ設計」の論理です。

また「チェック層のハンドはベットしない」というルールも絶対ではありません。相手が極端にオーバーフォールドしている（フォールドしすぎる）状況では、チェック層のハンドがバリューベットとして機能する場合があります。GTO的なバランスよりも、相手の弱点を突くエクスプロイトが優先されることがあります。

さらに、リバーでの3層分類は「どのハンドがどの層に属するか」がボードによって大きく変わります。「弱いトップペアはチェック層」という一般則も、相手のレンジが非常に弱い場合はバリュー層に変わります。本書の式はあくまで「相手がバランスを取って動く前提の中央値」を計算するものです。相手の傾向に応じた調整は、第8章以降の戦術編で扱います。
