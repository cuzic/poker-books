# 第2章　レンジ強度（リバー視点）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバーまでのアクション履歴がレンジをどう絞り込むかを理解し、「誰がナッツアドバンテージを持つか」がリバーでの攻撃力を決める仕組みを把握する。

---

## 2-1 レンジとは何か

ポーカーでは、相手がどの1枚のハンドを持っているかを直接知ることはできません。代わりに重要なのは、相手が取りうるすべてのハンドの集合である「レンジ」の形を把握することです。

「相手はAKを持っているのではないか」と1枚のハンドに注目するよりも、「相手のレンジにはAKが何コンボ含まれているか、その割合はどれくらいか」という思考の方が戦略的に正確です。

レンジには2つの独立した軸があります。

**軸1: 幅（ワイドかタイトか）**

レンジに含まれるハンドの数です。BTN（ボタン）のオープンレンジは6-maxで概ね40〜50%と広く（ワイド）、UTGのオープンレンジは約14〜17%と狭い（タイト）です。

**軸2: ナッツの含有量（アンキャップドかキャップドか）**

幅とは独立して、そのレンジが「最強ハンド（ナッツ）を含んでいるかどうか」という軸があります。

- **Uncapped（アンキャップド）レンジ**: ナッツを含む可能性があるレンジ。「上限がない」という意味
- **Capped（キャップド）レンジ**: ナッツが含まれない、または非常に少ないレンジ。「上限がキャップされている」という意味

「ワイドだがCapped」という状況は実戦で頻出します。この非対称性がリバーでの戦略構造を生み出しています。

---

## 2-2 アクションはレンジに刻み込まれる

リバーまでの各ストリートでプレイヤーが取るアクションは、そのレンジに情報を刻み込みます。

コールを選ぶことは「このハンドでレイズするほどではない」という情報をレンジに加えます。ベットを選ぶことは「このハンドでは攻め続ける価値がある」という情報を加えます。フォールドは「このハンドの強さは継続に値しない」という情報を刻み込みます。

この「アクション履歴によるレンジの絞り込み」は、ストリートが進むごとに累積されます。

```
プリフロップ：ポジション + ハンド → オープン/3-bet/コール/フォールド
フロップ：フロップCBet/コール/CR（チェックレイズ）/チェックバック
ターン：ダブルバレル/コール/CR/チェックバック
リバー：その結果の絞り込まれたレンジ同士の勝負
```

リバーに到達するまでに3ストリートの情報が蓄積されています。相手が「プリフロップコール → フロップコール → ターンコール」と来たなら、そのレンジは3回コールし続けた理由を持つハンドで構成されています。

---

## 2-3 Uncapped レンジが生まれる場面

Uncapped レンジは、アクション上の理由でナッツを排除していない場合に生まれます。

**プリフロップのオープンレイザー**

BTNがプリフロップでオープンライズした場合、そのレンジにはAA・KK・AKといったプレミアムハンドが含まれます。まだどんな強いハンドも排除していないため、Uncappedです。

**フロップでCBet（コンティニュエーションベット）を打ったIP**

BTNがフロップでCBetを打った場合、そのレンジには強いハンドも弱いブラフも含まれています。GTO的な設計では、ナッツもブラフも混在させてCBetします。CBetを打ったIPのレンジはUncappedのままです。

**チェックレイズ（CR）を打ったOOP**

OOP（BBなど）がフロップCBetに対してチェックレイズを打った場合、そのレンジはUncappedになります。強いハンドをバックに持ちながら積極的なアクションを取っているため、ナッツを含む状態が保たれます。

---

## 2-4 Capped レンジが生まれる場面

Capped レンジは、アクション上の理由でナッツが別のアクションに振り分けられている場合に生まれます。

**フロップCBetにコールしたOOP**

BBがBTNのフロップCBetにコールした場合を考えます。GTO的には、BBがセットや強いストレートを持っている場合、コールではなくチェックレイズを選びます。コールを選んだ時点で、ナッツの多くはCR方向に振り分けられており、コールレンジのナッツは薄くなります。

加えて、BBのコールレンジにはKK・AAがほぼ含まれません。これらはプリフロップで3-betしているためです。結果としてBBのフロップCBetコールレンジは「ワイドだがCapped」という状態になります。

**フロップをチェックバックしたIP**

BTNがフロップをチェックバックした場合、そのレンジはCappedになります。BTNがAA・KK・セットを持っていれば多くの場合CBetを選ぶため、チェックバックという選択は「ナッツが少ない」という情報を含んでいます。

ただし「遅延CBet（ディレイドCBet）」として、意図的に強いハンドをチェックバックしてターンで打つ戦術もあります。この点は第3章で詳しく扱います。

**複数ストリートをコールし続けたプレイヤー**

3ストリートにわたってコールし続けたプレイヤーは、そのたびに「ナッツならレイズしていたはず」という情報を与えてきました。このパターンはリバーでのレンジ分析で特に重要です。次節で詳しく見ます。

---

## 2-5 「3ストリート全コール」のレンジ分析

リバーで最も重要なシナリオの一つが「相手が3ストリート全コール」の状況です。

BBがBTNのCBet（フロップ）・バレル（ターン）に2回コールし、リバーに到達した場面を想定します。

BBが3回コールし続けた（フロップコール + ターンコール）とすると：

```
プリフロップコール時点：
  → AA・KKはほぼ3-bet済み（プリフロップで排除）

フロップCBetコール時点：
  → セット・強いストレートの多くはCRに振り向けられる
  → AA・KKの残存は希少

ターンバレルコール時点：
  → ターンCRの機会を使わなかった = ナッツ系をCRに使っていない
  → ただしターンでドローが強化されているならコールが合理的
  → 中程度のハンド（TPTK・2ペア・強めの1ペア・ドロー）が中心に

リバー到達時点：
  → 「ナッツが存在しない or 非常に少ない Capped レンジ」
  → 中強度ハンド（TPTK・2ペア・コンプリートしたドロー）が主体
```

このCappedレンジに対して、BTNは大きくベットする権利を持ちます。BTNのレンジはUncappedのままで、リバーまでCBetを続けたことによりナッツも含む状態を保っています。この非対称性（BTN: Uncapped / BB: Capped）がリバーでのBTNの攻撃力の根拠です。

ただし重要な注意があります。「3ストリート全コール = Capped」という図式は「傾向」であり、例外があります。特にドローが完成した場合（フラッシュやストレートが完成）、コールし続けていた相手がリバーでナッツを持つことがあります。「3ストリート全コール = 完全に弱い」ではなく、「ナッツが薄くなっているが、完成したドローには注意が必要」と読むのが正確です。

---

## 2-6 ナッツアドバンテージとは何か

両者のレンジがどちらもUncappedである場合（例: 3-betポットで両者ともに強いレンジを持っている場合）、判断の決め手になるのが「ナッツアドバンテージ」です。

ナッツアドバンテージとは、このボードで最強ハンド（ナッツ）をどちらのレンジがより多く含むかを表す概念です。

具体例で確認します。

**ドライボード K♠7♦2♣ + リバー 5♠**

ボードは K♠7♦2♣5♠ の4枚（リバー）です。

このボードでのナッツ候補は：
- KKのセット（フルハウスやクワッズへの昇格は起きていない。ボードにはKが1枚、7・2・5が各1枚）

実際にはK♠7♦2♣5♠のボードで最強ハンドはどれか確認します。

KKを持つプレイヤーの役：K♠7♦2♣5♠ + KK（例えばK♥K♦）= K×3枚（K♠+K♥+K♦）+ 7・2・5 → セット（3 of a Kind, K）

さらに55を持つプレイヤーの役：5♠ + 55（例えば5♥5♦）= 5×3枚（5♠+5♥+5♦）+ K・7・2 → セット（3 of a Kind, 5）

ストレートはA〜5のA高はA-2-3-4-5（ホイール）なら5♠がターンで来ているため、A3を持つプレイヤーにはA-2-3-4-5のストレートが完成しています。

このボードのナッツはホイールストレート（A-2-3-4-5）か、または強いセットです。

BTNのオープンレンジにはAA・KK・77・55・22・A3sなどが含まれます。一方、BBのコールレンジにはKK・AAがプリフロップ3-bet済みでほぼ不在です。77・55・22のポケットペアは含まれますが、A3sなどのナッツ候補もBTNの方が多く含まれる傾向があります。

このため、BTNはナッツアドバンテージを持っています。

---

## 2-7 ワイドとCappedは独立している

ここで重要な認識を整理します。「レンジが広い（ワイド）」こととそのレンジが「Capped」であることは、まったく独立した話です。

BBのコールレンジがその典型例です。

BBはBTNのオープンに対して非常に広くコールします。ポジション不利と既に投資したブラインドの関係から、多くのハンドをディフェンスレンジに含めます。GTO的に概ね 40〜50% 前後（100BB 6-max）のハンドでコールします。

しかしこの「広さ」はナッツが多いことを意味しません。

```
BB のフロップCBet コールレンジの構成（概念的整理）:
  - KK・AA: プリフロップで3-bet → ほぼ不在
  - セット: フロップCRに振り向けられる傾向 → コールレンジには少数
  - TPTK・2ペア・ドロー系: コールレンジの中心
  → 「ワイドだがCapped」
```

対してBTNのCBetレンジはUncappedです。BTNのオープンレンジにはAA・KK・AK等のプレミアムハンドが残り、CBetレンジにもそれらが含まれます。

重要なのは「タイトなレンジ = Capped」ではないということです。3-betポットではBB（または3-betコーラー）のレンジはタイトですが、3-betに入ったことでナッツ級ハンドが含まれており、Uncappedの場合もあります。レンジの幅とナッツの含有量は別の次元で評価する必要があります。

| 状態 | 例 |
|---|---|
| ワイドかつUncapped | BTNのフロップCBetレンジ（広くナッツも含む） |
| ワイドかつCapped | BBのフロップCBetコールレンジ（広いがナッツが薄い） |
| タイトかつUncapped | 3-bet後のBBのフロップコールレンジ（絞られているがナッツを含む） |
| タイトかつCapped | 複数ストリート全コール後の残存レンジ（絞られかつナッツが薄い） |

## 2-8 リバーでのナッツアドバンテージの意味

リバーでナッツアドバンテージを持つ側は、大きくベットする権利を持ちます。

なぜか。ナッツを持っている確率が高い側がオーバーベット（ポット超えのベット）を打っても、相手は「これはナッツかもしれない」という恐怖を感じながら対応しなければなりません。もし相手がナッツアドバンテージを持っていれば、「このベットに対して自分もナッツで対抗できる」という安心感があります。しかし Capped なレンジの持ち主は、そのような対抗ができません。

ナッツアドバンテージが重要な理由をもう一つ挙げます。リバーでのバランスの問題です。

ブラフを混ぜるためには、バリューハンドが必要です。バリューが少ないのにブラフを打つと、相手は「このプレイヤーはブラフが多い」と察してコールを増やします。ナッツアドバンテージを持つ側は、自然にバリューハンドが豊富なため、ブラフも適切な比率で混ぜられます。ナッツアドバンテージが低い（Cappedな）側は、バリューが足りないため大きなベットとブラフの組み合わせを設計しにくくなります。

```
ナッツアドバンテージ高（Uncapped）:
  → バリューが豊富 → ブラフも適切に混ぜられる → 大きなベットが成立
ナッツアドバンテージ低（Capped）:
  → バリューが少ない → 大きなベットはアンバランス → 中〜小サイズが適切
```

---

## 2-9 「誰が大きく打てるか」を瞬時に判断するフロー

リバーでの判断の第一歩は「自分はCappedかUncappedか、相手はどうか」を確認することです。

### ステップ1: 自分のレンジを評価する

アクション履歴を振り返ります。

- CBet・バレル・レイズを積極的に打ってきた → Uncapped の可能性が高い
- コール一辺倒・チェックバックが多かった → Capped 寄りの可能性が高い

### ステップ2: 相手のレンジを評価する

相手のアクション履歴を同様に確認します。

- 相手が複数ストリートをコールし続けた → 相手はCapped寄り
- 相手がCR・レイズ・3-bet等の積極的アクションを取った → 相手はUncapped

### ステップ3: ナッツアドバンテージを確認する

このリバーボードでのナッツ（フルハウス・フラッシュ・ストレートなど）を、どちらのレンジが多く含むかを評価します。

### ステップ4: アクション方向を決める

```
自分Uncapped・相手Capped → 大きくベット可能（バリューまたはブラフで）
自分Capped・相手Uncapped → 大きなベットは控える。コールか中サイズが中心
両者Capped → 中サイズ。大きなポラライズは効果薄
両者Uncapped → ナッツアドバンテージが高い側が大きく打てる
```

このフローは概念的なものです。実際の数値的な判断はα式（第6章）と後手スコア（第7章）が行います。

---

## 2-10 レンジ強度と本書の3つの暗算式

レンジ強度（Capped vs Uncapped）とナッツアドバンテージは、本書の3つの暗算式の土台となる概念です。

**α式との接続**: α式はベットサイズに応じたバリュー/ブラフ配分を計算します。しかし「何コンボのバリューがあるか」を確認するためには、自分のレンジにナッツが何コンボ含まれているかを把握する必要があります。ナッツアドバンテージの評価がα式の前提になります。

**後手スコアとの接続**: 後手スコアは相手のベットにコールするかどうかを判断する式です。相手がUncappedレンジから大きくベットしている場合、そのベットレンジには強いバリューハンドも多く含まれます。この事実は後手スコアの評価に影響します。具体的には第7章で扱います。

**ブロッカーとの接続**: 相手のレンジにナッツが何コンボあるかを評価するとき、自分の手持ちカードがそのナッツをブロックしているかどうかが重要です。例えば相手のフラッシュナッツに必要なカードを自分が持っていれば、相手のナッツ保有確率が下がります。ブロッカーはナッツアドバンテージの評価を精緻化するツールです（第5章・第8章で詳述）。

## ミニクイズ

### 問1

BTNがK♠7♦2♣でフロップCBetを打ち、BBがコールしました。リバーに到達したとき、各プレイヤーのレンジについて正しい説明はどれですか。

1. BTN: Uncapped、BB: Capped（BBはプリフロップで3-bet済みのKK・AAが少なく、フロップCRに強いハンドを使っているため、コールレンジのナッツは薄い）
2. BTN: Capped、BB: Uncapped（BBがコールしたのは強いハンドを隠すためだから）
3. 両者ともにUncapped（どちらもフロップ後はナッツを保有している）
4. 両者ともにCapped（フロップ後はどちらもナッツが薄い）

### 問2

「ワイドだがCapped」のレンジの典型例はどれですか。

1. UTGのオープンレンジ（ハンドの14〜17%程度の狭い範囲）
2. BTNのフロップCBetレンジ（AA・KK・セットを含む広いレンジ）
3. BBがBTNのフロップCBetにコールしたレンジ（広いが、KK・AA がプリフロップ3-bet済みで不在、セットはCRに振り向けられている）
4. OOPがフロップでチェックレイズを打った後のレンジ（ナッツを含む積極的なアクション）

### 問3

ナッツアドバンテージを持つ側がリバーで大きくベットできる理由として最も適切なものはどれですか。

1. スタックが多いから
2. バリューハンドが豊富なため、ブラフも適切な比率で混ぜられ、バランスの取れたレンジでのオーバーベットが成立するから
3. 相手はナッツを持っていないため、すべてのベットがバリューになるから
4. GTOがナッツアドバンテージを持つ側に大きなベットを推奨しているから

---

### 解答

- **問1**: 1（BTNがCBetを打つレンジにはAA・KK・セット等のナッツが含まれるためUncapped。BBのコールレンジはKK・AAをプリフロップ3-bet済みで持たず、フロップCRに強いハンドを使った残りなので、ナッツが薄くCappedになる）
- **問2**: 3（BBのコールレンジは「ワイドだがCapped」の典型。広いが、AAやKKはプリフロップ3-betで排除され、フロップのセット等はCRに振り向けられる。幅とナッツの含有量は独立している）
- **問3**: 2（ナッツアドバンテージが高い側はバリューハンドが豊富。バリューが多いと、それに対してブラフを適切な比率で混ぜることができ、大きなサイズのポラライズされたレンジが成立する。相手のCappedレンジではこのような対抗が難しい）

---

> **本章まとめ**
>
> - レンジには「幅（ワイド/タイト）」と「ナッツの含有量（Uncapped/Capped）」の2つの独立した軸がある
> - アクション履歴がレンジに情報を刻み込む。コールを繰り返すとCapped化が進む
> - 「3ストリート全コール」のレンジはCappedであることが多いが、完成したドローには注意が必要
> - ナッツアドバンテージを持つ側は大きくベットできる。バリューが豊富だからブラフも混ぜられる
> - ワイドとCappedは独立している。「ワイドだがCapped」はBBコールレンジの典型
> - レンジ強度の評価（Uncapped/Capped）がα式・後手スコア・ブロッカー論すべての前提になる

---

**【GTOとのズレ】**

GTO ソルバーはCapped/Uncappedを厳密に計算して戦略を設計します。実戦でのズレは主に2パターン生じます。

1つ目は「自分がCappedなのに大きく打ってしまう」パターンです。フロップをチェックバックしたターンのレンジや、複数ストリートをコールしてきたレンジからのオーバーベットは、GTO的には「そのレンジからの大きなベットはほぼない」とみなされます。Capped状態からの大きなベットは相手にコールを誘うだけになりやすいため、中〜小サイズが推奨されます。

2つ目は「相手がCappedなのに攻め切れない」パターンです。相手が3ストリート全コールしてきており、リバーで自分がナッツ級ハンドを持っている場合、大きなベットを打つことが合理的です。それをためらって小さくベットしたり、チェックしたりすると、ナッツアドバンテージを持ちながらバリューを取り逃がします。GTOソルバーでは、このような場面でBTNは高頻度で大きなサイズのベットを選びます。

「ワイドだからCapped」「タイトだからUncapped」という短絡的な思い込みも、実戦でのズレを生む要因です。具体的なアクション履歴を確認せずにレンジを評価すると、誤った判断につながります。第3章ではアクション履歴とレンジの絞り込みをより詳しく見ていきます。
