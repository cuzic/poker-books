## 16-1 受験ガイド

### 式の早見表（全問共通）

```
バレルスコア（第8章）:
  = FlopType係数 + TurnCard係数
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0
  ≥7 → 積極バレル / <7 → ハンド依存

後手スコア（第10・11章、HU前提のためM=0）:
  = HandScore + A − C
  A: ドライ=12 / セミ=6 / ウェット=0
  C: 33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30
  ≥40 → CR検討 / 20〜39 → コール / <20 → フォールド

α 式（第9章）:
  α = ベット額 ÷ (ポット + ベット額)
  後手下限確率 = 1 − α = ポット ÷ (ポット + ベット額)

HandScore目安（第5章、0〜100、equity %）:
  フルハウス=92 / フラッシュ=85-90 / ストレート=78-85
  セット=85-92 / 2ペア=68-78 / オーバーペア=68-78
  TPTK=70 / TPGK=66（42+Q×2）/ TPMK=50 / TPWK=45
  セカンドペア=32-42 / アンダーペア=35-45 / ボトムペア=32
  Aハイ=25 / Kハイ=20 / Qハイ=15

ドロー加点:
  ターン Rule of 2: アウツ × 2 (FD +18 / OESD +16 / GS +8)
  リバー: 0
  バックドア固定: BDFD +5 / BDSD +2

ブロッカー加点（重複なし、最大値のみ）:
  ナッツ +5 / 上位セット・ストレート +3 / バリュー +2
```

## 16-3 解答セクション

### Q1 解答　バレルスコア：ドライ板 × ブランクターン

**正解: A. ダブルバレル（50%ポット）**

**ボード読み確認**: A♣K♠ + A♠7♦2♣8♥。ランクカウント: A=2、K=1、8=1、7=1、2=1。ストレートなし。役はワンペア（AA、Kキッカー）。

**バレルスコア計算**:

```
FlopType係数: A♠7♦2♣ はドライ板 → 8
TurnCard係数: 8♥ はブランク → 2
バレルスコア = 8 + 2 = 10 → 積極バレル
```

バレルスコア10で積極バレルゾーン。ブランクターンはBBのコールレンジを強化しないため、A♣K♠のTTPKはバリューベットの条件が整っています。75%にするとBBの弱いAx（A6など）がフォールドして逆選択が起きます。50%が最適サイズです。

**参照**: 第8章（バレルスコア）、第14章（ターンのベットサイズ選択）

---

### Q2 解答　バレルスコア：ペアターンとhand evolution

**正解: A. ダブルバレル（50%ポット）**

**ボード読み確認（hand evolution）**: A♥K♦ + A♠6♦3♣6♥。ランクカウント: A=2（手札A♥＋ボードA♠）、6=2（ボード6♦＋6♥）、K=1、3=1。

```
フロップ: A♥K♦ → TPTK（Aトップ、Kキッカー）
ターン6♥後の5枚選択: A♥ A♠ K♦ 6♦ 6♥
役: 2ペア（AA & 66、Kキッカー）← TPTK から昇格
```

**バレルスコア計算**:

```
FlopType係数: A♠6♦3♣ はドライ板 → 8
TurnCard係数: 6♥ はペアターン → 4
バレルスコア = 8 + 4 = 12 → 積極バレル（最高水準）
```

「6が落ちてBBに有利」という直感は誤りです。ペアターン6はIPのAKをTTPKから2ペアに昇格させ、IP有利に働きます。バレルスコア12、2ペアのバリューを50%ポットで取るのが最善です。

**参照**: 第8章（バレルスコア）、第6章（ペアターンの評価）

### Q3 解答　バレルスコア：セミ板 × コネクターターン（ハンド依存）

**正解: B. チェックバック（SDV保護）**

**ボード読み確認**: T♦T♣ + K♦9♣4♠5♥。ランクカウント: T=2（手札T♦T♣）。ストレートなし（K-9-8-7-6 等の候補は5枚連続にならない）。役はワンペア（TT、Kキッカー）。

**バレルスコア計算**:

```
FlopType係数: K♦9♣4♠ はセミ板 → 6
TurnCard係数: 5♥ は4♠と5♥でコネクター形成 → 0
バレルスコア = 6 + 0 = 6 → ハンド依存
```

ハンド依存ゾーンでバレルを続けるには強いバリュー（2ペア以上）か8アウツ以上のセミブラフが必要です。T♦T♣はKより下のアンダーペアであり、コネクターターンでBBのレンジに45、56などのドローが加わった局面で攻める根拠がありません。チェックバックしてショーダウン価値を守るのが正解です。

**参照**: 第8章（バレルスコア）、第15章（チェックバックの判断）

### Q4 解答　後手スコアターン版：フォールド判断

**正解: C. フォールド**

**ボード読み確認**: T♠9♠ + K♣8♦2♠Q♥。ストレート確認: K-Q-J-T-9（Jなし）、Q-J-T-9-8（Jなし）。スペード: T♠,9♠,2♠=3枚（フラッシュなし）。役はハイカード（Kハイ）。

T♠9♠のドロー確認: J-T-9-8（Jなし）= 3枚連続のみ。アウツはJ 4枚（ガットショット）。

**HandScore計算**:

```
Kハイ基本値 = 20
ガットショット加点（ターン Rule of 2、4 outs × 2）= +8
HandScore ≈ 28
```

**後手スコア計算（HU前提、M=0）**:

```
HandScore = 28
A = 12（K♣8♦2♠Q♥ はドライ板）
C = 22（75%ベット）
後手スコア = 28 + 12 − 22 = 18
```

後手スコア18でフォールド域（20未満）。ガットショット（4アウツ）のドロー加点を含んでも20を割ります。75%という大きなベットに対し、役なし＋弱いドローでコールする根拠はありません。「ガットショットがあるからCR」も誤りです。4アウツではフォールドエクイティが弱く、CRの根拠になりません。

**参照**: 第10章（後手スコアターン版）、第7章（ブロッカー基礎）

### Q5 解答　後手スコアターン版：チェックレイズ判断

**正解: B. チェックレイズ（2.5倍程度）**

**ボード読み確認**: 9♣8♣ + 9♠8♦4♥3♠。ランクカウント: 9=2（手札9♣＋ボード9♠）、8=2（手札8♣＋ボード8♦）。ストレートなし（9-8-7-6-5 等は7,6,5なし）。クラブ: 9♣,8♣=2枚のみ（フラッシュなし）。役は2ペア（99 & 88）。

**HandScore推定**: 2ペア（top + 2nd、9's & 8's）≈ **75**。

**後手スコア計算（HU前提、M=0）**:

```
HandScore = 75
A = 6（9♠8♦4♥ はセミ板）
C = 22（75%ベット）
後手スコア = 75 + 6 − 22 = 59
```

後手スコア59でCR域（40以上）を明確に超えています。2ペア（99 & 88）は9♠8♦4♥3♠で非常に強力なハンドです。BTNの75%ベットに対し、CRして最大バリューを取るのが最善です。75%ベットへのCRは2.5倍（約16.9BB）が標準サイズです。

**参照**: 第10章（後手スコアターン版）、第13章（OOPの応戦）

### Q6 解答　α 式：ベットサイズからの後手下限確率

**正解: D. B と C の両方が正しい**

**α 式の計算**:

```
α = 15 ÷ (30 + 15) = 15 ÷ 45 ≈ 0.333（33.3%）
後手下限確率 = 1 − α = 1 − 0.333 ≈ 0.667（66.7%）
```

これは50%ポットベット（15 ÷ 30 = 0.5）です。

- B「67%でコールして後手下限ラインを守る」: 正しい。BBはハンドの67%以上でコール（またはCR）する必要があります。
- C「BTNはバリュー:ブラフ = 2:1」: 正しい。α ≈ 0.333 なので、BTNのベットレンジはバリュー（1−α）≈ 67% : ブラフ α ≈ 33% = 約2:1 で均衡します。
- D「B と C の両方が正しい」: 正解です。

50%ポットの後手下限確率67%とバリュー:ブラフ = 2:1 はセットで覚えておくと実戦で即座に使えます。

**参照**: 第9章（α 式）

### Q7 解答　後手スコアリバー版：チェックレイズ判断（セット）

**正解: B. チェックレイズ（バリューCR）**

**ボード読み確認**: 8♠8♦ + 8♣6♦3♠2♥7♦。ランクカウント: 8=3（手札8♠8♦＋ボード8♣）。ストレート確認: 7-6-5-4-3（5,4なし）、6-5-4-3-2（5,4なし）。フラッシュなし。役はスリーオブアカインド（セット、888）。best 5 = 8♠8♦8♣7♦6♦。

**HandScore推定**: セット（888）≈ **88**。

**後手スコア計算（HU前提、M=0）**:

```
HandScore = 88
A = 6（8♣6♦3♠2♥7♦ はセミ板）
C = 17（50%ベット）
後手スコア = 88 + 6 − 17 = 77
```

後手スコア77で強CRゾーン（40以上を大きく超えている）。セット（888）はほぼすべてのBTNコールレンジに勝ちます。「ストレートに注意」という選択肢Cは誤りです。このボードでストレートが完成するには5-4や4-3など手元にないカードが複数必要であり、現実的な脅威ではありません。バリューCRで最大EVを取るのが正解です。

**参照**: 第11章（後手スコアリバー版）、第13章（OOPの応戦）

### Q8 解答　後手スコアリバー版：ストレート完成の見落とし防止

**正解: B. チェックレイズ（強ハンドとして最大バリュー）**

**ボード読み確認（ストレート検証が核心）**: K♥Q♦ + J♣T♦9♥4♠K♠。ランクカウント: K=2（手札K♥＋ボードK♠）。

```
全ランク（ユニーク）: K, Q, J, T, 9, 4
K-Q-J-T-9 = 5連続 → ストレート完成！
```

K♥Q♦はこのボードで**K-highストレート（K-Q-J-T-9）**が完成しています。ワンペア（KK）ではなく、ストレートが役です。

**HandScore推定**: K-highストレート ≈ **82**。

**後手スコア計算（HU前提、M=0）**:

```
HandScore = 82
A = 0（J♣T♦9♥ はコネクテッドウェット板）
C = 22（75%ポット相当のベット）
後手スコア = 82 + 0 − 22 = 60
```

後手スコア60でCR域（40以上）を大きく超えています。K-highストレートは非常に強力なハンドであり、チェックレイズで最大バリューを取るのが最善です。

典型的な誤り: 「KKペアだからコールで守る」という判断。コネクテッドボードでは手牌がストレートに化けていないか、5枚連続チェックを必ず行ってください。

**参照**: 第11章（後手スコアリバー版）、第6章（コネクテッドボードの評価）

> **本章まとめ**
>
> - バレルスコアは「FlopType係数 + TurnCard係数」の足し算1回で判断できる。スコア7以上が積極バレルゾーン。
> - ターン・リバーの後手スコアは「HandScore + A − C（HU前提）」。20以上でコール、40以上でCR検討、20未満でフォールド。

**【GTOとのズレ】**

本章のドリルは基礎暗算式の直接適用を中心に設計しています。実際のGTOとのズレが出やすいポイントを3点示します。

後手スコアはCR検討の下限を示すだけであり、CR比率や具体的なサイズはGTOによって細かく変わります。後手スコアが35〜50の境界域では、GTO実測でも「コール寄り」「CR寄り」が混在します。本章ではこの境界域をコール判断に倒して設計していますが、実戦ではソルバーで確認することをお勧めします。

α式のV:B比率計算は「ベットレンジ全体の理論比率」を示しますが、GTO実測ではブロッカー効果・レンジ形状によってコンボごとに頻度が変わります。「全バリューハンドを100%ベット、全ブラフをα比率でランダムベット」という単純化はGTOの近似であり、誤差は10〜15%の範囲で生じます。

HandScore推定値（セット ≈ 88、2ペア ≈ 75、TPTK ≈ 70 など）は目安です。実際のGTOでは同じ「トップペアトップキッカー」でもボードのウェット度・ブロッカー効果・レンジ文脈によって5〜10点の差異が生じます。暗算式の精度を上げるには、第5章で学んだHandScoreの詳細計算（役スコア＋ドロー加点＋ブロッカー加点）を丁寧に適用してください。
