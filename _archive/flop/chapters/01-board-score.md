# 第1章　ボードスコア B を計算する

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**：フロップの 3 枚を見た瞬間に B（ボードスコア）を 1 秒以内で算出できるようになる。B は「IP 側がどれだけ CBet しやすいか」を 0〜100 で表す指標です。

---

## 1-1　なぜボードを数値化するのか

フロップを見たとき、「このボードは CBet しやすいか」をどうやって判断しますか。多くの初心者は「なんとなくドライだからベット」「なんとなくウェットだからチェック」という感覚に頼ります。しかし感覚は個人差が大きく、精度も安定しません。

本書では、ボードの有利不利を **B（ボードスコア）** という 0〜100 の数値で表します。B は「IP 側（ポジションのある側）がそのフロップで CBet を有効に打てる度合い」を表します。B が高いほど IP に有利なボードで CBet が通りやすく、B が低いほど OOP 側にドローや強いレンジが揃いやすいボードです。

B の役割は、第0章の 5 ステップフローで示した「Step 1：B を計算する」に対応します。B を出力してから HS と組み合わせることで、CBet するかしないかを客観的に決めることができます。

---

## 1-2　9 ルールの全体像

B は次の **9 ルール（優先順位つき）** で決まります。上から順にチェックし、最初に当てはまったルールの値を使います。

```
1. ペアボード × トップカード T 以上   → B = 83
2. モノトーン（3 枚同スート）          → B = 70
3. ペアボード × トップカード 9 以下    → B = 71
4. 2トーン × トップカード A/K         → B = 56
5. 2トーン（その他）                  → B = 50
6. レインボー × spread≤3 × トップ J 以上 → B = 67
7. レインボー × トップカード A/K      → B = 62
8. レインボー × トップカード Q        → B = 58
9. レインボー（その他）               → B = 55
```

「モノトーン」は 3 枚すべて同スート（例：K♠9♠4♠）、「2トーン」は 2 枚が同スートで 1 枚が異スート（例：K♠9♠4♥）、「レインボー」は 3 枚すべて異スート（例：K♠9♥4♦）を指します。「ペアボード」はフロップに同ランクが 2 枚含まれるボード（例：K♠K♥4♦、7♠7♣2♦）です。

「spread」はボード最上位ランクと最下位ランクの差です。例えば J-9-7 なら最上 J（11）と最下 7（7）の差は 4 となります。

---

## 1-3　9 ルールの覚え方

9 つの値を丸暗記するのは大変に見えますが、**大きな順序の不等式** として覚えると整理できます。

```
ペア高（83） > ペア低（71） ≈ モノトーン（70）
  > 2トーン高（56） > 2トーン低（50）
  > レインボー系（55〜67）
```

実は最も覚えやすい構造は「**ペアボードが最強、モノトーンが次、残りはスート構造 × トップカード位置**」です。

### なぜペアボードが最高値なのか

ペアボードでは OOP（BB 等）が 3bet せず BB コールで入ることが多いため、IP（BTN 等）のレンジの方がペアボードを「セット」で踏み台にできる頻度が高くなります。OOP はセットを持てるポケットペアでフラットコールすることも稀で、結果的にペアボードは IP 側がセット・トリップスで優位に立てるボードになります。B=83 はこれを反映した最高値です。

### なぜモノトーンが B=70 と中間なのか

モノトーンボードでは IP だけでなく OOP も同スートのフラッシュドローやフラッシュ完成ハンドを持てます。IP が一方的に優位にはならないため、B=83 のペアボードよりは低い 70 に設定されています。

### レインボーのバリエーション

レインボーの中で B が異なるのは「**つながり（spread）**」と「**トップカードの高さ**」によります。

- spread≤3（例：J-T-8）で top≥J → レンジがコネクテッドになりやすく、IP の強いコンボ数が増えるため B=67
- top A/K → IP レンジにハイカードが多く、ナッツアドバンテージが IP 側に偏るため B=62
- top Q → 中位のトップカードで IP もそれほど圧倒しないため B=58
- そのほか → 最低値 B=55

## 1-4　代表ボードで計算練習

実際にいくつかのボードで B を計算してみましょう。

### 例1：K♠ 7♥ 2♦（レインボー、トップ K）

- ペアボード？　いいえ
- モノトーン？　いいえ
- 2トーン？　いいえ（スート：♠♥♦）
- レインボー × spread≤3？　K（13）− 2（2）= 11 → spread=11 → 3 以下ではない
- レインボー × top A/K？　top は K → **ルール 7** 適用 → **B = 62**

### 例2：K♠ 9♠ 4♠（モノトーン）

- ペアボード？　いいえ
- モノトーン？　はい（♠♠♠）→ **ルール 2** 適用 → **B = 70**

### 例3：K♦ K♥ 7♠（ペアボード、トップ K）

- ペアボード？　はい（K が 2 枚）
- トップカード K（13）≥ T（10）？　はい → **ルール 1** 適用 → **B = 83**

### 例4：7♣ 7♦ 2♠（ペアボード、トップ 7）

- ペアボード？　はい（7 が 2 枚）
- トップカード 7（7）≥ T（10）？　いいえ → **ルール 3** 適用 → **B = 71**

### 例5：9♠ 8♦ 7♣（レインボー、spread≤3、top J 未満）

- ペアボード？　いいえ
- モノトーン？　いいえ
- 2トーン？　いいえ（スート：♠♦♣）
- レインボー × spread≤3？　9（9）− 7（7）= 2 → spread=2 ≤ 3 → top は 9（9）< J（11）→ ルール 6 の「top≥J」を満たさない
- レインボー × top A/K？　いいえ（top は 9）
- レインボー × top Q？　いいえ（top は 9）
- → **ルール 9** 適用 → **B = 55**

> **補足**: 9-8-7 はスプレッドが小さく連続性は高いですが、BB のワイドレンジに直撃しやすいため BTN のレンジ優位が小さく B=55 となります。ルール 6（B=67）は top≥J という高カード条件を満たしたコネクテッドボードに限定されます。

### 例6：Q♠ 5♦ 3♣（レインボー、top Q）

- ペアボード？　いいえ
- モノトーン？　いいえ
- 2トーン？　いいえ
- レインボー × spread≤3？　Q（12）− 3（3）= 9 → spread=9 → ルール 6 不適合
- レインボー × top A/K？　いいえ（top は Q）
- レインボー × top Q？　はい → **ルール 8** 適用 → **B = 58**

---

## 1-5　B と CBet 閾値の対比

B を計算したら、それを Tier の CBet 閾値と比べます。

| Tier | CBet の条件 | 意味 |
|------|------------|------|
| T1（HS ≥ 65） | B の値に関わらず CBet | 強いハンドは常に攻めてよい |
| T2（HS 20〜64） | B ≥ 58 なら CBet | 中強ハンドはボードが IP 有利なときだけ攻める |
| T3（HS < 20） | B ≥ 62 なら CBet | 弱いハンドは非常に IP 有利なボードでのみ攻める |

T1 は B の値に依存しないため、B を計算する意味はありません。B が重要なのは主に **T2 と T3 のハンド** です。

T2 の閾値 **B≥58** は、9 ルールでいうと「レインボー top Q（B=58）以上」が対象になります。つまり T2 は 2 トーン系・ペアボード・モノトーンなど比較的 IP 有利なボードでベットします。

T3 の閾値 **B≥62** は、「レインボー top A/K（B=62）以上」が対象です。T3 がベットを検討できるのは、レインボーのハイカードボード・ペアボード・モノトーンに絞られます。

---

## 1-6　B の限界と補正

B はフロップ 3 枚だけで決まる「マクロ指標」です。次のような状況には対応していません。

- **相手のレンジとの噛み合い**：相手が特定のハンドを持ちやすいとき（例：BTN オープンに対して BB のレンジには低ペアが多い）
- **ハンドクラスの偏り**：自分がセット・2ペアを持っている場合、B の値より実際のナッツ差が重要
- **深スタックでのポテンシャル**：SPR が非常に大きいとき、コネクテッドボードでのドローポテンシャルが B の示す値より高くなることがある

こうした補正は第3〜4章（T1/T2/T3 ティア × CBet 判断）で扱います。B はボードの「型」を掴むマクロ指標で、HS と組み合わせて初めて判断が確定します。まずは型の分類を確実にしてください。

---

## 1-7　よくある間違いと注意点

### 間違い1：スートを数え間違える

「2トーン」の条件をチェックするとき、スートの実際の枚数を数え忘れて「K♠9♠4♥ はモノトーンかも」と混乱するケースがあります。♠♠♥ で 2 枚♠ が 2 枚なら 2 トーン、3 枚全部が同スートならモノトーンです。実戦では手元の牌を見る前にボードのスートマークを素早く視認する訓練をするとよいです。

### 間違い2：spread の計算を間違える

spread はボードの「最大ランクと最小ランクの差」です。J-9-7 なら J=11、7=7 で差=4 となります。「9と7の差=2」のように隣接する 2 枚の差を計算してしまうと誤ります。A=14、K=13、T=10 として数値で差を出してください。

### 間違い3：ペアボード優先を忘れる

9 ルールは上から優先です。「7♠7♣2♦」は 2 トーン（♠♣♦ → ♠と♣が違うので。.. 実はこれはレインボーでもあります）が先に当てはまりそうに見えますが、「ペアボード × トップ 9 以下」のルール 3 が先に適用され B=71 になります。スートより「ペアかどうか」を先にチェックする習慣をつけましょう。

---

## 【GTOとのズレ】

B の 9 ルールはソルバーの CBet 頻度を平均的な代表値で近似しています。同じ「レインボー top K（B=62）」でも、ボードの連続性（例：K-7-2 vs K-J-9）や相手のレンジ構成によって実際の GTO CBet 率は 60〜95% に広がります。B=62 は「この範囲のボードの中間値」として機能しますが、境界付近のボードでは 5〜15% の誤差が生じることを覚えておいてください。

---

## 章のまとめ

- B（ボードスコア）はフロップ 3 枚の IP 有利度を 0〜100 で表す
- 9 ルールを上から順にチェックし、最初に当てはまった値を使う
- ペア高（83）> ペア低（71）≈ モノトーン（70）> 2トーン高（56）> 2トーン低（50）> レインボー系（55〜67）
- T2 ハンドは B≥58、T3 ハンドは B≥62 でのみ CBet を検討する
- B はフロップ 3 枚のみで決まるマクロ指標。HS との組み合わせで CBet 判断が確定する（第3・4章）

## ミニクイズ

### 問1

ボード A♥ 6♠ 3♦ の B はいくつですか？

A. B = 50  
B. B = 55  
C. B = 62  
D. B = 67

### 問2

ボード Q♣ T♣ 8♣（モノトーン）に対して、T2 ハンド（HS=35）は CBet すべきですか？

A. B を計算してから T2 閾値（B≥58）と比較する必要があるのでまず B を算出する  
B. モノトーンの B=70 は 58 以上なので CBet する  
C. モノトーンはドローが多く危険なのでチェックすべき  
D. T2 はどのボードでも CBet しない

### 問3

「ペアボード × トップカード T 以上」のルールが最優先なのはなぜですか。正しい理由を選んでください。

A. ペアボードはモノトーンより常にポットが小さくなるから  
B. IP 側がペアボードでセットを作りやすく、ナッツアドバンテージが最大になるから  
C. ペアボードは OOP のフラッシュドローを排除できるから  
D. ペアボードでは全プレイヤーがチェックしなければならないルールがあるから

---

### 解答

- **問1**：C。スート ♥♠♦ で 3 種類 → レインボー。トップカードは A → ルール 7「レインボー × top A/K」→ B = 62。
- **問2**：B。モノトーンはルール 2 で B=70。T2 の閾値は B≥58 なので、70 ≥ 58 を満たし CBet します。なお C の「モノトーンはドローが多い」は事実ですが、T2 ハンドには十分な CBet 価値があり、B の閾値判定で決めるのが本書の方針です。
- **問3**：B。IP 側（BTN など）のオープンレンジにはポケットペアが多く含まれ、ペアボードではセットを持てるコンボ数で IP が優位に立つことが多いです。これがナッツアドバンテージとして B=83 という最高値に反映されています。
