## カテゴリ1 暗算式の核

**Board Score B（ボードスコア B）**
フロップボードの IP ナッツアドバンテージを数値化した指標。9 ルールで 50〜83 の値を取る。T1/T2/T3 の CBet 閾値判断に使用。巻② で導入。

**T1/T2/T3 ティアシステム**
HandScore（HS）に基づくフロップ 3 段階分類。T1（HS≥65）= 常時 CBet。T2（HS 20-64）= B≥58 でCBet。T3（HS<20）= B≥62 でブラフ CBet。巻② で導入。

**OOP フォールド閾値**
フロップ防御側（OOP）がフォールドを選ぶ HS 水準。vs33%→HS<15、vs75%→HS<35 を基準とし、ボードテクスチャで補正する。巻② で導入。

**後手スコア**
ターン・リバーのディフェンス判断式。後手スコア = HandScore + A − C − M。スコア ≥ 40 でチェックレイズ検討、20〜39 でコール、20 未満でフォールド。ターン・リバーで使用する。

**HandScore**（ハンドスコア）
ハンド強度の数値指標（0〜100、equity % に対応）。役スコア + ドロー加点 + ブロッカー加点の 3 項からなる。フロップの T1/T2/T3 ティア判定とターン・リバーの後手スコアに共通入力として使用する。

**バレルスコア**
ターン攻撃の判断式。バレルスコア = FlopType係数 + TurnCard係数。スコア ≥ 7 で積極バレル。

**α 式（アルファ式）**
リバー配分の式。α = ベット ÷ (ポット + ベット)。MDF = 1 − α。

**レンジ優位**
ナッツアドバンテージ（一方のレンジにナッツが集中）とエクイティアドバンテージ（全体的なエクイティ優位）の 2 軸でレンジの強さを評価するフレームワーク。巻③ で精密分析を扱う。

## カテゴリ2 係数

**A（ボード値）**
ボードのドライ度を 3 段階で表す係数。ドライ = 12 / セミ = 6 / ウェット = 0。

**C（ベット負担）**
相手のベットサイズに応じたコスト係数。33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30。C ≒ α × 50 と覚える。

**M（マルチウェイ補正係数）**
プレイヤー数による補正。HU=0 / 3-way=12 / 4-way以上=22。巻⑥ の「M 値」（スタック深さ）とは別物。

## カテゴリ3 レンジ概念

**Capped / Uncapped（キャップド / アンキャップド）**
レンジ強度の分類。Uncapped はナッツ級ハンドを含み得るレンジ。Capped はナッツ級が薄く守備的になるレンジ。

**ナッツアドバンテージ**
最強のハンドがどちらのレンジに多く存在するかの指標。ターンカードの落ち方によって更新される。

**3軸統合**
ターン判断 = forward 軸（過去のアクション）× current 軸（ターンカードの影響）× backward 軸（リバー予測）の統合フレーム（巻⑤ で導入）。

**MDF**
コール側が確保すべき最低防御率の概念。MDF ライン（境界）、MDF（%値）、MDF スコア（式の判断境界 = 20）の 3 系統で使い分ける。

## カテゴリ4 トーナメント特有

**ICM equity（ICM エクイティ）**
チップを賞金期待値（$EV）に換算した値。「自分のスタックが今いくら相当か」を表す。

**ICM 補正**
ICM 圧力下で必要な上乗せ勝率（リスクプレミアム）。ICM 補正 = bubble factor − 1.0。

**bubble factor（バブルファクター）**
オールイン勝負時の「失う痛み / 得る喜び」比。BF = 1.0 なら ICM 影響なし。

**M 値（M ratio）**
スタック深さの指標。スタック ÷ (SB + BB + アンテ合計)。Green≥20 / Yellow=10-20 / Orange=6-10 / Red≤5。

**ペイジャンプ**
賞金階段の上昇幅。ITM 進入や FT 進入の「ジャンプ点」で ICM 補正が再上昇する。
