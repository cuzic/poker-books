# 第7章　HandScore ─ ハンド強度 0〜100

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 自分のハンドの強さを HandScore（0〜100、equity %）として計算し、後手スコアや先手スコアへの入力として使えるようになる

---

## 7-1 なぜハンドを「数値」にするのか

「トップペアがあるからベットしよう」「フラッシュドローがあるからコールしよう」という判断は、直感として正しいことが多いです。しかし判断の境界線が曖昧なまま実戦で使い続けると、微妙な手での判断がブレ続けます。

HandScore は、ハンドの強さを 0〜100 の数値（equity %）に変換することで、後手スコアや先手スコアの式に接続できる形にします。「この手はコールか、チェックレイズか」という判断を式で出せるようになるのは、HandScore が数値として定義されているからです。

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
            （0 ≤ HandScore ≤ 100、上限 100 でクランプ）
```

HandScore は「自分の equity %」と直感的に読めます。読者の Rule of 2 / Rule of 4 知識をそのまま活用できる構造です。3 つの要素を順番に見ていきます。

### 初心者向け 3 分類のまとめ

詳細表に進む前に、まず**強・中・弱の 3 段階で十分**な暗算判定を覚えてください。

| 強度 | HandScore 目安 | 主な対象 | 行動方針 |
|---|---|---|---|
| **強** | ≥ 65 | セット以上 / 2ペア / TPTK / オーバーペア（高） / モンスタードロー | バリューベット・コミット方向 |
| **中** | 35〜64 | TPGK / TPMK / TPWK（上端） / アンダーペア / FD 単独 / OESD 単独 | コール・SDV 保護 |
| **弱** | < 35 | ボトムペア / セカンドペア・弱キッカー / ハイカード / BDFD のみ | フォールド・ブラフキャッチ |

3 分類で 7 割の判断が決まります。残り 3 割（境界ハンド）に対してのみ、後段の役スコア・ドロー加点・ブロッカーで精密化します。

## 7-2 役スコア ─ 完成役の基礎点

フロップ時点で完成している役に応じた基礎点です。

| ハンド | 役スコア |
|---|---|
| ストレートフラッシュ / クワッズ | 95 |
| フルハウス | 92 |
| トップセット | 92 |
| A ハイフラッシュ（ナッツフラッシュ） | 90 |
| ミドルセット | 88 |
| ボトムセット / トリップス | 85 |
| フラッシュ（中） / A ハイストレート | 85 |
| ストレート（high / mid） | 80〜82 |
| ストレート（low） | 78 |
| 2ペア（top 2）/ オーバーペア（高: AA-QQ） | 78 |
| 2ペア（top + mid） | 75 |
| 2ペア（top + bottom）/ オーバーペア（中: JJ-TT） | 72 |
| **TPTK**（A or K キッカー） | **65** |
| TPGK（Q+ キッカー） | 66 |
| TPMK（8-J キッカー） | 55 |
| TPWK（7 以下キッカー） / アンダーペア（高） | 45 |
| アンダーペア（中: JJ-TT） / セカンドペア（Q+ キッカー） | 40〜42 |
| アンダーペア（低: 99 以下）/ セカンドペア（中キッカー） | 35 |
| ボトムペア / セカンドペア（弱キッカー） | 32 |
| A ハイ | 25 |
| K ハイ | 20 |
| Q ハイ以下 | 10〜15 |
| 完全空振り | 8 |

### キッカーの分類基準

トップペアのキッカー分類は 4 段階です。

- **TPTK（65点）**: キッカーが A または K（ナッツキッカー）
- **TPGK（66点、42+Q×2）**: キッカーが Q+（ただし TPTK に該当しない場合）
- **TPMK（55点）**: キッカーが 8〜J
- **TPWK（45点）**: キッカーが 7 以下

セカンドペアもキッカーで分割します。Q+ なら 42 点、中キッカーなら 35 点、J 以下なら 32 点です。

セカンドペアとアンダーペアの違いは「ボードのどのカードにヒットしたか」で決まります。トップカードにヒットすればトップペア、2 番目のカードならセカンドペア、最低カードならボトムペアです。ポケットペアがボードのどのカードより高くなければアンダーペアです。

> 本書の役スコア値は GTO ソルバーの equity 実測と整合しています（92.6%）。

## 7-3 ドロー加点 ─ 未来のエクイティを Rule of 4 / 2 で換算

Rule of 2 and 4 をそのままドロー加点に使えます。

```
フロップ: ドロー加点 = アウツ × 4
ターン:   ドロー加点 = アウツ × 2
リバー:   ドロー加点 = 0（確定）
```

| ドローの種類 | アウツ数 | フロップ | ターン |
|---|---|---|---|
| FD + OESD（モンスタードロー） | 13（重複−2） | **+52** | +26 |
| FD + ガットショット | 12 | +48 | +24 |
| **OESD（裸）** | 8 | **+32** | +16 |
| フラッシュドロー（FD） | 9 | +36 | +18 |
| **ガットショット（裸）** | 4 | **+16** | +8 |
| 2 オーバーカード | 6 | +24 | +12 |
| バックドアフラッシュドロー（BDFD、固定） | ─ | +5 | ─ |
| バックドアストレートドロー（BDSD、固定） | ─ | +2 | ─ |
| ダブルバックドア（BDFD+BDSD、固定） | ─ | +6 | ─ |

バックドアドローは Rule of 4 だと過大評価になるため固定値にします。

### 例外補正

モノトーン板上の FD や 3-flush 板上の FD（相手のフラッシュ完成 board）は補正 ×0.5（相手も完成するため）。

各ドローの戦略的意味:

- **OESD（+32）**: メイドハンド級の積極性で扱える。TPGK（66）に近い数値
- **ガットショット（+16）**: 4 アウツでも積極的に bet 候補。ストレート完成時にナッツに近い
- **FD+OESD（+52）**: 100% bet。メイドハンドより強い場合もある

---

## 7-4 ブロッカー加点 ─ 相手のナッツを間接的に削る

自分のカードが相手の特定の強いハンドの組み合わせ数を減らす効果をブロッカー加点として加算します（重複加算なし、最大値のみ）。

| ブロッカーの種類 | 加点 |
|---|---|
| ナッツブロッカー（ナッツフラッシュ A、ナッツストレートのキー） | +5 |
| 上位セット / ストレートブロッカー | +3 |
| バリューブロッカー（中位、相手の TP+ を削減） | +2 |
| バックドアブロッカー（BDFD のスート） | +1 |

ブロッカー加点は、主にブラフや半ブラフの局面で意味を持ちます。相手がナッツを持てる確率が下がれば、フォールドエクイティが上がります。詳細は巻③（レンジ優位 + ブロッカー基礎）で扱います。

## 7-5 計算例 4 つ

### 例1: AKo on K♦7♣2♥（A=12 のドライボード）

- ハンド: A♠K♣
- フロップ: K♦7♣2♥（レインボー）
- ヒット: トップペア（K）、キッカー A → TPTK

```
役スコア:   TPTK = 65
ドロー加点: なし = 0
ブロッカー加点: なし = 0
HandScore = 65
```

TPTK の標準値です。先手スコア = 65 + 12 = 77 ≥ 60 で大ベット、後手スコア計算にも使えます。

> **先手スコア = HandScore + A − M**（ベット額を負担しない攻撃側なので C を引かない）

### 例2: 88 on T♦9♣8♥（ウェットボード）

- ハンド: 8♠8♦
- フロップ: T♦9♣8♥（2 枚連続 + セット完成）
- ヒット: ボトムセット（8 のセット）

```
役スコア:   ボトムセット = 85
ドロー加点: なし = 0
ブロッカー加点: なし = 0
HandScore = 85
```

セットは役スコア単体で最高クラスです。ただしボードがウェット（A=0）なので、相手もドロー系ハンドを多く持ちます。

### 例3: A♠5♠ on K♠7♠2♦（セミウェットボード、フラッシュドロー）

- ハンド: A♠5♠
- フロップ: K♠7♠2♦（スペード 2 枚 = 2-tone）
- ヒット: 空振り（A ハイのみ）、フラッシュドロー（スペード 9 アウツ）、A ナッツブロッカー

```
役スコア:   A ハイ = 25
ドロー加点: FD（9 アウツ × 4）= 36
ブロッカー加点: A♠でナッツフラッシュブロッカー = +5
HandScore = 25 + 36 + 5 = 66
```

役なしでも HandScore 66 になります。TPGK（66）と同等の強さで、セミブラフとして積極的に使える手であることが数値で確認できます。

### 例4: JJ on K♠8♦3♣（ドライボード、オーバーペア）

- ハンド: J♠J♣
- フロップ: K♠8♦3♣（レインボー）
- ヒット: オーバーペア（ただし K がオーバーカード、JJ はミドルクラス）

```
役スコア:   オーバーペア（中）= 72
ドロー加点: なし = 0
ブロッカー加点: なし = 0
HandScore = 72
```

HandScore は 72 ですが、K がオーバーカードとして存在するため相手が K を持つケースに注意が必要です。HandScore はあくまで「役の強さの指標」であり、ボードとの文脈は先手スコア・後手スコアの式で組み合わせて判断します。

## 7-6 上限・例外ルール

暗算結果が実装値とずれないよう、以下のルールを押さえておきます。

- **HandScore 上限 100**: 強役 + 強ドロー + ブロッカー で 100 を超えたら 100 にクランプ
- **フロップドロー加点 上限 60**: FD+OESD (13 outs = 52) は許容、それ以上のコンボは 60 で頭打ち
- **ターンドロー加点 上限 30**: 同様に 30 で頭打ち
- **モノトーン板 / 3-flush 板の FD は ×0.5**: 相手も完成可能性があるため
- **ペア持ちのオーバーカード加点はゼロ**: ペア (TPTK 等) を作っているとき、追加の overcard は加点しない
- **ペア + BDFD = +3 / ペア + BDSD = +1 (固定)**: 役を持ちながらバックドアもあるときは Rule of 4 ではなく固定値

詳細は巻② 第5章・第9章を参照。

## ミニクイズ

### 問1

K♦Q♥ を持ち、フロップが K♠J♣5♦ の場合、HandScore を計算してください。

1. HandScore = 65（TPTK）
2. HandScore = 66（TPGK、42+Q×2=66）
3. HandScore = 45（TPWK）
4. HandScore = 78（オーバーペア）

### 問2

A♥T♥ を持ち、フロップが 9♥8♥7♦ の場合、HandScore を計算してください。なお、A♥ と T♥ でハートが 2 枚、ボードにも 9♥8♥ でハートが 2 枚あり、合計 4 枚のハートが見えています。

1. HandScore = 8（空振り）
2. HandScore = 36（FD のみ）
3. HandScore = 82（FD + OESD のモンスタードロー + ナッツブロッカー A♥）
4. HandScore = 100（上限）

---

### 解答

- **問1**: 正解は **2**（HandScore = 66、TPGK）
  K♦Q♥ on K♠J♣5♦。トップカードは K で、Q はキッカーです。Q は Q+ に該当し、TPTK（A または K キッカー）ではないため TPGK = 42+Q×2 = 42+24 = 66。ドロー加点・ブロッカー加点なし。HandScore = 66。

- **問2**: 正解は **3**（HandScore = 82）
  A♥T♥ on 9♥8♥7♦。完成役はなし（9-8-7 にヒットなし）で A ハイ役スコア = 25。OESD（J または 6 で 8 アウツ）+ FD（ハート 9 アウツ）。重複アウツ −2 で実効 13 アウツ。フロップ ×4 = 52。ナッツフラッシュ（A♥）ブロッカー +5。HandScore = 25 + 52 + 5 = 82。TPTK（65）を上回るモンスタードロー強度。

## 本章まとめ

- HandScore = 役スコア + ドロー加点 + ブロッカー加点の 3 項目合計（0〜100、equity %）
- 主要な役スコア: Set+/Flush+ = 85〜95 / 2pair top = 78 / OP = 68〜78 / TPTK = 70 / TPGK = 66（42+Q×2）/ TPMK = 50 / TPWK = 45 / 2nd = 32〜42 / ボトムP = 32 / ハイカード = 8〜25
- ドロー加点 = アウツ × 4（フロップ）/ × 2（ターン）/ 0（リバー）
- 代表値: FD = +36 / OESD = +32 / GS = +16 / FD+OESD = +52（フロップ）
- BDFD = +5 / BDSD = +2（固定）
- ブロッカー加点はナッツ +5、セット/ストレート +3、バリュー +2、BD +1（重複加算なし）
- ティア: T1 ≥65 / T2 20-64 / T3 <20
- スコア値は GTO 実測 92.6% の整合率
- HandScore は後手スコア・先手スコアの中核入力。この値単独ではなく A/C/M 係数と組み合わせて判断する
