# Bubble Factor の数値例

`scripts/icm_calc.py --bubble-factor` で計算した、典型シナリオの bubble factor。

## Bubble factor の定義

\[
\text{Bubble Factor} = \frac{|\Delta\$EV \text{（チップを失う場合）}|}{|\Delta\$EV \text{（同量のチップを得る場合）}|}
\]

オールイン勝負を想定: hero が villain と当たり、min(hero stack, villain stack) を勝ち負けする。

- Bubble Factor = 1.0 → ICM の影響なし、Chip EV と $EV が等価
- Bubble Factor > 1.0 → 失う $価値 > 得る $価値、コール頻度を下げるべき
- Bubble Factor < 1.0 → 得る価値が大きい、より積極的に（実戦では稀）

## シナリオ1: 9-max STT バブル（4-handed、Top 3 払い）

賞金 50/30/20、4 人残り、1 人脱落でバブルブレイク。

スタック: P1=4500, P2=3000, P3=1500, P4=1000（合計 10000）

### Bubble factor 行列

横軸 = Villain（hero がオールイン勝負する相手）、縦軸 = Hero。

| Hero \ Villain | P1 | P2 | P3 | P4 |
| :--- | ---: | ---: | ---: | ---: |
| **P1** (45%) | — | 1.53 | 1.17 | 1.11 |
| **P2** (30%) | 2.90 | — | 1.29 | 1.16 |
| **P3** (15%) | 2.25 | 2.04 | — | 1.19 |
| **P4** (10%) | 1.73 | 1.60 | 1.25 | — |

### 観察

- **最大 BF = 2.90**（P2 が P1 にオールインで勝負）。中スタック (P2) がリーダー (P1) と勝負する場合、失う $EV が得る $EV の約 3 倍。**極めて守備的に回るべき**。
- **最小 BF = 1.11**（P1 が P4 にオールイン）。リーダーがショート (P4) と勝負する場合、ICM ペナルティはほぼなし（バブルプレイヤーを脱落させれば一気に賞金圏 lock-in）。
- 中スタック同士（P2 vs P3）の BF も 1.29〜2.04 と高め。
- 一般則: **大きなスタックを巻き込む勝負ほど BF が上がる**（失うチップ量が大きくなるため）。

### 戦術的含意

P3 (1500 chip、15% chip) が P1 (4500 chip、リーダー) のオールインに直面したとき:

- BF = 2.25
- 必要 equity: BF / (BF + 1) = 2.25 / 3.25 = **69%**
- Chip EV だけなら 50% で良いが、ICM では 69% 必要

これは **JJ 以下、AQ 以下では call できない**水準（vs 任意レンジの場合）。

## シナリオ2: MTT バブル（10-handed、Top 6 払い）

賞金 40/25/15/10/6/4、10 人残り、4 人脱落でバブルブレイク。

スタック: 3000/2500/2000/1500/1000/800/600/400/200/100（合計 11200）

```bash
python scripts/icm_calc.py --preset bubble-mtt-tight --bubble-factor 4
```

P5 (1000 chip = 8.9% chip、ちょうど真ん中) の bubble factor:

| Villain | V Stack | Bubble Factor |
| :--- | ---: | ---: |
| P1 (chip leader) | 3000 | 1.63 |
| P2 | 2500 | 1.61 |
| P3 | 2000 | 1.57 |
| P4 | 1500 | 1.52 |
| P6 | 800 | 1.32 |
| P7 | 600 | 1.21 |
| P8 | 400 | 1.13 |
| P9 | 200 | 1.06 |
| P10 | 100 | 1.03 |

### 観察

- MTT バブル（Top 6/10 = 60% 入賞）は STT バブル（Top 3/4 = 75% 入賞）ほど極端な BF を生まない。
- 大スタック相手の BF は 1.5〜1.6 程度 → 必要 equity は 60〜62%
- 自分より小さいスタック相手は BF 1.03〜1.32 と相対的に低い
- 一般則は **「自分より大きなスタックを避け、小さなスタックを狙う」** で変わらないが、MTT バブルの度合いは STT より穏やか
- 小スタック相手でも BF > 1.0 で完全な「攻撃機会」にはならない

## シナリオ3: ITM 後（FT 3-handed）

賞金 50/30/20、3 人残り、全員 ITM 確定。

スタック: 4000/3000/3000

```bash
python scripts/icm_calc.py --stacks "4000,3000,3000" --payouts "50,30,20" --bubble-factor 0
```

| Hero \ Villain | P1 | P2 | P3 |
| :--- | ---: | ---: | ---: |
| P1 (40%) | — | 1.23 | 1.23 |
| P2 (30%) | 1.37 | — | 1.27 |
| P3 (30%) | 1.37 | 1.27 | — |

ITM 後でも BF は 1.0 ではない（賞金構造が依然非線形）。リーダー P1 でも BF=1.23 → 必要 equity 55%、コール頻度を約 10% タイトに。

## シナリオ4: ヘッズアップ（HU、50/30）

賞金 50/30。チップ合計 10000、どのスタック分布でも HU では BF = 1.000。

| シナリオ | BF (hero) |
| :--- | ---: |
| 5000/5000 (50/50) | 1.000 |
| 7000/3000 (70/30) | 1.000 |
| 9000/1000 (90/10) | 1.000 |

**理由**: HU は賞金が「勝ち $50 / 負け $30」で固定。1 チップあたりの $価値は ($50 − $30) / 全チップ = 一定。ICM が線形関数になるため bubble factor = 1。

**含意**: HU では Chip EV だけで戦略を立てる（ICM 補正 = 0）。ICM 思考は不要。

## シナリオ5: ファイナルテーブル序盤（9 人 FT）

賞金 9-place 30/20/13/10/8/6/5/4/4、9 人 FT 開始時、全員 10000 chip。

```bash
python scripts/icm_calc.py \
  --stacks "10000,10000,10000,10000,10000,10000,10000,10000,10000" \
  --payouts "30,20,13,10,8,6,5,4,4" \
  --bubble-factor 0
```

各プレイヤーの BF（vs 等スタック相手）: **1.488**

### 含意

- FT 9-max 開始時点で BF ≈ 1.5 → コール頻度を約 33% タイトに（`call equity ≥ BF/(BF+1) = 60%`）
- これは中盤の同状況より厳しい（賞金構造の傾斜が大きいため）
- バブル直前（STT n=4、BF 2.0+）よりは緩い

## ステージ別 BF まとめ

| ステージ | 代表 BF | 必要 equity (vs ATC) | 戦術指針 |
| :--- | ---: | ---: | :--- |
| 序盤（深いスタック、ITM まで遠い） | 1.00 | 50% | Chip EV ベースで OK |
| 中盤（M=10〜20、ITM まで近い） | 1.30〜1.50 | 56〜60% | やや守備的に |
| バブル直前（n=4 STT / 数% MTT） | 2.0〜3.0 | 67〜75% | 大スタック避ける、ショートを狙う |
| ITM 直後（短期反動） | 1.20〜1.50 | 55〜60% | 通常の中盤と同等 |
| FT 9-max 序盤 | 1.40〜1.60 | 58〜62% | 慎重 |
| FT 3-handed | 1.10〜1.45 | 52〜59% | 構造による |
| HU | 1.00 | 50% | Chip EV ベース |

これは本書 第3部・第4部の戦術指針の数値根拠です。

## BF の動学

ハンドが進むにつれて BF はどう変化するか。

### バブルブレイク前後

```
バブル直前 (n=4): BF ≈ 2.5（最大）
↓ 1 人脱落
ITM 直後 (n=3): BF ≈ 1.3（急降下）
```

**含意**: バブルブレイクは「BF が一気に下がる」ステージ変化点。これを意識して、バブル直前は最大限保守、ITM 直後は再び積極的に。

### FT 進行

```
FT 9 人スタート: BF ≈ 1.50
↓ 数人脱落
FT 5 人: BF ≈ 1.40
↓
FT 3-handed: BF ≈ 1.20
↓
HU: BF = 1.00
```

人数が減るにつれて BF が低下。HU で完全に消える。
