## 計算式の中核 — プリフロップスコア (2026-05-09 採用)

**詳細仕様: `preflop/PREFLOP_SCORE_SPEC.md`**

旧 Score / Score₃ を廃止し、**1 つの式 + 1 つの閾値表** で全プリフロップ判断を扱う。
RFI / 対RFI / 3-bet / Call / 4-bet / 5-bet / Squeeze / BB defense — すべて統合。

### プリフロップスコア（唯一の式）

```
Score = H + L
      + ペアボーナス     +10  （ペアのみ）
      + スーテッドボーナス  +3
      + コネクター差1    +1   / 差2-3 +0.5
      + ブロッカー: A=+3 / K=+2 / AK 両方=+4
      − ペナルティ: 差4以上−1 (A 含むと免除) / 両カード 9 未満 −1
```

### 閾値表（v3 2026-05-19、GTO Wizard 3betV2 検証済）

| シーン | 閾値 |
|---|---|
| RFI (open) | UTG=24 / HJ=22 / CO=20 / BTN=18 / SB=18※ |
| 対 RFI 3-bet (BTN は二段) | vs UTG: T_3bet=32, T_call=29 / vs HJ: 28/26 / vs CO: 25 |
| 対 RFI 3-bet (HJ/CO は単一) | vs UTG: 29 / vs HJ: 29 |
| 対 RFI 3-bet (SB は単一) | vs UTG: 29 / vs HJ: 29 / vs CO: 28 / vs BTN: 24 |
| BB defense (二段、Score_BB 使用) | vs UTG: 33/25, HJ: 32/24, CO: 32/24, BTN: 28/22, SB: 30/19 |
| 4-bet (vs 3-bet) | T_4bet=33 (全ポジ共通) |
| 5-bet (vs 4-bet) | T_5bet=39 (全ポジ共通) |
| Squeeze | T_3bet (vs オープナー) + 3 × コール数 |

※ SB T_open=18 はレイズ or フォールドモデルの最適値。Score 14〜17 はリンプ検討。

### 廃止された概念
- Score₃ (= H + 0.5L + ブロッカー...): プリフロップスコアに吸収
- 「3betスコア」「Score₃」: プリフロップスコア一本
- 0.5L 重み: H と L を等価に扱う

### 検証精度 (knowledges/preflop/gto-charts.json)
- RFI: 89.5% / 対RFI 3-bet (CO/HJ/SB): 95.5% / BB defense (5 シナリオ): 83.4% / 4-bet: 100% / 全体: 89.1%

### 補助ルール (約 7-8% の境界ケースを補完)
- 小ペア set mining: コール額 × 15 ≤ 相手スタック → CALL
- SC 暗黙オッズ: IP かつ深スタックなら別判断
- 3-bet ブラフコンボ: A2s-A5s, K9s, QJs 等は上級者向け混合戦略
- BB defense wide call: BB は IP オープン vs suited 系を T_call−3 まで広く CALL

### ポットオッズ・セットマイニング (補助式、維持)

```
必要勝率 ≈ コール額 ÷ 最終ポット
実効勝率 ≈ 生勝率 × 実現率（〜0.6 OOP時）
セットマイニング: コール額 × 15 ≤ 相手スタック
```
