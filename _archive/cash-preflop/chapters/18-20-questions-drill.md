# 第18章　20問ドリル：5秒で判断する

<!-- markdownlint-disable MD036 -->
<!-- textlint-disable preset-ja-technical-writing/no-mix-dearu-desumasu -->

> **本章の目標**: 本書で学んだ各種公式・しきい値を「5秒で回せる」状態まで身体化します。20問のドリルを通じて、計算 → 比較 → アクションの型を完全に定着させます。

ここまでの17章で、本書の主要な公式と判断基準はすべて出揃いました。残る課題はただ1つ、「**それを実戦で瞬時に回せるか**」です。

本章では、実戦で出会う典型シチュエーションを20問のドリルにしました。各問題は次のフォーマットで構成されています。

1. **シチュエーション**：手札、ポジション、相手のアクション
2. **あなたの選択肢**（3〜4択）
3. **解答**と、**使用した公式**

難易度は ★（基本）、★★（応用）、★★★（判断に迷う境界）の3段階です。まず自分で解き、その後で解説を読んでください。

## 使用する主な公式のおさらい

```text
プリフロップスコア（Score_R）（RFI / 3-bet / 4-bet / 5-bet / Squeeze 共通）:
  ペア:    2R + (2 if R≥10 else 0)
           例: AA=30, KK=28, JJ=24, TT=22, 99=18
  非ペア: H + L
           + スーテッド +4
           + コネクター: 差1=+3 / 差2=+2 / 差3=+1 / 差4以上=0
           + ブロッカー: AK=+3 / A（Kなし）=+2 / K（Aなし）=+1
           ペナルティなし

T_open (RFI): UTG=24, HJ=22, CO=20, BTN=18, SB=22

対 RFI 二段閾値 (T_3bet / T_call):
  BTN vs UTG: 30 / 22    BTN vs HJ: 28 / 20    BTN vs CO: 22 (単一)
  HJ vs UTG: 28 (単一)   CO vs UTG: 26 (単一)   CO vs HJ: 24 (単一)
  SB: vs UTG=28 / vs HJ=26 / vs CO=24 / vs BTN=20 (すべて単一)

4-bet: AA/KK/QQ/AKs のみ（単一閾値なし）
5-bet: AA のみ（オールイン）

BB defense (6ステップフロー / Score_C は suited+6/差1=+4/差2=+2/差3+=0):
  ①SR≥T_3bet→バリュー3bet ②Axs→ブラフ3bet ③ペア→コール
  ④SC≥T_call_s→コール ⑤SR≥T_call_o→コール ⑥フォールド
  vs UTG: 30/19/28    vs HJ: 28/17/26    vs CO: 26/15/24
  vs BTN: 24/13/22    vs SB: 22/11/20

ポットオッズ: 必要勝率 = コール額 ÷ 最終ポット
  2bb → 22%, 2.5bb → 27%, 3bb → 31%, 4bb → 35%
実現率: 実効勝率 = 生エクイティ × 実現率 (OOP ≈ 0.6〜0.8, IP ≈ 1.0)
セットマイニング: コール額 × 15 ≤ 相手スタック (IP)、× 25 (OOP)
```

## Q1（★）：UTG で AQs

あなたはUTGに座っています。手札はA♠ Q♠。どうしますか。

1. オープン
2. フォールド

**解答：1（オープン）**

計算：14 + 12 + 4 (s) + 2 (差2) + 2 (Aブロッカー) = **34**。UTG しきい値 24 を余裕で超えるのでオープン。

**使用した公式**：プリフロップスコア + T_open(UTG)=24。

---

## Q2（★）：UTG で 66

あなたはUTG。手札は6♦ 6♣。どうしますか。

1. オープン
2. フォールド

**解答：2（フォールド）**

計算：2 × 6 = **12**。T_open(UTG)=24 を大幅に下回る。Score_R では 66=12 はどのポジションの T_open（最低 BTN=18）も下回るため、RFI には使えない。誰かがオープンした後のセットマイニング専用ハンド。

**使用した公式**：プリフロップスコア（ペア計算）+ T_open。

---

## Q3（★）：BTN で 72o

あなたはBTN。全員フォールドで回ってきた。手札は7♦ 2♣。どうしますか。

1. オープン
2. フォールド

**解答：2（フォールド）**

計算：7 + 2 + 0 (差5、コネクターボーナスなし) = **9**。T_open(BTN)=18 を大幅に下回る。

**使用した公式**：プリフロップスコア + T_open(BTN)=18。

---

## Q4（★★）：BTN で K7s

あなたはBTN。全員フォールドで回ってきた。手札はK♠ 7♠。どうしますか。

1. オープン
2. フォールド

**解答：1（オープン）**

計算：13 + 7 + 4 (s) + 0 (差6、コネクターボーナスなし) + 1 (Kブロッカー) = **25**。T_open(BTN)=18 を超える。

**使用した公式**：プリフロップスコア + ブロッカー。

---

## Q5（★★）：HJ で AJo

HJ にあなた。UTG フォールド。手札はA♦ J♣。どうしますか。

1. オープン
2. フォールド

**解答：1（オープン）**

計算：14 + 11 + 1 (差3) + 2 (Aブロッカー) = **28**。T_open(HJ)=22 を超える。UTG (T_open=24) もクリアするので、実は UTG からでも開ける境界ハンド。

**使用した公式**：プリフロップスコア + コネクター + ブロッカー。

## Q6（★★）：BTN オープン 2.5bb、BB で 88

BTNが2.5bbオープン。SBフォールド。あなたはBBで8♥ 8♣。どうしますか。

1. フォールド
2. コール
3. 3ベット

**解答：2（コール）**

BB defense は **6ステップフロー** で判断します。88 の Score_R = 2 × 8 = **16**。BB vs BTN の各閾値：T_3bet=24 / T_call_s=13 / T_call_o=22。

- Step①: SR=16 < T_3bet=24 → 3-bet 不実行
- Step②: 88 は Axs ではない → スキップ
- Step③: **ペア → CALL**（セットマイニング）

深スタックなら 100bb ÷ 2.5bb = 40 倍のセットマイニング条件を余裕で満たします。

**使用した公式**：BB defense フロー第15章、Step③ ペア→コール）

## Q7（★）：BTN オープン 2.5bb、BB で 72o

BTNが2.5bbオープン。SBフォールド。あなたはBBで7♥ 2♣。

手札の生エクイティは約30%、ポットオッズは27%。どうしますか。

1. ポットオッズを満たすのでコール
2. フォールド

**解答：2（フォールド）**

実効勝率 = 30% × 0.6（OOP）= **18%**。ポットオッズ27% を下回るので赤字。

**使用した公式**：ポットオッズ + 実現率。

---

## Q8（★★★）：UTG オープン 2.5bb、BB で 22

UTGが2.5bbオープン。SBフォールド。あなたはBBで2♠ 2♦。相手の有効スタックは100bb。どうしますか。

1. フォールド
2. コール（セットマイニング）
3. 3ベット

**解答：2（コール）**

セットマイニング判定：コール額1.5bb（差額）、25倍ルール（OOPなので）→ 1.5 × 25 = **37.5bb**。相手スタック100bbはこれを満たすのでコール成立。

ただし、BBはOOPで実現率が低いので、15倍ルールではなく25倍ルールで判断するのが安全。

**使用した公式**：セットマイニング25倍ルール。

## Q9（★★）：CO オープン 2.5bb、BTN で A5s

COが2.5bbオープン。あなたはBTNでA♠ 5♠。どうしますか。

1. フォールド
2. コール
3. 3ベット

**解答：3（3ベット）**

プリフロップスコア：14 + 5 + 4 (s) + 0 (差9、コネクターボーナスなし) + 2 (Aブロッカー) = **25**。BTN vs CO の T_3bet=22 (単一) を超えるので 3-bet。A ブロッカーが効き、ブラフ 3-bet として機能。

**使用した公式**：プリフロップスコア（ブロッカー付きブラフ）

## Q10（★★★）：UTG オープン 2.5bb、CO で JJ

UTGが2.5bbオープン。HJフォールド。あなたはCOでJ♠ J♣。どうしますか。

1. フォールド
2. コール
3. 3ベット

**解答：1（フォールド）**

JJ の Score_R = 2 × 11 + 2 = **24**。CO vs UTG の T_3bet=26 (単一) を下回るため、**フォールド**。

GTOでも UTG の強いオープンレンジに対して CO から JJ を 3ベットするのはリスクが高い（4ベットを返されるとフォールド一択）。QQ (Score_R=26) 以上が CO vs UTG 3ベットの境界。コールで見るハンドにも入らない（CO は IP だがコールドコールは推奨しない）。

**使用した公式**：プリフロップスコア + T_3bet (CO vs UTG)=26

## Q11（★★★）：BTN オープン 2.5bb、SB で A9o

BTNが2.5bbオープン。あなたはSBでA♦ 9♣。どうしますか。

1. フォールド
2. コール
3. 3ベット

**解答：3（3ベット）**

SBでは基本「3-bet かフォールド」。A9o の Score_R = 14 + 9 + 0 (差5、コネクターボーナスなし) + 2 (Aブロッカー) = **25**。SB vs BTN の T_3bet=20 (単一) を超えるのでブラフ 3-bet 候補。

コールは「キャップされたレンジ」問題があるため原則避ける（第15章参照）。

**使用した公式**：プリフロップスコア + SB の特殊性。

## Q12（★）：BTN で AKo

あなたはBTN。全員フォールドで回ってきた。手札はA♥ K♦。

1. フォールド
2. オープン（2.5bb）
3. オープン（5bb）

**解答：2（2.5bb オープン）**

AKo の Score_R = 14 + 13 + 3 (差1) + 3 (AKブロッカー) = **33**。T_open(BTN)=18 を余裕で超える。ただし BTN は 2.5bb 固定が基本で、プレミアムハンドでもサイズを変えない（ワンペアの見せ方で情報を渡さない）。

**使用した公式**：プリフロップスコア、オープンサイズ固定。

## Q13（★★）：HJ オープン 2.5bb、BTN で 65s

HJが2.5bbオープン。COフォールド。あなたはBTNで6♠ 5♠。

1. フォールド
2. コール
3. 3ベット

**解答：2（コール）**

65s の Score_R = 6 + 5 + 4 (s) + 3 (差1) = **18**。BTN vs HJ の T_3bet=28 / T_call=20 のどちらにも届かないため、本式判定は **フォールド**。

ただし 65s は SC として暗黙オッズが大きく、IP かつ深スタックの BTN なら**補助ルール (SC 暗黙オッズ)** でコール候補に格上げ。フロップのナッツポテンシャル（ストレート・フラッシュ・SD）を生かす。

**使用した公式**：プリフロップスコア + 補助ルール (SC 暗黙オッズ)。

## Q14（★★）：UTG オープン 3bb、CO で AKs

UTGが3bbオープン。HJフォールド。あなたはCOでA♠ K♠。

1. フォールド
2. コール
3. 3ベット

**解答：3（3ベット）**

AKs の Score_R = 14 + 13 + 4 (s) + 3 (差1) + 3 (AKブロッカー) = **37**。CO vs UTG の T_3bet=26 (単一) を余裕で超える。バリュー 3-bet の代表格。

**使用した公式**：プリフロップスコア + AK のダブルブロッカー。

## Q15（★★★）：BTN オープン 2.5bb、BB で KQo

BTNが2.5bbオープン。SBフォールド。あなたはBBでK♦ Q♣。

1. フォールド
2. コール
3. 3ベット

**解答：2 または 3（どちらも可）**

KQo の Score_R = 13 + 12 + 3 (差1) + 1 (Kブロッカー) = **29**。BB vs BTN の **6ステップフロー** で判断します。

- Step①: SR=29 ≥ T_3bet=24 → **バリュー3ベット**

Step① でバリュー 3-bet に振り分けられます。GTO 的にも KQo を BB vs BTN で 3-bet するのは標準。ただしドミネーションリスク（AK、AQ に負ける）を意識して保守的にコールするのも選択肢。本書のフローはまず 3-bet 推奨。

**使用した公式**：BB defense フロー（第15章、Step① SR≥T_3bet=24）。

**解答：2（コール）**

## Q17（★★）：CO オープン 2.5bb、BTN で QJs

COが2.5bbオープン。あなたはBTNでQ♠ J♠。

1. フォールド
2. コール
3. 3ベット

**解答：2 または 3（どちらも可）**

QJs の Score_R = 12 + 11 + 4 (s) + 3 (差1) = **30**。BTN vs CO の T_3bet=22 (単一) を超えるので 3-bet 候補。

ただし QJs は IP でプレイアビリティが高いので、コールでフロップを見るのも GTO 整合的（一部混合戦略）。初心者は 3-bet 主体、慣れてきたら混合運用。

**使用した公式**：プリフロップスコア + プレイアビリティ。

## Q18（★★）：CO オープン 2.5bb、BTN で T9s

COが2.5bbオープン。あなたはBTNでT♠ 9♠。

1. フォールド
2. コール
3. 3ベット

**解答：2 または 3（コールまたは3ベット）**

T9s の Score_R = 10 + 9 + 4 (s) + 3 (差1) = **26**。BTN vs CO の T_3bet=22 (単一) を超えるため、純粋に 3ベット候補。IP かつ強いプレイアビリティなのでコールも GTO 整合。補助ルールではなく正規の判断範囲。

**使用した公式**：プリフロップスコア + T_3bet(BTN vs CO)=22。

## Q19（★★★）：BTN オープン 3bb、BB で 99

BTNが3bbオープン。SBフォールド。あなたはBBで9♠ 9♣。

1. フォールド
2. コール
3. 3ベット

**解答：2（コール）**

99 の Score_R = 2 × 9 = **18**。BB vs BTN の **6ステップフロー** で判断します。各閾値：T_3bet=24 / T_call_s=13 / T_call_o=22。

- Step①: SR=18 < T_3bet=24 → スキップ
- Step②: 99 は Axs ではない → スキップ
- Step③: **ペア → コール**（セットマイニング）

Step③ でコールに振り分けられます。GTO でも 99 は BB vs BTN でコール寄りが主流。セットヒット率約 11% × 深スタック倍率で利益が出る構造。

**使用した公式**：BB defense フロー（第15章、Step③ ペア→コール）

## Q20（★★★）：あなたの最終テスト

以下のシチュエーションで、あなたのアクションとその根拠を自分で説明してください。

**状況**：HJが2.5bbオープン、COが8bb 3ベット。フォールド、フォールドで回ってきて、あなたはBTNでA♦ K♠。有効スタック100bb。

**選択肢**：フォールド、コール、4ベット（18bb）

---

**解答例**：**コール（OR フォールド）**

根拠：

- AKo の Score_R = 14 + 13 + 3 (差1) + 3 (AKブロッカー) = **33**
- 4-bet リスト（AA/KK/QQ/AKs）を参照すると、AKo は 4-bet リスト外。本式判定は **3-bet を受けてコール**（または OOP ならフォールド）
- BTN は IP なのでコールでフロップを見る選択が安全
- もし 4-bet するなら「ブロッカーブラフ as value」の混合戦略 (上級者向け)。本書の決定論ルールでは AKo は 4-bet レンジ外
- AKs (Score_R=37) は 4-bet リスト入りで cold-4-bet 候補

**使用した公式**：プリフロップスコア + 4-bet リスト（AA/KK/QQ/AKs）+ ブロッカー理論（第16章）

## ドリル総合結果の自己採点

- **20問中17問以上正解**：本書の式は完全に身体化できています。第19章のチートシートで実戦運用に移ってください
- **12〜16問正解**：まだ迷う場面があります。間違えた問題の章を再読し、式の運用を反復してください
- **11問以下**：第5〜12章の基本に戻って復習が必要です。焦らず順に回してください
