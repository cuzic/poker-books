# 第6章　Very Short（SBR<10）——フロップ＝コミットorフォールドの一択

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: SBR<10のフロップで「コミットか、チェック・フォールドか」の二択を即断できるようになる。中間的なコールやマージナルなブラフが最大の損失源であることを理解する。

---

vol3では、SBR<10を「プッシュ/フォールドゾーン」と定義しました。プリフロップ段階でスタックを全投入するか降りるか、二択で判断する領域です。ではそのSBRでフロップに到達してしまった場合、何が起きているのでしょうか。

本章では、SBR<10でのポストフロップ判断を扱います。一言で言えば、フロップでもプリフロップとほぼ同じ「コミットorフォールド」の思考が必要です。

---

## 6-1　SBR<10でフロップに到達するとき

SBR<10、つまり実効スタックが約20BB以下でフロップに到達するパターンは主に2種類あります。

**パターン1：もともとSBRが低い**

中盤以降にブラインドが上がり、自分のスタックが相対的に目減りして気づけばSBR=8〜9になっているケースです。プリフロップでコールやリンプでポットを作ると、フロップ時点の残りスタックはポットと同程度か、それ以下になります。

**パターン2：3BPや大きなオープンの後**

SBR=15〜20でも、相手が大きめにレイズし、自分が3betまたはコールをするとフロップポットが膨らみます。SBR=15の3BPでSPR≈1.4（第1章参照）というケースもこの分類に含まれます。形式上のSBRは10以上でも、フロップ着地時にはSPR<2のコミット圏に入ることがあります。

### SPRから確認する

第1章の変換表を使うと、SBR=10のSRPでSPR≈3、SBR=7でSPR≈1.5です。本章のテーマである「SPR<2」はSBR=7〜10に相当します。この領域ではフロップポットが実効スタックの半分以上を占めており、標準サイズのベットが事実上オールインを意味します。

```
SBR=8（実効スタック16BB）、SRPのフロップポット≈6BB
SPR = 16 ÷ 6 ≈ 2.7

フロップで50%ポットベット（=3BB）をするとき:
  残りスタック = 16 − 3 = 13BB
  次のアクション（レイズ/コール）でほぼ全投入
→ ベット自体がコミットトリガーになる
```

このようにSPR≈2〜3の領域では、フロップでのベットとチェックの選択が「全スタックを投入するか・しないか」の分岐点になります。チェックした後に相手がベットしてくれば、コールは実質オールインです。

---

## 6-2　フロップでオールインする基準

SBR<10の判断は単純です。「コミットできる強さがあるか」だけを問います。

### コミット閾値

| 状況 | コミット最低HS | 手の例 |
|------|--------------|------|
| SBR<10、通常ステージ | HS≥50（TP以上） | トップペア + どのキッカーでも |
| SBR<10、ナッツドロー | コミット | ナッツFD+ペア、OESD+ペア |
| SBR<10、マージナル以下 | チェック・フォールド | セカンドペア以下、単独ドロー |

**TP（トップペア）以上ならコミット**が基本方針です。

vol2で学んだHandScoreでは、「TP弱キッカー（例: K♥5♦ on K-7-2）」がHS≈52でマージナルバケットに入ります。SPR≥4のゾーン（第5章）では「TP以上でコミット（HS≥50）」が基準でしたが、SPR<2ではキッカーを問わずTPがあればコミットに切り替えます。

### 強ドローのコミット

ナッツフラッシュドロー（NFD）にペアが加わった場合、フロップエクイティは60〜70%に達します。OESDにペアが加わっても50%前後です。これらは「ショーダウンの期待値」で見れば完成ハンドと同格なので、コミットを正当化できます。

一方、**単独ドロー（NFD単体やOESD単体）はコミット非推奨**です。エクイティは35〜40%あっても、コミット後に負ける確率が6割を超えます。SPR<2の小さなポットで6割負けを繰り返すのはチップ的に耐えられません。

### チェック・フォールドで割り切る

HS≤42（セカンドペア以下、単独ドロー）は基本的にチェック・フォールドです。

この判断に違和感を覚える方も多いでしょう。「セカンドペアでもコールできないか」「ドローがあるのにタダで諦めるのか」という気持ちは自然です。しかし、SBR<10の世界では「コミット=スタック全投入」と「チェック・フォールド=スタック温存」の選択しかありません。中間の「弱いコール」は、こうした場面では最も損失が大きいアクションです。

---

## 6-3　セットマイニングの変化：implied oddsが薄い

ポケットペアでフロップにセット（スリーカード）を狙う「セットマイニング」は、implied odds（将来取れる期待利益）が前提です。vol2では「コール額×10≤スタック」を基準として紹介しました。

SBR<10ではこの基準を満たせないことがほとんどです。

```
例: スタック18BB、相手のオープンが2BB → コール額 = 2BB
  implied odds基準: 2 × 10 = 20BB ≤ スタック（18BB）？
  → 18 < 20 → 満たさない → セットマイニング非推奨
```

さらに、implied oddsを実現するためには「セットが完成したときに相手が大きくコールしてくれる」必要があります。相手のスタックも浅ければ、セット完成時に取れるチップは数BBにすぎません。SBR<10では、セットマイニングの収益性は著しく低下します。

### 実際の計算で確認

スタック16BB、コール2BBでセットを狙うとします。

```
セット完成率: フロップで1/8.5 ≈ 12%
コール額: 2BB
break-even の必要期待取得額: 2 ÷ 0.12 ≈ 16.7BB
残りスタック（コール後）: 14BB

→ 14BB < 16.7BB → implied oddsが足りない
```

セットが完成しても、残り14BBしかないため期待取得額の16.7BBには届きません。フォールドが正解です。vol3で学んだプッシュ/フォールドゾーンの発想を、コール判断にも適用してください。

## 6-4　ICM補正：バブル直前はTPでも降りが正解になる場合がある

これまでの判断はすべて「通常ステージ（ICM補正ほぼなし）」を前提としています。バブル直前や深いファイナルテーブル（FT）では、ICM補正によってコミット閾値がさらに引き上がります。

第2章で確認したように、バブルのICM補正は+10〜15%です。これをコミット閾値のHS換算に直すと、おおよそ+10HSの上昇になります。

| ステージ | 通常コミットHS | ICM補正 | バブルコミットHS |
|--------|------------|--------|--------------|
| 通常（中盤まで） | HS≥50（TP） | なし | HS≥50 |
| バブル | HS≥50 | +10HS | HS≥60（TPMK以上） |

つまりバブルのSBR=8では、TPがあっても「強キッカーが伴わなければフォールド」が正解になります。

### ビッグスタックは別の論理で動く

自分がビッグスタックであれば、ICM補正は低くなります（自分は消えにくいため）。むしろ相手のICM恐怖を利用して、より積極的に圧力をかける場面が増えます。詳しくは第8章（バブル）で扱いますが、本章の「SBR<10コミット閾値」はショートスタック〜ミドルスタック視点での話です。

### 「降りすぎ」の罠にも注意する

バブルで過度にICMを意識すると、「チップEV的に大幅プラスなのにフォールドしてしまう」パターンが生まれます。コミット閾値は上がりますが、HS≥60以上の強いTPならバブルでもコミットが正当化されます。

「降りすぎる」罠については第8章で詳述します。本章では「バブルではコミット閾値がTP弱より1段上に上がる」だけを押さえてください。

## 6-5　実戦例：SBR=8（ほぼpush/fold境界）

BTN がオープン2BBし、BBがコールしてSRPになりました。両者のSBRはおよそ8（スタック16BB）です。

**フロップ: J♦7♠5♣（型3 ロードライ）**

```
フロップポット ≈ 6BB
残りスタック ≈ 10BB
SPR = 10 ÷ 6 ≈ 1.7

→ SPR<2の確定コミット圏
```

### ケース1: BB手がJ♠8♦（TP弱キッカー）

J♦7♠5♣でJ♠8♦を持つBBはトップペアです。キッカーは8で弱いですが、HS≈52でTP以上を満たします。

**判断: コミット（HS≥50を満たす）**

残り10BBを全力でプッシュします。SPR=1.7の世界では「TP弱キッカーでも降り」は損です。相手のレンジにはJ以下のペア、AハイQ/Kハイのオーバーカード、ドロー系が多く含まれており、トップペアはレンジ全体に対して高いエクイティを持ちます。

### ケース2: BB手がT♠9♠（OESD）

T♠9♠はJ♦7♠5♣でOESDを形成します（8か6でストレート完成、8アウツ）。ただしペアはありません。HS = 役スコア0 + DrawBonus（OESD）32 = 32です。

**判断: チェック・フォールド（単独OESDはコミット圏外）**

T♠9♠にはスペードのバックドアフラッシュドロー（BDFD）もありますが、それを加えても「エアー」のバケット（HS≤34）に収まります。コミット基準のHS≥50には届きません。

相手がベットしてきたらフォールドします。コールはここでは最悪の選択です。残りの10BBを弱ドローのコールで使うのではなく、次のハンドに温存します。

なお、ペアが加われば話が変わります。例えばJ♠9♠（Jヒット + BDFD）なら役スコアにTPが加わりHS≈50前後になり、コミット検討の範囲に入ります。

### ケース3: BB手がA♥4♥（エアー）

A♥4♥はJ♦7♠5♣に対して何も当たっていません。Aハイとバックドアフラッシュドロー（BDFDハート）のみです。HS≈5〜10のエアーです。

**判断: チェック・フォールド（即決）**

SPR<2でのエアーは最も単純な場面です。プロであってもブラフの価値はほぼありません。相手レンジが広いとはいえ、スタックが浅いと折り取り（相手をフォールドさせるブラフ）の成功率が上がらず、失敗したときの損失がスタック全体になります。チェックして相手がベットすれば静かにフォールドします。

## ミニクイズ

### 問1

SBR=9（スタック18BB）のSRP、フロップポット約6BBです。フロップでJ♣が落ちてJ♦8♣を持つあなたはトップペアTP弱キッカー（HS≈52）です。通常ステージ（中盤、ICM補正ほぼなし）の場合、正しい判断はどれですか？

1. チェックして相手がベットしたらフォールド
2. チェックして相手がベットしたらコール（スタックの半分以下）
3. 積極的にベット、相手がレイズしたらコミット（オールイン）
4. チェックして様子を見てからターンで判断

---

### 問2

SBR=7（スタック14BB）のSRP、フロップポット約6BB、SPR≈1.3です。あなたはポケット55を持ち、フロップ A♦K♠8♣が落ちてアンダーペアになりました（HS≈25）。相手がハーフポットベット（3BB）をしてきました。正しいアクションは？

1. コール（ドローが来るかもしれない）
2. レイズ（ブラフとして）
3. フォールド
4. オールイン（セットのふりをして）

---

### 問3

バブル直前、ICM補正+10%が推定されます。SBR=8のSRPでフロップにT♣を持ち、T♦8♠4♣でTPになりました（HS≈55、TP中キッカー）。相手がポットの70%ベット（約4BB）をしてきて、コールすれば実質コミット圏です。通常ステージとバブルで判断はどう変わりますか？

1. 通常もバブルもコミット（TP以上なので常にコミット）
2. 通常はコミット、バブルはフォールド検討（ICM補正でコミット閾値がHS≥60以上に上がる）
3. 通常もバブルもフォールド（TP中キッカーはSBR<10ではコミット不可）
4. 通常はフォールド、バブルはコミット（バブルで相手がよりタイトになるため）

---

### 解答

- **問1**: **3**（積極的にベット、レイズされたらコミット）
  - SPR≈18÷6=3（SBR=9のSRP）とやや深めですが、TP以上（HS≥50）のコミット基準を満たしています。積極的にベットしてバリューを得ます。レイズが入ったらスタックを全投入してください。チェックして様子を見るのは、浅いSPRでバリューを稼ぎ損ねる典型パターンです。

- **問2**: **3**（フォールド）
  - アンダーペア（HS≈25）はHS≥50のコミット基準を大幅に下回ります。コールしても残り8BB程度、次のベットでオールインを迫られます。コールはチップを無駄にする最悪の中間解です。静かにフォールドして次のハンドに備えましょう。

- **問3**: **2**（通常はコミット、バブルはフォールド検討）
  - 通常ステージではHS≥50でコミット基準を満たすため、TP中キッカー（HS≈55）はコミットです。バブルではICM補正+10%により閾値がHS≥60前後に上昇します。HS≈55は閾値を下回るため、相手のベットに対してフォールドが正解になります。ただし相手が弱いレンジだと読める場合は判断が変わることもあり、第8章でより詳しく扱います。

---

> **本章まとめ**
>
> - SBR<10のSRPはSPR≈1.5〜3で、フロップベットが事実上のオールインを意味する。
> - コミット基準はTP以上（HS≥50）。強ドロー（ナッツFD+ペア、OESD+ペア）もコミット。
> - 単独ドロー・セカンドペア以下はチェック・フォールドが基本。中間コールが最大の損失源。
> - セットマイニングは「コール額×10≤スタック」を満たさない場面が多く、非推奨。
> - バブルではICM補正+10%でコミット閾値がHS≥60前後に上昇する（TP弱でも降りが正解）。

---

**【まとめカード：SBR<10の判断フロー】**

```
SBR<10のフロップ判断（通常ステージ）

TP以上（HS≥50）？
  → YES → コミット（ベットまたはコール/レイズでオールイン）
  → NO  → ナッツFD+ペア / OESD+ペア？
             → YES → コミット
             → NO  → チェック・フォールド

バブル補正: コミット閾値をHS≥60以上に引き上げる
```

**【キャッシュとのズレ】**

vol2（キャッシュゲーム）では100BBスタックが前提のため、フロップでセカンドペアをコールしたり、ドロー単体でポットオッズコールをする判断が頻繁に登場しました。そこでは「中間解（ポットオッズコール）」が正しい選択になります。

SBR<10のMTTでその習慣を持ち込むと、スタックが少しずつ溶けていきます。HS=40の「マージナルなコール」を繰り返す人が最もチップを失うパターンです。

また、vol2で身につけた「ポットオッズが合えばコールする」という判断も注意が必要です。ポットオッズ計算自体は正しいですが、SBR<10でのコールは必ず「その後のアクションでスタックを全投入することになる」という前提を加えてください。コールのオッズが合っていても、オールインのオッズが合わなければフォールドが正解です。SBR<10の判断はポットオッズではなく、「コミットしてEVがプラスか」で測ります。
