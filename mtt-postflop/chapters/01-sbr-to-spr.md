# 第1章　フロップ時のSPRを計算する

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: SBR（スタック÷BB）からフロップのSPRを3ステップで瞬時に導き、コミットラインの入口を押さえる。

---

vol3で学んだSBR（Stack-to-Blind Ratio）は、プリフロップの判断軸でした。しかしフロップ以降の判断では、SBRをそのまま使うより**SPR（Stack-to-Pot Ratio）**に変換した方が扱いやすくなります。SPRはポットに対するスタック比率で、コミットライン（「ここまで行ったら全力」の境界）を直感的に把握できる指標です。

本章では、SBRからSPRへの3ステップ変換を習得し、MTTのフロップ判断に接続するための地図を作ります。

---

## 1-1　3ステップ変換：SBR → 実効スタック → SPR

SPRの計算は次の3ステップで完結します。

```
ステップ1: 実効スタック = min(自分のスタック, 相手のスタック) ÷ BB
ステップ2: フロップポット = ゲームタイプ別の概算値（後述）
ステップ3: SPR = 実効スタック ÷ フロップポット
```

**ステップ1：実効スタック**

実効スタックとは「2人のうち浅い方のスタック」です。例えば自分が30BBで相手が50BBなら、実質的に使えるスタックは30BBです。相手が先にオールインになるため、超過分の20BBはデッドマネーとなります。vol3で扱ったSBRはスタック全体（自分視点）の比率でしたが、SPRには必ず実効スタックを使います。

**ステップ2：フロップポット**

MTTではBBアンテが標準装備されています。SRP（シングルレイズポット）の場合、ポットはおよそ次のように積み上がります。

```
BTN オープン 2.5BB + BB コール 2.5BB + BBアンテ 1BB ≈ 6BB
```

わずかにポジション・オープンサイズ・BBアンテの大きさで変動しますが、**SRPのフロップポットは約5.5〜6.5BB**と覚えておけば実戦では十分です。本章では計算の簡便さから6BBを代表値として使います。

**ステップ3：SPR算出**

実効スタックをフロップポットで割ります。

```
例: SBR=20 の場合
  実効スタック = 20 × 2 = 40BB  （BB単位に換算）
  フロップポット ≈ 6BB
  SPR ≈ 40 ÷ 6 ≈ 6.7 → 約6〜7
```

「SBR=20 → SPR≈6」は頻繁に登場する組み合わせです。この感覚を先に身につけておきましょう。

---

## 1-2　SBR→SPR 変換早見表

手計算なしで使えるよう、主要SBRに対応するSPRをまとめました。

### SRP（1対1のシングルレイズポット）

| SBR | 実効スタック目安 | フロップポット | SRP の SPR |
|-----|------------|----------|-----------|
| 30+ | 60BB+ | 約6BB | ≥10 |
| 25 | 50BB | 約6BB | ≈8 |
| 20 | 40BB | 約6BB | ≈6〜7 |
| 15 | 30BB | 約6BB | ≈4.5〜5 |
| 10 | 20BB | 約6BB | ≈3 |
| 7 | 14BB | 約6BB | ≈1.5〜2 |

「SBR=25ならSPR≈8」「SBR=10ならSPR≈3」のように、代表値を3〜4点覚えるだけで8割の場面をカバーできます。

### 3BP（3ベットポット）のSPR

3BPではプリフロップに多くのチップが入るため、フロップポットが大きくSPRが低くなります。代表的なパターンを示します。

```
BTN オープン 2.5BB → BB 3bet 8BB → BTN コール
フロップポット ≈ 8×2 + BBアンテ1 ≈ 17BB（BTNの残スタックは92BB相当）
```

| SBR | 実効スタック目安 | 3BP フロップポット | 3BP の SPR |
|-----|------------|------------|----------|
| 30+ | 60BB+ | ≈17BB | ≈3〜4 |
| 25 | 50BB | ≈17BB | ≈2.7 |
| 20 | 40BB | ≈17BB | ≈2.0 |
| 15 | 30BB | ≈17BB | ≈1.4 |
| 10 | 20BB | ≈17BB | コミット圏（SPR≈1以下） |
| 7 | 14BB | — | プリフロップでオールイン圏 |

3BPではSBR=20でもSPR≈2と非常に浅くなります。vol2で「例外的」と扱った浅いSPRが、MTTの3BPでは毎回の普通です。

### マルチウェイポット

リンプが絡んでコーラーが複数いる場合、ポットはさらに膨らみます。

```
例: 4ウェイ（3人リンプ + BB チェック、BBアンテ1BB）
フロップポット ≈ 1×3人 + 1BB（アンテ） = 4〜5BB
実効スタック（最短スタック）が30BBなら SPR ≈ 6〜7
```

ただし参加人数が増えるほど「1人が出し抜けた強いハンドを持つ確率」が上がります。マルチウェイではSPRの数値だけでなく、コミットラインを1段引き上げる補正が必要です（詳しくは第11章で扱います）。

---

## 1-3　SPR別コミットライン概観

SPRが分かったら、次の問いに答えます。「どの強さのハンドからコミットするか？」

vol2では主にSPR≥8（キャッシュゲームの標準）を前提にしていました。MTTでは浅いSPRが日常となるため、コミットラインを下方向に拡張する必要があります。

### コミットラインの目安（通常ステージ・中盤まで）

| SPR | コミット最低HS | 代表ハンド |
|-----|------------|---------|
| ≥8 | HS≥65（TPTK） | A♠J♦ / K♠Q♦ on K-high ドライ |
| 5〜7 | HS≥55（TP+中キッカー） | K♠9♦ / Q♠J♦ on top pair |
| 3〜4 | HS≥42（セカンドペア強） | 中ポケットペア / TP+ドロー複合 |
| 2〜3 | HS≥30（TP弱〜中） | TP以上があればコミット圏を検討 |
| <2 | HS≥50（TP） | フロップに着地した時点で事実上コミット圏 |

**HSはvol2の計算式（R + DrawBonus）をそのまま使います。**

重要な感覚として、SPRが半分になるごとにコミットラインが約10〜15HS下がると覚えてください。「SPR≥8ならTPTK以上」「SPR≈4ならセカンドペア強以上」という2点だけ押さえれば、残りは補間できます。

### なぜSPRが浅いとコミットラインが下がるのか

SPRが高い（スタックが深い）ときは、コールしてもまだ多くのチップが残ります。相手のナッツ系ハンドに対して出し抜かれるリスクが大きいため、コミットには高い強度のハンドが必要です。

一方、SPR<2では残りスタックがポット以下です。この状況で「強いハンドが来るまで待つ」戦略は成立しません。スタックがポットの2倍以下なら、TPレベルでも積極的にコミットして正のEVを追求する方が、長期収支の期待値が上がります。

## 1-4　実例で確認する3ステップ変換

**実例1: SBR=20、BTN vs BB の SRP**

```
ステップ1: 実効スタック = 20 × 2 = 40BB
ステップ2: フロップポット ≈ 6BB（BTN 2.5BB open + BB call + BBアンテ）
ステップ3: SPR = 40 ÷ 6 ≈ 6.7

判断: SPR≈6〜7 → コミットラインはHS≥55（TP+中キッカー以上）
```

A♠J♦でJ♣8♦5♠に当たればHS≈66（TPTK）でコミット圏。K♠9♦でK♣7♦2♠に当たればHS≈60（TP中キッカー）でコミットを検討します。

**実例2: SBR=25、BB vs BTN の3BP**

```
ステップ1: 実効スタック = 25 × 2 = 50BB
ステップ2: 3BPフロップポット ≈ 17BB
ステップ3: SPR = 50 ÷ 17 ≈ 2.9

判断: SPR≈3 → コミットラインはHS≥30〜42（TP以上）
```

3BPでSBR=25のケースでは、TPがあればほぼコミット圏です。AKでA♠8♦3♦に当たればAハイTPTKでHS≈78、迷わずオールインを狙います。

**実例3: SBR=15、マルチウェイ（3ウェイ SRP）**

```
ステップ1: 実効スタック = 15 × 2 = 30BB（全員がおおむね同スタックと仮定）
ステップ2: フロップポット ≈ 7BB（3ウェイ、各2.5BB + アンテ1BB）
ステップ3: SPR = 30 ÷ 7 ≈ 4.3

マルチウェイ補正: コミットラインを1段引き上げ → HS≥55以上を目安に
```

SBR=15のマルチウェイでTPがあっても、強キッカーがなければコミットを慎重に判断します。

## ミニクイズ

### 問1

SBR=15、BTN vs BB の SRP（BBアンテあり）です。フロップのSPRはおよそいくつですか？

1. SPR≈2
2. SPR≈4〜5
3. SPR≈8
4. SPR≈12

---

### 問2

SBR=20、BTN vs BBの3BPです。BBが8BBで3betしてBTNがコールしました。フロップポットをおよそ17BBとしたとき、SPRはいくつですか？

1. SPR≈1
2. SPR≈2
3. SPR≈4〜5
4. SPR≈6〜7

---

### 問3

SBR=25、BTN open + CO call + BB call の3ウェイSRPです。全員のスタックが同程度（実効スタック≈50BB）で、フロップポットが7.5BBとします。SPRはおよそいくつですか？また、このSPRとウェイ数を踏まえると、コミットラインの目安はどうなりますか？

1. SPR≈6.7、コミットラインHS≥42（マルチウェイ補正なし）
2. SPR≈6.7、コミットラインHS≥55以上（マルチウェイで1段引き上げ）
3. SPR≈3.3、コミットラインHS≥42
4. SPR≈3.3、コミットラインHS≥30

---

### 解答

- **問1**: **2**（SPR≈4〜5）
  - 実効スタック30BB ÷ フロップポット約6BB ≈ 5。「SBR=15 → SPR≈4.5〜5」と変換表から読み取れます。

- **問2**: **2**（SPR≈2）
  - 実効スタック40BB ÷ フロップポット17BB ≈ 2.35。3BPではSBR=20でもSPR≈2に落ちます。コミットラインはHS≥30〜42（TP以上）です。

- **問3**: **2**（SPR≈6.7、マルチウェイで1段引き上げ）
  - 50BB ÷ 7.5BB ≈ 6.7。SPR数値は1対1と同程度ですが、マルチウェイでは他プレイヤーのナッツハンド確率が高まるため、コミットラインをHS≥55以上（TPMK以上）に引き上げます。

---

> **本章まとめ**
>
> - SBR → 実効スタック（×2してBB換算）→ SPR（÷フロップポット）の3ステップで変換する。
> - SRPのフロップポットは約6BB。SBR=20でSPR≈6〜7、SBR=15でSPR≈4〜5が基準値。
> - 3BPでは17BB前後がフロップポット。SBR=20でSPR≈2と大幅に浅くなる。
> - SPR別コミットライン: SPR≥8→HS≥65 / SPR5〜7→HS≥55 / SPR3〜4→HS≥42 / SPR<2→ほぼコミット圏。
> - マルチウェイではSPRの数値が同じでもコミットラインを1段引き上げる。

---

**【キャッシュとのズレ】**

vol2（キャッシュゲーム）では100BBスタックが前提で、SRPのSPRは常に15〜17程度でした。そのためTPTK基準のコミットライン（HS≥65）を体に染み込ませた読者も多いでしょう。MTTではSBR=20が「中盤の普通」であり、SPR≈6〜7でポストフロップが始まります。この感覚の切り替えが最初の関門です。

また、3BPの扱いも大きく変わります。キャッシュゲームの100BBでは3BPでもSPR≈5〜7程度ですが、MTTのSBR=20ではSPR≈2です。「3BPではTPがあればほぼオールインを視野に入れる」という意識が必要です。キャッシュゲームの「3BPでも慎重にブロックベット」の習慣を持ち込むと、MTTではスタックを無駄にするパターンが増えます。

SPR変換自体は単純な割り算ですが、「いつもの感覚がずれる」という心理的な落とし穴を最初に把握しておくことが重要です。
