# 第2章　ICMがフロップ以降に何を変えるか

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

キャッシュゲームでは、コールするかどうかの判断はベットサイズだけで決まります。MTTではそこに「ICM補正」が加わり、フォールドが正解になる範囲が広がります。本章ではvol3で学んだICM補正の考え方をフロップ以降に接続し、具体的なコール・フォールド・ベット判断への影響を整理します。

---

## 2-1　vol3の復習：ICM補正は「必要equityの加算」

vol3（MTTプリフロップ編）では、ICM補正を「コールに必要なequityへの上乗せ」として定義しました。ここで簡単に復習します。

**キャッシュゲームの場合**、コールに必要なequityはα（アルファ）式で求まります。αはブラフの損益分岐点でもあり、ベットサイズによってのみ決まります。

| ベットサイズ | 必要equity（α） |
|---|---|
| ポットの33% | 約25% |
| ポットの50% | 約33% |
| ポットの75% | 約43% |

たとえばポット100チップに対して50チップのCBetを受けた場合、コール額50÷（ポット100+CBet50+コール50）=50÷200=25%……ではなく、コール額÷最終ポット=50÷200=25%です。しかしここでは vol2 で使ったポットオッズ計算と同じ「コール後の最終ポットに対するコール額の割合」として求めます。50チップのコールで最終ポットが200チップになるので、必要equity=50÷200=25%……

少し整理します。ベットサイズをポットに対する割合で表したとき、必要equityの計算式は次のとおりです。

```
必要equity（α）= ベット額 ÷（ポット + ベット額 + コール額）
               = ベット額 ÷（ポット + 2×ベット額）
```

- 33%ベット: B=0.33P → α = 0.33÷1.66 ≈ 20%
- 50%ベット: B=0.50P → α = 0.50÷2.00 = 25%
- 75%ベット: B=0.75P → α = 0.75÷2.50 = 30%

※ここではシンプルな整数計算のためポットを1として計算しています。本書では以下の近似値を使います。

| ベットサイズ | 必要equity（α）【本書の近似値】 |
|---|---|
| ポットの33% | 約25% |
| ポットの50% | 約33% |
| ポットの75% | 約43% |

この近似値はvol2・vol3と同じです。キャッシュゲームではこのαを下回るハンドはフォールドが正解です。

**MTTの場合**は、ICM補正が上乗せされます。

```
MTTでの必要equity = α + ICM補正
```

ステージによってICM補正の大きさが変わります。

| ステージ | ICM補正 | 必要equity（50%CBetの場合） |
|---|---|---|
| 序盤（SBR≥25） | +1〜2% | 約34〜35% |
| 中盤 | +3〜5% | 約36〜38% |
| バブル | +10〜15% | 約43〜48% |
| FT（深賞金） | +15〜30% | 約48〜63% |

序盤の+1〜2%は誤差の範囲内で、実戦では無視してかまいません。バブルでは必要equityが大幅に上がるため、「キャッシュなら余裕でコール」という手がフォールドになる場面が頻繁に発生します。

## 2-2　フロップ以降への接続

ICM補正の考え方は、フロップ・ターン・リバーの全ストリートに適用できます。ただし「どのストリートで何枚残っているか」によって手の実際のequityが変わるため、HandScore（HS）と組み合わせて判断します。

### コール判断

フロップでCBetを受けたとき、コールの基準は次のとおりです。

```
コール条件: 手のequity ≥ α + ICM補正
```

vol2では「HS≥35（マージナル以上）でコール検討」という目安を使いました。MTTでは必要equityが上がるため、コールできるマージナルハンドの範囲が狭まります。

**具体例：バブル、BTNがBBに50%CBet、ボードQ♠7♦2♣（型1：ハイドライ）**

- キャッシュでの必要equity：約33%
- バブルICM補正：+12%（中央値）
- バブルでの必要equity：約33+12=45%

つまりBBは、equity45%以上の手でのみコールが正当化されます。ミドルペア（7ペア）程度のequityは約30〜35%であり、キャッシュならコール圏ですが、バブルではフォールドが正解です。

### フォールド判断

ICM補正が大きいほど「降り」が正解になる範囲が広がります。これをまとめると次のように整理できます。

- キャッシュ：equity < α → フォールド
- MTT序盤：equity < α+2% → フォールド（実質キャッシュと同じ）
- MTT中盤：equity < α+5% → フォールドが増える
- バブル：equity < α+15% → 大幅に降り寄りになる
- FT深賞金：equity < α+30% → 極端な降り寄り

## 2-3　ベット判断への影響：ICMは非対称にかかる

ICM補正がコール側にかかるのに対して、**ベットする側にはICM補正がかかりません**。この非対称性が重要です。

| 立場 | ICM補正の効果 |
|---|---|
| ICMプレッシャーをかける側（ビッグスタック） | 補正なし。攻める価値が上がる |
| ICMプレッシャーをかけられる側（バブル圧力を受けるスタック） | 折り取りが容易になる |

バブル時にビッグスタックがCBetを打つと、相手のコール基準が上がっているため、同じブラフがより高い頻度で成功します。ビッグスタックは「相手がフォールドしやすい状況」を利用して攻撃頻度を上げることができます。

一方、ミドルスタックやショートスタックがバブルでCBetを打つ場合は、攻撃にICM補正はかかりませんが、相手にレイズされたときの対応コストが大きくなります。バブルでのベットはビッグスタックほど有利ではないことを意識してください。

---

## 2-4　ICMバブル・ブラフ：相手の恐怖を突く

バブルでビッグスタックが活用できる戦術が「ICMバブル・ブラフ」です。相手のICM恐怖（チップを失ってバブル落ちすることへの恐れ）を利用し、通常より高い頻度でブラフCBetを打ちます。

### 有効な条件

1. **自分がビッグスタック**であること（ICM補正のプレッシャーをかける側）
2. **相手がバブル圧力を感じているスタック**であること
3. **ボードが型1（ハイドライ）**であること

型1のハイドライボード（例：Q♠7♦2♣、K♠8♦3♣）では、BBのコールレンジが通常でもタイトです。そこにICM補正が加わると、コールできるハンドの範囲がさらに狭まります。

### 具体例：BTN vs BB、バブル、Q♠7♦2♣

ポット=5.5BB（SRP標準）、BTNが50%CBet（2.75BB）を打った場合を考えます。

**通常（キャッシュ）の場合：**
- BBの必要equity：約33%
- BBがコールできるハンド：Qペア、中ポケット（66〜JJ）、ストロングドロー程度

**バブルの場合：**
- BBの必要equity：約33+12=45%
- BBがコールできるハンド：Q+良キッカー（TPTK水準）、セット・2ペア、ナッツドロー

BBのQ♣9♦はキャッシュなら余裕のコールですが、バブルではequity≈40%で必要equity45%を下回るため、フォールドが正解になります。BBのコールレンジが大幅に狭まることで、BTNのエアーCBetが割に合います。

**ICMバブル・ブラフのコスト計算（例）：**

- BTNがブラフCBetを打つコスト：2.75BB
- キャッシュでのフォールド率：仮に50%
- バブルでのフォールド率：仮に65%（コール閾値+12%により）
- ブラフの期待値（バブル）：0.65×5.5BB − 0.35×2.75BB ≈ 3.57BB − 0.96BB ≈ +2.6BB

同じブラフでもバブルでは相手のフォールド率が上がるため、ブラフのEVが大幅に改善します。ただしこれはあくまで定性的な説明です。実際の頻度は相手の読み方やスタック比率によって異なります。

### 型2〜7ボードでのICMバブル・ブラフ

型1（ハイドライ）が最も有効ですが、他のボードタイプでも活用できます。

| ボード型 | ICMブラフの有効性 | 理由 |
|---|---|---|
| 型1（ハイドライ） | 高 | 相手のコールレンジが元々タイト |
| 型6（ペア高） | 中〜高 | SBアドバンテージが大きく、相手が役を作りにくい |
| 型2（ハイウェット） | 中 | フラッシュドローを持つBBがコールしやすい |
| 型3/4（ロー系） | 低 | BBのコールレンジが元々広い |
| 型5（モノトーン） | 低 | ドローが多くコールが正当化されやすい |

## 2-5　ICM補正値まとめ表

本書全体で使うICM補正値をまとめます。

| ステージ | ICM補正 | 具体的な影響 |
|---|---|---|
| 序盤（SBR≥25） | +1〜2% | 無視可。キャッシュと同じ判断でよい |
| 中盤 | +3〜5% | ミドルペア水準のコールを1段タイトに |
| バブル | +10〜15% | マージナルハンドのほとんどがフォールド圏に |
| FT（深賞金） | +15〜30% | TPTK水準でもフォールドが正解になる場面あり |

**簡易暗算：**
バブルでのコール判断に迷ったら、「必要equity+12%」と覚えてください（+10〜15%の中央値）。50%CBetなら通常33%→バブル45%、75%CBetなら通常43%→バブル55%が目安になります。

## ハンドクイズ

### 問1

**状況：バブル直前、BTN vs BB（SRP）、SBR=20（SPR≈6）**
ボード：Q♠7♦2♣（型1：ハイドライ）
BTNが50%CBet。
BB視点、手はQ♠5♦（HS≈55程度、トップペア弱キッカー）。

このハンドの実際のequityは約40%と仮定する。コールするべきか？

1. コールする（ミドルレンジ以上なので問題ない）
2. コールする（equity40%はキャッシュの必要equity33%を上回る）
3. フォールドする（バブルの必要equity45%をequity40%が下回る）
4. レイズする（弱キッカーだが型1でのCRはバリューになる）

### 問2

**状況：中盤（ICM補正+4%）、BTN vs BB（SRP）、SBR=25（SPR≈8）**
ボード：J♥6♠3♣（型3：ロードライ）
BTNが50%CBet。
BB視点、手は6♠4♠（セカンドペア、HS≈42程度）。

このハンドの実際のequityは約35%と仮定する。コールするべきか？

1. コールする（セカンドペアはマージナル以上でコール圏）
2. コールする（型3はBBアドバンテージがあるのでコールが正当化される）
3. フォールドする（中盤の必要equity37%をequity35%が下回る）
4. チェックレイズする（型3でセカンドペアはCR圏）

---

### 解答

- **問1：3**

  バブルの必要equityは「α+ICM補正」=33%+12%=45%です。手のequityが約40%では45%を下回るため、フォールドが正解です。キャッシュなら33%を上回るのでコールできますが、バブルでは同じ手がフォールドになります。HS≈55でマージナル圏ではあっても、ICM補正が判断を覆すことを確認してください。

- **問2：3**

  中盤のICM補正+4%により、50%CBetへの必要equityは33%+4%=37%になります。手のequityが約35%では37%を下回るため、フォールドが正解です。選択肢2のように「型3はBBアドバンテージ」という考え方は正しいですが、それはBBのレンジ全体の話であり、個別のハンドのequityが必要水準を下回るかどうかとは別の問題です。選択肢4のCRは、セカンドペア単体では根拠が薄く、型3でもこの板ではエクイティ不足です。

---

> **本章まとめ**
>
> - MTTの必要equity = α + ICM補正。バブルでは+10〜15%、FT深賞金では+15〜30%上がる。
> - ICM補正はコール側にかかり、ベット側にはかからない。ビッグスタックの攻撃価値が相対的に上昇する。
> - バブルでの50%CBetをコールするには、通常33%→バブル約45%のequityが必要になる。
> - 型1（ハイドライ）ボードでのビッグスタックICMバブル・ブラフは、相手のコール閾値上昇を利用した高期待値プレー。
> - 序盤（SBR≥25）のICM補正+1〜2%は実戦では無視してよい。中盤以降から意識する。

---

**【キャッシュとのズレ】**

キャッシュゲームでは「equityがαを上回ればコール」という機械的な判断で済みます。しかしMTTでは、equityを正確に見積もりながらICM補正も加算する必要があります。バブルでICM補正+12%を意識するのは慣れるまで難しく、実戦では「このハンドのequityは十分なはず」と感じてコールしてしまいがちです。

特にミドルペア（equity約30〜35%）はキャッシュなら50%CBetに対してコールできますが、バブルでは必要equityが45%に達するためほぼ全域がフォールド圏です。この「バブルではミドルペアを降りる」という判断は直感に反しやすいため、事前に意識的に練習しておく価値があります。

また、ビッグスタックからICMバブル・ブラフを受ける側は「相手はブラフかもしれない」と感じながらも正しく降りる必要があります。ICM補正の観点からコールが正当化されない場面でブラフをコールすることは、感情的には正しく見えても数学的には損です。バブルでは「降りる勇気」がEVを守ります。
