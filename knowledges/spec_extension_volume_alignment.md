# 巻間の spec 整合性: 巻④ 拡張 vs 巻①-③ / 巻⑤-⑥

**起草日**: 2026-05-05
**目的**: 巻④ 第7章 7-5-a 節 (commit d2cad33) で導入したナッツブロッカー補正が、他巻の spec とどう整合するか整理。書籍改訂が必要か判断。

## 1. 巻④ で導入した拡張

| 項目 | 値 | 適用範囲 |
|------|----|---------|
| ナッツフラッシュドロー (NFD): 既存 +3 + 追加 **+3** | HS +6 | リバー想定の攻撃判断、フラッシュ完成 / ブロードウェイ完成ボード |
| サブナッツフラッシュドロー (Sub-NFD): K of suit, A 不在 | HS +5 | 同上 |
| ナッツストレートブロッカー: 完成ストレートの最上位カード保有 | HS +5 (existing +3 + 追加 +2) | 同上 |
| 上位セットブロッカー: 既存のまま | HS +2 | 変更なし |

実装: poker-drill `calc.py` (commit 15287ec, 4c927a6, 3834a21)

## 2. 巻 ごとの整合性チェック

### 巻① (preflop)

- **対象式**: Score (RFI / 3bet / 4bet)
- **ブロッカー関連**: A/K/Q ブロッカーは既に Score 式の一部 (`+B` 項)
- **巻④ 拡張との関係**: ポストフロップの NFD/Sub-NFD は preflop には影響しない
- **改訂要否**: ✗ 不要

### 巻② (flop 基礎)

- **対象式**: 簡易レンジスコア / HandScore / 後手スコア / Rule of 2 and 4
- **ブロッカー関連**: HandScore +2〜+3 (既存)
- **巻④ 拡張との関係**: 巻④ 7-5-a 節は **リバー想定** に限定。フロップは適用外
  - 第6章 (outs/equity): wheel A-2-3-4-5 や J-Q-K-A の特殊性は触れていないが、Rule of 2 and 4 はアウツ数で判断するため影響なし
  - 第9章 (HandScore): フロップ向けの +2〜+3 ブロッカー加点は維持。NFD/Sub-NFD はリバー想定なので加筆不要
- **改訂要否**: ✗ 不要（巻④ 7-5-a 節が「リバー想定の追加補正」として独立）

### 巻③ (flop 応用)

- **対象式**: 精密レンジスコア (D3) / マルチウェイ補正
- **ブロッカー関連**: 既存式に統合済み
- **巻④ 拡張との関係**: フロップ応用なのでリバー補正は適用外
- **改訂要否**: ✗ 不要

### 巻④ (本書、ターン・リバー基礎)

- **対象式**: バレルスコア / α 式 / 後手スコア / HandScore (ターン版)
- **巻④ 拡張**: 第7章 7-5-a 節として加筆済み (commit d2cad33)
- **改訂要否**: ✓ 完了

### 巻⑤ (ターン・リバー応用)

- **対象式**: 3 軸統合 / backward induction / コンボ単位選択
- **巻④ 拡張との関係**: 巻⑤ 第5章「ブロッカー実戦選択」が巻④ 7-5-a 節を引用すべき
  - 巻④ 7-5-a 末尾で「巻⑤ 第5章への橋渡し」として既に予告済み
  - 巻⑤ 第5章本文に補正値の参照を追加する余地あり
- **改訂要否**: ✓ 完了（commit 4f55daa: 第5章で巻④ 第7章 7-5-a 節を参照するよう修正）

### 巻⑥ (トーナメント)

- **対象式**: ICM equity / ICM 補正 / M値
- **巻④ 拡張との関係**: ICM 補正は別軸。ナッツブロッカーは ICM ステージで価値が上昇する可能性があるが、本書 spec の範囲外
- **改訂要否**: ✗ 不要

### digest

- **対象**: 6 巻の要約
- **巻④ 拡張との関係**: 巻④ 第7章のサマリで 7-5-a 節を 1 行追加する余地
- **改訂要否**: ✓ 完了（commit fccf8f2: 第14章にナッツブロッカー補正への参照を追加）

## 3. 結論

**現状の整合性**: 巻④ 7-5-a 節は「リバー想定の追加補正」として独立した位置付けを持つため、巻①-③ への影響なし。巻⑤ と digest は軽微な参照追加で完成度が上がるが、必須ではない。

**改訂優先度**:
1. ✓ 巻④ 第7章 7-5-a 節（完了、commit d2cad33）
2. ✓ 巻⑤ 第5章「ブロッカー実戦選択」への参照追加（完了、commit 4f55daa）
3. ✓ digest の巻④ サマリへの追記（完了、commit fccf8f2）
4. ✗ 巻①-③ / 巻⑥: 改訂不要

**今後の判断**:
全巻でナッツブロッカー補正の整合性が取れた状態。spec 拡張に伴う書籍改訂は完了。
