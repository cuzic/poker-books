# レンジリーディング研究: ターン/リバーでの相手レンジ推定

## 1. 基礎理論: レンジ絞り込みの原則

### 1.1 アクション別のレンジ変化

ポーカーのレンジリーディングの基本原則は、相手のプレイ履歴によって初期レンジが継続的に絞り込まれていくことです。6-max GTO戦略では、各アクションが特定の手札群を除外または残存させる明確なパターンが存在します。

**CBetによるレンジ構成:** IPプレイヤーがフロップでCBetを行う場合、強い手札（セット以上、トップペア以上）と強いドローを優先的に含みます。一方、弱い手札やエアはランダム度合いを持ちながらもある程度は含まれます。GTO的には、BTNからのCBetは約40-50%のレンジで行われます。OOPプレイヤーがCBetに直面した場合、フォルドされた手札は主に:
- A2o～A9o（エース以下のキッカーが弱い）
- K2o～K9o（キング以下のキッカー）
- その他の弱いエア（Q9o未満など）

で構成されます。結果として、OOPのコールレンジは比較的強くなります。

**フォルドによるレンジ縮小:** OOPプレイヤーがCBetにフォルドした場合、該当手札は完全に除外されます。残存するレンジは：コール手札の強度が直接OOPレンジを表現するため、弱い手札や中程度の引き込みは消滅します。

**コールによるレンジ保持:** OOPがコールする場合、多くの場合トップペアレベル以上、または強いドロー（オープンエンダー、フラッシュドロー）が中心です。同時に弱いペアやエアハンドも一部含まれます。このコールレンジの形状が「キャップされたレンジ」と呼ばれるもので、IPのアンキャップ性（CBet + ベットアップ余地）と対比されます。

### 1.2 キャップ vs アンキャップの概念

**IPのアンキャップレンジ:** フロップでIPがCBetを行った後、ターンで再度ベットする権利を保有します。このため、IPレンジには次の特性があります:
- 最強手（セット以上）を含む
- 強いドロー（ナッツドロー）を含む  
- 弱い手札も一定割合を含む

IPはターンでのアクションを通じて、レンジを「上向き」に調整する柔軟性を持ちます。

**OOPのキャップレンジ:** CBetコール後、OOPはIPが次のストリートでベットしてくる可能性に対応する必要があります。多くのGTO戦略では、OOPがコールする手札は：
- トップペア以上の既成手（トップペア、トップセット）
- 強いドロー（OESDs、フラッシュドロー）
- 稀に中程度のペア（セット未満のペア）

で構成されます。OOPレンジは「キャップ」されており、最強手を持っていない傾向が強くなります。

### 1.3 ターンカード別のレンジ影響

**ペアカード（フロップ上のランク重複）:**
IPから見たOOPレンジへの影響：ペアが落ちた場合、特定の手札（例：K♠7♦2♣ → 7♥）の意味が大きく変わります。OOPが7を持つセット（77など）の確率は低下しますが、IPもまた同様です。相対的には、セットを持つ確率の比較が重要です。BTNのペアボード戻り（特に2ペア化）はOOPレンジに対して脅威度が増加します。

**オーバーカード（OC）:**
BTN vs BBの場合、K♠7♦2♣ → A♥のようなOCが落ちた場合：
- IPのAを持つ率が高い（AKo、AQs等多くのオープンレンジに含まれる）
- OOPのAを持つ率が相対的に低い（BBディフェンスレンジでAK等は限定的）
- OCはIPに有利に働き、OOPのコールレンジは急速に絞り込まれます

**ブランクカード（フロップと相互作用なし）:**
K♠7♦2♣ → 5♥ のような無関連カードはレンジ構成をあまり変えません。既存のトップペアはトップペアのまま、ドローはドローのままです。ただしブランクはターンで「何も起きなかった」というシグナルをもたらし、両プレイヤーのレンジ強度はフロップより相対的に安定します。

**フラッシュ関連:**
K♠7♦2♣ → 5♠ のようなスート落ちは、フロップがモノトーン（3枚同スート）の場合に特に重要です。ドロー完成時、OOPのフラッシュ確率が上昇し、OOPレンジはアップグレードします。IPから見れば、ブランクを祈るエリア（特に弱い手札）が増加します。

**コネクタ相互作用:**
J♠T♦5♣ → 6♥のような隣接度の高いカードは、多くの手札に対して「ドロー完成」の可能性をもたらします。特に両プレイヤーのレンジに含まれやすいコネクタハンド（JT、T9等）は、コネクタ落ちでOESDF（オープンエンダー+フラッシュドロー）に進化する可能性があり、レンジの不確実性が最大化します。

### 1.4 リバーでのドロー完成/不成立

**ドロー完成時:** フロップで OESD → ターンでコール → リバーでストレート成立の場合、OOPレンジは「可能性のあったドロー」から「成立ハンド」へと急速にアップグレードされます。IP視点では、OOPの既成手に対する勝率が劇的に低下し、チェックダウンまたは消極的なベットを優先します。

**ドロー不成立時:** フロップでフラッシュドロー（FD）をコールしたOOPが、ターンブランク → リバーブランクを見た場合、OOPレンジは大きくダウングレードします。特に「ドロー確定→リバー不成立」の手札はエアに転落し、IPのバリューベットに対する耐性が大幅に低下します。このダウングレード現象はリバーのアグレッシブネスを決定する最重要要因です。

## 2. プリフロップレンジ基準

### 2.1 BTNオープンレンジ（40%）

BTNからのオープンレンジは約852ハンド（1326中40%）を含みます。カテゴリ別内訳：

| ハンド範囲 | カテゴリ | 推定コンボ数 | レンジ内% |
|-----------|---------|-----------|---------|
| AA～TT | PremiumPair | 33 | 4.8% |
| 99～55 | StrongPair | 30 | 4.4% |
| 44～22 | MidPair | 24 | 3.5% |
| AK～AQ (s) | SuitedAceStrong | 16 | 2.4% |
| AJ～AT (s) | SuitedAceWeak | 20 | 2.9% |
| KQ～KT (s) | SuitedBroadway | 24 | 3.5% |
| QJ～QT (s) | SuitedConnector | 20 | 2.9% |
| JT～T9 (s) | SuitedConnector | 16 | 2.4% |
| 98～65 (s) | SuitedConnector | 16 | 2.4% |
| AK～AT (o) | OffsuitBroadway | 48 | 7.1% |
| KQ～KJ (o) | OffsuitBroadway | 24 | 3.5% |
| QJ～QT (o) | OffsuitBroadway | 20 | 2.9% |
| JT～T9 (o) | Connector | 20 | 2.9% |
| A5s～A2s (弱) | WeakSuitedAce | 20 | 2.9% |
| K9～K2 (s) | WeakSuitedHand | 32 | 4.7% |
| その他ブロードウェイ | BroadwayMix | 150 | 22.1% |
| その他ハンド | Marginal | 83 | 12.2% |

BTNは位置的優位性と3位置のフォールドビリティが高いため、40%レンジは最も幅広くなります。ナッツアドバンテージは強く、IP有利です。

### 2.2 BBディフェンスレンジ vs BTN（40%）

BBがBTNの40%オープンに対して防御する場合、約850ハンドの防御レンジが構成されます：

| ハンド範囲 | カテゴリ | 推定コンボ数 | 戦略 |
|-----------|---------|-----------|------|
| AA～JJ | PremiumPair | 36 | スタンダードコール |
| TT～33 | MidSmallPair | 42 | ミックス（時々3bet） |
| AK～AQ (s) | SuitedAceStrong | 16 | 3betまたはコール |
| AJ～AT (s) | SuitedAceWeak | 20 | コール |
| KQ～KT (s) | SuitedBroadway | 24 | コール |
| QJ～QT (s) | SuitedConnector | 20 | コール |
| JT～T9 (s) | SuitedConnector | 16 | コール |
| 98～76 (s) | SmallConnector | 16 | コール |
| AK～AJ (o) | OffsuitAceStrong | 32 | 3betまたはコール |
| KQ (o) | Broadway | 4 | コール |
| その他 | EdgeHands | 124 | ミックス |

BBディフェンスは約40%のレンジで成立しますが、プリフロップ3bet頻度は約8%程度に限定されます。スーテッド・コネクタはBBにとって利益的な防御手であり、特にJT、T9、98等のオープンエンダーポテンシャルハンドが重視されます。OOP有利（実際にはBBは逆位置）になります。

### 2.3 COオープンレンジ（30%）

COからのオープンレンジは約400ハンド（1326中30%）です：

| ハンド範囲 | カテゴリ | 推定コンボ数 | レンジ内% |
|-----------|---------|-----------|---------|
| AA～TT | PremiumPair | 33 | 8.2% |
| 99～33 | MidSmallPair | 42 | 10.5% |
| AK～AT (s) | SuitedAceAll | 36 | 9.0% |
| KQ～KT (s) | SuitedBroadway | 24 | 6.0% |
| QJ～QT (s) | SuitedConnector | 20 | 5.0% |
| JT～T9 (s) | SmallConnector | 16 | 4.0% |
| AK～AJ (o) | OffsuitAceStrong | 32 | 8.0% |
| KQ (o) | Broadway | 4 | 1.0% |
| その他 | Marginal | 153 | 38.3% |

COレンジは30%に限定されるため、BTNより絞り込まれます。特に弱いオフスーテッド手札（K9o、Q9o等）の頻度が低下します。

### 2.4 3bet/4betレンジ基準

**BB vs BTN 3bet（約8%）:**
- AA、KK、QQ、AKs（3%強度）
- JJ、TT、AQs、AJs（1.5%）
- KQs（0.5%）

**BTN vs BB 3bet時の4bet（約3%）:**
- AA、KK（2%）
- AKs（0.8%）
- QQのポジション依存（0.2%）

## 3. フロップアクション後のレンジ変化

### 3.1 K♠7♦2♣（ドライ: K-high rainbow） — IP有利

**状況:** BTN vs BB SRP（シングルレイズドポット）

#### アクションa) IP CBet 50% → OOP Fold
- IP CBet側: フルレンジの約50%をベット（950コンボ中480）
- OOP Fold側: 除外されたハンド = 弱いペア(22-66), エア(Q9o, J8o, etc)
- **残OOPレンジ（ハンド数: 約200）:**
  - 強いペア系: 77（4コンボ）、KJ+（9コンボ）
  - ドロー系: QJ, QT, J9（ナッツドロー × 0.5頻度）
  - 既成手上位: AK, AQ（限定的に含まれ）
- **ナッツアドバンテージ:** IP優位

#### アクションb) IP CBet 50% → OOP Call（重要ケース）
- **OOPコールレンジ構成（約150-170コンボ）:**
  - セット: 22, 77（各4コンボ）＝ 8コンボ
  - トップペア+: K9, K8 (16コンボ)、K10-KQ以上(限定）＝ 30-40コンボ
  - ドロー: QJ, QT, J9（各4コンボ × 0.6頻度）＝ 7-8コンボ
  - 弱ペア: 99-88 (一部のみ)＝ 10-15コンボ
  - エア/浮き玉: A2-A6s（アセ系弱手）＝ 10-15コンボ
- **IPから見たOOP性質:** キャップレンジ。セットレス、トップペア中心、ドロー周辺に固まる
- **ナッツアドバンテージ:** IP有利（アンキャップ保有）

#### アクションc) IP Check → OOP Check
- **両者のチェック後レンジ（フルレンジの約60-70%）:**
  - IP: エアハンド（A2-A4, Q9, J8等）を多数保有
  - OOP: 弱ペア（55以下）、エア、ドロー候補
- **Nut Advantage:** 中立に近い。IPが弱く見えるため、OOPレンジも比較的幅広い
- **ターン推移:** ブランクターンではチェックダウン続行が多い

#### アクションd) OOP Donk 50% → IP Call
- **OOP Donkレンジ構成:**
  - セット: 22, 77（高頻度、約40-50%）
  - トップペア：K10-KJ（約30%）
  - 弱い見栄ドンク：77未満のペア、Q7, J7（約20%）
- **IP Call側:** IPはOOP Donkに対してフリークエンシーで応答。70-80%のレンジで応答コール
- **Nut Advantage:** OOP有利（セット多くを含む）

### 3.2 J♠T♦5♣（セミウェット: broadway） — 中立

**状況:** BTN vs BB SRP

#### アクションa) IP CBet 50% → OOP Fold
- **除外:** 弱いペアとエア系（55以下, A2-A4等）
- **残レンジ:** ドロー比率が上昇（OESD: KQs, K9, QT等多数）

#### アクションb) IP CBet 50% → OOP Call
- **OOPコールレンジ構成（約180-200コンボ）:**
  - ドロー: KQs, K9s（OESD）、89（ガッシュ）＝ 40-50コンボ
  - ペア: JJ, TT, 55（既成手）＝ 20-25コンボ
  - トップペア: JK, TX（含まれるが限定的）＝ 15-20コンボ
  - エア: A2-A4（ドロー要素）＝ 10-15コンボ
- **Nut Advantage:** 中立。両者ともドロー豊富でナッツ優位性が不明確

#### アクションc) IP Check → OOP Check
- **チェック構成:** エア系、弱いペア、「様子見」ドローが中心
- **ターン推移:** ターンで複合ドロー完成時に大きな変化

#### アクションd) OOP Donk 50% → IP Call
- **OOP Donk内容:** セット（JJ, TT, 55）が約40-50%、トップペア約30%、勢いドンク約20-30%
- **IP応答:** 広いコールレンジで応答

### 3.3 9♠8♦7♣（コネクテッド: 3連） — OOP有利

**状況:** BTN vs BB SRP

#### アクションa) IP CBet 50% → OOP Fold
- **除外:** 弱いペア(5以下), 無関連エア（AK外等）
- **残レンジ:** ドロー比率が極めて高い（T6s, 65s等OESD多数）

#### アクションb) IP CBet 50% → OOP Call
- **OOPコールレンジ構成（約200-220コンボ）:**
  - OESD: T6s, 65s, 54s（各4コンボ × 0.7）＝ 40-50コンボ
  - セット: 99, 88, 77（各4コンボ）＝ 12コンボ
  - 既成手ペア: TT, 66, 55（各4コンボ × 0.5）＝ 10-12コンボ
  - トップペア: 9J, 9T, 8T（含まれるが限定）＝ 10-15コンボ
  - フラッシュドロー（スーテッド）: 120コンボ中、フロップドロー含める = 30-40コンボ
- **Nut Advantage:** OOP有利。ドロー多数でOOP側の「ターン改善余地」が大
- **ターン推移:** OESフラッシュ組み合わせ落ちでOOP大優位化

### 3.4 K♠7♠5♠（モノトーン: フラッシュ） — 中立

**状況:** BTN vs BB SRP

#### アクションb) IP CBet 50% → OOP Call
- **OOPコールレンジ構成:**
  - フラッシュドロー: AA♠, KJ♠, Q♠J等多数 ＝ 70-90コンボ
  - セット/ツーペア: 55, 77（スーテッド多い）＝ 8-12コンボ
  - トップペア弱キッカー: K2-K4（スーテッド）＝ 8-10コンボ
  -既成フラッシュ（稀）: KK♠等＝ 1-2コンボ
- **Nut Advantage:** 中立～OOP やや有利。ナッツドロー完成確率が高い

### 3.5 Q♠Q♦4♣（ペアボード） — IP有利

**状況:** BTN vs BB SRP

#### アクションb) IP CBet 50% → OOP Call
- **OOPコールレンジ構成:**
  - セット: 44, QQ（フルハウス早期候補）＝ 4-6コンボ
  - トップペア: KQ, JQ（弱キッカー）＝ 10-15コンボ
  - オーバーペア: KK, JJ（稀）＝ 2-3コンボ
  - ドロー: AK, AJ（ガッシュ＋オーバーペアドロー）＝ 15-20コンボ
  - エア: A2, K2等＝ 5-10コンボ
- **Nut Advantage:** IP有利。IP側がQQのセット（4コンボ）保有確率が高い

#### ts_006-012: 同様に、以下パターン
- ts_006: CO vs BB, OC後（A♠が落ちた場合のCO→BBレンジ）
- ts_007: BTN vs SB, Pair後（ペアボード）
- ts_008: Flush (セミウェットFD落ち)
- ts_009: Gutshot形成後
- ts_010-012: 3つの異なるポジション組み合わせでOOP視点のシナリオ

### シナリオグループ2: Check+Check後のターン（6シナリオ）

#### ts_013: Blank後でのチェック継続
- **状況:** BTN vs BB, SRP | PF: BTN 2.5BB → BB Call | F: BB✓ → BTN ✓ | T: BB✓ → BTN?
- **問題:** "IPレンジは？"
- **答え:**
  - **レンジ構成:**
    - エア（主流）: 45-55%
    - ドロー（活動ドロー）: 25-30%
    - ペア（弱ペア）: 15-20%
  - **ナッツアドバンテージ:** 中立～OOP やや有利（IP弱さが露呈）
  - **キーポイント:** チェック継続は「IP弱さ」を明示し、OOPレンジの相対的強度が向上。
  - **アクション示唆:** OOPドンク（40-50%）が効果的、IPはフォルド頻度上昇

#### ts_014-018: その他チェック後シナリオ（異なるカード展開）

### シナリオグループ3: IP視点での30シナリオ総括

その他のシナリオ（ts_019-ts_030）は、以下の次元で構成：
- **POV:** IP読む (15), OOP読む (15)
- **Flop Action:** CBet+Call (18), Check+Check (6), Donk (6)
- **Turn Card:** Pair (7), OC (7), Blank (8), Connector (4), Flush (4)

各シナリオの一般的フレームワーク：
1. ポジション × 相手キャップレンジの形状
2. ターンカード × 相互作用
3. 推定レンジ構成（%）
4. ナッツアドバンテージ判定
5. ターンアクション推奨（頻度ベース）

## 5. リバー 20シナリオ

### リバーシナリオの特性

リバーに到達するレンジは「2ストリート全フロー」で極度に絞り込まれます。

#### rs_001: Draw Complete (OESD → Straight Made)
- **状況:** BTN vs BB, 3BP | PF: BTN 2.5BB → BB 3bet 7BB → BTN Call | F: BTN ✓ → BB CBet → BTN Call | T: BTN Check → BB 50% → BTN Call | R: Straight made
- **問題:** "OOPレンジは？（新展開）"
- **答え:**
  - **レンジ構成:**
    - ストレート（成立）: 40-50%
    - セット（ナッツ）: 20-30%
    - トップペア（相対的エア化）: 10-15%
    - フラッシュドロー不成立: 5-10%
    - 純エア: 5-10%
  - **ナッツアドバンテージ:** OOP圧倒的優位
  - **キーポイント:** ドロー成立で初めてOOPが「ナッツレンジ」を獲得。IP視点では消極的対応が必須。
  - **アクション示唆:** IP大幅チェック増（70%以上）、OOPバリューベット

#### rs_002: Draw Completion (FD → Flush Made)
- **状況:** 同上、フラッシュドロー成立時
- **答え:**
  - **レンジ構成:**
    - フラッシュ（成立）: 35-45%
    - セット: 25-35%
    - 既成手（ダウングレード）: 10-15%
  - **ナッツアドバンテージ:** OOP優位（フラッシュ頻度）
  - **キーポイント:** FD成立確率は約33-40%であり、リバーでの不確実性を最大化。

#### rs_003: Draw Miss (OESD未成立)
- **状況:** 同上、ガッシュ不成立
- **問題:** "IPレンジは？（強化）"
- **答え:**
  - **レンジ構成:**
    - ペア（相対強化）: 35-45%
    - エア（ダウングレード顕著）: 20-30%
    - ドロー不成立（エア化）: 25-35%
  - **ナッツアドバンテージ:** IP有利（相対化）
  - **キーポイント:** ドロー不成立で両者のエア比率が激変。OOP側のバリューレンジが大幅縮小。
  - **アクション示唆:** IP積極ベット（70-80%）、OOPのフォルド増

#### rs_004-020: 他のドロー組み合わせ、ボード進化

リバーシナリオの多くは「3ストリートコール→リバー評価」の極限フィルタリングです：
- ドロー成立×ナッツ化（rs_001-003）
- ボード改変（3ペア化等）によるハンド再評価（rs_004-010）
- 純粋チェックダウン完結（rs_011-020）

特に重要なのは **「3ストリート全コール後のレンジフィルタリング」** で、このシナリオセットは最も厳しいレンジ読み訓練となります。

## 6. レンジ読みクイズ問題集

### Q1: OC後のOOPコールレンジ構成
**問題:** "BTN のK♠7♦2♣CBet後 → BBコール → ターンA♥落下。以降BBはチェック。BBのコールレンジ内で**最も頻度が高い手札カテゴリ**は何か？"

**答え:** ドロー系手札（特にQJ, QT, OESD類）が**35-40%**を占めます。OC落下でトップペア系が相対的に弱体化し、ドロー「生存者」が相対優位化するためです。

### Q2: ペアボード上のOOP Donk
**問題:** "Q♠Q♦4♣でBBがドンク50%ベットした場合、そのレンジの**セット含有率**はおおよそ何%か？"

**答え:** 約**40-50%**。OOP側がペアボード上でドンクアグレッシブになるのは、セット多数保有を示唆します。IP側はこの高いセット含有率を考慮し、コール頻度を抑制するべき。

### Q3: マルチウェイ3-ストリート
**問題:** "3人マルチウェイ (UTG open 2.5BB → CO call → BB call) → フロップK♠7♦2♣でBBチェック → UTGチェック → COチェック → ターンA♥ → BBドンク50%。BBのドンクレンジ構成で**AK-AQ含有率**は？"

**答え:** 約**8-12%**（シングルレイズドポットより低い）。マルチウェイは参加者の増加により各プレイヤーのレンジが分散化され、特定ハンドの密度が低下。BBのAK-AQ保有確率は相対的に限定的。

### Q4: フラッシュドロー完成後のリバー
**問題:** "BTN vs BB SRP → Kの単スートフロップでBBがコール → ターンブランク → BBチェック → IPベット → BBコール → リバー: 同スートカード(完成)。このリバーでIPがチェックした場合、OOPレンジのフラッシュ含有率は？"

**答え:** 約**30-40%**。ターンで「生存」したOOPのコールレンジのうち、FD保有率は極めて高く、リバー成立でそのほぼ全部がナッツ化。IP側の消極的対応が合理的。

### Q5: 連続ストリート全コールの極限フィルタリング
**問題:** "BTN vs BB SRP → J♠T♦5♣（セミウェット）→ BBチェック → BTNコール → ターン6♥ → BBチェック → BTNベット → BBコール → リバー: 対戦手札はQ（OESD成立）。成立直後、BBレンジ内での**トップペア以上の手札カテゴリ**の構成比は？"

**答え:** 約**25-35%**（通常50%から激減）。3ストリート全コール後のレンジは「ドロー保有者」に極度に絞り込まれており、既成手の絶対数が激減。トップペア単独は逆に「弱点」へ転落。

### Q6: CO vs BB のポジション3ストリート
**問題:** "CO open 2.5BB → BB call → フロップA♠K♣5♦でBBチェック → COチェック → ターン2♥でBBチェック → COベット33% → BBコール。CO レンジ内で**セット確率**は？"

**答え:** 約**3-5%**。CO のAK スーテッド保有率は限定的（特にフロップCチェック後）。AK ペア確率は非常に低い。

### Q7: ドライボード vs セミウェット
**問題:** "2つのボード比較:①K♠7♦2♣（ドライ）での IP CBet後 OOP コール vs ②J♠T♦5♣（セミウェット）での IP CBet後 OOP コール。どちらの OOP コールレンジがドロー比率が高いか、またおおよそいくつか？"

**答え:** ②セミウェット。①ドライ: ドロー比率**25-30%** vs ②セミウェット: ドロー比率**40-45%**。セミウェットはOESD、ガッシュなど多様なドロー形成を許容。

### Q8: チェック継続後のターン評価
**問題:** "フロップ両者チェック後、ターンでIP がベットを仕掛けた場合、IP レンジ内での**ドロー比率**の推定値は？"

**答え:** 約**35-45%**。チェック継続は「IP エア多数」を意味し、ターンベットではそのエア＋ドローの混合比率が極めて高くなります。

### Q9: 逆ポジション読み（OOP → IP）
**問題:** "OOP がチェック → IP CBet → OOP コール → ターン BB チェック。このターンチェック後、IP レンジの**セット以上確率**は？"

**答え:** 約**5-8%**。OOP の「フロップ段階でのコール実行」が IP セットを相対的に排除しており、IP レンジのセット密度は低下。

### Q10: ナッツカテゴリ（ナッツドロー）判定
**問題:** "リバーで OESD がナッツストレートに成立。この状況下での OOP レンジ内の**ナッツハンド（ストレート以上）比率**は？"

**答え:** 約**45-55%**。ナッツドロー成立時、OOP レンジは劇的にアップグレード。セット等も含むと、ナッツ周辺の構成が過半数超へ。

```
✅ 答え:

├─ トップペア: 15-20% (K9, K8)
├─ ドロー: 18-22% (QJ, QT)
├─ ペア: 10-13% (99, 88)
└─ エア: 30-35% (A2-A4, J8)

📈 ナッツアドバンテージ: IP有利 / OOP有利 / 中立

💡 キーポイント:
[相互作用説明 + 推奨アクション]

🎯 ターンアクション示唆: ベット頻度 XX%, チェック XX%
```
