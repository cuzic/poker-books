## 第07章　HandScore ─ ハンド強度 0〜100

### 重大度★★★

**【問題1】TPTK / TPGK / TPMK の役スコア値が本書内で矛盾している**

- 詳細：第7章の役スコアテーブル（ch07）は TPTK=70、TPGK=62、TPMK=50 と定義している。ところが第8章の「HS の目安テーブル」（line 25-27）では TPTK=65、TPGK=60、TPMK=55 と異なる数値を示している。また付録D（第22章）の D-2-a フローでは TPTK=70、TPGK=62、TPMK=50 と ch07 に一致するが、ch08 と食い違う。
- 影響：TPTK の値が 65 か 70 かで T1/T2 の境界判定が変わる。TPTK=65 だと T1 の閾値（≥65）にちょうど到達するだけで、わずかなドロー加点がない純粋 TPTK は T1 の「境界ハンド」になる。TPTK=70 だと T1 に余裕が生まれる。読者が ch07 と ch08 を並べて学ぶと計算結果が一致しないため、混乱が大きい。
- 該当箇所：`07-hand-score.md` 役スコアテーブル（line 54）/ `08-t1t2t3-cbet.md` HS目安テーブル（line 25）/ `22-decision-flowchart.md` D-2-a（line 54）/ `19-appendix-a.md` A-3（line 52）
- 修正案：シリーズの他巻（vol2 フロップ編 ch02、vol4 ターン・リバー ch05 等）では TPTK=65 を「正典値」として用いている。ダイジェスト版は vol2 正典に統一し、ch07/ch17/appendix A の TPTK=70 を TPTK=65 に修正する。あわせて TPGK=60、TPMK=55 に揃える。

## 第07章　HandScore ─ ミニクイズ解答

### 重大度★★★

**【問題3】第7章ミニクイズ問2 の解答計算が誤っている**

- 詳細：問2（A♥T♥ on 9♥8♥7♦）の正解を「HandScore = 65」としているが、解答説明での導出が誤り。説明文は「25 + 32（OESD）+ 18（追加 FD分、重複考慮）≒ 65」と書いているが、25+32+18=75 であり 65 にならない。また ch07 の FD+OESD コンボ表（line 76）は「実効13アウツ → フロップ +52」と明記しており、ブロッカー加点（A♥ ナッツフラッシュ +5）を加えると 25+52+5=82 となる。
- 影響：「答え合わせ」で計算しても 65 にならず、読者が自分の計算ミスだと思い込むリスクがある。正しい計算方法を誤認させる。
- 該当箇所：`07-hand-score.md` line 248-249
- 修正案：FD+OESD コンボ値 +52 を適用すると HS = 25 + 52 + 5 = 82 となり選択肢 4（上限 100 でクランプ前に 82）が最も近い。選択肢のいずれかが実際に正しい値に対応するよう選択肢を作り直し、解答説明を正しい計算式に差し替える。あるいは「選択肢 3（65）を正解にする意図」があれば、ブロッカー加点なし・別計算ロジックを採用した根拠を明記する。

## 第08章　T1/T2/T3 ─ OOP 防御フローの説明

### 重大度★★

**【問題4】フォールド閾値の「2tone でコール圏が広がる」説明が逆方向**

- 詳細：ch08 line 130 の補正説明で「vs75%・2tone: 35 + 5 = 40 → HS < 40 でフォールド（2tone ではドローがあるのでコール圏が広がる）」と書かれている。しかし閾値が 35 → 40 に上がると、HS 35-39 のハンドが従来の「コール」から「フォールド」に変わり、コール範囲は縮小する（広がるのではなく狭まる）。説明文とテーブル値が矛盾している。
- 影響：2tone ボードでの OOP 防御判断を誤解させる。「コール圏が広がる」と読んで HS=38 でコールしてしまうと、閾値 40 未満のためフォールドが正解というズレが生じる。
- 該当箇所：`08-t1t2t3-cbet.md` line 130
- 修正案：説明を「（2tone ではドローが多く相手の攻撃が通りにくいため、IP 側はより強い手でないとポットを奪えない。防御側は本来やや強い手を要求される）」のように、閾値上昇と整合した説明に修正する。あるいはテーブル値自体を見直し、2tone でフォールド閾値が下がる（= 守りやすい）設計に戻す。

## 第12章　後手スコア（ターン版・リバー版）

### 重大度★★★

**【問題6】第12章ミニクイズ Q1/Q2 の正解選択肢番号が解答説明と食い違っている**

- 詳細：
  - Q1（K♥Q♥ on J♥8♠3♦ + 9♣ターン）: 問題文で「HandScore = 25(K ハイ) + 12 + 8 = 45」と明記。後手スコア = 45+0-17-0 = 28 となり、選択肢2（後手スコア=28 → コール）が正解のはず。しかし解答欄は「**1** が正解（後手スコア=22→コール）」と誤って選択肢 1 を指定した上で、説明本文には「後手スコア = 45 + 0 − 17 − 0 = **28**」と書かれており、番号と計算結果が矛盾している。
  - Q2（9♦8♣ on A♥K♥Q♥J♠T♦）: HandScore=82、後手スコア=82+6-22-0=66 で、選択肢2（後手スコア=66 → CR推奨）が正解のはず。しかし解答欄は「**1** が正解（後手スコア=60→CR推奨）」を選び、説明本文には「後手スコア = 82 + 6 − 22 − 0 = **66**」と書かれており矛盾している。
- 影響：読者が解答の選択肢番号を信じると全く別の数値（22 や 60）を正解と学習してしまう。後手スコア式の体得に直接影響する重大な誤り。
- 該当箇所：`12-defender-score-turn-river.md` line 190-193
- 修正案：
  - Q1 の解答を「**2** が正解（後手スコア = 45 + 0 - 17 - 0 = 28 → コール）」に修正。
  - Q2 の解答を「**2** が正解（後手スコア = 82 + 6 - 22 - 0 = 66 → CR推奨）」に修正。
  - 付随して Q1 の HandScore が K-high=25 を使っているが、ch07 役スコアテーブル（K ハイ = 20）と食い違うため、K-high の値も統一後に再計算する（K-high=20 なら HS=40、後手スコア=23、選択肢に追加を要検討）。

## 第06章　Board Score B

### 重大度★

**【問題11】優先順位ルール2（モノトーン B=70）とルール3（ペア低 B=71）の順序が直感に反する**

- 詳細：9ルールでは「ルール2: モノトーン → B=70」が「ルール3: ペアボード × トップ 9 以下 → B=71」より優先される。つまりペア低ボードがモノトーンの場合、ルール2が先に適用されて B=70 と判定される。しかし B 値としてはペア低（71）＞モノトーン（70）なので、本来ならより高い優位度を示す B=71 を採用すべきように見える。
- 影響：厳密には局所的な問題（当てはまるケースが少ない）だが、ルール優先順位の設計思想が読者には説明なく不透明である。
- 該当箇所：`06-board-score-b.md` line 22-32
- 修正案：「ペア低+モノトーンの複合ボードは珍しいが、存在する場合はルール2（モノトーン）が優先される。これは実測データに基づく近似値として意図的に設定している」旨の注を追加する。あるいはルール3をルール2の前（優先順位を2番目）に移動し、B=71 > B=70 の順に統一する。
