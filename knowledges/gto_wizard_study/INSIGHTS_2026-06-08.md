# 今日の知見まとめ — 2026-06-08

MATCHA Framework の 5 判定軸のうち、**SPR 軸** の境界を GTO 実データで明確化した日。

## 1. 主要発見: SPR=3 が GTO 戦略反転点

同じ board (Ks7d2c, K-high rainbow dry) で SPR だけを 1.3 → 3.4 → 8 → 16 と
変化させると、tier ごとの cbet 頻度が劇的に変わることを実測:

| tier | SPR 1.3 (4BP) | SPR 3.4 (3BP) | SPR 8 (Cash50 SRP) | SPR 16 (Cash100 SRP) |
|------|---:|---:|---:|---:|
| ストロング (set) | **4%** | 41% | 69% | **96%** |
| ツーペア | 18% | 80% | **97%** | 83% |
| トップペア+ | 61% | 70% | 68% | 61% |
| ミドルペア | **73%** | 49% | 43% | 55% |
| エア | 41% | 46% | 46% | 44% |

### 戦略パラダイム転換: slowplay ↔ fastplay

- **SPR < 3 (オールイン/ロー)**: 強い手ほど **slowplay** (set 4%, 2pair 18%)。
  pot が既に大きく相手が commit しやすいため、check で trap。
- **SPR > 3 (ミディアム/ディープ)**: 強い手ほど **fastplay** (set 96%, 2pair 97%)。
  multi-street で value をかけて stack を引き出す必要。

### 4BP の逆転現象

SPR 1.3 (4BP flop) では:
- ミドルペア 73% bet (最高頻度)
- ストロング 4% bet (最低頻度)
- → 強い手 < 弱い手 の頻度逆転

これは jam-or-fold ゾーンで、ミドルペアが「相手の commit を引き出す」役割を負うため。
MATCHA 5 軸のうち SPR 軸が他軸を支配する典型例。

## 2. 二つの独立した裏付け

### (A) 293K rows データからの逆算

`dataset_unified_v2.csv` の scenario_id × street × pot_type で SPR を推定し、
bin ごとの GTO 行動を集計:

| SPR bin | n | fold | call | raise |
|---------|--:|---:|---:|---:|
| オールイン (<1) | 121K | 59% | 38% | 3% |
| **ロー (1-3)** | **55K** | **31%** | **47%** | **22%** |
| ミディアム (3-7) | 67K | 53% | 38% | 9% |
| ディープ (7-15) | 10K | 65% | 29% | 6% |
| >15 | 40K | 79% | 18% | 3% |

ロー (1-3) で raise 頻度が他の **2-3 倍**。SPR 3 を境に raise -13pp の不連続性。

### (B) 同 board × SPR 直接 probe (5 spots 取得)

同じ Ks7d2c で 4BP / 3BP / Cash50 SRP / Cash100 SRP を直接 probe (上記 (1) の表)。
data 逆算 (集合平均) と direct probe (spot レベル) の両方で **SPR=3 境界** が再現。

## 3. MATCHA 5 軸の SPR 軸が独立変数であることの確認

| MATCHA SPR tier | SPR 範囲 | data 上の特徴 |
|-----------------|---------|--------------|
| **オールイン** | <1 | 4BP turn/river, 3BP river。fold/call 中心、raise は jam |
| **ロー** | 1-3 | 4BP flop, 3BP turn。value-jam 中心、ミドルペアが活躍 |
| **ミディアム** | 3-7 | 3BP flop, SRP river, CR/donk defense。value/bluff 分離開始 |
| **ディープ** | >7 | SRP flop/turn。protect range, 多 sizing, multi-street value |

→ MATCHA 4 段階の境界は data 完全裏付け。

## 4. tier 別の SPR sensitivity (gradient slope)

| tier | SPR sensitivity | 解釈 |
|------|----------------|------|
| ストロング (set+) | **+92pp** (4→96%) | 最も SPR 依存。multi-street value 戦略の純粋形 |
| ツーペア | +79pp (18→97%, then -14) | SPR 8 で peak、SPR 16 でやや低下 (range protection) |
| トップペア+ | ±10pp (61-70%) | SPR 不変。tier 自体が支配的 |
| ミドルペア | -30pp + jam reversal | 4BP のみ逆転現象 (73%) |
| エア | ±6pp (40-46%) | SPR 不変。ブラフ頻度は tier 規定 |

ストロングが「SPR の正規ベクトル」を体現するハンドクラス。MATCHA で SPR 軸を学ぶときの
golden example として set with SPR variation を使うべき。

## 6. 限界と今後の追加 probe 候補

### 今日の probe で取れなかった点

- SPR <1 帯 (4BP turn/river, 3BP river) の **同 board** 比較データ不足
- 同じ board の異 sizing 比較 (Ks7d2c は 33% one-sizing で 75%/100% は 204)
- 1 → 3 の連続性 (1.3 → 3.4 は 4BP/3BP の質的差を含む)

### 追加 probe で取るべき spot

1. wet board (T98ss 等) で multi-sizing が available な spot
   → cbet 25% / 33% / 75% で turn SPR を細かく刻む
2. river jam frequency by SPR (0.3 / 0.5 / 0.8 / 1.5 / 3.0)
3. CR/donk defense @ varying SPR で defense 行動の SPR 依存
