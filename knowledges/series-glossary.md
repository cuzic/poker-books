## 1. 基礎概念

### アウツ
ハンドが完成するために必要な未公開カードの枚数。例: フラッシュドローは 9 アウツ、OESD（オープンエンドストレートドロー）は 8 アウツ。

### Rule of 2 and 4
Phil Gordon が提唱したエクイティ概算則（巻2 第6章）。
- アウツ × 2 ≒ 1 ストリート進行で完成する確率（%）
- アウツ × 4 ≒ 2 ストリート進行で完成する確率（%）

巻2 の HandScore のドロー加点（アウツ × 1.5）の根拠でもある。

### ポットオッズ
コール時のリターン比率。

```
ポットオッズ = コール額 ÷ (ポット + コール額)
            = コール額 ÷ 最終ポット
```

たとえばポット 100 にベット 50 のとき、コール 50 でポットは 200 になる。コール側のオッズは 50/200 = 25%。これが「コール側が必要とする最低勝率」になる。

### レンジ思考
ハンド単体ではなく「相手が持ちうる手の集合（レンジ）」で考える発想。シリーズ全体の前提。

## 2. ボード評価

### 簡易レンジスコア
**フロップのレンジ全体の CBet 頻度を 0〜10 で予測するマクロモデル**（巻2 で導入、巻3 で改称・再定義）。

- 入力: ストレート要素 + フラッシュ要素 + ハイボードリスク
- 出力: 0〜10 のスコア
- スコア → ボード分類（ドライ / セミ / ウェット）→ A 係数 として下流式に投入

**重要な注意**:
- ボードの「ドライ度そのもの」を測る静的指標ではなく、**「攻撃側の CBet 頻度の予測値」**
- 後手スコア・先手スコアの式に**直接加算しない**（A 係数として間接的に効く）

✗ 誤った要約: 「簡易レンジスコアと HandScore を組み合わせる」  
✓ 正しい要約: 「ボード特性（A 係数）と HandScore を組み合わせる」または「簡易レンジスコアの示すボード特性と HandScore を組み合わせる」

### 精密レンジスコア
簡易レンジスコアを精密化した CBet 頻度予測モデル（巻3 で導入）。外れ値ボード（簡易モデルが弾く特殊なボード）を吸収する。

### ターンカードの5分類
巻4 で導入。
- **ペア**: ボードペアリング → ナッツアドバンテージ更新
- **オーバーカード（OC）**: フロップ最高位より高いカード → ナッツアドバンテージ更新
- **ブランク**: 既存レンジに影響少 → ナッツアドバンテージ維持
- **フラッシュ**: フラッシュ完成カード → レンジ遷移急変
- **コネクター**: ストレート系を進行・完成 → レンジ遷移急変

### 9マスマトリクス
H1（強）/ H2（中）/ H3（弱）× ドライ / セミ / ウェット の 3×3 表（巻2 で導入）。フロップの「ハンド × ボード」マトリクスでアクション決定。

## 3. ハンド評価

### HandScore
ハンドの強さ指標 0〜50（巻2 第5章で導入、巻3 で精密化）。

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
```

代表値:
- TPTK（トップペア・トップキッカー、A キッカーのみ）= 18
- TPGK（トップペア・グッドキッカー）= 15
- TPWK（トップペア・弱キッカー）= 10
- セット = 30
- オーバーペア（OP）= 20

3つの加算項目はすべて**「○○加点」「役スコア」**と呼ぶ:
- ✗ 「ブロッカー」 → ✓ 「ブロッカー加点」（必ず「加点」を付ける）
- ✗ 「ドロー」 → ✓ 「ドロー加点」

ドロー加点の係数は 1.5（Rule of 2 and 4 の保守的な丸め）:
- フラッシュドロー（9 アウツ）→ 約 13点
- OESD（8 アウツ）→ 約 12点

### ハンドの3層分類
リバーで自分のハンドをどう振り分けるかの軸（巻4 第5章 / 巻5 で展開）:
- **バリュー**: コールされても勝てる手（HandScore 上位）
- **ブラフ候補**: コールされたら負けるが、フォールドさせる価値がある手
- **チェック / ショーダウンバリュー**: 戦わずに showdown を狙う中堅手

### ブロッカー基礎
自分のカードで相手のレンジを削る効果（巻4 第7章で導入、巻5 第5章で実戦選択）。
- **バリューブロッカー**: 相手のバリューレンジを削る（A♠ がフラッシュボードでナッツフラッシュをブロック）
- **ブラフブロッカー**: 相手のブラフレンジを削る（自分が J を持つと相手の JT 系ブラフを減らす）

ブロッカーは「方針なきハンド選択の道具」ではない。α 式や後手スコアで方針を決めた後の**最終層の選別ツール**。

## 4. 攻撃側の式

### CBet 統合式
フロップの IP CBet 判断式（巻2 第7章ドリル版）:

```
CBet スコア = HandScore − 簡易レンジスコア頻度補正値 + ポジション係数

簡易レンジスコア頻度補正値: 高頻度帯→0、中頻度帯→5、低頻度帯→10

判定:
  ≥ 15 → CBet 75%
  8〜14 → CBet 33%
  2〜7  → チェック
  < 2   → フォールド準備
```

### 先手スコア
フロップの攻撃側判断式（巻2 第10章以降の標準形）:

```
先手スコア = HandScore + A − M

判定:
  ≥ 7 → ベット（33% 基準）
  < 7 → チェックバック
```

### バレルスコア
ターン攻撃の式（巻4 第8章で新規導入）:

```
バレルスコア = FlopType係数 + TurnCard係数

FlopType係数:
  ドライ = 8
  セミ = 6
  スーテッド = 4
  コネクテッド = 3

TurnCard係数:
  ペア = 4
  オーバーカード = 3
  ブランク = 2
  フラッシュ = 1
  コネクター = 0

判定:
  ≥ 7 → 積極バレル
  < 7 → 慎重 / チェック
```

### α 式
リバー配分の式（巻4 第9章で新規導入、巻5 で応用展開）:

```
α = ベット ÷ (ポット + ベット)
後手下限確率 = 1 − α
```

リバーで打つベットの「バリュー:ブラフ比率」のインディファレンス点を与える。

代表値:
- 33% pot ベット: α = 0.25、後手下限確率 = 0.75
- 50% pot ベット: α = 0.33、後手下限確率 = 0.67
- 75% pot ベット: α = 0.43、後手下限確率 = 0.57
- 100% pot ベット: α = 0.50、後手下限確率 = 0.50
- 150% pot（オーバーベット）: α = 0.60、後手下限確率 = 0.40

## 5. 防御側の式

### 後手スコア
ディフェンス側の判断式（巻2 第13章 HU 形 + 第16章マルチウェイ形で導入）:

```
HU:    後手スコア = HandScore + A − C
全般:  後手スコア = HandScore + A − C − M

判定（新スケール 0-100）:
  ≥ 40 → チェックレイズ検討
  20〜39 → コール
  < 20  → フォールド
```

**HU 前提で M を省略する場合は、必ず「HU 前提のため M=0」と注記する**こと。

#### 後手スコア（フロップ版）
巻2 で確立した式（C 値: 33%=12, 50%=17, 75%=22、新スケール）。

#### 後手スコア（ターン版）
ターンへの拡張（巻4 第10章）。係数の解釈はフロップ版と同じだが、ターンではドロー加点（Rule of 2: アウツ × 2）が生きる。

#### 後手スコア（リバー版）
リバーへの拡張（巻4 第11章）。リバー特有の C 値拡張:
- 100% pot = 25
- 150% pot（オーバーベット）= 30

### 後手下限
コール側が確保すべき最低防御率（巻1-3 で確立、巻4-5 で継承）。  
※ 旧用語「MDF」は使わない。

文脈に応じて 3 通り使い分ける:

| 用語 | 用途 | 例文 |
|---|---|---|
| **後手下限ライン** | しきい値・境界として語る | 「後手下限ラインを下回るとブラフを許してしまう」 |
| **後手下限確率** | 具体的な % 数値 | 「75% ベットの後手下限確率は 57%」 |
| **後手下限スコア** | スコア式の出力値 | 「後手スコアが後手下限スコアを超えていればコール」 |

3者の関係:

```
α                = 0.43   (先手のブラフ損益分岐点)
後手下限確率     = 1 − α = 0.57   (頻度の話)
後手下限ライン            (57% を割ると守りすぎ、概念の話)
後手下限スコア   = 0      (後手スコアの式における判断境界、スコアの話)
                          後手スコア ≥ 後手下限スコア → コール
                          後手スコア < 後手下限スコア → フォールド
```

無印の「**後手下限**」は概念全体を指すときに使う。

## 6. 係数

### A（ボード値、ドライ度）
巻2 で導入。簡易レンジスコアの分類結果が A として下流式に入る。
- ドライ = 3
- セミ = 2
- ウェット = 1

### C（ベット負担）
巻2 で導入。ベットサイズに応じた相手の負担。
- 33% pot = 3
- 50% pot = 5
- 75% pot = 7

リバー版（巻4 第11章）では拡張:
- 100% pot = 9
- 150% pot = 11

### M（マルチウェイ補正係数）
巻2 で導入。プレイヤー数による補正。
- HU = 0
- 3-way = 3
- 4-way 以上 = 6

注意: 巻6 の「M 値」（M ratio）とは別物。混同しないこと。

### ポジション係数
CBet 統合式で使う。詳細は巻2 第7章。

## 7. レンジ概念

### Capped / Uncapped
レンジ強度の分類（巻4 第3章で再導入、巻5 で精密化）。
- **Uncapped**: ナッツ級ハンドを含み得るレンジ。大きなベットを打てる
- **Capped**: ナッツ級ハンドが薄いレンジ。守備的にならざるを得ない

### ナッツアドバンテージ
最強のハンドがどちらのレンジに多く存在するかの指標（巻4 第3章 / 巻5 で展開）。

### レンジ強度
レンジ全体の強さ・分布（巻4 第3章）。Capped/Uncapped の上位概念。

### 3軸統合
巻5 で導入する応用フレーム。ターン判断 = forward 軸（過去レンジ）× current 軸（ターンカード）× backward 軸（リバー予測）。

### backward induction
リバーから逆算してターンの判断を決める（巻5 第2章）。ゲーム理論の標準手法。

### forward thinking
過去のアクション履歴を活用して現在のレンジを精密化する（巻5 第3章）。

## 8. トーナメント特有

### ICM equity
チップを賞金期待値（$EV）に換算した値（巻6 で導入）。Malmuth-Harville アルゴリズムで計算する。

「**自分のスタックが今いくら相当か**」を表す。

### ICM%
賞金プール全体に対する自分の取り分%。`ICM equity ÷ 賞金プール × 100`。

### ICM 圧縮
チップ価値の限界価値逓減により、大スタックの 1 チップ$価値は小さく、小スタックの 1 チップ$価値は大きい現象。トーナメントの戦略非対称性の根本原因。

### ICM 補正
ICM 圧力下で必要な上乗せ勝率（リスクプレミアム）。

```
ICM 補正 = bubble factor − 1.0
必要 equity = (1 + ICM 補正) ÷ (2 + ICM 補正) = bubble factor ÷ (bubble factor + 1)
```

ステージ別の代表値:
- 序盤: 0.05
- 中盤: 0.20
- バブル直前 (STT): 0.875
- バブル直前 (MTT): 0.40
- ITM 直後: 0.32
- FT 9-max: 0.488
- HU: 0.000（ICM 線形化、Chip EV と等価）

### bubble factor (BF)
オールイン勝負時の「失う $痛み / 得る $喜び」比。

```
bubble factor = |Δ$EV (チップを失うとき)| ÷ |Δ$EV (同量のチップを得るとき)|
```

BF = 1.0 → ICM 影響なし、Chip EV と $EV 等価。

### M 値（M ratio）
スタックを「強制ベット 1 ハンド分」で割った値（Harrington 系譜、巻6 第6章）。

```
M 値 = スタック (chips) ÷ (SB + BB + アンテ合計)
```

ステージ判定（Harrington による分類）:
- **Green** (M ≥ 20): 深スタック、キャッシュ寄り
- **Yellow** (M 10-20): 標準的 MTT
- **Orange** (M 6-10): 積極ショブ域
- **Red** (M ≤ 5): プッシュ/フォールド完結

注意: 巻2-5 の係数 M（マルチウェイ補正）とは別物。

### ペイジャンプ
賞金階段の上昇幅（巻6 第14章）。ITM 進入、FT 進入、上位賞金などの「ジャンプ点」で ICM 補正が再上昇する。

### Push/Fold（ゲーム）
ショートスタック（M ≤ 5）での「オールインかフォールドか」の 2 択戦略。Nash 均衡解が確立されている。

### サテライト
上位 N 名一律で次のトーナメント参加権を獲得するトーナメント。賞金構造がステップ関数で、ICM 補正が極端に大きい（巻6 第16章）。
