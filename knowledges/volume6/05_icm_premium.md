# ICM 補正（ICM Risk Premium）— ステージ別数値

`scripts/icm_calc.py --bubble-factor` で計算した、ステージごとの ICM 補正値。

## ICM 補正の定義

\[
\text{ICM 補正} = \text{Bubble Factor} - 1.0
\]

すべての対戦相手に対する平均値を取る（hero がランダムな相手とオールインする想定）。

- 0.00 → ICM 影響なし、Chip EV と同等
- 0.30 → 「30% プレミアム」、コール頻度を約 23% 削減 (`1 / (1+0.30)`)
- 1.00 → 「2 倍のリスク」、必要 equity 67%
- 2.00 → 必要 equity 75%

実測値（同 chip% 等スタック分布での平均 BF）。

| ステージ | 残り人数 | Top 賞金構造 | 等スタック ICM 補正 |
| :--- | ---: | :--- | ---: |
| 序盤（深いスタック、まだ ITM 遠い） | 100+ | — | ≈ 0.05 |
| 中盤（ITM が近づく、M=15-25） | 30〜50 | — | ≈ 0.20 |
| バブル直前（ITM 数% 上） | 4 (STT) | 50/30/20 | **0.875** |
| バブル直前（MTT、Top 60% 払い） | 10 | 40/25/15/10/6/4 | **0.4** |

| FT 9-max スタート | 9 | 30/20/13/10/8/6/5/4/4 | **0.488** |

| FT 3-handed | 3 | 50/30/20 | ≈ 0.32 |

## バブル付近の詳細（n=4 STT 等スタック）

スタック: 各 2500 chip、賞金 50/30/20。

```bash
python scripts/icm_calc.py --stacks "2500,2500,2500,2500" --payouts "50,30,20" --bubble-factor 0
```

P1 の bubble factor（vs 各相手）:

| 対戦相手 | BF | 必要 equity |
| :--- | ---: | ---: |
| P2 (等スタック) | 1.875 | 65% |
| P3 (等スタック) | 1.875 | 65% |
| P4 (等スタック) | 1.875 | 65% |

平均 ICM 補正 = 0.875

戦術的含意: AT off-suit は約 56% (vs random)、AQ は 60%、KK は 81% などの equity を持つ。バブル直前の必要 equity 65% は **AQ よりも上、KK の下** という水準。すなわち **JJ-、AQs- は call できない**。

## バブル直前のスタック非対称（n=4、STT）

スタック: 4500/3000/1500/1000、賞金 50/30/20。

各プレイヤーの平均 ICM 補正:

| プレイヤー | Chip% | ICM 補正 | 含意 |
| ---: | ---: | ---: | :--- |
| P1 (リーダー) | 45% | 0.270 | やや守備的（BF≈1.27） |
| P2 (中スタック) | 30% | **0.784** | 極めて守備的 |
| P3 (中スタック) | 15% | **0.825** | 極めて守備的 |
| P4 (ショート) | 10% | 0.529 | やや守備的（BF≈1.53） |

**観察**:

- リーダー (P1) の premium は意外に低い（0.27）。リーダーは「攻める側」になれる。
- 中スタック (P2, P3) は最も premium が高い → 大スタック相手とブツかると失う $EV が大きい。
- ショート (P4) はリーダーよりは premium 高いが、中スタックよりは低い。チップを失っても元々失うものが少ないため。

## MTT バブル（n=10、Top 6 払い、6 人入賞）

スタック分布次第だが、典型例（3000/2500/2000/1500/1000/800/600/400/200/100）でのチップ%中位 (P5) の平均 premium:

```bash
python scripts/icm_calc.py --preset bubble-mtt-tight --bubble-factor 4
```

P5 (1000 chip = 8.9%) の各 villain との BF 平均: **約 1.34**

→ ICM 補正 ≈ **0.34**

MTT バブルは STT バブルほど premium 高くない（賞金分布が緩いため）。

## ファイナルテーブル進行（FT）

```bash
python scripts/icm_calc.py --preset ft-9max --bubble-factor 0
```

### FT 9 人スタート（等スタック 10000 each、9-place 30/20/13/10/8/6/5/4/4）

各プレイヤーの平均 ICM 補正: **0.488**

→ 必要 equity 60%、コール頻度を 33% タイトに。

### FT 6 人残り（賞金構造 30/20/13/10/8/6 = 87% pool 残り）

```bash
python scripts/icm_calc.py \
  --stacks "20000,16000,15000,14000,13000,12000" \
  --payouts "30,20,13,10,8,6" \
  --bubble-factor 0
```

平均 BF: 約 1.32〜1.45（リーダー側ほど低い）。

### FT 3-handed

ITM 内の構造に応じて。賞金 50/30/20 の場合（実測）:

| Stack 比 | P1 premium | P2 premium | P3 premium |
| :--- | ---: | ---: | ---: |
| 等分配 (33/33/33) | 0.333 | 0.333 | 0.333 |
| 40/30/30 | 0.225 | 0.319 | 0.319 |
| 50/30/20 | 0.129 | 0.330 | 0.258 |
| 60/25/15 | 0.066 | 0.385 | 0.247 |

**観察**: リーダー (P1) が大きくなるほど **リーダーの premium は急降下**（攻める側に回れる）。中スタック (P2) の premium は安定して 0.33 付近で高い。最ショート (P3) の premium は意外に低い（失うものが少ないため、コミット閾値が低い）。

「**リーダー = 攻撃、中スタック = 守備、ショート = 諦めの覚悟」**という非対称性。

### HU

50/30 賞金で、どんな chip 分布でも premium = **0.000**。

ICM が線形のため、Chip EV と $EV が等価。HU では伝統的なポーカー戦略をそのまま適用できる。

---

## 戦術指針：必要 equity = BF / (BF + 1)

オールイン勝負時の最低必要 equity は、Chip EV のような 50% ではなく、

\[
\text{必要 equity} = \frac{\text{BF}}{\text{BF} + 1}
\]

| BF | 必要 equity | 該当ハンドの目安（vs random） |
| ---: | ---: | :--- |
| 1.0 | 50% | 任意の正の equity（A2o ≈ 53%） |
| 1.2 | 55% | A8o, KQo |
| 1.5 | 60% | AT, KQs, 88 |
| 2.0 | 67% | AJ, AQ, JJ |
| 2.5 | 71% | KK, AKs |
| 3.0 | 75% | AA, KK |

これは「ATC（任意の手）」相手の場合。実際の opponent push range を絞れば、必要 equity は変わる（後手スコア計算で別途扱う）。
