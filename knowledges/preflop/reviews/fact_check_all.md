## 致命的エラー（★★★）

### エラー1: 第16章 「8.5コンボ」の誤記

**場所**: `src/chapters/16-4bet-all-in.md` / 5ベット対応の節

**問題のある記述**:
```
相手の5ベットオールインレンジ = {QQ+, AK}（8.5 コンボ）
```

**正しくは**:
{QQ+, AK} のコンボ数は以下の通り。

- QQ: 6コンボ
- KK: 6コンボ
- AA: 6コンボ
- AKo: 12コンボ
- AKs: 4コンボ
- 合計: **34コンボ**（自分がQQを持つ場合は31コンボ）

**根拠**:
8.5 という数字は「セットマイニング」の文脈で使われる「ポケットペアがセットになるオッズ = 約8.5対1」から来ている。コンボカウントとは全く異なる概念であり、この文脈での「8.5コンボ」は数学的に意味をなさない。

**影響**:
この誤記を元にEV計算をしている場合、計算結果全体が破綻する可能性がある。5ベットへのコール判断の根拠が数学的に無効になる。

## 重大なエラー（★★）

### エラー2: 第12章 AKo の3ベットスコア計算（コネクターボーナス欠落）

**場所**: `src/chapters/12-3bet-score.md`

**問題のある記述**:
```
AKo: H=14, L=0.5×13=6.5, B=+4 → Score₃ = 14 + 6.5 + 4 = 24.5
```

**正しくは**:
AKo はランク差が1のコネクター（K=13, A=14, 差=1）なので C=+1 が適用される。

```
Score₃ = 14 + 6.5 + 4 + 1 = 25.5
```

**根拠**:
3ベット式 `Score₃ = H + 0.5L + B + S + C − G − R` の C はコネクターボーナス。AKo はコネクターに該当する（A=14とK=13の差は1）。

**影響**:
しきい値との比較で1点の差が生じる。ただし AKo のスコア 25.5 は全ポジションのしきい値（最高23）を大きく超えるため、判断結論は変わらない。

### エラー4: 第5章 クイズ AQs のスコア計算（ギャップボーナス欠落）

**場所**: `src/chapters/05-base-score-formula.md` / クイズ Q1(3)

**問題のある記述**:
```
AQs = 14 + 12 + 2 = 28
```

**正しくは**:
AQs: A=14, Q=12, 差=2 → ギャップ2以内ボーナス +0.5 が適用される。

```
AQs = 14 + 12 + 2（スーテッド）+ 0.5（ギャップ2以内）= 28.5
```

**根拠**:
本書のボーナスルールで「ギャップ2以内（差2〜3）: +0.5」が定義されている。A(14)とQ(12)の差は2であるため、この条件を満たす。

**影響**:
ランク差2のハンドのスコアが系統的に0.5点低く計算される。学習者がAQsや同様のハンドを誤って計算するリスクがある。

### エラー5: 付録B KToのスコア計算（算術エラー）

**場所**: `src/chapters/21-appendix.md` / 付録B スコア早見表

**問題のある記述**:
```
KTo: 13 + 10 + 0.5 = 22.5
```

**正しくは**:
13 + 10 + 0.5 = **23.5**（算術が正しくない。計算式は正しいが合計が誤り）

**根拠**:
単純な算術エラー。13 + 10 = 23、23 + 0.5 = 23.5 である。

**影響**:
スコア23.5であれば MP しきい値22 を超えてオープン、UTG しきい値24 は下回る。スコア22.5と誤記すると MP でのオープン判断（22.5 ≥ 22）も変わらないが、正確な学習の妨げになる。

### エラー6: 第16章 エクイティ値の誤り（JJ vs {QQ+, AK}）

**場所**: `src/chapters/16-4bet-all-in.md`

**問題のある記述**:
```
JJ のエクイティ = 33%
```

**正しくは**:
JJ vs {QQ, KK, AA, AKo, AKs} のエクイティは約 **37%** 程度。

- JJ vs QQ: ~19%
- JJ vs KK: ~19%
- JJ vs AA: ~19%
- JJ vs AKs: ~54%
- JJ vs AKo: ~55%
- コンボ加重平均: 約37%

**根拠**:
標準的なエクイティ計算（Pokerstove/Equilab値）。

**影響**:
「JJはフォールド」という結論は正しいが、エクイティ根拠の数値が不正確。37%でも必要エクイティ（スタック/ポット）を下回る場合が多く結論は変わらない。
