## 検証方針

以下の計算規則に基づいて機械的に再計算し、記載値と照合した。

**基本スコア式（オープン用）**
```
Score = H + L + bonus - penalty
  bonus: ペア+10, スーテッド+2, コネクター(差1)+1, ギャップ2以内(差2or3)+0.5
  penalty: ギャップ3以上(差>=4)-1, 両方9未満(H<9 and L<9)-1
  ペア(H==L)には「両方9未満」ペナルティを適用しない（記載値との整合より）
```

**3betスコア式**
```
Score3 = H + 0.5L + B + S + C - G - R
  B: A含む+3, K含む+2, AK両方+4
  S: スーテッド+2
  C: 差=1 +1, 差=2or3 +0.5
  G: 差>=4 -1 (A含む場合免除)
  R: 両方9未満 -1
  Broadway例外: 両方10以上かつ差3の場合はC+1（KTsのみ適用確認）
```

## 未検証・疑問点

### 疑問点1: Broadway例外の適用範囲が不明確（設計上の曖昧さ）

**場所**: 第12章 本文および問題文の3betスコア定義

**内容**: Broadway例外の定義が「両方がT以上かつ差3の場合はC+1」とある。これはAJsにも適用される条件（A=14>=10, J=11>=10, diff=3）だが、境界⑫のAJsスコアは25.0（Broadway例外なしのC=0.5で計算）であり、適用されていない。

- KTs（境界⑦）: 13+5+2+2+1=23 → Broadway例外 C=+1 適用
- AJs（境界⑫）: 14+5.5+3+2+0.5=25 → Broadway例外なし C=+0.5

**計算の正誤**: AJsスコア25.0自体は計算ミスではなく、Broadway例外を適用しない解釈に基づいた正しい値。もし例外を適用するとAJs=25.5となり、記載値25.0と矛盾する。

**推奨整理**: Broadway例外の適用条件を「KTs固有の特例（K-T間の差3のみ）」と明示するか、「差3かつ両カードが10〜Kの範囲（Aを含まない）」と定義を厳密化する。

### 疑問点2: 第12章本文のC・G定義と問題文定義の表記差

**場所**: 第12章本文vs問題文

**内容**:
- 第12章本文: `C: 差=1 +1、差=2 +0.5`、`G: 差=3以上 -1`
- 問題文: `C: 差=1 +1、差=2 or 3 +0.5`、`G: 差>=4 -1`

付録Dの「ギャップ=差-1」の定義から解釈すると、「ギャップ3以上=差>=4」になるため、両者は同じ意味。しかし第12章の表記「差=2」は差=3のケースを明示していないため、読者が混乱する可能性がある。記載値（KTs, AJsなど）はいずれも問題文定義で正しく計算されている。

**推奨整理**: 第12章本文のCの定義を「差=1 +1、差=2〜3 +0.5」と明示する。

### 疑問点3: ペアの「両方9未満」ペナルティ適用の明示なし

**場所**: 基本スコア式の定義

**内容**: 44（H=4, L=4）はH<9かつL<9だが、記載スコアは18（=4+4+10、ペナルティなし）。ペアにペナルティを適用すると17になる。ペアには「両方9未満」ペナルティを適用しないとする明示的なルールが本文にない。

**計算の正誤**: 記載値18は計算ミスではなく、ペアにペナルティ非適用のルールに従った値。ただし、このルールが本文に明記されていない。
