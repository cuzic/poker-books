### 2. A5sスコアの計算ミス（第12章）

**第12章 12-5節 例2「A5s（スコア = 21.5）」の計算過程に内部矛盾がある。**

```
14 + 2.5 + 3 + 2 − 1 = 20.5  ←本文中の一次計算結果
```

と書いた直後に

```
14 + 2.5 + 3 + 2 = 21.5（ペナルティを差し引かずに見る場合）
```

と訂正している。ギャップ（差=9）のペナルティ −1 を含めると20.5、除くと21.5と両方が混在している。

本書の他箇所の整合性を確認すると：
- 第8章 8-2節：「A5s の本書スコアは 14 + 5 + 2 − 1 = 20（UTG しきい値24 を下回る）」

つまり第8章では **A5s = 20** と明記している（基本スコア式を適用）。しかし第12章では3betスコア式（H + 0.5L + B + S + C − G − R）を計算しており、文脈は異なる。ただし第12章での計算過程が混乱した記述になっており、読者が誤解しやすい。

さらに付録Bのスコア早見表（基本スコア）では：
- A5s：スコア 20（14+5+2−1）として掲載

これは第8章と一致しており、付録は正確。問題は第12章の記述の混乱にある。

**修正方針**：
- 第12章の例2を書き直し、3betスコア式の計算過程を明確に示す。
- 最終スコアを「20.5」とし、ペナルティを省略した誤計算を削除する。
- 「スコア 21.5」という誤った数字を本文・章末まとめ・ミニクイズ解答から除去する（現在も「A5s=21.5」が章末まとめに残っている）。

### 3. A9oのEV差：「−0.49bb/手」と「−49bb/100」の混用

| 章 | 記述 |
|----|------|
| 第1章 1-2節 | 「**約0.49bb/手**の期待値差が発生します。1,000手プレイすれば**約49bb**の差」 |
| 第1章まとめ | 「境界ハンドの1つの判断差が、1,000手あたり49bbの差を生む」 |
| 第4章 4-3節 | 「特に A9o は、第1章で触れた通り **-0.49bb/手**（1,000手で -49bb）の損失」 |
| 第4章 GTOとのズレ | 「弱い Ax を UTG から −49 bb/100」 |
| 付録C Q2 | 「A9o の UTG オープンは約 49bb/100 の損失」 |

「bb/手（per hand）」と「bb/100（per 100 hands）」が混在している。  
- 0.49bb/手 × 1,000手 = 490bb  
- -49bb/100 × 1,000手 = -490bb  

どちらで書いても1,000手で490bb（≠49bb）になるため、**数字自体に矛盾がある**。正確には：
- 0.49bb/手 × 100手 = 49bb/100 →「100手で49bb」
- 0.49bb/手 × 1,000手 = 490bb/1,000手

第1章の「1,000手プレイすれば約49bbの差」は計算が合わない。正しくは「100手あたり49bb」か「1,000手で490bb」のどちらか。

**修正方針**：
- 「0.49bb/手」を正とすれば「100手あたり約49bb」に修正する。
- 第1章の「1,000手プレイすれば**約49bb**」→「**約490bb**」に修正するか、「1,000手あたり」の言及を「100手あたり」に変更する。
- 全章で「49bb/100」に統一し、「1,000手」への言及を「100手」に修正する。

### 13. AQsスコアの不整合（付録B）

付録Bに「AQs：28.5（14+12+2+0.5）」と記載されている。  
基本スコア式では：H=14、L=12、差=2（ギャップ2以内）→ +0.5。スーテッド +2。  
14 + 12 + 2 + 0.5 = **28.5** ✓

第18章Q1では「AQs：14 + 12 + 2 = **28**」と計算しており、ギャップボーナス +0.5 を省略している。

**これは計算ミス。** AQsの差は 14−12=2 なので「ギャップ2以内（差2〜3）」に該当し、+0.5が適用される。

| 章 | 記述 | 正否 |
|----|------|------|
| 第18章 Q1解答 | 「14 + 12 + 2 = **28**」 | **誤り**（+0.5が抜けている） |
| 付録B | 「28.5（14+12+2+0.5）」 | 正しい |
| 第7章 問1の選択肢 | 「AQs（スコア = 28）」 | **誤り** |
| 第19章 練習リスト解答例 | AQsの具体計算なし | 要確認 |

さらに第8章の冒頭まとめで「過大評価ハンド：AJo、KQo、QJs」とあるが、AQsについては言及なし。AQs=28.5ならUTGしきい値24を大幅に超えており、問題なし。

**修正方針**：
- 第18章Q1の解答を「28.5」に修正し、計算式を「14 + 12 + 2 + 0.5 = 28.5」に直す。
- 第7章問1の選択肢「AQs（スコア = 28）」を「28.5」に修正。
