### 問題1：第18章 Q9の3betスコア計算に不整合がある ★★★

**詳細**:  
Q9（CO オープン 2.5bb、BTN で A5s）の解答で、3betスコアの計算が次のように示されている。

```
3betスコア：14 + 2.5 + 3 + 2 = 21.5
```

この計算は明らかに誤りである。3betスコア式は `Score₃ = H + 0.5L + B + S + C − G − R` であるが、ここで「0.5L = 0.5 × 5 = 2.5」として計算しているのは正しい。しかし `C`（コネクター）の適用が欠落しており、`G`（ギャップ3以上）と `R`（両方9未満）の処理も記載がない。

A5s の正確な計算は次のようになる。

```
H=14, L=5, ギャップ=9（差8）→ ギャップ3以上: G=−1
スーテッド: S=+2
コネクター（差8）: 非該当, C=0
両方9未満（5は9未満だが14は該当なし）: R=0

Score₃ = 14 + 2.5 + 3（Aブロッカー）+ 2（S）+ 0 − 1（G）− 0 = 20.5
```

本問の解答「21.5」と付録B・第19章チートシートの記載とも整合しない。

**影響**: 読者が計算式を正しく適用できない。試験的な問題集で計算手順が追えないのは致命的欠陥。

**該当箇所**: 第18章 Q9（183行目）

### 問題2：第18章 Q11のA9o 3betスコア計算が不整合 ★★★

**詳細**:  
Q11（BTN オープン 2.5bb、SB で A9o）の計算：

```
A9o の 3betスコア = 14 + 4.5 + 3 = 21.5
```

`0.5 × 9 = 4.5` は正しいが、ギャップ（差 = 5）の扱いが消えている。差が5なのでギャップ3以上に該当し、`G = −1` を適用すべき。正確な計算は次の通り。

```
H=14, L=9, ギャップ=5（差5）→ G=−1
スーテッド: 非該当, S=0
コネクター: 非該当, C=0
Aブロッカー: B=+3

Score₃ = 14 + 4.5 + 3 + 0 + 0 − 1 − 0 = 20.5
```

しきい値18（対BTN）は超えているので「3ベット」という結論自体は変わらないが、計算過程が追えない。

**影響**: 読者が「Gペナルティを無視してよい」と誤学習するリスク。

**該当箇所**: 第18章 Q11（213行目）

### 問題3：第18章 Q14のAKs 3betスコア計算が誤り ★★★

**詳細**:  
Q14（UTG オープン 3bb、CO で AKs）の計算：

```
AKs の 3betスコア = 14 + 6.5 + 4 + 2 + 1 = 27.5
```

この計算は `0.5 × 13 = 6.5`（L=K=13）、AK両方ブロッカー `B=+4`、スーテッド `S=+2`、コネクター `C=+1` として組み立てており、これ自体は正しいように見える。しかし「ギャップ=0（差1）」なので `G=0`、「両方9未満ではない」ので `R=0`、これらの「0」であることを明示しないまま合計している。

より大きな問題は、Q20解答例で「AKo は 3betスコア = 24.5」と記されている点だ。AKo の場合はスーテッドがなく（S=0）コネクター適用（差1なのでC=+1）で `14 + 6.5 + 4 + 0 + 1 = 25.5` となるはずだが、Q14の計算と照合しても値が揃わない。

第12章に示した式の`B`の扱いが「AK両方 +4」なら Q14の27.5 は式通りだが、Q20での「24.5」は `14 + 6.5 + 4 = 24.5`（スーテッド `S` とコネクター `C` を落とした計算）であり、**同じ本文内での計算基準がブレている**。

**影響**: 本書で最も重要な3betスコア式の信頼性が崩れる。

**該当箇所**: 第18章 Q14（265行目）、Q20解答例（368行目）

### 問題5：第18章 Q8のセットマイニング計算で「コール額」の定義が揺れる ★★

**詳細**:  
Q8（UTG オープン 2.5bb、BB で 22）の解答：

```
コール額 1.5bb（差額）、25倍ルール（OOPなので）→ 1.5 × 25 = 37.5bb
```

ここでは BB が 1bb 既に出しているため「追加コール額 = 1.5bb」として計算している。しかし第11章のセットマイニング式では「コール額」が追加コール額なのか全コール額（2.5bb）なのかが明示されていない可能性がある。Q16（CO で 44）では同じ状況で「コール額 2.5bb × 15 = 37.5bb」としており、BB の 1bb 差引きを行っていない。

つまり：
- Q8（BB）: コール額 = 1.5bb（差引き後）× 25 = 37.5bb
- Q16（CO）: コール額 = 2.5bb × 15 = 37.5bb

両者は結果的に同じ値だが、コール額の定義が異なる。読者が混乱する。

**影響**: セットマイニング判断を誤るリスク。BBからのセットマイニングが過度に緩くなる。

**該当箇所**: 第18章 Q8（163行目）、Q16（299行目）

### 問題6：第19章チートシートのボーナス定義が本文と微妙に異なる ★★

**詳細**:


**影響**: チートシート単体を参照する読者が計算を誤る。特にスーテッドコネクター以外のコネクター（オフスーツ差1ハンド）の扱いが混乱する。

### 問題12：付録Bのスーテッドコネクター系でギャップペナルティの適用が一部不明瞭 ★★

**詳細**:  
付録Bで A5s の計算は「14+5+2−1 = 20」と示されている。差が 9（14−5）なのでギャップ3以上（−1）が適用される。

しかし A9s の計算は「14+9+2−1 = 24」。差が 5（14−9）なのでギャップ3以上（−1）が適用されている。これは正しい。

ところが ATs の計算は「14+10+2−1 = 25」。差が 4（14−10）なのでギャップ3以上（−1）が適用されている。しかし「ギャップ2以内（差2〜3）に +0.5」との分岐がここには適用されていない。差4はギャップ3以上に該当し正しいが、第18章の Q5で「AJo: 14+11+0.5 = 25.5」とギャップ2以内ボーナスが適用されている（差2）のに対し、付録Bの ATs（差4）との比較が読者に直感的に分かりにくい。

より問題なのは、付録B内の AQs 計算「14+12+2+0.5 = 28.5」において、AQs の差は 2（14−12）なのでギャップ2以内ボーナス +0.5 が適用されているが、ここに「コネクターボーナス+1は適用されない（差1でないから）」という説明が付加されていない。一方 AKs は「14+13+2+1 = 30」と差1のコネクターボーナスが適用されている。この「コネクター(+1) vs ギャップ2以内(+0.5)」の境界が一覧表だけでは読み取りにくい。

**影響**: スコア計算の習得に不必要な混乱を生じさせる。

**該当箇所**: 付録B

## 改善提案

### 1.【優先度：高】第18章の3betスコア計算を全問見直して統一する

Q9、Q11、Q14、Q20の計算式表示を統一し、すべてのテンプレートを「H + 0.5L + B + S + C − G − R」の形式で丁寧に展開する。計算の途中を省略しない。

特に G（ギャップペナルティ）と R（両方9未満ペナルティ）は「0だから省略」するのではなく、「G=0、R=0」と明示することで式の構造が伝わる。

### 2.【優先度：高】付録B（169ハンドスコア早見表）のA7sとA6sを追加し、付録Aとの整合を取る

現状 A8s と A5s の間が欠落している。「A7s（スコア22、MP〜）」「A6s（スコア21、MP〜またはCO〜）」を明記する。付録Aの CO 欄の「A7s〜A2s」も実際の境界に合わせて修正する。

### 3.【優先度：高】付録Dの「ローラー」を「ニット（Nit）」に差し替える
