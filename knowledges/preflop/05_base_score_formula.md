# 05: 基本スコア式の実装と検証

検索日: 2026-04-19

## 概要

本書の中核となる「基本スコア式」を検証するための調査結果。Chenフォーミュラ・Sklanskyグループ・現代GTOレンジとの比較により、本書式の妥当性と境界問題を整理する。

---

## 1. スコア式の全体像と設計意図

### 本書のスコア式

```
Score = H + L + ボーナス − ペナルティ

H: 高い方のカード（A=14, K=13, Q=12, J=11, T=10, ..., 2=2）
L: 低い方のカード

ボーナス:
  - ペア:           +10
  - スーテッド:     +2
  - コネクター(差0): +1
  - ギャップ2以内:  +0.5

ペナルティ:
  - ギャップ3以上:  −1
  - 両方9未満:      −1
```

### ポジション別しきい値

| ポジション | 最低スコア |
|-----------|-----------|
| UTG       | 24        |
| MP        | 22        |
| CO        | 20        |
| BTN       | 18        |
| SB        | 20        |

### 設計思想

- H+L という「足し算だけ」で済む暗算しやすさを最優先
- スーテッドとコネクターを段階的なボーナスで評価
- 「両方9未満」ペナルティで小さいカード同士の弱さを捕捉
- ギャップペナルティでブロードウェイオフスーツの過大評価を防止

## 3. 10例題の詳細計算

### 例1: AKs（スコア = 29 または 30）

```
H = 14（A）
L = 13（K）
スーテッド: +2
コネクター(差1): +1
14 + 13 + 2 + 1 = 30
```

**GTO評価**: Sklanskyグループ1。全ポジションでオープン。プレミアムハンド。現代GTOでUTG開始率10.1%のレンジに含まれる最強のスーテッドハンド。本書スコア30は最高クラスに位置し妥当。

出典: [Sklansky Groups - ThePokerBank](https://www.thepokerbank.com/strategy/basic/starting-hand-selection/sklansky-groups/)

---

### 例2: AA（スコア = 38）

```
H = 14（A）
L = 14（A、ペア扱い）
ペアボーナス: +10
14 + 14 + 10 = 38
```

**GTO評価**: Sklanskyグループ1。最強ハンド。EV = 2.32（実戦データベース）。6人テーブルで約49.5%の勝率。本書スコア最高値。

出典: [Texas hold'em starting hands - Wikipedia](https://en.wikipedia.org/wiki/Texas_hold_%27em_starting_hands)

---

### 例3: 77（スコア = 24）

```
H = 7
L = 7（ペア）
ペアボーナス: +10
7 + 7 + 10 = 24
```

**GTO評価**: Sklanskyグループ5。UTGしきい値ちょうどの設計。実際のGTO 6maxレンジでは77はUTGから開く。66はHJから開始。この境界（77=UTG、66=HJ）が本書しきい値UTG≥24と一致する点は意図的な設計。

出典: [Preflop Range Morphology - GTO Wizard](https://blog.gtowizard.com/preflop-range-morphology/)

---

### 例4: 22（スコア = 14）

```
H = 2
L = 2（ペア）
ペアボーナス: +10
2 + 2 + 10 = 14
```

**GTO評価**: Sklanskyグループ7。BTN以降でのみ開くのが標準。22-55はBTNから開始がGTO的に妥当。本書BTN≥18のしきい値に対してスコア14は大幅に下回り、BTNでも「開かない」と判定される。

**乖離注意**: GTOではBTNで22はオープン対象だが、本書スコア14 < BTN閾値18のため「フォールド」と判定される。小さいペアを過小評価している可能性。

出典: [GTO Opening Ranges - Pokerati](https://pokerati.com/poker-preflop-charts/)

---

### 例5: AJo（スコア = 25）

```
H = 14（A）
L = 11（J）
ギャップ = 2: ボーナスなし（差2は+0.5のみ）

正確な計算:
差 = 14 - 11 - 1 = 2（J-Q-Kを挟む）
→ ギャップ2なので +0.5
14 + 11 + 0.5 = 25.5 → 25（切り捨て）
```

**GTO評価**: Sklanskyグループ4。COからオープンが標準。本書スコア25 ≥ CO閾値20なのでCOオープンOK、MP閾値22も超えるのでMP開可。本書ではUTG閾値24と比べて25なのでUTGでもオープンとなるが、GTO的にはUTGはやや広い。

**乖離**: GTOではAJoはUTGでは通常フォールド。本書がAJoをUTG開可とするのはやや積極的すぎる可能性。

出典: [GTO Open Raising Strategies - 888 Poker](https://www.888poker.com/magazine/strategy/gto-opening-raising-strategy)

---

### 例6: A9o（スコア = 23）

```
H = 14（A）
L = 9
差 = 14 - 9 - 1 = 4 → ギャップ3以上: −1
14 + 9 − 1 = 22

両方9未満？ → Aは9以上、9は9以上（境界）→ペナルティなし

実際: A=14, 9=9。「両方9未満」ではないのでペナルティなし
最終: 14 + 9 − 1(ギャップ4) = 22
```

**追記**: 式の「ギャップ3以上: −1」が適用される。AとJの差はA=14, J=11、差=3（ギャップ2）。AとKの差は1（コネクター）。A-9はギャップ=4。

A9oの正確計算:
- H=14, L=9
- ギャップ = (14-9-1) = 4 → ペナルティ −1
- 両9未満? → 9=9（境界）、14>9 → 少なくとも一方は9以上 → ペナルティなし
- Score = 14 + 9 − 1 = 22（MP閾値ちょうど）

**GTO評価**: Sklanskyグループ8（かなり弱い評価）。GTOではA9oはHJ-CO域で開く。本書スコア22はMP閾値22に一致→MPオープンOKの判定。GTOと概ね整合。

出典: [Texas hold'em starting hands - Wikipedia](https://en.wikipedia.org/wiki/Texas_hold_%27em_starting_hands)

---

### 例7: KTs（スコア = 25）

```
H = 13（K）
L = 10（T）
スーテッド: +2
ギャップ = 13 - 10 - 1 = 2 → +0.5
13 + 10 + 2 + 0.5 = 25.5 → 25
```

**GTO評価**: Sklanskyグループ4。UTGから開くのが標準（6max GTO範囲に含まれる）。本書スコア25 ≥ UTG閾値24 → UTGオープンOK。GTOと整合。

---

### 例8: QJs（スコア = 25）

```
H = 12（Q）
L = 11（J）
スーテッド: +2
コネクター(差1): +1
12 + 11 + 2 + 1 = 26
```

**GTO評価**: Sklanskyグループ3。GTOでは主にCO以降でオープン（HJで混合）。本書スコア26 ≥ UTG閾値24 → UTGでもオープン可の判定。GTOより若干広い開き方になる。

**乖離**: QJsのUTGオープンはGTO的には疑問あり。HJ以降が適切。本書スコアでは過大評価気味。

---

### 例9: T9s（スコア = 21）

```
H = 10（T）
L = 9
スーテッド: +2
コネクター(差1): +1
両9未満? → T=10（9以上）、9=9（9以上）→ ペナルティなし
10 + 9 + 2 + 1 = 22
```

**追記**: 「両方9未満」ペナルティはT-9には適用されない。スコア = 22。

GTOレンジでは「UTG 10.1%レンジにT9sが含まれる」との情報もあるが、多くの資料ではCOからが標準。本書スコア22 < UTG閾値24 → UTGフォールド。CO閾値20を超えるのでCOオープンOK。概ねGTOと整合。

出典: [6max Preflop Charts - Preflop Range Morphology](https://blog.gtowizard.com/preflop-range-morphology/)

---

### 例10: 72o（スコア = 最弱）

```
H = 7
L = 2
ギャップ = 7 - 2 - 1 = 4 → ペナルティ −1
両9未満? → 7 < 9、2 < 9 → ペナルティ −1
7 + 2 − 1 − 1 = 7
```

**GTO評価**: Sklanskyグループ9（最下位グループ）。全ポジションでフォールド。本書スコア7は全しきい値（18〜24）を大幅に下回り一致。

### 例11: 98s

```
H = 9
L = 8
スーテッド: +2
コネクター(差1): +1
両9未満? → 9=9（境界）、8<9 → 「両方9未満」ではない（一方は9）
→ ペナルティなし

9 + 8 + 2 + 1 = 20
```

**GTO評価**: Sklanskyグループ4。COから標準オープン。本書スコア20 = CO閾値20 → COオープン可。GTOと整合。

---

### 例12: K3s

```
H = 13（K）
L = 3
スーテッド: +2
ギャップ = 13 - 3 - 1 = 9 → ペナルティ −1
両9未満? → K=13（9以上）、3<9 → 一方は9以上 → ペナルティなし
13 + 3 + 2 − 1 = 17
```

**GTO評価**: Sklanskyグループ7-8域（非常に弱い）。GTOでは全ポジションでフォールドが基本。本書スコア17 < BTN閾値18 → 全ポジションフォールドの判定。GTOと整合。

## 4. 境界ハンドの微細な問題

### 4-1. 65s：本書式での過小評価

```
65s スコア計算:
H = 6, L = 5
スーテッド: +2
コネクター(差1): +1
両9未満: −1（6 < 9、5 < 9）
6 + 5 + 2 + 1 − 1 = 13
```

**問題**: スコア13はBTN閾値18を大幅に下回り、全ポジションフォールドと判定される。しかし、GTOでは65sはCO以降でオープンが標準。6maxではCO（27%レンジ）に64s以上が含まれる。BTNでは51.3%レンジに75s+が含まれる。

**原因**: 「両方9未満」ペナルティが65s〜54sといったスーテッドコネクターに重くのしかかる。スーテッドコネクターは実際にはポストフロップのナッツメイク力が高く、フォールドエクイティを含めたEVは本書スコアより高い。

**推奨対応**: 65s（スコア13）はBTNに限り例外的にオープン可とする補足ルールを設けるか、「スーテッドコネクター（56s〜89s）はBTNでオープン可」という注釈を加える。

出典: [How to Play 65s - Upswing Poker](https://upswingpoker.com/six-five-suited/)、[GTO CO Range - Pokerati](https://pokerati.com/poker-preflop-charts/)

---

### 4-2. A2s：ブロッカー効果を未反映

```
A2s スコア計算:
H = 14（A）, L = 2
スーテッド: +2
ギャップ = 14 - 2 - 1 = 11 → ペナルティ −1
両9未満: → A=14（9以上） → ペナルティなし
14 + 2 + 2 − 1 = 17
```

**問題**: スコア17 < BTN閾値18 → 全ポジションフォールドの判定。しかしGTOではA2sはUTGから開く（10.1%UTGレンジに含まれる）。

**原因**: A2sはバック
ドア・ナッツフラッシュ・ナッツ（A-high flush）のドロー力に加え、Aという強いブロッカーを持つ。相手のAAやAKへのブロッカー効果でフォールドエクイティを引き出す。本書式はこれを全く評価していない。

**推奨対応**: スーテッドエースの小さいカード（A2s〜A5s）についてはブロッカー補正の注釈を追加。「A2s〜A5sはスコアが低いが、実戦ではCO以降でのオープンを検討してよい」と明記する。

出典: [GTO Opening Strategies - 888 Poker](https://www.888poker.com/magazine/strategy/gto-opening-raising-strategy)

---

### 4-3. AJo：UTGで本書スコアがやや広い

```
AJo スコア計算:
H = 14（A）, L = 11（J）
ギャップ = 14 - 11 - 1 = 2 → +0.5
14 + 11 + 0.5 = 25.5 → 25（切り捨て）
```

**問題**: スコア25 > UTG閾値24 → UTGオープン可の判定。しかし、GTOでは標準的な6maxのUTGレンジにAJoは含まれない（CO以降から）。

**原因**: H+Lの単純和がAとJという大きな数値のため、高スコアを出しやすい。AJoはポストフロップでドミネートされるリスクが高く（KKや他のAXに相手からコールされやすい）、UTGでのEVは低い。

**推奨対応**: 本書ではAJoをUTGボーダーラインとして扱い、「UTGではAJoは混合戦略で、実際にはフォールド気味」という説明を加える。または閾値をUTG≥25に引き上げる選択肢も検討。

出典: [Preflop Range Morphology - GTO Wizard](https://blog.gtowizard.com/preflop-range-morphology/)

---

### 4-4. 22〜44：小ペアのBTNオープン問題

本書スコア: 22=14、33=16、44=18

BTN閾値18に対して22=14、33=16は下回るため「フォールド」と判定されるが、GTOでは22〜55はBTNから開くのが標準。

**推奨対応**: 「小ペア（22〜55）はBTNでは閾値を1段下げてBTN≥16とする」という例外ルールを設けると整合性が改善する。または本書の趣旨として「初心者には小ペアのBTNオープンを省略する」方針を明示する。

---

### 4-5. QJsとJTs：UTGオープン判定

```
QJs: 12+11+2+1 = 26 > UTG閾値24 → UTGオープン可
JTs: 11+10+2+1 = 24 = UTG閾値24 → UTGオープン可
```

**問題**: GTOではQJsはCO〜HJから、JTsはUTGから（一部資料）またはHJから開くのが標準。QJsのUTGオープンはGTO的に広い。

**整合性評価**: JTs=24はUTG判定OKで多くのGTO資料と一致。QJs=26はUTG判定となるが、GTOと一部乖離。

## 5. 既存式との比較

### 5-1. Chenフォーミュラとの比較

Chenフォーミュラ（1990年代、リミットポーカー向け）との対比:

| ハンド | 本書スコア | Chenスコア | 差の方向 |
|--------|----------|-----------|---------|
| AA | 38 | 20 | 本書が比例的に大きい |
| KK | 36 | 16 | 同上 |
| QQ | 34 | 14 | 同上 |
| JJ | 32 | 12 | 同上 |
| TT | 30 | 10 | 同上 |
| 99 | 28 | 9 | 同上 |
| 77 | 24 | 7 | 同上 |
| 22 | 14 | 5 | 本書のペアが相対的に小さい |
| AKs | 30 | 12 | 本書がはるかに大きい |
| AKo | 27 | 10 | 同上 |
| QJs | 26 | 8 | 同上 |
| JTs | 24 | 9 | 同上 |
| T9s | 22 | 8 | 同上 |
| 65s | 13 | 5 | 本書がやや大きい |
| 72o | 7 | −1 | 本書はマイナスにならない |

**Chenフォーミュラの主な違い**:
1. **高カードのスコアが低い**: Aを14ではなく10とし、Kを8と評価。H+Lを加算しないためスーテッドブロードウェイが低く評価される
2. **ペアの評価方法が異なる**: Chenは「ペアは2倍」（AA=20、22=5）。本書は「H+L+10」（AA=38、22=14）
3. **ギャップペナルティが重い**: Chenは4ギャップで−5点。本書は−1のみ
4. **コネクターボーナス条件**: ChenはQ未満の場合のみ+1。本書は差0〜1で常に+1

**現代における評価**: Chenフォーミュラは「今日の専門家はほとんど使用しない。自転車の補助輪のようなもの」（888ポーカー）。ノーリミット・ホールデムのポストフロップ複雑性を反映できていない。

出典: [Chen Formula - 888 Poker](https://www.888poker.com/magazine/strategy/chen-formula)、[Chen Formula - ThePokerBank](https://www.thepokerbank.com/strategy/basic/starting-hand-selection/chen-formula/)

**評価**: グループ1〜4のハンドは本書スコアとポジション閾値がほぼ整合。グループ5〜6の境界（65sなどのスーテッドコネクター、小さいスーテッドエース）で乖離が目立つ。

### 5-3. GTO現代ソルバーとの近似度

GTO Wizardなどの現代ソルバーが示す6max 100bb UTGオープン（約10〜17%）との比較:

**本書式がGTOと一致するハンド**:
- AA〜JJ（全UTGオープン、本書スコア32〜38）✓
- TT〜88（UTGオープン、本書スコア26〜30）✓
- 77（UTGボーダー、本書スコア24）✓
- AKs、AQs、AJs（UTGオープン、本書スコア26〜30）✓
- KJs、JTs（UTGオープン）✓
- KTs（UTGオープン、本書スコア25）✓

**本書式がGTOより広い（過大評価）**:
- QJs（本書UTGオープン可 → GTOではHJ-CO推奨）△
- AJo（本書UTGオープン可 → GTOではCO推奨）△
- A9s（本書UTGオープン可 → GTOでUTGオープンあり）△

**本書式がGTOより狭い（過小評価）**:
- 22〜55（本書BTNフォールド → GTOではBTNオープン）×
- 65s（本書全ポジションフォールド → GTOではCOオープン）×
- A2s〜A4s（本書全ポジションフォールド → GTOではUTGオープン）×

**総評**: プレミアムハンドと中堅ハンドについては高精度で一致。スーテッドコネクターの下位（65s以下）とスモールペア（22〜55）、スーテッドスモールエース（A2s〜A4s）の3カテゴリーで系統的に過小評価が発生する。

## 6. 計算を暗算で回すコツ

### 6-1. H+Lの暗算パターン

**Aがある場合（H=14固定）**:
- A+K = 14+13 = 27（覚える: AKは27ベース）
- A+Q = 14+12 = 26
- A+J = 14+11 = 25
- A+T = 14+10 = 24
- A+9 = 14+9 = 23
- A+2 = 14+2 = 16

**Kがある場合（H=13固定）**:
- K+Q = 13+12 = 25
- K+J = 13+11 = 24
- K+T = 13+10 = 23
- K+9 = 13+9 = 22

**ペアの場合**:
- ペアスコア = カード値×2 + 10
- AA = 28+10 = 38
- 77 = 14+10 = 24（UTGしきい値）
- 22 = 4+10 = 14

### 6-2. ボーナス・ペナルティの2秒判定

判定順序（フロー）:
1. スーテッド? → YES: +2を即加算
2. 差を計算（H-L-1）:
   - 差=0（コネクター）: +1
   - 差=1（ワンギャップ）: +0.5（ほぼ無視可）
   - 差=2（ツーギャップ）: +0.5
   - 差≥3: −1
3. 両方9未満? → YES: −1（中程度・低いコネクターに注意）

**よく使うシナリオの暗算例**:
- スーテッドコネクター: H+L+2+1=H+L+3（スーテッドコネクター補正）
- オフスーツブロードウェイ（AXo）: H+L（ボーナスペナルティがキャンセルしやすい）
- ポケットペア: H×2+10

### 6-3. スーテッド/ギャップ判定を2秒で終わらせる練習

1. カードを見た瞬間に「同じマーク?」（スーテッド判定）
2. 数値の差を引き算（K-T=3、差-1=2がギャップ数）
3. 「9より小さいか?」（ペナルティ判定）

練習ドリル: 以下の5ハンドを3秒以内にスコア計算する
- Q9s → 12+9+2−1(ギャップ2→+0.5)−1(9=境界、9未満ではない) = ?
- 86o → 8+6−1(ギャップ1→実はコネクター?)+0.5−1(両9未満) = ?

## 7. 本書への適用

### 第5章での活用

1. **スコア式の導入**: H+L+ボーナス−ペナルティの順序で解説
2. **10例題**: 上記3節の順序（AA → AKs → 77 → 22 → AJo → A9o → KTs → QJs → T9s → 72o）で段階的に難易度を上げる
3. **暗算フロー**: セクション6の判定順序を図解で示す
4. **境界問題の補足**: スーテッドコネクター（65s以下）と小ペアは例外として脚注に追記

### 注意すべき説明上の問題

- 22〜55のBTNオープンを本書式では不可とするが、実際は可能。「上級者はBTNで小ペアをオープンするが、本書では省略している」と明示が必要
- A2sのUTGオープンを本書式では不可とするが、GTOでは可能。「ブロッカー効果は本書のスコープ外」と説明が必要
- QJsがUTGオープン可能に計算されるが、GTO的には広め。「スコアが閾値を超えても、ポジションに応じて控えめにプレイする選択も正しい」と補足が必要
