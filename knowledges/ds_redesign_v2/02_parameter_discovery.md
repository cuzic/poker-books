  ≥ 40 → CR 検討

  < 20 → フォールド

## ドロー加点 (Rule of 4 / Rule of 2 直接)

```
ドロー加点 (フロップ): アウツ × 4 = Rule of 4 (2 ストリート分の equity)
ドロー加点 (ターン):   アウツ × 2 = Rule of 2 (1 ストリート分)
ドロー加点 (リバー):   0

例:
  FD (9 outs): フロップ +36 / ターン +18 / リバー 0
  OESD (8):    フロップ +32 / ターン +16 / リバー 0
  GS (4):      フロップ +16 / ターン +8 / リバー 0
  FD+OESD (15-2 重複): フロップ +52 / ターン +26 / リバー 0
  BDFD: +5 (固定、Rule of 4 だと過大評価)
  BDSD: +2 (固定)
```

## 後手スコア式 (新スケール)

```
新後手スコア = HandScore + A − C − M

HandScore = 役スコア + ドロー加点 + ブロッカー加点 (上限 100)
A: ドライ +12 / セミ +6 / ウェット 0
C: 33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30 (= (1−MDF) × 50)
M: HU=0 / 3-way=8 / 4-way+=15 (要追加検証)

判定:
  ≥ 40 → CR 検討
  20〜39 → コール
  < 20 → フォールド
```

## 例 (新スケールでの計算例)

### 例1: TPGK (KQ on K72r dry) vs 50% bet (HU)

```
HS = 62 (TPGK 平均 equity)
A = 12 (ドライ)
C = 17 (50%)
M = 0 (HU)

DS = 62 + 12 - 17 - 0 = 57 → CR 検討
```

GTO 実測: 50% bet vs TPGK on dry → CR 36% / Call 64%（混合）→ DS=57 で CR 寄りは整合

### 例2: TPMK (KJ on K72r dry) vs 75% bet

```
HS = 50 (TPMK)
A = 12 (ドライ)
C = 22 (75%)

DS = 50 + 12 - 22 = 40 → CR 検討（境界）
```

GTO 実測: 75% vs TPMK on dry → Call 90.6% / Raise 9.4% → "コール寄り境界" だが境界 ≥40 で CR 判定。
**閾値を ≥45 に上げれば CALL 判定になる** → 微調整余地あり。

### 例3: ハイカード (T9 on K72r dry) vs 75% bet

```
HS = 25 (ハイカード A-high 相当)
A = 12
C = 22

DS = 25 + 12 - 22 = 15 → フォールド
```

GTO 実測: フォールド ✓

## 結論

**equity % ベース新仕様の最適パラメータ:**
- HS = 自分の equity %（vs 典型レンジ）
- A = ドライ +12 / セミ +6 / ウェット 0
- C = (1−MDF) × 50 = 12/17/22/25/30
- M = 0/8/15 (要検証)
- 閾値: R≥40 / 20-39 C / <20 F

**現状一致率: 92.6%（旧 85.2% から大幅改善）**
