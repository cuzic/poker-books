# IP / OOP 非対称性の検証

実施日: 2026-05-05

## 結論: 後手スコア式は IP/OOP 共通で良い（ただし戦略的非対称性は別途）

### 検証データ (Phase1 OOP defender)

```
OOP (BB) が IP (BTN) の CBet に直面したときの挙動:

K72r ドライ (A=12) vs 75% bet (C=22):
  H3 (HS≥65): F 0.0% / C 0.0% / R 100.0%   → CR ✓
  H2 (35-64): F 0.0% / C 56.0% / R 44.0%    → 混合 (CR↗)
  H1 (<35):   F 54.4% / C 43.8% / R 1.9%    → フォールド ✓

新後手スコア予測:
  H3 (HS=70): DS = 70 + 12 - 22 = 60 → CR ✓
  H2 (HS=47): DS = 47 + 12 - 22 = 37 → コール (実測 56% call、CR 44%)
  H1 (HS=28): DS = 28 + 12 - 22 = 18 → フォールド ✓
```

**Phase1 27 cases で 92.6% 一致** → OOP defender は新式と整合。

### IP defender データの不足

検証データ (`phase1/`) は **OOP defender 視点のみ** 含む。
IP defender (BTN がチェックレイズに直面、または OOP のドンクベット直面) のデータは集約データに含まれず。

### 理論的考察

#### 後手スコア式は対称的

```
後手スコア = HandScore + A − C − M

この式は「ベットを受けた側が次にどう動くか」を示す。
IP/OOP どちらも適用可能。
```

#### IP/OOP の戦略的非対称性

| 観点 | IP | OOP |
|---|---|---|
| 後手スコア式 | 同じ | 同じ |
| 情報優位 | 相手の行動を見てから判断 | 先にアクション |
| CR の効果 | OOP がチェックすれば一発 | OOP の CR は IP の CBet を待つ必要 |
| ブラフ余地 | より広い | より狭い |
| コール余地 | より広い (フリーカード可能性) | より狭い |

**これらの非対称性は後手スコアの式では捉えない。** 別の章で扱う:
- 巻④ Ch12 (IP 攻撃) / Ch13 (OOP 応戦) で対称的なフォーマット
- 巻⑤ Ch11 (SB vs BB) で SB OOP の特殊性 (ナッツアドバンテージ非対称)

### 結論

```
後手スコア式: IP/OOP 共通で適用可
非対称性は:
  - 巻⑤ Ch11 (SB vs BB) で扱う
  - レンジ強度の差として A 値に反映済み
  - CR/コールの戦略選択は局面ごとの判断
```

**式自体に補正を加える必要はない**。

ただし以下の追記を巻④ Ch13 (OOP 応戦) に提案:

```
## 13-X IP / OOP の非対称性メモ

後手スコア式 (HS + A − C − M) は IP/OOP 共通で適用できますが、
実戦の戦略選択には以下の非対称性があります:

1. CR の意義
   - OOP CR: IP CBet 後の一発レイズ → 強力
   - IP CR: 通常 OOP は先手ベットしない → 機会少
   - → OOP は CR を中心、IP は コール優先

2. コール余地
   - IP コール: フリーカード可能性、相手の反応見られる
   - OOP コール: 次のストリートでも先手必要
   - → 同じ DS でも IP の方がコール余地広い

3. レンジ強度の反映
   - これは A 値（ボード補正）で部分的に表現
   - SB OOP の特殊性は巻⑤ Ch11 で扱う
```
