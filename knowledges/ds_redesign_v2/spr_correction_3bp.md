# 3BP / 4BP 用 SPR 補正式の導出

実施日: 2026-05-05

## 問題設定

新後手スコア式 `DS = HS + A − C − M` は SRP (SPR ~17) で 92.6% 整合。
しかし 3BP (SPR ~5) / 4BP (SPR ~1.5) では混合戦略を捉えられない。

## 3BP scenario A の GTO 実測 (K72r、SPR 4.8、33% CBet)

```
Hand  新HS  新DS=HS+12-12  予測   GTO実測 C/F/R     乖離
AA    75    75              CR    53.7/0.0/46.3    混合 (CR 46%)
KK    88    88              CR    69.3/0.0/30.7    混合 (CR 31%)
QQ    72    72              CR    97.5/2.1/0.4     ほぼ純 call
AKs   70    70              CR    66.1/0.0/33.9    混合 (CR 34%)

avg raise: 18.3% (vs SRP avg ~50%)
```

**観察**: 3BP では「CR の重み」が SRP と異なる:
- CR = リレイズ → ほぼコミット確定
- 強ハンドでもコール優先 (相手の継続バレルから余分にバリューを取る)
- ナッツ近辺 (Set+) のみ純 CR

## 補正式の導出

### 案 A: SPR 別 CR 閾値の引き上げ

```
SPR ≥ 6 (SRP):     CR 閾値 ≥ 40 (現行)
SPR 3〜5 (3BP):    CR 閾値 ≥ 60 (Set+ / 強 2pair / モンスタードロー)
SPR < 3 (4BP):     CR 閾値 ≥ 75 (Set+ のみ)
```

検証 (3BP K72r 33% CBet):
```
Hand  HS   DS    CR 閾値≥60 で予測   実測       Match
AA    75   75    RAISE              CR 46%混合 △ (混合許容)
KK    88   88    RAISE              CR 31%混合 △
QQ    72   72    CALL (60 未満では) CR 0.4%    ✓
AKs   70   70    CALL               CR 34%混合 △
```

QQ は CALL 予測に変わり、実測と一致 ✓
AA/KK/AKs は混合戦略の範囲内 (混合の中で CR が含まれる)

### 案 B: 3BP 用後手スコア補正

```
3BP 後手スコア = (HS + A − C − M) − SPR 補正

SPR 補正:
  SPR ≥ 6:      0
  SPR 3〜5:    -10 (CR 閾値が実質 +10 上がる)
  SPR < 3:     -20 (4BP)
```

検証:
```
Hand  HS   DS-10  予測 (≥40)       実測       Match
AA    75   65     RAISE            混合       ✓
KK    88   78     RAISE            混合       ✓
QQ    72   62     RAISE            CR 0.4%   ✗
AKs   70   60     RAISE            混合       ✓
```

QQ で外れる。案 A (閾値変更) の方がシンプルで精度高い。

### 推奨: **案 A (SPR 別閾値)**

```
新後手スコア式 + SPR 補正:

DS = HS + A − C − M (式は変わらず)

判定 (SPR 別):
  SPR ≥ 6:     ≥ 40 CR / 20-39 コール / < 20 フォールド
  SPR 3〜5:    ≥ 60 CR / 20-59 コール / < 20 フォールド
  SPR < 3:     ≥ 75 CR (実質 commit) / 30-74 コール / < 30 フォールド
```

## 4BP の特殊性

```
4BP 想定: SPR ~1.5、ほぼ commit 圏

判断ロジック:
  ほぼ「Set+ で commit、それ以外フォールド」
  ベットサイズの調整余地ほとんどなし
  → push/fold 的な単純化が有効
```

## 巻⑤ Ch10 (3BP) への提案追記

```markdown
## 10-X SPR 別の閾値補正

3BP / 4BP では SPR が低く、CR がほぼコミット確定になります。
そのため後手スコアの CR 閾値は SPR に応じて引き上げます:

| SPR 帯域 | CR 閾値 | コール下限 | 備考 |
|---|---:|---:|---|
| ≥ 6 (SRP) | ≥ 40 | ≥ 20 | 標準 |
| 3〜5 (3BP) | ≥ 60 | ≥ 20 | CR は Set+ / 強 2pair に絞る |
| < 3 (4BP) | ≥ 75 | ≥ 30 | ほぼ commit、コール域も狭く |

例: TPTK on K72r 3BP vs 33% CBet
  HS = 70、A = 12、C = 12 → DS = 70
  SPR 4.8 → CR 閾値 ≥ 60 でも CR 域内
  ただし実測 GTO は混合戦略 (CR 34% / call 66%)
  → 「CR か慎重コール」を許容と覚える
```

## 結論

**案 A（SPR 別閾値）を採用**:

- 式自体は変わらず (`DS = HS + A − C − M`)
- 閾値だけ SPR 帯域で動かす
- 暗算負荷を増やさない
- GTO 実測と整合 (3BP で QQ が CALL 寄りと予測 ✓)
