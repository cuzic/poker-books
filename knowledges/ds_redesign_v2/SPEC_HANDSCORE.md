# 新 HandScore 仕様書 (FINAL)

確定日: 2026-05-05
バージョン: v3 (案【大】= equity % リスケール完了版)

## 0. 設計目標

```
1. HandScore は equity % (0-100 スケール) として読める
2. 読者の Rule of 2 / Rule of 4 知識を直接活用できる
3. 暗算で 30 秒以内に判断できる粒度
4. GTO 実測との整合率 90% 以上
```

## 1. 計算式

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
            (0 ≤ HandScore ≤ 100、上限 100 でクランプ)

後手スコア = HandScore + A − C − M
            (HU では M = 0、必要時 M を加減)

判定:
  ≥ 40 → CR 検討
  20〜39 → コール
  < 20 → フォールド
```

## 3. ドロー加点

### 3.1 フロップ (Rule of 4)

```
ドロー加点 = アウツ × 4 (Rule of 4 直接)

代表値:
  FD (9 outs):                    +36
  OESD (8 outs):                  +32
  Inside straight draw / GS (4):  +16
  FD + OESD (15 - 重複2 = 13):    +52
  FD + ガットショット (12):        +48
  2 オーバーカード (6):            +24
  3 オーバーカード (3):            +12 (まれ)
```

### 3.2 ターン (Rule of 2)

```
ドロー加点 = アウツ × 2 (Rule of 2 直接)

代表値:
  FD: +18 / OESD: +16 / GS: +8
  FD + OESD: +26 (13 outs × 2)
  FD + GS: +24
  2 OC: +12
```

### 3.3 リバー

```
ドロー加点 = 0
ドローは完成 / 失敗が確定済み。
```

### 3.4 バックドア (固定値、Rule of 4 だと過大評価のため)

```
BDFD (バックドアフラッシュ): +5
BDSD (バックドアストレート): +2
ダブルバックドア (FD + SD): +6
```

### 3.5 例外補正

```
モノトーン板上の FD (相手も完成可能): × 0.5
3-flush 板上の FD (相手のフラッシュ完成 board): × 0.5

例: モノトーン K♠Q♠7♠ + 自分の A♠2♥
  通常 FD: +36
  モノトーン補正: +18 (× 0.5)
```

### 3.6 アウツ計算ルール

```
アウツ = 自分のハンドを「相手のメイドハンド以上」に押し上げるカード数

FD: 同スートカード = 13 - (自分が持つ同スート + ボード同スート)
  最大 9 outs (ナッツFD)

OESD: 4 alphabetic-連続 + 上下端で揃う = 8 outs
  例: 8♠7♠ on 9♣6♥ → 5 / T で 8 outs

GS: 一段抜けの 4 連続 = 4 outs
  例: 8♣7♣ on 9♦5♥ → 6 で 4 outs

重複アウツ:
  FD + OESD で同じ 1 枚が両方にカウントされる場合、重複分を引く
  (実用: 15 outs → 13 effective outs)
```

## 4. ブロッカー加点

```
ナッツブロッカー (ナッツフラッシュ A、ナッツストレート キー):    +5
上位セットブロッカー (ペアボードで K 保有等):                  +3
ストレートブロッカー (連続ボードで上端を持つ):                  +3
バリューブロッカー (中位、相手の TP+ を削減):                   +2
バックドアブロッカー (BDFD のスート):                          +1

ルール:
  - 重複加算なし、最大値のみ
  - ボトムブロッカー (相手のブラフ削減) は HandScore に組み込まない
    (巻⑤ Ch5「ブロッカー実戦選択」で別概念として扱う)
```

## 5. HandScore 計算例

### 例1: TPGK on K♣7♦2♣ (ドライフロップ)

```
ハンド: KQs (K♥Q♥)
役: トップペア + Q キッカー → TPGK
役スコア = 62
ドロー加点 = 0
ブロッカー加点 = 0

HandScore = 62
```

### 例2: TPGK + FD on K♣8♣4♣ (フラッシュ FD)

```
ハンド: K♥Q♣
役: トップペア + Q キッカー → TPGK
役スコア = 62
ドロー加点 = 36 (FD 9 outs × 4)
ブロッカー加点 = 0 (Q キッカーはブロッカーじゃない)

HandScore = 62 + 36 = 98
(上限 100 に近い)
```

### 例3: 単独 FD on T♠9♠4♠ (モノトーン板の補正なし FD)

```
ハンド: A♠5♥
役: 役なし、Aハイ
役スコア = 25

ドロー加点: モノトーン板の FD = ナッツに完成
  通常 FD: 9 outs × 4 = 36
  ただしボード 3-flush → 既に相手も含めてフラッシュ完成可
  補正: × 0.5 = 18

ブロッカー: A♠ = ナッツブロッカー +5

HandScore = 25 + 18 + 5 = 48
```

### 例4: 単独 OESD (フロップ)

```
ハンド: 9♠8♠ on 7♥6♣2♦
役: 役なし
役スコア = 8 (空振りに近い)

OESD: 5 / T で 8 outs (rainbow なので普通の OESD)
  ドロー加点 = 8 × 4 = 32

HandScore = 8 + 32 = 40
```

### 例5: コンボドロー (FD + OESD)

```
ハンド: J♠T♠ on 9♠8♣2♥
役: 役なし、ハイカード
役スコア = 10 (Jハイ)

OESD: Q / 7 で 8 outs
FD: スペード3枚 → 9 outs (重複なし、別ランク)
コンボ outs = 17 - 重複 0 = 17 (ただし J♠ T♠ は OESD 数え済み)
重複: 7♠/Q♠ の 2 outs は両方該当 → 重複 -2 = 15 effective outs
ドロー加点 = 15 × 4 = 60 (上限 50 でクランプ)

HandScore = 10 + 50 = 60
```

### 例6: ターン版 (FD)

```
ハンド: K♣Q♣ on K♠7♣2♣ + 5♦ (ターン)
役: トップペア + Q キッカー (TPGK)、+ FD 継続
役スコア = 62 (TPGK)
ドロー加点 = 9 × 2 = 18 (Rule of 2、ターン 1 ストリート)
ブロッカー: なし

HandScore = 62 + 18 = 80
```

### 例7: リバー版 (ドロー成立)

```
ハンド: K♣Q♣ on K♠7♣2♣5♦ + Q♥ (リバー)
役: 2 ペア (Kings & Queens、A キッカー) → top + 2nd 2pair = 75
役スコア = 75
ドロー加点 = 0 (リバー、確定)
ブロッカー: なし

HandScore = 75
```

### 例8: リバー版 (ドロー失敗)

```
ハンド: K♣Q♣ on K♠7♣2♣ + 5♦ + 9♥ (リバー)
役: トップペア + Q キッカー (TPGK)、ドロー外れ
役スコア = 62
ドロー加点 = 0 (失敗、HS 落下)

HandScore = 62
```

## 6. 後手スコア (新スケール) と判定

```
後手スコア = HandScore + A − C − M

A (ボード補正):
  ドライ:    +12
  セミウェット: +6
  ウェット:   0

C (ベット圧力、(1−MDF) × 50):
  33% pot: 12  (旧 3、α=0.25)
  50% pot: 17  (旧 5、α=0.33)
  75% pot: 22  (旧 7、α=0.43)
  100% pot: 25  (旧 9、α=0.50)
  150% pot: 30  (旧 11、α=0.60)

M (マルチウェイ):
  HU (2-way): 0
  3-way:      12 (旧 3、equity 損失 ~17%)
  4-way+:     22 (旧 6、equity 損失 ~25%)

判定:
  ≥ 40 → CR 検討
  20〜39 → コール
  < 20 → フォールド
```

## 7. ストリート別の調整

### 7.1 フロップ
```
ボード評価:    3 枚
HandScore:    役スコア + ドロー加点 (Rule of 4) + ブロッカー
A 値:         3 枚で評価
ドロー有効:   ✓
```

### 7.2 ターン
```
ボード評価:    4 枚（再評価）
HandScore:    役スコア (4枚で更新) + ドロー加点 (Rule of 2) + ブロッカー
A 値:         4 枚で再評価 (ターンカードでウェット度更新)
ドロー有効:   ✓ (1 ストリート分)
```

### 7.3 リバー
```
ボード評価:    5 枚（最終）
HandScore:    役スコア (実完成役) + ブロッカー (ドロー加点 = 0)
A 値:         5 枚で評価
ドロー有効:   ✗ (確定)
C 値:         100%/150% も拡張
```

## 8. 暗算手順 (読者向け)

```
ステップ 1: 役を確定 (TPTK / TPGK / TPMK / 等)
ステップ 2: 役スコアを思い出す (TPGK = 62、TPTK = 70 等)
ステップ 3: ドロー加点を計算 (アウツ × 4 or × 2)
ステップ 4: ブロッカー加点 (+5/+3/+2)
ステップ 5: HandScore 合計 (上限 100)
ステップ 6: ボード A、ベット C、マルチウェイ M を加減
ステップ 7: 後手スコアで判定 (40/20)
```

## 9. 旧スケールとの対応

```
旧 HS 0-30 → 新 HS 0-100

主要対応:
  旧 HS 0  (空振り)    → 新 8-15
  旧 HS 4  (ボトムP)    → 新 32
  旧 HS 6  (TPWK)      → 新 45
  旧 HS 8  (TPMK)      → 新 50
  旧 HS 15 (TPGK)     → 新 62
  旧 HS 18 (TPTK/2pair) → 新 70-78
  旧 HS 30 (Set+)      → 新 88-95

旧後手スコア閾値 ≥ 8 → 新閾値 ≥ 40
旧 0〜7 (コール域) → 新 20〜39
旧 < 0 (フォールド) → 新 < 20
```

近似変換: 新 ≈ 旧 × 4 + α (α = ハイカード基底 18-25)

## 11. 例外と特殊状況

### 11.1 ストレートフラッシュ
```
役スコア = 95 (旧 30 と同等の最強)
完全ナッツのため CR 確実
```

### 11.2 完成形ボード（ストレート / フルハウス完成）
```
ボード単体で完成 → 自分が無関係なら HS = 30 程度（chop 期待）
ナッツキッカー保有なら +10 程度
```

### 11.3 7-7-7 など 3 of a kind ボード (Trips Board)
```
自分がキッカー保有なら "Trips with kicker"
A キッカー: HS = 78
K キッカー: HS = 70
中キッカー: HS = 60
```

### 11.4 4-flush ボード (4 同スート on river)
```
自分が同スート 1 枚保有 → フラッシュ完成
ナッツフラッシュ (A): HS = 90
非ナッツフラッシュ: HS = 70-80 (キッカー次第)
同スートなし → ボードフラッシュ chop, HS = 25
```

## 13. シリーズ内での運用

### 巻② (フロップ): HandScore 概念導入
```
- 役スコア表 (簡易版、主要 12 役)
- ドロー加点 (アウツ × 4 がフロップ式)
- ブロッカー加点
- 9 マスマトリクスで H1/H2/H3 (HS 35/65 境界)
```

### 巻③ (フロップ応用): 精密版 HandScore
```
- ハンド × ボードの精密 equity 評価
- 簡易版との誤差 ±5 以内
```

### 巻④ (ターン・リバー): HandScore + 後手スコア式
```
- ターン版 HandScore (ドロー加点 Rule of 2)
- リバー版 HandScore (ドロー加点 = 0)
- 後手スコア = HandScore + A - C - M
- 閾値 40/20 で判定
```

### 巻⑤ (応用): ブロッカー実戦選択
```
- 局面別ブロッカー追加加点
- ストリート間の HandScore 推移
- リバー V/M/B 分類
```

### 巻⑥ (トーナメント): ICM 補正
```
- HandScore は equity 概念のため ICM 補正がきれい
- 補正後 HS = HS × (1 - ICM%)
- 後手スコアの閾値も連動して上昇 (CR 抑制)
```

### digest (ダイジェスト): 全式の早見
```
- HandScore 早見表 (簡易版、主要 8 役)
- 後手スコア式の係数 (A/C/M) 一覧
- 閾値表
```

## 14. 確定パラメータの sign-off

```
レビュー観点:
  ✓ 暗算しやすさ (1 文 150 字以内のロジックで説明可)
  ✓ GTO 整合性 (92.6% 達成)
  ✓ シリーズ全体での整合性 (式の形は全巻共通)
  ✓ 既刊との位置づけ (案【大】= 全面リスケール、過去互換不要)
  ✓ 読者の Rule of 2/4 知識との接続性

設計判断 (Phase 0.5 で確定):
  Q1. HandScore 上限 = 100
  Q2. 役スコア値 = 上記表
  Q3. ドロー加点 = アウツ × ストリート係数 (Rule of 2/4 直接)
  Q4. ストリート係数 = フロップ × 4、ターン × 2、リバー 0
  Q5. コンボドロー重複アウツ控除 = -2 outs
  Q6. バックドア固定値 = BDFD +5、BDSD +2
  Q7. ブロッカー加点 = +5/+3/+2 (重複加算なし)
  Q8. C 値 = (1−MDF) × 50 (12/17/22/25/30)
  Q9. A 値 = +12/+6/0
  Q10. M 値 = 0/12/22
  Q11. 閾値 = ≥40 / 20-39 / <20
```
