# 新 HandScore 仕様 提案書 (Phase 0.5 統合)

実施日: 2026-05-05

Phase 0.5 の調査 #322-#330 の結果を統合し、Phase 1 (#292) で確定すべき
新 HandScore 仕様を提案する。

## ★ 提案の核

```
HandScore = equity %（自分のハンドの推定 equity vs 典型レンジ）
            = 役スコア + ドロー加点 + ブロッカー加点
            (上限 100、下限 0)

後手スコア = HandScore + A − C − M

A: ボード補正 (ナッツアドバンテージ)
C: ベット圧力 ((1−MDF) × 50)
M: マルチウェイ補正

判定:
  ≥ 40 → CR 検討
  20〜39 → コール
  < 20 → フォールド
```

### ドロー加点

```
フロップ (Rule of 4 直接):
  ドロー加点 = アウツ × 4
  
  代表値:
    FD (9 outs):    +36
    OESD (8 outs):  +32
    ガットショット (4 outs): +16
    FD + OESD (15 outs - 重複2 = 13): +52
    FD + ガットショット (12 outs): +48
    2 オーバーカード (6 outs): +24

ターン (Rule of 2 直接):
  ドロー加点 = アウツ × 2
  代表値:
    FD: +18 / OESD: +16 / ガットショット: +8 / FD+OESD: +26

リバー:
  ドロー加点 = 0

バックドア固定:
  BDFD: +5 (アウツベースだと過大評価)
  BDSD: +2

例外 (モノトーン):
  既に相手も完成している場合の FD: × 0.5
```

### ブロッカー加点

```
ナッツブロッカー (ナッツフラッシュ A 等):  +5
上位セットブロッカー / ストレートブロッカー: +3
バリューブロッカー (中位):                   +2

重複加算なし。最大値のみ。
ボトムブロッカー (相手のブラフ削減) は別概念として巻⑤ Ch5 で扱う。
```

## ストリート別の式

### フロップ
```
HandScore = 役スコア + ドロー加点 (Rule of 4) + ブロッカー加点
後手スコア = HandScore + A − C − M
```

### ターン
```
HandScore = 役スコア (4枚ボードで再評価) + ドロー加点 (Rule of 2) + ブロッカー加点
後手スコア = HandScore + A − C − M

A 値の再評価: ターンカードでウェット度更新
```

### リバー
```
HandScore = 役スコア (5枚ボードで実完成役) + ブロッカー加点 (ドロー加点 = 0)
後手スコア = HandScore + A − C
M はリバーでマルチウェイの場合のみ

C 値: 33%/50%/75%/100%/150% フル対応 (オーバーベット含む)
```

## 計算例

### 例1: TPGK (KQ on K72r dry) vs 50% bet (HU)

```
HS = 62 (TPGK)
A = 12 (ドライ)
C = 17 (50% pot)
M = 0 (HU)

DS = 62 + 12 - 17 = 57 → CR 検討
```

GTO 実測: 50% bet vs TPGK on dry → CR 36% / Call 64% (混合) → "CR 寄り境界" 整合

### 例2: TPGK + FD (KQs on K78s) vs 50% bet (HU)

```
役スコア = 62 (TPGK)
ドロー加点 = 36 (FD on flop)
HandScore = min(98, 100) = 98

A = 6 (セミウェット)
C = 17

DS = 98 + 6 - 17 = 87 → CR 強推奨
```

### 例3: 単独 OESD (J9 on T84r flop) vs 33% bet

```
役スコア = 0 (役なし)
ドロー加点 = 32 (OESD)
HandScore = 32

A = 6 (セミ T84r)
C = 12

DS = 32 + 6 - 12 = 26 → コール
```

GTO 実測: OESD は 99.9% で CR or call 強い → 整合

### 例4: TPMK (KJ on K72r dry) vs 75% bet (HU)

```
HS = 50
A = 12
C = 22
M = 0

DS = 50 + 12 - 22 = 40 → CR 境界
```

GTO 実測: 90.6% コール / 9.4% CR → 境界判定の "CR 寄り" は曖昧。

### 例5: ハイカード (T9 on K72r dry) vs 75% bet

```
HS = 25 (役なし、A-high なし)
A = 12
C = 22

DS = 25 + 12 - 22 = 15 → フォールド
```

GTO 実測: フォールド寄り ✓

### 例6: AA 4-way K-T-6 (semi) vs 75% pot

```
HS = 75 (オーバーペア)
A = 6
C = 22
M = 22 (4-way+)

DS = 75 + 6 - 22 - 22 = 37 → コール
```

Galfond 分析: 4-way AA は CR 抑制でコール → 整合 ✓

### 例7: ナッツフラッシュ (Aハイ) on monotone river vs 100% pot

```
HS = 88 (フラッシュ) + 5 (ナッツブロッカー A) = 93
A = 0 (ウェット完成)
C = 25 (100%)

DS = 93 + 0 - 25 = 68 → CR 強推奨
```

実戦: ナッツフラッシュは CR or オーバーベットで最大バリュー狙い ✓

## 旧式との互換変換

```
新 HS ≈ 旧 HS × 4 + 25 (ハイカード補正)

例:
  旧 TPTK 18 → 新 18 × 4 = 72 ≈ 70 ✓
  旧 TPGK 15 → 60 ✓
  旧 TPMK 8 → 32 + 18 ≈ 50 ✓
  旧 ハイカード 0 → 25 ✓
```

これは厳密な linear transformation ではないが、概ねの目安。

## 暗算しやすさの評価

```
読者が:
1. アウツ数を数える (例: FD = 9 outs)
2. Rule of 4 / Rule of 2 を当てる:
   フロップなら × 4 = 36 (FD ドロー加点)
   ターンなら × 2 = 18
3. 役スコアを思い出す (TPGK = 62 (≈65% equity))
4. HandScore = 役スコア + ドロー加点 + ブロッカー加点
5. A/C/M を加減
6. 閾値 (40/20) で判定

メリット:
  - HandScore の数値が equity % と一致 (直感的)
  - Rule of 2/4 の知識を直接活用
  - 暗算ステップは旧スケールと同じ
```
