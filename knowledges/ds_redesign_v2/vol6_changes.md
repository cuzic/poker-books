## 2. ICM 補正の処理方法（最重要）

旧式（巻⑤ までキャッシュ）:

```
後手スコア = HandScore (0-30) + A − 3 − C − M
判定: ≥ 8 → CR、0〜7 → コール、< 0 → フォールド
ICM 補正後 = 後手スコア − (p × 5)
```

新式（本書 第19章）:

```
後手スコア = HandScore (0-100 equity %) + A − C − M
判定: ≥ 40 → CR、20〜39 → コール、< 20 → フォールド
ICM 補正後 = 後手スコア − (p × 20)
```

**スケール係数**: 旧 `p × 5` → 新 `p × 20`（× 4 倍、HS スケール拡大に整合）。

ICM 補正ステージ別の最低ライン:

| ICM 補正 | 旧最低 | 新最低 |
|---:|---:|---:|
| 0.00 | 0 | **20** |
| 0.20 | 1 | **24** |
| 0.40 | 2 | **28** |
| 0.50 | 3 | **30** |
| 0.875 | 4 | **38** |

「巻⑤ ICM 補正後 = HS × (1 − ICM%)」という形は本巻では採用せず、補正項減算方式（仕様書通り）で統一。

## 4. ドリル 53 問のうち判定変化数

| ドリル区分 | 数値判定式を含む問題数 | 判定変化数 |
|---|---:|---:|
| Q1〜Q15（プリフロップ・push/fold） | 0（HS / 後手スコア参照なし） | 0 |
| Q16〜Q35（ICM 計算 / Score 系） | 0（数値そのものが ICM equity / Score で旧スケール影響なし） | 0 |
| Q36 後手スコア + ICM | 1 | **1**（数値式は更新、判定 = フォールドは不変） |
| Q37 Score | 1 | 0（Score は旧スケールのまま） |
| Q38 リバー後手スコア + ICM | 1 | **1**（数値式は更新、判定 = フォールドは不変） |
| Q39〜Q53 | 0（後手スコアの直接参照なし） | 0 |

**結論**: ドリル全 53 問のうち 後手スコア / HandScore を直接計算する問題は **2 問のみ**。両問とも数値を新スケールに置換したが、最終判定（フォールド / コール）は両問とも変化なし。これは「ICM 補正下では境界ハンドはフォールド」という結論が新旧スケール両方で同じ結論に至るため。
