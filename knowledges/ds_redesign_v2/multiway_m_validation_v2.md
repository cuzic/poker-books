# M 値 (マルチウェイ補正) 検証 v2

実施日: 2026-05-05

## 結論: M = 12 (3-way) / 22 (4-way+) は妥当

GTO Wizard/Upswing/Galfond の公開データと整合。微調整不要。

## 検証根拠

### 1. エクイティ低下原則 (Upswing/Pokertube)

**「プレイヤーごとに約 12% のエクイティ低下」** — 経験則として広く流通。

```
AK 対ランダム:
  HU (2人):  65%
  3-way:     50%   (HU から -15)
  4-way:     40%   (HU から -25)

AA 対ランダム:
  HU:        85%
  3-way:     73%   (HU から -12)
  4-way:     64%   (HU から -21)

平均低下: 3-way で約 -12〜-15 / 4-way で約 -21〜-25
```

**M=12 (3-way) / M=22 (4-way+) と完全一致** ✓

### 2. Galfond ケーススタディ (4-way K-T-6 で AA)

> 「誰かがトップペア以上を持つ確率は 69%」
> 「AA で 75%pot ベットして 1 回コールされただけで約 40% の確率でビート済み」

新後手スコアでの予測:

```
AA on K-T-6 (overpair to T、ただし K がボードにあり):
  HS = ~70 (overpair)
  A = 0 (KT6 はセミウェット)
  C = 22 (75% pot)
  M = 22 (4-way)
  DS = 70 + 0 − 22 − 22 = 26 → コール

判定: 26 (20-39 帯) → コール
実測: 40% の確率でビート済 → CR は危険、コール推奨
→ 一致 ✓
```

### 3. CBet 頻度の激減 (GTO Wizard)

> 「ポットサイズの CBet」はマルチウェイで 18% → 1.3% に激減

新後手スコアでの含意:

```
攻撃側 (バレル/CBet) は本式の対象外だが、
M 値の大きさは「マルチウェイで CR 域に入るハンドが激減する」ことを示唆

3-way M=12: CR 閾値 ≥ 40 を実質的に ≥ 52 に引き上げ
4-way M=22: CR 閾値 ≥ 40 を実質的に ≥ 62 に引き上げ
→ Set+/Top 2pair 以上のみ CR
→ 実測 (大ベットは Nut 比率高いときのみ) と整合 ✓
```

### 4. Brokos「スモールペアはマルチウェイで優良」

```
スモールペア (HS=35-45):
  3-way DS = 40 + 12 (dry) − 12 (33% bet) − 12 = 28 → コール
  4-way DS = 40 + 12 − 12 − 22 = 18 → フォールド境界

→ マルチウェイでは「セットヒット狙い」が中心
→ ペア単発ではフォールド
→ Brokos の「セット引き目当て」と整合 ✓
```

### 5. AQo/KQo の劣化 (Upswing)

> 「AQo はマルチウェイでプレイすべきでない」
> 「KQo の TPMK はマルチウェイで逆選択を起こす」

新後手スコア予測 (TPMK on Q-high board, M=12 で 3-way):

```
KQo TPMK on Q-7-2:
  HS = 50 (TPMK)
  A = 12 (Q72 dry)
  C = 12 (33% bet)
  M = 12 (3-way)
  DS = 50 + 12 − 12 − 12 = 38 → コール (CR 域外)

→ ヘッズアップでは DS = 50 → CR 域、3-way では 38 でコール
→ TPMK の価値低下が反映されている ✓
```

## M 値の数値妥当性

```
| プレイヤー数 | エクイティ低下 (実測) | M 値 (式) | 整合性 |
|---|---|---|---|
| 2 (HU)      | 0%        | 0    | ✓ baseline |
| 3 (3-way)   | -12〜-15% | 12   | ✓ |
| 4 (4-way)   | -21〜-25% | 22   | ✓ |
| 5+          | -28%以上  | 22   | △ (4-way+ で固定、十分タイト化) |
```

## 微調整は不要

```
案 1: M = {0, 10, 20}     → equity 低下と乖離 (12〜15 が中央値)
案 2: M = {0, 12, 22}     → equity 低下と一致 ✓ (現行)
案 3: M = {0, 15, 25}     → やや過剰補正 (3-way で TPGK までフォールドに)
```

**現行 M = {0, 12, 22} を採用**。

## 5+ way の扱い

```
5+ way は実測データほぼなし、書籍読者層では稀
→ 4-way+ で M=22 一律として簡略化 (現行通り)

```
