# 他の暗算式の新仕様書

確定日: 2026-05-05
バージョン: v3 (新スケール対応)

新 HandScore (0-100 equity %) 仕様に対応した、他の暗算式 (後手スコア / 先手スコア / バレルスコア / α 式) の確定値。

## 1. 後手スコア式

### 1.1 形式

```
後手スコア = HandScore + A − C − M
```

旧式の "− 3" (ベースライン補正) は新式では A 値に吸収。

### 1.2 係数

```
A (ボード補正):
  ドライ:    +12
  セミウェット: +6
  ウェット:   0

C (ベット圧力):
  33% pot:  12
  50% pot:  17
  75% pot:  22
  100% pot: 25
  150% pot: 30

M (マルチウェイ補正):
  HU (2-way): 0
  3-way:      12
  4-way+:     22
```

### 1.3 判定

```
≥ 40 → CR (チェックレイズ) 検討
20〜39 → コール
< 20 → フォールド
```

### 1.4 ストリート別運用

```
フロップ版:    HandScore = 役スコア + ドロー加点 (Rule of 4) + ブロッカー
ターン版:      HandScore = 役スコア (4枚) + ドロー加点 (Rule of 2) + ブロッカー
リバー版:      HandScore = 役スコア (5枚) + ブロッカー (ドロー加点 = 0)
```

### 1.5 計算例

```
TPGK on K72r dry vs 50% bet (HU):
  HandScore = 62 (TPGK)
  A = 12 (ドライ)
  C = 17 (50%)
  M = 0 (HU)
  
  後手スコア = 62 + 12 - 17 - 0 = 57 → CR 検討
```

## 2. 先手スコア式 (攻撃側)

### 2.1 形式

```
先手スコア = HandScore + A − M
```

C 値は含まない (自分が先手で打つため、ベット圧力は受けない)。

### 2.2 判定

```
≥ 40 → ベット (50%pot 以上)
20〜39 → 小ベット (33%) または チェック
< 20 → チェック
```

ベットサイズの選択:
```
≥ 60 → 75-150%pot ベット (バリュー強力)
40-59 → 50-75%pot (標準)
20-39 → 33%pot (薄バリュー or チェック)
< 20 → チェック
```

### 2.3 計算例

```
TPTK on dry K72r flop (HU):
  HandScore = 70 (TPTK)
  A = 12 (ドライ)
  M = 0 (HU)
  
  先手スコア = 70 + 12 - 0 = 82 → ≥ 60 で 75%pot ベット
```

## 3. バレルスコア式 (ターン攻撃)

### 3.1 形式

ターンの攻撃判断専用。HandScore 系統とは独立した補助式。

```
バレルスコア = FlopType + TurnCard

FlopType (フロップタイプ):
  ドライ (rainbow + 不連続):  8
  ペア (フロップ既ペア):       6
  スーテッド (2-flush):         4
  コネクテッド (3 連続):        3
  
TurnCard (ターンカード型):
  ペアターン (フロップとペア): +4
  オーバーカード (フロップ最高位より高い): +3
  ブランク (中位、影響少):      +2
  フラッシュターン (3-flush 完成形): +1
  コネクター (連続性増): 0
```

### 3.2 判定

```
≥ 7 → 積極バレル (75% pot 以上)
4-6 → ハンド依存 (HandScore で個別判断)
≤ 3 → 強チェックバック
```

### 3.3 計算例

```
フロップ K♠7♦2♣ (ドライ) + ターン 5♦ (ブランク):
  FlopType = 8 (ドライ)
  TurnCard = 2 (ブランク)
  バレルスコア = 10 → 積極バレル

フロップ J♥8♠5♣ (セミ) + ターン 9♣ (コネクター):
  FlopType = 4 (スーテッド) ※ 訂正：実は rainbow なので 3 (コネクテッド)
  TurnCard = 0 (コネクター)
  バレルスコア = 3 → 強チェックバック
```

### 3.4 HandScore との連携

バレルスコア単独で「打つかチェック」を決め、打つ場合は HandScore でサイズを決める:

```
バレルスコア ≥ 7 + HandScore ≥ 60 → 75-100% bet
バレルスコア ≥ 7 + HandScore 30-59 → 50% bet (薄バリュー)
バレルスコア ≥ 7 + HandScore < 30 → 33% bet (ブラフ)
バレルスコア 4-6 → HandScore で個別判断
バレルスコア ≤ 3 → 全部チェック
```

## 4. α 式 (リバー配分)

### 4.1 形式 (旧式と変わらず)

```
α = ベット額 ÷ (ポット + ベット額)
MDF = 1 − α
V:B 比率 = (1 − α) : α = ポット : ベット額
```

α 値はベットサイズで一意に決まる (旧スケールから変更なし):

```
33% pot:   α = 0.25 (25%) / MDF = 0.75 (75%) / V:B = 3:1
50% pot:   α = 0.33 (33%) / MDF = 0.67 (67%) / V:B = 2:1
75% pot:   α = 0.43 (43%) / MDF = 0.57 (57%) / V:B = 4:3
100% pot:  α = 0.50 (50%) / MDF = 0.50 (50%) / V:B = 1:1
150% pot:  α = 0.60 (60%) / MDF = 0.40 (40%) / V:B = 2:3
```

### 4.2 用途

リバーで先手として:
- バリュー数 = 自分の強ハンド (HS ≥ 70) のコンボ数
- ブラフ上限 = バリュー数 × α ÷ (1 − α)

### 4.3 計算例

```
75% pot ベット、バリュー 8 コンボ:
  α = 0.43
  V:B = 4:3
  ブラフ上限 = 8 × 3 ÷ 4 = 6 コンボ
```

### 4.4 C 値との接続

```
C = (1 − MDF) × 50 = α × 50
```

つまり 新 C 値 = α × 50:
- 33%: α=0.25 → C=12.5 → 12
- 50%: α=0.33 → C=17 (≈ 16.5)
- 75%: α=0.43 → C=21.5 → 22
- 100%: α=0.50 → C=25
- 150%: α=0.60 → C=30

「C 値は α × 50」と覚えると、α と C が直結して暗算しやすい。

## 5. CBet 統合式 (フロップ用、巻②)

### 5.1 形式 (簡易)

```
CBet スコア = HandScore − 簡易レンジスコア頻度補正値 + ポジション係数

簡易レンジスコア頻度補正値:
  高頻度帯 (≥ 70%): 0
  中頻度帯 (40-69%): 5
  低頻度帯 (< 40%): 10

ポジション係数:
  IP: +5
  OOP: 0
```

注: 旧スケール対応の場合は、上記の +5/+10 は新スケール × 4 で +20/+40 に拡大。

### 5.2 新スケール対応

```
CBet スコア = HandScore − レンジ補正 (新)+ ポジション係数 (新)

レンジ補正:
  高頻度: 0
  中頻度: 20
  低頻度: 40

ポジション:
  IP: +20
  OOP: 0

判定:
  ≥ 60 → CBet 75%
  30-59 → CBet 33%
  < 30 → チェック
```

## 6. シリーズ内での全式の関係

```
                 [フロップ]
   攻撃: CBet 統合式 ←─→ 9 マスマトリクス (役割マッピング)
        簡易レンジスコア (ボード予測) ←→ HandScore (ハンド評価)

                 [ターン]
   攻撃: バレルスコア (ターン攻撃)
   防御: 後手スコア (ターン版、ドロー加点 Rule of 2)

                 [リバー]
   攻撃: α 式 (V:B 配分) + HandScore (バリュー判断)
   防御: 後手スコア (リバー版、ドロー加点 0、C 値拡張)

                 [トーナメント]
   全式に ICM 補正 (HandScore × (1 - ICM%))
   M 値 (スタック深さ) はトーナメント特有 (Harrington's M ratio)
```

```
       先手スコア ≥60 大ベット / 40-59 標準 / 20-39 小ベット / <20 チェック

```

```
33%: α=0.25 / 50%: α=0.33 / 75%: α=0.43 / 100%: α=0.50 / 150%: α=0.60
V:B 比率 = (1-α):α
ブラフ上限 = バリュー × α ÷ (1-α)
```
