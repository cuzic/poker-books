## 2. ドロー加点表

### 2.1 フロップ (Rule of 4 直接)

```
ドロー加点 = アウツ × 4
```

| ドロー種別 | アウツ | 新加点 | 旧加点 | 備考 |
|---|---:|---:|---:|---|
| FD (フラッシュドロー) | 9 | +36 | +13 | ナッツ FD は +37（A ブロッカー +5 込み） |
| OESD (オープンエンド) | 8 | +32 | +14 | |
| GS / Inside straight | 4 | +16 | +6 | |
| FD + OESD (コンボ) | 13 (重複 -2) | +52 | +20 | 上限注意 |
| FD + GS | 12 | +48 | +18 | |
| 2 オーバーカード | 6 | +24 | +6 | (相手 TP 想定) |
| 3 オーバーカード | 3 | +12 | +3 | (まれ) |
| BDFD (固定) | - | +5 | +1 | Rule of 4 だと過大評価のため固定 |
| BDSD (固定) | - | +2 | +1 | |
| ダブルバックドア (BDFD+BDSD) | - | +6 | +2 | |

### 2.2 ターン (Rule of 2 直接)

```
ドロー加点 = アウツ × 2
```

| ドロー種別 | アウツ | 新加点 | 旧加点 |
|---|---:|---:|---:|
| FD | 9 | +18 | +13 |
| OESD | 8 | +16 | +12 |
| GS | 4 | +8 | +5 |
| FD + OESD | 13 | +26 | +20 |
| FD + GS | 12 | +24 | +18 |
| 2 オーバーカード | 6 | +12 | +5 |

### 2.3 リバー

```
ドロー加点 = 0 (確定)
```

ドローは完成 / 失敗のいずれかが確定済みのため、加点なし。

### 2.4 例外補正

| 状況 | 補正 |
|---|---|
| モノトーン板上の FD | × 0.5 |
| 3-flush 板上の FD (相手も完成可能) | × 0.5 |
| ペアボード上の OESD | 通常通り（相手の役上限低下） |

例: モノトーン K♠Q♠7♠ + A♠2♥
- 通常 FD: +36
- モノトーン補正: +18

## 4. A 係数表 (ボード補正)

```
A = ボードのドライ度を表す加点。後手スコア / 先手スコアに加算。
```

| ボードタイプ | 新 A | 旧 A | 判定例 |
|---|---:|---:|---|
| ドライ | +12 | +3 | rainbow + 不連続 (例: K72r) |
| セミウェット | +6 | +1 | 2-flush or 軽連続 (例: K8♠2♠) |
| ウェット | 0 | 0 | モノトーン or 3-連続 (例: 9♠8♠7♠) |

### 4.1 ボードタイプ判定基準

| 要素 | ドライ | セミ | ウェット |
|---|---|---|---|
| スーツ | rainbow | 2-flush | モノトーン or 4-flush |
| 連続性 | gap ≥ 3 | gap 2 | 3-連続 / 2-連続 |
| ペア | 無 | 無 | 既ペア (例外あり) |

## 5. C 係数表 (ベット圧力)

```
C = (1 − MDF) × 50 = α × 50
```

α と直結しているため「α × 50」と覚える。

| ベットサイズ | α | MDF | V:B 比率 | 新 C | 旧 C |
|---|---:|---:|---:|---:|---:|
| 33% pot | 0.25 | 0.75 | 3 : 1 | 12 | 3 |
| 50% pot | 0.33 | 0.67 | 2 : 1 | 17 | 5 |
| 75% pot | 0.43 | 0.57 | 4 : 3 | 22 | 7 |
| 100% pot | 0.50 | 0.50 | 1 : 1 | 25 | 9 |
| 150% pot | 0.60 | 0.40 | 2 : 3 | 30 | 11 |

### 5.1 暗算メモ

```
C ≒ α × 50  (50倍で覚える)
33%: 0.25 × 50 = 12.5 → 12
50%: 0.33 × 50 = 17
75%: 0.43 × 50 = 22 (≒ 21.5)
100%: 0.50 × 50 = 25
150%: 0.60 × 50 = 30
```

## 6. M 係数表 (マルチウェイ)

```
M = 相手プレイヤー数増加によるエクイティ損失補正。
```

| プレイヤー数 | 新 M | 旧 M | equity 損失 (実測) |
|---|---:|---:|---|
| HU (2-way) | 0 | 0 | ベースライン |
| 3-way | 12 | 3 | ~17% |
| 4-way+ | 22 | 6 | ~25% |

### 6.1 補足

- 多人数で TP/オーバーペア の equity が下がるため M を引く
- セット以上は M の影響が小さい (実装で要微調整)
- M は「人数」だけでなく「レンジ重複度」にも依存（簡易式は人数のみで近似）

## 7. 後手スコア閾値表

```
後手スコア = HandScore + A − C − M
```

| 後手スコア | 新閾値 | 旧閾値 | アクション |
|---|---|---|---|
| 強 (≥ 40) | ≥ 40 | ≥ 8 | **CR 検討** (チェックレイズ) |
| 中 (20-39) | 20 〜 39 | 0 〜 7 | コール |
| 弱 (< 20) | < 20 | < 0 | フォールド |

### 7.1 計算例 (TPGK on K72r dry vs 50% bet HU)

```
HandScore = 62 (TPGK)
A = 12 (ドライ)
C = 17 (50%)
M = 0 (HU)

後手スコア = 62 + 12 − 17 − 0 = 57 → CR 検討 ✓
```

### 7.2 先手スコア閾値 (参考)

```
先手スコア = HandScore + A − M  (C なし)
```

| 先手スコア | アクション | サイズ |
|---|---|---|
| ≥ 60 | 大ベット | 75-150% pot |
| 40 〜 59 | 標準ベット | 50-75% pot |
| 20 〜 39 | 小ベット or チェック | 33% pot |
| < 20 | チェック | - |

## 8. HandScore バケット表 (H1/H2/H3)

巻②で導入する 3 バケット分類。9 マスマトリクスの行軸。

| バケット | 新 HS 範囲 | 旧 HS 範囲 | 名称 | 代表例 |
|---|---|---|---|---|
| **H1** | < 35 | < 4 | 弱 (空振り / 弱ペア) | 空振り、ボトムP、A ハイ |
| **H2** | 35 〜 64 | 4 〜 14 | 中 (ミドル / ドロー) | TPMK、TPWK、アンダー、単独ドロー |
| **H3** | ≥ 65 | ≥ 15 | 強 (TP+ / コンボ) | TPGK、TPTK、Set+、コンボドロー |

### 8.1 境界値の根拠

- H1/H2 境界 35 = 「ボトムペアと TPWK の中間」
- H2/H3 境界 65 = 「TPGK 直下と TPGK 直上の境界」

### 8.2 旧 → 新 境界対応

```
旧 4 → 新 35  (H1/H2 境界)
旧 14 → 新 65 (H2/H3 境界)
```

## 9. 9 マスマトリクス

役割×頻度の判断マトリクス。HandScore バケット H1/H2/H3 × ボード頻度帯 (高/中/低)。

### 9.1 新スケール版マトリクス

| | 高頻度帯 (≥70%) | 中頻度帯 (40-69%) | 低頻度帯 (< 40%) |
|---|---|---|---|
| **H3** (HS ≥ 65) | 75% CBet | 50-75% CBet | 33-50% CBet |
| **H2** (HS 35-64) | 33% CBet (薄バリュー) | 33% CBet or check | check (主体) |
| **H1** (HS < 35) | 33% CBet (ブラフ) | check | check |

### 9.2 旧 → 新 境界更新

```
H1/H2 境界:  旧 HS < 4   →  新 HS < 35
H2/H3 境界:  旧 HS ≥ 14  →  新 HS ≥ 65
```

役割名 (CBet/check) はスケール変更で変わらない。

### 9.3 マトリクスの解釈

- 高頻度帯ボード = レンジで打つボード (例: A-high dry, K-high dry)
- 低頻度帯ボード = 守るボード (例: 9-8-7 wet, モノトーン)
- H1 でも高頻度帯では ブラフ CBet 33% を打つ (レンジベット)

## 10. α 早見表

α 値は equity 数学そのものなので **スケール変更不要**。新 C 値の併記のみ更新。

| ベットサイズ | α | 1 − α (MDF) | V : B | 新 C | 用途 |
|---|---:|---:|---:|---:|---|
| 33% pot | 0.25 | 0.75 | 3 : 1 | 12 | 弱ベット (薄バリュー / ブラフ) |
| 50% pot | 0.33 | 0.67 | 2 : 1 | 17 | 標準 (TP / セミブラフ) |
| 75% pot | 0.43 | 0.57 | 4 : 3 | 22 | 強バリュー / プレッシャー |
| 100% pot | 0.50 | 0.50 | 1 : 1 | 25 | リバー大ベット |
| 150% pot | 0.60 | 0.40 | 2 : 3 | 30 | リバー overbet |

### 10.1 ブラフ上限計算

```
ブラフ上限 = バリュー × α ÷ (1 − α) = バリュー × (B / V)
```

例: 75% pot ベット、バリュー 8 コンボ
- α = 0.43 → V:B = 4:3
- ブラフ上限 = 8 × 3 ÷ 4 = 6 コンボ

## 11. バレルスコア表

ターン攻撃判断専用。HandScore とは独立した補助式。**旧スケール継続** (5-12 範囲のまま、リスケールしない)。

```
バレルスコア = FlopType + TurnCard
```

### 11.1 FlopType (フロップ初期値)

| フロップタイプ | スコア | 例 |
|---|---:|---|
| ドライ (rainbow + 不連続) | 8 | K72r、A83r |
| ペア (フロップ既ペア) | 6 | KK7、772 |
| スーテッド (2-flush) | 4 | K♠8♠2♣ |
| コネクテッド (3 連続) | 3 | T98r、JT9 |

### 11.2 TurnCard (ターンカード補正)

| ターンカード型 | 補正 | 例 |
|---|---:|---|
| ペアターン (フロップとペア化) | +4 | K72r → 7 (ペア化) |
| オーバーカード (フロップ最高位より高) | +3 | K72 → A |
| ブランク (中位、影響少) | +2 | K72 → 5 |
| フラッシュターン (3-flush 完成形) | +1 | K♠8♠2♣ → 5♠ |
| コネクター (連続性増加) | 0 | T98 → 7 or J |

### 11.3 判定

| バレルスコア | アクション |
|---:|---|
| ≥ 7 | 積極バレル (75% pot 以上) |
| 4 〜 6 | ハンド依存 (HandScore で個別判断) |
| ≤ 3 | 強チェックバック |

### 11.4 HandScore との連携

```
バレルスコア ≥ 7 + HandScore ≥ 60 → 75-100% bet
バレルスコア ≥ 7 + HandScore 30-59 → 50% bet (薄バリュー)
バレルスコア ≥ 7 + HandScore < 30 → 33% bet (ブラフ)
バレルスコア 4-6 → HandScore で個別判断
バレルスコア ≤ 3 → 全部チェック
```

## 12. CBet 統合式表

巻② フロップ用。新スケール対応版。

```
CBet スコア = HandScore − レンジ補正 + ポジション係数
```

### 12.1 レンジ補正 (新)

| 簡易レンジスコア頻度帯 | 旧補正 | 新補正 |
|---|---:|---:|
| 高頻度帯 (≥ 70%) | 0 | 0 |
| 中頻度帯 (40-69%) | 5 | 20 |
| 低頻度帯 (< 40%) | 10 | 40 |

### 12.2 ポジション係数

| ポジション | 旧 | 新 |
|---|---:|---:|
| IP (in position) | +5 | +20 |
| OOP (out of position) | 0 | 0 |

### 12.3 判定

| CBet スコア (新) | 旧閾値 | アクション |
|---:|---:|---|
| ≥ 60 | ≥ 15 | CBet 75% |
| 30 〜 59 | 5 〜 14 | CBet 33% |
| < 30 | < 5 | チェック |

### 12.4 計算例

```
TPGK on K72r dry, IP, レンジ高頻度帯:
  HandScore = 62
  レンジ補正 = 0 (高頻度)
  ポジション = +20 (IP)
  CBet スコア = 62 − 0 + 20 = 82 → CBet 75% ✓
```

## 13. 役割マッピング × HS 範囲

リバー V/M/B (Value / Marginal / Bluff) 分類。巻⑤ Ch5 の核。

| 役割 | 新 HS 範囲 | 旧 HS 範囲 | 行動指針 |
|---|---|---|---|
| **攻める (Value)** | ≥ 70 | ≥ 18 | 自分から打つ / バリューベット |
| **守る (Marginal / SDV)** | 35 〜 69 | 4 〜 17 | check + bluffcatch / コール |
| **捨てる (Fold candidate)** | < 35 | < 4 | フォールド or 強ブラフ昇格 |
| **SDV (showdown value)** | 30 〜 50 | 3 〜 8 | 主にチェックダウン |

### 13.1 ストリート別の役割境界

| ストリート | Value 境界 | SDV 範囲 | Bluff 候補 |
|---|---|---|---|
| フロップ | HS ≥ 65 | 35-64 | < 35 |
| ターン | HS ≥ 70 | 40-69 | < 40 |
| リバー | HS ≥ 70 | 35-65 | < 35 |

リバーは確定済みなのでドロー加点無し → SDV 範囲が下降。

## 14. ストリート別運用早見

| ストリート | ボード枚数 | HandScore 公式 | 判定式 | A 値再評価 |
|---|---:|---|---|---|
| **フロップ** | 3 | 役 + ドロー(×4) + ブロッカー | HS + A − C − M | フロップ 3 枚 |
| **ターン** | 4 | 役 (4枚) + ドロー(×2) + ブロッカー | HS + A − C − M | 4 枚で再評価 |
| **リバー** | 5 | 役 (5枚) + ブロッカー (ドロー=0) | HS + A − C − M | 5 枚で評価 |

### 14.1 ターンでの再評価ポイント

- ターンカードがフロップとペア化 → ボードがウェット化 (A 値減)
- ターンカードがフラッシュ完成 → A = 0 (ウェット)
- ターンカードがブランク → A 値継続

### 14.2 リバーで C 値を拡張

```
リバーは 100%/150% ベットも一般的 → C = 25/30 を使用
```

## 15. マルチウェイ調整表

```
M = 0 (HU) / 12 (3-way) / 22 (4-way+)
```

### 15.1 マルチウェイでの戦略変化

| 人数 | M | 戦略変化 |
|---|---:|---|
| HU (2-way) | 0 | 標準 (本マスター文書の係数を直接適用) |
| 3-way | 12 | TP は CR 抑制、強ハンドのみバリュー、ブラフ削減 |
| 4-way+ | 22 | セット以上のみで CR、TP はチェックダウン主体 |

### 15.2 マルチウェイでの後手スコア計算例

```
TPTK on K72r dry vs 50% bet:
  HU:    70 + 12 − 17 − 0  = 65 → CR ✓
  3-way: 70 + 12 − 17 − 12 = 53 → CR (境界)
  4-way+: 70 + 12 − 17 − 22 = 43 → CR 境界、コール選択肢あり
```

### 15.3 攻撃側 (CBet) でのマルチウェイ

| 人数 | CBet 頻度低下 | サイズ |
|---|---|---|
