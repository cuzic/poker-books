# Phase 0.5: ドロー加点・ブロッカー加点の検証

実施日: 2026-05-05

## ドロー加点の検証

### 提案する新スケール ドロー加点

```
フロップ: アウツ × 4 (Rule of 4 を直接使用)
ターン:   アウツ × 2 (Rule of 2)
リバー:   0

固定値:
  BDFD: +5 (Rule of 4 だと過大評価のため固定)
  BDSD: +2

例:
  FD 9 outs:        フロップ +36 / ターン +18 / リバー 0
  OESD 8 outs:      フロップ +32 / ターン +16 / リバー 0
  ガットショット 4: フロップ +16 / ターン +8 / リバー 0
  FD+OESD 15-2 重複 outs (= 13 effective): フロップ +52 / ターン +26
  2 オーバーカード 6: フロップ +24 / ターン +12
```

### 検証データ (handscore_boundary)

```
ボード Ks,7c,2c (K72r) ドライ、 vs 33% bet:

ナッツFD単独 (AcXc):   旧HS=13, 新HS≈41 (FD 36 + ナッツブロッカー 5)
                       実測 R=80.1% → 新スケール DS=41 → RAISE 予測 ✓

OESD単独 (J9 全スート on T84r セミ):
                       旧HS=14, 新HS≈32 (OESD 32)
                       実測 R=99.9% → 新スケール DS=32+6-12=26 → CALL 予測 △ (RAISE 寄り)

ガットショット単独 (QJ on T84r):
                       旧HS=10, 新HS≈16 (gutshot 16)
                       実測 C=58.9 / R=41.1 → DS=10 → FOLD 予測 △ (CALL 寄り)

BDFD単独 (Ah2h on T84r):
                       旧HS=4, 新HS≈5 (BDFD 5)
                       実測 C=84.2 → DS=-1 → FOLD 予測 ✗ (CALL 正解)
```

**観察**: 単体ドローのバケット境界では新スケールでも誤差あり。
理由: ドロー単独はバケツ境界域 (HS 30-40) に集まり、判定が境界依存。

### 推奨

```
ドロー加点 = アウツ × ストリート係数

具体値:
  フロップ: Rule of 4 = アウツ × 4
  ターン:   Rule of 2 = アウツ × 2
  リバー:   0

例外:
  BDFD: +5 (固定、Rule of 4 だと 12 → 過大)
  BDSD: +2 (固定、Rule of 4 だと 6 → 過大)
  モノトーン上の FD: × 0.5 (既に相手も完成している可能性)
```

### 旧スケールとの比較

| ドロー | 旧 加点 | 新 加点 (フロップ) | 新 加点 (ターン) |
|---|---:|---:|---:|
| FD (9 outs) | +13 | +36 | +18 |
| OESD (8 outs) | +14 | +32 | +16 |
| ガットショット (4 outs) | +10 | +16 | +8 |
| FD + OESD (13 effective outs) | +17 | +52 | +26 |
| 2 OC (6 outs) | +7 | +24 | +12 |
| BDFD | +4 | +5 | (なし) |
| BDSD | +2 | +2 | (なし) |

**新スケールでは、Rule of 2/4 と直接対応**しており、読者が Rule of 2/4 の知識から HandScore を再現できる。

## ブロッカー加点の検証

### 既存データ (Scenario 105)

```
ファイル: knowledges/volume4/results/105/
内容: 20 cases (AA_vs_88 / missed_fd / reverse_block × 5 ボード)

検証可能な仮説:
  ナッツブロッカー保有時の equity 効果は +3〜+5%
  ボトムブロッカー (相手のブラフ削減) は -2〜-3%
```

### 提案する新スケール ブロッカー加点

```
ナッツブロッカー (ナッツフラッシュ A 等):  +5
上位セットブロッカー (ペアボードのキー):    +3
ストレートブロッカー:                       +3
バリューブロッカー (中位):                  +2

重複加算なし、最大値のみ。

ブラフブロッカー (相手のブラフ削減、リバーで重要):
  巻⑤ 第5章「ブロッカー実戦選択」で扱う独立概念として
  HandScore 計算には含めない (or -3% として加減)
```

### 検証

```
ブロッカー加点を含めると:
  KsJc on Ks,7c,2c (TPMK + ナッツFD blocker?):
    旧HS=8, 新HS≈55 (TPMK 50 + ブロッカー +5)
    実測 R=1.1 / C=98.9 → DS=55+12-12=55 → RAISE 予測 ✗

ブロッカー加点だけでは GTO 整合性は限定的に向上。
巻⑤ 第5章で局面別の調整を扱うべき。
```

## まとめ

### ドロー加点
- **アウツ × 4 / アウツ × 2 / 0** が読者に最も伝わりやすい
- Rule of 4 を採用するとフロップで equity が高めに出る (例: FD = 36% は実測 35%)
- バックドアは固定値 (+5/+2) で過大評価防止
- バケット境界 (HS 30-40 域) は判定が不安定 → 巻⑤ で個別対応

### ブロッカー加点
- **+5 / +3 / +2 (ナッツ / セット / バリュー)** がシンプル
- HandScore 計算に組み込む
- 局面別の追加調整は巻⑤ Ch5 で扱う
- ブラフブロッカー (ネガティブ効果) は HandScore に組み込まない別概念として整理

## 結論

```
ドロー加点 (新スケール):
  フロップ = アウツ × 4
  ターン   = アウツ × 2
  リバー   = 0
  バックドア固定: BDFD +5, BDSD +2

ブロッカー加点:
  ナッツブロッカー:        +5
  上位セット/ストレート:   +3
  バリューブロッカー:      +2
  (重複加算なし、最大値のみ)
```

これらは **巻② の HandScore 概念導入から巻⑥ の ICM 補正まで一貫して使用可能**。
