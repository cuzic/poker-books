# Phase 0.5: ターン・リバーへのパラメータ延長

実施日: 2026-05-05

Phase1 (フロップ) で確認した最適パラメータを **ターン・リバーに延長**。

## ターン・リバー データの限界

```
ターン (102, 107, 270 + 10 ファイル):
  - aggressor 側のみ (turn_cbet_pct, bet_size_distribution)
  - defender 側の役カテゴリ集計データなし
  → バレルスコア検証には使えるが、後手スコア検証には限定的

リバー (103, 105, 106, 各 30 / 20 / 20 ファイル):
  - 103: IP first action (V/M/B 別 bet 確率) ✓
  - 105: blocker 検証 ✓
  - 106: OOP 直面 (V/M/B 別 raise 確率)、fold/call は overall のみ △
```

## ターン版の後手スコア（フロップ式の延長）

ターンの defender data はないが、フロップで確認した式を **同じパラメータで延長**:

```
ターン後手スコア = HandScore + A − C − M

HandScore (ターン版):
  役スコア = フロップ版と同じ (TPTK=70, TPGK=62, ...)
  ドロー加点 = アウツ × 2 (Rule of 2、1 ストリート分)
  ブロッカー加点 = フロップ版と同じ
  
A 値: ボード4枚で再評価
C 値: 33%=12, 50%=17, 75%=22, 100%=25, 150%=30
M 値: 0/8/15

閾値: ≥40 CR / 20-39 コール / <20 フォールド (フロップ版と同じ)
```

### ターン特有の調整

```
A 値再評価:
  ターンカードで 4 枚評価
  例: K72r (A=12 ドライ) + 5♠ → K725♠ (A=6 セミ、スペード 2 枚)

ドロー加点:
  フロップ Rule of 4 → ターン Rule of 2 で半減
  例: FD on flop (+36) → on turn (+18)
  完成 → 役スコアに昇格 (FD完成→フラッシュ、HS=85)
  外れ → 加点除去
```

## リバー版の後手スコア

リバー特有の調整:

```
リバー後手スコア = HandScore + A − C

HandScore (リバー版):
  役スコア = ストレート/フラッシュ等の実完成役で評価
  ドロー加点 = 0 (確定済み)
  ブロッカー加点 = +5/+3/+2 + 局面別ボーナス (巻⑤ 第5章)
  
A 値: ボード5枚で評価
C 値: 33%=12, 50%=17, 75%=22, 100%=25, 150%=30 (拡張)
M 値: 大半 HU、稀にマルチウェイ

閾値: ≥40 CR / 20-39 コール / <20 フォールド (フロップ版と同じ)
```

## V/M/B 分類 (リバー専用)

```
V (Value):     HS ≥ 70  (TPTK 以上)
M (Marginal):  HS 35-69 (TPGK / TPMK / 2pair-split)
B (Bluff候補): HS < 35  (ハイカード)

GTO 実測 (Scenario 103 IP first action):
  Value bet rate:  20-25% (bluff 比率の調整に応じる)
  Mid bet rate:    15-25%  
  Bluff bet rate:  20-35% (α 式から)

これは新閾値と整合: V/M/B の境界が HS=70 / 35 と判定。
```

## ストリート別の C 値（リバー拡張）

```
33% pot:  C=12 (1−MDF=25%)
50% pot:  C=17 (1−MDF=33%)
75% pot:  C=22 (1−MDF=43%)
100% pot: C=25 (1−MDF=50%) ← リバー拡張
150% pot: C=30 (1−MDF=60%) ← リバー拡張 (オーバーベット)
```

リバーで頻出するオーバーベット 100%/150% も同じ式で対応可能。

## バレルスコア (ターン攻撃)

ターンの aggressor 用バレルスコア:

```
バレルスコア = FlopType + TurnCard

FlopType (ボード別):
  ドライ:        8
  ペア:          6
  スーテッド:    4
  コネクテッド:  3
  
TurnCard (ターンカード別):
  ペア:        +4
  オーバー:    +3
  ブランク:    +2
  フラッシュ:  +1
  コネクター:  0
  
判定:
  ≥ 7 → 積極バレル
  4-6 → ハンド依存
  ≤ 3 → 強チェックバック
```

これは旧スケールのままでよい（バレルスコア自体は HandScore と無関係の独立指標）。
ただし HandScore との連携で「バレルスコア = X、HandScore ≥ Y」のような閾値判定では新 HandScore スケールに合わせる。

## α 式 (リバー配分)

α 式そのものは変わらない:

```
α = ベット額 ÷ (ポット + ベット額)

33% pot:  α = 25%
50% pot:  α = 33%
75% pot:  α = 43%
100% pot: α = 50%
150% pot: α = 60%
```

α 値は equity ベースで読み解ける:
- α は「相手のフォールド要求率」
- 1 - α = 相手のコール率 (MDF)
- C 値も α と直結 (C = (1−MDF) × 50 = α × 50)

## 結論

**ターン・リバーは、フロップで確認した最適パラメータをそのまま延長可能**:

```
全ストリート共通:
  HS = equity %（0-100）
  A = +12/+6/0
  M = 0/8/15
  閾値 = ≥40 / 20-39 / <20

ストリート差:
  ドロー加点: フロップ × 4、ターン × 2、リバー 0
  C 値: リバーで 100%/150% 拡張
  HandScore 上限: 95 (役スコア) + 40 (ドロー加点) = 135 → 100 でクランプ
```
