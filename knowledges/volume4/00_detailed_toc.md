# 巻4 『ターン・リバー編 (仮題)』詳細目次

ポーカー書籍シリーズ 4 冊構成のうち **巻4**。ターン・リバーを独立した単行本として扱う。

## 執筆方針

- 巻2 (フロップ初中級編)・巻3 (フロップ上級編) の読者を想定
- 各章の冒頭に「巻2 / 巻3 からのブリッジ」節を置く
- 実戦例は 60 問 (ターン 20 + リバー 20 + 総合 50 の一部)
- GTO データの継続取得 (巻2 の 30 ボード → 巻4 で 50-100 ボードに拡張)
- マルチストリート思考を前面に

## 各章の詳細仕様

### 第1章　ターンの位置づけ

**ゴール**: ターンで判断基準がフロップから何が変わるのかを把握。

**構成 (推定 20 ページ)**:
- 1-1. ストリート間の違い (フロップ vs ターン)
- 1-2. ターンで増える情報 (相手のフロップアクション履歴)
- 1-3. ターンで減る情報 (1 枚少ないカード)
- 1-4. SPR の変化 (フロップ SPR → ターン SPR)
- 1-5. 巻2 からのブリッジ

### 第2章　ターンカードの 5 分類

**ゴール**: ターンカードの種類による戦略の違いを理解。

**構成 (推定 30 ページ)**:
- 2-1. カテゴリ A: オーバーカード (A/K/Q/J が落ちる)
- 2-2. カテゴリ B: ブランク (影響なし)
- 2-3. カテゴリ C: ボードペア (フロップカードのペア)
- 2-4. カテゴリ D: フラッシュ完成カード (同スート 3 枚目)
- 2-5. カテゴリ E: ストレート連結カード
- 2-6. K72r ターンカード別 BTN エクイティ表 (T=49.9%, A=45.9%, 5=44.5%, K=41.9%)
- 2-7. フック: 「テンがエースより有利」

**素材**: `knowledges/volume4/03_turn_card_categories.md`, `01_turn_cbet_frequencies.md`

### 第3章　フロップ → ターンのレンジ遷移

**ゴール**: ターンが来たとき、両者のレンジがどう更新されるか可視化。

**構成 (推定 30 ページ)**:
- 3-1. エクイティバケット (ナッツ/トップ/中/弱/エアー)
- 3-2. BB 逆転現象 (フロップ優位 → ターン逆転)
- 3-3. HandScore の再計算
- 3-4. 「自分のレンジ」と「相手のレンジ」の対比
- 3-5. 実戦例 8 ボード

### 第4章　ダブルバレルの論理 ★ 最重要

**ゴール**: フロップ CBet 後、ターン継続すべきか判定できる。

**構成 (推定 60 ページ、最厚章)**:
- 4-1. GTO 継続率 50-70% を条件別に分解
- 4-2. マルチストリート EV 計算式
- 4-3. ブリックターンの 49:51 バリュー/ブラフ比
- 4-4. 継続すべきハンド (A/B プランへの分岐)
- 4-5. 継続しないハンド (Give up の基準)
- 4-6. ディレイド CBet (フロップ Check → ターン打つ) の条件
- 4-7. 実戦例 15 問

**素材**: `01_turn_cbet_frequencies.md`, `06_turn_strategy_outline.md`

## 巻4 執筆で気をつけること

1. **巻2/巻3 との重複を避ける**: 巻2 の D3、巻3 の BDM v5/混合戦略は再説明せず、`[→巻X 第Y章]` で参照
2. **実戦例は多ストリート化**: 単一ストリートの問題では巻3 との差別化が弱い。フロップ → ターン → リバーの 3 段階問題を中心に
3. **MDF の過信禁止**: リバーレイズでは機械適用不可を繰り返し明示
4. **ポラライズ vs マージ**: 定義を第10章で固定、章によって揺れない
5. **ブロッカー逆転の印象付け**: 第11章で「AA < 88」のサイズ逆転を徹底的に刷り込む (フック)
