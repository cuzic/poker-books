# マルチストリート統合論 (巻4 第III部第18章 素材)

フロップ → ターン → リバーの連続判断を統合的に扱う論点集。

## 背景

巻2 (フロップ編) と巻4 (ターン・リバー編) の知識を統合するには、**各ストリートを独立に判断する**のではなく、**最初から 3 ストリートの流れを計画する**発想が要る。巻4 第18章「マルチストリート統合判断」の素材。

## 1. ポット・ジオメトリ (Pot Geometry)

### 定義

スタックを全部突っ込むために必要なベットサイズをストリートごとに逆算する手法。SPR から最終ポットサイズとコミット額を割り出す。

### 基本式

```
Geometric bet size = ((最終ポット / 初期ポット) ^ (1/N) − 1) / 2

N = 残りストリート数 (2 または 3)
```

実戦での暗算:

- SPR 4 (フロップ時点): 3 ストリートで all-in まで持ち込むなら各ストリート ~70% ポット
- SPR 6: 各ストリート ~75% ポット
- SPR 10: 各ストリート ~85% ポット

### 応用

**ターンで継続するか判断**:

- フロップ 75% ポット打った → ターンもほぼ同じサイズで継続で all-in 到達
- フロップ 33% 打った → ターン 75% 以上打ってもバレル段階が不均衡
- ターンサイズは「自分の最終目標ポット」から逆算する

## 2. SPR の時間変化

### ストリートごとの SPR 変化

```
フロップ SPR = 残スタック / 現在ポット
ターン SPR  = フロップ残 − フロップベット合計 / (フロップポット + フロップベット合計 × 2)
リバー SPR  = ...
```

### SPR がアクションに与える影響

| SPR レンジ | 特徴 | 推奨戦略 |
| --- | --- | --- |
| 1 以下 | コミット済み | TP 以上でオールイン一択 |
| 1-3 (浅い) | ストレート・フラッシュの価値 高 | プロテクション CBet 重要 |
| 4-10 (標準) | 標準的な意思決定 | 巻2 の D3/9マス マトリクス通り |
| 11-20 (深い) | セット・ストレートの価値 高 | バリュータウン長く、ブラフ慎重 |
| 21+ (超深い) | インプライド重視 | 強ドロー価値が上がる |

## 3. 3 ストリート EV の連鎖計算

### フロップで CBet するかの判断は「リバーまでの EV」

単純化した式:

```
EV(フロップベット) = Fold equity + Call equity × EV(ターン)
EV(ターン)       = Fold equity + Call equity × EV(リバー)
EV(リバー)       = ハンド強度に応じた確定値
```

実戦では逆算が難しいが、上級者は「どのハンドでフロップ-ターン-リバー全部打つか」を決めた上でフロップから打つ。

### 「プラン」思考

フロップベット時に、想定される 3 パターン:

- **A プラン**: バリュー、3 ストリート全部押し込む
- **B プラン**: セミブラフ、ターンでドロー成立/未成立で分岐
- **C プラン**: ブラフ、1 ストリートのみで撤退

## 4. ストリート間のレンジ更新

### フロップ → ターンのレンジ変化

ターンカードが何であれ、**両者のレンジが更新**される。

- PFA の更新: フロップ CBet したハンドだけが残る
- BB の更新: フロップ CBet をコールしたハンドだけが残る
- ターンカードが: A/K/Q 落ちるか、ブランク、ペア、フラッシュで BB 側の優劣が変わる

### ターン → リバーのレンジ変化

- ターン 2nd barrel した PFA のレンジはさらに狭まる
- BB のコールレンジも狭まる (両者がナッツ寄りに)
- リバーでは両者のレンジが最も先鋭化

- GTO Wizard Blog: *Principles of Turn Strategy*

## 5. ストリート間の決定相関

### 独立な判断 vs 連続的な判断

- **初心者**: 各ストリートを独立に判断 (フロップで打ち、ターンで打つか別判断)
- **中級者**: フロップ時点でターンまで想定 (2 ストリートプラン)
- **上級者**: フロップ時点でリバーまで想定 (3 ストリートプラン、バリューライン/ブラフラインを最初から決める)

### 実戦での使いどころ

- **SPR 低** (1-3): プランを事前に固定してよい。後から変えない
- **SPR 標準** (4-10): 2 ストリートプランを想定、リバーは情報次第
- **SPR 深** (11+): 柔軟性重視、カードで大きく変わる

## 6. ミスストリートの概念

### 「このストリートだけ間違える」

- フロップ正しい、ターン間違い、リバー正しい → 全体の EV は大幅マイナス
- 連鎖的に次のストリートの判断も歪む

### ハンドレビューでの扱い

- ストリートごとに EV ロスを測定 (巻3 第21章のレビュー手順)
- 最も大きいロスのストリートから改善
