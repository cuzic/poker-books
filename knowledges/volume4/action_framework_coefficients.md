## 確定した係数

### 1. 先手スコア (AS = H + A)

**閾値: AS ≥ 7 → ベット推奨**

| AS | アクション | 理由 |
|---|---|---|
| ≥ 14 | ベット (好サイズ選択) | H2-H3 on any board |
| 7-13 | ベット (主に33%) | H1+dry, H2+wet (boardによる) |
| < 7 | チェックバック | H1+semi/wet |

**3×3マトリックス (実測ベース):**

| | Dry (A=3) | Semi (A=2) | Wet (A=1) |
|---|---|---|---|
| **H3 (≥15)** | ○ 75% | ○ 75% | ○ 75% |
| **H2 (8-14)** | ○ 75% | ○ 75% | ○ 50-75% |
| **H1 (<8)** | ○ 33% (range bet) | △ 33% (39%) | − (19%) |

**ドライ板レンジベット**: H1 でも 33% でベット (54%)。これはドライ板でのレンジベット戦略。

### 2. 後手スコア (DS = H + A - 3 - C)

**旧式**: DS = H - C  
**新式**: **DS = H + A - 3 - C**  (ボードアドバンテージを反映)

BetCost (C):
- 33% bet: C = 3
- 50% bet: C = 5
- 75% bet: C = 7

**閾値:**

| DS | アクション |
|---|---|
| ≥ 8 | **チェックレイズ** |
| 0-7 | **コール** |
| < 0 | **フォールド** |

**MDF 例外**: 33% ベットに対して OOP は 75% 以上を守る必要がある (MDF)。  
DS < 0 でも、H3+H2 のコンボ数が MDF を満たさない場合、H1 の一部がコールに混ぜられる。

**検証 (全18ケース):**

| ボード | A | サイズ | バケツ | DS | 予測 | 実測 | 判定 |
|--------|---|--------|--------|----|----|-----|-----|
| K72r | 3 | 33% | H3 | 14 | raise | 100%raise | ✓ |
| K72r | 3 | 33% | H2 | 8  | raise | 69%raise | ✓ |
| K72r | 3 | 33% | H1 | 1  | call  | 81%call | ✓ (MDF) |
| K72r | 3 | 50% | H3 | 12 | raise | 100%raise | ✓ |
| K72r | 3 | 50% | H2 | 6  | call  | 52%raise | △ 境界 |
| K72r | 3 | 50% | H1 | -1 | fold  | 50%fold | ✓ |
| K72r | 3 | 75% | H3 | 10 | raise | 100%raise | ✓ |
| K72r | 3 | 75% | H2 | 4  | call  | 56%call | ✓ |
| K72r | 3 | 75% | H1 | -3 | fold  | 54%fold | ✓ |
| KJ7r | 2 | 33% | H3 | 13 | raise | 100%raise | ✓ |
| KJ7r | 2 | 33% | H2 | 7  | call  | 57%raise | △ 境界 |
| KJ7r | 2 | 33% | H1 | 0  | call  | 76%call | ✓ (MDF) |
| KJ7r | 2 | 75% | H3 | 9  | raise | 100%raise | ✓ |
| KJ7r | 2 | 75% | H2 | 3  | call  | 84%call | ✓ |
| KJ7r | 2 | 75% | H1 | -4 | fold  | 55%fold | ✓ |
| T98r | 1 | 33% | H3 | 12 | raise | 87%raise | ✓ |
| T98r | 1 | 33% | H2 | 6  | call  | 67%call | ✓ |
| T98r | 1 | 75% | H3 | 8  | raise | 69%raise | ✓ |
| T98r | 1 | 75% | H2 | 2  | call  | 77%call | ✓ |
| T98r | 1 | 75% | H1 | -5 | fold  | 68%fold | ✓ |

**一致率: 18/20 = 90%** (△境界2件: H2 vs 50% dry, H2 vs 33% semi)

境界ケースの解釈: DS = 6-8 は raise と call の混合ゾーン。実戦では「H2 vs 33% はレイズ気味」と覚える。

### 3. チェックレイズ応答 (IP vs OOP CR)

**旧式**: H ≥ 18 → reraise, H 15-17 → call, H < 15 → fold  
**新式**: **H ≥ 15 (= H3) → reraise, H 8-14 (= H2) → call, H < 8 (= H1) → fold**

| バケツ | アクション | 実測根拠 |
|--------|-----------|---------|
| H3 (≥15) | リレイズ | K72r 100%, KJ7r 61%, T98r 52% |
| H2 (8-14) | コール | K72r 72%, KJ7r 77%, T98r 44% |
| H1 (<8) | フォールド | K72r 80%, KJ7r 83%, T98r 95% |

**ウェット板注意**: T98r では H3 も 52% reraise (残り 48% call)。  
H3 on wet → reraise or call (both acceptable)

## フレームワーク最終版

### 先手判断

```
AS = H + A
AS ≥ 7 → ベット
AS < 7 → チェックバック

ベットサイズ:
  AS ≥ 14 (H2-H3 any board): 50-75%
  AS 7-13 (H1 dry / H2 wet):  33%
```

### 後手判断

```
DS = H + A - 3 - C
DS ≥ 8 → チェックレイズ
DS 0-7 → コール
DS < 0 → フォールド
(33% ベット時: MDF=75% を意識して H1 も一部コール)
```

### チェックレイズ応答

```
H3 (≥15) → リレイズ / オールイン
H2 (8-14) → コール
H1 (<8)  → フォールド
```

### マルチウェイ調整

```
AS_actual = H + A - M
DS_actual = H + A - 3 - C - M
  M = 0 (HU), 3 (3-way), 6 (4-way+)  ← 理論値・未検証
```

## 旧フレームワークからの主な変更点

| 項目 | 旧値 | 新値 | 根拠 |
|------|------|------|------|
| DS 式 | H - C | **H + A - 3 - C** | ボードによる CR 閾値の変動を反映 |
| DS raise 閾値 | 12 | **8** | H2 の raise が DS=8 以上で多数 |
| DS fold 閾値 | 7 | **0** | H2 vs 75% wet (DS=2) でも call 多数 |
| CR reraise 閾値 | H ≥ 18 | **H ≥ 15 (H3)** | H3 全体が reraise 多数 |
| AS ベット閾値 | 9 | **7** | ドライ板 H1 (AS=7) でも 54% ベット |
