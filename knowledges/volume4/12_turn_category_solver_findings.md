# ターンカード分類: TexasSolver 実測データの知見

作成: 2026-04-23 (K72r/A72r/K44 データより)

## 重要な発見

### 知見1: 「オーバーカード = 高CBet」は文脈依存

K72r + A ターン: 83-86% (高い) → 正の相関
K44 + A ターン: 77-78% (低い) → 負の相関！

**理由**: K44 ではBBの防御レンジにAx が豊富。A が落ちると BB が強化される。
K72r では BTN の Ax が BB の Kx より多い → A が落ちると IP が強化。

### 知見2: 「ペア = 低CBet」は誤解

K72r + K ターン: 100% (極めて高い)
K72r + 2 ターン: 100% (なんと 2 ペアも 100%)
A72r + A ターン: 98.3% (極めて高い)
K44 + K ターン: 100%
K44 + 4 ターン: 100%

**例外**: K44 + A は 77% (A は IP に不利なオーバーカード)

**理由**: ペアになるカードが IP の強いカードの場合 (K on K72r)、IP のレンジが爆発的に強化される。

### 知見3: 真の決定因子は「誰のレンジを改善するか」

```
Turn CBet が高い ←→ ターンカードが IP のレンジを OOP より多く改善する
Turn CBet が低い ←→ ターンカードが OOP のレンジを IP より多く改善する
```

具体的に:
- K72r では BTN の Kx 比率 >> BB の Kx 比率 → Ks/2c ターンで BTN が爆発 → 100%
- K44 では BB の Ax 比率 >> BTN の Ax 比率 (BB は Ax で広く防御) → As ターンで BB が強化 → 77%

### 知見4: ドライ高頻度ボードは全ターンカードで高CBet

K72r: 78-100% (全ターンカード)
A72r: 72-98% (全ターンカード)
K44: 77-100% (全ターンカード)

「ドライボード → ターン CBet は常に高い」

最低でも 72%。ターンカードの選択が大きく変わるのは「中間帯」ボード (J75r, T87r 等)。

### 知見5: 分類の実用的再解釈

| 原分類 | GTO的な解釈 | 注意点 |
|---|---|---|
| オーバーカード | IP レンジ強化 → 通常高CBet | BB に Ax が多い場合は逆転 |
| ブランク (低カード) | レンジ変化最小 → 中程度 | ドライ板では意外と高い |
| ペア (フロップカード) | IP のレンジ比率が鍵 | 高カードペアはIP超有利 |
| フラッシュ (3枚目同スート) | 未測定 (flush ボード待ち) | |
| コネクター | 未測定 (connector ボード待ち) | |

## 係数の暫定推定 (K72r, A72r, K44 ベース)

ドライ rainbow 板では：
- 全ターンカード平均: 83-87%
- 最低値: ~72% (A72r + 3c blank)
- 最高値: 100% (複数)

**BDM_turn への含意**:
- ドライ板では「ターンカード補正は小さい」
- 大きな補正が必要なのはセミウェット〜ウェット板
- wet board データは #102 実行の後半 (987ss, JT9ss, 987mono) まで待つ必要あり
