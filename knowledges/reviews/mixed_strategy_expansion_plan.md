# 『計算で勝つ』シリーズ 中級編拡張：詳細実装計画

策定日: 2026-04-20

## この計画が解決する課題

外部レビュー（`critique_gto_exploit.md` 参照予定）から抽出された構造的弱点：

1. **境界で0/1に固定** → 搾取されやすい
2. **ハンド単体評価** → RangeAdv / NutsAdv が欠落
3. **サイズが硬直** → 同サイズ内での混合がない
4. **MDF が固定値** → 相手タイプに応答しない
5. **チェックレンジが弱い** → ターンで浮かされる

ただし本書の核である「**暗算できる**」を壊す拡張は不可。よってシグモイドや確率分布は採用せず、**整数加減算＋閾値ガード＋スート判定による疑似混合**で対応する。

---

## 設計原則

| 原則 | 内容 |
| ---- | ---- |
| P1. 暗算可 | 掛け算・割り算（2,3,4以外）・小数・対数・指数を導入しない |
| P2. 整数化 | 全ての新パラメータは整数 ±N で表現 |
| P3. 乱数源は視覚情報 | 混合戦略はハンドのスート・ランクで機械的に決定 |
| P4. 既存式との後方互換 | 旧版読者が混乱しないよう、既存の単一閾値も「基本ライン」として残す |
| P5. 1節1ルール | 複数ルールを同時に導入しない。各ルールは独立に理解・適用可能 |

## 採用する5つの修正ルール

### ルール R1: 3バンド化（決定論 → 粗い混合）

旧：`Score > T → 100%ベット、Score ≤ T → 100%チェック`

新：
```
Score ≥ T+2              → 100%ベット（強バンド）
T−2 ≤ Score ≤ T+1        → 混合ゾーン（R2 で決定）
Score ≤ T−3              → 100%チェック（弱バンド）
```

**暗算負荷**：T は既存値（UTG=24 等）をそのまま使用。加減算 `T+2 / T−2` のみ。

### ルール R2: スート判定による疑似混合（50/50）

混合ゾーンに入ったら、**自分のハンドの左側カード（アルファベット順で先）のスート**で二値決定：

| スート | 判定 |
| ---- | ---- |
| ♠ / ♥（黒赤の「濃い」側） | アクション側（ベット／3ベット） |
| ♣ / ♦ | 受動側（チェック／コール） |

**暗算負荷**：視覚のみ、計算ゼロ。
**効果**：同一ハンドが状況ごとに違う行動を取ることはないが、169ハンド × スート4通り全体で見れば混合戦略の統計的性質を近似する（疑似混合）。

### ルール R3: RangeAdv 補正 +R

旧スコア式（3bet の例）：`Score = H + 0.5L + B + S + C − G − R_block`

新：末尾に **+R（RangeAdv、整数）** を追加：

```
R =
  +2  … ハイカードボード（A / K / Q が1枚以上）×自分がレイザー側
  +2  … ローカードボード（全てJ以下）×自分がコール側
  −2  … その逆（不利側）
   0  … その他
```

**暗算負荷**：ボードの最高カードを1回見るだけ。
**適用先**：preflop の 3bet スコア、flop の CBet スコア両方。
**理論的根拠**：レンジ優位はラージスケールで±10〜15% の EV 差を生むため、スコア上の±2 点（≒しきい値の10%）に相当する補正は整合的。

### ルール R4: サイズ2択（NutsAdv）

フロップ以降の話。CBet サイズを 33%（pot÷3）と 75%（pot÷2 + pot÷4）の2択に圧縮：

```
NutsAdv 判定：
  自分のレンジに上位10%ハンドが多く含まれる
    → 75%
  ボードが相手レンジの上位10%に寄っている（モノトーン等）
  または拮抗
    → 33%
```

**暗算負荷**：2択の if 文のみ。判定基準は既存章の「ナッツ優位」概念を流用。

### ルール R5: チェックレンジ保護（強ハンドの一部チェック）

**QQ+ / AK の扱い**：

| ハンド形 | スーテッド | オフスート |
| ---- | ---- | ---- |
| AA〜QQ | 100% ベット | 20% チェック（小さなトラップ） |
| AK | 100% ベット | 50% チェック |

**暗算負荷**：ハンドの s/o を確認するのみ（常に必要な操作）。
**効果**：チェックレンジに強ハンドが混ざるため、ターンで機械的なベットに対して反撃できる。
**適用**：preflop の 3bet 場面、flop の CBet 場面。

### ルール R6: MDF ±10%

旧：`Defend% = 1 − ベット額/ポット`（固定）

新：
```
基本 MDF を算出
  相手がバリュー寄り（コール後はほぼチェックレイズなし、レンジが狭い） → MDF −10%
  相手がブラフ寄り（連打型、頻度高い） → MDF +10%
  判断つかず → 基本 MDF
```

**暗算負荷**：基本MDFは既に暗算済み。±10 の補正のみ。
**注意**：補正後の値が「全体の1〜2枚分」に該当することを本文で示し、ハンド選択への具体的な影響を明記する。

## リスクと懸念

### 懸念1: 暗算負荷の膨張
- 5つのルールを同時適用すると、1スポット判定に30秒以上かかる可能性
- 対策：各ルールを独立に使えるよう、本文で「最初は R1 だけでよい、慣れたら R3 を足す」の段階導入を明記

### 懸念2: スート判定（R2）の恣意性
- 「左側カードのスート」は GTO の真の混合頻度とは独立
- 対策：本文で明示的に「疑似混合である」と断る。exploit されないのは、相手が同じルールを知らない限り有効（=学習者間では十分な防御）。

### 懸念3: 旧版読者の混乱
- v1 で買った読者に v2 の変更をどう伝えるか
- 対策：第21/27章の最初で「第20/26章までの読者はこれまでの判断でOK。本章は上級への橋渡し」と明記

### 懸念4: 既存の「GTOとのズレ」コラムとの重複
- 各章末コラムと新章の内容が被る
- 対策：新章は「どう修正するか」、コラムは「どこがズレるか」で切り分ける（既存コラムはそのまま）

### 懸念5: ページ数増加
- preflop が 22 → 23 章、flop が 27 → 28 章。付録増でさらに増える
- 対策：KDP 販売価格への影響は小さい（電子書籍）。物理印刷の場合のみ要検討。

1. 各新章の内容を「5分以内に 1 スポットを判定できる」ようユーザーテストで確認
