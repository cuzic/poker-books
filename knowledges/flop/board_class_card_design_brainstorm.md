## 1. 学習させたいこと（ゴール）

テキサスホールデムのフロップ（3枚の公開牌）を見て、以下の3種類に即座に分類できるようになること。

| 分類 | A値 | 典型的なボード |
|------|-----|--------------|
| ドライ | 12 | K♠7♦2♣（レインボー・散らばり） |
| セミウェット | 6 | K♠T♥2♠（2トーン or ハイ接続） |
| ウェット | 0 | T♥9♦8♣（差≤2）/ Q♠J♠9♠（モノトーン） |

この分類を「後手スコア = HS + A − C − M」という式のA値として使う。

**判定アルゴリズム（5ステップ）：**
```
① 3枚同スーツ（モノトーン）? → Yes → ウェット（A=0）
② max-min ≤ 2（密集）?     → Yes → ウェット（A=0）
③ スーツ2種（2トーン）?    → Yes → セミウェット（A=6）
④ top≥T かつ top-2位差≤4? → Yes → セミウェット（A=6）
⑤ 全て×                  → ドライ（A=12）
```

## 2. フラッシュカードの技術的制約

- 表面と裏面の2面のみ
- 表面に出せるもの：テキスト（質問文/補足）、手牌画像（最大2枚）、ボード画像（最大5枚）
- 裏面に出せるもの：答えバナー（1行）、フォーミュラステップ（ラベル+値の複数行リスト）、まとめ文、GTO補足
- SRS（間隔反復）での学習なので、1枚に詰め込みすぎると逆効果

## 3. 現在の設計の問題点

### カード種別（現状）
- 概念カード4枚：ルールの説明（ボード画像なし or 例ボード付き）
- クイズカード13枚：ボードを見てA値を答える

### 問題点リスト
1. **概念カードにボードがない**：「ウェットの条件は？」と聞いても視覚イメージが作れない
2. **クイズカードの裏面が長すぎ**：5ステップ全部書いてあるが、毎回全部読んでも記憶に残らない
3. **「なぜその分類か」が伝わらない**：差=2でなぜウェットなのか、ポーカー的な理由（OESD量産）が薄い
4. **概念カードとクイズカードの役割が曖昧**：概念カードは何を問い、何で答えるのか不明確
5. **境界ケースの学習が孤立している**：K93（差=4セミ）とK83（差=5ドライ）のペアが「比較」として機能していない
6. **フォーミュラステップの視認性が低い**：全ステップを同じ書式で並べると、どこが重要かわからない
7. **応用（A値を式に代入する）を練習するカードがない**

## 4. ブレスト：表面・裏面に入れられる要素の洗い出し

### 表面の候補要素

**視覚系（最強）**
- A. ボード3枚の画像（Quiz系の核心）
- B. ボード + ハンド2枚（より具体的なシナリオ）
- C. 2ボードの並列（比較問題：「どちらがドライ？」）

**テキスト系（問いかけ）**
- D. 分類名を問う（「このボードのA値は？」）
- E. 理由を問う（「なぜウェット？」）
- F. 条件を問う（「ウェットになる2条件は？」）
- G. 数値を問う（「A値はいくつ？」→ドライ=12等）
- H. 逆引き（「A=6になるのはどんなボード？」）
- I. 特定ステップを問う（「②を確認すると？」）
- J. 比較（「K93とK83の違いは？」）
- K. 境界（「差=4と差=5で分類はどう変わる？」）
- L. 応用（「K72r、SRP OOP CBet50% vs BB、A値を求めよ」）

**補足情報系**
- M. 状況テキスト（ポジション、ポット、CBetサイズ）
- N. handDesc（そのカードのポイントを一言でヒント）
- O. ステップ番号のヒント（「ステップ②で判断」）

### 裏面の候補要素

**答え系**
- P. 分類結果バナー（「ドライ（A=12）」）
- Q. A値の数値
- R. 判定に使ったステップ番号

**判定プロセス系**
- S. 全5ステップチェック（詳細）
- T. 関係するステップだけ（簡潔）
- U. "決め手"となったステップのみ（超簡潔）

**理由・背景系**
- V. ドロー分析（FD有無、OESD有無、GS有無）
- W. フォールド率の目安（ドライ~65%、ウェット~30%）
- X. なぜその分類か（ポーカー的理由1文）
- Y. 境界値とのセット比較（「K83（差=5）はドライ」）

**応用系**
- Z. 後手スコア式への代入例（HS=30, A=12, C=17 → 後手スコア=25）
- AA. このボードでよくある行動パターン

## 5. 「どんな問い方が一番学習効果が高いか」の論点

### 問い方パターンの選択肢

**パターンA：ボード → 分類（認識）**
```
表：[ボード画像] + 「A値は？」
裏：「ドライ（A=12）」+「決め手：K-7差=6>4」
```
→ 最も素直。実戦で使う形に近い。

**パターンB：分類 → 例（想起）**
```
表：「ドライ（A=12）の典型ボードを3つ挙げよ」
裏：「K72r / K83r / 952r」
```
→ 逆引き力がつくが主観が入りやすい。

**パターンC：ルール → 条件（再生）**
```
表：「ウェット（A=0）になる2条件は？」
裏：「① モノトーン ② max-min≤2」
```
→ アルゴリズム暗記に特化。視覚イメージなし。

**パターンD：ボード → 理由（説明）**
```
表：[T♥9♦8♣] + 「なぜウェット（A=0）？」
裏：「差=2 → 78/QJがOESD（8アウツ）→ コール強制」
```
→ 「なぜ」の理解を促す。記憶の定着が深い。

**パターンE：比較ペア（差分学習）**
```
表：[K♠9♦3♣] vs [K♠8♦3♣]  「分類の違いは？」
裏：「K93: セミ（差=4）/ K83: ドライ（差=5）」+「2位牌1枚でGSが消える」
```
→ 境界の理解に最強。ただし1枚に情報量多め。

**パターンF：応用（式への代入）**
```
表：「[K♠7♦2♣]でCBet50% vs BB。後手スコアに入れるA値は？」
裏：「A=12（ドライ）」+「後手スコア = HS + 12 − C − M」
```
→ 実用性最高だが前提知識が必要。

## 6. 論点・設計上の問い

以下について、意見と推奨設計を教えてください。

### Q1. カードの分割粒度
「5ステップフロー」を1枚のカードで覚えるべきか、ステップごとに1枚ずつ分けるべきか？

### Q2. 概念カードは必要か
「ウェットの条件は？」型の概念カードと「このボードは？」型のクイズカードを両方持つべきか。それとも全部クイズカードにして、裏面に条件を書けばいいか？

### Q3. 「なぜ」を裏面に入れるか
ドロー分析（OESD/FD の有無）を裏面に毎回入れるべきか。入れると記憶に残りやすいが長くなる。

### Q4. 境界ペアの扱い
K93（セミ）とK83（ドライ）のような境界ペアは、別々の1枚カードにすべきか、1枚の比較カードにすべきか？

### Q5. 応用カードを作るか
「A値を求めた上で後手スコアを計算する」カードは、ボード分類デッキに含めるべきか、後手スコアデッキに含めるべきか？

### Q6. フローチャートの表現
5ステップの判定フローを、テキストステップで表現するか、視覚的に分岐ツリーで表現するか（ただし画像の追加が必要）。

## 7. 制約・要望

- **1枚の裏面ステップは4〜5行以内**に収めたい（それ以上は読み飛ばされる）
- **全体のカード枚数は15〜25枚程度**が理想（多すぎると続かない）
- 「境界ケース」の暗記は特に重要（1枚違いで分類が変わる点）
- ポーカー理論（FD/OESD）の説明は簡潔に1文で済ませたい
- SRSなのでカードの独立性が高い（前のカードを前提にしない）こと
