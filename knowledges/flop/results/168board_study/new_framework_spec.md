257ボード GTO データセット（TexasSolver, BTN vs BB, 100BB, 6-max）から
ゼロベースで再設計したフロップ CBet / Defense 統合フレームワーク。

策定日: 2026-05-12

## 式1: ボードスコア（Board Score = B）

ボード単独の CBet 適正頻度を 0-100 でスコア化。

**優先順位付き 9 ルール（上位ルールが優先）:**

| 優先 | 条件 | B |
|-----|------|---|
| 1 | モノトーン（3枚同スート） | **70** |
| 2 | ペアボード × トップペアランク ≥ T | **83** |
| 3 | ペアボード × トップペアランク < T | **71** |
| 4 | 2-tone × トップカード A/K | **56** |
| 5 | 2-tone（その他） | **50** |
| 6 | Rainbow × spread≤3 × トップカード ≥ J | **67** |
| 7 | Rainbow × トップカード A/K | **62** |
| 8 | Rainbow × トップカード Q | **58** |
| 9 | Rainbow（その他） | **55** |

- **ペアボード**: 同ランク 2 枚以上（例: AA2, K77, T99）
- **トップペアランク**: ペアになっているカードのランク（AA2 → 14, T99 → 9）
- **spread**: 最大ランク − 最小ランク（例: JT9 → spread=2, A83 → spread=11）
- **2-tone**: フラッシュドロー可能な 2 色構成（スート 2 種以下）

**精度**: R²=0.879, RMSE=3.79%（257 ボード）

## 式2: ハンドスコア（Hand Score = HS）

役スコア + ドロースコアのシステム（既存スケール継続）。

### 役スコア（主要ハンド）

| ハンド | HS |
|--------|-----|
| セット以上 | 88 |
| ツーペア | 78 |
| オーバーペア (AA-QQ) | 78 |
| オーバーペア (JJ-TT) | 72 |
| TPTK | 70 |
| TPGK | 62–66 |
| TPMK | 58 |
| アンダーペア (JJ-TT) | 43–44 |
| セカンドペア | 32–42 |
| ボトムペア | 32 |

### ドロースコア（Rule of 4 / Rule of 2）

```
フロップ: outs × 4  （9アウツ以下では実際のエクイティとほぼ一致）
ターン:   outs × 2
```

12 アウツ以上は過大推計になるため −5 の補正を推奨。

**主要ドロー別スコア（フロップ）:**

| ドロー | アウツ | HS |
|--------|--------|-----|
| FD+OESD | 13 (実効) | 52 |
| NFD | 9+5 | 41 |
| FD | 9 | 36 |
| OESD | 8 | 32 |
| 2OC+GS | 10 | 40 |
| 2OC | 6 | 24 |
| GS | 4 | 16 |
| 1OC | 3 | 12 |

### ハンドティア（T1/T2/T3）

```
T1: HS ≥ 65  → 強ハンド（メイドストロング・ナッツドロー）
T2: HS ≥ 20  → 中ハンド（TP弱〜ドロー全般）
T3: HS < 20  → 弱ハンド（エアー・ごみドロー）
```

旧バケツ境界（H3 ≥ 65 / H2 ≥ 35 / H1 < 35）から T2 下限を 35→20 に拡大。
これにより 2OC (HS=24) が T2 に含まれる。

## 式3: フロップ CBet 判断

```
T1 (HS ≥ 65): 常にベット（ボード問わず）
T2 (HS ≥ 20): B ≥ 58 ならベット（B < 58 = 2-tone 全体 ≈ チェック）
T3 (HS < 20):  B ≥ 70 ならベット（Mono以外のほぼ全てはチェック）
```

### 実例

| ハンド | HS | ティア | ボード例 (B) | アクション |
|--------|-----|------|------------|----------|
| TPTK | 70 | T1 | 任意 | ベット |
| 2OC | 24 | T2 | Rainbow A83 (62) | ベット |
| 2OC | 24 | T2 | 2-tone JT9 (50) | チェック |
| GS | 16 | T3 | Paired K77 (83) | ベット |
| GS | 16 | T3 | Rainbow Q54 (58) | チェック |
| エアー | 10-25 | T3 | Mono (70) | ベット |

## 式4: CBet サイズ

```
Mono (B=70):   33% ポット
Paired (B=71/83): 50% ポット
B < 58 (2-tone): 75% ポット（低頻度・大きく）
その他:         50% ポット
```

サイズ根拠: GTO データの実測値（Mono は低頻度高頻度バランス、Paired は高頻度中サイズ）

## 式5: Defense（vs CBet） — フォールド閾値

後手スコア廃止。サイズ別フォールド閾値に一本化。

### 基本閾値

```
vs 33%: fold if HS < 15  （MDF 75%、エクイティ必要 20%）
vs 50%: fold if HS < 25  （MDF 67%、エクイティ必要 25%）
vs 75%: fold if HS < 35  （MDF 57%、エクイティ必要 29%）
```

### ボード補正（加算）

```
+5:  2-tone    ← レンジが広い、攻める必要あり
−5:  Mono      ← 相手も低頻度、コール基準を緩める
−10: Paired    ← フルハウス恐怖で相手もブラフ多め、コール基準を緩める
```

補正後閾値 = 基本閾値 + ボード補正（負になる場合は 0）

**2OC (HS=24) の例:**
- vs 33%: fold threshold = 15 - 0 = 15 → HS 24 ≥ 15 → **コール**
- vs 50%: fold threshold = 25 - 0 = 25 → HS 24 < 25 → **フォールド**（ポットオッズ不足）
- vs 75%: fold threshold = 35 → HS 24 < 35 → **フォールド**

## 式6: Donk ベット（BB 先行ベット）

```
Donk: HS ≥ 70 AND B ≤ 58
```

強ハンド（T1 上位）かつ相手 CBet 頻度が低いボードで先手をとる。

---

## 式7: マルチウェイ補正

```
3-way: B + 10（相手 1 人追加）
4-way: B + 20（相手 2 人追加）
```

プレイヤー数が増えると CBet 採算が下がるため、ベット基準を上げる（B の閾値を上げる）。

等価表現: マルチウェイでは T2 以上でのみ CBet（T3 はほぼ放棄）。
