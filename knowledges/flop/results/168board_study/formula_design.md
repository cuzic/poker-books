# 257ボード GTO 回帰 — 新 CBet 式設計書

## 確定式（書籍掲載版）

```
BTN CBet% = 50 + 0.8×kicker - 5×[2tone] + 13×[mono] + 20×[paired]
```

- **kicker**: フロップ中位カードのランク（2=2, T=10, J=11, Q=12, K=13, A=14）
- **[2tone]**: 2色フラッシュドローありなら 1、なければ 0
- **[mono]**: 3枚同色なら 1
- **[paired]**: ペアボード（XX Y型）なら 1

**適合度**: R²=0.806、RMSE=4.81%（257ボード）

- エアー → pairedで65%、rainbow/2toneで40%前後
