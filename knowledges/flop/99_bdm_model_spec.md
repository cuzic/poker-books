# BDM (Board Deficit Model) 完全仕様書

> 本書『ゼロから勝てるテキサスホールデム フロップ編』で採用する新モデルの中核仕様。
> 第5〜29章の全ての式・実戦例・図解はこの仕様に準拠する。

## 背景と設計哲学

従来の「BoardScore = ウェットネス単軸」設計 (r = -0.822) は、GTO 頻度との残差が
トップカード/スート構造/ペア特殊性の 3 次元に強く依存し、精度が頭打ちになった。

本モデルは以下の3つの観察を起点に再設計されている:

1. **トップカードは連続性と直交した次元**: A/K 高ドライは GTO 85-90% だが、J 高ドライは 40-50%
2. **2-tone は rainbow と決定的に異なる**: 残差分析で平均 -9.2% の過大評価を引き起こす
3. **ペアボードは単軸スコアに押し込むと K44 で -41% の巨大外れ値を生む**

設計方針: **「90% から理由で引いていく」**。PFA のデフォルト攻撃頻度を上限に、
相手のヒット構造・ドロー密度・レンジ優位消失の要因で減算していく加算（減算）モデル。

## 階層1: D3 暗算モデルの完全仕様

### 4 ステップの判定手順

```
Step 1 ── モノトーンか？                    → YES: 20%
Step 2 ── ペアボードか？                    → YES: ペア表参照
Step 3 ── ウェット要素のチェック
Step 4 ── トップカード × ウェット で頻度決定
```

### Step 4 の中核マトリクス (非ペア・非モノトーン)

|                          | ドライ | ウェット |
| ------------------------ | ---- | ------ |
| **ハイ (トップ A/K/Q)**    | 85%  | 55%    |
| **ロー (トップ J 以下)**   | 55%  | 30%    |

**「ウェット」の定義** (いずれかに該当):
1. **連続3枚** (3枚の最大ランク差 ≤ 2): 例 987、T98、JT9
2. **2-tone** (3枚のうち2枚が同スート)
3. **高ボード連続** (3枚の最大ランク差 ≤ 4 かつトップ T 以上): 例 KT5、QJ8

### ペア表 (Step 2 で参照)

| パターン                          | 頻度 | 例               |
| -------------------------------- | ---- | --------------- |
| ハイペア (QQ+) + 高キッカー (≥8) | 80%  | AAK, KK9, QQT |
| ハイペア (QQ+) + 低キッカー (<8) | 50%  | KK4, QQ3      |
| 中低ペア (TT 以下の top pair)     | 72%  | TT5, 995, 772 |
| A/K ハイ + ローペア (ペア ≤7)    | 45%  | K44, A33      |
| A/K ハイ + 中ペア (ペア 8-T)     | 75%  | A99, K88      |

### 暗算手順の完全コード

```python
def d3(top, is_paired, is_mono, is_wet, pair_rank=None, kicker=None):
    if is_mono:
        return 20
    if is_paired:
        # ペア表で決定
        ...
    if top >= Q:  # A/K/Q
        return 55 if is_wet else 85
    else:  # J 以下
        return 30 if is_wet else 55
```

### CBet 判定への橋渡し

D3 で算出した頻度 X% を、**自ハンドの強さによる乗算修正**に通す。

```
自ハンドが以下のとき:
  ・トップペア以上        → X × 1.2 (上限 100)
  ・ポケットペア/ミドル    → X × 1.0
  ・エアー + ナット BDFD  → X × 1.0
  ・純粋エアー             → X × 0.4
```

これでレンジ全体の X% を自分のハンド個別に割り振る。

## 階層2: BDM v5 精密モデルの完全仕様

### 基本式

```
CBet% = 90 − HighCardDeficit − TextureCost − SuitPenalty − Extra
        (ペアは override、monotone は 18% 固定)
```

### HighCardDeficit (トップカード基準差)

| トップカード | 減算 |
| ----------- | ---- |
| A           | 0    |
| K           | 0    |
| Q           | 5    |
| J           | 35   |
| T           | 35   |
| 9           | 35   |
| 8 以下       | 30   |

### TextureCost (連続性 × トップカード)

**max_diff = トップカード − ボトムカード**

| max_diff            | 条件                    | 減算 |
| ------------------- | ----------------------- | ---- |
| ≥ 8 (散開)          | -                       | 0    |
| 5〜7 (中程度)        | -                       | 5    |
| 3〜4 (2連+ギャップ)  | top ≤ 8                | 5    |
| 3〜4                 | top T-J                 | 15   |
| 3〜4                 | top Q+                  | 25   |
| ≤ 2 (連続3枚)       | top ≤ 8                 | 5    |
| ≤ 2                  | top 9 (rainbow)         | 10   |
| ≤ 2                  | top 9 (2-tone)          | 20   |
| ≤ 2                  | top T (2-tone)          | 15   |
| ≤ 2                  | top T (rainbow)         | 20   |
| ≤ 2                  | top J                   | 25   |
| ≤ 2                  | top Q+                  | 30   |

### SuitPenalty

| スート構造  | 減算 / 扱い         |
| ---------- | ----------------- |
| rainbow    | 0                 |
| 2-tone     | 10                |
| monotone   | 全体 override → 18% |

### Extra (ブロードウェイ補正)

| 条件                                                           | 追加減算 | 例          |
| ------------------------------------------------------------- | ------- | ----------- |
| middle=T かつ top≥Q かつ rainbow                                | +15     | KT5r, QT3r  |
| 3枚とも T 以上 かつ 2-tone                                      | +10     | KQTss, QJTss |
| top=A/K/Q + middle=T + 2-tone + low<T                         | +15     | AT7ss, KJ2ss |
| Q-high + middle<T + 2-tone                                    | +10     | Q83ss       |

### Pair Override

| パターン                          | 頻度 | 条件                                |
| -------------------------------- | ---- | ----------------------------------- |
| ハイペア (QQ+) + 高キッカー (≥8) | 82%  | 最上位ランクがペア, キッカー 8 以上 |
| ハイペア (QQ+) + 低キッカー (<8) | 50%  | 最上位ランクがペア, キッカー 7 以下 |
| ミドルペア (TT-88)                 | 75%  | 最上位ランクがペア, pair_rank 8-10  |
| ローペア (77 以下)                 | 68%  | 最上位ランクがペア, pair_rank ≤ 7   |
| A/K ハイ + ローペア (pair ≤ 7)     | 45%  | 最上位が A/K、ペアランク ≤ 7        |
| A/K ハイ + 中ペア (pair ≥ 8)       | 76%  | 最上位が A/K、ペアランク 8 以上     |
| Q/J ハイ + ローペア                | 55%  | 最上位が Q/J、ペアランク ≤ 7        |

## GTO 検証結果 (30 ボード)

以下は 6-max 100BB キャッシュ BTN vs BB SRP の GTO Wizard 公開データに対する実測。

| モデル                       | R²    | MAE   | Pearson r |
| ---------------------------- | ----- | ----- | --------- |
| 旧 BoardScore Level 1         | 0.542 | ~12   | -0.736    |
| 旧 BoardScore Level 2 (advanced) | 0.675 | ~10   | -0.822    |
| **D3 暗算モデル (新)**        | **0.873** | **6.03** | **+0.938** |
| **BDM v5 精密モデル (新)**    | **0.914** | **5.27** | **+0.962** |

### 最大外れ値

**D3 モデル:**
- 残差 >= 15: 5 ボード (Q83ss、QJ9r、KQTss、T98ss、965r)

**BDM v5 モデル:**
- 残差 >= 15: 1 ボード (965r のみ、+20%)
