## 主要な数値依存ルート

### ルート 1: 巻② → 巻③ → 巻④ → 巻⑤ → 巻⑥（HandScore 系統）

```
巻② Ch5 / Ch9 ← HandScore の概念導入と詳細
   ↓
巻③ Ch3 ← 精密 HandScore（強化版）
   ↓
巻④ Ch5 / Ch10 / Ch11 ← ターン・リバー版 HandScore
   ↓
巻⑤ Ch5 / Ch12 / Ch16 ← 応用と統合
   ↓
巻⑥ Ch19 ← ICM 補正
```

各段階で「前巻の式を継承」しているため、**巻②でスケール変更すると下流すべてに伝播**。

### ルート 2: 巻② → 巻④ → 巻⑤ → 巻⑥（後手スコア系統）

```
巻② Ch16 ← 後手スコア（フロップ HU + マルチウェイ）の確立
   ↓
巻④ Ch10 / Ch11 ← ターン版・リバー版 後手スコア
   ↓
巻⑤ Ch10/11/12 ← SBvsBB / 3BP / マルチウェイ
   ↓
巻⑥ Ch15 / Ch19 ← HU 戦術 / ICM 補正
```

### ルート 3: 巻① → 巻⑥（プリフロップ Score → ICM 補正）

```
巻① Ch5 ← Open Score / 3-bet Score の基本式
   ↓
巻⑥ Ch7 / Ch10 / Ch15 ← トーナメントでの Score 補正
```

巻① の Score 系統は **HandScore とは独立** だが、巻⑥ で ICM 補正をかける際にプリフロップ Score を併用する。

## 巻① preflop の特殊性

```
preflop の Score 系統:
  Open Score = ChenScore + ポジション補正
  3-bet Score = HandScore（独自） + 状況補正
  
HandScore (postflop) と Open/3-bet Score は別系統だが、
  "Score" という用語が共有されているため、読者が混同するリスクあり

→ 案【大】で postflop HandScore を equity % にした場合、
   preflop の Score 系統も同様に equity % で統一するか、
   明確に「役割が違う」と区別するかの設計判断が必要
```

## digest の特殊性

digest は全巻のダイジェストのため、**最後に統合更新**する位置づけ:
- 巻②/③/④/⑤/⑥ の式と数値が確定してから対応
- 全 18 章で他巻参照あり
- digest 自身に式定義 + worked example も含む

## 結論

- **影響の中心は巻②（HandScore + 後手スコア の発祥）**
- **巻④ がハブ**（巻②/③ から HandScore を受け、巻⑤/⑥/digest へ展開）
- **巻① preflop は独立**（Open/3-bet Score 系統）→ 案【大】の影響最小
- digest は最後に統合更新
- **総影響範囲: 巻① 軽 → 巻②〜⑥ + digest 全面**
- 推奨実装順序: 巻② → 巻③ → 巻④ → 巻⑤ → 巻⑥ → digest → 巻① 確認 → poker-drill
