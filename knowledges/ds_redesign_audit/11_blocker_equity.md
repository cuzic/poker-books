# 調査11: ブロッカー加点の equity 換算調査

実施日: 2026-05-05

## 現状（旧スケール）

```
ブロッカー加点:
  ナッツブロッカー (ナッツフラッシュ A や、ナッツフルハウスのキー):  +3
  上位セットブロッカー:                                              +2
```

巻⑤ Ch5「ブロッカー実戦選択」で局面別に細分化されている。

## ブロッカー効果の equity 換算

### A. ナッツブロッカー（A♥ on monotone 完成 board 等）

```
効果: 相手のレンジから「ナッツコンボ」を物理的に削除する

例: K♥7♥2♥ + 5♥（リバー、ハート 4 枚） vs BB の 3-bet レンジ
  通常 BB のナッツフラッシュコンボ: A♥X (4 枚)
  自分が A♥ を保有 → BB の A♥ コンボ完全除去

equity 効果:
  相手のバリュー密度が ~10-20% 低下
  自分のブラフ成功率が +5-10% 上昇
  ブロッカー保有時の bluff EV ≈ +0.3 BB / spot
```

equity % 換算:
- フロップ・ターンの中強度ハンドで A 保有: **+3〜5%**
- リバーのブラフ判断で A 保有: **+5〜10%**
- 自分が既にナッツの場合: ブロッカー効果は意味なし（+0）

### B. 上位セットブロッカー（ペアボードで T を持つ）

```
例: K♠K♥7♣2♦5♥ ボードで KQ 持ち
  自分が K を保有 → 相手の KK セット（ナッツ近辺）を 1/3 削減
  
equity 効果:
  相手のクッキー（KK セット）が出現確率 3/1 → 2/1 に減
  自分が TPTK 程度 vs 相手の Kx ナッツ系の equity 改善
```

equity % 換算:
- ペアボード上の K 保有（Kx ナッツ削減）: **+3〜5%**
- ストレート完成ボードでの「ストレートブロッカー」: **+2〜4%**

### C. ボトムブロッカー（相手のブラフコンボを削除）

```
例: 相手のブラフレンジに含まれる「8x」を自分が保有
効果: 相手のブラフ密度低下 → 自分のコール EV 低下

→ ブロッカー加点ではなく逆効果（+0 または -3% 程度）
```

これは旧設計でも考慮されていない。**ネガティブブロッカー**として認識し、巻⑤ で別途扱う。

## 新スケール（equity %）でのブロッカー加点案

### 案 1: シンプル固定値

```
ブロッカー加点:
  ナッツブロッカー（ナッツバリューを物理削除）:        +5
  上位セットブロッカー（K on K-pair board 等）:        +3
  ナッツストレートブロッカー:                          +3
  バリューブロッカー（ペアボードのキー）:              +2
```

### 案 2: 局面別細分化（巻⑤ Ch5 風）

```
フロップ・ターンでの加点:
  ナッツブロッカー保有: +3 (まだリバーまであるため効果限定)
  
リバーでの加点:
  ナッツブロッカー保有 (FD完成 board): +8
  ナッツブロッカー保有 (str完成 board): +6
  ナッツブロッカー保有 (ペア board): +5
  
ブラフ局面での加点（vs 自分がブラフ判断）:
  ナッツブロッカー保有: +10 (相手のフォールド率が顕著に上昇)
```

### 案 3: 相手レンジ依存（巻⑤ 高度版）

```
相手レンジが「ナッツ偏重 (3-bet で QQ+)」の場合:
  ナッツブロッカー: +5 (高効果)
  
相手レンジが「ポーラー (ブラフ多含)」の場合:
  ナッツブロッカー: +1 (ブラフ密度を増やす逆効果)
  
HandScore 計算では「+3 固定」、巻⑤ で +0/+5 のレンジ調整
```

## 推奨

### Phase 1 設計仕様（HandScore 計算用）

```
ブロッカー加点（一律、equity %）:
  ナッツブロッカー:               +5
  上位セットブロッカー:           +3
  ストレートブロッカー:           +3
  バリューブロッカー（中位）:     +2

ブロッカー加点 = max(該当する全ブロッカーの値) (重複加算しない)
```

### Phase 2 巻⑤ 応用（実戦選択）

```
リバーでブラフを打つ場合:
  ナッツブロッカー保有: 後手スコアに直接 +5%
  ナッツブロッカー非保有: -3% (ブラフ EV 低下)
  
リバーでコール判断する場合:
  バリューブロッカー保有: +3%
  ボトムブロッカー（相手ブラフ削除）保有: -2%
```

## 「+3 固定」を維持する根拠

旧設計の「+3 固定」は十分実用的:
- 局面依存性は ±2% 程度の誤差
- 暗算簡素化で一律 +3 が良い
- 巻⑤ 応用で個別調整

新スケール（0-100）に合わせる場合:
- 旧 +3 → 新 +5 (ナッツブロッカー)
- 旧 +2 → 新 +3 (上位セットブロッカー)

## 結論

**新スケールでのブロッカー加点（推奨）**:

```
ナッツブロッカー:        +5
上位セットブロッカー:    +3
ストレートブロッカー:    +3
バリューブロッカー:      +2

(equity % ベース、最大値のみ加算、重複加算なし)
```

巻⑤ Ch5「ブロッカー実戦選択」で局面別の調整（リバーブラフで +10、ボトムブロッカー -2 等）を扱う。

## 設計仕様の確定事項

1. ブロッカー加点は **HandScore の一部** として計算（+5 / +3 / +2）
2. 局面依存の細分化は **巻⑤ Ch5** で扱う（後手スコアの最終調整）
3. ボトムブロッカー等のネガティブ効果は **巻⑤ で別概念**として導入
4. **重複加算なし**（最も大きい値のみ）
