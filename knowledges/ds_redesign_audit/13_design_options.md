# 調査13: 設計判断のオプション整理（Phase 0 統合）

実施日: 2026-05-05

調査 01〜12 の結果を統合し、Phase 1（設計仕様確定）で決定すべき選択肢を整理する。

## 既知の設計枠組み

```
新 HandScore = 自分の equity % (vs 典型レンジ)
              = 役スコア + ドロー加点 + ブロッカー加点

新後手スコア = HandScore + A − C − M
            (旧式の "− 3" はベースライン補正として吸収)

判定:
  ≥ X → CR 検討
  Y〜X-1 → コール
  < Y → フォールド
```

### Q11. 後手スコア閾値

```
後手スコア = HandScore + A − C − M

仮の数値で検証:
  TPTK on dry vs 50% bet (HU):
    新後手スコア = 68 + 5 − 33 − 0 = 40
  
  Set on dry vs 75% bet (HU):
    新後手スコア = 85 + 5 − 43 − 0 = 47
  
  TPMK on dry vs 75% bet (HU):
    新後手スコア = 50 + 5 − 43 − 0 = 12
```

| 選択肢 | CR 閾値 | コール下限 | フォールド |
|---|---:|---:|---:|
| A. 50 / 20 | ≥ 50 | 20〜49 | < 20 |
| B. 45 / 15 | ≥ 45 | 15〜44 | < 15 |
| C. 40 / 10 | ≥ 40 | 10〜39 | < 10 |

**推奨**: A（50 / 20）。

検証:
- Set 47 → 50 未満 → コール (近い、CR 寄り)
- TPTK 40 → コール ✓
- TPMK 12 → フォールド ✓

→ Set がコール域に落ちるのは少し違和感。Q9 (A 値) を A=10 にすれば Set = 52 となり CR 閾値超過 ✓

### 再検討: Q9 を **A=10/5/0** に修正

```
Set on dry vs 75%: 85 + 10 − 43 = 52 → CR
TPTK on dry vs 50%: 68 + 10 − 33 = 45 → コール (境界)
TPMK on dry vs 75%: 50 + 10 − 43 = 17 → フォールド
```

GTO 実測:
- Set on dry vs 75%: CR 60-70% / コール 30-40% → 新 CR ≈ 50% で整合
- TPTK on dry vs 50%: CR 25-30% / コール 70-75% → 新 コール → ✓
- TPMK on dry vs 75%: フォールド 70%+ → ✓

**再推奨**: Q9 = A（+10 / +5 / 0）

## 暗算しやすさの評価

```

「TPGK on K72r ドライ、相手が 50% pot ベット」
→ 役スコア 60 (TPGK) + ボード補正 +10 (ドライ) − ベット圧 33 (50%pot)

```
