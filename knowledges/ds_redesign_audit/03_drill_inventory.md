## 特に注意が必要な「境界値ぴったりで判定する」問題

スケール変更で答えが変わる可能性が高い問題タイプ:

1. **CR 閾値ぴったり（後手スコア = 8）の問題**
   - 旧: スコア 8 → CR 検討
   - 新スケール（仮に閾値 ≥ 50%）→ HandScore 50%相当が境界
   - 境界域は判定が真逆になる可能性

2. **コール/フォールド境界（後手スコア = 0）の問題**
   - 旧: スコア 0 がコール下限
   - 新: equity % で 30% が下限になるなど

3. **TPGK（HS=15）+ A=2 + C=5 のようなボーダー計算**
   - 結果スコアが 2〜3 になり「コール域」「ぎりぎり」と書かれている問題群

これらは新スケールで再計算後、**結論文も書き直し**が必要。

## 判定境界をまたぐ可能性のある問題（推定）

巻④/⑤ の 後手スコア計算 94 件のうち、**境界±2 以内のものは推定 25-30 件**。これらは結論まで再評価。

```
（旧スケール）
  CR 検討 (≥8) で結論 = 8〜12 のもの → 約 15 件
  コール (0〜7) で結論 = 0〜2、5〜7 のもの → 約 10 件
  フォールド (<0) で結論 = -1 〜 -3 のもの → 約 5 件
```
