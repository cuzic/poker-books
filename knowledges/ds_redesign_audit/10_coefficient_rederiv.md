# 調査10: C/A/M 係数の equity ベース再導出

実施日: 2026-05-05

## 現状（旧スケール、HandScore 0-30）

```
後手スコア = HandScore + A − 3 − C − M

C（ベット負担）:  33%=3, 50%=5, 75%=7, 100%=9, 150%=11
A（ボード値）:    ドライ=3, セミ=2, ウェット=1
M（マルチウェイ）: HU=0, 3-way=3, 4-way+=6

閾値:
  ≥ 8  → CR 検討
  0〜7 → コール
  < 0  → フォールド
```

## 新スケール（HandScore 0-100、equity %）への再導出方針

### 後手スコア式の意味

```
後手スコア = HandScore + A − 3 − C − M
         (equity %)
         
意味: 「自分のハンドの equity から、ベットサイズの圧力を引いた後の調整 equity」
```

CR 閾値: 「相手のレンジに対し、コールでなくレイズで EV+ になる equity 水準」
コール閾値: 「ポットオッズ + α 安全マージンを満たす水準」
フォールド閾値: 「ポットオッズに届かない」

### 各係数の equity 換算

#### **C 係数（ベット負担）**

数式: C = (1 − MDF) × 調整係数

ベットサイズ別 MDF:
- 33% ベット → MDF = 75% → 1-MDF = 25%
- 50% ベット → MDF = 67% → 1-MDF = 33%
- 75% ベット → MDF = 57% → 1-MDF = 43%
- 100% ベット → MDF = 50% → 1-MDF = 50%
- 150% ベット → MDF = 40% → 1-MDF = 60%

new C = α × 50（α を equity % にスケール）:
```
新 C 表（equity %）:
  33% pot → C = 12% (旧 3 × 4)
  50% pot → C = 17% (旧 5 × 3.4)
  75% pot → C = 22% (旧 7 × 3.1)
  100% pot → C = 25% (旧 9 × 2.8)
  150% pot → C = 30% (旧 11 × 2.7)
```

または、**シンプルに「α そのまま」**:
```
新 C 表（α 値）:
  33% pot → C = 25% (= α)
  50% pot → C = 33%
  75% pot → C = 43%
  100% pot → C = 50%
  150% pot → C = 60%
```

これだと C は「ポットオッズの必要 equity」と等しくなり、暗算しやすい。

#### **A 係数（ボード値）**

ナッツアドバンテージの equity 換算:
- ドライボード: IP に +5〜10% のナッツアドバンテージ → 守備側はその分損
- セミウェット: +2〜5%
- ウェット: ±0% または OOP に +3% (中強度ハンドが拮抗)

```
新 A 表（equity %）:
  ドライ: A = 10% (守備側の追加 equity 損失分)
  セミ:   A = 5%
  ウェット: A = 0%
```

ただし旧 A は「ドライ = 3」が **加点**（後手スコアを上げる）。これは「ドライボードでは中強度のハンドの相対価値が高い」という設計思想。

新スケールでは:
- ドライで TPGK は強い（コールしやすい）→ 後手スコアに +10%
- ウェットで TPGK は弱い（フォールド寄り）→ +0%

```
新 A（equity %）:
  ドライ:   A = +10
  セミ:     A = +5
  ウェット: A = 0
  
旧式の「− 3」は新式では「ベースライン補正」として吸収。
新後手スコア = HandScore + A − C − M (基本形)
```

#### **M 係数（マルチウェイ）**

マルチウェイで equity 損失する量:
- HU (2-way): 0
- 3-way: 各プレイヤーの equity が ~33% に薄まる効果 → 中強度のハンドは -10〜15%
- 4-way+: -15〜25%

```
新 M 表（equity %）:
  HU:       M = 0
  3-way:    M = 12%
  4-way+:   M = 20%
```

### 後手スコア式（新スケール）

```
新後手スコア = HandScore + A − C − M

A（ボード補正）: ドライ=+10、セミ=+5、ウェット=0
C（ベット圧力）: 33%=12、50%=17、75%=22、100%=25、150%=30
M（マルチウェイ）: HU=0、3-way=12、4-way+=20

閾値:
  ≥ 65% → CR 検討（強優位）
  35〜64% → コール（ポットオッズ満たす）
  < 35% → フォールド（ポットオッズに届かない）
```

### 検証例

#### 例1: TPTK on K72r vs 50% bet (HU)

```
旧:
  HandScore = 18 (TPTK)
  後手スコア = 18 + 3 − 3 − 5 − 0 = 13 → CR 検討

新:
  HandScore = 68 (TPTK on dry, vs typical range ≈ 68% equity)
  後手スコア = 68 + 10 − 17 − 0 = 61 → 35〜64 でコール（境界）

判断: 旧「CR 検討」→ 新「コール」（やや境界寄り）
GTO 実測: TPTK on dry vs 50% は CR 30%、コール 70% → **新の方が GTO 寄り**
```

#### 例2: Set on K72r vs 75% bet (HU)

```
旧:
  HandScore = 30 (Set)
  後手スコア = 30 + 3 − 3 − 7 − 0 = 23 → CR 強推奨

新:
  HandScore = 88 (Set vs typical, approximately 88% equity)
  後手スコア = 88 + 10 − 22 − 0 = 76 → ≥65 で CR 検討

判断: 旧「CR 強推奨」→ 新「CR 検討」 ✓ 一致
```

#### 例3: TPMK on K72r vs 75% bet (HU)

```
旧:
  HandScore = 8 (TPMK)
  後手スコア = 8 + 3 − 3 − 7 − 0 = 1 → コール

新:
  HandScore = 50 (TPMK ≈ 50% equity)
  後手スコア = 50 + 10 − 22 − 0 = 38 → 35〜64 コール（境界）

判断: 一致
```

#### 例4: ハイカード on K72r vs 75% bet (HU)

```
旧:
  HandScore = 0 (役なし)
  後手スコア = 0 + 3 − 3 − 7 − 0 = −7 → フォールド

新:
  HandScore = 22 (A-high or random card ≈ 22% equity)
  後手スコア = 22 + 10 − 22 − 0 = 10 → < 35 フォールド ✓ 一致
```

## 結論

新 C/A/M 値は「**equity % で読み解ける**」スケール:

```
新 C (ベット圧力):     33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30
新 A (ボード補正):     ドライ=+10 / セミ=+5 / ウェット=0
新 M (マルチウェイ):   HU=0 / 3-way=12 / 4-way+=20

新後手スコア式:    後手スコア = HandScore + A − C − M
新閾値:            ≥65 で CR / 35〜64 でコール / <35 でフォールド
```

または **より暗算しやすい代替案**:

```
新 C は α 値そのまま:  33%=25 / 50%=33 / 75%=43 / 100%=50 / 150%=60
                       (= α の数値、「相手のフォールド要求率」)
新 A は 5/3/0:         (ドライ +5、セミ +3、ウェット 0)

新後手スコア式: 後手スコア = HandScore + A − C
新閾値（HU 想定）: ≥45 で CR / 25〜44 でコール / <25 でフォールド
```

**Phase 1 で決定する設計判断**:
1. C を「(1−MDF) × 50」とするか「α そのまま」とするか
2. A の絶対値（10/5/0 vs 5/3/0）
3. M の値（12/20 vs 10/15 など）
4. 閾値（65/35 vs 45/25）

これらは Phase 2 でシミュレーション + 既存 GTO 実測 (`knowledges/volume4/results/`) で再キャリブレーション必要。

## 推奨

「**equity % をそのまま読める**」設計を採用:
- HandScore = 自分の equity %
- C = (1 − MDF) × 50 = 12 / 17 / 22 / 25 / 30
- A = 10 / 5 / 0
- M = 0 / 12 / 20
- 後手スコア = HS + A − C − M
- 閾値 = 65 / 35（CR / コール / フォールド）

これで「後手スコア = 65 → 65% equity 水準で CR」と直感的に読める。
