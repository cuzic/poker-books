# HUD統計ベースの E 補正テーブル (巻3 第3章 素材)

検索日: 2026-04-21

## 概要

巻2 第17章では相手をNit / TAG / LAG / コールステーションの4分類で粗くE補正を適用した。
巻3 第3章では、HUD統計から連続値でE補正を精密に算出する方法を解説する。
本稿は旧付録M（`old_L_M_verification_hud.md`）を土台として、これを定量的・実践的に大幅拡張したものである。

## 1. HUD統計の基本指標

### 1-1. 指標一覧と定義

| 指標 | 正式名称 | 定義 | 収集タイミング |
|------|----------|------|---------------|
| VPIP | Voluntarily Put Money In Pot | 自発的にポットに参加した頻度。BBの強制投入は含まない。式: `参加回数 / (総手数 - ウォーク数)` | プリフロップ |
| PFR | Pre-Flop Raise | プリフロップでレイズした頻度 | プリフロップ |
| AFq | Aggression Frequency | 全ポストフロップアクションのうちベット+レイズが占める割合。`(Bet+Raise) / (Bet+Raise+Check+Call+Fold)` | ポストフロップ全体 |
| 3Bet% | 3Bet Percentage | オープンレイズに対してリレイズした頻度 | プリフロップ |
| Fold vs CBet | Fold to Flop CBet % | フロップCBetに対してフォールドした頻度 | フロップ |
| CBet% | Flop Continuation Bet % | プリフロップアグレッサーとしてフロップでCBetを打った頻度 | フロップ |
| Check-Raise% | Flop Check-Raise % | フロップでチェックレイズを行った頻度 | フロップ |

### 1-2. 6-max 100BB キャッシュゲームの標準値

以下はGTO近似プレイヤー（バランス型レギュラー）の目安値。

| 指標 | 低め | 標準（GTO近似） | 高め | 備考 |
|------|------|-----------------|------|------|
| VPIP | 18% 以下 | 24〜28% | 35% 以上 | 出典: [SplitSuit](https://www.splitsuit.com/the-most-important-poker-stat-vpip) |
| PFR | 13% 以下 | 20〜24% | 30% 以上 | VPIP との差は 3〜6% が標準 |
| AFq | 25% 以下 | 45〜55% | 65% 以上 | 出典: [BlackRain79](https://www.blackrain79.com/2017/10/what-are-the-best-poker-hud-stats.html) |
| 3Bet% | 3% 以下 | 5〜8% | 10% 以上 | 6-max では FRより 1〜2% 高め |
| Fold vs CBet | 45% 以下 | 48〜58% | 65% 以上 | 60%超でブラフCBet有効域 |
| CBet% (フロップ) | 45% 以下 | 55〜65% | 75% 以上 | 70%超は過剰、搾取可 |
| Check-Raise% | 5% 以下 | 8〜12% | 15% 以上 | 12%超は要警戒 |

### 1-3. サンプル数による信頼性補正

統計値は少ないサンプルでは確率論的ノイズが大きく、鵜呑みにすると誤搾取を招く。

| サンプル数 | 信頼度 | E値の扱い方 | 対応指標 |
|-----------|--------|-------------|---------|
| 0〜50 | 非常に低 | E = 0（初期値）を使用 | - |
| 50〜200 | 低〜中 | E の振れ幅を ±1 に縮小 | VPIP, PFR のみ参照可 |
| 200〜500 | 中〜高 | 標準テーブル通りに使用 | VPIP, PFR, AFq, CBet% |
| 500〜1000 | 高 | ポジション別・フロップ型別まで細分化可 | 全指標 |
| 1000超 | 非常に高 | サイチュエーション特化統計も信頼可 | Fold vs CBet, C-R% 等 |

出典: [SmartPokerStudy - HUD Reliability](https://smartpokerstudy.com/hud-reliability-number-of-hands-and-sample-sizes-226/), [BlackRain79 - Sample Size](https://www.blackrain79.com/2017/11/poker-hud-stat-sample-size.html)

**重要原則**: 500ハンド未満では、フロップ特化統計（Fold vs CBet, Check-Raise%）は「傾向の確認」程度に留め、それだけでE値を変更しない。

## 2. プレイヤータイプの連続分類

### 2-1. VPIP/PFR 2次元マップ

巻2の4分類は以下の連続座標系に拡張される。X軸 = VPIP、Y軸 = PFR。

```
PFR(%)
35 |                    [マニアック]
   |                   (35+/30+)
25 |         [TAG]         [LAG]
   |       (20-24/18-22) (28-35/22-28)
15 |  [Nit]
   | (≤18/≤13)    [Reg]     [Semi-LAG]
   |            (24-28/20-24)
 5 |                        [コールステ]
   |                       (35+/5-15)
   +-------------------------------------> VPIP(%)
     15    20    25    30    35    40
```

#### 各領域の代表的戦略想定

| ラベル | VPIP | PFR | VPIP−PFR差 | 想定戦略 |
|--------|------|-----|------------|---------|
| Nit | ≤18 | ≤13 | 2〜5 | プレミアムハンドのみ参加。CBet少ない。フォールド多い。 |
| TAG | 20〜24 | 18〜22 | 2〜4 | バランス型。GTO近似。搾取しにくい。 |
| Reg（バランス） | 24〜28 | 20〜24 | 3〜5 | ほぼGTO。実戦の基準点。 |
| Semi-LAG | 26〜32 | 20〜26 | 5〜8 | オープンは広いがポストはバランス。 |
| LAG | 28〜35 | 22〜28 | 4〜8 | 広いレンジ、高アグレ。ブラフ頻度高め。 |
| マニアック | 35超 | 28超 | 5以内 | 過剰アグレ。トラップが有効。 |
| コールステーション | 35超 | ≤15 | 20超 | 広くコール、ほとんどレイズしない。バリューベット推奨。 |

### 2-2. VPIP−PFR差（ギャップ）の解釈

ギャップ = VPIP − PFR は「パッシブ度」を示す最重要補助指標。

| ギャップ | 傾向 | E補正への影響 |
|---------|------|--------------|
| 0〜3 | 高アグレ（参加＝ほぼレイズ） | ブラフ頻度高め → CBetのノーフォールドリスク増 |
| 3〜6 | バランス型（標準） | 補正なし |
| 7〜12 | 中程度パッシブ（リンプ多め） | バリューベット追加可 |
| 13超 | 高パッシブ（コールステ傾向） | E補正を+方向（大きく搾取） |

### 2-3. 境界ケースの判定

**ケース1: VPIP/PFR = 28/22（ギャップ6）**
Semi-LAGとRegの境界。AFqが55以上ならLAG寄り（E: −1）。AFqが45以下ならReg（E: 0）。

**ケース2: VPIP/PFR = 22/10（ギャップ12）**
Nitの数字だがギャップが大きい。パッシブNit（リンプが多い）。E = +2〜+3。Fold vs CBetが55超なら +3 に確定。

**ケース3: VPIP/PFR = 40/36（ギャップ4）**
マニアック。AFq が 60 超ならE = −1〜−2（過剰ブラフ）。ただし Check-Raise% が 15超なら追加 −1。

## 3. E補正値の連続算出式

### 3-1. 基本E値の算出（プリフロップ指標から）

旧付録Mの5値（+3/+2/0/−2/−3）を連続値に精密化する。

**ステップ1: VPIP スコア（V_score）**

```
V_score = (VPIP − 26) / 4
```

VPIPが標準（26%）から離れるほどスコアが大きくなる。
- VPIP = 16 → V_score = −2.5（非常にタイト）
- VPIP = 26 → V_score = 0（標準）
- VPIP = 38 → V_score = +3.0（非常にルース）

**ステップ2: パッシブ度スコア（P_score）**

```
Gap = VPIP − PFR
P_score = (Gap − 5) / 3
```

ギャップが標準（5）を超えるほどパッシブ性が高い。
- Gap = 3 → P_score = −0.67（アグレ寄り）
- Gap = 5 → P_score = 0（標準）
- Gap = 14 → P_score = +3.0（コールステ）

**ステップ3: ポストフロップアグレスコア（A_score）**

```
A_score = (45 − AFq) / 10
```

AFqが標準（45%）より低いほどパッシブ（E+方向）。
- AFq = 65 → A_score = −2.0（ポストフロップ過剰アグレ）
- AFq = 45 → A_score = 0（標準）
- AFq = 25 → A_score = +2.0（ポストフロップ超パッシブ）

**ステップ4: E基本値の合成**

```
E_base = (V_score × 0.4 + P_score × 0.4 + A_score × 0.2)
E_base = clamp(E_base, −3.0, +3.0)
```

重み付け: VPIPとギャップが主要因（各40%）、AFqは補助（20%）。

### 3-2. フロップ特化指標による追加補正

サンプル数が500以上の場合、以下の追加補正をE_baseに加算する。

| 条件 | 補正値 | 意味 |
|------|--------|------|
| Fold vs CBet ≥ 65% | +0.5 | CBetブラフが非常に通りやすい |
| Fold vs CBet 58〜64% | +0.25 | CBetブラフがやや通りやすい |
| Fold vs CBet ≤ 45% | −0.5 | CBetに対してコール/レイズが多い |
| Check-Raise% ≥ 15% | −0.5 | フロップC-R要警戒 |
| Check-Raise% 12〜14% | −0.25 | フロップC-Rやや多め |
| CBet% ≥ 75% | −0.25 | 過剰CBetでブラフ混在（C-R有効） |
| 3Bet% ≤ 3% | +0.5 | 3betレンジ極端に狭い → 4betブラフ有効 |
| 3Bet% ≥ 10% | −0.5 | 3betブラフ多め → コールレンジ広げる |

```
E_final = clamp(E_base + Σ(フロップ補正), −3.5, +3.5)
```

実用上は小数点以下は0.5単位で丸める。

### 3-3. フロップ型別（7型）の補正係数

巻2のフロップ7型分類（Type A: 高カードドライ〜Type G: モノトーン）に対して、E値の「効き方」が異なる。

| フロップ型 | Nit寄り相手でのE効果 | コールステ相手でのE効果 | 推奨アクション |
|-----------|---------------------|------------------------|---------------|
| A型（高カードレインボー: K72r等） | E+が特に有効。CBetバリュー幅広い | E補正の恩恵小（相手もヒット少ない） | vs Nit: 大きいCBet / vs コールステ: 中サイズ |
| B型（中カードドライ: T64r等） | E+中程度。フロップコール多め | E−考慮。ターン読み重要 | E+のみCBet推奨 |
| C型（連続ウェット: JT9r等） | E+の優位小（相手もドロー持つ） | E−が顕著。チェックバック推奨 | 両タイプ: 慎重なCBet |
| D型（低カード: 543r等） | E+が有効（相手のレンジミス） | E−大（ルースは低カードヒット多い） | vs Nit: CBet / vs コールステ: チェック |
| E型（ペアボード: K44等） | E+大（セット範囲で圧迫） | E補正小（相手はセット=ショウダウン） | vs Nit: 大きいCBet |
| F型（2トーン: QJ4ss等） | E+で小〜中サイズCBet | E−で小さいCBetまたはチェック | フラッシュドローでE変化 |
| G型（モノトーン: AK7全スート等） | E+ですら慎重（自分のFDも重要） | E−大（ドロー多い） | 全タイプ: SPRと合わせて判断 |

## 4. 具体例 12ケース

### ケース1: TAG相手 - 高カードドライ IP

**状況**: BTN vs BB、KQ on K72r、SRP 100BB
**相手HUD**: VPIP 22 / PFR 18 / AFq 48 / Fold vs CBet 55% / サンプル 600手

計算:
- V_score = (22 − 26) / 4 = −1.0
- Gap = 22 − 18 = 4 → P_score = (4 − 5) / 3 = −0.33
- A_score = (45 − 48) / 10 = −0.30
- E_base = −1.0 × 0.4 + (−0.33) × 0.4 + (−0.30) × 0.2 = −0.40 − 0.13 − 0.06 = −0.59 → 丸め: **E = −0.5**
- フロップ補正: Fold vs CBet 55% → 補正なし

**巻2の粗い分類**: TAG → E = +1
**巻3の精密値**: E = −0.5（GTO近似に近い。CBetサイズ小〜中推奨）
**実際のアクション差**: 巻2ではE+1でブラフCBet頻度を上げる判断になったが、巻3では標準頻度を維持し、バリューCBetに集中する。

---

### ケース2: Nit相手 - 高カードドライ IP

**状況**: BTN vs BB、AK on Q72r、SRP 100BB
**相手HUD**: VPIP 15 / PFR 11 / AFq 30 / Fold vs CBet 68% / サンプル 800手

計算:
- V_score = (15 − 26) / 4 = −2.75
- Gap = 15 − 11 = 4 → P_score = −0.33
- A_score = (45 − 30) / 10 = +1.50
- E_base = −2.75 × 0.4 + (−0.33) × 0.4 + 1.50 × 0.2 = −1.10 − 0.13 + 0.30 = −0.93
- フロップ補正: Fold vs CBet 68% → +0.5
- E_final = −0.93 + 0.5 = −0.43 → 丸め: **E = −0.5**

※注: VPIPが低くAFqも低いが、Fold vs CBetが高い。旧付録Mの感覚（Nit = E+3）とは大きく異なる。この相手はFold vs CbetよりAFqの低さがポイントで、ポストフロップでの誤りが少ない。ここはE_baseの計算式再確認が必要なケース。

**補足再計算（直感確認）**:
Fold vs CBet 68% はブラフCBetが通りやすいことを示す。しかしAFqが低い（30%）ということはポストで滅多にアグレを見せない。これはNitではなくタイトパッシブの典型。
- 正確な分類: **タイトパッシブ（ロック）**
- 推奨: バリューベット毎回、ブラフCBetも中頻度で有効

**巻2の粗い分類**: Nit → E = +3
**巻3の精密値**: E = +2.5（Fold vs CBet補正で+方向、ただし過剰なブラフは不要）
**実際のアクション差**: 巻2の+3では過剰ブラフになりがち。精密値+2.5ではバリューCBetを最優先にし、ブラフCBetは選択的に。

---

### ケース3: コールステーション相手 - 低カードウェット OOP

**状況**: BB vs BTN、65s on 543r、SRP 100BB（OOP）
**相手HUD**: VPIP 42 / PFR 12 / AFq 22 / Fold vs CBet 38% / サンプル 1200手

計算:
- V_score = (42 − 26) / 4 = +4.0 → clampで上限 → +3.0
- Gap = 42 − 12 = 30 → P_score = (30 − 5) / 3 = +8.3 → clamp → +3.0
- A_score = (45 − 22) / 10 = +2.3
- E_base = 3.0 × 0.4 + 3.0 × 0.4 + 2.3 × 0.2 = 1.2 + 1.2 + 0.46 = 2.86 → clamp → **+3.0**
- フロップ補正: Fold vs CBet 38% → −0.5
- E_final = 3.0 − 0.5 = **+2.5**（バリューは厚めだがブラフは控える）

**巻2の粗い分類**: コールステ → E = −3
**巻3の精密値**: E = +2.5（ブラフしない、バリューベット拡大）

**注意**: 巻2の「コールステーションにはE = −3（控える）」という覚え方は正確ではない。コールステに対してはバリューベットを「より積極的に」すべき（E+方向）なのに、マイナスだと誤解を生む。巻3では符号の意味を整理し直す必要がある。→ 執筆注意点に記録。

**実際のアクション差**: 巻2ではE−3で「攻撃的なCBetを避ける」方向だったが、巻3では「ブラフCBetを避け、バリューCBetを拡大する」という正確な指針になる。

### ケース4: LAG相手 - 連続ウェットボード IP

**状況**: CO vs BB、KK on JT9r、SRP 100BB（IP）
**相手HUD**: VPIP 32 / PFR 26 / AFq 62 / Fold vs CBet 44% / Check-Raise% 16% / サンプル 700手

計算:
- V_score = (32 − 26) / 4 = +1.5
- Gap = 32 − 26 = 6 → P_score = (6 − 5) / 3 = +0.33
- A_score = (45 − 62) / 10 = −1.7
- E_base = 1.5 × 0.4 + 0.33 × 0.4 + (−1.7) × 0.2 = 0.60 + 0.13 − 0.34 = +0.39
- フロップ補正: Fold vs CBet 44% → −0.5 / Check-Raise% 16% → −0.5
- E_final = 0.39 − 0.5 − 0.5 = −0.61 → 丸め: **E = −0.5**

**巻2の粗い分類**: LAG → E = −2
**巻3の精密値**: E = −0.5（LAGだがVPIP/PFRギャップが小さく、C-R多いため注意）
**実際のアクション差**: 巻2の−2では「CBetを避けてチェックバック」になるが、巻3の−0.5では「Potの33〜50%サイズでCBet」し、C-Rされたらフォールドするという明確な計画が立てられる。

### ケース5: セミLAG相手 - 2トーンボード

**状況**: BTN vs BB、AJs on Q75ss（自分はハート持ち）、SRP 100BB IP
**相手HUD**: VPIP 29 / PFR 23 / AFq 52 / CBet% 72% / Fold vs CBet 50% / サンプル 550手

計算:
- V_score = (29 − 26) / 4 = +0.75
- Gap = 29 − 23 = 6 → P_score = +0.33
- A_score = (45 − 52) / 10 = −0.7
- E_base = 0.75 × 0.4 + 0.33 × 0.4 + (−0.7) × 0.2 = 0.30 + 0.13 − 0.14 = +0.29
- フロップ補正: CBet% 72% → −0.25（過剰CBet、ブラフ混在）
- E_final = 0.29 − 0.25 = +0.04 → 丸め: **E = 0**（事実上GTO想定）

**巻2の粗い分類**: LAG寄りの中間 → E = −1
**巻3の精密値**: E = 0（バランス型として扱う）
**実際のアクション差**: 巻2の−1ではレイズを控えたが、巻3ではGTO頻度でレイズし、FDのナッツアウトを活かしたセミブラフが正当化される。

### ケース6: マニアック相手 - ペアボード

**状況**: HJ vs BTN、TT on T44r（フルハウス）、SRP 100BB OOP
**相手HUD**: VPIP 45 / PFR 38 / AFq 68 / 3Bet% 12% / サンプル 400手

計算:
- V_score = (45 − 26) / 4 = +4.75 → clamp → +3.0
- Gap = 45 − 38 = 7 → P_score = (7 − 5) / 3 = +0.67
- A_score = (45 − 68) / 10 = −2.3
- E_base = 3.0 × 0.4 + 0.67 × 0.4 + (−2.3) × 0.2 = 1.2 + 0.27 − 0.46 = +1.01
- フロップ補正: 3Bet% 12% → −0.5
- サンプル400手 → フロップ補正信頼度「中」。補正は半分に: −0.25
- E_final = 1.01 − 0.25 = +0.76 → 丸め: **E = +1.0**

**巻2の粗い分類**: マニアック → E = −1（「混在、判断困難」と注記）
**巻3の精密値**: E = +1.0（バリューが通りやすい。フルハウスはスロープレイよりリード）
**実際のアクション差**: 巻2の−1ではトラップ（チェック）が推奨されたが、巻3の+1ではリードベットしてマニアックの過剰レイズを誘い、リレイズで返す計画が立てられる。

### ケース7: タイトパッシブ（ロック）- 中カードドライ

**状況**: CO vs BB、QQ on 972r、3bet Pot 100BB IP
**相手HUD**: VPIP 14 / PFR 9 / AFq 28 / Fold vs CBet 70% / サンプル 900手

計算:
- V_score = (14 − 26) / 4 = −3.0 → clamp → −3.0
- Gap = 14 − 9 = 5 → P_score = 0
- A_score = (45 − 28) / 10 = +1.7
- E_base = −3.0 × 0.4 + 0 × 0.4 + 1.7 × 0.2 = −1.20 + 0 + 0.34 = −0.86
- フロップ補正: Fold vs CBet 70% → +0.5
- E_final = −0.86 + 0.5 = −0.36 → 丸め: **E = −0.5**（予想より低い！）

**考察**: VPIPが14と非常に低いのにE_finalが−0.5になるのは、AFqが低くFold vs CBetが高いという相反する特性のためである。このロックは「ヒットしたときしか戦わないが、ミスしたらすぐ降りる」プロファイル。ポット参加自体が少ないため、3BetPotに来ているなら強いハンドの可能性が高い。

**実際のアクション差**: 巻2の+3では過剰なCBetになる。巻3の−0.5では「相手のレンジが強い3BetPot特性を優先し、CBetサイズは小〜中で、ターンは慎重」という戦略になる。

### ケース8: レギュラー（バランス）- モノトーン

**状況**: BTN vs CO（3Bet）、AKo on K87（全クラブ）、3Bet Pot IP
**相手HUD**: VPIP 26 / PFR 21 / AFq 50 / Fold vs CBet 52% / サンプル 1500手

計算:
- E_base = 0 × 0.4 + (−0.33) × 0.4 + (−0.5) × 0.2 = 0 − 0.13 − 0.10 = −0.23
- フロップ補正: なし（全指標が標準域）
- E_final = −0.23 → 丸め: **E = 0**（GTO想定で行動）

**実際のアクション差**: E = 0なので、ソルバー推奨の混合戦略（CBet 40% / チェックバック 60%等）をそのまま実行。

---

### ケース9: 中間パッシブ - フラッシュドロー完成ターン

**状況**: BTN vs BB、Kh5h on AhJh（フロップ）、ターンで相手チェック
**相手HUD**: VPIP 33 / PFR 14 / AFq 35 / Check-Raise% 8% / Fold vs CBet 55% / サンプル 600手

計算:
- V_score = (33 − 26) / 4 = +1.75
- Gap = 33 − 14 = 19 → P_score = (19 − 5) / 3 = +4.67 → clamp → +3.0
- A_score = (45 − 35) / 10 = +1.0
- E_base = 1.75 × 0.4 + 3.0 × 0.4 + 1.0 × 0.2 = 0.70 + 1.20 + 0.20 = +2.10
- フロップ補正: Fold vs CBet 55% → 補正なし / Check-Raise% 8% → 補正なし
- E_final = **+2.0**（バリューベット拡大）

**実際のアクション差**: コールステ寄りの相手。フラッシュドロー完成ボードでもターンバリューベットを通常より大きく（Pot75%）。

---

### ケース10: サンプル少 - 判断保留の例

**状況**: SB vs BTN、JJ on 873r、SRP 100BB OOP
**相手HUD**: VPIP 28 / PFR 22 / AFq 55 / サンプル 80手（Fold vs CBet: 3機会のみ）

計算:
- サンプル80手 → E は ±1 に縮小。フロップ補正は使用しない。
- V_score = +0.5 / P_score = +0.33 / A_score = −1.0
- E_base = 0.20 + 0.13 − 0.20 = +0.13
- 縮小後: E_final = clamp(0.13, −1.0, +1.0) → **E ≈ 0**（デフォルト戦略）

**実際のアクション差**: サンプル不足のため、GTO戦略に従いチェックバックから入りターンの挙動を観察してからE判断を更新する。

---

### ケース11: 3Bet極小 - プリフロップエクスプロイト

**状況**: BTN オープン、BB が 3Bet可能な位置
**相手HUD**: VPIP 19 / PFR 15 / AFq 45 / 3Bet% 2% / サンプル 1000手

計算:
- E_base ≈ −0.8（タイト寄り）
- フロップ補正: 3Bet% 2% → +0.5
- E_final = −0.8 + 0.5 = **−0.3 → E = 0**

**特記**: 3Bet%が2%以下は「プリフロップ3betレンジ = ほぼプレミアムのみ」。4Betブラフが有効。これはポストフロップのCBet頻度よりもプリフロップ戦略に直接影響するため、第3章の補足項目として扱う。

---

### ケース12: 境界LAG + 高CR% - 最難関ケース

**状況**: HJ vs BTN（コールド）、A8s on A52r、SRP 100BB OOP
**相手HUD**: VPIP 30 / PFR 25 / AFq 60 / Check-Raise% 18% / Fold vs CBet 42% / 3Bet% 9% / サンプル 1100手

計算:
- V_score = +1.0 / Gap = 5 → P_score = 0 / A_score = −1.5
- E_base = 0.40 + 0 − 0.30 = +0.10
- フロップ補正: Fold vs CBet 42% → −0.5 / Check-Raise% 18% → −0.5 / 3Bet% 9% → −0.5
- E_final = 0.10 − 1.5 = **−1.4 → E = −1.5**（要注意 LAG）

**巻2の粗い分類**: LAG → E = −2
**巻3の精密値**: E = −1.5（やや抑制、ただし過剰なチェックもNG）
**実際のアクション差**: TPTK（A8s on A52r）でのCBetは小サイズ（Pot33%）で行い、C-Rに対してはフォールド。チェックバックからインダクションを狙う選択肢が増える。

## 5. オフライン（ライブ）での代用法

### 5-1. ライブでのVPIP推定法

HUDがないライブでは、1オービット（6〜9ハンド）の観察でVPIPを粗く推定できる。

| 観察窓 | 参加手数 | 推定VPIP | 分類 |
|--------|---------|---------|------|
| 10手で1〜2回参加 | 15〜20% | Nit〜TAG |
| 10手で2〜3回参加 | 20〜30% | TAG〜Reg |
| 10手で3〜4回参加 | 30〜40% | Semi-LAG |
| 10手で4回以上参加 | 40%超 | コールステ〜マニアック |

出典: [SplitSuit - Exploiting Poker Player Types](https://www.splitsuit.com/exploiting-poker-player-types/)

### 5-2. PFR推定の代用観察

「参加手数のうち何回レイズしているか」を数える。

- 参加のほぼ毎回レイズ → 高PFR（LAG / TAG）
- 参加の半分以下でレイズ → 低PFR（パッシブ）
- ほぼリンプのみ → 極低PFR（コールステ / ロック）

### 5-3. AFq推定の代用観察

フロップ以降の行動パターンを数回追跡する。

| 観察ポイント | ベット/レイズ多い | チェック/コール多い |
|------------|-----------------|------------------|
| フロップ | AFq高め (>50%) | AFq低め (<40%) |
| ターン継続 | AFq高め確認 | パッシブ確定 |
| ブラフショウダウン | 確認できればLAG/マニアック | 確認できればタイトパッシブ |

### 5-4. Fold vs CBet代用観察

「前の3ハンドでCBetを打たれた際にどうしたか」を記録する。
- 3回のうち2回以上フォールド → Fold vs CBet 67%以上相当 → ブラフCBet有効
- 3回のうち2回以上コール/レイズ → Fold vs CBet 33%以下相当 → バリューCBet重視

### 5-5. Check-Raise%代用観察

C-Rは頻度が低い（標準8〜12%）ため、1回の観察でも情報価値が高い。

- 過去のハンドでC-Rを1回見た → C-R%が高い可能性、以後フロップC-Rを警戒
- C-Rを一度も見ていない（20手以上） → C-R%低め。フロップCBetに安心感

### 5-6. ライブでのE推定フローチャート

```
[プリフロップ参加頻度を1オービット観察]
     |
     +-- 低 (20%以下): タイト寄り → E_base候補: +1〜+2
     |
     +-- 標準 (20〜30%): バランス → E_base候補: 0
     |
     +-- 高 (30%超): ルース → E_base候補: −1〜+1（ギャップ次第）
                                        |
                      [参加時のアクション確認]
                           |
                +----------+----------+
                |                     |
              レイズ多い           リンプ多い
           (高PFR相当)           (低PFR相当)
           E_base−0.5          E_base+1.0
                |
         [ポストフロップ挙動]
                |
         +------+------+
         |             |
      CBet多い      チェック多い
      (AFq高め)     (AFq低め)
      E −0.3        E +0.5
```

### 5-7. ライブ10秒チェックリスト（実戦カード）

各相手に初遭遇したときの5項目チェック（実戦で暗記推奨）:

1. **リンプしてきたか？** → Yes → E +0.5（パッシブ寄り）
2. **3betを過去に見たか？** → Noなら3bet%低め → E +0.3
3. **CBetに対して折れたか？** → Yes → E +0.3
4. **チェックレイズを見たか？** → Yes → E −0.5（要警戒）
5. **ショウダウンで弱いハンドを見せたか？** → Yes → E −0.5（ブラフ屋）

合計スコアを加算してE_liveを導出。最大+2.0〜−1.5の範囲に収める。

出典: [Red Chip Poker - Basic HUD Stats](https://redchippoker.com/basic-hud-stats/), [SplitSuit - Live Poker Cash Game Truths](https://www.splitsuit.com/live-poker-cash-game-truths)

### 執筆上の注意点

1. **コールステーションのE符号問題**: 巻2のE = −3（コールステ）という表記は、「CBetを控えよ」という意味で使われていたが、「バリューベットを多くしブラフを減らす」が正確。巻3では符号の再定義または脚注で補足が必要。

2. **サンプル数の章内強調**: 実用上、500ハンド未満の場面がほとんど。「まず標準テーブルで出発し、サンプルが増えるにつれて精密値に収束させる」という動的なアプローチを章の中心に置く。

3. **式の暗算困難性への対処**: E_base算出式（3ステップ）は実戦では計算困難。暗算用の「スコアカード版」（5分類に区切った近似テーブル）をサイドバーに掲載する。

4. **巻2との連続性**: 「巻2のE = +3はVPIP≤18/AFq≤30/Fold vs CBet≥65%の三拍子が揃ったときに限る」と明示し、巻2読者が混乱しないよう橋渡し説明を冒頭に入れる。
