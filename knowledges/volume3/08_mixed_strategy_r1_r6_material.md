## 1. 各ルールの背景と搾取耐性理論

### 搾取の構造

9マスマトリクスを決定論的に使うと、D3 頻度カテゴリとHandScoreの組み合わせからアクションが一意に決まる。観察者は次の情報を得られる:

- 「このD3 = 高頻度ボードで相手がチェックした → 弱いハンドしか持っていない」
- 「75% CBetを打ってきた → 強ハンド確定（高頻度 × 強セル）」

これが「ベット/チェックからのハンド逆算」であり、意識的な相手に50ハンド前後で学習される。

### R1-R6 の役割分担

| ルール | 解決する搾取スポット | 理論的根拠 |
|--------|---------------------|-----------|
| R1（3バンド化） | 境界セルの特定が曖昧 → 適用スコープを明確化 | 混合が必要なセルとそうでないセルを分離 |
| R2（スート判定） | 境界セルで同一アクションを取る → パターン化 | 擬似ランダム化で観察コストを天文学的に増大 |
| R3（レンジ補正） | D3がポジション有利不利を無視する → 過不足 | レイザー/コーラーの非対称をカテゴリシフトで近似 |
| R4（サイズ2択） | サイズが固定 → サイズからハンド逆算される | ナッツアドバンテージ軸でサイズを分岐させ逆算不可に |
| R5（チェック保護） | チェックレンジが弱のみ → 安易なブラフ搾取 | 強ハンドの一部をチェックに混入してチェックレンジを守る |
| R6（MDF補正） | 相手のタイプを無視したMDF → 搾取または過剰防御 | 相手スタイルでMDFを±10%調整して収支を最適化 |

### 組み合わせ効果

R1 でスコープを絞り、R2 でランダム化し、R3 でレンジ非対称を補正し、R4 でサイズを揺らし、R5 でチェックレンジを守り、R6 でディフェンス量を最適化する。6ルールは独立して機能するが、組み合わせることで「サイズ」「頻度」「チェックレンジ構成」の3次元が同時に揺れる。相手は単一の観察軸では解析できなくなる。

GTO Wizard の研究（The Mechanics of C-Bet Sizing, 2023）は「ナッツアドバンテージがサイズを、レンジアドバンテージが頻度を決める」と述べており、R4（サイズ）と R3（頻度カテゴリ）がこの2軸に対応する。

## 2. R1: 9マスマトリクスの3バンド化

### 定義（巻2 9マスマトリクス前提版）

巻2 の 9マスマトリクス（D3 頻度カテゴリ × HandScore カテゴリ）の9セルを3バンドに分類する。

```
バンドA（ベット確定）: アクションが一意に決まるセル
  ・高頻度 × 強 → CBet 75%確定
  ・高頻度 × 中 → CBet 33%確定
  ・中頻度 × 強 → CBet 50%確定
  ・低頻度 × 強 → CBet 50%確定

バンドB（境界・混合ゾーン）: R2で判断を分岐させるセル
  ・高頻度 × 弱 → CBet 33% or チェック
  ・中頻度 × 中 → CBet 33% or チェック
  ・低頻度 × 中 → チェック優先、稀に50%（R2で例外）

バンドC（チェック確定）: チェック一択のセル
  ・中頻度 × 弱
  ・低頻度 × 弱
```

### バンドB が全体の40〜50%を占める根拠

境界セルに該当するハンドの頻度推計:

- 高頻度ボード（D3 ≥ 70%）でHS 0-4（弱）のハンド: 空振りとBDFDのみのコンボ → 各ハンドレンジの約20-30%
- 中頻度ボード（D3 40-69%）でHS 5-14（中）のハンド: TP弱キッカー・中程度ドロー → 約25-35%
- 合計で全ハンドの40〜50%程度がバンドBに該当

旧ドラフトの「40〜50%」という数値は妥当。巻3では「バンドBに入ったときだけR2を使う」という限定適用が重要。

### R1 ミニクイズ5問

**Q1.** D3 = 75%（高頻度）、HandScore = 18（強）のとき、バンドは？

解: バンドA（高頻度 × 強 → CBet 75%確定）。R2は不要。

**Q2.** D3 = 50%（中頻度）、HandScore = 10（中）のとき、バンドは？

解: バンドB（中頻度 × 中 → R2で決定）。

**Q3.** D3 = 30%（低頻度）、HandScore = 3（弱）のとき、バンドは？

解: バンドC（低頻度 × 弱 → チェック確定）。R2不要。

**Q4.** D3 = 80%（高頻度）、HandScore = 2（弱）のとき、バンドは？

解: バンドB（高頻度 × 弱 → R2で決定）。

**Q5.** D3 = 45%（中頻度）、HandScore = 25（強）のとき、バンドは？

解: バンドA（中頻度 × 強 → CBet 50%確定）。R2不要。

## 3. R2: スート判定（フロップ版10ケース以上）

### 定義

バンドBの境界セルに入ったとき、**手札の高い方のカードのスート**でアクションを決定する。

```
♠ または ♥ → アクション側（CBet 33% / より大きいサイズを選択）
♣ または ♦ → 受動側（チェック / より小さいサイズを選択）
```

ポケットペアは「左で持っている方」を基準とする（実戦では任意の一貫した方法で可）。

### なぜスートを使うのか

ハンドのスートは相手から見えない。かつ、スート分布は均等（各スート25%）であるため、観察によって解析不能である。フロップの組み合わせ1,755通り × ハンド169種 × ポジション5パターン × スート判定という多層の分岐は、現実の観察では解析不可能。

## 4. R3: D3 カテゴリ補正とレンジアドバンテージ

### 定義（巻3版：9マスマトリクス前提）

D3 頻度カテゴリ（低/中/高）を、プリフロップの立場とボードのトップカードで±1段階シフトする。

```
+1段階（積極的方向）:
  ・ハイカードフロップ（A/K/Q が1枚以上）× 自分 = レイザー
  ・ローカードフロップ（J以下が最高ランク）× 自分 = コーラー（BB等）

−1段階（消極的方向）:
  ・ハイカードフロップ × 自分 = コーラー
  ・ローカードフロップ × 自分 = レイザー

変化なし:
  ・Jトップボード（中間的なため変化なし、または微小で切り捨て）
  ・ミドルカードフロップ（判断つかず）
```

### D3 との関係

D3 チェックリストはすでにトップカード（ハイ/ロー）を Step4 の 2×2 マトリクスで反映している:

```
ハイ（A/K/Q）× ドライ = 85%（高頻度）
ハイ × ウェット      = 55%（中頻度）
ロー × ドライ        = 55%（中頻度）
ロー × ウェット      = 30%（低頻度）
```

D3 はレンジ全体の平均頻度を与える。R3 が補正するのは「自分の立場（レイザー/コーラー）」という D3 が捉えていない変数。レイザーはハイカードボードで非対称にナッツが多く、コーラーはローカードボードで非対称にヒットしやすい。この非対称を1段階シフトで近似する。

### 補正値の根拠

GTO Wizard の集計データ（Aggregate Flop Strategy）によれば:

- BTN（レイザー）vs BB（コーラー）SRP でのハイカードボード（K72r 等）での BTN CBet 頻度: 約75-85%
- 同ボードでの BB ドンクベット頻度: 約5-15%

この非対称は約60-70%ptの差であり、マトリクスの「高頻度（≥70%）vs 低頻度（≤39%）」の区分と一致する。+1段階（低→中、または中→高）はこの方向性を正しく反映する。

### R3 ミニクイズ5問

**Q1.** ボード J♦8♣3♥（ロー×ドライ）、IP レイザー。D3 素 = 55%（中頻度）。R3 補正後のカテゴリは？

解: Jがトップ → ロー扱い。レイザー×ロー → −1段階 → **低頻度**。

**Q2.** ボード A♣7♦2♠（ハイ×ドライ）、OOP コーラー(BB)。D3 素 = 85%（高頻度）、OOP補正後 中頻度。R3 補正後は？

解: ハイ×コーラー → −1段階 → **低頻度**。

**Q3.** ボード 9♠8♣4♦（ロー×ドライ）、OOP コーラー(BB)。D3 素 = 55%（中頻度）、OOP補正後 低頻度。R3 補正後は？

解: ロー×コーラー → +1段階 → **中頻度**（OOP補正と相殺で元の中頻度に戻る）。

**Q4.** ボード K♥Q♦9♠（ハイ×ウェット）、IP レイザー。D3 素 = 55%（中頻度）。R3 補正後は？

解: ハイ×レイザー → +1段階 → **高頻度**。

**Q5.** ボード 6♣5♦2♠（ロー×ドライ）、IP レイザー。D3 素 = 55%（中頻度）。R3 補正後は？

解: ロー×レイザー → −1段階 → **低頻度**。

## 5. R4: サイズ2択の判定（NutsAdv 判定、20ケース）

### 定義

CBetを打つことが確定したとき（バンドA または R2でベット選択された境界セル）、サイズを33% か75% に二択化する。

```
NutsAdv 判定:
  自分レンジのナッツ（セット以上、または最強FD、または最強ストレート）が
  相手レンジより多い場合 → 75%
  
  相手レンジのナッツが同等または多い場合、または拮抗 → 33%
```

マトリクスの50%サイズ（中頻度 × 強、低頻度 × 強）も R4 で 33% か75% に振り分ける。

### サイズ選択の背景

GTO Wizard（The Mechanics of C-Bet Sizing, 2023）は「ナッツアドバンテージがある側は大サイズを使う」と明示している。R4 はこの原則を「上位10%ナッツを自分が持つか否か」という暗算可能な判定に落とし込む。

| 16 | 6♦5♣4♠ | OOP コーラー(BB) | 78s/65s/54s がBBに多い | 75% | コーラーがナッツ多 |
| 17 | K♦K♠7♣（ペア）| IP レイザー | KK はBTNに多い | 75% | レイザーがナッツ多 |
| 18 | A♠A♦3♣（ペア）| IP レイザー | AA はBTNに多い | 75% | レイザーがナッツ多 |
| 19 | 8♣7♦6♠（ロー連続）| IP レイザー | BTN には 65s/T9s が少ない | 33% | 拮抗〜劣位 |
| 20 | K♥Q♦J♠（ハイ×ウェット）| IP レイザー | AK/AQ がBTNに多い | 75% | レイザーがナッツ多 |

### R4 と R2 の組み合わせ（サイズをさらに揺らす効果）

バンドAの確定セルで R4 が75% を指定している場合でも、R2（スート判定）と組み合わせると実際のサイズが混合する:

例: K♠7♦2♣（高頻度 × 強）、ハンド = KQ

- K♠Q♥（Kが♠）→ バンドA確定、R4 = NutsAdv あり → 75%。R2 は バンドBのみ適用なので関係なし → **75%**
- K♣Q♦（Kが♣）→ バンドA確定、R4 = 75%。ただし R5 の観点からチェック候補になる可能性あり

注: R2 はバンドBのみに適用。バンドAでのサイズ分岐は R4 + R5 の組み合わせで生じる。

### R4 ミニクイズ5問

**Q1.** K♠T♦5♣（ハイ×ドライ）、IP レイザー、バンドA確定。R4 のサイズは？

解: KKやTT、55がレイザーに多い → NutsAdv → **75%**。

**Q2.** T♥9♠8♦（ロー連続）、IP レイザー、バンドA確定。R4 のサイズは？

解: 最強ストレート（67、JT）はコーラーレンジに多い → 拮抗 → **33%**。

**Q3.** 7♦6♣4♠（ロー×ドライ）、OOP コーラー(BB)、バンドA確定。R4 のサイズは？

解: 54s/66/44がBBに多い → NutsAdv → **75%**。

**Q4.** A♣K♦Q♠（ハイ連続）、IP レイザー、バンドA確定。R4 のサイズは？

解: AK/AQ/AA/KK がBTNに多い → NutsAdv → **75%**。

**Q5.** J♦8♣4♦（ロー×ウェット）、IP レイザー、バンドA確定。R4 のサイズは？

解: JJは有るが、♦FDはBBにも多く拮抗 → **33%**。

## 6. R5: チェックレンジ保護と強ハンドの判別

### 定義

バンドA（ベット確定）セルに入っていても、以下のハンドはチェック候補に回す。

```
チェック候補（スート判定で受動側に回す）:
  AA, KK, QQ（オフスート）: ♣♦ なら チェック
  AK, AQ（オフスート）: 50% の確率でチェック（スート判定で近似）
  
  スーテッドのプレミアムは CBet で最大化（ドロー価値を含む）
```

「チェック＝弱い」という思い込みを崩し、チェックレンジにナッツを混入させることで相手の安易なバレルを封じる。

### チェック候補の選び方（判別フロー）

```
Step 1: バンドA（高頻度 × 強）確定か？ → No ならR5不要
Step 2: ハンドはAA/KK/QQ/AK/AQ か？ → No ならR5不要
Step 3: オフスートか？ → No（スーテッド）ならCBet継続
Step 4: スート判定（高い方のカード）
  ♣ または ♦ → チェック候補
  ♠ または ♥ → CBet継続（R5チェックは行わない）
```

### 具体例（チェック候補 vs CBet 継続）

| ハンド | ボード例 | R5 判定 | 理由 |
|--------|---------|---------|------|
| A♣A♦（オフスート） | K♥7♣2♦ | チェック候補（♣基準） | オフスート、♣受動側 |
| A♠A♥（スーテッド） | K♥7♣2♦ | CBet継続（♠） | スーテッド → フラッシュドロー価値あり |
| A♣K♦（オフスート） | A♥8♣5♠ | チェック候補（♣基準） | TPTK をトラップに |
| A♠K♣（オフスート） | A♥8♣5♠ | CBet継続（♠） | ♠はアクション側 |
| K♣Q♦（オフスート） | K♠7♥2♣ | チェック候補（♣基準） | TPTK のチェック混入 |
| Q♠Q♦（オフスート） | J♥8♣4♦ | チェック候補（♦基準） | QQ のチェックトラップ |
| Q♥Q♠（スーテッド） | J♥8♣4♦ | CBet継続（♥） | スーテッド優先 |

### チェックレンジ保護の搾取耐性

R5 を使わない場合、チェックレンジの最高 HandScore はおよそ HS=8〜14（中ハンド）に留まる。相手はターンで機械的にバレルを打てる。R5 でHS=30 前後のハンドをチェックレンジに混入させると、チェックレンジの上限が「セット相当」まで上昇し、相手のオートバレルを抑止する。

GTO Wizard の研究（Balancing Your Check-Back Range, 2023）でも「IPのチェックバックレンジには常に強いハンドを含めるべき」と明示されている。

### R5 ミニクイズ5問

**Q1.** ハンド K♣K♦（オフスート）、バンドA確定。R5 の判定は？

解: KK オフスート、♣基準 → ♣は受動側 → **チェック候補**。

**Q2.** ハンド A♥A♠（オフスート）、バンドA確定。R5 の判定は？

解: AA オフスート、♥基準 → ♥はアクション側 → **CBet継続**（R5チェックは行わない）。

**Q3.** ハンド A♣K♠（オフスート）、バンドA確定。R5 の判定は？

解: AK オフスート、A（高い方）が♣ → ♣は受動側 → **チェック候補**。

**Q4.** ハンド A♥K♥（スーテッド）、バンドA確定。R5 の判定は？

解: AK スーテッド → スーテッド優先 → **CBet継続**。ドロー価値を活かす。

**Q5.** ハンド Q♠J♠（スーテッド）、バンドA確定。R5 の判定は？

解: QJ は AA/KK/QQ/AK/AQ 以外 → **R5 対象外**。バンドAならCBet継続。

## 7. R6: MDF ±10% と相手タイプ別ディフェンス

### 定義

基本 MDF に対して、相手のプレイスタイルで ±10% 補正する。

```
相手がブラフ寄り（LAG型：VPIP 30%超、PFR 25%超、連打・小サイズ繰り返し）
  → MDF +10%（より広くディフェンスが必要）

相手がバリュー寄り（ロック型：VPIP 15%以下、PFR 13%以下、大サイズ・低頻度ベット）
  → MDF −10%（より多くフォールドしてよい）

判断つかず（情報なし）
  → 基本 MDF をそのまま使用
```

### 基本 MDF 表

| ベットサイズ | 基本 MDF | LAG補正(+10%) | ロック補正(−10%) |
|------------|---------|-------------|--------------|
| 25% | 80% | 90% | 70% |
| 33% | 75% | 85% | 65% |
| 50% | 67% | 77% | 57% |
| 75% | 57% | 67% | 47% |
| 100% | 50% | 60% | 40% |

### 具体例（MDF調整の計算）

**例1: LAG型相手の33% CBetに対して**

```
基本 MDF = 75%
R6: LAG（VPIP 35%、PFR 28%）→ +10%
最終 MDF = 85%
→ 85%のレンジでディフェンス必要。15%しかフォールドできない。
```

**例2: Nit型相手の75% CBetに対して**

```
基本 MDF = 57%
R6: Nit（VPIP 12%、PFR 10%）→ −10%
最終 MDF = 47%
→ 53%フォールドしてよい。Nit の 75% は強ハンドのバリュー確率が高い。
```

**例3: VPIP 20〜25%程度の標準的な相手の50% CBetに対して**

```
基本 MDF = 67%
R6: 補正なし
最終 MDF = 67%
→ 33%のレンジはフォールドしてよい。
```

### チェックレイズ側への R6 適用

R6 はディフェンス側だけでなく、チェックレイズを行う側にも応用できる。

相手のCBetサイズが大きい（75%）場合、相手レンジはバリュー寄りに絞られる。この状況でのチェックレイズブラフは EV が下がるため、チェックレイズの閾値を上げる（よりナッツに近いハンドに限定）。

相手のCBetサイズが小さい（33%、レンジベット）場合、相手レンジはバリューからブラフまで広く、チェックレイズのセミブラフが通りやすい。HandScore 12以上でセミブラフ候補の基準をそのまま適用できる。

### LAG vs Nit vs TAG の判定目安

| タイプ | VPIP | PFR | 特徴 | R6 補正 |
|--------|------|-----|------|---------|
| Nit/ロック | ≤15% | ≤13% | 大サイズ・低頻度、バリューのみ | −10% |
| TAG（標準） | 20-25% | 16-22% | バランス型 | 補正なし |
| LAG | 30%超 | 25%超 | 連打、小サイズ多用、頻繁CB | +10% |
| マニアック | 40%超 | 35%超 | 極端なオーバーブラフ | +10%（上限） |

### R6 ミニクイズ5問

**Q1.** 相手LAG（VPIP 32%）が75% CBetを打ってきた。基本 MDF = 57%。R6 適用後は？

解: ブラフ寄り → +10% → **MDF 67%**。33%しかフォールドできない。

**Q2.** 相手ロック（VPIP 12%）が33% CBetを打ってきた。基本 MDF = 75%。R6 適用後は？

解: バリュー寄り → −10% → **MDF 65%**。35%フォールドしてよい。

**Q3.** 相手の情報がない（新しいテーブル）、50% CBetに直面。R6 適用後は？

解: 補正なし → **MDF 67%**（基本値そのまま）。

**Q4.** 相手LAG（VPIP 38%）が100% CBetを打ってきた。基本 MDF = 50%。R6 適用後は？

解: ブラフ寄り → +10% → **MDF 60%**。40%しかフォールドできない。

**Q5.** 相手ロック（VPIP 14%）が75% CBetを打ってきた。チェックレイズを検討中。どの判断が適切か？

解: バリュー寄り（MDF 47%、53%フォールド可）。チェックレイズのブラフ閾値を上げ、ナッツまたはナッツドロー（OESD + トップペア等、HS 20以上）に限定する。

## 8. 混合戦略の搾取耐性: R1-R6 の組み合わせ理論

### 搾取不可条件と GTO

GTO（Game Theory Optimal）戦略が搾取不可能である条件は「相手がどのアクションで搾取しようとしても EV が最大化されない」こと。純粋戦略（決定論的）はこの条件を満たさない場合が多い。

混合戦略（同一状況で複数のアクションを確率的に実行）を使うことで、相手の最良応答の EV を下げる。

### R1-R6 の組み合わせが搾取耐性を高める理由

1. **サイズのランダム化（R4 + R2）**: 同一ハンドで時に33%、時に75%が登場する。サイズからのハンド逆算を防ぐ。
2. **頻度のランダム化（R2）**: 境界セルで50%:50%の分岐。観察者は平均的にどちらでもある事実しか学習できない。
3. **チェックレンジへの強ハンド混入（R5）**: チェックが「弱い」という等式を崩す。
4. **ディフェンス量の適応化（R6）**: 相手タイプに応じてMDFを調整し、ブラフ過多の相手に対してタイトフォールドを避ける。
5. **フロップ頻度の調整（R3）**: レンジ非対称をカテゴリシフトで反映し、不利なボードで安易にベットしない。

### GTO とのズレの定量評価

BDM v5 の検証データ（knowledges/volume3/05_bdm_v5_extension_material.md）によれば:

- D3 単体: R² = 0.873、MAE = 6.03%
- BDM v5（D3 + 精密補正）: R² = 0.914、MAE = 5.27%

R1-R6 は BDM v5 の精密補正より粗い（カテゴリシフトのみ）が、「境界セルの混合化」によって GTO との EV ギャップを実戦レベルで許容範囲内に収める。

境界セルの純粋戦略（常にベット or 常にチェック）から混合戦略（R2 による50%:50%）への移行で、GTO との頻度ズレが約40-60%pt から 0-10%pt 程度に縮小する。

### 残る限界

- 頻度の粒度: R2 は50:50固定。GTO が推奨する37:63や45:55は再現不可。
- ターン・リバーへの引き継ぎ: フロップで混合を選んでも、ターンで新しいD3+HandScore を再計算する必要がある。フロップの混合がターンの最適戦略と連続していない。
- 多次元最適化: GTO はブロッカー効果、レンジ全体のバリュー/ブラフ比率を同時最適化。R1-R6 はこれを単変数ずつ近似するため、相互作用が残る。

## 9. 実戦ドリル素材（各ルール統合クイズ）

### 統合問題1: R1→R2 の完全適用

**状況**: BTN（IP、レイザー）vs BB。ボード A♣8♦5♦（ハイ×ウェット）。D3 = 55%（中頻度）。ハンド K♠Q♥（空振り + バックドアFD）。HandScore = 4（弱）。

R1バンド → R3補正 → R2判断 → 最終アクション（スペードのKの場合とダイヤのKの場合）を示せ。

**解答**:

```
D3 = 55%（中頻度）
R3: ハイカードフロップ × レイザー → +1段階 → 高頻度

マトリクス: 高頻度 × 弱（HS=4） → バンドB（混合ゾーン）

R2: 高い方のカード = K♠ → ♠ → アクション側 → CBet 33%
   （K♦の場合 → ♦ → 受動側 → チェック）
```

### 統合問題2: R4 + R5 の組み合わせ

**状況**: BTN（IP、レイザー）vs BB。ボード A♥K♣Q♦（ハイ×ウェット）。D3 = 55%（中頻度）。ハンド A♣A♦（オフスート、セット）。HandScore = 30（強）。

R1バンド → R4 サイズ → R5 判定 → 最終アクションを示せ。

**解答**:

```
D3 = 55%（中頻度）
R3: ハイ × レイザー → +1段階 → 高頻度
マトリクス: 高頻度 × 強（HS=30） → バンドA（CBet確定）

R4: A♥K♣Q♦でAAセット → NutsAdv → 75%

R5: AA オフスート（A♣、♣は受動側）→ チェック候補

最終: AKQウェットボードでのAAセット × オフスートは R5 でチェック。
ターンでチェックコールを誘い込み、リバーでオーバーベットを狙う。
```

### 統合問題3: R6 適用後のコールフォールド判断

**状況**: BB（OOP）。BTN が A♣7♦2♠（ハイ×ドライ）で 75% CBetを打ってきた。相手は LAG（VPIP 31%、PFR 26%）。自分のハンドは 8♥8♣（ポケット8、オーバーペア）。HandScore = 20（強）。

R6 適用後の MDF と、コール/フォールドの判断を示せ。

**解答**:

```
基本 MDF（75% CB）= 57%
R6: LAG → +10% → 最終 MDF = 67%

88 はオーバーペア（HS=20）で十分ディフェンスレンジに入る。
A♣7♦2♠ で A はBTNに多いが、LAG補正で広くディフェンスが必要 → コール。
（ただし A がターンに落ちた場合は再評価が必要）
```

## 10. 巻3での最重要論点（3点）

### 論点1: R3 の補正方向の直感的な解説

旧ドラフトでは「+1段階/-1段階」の方向性の説明が直感に反しやすい（「ハイカードフロップでレイザー側が積極的になる」という感覚は正しいが、数学的根拠が薄い）。巻3では GTO Wizard の集計データ（BTN vs BB の SRP でのハイカードフロップ CB 頻度）を引用して定量化する。

### 論点2: R4 の NutsAdv 判定基準の明確化

旧ドラフトでは「上位10%ナッツが多い側」という定義が曖昧。巻3では「セット以上、または最強FD（ナットFD）、または最強ストレート（直接完成または OESD で最長）のコンボ数を両レンジで比較」というオペレーショナルな定義に書き換える。

### 論点3: R5 と R2 の優先順位の整理

旧ドラフトには「バンドAではR2を適用しない」ことが明示されているが、R5 は「バンドAでもチェックを選ぶ」ことを定義しているため、一部の読者が混乱する。巻3では「R1 → R3 → R4（バンドA確定後） → R5（プレミアムハンドのチェック候補化） → R6（ディフェンス側）」という適用順序を明示する。
