# 第6章　ターンオーバーベット

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ターンで100%以上のオーバーベット（OB）を使うべき状況を体系的に理解し、リバーOBとの目的の違いを踏まえた上で実戦判断に落とし込む。

---

## 6-1 ターンOBとリバーOBの目的の違い

オーバーベットとは、現在のポットサイズを超えるベット（100%pot以上）のことです。リバーOBは巻⑤「リバーOB」で扱いますが、本章ではターンOBを別のテーマとして独立させます。ターンOBとリバーOBは見た目のサイズは似ていても、目的が根本的に異なるからです。

```
リバーOB（巻⑤のテーマ）:
  目的: 最後の1回でバリューを最大化する
  文脈: ナッツ確定またはナッツに近い状態でのショーダウン前最終ベット
  結果: コールされてもフォールドされても、そこでハンドが終わる

ターンOB（本章のテーマ）:
  目的①: SPRをリバーでコミット圏に下げる（リバーの設計）
  目的②: フォールドエクイティを今すぐ回収する
  文脈: ナッツアドバンテージが最大の局面でポーラード化を加速させる
  結果: コールされるとリバーでSPRが約1以下になり、ほぼオールイン確定
```

リバーOBは「最後の1撃を大きく」というシンプルな発想です。一方、ターンOBは「リバーをどういう形で迎えるか」という先を見据えた設計行為です。

ターンで150%ベットして相手がコールした後のSPRを計算すると、リバーでスタックがほぼ消える状態になります。これを意図的に作り出すのがターンOBの本質です。コールされることも想定に入れながら、「コールされたリバーでの優位」を担保できているかどうかが判断の核心になります。

---

## 6-2 SPRとコミット圏の数学

ターンOBの効果を理解するには、SPR（スタック対ポット比率）の変化を追う必要があります。ここでは具体的な数値で確認します。

### 標準的なSRPでのSPR推移

6-max 100BB キャッシュゲーム、BTN vs BB のシングルレイズドポット（SRP）を想定します。

```
前提:
  フロップ開始時: ポット=6BB、スタック=94BB、SPR≈16

フロップCBet 50% (3BB) → BBコール:
  ターン開始時: ポット=12BB、スタック=91BB、SPR≈7.6

ターン標準ベット 75% (9BB) → BBコール:
  リバー開始時: ポット=30BB、スタック=82BB、SPR≈2.7

ターンOB 150% (18BB) → BBコール:
  リバー開始時: ポット=48BB、スタック=73BB、SPR≈1.5
  → リバーでオールイン圏（コミット確定）
```

ターンで150%OBしてコールされると、リバーのSPRが1.5になります。SPR1〜2はコミット圏です。どんなリバーカードが来てもほぼオールインするシナリオに持ち込まれます。

### α式でコールオッズを確認する

巻④ 第9章で学ぶα式を使うと、BBに要求されるコール頻度が計算できます。

```
α = ベット額 ÷ (ポット + ベット額)

150%OBの場合（ポット=12BB、ベット=18BB）:
  α = 18 ÷ (12 + 18) = 18 ÷ 30 = 0.60

MDF = 1 − α = 0.40
→ BBは40%以上のコール率が必要（それを下回るとブラフを許容しすぎる）

BBの視点: コスト60%で呼ぶ必要がある
→ 「自分のハンドがIPのレンジの60%以上に勝てる」が要件
```

BBに課される「60%の壁」は非常に高いハードルです。トップペアトップキッカー（TPTK）ですら、IPのナッツヘビーなバリューレンジには勝率60%を確保できません。

```
200%OBの場合（ポット=12BB、ベット=24BB）:
  α = 24 ÷ (12 + 24) = 24 ÷ 36 ≈ 0.67

MDF = 1 − α = 0.33
→ BBは33%以上のコール率が必要

BBの視点: コスト67%で呼ぶ必要がある
→ ほぼナッツ近辺のみがコール可能
```

200%OBはさらに厳しく、BBがコールできるのは実質ナッツ付近に限られます。

## 6-3 ターンOBが有効な3条件

ターンOBはすべての状況で有効ではありません。以下の3条件がそろったときにだけ機能します。

### 条件1: ナッツアドバンテージが圧倒的

IPのレンジがOOPのレンジを圧倒する状況です。第2章のCapped/Uncapという概念で言えば、「OOPのレンジがCappedになっている状況」です。

具体的には、次のような状況を指します。

- ドライボード + ペアターン（IPのKやAがボードに当たり、セット・トリップス・フルハウスが多くなる）
- ドライボード + オーバーカードターン（IPのAxが急激に強化され、BBのKxが相対的に弱化する）
- フラッシュ完成ターンでIPがナッツフラッシュを持つ

このアドバンテージが大きいほど、150%OBのバリューレンジが強固になります。

### 条件2: リバーでコミット状態にしたい

「ターンでコールさせて、リバーでSPRが1以下になる状態を作る」という設計意図が必要です。

これが有利なのは「リバーでどのカードが来てもIPが有利」な局面です。ドロー完成を恐れる必要がない状況、言い換えると「リバーカードによってIPの優位が崩れない」状況です。

逆に言えば、リバーで逆転されるリスクがある場合、ターンOBでコミットを強制することは危険です。相手のドローが完成すれば、大きなポットで負けることになります。

### 条件3: ドライボード + ブランクターンまたはペアターン

バレルスコアで言えばスコア9以上の局面です。ドライ板（FlopType係数=8）にペア（+4）やOC（+3）が落ちたとき、標準的なダブルバレルに加えてOBサイズを選ぶ根拠が生まれます。

ウェットボードやコネクテッドボードは、OOPのコールレンジが厚いためOBに向きません。OOPがドローやツーペアをコールして来ると、IPのナッツアドバンテージが薄まります。

## 6-4 有効なボードパターン3種

### パターン1: ドライ板 + ペアターン

代表ボード: K♣7♦2♠ + K♥ターン（ボード K-K-7-2）

フロップK72rは典型的なドライボードです（FlopType係数=8）。ターンにKが落ちると、IPのナッツアドバンテージが最大化されます。

```
IPのKヒット状況（K-K-7-2ボード）:
  KK（ポケット）: K-K-K-K-7 → クワッズ
  AK: A-K-K-K-7 → トリップス（3Kings）
  KQ: K-K-K-Q-7 → トリップス

OOPのKヒット状況:
  BBが3betせずにフラットコールしたレンジにKKは少ない
  BBのKxはAK, KQ程度で、IPと比べて少ない
```

また、ペアターンは第5章で確認したように、GTO実測で最も高いCBet頻度（平均91%）を示すカテゴリです。このボードでIPが大サイズのOBを選ぶ根拠として機能します。

BBには「コールできる強いハンドがほぼない」状態になります。77のセット（7-7-7-K-K = フルハウス）と22のセット（2-2-2-K-K = フルハウス）はコールできますが、それ以外のほとんどはIPのナッツ系に対抗できません。

### パターン2: ドライ板 + オーバーカードターン（A落ち）

代表ボード: K♦7♣2♠ + A♥ターン（ボード A-K-7-2）

AターンはK72rにとって「IPのAxを急激に強化するカード」です。

```
IPとBBの変化（A-K-7-2ボード）:
  IP（BTN）:
    AK: A-A-K-K-7 → 2ペア（Aces & Kings）
    AA: A-A-A-K-7 → トリップス（3Aces）
    → IPのAxがすべて2ペア以上に昇格

  BB:
    KQ（Kトップペア）: K-K-Q-A-7 → 2ペア（Kings & A、BBのQよりAキッカー）
    → しかしIPのAKには劣る
    KJ: K-K-J-A-7 → 2ペア（K's & A）← IPに劣る
    K9など: 同様に2ペアだが、Aキッカーで劣位
```

BBが保有するKxは、A落ちで相対的に弱化します。IPのAxがすべて2ペア以上に強化される中で、BBのKxは「2ペアではあるが、IPの2ペアに負ける」状況になります。

このナッツアドバンテージの非対称性がOBを正当化します。

### パターン3: フラッシュ完成ターンでIPがナッツフラッシュ保有

代表ボード: K♥T♠5♦ + 2♥ターン（ボード K-T-5-2♥3枚）

フロップがスーテッドボード（FlopType係数=4）の場合、ターンにフラッシュが完成するとOBの条件が整うことがあります。

ただし、この局面でのOBは条件が厳しくなります。IPがナッツフラッシュ（A♥K♥等）を確実に保有している場合にのみ有効です。IPもOOPも同スートのカードを持てる状況では、フラッシュアドバンテージがIPに偏らないため、OBは過剰になりやすいです。

## 6-5 ターンOBに向かないパターン

### NG1: ウェット板でのOB

ウェット板（コネクテッド・スーテッド）ではOOPのコールレンジが厚く残っています。

例: T♠9♦8♣ + J♠ターン（ボード J-T-9-8）

このボードでは多くのハンドがストレートを作っています。

```
ストレート確認（J-T-9-8ボード）:
  QJ: Q-J-J-T-9-8 → J-T-9-8のOESD → ただしQが手に2枚
       実際: hand Q-J + board J-T-9-8 = J,J,T,9,8,Q → Q-J-T-9-8 = ストレート（Qハイ）
  76: hand 7-6 + board J-T-9-8 = 7,6,J,T,9,8 → 8-7-6（+9-T待ち）= ガットショット方向
       実際: 6-7-8-9-T = 6から10の5連続 → ストレート完成
  Q7: hand Q-7 + board J-T-9-8 → Q-J-T-9-8 = ストレート完成
```

OOPがストレートやフラッシュドロー、ツーペアをコールしてくる環境では、150%OBに対してOOPのコール率が予想外に高くなります。IPのナッツアドバンテージが薄い分、OBはバランスを崩します。

ウェット板では75%以下の標準サイズでコントロールベットを選択します。

### NG2: IPのバリューが薄い場合

IPが「負けてはいないが強くもない」ハンドを持つ場面では、OBは逆効果です。

例: K♦7♣2♠ + A♥ターンでIPがKQ（TPセカンドキッカー）

```
KQのA-K-7-2での評価:
  ハンド K,Q + ボード A,K,7,2 = K,K,Q,A,7 → 2ペア（Kings & A、Qキッカー）

IPのKQは2ペアではあるが:
  BBのAKには負ける（AKは A-K-K-A-7 = 2ペア、AキッカーがQを上回る）
  BBのAAには大きく負ける（トリップス）
  BBのAQにも負ける（AQ: A-A-K-Q-7 = 2ペア、IPのKQより上位）
```

IPのKQがAターンで「薄バリュー」に転落しています。150%OBでコールされると、上記のAx系ハンドに負けるケースが多くなります。このような状況ではチェックバックか33%ブロッキングベットが適切です。

### NG3: フロップチェックバック後のOB

フロップでIPがチェックバックすることは「弱さのシグナル」として機能します。バリューが薄い、またはトラップ目的以外のチェックバックは「IPは強くない」という情報を相手に提供します。

直後のターンで突然150%OBを打つと、OOPから見て「ストーリーが崩れている」と映ります。

```
フロップ: IP CBet → チェックバック（弱さのシグナル）
ターン: IP 150% OB

OOPの解釈:
  「フロップで弱かったはずのIPが、なぜ突然大きく打つ?」
  → ブラフとバリューの判別が難しい → OOPがコールしやすくなる
  → IPのブラフは効果的にフォールドを取れない
  → IPのバリューはコールレンジを絞れない
```

チェックバック後のターンOBは「ストーリーの一貫性」を破壊します。GTOでは例外的なシナリオで存在することはありますが、入門〜中級段階では「チェックバック後のターンOBは避ける」ルールで十分です。

## 6-6 OOPがターンOBを受けたときの対応

IPから150%OBを受けたOOPは、巻④ 第10章で学んだ後手スコアとα式（巻④ 第9章）を組み合わせて判断します。

### コール基準の数学

```
150%OB（ポット12BB、ベット18BB）:
  α = 18/(12+18) = 0.60
  MDF = 1 − 0.60 = 0.40

OOPに課される要件:
  「自分のハンドが、IPのベットレンジ全体の40%以上のコンボに勝てるか」
```

このMDF40%は非常に低い水準です。言い換えると、「IPのベットレンジの60%に負けていてもコール可能」という計算ですが、IPがナッツヘビーなレンジでOBしている場合、OOPの「60%負けていないハンド」はほとんど残りません。

### OOPのハンドクラス別対応

| ハンドクラス | 150%OBへの対応 | 根拠 |
|---|---|---|
| ナッツ〜準ナッツ（セット、フルハウス、ストレート） | コールまたはレイズ | MDFを満たす |
| 強い2ペア（上位側） | 状況依存コール | ボード次第で条件を満たす場合あり |
| 弱い2ペア、TPTK | 基本フォールド | 60%のコールコストに耐えられない |
| トップペアセカンドキッカー以下 | フォールド | コール不可 |
| ナッツドロー（ナッツフラッシュドロー等） | エクイティ次第でコール | 完成時のリバーEVを計算 |
| セカンドナッツドロー以下のドロー | フォールド | コール不可 |

### 具体例：BBがKQでK-K-7-2ボードのIP 150%OBを受けた場合

```
ボード: K♣7♦2♠ + K♥ターン（K-K-7-2）
BBのハンド: K♦Q♥
  hand K,Q + board K,K,7,2 = K,K,K,Q,7 → トリップス（3Kings、Qキッカー）

  IPの150%OBレンジ想定:
    KK（クワッズ）: BBのトリップスは負ける
    AK（トリップスAキッカー）: K-K-K-A-7 → BBのKQに勝つ（Aキッカー > Qキッカー）
    KQ（トリップスQキッカー）: K-K-K-Q-7 → BBと同じ → タイ
    77（フルハウス: 7-7-7-K-K）: BBのトリップスに勝つ
    22（フルハウス: 2-2-2-K-K）: BBのトリップスに勝つ

  BBの勝ち条件:
    IPがKQより弱いキッカーのKx（K-J, K-T等）でOBしている場合のみ
    → 実際にはIPがK-J, K-Tで150%OBするシナリオは少ない

  → BBのKQはほとんどのIPバリューに負けまたはタイ → フォールド推奨
```

## 6-7 ターンOBの実戦例

### 実戦例1: K72r + Aターン、150%OB

**状況**: BTN（IP）vs BB（OOP）、SRP。フロップ K♦7♣2♠ で BTN が50%CBet → BBコール。ターン A♥落下。ポット12BB、スタック88BB。BTNのハンド: A♠K♥。

**ボード確認**: A♠,K♥ + A♥,K♦,7♣,2♠

- hand A,K + board A,K,7,2 = A,A,K,K,7 → 2ペア（Aces & Kings）
- broadway確認: A-K-Q-J-T のうち A,K のみ → 連続2枚のみ、ストレート不成立 ✓

**判断**:

BTNはA落ちでAK（2ペア A's & K's）に強化されました。BBのKx（以前のトップペア）はAターンで「2ペアK's & A's」になりますが、BTNのAKより下位になります。BBがAKを持つ可能性はBTNがAKを保有している分だけ減少します（アンブロック状況ではない）。

BTNのナッツアドバンテージ: AA（トリップス）、AK（2ペア上位）を多く保有。
BBのKxはすべてAKの2ペアに劣位。

**推奨アクション**: 150%OB（18BB）

```
α = 18/(12+18) = 0.60
BBに課されるコールコスト: 60%

BBがコールできるハンド:
  AK: BTNと同等（ただしBTNがAK保有なら減少）
  AA: 存在するが少ない
  → BBのほとんどはフォールド

コール後のSPR: (88−18)/(12+18+18) = 70/48 ≈ 1.5 → リバーオールイン圏
```

BTNはリバーで「コール後でもSPRが1.5でオールインが確定」という状況を作りながら、多くのBBハンドをフォールドさせる理想的なOBが成立します。

---

### 実戦例2: K72r + 7♥ペアターン、150%OB

**状況**: BTN（IP）vs BB（OOP）、SRP。フロップ K♣7♦2♠ でBTN 50%CBet → BBコール。ターン 7♥落下（ボード K-7-7-2）。ポット12BB、スタック88BB。BTNのハンド: K♠K♥。

**ボード確認（ペアターンのhand evolution）**:

- KK + K-7-7-2 = K,K,K,7,7,2 → best 5 = K-K-K-7-7 → K's full of 7's（フルハウス）✓
- AK + K-7-7-2 = A,K,K,7,7,2 → best 5 = A-K-K-7-7 → 2ペア（K's & 7's、Aキッカー）✓
- 77 + K-7-7-2 = 7,7,7,7,K,2 → best 5 = 7-7-7-7-K → クワッズ（77はBBが持てるが少数）

**判断**:

7ターンはペアカードです。バレルスコア = ドライ(8) + ペア(4) = 12 → 積極バレルゾーンです。さらにBTNのKKがフルハウスに昇格しています。

BBのレンジでこのボードに対抗できるハンド:

- 77（クワッズ）: ごく少数
- K7（フルハウス: 7-7-7-K-K）: 存在するが少数
- 72、K2: フルハウス系（少数）

BBのAK（2ペア）はBTNのフルハウスに負けます。BBのほとんどのハンドがBTNのフルハウスに対してコールできません。

**推奨アクション**: 150%OB（18BB）

BTNのフルハウスは、BBの全コールレンジのほぼ100%を上回るナッツアドバンテージです。コールされれば大きなポットでほぼ勝利確定。フォールドされても12BBを獲得。両方向でプラスEVが成立します。

---

### 実戦例3: ウェット板でOBを避けるべきケース

**状況**: BTN（IP）vs BB（OOP）、SRP。フロップ T♠9♦8♣ でBTN 50%CBet → BBコール。ターン J♠落下（ボード J-T-9-8）。ポット12BB。

**ボード確認**:

- バレルスコア = コネクテッド(3) + コネクター(0) = 3 → ハンド依存ゾーン
- J-T-9-8ボードではストレート完成ハンドが多数:
  - QJ: hand Q,J + board J,T,9,8 = Q,J,J,T,9,8 → Q-J-T-9-8 = ストレート（Qハイ）
  - 76: hand 7,6 + board J,T,9,8 = 7,6,J,T,9,8 → 6-7-8-9-T = ストレート完成 ✓
  - KQ: hand K,Q + board J,T,9,8 = K,Q,J,T,9,8 → Q-J-T-9-8またはK-Q-J-T-9 = ストレート完成 ✓
  - 77: hand 7,7 + board J,T,9,8 → J,T,9,8,7 の5連続が成立（7〜J）→ best 5 = J-T-9-8-7 = **ストレート（7ハイ）** ✓

BBのコールレンジにはストレート完成ハンドが多く含まれます。BTNが150%OBを打つと、BBのコールレンジが厚くなりすぎます。

**推奨アクション**: 75%以下の標準ベット（または単一ベットサイズで混合戦略）

コネクテッドボードでのOBはBBのナッツを呼び込む危険があります。バレルスコアが低いほど、ベットサイズも小さくコントロールするべきです。

---

### 実戦例4: フロップチェックバック後のOBは禁忌

**状況**: BTN（IP）vs BB（OOP）。フロップ K♣7♦2♠ で BTN チェックバック。ターン A♥落下（ボード A-K-7-2）。BBチェック。BTNのハンド: A♦J♣。

**ボード確認（ハンド役）**:

- hand A♦,J♣ + board A♥,K♣,7♦,2♠
- ランクカウント: A=2（hand+board）, K=1, J=1, 7=1, 2=1
- Aが2枚ペア → **1ペア（Aces）、K,J,7キッカー**
- JはボードになくBoardにも1枚しかないため、2ペアは不成立
- ストレート確認: A-K-J-7-2 は連続していない → ストレートなし ✓

**分析**:

フロップでBTNがチェックバックしたことは「弱さのシグナル」です。フロップのK72rでチェックバックは「BTNがKxを保有していない可能性、またはドロー系ハンドで打ちにくい状態」を示します。

ターンでAが落ちてBTNのAJが1ペア（Aces）に強化されましたが、このタイミングで150%OBを打つのは問題があります。

```
OOPからの視点:
  フロップ: BTNチェックバック → 「BTNは強くない」
  ターン: BTN 150%OB → 「なぜ突然大きく打つ?」

  OOPの解釈:
    パターンA: BTNがターンで強化（AJがフロップで弱く、Aターンで強化）
    パターンB: BTNがブラフ（ストーリーに矛盾があるから大きく打っている）

  → OOPはAとBを区別できないため、コールしやすくなる
  → BTNのAJは「コールされると負ける可能性がある」手でOBをすることになる
```

AJの1ペアはBBのAK（2ペア or トリップス）に負けます。ストーリーの崩れがあるOBは、BBの強いハンドを引き込むリスクがあります。

**推奨アクション**: 50%以下のブロッキングベットまたはチェックバック

---

### 実戦例5: SPRを活かした150%OBの設計

**状況**: BTN（IP）vs BB（OOP）、SRP。フロップ A♠5♦2♣ でBTN 50%CBet（3BB）→ BBコール。ターン A♥落下（ボード A-A-5-2）。ポット12BB、スタック88BB。BTNのハンド: A♣K♦。

**ボード確認（ペアターン + A）**:

- AK + A-A-5-2 = A,A,A,K,5,2 → A-A-A-K-5 = トリップス（3 Aces、Kキッカー）
- AA + A-A-5-2 = A,A,A,A,5,2 → A-A-A-A-5 = クワッズ（BBが持てる可能性は低い）
- A5 + A-A-5-2 = A,A,A,5,5,2 → A-A-A-5-5 = フルハウス（Aces full of 5s）
- KK + A-A-5-2 = K,K,A,A,5,2 → A-A-K-K-5 = 2ペア（A's & K's）

**SPR計算**:

```
現在: ポット12BB、スタック88BB、SPR≈7.3

ターン150%OB: ベット18BB
  コール後のポット: 12+18+18 = 48BB
  コール後のスタック: 88−18 = 70BB
  コール後のSPR: 70/48 ≈ 1.5 → リバーコミット圏
```

BTNのAKはトリップス（3Aces）という超強力なバリューです。BBのレンジでコールできるのは：

- AA（クワッズ）: 存在するが極めてレア
- A5（フルハウス）: 少数
- A2（フルハウス）: 少数
- AK以下のAx（トリップス）: Kキッカーに劣位、または同等

BBがコールできるのはほぼ同等以上のトリップス系のみ。BTNがリバーでコミット（SPR1.5でオールイン）になっても「どのリバーカードが来てもBTNが有利」な状態です。

**推奨アクション**: 150%OB（18BB）が最大EV

コールされてリバーでコミットしても、BBが勝つシナリオは「AA（クワッズ）」か「A5/A2（フルハウス）」のみです。この小さな確率に対して、BBの多くのハンドにフォールドを引き出せる大きなメリットがあります。

## 6-8 ターンOBの使用頻度（GTO視点）

GTO実測データとバレルスコアの係数から、ターンOBが使われる場面の目安を整理します。

### OBが多い状況

- ドライ板 + ペアターン（バレルスコア12）: このゾーンでのCBet頻度は平均91%で最高水準。OBサイズを選択するのはこのゾーンのIPナッツ系ハンドが中心。
- ドライ板 + OC（バレルスコア11）: 平均76%のCBet頻度。Axが爆発的に強化されるA落ちシナリオでは大サイズが選ばれる傾向がある（v7b蒸留モデル実測）。

### OBが少ない状況

- スーテッド板・コネクテッド板: フラッシュドロー、ストレートドローが絡むとOOPのコールレンジが広がり、OBのポーラード化効果が薄まる。
- セミ板のコネクター落ち（バレルスコア3）: このゾーンはOBどころか標準ベットすら慎重に打つ局面。

### 実戦での使用指針

ターンOBは「使う場面が限られる」特殊戦術です。以下のシンプルルールで入門段階は十分です。

```
ターンOBを使う基本条件（暗記推奨）:
  ① ドライ板（FlopType係数=8）
  ② ペアターンまたはA落ち（TurnCard係数4または3）
  ③ バレルスコア11以上
  ④ IPがナッツまたは準ナッツを保有

この4条件がそろったとき → 150%OBを検討
それ以外 → 75%以下の標準サイズ
```

## ミニクイズ

### 問1

ドライ板 K♣7♦2♠ + 7♥ターン（ボード K-7-7-2）で BTN が KK（フルハウス：K's full of 7's）を持ちます。ポット12BB、スタック88BB。ターンで150%OBを選択する主な理由は何ですか？

1. フルハウスは最強ハンドなので、何でも大きく打って問題ない
2. ペアターンでナッツアドバンテージが最大化し、BBのコールできるハンドがほぼなくなる。SPRをリバーでコミット圏にしながらフォールドを大量に引き出せる
3. 150%OBはポットを素早く大きくして運の要素を増やすから

### 問2

IP が150%OBを打ってきたとき、BBに課されるコールコストは何%ですか？また、BBのコール基準を正しく説明しているのはどれですか？

1. コールコストは50%。1ペアがあれば基本コールで良い
2. コールコストは60%（α=0.60なのでMDF=0.40）。IPのベットレンジの60%以上に勝てなければコールはマイナスEV
3. コールコストは75%。ナッツのみコール、それ以外はすべてフォールド

### 問3

「フロップでIPがチェックバックした後、ターンで150%OBを打つ」ラインの問題点はどれですか？

1. チェックバック後にOBを打つのはルール違反である
2. フロップの「弱さのシグナル」と直後の大ベットの間でストーリーが崩れ、OOPがコールしやすくなる。バリューの場合でもOOPの強いハンドを呼び込むリスクがある
3. ターンOBはリバーの前にしか使えないから、フロップ後は禁止されている

---

### 解答

- **問1**: 2（ペアターン K-7-7-2 でBTNのKKはフルハウス（K's full of 7's）に昇格。BBのほとんどのハンドがコールできないナッツアドバンテージ最大局面。コールされればSPR≈1.5でリバーコミット、フォールドされても現ポットを獲得。両方向でプラスEV）
- **問2**: 2（α = 18/(12+18) = 0.60。MDF = 1-0.60 = 0.40。BBがコールするためにはIPのバリューレンジの60%以上に自分のハンドが勝てることが必要。150%OBはほぼナッツ近辺のみが正当にコールできる大サイズ）
- **問3**: 2（フロップのチェックバックは「弱さのシグナル」。直後のターン大ベットはストーリーの一貫性を破壊する。OOPは「ブラフ or 突然の強化」を判別しにくくなり、コールを引き込みやすい。入門段階ではチェックバック後のターンOBは避けるのが安全）

> **本章まとめ**
>
> - ターンOBの目的は「SPRをリバーでコミット圏にする」と「即時フォールドエクイティ回収」の2つ。リバーOBの「最終ベット最大化」とは異なる
> - 150%OBのα = 0.60、MDF = 0.40。BBには「コストオッズ60%の壁」がある
> - 有効な3条件: ナッツアドバンテージが圧倒的 / SPRをコミット圏にしたい / ドライ板 + ペアまたはOCターン
> - バレルスコア11以上（ドライ板 + ペア/OC）がOBの目安。それ以下では標準サイズ
> - NG3パターン: ウェット板（コールレンジ厚）/ 薄バリュー（コールされると損）/ フロップCBバック後（ストーリー崩壊）
> - 第13章のターン実戦例でOB判断を含む総合演習を行う

**【GTOとのズレ】**

GTOでのターンOBはドライボードのペアターンやAターンに集中しており、実際の使用頻度はそれほど高くありません。しかし実戦では「強いハンドを持ったら大きく打つ」という直感から、ウェット板やセミ板でもOBを試みるプレイヤーが多く見られます。これはOOPのコールレンジが広い状況で大きなポットを作り、結果的に相手の強いハンドに多くのチップを支払う形になります。

もう一つのズレは、ターンOBのブラフレンジについてです。GTOではターンOBのバリューに対してバランスとなるブラフをレンジに含めます。具体的には「ナッツをブロックしているが自分の役は弱い」ハンドでOBブラフを打つシナリオがあります。たとえばA♠2♠のようにナッツフラッシュをブロックしながらエクイティが低いハンドです。しかしこのブラフOBを実戦で再現するには、相手のコールレンジとブラフ比率の正確な把握が必要で、精度が低いとただの大きなマイナスEVプレイになります。初〜中級段階では「ターンOBはバリューのみ」で運用し、ブラフOBは上級者のオプションとして保留するのが合理的です。
