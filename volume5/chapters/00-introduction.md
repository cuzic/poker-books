## 本書の主題 ─ 3軸統合

巻④では4つの式を使って1ストリートずつ判断しました。応用編の目的は、その判断を**マルチストリートの視点で統合すること**です。ターン判断を整理すると、3つの情報軸が同時に存在します。

```
ターン判断 = forward 軸（過去レンジ）
          × current 軸（ターンカード）
          × backward 軸（リバー予測）
```

**forward 軸**は、プリフロップ・フロップのアクション履歴から積み上がったレンジ情報です。巻①〜3の簡易レンジスコア・精密レンジスコア・HandScore が入力となります。

**current 軸**は、ターンカードが両者のレンジにどう作用するかです。巻④のターンカード5分類とバレルスコアの係数がここに対応します。

**backward 軸**は、リバーで予測される主要シナリオを先読みしてターンのアクションを逆算することです。「リバーで何が起きるか」から「今ターンで何をするか」を決める考え方で、**backward induction（逆向き帰納）**と呼びます。

リバー判断は forward 軸と current 軸の2軸のみです。リバーにはもう1枚カードが落ちないため、backward 軸は消えます。ターンは唯一3軸すべてが揃うストリートで、最も総合判断を要します。

## 巻④ から継承する4つの暗算式

本書では以下の4つの暗算式を**既出**として扱います。式の形と係数を忘れた場合は付録A（第17章）で確認してください。

```
バレルスコア = FlopType係数 + TurnCard係数     （巻④ 第8章）
  FlopType係数: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard係数: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0

α           = ベット ÷ (ポット + ベット)        （巻② 第9章）
MDF = 1 − α

後手スコア   = HandScore + A − 3 − C − M       （巻④ 第10〜11章）
  ≥ 8: チェックレイズ検討 / 0〜7: コール / < 0: フォールド
```

ターン版ではドロー加点が有効で、リバー版では C 係数の拡張とドロー加点の固定が加わります。

## 想定読者

本書は以下のような読者を対象としています。

**巻④読了済みで判断を統合したい方。** 4つの暗算式を個別には使えるようになったが、複数ストリートの繋げ方が体系化できていない方に向けています。3軸統合と backward induction がその橋渡しになります。

**高度戦術を習得したい中級〜上級者。** オーバーベット・リバーチェックレイズ・ブロッカー実戦選択は巻④では概要のみでした。本書では判断基準を明確にして実戦投入できる形で解説します。

**ソルバー学習の橋渡しとして。** 3軸統合と backward induction はソルバーの思考プロセスと接続します。「なぜその答えになるか」を理解するための枠組みとして活用してください。

## 巻④ で習得済みとして扱う概念

本書では以下を既習として扱います。式の形を忘れた場合は付録A（第17章）、継承関係の全体図は付録C（第19章）を参照してください。

- **4つの暗算式**: バレルスコア / α式 / 後手スコア（ターン版・リバー版）
- **ハンドの3層分類**: ナッツ層 / ミドル層 / ブラフ層
- **ターンカードの5分類**: ペア / オーバーカード / ブランク / フラッシュ / コネクター
- **ブロッカー基礎**: バリューブロッカー / ブラフブロッカーの識別
- **レンジ強度（Capped vs Uncapped）**: アクション履歴によるレンジ上限の有無
- **アクションとレンジ遷移**: 各ストリートのアクションがレンジを絞り込む仕組み

巻①〜3 の簡易レンジスコア・精密レンジスコア・HandScore・後手スコア（フロップ版）も用語と式の形をそのまま使います。
