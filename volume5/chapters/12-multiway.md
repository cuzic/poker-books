# 第12章　マルチウェイポットのターン・リバー

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 3人以上のマルチウェイポットでのターン・リバー戦略を習得し、本書 巻⑤ 第11章の後手スコアにM補正を正確に組み込めるようになる。

---

## 12-1 マルチウェイとは何か

マルチウェイポットとは、3人以上のプレイヤーがフロップ以降も参加しているポットです。6-maxキャッシュゲームでは、フロップを3way以上で迎える局面が全体の約20〜30%を占めます。この割合は無視できる頻度ではなく、毎セッション複数回は直面する状況です。

```
ヘッズアップ（HU）: 2人 → 本書のここまでの標準シナリオ
3way             : 3人 → 本章の主対象
4way+            : 4人以上 → 3wayのルールをさらに強化して適用
```

本書がここまで扱ってきたバレルスコア・後手スコア・α式はすべてHUを前提に設計されています。マルチウェイでも同じ式の骨格を使いますが、M補正（マルチウェイ補正係数）を追加することで判断精度を保ちます。

本章では「なぜHUと同じ判断ではダメなのか」を数学的に確認した上で、実戦で使える判断基準を整理します。

---

## 12-2 マルチウェイでバリューラインが上がる理由

### 「最強ハンドである確率」が下がる

HUでのバリューベットの条件は「相手のレンジに対して50%超で勝てるか」です。相手が1人なので、自分が勝てる確率が半分を超えれば期待値がプラスになります。

3wayになると状況が変わります。2人の相手のレンジに対して同時に勝てる確率を考えなければなりません。独立性を仮定した粗い計算では次のようになります。

```
HU  : P(勝ち) ≈ 50% → バリューベット成立
3way: P(AよりBに勝つ) × P(AよりCに勝つ)
     ≈ 50% × 50% = 25%（独立仮定の近似値）

→ バリューベットとして機能するには、より高い勝率が必要
```

この「最強ハンドである確率」の低下が、マルチウェイでバリューラインを押し上げる根本的な理由です。実際には2人の相手のハンドには相関（同一ランクの引き合い）があるため、この独立計算はあくまで概念的な近似ですが、「閾値が上がる」という方向性は正しく示しています。

### 実践的なバリューライン

人数が増えるほど、バリューとして機能するハンドに「1段階上の強さ」が必要です。

| プレイヤー数 | 最低バリューライン | 大ベットのライン |
|---|---|---|
| HU | トップペア（状況依存） | 2ペア以上 |
| 3way | 2ペア以上 | セット以上 |
| 4way+ | セット以上 | ストレート・フラッシュ以上 |

この表は「絶対的なルール」ではなく、ベットサイズと相手の傾向によって調整が必要です。しかし方向性として「1人増えるごとに1段階上のハンドが必要」と覚えておけば、判断の基準として十分機能します。

## 12-3 マルチウェイでブラフ頻度が下がる理由

### ブラフ成功は「全員フォールド」を要求する

ブラフが利益を生むためには、ポットに残っている全員がフォールドしなければなりません。ここに人数の影響が指数的に効いてきます。

```
前提: 各相手がベットに対して60%の確率でフォールドするとする

HU（相手1人）:
  全員フォールド = 60%

3way（相手2人）:
  全員フォールド = 60% × 60% = 36%

4way（相手3人）:
  全員フォールド = 60% × 60% × 60% ≒ 22%
```

1人ずつが十分な頻度でフォールドしてくれる状況でも、全員を同時にフォールドさせる確率はHUの6割以下まで落ちます。この成功率の低下は、ブラフのEV計算に直結します。

### ブラフEVが下がる数学

簡単な例で確認します。ポット100BBに対して50BB（50%）をベットするピュアブラフを考えます。

```
HU の場合:
  EV = (60% × 100) − (40% × 50) = 60 − 20 = +40BB

3way の場合:
  EV = (36% × 100) − (64% × 50) = 36 − 32 = +4BB（ほぼ損益分岐）

4way の場合:
  EV = (22% × 100) − (78% × 50) = 22 − 39 = −17BB（明確に損）
```

HUで有効なブラフが、3wayでは辛うじてプラスまたは損益分岐になり、4wayでは明確に損になります。この計算が「マルチウェイでのピュアブラフは避ける」という経験則の数学的根拠です。

### セミブラフの位置づけ

ドロー系ハンドでのセミブラフ（フォールドエクイティ + ドロー完成時のバリュー）はマルチウェイでも一定の有効性があります。ドローが完成すれば全員に対してバリューを取れるからです。ただし、「フォールドエクイティだけで利益が出るか」という計算は慎重に行う必要があります。完成時に全員からコールを引き出せる強いドロー（フラッシュドロー + OESDの組み合わせなど）でない限り、マルチウェイでのセミブラフも抑制的に使うべきです。

## 12-4 マルチウェイでのポジション影響

### IPの優位がより重要になる

HUでもポジションは重要ですが、マルチウェイではその重要性がさらに増します。その理由は「全員のアクションを見てから判断できるか否か」の差が大きくなるからです。

```
例: CO、BTN、BBの3way

CO  : 毎ストリートで最初にアクション → 情報最小
BTN : COとBBのアクションを見てから判断 → 情報最大（有利）
BB  : フロップ以降は最初か2番目にアクション → 情報少
```

BTNは3wayでも全員のアクションを後から見ることができます。COとBBが両方チェックした後でベットできる位置にいます。COとBBの両方のアクションを吸収した上で判断できるため、ポジションの優位が実質的に拡大します。

### OOPのCBet頻度低下

IP（BTN）がCBetする場合、HU前提と3way前提では推奨頻度が変わります。3wayではコールレンジを持つ相手が増えるため、弱いハンドでの「とりあえずCBet」は損になります。目安として、3wayのドライ板CBetはHUの約7割前後まで下がります（ただしこれは概算であり、ボードとレンジによって変動します）。

OOP（CO、BB）のドンクベットはマルチウェイではさらに使いにくくなります。自分のベットに対してIPがレイズし、さらに3人目が再レイズするリスクがあるため、ドンクベットには非常に強いハンドが必要です。

## 12-5 3wayでのチェックとベットの使い分け

### チェックが増える状況

マルチウェイでは「迷ったらチェック」が基本姿勢になります。次の状況では特にチェックを優先します。

**薄いバリューハンド（トップペアレベル）**

3wayでトップペアにバリューベットすると、2人のコールレンジを相手にすることになります。1人がコールするだけでそのコールレンジは「トップペアに勝てるハンド（2ペア・セットなど）」の比率が高くなります。さらに2人目もコールすれば、その相手のレンジはさらに絞られます。逆選択が二重に働くため、トップペアでの大きなバリューベットは損になりやすいです。

**ドロー系ハンド**

3wayではドローが複数のプレイヤーに競合している可能性があります。自分がフラッシュドローを持っていても、別の相手がより良いフラッシュドローを持っている可能性がHUより高くなります。セミブラフのコストと完成時のバリューの両方を考慮して判断します。

### ベットが有効な状況

**強いバリューハンド（セット以上）**

セット以上では3wayでもベットが推奨されます。複数の相手からコールを引き出せる可能性があり、ポット保護（ドローに安く見せない）の観点からもベットが優先されます。

**ナッツドロー**

フラッシュドロー + OESDの組み合わせなど、完成すれば全員に対してナッツを持てる見込みがあるハンドはセミブラフとして機能します。ただし「全員フォールド確率」が低いことを念頭に置き、フォールドエクイティへの依存度を下げた計算をする必要があります。

## 12-6 マルチウェイのリバー判断

### リバーバリューラインの確認

ターンを3wayで生き残ったプレイヤーのレンジは、フロップ・ターンのアクションによって絞り込まれています。3wayでターンまでコールし続けるプレイヤーは、弱いハンドをほとんど持ちません。この「レンジの圧縮」がリバーでの判断に大きく影響します。

```
3wayリバーでのガイドライン:

バリューベット（小〜中サイズ）:
  → 2ペア以上を目安とする

バリューベット（大サイズ・75%超）:
  → セット以上を目安とする

チェックバック / チェック:
  → トップペア以下はコールを引き出しにくい

ブラフ:
  → 基本的に避ける（全員フォールド確率が低い）
```

### 後手側のコール基準（マルチウェイリバー）

相手からリバーベットが来た場合の判断も、3wayでは変わります。

1人がベットして1人がコールしている状況で自分が直面する場合、コールしてくる相手は弱いレンジを持ちません。2人分のコールアクションが強さのシグナルを出しているため、自分のコール基準も上がります。

ターン・フロップを3wayでコール、コール、コールと進んできた相手がリバーでもベットしてくる場合、ブラフ頻度は極めて低くなります。マルチウェイで三連続でアグレッションを続けられるプレイヤーは、通常、非常に強いハンドを持っています。

## 12-7 後手スコアへのM補正の組み込み

### 本書 巻⑤ 第11章の後手スコアを再確認

本書 巻⑤ 第11章で学んだ後手スコアの式は次のとおりです（HU前提のため M=0）。

```
後手スコア = HandScore + A − 3 − C − M

A（ボード値）: ドライ=3 / セミウェット=2 / ウェット=1
C（ベット負担）: 33%=3 / 50%=5 / 75%=7
M（マルチウェイ補正）: HU=0 / 3-way=3 / 4-way+=6

後手スコア ≥ 8 → チェックレイズ検討
後手スコア 0〜7 → コール
後手スコア < 0 → フォールド
```

この式は本書 巻⑤ 第11章ではHU前提（M=0）で運用してきました。マルチウェイではMが非ゼロになるため、コール・チェックレイズ・フォールドの境界が動きます。

### M補正の理論根拠

M補正はフォールドエクイティの縮小則に基づく近似値です。3wayではブラフのフォールドエクイティが HUの約半分（f² ≈ f × 50%）になることから、A=3のドライ板での3wayは A=2のセミウェット板相当のブラフ価値になると考えられます。この「1段階のボード値下落」をM=3として後手スコアに反映しています。

重要な注記として、M補正の係数（M=3, M=6）はTexasSolverによる直接検証が行えない理論値です（本書が使用するソルバーは2プレイヤー専用のため）。将来のGTOソルバーによる3wayの実測検証を経て、係数の調整が必要になる可能性があります。現段階では「方向性として正しい近似値」として使ってください。

### M補正によるチェックレイズ閾値の変化

M補正を加えることで、チェックレイズ（CR）に必要な後手スコアが実質的に上がります。

```
後手スコア ≥ 8 → CR検討 （HU の判断基準）

3wayでCRを行うには:
  HandScore + A − 3 − C − 3 ≥ 8
  → HandScore + A − 3 − C ≥ 11（実質的な要求スコアが11に上昇）

4wayでCRを行うには:
  HandScore + A − 3 − C − 6 ≥ 8
  → HandScore + A − 3 − C ≥ 14（実質的な要求スコアが14に上昇）
```

これが「マルチウェイでのCRはより強いハンドが必要」という直感を式で裏付けたものです。

## 12-8 よくある失敗パターン

### 失敗1: 3wayでトップペアを大きくベット

HUではトップペアでのバリューベット（50〜75%）が有効な場面があります。しかし3wayでは、その「大きなベット」が自分に不利な状況を生みやすいです。

コールしてくる相手は「トップペアに勝てる確信がある相手」に偏ります。1人がコールした時点で、2人目がさらにコールすることはまれで、コールする場合は2人目もトップペアより強いハンドを持っている可能性が高くなります。

3wayでのトップペアは、チェックバックまたは小さなブロッキングベット（33%以下）で相手のハンドを確認しながら慎重に進めるのが無難です。

### 失敗2: 3wayでのピュアブラフバレル

3wayで「1人が降りるかもしれない」という考えでブラフを続けることは、数学的に問題があります。1人が「なんとなくコール」するだけでブラフは失敗し、2人分のコールに対して損が拡大します。

セミウェット板のセミブラフが3wayで有効に機能するのは、「ドローが完成したら全員に勝てる」という条件が揃う場合に限定されます。完成後のバリューが明確でないピュアブラフや、完成しても全員に勝てない弱いドローでのセミブラフは、3wayでは避けるべきです。

### 失敗3: 全員のアクションを追跡しない

マルチウェイでは「この相手にはどう対応するか」という1対1の思考に陥りやすいです。しかし、2人目の相手のアクションも同時に情報として扱う必要があります。

COとBBが両方チェックした後でBTNがベットした場合と、COがベットした後でBBが「コール」してBTNがアクションを迎える場合では、BTNの判断が大きく変わります。後者では「COのベットレンジ」と「BBのコールレンジ」を両方考慮に入れる必要があります。

## 12-9 3way・4way 実戦例

### 例1: 3way でのターン2ペア（バリューベット）

**状況**: CO・BTN・BBの3way。フロップでBTNがCBet、COとBBがコール。
**ボード**: K♦7♣2♠（フロップ）→ A♥（ターン）
**ハンド**: A♠K♠（BTN）

ボード読みの確認:
- 保有カード: A♠, K♠ + ボード K♦, 7♣, 2♠, A♥
- Aランク: A♠（ハンド）+ A♥（ボード）= 2枚
- Kランク: K♠（ハンド）+ K♦（ボード）= 2枚
- 最強5枚: A, A, K, K, 7 → **2ペア（AとK、7キッカー）**
- ストレート: A-K-Q-J-T（Qなし）、K-Q-J-T-9（Q、J、Tなし）→ なし
- フラッシュ: スペード A♠, K♠, 2♠ = 3枚 → フラッシュ未完成

**バレルスコアの確認**（巻④ 第8章より）:
- ボードK♦7♣2♠はドライ（FlopType係数=8）
- ターンカードA♥はオーバーカード（TurnCard係数=3）
- バレルスコア = 8 + 3 = 11 ≥ 7 → 積極バレル推奨

しかしこれはHU前提のスコアです。3wayでのバリューベット判断では、ハンドの強さを確認します。A♠K♠の2ペアは3wayの「バリューライン（2ペア以上）」を満たしています。AA（相手にとってセットに近い強さ）のみ負け、ほかのレンジに対しては優位があります。

**判断**: 50〜75%でバリューベット推奨。ただし3wayのため、コールが2つ来た場合はAAを警戒してリバーの大ベットは控えめに検討する。

---

### 例2: 3way でのウェット板チェックバック

**状況**: SB・BTN・BBの3way。フロップでBTNがCBet、SBとBBがコール。
**ボード**: J♠T♦9♣（フロップ）→ 8♣（ターン）
**ハンド**: T♠9♠（BTN）

ボード読みの確認:
- 保有カード: T♠, 9♠ + ボード J♠, T♦, 9♣, 8♣
- Tランク: T♠（ハンド）+ T♦（ボード）= 2枚
- 9ランク: 9♠（ハンド）+ 9♣（ボード）= 2枚
- 最強5枚: J, T, T, 9, 9 → **2ペア（TペアとNineペア、Jキッカー）**
- ストレート確認（連続ランクの列挙）:
  - 保有ランク: J, T, T, 9, 9, 8 → J-T-9-8の4連続、7かQが来れば完成 = **OESD（ストレート未完成）**
  - 5枚連続: J-T-9-8-7（7がない）/ Q-J-T-9-8（Qがない）→ ストレート未完成
- スペードスーツ: J♠, T♠, 9♠ = 3枚 → フラッシュ未完成（スペードFD要素あり）

この4枚ボードはウェット（コネクテッドかつフラッシュドロー可能）で、A値=1です。

**後手スコアの計算**（BTNがOOPの相手からベットを受けた場合を想定、Cは相手のベットサイズ依存）:

ここでのポイントは「3wayで誰かがベットしてくる場合の応対」より「BTNがバリューを取れるか」という設計です。

T♠9♠の2ペアはストレートに負け（OESD保有者に完成の逆転がある）、3wayの相手2人のレンジに多くのストレート完成形やドロー完成形が含まれます。3wayの「バリューラインの境界（2ペア以上でバリュー）」はギリギリ満たしていますが、ウェット板であることとOESDへの脆弱性を考慮します。

**判断**: チェックバックが優先。3wayウェット板では2ペアは「薄いバリュー」にとどまり、OESDの多数完成リスクと3wayの「逆選択リスク」を回避するために積極的なバレルは控えます。

---

### 例3: 3way でのトップペアに対する後手スコア計算

**状況**: BTN（CBettr）・CO・BBの3way。BTNがターンでバレル（75%ベット）。
**ボード**: Q♣T♦8♥（フロップ）→ A♦（ターン）
**ハンド**: Q♥J♦（CO・OOP）

ボード読みの確認:
- 保有カード: Q♥, J♦ + ボード Q♣, T♦, 8♥, A♦
- Qランク: Q♥（ハンド）+ Q♣（ボード）= 2枚 → **トップペア**
- ストレート確認（使用ランク: Q, J, Q, T, 8, A）:
  - A-K-Q-J-T（Kがない）→ ストレート未完成
  - Q-J-T-9-8（9がない）→ ストレート未完成
  - ダイヤ: J♦（ハンド）+ T♦（ボード）+ A♦（ボード）= 3枚 → バックドアFD（リバーでさらに1枚必要）
- 役: Qのトップペア、Jキッカー（**TPGK相当**）

HandScoreの概算:
- 役スコア: Qのワンペア ≈ 10点
- ドロー加点: バックドアFD（まだ3枚スーツ） ≈ 加算なし（ターン時点で2枚ドロー）
- HandScore ≈ 10〜12（おおよそ）

**後手スコアの計算**（3way、BTNからの75%ベット対応）:

```
後手スコア = HandScore + A − 3 − C − M

A（ボード値）: Q♣T♦8♥A♦はやや連続性あり・ダイヤが3枚（セミウェット〜ウェット）→ A=1〜2
  ここでは A=2（セミウェット）と評価する

C（ベット負担）: 75%ベット → C=7

M（3way補正）: M=3

後手スコア = 11 + 2 − 3 − 7 − 3 = 0
```

後手スコア=0は「コールの下限」に位置します。HUなら0〜7がコールゾーンですが、3wayでは M=3 の圧力で同じハンドの後手スコアが3点低く出ます。

**判断**: コールはギリギリ支持される（スコア=0）。HUなら明確にコールだったハンドが、3wayでは「呼んでいい最弱クラス」に変わります。COの後ろにBBがまだアクションを残している場合は、さらに慎重な判断（パスする選択肢も考慮）が必要です。

---

### 例4: 4wayでの超慎重なバリュー設計

**状況**: BTN・SB・BB・CO（orMPなど）の4way。ターンまでフォールドなし。
**ボード**: 9♠8♦2♣（フロップ）→ 6♥（ターン）
**ハンド**: 9♥9♦（BTN、セット保有）

ボード読みの確認:
- 保有カード: 9♥, 9♦ + ボード 9♠, 8♦, 2♣, 6♥
- 9ランク: 9♥（ハンド）+ 9♦（ハンド）+ 9♠（ボード）= 3枚 → **セット**
- ストレート確認（使用ランク: 9, 9, 9, 8, 2, 6）:
  - 9-8-7-6-5（7と5がない）→ 未完成
  - 6-7-8-9-T（7とTがない）→ 未完成
  - 5-6-7-8-9（7と5がない）→ 未完成
- 役: **セット（スリーカード）**

4wayでも、セット（9♥9♦ on 9♠8♦2♣6♥）は「4wayのバリューライン（セット以上）」を満たしています。ただし4way特有の注意点があります。

**4wayのリスク評価**:

ターンの6♥でボードが 9♠8♦2♣6♥（4連続に近い） になります。

連続ランク確認: 6, 8, 9（7が抜けている）。9-8-7-6 = 4連続にはならないが、7が落ちれば完成形が多数あります。4人のうち誰かが7-5（ストレートドロー）、T-7（ストレートドロー）を持っている確率はHUより大幅に高くなります。

また、4wayでのセットはストレート・フラッシュ完成に対して負けます。4人のポットではナッツでない強ハンドの価値が相対的に下がります。

**判断**: セットは4wayでもバリューベット推奨だが、ベットサイズは75%より50%に抑えるのが無難です。コールしてくる相手の多くは「セットに勝てる手」または「強いドロー」を持っている可能性があるため、大きなベットは逆選択のリスクを孕みます。

本章ではマルチウェイポットのターン・リバー判断を体系的に整理しました。HUとの核心的な違いは「全員フォールドの確率論」と「逆選択の二重化」にあります。

また、マルチウェイでの判断精度を上げる最も効果的な方法は、本書 第19章で扱うソルバーによるハンドレビューです。HUのソルバーデータをマルチウェイに適用する際の限界と、そこから得られる定性的な示唆を活用する方法を学びます。

## ミニクイズ

### 問1

3wayポットでのリバーバリューベットの最低基準として正しいものはどれですか。

1. トップペア以上（HUと同じ基準で良い）
2. 2ペア以上
3. セット以上

### 問2

3wayポットで、各相手が60%の確率でフォールドするとした場合のブラフ成功率はどれですか。

1. 60%
2. 36%
3. 22%

### 問3

後手スコア = HandScore + A − 3 − C − M において、3wayでの後手スコアがHU時より低くなる理由として正しいものはどれですか。

1. HandScoreが3way対応で再計算されるから
2. M=3が加算されることで後手スコアが3点低下するから
3. A値がマルチウェイでは必ず1になるから

---

### 解答

- **問1**: 2（3wayではバリューラインが1段階上がります。HUでトップペアがバリューになる局面でも、3wayでは2ペア以上が最低基準です。2人のコールレンジに対して「よく勝てる」ためにはより強いハンドが必要で、1ペアでの大きなベットは逆選択が二重に働きます）
- **問2**: 2（60% × 60% = 36%。1人ずつは十分な頻度でフォールドしてくれても、全員フォールドの確率は大幅に低下します。4wayなら60%の3乗で約22%になります。この指数的な低下がマルチウェイでのピュアブラフを非効率にする数学的根拠です）
- **問3**: 2（M=3が後手スコアから減算されるため、3wayでは同一ハンドでも後手スコアが3点低くなります。HandScoreの計算方法は変わらず、A値もボードの特性から決まります。M補正はフォールドエクイティの縮小則（f²≈f×50%）に基づく近似的な調整係数です）

---

> **本章まとめ**
>
> - バリューラインが人数分上がる: HUトップペア → 3way 2ペア → 4wayセット
> - ブラフ成功率は指数的に低下: HU 60% → 3way 36% → 4way 22%
> - M補正を後手スコアに追加: 3way M=3、4-way+ M=6
> - 3wayでのチェックレイズには HU比+3点のHandScore+Aが必要
> - 全員のアクションを常に追跡し、コールが来るほど相手レンジが絞られていることを意識する
> - 3wayピュアブラフは基本的に避け、セミブラフも完成後に全員に勝てる場合に限定する

**【GTOとのズレ】**

マルチウェイのGTO均衡は、2人対戦のGTOよりもはるかに複雑です。各プレイヤーのレンジが互いに影響し合うナッシュ均衡を解くためには、2プレイヤーの何倍ものゲームツリーの探索が必要になります。本書で使用しているソルバーは2プレイヤー専用のため、3way以上のGTO均衡を直接確認する手段がありません。

本章のM補正係数（M=3, M=6）はフォールドエクイティの縮小則から導いた理論値であり、GTO実測による検証を経ていません。HUのGTOデータが「ドライ板では積極バレル」と示していても、3wayでは同じボードで明確に抑制的になることが、定性的には広く知られています。係数の精度については将来の改善余地があることをご承知おきください。

実戦でGTOからずれやすいのは「HUで有効だった戦術をそのままマルチウェイに持ち込む」パターンです。特にトップペアでのバリューベット頻度と、ブラフバレルの継続が過剰になります。GTOからのずれを最小化するシンプルな指針として、「マルチウェイでは迷ったらチェックか小ベット、強バリューだけアグレッション」を意識することで、重大なミスの多くは防げます。
