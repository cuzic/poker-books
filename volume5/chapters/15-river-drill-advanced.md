> **本章のゴール**: α式の精密適用・ブロッカー実戦選択・リバーオーバーベット・ポットコミット判断・リバーCR・backward inductionの6テーマを20問の実戦ドリルで統合し、リバー判断の精度を実戦レベルに引き上げる。

## 15-1 受験ガイド

本章は巻4 第16章（基礎ドリル）および本書 第14章（ターン応用ドリル）の続編として設計された**リバー応用問題集**です。α式の単純計算や後手スコアの基礎計算は巻4 第16章で扱済みです。本章では「なぜその計算になるか」「複数の要素が絡み合うときどう優先順位をつけるか」を問います。

各問は次の手順で取り組んでください。

1. 問題文を読み、**5秒以内に直感判断**を出す
2. ボード読み（ストレート・フラッシュ・ペアボードの役判定）を必ず実行する
3. α式・後手スコア・ブロッカーの計算根拠を言語化する
4. 解答と照合し、どのステップで判断がずれたかを確認する

**合格ライン**: 20問中14問以上の正解。14問以上なら応用リバー技術が実戦レベルに達しています。13問以下の場合は、誤答した問題の参照章に戻って確認してください。

### 式の早見表（全問共通）

```
α式（本書 巻4 第9章）:
  α = ベット額 ÷ (ポット + ベット額)
  後手下限確率 = 1 − α
  V:B均衡比 = (1 − α) : α

後手スコア（巻4 第11章、HU前提のためM=0）:
  = HandScore + A − 3 − C
  A: ドライ=3 / セミ=2 / ウェット=1
  C: 33%=3 / 50%=5 / 75%=7 / 100%=9 / 150%=11
  ≥8 → CR検討 / 0〜7 → コール / <0 → フォールド

HandScore目安（本書 巻4 第5章）:
  ナッツストレート=40 / ストレート=35 / フラッシュ=30
  セット≈25 / 2ペア上位≈27 / 2ペア下位≈22
  TPTK≈20 / TPWK≈15 / セカンドペア≈10
  ブロッカー加点: ナッツブロッカー+4 / 標準ブロッカー+2

ポットコミット条件（本書 第9章）:
  勝率 ≥ コール額 ÷ (ポット + コール額)
```

### 基本前提（全問共通）

```
形式: 6-max キャッシュゲーム、100BB
ポジション: BTN（IP）vs BB（OOP）、HU
M=0（HU前提のためマルチウェイ補正なし）
プリフロップ: BTN 2.5BB オープン → BB コール
```

### Q1 解答　V:B比率の精密設計

**正解: A（75%OBの方が多くのブラフを入れられる、ブラフ上限: 約6コンボ）**

**計算過程:**

```
75%ポットベット（18BB into 24BB）:
  α = 18 ÷ (24 + 18) = 18 ÷ 42 ≈ 0.429（43%）
  V:B均衡比 = (1 − 0.429) : 0.429 = 0.571 : 0.429 ≈ 4:3
  バリュー8コンボに対してブラフ上限: 8 × (0.429 ÷ 0.571) ≈ 8 × 0.75 ≈ 6コンボ

50%ポットベット（12BB into 24BB）:
  α = 12 ÷ (24 + 12) = 12 ÷ 36 ≈ 0.333（33%）
  V:B均衡比 = 0.667 : 0.333 = 2:1
  バリュー8コンボに対してブラフ上限: 8 × (0.333 ÷ 0.667) ≈ 8 × 0.5 ≈ 4コンボ
```

75%OBではブラフ上限が約6コンボ、50%では約4コンボです。ベットサイズが大きいほどαが大きくなり、均衡上入れられるブラフが増えます。これは「大きいベットほど相手に高いフォールド率を要求できる」という関係から生まれます。

選択肢Dの「9コンボ」は過剰です。α=0.429のとき、ブラフ比率はバリューの約75%であり、8コンボに対しては約6コンボが上限です。

**教訓**: ベットサイズを大きくすると、均衡上のブラフ許容量も増える。ブラフを多く入れたいときは大きいサイズを選ぶのが一貫した設計。ただし、大きいサイズは逆にコールしてくる相手のレンジも強くなるため、バリューの質も同時に問われる。

### Q4 解答　α式の逆算

**正解: A（α ≈ 0.25 → 約33%ポットベット）**

**逆算の計算:**

```
V:B = 12:4 = 3:1
α（ブラフ比率）= ブラフ ÷ (バリュー + ブラフ) = 4 ÷ (12 + 4) = 4 ÷ 16 = 0.25

α = ベット ÷ (ポット + ベット) = 0.25
→ ベット = 0.25 × (ポット + ベット)
→ ベット = 0.25 × ポット + 0.25 × ベット
→ 0.75 × ベット = 0.25 × 20
→ ベット = 5 ÷ 0.75 ≈ 6.7BB

約33%ポットベット（33% × 20 = 6.7BB）
```

α = 0.25 のとき、ベットサイズはポットの約33%です。3:1のV:B比率を達成するには小さいベットサイズが必要です。

α式は「ベットサイズを決めたらα（ブラフ比率）が決まる」という順方向の計算が基本ですが、「V:B比率を決めてからサイズを逆算する」という使い方も重要です。本問はその逆算能力を問うものです。

**教訓**: 先手はV:B比率の設計とベットサイズの選択を連動させる。「このサイズで打つなら均衡ブラフ数はいくつか」と「このブラフ数でいくつのバリューが必要か」の両方向で思考できると設計精度が上がる。

### Q8 解答　ダブルブロッカーの評価

**正解: B（バリューベット50%ポット、14BB）**

**ボード読み:**

```
手札: A♣ K♣
ボード: A♠ K♥ Q♣ 2♦ 6♥（5枚）

ランクカウント:
  A: 2枚（A♣手札 + A♠ボード）
  K: 2枚（K♣手札 + K♥ボード）
  Q: 1枚、2: 1枚、6: 1枚

2ペアの確認:
  AペアとKペアが存在 → 2ペア（A's & K's、Qキッカー）

ストレート確認: A-K-Q-J-T → J,T なし → 不成立
フラッシュ: クラブはA♣,K♣,Q♣=3枚 → 不成立
best5: A♣ A♠ K♣ K♥ Q♣ → 2ペア（Aces & Kings、トップ2ペア）
```

A♣K♣はこのボードで**トップ2ペア（Aces & Kings）**です。

**ブロッカー評価:**

A♣K♣はAとKの両方をブロックします。これは「相手のAK（トップ2ペア）」コンボを削ります。しかし同時に、BTN自身もAK 2ペアを持っているため、**バリューハンドとしても機能する**のが特徴です。

「ブラフとして打てるか」の評価: ブラフが有効なのは相手がフォールドしてくれる場合です。このボードでBBがトップ2ペア（AK）を持てないとき（BTNがAとKをブロックしているため確率が下がる）でも、BBは2ペア（AQ、KQなど）やセット（QQ）を持つ場合があります。これらはフォールドしません。

大きいサイズでブラフを打っても、BBの残りコールレンジはBTNのトップ2ペアに勝つハンドが多い状況になります。ブラフよりもバリューとして50%ポットで打つのが最善です。

チェックバックは「BBに無料でショーダウンを与える」ため、トップ2ペアのような強い薄バリューには不向きです。

**教訓**: ダブルブロッカーは「ブラフ候補」だけでなく「バリューベット」の評価にも使える。自分がAKのブロッカーを持つとき、相手のAKが少ない = 自分のAK 2ペアへのコールレンジが変化する。

### Q19 解答　Backward Induction

**正解: B（ダブルバレル50%ポット）**

**ボード読み（ターン段階）:**

```

ボード: A♥ K♦ 7♣ 3♠（4枚ターン）

  A: 2枚（A♣手札 + A♥ボード）→ ペアAA

ストレート確認: A-K-Q-J-T（Q,J,T なし）→ 不成立
フラッシュ: クラブはA♣,7♣,Q♣=3枚 → 不成立
役: 1ペアAA（TPTK）
```

A♣Q♣はターンでTTPK（AA、Qキッカー）です。

**Backward Inductionの思考:**

```
ターンでダブルバレルした場合のリバー:
  ダブルバレル後、リバーでBBがチェックした場合:
    BTNのレンジ = 「強バリューで2バレルを正当化できるハンド」
    → BTNのリバーベット頻度が高く、BBのフォールドを引き出しやすい
    → AQのTTPKなら3バレルバリューまたはリバーチェックバックが設計できる

ターンをチェックバックした場合のリバー:
  BTNのレンジが「強さが不明確なハンド」と読まれる
  → リバーでベットしても信頼性が下がる（第19章Q5と同様の「ストーリー不整合」）
  → AQのような薄バリューでリバーベットの信頼性を確保するには、ターンから攻撃が必要
```

AQ on A-K-7-3（ドライセミ板）のターンではバレルスコアを確認します:

```
FlopType: A♥K♦7♣ → セミ板（K-7は離れている）→ 係数=6
TurnCard: 3♠ → ブランク → 係数=2
バレルスコア = 6 + 2 = 8 → 積極バレルゾーン（≥7）
```

バレルスコア8で積極バレル。AQのTTPK（AキッカーがAのため、正確にはAAペアのQキッカー）は強いバリューです。50%ポットのダブルバレルで攻撃しつつ、リバーへの設計（AQならリバーも薄バリューとして続けられる）を確保します。

**Backward inductionの結論**: ターンでベットしてリバーの選択肢を広く保つ方が、チェックバックしてリバーのストーリーを弱めるより優れています。

**教訓**: Backward inductionは「このアクションが将来の選択肢の質をどう変えるか」を評価する技術。ターンのバレルはリバーのレンジ構成を強化し、将来のベット信頼性を高める。

**参照**: 本書 第2章（backward induction）、本書 第3章（forward thinking）

**正解: B（チェックレイズ）**

**ボード読み（5枚での最終役判定が核心）:**

```
手札: K♠ J♣
ボード: J♥ 9♦ 6♣ T♠ Q♦（5枚）

ランクカウント:
  J: 2枚（J♣手札 + J♥ボード）
  K,Q,T,9,6: 各1枚

ストレート確認:
  K-Q-J-T-9: K♠✓（手札）Q♦✓ J♥✓ T♠✓ 9♦✓ → 5連続 → K-high straight完成！
  A-K-Q-J-T: A なし → 不成立

best5: K♠ Q♦ J♥ T♠ 9♦ → K-high straight（K-Q-J-T-9）
（J♣手札は使用せず、K♠を使ってK-highを形成）
```

K♠J♣はリバーで**K-high straight（K-Q-J-T-9）**を完成させています。フロップからのトップペア（J）という評価は変わり、ストレートが完成しています。

**後手スコア計算（HU前提、M=0）:**

```
HandScore（K-high straight）: 35
A: J♥9♦6♣T♠Q♦ → コネクテッドウェット → A = 1
C: 73%ポット ≈ 75% → C = 7
後手スコア = 35 + 1 − 3 − 7 = 26
```

**Backward inductionの観点:**

このボードでBTNの73%ベットレンジには、K-high以上のストレート（broadway = AJが必要）とブラフが含まれます。BTNがAJでbroadwayを持つ場合はBBが負けますが、BTNがブラフや中程度のバリュー（2ペア等）を持つ場合はBBのK-high straightが勝ちます。

後手スコア26でCR域（8以上）を大幅に超えています。CRでポットを膨らませてEVを最大化するのが正解です。

backward induction的には: BBがここでコールのみを選ぶと、リバー終了後のショーダウンで「コールで守る」という受動的な戦略になります。CRを選べば「BTNのブラフを強制的にフォールドさせる」か「BTNのバリューからさらにコールを引き出す」という能動的な設計になり、期待値が高まります。

**教訓**: コネクテッドボードでは「トップペアと思っていたハンドがストレートに化けている」ケースがある。5枚の役判定を怠らないことが、CRのような重要な判断ミスを防ぐ。

**参照**: 本書 第2章（backward induction）、本書 第8章（リバーCR）

### 問2

ボード **K♦Q♣J♠T♥2♣** で、BTNのハンドは **A♣9♠** 。BTNの役は何か。

```
1. ハイカード（Aハイ）
2. ペア（ボードKQJTのいずれかとペア）

```

### 問3

ポット40BB、BBスタック25BB。BBが **25BB オールイン** 。BTNのコール必要勝率（ポットオッズ）はいくつか。

```
1. 約25%（コミット状態に近い）
2. 約38%（コミット境界域）
3. 約50%（大きなベット）
4. 約60%（コールが難しい）
```

---

### 解答

**問1: 1（40%）**

```
α = 45 ÷ (30 + 45) = 45 ÷ 75 = 0.60
後手下限確率 = 1 − 0.60 = 0.40（40%）
```

150%OBは非常に大きなサイズのため、後手下限確率が40%まで下がります。BBはレンジの40%のみでコールが必要です。

**問2: 3（ブロードウェイ）**

A♣ + K♦Q♣J♠T♥ = A-K-Q-J-T = broadway（A-high straight）が完成しています。9♠はストレートに不参加。ハイカードやペアではなく、ナッツストレートです。

**問3: 2（約38%）**

```
ポットオッズ = 25 ÷ (40 + 25) = 25 ÷ 65 ≈ 0.385（約38%）
```

BTNは勝率38%以上あれば、コールがEV上プラスです。

> **本章まとめ**
>
> - α式の逆算（V:B比率 → αの計算 → ベットサイズの決定）は先手の設計力を高める。ベットサイズが大きいほど均衡ブラフ数が増える。
> - ブロッカーは「バリューブロッカー」と「ブラフブロッカー」のスート単位での効果を評価する。A♥とA♦は同じAブロッカーでもフラッシュボードでは全く異なる価値を持つ。
> - リバーOBはナッツアドバンテージが明確な局面（ナッツフラッシュ・ナッツストレート保有）でのみ正当化される。ナッツ未満でのOBは相手の強コールレンジに捕まるリスクが大きい。
> - コミット判断の順序: まずハンド強度とポットオッズを比較し、コールEVが正なら強制コール。SPR<1はコミット状態の目安だが、ハンドが弱ければSPR<1でもフォールドが正しい場合がある。
> - リバーCRは後手スコア8以上が基準。ストレートやセットを持つ場面では、コールよりCRが期待値を高める（BTNのブラフをフォールドさせながら、バリューのコールを引き出す）。
> - Backward inductionはリバーの選択肢の質を先読みしてターンのアクションを決める思考法。ターンでバレルすることでリバーのベット信頼性が高まる。

**【GTOとのズレ】**

本章のドリルは6つの応用技術を暗算式で処理できるよう設計していますが、GTOとのズレが生じやすいポイントが3つあります。

第1に、ブロッカー評価の精度についてです。本章では「ブロッカーが有効か無効か」の二択で評価していますが、GTOではコンボごとのブロッカー効果を数値化して混合戦略の頻度調整に使います。たとえばQ10のようなケースで、A♣ブロッカーが「broadway削減30%」程度の効果しかない場合、GTOはコール頻度をわずかに下げる（完全フォールドではなく低頻度コール）という混合戦略を取ることがあります。本章の「フォールド一択」という結論はGTO近似ですが、実際は「低頻度コール」が混在する可能性があります。

第2に、backward inductionの精度についてです。Q19のようなターン段階での先読みは、GTOでは「リバーの期待値 × リバー到達確率」という積分計算で評価されます。本章の解答は「レンジの整合性」と「ストーリーの一貫性」という定性的な評価に基づいており、実際のEV差は局面によって小さいケース（チェックバックとバレルのEV差が1BB未満）もあります。感覚的に「どちらでもいい」と感じる局面では、GTOの確認が有効です。

第3に、OBのサイズ選択についてです。Q11・Q13のナッツOBでは「150%ポット」を正解としていますが、GTOでは「75%・100%・150%」の複数サイズを混ぜて使う設計が多く見られます。150%一本化は最大化ではなく近似です。実際の最適サイズは相手のコールレンジの形状（Capped vs Uncapped）によって変化するため、ソルバーでの確認を推奨します。
