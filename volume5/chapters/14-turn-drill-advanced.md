# 第14章　ターン実戦例20問（応用）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 第1章〜第13章で学んだ3軸統合・backward induction・ブロッカー実戦選択・ターンオーバーベット・マルチストリート計画を、20問の実戦形式で総点検する。各問の解答では「なぜその判断になるか」を3軸で説明できることが目標。

---

## 14-1 受験ガイド

本章は巻4 第16章（基礎ドリル）の続編として設計された**応用問題集**です。バレルスコアの単純計算や後手スコアの基礎計算は巻4 第16章で扱済みのため、本章では扱いません。

各問は次の手順で取り組んでください。

1. 問題文を読み、**5秒以内に直感判断**を出す
2. その判断の根拠を「3軸で言語化」してみる（forward / current / backward）
3. 解答を確認し、自分の論理との差を確認する

答えが正しかったかどうかより、「なぜそうなるか」を3軸で説明できたかどうかが重要です。第14-3節の解答セクションは、問題を全問解いてからまとめて読むことをお勧めします。

**合格ライン**: 20問中15問以上の正解。15問以上なら3軸統合の実戦応用力が身についています。15問未満の場合は、誤答した問題の参照章に戻って確認してください。

### 式の早見表（全問共通）

```
バレルスコア（巻4 第8章）:
  = FlopType係数 + TurnCard係数
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0
  ≥7 → 積極バレル / <7 → ハンド依存

後手スコア（巻4 第10・11章、HU前提のためM=0）:
  = HandScore + A − 3 − C
  A: ドライ=3 / セミ=2 / ウェット=1
  C: 33%=3 / 50%=5 / 75%=7 / 100%=9 / 150%=11
  ≥8 → CR検討 / 0〜7 → コール / <0 → フォールド

α式（巻4 第9章）:
  α = ベット額 ÷ (ポット + ベット額)
  後手下限確率 = 1 − α = ポット ÷ (ポット + ベット額)

HandScore目安（巻4 第5章）:
  ナッツストレート=40 / ストレート=35 / フラッシュ=30
  セット≈25 / 2ペア上位≈27 / 2ペア下位≈22
  TPTK≈20 / TPWK≈15 / セカンドペア≈10
  ドロー加点: FD≈13 / OESD≈12 / GS≈6
```

### 基本前提（全問共通）

```
形式: 6-max キャッシュゲーム、100BB
ポジション: BTN（IP）vs BB（OOP）、HU
M=0（HU前提のためマルチウェイ補正なし）
プリフロップ: BTN 2.5BB オープン → BB コール
フロップ前ポット: 5.5BB（スタック: 97.5BB 各自）
```

**正解: A. チェック → OOPのベットをコール**

- Q-J-T-9-8 → T なし → NO
- J-T-9-8-7 → T なし → NO
- T-9-8-7-6 → T, 6 なし → NO

- Q-J-T-9（Tなし）→ NO
- J-T-9-8（Tなし）→ NO
- Q-J-9-8 → 連続ではない（Tが欠けており4連続にならない）

**forward thinking でBBのCRレンジを評価する（第3章）**:

BBがフロップ9♠8♣7♦でCRを打ちました。BBのCRレンジには:

- 強いドロー（J-T等のOESD + 高カード）

- ターン2♦はブランク（BBのレンジを変えない）
- Q♠J♦のガットショット（T待ち4アウツ）は弱いセミブラフ
- BBのCRレンジが強いため、BTNのベット（セミブラフ）は期待値が低い

**【GTOとのズレ】**

**3軸統合の「競合」シナリオでのGTOの混合戦略**

本章のQ4（バレルスコア9だがSDV保護でチェックバック）やQ18（後手スコア7だがfold推奨）のような「境界付近の判断」では、GTOが純粋な1択を返すことは少ありません。実際にはGTOは「チェックバック60%、50%バレル30%、75%バレル10%」のような混合戦略を使います。

本章での正解は「最善の純粋行動」を示したものです。境界付近のハンドを実戦で混合戦略で回すことは人間には難しいため、「まず1択で判断できる力をつけ、その後ソルバー学習で混合戦略を確認する」という順序が合理的です。

**ターンOBのGTO頻度と実戦乖離**

ターンOBは第6章の条件を満たしても、GTO上では必ずしも100%の頻度で使うわけではありません。クワッズや超強力なフルハウスでも、GTO上は「OB50%、標準ベット50%」のように混合する場合があります。これはプロテクション（ブラフのカモフラージュ）の目的からです。本章の問題では「OBが最優先」と示しましたが、実戦ではOB：標準ベット = 7:3程度の比率で混合することをソルバーで確認することを推奨します。

**forward thinking と実際のレンジとのずれ**

Q20のフロップCR後のBBのレンジ評価で、「BBのCRレンジは強いハンドに絞られる」としましたが、実際のGTO上ではBBのCRレンジにはブラフCRも一定量含まれます。BBのCRすべてを「強いハンドのみ」と解釈すると、BTNはチェックバックしすぎになります。forward thinking では「BBのCRのうちバリューが多い」という方向性の把握に使い、「バリューだけ」と断定しないことが重要です。
