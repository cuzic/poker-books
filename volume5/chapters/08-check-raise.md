# 第8章　チェックレイズとリバーCR

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: チェックレイズ（CR）の応用判断を体系化する。ターンCR・リバーCR・チェックビハインドからの裏切りを習得し、巻④ 第15章の基礎を実践レベルに引き上げる。

---

## 8-1 基礎の先にある応用CR

巻④ 第15章でチェックビハインドとブラフキャッチの基礎を学びました。チェックビハインドの3クラス（SDV保護・トラップ・攻撃の放棄）と、後手スコアによるコール/フォールド判断がその骨格です。

本章では「コールかフォールド」という二択を超えた選択肢、すなわちチェックレイズ（CR）を扱います。CRはポットを積み上げ、相手にプレッシャーをかけ、自分のレンジを守るための攻撃的なディフェンス手段です。正しく使えば大きな利益をもたらし、誤用すれば致命的なEVロスを招きます。

本章の軸は3つです。

```
軸1: ターンCR
  いつ打つか、どのハンドで打つか、サイズはどうするか

軸2: リバーCR
  フロップ・ターンのCRとは何が異なるか
  バリューCRとブラフCR（BCR）をどう設計するか

軸3: チェックビハインドからの裏切り
  ターンのチェックバック後にリバーで攻撃する
  backward induction（第2章）を使った設計
```

本章では第2章のbackward inductionと、第5章のブロッカー実戦選択を頻繁に参照します。CRの判断はこれら2つを統合した高度な戦術であるからです。

## 8-2 ターンCR ─ 基本条件と設計

### いつターンCRを打つか

ターンでCRを打てる条件は「コール」より高い基準が必要です。後手スコアはコール/フォールドの判断式ですが、CR検討が始まる閾値（スコア40以上）に加えて、実際にCRを選ぶには次の2条件も必要です。

```
ターンCR追加条件:
  条件1: IPがベットしてくれる頻度が高い
    → バレルスコア（巻④ 第8章）が7以上のボードでIPは積極的にベット
    → IPがベットしないとCRを仕掛けられない

  条件2: IPの3bet（再レイズ）リスクが許容範囲内
    → 自分のハンドがIPの3betレンジに勝てる強さがあるか
    → 2ペア以下でCRするとIPの3betで壊滅的なEVロスになりうる
```

この2条件を満たした上で後手スコアが40以上であれば、ターンCRが有力な選択肢になります。

### バリューCRの構成

ターンでバリューCRを打てるハンドは、IPのベットレンジの大部分に勝てる強さが必要です。目安は以下のとおりです。

| ハンドの強さ | ターンCRへの適性 | 理由 |
|---|---|---|
| セット以上 | 高い | IPの3betに対しても優位。ポットを大きくするメリット大 |
| ストレート・フラッシュ完成 | 高い | ナッツ近辺。IPのコールレンジから追加利益 |
| 強い2ペア（トップ2ペア等） | 中程度 | IPの3betリスクを考慮して判断 |
| トップペア | 低い | IPの3betで詰まる。チェックコールが安全 |

2ペアでのCRは「ボードがウェットで相手に強いバリューが多い」状況では危険です。特に連続ボードではIPがセット・ストレート・フラッシュを高確率で持てるため、2ペアのCRにIPが3betしてくることが頻繁に起きます。

### ブラフCR（BCR）の選択

ターンBCRはリバーのBCRより広い意味でセミブラフ的な性質を持ちます。ターンにはまだ1ストリートが残るため、ドロー中のハンドでCRすることで「フォールドエクイティ（相手を今フォールドさせる価値）」と「ドロー完成後のバリュー」の両方を得られます。

```
ターンBCRの優先候補:
  1. フラッシュドロー保有 + バリューブロッカーあり
     → リバーでフラッシュ完成ならバリュー、外れならBCR継続
     → 相手のレンジをブロックしながらFEを得る

  2. OESDまたはガットショット + ブロッカーあり
     → ストレート完成なら大バリュー、外れならBCR継続

  3. ドローなし + 強いバリューブロッカー保有
     → 相手のコールレンジの中心を削りながらFEのみ狙う
     → 成功率が低いため使用頻度は限定的
```

第5章で確認したとおり、ブロッカーはブラフの方針を作るものではなく、方針が決まった後にコンボを選ぶための最終調整です。「ブロッカーがあるからBCRできる」ではなく「BCRする局面でブロッカーの強いコンボを選ぶ」という順序で使います。

### α 式でCRサイズを設計する

ターンCRのサイズはIPのベットの2.5〜3倍が標準です。α 式（巻④ 第9章）を使って、IPのコールオッズとBCRの必要フォールドエクイティを確認します。

```
例: ポット20BB、IPが33%（7BB）ベット
    BCRを3倍（21BBに）CR

IPのコールコスト = 21 − 7 = 14BB
コール後のポット = 20 + 7 + 21 = 48BB
α = 14 ÷ 48 ≒ 0.29

→ IPのMDF = 1 − 0.29 = 0.71（71%）
→ BCRがバリューCRの29%以内なら均衡
```

BCRの比率はバリューCRのコンボ数を基準に管理します。ターンCRのサイズが大きいほどFEは高くなりますが、バランス上のBCR枠が狭まります。

### 実例: ターンCR

**状況**: BTN（IP）vs BB（OOP）、SRP、100BB

**ボード（4枚）**: T♠9♦8♣J♦（ターンJ♦）

ボード役の確認（T♠9♦8♣J♦の4枚）: スーツ別 ♠=T♠ 1枚、♦=9♦8♣J♦ 3枚、♣=8♣ 1枚。ストレート要素: J-T-9-8の4連続あり。フラッシュ要素: ♦3枚（フラッシュドロー状態）。

**BBのハンド**: T♥9♣

役確認: T♥, 9♣, T♠, 9♦, 8♣, J♦ の6枚。Tが2枚（T♥・T♠）、9が2枚（9♣・9♦）。ストレートチェック: J-T-9-8-7（7なし）、Q-J-T-9-8（Qなし）。best 5 = T-T-J-9-9 → **2ペア（T's and 9's）**。

```
HandScore = 75（2ペア top + mid、新スケール役スコア）

後手スコア計算:
  A（ウェット＝4連続コネクテッド）= 0（ウェット）
  C（BTNの50%ポットベット）= 17
  M（HU）= 0

後手スコア = 75 + 0 − 17 − 0 = 58 → CR検討域（≥ 40）
```

ただし2ペア（T's and 9's）は強いですが、J♦ターンでQT・QK・77等でストレートが成立するボードです。BTNの3betリスクを確認します。

```
このボード（TJJT9...ではなくT♠9♦8♣J♦）でBTNが3betするレンジ:
  QT（ストレート: Q-J-T-9-8）、Q7（ストレート: Q-J-T-9-8 ← 7あるか?）
  
  実際にストレート確認:
  QT on T♠9♦8♣J♦: ランク=Q,T,J,T,9,8。5連続: Q-J-T-9-8 → 全部揃う → ストレート完成
  
  BTNがQT等のナッツストレートを持てる可能性がある。
  → BBの2ペアで大きなCRを打つとBTNに3betされるリスク中程度
  → バリューCR（2〜2.5倍の小CR）が安全。大CR（3倍以上）は慎重に
```

**判断**: 2ペアでの小CR（2倍CR = 約14BB）が合理的。IPの3betを防ぎながらポットを積み上げられます。

## 8-3 リバーCR ─ 希少性と威力

### リバーCRがターンCRと異なる点

リバーのCRには、ターンCRにはない根本的な制約があります。セミブラフが存在しないことです。

ターンのBCRには「ドロー完成でバリューに昇格する」という逃げ道がありました。リバーは最終ストリートです。リバーのCRはバリューかブラフかの純粋な二択です。中間的なセミブラフは物理的に成立しません。

```
ターンBCR（セミブラフあり）:
  フォールドエクイティ + ドロー完成後のバリュー

リバーBCR（純粋ブラフのみ）:
  フォールドエクイティのみ
  → コールされたら100%負け
```

この違いがリバーCRを希少かつ高リスクな選択にします。GTO上でもリバーCRはターンCRより頻度が低く、特にBCRは厳しい条件が揃ったときだけ機能します。

### バリューCRの条件（リバー版）

リバーのバリューCRが成立するためには3つの条件が揃う必要があります。

```
条件1: IPのコールレンジの大部分に勝てる強さ
  セット、ナッツフラッシュ、ナッツストレート、フルハウス等
  IPのベットレンジの70%以上に勝てることが目安

条件2: IPがCRに対してコールするハンドが存在する
  IPのベットレンジが広い（1ペア〜2ペアのバリューやブラフを含む）
  IPのバリューがCRにコールできる強さを持つ

条件3: ポットを大きくするメリットがある
  自分のナッツ強度が高く、IPのコールで確実に利益が増える
```

バリューCRはIPが「広いレンジでベットしている」場面で特に有効です。IPが強いバリューのみでベットしている局面では、CRへのコールが強いハンドに絞られるため、利益が限定されます。

### BCR（ブラフCR）の設計

リバーBCRは本書で最もリスクの高い戦術のひとつです。成立するためには第5章で確認した3要素が揃う必要があります。

```
要素1: フォールドエクイティ
  IPのベットレンジに、CRに対してフォールドする
  中程度のハンドが十分含まれている
  → IPが1ペア以下でベットしている場面で最も機能する

要素2: バリューブロッカー（第5章）
  IPのコールレンジの中心をブロックするカードを保有
  例: フラッシュ完成ボードでA♠を持ち、
      IPのナッツフラッシュコンボを削減する

要素3: ストーリーの一貫性
  フロップ・ターンのアクション履歴がリバーCRと矛盾しない
  例: フロップでドローとしてコールし、リバーでCRすることで
      「完成した？」というイメージを相手に持たせられる
```

3要素のうちひとつでも欠けると、BCRの期待値が大幅に低下します。特にストーリーの整合性は、ブロッカーが強くても覆せない要素です。フロップ・ターンで「強い手を持っている」という印象を与えるアクションをしていたのに、リバーで突然BCRを打っても相手はコールしやすくなります。

### α 式でBCRの比率を管理する

BCRの頻度は、バリューCRのコンボ数を基準にα 式で管理します。

```
例: リバーで3倍CRを打つ（IPの10BBベットを30BBにCR）

ポット20BB、IPの10BBベット後、30BBにCR:
  IPのコールコスト = 30 − 10 = 20BB
  コール後のポット = 20 + 10 + 30 = 60BB
  α = 20 ÷ 60 ≒ 0.33

→ BCRの比率上限 = バリューCRコンボ × (0.33 ÷ 0.67) ≒ バリューの50%
```

バリューCRが6コンボなら、BCRは3コンボ以内が均衡した配分です。BCRを過剰に使うと、IPはCRに対してコールを増やして搾取してきます。

### 実例: リバーBCR

**状況**: BTN（IP）vs BB（OOP）、SRP、100BB

**ボード（5枚）**: K♠8♠4♥2♣J♦（リバーJ♦）

ボード確認: スーツ別 ♠=K♠,8♠ 2枚、♦=J♦ 1枚、♥=4♥ 1枚、♣=2♣ 1枚。ストレート: K-J-8-4-2 → 5連続なし。フラッシュ不成立。

**BBのハンド**: A♠6♠

役確認: A♠, 6♠, K♠, 8♠, 4♥, 2♣, J♦ の7枚。スペード: A♠, 6♠, K♠, 8♠ = 4枚（フラッシュ未完成、バスト）。5連続確認: A-K-J-8-6 → A-K-Q-J-T（Q,Tなし）、不成立。役なし（Aハイ）。HandScore = 25。

```
後手スコア = 25 + 12 − 22（75%ポットベット仮定）− 0 = 15 → フォールド（< 20）
```

スコアは明確なフォールド域ですが、BCRの3要素を確認します。

```
要素1（フォールドエクイティ）:
  BTNがリバー75%ポットベット。BTNのベットレンジにはバリュー（Kx・Jx等）と
  ブラフが混在。BTNが1ペア以下でベットするコンボが一定数存在。
  Kxはリバー最多バリュー。J♦ターンでJxも増加。
  → FE中程度

要素2（バリューブロッカー）:
  A♠保有。ボードはスペード2枚。リバーJ♦でスペードフラッシュは未完成。
  A♠はナッツスペードフラッシュ候補（A♠x♠）をブロック。
  しかしこのリバーではスペードフラッシュは完成していない。
  → A♠のブロッカー効果は「Ax系バリュー（AK等）のブロック」に限定される

要素3（ストーリーの一貫性）:
  フロップでスペードFDとしてコールしたことが自然な前提。
  リバーJ♦でスペードFDがバスト。CRは「FDが完成したかも」という誤解を
  利用できる（実際は4枚のみ）。
  → ストーリーはやや成立
```

BCRが機能するかは、BTNのベットレンジにどの程度のブラフが含まれるかに依存します。ボードがドライ寄り（K♠8♠4♥2♣）で、J♦がブランク系のターンなら、BTNのバレルレンジはバリュー中心に絞られている可能性があります。FEが十分でない局面では、BCRのリスクが見返りを上回ります。

A♠のブロッカーが機能するのは「相手のAKコンボを削る」効果のみです。ナッツフラッシュがこのボードでは完成していないため、第5章で最優先とされた「フラッシュボードでのA♥保有」のような強力なブロッカー効果は得られません。

**判断**: このBCRは「弱いストーリー + 限定的ブロッカー + 中程度のFE」という組み合わせであり、採用は限定的です。実戦ではフォールドまたはコールが安全な判断になるケースが多いです。

## 8-4 チェックビハインドからの裏切り

### 「信頼された自分のレンジ」を利用する

ターンでチェックバックした後のリバーベットは、「裏切り」というよりも計画的な遅延攻撃です。巻④ 第15章でIPのチェックビハインドには「トラップ」クラスが存在することを学びました。本節ではそのトラップを、第2章のbackward inductionで設計する方法を具体化します。

```
相手の目線:
  IPがターンでチェックバック → 「IPのレンジはSDV保護か攻撃放棄」
  → リバーでIPがベットしてきても「弱いハンドのブラフ？」と疑いにくい

IPの目線:
  ターンでチェックバック → リバーで攻撃
  → 相手が「IPの弱さ」を信頼した状態でリバーベットが刺さる
```

このギャップを意図的に生み出すのが「チェックビハインドからの裏切り」の本質です。

### backward inductionによる設計

第2章の5ステップbackward inductionをCR設計に応用します。

```
Step 1: ターン時点で主要リバーシナリオを立てる
  例: K♠9♦4♣（フロップ）+ 2♥（ターン）の4枚ボード
  → リバーのシナリオA: ブランク（最多）
  → リバーのシナリオB: OC（A落ち）
  → リバーのシナリオC: ペア（K・9・4・2落ち）

Step 2: 各シナリオでハンドの役を確認する
  例: ハンドが9♣9♥
  
  役確認（4枚ボード K♠9♦4♣2♥）: 9♣, 9♥, K♠, 9♦, 4♣, 2♥ の6枚
  9が3枚（9♣, 9♥, 9♦）、2が1枚（2♥）
  ペアボード（2♥単枚=ペアなし）
  best 5 = 9-9-9-K-4 → セット（9's）
  ※2♥はボードに1枚のみのため9-9-9-2-2のフルハウスには未達

  シナリオA（ブランク）: セット維持。バリューベット候補
  シナリオB（A落ち）: セット維持。Aのペアには負ける可能性（A-K-9-9-9 < A-A-K-9-9等）
  シナリオC（Kペア）: フルハウス（9's full of K's）に昇格

Step 3: ターンのトラップ設計
  9♣9♥はターンで「バリューベット or チェックバック（トラップ）」の判断
  → トラップを選ぶ理由: リバーでシナリオAやCで大きいバリューを取れる
     相手がリバーでブラフしやすい条件が揃っているか確認
```

トラップを選ぶターンは「相手が積極的にリバーベットしやすい状況」です。相手がパッシブなら誘い出せないため、トラップのEVが下がります。

### 実例: トラップ設計とリバーバリューベット

**状況**: BTN（IP）vs BB（OOP）、SRP、100BB

**ボード（4枚）**: 9♠8♦3♣3♥（ターン3♥、ペアターン）

**IPのハンド**: 9♦9♣

役確認: 9♦, 9♣, 9♠, 8♦, 3♣, 3♥ の6枚。9が3枚（9♦, 9♣, 9♠）→ セット（9's）。3が2枚（3♣, 3♥）。best 5 = 9-9-9-3-3 → **フルハウス（9's full of 3's）**。

```
backward induction（ターン時点での設計）:

Step 1: 主要リバーシナリオ
  シナリオA: ブランク（最多）
  シナリオB: OC（A・K・Q・J・T）
  シナリオC: ペア（9・8・3落ち）

Step 2: 各シナリオでの役
  シナリオA: フルハウス（9's full of 3's）維持
  シナリオB-T: フルハウス（9's full of 3's）維持（Tでは役変化なし）
  シナリオC-9: クワッズ（9's four of a kind）
  シナリオC-3: フルハウス（9's full of 3's）維持

Step 3: トラップ判断
  全シナリオでフルハウス以上 → 常に大きなバリュー
  相手（BB）がリバーでベット/ブラフしてくる条件は？
  → ターンのペアターン（3♥）でIPがチェックバックすると
    「IPは弱い」シグナルをBBに送れる
  → BBが攻撃的なプレイヤーなら、リバーでドンク/ブラフベットしてくる

ターン判断: フルハウス（9's full of 3's）でチェックバック（トラップ）
```

リバーでBBがチェックした場合はIPがバリューベットします。BBがリバーでベットしてきた場合はコール（またはCR）で利益を最大化します。ターンのチェックバックが「IPの弱さ」として記録され、リバーでの搾取を生む設計です。

### SDV保護からリバー攻撃への転換

チェックビハインドからの裏切りには、SDV保護としてチェックバックした後のリバー攻撃も含まれます。

ターンでSDV保護としてチェックバックした手が、リバーカードによって強さが変化する場合があります。第2章で学んだ「役はシナリオごとに再計算する」という原則です。

```
例: ターンでセカンドペアとしてチェックバック

ターンボード: K♠9♦4♣2♥（セカンドペア: 9's）
ハンド: 9♣8♣

役確認（4枚ボード）: 9♣, 8♣, K♠, 9♦, 4♣, 2♥
9が2枚（9♣, 9♦）→ ペア（9's）。ストレート不成立。best 5 = K-9-9-8-4 → 1ペア（9's）

リバー9♥が落ちた場合:
5枚ボード: K♠9♦4♣2♥9♥

役確認: 9♣, 8♣, K♠, 9♦, 4♣, 2♥, 9♥ の7枚
9が3枚（9♣, 9♦, 9♥）→ トリップス
best 5 = 9-9-9-K-8 → トリップス（9's）

→ ターンでSDV保護としてチェックバックしたが、
  リバーでトリップスに昇格 → バリューベットが適切
```

このような「予期せぬ強化」も計画的に使えます。第2章のStep 2（各シナリオでの役の確認）でターン時点から「どのリバーで強くなるか」を先読みしておき、強化シナリオが来たときに迷わずバリューベットを打てる準備をしておくことが重要です。

## 8-5 CR戦術の意義と管理

### バリューレンジを守る

CRはOOPのプレイヤーが「強いハンドを持っていること」を相手に認識させる重要なシグナルです。OOPが常にコールかフォールドしかしない場合、IPは「OOPがチェックしたらベットし放題」という搾取戦略を取りやすくなります。

CRを適切な頻度で打つことで、IPのベット判断に制約が生まれます。IPは「OOPがCRしてくる可能性」を考慮して、ブラフベットの頻度を抑制せざるを得なくなります。これがCRの「レンジを守る」機能です。

```
CRがない場合:
  IPは「OOPがチェック = 弱い」と判断してブラフ頻度を増やせる
  → OOPはより搾取される

CRが適切にある場合:
  IPは「OOPがCRしてくるかもしれない」と考えてブラフを抑制
  → OOPのチェックの価値が保たれる
```

### 相手の読みをかき乱す

チェックビハインドからの裏切り（8-4節）は、相手の「IPのチェックバック = 弱いハンド」という固定観念を崩します。IPのチェックバックレンジが「弱いハンドのみ」ではなく「強いハンドのトラップも含む」という認識を相手に持たせることで、両方向で利益が生まれます。

```
方向1: トラップからのバリュー
  チェックバック後にリバーでバリューベット → 相手のコールを引き出す

方向2: トラップの抑止力
  「IPがチェックバックしても強いかもしれない」 → 相手がリバーで攻撃しにくくなる
```

この双方向の効果を生むためには、強いハンドでのチェックバックを一定頻度で実際に行うことが必要です。「必ず強いハンドはベットする」プレイヤーはトラップの抑止力を失います。

### 過剰なCRを防ぐ管理

CRは強力ですが、頻度が多すぎると逆効果です。バリューレンジが薄い（強いハンドが少ない）局面で頻繁にCRを打つと、IPが「OOPのCRにはブラフが多い」と判断してコール頻度を上げます。

```
CR頻度の管理:
  □ バリューCRのコンボ数を確認
  □ BCRはバリューの50〜100%以内に抑制（サイズによる）
  □ 「何もないからCR」は最悪の選択
```

第5章のブロッカー選択と同様、CRの判断もα 式による配分設計が先行します。ブロッカーやFEはその後の「どのコンボを使うか」という調整です。

## ミニクイズ

### 問1

リバーCRブラフ（BCR）を打つのに最適なハンドの特徴として最も正しいものはどれですか。

1. ショーダウンバリューがある（弱いペアなど）ため、相手がフォールドしなくてもある程度ポットを取れる
2. バリューブロッカーが極めて強い手で、ショーダウンバリューがほぼゼロ、かつフォールドエクイティが十分にある
3. ドロー外れのハンドであれば常にBCRが機能する

### 問2

ターンCRとリバーCRを比較したとき、リバーCRの方が一般的に頻度が低い理由として最も正しいものはどれですか。

1. リバーはポットが大きくなりすぎてCRが怖い
2. リバーではセミブラフが消滅し、BCRが純粋ブラフになるため、条件が厳しくなる
3. リバーはIPがベットしてくる頻度が低いため、CRのチャンスが少ない

### 問3

チェックビハインドからの裏切り（ターンでチェックバック → リバーで攻撃）の典型的なバリュー例はどれですか。

1. ターンで役なし（空振り）でチェックバック → リバーでブラフベットを打つ
2. ターンで強いハンドをチェックバックしてトラップ → リバーで相手のベット/チェックに対してバリューベット（またはCR）で最大化する
3. ターンでトップペアをチェックバック → リバーで小さいバリューベットを打つ

---

### 解答

- **問1**: 2（BCRが機能する3要素は「フォールドエクイティ・バリューブロッカー・ストーリーの一貫性」です。ショーダウンバリューがあるハンドはバリューとして使うべきで、ブラフに使うのはEVを捨てる行為です。「ドロー外れなら常にBCR」という考え方も誤りで、3要素が揃った条件に限定する必要があります）

- **問2**: 2（ターンBCRはセミブラフ（ドロー完成の可能性）を含むため、「フォールドエクイティ + ドロー価値」で成立します。リバーBCRはセミブラフが消滅し、コールされたら100%負けるという純粋ブラフになります。この制約がBCRの成立条件を厳しくし、頻度を低くします。選択肢1はサイズの問題であり本質ではありません。選択肢3はIPのベット頻度と直接の関係はありません）

- **問3**: 2（トラップ設計の本質は「強いハンドをあえてチェックバックして相手のベット/ブラフを誘い、リバーで最大利益を取る」ことです。選択肢1は役なしからのブラフであり、backward inductionの「リバーでバリューになれない手はブラフ候補」という観点からはブラフとして機能することもありますが、典型的なバリュー例ではありません。選択肢3のトップペアチェックバックは条件によりますが、リバーでの小さいバリューベットはトラップの利益最大化として非最適です）

---

> **本章まとめ**
>
> - ターンCRの条件は「後手スコア40以上」に加えて「IPの高頻度ベット（バレルスコア7以上）」と「IPの3betリスクが許容範囲内」が必要
> - バリューCRはセット以上が基準。2ペアでのCRはIPの3betで壊滅することがあるため慎重に
> - リバーCRはセミブラフが消滅するため、BCRは純粋ブラフであり条件が厳しい。3要素（FE・バリューブロッカー・ストーリー）が揃った局面に限定する
> - BCRの比率はα 式で管理する。バリューCRのコンボ数 × α ÷（1 − α）がBCR上限
> - チェックビハインドからの裏切りはbackward inductionで設計する。リバーシナリオを先読みし、強いハンドを計画的にトラップとしてターンでチェックバックする
> - CRはレンジを守る機能を持つ。一定頻度のCRがIPのブラフを抑制する

**【GTOとのズレ】**

GTOでは、OOPのターンCRとリバーCRはバリューとBCRのバランスが精密に管理されます。特にリバーCRのBCRは、バリューCRに対してα 式が示す比率を厳格に守るよう設計されます。実戦でよく見られるズレは2方向あります。

ひとつは「2ペアで大きくCRを打ちすぎる」問題です。GTOでは2ペアはターンCRよりチェックコールが多い傾向があります。2ペアのCRはIPの3betに対して脆弱で、ウェットボードでは特に危険です。「2ペアは強いからCRする」という直感に頼ると、IPのナッツ3betに吸い込まれます。

もうひとつは「チェックビハインドのトラップを使わない」問題です。多くのプレイヤーは強いハンドをほぼ全てターンでベットします。そのためIPのチェックバックが「弱いハンド」と完全に読まれ、相手はIPのチェック後に積極的に攻めてきます。GTOではナッツ〜準ナッツのハンドでも一定割合でチェックバックし、レンジのバランスを保ちます。「時には強い手をチェックバックする」意識を持つだけで、相手の搾取を大幅に減らせます。

リバーBCRについては、GTO的にはバリューCRの比率に合わせた頻度が必要ですが、実戦の一般プレイヤーはリバーCRをほぼバリューのみで打つ傾向があります。この現実を踏まえると、相手のリバーCRには「まずバリューを疑う」姿勢が実戦的なエクスプロイトになります。
