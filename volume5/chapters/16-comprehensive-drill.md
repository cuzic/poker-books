## 16-1 ドリルの使い方

本章は本書のフィナーレです。50問を通じて、バレルスコア・α 式・後手スコア・ブロッカー論・マルチストリート統合の各要素を一体として使う練習をします。

### 問題の前提（全問共通）

```
形式: 6-max キャッシュゲーム、100BB スタック
ポジション: BTN（IP）vs BB（OOP）、HU（ヘッズアップ）
プリフロップ: BTN 2.5BB オープン → BB コール（SRP）
HU前提のためM=0（マルチウェイ補正なし）
```


### 式の早見表

演習中いつでも参照できるように、3つの暗算式をまとめます。

```
バレルスコア（巻④ 第8章）:
  = FlopType係数 + TurnCard係数
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0
  ≥7 → 積極バレル   <7 → ハンド依存

後手スコア（本書 巻⑤ 第11章、HU前提のためM=0）:
  = HandScore + A − 3 − C
  A: ドライ=3 / セミ=2 / ウェット=1
  C: 33%=3 / 50%=5 / 75%=7 / 100%=9 / 150%=11
  ≥8 → CR検討   0〜7 → コール   <0 → フォールド

α 式（巻④ 第9章）:
  α = ベット額 ÷ (ポット + ベット額)
  MDF = 1 − α
  最適ブラフ率 = α（ベットレンジ中）

HandScore基準値（主要ハンド）:
  TPTK（AKのトップペア）   = 18
  TPGK（KQ等のトップペア） = 15
  TPWK（K7等のトップペア） = 10
  セカンドペア（J on KJ2）  = 8
  ボトムペア               = 5
  OESD                     = 12
  フラッシュドロー（FD）    = 13
  セット                   = 25
  2ペア                    = 20
  フラッシュ               = 25
  ストレート               = 28
  フルハウス               = 35
```

### 第1部の解答（問1〜10）

**問1: C**

BTNはCBetを打ってもナッツ（AA・セット等）を含んでいるため**Uncapped**のまま。BBはコールを選ぶことで「強すぎて3betしなかった」ハンドが選別されますが、それでも相当強いハンド（セット等）も含まれます。ただし「最強手への直接アクション（CR等）」を取らなかった分、相対的にはCappedになります（本書 第2章）。

---

**問2: D**

BBがフロップのCBetに対してチェックレイズした（B）場合、強いハンドが含まれるためUncapped。また、フロップでBBがチェック → BTNもチェック → ターンでBBがベット（C）という場合も、OOPがターンでドンクベットする形になりUncapped要素が残ります。どちらもOOPがナッツを含んで積極的なアクションを取る場面です（本書 第2章、巻④ 第4章）。

---

**問3: B**

ペアターン（7♥）で、BTN（IP）のほうがナッツアドバンテージが高い。なぜなら、BTNのオープンレンジには77（クワッズ候補）や K7（フルハウス）が含まれます。BBのコールレンジにも77は含まれますが、K7sのようなハンドはBTNのほうが多く保有しています。加えて、BTNはCBetを打った = Uncappedのまま、BBはコールを選んだ = 相対Cappedという非対称があります（本書 第2章、巻③ 第7章）。

---

**問4: A**

アクションを取るたびにレンジが更新（選別）される。コールは弱すぎるハンドをフォールドで除外し、強すぎるハンドは（本来ならCRで除外されるはずだが）コールに残す形で選別が起きます。フォールドも「フォールドした＝そのハンドはそのプレイヤーのレンジから消えた」という意味でレンジを変化させます（本書 巻⑤ 第4章）。

---

**問5: B**

リバーではエクイティが二値（0%または100%）に収束します。ドローが完成するかしないかが確定し、「エクイティが中間の状態」が消滅します。これがリバーのセミブラフ不可能の根拠です（本書 第1章）。

---

**問6: B**

7♣7♠はK-7-2-7ボードでクワッズ（7-7-7-7）を保有しており、これが最強手の候補です。BBがコールを選んだとしても、クワッズを持っていれば「Uncapppedの最強ハンド」として機能します（本書 第2章）。

**問7: B**

**問8: C**

ターンカードが落ちると、IPとOOPのレンジがそれぞれ異なる方向に更新されます。ペアターンはIPのナッツを強化し、フラッシュターンはOOPのドローを完成させます。この非対称的な更新が判断を複雑にします（巻③ 第5章、巻② 第7章）。

**問9: C**

バリューベットの本質は「相手がコールしてくれるとき、自分が勝つ頻度がα（MDF）を超えているか」です。ハンドの絶対的な強さではなく、相手のコールレンジとの比較が重要です（本書 第1章、巻② 第9章、巻⑤ 第12章）。

**問10: B**

```
ボード読み確認:
  手札: 9♥, 8♦
  ボード: A♠, K♦, Q♣, J♠, T♥（5枚）
  5枚連続チェック:
    A-K-Q-J-T: A♠,K♦,Q♣,J♠,T♥ → ボード5枚で完成（手札不要）

```

### 解答

- **問A**: 2（ナッツ）。ナッツ保有ハンドはスコアによらず積極的バリューベットが推奨されます。バレルスコアはレンジ全体の傾向を示しますが、個別ハンドの判断はハンドの絶対強度と組み合わせます（巻④ 第8章）。

- **問B**: 2（フォールド）。後手スコア < 0 はフォールドが推奨されます。スコアが−3の場合、このハンドをコールレンジに含めることはGTOから大きく外れます（本書 巻⑤ 第11章）。

- **問C**: 3（50%）。α = P÷(P+P) = P÷(2P) = 0.5。MDF = 1 − 0.5 = 0.5 = **50%**。100%ポットベットでは後手は最低50%のレンジを守る必要があります（本書 巻② 第9章）。

> **本章まとめ**
>
> - バレルスコア（フロップ板タイプ係数 + ターンカード係数）は、レンジ全体のCBet傾向を示す。個別ハンドの判断はハンドの強度と組み合わせて行う
> - α 式（= ベット ÷ (ポット + ベット)）は先手のブラフ損益分岐点であり、MDF（1−α）の逆面
> - 後手スコア（= HandScore + A − 3 − C − M）は個別ハンドがコール/CR/フォールドのどれかを数値で判断する
> - ボード読みの精度が判断の土台。ストレート完成・フラッシュ完成・ペアボードでのハンド評価を「書き出して確認」する習慣が重要
> - マルチストリートはフロップ時点でリバーまでの設計を逆算することで、サイズの一貫性と一貫したストーリーが生まれる

**【GTOとのズレ】**

本章の50問はGTOソルバーの近似式（バレルスコア・α 式・後手スコア）を使って判断する形式です。実際のGTO出力と比較したとき、「式の答えと実際の最善手が一致しない」ケースが存在します。特に境界値付近（バレルスコア7前後、後手スコア0付近）では、GTOは複雑な混合戦略を取ることが多く、式が示す「コール/フォールド」という二択に収まらない場合があります。

暗算式の目的は「9割の状況で正しい方向を示す」ことであり、残り1割の微妙な境界ケースに対しては式の出力を「参考値」として扱い、ハンドの文脈（ブロッカー・ストーリーの一貫性・相手のレンジ読み）を加えた上で最終判断をすることを推奨します。

また、問10や問35のような「ボードが全員使えるストレートを作る（board itself plays）」局面では、チョップの判断が重要になります。このような局面でバリューベットを大きく打っても、相手がチョップとわかっていればコールしてくるため、EVの期待値が下がります。GTOでは「ボードが全員使えるハンドを形成するとき、ベットサイズを小さくする」傾向があります。ボードを正確に読み、「チョップ可能性」を常に念頭に置いてください。
