# 第5章　ブロッカー実戦選択

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 巻④ 第7章で学んだブロッカーの基礎を踏まえ、リバーでの具体的なコンボ選択フローを習得する。α 式・後手スコアが示した方針を、ブロッカーでコンボ単位に絞り込む技術を身につける。

---

## 5-1 ブロッカーの立ち位置 ─ 4ステップ階層の最終層

リバーでの判断は4つの層で構成されます。ブロッカーはその最終層です。

```
ステップ1（巻④ 第9章）: α 式でバリューとブラフの比率を決める
  α = ベット額 ÷ (ポット + ベット額)
  → 打てるブラフの総数を設計

ステップ2（巻④ 第11章）: 後手スコアでコール/CR/フォールドを決める
  後手スコア = HandScore + A − C − M
  → 守備側が何%のレンジを守るかを個別ハンドで判断

ステップ3（本書 第12章〜）: 具体的な戦術を実行する
  → IP/OOPのアクション、サイズ選択、CR条件を判断

ステップ4（本章）: 同強度のコンボ群の中からブロッカーで最終選択する
  → ブラフ候補: バリューブロッカーが強いコンボを優先
  → コール候補: バリューブロッカー保持は強化、ブラフブロッカー保持は抑制
```

### ブロッカーが重要になる 3 条件

すべての場面でブロッカーが同じ重みを持つわけではありません。以下の3条件が揃うほど、ブロッカー選択の価値が高まります。

1. **相手のレンジが狭い**: レンジが広い場合、1枚のブロッカーが削れるコンボ比率は低い。レンジが狭いほど1コンボの価値が大きくなる
2. **レンジがポーラード化している**: バリューとブラフの2極構成のとき、ナッツをブロックする価値が最大化する
3. **大きなベットサイズ**: 小さなベットではコール判断が容易で、ブロッカーの微調整効果は限定的。大サイズほど境界ハンドの差が大きくなる

また、ブロッカー選択は意思決定の**第3優先事項**です。

```
優先順位：
  ①「ブラフに勝てるか」を確認する（HandScoreの比較）
  ②「相手のブラフ頻度は過不足か」を確認する（α 式による配分設計）
  ③ 同格コンボの中でブロッカーで最終選択する
```

ここで最も重要なことを最初に述べます。**ブロッカーは方針を変えない**、という点です。

α 式で「ブラフを打てる余地がある」と判断した上でブラフコンボを選ぶ際に、同強度のコンボ群の中でブロッカーの強いものを選ぶのがブロッカーの正しい使い方です。α 式が「ブラフは不要」と示している局面で「バリューブロッカーがあるからブラフを打てる」という逆転は誤りです。

巻② 第5章でブロッカー加点（HandScore +2〜+5）を、巻④ 第7章でブロッカーの基礎概念（バリューブロッカー・ブラフブロッカー・ダブルブロッカー）を学びました。とくに巻④ 第7章 7-5-a 節では、ターン以降のフラッシュ完成 / ブロードウェイ完成ボードでナッツブロッカー保有時の追加補正（NFD +5、サブナッツ FD +3、ナッツストレートブロッカー +3）を扱いました。本章ではそれらをコンボ単位の最終選択へ展開します。

## 5-2 ブラフ候補の優先順位 ─ バリューブロッカーで選ぶ

先手がブラフを打つ場面で、複数のブラフ候補コンボがある場合、どのコンボを選ぶかをブロッカーで決めます。

### ブラフ候補の 2 軸評価シート

優良ブラフを選ぶための基準を **バリュー除去スコア × トラッシュ除去スコア** の2軸で整理します。

| | **トラッシュ除去 低**（フォールドハンドをアンブロック）| **トラッシュ除去 高**（フォールドハンドをブロック）|
|---|---|---|
| **バリュー除去 高**（相手ナッツをブロック）| ★★★ 最良ブラフ（A5s〜A3s: AA/AKをブロックし弱いKxをアンブロック）| △ ナッツブロックは強いがフォールドを妨げる |
| **バリュー除去 低**（相手ナッツをアンブロック）| △ フォールドは誘いやすいがコール時に弱い | ✗ 最悪（K8s等: フォールドハンドをブロック、ナッツをアンブロック） |

- **A5s が最良ブラフ候補**：AでAA/AKをブロック（バリュー除去高）+ 弱いキングやQxが降りやすい（トラッシュ除去低）
- **K8s が劣るブラフ候補**：KでKx弱ハンドをブロックしてしまい（トラッシュ除去高）、ナッツのAK/AAはアンブロック（バリュー除去低）

この2軸評価は「コンボの選択」という第3優先事項の範囲で使います。α 式で打てるブラフ枚数が決まった後、同格コンボの中から最良を選ぶ目的です。

**基本原則: 相手のバリューコールレンジの中心をブロックするコンボを選ぶ**

相手がコールしてくるハンドの中心が何かを3秒で特定し、そのキーカードを自分が持つコンボをブラフとして選びます。

### フラッシュ完成ボードでのブラフ選択

**ボード**: K♥T♥2♣A♥9♥（ハート4枚、フラッシュが「完成している環境」）
**α 式の計算**: 75%ポットサイズでブラフを打てる方針（方針はStep1で確定済み）

ブラフ候補コンボ（いずれもショーダウン価値が低い）:

| コンボ | ブロッカー効果 | 評価 |
|---|---|---|
| A♥Q♣ | A♥でナッツフラッシュ（A♥x♥）を完全ブロック | 最優先 |
| A♣Q♦ | A♣はハートのブロッカーにならない。Aで非フラッシュバリューをブロック | 次点 |
| K♠J♦ | K♠でボードのK♥と重複なし。K系バリューをブロック | 限定的 |
| 7♦6♣ | ブロッカーほぼなし | 最下位 |

役判定の確認（A♥Q♣ + K♥T♥2♣A♥9♥）: A♥はボードにあり手にあるため同カードの使用不可。このボード設定ではA♥がボードとハンド両方に存在することになり、デッキの整合性に注意が必要です。ハンドを A♦Q♣ に変更して考えます。A♦Q♣ + K♥T♥2♣A♥9♥: ハートの枚数は手に0枚 + ボードに4枚 = 4枚。フラッシュ不成立（5枚必要）。役なしハイカード（Aハイ）。HandScore = 25。

一方、A♥Q♦を持つ場合: A♥はボードに既に存在するため、このコンボは使えません。

実際にブラフとして使えるコンボで、ナッツフラッシュ（A♥含み）をブロックするには、自分が「もう1枚のハート」ではなく「A♥そのもの」を持つ必要があります。フラッシュが完成しているボードでA♥がボードに落ちている場合、「A♥を手に持つ」という状況は発生しません。

実際には、ターンまでの進行でA♥がボードになかった段階（フロップ・ターン）でA♥を手に持っていれば、ブラフとしての機能を果たせます。本ボードでA♥がボードに含まれる以上、A♥ブロッカーは手牌では使えません。代わりに「非フラッシュのバリュー（AK・AQ等）をブロックするA」を持つコンボが次善となります。

### 非フラッシュボードでのブラフ選択

**ボード**: K♠7♦2♣A♥Q♦（散開rainbow、フラッシュなし）
**α 式の計算**: 50%ポットサイズでブラフを打てる方針

ブラフ候補コンボ（いずれも外れたドロー等、役なし）:

| コンボ | ブロッカー効果 | 評価 |
|---|---|---|
| A♣J♣ | A♣で相手のAK・AQ等のバリューをブロック | 優先 |
| Q♣J♣ | Q♣で相手のQQ・KQ等をブロック | 次点 |
| J♦T♣ | このボードで特定のブロッカー効果なし | 最下位 |

このボード（K・A・Q・7・2）での相手のバリューの中心はAK・KQ・AQ・AA・KK・QQ等です。AとQを持つコンボが相手のバリューを最も削れます。J♦T♣はこのボードで「Jがボードに絡まず、Tもボードに絡まない」ため有効なブロッカーを持てません。

## 5-3 コール判断でのブロッカー ─ バリューブロッカーとブラフブロッカー

後手スコアで「コール圏内のボーダーライン」と判断したハンドに対して、ブロッカーが判断を微調整します。

### バリューブロッカー ─ コールを強化する

相手のバリューのキーカードを自分が持つ場合、相手のバリュー密度が下がります。同じ後手スコアでも、コールの期待値がわずかに上昇します。

**例: フラッシュ完成ボードでのコール判断**

**ボード**: K♥T♥2♣5♥9♥（ハート4枚、フラッシュ完成環境）
**相手**: 75%ポットをベット
**BBのハンド**: A♦8♦（Aのペアなし、A high）

役判定: A♦8♦ + K♥T♥2♣5♥9♥。ランク: A, 8, K, T, 2, 5, 9。5連続なし。ハートの枚数: 手に0枚 + ボードに4枚 = 4枚でフラッシュ不成立。役なし（Aハイ）。HandScore = 25。

```
後手スコア = 25 + 6 − 22 − 0 = 9 → 明確なフォールド（< 20）
```

この例ではスコアが大幅にマイナスなため、ブロッカーで調整できる範囲を超えています。ブロッカーはボーダーライン付近のハンドにのみ有効です。

**例: ボーダーラインでのブロッカー確認**

**ボード**: A♠K♦Q♣J♠2♣（散開ほぼドライ、A=12）
**相手**: 75%ポットをベット（C=22）
**BBのハンド1**: Q♥T♦（Qのペア+Tのブロッカー）

役判定: Q♥T♦ + A♠K♦Q♣J♠2♣。Qが2枚（Q♥とQ♣）、A・K・J・2が各1枚。ボードのペア（Q♣）と手のQ♥でQのペア（Q's）。Tは手のみで1枚。best 5 = A-K-Q-Q-J（2ペアではなく1ペア、Qのペア、AKJキッカー）。Qはボードのトップ（A）から3番目 = サードペア相当（2nd Q+ キッカー = 42 ではなくボトムペア寄り）。HandScore = 35（セカンドペア中位相当、便宜値）。

```
後手スコア = 35 + 12 − 22 − 0 = 25 → コール（20〜39）
```

スコア=25でコール圏内です。ブロッカー確認: Q♥でQxのバリュー（QQ、AQ、KQ）を1枚ブロック。T♦でストレート（broadway: A-K-Q-J-T）のTを1枚ブロック。相手のバリューの一部が削れており、コール方向に微調整できます。

**BBのハンド2**: 6♦5♦（ブロッカーなし）

役判定: 6♦5♦ + A♠K♦Q♣J♠2♣。ランク: 6, 5, A, K, Q, J, 2。5連続なし（A-K-Q-J-6の連続は4枚止まり）。役なし（Aハイ）。HandScore = 15（Qハイ以下扱い、ボードに A・K・Q・J が見えており実質高カードの効力なし）。

```
後手スコア = 15 + 12 − 22 − 0 = 5 → フォールド（< 20）
```

6♦5♦はHandScoreが低くスコアが大幅マイナス。ブロッカーで調整できる範囲外です。

2つのハンドの比較で明確なのは、「HandScoreが高いハンドを選ぶ」が「ブロッカーで調整する」より圧倒的に重要だということです。ブロッカーはHandScoreが近い複数のコンボを比較する際に機能します。後手スコアの差（10 ポイント以上）を覆すことはできません。

### ブラフブロッカー ─ コールを抑制する

相手のブラフのキーカードを自分が持つ場合、相手のブラフ候補が物理的に減少します。相手のベットがよりバリューに偏り、コールの期待値が下がります。

**例: 外れたドローのキーカードを自分が持つ**

**ボード**: J♠T♣5♦A♣2♠（リバー、散開ほぼドライ）
**相手**: ポットをベット（C=25）
**BBのハンド**: Q♦9♦（外れたOESD）

役判定: Q♦9♦ + J♠T♣5♦A♣2♠。ランク: Q, 9, J, T, 5, A, 2。5連続確認: A-K-Q-J-T（Kなし）、K-Q-J-T-9（Kなし）、Q-J-T-9-8（8なし）。ストレート不成立。役なし（Aハイ）。HandScore = 25。

```
後手スコア = 25 + 12 − 25 − 0 = 12 → フォールド（< 20）
```

スコアが大幅マイナスで基本フォールドです。加えてブラフブロッカー確認: Q♦と9♦を持つことで、相手の「外れたQ9系OESDブラフ」が物理的に1コンボ削れます。しかし相手のブラフには Q9 以外の外れたドロー（K9、QT等）も残ります。ブラフブロッカーの効果でさらにフォールド方向が確認されます（ただしこの例ではスコアが既に大幅マイナスのため、ブロッカーが判断を変えるほどの効果はありません）。

## 5-4 ダブルブロッカーの強力さ

1枚のカードで複数の相手バリューを同時にブロックするコンボを「ダブルブロッカー」と呼びます。リバーのブラフ選択で特に強力です。ブラフに使えるのは HandScore < 35 の弱いハンド（ショーダウン価値が低いコンボ）のみです。

**例: K-A-high ボードでのブラフ選択**

**ボード**: K♣9♦4♠A♠7♥（散開rainbow、A=12）
**α 式計算**: 50%ポットでブラフを打てる方針
**ブラフ候補**（いずれも役なし、HandScore ≈ 10〜15）:

| コンボ | 役確認 | ブロッカー | 評価 |
|---|---|---|---|
| Q♦J♣ | 役なし（Q/Jはボードになし、5連続不成立） | QでAQ・KQ等をブロック、JでAJ・KJ等をブロック | **ダブルブロッカー: 最優先** |
| J♦T♣ | 役なし | JでKJ等を部分ブロック | 単一ブロッカー: 中程度 |
| 5♣6♥ | 役なし | ブロッカーなし | 最下位 |

Q♦J♣は「Q系バリュー（AQ・KQ）」と「J系バリュー（AJ・KJ）」を2方向で同時にブロックするダブルブロッカーです。相手のコールレンジの中心を2方向から削れるため、ブラフとして選ぶ場合の期待値が最も高くなります。

バリューとブラフの区別を正確に行った上で、ブラフ候補の中でダブルブロッカーを選びます。バリューハンド（AペアやKペア）をブラフとして使うのは期待値を捨てる行為です。

## 5-5 ブラフ選択の5秒判断フロー

実戦では長時間の計算が不可能です。5秒以内で判断するためのフローを示します。

```
【ブラフ選択の5秒フロー】

Q1: 複数のブラフ候補コンボがあるか？
  → NO（1種類しかない）: そのコンボでブラフ
  → YES（複数ある）: Q2へ

Q2: 相手のバリューの中心は何か？（3秒で特定）
  フラッシュ完成ボード → ナッツフラッシュ（Ax♥等）
  ドライボード → セット・トップペア（KK・AK等）
  コネクテッドボード → ストレート・2ペア以上

Q3: その「相手のバリュー中心」をブロックするコンボはどれか？
  → ブロックしているコンボを選ぶ
```

この3問を5秒以内で処理します。Q2の「相手のバリュー中心の特定」が最も重要で、これが明確であれば自然にQ3の答えが出ます。

**コール判断の5秒フロー**

```
Q1: 後手スコアで「コール/フォールドの境界付近」（スコア±2）か？
  → NO（明確にコールまたはフォールド）: 後手スコアに従う
  → YES（ボーダーライン）: Q2へ

Q2: 自分は相手のバリューをブロックしているか？
  → YES → コール方向に微調整（コールの期待値がわずかに上昇）
  → NO → 後手スコアの標準に従う

Q3: 自分は相手のブラフをブロックしているか？
  → YES → フォールド方向に微調整（相手のベットがよりバリューに偏る）
  → NO → 後手スコアの標準に従う
```

Q2とQ3は同時に確認します。バリューブロッカーとブラフブロッカーを同時に持つ場合は、どちらの効果が大きいかを直感的に判断します。

## 5-6 実戦例 ─ ブロッカーで判断が変わる4場面

### 場面1: フラッシュ外れのブラフ候補選択

**ボード**: K♥T♥2♣5♥Q♦（ハート3枚でフラッシュ未完成リバー）
**α 式**: 75%ポットでブラフ打てる方針
**ブラフ候補（いずれもHandScore = 10〜25 のハイカード）**:

候補A: A♥J♣（A♥でナッツフラッシュ（A♥x♥）をブロック、Jはこのボードで限定的）

役判定: A♥J♣ + K♥T♥2♣5♥Q♦。ハートの枚数: 手に1枚（A♥）+ ボードに3枚（K♥, T♥, 5♥）= 4枚。フラッシュ不成立（5枚必要）。役なし（Aハイ）。HandScore = 25。

候補B: A♦J♣（Aのブロッカーだがハートなし）

役判定: A♦J♣ + K♥T♥2♣5♥Q♦。ハート: 手に0枚 + ボード3枚 = 3枚。フラッシュ不成立。役なし（Aハイ）。HandScore = 25。

候補C: J♦8♦（ブロッカーほぼなし）

役判定: J♦8♦ + K♥T♥2♣5♥Q♦。ランク: J, 8, K, T, 2, 5, Q。5連続なし。役なし（J ハイ以下）。HandScore = 10。

ブロッカー比較:

- 候補A（A♥J♣）: A♥でナッツフラッシュを完全ブロック → **最優先**
- 候補B（A♦J♣）: Aで非フラッシュバリュー（AK・AQ等）をブロック → **次点**
- 候補C（J♦8♦）: ブロッカー弱い → **最下位**

ハート3枚ボードでのコールレンジの中心は「フラッシュ（ハート×2のハンド）」です。A♥を持つ候補Aはそのナッツフラッシュを完全に削れるため、ブラフとして最優先されます。

### 場面2: ペアボードでのコールボーダーライン

**ボード**: J♠J♦T♣9♥2♠（Jのペア、A=6 セミウェット）
**相手**: 75%ポットベット（C=22）
**BBのハンド1**: K♠Q♦（役なし、K-Qハイ）

役判定: K♠Q♦ + J♠J♦T♣9♥2♠。Jが2枚（J♠とJ♦）→ ボードのペア。best 5 = K-J-J-Q-T（1ペア、J's、KQキッカー）。HandScore = 35（ボードペアのみ、セカンドペア中相当の便宜値）。

```
後手スコア = 35 + 6 − 22 − 0 = 19 → コール / フォールド境界
```

スコア=19はコール/フォールドの境界（フォールド域 < 20 のすぐ上）です。ブロッカー確認: K♠でKK・AK等のバリューをブロック（相手のナッツに近いKK、AKが少し削れる）。コール方向への微調整あり。

**BBのハンド2**: 5♠4♠（役なし）

役判定: 5♠4♠ + J♠J♦T♣9♥2♠。ランクはJ, J, T, 9, 5, 4, 2。5連続: T-9-8-7-6（8なし）、9-8-7-6-5（8なし）等不成立。役はボードペア（J-J）のみ → best 5 = J-J-T-5-4（1ペア、J's、ボード貢献のみ）。HandScore = 35（同じ便宜値）。

```
後手スコア = 35 + 6 − 22 − 0 = 19 → コール / フォールド境界
```

同じHandScore=35 でも、K♠Q♦はブロッカーあり（コール向き）、5♠4♠はブロッカーなしです。ボーダーラインではK♠Q♦が優先されます。

### 場面3: ダブルブロッカーが明暗を分けるブラフ選択

**ボード**: A♠K♦Q♦J♠2♣（ほぼブロードウェイ、A=6 セミウェット）
**α 式**: 50%ポットでブラフを打てる方針

注意: このボードではA-K-Q-J-Tのブロードウェイストレートが完成する可能性があります。T（10）を持つハンドは既にストレートが成立しています。役確認が重要です。

ブラフ候補の中で役なしのコンボを確認します。

候補A: T♥8♦

役判定: T♥8♦ + A♠K♦Q♦J♠2♣。ランク: T, 8, A, K, Q, J, 2。5連続: A-K-Q-J-T（broadway）→ Tがhandにある → **ブロードウェイストレート完成**。HandScore = 85（ストレート broadway）。これはブラフ候補ではなくバリューです。

候補B: 8♥7♦

役判定: 8♥7♦ + A♠K♦Q♦J♠2♣。ランク: 8, 7, A, K, Q, J, 2。5連続: A-K-Q-J-8（8が連続しない）、K-Q-J-9-8（9なし）等不成立。役なし（Aハイ）。HandScore = 25。ブロッカーなし。

候補C: T♠9♦

役判定: T♠9♦ + A♠K♦Q♦J♠2♣。5連続: A-K-Q-J-T（broadway完成）→ Tがある → **ストレート完成**。HandScore = 85（broadway）。バリュー。

候補D: 9♥8♦

役判定: 9♥8♦ + A♠K♦Q♦J♠2♣。5連続: K-Q-J-T-9（Tなし）。役なし（Aハイ）。HandScore = 25。ブロッカー: 9♥でK-Q-J-T-9のTサイドをブロックするわけではなく、9を持つことで「相手の98系のストレートドロー外れのブラフ（98はブロードウェイ未完成だが）」が削れます。効果は限定的。

このボードではTを含むハンドがストレートを完成させるため、ブラフとして使えるのはTを含まないHandScore=0のコンボに限られます。8♥7♦や9♥8♦が候補ですが、どちらもブロッカー効果は限定的です。ブロードウェイ系ボードはブラフ候補が少なく、ブロッカーで差をつけにくい代表例です。

### 場面4: コールのブラフブロッカー確認

**ボード**: Q♠J♦T♥4♣2♠（A=6 セミウェット、コネクテッド少し）
**相手**: 75%ポットベット（C=22）
**BBのハンド**: K♠9♠

役判定: K♠9♠ + Q♠J♦T♥4♣2♠。ランク: K, 9, Q, J, T, 4, 2。5連続: K-Q-J-T-9（全部揃う） → **K-highストレート完成**。HandScore = 82（ストレート high）。

```
後手スコア = 82 + 6 − 22 − 0 = 66 → CR強推奨（≥ 40）
```

スコアが大きくCR域なのでブロッカー確認の前にCRを選びます。これはブロッカーが判断を変えない（強いハンドの場合）の典型例です。

同じ局面でBBのハンドが 8♥7♦ だった場合を確認します。

役判定: 8♥7♦ + Q♠J♦T♥4♣2♠。ランク: 8, 7, Q, J, T, 4, 2。5連続: J-T-9-8-7（9なし）。役なし（Qハイ）。HandScore = 15。

```
後手スコア = 15 + 6 − 22 − 0 = −1 → フォールド（< 20）
```

大幅マイナスなのでブロッカー確認の必要なくフォールドです。

ブロッカーが機能する「ボーダーライン」のハンド例: A♠3♠

役判定: A♠3♠ + Q♠J♦T♥4♣2♠。ランク: A, 3, Q, J, T, 4, 2。5連続: A-K-Q-J-T（Kなし）。役なし（Aハイ）。HandScore = 25。

```
後手スコア = 25 + 6 − 22 − 0 = 9 → フォールド（< 20）
```

これも大幅マイナス。このボードではハイカード単体ハンドはすべてフォールドです。

セカンドペア以上がないとボーダーラインになりません。セカンドペア（例: J♥8♥、JのペアはボードのJ♦と手のJ♥）を確認します。

役判定: J♥8♥ + Q♠J♦T♥4♣2♠。Jが2枚（J♥とJ♦）→ トリップス? いいえ、J♦はボードの1枚、J♥は手の1枚。合計2枚のJ = ペア。best 5 = Q-J-J-T-8（1ペア、J's、QTキッカー）。HandScore = 35（セカンドペア中キッカー）。

```
後手スコア = 35 + 6 − 22 − 0 = 19 → コール / フォールド境界
```

スコア=19でボーダーライン（フォールド域 < 20 のすぐ上）。ブロッカー確認: J♥でJJ・QJ・KJ・AJ等のバリューを1枚ブロック（バリューブロッカー弱）。また8♥で外れたドロー（98、87等）の一部をブラフブロッカーとして削る効果もわずかにあります。このような境界付近では、相手のプレイスタイルや実戦的な読みを加味した総合判断になります。

## 5-7 ブロッカーの限界 ─ 3つの境界線

ブロッカーは補助ツールです。その限界を理解することで、過信を防げます。

### 限界1: レンジの一部しか削れない

ナッツフラッシュをブロックしても、相手のコールレンジにはセカンドナッツフラッシュ・非フラッシュバリュー等が残ります。「ブロッカーがあるから必ずブラフが通る」という思考は誤りです。

```
フラッシュ完成ボードで A♥を持つ場合:
  削れるもの: ナッツフラッシュ（A♥x♥）
  残るもの: セカンドナッツフラッシュ（K♥x♥）
          中位フラッシュ（Q♥x♥〜6♥x♥）
          セット・2ペア等の非フラッシュバリュー
```

ブロッカーは「相手のコールレンジの一部を削る」効果です。削られた後に残るレンジに対してブラフが成功するかどうかが、ブラフの期待値を決めます。

### 限界2: ストーリー整合性がブロッカーより優先

フロップ・ターンのアクションと一貫したストーリーがない場合、ブロッカーが強くても相手はコールしてきます。

フロップでチェック、ターンでチェック、リバーで突然大きなブラフを打つ場合、ブロッカーが機能していても相手は「ストーリーが不自然」と判断してコールしやすくなります。ブロッカーは「良いストーリーの上に乗せる最終調整」です。ストーリーなきブロッカー選択は効果を発揮しません。

### 限界3: 相手がGTOから外れたプレイをしている場合

ブロッカー効果は「相手がGTO的にプレイしている場合」に最大化します。相手がブラフをほとんどしない（タイトなバリューベットのみ）プレイヤーに対しては、バリューブロッカーを使ったブラフは機能しません。相手のレンジのブラフ比率が低い場合、バリューブロッカーで「ナッツを削っても」相手のコールレンジの中心はバリューのままだからです。

逆に、相手が頻繁にブラフをするプレイヤーに対しては、ブラフブロッカーの見落としを特に注意します。相手のブラフレンジのキーカードを自分が持つ場合、コール判断が弱まります。

## 5-8 4ステップ階層のまとめと巻⑤ 第12章への橋渡し

本章で整理したブロッカー論を、4ステップ階層全体の中で位置づけます。

**4ステップ階層（再確認）**

```
Step 1（巻④ 第9章）: α 式 → バリューとブラフの比率を決定
Step 2（巻⑤ 第11章）: 後手スコア → コール/CR/フォールドを決定
Step 3（巻⑤ 第12章〜）: 戦術実行 → 具体的なアクションを選択
Step 4（本章）: ブロッカー → 同強度のコンボ群から最終選択
```

この4ステップは独立しています。各ステップが異なる問いに答えます。

- α 式は「何枚のブラフを打てるか」（レンジレベルの問い）
- 後手スコアは「このハンドをコールレンジに含めるか」（ハンドレベルの問い）
- ブロッカーは「同じ役割を果たせる複数のコンボのどれを選ぶか」（コンボレベルの問い）

この粒度の違いを混同すると判断が誤ります。ブロッカーはコンボレベルの最終調整です。

**巻⑤ 第12章への橋渡し**

巻⑤ 第12章からはIPのリバー攻撃（巻⑤ 第12章）、OOPのリバー応戦（巻② 第13章）と、実際のリバー戦術を扱います。これらの章では、α 式・後手スコア・ブロッカーの3要素を統合した実戦判断を展開します。

巻⑤ 第11章（後手スコア）で数値化した「守る強さ」と、本章（ブロッカー）で決めた「どのコンボを使うか」という2つの判断を組み合わせることで、巻⑤ 第12章以降の戦術が生きてきます。

## ミニクイズ

### 問1

フラッシュ完成リバーボード K♥9♥2♣T♥7♣（ハート4枚）で、あなたはα 式でブラフを打てる方針と判断しました。次の2つのブラフ候補コンボのうち、ブロッカー観点で優れているのはどちらですか。両者ともHandScore < 35（ハイカード）です。

1. A♣Q♦（AとQ、ハートなし）
2. A♥Q♣（A♥を保有）

ただし、A♥はボードに含まれていません（ボードのハートはK♥、9♥、T♥、7♥）。

### 問2

後手スコアで「コール境界（20 付近）」と判断したハンドが2つあります。ブロッカー観点でどちらを選びますか。

ボード A♠K♦Q♣J♠2♣（散開ほぼドライ、A=12）、相手が75%ポットをベット（C=22）。

ハンド1: Q♥T♦（役はQのペア=QとQ♣で2枚、HandScore = 35、後手スコア = 35+12−22−0 = 25）

ハンド2: 6♥5♦（役なし=ハイカード、HandScore = 15、後手スコア = 15+12−22−0 = 5）

1. ハンド1（Q♥T♦）を選ぶ
2. ハンド2（6♥5♦）を選ぶ
3. どちらも後手スコアがマイナスなのでフォールド

### 問3

次のブロッカーの使い方のうち、正しいものはどれですか。

1. バレルスコアが閾値未満（積極バレル不可）でも、ナッツブロッカーを持つならブラフを打てる
2. 後手スコアが明確なフォールド域（スコア−7以下）でも、バリューブロッカーを持つならコールできる
3. 同強度のブラフ候補コンボが複数ある場合、バリューブロッカーが強いコンボを優先してブラフとして選ぶ

---

### 解答

- **問1**: 2（A♥Q♣がブロッカー観点で優れる。ボードにハートが4枚ある場合、相手のコールレンジの中心はフラッシュ（ハート×2のハンド）です。ナッツフラッシュはA♥x♥ですが、A♥がボードにないため手でA♥を保有できます。A♥を持つことで相手のナッツフラッシュコンボ（A♥+他のハート）が物理的にゼロになり、ブラフが通りやすくなります。A♣Q♦はAで非フラッシュバリューをブロックできますが、フラッシュボードでの相手のコールはフラッシュが中心のため、効果が限定的です）

- **問2**: 1（ハンド1のQ♥T♦を選ぶ。後手スコアはハンド1=25（コール）、ハンド2=5（フォールド）です。ハンド2は後手スコアが明確なフォールド域なのでコールできません。ハンド1はコール域（20〜39）に入っており、さらにQ♥でQxバリュー（AQ・KQ等）をブロック、T♦でストレート（broadway）のTを1枚ブロックというバリューブロッカー効果もあります。実際にはハンド1とハンド2で後手スコアが大きく異なるため、ブロッカーの比較以前に後手スコアで判断が確定しています）

- **問3**: 3（正しい使い方は「同強度のコンボ群の中でバリューブロッカーが強いコンボを優先する」こと。選択肢1はα 式やバレルスコアを無視した誤り。ブロッカーは方針を変えない。選択肢2は後手スコアを無視した誤り。スコア5のような大幅フォールド域はブロッカーで変えられない。ブロッカーが機能するのは「ボーダーライン（後手スコア 18〜22 程度）」のコンボ選択においてのみです）

> **本章まとめ**
>
> - ブロッカーは4ステップ階層の最終層。α 式・後手スコアが決めた方針を変えず、コンボ単位の選択を微調整する
> - ブラフ選択では「相手のバリューコールレンジの中心をブロックするコンボ」を優先する（バリューブロッカー優先）
> - コール判断では、バリューブロッカー保持でコール方向に微調整、ブラフブロッカー保持でフォールド方向に微調整する
> - ダブルブロッカー（2枚のカードが異なる種類の相手バリューを同時にブロック）は特に強力
> - ブロッカーが機能するのはコール/フォールドのボーダーライン（後手スコア18〜22 程度）のコンボに対してのみ
> - 限界1: レンジの一部しか削れない。限界2: ストーリー整合性がブロッカーより優先。限界3: 相手のプレイスタイルによって効果が変わる
> - 巻⑤ 第12章以降では、α 式・後手スコア・ブロッカーの3要素を統合した実戦判断を展開する

**【GTOとのズレ】**

GTOソルバーはコンボ単位で期待値を計算し、ブロッカー効果を内包した形で最適なアクションを導出します。人間がブロッカーを使って同じ精度を再現するのは不可能ですが、実戦で最も顕著にGTOとズレる点を2つ挙げます。

最大のズレは**「ブロッカーがあるから方針を変える」という逆転**です。α 式で「この局面ではブラフ余地がない」と判断した後でも、「ナッツブロッカーを持つから打てるはず」という思考でブラフを実行するプレイヤーがいます。GTOはα 式に相当する配分設計を先に完了させた上でコンボを選びます。配分なきブロッカー選択は、単にバリュー/ブラフのバランスを崩すだけです。ブロッカーは方針を変えない、という原則は実戦で最も守りにくいルールです。

次のズレは**ブラフブロッカーの見落とし**です。コール判断で「相手のバリューをブロックしているか」は意識しやすい一方で、「自分が相手のブラフを削っているか（ブラフブロッカー）」は見落とされやすいです。外れたフラッシュドローのキーカードや、外れたOESDのキーカードを自分が持つ場合、相手のブラフが物理的に減少しており、コールの期待値が下がります。GTOソルバーはこの両方向のブロッカー効果を正確に計算しますが、人間は一方向（バリューブロッカー）に注目しがちです。

また、**バリューをブラフとして使う誤り**も実戦で頻繁に起きます。「このカードはブロッカーが強いからブラフとして使える」と判断した際に、実はそのハンドがショーダウン価値を持つバリューハンドだった場合です。役の見落とし（特にリバーでのブロードウェイストレートの完成、ペアボードでの2ペア昇格等）がこの誤りの原因になります。ブラフ候補を選ぶ前に必ずHandScoreを計算し、バリューのハンドをブラフとして使わないことが最優先です。
