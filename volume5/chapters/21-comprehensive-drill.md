# 第21章　総合ドリル5問

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ターン→リバーの連続判断を問う5問を通じて、バレルスコア・α 式・後手スコア・backward induction を一体として使い、複数ストリートにまたがる判断精度を完成させる。

---

## 21-1 前提と式の早見表

基本前提（全問共通）: 6-max キャッシュ、100BB、BTN（IP）vs BB（OOP）、SRP、M=0。

```
バレルスコア: FlopType(ドライ=8/セミ=6/コネクテッド=3) + TurnCard(ペア=4/OC=3/ブランク=2/コネクター=0)
後手スコア: HandScore + A − C（A=ドライ12/セミ6/ウェット0、C=33%12/50%17/75%22/100%25）
α 式: α = ベット額 ÷ (ポット + ベット額)
主要 HandScore: フルハウス=92 / セット=85〜92 / 2ペア上位=78 / TPTK=70 / セカンドペア=32〜42
```

各問はターン問・リバー問の2段構えです。解答前に必ずボード×ハンドの役を確認してください。

---

## 21-2 総合ドリル5問

### 問1　バレルスコア + backward induction

フロップ **K♠9♣4♦**（ドライ）。BTN 33%CBet、BB コール。ターン **Q♥**（OC）。BTN ハンド: **A♣K♣**。ポット 9BB。

**T問**: バレルスコアを計算し、BTN のターンアクションを選べ。

```
A. 75%ポットベット  B. 50%ポットベット  C. チェックバック
```

仮に B を選択。BB コール。ポット 18BB。リバー **J♦**。

**R問**: A♣K♣ のリバーでの役を確認し、backward induction の観点から BTN の行動を選べ。

```
A. 75%ポットベット  B. チェックバック  C. オーバーベット（150%）
```

---

### 問2　backward induction + ストレート完成

フロップ **T♥8♦6♣**（コネクテッド）。BTN 33%CBet、BB コール。ターン **9♥**（コネクター）。BTN ハンド: **Q♠J♠**。ポット 9BB。

**T問**: Q♠J♠ のターン役を確認し、BTN のターンアクションを選べ。

```
A. 75%ポット（セミブラフ）  B. チェックバック  C. 50%ポット（バリュー）
```

仮に C を選択。BB コール。ポット 18BB。リバー **K♠**。

**R問**: Q♠J♠ のリバー役を確認し（ストレートとスペードの両方をチェック）、BTN のリバーアクションを選べ。

```
A. 75%ポットベット  B. チェックバック  C. オーバーベット（150%）
```

---

### 問3　後手スコアの連続計算

フロップ **A♥J♦5♣**（セミ）。BTN 50%CBet、BB コール。ターン **2♣**（ブランク）。BB ハンド: **J♠T♠**。ポット 11BB。

**T問**: BTN 75%ポットベット。BB の後手スコアを計算し、コール/フォールド/CR を選べ。

```
A. コール  B. フォールド  C. チェックレイズ
```

仮に A を選択。ポット 27.5BB。リバー **T♣**。

**R問**: J♠T♠ のリバー役を確認し、BTN 75%ポットベット（約 20.6BB）に対して後手スコアを再計算して判断せよ。

```
A. コール  B. フォールド  C. チェックレイズ
```

---

### 問4　3軸統合 + リバーOB

フロップ **K♥7♦2♣**（ドライ）。BTN 33%CBet、BB コール。ターン **K♠**（ペアターン）。BTN ハンド: **A♣K♦**。ポット 9BB。

**T問**: A♣K♦ のターン役を確認し、3軸で分析した上でターンアクションを選べ。

```
A. チェックバック（スロープレイ）  B. 50%ポットベット  C. オーバーベット（100%）
```

仮に A を選択。ポット 9BB のまま。リバー **5♦**（ブランク）。

**R問**: A♣K♦ のリバー役を確認し、第7章（リバーOB）の観点から最適なアクションを選べ。

```
A. オーバーベット（150%、約 13.5BB）  B. 75%ポットベット  C. チェックバック
```

---

### 問5　α 式 + 後手スコアの守備

フロップ **Q♦J♣9♠**（コネクテッド）。BTN 50%CBet、BB コール。ターン **2♥**（ブランク）。BTN ハンド: **A♦Q♣**（TPTK）。ポット 11BB。

**T問**: バレルスコアを計算し、BTN のターンアクションを選べ。

```
A. 75%ポットベット  B. 50%ポットベット  C. チェックバック
```

仮に B を選択。BB コール。ポット 22BB。リバー **K♠**。BTN が 75%ポットベット（約 16.5BB）。

**R問**: BB ハンド **J♥T♥** のリバー役を確認し（ストレートを必ずチェック）、後手スコアを計算して判断せよ。

```
A. コール  B. フォールド  C. チェックレイズ
```

---

## 21-3 解答・解説

### 問1

**T問: B** バレルスコア = ドライ(8) + OC(3) = 11。TPTK のため 50%ポットで継続。
**R問: B** A♣K♣ on K♠9♣4♦Q♥J♦ → Kペア（ストレートなし）。BB の2回コールレンジには J・Q トップペアが多く Kペアでは勝てない。チェックバックで SDV を守ります。

### 問2

**T問: C** Q♠J♠ on T♥8♦6♣9♥ → Q-J-T-9-8 = 5連続 → **ストレート完成（Q-high）**。バリューベット継続。
**R問: A** K♠落ち → K-Q-J-T-9 = 5連続 → **K-high straight**。75%ポットバリューベットを続けます。

### 問3

**T問: A** J♠T♠ on A♥J♦5♣2♣ → J×2 = Jペア。HS ≒ 38。後手スコア = 38 + 6 − 22 = 22 → コール域。
**R問: C** T♣落ち → J×2、T×2 = **2ペア（J's & T's）**。HS ≒ 78。後手スコア = 78 + 6 − 22 = 62 → CR 域。

### 問4

**T問: A** A♣K♦ on K♥7♦2♣K♠ → K×3 = **トリップス**。スロープレイでリバーのアクションを引き出します。
**R問: A** 5♦はブランク。トリップス継続。スロープレイ後は第7章に従いOBを選びます（ポット 9BB、150% ≒ 13.5BB）。

### 問5

**T問: B** バレルスコア = コネクテッド(3) + ブランク(2) = 5 → ハンド依存。TPTK の強バリューのため 50%ポット継続。
**R問: C** J♥T♥ on Q♦J♣9♠2♥K♠ → K-Q-J-T-9 = 5連続 → **K-high straight**。後手スコア = 80 + 6 − 22 = 64 → CR 域。チェックレイズが正解です。

## ミニクイズ

### 問1

バレルスコアが 5（ハンド依存）で、TPTK を持つ場合の適切なアクションはどれですか。

1. チェックバック一択（バレルスコアが低い）
2. 50%ポット程度のバリューベット（TPTK の強さを活かして継続）
3. フォールド準備

### 問2

ターンでコール域（後手スコア 22）だったハンドがリバーで2ペアになった場合、後手スコアはどう変わりますか。

1. 変わらない
2. CR 域に跳ね上がる（HandScore が約 40 増加）
3. フォールド域に下がる

---

### 解答

- **問1**: 2（バレルスコアはレンジ平均の傾向。TPTK は強いバリューのため 50%ポットを継続します）
- **問2**: 2（HandScore が 38 → 78 に増加すると後手スコアも同幅上昇し、CR 域に到達します）

---

> **本章まとめ**
>
> - ターン→リバーの連続判断では、各ストリートで役の確認（hand evolution）を必ず行う
> - backward induction: ターンでリバーの各シナリオを先読みし、「バリューとして機能し続けるか」を確認する
> - バレルスコアが低くても TPTK 等の強いコンボはバリューベットを継続する
> - リバーで役が大幅強化（ワンペア→2ペア・ストレート）した場合、後手スコアが CR 域に跳ね上がる

---

**【GTO とのズレ】**

本章のドリルで最も発生しやすい GTO とのズレは「リバーで役が強化されても後手スコアを更新し忘れる」パターンです。ターンの計算結果をリバーにそのまま流用すると、HandScore の大幅な上昇を見逃します。

また GTO は混合戦略（部分ベット + 部分チェック）を採用します。式では「チェックバック」という二値判断に落とし込みますが、実際には弱いバリューを低頻度でベットすることも均衡の一部です。式の判断を「ベース」として使い、相手の傾向に応じて調整する姿勢が本書全体を通じた推奨です。
