# 第7章　リバーオーバーベット

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバーで100%以上のオーバーベット（OB）を使うべき状況を体系的に理解し、ナッツアドバンテージとα 式を組み合わせたリバーOBの判断フローを習得する。

---

## 7-1 リバーOBとターンOBの根本的な違い

巻⑤ 第12章でターンOBを学びました。ターンOBの目的は「SPRをリバーでコミット圏に下げること」でした。ターンで150%ベットしてコールされると、リバーのSPRが約1.5になります。コミット圏に入れることで「どのリバーカードが来てもオールインが確定する」状態を設計するのがターンOBの本質でした。

リバーOBはまったく異なる目的で使います。

```
ターンOB（巻⑤ 第12章）:
  目的: SPRをリバーでコミット圏にする（2ストリートの設計行為）
  効果: コールされるとリバーSPR≈1.5 → ほぼオールイン確定
  前提: 「コールされたリバーでも有利」な状況が必要

リバーOB（本章）:
  目的: 最後の1回でバリューを最大化する、または超強力なブラフでフォールドを取る
  効果: コールされてもフォールドされても、そこでハンドが終わる
  前提: レンジがポーラード化している（ナッツ + ブラフの二極構成）
```

リバーには次のストリートがありません。「コールされた後」のことを考える必要がない、という点がターンOBと根本的に異なります。リバーOBは「1回きりの最終決断」です。ナッツクラスのバリューなら相手から最大値を引き出し、ブラフなら一度に大きなフォールドを取る。この二択の一択に集中できます。

---

## 7-2 オーバーベットの数学 ─ α 式との接続

巻④ 第9章で学んだα 式を使って、OBのコール要件を計算します。

```
α = ベット額 ÷ (ポット + ベット額)
MDF = 1 − α
```

主要なOBサイズでの数値を整理します。

| ベットサイズ | α（ブラフ損益分岐） | MDF（最低コール率） | V:B比率 |
|---|---|---|---|
| 100% pot | 0.50（50%） | 0.50（50%） | 1:1 |
| 125% pot | 0.56（56%） | 0.44（44%） | 約4:5 |
| 150% pot | 0.60（60%） | 0.40（40%） | 2:3 |
| 200% pot | 0.67（67%） | 0.33（33%） | 1:2 |

OBのサイズが大きくなるほど、後手（コール側）に課されるハードルが上がります。150%ベットに対してOOPがコールするためには、IPのベットレンジ全体の60%以上に自分のハンドが勝てることが必要です。200%ベットになると、この要件が67%になります。

この「高いコール要件」が、リバーOBの武器になります。ナッツに近いハンドでOBすれば、OOPの多くのハンドはMDFを満たせずフォールドせざるを得ません。コールできるのはほぼナッツ付近のみです。

### バリューとブラフの比率

本書 巻② 第9章の逆算用法を使うと、OBでのブラフ上限数が計算できます。

```
ブラフ上限数 = バリューコンボ数 × α ÷ (1 − α)

例: 150%OB（α=0.60）でバリューが8コンボ
  ブラフ上限 = 8 × (0.60 ÷ 0.40) = 8 × 1.5 = 12コンボ
```

OBではブラフがバリューを数の上で上回ります。「オーバーベット = 強い」という直感は、バリュー比率の観点では正しいのですが、コンボ数ではブラフの方が多くなります。これは相手のコール率が低いためで、数学的には正常な均衡です。

### 実測 ─ リバー IP は「実はあまり OB しない」

巻④ 第11章のリバー後手スコア検証と同じ TexasSolver パイプラインで、10 種類の代表リバーボードについて IP（BTN）の第一手選好を実測しました（BTN open vs BB defend、ポット 27BB、スタック 80BB の SRP リバー設定）。

| アクション | IP first 採用率（30 シナリオ平均） |
|---|---|
| CHECK | **76.1%** |
| BET（中サイズ、約 50% pot 相当） | 22.1% |
| ALLIN（約 300% pot 相当のオーバーベット） | **1.8%** |

**IP のリバー第一手はチェックが基本（76%）**、ベットする場合も中サイズが主流で、オーバーベット相当のオールインは平均 1.8% しか採用されません。リバーOB は強力な武器である一方、**全リバーボードの 1〜2 割でしか成立しない**特殊な選択肢である、というのが実測の姿です。

このことが意味するのは、本章で示すような「OB の判断フロー」は**ボードを精選した上での例外的な手段**であり、初心者は「リバーは基本チェック、確信のあるナッツ局面でだけ OB」という防御的な姿勢から入るのが安全だという点です。本章 7-7 で扱う「OB に向かないパターン」が大多数で、向くパターン（7-4）が少数派、という比率を頭に入れておいてください。

## 7-3 ポーラード化の極限形態 ─ ナッツかブラフか

リバーOBが有効に機能するためには、あなたのレンジが「ポーラード化（二極化）」していることが必要です。

ポーラード化とは、レンジが「非常に強いハンド（ナッツ）」と「非常に弱いハンド（ブラフ）」に集中しており、中強度のハンドが少ない状態です。

```
ポーラード化レンジ（OBに適合）:
  ナッツ: セット、フルハウス、ナッツフラッシュ、ナッツストレート
  ブラフ: 空振りしたドロー（ナッツブロッカー保有が条件）
  中強度（トップペア〜2ペア等）: 少ない、またはチェックに回す

コンデンス（中央化）レンジ（OBに不適合）:
  中強度ハンドが多数
  ナッツもブラフも少ない
```

なぜ中強度ではOBが機能しないのでしょうか。中強度のハンドでOBしてもコールされるとき、相手はしばしばそれよりも強いハンドを持っています。コール料を多く取れる一方、コールされたときの負けが大きくなります。バランスが崩れてしまいます。

本書 巻⑤ 第12章で確認した「バリューベットは相手のコールレンジに対して50%以上の確率で勝てること」という原則を思い出してください。OBでは、コールされるのがOOPのナッツ付近のみという状況なので、IPはさらに強い部分（フルハウスやナッツフラッシュ等）のみでバリューOBを打てます。中強度はこの基準を満たさず、チェックに回ります。

## 7-4 リバーOBが有効なボードパターン

どのような状況でリバーOBを打つべきか。ナッツアドバンテージが最大化される3つのパターンを整理します。

### パターン1: ペアターン後のリバーでIPがフルハウス保有

巻⑤ 第12章で確認したように、ペアターン（フロップカードと同ランクのターンカード）はIPのナッツアドバンテージが最大化される局面です。ターンでさらにバレルして相手がコールした後のリバーでも、そのアドバンテージは続きます。

特に、IPがポケットペアでセット→フルハウスに昇格している場面が典型例です。OOPにはフルハウスを上回るハンド（クワッズ、より上位のフルハウス）がほぼ残っていない状況になります。

### パターン2: フラッシュ完成ボードでIPがナッツフラッシュ保有

4枚同スートのボードでIPがナッツフラッシュ（Aハイフラッシュ）を持つ状況です。

この局面でIPのレンジは二極化します。ナッツフラッシュを保有しているならバリューOBが最大化できます。フラッシュを持たないがドローを追っていたハンドは完成しておらず、ブラフ候補になります。中強度（フラッシュなしのペア等）はチェックに回ります。

### パターン3: 4連続ボードでIPがナッツブロードウェイ保有

K-Q-J-T のような4連続ボードでリバーに5枚目が落ちる局面があります。IPがAを持てば A-K-Q-J-T = ブロードウェイ（ナッツストレート）が完成します。OOPには同じブロードウェイを持つかどうかがコール基準になりますが、Aを保有していない場合はコールが困難です。

IPのAが「ナッツ確定」として機能する局面では、OBで最大バリューを取りに行けます。

---

## 7-5 リバーOBのブラフ候補 ─ ナッツブロッカー必須

リバーOBのブラフには、通常のブラフとは違う条件が必要です。

**条件1: ナッツブロッカーを保有すること**

ナッツブロッカーとは、OOPが持てるナッツの主要コンボをブロックするカードです。たとえばフラッシュ完成ボードでのA（ナッツフラッシュのA♥等）や、ストレート完成ボードでのキーカードがブロッカーになります。

ブロッカーを持つことで、OOPがコールしてくる確率が下がります。ナッツが減るのですから、OOPのコールレンジ全体が縮小します。フォールドを取りやすくなるわけです。

本書 第5章で確認したブロッカー論の応用です。ブロッカー加点がHandScoreを上げるのと同じ理屈で、ブロッカー保有はOBブラフの「成功率を上げる効果」があります。

**条件2: ストーリーが整合していること**

フロップ・ターンのアクションと、リバーOBのストーリーが一貫していなければなりません。フロップでチェックバックした後にリバーで突然150%OBを打つと、相手にストーリーの矛盾が見えます。この矛盾はOOPのコール率を上げてしまいます。

「フロップCBet → ターンバレル → リバーOB」という3ストリートの連続した積極的なアクションが、最も自然なストーリーです。または「フロップCBet → ターンチェック → リバー大ベット」も、チェックバックでポットをコントロールした後の大ベットとして成立します。

## 7-6 OOPがリバーOBを受けたときの対応

OOPの立場でIPからOBが来た場合、MDFとの照合が判断の基準になります。

```
150%OBに対するOOPのMDF = 1 − 0.60 = 0.40（40%）
200%OBに対するOOPのMDF = 1 − 0.67 = 0.33（33%）
```

OOPは40%（または33%）の頻度でコールしなければ、理論上フォールドしすぎている状態になります。しかし、IPのOBレンジがポーラード化している場合、OOPがコールできる「質の高いコールレンジ」が40%を確保できないことが多くなります。

### OOPのハンドクラス別対応

| ハンドクラス | 150%OBへの対応 | 根拠 |
|---|---|---|
| ナッツ〜セカンドナッツ（フルハウス、ナッツフラッシュ等） | コールまたはレイズ | IPのバリューに勝てる、または対抗できる |
| 強い2ペア以上でフラッシュ/ストレートを否定できる | 状況依存コール | ボード次第でMDFを満たす場合がある |
| TPTK以下の1ペア系 | フォールド推奨 | 150%OBのコール要件（60%の壁）を超えられない |
| ブラフキャッチャーとしてのナッツブロッカー保有の中程度ハンド | 状況依存コール | ブロッカーがIPのバリュー密度を下げる分、コールEVが改善する |

重要なのは、「MDF40%を守ろうとして薄いコールを増やす」よりも、「コールできるハンドの質を高く保つ」ことです。MDFは下限であり、無理にそれを満たすために弱いハンドを混ぜる必要はありません。相手がGTOから外れてバリューに偏りすぎているなら、フォールドが最適解になることもあります。

## 7-7 OBに向かないパターン

リバーOBが誤りになる状況も明示しておきます。

**NG1: 中強度ハンドでのOB**

トップペア・2ペア程度のハンドでOBすると、相手のコールレンジはセット・フルハウス・フラッシュ・ストレート等の強いハンドに絞られます。コールされるとき負けている可能性が高く、バリューOBとして機能しません。中強度ハンドは50〜75%の標準サイズでコールを集める設計が適切です。

**NG2: ストーリーが崩れている場合**

フロップでチェックバックした後にリバーで突然150%OBを打つシナリオは、巻⑤ 第12章でも確認した「ストーリー崩壊のパターン」です。フロップのパッシブアクションは「弱さのシグナル」として機能します。その後の大ベットは、OOPに「ブラフか？」という疑問を生じさせ、コール率を不当に上げます。

**NG3: broadway完成ボードでのOB（チョップ状況）**

ボード上でA-K-Q-J-T（ブロードウェイ）が完成している場合、すべてのプレイヤーがこの5枚を使ってブロードウェイストレートを持ちます。ハンドカードが何であれ、best 5はA-K-Q-J-Tです。この状況ではOBを打っても、コールしてきた相手と同じ役でポットが分配されます（チョップ）。チェックでショーダウンに持ち込むか、相手にドンクを防ぐための小さなブロッキングベットが適切です。

**NG4: ウェット板で自分が中強度**

ウェット板（コネクテッド・スーテッド系）のリバーではOOPのコールレンジが多様です。フラッシュ・ストレート・2ペア・セット等が広く分散しています。IPが中強度のハンドでOBすると、コールされるのは常にIPより強いハンドになります。

## 7-8 実戦例

### 実戦例1: ナッツフラッシュでの200%OB

**状況**: BTN（IP）vs BB（OOP）、SRP。ポット25BB、スタック75BB（リバー開始時）。

**ボード（リバー完成後）**: K♥9♥6♥3♥2♣

ボード確認:

- スート別: ハート = K♥,9♥,6♥,3♥（ボード上4枚）、クラブ = 2♣（1枚）
- フラッシュ完成の条件 = 5枚同スート。ボード単体では4枚のみ

**BTNのハンド**: A♥5♠

ハンド評価:

- hand A♥ + board K♥,9♥,6♥,3♥ = A♥,K♥,9♥,6♥,3♥ → ハート5枚 → **ナッツフラッシュ（Aハイフラッシュ）完成**
- broadway確認: A-K-Q-J-T のうち A,K のみ → 2枚のみ。ストレート不成立 ✓
- 5♠はハートでないためフラッシュに貢献しない ✓

**分析**:

BTNはナッツフラッシュを保有しています。OOPのコールできるハンドは:

- K♥X（K♥含むフラッシュ）: 2番手フラッシュ
- Q♥X、J♥X等（Q〜9を含むフラッシュ）: 下位フラッシュ

ナッツフラッシュに対してコールできるフラッシュは全て負けます。OOPのコールレンジでBTNを上回れるハンドは存在しません（BTNがナッツなので）。

BTNのレンジはポーラード化しています。A♥を保有 = ナッツフラッシュ。A♥なしのバレル継続ハンド = フラッシュドロー外れのブラフ候補。

**推奨アクション**: 200%OB（50BB）

```
α = 50 ÷ (25 + 50) = 50 ÷ 75 = 0.67
MDF = 1 − 0.67 = 0.33（33%）
OOPに課されるコールコスト: 67%

BBがコールできる条件:
  「IPのベットレンジの67%以上に自分が勝てること」
  → ナッツフラッシュが相手レンジの中心 → 下位フラッシュはすべて負け
  → BBのほとんどがフォールド、K♥〜9♥フラッシュのみが泣く泣くコール
```

ナッツ確定局面での200%OBは、フラッシュを持つOOPから最大値を引き出します。OOPがフラッシュを持たない場合はフォールドが確定するので、IPにとって理想的な結果です。

### 実戦例2: ペアターン後のリバーで150%OB

**状況**: BTN（IP）vs BB（OOP）、SRP。フロップ K♣7♦2♠ → ターン 7♥（ペアターン、ボード K-7-7-2）→ リバー 4♦（ボード K♣7♦2♠7♥4♦）。

フロップBTN 50%CBet → BBコール。ターンBTN 75%バレル → BBコール。リバー開始時ポット: 約30BB、スタック: 約70BB。

**BTNのハンド**: K♠K♥

ボード確認（5枚ボード: K♣7♦2♠7♥4♦）:

- ランクカウント: K=1枚(board), 7=2枚(board), 2=1, 4=1
- hand K♠,K♥ + board K♣,7♦,2♠,7♥,4♦
- 全カード: K♠,K♥,K♣,7♦,7♥,2♠,4♦ (7枚中best 5を選ぶ)
- ランク別: K=3枚, 7=2枚, 2=1枚, 4=1枚
- セット+ボードペア → **フルハウス（K's full of 7's）: K-K-K-7-7** ✓
- broadway確認: A-K-Q-J-T のうちKのみ→ストレート不成立 ✓
- フラッシュ確認: スペード=K♠,2♠（2枚）、ハート=K♥,7♥（2枚）、ダイヤ=7♦,4♦（2枚）→ フラッシュ不成立 ✓

**BBのレンジ分析**:

- 77（クワッズ）: 7-7-7-7-K → BTNのフルハウスに勝つ（ただし77はBBのフラットコールレンジにはほぼ存在しない）
- K7（フルハウス: 7's full of K's）: 7♦7♥と既にボードにあるため、BBがK7♦または7♥以外のK7を持つ場合 → 7-7-7-K-K → BTNのK's full of 7'sと比較: 7's full of K's = 7-7-7-K-K、K's full of 7's = K-K-K-7-7。K-K-K > 7-7-7 なのでBTNが勝つ ✓
- AK（2ペア: A-K-K-7-7）: BTNのフルハウスに完敗
- BBのほとんどのハンドがBTNのフルハウス（K-K-K-7-7）に対抗できない

**推奨アクション**: 150%OB（45BB）

```
α = 45 ÷ (30 + 45) = 45 ÷ 75 = 0.60
MDF = 0.40（40%）
BBに課されるコールコスト: 60%

BBのコール可能ハンド（K-7-7-2-4ボード）:
  - K7（7's full of K's）: コール可（ただしBTNより下位フルハウス、コールしてもほぼ負ける）
  - 22（2's full of 7's: 2-2-2-7-7）: コール可（中程度フルハウス、BTNに負ける）
  - 44（4's full of 7's: 4-4-4-7-7）: コール可（BTNに負ける）
  → BBが「コールして勝てる」シナリオはほぼ77のみ
  → 実際にはほとんどフォールド
```

BTNのフルハウスは「コールされても負けない」確信のある手です。150%OBでポーラード化を表現し、OOPに最大のコール圧力をかけます。

### 実戦例3: 4連続ボードでAを持ち、ブロードウェイ完成

**状況**: BTN（IP）vs BB（OOP）、SRP。リバー完成後ボード: K♠Q♦J♣T♥5♣

**BTNのハンド**: A♣8♦

ボード確認:

- board K♠,Q♦,J♣,T♥,5♣（5枚）
- hand A♣,8♦ + board K♠,Q♦,J♣,T♥,5♣
- 全ランク: A,8,K,Q,J,T,5
- ストレート確認 A-K-Q-J-T: A✓, K✓, Q✓, J✓, T✓ → **ブロードウェイ（A-K-Q-J-T = ナッツストレート）完成** ✓
- K-high straight（K-Q-J-T-9）: 9が不在 → 不成立 ✓
- 8は使われない（ストレートにA,8は入らない）✓
- フラッシュ確認: スペード=K♠（1枚）、ダイヤ=Q♦,8♦（2枚）、ハート=T♥（1枚）、クラブ=J♣,5♣（board2枚）+ A♣（hand1枚）= 3枚 → フラッシュ不成立 ✓

ナッツ確認: A-K-Q-J-T = ブロードウェイ。このボードでは誰がAを持っていても同じブロードウェイです。OOPもAを持てばチョップ。AなしのKxはKQJT5の最高5枚 = Kハイのノーストレート（4連続のみ）でコール困難。

**分析**:

BTNはブロードウェイ（ナッツストレート）を保有。OOPがAを持つ場合はチョップになりますが、OOPが3betなしでフラットコールしたBBレンジにはAx（特にAK, AQ, AJ等）のコンボが多く残ります。これらにコールされるとチョップです。

ただしAなしのOOPハンド（Kx, Qx等）はコール困難。ブロードウェイに対して2番手はKQJT5（Kハイ）しかなく、ストレートに負けます。

**推奨アクション**: 100〜150%OB

```
OOPのコール可能ハンド:
  - Ax: ブロードウェイを共有 → チョップ（コールしてもEV±0）
  - KQ, KJ, KT以下: ブロードウェイに完敗 → フォールド推奨

Ax（チョップ）のOOPは「フォールドする理由がない」のでコールします。
しかし、BTNから見るとチョップのコールではEVが変わらない。
OBの価値はAなしのOOPがフォールドすることにある。

150%OBを打てば、Aなしのレンジ（大多数）はフォールド。
Axのみがコール（チョップ）。BTNはチョップ負けなし・フォールド勝ちの非対称を作れる。
```

OBの本質は「負けないベット」を大きくすることです。チョップではEVが変わらず、フォールドさせれば利益が増えます。150%OBによって「Aなしのフォールド」を最大化できます。

---

### 実戦例4: ブラフOB ─ ナッツブロッカーを使った150%OB

**状況**: BTN（IP）vs BB（OOP）、SRP。フロップ・ターンで3ストリートのバレルを継続し、積極的なストーリーが成立。リバー完成後ボード: Q♣T♣6♦3♣2♠

**BTNのハンド**: A♣K♦

ボード確認:

- スート別: クラブ = Q♣,T♣,3♣（ボード3枚）、スペード = 2♠（1枚）、ダイヤ = 6♦（1枚）
- hand A♣（クラブ1枚）+ board Q♣,T♣,3♣ = クラブ4枚合計 → **クラブフラッシュ未完成（5枚必要）** ✓
- フラッシュ完成の条件（5枚同スート）を満たさない ✓
- ストレート確認: A-K-Q-J-T → ボードにJ不在 → 不成立。K-Q-J-T-9 → J,9不在 → 不成立 ✓
- BTNのK♦はダイヤ1枚のみ。役なし（Aハイ）

**分析**:

BTNはA♣（クラブのエース）を保有しています。ボード上にはクラブが3枚（Q♣,T♣,3♣）あります。OOPがクラブフラッシュを持つためにはクラブを2枚保有している必要があります。しかし、A♣はBTNが握っているため、OOPがナッツフラッシュ（A♣ハイフラッシュ）を作ることは不可能です。

BTNのA♣K♦はこのボードで役なしのAハイです。フロップ・ターンのバレル継続というストーリーがあり、リバーで「バリューに見える大ベット」を打てる文脈が整っています。

```
フォールドエクイティの算出（150%OB）:
  α = 0.60
  MDF = 0.40
  OOPがコールしてくる40%の内訳:
    主にクラブフラッシュ完成ハンド（クラブ2枚保有者）
    2ペア以上（QQ,TT等でセット保有）
    → これらはBTNのAハイに勝つ（BTNはコールされると負ける）

ブラフの機能条件:
  OOPがフォールドする頻度 > 60% → ブラフがプラスEV
  A♣ブロッカー効果: OOPのナッツフラッシュを排除
  → OOPのクラッシュコールレンジが縮小し、フォールド率が上昇
  → ナッツフラッシュバリューに「見える」ベットにOOPが折れやすい
```

**推奨アクション**: 150%OBブラフ。ただし相手のプロファイルを確認してから実行する。フォールドしやすいタイトなOOPには有効。コールしすぎるOOPには使わない。

### 実戦例5: OBに向かないケース ─ ブロードウェイ完成ボードのチョップ

**状況**: BTN（IP）vs BB（OOP）、SRP。リバー完成後ボード: A♠K♦Q♣J♥T♠（ブロードウェイ完成）

ボード確認:

- ランク: A,K,Q,J,T（全て異なる）
- ストレート確認: A-K-Q-J-T = 5連続 → **ブロードウェイ（ナッツストレート）がボード上に完成** ✓
- このボードでは**全てのプレイヤーがA-K-Q-J-Tのブロードウェイを best 5 として使える**
- BTNのハンド（例: 9♣8♦）: hand 9,8 + board A,K,Q,J,T → best 5 = A-K-Q-J-T（ボードのみ）= ブロードウェイ ✓（ハンドカード9,8は不参加）
- BBのハンド（例: 7♣6♦）: 同様に best 5 = A-K-Q-J-T → チョップ

**分析**:

ボードがブロードウェイを完成させている場合、全プレイヤーが同じナッツストレートを保有します。どのハンドを持っていても、ベット・コールしてショーダウンになればチョップです。

この状況でOBを打っても意味がありません。コールされればチョップ（EV変化なし）、フォールドされれば現ポットを獲得できますが、OOPは「コールすれば最悪でもチョップ」と知っているのでフォールドする理由がありません。

**推奨アクション**: チェックでショーダウン（または小さなブロッキングベット）

小さなブロッキングベットを打つのは「OOPのドンクをブロックする」目的のみ有効です。100%以上のOBは純粋に無意味です。

## 7-9 リバーOB判断の実戦チェックリスト

実戦でOBを選択する前に確認するべき項目を整理します。

```
リバーOB判断チェックリスト:

□ 自分はナッツまたはナッツに非常に近いハンドを持っているか？
  → YES → バリューOBを検討
  → NO  → ブラフOBの条件へ

□ ブラフOBの場合:
  □ ナッツブロッカーを保有しているか？
  □ フロップ〜ターンとリバーのストーリーが一貫しているか？
  □ 相手がコールしすぎるプレイヤーではないか？

□ 自分のレンジはポーラード化しているか？（中強度ハンドは少ないか）

□ ボードがチョップ状況ではないか？（broadway完成ボード等）

□ ターンからのSPR計算で、OBサイズがスタックに対して現実的か？
  （極端に大きいOBは「ブラフに見えすぎる」場合がある）

全て問題なし → OBを実行
いずれかに問題 → 標準サイズ（50〜75%）に切り替える
```

## 7-10 本書 第9章への橋渡し

本章では「リバーOBをいつ使うか」という判断フローを整理しました。リバーOBはポーラード化したレンジで最大バリューを引き出す、またはナッツブロッカーを活かして強いブラフをする、という限定的な武器です。

ボードがA♠K♦Q♣J♥T♠（ブロードウェイ完成）のとき、BTNが200%OBを打つことが適切でない主な理由はどれですか。

1. スタックが足りないから
2. OOPも同じブロードウェイを持つため、コールされればチョップになり、OBに意味がない

### 解答

- **問1**: 2（150%OBのα = 150/(100+150) = 0.60。ブラフ比率の上限がα=60%、バリューが1-α=40%。V:B = 40:60 = 2:3。オーバーベットではブラフがバリューを数の上で上回る）
- **問2**: 2（リバーOBの核心はポーラード化したレンジでのナッツバリュー最大化。1はOBサイズのコール要件を満たせない薄バリュー。3はストーリー崩壊。4はナッツブロッカーなしのブラフで不成立）
- **問3**: 2（ブロードウェイ完成ボードでは全プレイヤーが best 5 でA-K-Q-J-Tを使える。OOPは「コールすればチョップ、フォールドすれば損」と知っているためフォールドしない。OBは機能しない）

> **本章まとめ**
>
> - リバーOBとターンOBは目的が根本的に異なる。リバーOBは「最後の1回で最大化」、ターンOBは「SPRをコミット圏に設計する」
> - OBのサイズが大きいほどMDFが下がる（150% → 40%、200% → 33%）。OOPに課されるハードルが高くなる
> - リバーOBはポーラード化したレンジが前提。ナッツとブラフの二極構成でのみ機能する。中強度は標準サイズ
> - バリューOBに有効な状況: ナッツフラッシュ保有・フルハウスでのペアターン後・ナッツブロードウェイ保有
> - ブラフOBにはナッツブロッカー保有とストーリー整合が必須
> - broadway完成ボードはチョップ状況。OBは無意味

**【GTOとのズレ】**

リバーOBはGTOでも使用頻度が限られており、適切な状況でのみ選択されます。実戦でのよくある誤りは「強いハンドを持ったらとにかくOB」という判断です。GTOでは「どのサイズが最も期待値を高めるか」を計算した上でサイズを選択しており、ナッツでも75%ベットが最適になる場合があります。たとえば相手がコールしてくれる確率が高い（コールしすぎる相手）なら、150%より75%ベットの方が多くのコールを集めてトータルのEVが高くなることがあります。

もう一点は「ブラフOBの過剰使用」です。GTOでブラフOBが打たれるのは、ナッツブロッカーを保有しており、かつバリューレンジとのバランスが取れている場合に限られます。単純に「役が外れたからOBブラフを打つ」という判断はGTOとは大きくズレています。役が外れた場合でも「チェックでショーダウンに持ち込む」「小さなブロッキングベットでOOPのドンクを防ぐ」が正解になるケースが多く、OBブラフを選ぶのはナッツブロッカー保有かつストーリーが完璧に整合している少数の局面のみです。

実戦では「OBを打ちたくなったとき」こそ、自分のレンジがポーラード化しているかどうかを一呼吸おいて確認する習慣が、GTOとのズレを最小化します。
