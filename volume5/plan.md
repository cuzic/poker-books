# 巻⑤「迷わないポーカー⑤ ターン・リバー[応用]」詳細プラン

## 本書の位置づけ

シリーズ第⑤巻、ターン・リバー応用編。巻④（基礎編）で4つの暗算式を習得した読者を対象に、3軸統合と backward induction によるマルチストリート総合判断を体系化。

```
巻① プリフロップ                  ─ Score
巻② フロップ[基礎]                 ─ 簡易レンジスコア / HandScore / 後手スコア（フロップ版）
巻③ フロップ[応用]                 ─ 精密レンジスコア
巻④ ターン・リバー[基礎]            ─ バレルスコア / α 式 / 後手スコア（ターン版・リバー版）
巻⑤ ターン・リバー[応用] (本書)     ─ 3軸統合 / backward induction / 高度戦術
巻⑥ トーナメント                   ─ ICM equity / ICM 補正 / M 値
```

## 本書の中心テーゼ

**「ターンは 3軸の交差点」**

ターン判断 =
- **forward 軸**: 過去レンジ（巻①-③ で築いたプリフロップ・フロップのレンジ情報）
- **current 軸**: ターンカード（巻④ で学んだ5分類）
- **backward 軸**: リバー予測（巻④ で学んだ α 式・後手スコア・ブロッカー）

リバー判断はこのうち forward + current のみ（将来カードがないため backward は消える）。  
ターンは唯一 3 軸すべてが揃うストリートで、最も総合判断を要する。

- 巻④ の4つの暗算式は **既出** として参照（再導入しない）
- 3軸統合（forward × current × backward）が本書の主軸
- 第I部で統合の枠組み、第II部で高度戦術、第III部で応用、第IV部で実戦
- 各章末に「ミニクイズ3問」+「まとめ」+「GTOとのズレ」コラム
- ソルバー学習への接続を意識
