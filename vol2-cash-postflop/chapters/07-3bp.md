# 第07章 3-bet pot postflop — cash 100bb

3-bet pot (3BP) は SPR が ~5 まで下がった特殊な局面です。
Light UCBS v2 の 3bp context を使って cbet 頻度を判断します。
3bp では air (45%)・weak (50%)・mid (60%)・strong (70%)・nut (60%) の 5 バンド値になります。
SPR が低いほどコミット圧力が増し、strong/nut はバリューを積極的に取ります。
nut バンドはスロープレイで相手を引き付ける場面もあります。

## 3bp context の特徴

3-bet pot では flop 前に双方が多くのチップを投入しているため、スタックとポットの比率 (SPR) が約 5 まで下がります。

SPR ~5 の意味:
- フロップで 33% cbet を打つと SPR は ~3.5 まで下がります。
- ターンでさらにベットすると SPR は ~1-2 になり、ポットコミット判定が近づきます。
- コミット判断が「今ここ」に来るため、フロップの bet/check が重要です。

3bp context の LIGHT_V2_BASE 値:

| バンド | 3bp context | 備考 |
|---|---:|---|
| air (CBS 0-2) | 45% | SRP cash と同じ |
| weak (CBS 3-4) | 50% | SRP よりやや高い |
| mid (CBS 5-6) | 60% | コミット圧力で高め |
| strong (CBS 7-8) | 70% | バリュー積極策 |
| nut (CBS 9+) | 60% | slowplay 候補も含む |

**nut が 70% より低い理由**: nut ハンドはスロープレイで相手を引き付ける価値があります。
70% のプレッシャーで打ち続けると相手が降りてしまうため、60% に抑えてバランスを取ります。

## 3bp での暗算フロー

3bp context の使い方は通常の cash context と同じステップです。

```
[3bp 暗算フロー]

Step 1: HP 確認 → HP テーブル参照
Step 2: DP 確認 → DP テーブル参照
Step 3: CBS = HP + DP
Step 4: CBS → バンド (air/weak/mid/strong/nut)
Step 5: LIGHT_V2_BASE["3bp"][band] → freq
Step 6: low_pair なら -10pt → 判断 (≥50% ベット / <50% チェック)
```

context を「3bp」に切り替えるだけで、他の手順は cash と同じです。
mid バンド (CBS 5-6) の freq が 60% と高い理由は、SPR が低いため second pair でも積極的にポットを積むことが得だからです。

## SPR 別の調整

3-bet pot の典型的な SPR は ~5 ですが、実際にはレイズサイズによって変動します。

**SPR ≤3 (4-bet pot 相当)**:
3-bet pot よりさらに浅いスタックです。
この場合はほぼオールインプランになるため、Light UCBS v2 の freq は参考値にとどまります。
strong / nut はほぼ 100% ベット (コミット判断)。
mid (second pair) も 75%+ でベット推奨。
air / weak は fold か厳選したブラフに限定します。

**SPR 3-7 の中間ゾーン (典型的な 3bp)**:
Light UCBS v2 の 3bp context がそのまま使えます。
air は 45%、mid は 60%、strong は 70% の値で判断します。

**SPR ≥8 (ディープスタック 3bp)**:
3-bet pot でも深いスタックの場合は mtt_deep context が近い挙動になります。
base 値は mtt_deep に近い 40-60% 帯で考えます。

## nut での slowplay

3bp context では nut バンド (CBS 9+) が 60% と strong (70%) より低くなっています。
この非直感的な設計の理由を説明します。

**slowplay の 2 つの目的**:
1. 相手のバレルを引き出す: チェックすることで相手が bluff barrel を打ちやすくなります。
2. ポットコントロール: nut で大きく打つと相手が降りてしまい、EV が下がることがあります。

**slowplay を選ぶ条件**:
- CBS 9+ (2 pair / flush / set) で相手のバレル継続率が高い場合。
- ボードがドロー豊富で、相手が将来改善する可能性がある場合。
- nut で打っても相手の calling range が薄い場合 (コールが少ない局面)。

**slowplay を選ばない条件**:
- ボードが完全ドライで相手のドローが少ない → バリューを取る。
- 相手のスタックが薄く、引き出す余地がない → 今すぐ打つ。

## 計算例 — 3bp context

### 3-bet pot での判断例

**例**: オーバーペア (overpair) + ドローなし on 3-bet pot IP

1. HP = **7** (overpair のバケット)
2. DP = **0** (ドローなし)
3. CBS = HP + DP = 7 + 0 = **7**
4. CBS バンド: 強ペア (CBS 7-8)
5. base = LIGHT_V2_BASE[3bp][strong] = **70%**

## polarize 5 条件と 3bp の関係

3-bet pot では polarize ボード判定も機能します。
ただし overbet (116%) は cash の IP cbet 限定です。
3bp でのサイズは原則として 33% または 50% の 2 択です。

3-bet pot の典型的なボード別 cbet 戦略:

**K♠7♦2♣ (型1 ハイドライ)**:
SB 有利ボード。3bp context + strong (top pair 以上) なら 70% でベット推奨。
air / weak はポーラー判断なので 45-50% の境界。

**T♠9♠8♦ (型4 連結低ボード)**:
BB のレンジが当たりやすいボード。3bp でも air は 45%、ミスしたレンジは慎重に。
mid (second pair 以上) は 60% でベット推奨。

**A♠K♦Q♣ (型1 broadway)**:
IP (3-bettor) のレンジが強く当たるボード。strong / nut は 70%+ で積極策。
low_pair (-10pt 適用後 35%) はチェック。

## まとめ

- 3bp context では mid (60%) と strong (70%) が高い。コミット圧力を活かしてバリューを積む。
- nut (60%) は strong より低い。slowplay でバレルを引き出す選択肢を持つ。
- SPR ≤3 はほぼコミット判断。Light UCBS freq は参考値として使う。
- overbet (116%) は 3bp 非推奨。サイズは 33% か 50% に絞る。
- context 切り替えは「3bp か否か」だけ。他の手順は cash と同一。
