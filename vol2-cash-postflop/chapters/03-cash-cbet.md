# 第03章 Cash 100bb cbet 完全ガイド

Cash context を使った実戦的な cbet 判断を習得します。
代表的なボード 5 例題で Light UCBS v2 の計算フローを体得し、「暗算 5-7 秒」の実践力を身につけます。
また GTO Wizard データとの照合 (WRMSE 約 19%) を通じて、Light UCBS v2 の精度と限界を確認します。

## Cash context のパラメータ確認

Cash context (Cash 100bb SRP) のパラメータを確認します。標準的な状況は pot=6bb / stack=97bb で、IP (BTN) が cbet を打つ場面です。

Light UCBS v2 の Cash context の 5 値は前章で学びました。再確認すると、air=45%・weak=40%・mid=40%・strong=60%・nut=60% です。強さの境界は mid と strong の間 (CBS 6-7 の境界) にあります。

Cash context では、ボード型 (型1-7) との連携も重要です。型6 (ハイペア) ではナッツアドバンテージが SB 側に大きくあるため、信頼度補正として freq を +1 段階 up することができます。型5 (モノトーン) では cash のみ -1 段階 down の調整が推奨されます。型1-4・型7 は補正なしで 25 セル表の値をそのまま使います。

## 暗算フロー 6 ステップの確認

Cash cbet を判断する 6 ステップを再確認します。以下のステップを体得することが本章の目標です。

Step 1: フロップを見てハンドタイプを確認する (top_pair? underpair? など)。

Step 2: ドロー種別を確認する (no_draw? OESD? FD? など)。

Step 3: CBS = HP + DP を計算する。

Step 4: CBS 値をバンド (air/weak/mid/strong/nut) に分類する。

Step 5: Cash context の 25 セル表から freq を読む。low_pair なら -10pt を引く。pos_lift 補正があれば加える (BTN=0, SB=-8, CO/HJ=+10)。

Step 6: freq ≥ 50% ならベット、< 50% ならチェックを選択する。

## 例題 5 問 — 代表ボードで計算フローを体得する

以下の 5 例題は Cash 100bb SRP での代表的なスポットです。各例題で 6 ステップの計算フローを確認します。ハンドは代表的なハンドタイプを選んでいます。実際のハンドは状況によって異なりますが、ハンドタイプが同じなら CBS は共通です。

### 例題 1: ハイドライボード (型1) での各バンド判定

**例**: トップペア (top_pair) + ドローなし on Cash 100bb

1. HP = **7** (top_pair のバケット)
2. DP = **0** (ドローなし)
3. CBS = HP + DP = 7 + 0 = **7**
4. CBS バンド: 強ペア (CBS 7-8)
5. base = LIGHT_V2_BASE[cash][strong] = **60%**
→ **連続 bet 頻度 ≈ 60%**

**ハイドライボード (型1) の特徴**: K♠7♦2♣ のような型1 ボードでは、SB がナッツアドバンテージを持ちます。トップペア (top_pair) は CBS=7 (strong) で 60% のベット推奨です。アンダーペア (underpair) は CBS=3 (weak) で 40% のチェック推奨です。

型1 ボードでは IP がベットサイズを大きくできる傾向があります (33% 標準 → overbet 検討)。サイズ選択の詳細は ch05 で扱います。

**ウェットボードの特徴**: T♠9♠8♦ のような型4 (ローウェット) ボードでは BB がレンジアドバンテージを持ちます。combo_draw (CBS=5, mid) は 40% でチェック寄りですが、FD つきのセカンドペア (CBS=7, strong) は 60% でベット推奨です。

ウェットボードでは IP が cbet を打つとドローに安い呼び値を提供してしまうリスクがあります。mid バンド (40%) でチェックを選ぶのは、ターンの card が有利ならベットする「チェックバック戦略」と組み合わせることで意味を持ちます。

**モノトーンボード (型5) の特徴**: A♥K♥Q♥ のような型5 ボードでは特別な注意が必要です。3 枚同スーツのため、IP も OOP もフラッシュドローを保有しやすく、ナッツアドバンテージが読みにくい状態です。

Cash context では型5 ボードで freq を -1 段階 down する調整が推奨されます。top_pair のみ (CBS=7, strong=60%) であれば、モノトーン補正を加えて mid バンドの 40% 相当に下げる判断もあります。flush を持っている場合 (CBS=9, nut=60%) は 60% でベット推奨ですが、slowplay も選択肢になります。

## チェック vs ベットの境界線

Cash context で最も判断が難しいのは mid バンド (CBS 5-6) です。mid は 40% (チェック推奨) ですが、個別のハンドと状況によってはベットを選ぶ場面があります。

mid バンドには 2 種類のハンドが含まれます。ひとつは second_pair (HP=5) で、もうひとつは combo_draw / FD など強いドロー (HP=2, DP=3) です。second_pair はチェックバックしてターンで判断する戦略が GTO 上は多く、これが 40% の根拠です。一方、combo_draw は積極的なセミブラフとしてベットする価値があることもあります。

実践的な判断基準として、以下を参考にしてください。ドライボード (型1/型3) の second_pair は 40% でチェック寄り。ウェットボード (型4) の combo_draw はベット検討余地あり。どちらも 50% 未満なので「基本はチェック」ですが、ボード構造と相手のレンジ読みで調整します。

## GTO Wizard データとの照合

Light UCBS v2 の Cash 100bb での精度は WRMSE 約 19% です。Full UCBS-v2 (16.43%) と比べて約 2-3pt の誤差増です。この誤差の意味を理解することで、Light UCBS v2 の使いどころと限界を正しく把握できます。

**WRMSE 19% の解釈**: WRMSE (加重二乗平均誤差) は「予測した freq と GTO ソルバーの freq の差の大きさ」を表します。19% は「平均的な局面で GTO から約 19 ポイント離れた判断をする」という意味です。例えば GTO が 60% のべき局面で Light UCBS v2 が 40-80% の範囲に入っていれば誤差内です。

**精度が高い場面**: strong/nut バンドの判断 (GTO もほぼ常にベット) と air バンドのブラフ判断 (GTO も 40-50% 前後) では精度が高めです。

**精度が低い場面**: mid バンドのウェットボード (型4) と、モノトーンボード (型5) が最も誤差が出やすい場面です。これらはボード特有のダイナミクスが強く、平均値での近似が難しいためです。

**実戦での対処**: 誤差が大きい場面では Light UCBS v2 の値を参考にしつつ、「型4 ウェット × mid バンドはやや控えめに」「型5 モノトーン × strong バンドはやや控えめに」という補正を加えることを推奨します。
