# 第7章　HandScore ─ ハンド強度 0〜50

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 自分のハンドの強さを HandScore（0〜50）として計算し、後手スコアや先手スコアへの入力として使えるようになる

---

## 7-1 なぜハンドを「数値」にするのか

「トップペアがあるからベットしよう」「フラッシュドローがあるからコールしよう」という判断は、直感として正しいことが多いです。しかし判断の境界線が曖昧なまま実戦で使い続けると、微妙な手での判断がブレ続けます。

HandScore は、ハンドの強さを 0〜50 の数値に変換することで、後手スコアや先手スコアの式に接続できる形にします。「この手はコールか、チェックレイズか」という判断を式で出せるようになるのは、HandScore が数値として定義されているからです。

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
```

3 つの要素を順番に見ていきます。

---

## 7-2 役スコア ─ 完成役の基礎点

フロップ時点で完成している役に応じた基礎点です。

| ハンド | 役スコア |
|---|---|
| セット以上（セット / ストレート / フラッシュ） | 30 |
| オーバーペア（OP） | 20 |
| TPTK（トップペア・トップキッカー） / 2 ペア | 18 |
| TPGK（トップペア・グッドキッカー） | 15 |
| セカンドペア・良キッカー（Q+） | 9 |
| TPMK（トップペア・中キッカー、8-T） | 8 |
| TPWK（トップペア・弱キッカー、J 以下） / アンダーペア | 6 |
| ボトムペア | 4 |
| セカンドペア・弱キッカー（J 以下） | 3 |
| ハイカードのみ（空振り） | 0 |

### キッカーの分類基準

トップペアのキッカー分類は 4 段階です。

- **TPTK（18点）**: キッカーがボードの最高カードより高い（例: K♥Q♠ on K♦7♣2♥ は TPTK）
- **TPGK（15点）**: キッカーが A / K / Q のいずれか（ただし TPTK に該当しない場合）
- **TPMK（8点）**: キッカーが 8〜T
- **TPWK（6点）**: キッカーが J 以下のうち下半分（GTO 上の bet 頻度はわずか 9.6% でほぼチェック）

セカンドペアもキッカーで二分割します。Q+ なら 9 点、J 以下なら 3 点です。

セカンドペアとアンダーペアの違いは「ボードのどのカードにヒットしたか」で決まります。トップカードにヒットすればトップペア、2 番目のカードならセカンドペア、最低カードならボトムペアです。ポケットペアがボードのどのカードより高くなければアンダーペアです。

> 本書の役スコア値は GTO ソルバーの bet 頻度と単調に対応するよう設定されています。

---

## 7-3 ドロー加点 ─ 未来のエクイティを現在値に換算

フロップ段階ではまだ 2 枚のカードが残っており、ドローには将来のエクイティがあります。これを現在の HandScore に加算します。

| ドローの種類 | アウツ数 | ドロー加点 |
|---|---|---|
| FD + OESD（モンスタードロー） | 15 | **+17** |
| FD + ガットショット | 12 | +14 |
| **OESD（裸）** | 8 | **+14** |
| フラッシュドロー（FD） | 9 | +13 |
| **ガットショット（裸）** | 4 | **+10** |
| 2 オーバーカード | 6 | +7 |
| バックドアフラッシュドロー（BDFD） | 実効 ~3 | +4 |
| バックドアストレートドロー（BDSD） | 実効 ~3 | +2 |

ドロー種別ごとに係数が異なる（OESD は 8 アウツで 90.5% bet、ガットショットは 4 アウツでも 63.4% bet）ため、単一公式（× N）ではなく**表で直接覚える**方式を採用しています。BDFD は 2 ストリートを要するため実効アウツを約 3 として +4 の固定加点にします。

各ドローの戦略的意味:

- **OESD（+14）**:メイドハンド級の積極性で扱える。実 GTO bet 頻度 90.5% は TPGK（50%）を超える
- **ガットショット（+10）**:4 アウツでも積極的に bet 候補。ストレート完成時にナッツに近い
- **FD+OESD（+17）**:100% bet。メイドハンドより強い場合もある

---

## 7-4 ブロッカー加点 ─ 相手のナッツを間接的に削る

自分のカードが相手の特定の強いハンドの組み合わせ数を減らす効果をブロッカー加点として加算します。

| ブロッカーの種類 | 加点 |
|---|---|
| ナッツブロッカー（例: フラッシュボードで A♠ を保有） | +3 |
| 上位セットブロッカー（例: ボードの最高ランクと同じポケットペア） | +2 |

ブロッカー加点は、主にブラフや半ブラフの局面で意味を持ちます。相手がナッツを持てる確率が下がれば、フォールドエクイティが上がります。詳細は巻3（精密レンジスコア + ブロッカー基礎）で扱います。

---

## 7-5 計算例 4 つ

### 例1: AKo on K♦7♣2♥（A=3 のドライボード）

- ハンド: A♠K♣
- フロップ: K♦7♣2♥（レインボー）
- ヒット: トップペア（K）、キッカー A → TPTK

```
役スコア:   TPTK = 18
ドロー加点: なし = 0
ブロッカー加点: なし = 0
HandScore = 18
```

TPTK の標準値です。先手スコア = 18 + 3 = 21 ≥ 7 でベット、後手スコア計算にも使えます。

### 例2: 88 on T♦9♣8♥（ウェットボード）

- ハンド: 8♠8♦
- フロップ: T♦9♣8♥（2 枚連続 + セット完成）
- ヒット: セット（8 のセット）

```
役スコア:   セット = 30
ドロー加点: なし = 0
ブロッカー加点: なし = 0
HandScore = 30
```

セットは役スコア単体で最高値です。ただしボードがウェット（A=1）なので、相手もドロー系ハンドを多く持ちます。

### 例3: A♠5♠ on K♠7♠2♦（セミウェットボード、フラッシュドロー）

- ハンド: A♠5♠
- フロップ: K♠7♠2♦（スペード 2 枚 = 2-tone）
- ヒット: 空振り（A ハイのみ）、フラッシュドロー（スペード 9 アウツ）、A ナッツブロッカー

```
役スコア:   空振り = 0
ドロー加点: FD（9 アウツ）= 13
ブロッカー加点: A♠でナッツフラッシュブロッカー = +3
HandScore = 0 + 13 + 3 = 16
```

役がないのに HandScore 16 になります。TPGK（15）と同等以上の強さです。セミブラフとして積極的に使える手であることが数値で確認できます。

### 例4: JJ on K♠8♦3♣（ドライボード、オーバーペア）

- ハンド: J♠J♣
- フロップ: K♠8♦3♣（レインボー）
- ヒット: オーバーペア（ただし K がオーバーカード）

```
役スコア:   オーバーペア = 20
ドロー加点: なし = 0
ブロッカー加点: なし = 0
HandScore = 20
```

HandScore は 20 ですが、K がオーバーカードとして存在するため相手が K を持つケースに注意が必要です。HandScore はあくまで「役の強さの指標」であり、ボードとの文脈は先手スコア・後手スコアの式で組み合わせて判断します。

## 7-6 詳しい解説へ

HandScore の各係数の根拠（エクイティデータとの対応）は巻2 第5章・第9章で詳しく扱います。巻3 第3章では「精密 HandScore」として境界ケースの補正が加わります。

本書では「役スコア + ドロー加点 + ブロッカー加点」の 3 項目の暗算ができれば十分です。

## ミニクイズ

### 問1

K♦Q♥ を持ち、フロップが K♠J♣5♦ の場合、HandScore を計算してください。

1. HandScore = 18（TPTK）
2. HandScore = 15（TPGK）
3. HandScore = 10（TPWK）
4. HandScore = 20（オーバーペア）

### 問2

A♥T♥ を持ち、フロップが 9♥8♥7♦ の場合、HandScore を計算してください。なお、A♥ と T♥ でハートが 2 枚、ボードにも 9♥8♥ でハートが 2 枚あり、合計 4 枚のハートが見えています。

1. HandScore = 0（空振り）
2. HandScore = 13（FD のみ）
3. HandScore = 17（FD + OESD のモンスタードロー）
4. HandScore = 25（OESD + FD + 役スコア合算）

---

### 解答

- **問1**: 正解は **2**（HandScore = 15、TPGK）
  K♦Q♥ on K♠J♣5♦。トップカードは K で、Q はキッカーです。Q は A/K/Q のいずれかに該当し、かつ TPTK（キッカーがトップカードより高い）ではないため TPGK = 15。ドロー加点・ブロッカー加点なし。HandScore = 15。

- **問2**: 正解は **3**（HandScore = 17）
  A♥T♥ on 9♥8♥7♦。完成役はなし（9-8-7 にヒットなし）で役スコア = 0。FD + OESD のモンスタードローで「+17」（GTO 上は 100% bet）。HandScore = 0 + 17 = 17。これは TPTK の 18 にほぼ匹敵する強さ。

---

## 本章まとめ

- HandScore = 役スコア + ドロー加点 + ブロッカー加点の 3 項目合計
- 主要な役スコア: セット=30 / OP=20 / TPTK・2 ペア=18 / TPGK=15 / セカンドペア強=9 / TPMK=8 / TPWK・アンダーペア=6 / ボトムペア=4 / セカンドペア弱=3
- ドロー加点 = ドロー種別ごとの表（FD+OESD +17 / OESD +14 / FD +13 / ガット +10 / 2 オーバー +7）
- ブロッカー加点はナッツブロッカー +3、上位セットブロッカー +2
- バケツ:H3 ≥14 / H2 7-13 / H1 < 7
- スコア値は GTO ソルバーの bet 頻度と単調に対応
- HandScore は後手スコア・先手スコアの中核入力。この値単独ではなく A/C/M 係数と組み合わせて判断する
