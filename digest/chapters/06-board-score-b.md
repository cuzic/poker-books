# 第6章　Board Score B ─ ボードを9ルールで数値化する

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップの3枚を見た瞬間に Board Score B（0〜100）を算出し、T1/T2/T3 の CBet 判断に接続できるようになる

---

## 6-1 なぜボードを数値化するのか

フロップを見た瞬間、「このボードはドライかウェットか」という感覚判断に頼っていませんか。感覚は人によって精度が異なり、境界付近のボードでは迷いが生まれます。

本書のフロップ体系では、ボードの有利不利を **Board Score B（0〜100）** という単一の数値で表します。B は「IP 側（ポジションのある側）がそのフロップで CBet をどれだけ有効に打てるか」の指標です。B が高いほど IP にナッツアドバンテージがあり CBet が通りやすいボードを意味し、B が低いほど OOP 側にドローや強いレンジが揃いやすいボードを意味します。

B の役割は1つに絞られます。「T2 / T3 のハンドで CBet を打つかチェックするかを決める閾値」との比較です。強いハンド（T1）は B の値に関わらず常時 CBet するため、B の計算が実戦で効くのは主に中弱ハンドのときです。

---

## 6-2 9ルールの全体像

B は次の **9ルール（優先順位付き判定）** で決まります。上から順にチェックし、最初に当てはまったルールの値を使います。

```
Board Score B（9ルール優先判定）:

1. ペアボード × トップカード T 以上   → B = 83
2. モノトーン（3枚同スート）           → B = 70
3. ペアボード × トップカード 9 以下    → B = 71
4. 2トーン × トップカード A/K         → B = 56
5. 2トーン（その他）                   → B = 50
6. レインボー × spread≤3 × トップ J 以上 → B = 67
7. レインボー × トップカード A/K       → B = 62
8. レインボー × トップカード Q         → B = 58
9. レインボー（その他）                → B = 55
```

> **ルール優先順位の注意**: ルール2（モノトーン→70）はルール3（ペア低→71）より先に適用されます。ペア低かつモノトーンのボード（例: 4♠4♣4♠…は3枚同ランクなので別扱いだが、複合ボードが存在する場合）はルール2（70）が採用されます。B=71 > B=70 ですが、ルール優先順位は実測データに基づく近似値として意図的に設定されています。

**用語の定義**

- **モノトーン**: 3枚すべてが同スート（例: K♠9♠4♠）
- **2トーン**: 2枚が同スート、1枚が異スート（例: K♠9♠4♥）
- **レインボー**: 3枚すべてが異スート（例: K♠9♥4♦）
- **ペアボード**: フロップに同ランクが2枚含まれるボード（例: K♠K♥4♦）
- **spread**: ボードの最上位ランクと最下位ランクの差（例: J-9-7 の spread = 11 − 7 = 4）

## 6-3 9ルールの暗記法

9つの値を別々に覚えるよりも、**不等式の大きな流れ** として整理すると記憶しやすくなります。

```
ペア高（83） > ペア低（71） ≈ モノトーン（70）
  > 2トーン高（56） > 2トーン低（50）
  > レインボー連続（67） > レインボー高（62） > レインボーQ（58） > レインボー低（55）
```

骨格の覚え方は「**ペアが最強、モノトーンが次、残りはスート × トップカード位置**」です。

### ペアボードが最高値の理由

IP（BTN など）のオープンレンジにはポケットペアが多く含まれます。ペアボードではその IP 側がセット・トリップスを作れるコンボ数が OOP（BB など）より多いため、ナッツアドバンテージが IP 側に大きく傾きます。これが B=83 という最高値の根拠です。

### レインボー内のバリエーション

レインボーの中で B が異なるのは「**つながり（spread）**」と「**トップカードの高さ**」です。

| 条件 | B | 理由 |
|---|---|---|
| spread≤3 かつ top≥J | 67 | IP のコネクテッドコンボ数が増えナッツアドバンテージ拡大 |
| top A/K | 62 | ハイカードが IP のオープンレンジに多く集中 |
| top Q | 58 | 中位トップで IP 優位は中程度 |
| そのほか | 55 | ローカードで OOP も広く対応できる |

## 6-4 CBet 判断への接続

B を計算したら、ハンドの強さ（HS）によって決まるティア分類と組み合わせて CBet の可否を判断します。

```
CBet 判断の3ルール:

T1（HS ≥ 65）: B に関わらず常時 CBet
T2（HS ≥ 20）: B ≥ 58 なら CBet（そうでなければチェック）
T3（HS < 20）: B ≥ 62 なら CBet（乾燥ボード限定のブラフ）
```

**サイズ選択**

CBet サイズは B の値が示すボードテクスチャから決まります。

```
paired_high（B=83） → 50%
mono（B=70）        → 75%
その他              → 33%
```

モノトーンで 75% を使うのは、OOP が保有するフラッシュドローに高コストを強いるためです。ペアボードで 50% を使うのは、OOP が Ax 系ハンドを多く保有しているため大サイズが逆にナッツを誘引するリスクがあるからです。

**T2 閾値 B≥58 の実戦上の意味**

B=58 は「レインボー top Q」です。これより B が低いのは「2トーン系（B=50/56）」と「レインボー低（B=55）」のみです。つまり T2 がチェックするのは実質この2パターンだけで、多くのボードでは T2 もベットできます。

**T3 閾値 B≥62 の実戦上の意味**

B=62 は「レインボー top A/K」です。T3 の純ブラフが成立するのは、ペアボード・モノトーン・レインボー連続・レインボー A/K の4パターンに限られます。それ以外ではチェックが正解です。

## 6-5 計算例3問

### 例1: K♥7♦2♠（レインボー、top K）

- ペアボード？ → いいえ
- モノトーン？ → いいえ（♥♦♠ で3種類）
- 2トーン？ → いいえ
- spread≤3? → K(13) − 2(2) = 11 → spread=11 → 満たさない
- top A/K? → top は K → **ルール7** 適用 → **B = 62**

TS=62 は T2 の CBet 閾値 B≥58 を満たします。T2 ハンドは CBet、T3 ハンドも B≥62 なのでブラフ CBet が可能です。

### 例2: K♠9♠4♠（モノトーン）

- ペアボード？ → いいえ
- モノトーン？ → はい（♠♠♠）→ **ルール2** 適用 → **B = 70**

B=70 はすべてのルールを満たします。T2 でも T3 でも CBet です。サイズは 75%（mono 専用）を選びます。

### 例3: 9♦5♣2♥（レインボー、top 9）

- ペアボード？ → いいえ
- モノトーン？ → いいえ（♦♣♥ で3種類）
- 2トーン？ → いいえ
- spread≤3? → 9(9) − 2(2) = 7 → 満たさない
- top A/K? → top は 9 → いいえ
- top Q? → いいえ
- → **ルール9** 適用 → **B = 55**

B=55 は T2 の閾値 B≥58 を満たしません。T2 ハンドはチェック、T3 ハンドもチェックです。

## 6-6 GTO整合データ

B の9ルールは GTO ソルバー実測（68ボード）で検証されています。

```
GTO実測 CBet 頻度（平均）:

paired_high（B=83）: 97.8%
rainbow_ak （B=62）: 96.3%
mono       （B=70）: 95.4%
2tone_ak   （B=56）: 91.1%
rainbow    （B=55）: 88.2%
2tone      （B=50）: 86.7%
```

いずれのテクスチャでも CBet 頻度は 85% 超と高水準です。これは IP（BTN）がほぼすべてのボードで何らかのハンドで CBet することを示しています。B の値は「全体の CBet 頻度」ではなく、「T2/T3 の中弱ハンドがどこまで CBet できるか」の閾値判定に使う指標と理解してください。

paired_high の 97.8% は、ペアボードで IP の強いコンボ（セット・トリップス）が非常に多く機能するためです。一方 2tone（86.7%）は、OOP がフラッシュドローを保有して守りやすいため、IP がやや絞る形になっています。

## ミニクイズ

### 問1

ボード Q♣T♣8♦（2トーン、top Q）の B はいくつですか。また、T2 ハンド（HS=35）の CBet 判断はどうなりますか。

1. B=50、T2 はチェック
2. B=50、T2 は CBet
3. B=58、T2 はチェック
4. B=58、T2 は CBet

### 問2

T3 ハンド（HS=15）が CBet（ブラフ）できるボードとして正しいものはどれですか。

1. J♥7♣2♦（レインボー、top J、spread=9）
2. K♠9♥4♣（レインボー、top K）
3. 8♠5♦3♦（2トーン、top 8）
4. T♣6♥4♠（レインボー、top T）

### 解答

- **問1**: 正解は **1**（Q♣T♣8♦ は2枚が♣で1枚が♦ → 2トーン。top は Q だが、9ルールの優先順位は「2トーン × top A/K → B=56」が先。top は Q なので「2トーン（そのほか）→ ルール5 → B=50」。B=50 < 58 なので T2 はチェックです）
- **問2**: 正解は **2**（T3 の CBet 条件は B≥62。選択肢2: K♠9♥4♣ はレインボー × top K → ルール7 → B=62。B≥62 を満たすため T3 ブラフが可能。選択肢1: J-high レインボーで spread=11-2=9 → ルール9 → B=55 → 不可。選択肢3: 2トーン → B=50 → 不可。選択肢4: レインボー top T → T は A/K/Q でもなく、spread≤3 の条件も確認すると T(10)-4(4)=6 → 不可 → ルール9 → B=55 → 不可）

---

## 【GTO とのズレ】

9ルールはボードの平均的 CBet 率を単一の代表値で近似しています。同じ「レインボー top K（B=62）」でも、ボードの連続性（例: K-7-2 vs K-J-9）や対峙するレンジ構成によって、GTO の実際の CBet 率は 60〜95% に広がります。B=62 はこの範囲の中間値として機能しますが、境界付近のボードでは 5〜15% の誤差が生じます。また、本章では SRP（シングル・レイズド・ポット）の BTN vs BB を前提としており、3-bet ポットやマルチウェイでは B の閾値がずれることがあります。より精密なモデルは **巻② 第2〜5章** で扱います。

## 本章まとめ

- Board Score B（0〜100）はフロップ3枚から IP の CBet 有利度を9ルールで数値化する指標
- 9ルールは「まず優先順位の高い条件から確認し、最初に当てはまったルールを使う」
- 代表値の序列: ペア高（83）> ペア低（71）≈ モノトーン（70）> 2トーン高（56）> 2トーン低（50）> レインボー連続（67）> レインボー高（62）> レインボーQ（58）> レインボー低（55）
- CBet 判断: T1は常時 CBet、T2は B≥58 で CBet、T3は B≥62 で CBet（ブラフ）
- CBet サイズ: paired_high→50%、mono→75%、そのほか→33%
- 詳細な導出・精密化モデルは **巻② 第1〜5章** で扱う
