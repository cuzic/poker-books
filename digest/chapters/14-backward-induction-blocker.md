# 第14章　backward induction とブロッカー実戦

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバーから逆算してターンを設計する「backward induction」の5ステップを理解し、ブロッカーでコンボを絞り込む実戦フローを習得する。

---

## 14-1 backward induction ─ リバーを先に決める

「今のハンドは強いか？ → 強ければベット」という思考は forward のみの判断です。backward induction（逆向き帰納）は逆から設計します。

```
通常の思考（forward のみ）:
  今強いか？ → 強ければベット → リバーで考える

backward induction:
  リバーでこのハンドは何になるか？ → バリューになれるか？
    → ターンでどう準備するか？ → ターンアクションを決める
```

「今強いか」ではなく「リバーで何になるか」を起点に設計する点が本質です。

---

## 14-2 5ステップフロー

**Step 1: 主要リバーシナリオを2〜3個立てる**

全パターンの予測は不要です。「判断が大きく変わるシナリオ」を絞ります。フラッシュ完成シナリオ（ウェットボードの場合）・ペアシナリオ・ブランク/OCシナリオの優先順位で選びます。

**Step 2: 各シナリオでハンドの役を確認する**

ターン時点の役はリバーカードで変化します。「ターンで2ペアだからリバーでも2ペア」という思い込みを排し、シナリオ別に役を計算し直します。

**Step 3: バリュー候補かブラフ候補かを判断する**

バリュー候補は相手のコールレンジ過半数に勝てる手。ブラフ候補は「ショーダウン価値がほぼゼロ」かつ「バリューブロッカー（相手の強いコールコンボを削るカード）を持つ手」を優先します。

```
ブラフ優先度:
  高: バリューブロッカーあり + ショーダウン価値ゼロ
  低: バリューブロッカーなし + ショーダウン価値ゼロ
```

**Step 4: α式でベット配分を確認する**

```
α = ベット額 ÷ (ポット + ベット額)
ブラフ上限数 = バリューコンボ数 × α ÷ (1 − α)

例: 75%ポットベット（α≈0.43）でバリュー8コンボ
  ブラフ上限 = 8 × (0.43÷0.57) ≈ 6コンボ
```

**Step 5: 逆算の3ルールでターンアクションを決める**

- **ルール1**: 主要シナリオの多くでリバーバリューになれる手 → ターンで打つ
- **ルール2**: リバーでブラフになれる手（バリューブロッカー持ちの弱い手） → ターンでセミブラフ
- **ルール3**: リバーでバリューにもブラフにもならない手 → ターンでチェックバック

## 14-3 backward induction の簡易実例

BTN vs BB（HU）、SRP。フロップT♠9♦4♣でBTNがCBet（33%）、BBがコール。ターン8♥（ボードT♠9♦4♣8♥）。BTNのハンドはA♠K♦（役の確認: ランクはA・K・T・9・4・8、5連続なし・フラッシュなし → 役なし、HandScore=0）。

- **Step 1**: ブランクシナリオ / ストレート完成（7か J）/ OC（A・K・Q）を立てる
- **Step 2**: ブランク → 役なし。OC（A）→ Aのトップペア（HandScore≈20）
- **Step 3**: ブランク → ブラフ候補（A♠のバリューブロッカーあり）。OC → バリュー候補
- **Step 4**: 50%ポット（α≈0.33）でブラフ上限はバリューの約半数
- **Step 5**: OCシナリオでバリュー、ブランクシナリオでブラフと両方機能 → ターンで小〜中サイズのベットが backward induction の示す方向

詳細は巻⑤ 第2章で扱われています。

## 14-4 ブロッカー実戦 ─ 方針を変えない最終層

ブロッカーは**方針を変えない**ツールです。リバーでの判断は4つの層で構成されます。

```
Step 1: α式でバリューとブラフの比率を設計する
Step 2: 後手スコアでコール/フォールドを判断する
Step 3: 具体的な戦術（サイズ選択・CR条件）を実行する
Step 4: 同強度コンボ群の中からブロッカーで最終選択する（←ブロッカーはここ）
```

「α式がブラフ不要と示している局面で、バリューブロッカーがあるからブラフを打つ」という逆転は誤りです。ブロッカーは Step 4 にのみ機能します。

---

## 14-5 ブラフ選択でのブロッカー

α式でブラフを打てる余地があると判断した上で、複数のブラフ候補コンボがある場合は「相手のバリューコールレンジの中心をブロックするコンボ」を選びます。

ボードK♠7♦2♣A♥Q♦（散開rainbow）で50%ポットブラフを打てる方針のとき:

| コンボ（いずれも役なし） | ブロッカー効果 | 選択順位 |
|---|---|---|
| A♣J♣ | AでAK・AQ等のバリューをブロック | 優先 |
| Q♣J♣ | QでQQ・KQ等をブロック | 次点 |
| J♦T♣ | このボードで有効なブロッカーなし | 最下位 |

相手のバリュー中心はAK・AQ・KQ・AA・KK・QQ等です。AかQを持つコンボが相手のコールレンジを最も削れます。

---

## 14-6 コール判断でのブロッカー

後手スコアが明確にコールまたはフォールドを示す場合、ブロッカーはその判断を変えません。ブロッカーが機能するのは**後手スコア±2のボーダーライン**のみです。

- **バリューブロッカー保持** → 相手のバリュー密度が下がる → コールを微強化
- **ブラフブロッカー保持** → 相手のブラフ候補が減り、ベットがよりバリューに偏る → コールを微抑制

ボーダーラインでの5秒判断:「後手スコア±2か？ → YES → バリューブロッカーあり？ → YES → コール方向に微調整」という流れです。詳細は巻⑤ 第5章で実例多数とともに扱われています。

## ミニクイズ

### 問1

backward induction の5ステップフローの正しい順序を選んでください。

1. 主要シナリオ立案 → バリュー/ブラフ判断 → 役の確認 → α式確認 → ターンアクション逆算
2. 主要シナリオ立案 → 役の確認 → バリュー/ブラフ判断 → α式確認 → ターンアクション逆算
3. α式確認 → 主要シナリオ立案 → 役の確認 → バリュー/ブラフ判断 → ターンアクション逆算
4. 役の確認 → 主要シナリオ立案 → α式確認 → バリュー/ブラフ判断 → ターンアクション逆算

### 問2

ブロッカーの正しい使い方を選んでください。

1. α式が「ブラフ不要」を示していても、バリューブロッカーがあればブラフを打てる
2. α式と後手スコアで方針を確定した後、同強度コンボ群の中からブロッカーで最良コンボを選ぶ
3. ブロッカーはHandScoreに関係なく、相手のレンジを削れるならどのハンドでも使える
4. ブロッカーはコール判断では使えず、ブラフ選択にのみ有効である

---

### 解答

- **問1**: 2（Step 1でリバーの主要シナリオを立て、Step 2で各シナリオでの役を確認し、Step 3でバリューかブラフかを判断し、Step 4でα式でベット配分を確認し、Step 5で逆算の3ルールでターンアクションを決めます）

- **問2**: 2（ブロッカーは4ステップの最終層（Step 4）にのみ機能します。α式が「ブラフ不要」の局面でブロッカーを根拠にブラフを打つのは誤りです。同強度の複数コンボがある場合に最良コンボを選ぶためのツールが正しい位置づけです）

> **本章まとめ**
>
> - backward induction の5ステップ: ①主要リバーシナリオを立てる ②シナリオ別の役を確認する ③バリュー/ブラフ候補を判断する ④α式でベット配分を確認する ⑤逆算の3ルールでターンアクションを決める
> - 逆算の3ルール: バリューになれる手→ターンで打つ / ブラフになれる手→セミブラフ / どちらでもない手→チェック
> - ブロッカーは方針を変えない最終層の選別ツール。α式と後手スコアで方針を確定してから使う
> - ブラフ選択では「相手のバリューの中心をブロックするコンボ（バリューブロッカー）」を優先する
> - コール判断ではボーダーライン（±2）の場合のみブロッカーが微調整の役割を持つ
> - 詳細は巻⑤ 第2章（backward induction）・第5章（ブロッカー実戦）で扱われている
