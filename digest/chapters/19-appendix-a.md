# 付録A　全シリーズ早見表（チートシート）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **使い方**: 「あの式の係数は何だったか」をすぐ引けるよう、シリーズ全6巻の暗算式を 1 か所に集約しました。HandScore は 0-100（equity %）の指標です。

---

## A-1 暗算式早見表

| 場面 | 式名 | 式 | 判定基準 |
|---|---|---|---|
| プリフロップ | プリフロップスコア | Score = H + L + ボーナス + ブロッカー − ペナルティ | T_open: UTG≥24 / HJ≥22 / CO≥20 / BTN≥18 / SB≥22 |
| フロップ CBet | Board Score B × T1/T2/T3 | B = 9ルール数値化、HS でティア判定 | T1→常時 / T2: B≥58 / T3: B≥62 |
| フロップ防御 | OOP フォールド閾値 | vs33%→HS<15 / vs75%→HS<35 | テクスチャ補正あり（±5/−10） |
| ハンド強度 | HandScore | 役スコア + ドロー加点 + ブロッカー加点（0-100、equity %） | T1 ≥65 / T2 20-64 / T3 <20 |
| ターン・リバー防御 | 後手スコア | 後手スコア = HandScore + A − C − M | ≥40→CR検討 / 20-39→コール / <20→フォールド |
| ターン（攻撃） | バレルスコア | バレルスコア = FlopType係数 + TurnCard係数 | ≥7→積極バレル / <7→ハンド依存 |
| リバー（配分） | α 式 | α = ベット ÷ (ポット + ベット) | α がMDFを規定 |
| トーナメント | ICM 補正 | 必要 equity = (1 + ICM 補正) ÷ (2 + ICM 補正) | bubble factor − 1.0 = ICM 補正 |
| トーナメント | M 値 | M 値 = スタック ÷ (SB + BB + アンテ合計) | ≥20→Green / 10-20→Yellow / 6-10→Orange / ≤5→Red |
