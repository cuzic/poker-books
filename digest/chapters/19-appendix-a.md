# 付録A　全シリーズ早見表（チートシート）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **使い方**: 「あの式の係数は何だったか」をすぐ引けるよう、シリーズ全6巻の暗算式を 1 か所に集約しました。

---

## A-1 暗算式早見表

| 場面 | 式名 | 式 | 判定基準 |
|---|---|---|---|
| プリフロップ | Score 式 | Score = H + L + ボーナス − ペナルティ | UTG≥23 / MP≥22 / CO≥21 / BTN≥18 / SB≥20 |
| フロップ CBet | 簡易レンジスコア | ストレート要素 + フラッシュ要素 + ハイボードリスク → 0〜10 | 8〜10→ドライ / 4〜7→セミ / 0〜3→ウェット |
| ハンド評価 | HandScore | HandScore = 役スコア + ドロー加点 + ブロッカー加点 | 0〜50（高いほど強） |
| フロップ以降（防御） | 後手スコア | 後手スコア = HandScore + A − 3 − C − M | ≥8→CR検討 / 0〜7→コール / <0→フォールド |
| ターン（攻撃） | バレルスコア | バレルスコア = FlopType係数 + TurnCard係数 | ≥7→積極バレル / <7→ハンド依存 |
| リバー（配分） | α 式 | α = ベット ÷ (ポット + ベット) | α が後手下限確率を規定 |
| トーナメント | ICM 補正 | 必要 equity = (1 + ICM補正) ÷ (2 + ICM補正) | bubble factor − 1.0 = ICM補正 |
| トーナメント | M 値 | M 値 = スタック ÷ (SB + BB + アンテ合計) | ≥20→Green / 10-20→Yellow / 6-10→Orange / ≤5→Red |
