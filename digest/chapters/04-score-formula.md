# 第4章　プリフロップスコア ─ オープンの判断

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: プリフロップスコアでオープン判断を 5 秒以内で完了できるようになる

---

## 4-1 オープンレイズを「式」で決める発想

「この手でオープンすべきか」を瞬時に判断するには、ポジションごとに何十種類ものハンドを暗記するか、式で計算するかのどちらかです。巻① プリフロップ編は後者の道を選びました。

手札を見たら 1 つの数字（プリフロップスコア）を計算し、ポジション別の T_open と比べるだけです。暗記量を大幅に削りながら、GTO の開き頻度とほぼ同じ結果が得られます。

---

## 4-2 プリフロップスコア式の全体像

### 式の定義

```
Score = H + L + ボーナス + ブロッカー − ペナルティ
```

- **H**: 高い方のカード値（A=14、K=13、Q=12、J=11、T=10、…、2=2）
- **L**: 低い方のカード値（同じ計算）
- **ボーナス / ブロッカー / ペナルティ**: 以下の表に従って加減算

### ボーナス・ブロッカー・ペナルティの一覧

| 種別 | 条件 | 値 |
|---|---|---|
| ボーナス | ペア（同じ数字 2 枚） | +10 |
| ボーナス | スーテッド（同じマーク） | +3 |
| ボーナス | コネクター（差 = 1） | +1 |
| ボーナス | コネクター（差 = 2 または 3） | +0.5 |
| ブロッカー | A を含む | +3 |
| ブロッカー | K を含む（A は含まない） | +2 |
| ブロッカー | A・K 両方 | +4（A と K を**両方**保有する場合のみ。A+Q 等は A ブロッカー +3 のみ） |
| ペナルティ | 差 4 以上 | −1（A を含む場合は免除） |
| ペナルティ | 両方のカードが 9 未満 | −1 |

「差」は 2 枚のカード値の絶対値の差です。AK なら 14−13=1、AJ なら 14−11=3、A9 なら 14−9=5 です。

**重要な適用ルール:**

- ペアには「両方 9 未満」ペナルティ・コネクター・ギャップ・スーテッドを適用しない
- ブロッカーボーナスはペアにも適用される（AA は +3、KK は +2）
- 差 4 以上ペナルティは A を含む場合は免除（A5s や A2s は Wheel ストレートの可能性を考慮）

---

## 4-3 ポジション別しきい値（T_open）

計算した Score をポジション別の T_open と比較します。

```
Score ≥ T_open → オープンレイズ
Score < T_open → フォールド
```

| ポジション | T_open |
|---|---|
| UTG | 24 |
| HJ | 22 |
| CO | 20 |
| BTN | 18 |
| SB | 22 |

このしきい値を使うと、GTO のオープン頻度と各ポジションで ±2% 以内に収まります。UTG は最もタイト（約 17%）、BTN は最もルース（約 44%）という傾向がそのまま反映されています。SB は OOP のため BTN（IP）より絞り、HJ と同じ T_open=22（GTO の SB raise-only 約 24% に整合）に設定しています。

---

## 4-4 計算例 3 選

### 例 1: AKs（Score = 35）

- H = 14、L = 13
- スーテッド: +3、コネクター（差=1）: +1
- ブロッカー（AK 両方）: +4

```
14 + 13 + 3 + 1 + 4 = 35
```

全ポジションで余裕のオープン。プレミアムハンドの代表例です。

### 例 2: 99（Score = 28）

- H = 9、L = 9
- ペア: +10

```
9 + 9 + 10 = 28
```

全ポジションでオープンできます。ペアはボーナス +10 が大きく効くため、見た目以上に高スコアになります。

### 例 3: T8s（Score = 21.5）

- H = 10、L = 8
- スーテッド: +3、コネクター（差=2 で +0.5）
- 両方 9 未満？ T は 10 なので不適用

```
10 + 8 + 3 + 0.5 = 21.5
```

T_open(HJ)=22 に届かないため HJ ではフォールド、CO（T_open=20）以降でオープンできます。スーテッドのギャッパーは思ったより低スコアになりやすいことがわかります。

---

## 4-5 暗算手順 ─ 5 秒で計算する

プロセスをルーティン化すると計算が速くなります。

```
手順 1: H と L を足す                 (2秒)
手順 2: ボーナスを足す                 (1秒)
         ペア: +10 / スーテッド: +3 / コネクター差1: +1 / 差2-3: +0.5
手順 3: ブロッカーを足す               (1秒)
         A=+3 / K=+2 / AK 両方=+4
手順 4: ペナルティを引く               (1秒)
         差4以上: −1（A 含むと免除）/ 両方9未満: −1
手順 5: ポジション別 T_open と比較    (1秒)
```

最初のうちは頭の中で「14 + 13 = 27、スーテッドで +3、コネクターで +1、AK 両ブロッカーで +4 → 35」のように声に出してみるのが効果的です。50 手ほど繰り返すと、主要ハンドはほぼ瞬時に出るようになります。

スコアの「相場観」として、32 以上はほぼ全ポジでオープン、18 未満は BTN でも難しいと覚えておくと判断が速くなります。

詳細な導出と 10 例のドリルは **巻① 第5章・第7章** で扱っています。

## ミニクイズ

### 問 1

次のハンドの Score を計算してください。

1. JJ
2. AQs
3. 98s

---

### 問 2

あなたは CO で K9s を持っています。Score はいくつで、オープンしますか。

ヒント: H + L + スーテッド +3 + ブロッカー（K=+2）+ ペナルティ判定（差=4 ≥ 4 で −1）

---

### 解答

- **問 1**:
  1. JJ: 11 + 11 + 10 = **32**（全ポジでオープン）
  2. AQs: 14 + 12 + 3 + 0.5 + 3 (Aブロッカー) = **32.5**（差=2、ギャップ2以内で+0.5、全ポジでオープン）
  3. 98s: 9 + 8 + 3 + 1 = **21**（差=1、コネクター、両方9以上でペナルティなし、CO 以降でオープン）

- **問 2**: 13 + 9 + 3 + 2 (Kブロッカー) − 1 (差4≥4) = **26**。T_open(CO)=20 を大きく超えるのでオープンします。

---

> **本章まとめ**
>
> - プリフロップスコア式: `Score = H + L + ボーナス + ブロッカー − ペナルティ`
> - ボーナス: ペア+10 / スーテッド+3 / コネクター差1=+1 / 差2-3=+0.5
> - ブロッカー: A=+3 / K=+2 / AK 両方=+4
> - ペナルティ: 差4以上=−1（A 含むと免除）/ 両方9未満=−1（ペアには適用しない）
> - T_open（6-max）: UTG=24 / HJ=22 / CO=20 / BTN=18 / SB=22
> - Score ≥ T_open でオープン、未満でフォールド
> - 暗算手順を固定して繰り返すことで 5 秒以内に計算できるようになる

---

**【GTOとのズレ】**

プリフロップスコアは A・K ブロッカーを式に組み込み、AJo や A5s も自動的にオープン域に拾えるよう設計されています。それでも 2 つの系統的な弱点が残ります。小さいペア（22〜33）はスコア 14〜16 で BTN T_open=18 を下回るためフォールド判定になりますが、GTO では BTN から 22+ を開きます（補助ルール: set mining でカバー）。スーテッドコネクターの下位（65s、54s）も「両方 9 未満」ペナルティが重くのしかかり、BTN で開けないスコアになります（補助ルール: SC 暗黙オッズでカバー）。

これらの弱点はすべて「控えめすぎる損失」の方向にあります。大事故につながるオーバープレイを誘発しないため、初心者が使う分には実害が少なく、補助ルールで補強できます。
