# 第9章　レンジ優位とブロッカー ─ Vol.③ の2軸

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: レンジ優位（ナッツアドバンテージ + エクイティアドバンテージ）でなぜ CBet 率が変わるかを理解し、ブロッカー加点の3種類を実戦の判断に組み込めるようになる。

---

## 9-1 レンジ優位の2種類

巻③が扱う核心テーマは「1枚のハンド判断」から「レンジ全体の優位性」への視点拡張です。本章ではその中核概念であるレンジ優位を2種類に整理します。

**ナッツアドバンテージ**は、最強クラスのハンド（T1: HS ≥ 65）の密度比較です。どちらのレンジにセット・フルハウス・ナッツフラッシュなどのナッツ級が多いかを測ります。ナッツアドバンテージを持つ側は大きなサイズでベットでき、相手は「強い手を持っている確率が高い」という圧力を受けます。

**エクイティアドバンテージ**は、レンジ全体の平均 HS の差です。個々のハンドが強いか弱いかではなく、「全レンジの平均として何点か」で測ります。エクイティアドバンテージがある側はより高い頻度で CBet を正当化できます。

```
レンジ優位の2種類:

  ナッツアドバンテージ
    = T1 ハンド（HS ≥ 65）の密度比較（IP > OOP → IP 有利）
    → サイズを大きくできる根拠

  エクイティアドバンテージ
    = 全ハンドの平均 HS 比較（IP > OOP → IP 有利）
    → CBet 頻度を上げられる根拠

  両者は独立して機能する
```

2つの優位が重なるほど CBet 頻度とサイズが高まります。エクイティアドバンテージがあってもナッツアドバンテージが薄いと、頻度は高くてもサイズを大きくしにくくなります。

BTN vs BB の SRP（シングルレイズドポット）を基準に考えます。BTN は約 40% のオープンレンジを持ち、AA・KK・AKs などのプレミアムハンドをすべて含みます。BB は約 67% の広いディフェンスレンジで、T1 の密度は BTN より低くなります。この非対称性がフロップでのレンジ優位の出発点です。

## 9-2 テクスチャ別 CBet 率とレンジ優位の関係

GTO ソルバーの実測データ（68 ボード）から、テクスチャ別の CBet 率を確認します。

```
テクスチャ別 CBet%（GTO 実測, BTN vs BB SRP, 68ボード集計）:

  paired_high  (B=83): 97.8%  ← IP の FH/クワッズが急増 → IP ナッツ圧倒
  rainbow_ak   (B=62): 96.3%  ← IP が K/A-high で T1 多数 → IP 大優位
  mono         (B=70): 95.4%  ← IP のプレミアムスーテッドが多い
  paired_low   (B=71): 93.1%  ← ペアだが IP の有利が中程度
  2tone_ak     (B=56): 91.1%  ← A/K-high で有利も FD でやや均等化
  rainbow      (B=55): 88.2%  ← 両者にドロー少 → レンジ差が縮小
  2tone        (B=50): 86.7%  ← 両者に FD → レンジが均等化
```

B（ボードスコア）が高いほど CBet 率が上がる傾向があります。ただしこれはボードの「ドライ度」ではなく、そのテクスチャで IP のレンジ優位がどの程度成立するかを反映しています。

**paired_high が最高値の理由**: K-K-X や A-A-X のようなペアボードでは、IP のレンジにフルハウス（KK + 他のポケットペア）やクワッズが急増します。BB がこれらを保有する確率は非常に低く、IP のナッツアドバンテージが圧倒的になります。

**2tone の CBet 率が下がる理由**: フラッシュドローがあると BB のワイドレンジ（スーテッドコネクター、スーテッドエースなど）が多くヒットします。BB の T1 密度が上昇し、IP のレンジ優位が縮小します。

B が高いテクスチャほど IP のレンジ優位（特にナッツアドバンテージ）が大きく、全レンジでの CBet が正当化されます。これが「第8章の先手スコアで T3 ブラフは B ≥ 62 のみ有効」というルールの背景です。

ボードスコア B の定義と A 係数への変換は本書第6章で扱っています。

## 9-3 例外：OOP がレンジ優位を持つボード

多くのボードで IP（BTN）が有利ですが、OOP（BB）のレンジ優位が逆転するケースがあります。

**代表例: A♣9♦9♠（paired_low のひとつ）**

このボードで BB のディフェンスレンジには Ax ハンドが広く含まれます。A9s（2ペア）、A6s（2ペア）、その他の Ax suited など、このボードにヒットするコンボが BTN より相対的に多くなります。BTN のオープンレンジにも 99 はありますが、AA や AK といった高カードハンドがこのボードを「飛ばしてしまう」ケースが増えます。

```
Ac,9d,9s の GTO 実測:
  CBet 率: 約 67%  ← 他の多くのボードより大幅に低い
  理由: OOP の BB が Ax を多く保有 → OOP レンジ優位が発生
```

OOP がレンジ優位を持つボードでは次の変化が起きます。

- IP の CBet 率が大きく低下する（全体 67% 程度）
- OOP のチェックレイズが増える（OOP がナッツを多く保有）
- IP の大きなサイズが成立しにくくなる

この逆転を「外れ値ボード」として機械的に補正するのではなく、「BB のレンジに何がヒットしやすいか」というレンジ優位の原則で理解することが重要です。詳細は巻③ 第01章・第06章で扱います。

## 9-4 ブロッカー加点の3種類

ブロッカーとは、自分のカードで相手のコンボを物理的に除外する効果です。デッキに同じカードは1枚しかないため、自分が持つカードは相手の手札にありえません。

HandScore はブロッカー加点を含む3要素から成ります（本書第7章参照）。

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
```

巻④の実装（calc.py）では、ブロッカー加点を次の3種類で定義しています。

```
ブロッカー加点（calc.py 実装値）:

  NFD（ナッツフラッシュドロー）:     +5
    フラッシュボードの同スート A 保有
    → 相手のナッツフラッシュコンボを100%除外

  Sub-NFD（サブナッツフラッシュドロー）: +3
    フラッシュボードの同スート K 等、2番手フラッシュを持つ
    → 相手のセカンドナッツフラッシュを部分除外

  ナッツストレートブロッカー:        +2
    ストレート完成に必要なキーカード保有
    → 相手のナッツストレートコンボを部分除外
```

この3種類はフロップ段階から HandScore に加算されます。ただし、ブロッカー1枚の実質的な影響力はストリートが進むにつれて大きくなります。

```
ブロッカー効果の目安:

  フロップ時: 相手レンジ ≈ 180 コンボ → 1枚の削減割合 ≈ 数%
  リバー時:  相手レンジ ≈ 20〜40 コンボ → 1枚の削減割合 ≈ 10〜50%
```

フロップでは「あるとわずかに有利」な補正ですが、リバーでは「ブラフの成否を左右する」水準になります。ブロッカー加点が HandScore に組み込まれる仕組みの詳細は巻④ 第7章で扱います。

## 9-5 ブロッカーを使った判断フロー

ブロッカーは「方針を決める道具」ではなく、「方針が決まった後の最終調整ツール」です。この順序を守ることがブロッカー活用の根本原則です。

```
正しい使用順序:

  Step 1: 先手スコア（= HandScore + A − M）で
          ベットするかチェックするかを決める

  Step 2: α 式でブラフの枠数を確認
          （リバーでブラフを何コンボ打てるか）

  Step 3: 方針が決まった複数コンボの中から
          ブロッカー加点が高いものを優先する
```

**NFD 保有コンボを優先すべき場面**: フラッシュボードでブラフを打つ方針が確定しており、ブラフ候補が複数ある場合です。NFD（同スート A）を持つコンボは相手のナッツフラッシュを 100% 除外するため、ブラフが成功しやすくなります。

**Sub-NFD でも意味がある場面**: NFD を持たないが同スートの K を持つコンボは、セカンドナッツフラッシュ（Kx♥）を部分的に除外します。NFD ほど強力ではありませんが、候補が同等の強度なら Sub-NFD 保有コンボを選ぶ理由になります。

**ナッツストレートブロッカーの使い方**: コネクテッドボードでショーダウン価値がほぼゼロのコンボが、たまたまストレート完成のキーカードを持っている場合です。ブラフ候補として優先する根拠になります。

バリューブロッカー（相手の強いハンドを削る）とブラフブロッカー（相手のブラフを削る）という2分類の詳細は巻④ 第7章・巻⑤ 第5章で扱います。ダイジェスト版では「加点値の高いコンボを優先する」という実践的なルールを覚えておけば十分です。

## ミニクイズ

### 問1

BTN vs BB の SRP でフロップが A♣9♦9♠ になりました。GTO 実測で BTN の CBet 率が約 67% と、K♣7♦2♠（約 96%）より大幅に低い理由として最も適切なものはどれですか。

1. ペアボードは常に CBet 率が下がるから
2. BB のレンジに Ax ハンドが多く含まれ、このボードで OOP のレンジ優位が生じるから
3. A-high ボードは BTN に不利だから
4. BTN はダブルペアボードを苦手とするから

### 問2

フラッシュボード（ハート3枚）でブラフを打つ方針が α 式で確定しています。次の2つのブラフ候補コンボのうち、ブロッカー観点で優れているのはどちらですか（いずれもショーダウン価値はほぼゼロ）。

1. A♣Q♦（クラブとダイヤを保有、ハートは持たない）
2. A♥Q♣（A♥でナッツフラッシュを100%ブロック）

---

### 解答

- **問1**: 正解は **2**。A♣9♦9♠ は BB のディフェンスレンジに Ax が広く含まれるため、A9 の 2ペアがヒットしやすくなります。BB の T1 密度が BTN に対して相対的に上昇し、OOP のレンジ優位が発生します。これが CBet 率を大きく下げる原因です。ペアボード全般で下がるわけではなく（K♣4♦4♠ の paired_high は CBet 97.8%）、OOP レンジにどれだけヒットするかが決定因子です。

- **問2**: 正解は **2**（A♥Q♣）。フラッシュボードで相手のバリューコアはナッツフラッシュ（A♥x♥）です。A♥ を自分が持つと、このコンボが物理的にゼロになります。相手は「ナッツを持っている確信」でコールできなくなり、ブラフの成功率が上がります。A♣Q♦ はハートフラッシュをまったくブロックしないため、相手のナッツコール確率はそのままです。

## 本章まとめ

- レンジ優位は2種類: **ナッツアドバンテージ**（T1 の密度差）と**エクイティアドバンテージ**（平均 HS 差）。両者が重なるほど CBet 頻度・サイズが上昇する
- テクスチャ別 CBet 率は IP のレンジ優位を直接反映する。paired_high が最高（97.8%）、2tone が最低（86.7%）
- OOP のレンジ優位が逆転するボード（例: A♣9♦9♠）では IP の CBet 率が大きく下がり、OOP のチェックレイズが増える
- ブロッカー加点は NFD=+3、Sub-NFD=+2、ナッツストレートブロッカー=+2。先手・後手スコアで方針を決めた後の最終調整ツール
- 詳細は巻③ 第01章（レンジ優位）・巻④ 第7章（ブロッカー基礎）・巻⑤ 第5章（ブロッカー実戦）で扱う

---

**【GTO とのズレ】**

実戦で陥りやすい誤りが2つあります。第一は「自分のハンドが強いからベット」という個別ハンド視点にとどまることです。GTO はレンジ全体の優位性でベット頻度を決めるため、T3（エアー）のブラフも全体最適の一部になります。レンジ優位の視点がないと、コネクテッドボードで T1 を過剰にベットしたり、レンジ優位が大きいボードでエアーをチェックしすぎたりするズレが生じます。

第二は「ブロッカーがあるから打てる」という本末転倒の思考です。GTO ではまず方針（先手スコア・α 式）を確定させてからブロッカーで最終選択します。方針なきブロッカー活用は均衡を崩し、搾取されるリスクを高めます。
