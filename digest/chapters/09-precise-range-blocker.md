# 第9章　精密レンジスコア + ブロッカー基礎

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 簡易レンジスコアが外す外れ値ボードを精密レンジスコアで修正できるようになる。加えて、ブロッカーの2分類（バリューブロッカー・ブラフブロッカー）と正しい使い方を理解する。

---

## 9-1 簡易レンジスコアが外す外れ値ボード

第6章で学んだ簡易レンジスコアは、フロップにおける攻撃側（IP）のレンジ全体の CBet 頻度を 0〜10 で予測するモデルです。「ストレート要素・フラッシュ要素・ハイボードリスク」の 3 軸から CBet 頻度を推定し、実測との相関 R² = 0.873 を達成しています。

しかしこのモデルには「外れ値ボード」が存在します。巻3 第1章の 30 ボード検証では、10% 以上の誤差が出るボードが 5 個見つかりました。

代表的な外れ値の例を 2 つ示します。

**例1: A♠8♦2♥（A82r）**  
- 簡易レンジスコアの判定: 2-tone に該当 → ウェット扱い → 推定 55%  
- GTO 実測: 約 88%（残差 −33%）

A-high でかつ 3 枚が大きく散開（最大差 = 11）しているため、IP のレンジアドバンテージがフル機能しています。しかし簡易レンジスコアは「2-tone = ウェット」と扱ったために、CBet 頻度を大幅に低く見積もりました。

**例2: K♦T♠5♣（KT5r）**  
- 簡易レンジスコアの判定: 散開 rainbow → ドライ扱い → 推定 85%  
- GTO 実測: 約 70%（残差 +15%）

middle に T が入ると BB のレンジにヒットするコンボが増え、IP のレンジ優位が削られます。簡易レンジスコアはこの「ミドル T の影響」を捉えられませんでした。

このように、「高・低」「ウェット・ドライ」の 4 マス分類では吸収しきれない構造が存在します。この問題を解消するのが精密レンジスコアです。

---

## 9-2 精密レンジスコアの役割と構造

精密レンジスコアは簡易レンジスコアと同じ「CBet 頻度予測モデル」です。出力するのはボード属性スコアではなく、「このボードで IP のレンジは何 % 程度 CBet するか」という頻度の予測値です。

巻3 第1章で導入された式は「90 から引く」発想に基づく 4 項減算式です。

```
精密レンジスコア（CBet% 予測）
  = 90 − HighCardDeficit − TextureCost − SuitPenalty − Extra

  ただし:
    ペアボード → 固定値表（Pair override）で即決定
    モノトーン → 18% 固定（以降の計算なし）
```

4 つの減算項の概要は次のとおりです。

| 減算項 | 役割 | 典型的な値 |
|---|---|---|
| HighCardDeficit | トップカードが A/K 以外なら引く | A/K=0、Q=5、J/T/9=35 |
| TextureCost | 連続性とトップカードの組み合わせで引く | 散開=0〜5、連続3枚=10〜30 |
| SuitPenalty | スート構造で引く | rainbow=0、2-tone=10 |
| Extra | broadway 複合などの局所パターンで引く | 0〜15（4パターン限定） |

係数の詳細は巻3 第1章および巻3 付録 B に掲載されています。

精密レンジスコアの精度（30 ボード検証）:

| 指標 | 簡易レンジスコア | 精密レンジスコア |
|---|---|---|
| R²（相関） | 0.873 | **0.914** |
| MAE（平均誤差） | 6.0% | **5.3%** |
| 誤差 15% 超のボード | 5 / 30 | **1 / 30** |

外れ値が 5 個から 1 個に減ります。先の A82r は約 88% を正確に予測し、KT5r は Extra E1（middle=T かつ top≥Q かつ rainbow → −15 追加）が発動して約 70% を予測します。

## 9-3 精密レンジスコアと先手・後手スコアの役割分担

精密レンジスコアはマクロ（レンジ全体）の予測、先手・後手スコアはミクロ（個別ハンド）の判断です。

```
精密レンジスコア → 「このボードでレンジ全体が何 % CBet するか」
先手スコア       → 「自分のこのハンドでベットするか」
後手スコア       → 「自分のこのハンドでコール / CR / フォールドか」
```

精密レンジスコアが「55% 戦略」のボードでも手が強ければベットが正当化され、「75% 戦略」のボードでも手が弱ければチェックバックが正解になります。2 つは独立した役割を持ち、組み合わせて使います。詳細は巻3 第1章で扱います。

---

## 9-4 ブロッカーとは何か

ブロッカーとは、自分のカードで相手のハンドを物理的に除外する効果です。「自分がカード X を持つ → 相手はカード X を持てない → カード X を含むコンボが相手のレンジから消える」という連鎖です。

HandScore にブロッカー加点（+2〜+3）として組み込まれているように、ブロッカー効果はフロップ段階から存在します。ただし、フロップでは相手レンジが広くブロッカー 1 枚の影響は小さく、リバーでレンジが絞られると影響が格段に大きくなります。

```
フロップ時: 相手レンジ ≈ 180 コンボ → ブロッカー 1 枚の削減割合 ≈ 数%
リバー時:  相手レンジ ≈ 20〜40 コンボ → ブロッカー 1 枚の削減割合 ≈ 10〜50%
```

---

## 9-5 バリューブロッカーとブラフブロッカー

ブロッカーは「何のレンジを削るか」によって 2 種類に分かれます。

### バリューブロッカー

相手の強いハンド（バリューベットするコンボ）を削るブロッカーです。ブラフを打つ側に有利に働きます。

例: ボード K♥9♥4♣A♥7♦（リバー、ハート 3 枚）で自分が A♥ を持つ場合、相手のナッツフラッシュ（A♥ x♥）のコンボが物理的にゼロになります。ブラフを打ったとき、相手はナッツフラッシュを持っていないため「確信を持ったコール」ができず、ブラフが通りやすくなります。

### ブラフブロッカー

相手のブラフハンドを削るブロッカーです。コールを受ける側（後手）に不利に働きます。

同じボード K♥9♥4♣A♥7♦ で自分が Q♥ を持つ場合、相手のフラッシュドロー外れのブラフ候補（例: Q♥J♣）が消えます。相手のベットレンジがバリュー寄りになるため、自分のコールの期待値が下がります。

### 同じカードでも文脈次第

同じカードがバリューブロッカーとして働くか、ブラフブロッカーとして働くかは、自分が攻撃側か防御側かと、そのカードが相手のどのレンジを削るかによって変わります。ブロッカー効果は常に「文脈次第」です。

---

## 9-6 ブロッカーは「最終層の選別ツール」

ブロッカーを使う際の最重要原則があります。**ブロッカーは方針を決める道具ではなく、方針が決まった後に同じ強度のコンボ群の中から最終選択するための調整ツール**です。

```
正しい使用順序:
  Step 1: α 式でブラフの枠数を確定（ベットするかどうか）
  Step 2: 後手スコアでコール / フォールドを確定
  Step 3: 方針が決まった複数コンボの中から、ブロッカー効果が強いものを優先
```

ブラフを打つ方針がないのにバリューブロッカーを持つからブラフを打つ、というのは誤りです。方針を覆す根拠にはなりません。

実例で確認します。ボード K♥9♥4♣7♥2♦（リバー、ハート 3 枚）で、α 式によりブラフを打てる方針が確定しているとします。ブラフ候補として以下の 2 コンボがあります。

| コンボ | ブロッカー効果 |
|---|---|
| A♥Q♣ | A♥でナッツフラッシュ（A♥x♥）を 100% ブロック → 相手の最強コールが消える |
| J♦T♣ | このボードで強いブロッカー効果なし |

いずれもショーダウン価値はほぼゼロで、同じ強度のブラフ候補です。この場合は A♥Q♣ を選びます。ブロッカーが機能するのは、このように「方針は決まっているが、候補が複数ある」場面です。

詳細は巻4 第7章（ブロッカー基礎）と巻5 第5章（ブロッカー実戦選択）で扱います。

## ミニクイズ

### 問1

フロップ: Q♠T♦3♣（Q-T-3, rainbow）。精密レンジスコアの Extra E1（middle=T かつ top≥Q かつ rainbow → −15 追加）が発動します。次の計算のうち正しいものを選んでください（top=Q なので HighCardDeficit=5、TextureCost=0（散開）、SuitPenalty=0）。

1. 90 − 5 − 0 − 0 − 0 = 85%（Extra が発動しない）
2. 90 − 5 − 0 − 0 − 15 = 70%（Extra E1 が発動）
3. 90 − 0 − 0 − 0 − 15 = 75%（HighCardDeficit を引かずに Extra のみ）
4. 90 − 5 − 10 − 0 − 15 = 60%（SuitPenalty=10 も加算）

### 問2

リバーでブラフを打つ方針が α 式により確定しています。ブラフ候補が「A♥Q♣」と「J♦T♣」の 2 コンボです（いずれもショーダウン価値はほぼゼロ）。ボードのハートが 3 枚あり、相手のバリューコアはナッツフラッシュ（A♥x♥）です。ブロッカー観点で正しい選択はどちらですか。また、その理由を正しく説明しているものを選んでください。

1. A♥Q♣ を選ぶ。A♥ で相手のナッツフラッシュコンボが物理的に消え、相手の確信コールが減るため
2. J♦T♣ を選ぶ。J と T を持つことで相手のストレート系ブラフが削れ、コールが難しくなるため
3. どちらでも同じ。ブロッカーはブラフ成功率に影響しない
4. A♥Q♣ は選ばない。ナッツブロッカーを持つと自分のレンジが読まれるため

---

### 解答

- **問1**: 正解は **2**（90 − 5 − 0 − 0 − 15 = 70%）  
  Q♠T♦3♣ は top=Q（HighCardDeficit=5）、散開（TextureCost=0）、rainbow（SuitPenalty=0）、Extra E1（middle=T、top=Q≥Q、rainbow）が発動して −15。合計 90 − 5 − 15 = 70%。簡易レンジスコアなら「Q-high × ドライ ≈ 85%」と推定されますが、Extra E1 が middle T の影響を捉えて 15% 引き下げます。

- **問2**: 正解は **1**（A♥Q♣ を選ぶ。A♥ でナッツフラッシュを 100% ブロック）  
  このボードで相手の最強コールコンボはナッツフラッシュ（A♥x♥）です。A♥ を自分が持てば、相手はこのコンボを物理的に保有できません。ブラフを打ったとき、相手はナッツで「確信コール」ができず成功率が上がります。J♦T♣ はハートに関わるブロッカー効果を持たないため、ナッツコールを防ぐ力がありません。

## 本章まとめ

- 精密レンジスコアは簡易レンジスコアと同じ「CBet 頻度予測モデル」。4 項減算式（90 − HighCardDeficit − TextureCost − SuitPenalty − Extra）で外れ値ボードを吸収し、R² を 0.873 → 0.914 に改善する
- 精密レンジスコアはマクロ（レンジ全体）、先手・後手スコアはミクロ（個別ハンド）。2 つは独立した役割を持ち、組み合わせて使う
- ブロッカーとは「自分のカードで相手のコンボを物理的に除外する効果」。リバーではレンジが絞られるため影響が特に大きい
- バリューブロッカーは相手の強いハンドを削り（ブラフ側に有利）、ブラフブロッカーは相手のブラフを削る（コール側に不利）
- ブロッカーは「α 式・後手スコアで方針を決めた後に、同強度の候補コンボから最終選択する調整ツール」。方針を変える根拠にはならない
- 精密レンジスコアの詳細は巻3 第1章、ブロッカー実戦は巻4 第7章・巻5 第5章で扱う
