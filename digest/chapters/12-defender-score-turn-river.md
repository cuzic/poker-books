# 第12章　後手スコア（ターン版・リバー版）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップ版の後手スコアをターン・リバーへ拡張する2つの調整点を押さえ、コール/チェックレイズ/フォールドを数値で判断できるようになる。

---

## 12-1 後手スコアの継承と拡張

本書第8章で学んだ後手スコア（フロップ版）の式は次の通りです。

```
後手スコア = HandScore + A − 3 − C − M

A（ボード値）: ドライ=3 / セミ=2 / ウェット=1
C（ベット負担）: 33%=3 / 50%=5 / 75%=7
M（マルチウェイ補正）: HU=0 / 3-way=3 / 4-way以上=6

後手スコア ≥ 8  → チェックレイズ（CR）検討
後手スコア 0〜7 → コール
後手スコア < 0  → フォールド
```

この式の形はターン・リバーでも変わりません。巻④ 第10・11章の拡張は、各変数の**評価方法**にあります。式を覚え直す必要はなく、3点の調整を加えるだけです。

---

## 12-2 フロップ版・ターン版・リバー版の比較表

| 項目 | フロップ版（第8章） | ターン版（巻④ 第10章） | リバー版（巻④ 第11章） |
|---|---|---|---|
| **式の形** | HandScore + A − 3 − C − M | 同じ | 同じ |
| **HandScore** | 役スコア + ドロー加点 + ブロッカー加点 | ターン後の役で更新 | ドロー加点をゼロに |
| **A（ボード値）** | フロップ3枚で評価 | 4枚全体で再評価 | 5枚全体で再評価 |
| **C（ベット負担）** | 33%=3 / 50%=5 / 75%=7 | 同じ | 100%=9 / 150%=11 を追加 |
| **ドロー加点の扱い** | 生きる | 生きる | ゼロ |

---

## 12-3 ターン版の特徴：A値の再評価とドロー加点

ターン版で押さえるべき点は2つです。

**1. A値を4枚全体で再評価する**

フロップのA値をそのままターンに引き継がないことが重要です。ターンカードが落ちるとボードのウェット度が変化します。例えばドライ板（A=3）にスペードが2枚目として落ちればセミ扱い（A=2）に下がります。ペアターンやブランクターンは通常ドライ評価を維持します。

**2. HandScoreをターン後の役で更新する**

TPTK（HandScore=18）だったハンドがターンで2ペアに昇格すればHandScore=22に上げます。フラッシュドローがターンで外れればドロー加点を除去します。ターンカードによる役進化を正確に反映することが精度の鍵です。

ターン版ではドロー加点は生きています。フラッシュドロー（9アウツ）は +13 点、OESD（8アウツ）は +14 点が HandScore に加算されます。

---

## 12-4 リバー版の特徴：ドロー加点の消失とC値拡張

リバー版の調整点も2つです。

**1. HandScoreからドロー加点をゼロにする**

リバーではドローが完成か外れかが確定しています。「次のカードで完成する可能性」が存在しないため、ドロー加点の根拠がなくなります。

フラッシュドロー（FD）が完成すればフラッシュとして役スコア（約25）を使います。外れれば役スコアのみ（FDがなければ約0）になります。ターンでHandScore=13程度あったFD保有ハンドが、リバーで外れるとHandScore=0まで落下します。

**2. C値を100%と150%に拡張する**

リバーでは先手がオーバーベットを多用するため、C値テーブルを拡張します。

```
C値（全ストリート共通）:
  33% pot = 3
  50% pot = 5
  75% pot = 7

リバー専用拡張:
  100% pot = 9
  150% pot（オーバーベット）= 11
```

C値はポットサイズではなくベット比率（%ポット）に連動します。ポットが10BBでも30BBでも、75%ベットならC=7です。この「ポット不変性」のおかげでターン・リバーでも同じテーブルを使えます。

## 12-5 計算例

### 例1（ターン版）: K♠7♦2♣ + 7♥ターン、75%ベット、HU

BTN vs BB（HU、M=0）。フロップK♠7♦2♣（ドライ）でCBet後、ターン7♥（ペアカード）。BTNが75%ベット。

4枚ボードK-7-2-7はペアボードなのでドライ評価を維持（A=3）、C=7。

BBのハンドがK♣J♦の場合: ターン後の役はKペアとボードの7ペアで2ペア（KsとシードKJに対し7-7も加わる）。HandScore=15。

```
後手スコア = 15 + 3 − 3 − 7 − 0 = 8 → CR境界（実戦ではコール）
```

スコア8はCR検討の下限ですが、BTNのUncappedレンジにK7（フルハウス）やKK（フルハウス）が含まれるペアターンでは、CRしてリレイズされるとフォールドせざるを得ません。「スコア8だがコールに留める」が実戦的な判断です。

### 例2（リバー版）: K♠7♦2♣A♥Q♦（5枚）、150%OB、HU

同じ展開でリバーQ♦が落ち、BTNが150%オーバーベット。5枚ボードは散開レインボー（A=3）、C=11。

BBのハンドがK♣J♣（Kのペア）の場合: リバーではドロー加点ゼロ。HandScore=15。

```
後手スコア = 15 + 3 − 3 − 11 − 0 = 4 → コール（薄い）
```

150%オーバーベットにもKペアはコール域に入ります。ただしスコア4は「薄いコール」で、相手のバリュー密度次第ではフォールドも考慮します。

## ミニクイズ

### 問1

フロップ J♥8♠3♦（セミ、A=2）でBTNがCBet、BBがコール。ターン 9♣（コネクター）が落ち、4枚ボードJ-8-9-3はウェット化（A=1）。BTNが50%ポットベット（C=5）。BBの手はK♥Q♥（2OC残存 + ガットショット4アウツ）、HandScore = 9(2OC) + 6(ガットショット) = 15。HU前提（M=0）。後手スコアはいくつですか。

1. 後手スコア = 8 → CR境界
2. 後手スコア = 7 → コール
3. 後手スコア = 11 → CR推奨

### 問2

リバーで5枚ボード A♥K♥Q♥J♠T♦（ウェット、ハート3枚でA=2）、ポット20BB、BTNが75%ベット（C=7）。BBの手は 9♦8♣。役判定: ランクはA・K・Q・J・T・9・8。K-Q-J-T-9 の5連続が成立し、K-highストレート完成。HandScore=30。リバーのため、ドロー加点はゼロ。HU前提（M=0）。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 20 → CR推奨
2. 後手スコア = 22 → CR推奨
3. 後手スコア = 30 → CR推奨

---

### 解答

- **問1**: 1（後手スコア = 15 + 1 − 3 − 5 − 0 = 8 → CR境界。A=1（ウェット）、C=5（50%ベット）が入る。HandScore=15はKQ 2OC+ガットショットで計算）

- **問2**: 2（後手スコア = 30 + 2 − 3 − 7 − 0 = 22 → CR推奨。HandScore=30（ストレート完成）、A=2（ハート3枚でセミウェット）、C=7（75%ベット）。リバー版なのでドロー加点はゼロだが、ストレート完成がHandScore=30として反映されている）

> **本章まとめ**
>
> - 後手スコアの式（HandScore + A − 3 − C − M）はフロップ・ターン・リバー共通
> - ターン版の調整: A値を4枚全体で再評価し、HandScoreをターン後の役で更新する
> - リバー版の調整: HandScoreのドロー加点をゼロにし、C値を100%=9 / 150%=11 に拡張する
> - α 式（前章）は先手の配分設計、後手スコアは後手の防御判断。表裏の関係にある
