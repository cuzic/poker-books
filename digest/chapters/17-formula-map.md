# 第17章　全暗算式マップ ─ 状況別の使い分け

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 本書で学んだ全暗算式を状況別に整理し、「今どの式を使えばよいか」を瞬時に引けるようにする。

---

## 17-1 式が多い、迷うのはなぜか

本書ではプリフロップから始まり、フロップ・ターン・リバー、さらにトーナメント専用の式まで合計 8 系統の暗算式を学んできました。実戦ではこれらを状況に応じて使い分けなければなりませんが、慣れないうちは「今どの式を引けばよいか」で迷います。

迷いが生じる理由は 2 つあります。1 つ目は、式の数が多く見えること。2 つ目は、後手スコアのようにフロップ・ターン・リバーで同じ名前の式が使われていること。実際には式の選択ルールは単純で、「ストリート」と「攻撃か防御か」の 2 軸だけで決まります。本章ではその 2 軸を整理します。

---

## 17-2 状況別 式選択マップ

次の表が本書全体のチートシートです。「今どの局面か」を縦軸で確認し、「攻撃か防御か」で横軸を選ぶと使う式が決まります。

| 局面 | 攻撃側の式 | 防御側の式 |
|---|---|---|
| プリフロップ オープン | Score 式 | ─ |
| プリフロップ 3bet | プリフロップスコア | ─ |
| フロップ CBet | 簡易レンジスコア × 役割 → 9マスマトリクス | 役割マッピング + 判断表（フロップ版） |
| ターン バレル | バレルスコア | 後手スコア（ターン版） |
| リバー ベット | α 式 + ブロッカー選別 | 後手スコア（リバー版） |
| トーナメント（全ストリート） | 上記 + ICM 補正 | 上記 + ICM 補正 |

後手スコアは 3 ストリート共通の形式（HandScore + A − C − M）ですが、C 係数（ベット負担）の値が変わります。フロップ・ターンは C: 33%=12 / 50%=17 / 75%=22 で固定されており、リバー版では 100%=25 / 150%=30 が追加されます。HandScore は equity % に整合した 0-100 の指標です。

---

## 17-3 式選択フロー（3ステップ）

ゲーム中に式を選ぶときは、次の 3 問を順番に確認します。

**ステップ 1: ストリートは何か**

```
プリフロップ → Score 式 / プリフロップスコア
フロップ     → 9マスマトリクス（攻撃）/ 役割判断表（防御）
ターン       → バレルスコア（攻撃）/ 後手スコア（防御）
リバー       → α 式（攻撃）/ 後手スコア（防御）
```

**ステップ 2: 自分は攻撃側か防御側か**

```
攻撃側（CBet・バレル・ベット）
  フロップ → 簡易レンジスコア × 役割 → 9マスマトリクス
  ターン   → バレルスコア
  リバー   → α 式

防御側（コール・フォールド・CR検討）
  フロップ → 役割マッピング × ベットサイズ判断表
  ターン   → 後手スコア（C=12/17/22）
  リバー   → 後手スコア（C=12/17/22/25/30）
```

**ステップ 3: トーナメントか否か**

```
キャッシュゲーム → 各式をそのまま適用
トーナメント    → 必要 equity = (1 + ICM 補正) ÷ (2 + ICM 補正)
                  M 値でステージを確認し、戦略モードを切り替え
```

## 17-4 各式の核心パラメータ早見

本書で定義した全式の係数・判定基準を一覧にまとめます。

### プリフロップ（巻① のプリフロップスコア体系）

```
Score = H + L + ボーナス + ブロッカー − ペナルティ
  ボーナス: ペア+10 / スーテッド+3 / コネクター差1=+1 / 差2-3=+0.5
  ブロッカー: A=+3 / K=+2 / AK 両方=+4
  ペナルティ: 差4以上=−1（A 含むと免除）/ 両方9未満=−1

T_open（6-max）: UTG≥24 / HJ≥22 / CO≥20 / BTN≥18 / SB≥22

T_3bet/T_call（BTN vs UTG 例）: 32/28（二段閾値）
T_4bet=33（QQ+/AKs のみ）/ T_5bet=39（AA のみ）

BB defense は Score_BB（係数強化版）+ 5 ステップフロー
  T_3bet/T_call: vs UTG=34/24, HJ=32/23, CO=28/22, BTN=28/18
```

### HandScore（フロップ・ターン共通の役・ドロー強度、0-100 equity %）

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点（上限 100）

役スコア（主要）:
  Set+ / Flush+ / Straight+: 78〜95
  Top 2pair / OPair AA-QQ:   78
  TPTK = 70 / TPGK = 62 / TPMK = 50 / TPWK = 45
  アンダーペア = 35-45 / セカンドペア = 32-42
  ボトムペア = 32 / A ハイ = 25 / 空振り = 8

ドロー加点:
  フロップ: アウツ × 4（FD = +36 / OESD = +32 / GS = +16 / FD+OESD = +52）
  ターン:   アウツ × 2（FD = +18 / OESD = +16 / GS = +8 / FD+OESD = +26）
  リバー:   0
  BDFD = +5 / BDSD = +2（固定）

ブロッカー加点（重複なし、最大値のみ）:
  ナッツ = +5 / セット・ストレート = +3 / バリュー = +2 / BDFD スート = +1

バケツ: H3 ≥65 / H2 35-64 / H1 < 35
```

### フロップ（役割マッピングを基盤として使う）

```
ハンド役割分類（攻める / 守る / 捨てる）:
  攻める: セット以上 / 2ペア / OESD / ナッツFD / トップペア+FD / モンスタードロー
  守る:   トップペア（OOP） / セカンドペア以上 / ペア+中ドロー / 非ナッツFD
  捨てる: TPWK単独（OOP） / アンダーペア単独 / ボトムペア単独 / 役なし

ポジション補正: IPではトップペアも攻める

9マスマトリクス（攻撃側）:
  高頻度×攻める→75% / 高頻度×守る→33% / 高頻度×捨てる→33%（レンジベット）
  中頻度×攻める→50% / 中頻度×守る→33% / 中頻度×捨てる→チェック
  低頻度×攻める→50% / 低頻度×守る→チェック / 低頻度×捨てる→チェック

役割×ベットサイズ判断表（防御側）:
  攻める×33%→CR / 攻める×50%→CR / 攻める×75%→CRまたはコール
  守る×33%→コール / 守る×50%→コール / 守る×75%→コールまたはフォールド
  捨てる×33%→コール(MDF) / 捨てる×50%→フォールド気味 / 捨てる×75%→フォールド
```

### ターン

```
バレルスコア = FlopType係数 + TurnCard係数（5-12 範囲のオーディナルスコア）
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0
  判定: ≥7→積極バレル / <7→慎重

後手スコア（ターン版）= HandScore + A − C − M
  HandScore: 役 + ドロー加点（アウツ × 2、Rule of 2）+ ブロッカー
  A = 12/6/0、C = 12/17/22、M = 0/12/22
  判定: ≥40→CR / 20-39→コール / <20→フォールド
```

### リバー

```
α 式: α = ベット ÷ (ポット + ベット)
  MDF = 1 − α
  バリュー:ブラフ = (1−α) : α

  33% pot → α=0.25, MDF=0.75
  50% pot → α=0.33, MDF=0.67
  75% pot → α=0.43, MDF=0.57
  100% pot → α=0.50, MDF=0.50

後手スコア（リバー版）= HandScore + A − C − M
  HandScore: 役（5枚で確定）+ ブロッカー（ドロー加点 = 0）
  C 拡張: 100%=25 / 150%=30
  C ≒ α × 50 と覚えると暗算しやすい
```

### トーナメント

```
M 値 = スタック ÷ (SB + BB + アンテ合計)
  Green≥20 / Yellow 10-20 / Orange 6-10 / Red≤5

ICM 補正 = bubble factor − 1.0
必要 equity = (1 + ICM 補正) ÷ (2 + ICM 補正)

  バブル直前 STT: 補正≈0.875 → 必要 equity ≈ 65.8%
  バブル直前 MTT: 補正≈0.40 → 必要 equity ≈ 58.3%
  HU（最終2名）: 補正=0 → Chip EV = $EV
```

## 17-5 式間のつながり

各式は独立したツールではなく、上流から下流へ情報を引き継いでいます。

```
簡易レンジスコア
  ↓ ボード分類（ドライ/セミ/ウェット）
  ↓ A 係数として投入
役割マッピング × 9マスマトリクス（フロップ）
  ↓ フロップ判断の出力
  ↓ FlopType 分類をターンに引き継ぐ
バレルスコア（ターン）
  ↓ FlopType がフロップの分類を引き継ぐ
α 式（リバー）
  ↓ MDFを設定
後手スコア（リバー版）でディフェンスを完結
```

プリフロップで Score 式を使ってハンドを選び、フロップで役割分類と簡易レンジスコアを組み合わせ、ターンでバレルスコアを計算し、リバーで α 式を使ってベットバランスを取る——これが 1 ハンドの暗算フローです。詳細は各章を参照してください。

## ミニクイズ

### 問1

ターンで相手から 75% pot のベットを受けました。自分は HU（M=0）です。コールを検討するとき、使う式と C の値の正しい組み合わせはどれですか。

1. バレルスコア（攻撃式のため C を使わない）
2. α 式 / α = 0.43
3. 後手スコア（ターン版）/ C = 22
4. 後手スコア（フロップ版）/ C = 17

### 問2

リバーで自分がベットを検討しています。ポット 100、ベット候補は 50（50% pot）です。α 式の α 値と、バリュー:ブラフの理論比率はどれですか。

1. α=0.25、バリュー:ブラフ = 3:1
2. α=0.33、バリュー:ブラフ = 2:1
3. α=0.43、バリュー:ブラフ ≈ 1.3:1
4. α=0.50、バリュー:ブラフ = 1:1

---

### 解答

- **問1**: 3（防御側はターン版後手スコアを使う。75% pot は C=22。詳細は本書 第12章）
- **問2**: 2（50% pot のとき α = 50÷150 ≈ 0.33、MDF = 0.67。バリュー:ブラフ = 0.67:0.33 = 2:1。詳細は本書 第11章）

## 本章まとめ

- 式選択は「ストリート」と「攻撃か防御か」の 2 軸で決まる
- フロップ防御は役割判断表、ターン・リバー防御は後手スコア（形式共通、C 係数のみ変化）
- 各式は上流から下流へ情報を引き継いでおり、フロップの簡易レンジスコアがターンのバレルスコアにつながる
- トーナメントでは ICM 補正を全式に重ねて必要エクイティを引き上げる
- 迷ったら「ストリート → 攻防 → キャッシュ/トーナメント」の 3 問を順番に確認する
