# 第17章　全暗算式マップ ─ 状況別の使い分け

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 本書で学んだ全暗算式を状況別に整理し、「今どの式を使えばよいか」を瞬時に引けるようにする。

---

## 17-1 式が多い、迷うのはなぜか

本書ではプリフロップから始まり、フロップ・ターン・リバー、さらにトーナメント専用の式まで合計 8 系統の暗算式を学んできました。実戦ではこれらを状況に応じて使い分けなければなりませんが、慣れないうちは「今どの式を引けばよいか」で迷います。

迷いが生じる理由は 2 つあります。1 つ目は、式の数が多く見えること。2 つ目は、後手スコアのようにフロップ・ターン・リバーで同じ名前の式が使われていること。実際には式の選択ルールは単純で、「ストリート」と「攻撃か防御か」の 2 軸だけで決まります。本章ではその 2 軸を整理します。

---

## 17-2 状況別 式選択マップ

次の表が本書全体のチートシートです。「今どの局面か」を縦軸で確認し、「攻撃か防御か」で横軸を選ぶと使う式が決まります。

| 局面 | 攻撃側の式 | 防御側の式 |
|---|---|---|
| プリフロップ オープン | Score 式 | ─ |
| プリフロップ 3bet | Score₃ | ─ |
| フロップ CBet | 先手スコア（簡易レンジスコア→A係数経由） | 後手スコア（フロップ版） |
| ターン バレル | バレルスコア | 後手スコア（ターン版） |
| リバー ベット | α 式 + ブロッカー選別 | 後手スコア（リバー版） |
| トーナメント（全ストリート） | 上記 + ICM 補正 | 上記 + ICM 補正 |

後手スコアは 3 ストリート共通の形式ですが、C 係数（ベット負担）の値が変わります。フロップは C: 33%=3 / 50%=5 / 75%=7 で固定されており、リバー版では 100%=9 / 150%=11 が追加されます。

---

## 17-3 式選択フロー（3ステップ）

ゲーム中に式を選ぶときは、次の 3 問を順番に確認します。

**ステップ 1: ストリートは何か**

```
プリフロップ → Score 式 / Score₃
フロップ     → 先手スコア（攻撃）/ 後手スコア（防御）
ターン       → バレルスコア（攻撃）/ 後手スコア（防御）
リバー       → α 式（攻撃）/ 後手スコア（防御）
```

**ステップ 2: 自分は攻撃側か防御側か**

```
攻撃側（CBet・バレル・ベット）
  → 先手スコア / バレルスコア / α 式

防御側（コール・フォールド・CR検討）
  → 後手スコア
    フロップ: C=3/5/7
    ターン:   C=3/5/7（形式同じ）
    リバー:   C=3/5/7/9/11（拡張あり）
```

**ステップ 3: トーナメントか否か**

```
キャッシュゲーム → 各式をそのまま適用
トーナメント    → 必要 equity = (1 + ICM補正) ÷ (2 + ICM補正)
                  M 値でステージを確認し、戦略モードを切り替え
```

## 17-4 各式の核心パラメータ早見

本書で定義した全式の係数・判定基準を一覧にまとめます。

### プリフロップ

```
Score = H + L + ボーナス − ペナルティ
  しきい値: UTG≥23 / MP≥22 / CO≥21 / BTN≥18 / SB≥20

Score₃ = H + 0.5L + B + S + C − G − R
```

### フロップ（HandScore を共通基盤として使う）

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
  セット=30 / OP=20 / TPTK・2ペア=18 / TPGK=15 / セカンドペア強=9 /
  TPMK=8 / TPWK=6 / アンダーペア=6 / セカンドペア弱=3
  ドロー加点（表）: FD+OESD +17 / OESD +14 / FD +13 / ガット +10 / 2オーバー +7
  バケツ: H3≥14 / H2 7-13 / H1<7

先手スコア = HandScore + A − M
  A: ドライ=3 / セミ=2 / ウェット=1  / M: HU=0 / 3-way=3 / 4-way+=6
  判定: ≥7→ベット / <7→チェックバック

後手スコア（フロップ版）= HandScore + A − 3 − C − M
  C: 33%=3 / 50%=5 / 75%=7
  判定: ≥8→CR検討 / 0〜7→コール / <0→フォールド
```

### ターン

```
バレルスコア = FlopType係数 + TurnCard係数
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0
  判定: ≥7→積極バレル / <7→慎重

後手スコア（ターン版）= HandScore + A − 3 − C − M
  （係数の解釈はフロップ版と同じ、ドロー加点が生きる局面も多い）
```

### リバー

```
α 式: α = ベット ÷ (ポット + ベット)
  後手下限確率 = 1 − α
  バリュー:ブラフ = (1−α) : α

  33% pot → α=0.25, 後手下限確率=0.75
  50% pot → α=0.33, 後手下限確率=0.67
  75% pot → α=0.43, 後手下限確率=0.57
  100% pot → α=0.50, 後手下限確率=0.50

後手スコア（リバー版）= HandScore + A − 3 − C − M
  C 拡張: 100%=9 / 150%=11
```

### トーナメント

```
M 値 = スタック ÷ (SB + BB + アンテ合計)
  Green≥20 / Yellow 10-20 / Orange 6-10 / Red≤5

ICM 補正 = bubble factor − 1.0
必要 equity = (1 + ICM補正) ÷ (2 + ICM補正)

  バブル直前 STT: 補正≈0.875 → 必要 equity ≈ 65.8%
  バブル直前 MTT: 補正≈0.40 → 必要 equity ≈ 58.3%
  HU（最終2名）: 補正=0 → Chip EV = $EV
```

## 17-5 式間のつながり

各式は独立したツールではなく、上流から下流へ情報を引き継いでいます。

```
簡易レンジスコア
  ↓ ボード分類（ドライ/セミ/ウェット）
  ↓ A 係数として投入
先手スコア / 後手スコア
  ↓ フロップ判断の出力
  ↓ ハンド評価（HandScore）を共有
バレルスコア（ターン）
  ↓ FlopType がフロップの分類を引き継ぐ
α 式（リバー）
  ↓ 後手下限確率を設定
後手スコア（リバー版）でディフェンスを完結
```

プリフロップで Score 式を使ってハンドを選び、フロップで HandScore と簡易レンジスコアを組み合わせ、ターンでバレルスコアを計算し、リバーで α 式を使ってベットバランスを取る——これが 1 ハンドの暗算フローです。詳細は各章を参照してください。

## ミニクイズ

### 問1

ターンで相手から 75% pot のベットを受けました。自分は HU（M=0）です。コールを検討するとき、使う式と C の値の正しい組み合わせはどれですか。

1. バレルスコア / C = 7
2. α 式 / α = 0.43
3. 後手スコア（ターン版）/ C = 7
4. 後手スコア（フロップ版）/ C = 5

### 問2

リバーで自分がベットを検討しています。ポット 100、ベット候補は 50（50% pot）です。α 式の α 値と、バリュー:ブラフの理論比率はどれですか。

1. α=0.25、バリュー:ブラフ = 3:1
2. α=0.33、バリュー:ブラフ = 2:1
3. α=0.43、バリュー:ブラフ ≈ 1.3:1
4. α=0.50、バリュー:ブラフ = 1:1

---

### 解答

- **問1**: 3（防御側はターン版後手スコアを使う。75% pot は C=7。詳細は本書 第12章）
- **問2**: 2（50% pot のとき α = 50÷150 ≈ 0.33、後手下限確率 = 0.67。バリュー:ブラフ = 0.67:0.33 = 2:1。詳細は本書 第11章）

---

## 本章まとめ

- 式選択は「ストリート」と「攻撃か防御か」の 2 軸で決まる
- 後手スコアはフロップ・ターン・リバーで形式が共通、C 係数の値だけが変わる
- 各式は上流から下流へ情報を引き継いでおり、フロップの簡易レンジスコアがターンのバレルスコアにつながる
- トーナメントでは ICM 補正を全式に重ねて必要エクイティを引き上げる
- 迷ったら「ストリート → 攻防 → キャッシュ/トーナメント」の 3 問を順番に確認する
