# 第2章　ポットオッズとMDF

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ポットオッズで個別ハンドのコール可否を判断し、MDFでレンジ全体の防衛頻度を把握する

---

## 2-1　ポットオッズとは何か

**ポットオッズ** とは、コール時のリターン比率です。「このコールに必要な最低勝率」を計算します。

```
ポットオッズ（必要勝率）= コール額 ÷ (ポット + コール額)
                       = コール額 ÷ 最終ポット
```

具体例で確認します。ポット 100 に対して相手が 50 ベットした場面を考えます。

```
最終ポット = 100（既存）+ 50（ベット）+ 50（コール）= 200
必要勝率   = 50 ÷ 200 = 25%
```

自分のハンドが 25% 以上の勝率を持っていれば、コールは数学的に正当化されます。第1章の Rule of 2 and 4 で計算したエクイティがこの 25% を上回るかどうかを判断することで、コール可否が決まります。

**ベットサイズ別の必要勝率**:

| ベットサイズ（ポット比） | 必要勝率 | 覚え方 |
|---|---|---|
| 33% | 約 20% | 5 回に 1 回勝てれば OK |
| 50% | 約 25% | 4 回に 1 回勝てれば OK |
| 75% | 約 30% | 3 回に 1 回勝てれば OK |
| 100% | 約 33% | 3 回に 1 回強く勝てれば OK |

---

## 2-2　MDFの 3 系統

ポットオッズは「このハンドをコールすべきか」という個別判断に使います。一方、「レンジ全体として折りすぎていないか」という大局的な視点がMDFです。

本シリーズでは、文脈に応じて「MDF」を次の 3 つの用語で使い分けます。曖昧な単独用法を避けるための明示化です。

| 用語 | 用途 | 例文 |
|---|---|---|
| **MDF ライン** | しきい値・境界として語る | 「MDF ラインを下回るとブラフを許してしまう」 |
| **MDF** | 具体的な % 数値 | 「75% ベットのMDFは 57%」 |
| **MDF スコア** | スコア式の判断境界 | 「後手スコアがMDF スコアを超えていればコール」 |

無印の「MDF」は概念全体を指します。

**3 者の関係**:

```
α（先手のブラフ損益分岐点）= ベット ÷ (ポット + ベット)
MDF               = 1 − α     （頻度の話）
MDF ライン                         （MDFを下回ると守りすぎ、概念の話）
MDF スコア             = 0         （後手スコア式の判断境界、スコアの話）
```

MDFは「相手のブラフが損益分岐点になる防衛頻度」です。この頻度を下回ってフォールドしすぎると、相手は 0 エクイティのピュアブラフを打つだけで利益を得られます。

---

## 2-3　MDFの早見表

α 式（巻④ 第9章で詳述）から計算したMDFの代表値を示します。

```
α             = ベット ÷ (ポット + ベット)
MDF  = 1 − α
```

| ベットサイズ | α | MDF |
|---|---|---|
| 33% pot | 0.25 | 75%（4 回中 3 回は守る） |
| 50% pot | 0.33 | 67%（3 回中 2 回は守る） |
| 75% pot | 0.43 | 57%（2 回中 1 回強く守る） |
| 100% pot | 0.50 | 50%（半分は守る） |
| 150% pot（オーバーベット） | 0.60 | 40%（5 回中 2 回守る） |

「100% ポットベットに半分コールするのは多すぎる」と感じる方も多いですが、これが「ブラフを抑止するために必要な防衛」です。

**感覚ルール**: 33% ベットには基本コール、75% 以上で初めて絞る。

---

## 2-4　MDF スコアと防御判断の関係

MDFをスコアとして表現したものが**MDF スコア**です。

**フロップ**では、役割マッピング（攻める/守る/捨てる）× ベットサイズ判断表でアクションを決定します（本書第8章・巻② 第9章・第13章）。捨てる手で後手スコアが 0 に近い局面が「MDF コール境界」に相当します。

**ターン・リバー**では後手スコア式を使います（本書第12章・巻④ 第10章・第11章）。

```
後手スコア（ターン・リバー）= HandScore + A − 3 − C（− M）

A: ドライ=3 / セミ=2 / ウェット=1
C: 33%=3 / 50%=4 / 75%=6
M: HU=0 / 3-way=3 / 4-way+=6

判定:
  後手スコア ≥ 8  → チェックレイズ検討
  後手スコア 0〜7 → コール
  後手スコア < 0  → フォールド
```

MDF スコアは 0 です。後手スコア ≥ 0 ならコール、後手スコア < 0 ならフォールドです。

---

## 2-5　ポットオッズ vs MDFの使い分け

| 概念 | 対象 | 目的 | 使いどころ |
|---|---|---|---|
| ポットオッズ | 個別ハンド | このハンドのコールが得かどうか | 実戦での個別判断 |
| MDF | レンジ全体 | ブラフを無価値にする最低防衛率 | バランス確認・勉強時 |
| MDF スコア | 個別ハンド | スコア式での判断境界 | 後手スコア（ターン・リバー）と組み合わせた判断 |

実戦の手順は「まずポットオッズで個別判断、MDFでレンジ全体の折り過ぎをチェック」です。

## ミニクイズ

### 問1

ポット 100 に対して相手が 75 ベット（75% サイズ）しました。このコールに必要な最低勝率はいくつですか。また 75% ベットのMDFはいくつですか。

### 問2

「MDF ライン」「MDF」「MDF スコア」の 3 つはそれぞれどの文脈で使いますか。1 文ずつ説明してください。

---

### 解答

- **問1**: 必要勝率は 75 ÷ (100 + 75 + 75) = 75 ÷ 250 = **30%**。MDFは α = 0.43 から 1 − 0.43 = **57%**（レンジ全体の 57% を守る必要がある）。
- **問2**: MDF ライン = 「57% を下回ると守りすぎ」のように概念・境界を語るとき。MDF = 「75% ベットのMDFは 57%」のように具体的な % 数値を示すとき。MDF スコア = 「後手スコア ≥ 0（MDF スコア）ならコール」のようにスコア式の判断境界を示すとき。

---

> **本章まとめ**
>
> - ポットオッズ = コール額 ÷ 最終ポット で「必要最低勝率」を求める
> - MDFは 3 系統（ライン / 確率 / スコア）で用途別に使い分ける
> - MDF = 1 − α で、ベットサイズに応じた最低防衛頻度を示す
> - MDF スコア = 0 で、後手スコア（ターン・リバー版）がこれを下回ればフォールド
> - フロップ防御は役割マッピング（第8章）で判断する
> - 「MDF」単独表記は曖昧さ回避のため、ライン / 確率 / スコア の 3 系統に分ける
