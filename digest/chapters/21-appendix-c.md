## カテゴリ1 暗算式の核

**HandScore**（ハンドスコア）
ハンドの強さを 0〜50 で数値化した指標。役スコア + ドロー加点 + ブロッカー加点の 3 項からなる。

**簡易レンジスコア**
フロップ全体の CBet 頻度を 0〜10 で予測するモデル。ボード属性そのものではなく、攻撃側の CBet 頻度予測値。出力値でボードをドライ / セミ / ウェットに分類し、A 係数として下流式に渡す。

**後手スコア**
ディフェンス側の判断式。後手スコア = HandScore + A − 3 − C − M。スコア ≥ 8 でチェックレイズ検討、0〜7 でコール、0 未満でフォールド。

**バレルスコア**
ターン攻撃の判断式。バレルスコア = FlopType係数 + TurnCard係数。スコア ≥ 7 で積極バレル。

**α 式（アルファ式）**
リバー配分の式。α = ベット ÷ (ポット + ベット)。後手下限確率 = 1 − α。

**精密レンジスコア**
簡易レンジスコアの精密版。外れ値ボードに追加補正項を持つ（巻3 で導入）。

## カテゴリ2 係数

**A（ボード値）**
ボードのドライ度を 3 段階で表す係数。ドライ = 3 / セミ = 2 / ウェット = 1。

**C（ベット負担）**
相手のベットサイズに応じたコスト係数。33%=3 / 50%=5 / 75%=7 / 100%=9 / 150%=11。

**M（マルチウェイ補正係数）**
プレイヤー数による補正。HU=0 / 3-way=3 / 4-way以上=6。巻6 の「M 値」（スタック深さ）とは別物。

## カテゴリ3 レンジ概念

**Capped / Uncapped（キャップド / アンキャップド）**
レンジ強度の分類。Uncapped はナッツ級ハンドを含み得るレンジ。Capped はナッツ級が薄く守備的になるレンジ。

**ナッツアドバンテージ**
最強のハンドがどちらのレンジに多く存在するかの指標。ターンカードの落ち方によって更新される。

**3軸統合**
ターン判断 = forward 軸（過去のアクション）× current 軸（ターンカードの影響）× backward 軸（リバー予測）の統合フレーム（巻5 で導入）。

**後手下限**
コール側が確保すべき最低防御率の概念。後手下限ライン（境界）、後手下限確率（%値）、後手下限スコア（式の判断境界）の 3 系統で使い分ける。

## カテゴリ4 トーナメント特有

**ICM equity（ICM エクイティ）**
チップを賞金期待値（$EV）に換算した値。「自分のスタックが今いくら相当か」を表す。

**ICM 補正**
ICM 圧力下で必要な上乗せ勝率（リスクプレミアム）。ICM 補正 = bubble factor − 1.0。

**bubble factor（バブルファクター）**
オールイン勝負時の「失う痛み / 得る喜び」比。BF = 1.0 なら ICM 影響なし。

**M 値（M ratio）**
スタック深さの指標。スタック ÷ (SB + BB + アンテ合計)。Green≥20 / Yellow=10-20 / Orange=6-10 / Red≤5。

**ペイジャンプ**
賞金階段の上昇幅。ITM 進入や FT 進入の「ジャンプ点」で ICM 補正が再上昇する。
