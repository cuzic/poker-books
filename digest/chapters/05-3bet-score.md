# 第5章　3bet スコア ─ リレイズの判断

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 3bet スコア式で「いつ 3 ベット（リレイズ）するか」を暗算で判断できるようになる

---

## 5-1 3 ベットの 2 つの目的

3 ベットには「バリュー」と「ブラフ」の 2 種類があります。この区別を最初に押さえることが重要です。

**バリュー 3 ベット**: QQ+、AK のような強いハンドでポットを大きくして価値を取ります。相手がコールすれば大きなポットで有利な勝負ができます。

**ブラフ 3 ベット**: A5s、KTs のようなブロッカー付きハンドで相手をフォールドさせます。フォールドエクイティを狙いながらレンジバランスも維持します。ブラフを加えることで相手はあなたの 3 ベットにタイトに降りられなくなります。

---

## 5-2 3bet スコア式の全体像

### 式の定義

```
Score₃ = H + 0.5L + B + S + C − G − R
```

各項目の意味は次の通りです。

- **H**: 高い方のカード値（A=14、K=13、…、2=2）
- **0.5L**: 低い方のカード値の半分（低カードの影響を半減）
- **B**: ブロッカーボーナス
  - A を含む: +3
  - K を含む: +2
  - A・K 両方: +4（重複効果は減衰）
- **S**: スーテッド → +2
- **C**: コネクター / ギャップ 2 以内
  - 差 = 1（コネクター）: +1
  - 差 = 2 または 3（ギャップ 2 以内）: +0.5
- **G**: ギャップ 4 以上（差 = 5 以上）: −1（ただし A を含む場合は免除）
- **R**: 両方 9 未満: −1（ペアには適用しない）

### 第 4 章の Score 式との違い

オープン判断式が `H + L`（低カードを等価に扱う）だったのに対し、3bet スコア式は `H + 0.5L` です。3 ベットでは高カード 1 枚のブロッカー効果が低カードの値より重要なためです。スーテッドボーナスも +3 から +2 に下がっています。3 ベットではドロー価値よりブロッカー効果の方が判断に直結します。また、ブロッカーボーナス（B）が新設されました。これが 3bet スコアの核心です。

### ペアの扱い

3bet スコア式はノンペアハンド用です。ペアは次のルールで扱います: QQ+ は常にバリュー 3 ベット、JJ・TT はポジション次第、99 以下は基本コール（セットマイニング狙い）。

---

## 5-3 ブロッカー効果の数値的根拠

A を 1 枚持つだけで相手の AA コンボが 6 通りから 3 通りへ半減し、AK コンボが 16 通りから 12 通りへ減ります。AK 両方を持てば相手の AK は 9 通りまで削れます（約 44% 減）。ブラフ 3 ベットを成功させるうえで、これは大きなアドバンテージです。

ブロッカーボーナスの値（A:+3、K:+2、AK:+4）はこの効果量の差を反映しています。A のほうが K よりブロッカー力が強いため +3 と +2 に差をつけ、AK 両方は +5 ではなく +4 としているのは重複効果が完全には累積しないためです。

---

## 5-4 ポジション別しきい値

3 ベットは相手のポジションで判断が変わります。UTG の強いオープンレンジには厳しく、BTN の広いオープンレンジには緩く対応できます。

| 相手のポジション | 3bet しきい値 |
|---|---|
| 対 UTG | ≥ 23 |
| 対 MP | ≥ 21 |
| 対 CO | ≥ 19 |
| 対 BTN | ≥ 18 |

```
Score₃ ≥ しきい値 → 3 ベット
Score₃ < しきい値 → コール またはフォールド
```

---

## 5-5 計算例 3 選

### 例 1: AKo（Score₃ = 25.5）

- H = 14、0.5L = 0.5 × 13 = 6.5
- B: A・K 両方 → +4
- C: 差 = 1（コネクター）→ +1

```
14 + 6.5 + 4 + 1 = 25.5
```

対 UTG しきい値 23 も余裕で超えます。全ポジションから 3 ベットできるバリューハンドの典型です。

### 例 2: A5s（Score₃ = 21.5）

- H = 14、0.5L = 0.5 × 5 = 2.5
- B: A を含む → +3
- S: スーテッド → +2
- G: 差 = 9 だが A を含むため免除

```
14 + 2.5 + 3 + 2 = 21.5
```

対 CO しきい値 19 と対 MP しきい値 21 を超えます。対 UTG（しきい値 23）には届かないためコール判定になります。GTO では混合戦略（3 ベット約 60%・コール約 40%）を採るスポットです。

### 例 3: KTs（Score₃ = 23）

- H = 13、0.5L = 0.5 × 10 = 5
- B: K を含む → +2
- S: スーテッド → +2
- C: Broadway 近接（差 = 3）→ +1（KTs 専用例外）

```
13 + 5 + 2 + 2 + 1 = 23
```

対 UTG しきい値 23 をぴったり満たします。K と T は Broadway ストレートの両端を抑えるため、コネクター扱い（+1）とします。ただしこの例外は KTs 専用で、AJs、KJs、QTs などは通常のルール通りに計算します。

詳細なブロッカー論と各ポジション別ドリルは **巻1 第12章・第13章** で扱っています。

## ミニクイズ

### 問 1

次のハンドの 3bet スコアを計算してください。

1. QQ
2. A5s
3. KJo

---

### 問 2

あなたは BTN でオープンした CO に対して AQo を持っています。3bet スコアはいくつで、3 ベットしますか。

- H = 14、0.5L = 0.5 × 12 = 6
- B: A を含む → +3（K は含まない）
- C: 差 = 2（ギャップ 2 以内）→ +0.5

---

### 解答

- **問 1**:
  1. QQ は式対象外。QQ+ は常にバリュー 3 ベット。
  2. A5s: 14 + 2.5 + 3 + 2 = **21.5**
  3. KJo: 13 + 5.5 + 2 + 0.5 = **21**（対 MP しきい値 21 をぴったり満たす）

- **問 2**: 14 + 6 + 3 + 0.5 = **23.5**。対 CO しきい値 19 を大きく超えるため 3 ベットします。

---

> **本章まとめ**
>
> - 3bet スコア式: `Score₃ = H + 0.5L + B + S + C − G − R`
> - B（ブロッカー）: A含む+3 / K含む+2 / AK両方+4
> - S（スーテッド）: +2（オープン式の +3 より低い）
> - しきい値: 対UTG 23 / 対MP 21 / 対CO 19 / 対BTN 18
> - QQ+ は式を使わず常にバリュー 3 ベット
> - A を 1 枚持つだけで相手の AA が半減するブロッカー効果が核心

---

**【GTOとのズレ】**

本書の 3bet スコア式は、GTO がミックス戦略を採るハンド（A5s、A4s、KTs など）を決定論的に「3 ベット」または「コール」に振り分けます。たとえば A5s は 3bet スコア 21.5 で対 UTG しきい値 23 に届かないためコール判定になりますが、GTO では約 60% の確率で 3 ベットします。

この近似により、初心者はバリュー 3 ベット（QQ+、AK）だけが 3 ベット候補に残ります。相手に「この人の 3 ベットは強い手だけ」と読まれるリスクはありますが、初心者段階ではバリュー 3 ベットで勝ち方を覚えることを優先するのが適切です。

ブラフ 3 ベットを加えたい場合は、しきい値より 2〜3 点低い範囲のスーテッドブロッカー付きハンド（A5s、A4s など）を 50% の頻度で 3 ベットに混ぜることから始めると、GTO の混合戦略に近づけます。
