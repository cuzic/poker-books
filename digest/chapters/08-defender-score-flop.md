# 第8章　ハンド役割分類（フロップ版）+ 9マスマトリクス

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップのハンドを「攻める・ショーダウンバリュー・守る・捨てる」4 役割に即分類し、9マスマトリクスで CBet アクションを決定できるようになる

---

## 8-1 ハンドの役割分類とは何か

フロップで同じハンドでも「今ベットすべきか」「コールすべきか」は状況次第です。この判断を数値で計算するのではなく、**4 種類の役割**に直接マッピングすることで、暗算なしに即断できます。

| 役割 | 基本方針 |
|---|---|
| **攻める** | 積極的にベット・レイズ、ポットを拡大 |
| **ショーダウンバリュー** | IP ではベット・OOP ではコール（ポジション依存） |
| **守る** | コール・チェック、ポットを大きくしすぎない |
| **捨てる** | 大きなベットにはフォールド、33%ベットのみ MDF でコール候補 |

---

## 8-2 役割マッピング表

### 攻める手

| ハンド | 備考 |
|---|---|
| セット以上 | ストレート・フラッシュ含む |
| 2ペア | ボード依存で OOP では守る寄り |
| OESD（両面ストレートドロー） | 8アウツ |
| ナッツ FD（ナッツフラッシュドロー） | トップスーツ保持 |
| トップペア + FD | コンボドロー |
| モンスタードロー（12アウツ以上） | FD+OESD など |

### ショーダウンバリューの手

| ハンドパターン | IP のアクション | OOP のアクション |
|-------------|-------------|--------------|
| TPTK（トップペア最良キッカー） | ベット 50〜75% | コール |
| TPGK（トップペア良キッカー）  | ベット 33〜50% | コール |
| TPMK（トップペア中キッカー）  | ベット 33〜50% | コール |
| オーバーペア（FDなし）        | ベット 33〜50% | コール |

> **ショーダウンバリュー（Showdown value）** はポーカー標準用語です。「ショーダウンになれば相手の弱い手に勝てる強さがあるが、レイズするには不十分な中程度の手」を指します。ポジションによって最適なアクションが変わるため独立したカテゴリとして扱います。

### 守る手

| ハンド | 備考 |
|---|---|
| TPWK 単独（ドライ板） | セカンドペア相当の守り |
| セカンドペア以上 | 強キッカー優先 |
| ペア + 中ドロー | ガットショットや 2 オーバーなど |
| 非ナッツ FD 単独 | サブナッツ FD |

### 捨てる手

| ハンド | 備考 |
|---|---|
| TPWK 単独（ウェット板） | ドローに当たりやすい |
| アンダーペア単独 | ポジション問わず |
| ボトムペア単独 | |
| 役なし | |

## 8-3 役割×ベットサイズ判断表（防御側）

相手が CBet を打ってきたとき、自分の役割とベットサイズの組み合わせでアクションを選びます。

| 役割 \ ベットサイズ | 33% pot | 50% pot | 75% pot |
|---|---|---|---|
| **攻める** | CR | CR | CR またはコール |
| **ショーダウンバリュー** | コール | コール | コール |
| **守る** | コール | コール | コール またはフォールド |
| **捨てる** | コール（MDF） | フォールド気味 | フォールド |

**CR** = チェックレイズ検討。攻める手は積極的に CR でポットを拡大します。
**MDF** = 33% 小ベットに対してはレンジ全体の約 75% を守る必要があるため、捨てる手も一部コール候補になります。

---

## 8-4 9マスマトリクス ─ 攻撃側の統合判定

攻撃側（CBet を打つ側）の判断は**9マスマトリクス**で整理されます。

- 横軸: ハンド役割（攻める / 守る / 捨てる）
- 縦軸: 簡易レンジスコアの CBet 頻度帯（高頻度 / 中頻度 / 低頻度）

### 9マスマトリクス

|  | 攻める | 守る | 捨てる |
|---|---|---|---|
| **高頻度**（ドライ ≥ 70%） | CBet 75% | CBet 33% | CBet 33%（レンジベット） |
| **中頻度**（セミ 40〜69%） | CBet 50% | CBet 33% | チェック |
| **低頻度**（ウェット ≤ 39%） | CBet 50% | チェック | チェック |

### レンジベットの読み方

ドライボード（高頻度）では、捨てる手も 33% でベットします。これを「レンジベット」と呼びます。ドライボードは攻撃側が全レンジで優位を持つため、弱いハンドもブラフとして押すことで相手のチェック後の攻撃を封じます。

ショーダウンバリュー（トップペア・オーバーペア）は IP では攻める列、OOP では守る列に相当します。

詳細は巻② 第9・10・13章で扱います。

## 8-5 具体例

### 例1: ドライボード、トップペア（IP）

ボード: K♠7♦2♣（ドライ、高頻度）
ハンド: A♣K♦（TPTK）
ポジション: IP（ボタン）

役割 = IP のトップペアは **ショーダウンバリュー**（IP では攻める相当）。マトリクス「高頻度 × 攻める」→ **CBet 75%**。

### 例2: ドライボード、CBet を受けた側（OOP）

同ボード K♠7♦2♣、相手が 50% CBet。
ハンド: K♥T♦（トップペア弱キッカー）
ポジション: OOP（BB）

役割 = OOP のトップペアは **ショーダウンバリュー**（OOP では守る相当）。判断表「ショーダウンバリュー × 50%」→ **コール**。

### 例3: ウェットボード、セット（OOP）

ボード: T♥9♦8♣（ウェット、低頻度）、相手が 75% CBet。
ハンド: 8♠8♦（セット）

役割 = セットは **攻める**。判断表「攻める × 75%」→ **CR またはコール**。ポット構造次第で CR を優先します。

## ミニクイズ

### 問1

ボード: A♣9♦2♥（ドライ）、HU、相手が 75% CBet。自分のハンドは J♠J♦（オーバーペア）、OOP です。役割とアクションを選んでください。

1. 役割 = 攻める → CR 検討
2. 役割 = ショーダウンバリュー → コール
3. 役割 = 捨てる → フォールド
4. 役割 = 守る → フォールド

### 問2

ボード: T♥9♠8♦（ウェット）、簡易レンジスコアは低頻度帯。ハンド QQ（オーバーペア）を持つ CBet 側の IP のアクションを選んでください。

1. CBet 75%
2. CBet 50%
3. CBet 33%
4. チェック

---

### 解答

- **問1**: 正解は **2**（オーバーペアは FD なしのため「ショーダウンバリュー」。OOP のショーダウンバリューは守る相当で、判断表「ショーダウンバリュー × 75%」→ コール）

- **問2**: 正解は **2**（T♥9♠8♦ は 3 枚連続コネクター → 低頻度帯。QQ はオーバーペアで役割 = ショーダウンバリュー。IP のショーダウンバリューは攻める列として機能するため「低頻度 × 攻める → CBet 50%」。ウェットボードで強いハンドは中サイズでバリューとプロテクションを両立します）

## 本章まとめ

- ハンドは「攻める / ショーダウンバリュー / 守る / 捨てる」4 役割に直接マッピングする
- ショーダウンバリュー（トップペア・オーバーペア）: IP ではベット、OOP ではコール
- 防御側: 役割 × ベットサイズ判断表で CR / コール / フォールドを決める
- 攻撃側: 簡易レンジスコアの頻度帯 × 役割の 9 マスマトリクスで CBet を決める
- 9 マスマトリクスの横軸は「攻める / 守る / 捨てる」3 列。ショーダウンバリューは IP → 攻める列、OOP → 守る列として機能する
- ドライボード（高頻度）では捨てる手も 33% でレンジベット
- 詳細は巻② 第9・10・13章で扱う
