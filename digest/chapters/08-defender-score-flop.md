# 第8章　後手スコア（フロップ版）+ 9マスマトリクス

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 相手の CBet に対してコール/チェックレイズ/フォールドを後手スコアの式で一本化し、9マスマトリクスで攻撃側の判断も統合できるようになる

---

## 8-1 「折りすぎ」と「折らなさすぎ」の均衡点

相手が CBet を打ってきたとき、「手が弱いからフォールド」という判断を繰り返していると、相手はブラフを打ち続けるだけで利益を得ます。逆に何でもコールしていると、バリューベットに対して必要以上のチップを失います。

この均衡点を与えるのが後手スコアです。後手スコアはハンドの強さ（HandScore）、ボードの性質（A 係数）、ベットの重さ（C 係数）、参加人数（M 係数）を一本の式に収め、コール/チェックレイズ/フォールドを数値で判断します。

---

## 8-2 後手スコアの式

```
HU（ヘッズアップ）:
  後手スコア = HandScore + A − 3 − C

全般（マルチウェイ含む）:
  後手スコア = HandScore + A − 3 − C − M
```

HU 前提で M=0 を省略する場合は、必ず「HU 前提のため M=0」と意識してください。

### 係数の意味と値

**A（ボード値 / ドライ度）**: 第6章で求めた簡易レンジスコアのボード分類が A 係数に変換されます。

| ボード分類 | A 値 |
|---|---|
| ドライ | 3 |
| セミ | 2 |
| ウェット | 1 |

**C（ベット負担）**: 相手のベットサイズが大きいほど C 値が大きく、守りにくくなります。

| ベットサイズ | C 値 |
|---|---|
| 33% pot | 3 |
| 50% pot | 5 |
| 75% pot | 7 |

**M（マルチウェイ補正係数）**: 参加人数が増えるほど、チェックレイズが通りにくくなります。

| 状況 | M 値 |
|---|---|
| HU（ヘッズアップ） | 0 |
| 3-way | 3 |
| 4-way 以上 | 6 |

### 判定基準

| 後手スコア | 判断 |
|---|---|
| **≥ 8** | チェックレイズ（CR）を検討 |
| **0〜7** | コール |
| **< 0** | フォールド |

---

## 8-3 計算例 3 つ

### 例1: ドライボード、33% CBet、TPTK（HU）

ボード: K♠7♦2♣（ドライ, A=3）  
ベット: 33% pot（C=3）  
ハンド: A♣K♦（TPTK, HandScore=18）  

```
後手スコア = 18 + 3 − 3 − 3 = 15 → チェックレイズ検討
```

ドライボードで TPTK は後手スコアが高く、CR を検討できる水準です。33% の小ベットに対して強いハンドで CR を打てば、相手のブラフを損させながらポットを拡大できます。

### 例2: ウェットボード、75% CBet、セカンドペア（HU）

ボード: T♥9♦8♣（ウェット, A=1）  
ベット: 75% pot（C=7）  
ハンド: 8♠8♦（セット、HandScore=30）  

※ T♥9♦8♣ で 8♠8♦ を持つ場合、ボードに 8 が 1 枚あるため 8♠8♦ はトリップス（ボードの 8 + ハンドの 2 枚）ではなく、ハンドの 8♠8♦ + ボードの 8♥ = セット（3 枚の 8）になります。HandScore = 30。

```
後手スコア = 30 + 1 − 3 − 7 = 21 → チェックレイズ検討
```

ウェットボードで 75% の大ベットを受けてもセットなら後手スコアは高水準です。ただし T♥9♦8♣ は相手がストレートを持っている場合もあり、バックドアリスクを意識します。

### 例3: セミウェットボード、50% CBet、セカンドペア（HU）

ボード: K♠J♦7♣（セミウェット, A=2）  
ベット: 50% pot（C=5）  
ハンド: J♥T♦（セカンドペア・キッカー T = J 以下なので弱キッカー + BDFD、HandScore = 3 + 4 = 7）  

```
後手スコア = 7 + 2 − 3 − 5 = 1 → コール（境界）
```

セカンドペア・弱キッカー + BDFD でも、A=2 と BDFD 加点でかろうじてコール境界。50% ベットの MDF を埋めるためにコール候補。

---

## 8-4 9マスマトリクス ─ 攻撃側の統合判定

後手スコアが防御側の式なのに対し、攻撃側（CBet を打つ側）の判断は**9マスマトリクス**で整理されます。

マトリクスの 2 軸は次のとおりです。

- 横軸: ハンド強度（H3 / H2 / H1）
- 縦軸: 簡易レンジスコアの CBet 頻度帯（高頻度 / 中頻度 / 低頻度）

### H3 / H2 / H1 の分類

| バケツ | HandScore | 典型例 |
|---|---|---|
| H3（強） | ≥ 14 | TPTK(18)、OP(20)、セット(30)、TPGK(15)、2 ペア(18)、**OESD 単独(14)**、FD+OESD(17) |
| H2（中） | 7〜13 | TPMK(8)、セカンドペア強(9)、FD 単独(13)、ガットショット(10)、アンダーペア(6) |
| H1（弱） | < 7 | **TPWK(6)**、ボトムペア(4)、セカンドペア弱(3)、空振り(0) |

### 簡易レンジスコアの頻度帯

| 頻度帯 | スコア | CBet 頻度目安 |
|---|---|---|
| 高頻度 | 7〜10（ドライ） | 約 70〜90% |
| 中頻度 | 4〜6（セミ） | 約 40〜69% |
| 低頻度 | 0〜3（ウェット） | 約 40% 未満 |

### 9マスマトリクス

|  | H3（強 ≥14） | H2（中 7-13） | H1（弱 <7） |
|---|---|---|---|
| **高頻度**（ドライ） | CBet 75% | CBet 33% | CBet 33%（レンジベット） |
| **中頻度**（セミ） | CBet 50% | CBet 33% | チェック |
| **低頻度**（ウェット） | CBet 50% | チェック | チェック |

### レンジベットの読み方

ドライボード（高頻度）では、H1 の弱いハンドも 33% でベットします。これを「レンジベット」と呼びます。ドライボードは攻撃側が全レンジで優位を持つため、弱いハンドもブラフとして押すことで相手のチェック後の攻撃を封じます。

詳細は巻② 第10章・第13章で扱います。

---

## 8-5 先手スコアとの関係

9マスマトリクスのうち「H1 をレンジベットするかどうか」の境界は、**先手スコア**でも確認できます。

```
先手スコア = HandScore + A − M

判定:
  ≥ 7 → ベット推奨
  < 7 → チェックバック
```

K72r（A=3）でアンダーペア HandScore=6 の場合:  
先手スコア = 6 + 3 = 9 ≥ 7 → ベット（レンジベット成立）

T98r（A=1）で空振り HandScore=0 の場合:  
先手スコア = 0 + 1 = 1 < 7 → チェック

先手スコアは 9マスマトリクスの「高頻度 × H1 → レンジベット」の境界を連続値で与えます。

## ミニクイズ

### 問1

ボード: A♣9♦2♥（ドライ, A=3）、HU、相手が 75% CBet（C=7）。自分のハンドは J♠J♦（オーバーペア, HandScore=20）です。後手スコアを計算して正しいアクションを選んでください（HU 前提のため M=0）。

1. 後手スコア = 13 → コール
2. 後手スコア = 13 → チェックレイズ
3. 後手スコア = 8 → コール
4. 後手スコア = 8 → チェックレイズ

### 問2

ボード: T♥9♠8♦（ウェット, A=1）、HU、相手が 50% CBet（C=5）。9マスマトリクスで QQ（HandScore=20, H3）のアクションを選んでください。

1. CBet 75%
2. CBet 50%
3. CBet 33%
4. チェック

---

### 解答

- **問1**: 正解は **2**（後手スコア = 13 → チェックレイズ）
  後手スコア = 20 + 3 − 3 − 7 = **13**。13 ≥ 8 なのでチェックレイズ検討です。A♣9♦2♥ のドライボードで JJ はオーバーペアとして強く、75% の大ベットに対してもチェックレイズを検討できる水準にあります。

- **問2**: 正解は **2**（CBet 50%）
  T♥9♠8♦ は 3 枚連続 + レインボー → 簡易レンジスコアはストレート要素 −5、フラッシュ要素 0 → スコア約 5 → 中頻度帯（セミ）。QQ は HandScore=20 で H3。マトリクスの「中頻度 × H3 → CBet 50%」が対応します。ウェットボードで強いハンドは中サイズでバリューとプロテクションを両立します。

---

## 本章まとめ

- 後手スコア = HandScore + A − 3 − C − M（HU では M=0）
- 係数: A（ドライ=3/セミ=2/ウェット=1）、C（33%=3/50%=5/75%=7）、M（HU=0/3-way=3/4-way+=6）
- 判定: ≥8 → CR 検討 / 0〜7 → コール / < 0 → フォールド
- 9マスマトリクスは簡易レンジスコアの頻度帯（高/中/低）と HandScore 強度（H3/H2/H1）の 3×3 表
- ドライボード（高頻度）では H1 の弱いハンドも 33% でレンジベット
- 詳細は巻② 第10章（マトリクス）・第13章（後手スコア）・第16章（マルチウェイ）で扱う
