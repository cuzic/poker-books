# 第6章　簡易レンジスコア ─ フロップ CBet 頻度予測

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: フロップのボードを見た瞬間に、攻撃側がレンジ全体の何%をベットするかを 0〜10 の数値で予測できるようになる

---

## 6-1 「ドライ度」ではなく「CBet 頻度の予測値」

フロップを見たとき、多くの人は「このボードはドライかウェットか」と考えます。しかし「ドライ」「ウェット」は感覚的な二項分類であり、どのくらいの頻度でベットすべきかを数値で示しません。

簡易レンジスコアは、この問いに対して数値で答えるモデルです。「このフロップで、攻撃側はレンジ全体の何%をベットするか」という CBet 頻度を 0〜10 の整数で予測します。

重要な点は、簡易レンジスコアは**ボードの属性スコアではなく、攻撃側の CBet 行動の予測値**であるということです。同じドライボードでも、ハイボードとローボードでは CBet 頻度が異なります。この差を吸収するため、簡易レンジスコアはストレート要素、フラッシュ要素、ハイボードリスクという 3 つの入力から CBet 頻度を計算します。

詳細なモデルは巻② 第8章で扱います。本章ではエッセンスを把握してください。

---

## 6-2 3 つの入力と計算の流れ

```
簡易レンジスコア = 10 − ストレート要素 − フラッシュ要素 − ハイボードリスク
```

3 つの減算項目が「CBet 頻度を下げる理由」を表します。ストレートやフラッシュの可能性が高いほど、相手のコールが正当化される手が増えるため、攻撃側はベット頻度を絞ります。

### ストレート要素（減算値）

| 条件 | 減算値 |
|---|---|
| 3 枚連続（例: 987, T98） | −5 |
| 2 枚 + 1 ギャップ以内（例: JT8, 976） | −3 |
| 1 ギャップのみ（例: J9, T8 など） | −2 |
| ストレート要素なし | 0 |

### フラッシュ要素（減算値）

| 条件 | 減算値 |
|---|---|
| 3 枚同スート（モノトーン） | −5 |
| 2 枚同スート（2-tone） | −2 |
| レインボー | 0 |

### ハイボードリスク（減算値）

| 条件 | 減算値 |
|---|---|
| Broadway カード 2 枚以上（A/K/Q/J/T の組み合わせ） | −1 |
| ペアボード | +1（加算） |

### 出力スコアとボード分類

| 簡易レンジスコア | ボード分類 | A 係数 | CBet 頻度目安 |
|---|---|---|---|
| 7〜10 | ドライ | 12 | 高頻度（約 70〜90%） |
| 4〜6 | セミ | 6 | 中頻度（約 40〜69%） |
| 0〜3 | ウェット | 0 | 低頻度（約 40% 未満） |

この A 係数が、後手スコアや先手スコアに間接的に入力されます。**簡易レンジスコアの値そのものを後手スコアや先手スコアに直接加算するのではありません**。あくまでボードをドライ/セミ/ウェットに分類するための道具であり、その分類結果が A 係数として下流の式へ流れます。

---

## 6-3 計算例 3 つ

### 例1: A♣9♦2♣（A92r、ドライ）

- ストレート要素: A と 9 の差が 7、9 と 2 の差が 7 → 連続なし → **0**
- フラッシュ要素: レインボー → **0**
- ハイボードリスク: Broadway は A のみ（1 枚）→ 2 枚未満 → **0**

```
簡易レンジスコア = 10 − 0 − 0 − 0 = 10 → ドライ（A=12）
```

A ハイのレインボードライボードは攻撃側がレンジ全体を高頻度でベットします。A 係数は 12。相手が A にヒットできるのは一部のハンドに限られ、攻撃側は大きなアドバンテージを持ちます。

### 例2: J♣8♦5♣（J85ss、セミウェット）

- ストレート要素: J−8 の差が 3、8−5 の差が 3 → ギャップが大きく 3 枚連続ではない → **−2**（1 ギャップ相当）
- フラッシュ要素: クラブ 2 枚（2-tone）→ **−2**
- ハイボードリスク: Broadway は J のみ（1 枚）→ **0**

```
簡易レンジスコア = 10 − 2 − 2 − 0 = 6 → セミ（A=6）
```

J85ss はフラッシュドローと一定のストレート可能性を含みます。A 係数は 6。守備側がドロー系ハンドを多く持てるため、攻撃側はベット頻度を絞ります。

### 例3: T♠9♠8♦（T98ss、ウェット）

- ストレート要素: 3 枚連続（T−9−8、差が 2 以内）→ **−5**
- フラッシュ要素: スペード 2 枚（2-tone）→ **−2**
- ハイボードリスク: Broadway カードは T（1 枚）→ **0**

```
簡易レンジスコア = 10 − 5 − 2 − 0 = 3 → ウェット（A=0）
```

T98ss は CBet 頻度が最も下がるクラスのボードです。ストレートとフラッシュが同時に刺さるため、守備側が有利なレンジを持ちます。A 係数は 0。

## 6-4 「直接加算しない」という注意点

簡易レンジスコアを学んだ後によくある誤解は、「HandScore と簡易レンジスコアを足し算して判断する」という思い込みです。これは誤りです。

正しい流れは次の通りです。

```
簡易レンジスコア（0〜10）
      ↓ 分類
ドライ / セミ / ウェット
      ↓ A 係数に変換（ドライ=12 / セミ=6 / ウェット=0）
      ↓
後手スコア = HandScore + A − C − M
先手スコア = HandScore + A − M
```

簡易レンジスコアは「ボード分類のゲートウェイ」です。最終的な判断式には A 係数として姿を変えて入ります。

詳細な式の使い方は、第7章（HandScore）と第8章（後手スコア）で示します。

## ミニクイズ

### 問1

K♥7♦2♣（K72r）の簡易レンジスコアを計算し、ボード分類（ドライ/セミ/ウェット）と A 係数を答えてください。

1. 簡易レンジスコア = 10、ドライ、A=12
2. 簡易レンジスコア = 6、セミ、A=6
3. 簡易レンジスコア = 5、セミ、A=6
4. 簡易レンジスコア = 3、ウェット、A=0

### 問2

次の文のうち、簡易レンジスコアの役割として正しいものはどれですか。

1. HandScore に直接加算して CBet の可否を判断する
2. ボードをドライ/セミ/ウェットに分類し、A 係数として後手スコアや先手スコアに間接的に入力される
3. リバーのベットサイズを決める係数として使う
4. プレイヤーのレンジの強さを 0〜10 で評価する

---

### 解答

- **問1**: 正解は **1**（簡易レンジスコア = 10、ドライ、A=12）
  K72r は 3 枚のランク差が大きく（K−7=6、7−2=5）ストレート要素なし（0）、レインボーでフラッシュ要素なし（0）、Broadway は K 1 枚のみでハイボードリスク 0。計算: 10 − 0 − 0 − 0 = 10 → ドライ帯（A=12）。K ハイのドライボードは攻撃側が高頻度でベットできる代表ボードです。
- **問2**: 正解は **2**
  簡易レンジスコアは分類モデルであり、A 係数への変換を経て下流式に入ります。HandScore への直接加算は誤りです。

## 本章まとめ

- 簡易レンジスコアは「フロップのレンジ全体の CBet 頻度を 0〜10 で予測するマクロモデル」
- 入力はストレート要素・フラッシュ要素・ハイボードリスクの 3 つ
- 出力スコアはドライ（A=12）/ セミ（A=6）/ ウェット（A=0）に変換され、A 係数として下流式へ入る
- 簡易レンジスコアを HandScore に直接加算するのは誤り
- 精密化モデルは巻③ 第1章（精密レンジスコア）で扱う
