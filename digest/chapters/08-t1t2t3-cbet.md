# 第8章　T1/T2/T3 ─ フロップ攻守判断の3ルール

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: T1/T2/T3 ティア判定から CBet 判断・サイズ選択・OOP フォールド閾値まで、フロップの攻守を一連のフローとして暗算で回せるようになる

---

## 8-1 ティアシステムの全体像

前章で計算した HandScore（HS）を 3 段階に分類したものが「T1/T2/T3 ティアシステム」です。

```
T1：HS ≥ 65　→　強いメイドハンド（常時 CBet）
T2：HS ≥ 20　→　ミドルハンド（ボードスコア B で判断）
T3：HS < 20　→　弱い手・ブラフ候補（乾燥ボード限定で CBet）
```

HS の代表値と対応するティアを確認しておきましょう。

| ハンド例 | HS の目安 | ティア |
|---|---|---|
| セット | 85 | T1 |
| AA/KK（オーバーペア） | 80 | T1 |
| TPTK（トップペア最良キッカー） | 65 | T1 |
| TPGK（トップペア良キッカー） | 60 | T2 |
| TPMK（トップペア中キッカー） | 55 | T2 |
| A-high + 2OC ボーナス | 49 | T2 |
| TPWK（トップペア弱キッカー） | 45 | T2 |
| A-high エアー（2OC なし） | 25 | T2 |
| K-high エアー | 15〜20 | T2/T3 境界 |
| エアー + BDFD のみ | 16 | T3 |
| 完全なエアー | 10 | T3 |

T2 の下限を 20 に設定している点が重要です。これにより、A-high エアーや「ボード上の全カードを上回る 2 オーバーカード（2OC ボーナス: +24）」を持つハンドが正しく T2 に分類されます。旧来の H2 下限（35）では A-high 2OC ハンドを「弱手」として扱っていましたが、GTO データはこれらが高頻度で CBet していることを示しており、T2 下限 20 によってその実態に近づけています。

---

## 8-2 CBet 判断フロー ─ T1/T2/T3 × B 閾値

フロップの IP（インポジション）CBet を決める 2 ステップフローです。

```
STEP 1: HS を計算 → ティア決定
  HS ≥ 65  → T1：CBet 確定（STEP 2 をスキップ）
  HS ≥ 20  → T2：STEP 2 へ
  HS < 20  → T3：STEP 2 へ

STEP 2: ボードスコア B を確認
  T2 かつ B ≥ 58 → CBet
  T2 かつ B < 58 → チェック
  T3 かつ B ≥ 62 → CBet（乾燥ボード限定ブラフ）
  T3 かつ B < 62 → チェック
```

### ボードスコア B の代表値

ボードスコア B は第6章で扱ったボード属性の数値化です（詳細は巻② 第1章）。

| ボードテクスチャ | B 値 | T2 CBet? | T3 CBet? |
|---|---|---|---|
| paired_high（KK7 など） | 83 | ベット | ベット |
| モノトーン（全同スート） | 70 | ベット | ベット |
| rainbow_connected（987r など） | 67 | ベット | ベット |
| rainbow_ak（K72r など） | 62 | ベット | ベット（ちょうど境界） |
| rainbow_q（Q53r など） | 58 | ベット（境界） | チェック |
| rainbow（J84r など） | 55 | チェック | チェック |
| 2tone（Jh7h2c など） | 50 | チェック | チェック |

T1 はどのボードでも常時 CBet です。T2 がチェックになるのは「rainbow（B=55）」と「2tone（B=50）」の 2 テクスチャだけです。T3 がベットできるのはさらに絞られ、B ≥ 62 の乾燥ボードのみになります。

### 各ティアの意味

**T1（常時 CBet）**: HS ≥ 65 はすべてのボードでエクイティ優位を持ちます。チェックバックすると相手に無料でターンを見せることになり、エクイティを損ないます。GTO 実測でも T1 の CBet 率は 90% 超です。

**T2（B ≥ 58 でベット）**: 単独では CBet を正当化できませんが、ボードが乾燥していれば相手がコールしにくくなるため CBet が成立します。T2 が「レインボー J 以下」と「2トーン」でチェックするのは、これらのボードで OOP の守備レンジが広く残り、ブラフの採算が合わないためです。

**T3（B ≥ 62 でブラフ）**: 33% ベット時のフォールド要求率は 25% です。rainbow_ak（K-high 乾燥ボード）では OOP のフォールド率が実測で約 46% に達するため、T3 ブラフが十分に成立します。一方、2tone や rainbow（B < 62）では OOP がドローやエクイティを保持しやすく、ブラフが機能しません。

## 8-3 CBet サイズ選択

CBet を打つと決まったら、次はサイズを選びます（詳細は巻② 第5章）。

```
CBet サイズルール（ボードテクスチャ基準）:
  paired_high（B=83）: 50%
  モノトーン（B=70）:  75%
  その他のボード:      33%
```

**なぜ 3 分類か**: GTO 実測（44 シナリオ）で全体の 69% が 33% を選択しています。ドライボードは「レンジベット（全ハンドでベット）」戦略のため、全レンジをバランスよく混ぜやすい小サイズが最適です。

**paired_high で 50%**: ペアボードは OOP に強いハンド（Kx など）が当たる可能性があり、大サイズで押しすぎるとナッツで返されるリスクがあります。50% が均衡に近い選択です。

**モノトーンで 75%**: 全同スートのボードでは OOP がフラッシュドロー（9アウツ、勝率約 36%）を多数保有します。33% の小サイズではドローに有利なポットオッズを与えすぎるため、75% で高コストを強いる必要があります。

### ベットサイズとポット変化の早見表

SRP（シングルレイズドポット：pot=6bb、stack=97bb）での計算です。

| サイズ | ベット額 | コール後のポット | SPR（スタック/ポット） |
|---|---|---|---|
| 33% | 2bb | 10bb | 9.6 |
| 50% | 3bb | 12bb | 7.8 |
| 75% | 4.5bb | 15bb | 6.1 |

SPR が小さいほどターン以降のコミット感が増します。75% CBet 後は SPR=6.1 となり、続くバレルが「コミット宣言」に近づきます。

## 8-4 OOP 防御フロー ─ フォールド閾値

攻撃側（IP）が CBet を打ってきたとき、防御側（OOP）はどこでフォールドすべきでしょうか。

```
フォールド閾値（ベースライン）:
  vs 33%: HS < 15 でフォールド
  vs 75%: HS < 35 でフォールド

ボードテクスチャ補正（閾値に加算）:
  2tone:        +5（ドローが多く守りやすい）
  モノトーン:   −5（フラッシュ完成を恐れてフォールドしやすい）
  paired_high: −10（トリップスを恐れて守備しにくい）
```

**補正の読み方**: 2tone では閾値が上がる（= より強い手でないとコールできない）、paired_high では閾値が下がる（= 少し弱い手でもコールできる）と感じるかもしれませんが、逆です。閾値は「この未満ならフォールド」のラインです。

- vs75%・2tone: 35 + 5 = 40 → HS < 40 でフォールド（2tone ではドローがあるのでコール圏が広がる）
- vs75%・paired_high: 35 − 10 = 25 → HS < 25 でフォールド（ペアボードはナッツが強烈なので基準を緩める）
- vs33%・モノトーン: 15 − 5 = 10 → HS < 10 でフォールド

### フォールド閾値テーブル（代表的な組み合わせ）

| ベットサイズ | ボード | 閾値（この未満でフォールド） |
|---|---|---|
| 33% | rainbow（B=55、標準） | HS < 15 |
| 33% | 2tone（B=50） | HS < 20 |
| 33% | モノトーン（B=70） | HS < 10 |
| 33% | paired_high（B=83） | HS < 5 |
| 75% | rainbow（B=55、標準） | HS < 35 |
| 75% | 2tone（B=50） | HS < 40 |
| 75% | モノトーン（B=70） | HS < 30 |
| 75% | paired_high（B=83） | HS < 25 |

閾値以上の HS でコールまたはチェックレイズを選びます。チェックレイズの判断基準は次節の C 値で扱います。

---

## 8-5 C 値 ─ ブラフ収益性の判断

C 値は「このベットサイズが相手に要求するフォールドの度合い」を HS スケールに乗せた指標です（詳細は巻② 第7章）。

```
C 値の定義:
  α（ブラフの要求フォールド率）= bet ÷ (pot + bet)
  C = α × 50

代表値（実戦で暗記する 3 点）:
  33% ベット → α = 0.25 → C = 12
  50% ベット → α = 0.33 → C = 17
  75% ベット → α = 0.43 → C = 22
```

**C 値の使い方**: C 値を「相手のレンジでフォールドさせられる HS 水準」と比べます。相手の平均 HS が C 値を下回っていれば、ブラフが収益的です。

乾燥 K-high ボード（K72r）では OOP の多くのハンドが HS < 12 に集中します。C=12 の 33% ベットを打てば、相手の大半がフォールドするためブラフが成立します。これが T3 のドライボード限定ブラフを許容する理由です。

**SPR 別チェックレイズ（CR）判断閾値**:

```
SPR ≥ 6 （SRP 標準フロップ）: HS ≥ 40 で CR 検討
SPR 3〜5（3ベットポット後）: HS ≥ 60 で CR 検討
SPR < 3 （極短スタック）:     HS ≥ 75 で CR 検討
```

SRP 標準フロップの SPR は pot=6bb・stack=97bb から約 16 です（≥ 6 のカテゴリ）。

## 8-6 統合例題 ─ HS=60、B=62 のケース

**状況**: BTN vs BB の SRP（pot=6bb）。あなたは IP（BTN）。ボードは K♠7♦2♣（rainbow_ak、B=62）。ハンドは K♦Q♠（TPGK）。

**ステップ1 ─ HS 計算**

K でトップペアを形成し、キッカーは Q（グッドキッカー）です。HS = 60（TPGK）となります。ドロー加点・ブロッカー加点は今回なしとします。

**ステップ2 ─ ティア判定**

HS = 60 は T2 の範囲（20 ≤ 60 < 65）です。T1 の閾値（65）には届きません。

**ステップ3 ─ B との比較**

B = 62 ≥ 58 なので、T2 の CBet 条件を満たします。→ **CBet 確定**。

**ステップ4 ─ サイズ選択**

B=62 は paired_high でもモノトーンでもありません。→ **33% を選択**（bet=2bb、コール後ポット=10bb）。

**まとめ**: K♦Q♠ on K♠7♦2♣ → T2、B ≥ 58 → CBet 33%。

---

### 追加例: HS=40、B=62 のケース

**ハンド**: 7♥7♠（セカンドペア）。HS = 約 40（セカンドペア）。ティアは T2（40 ≥ 20）。B = 62 ≥ 58 → **CBet 33%**。

**参考: 同ハンドで B=55（J84r）ならどうなるか**: B = 55 < 58 → T2 の条件を満たさない → **チェック**。

## ミニクイズ

### 問1

BTN vs BB の SRP。あなたは IP（BTN）でハンドは A♣J♦、ボードは K♠8♦3♣（rainbow、B=62）です。

HS = 25（A-high）。2OC ボーナスは A > K が成立しますが J < K のため 2OC 不成立。HS = 25 のままです。

ティアと CBet 判断として正しいのはどれですか。

1. T2（HS=25 ≥ 20）、B=62 ≥ 58 なので CBet
2. T3（HS=25 < 20）、B=62 ≥ 62 なので CBet
3. T2（HS=25 ≥ 20）、B=62 < 58 なのでチェック
4. T1（HS=25 ≥ 20）なので常時 CBet

### 問2

あなたは OOP（BB）でハンドは A♠K♦（TPTK）、ボードは K♥9♥3♠（2tone、B=50）。IP が 75% CBet を打ちました。

HS = 65（TPTK）、フォールド閾値は何点ですか。また BB のアクションは何ですか。

1. 閾値 = 40（75% 基本 35 + 2tone +5）。HS=65 ≥ 40 なのでコールまたは CR
2. 閾値 = 35（75% 基本、補正なし）。HS=65 ≥ 35 なのでコールまたは CR
3. 閾値 = 30（75% 基本 35 − モノトーン補正 −5）。HS=65 ≥ 30 なのでコール

---

### 解答

**問1**: **1 が正解**（A♣J♦ on K♠8♦3♣ は A-high のエアーで HS = 25。2OC ボーナスは両手札がボードの最高位カード（K=13）を超える必要があります。A（14）> K は成立しますが J（11）< K（13）なので 2OC 不成立。HS = 25 → T2。B = 62 ≥ 58 → CBet が正解です）

**問2**: **1 が正解**（75% ベット基本閾値 35 + 2tone 補正 +5 = 40。HS = 65 ≥ 40 なのでフォールドしません。TPTK の HS=65 は T1 相当の強さですから、コールまたはチェックレイズが選択肢です。SPR≈16 のため CR 閾値は HS ≥ 40 を満たしており、CR も十分に検討できます）

## GTOとのズレ

本章のティアシステムは GTO の CBet 判断と約 90% の整合性を持ちます。ただし、境界付近のハンド（HS ≈ 65 の T1/T2 境界や HS ≈ 20 の T2/T3 境界）では GTO が「混合戦略（50% CBet など）」を取ることがあり、2 択に丸めた場合に最大 20〜30% の頻度ズレが生じます。

OOP フォールド閾値は、ボードとハンドの具体的な組み合わせで数%〜10% の誤差があります。特に IP がレンジ CBet をする乾燥 A/K-high ボードでは、GTO が HS の低いハンドにも少量のコールを混ぜてレンジバランスを保ちます。閾値テーブルは「大枠で正しい、細部はソルバーで確認」という使い方が最適です。

---

## 本章まとめ

- **T1（HS ≥ 65）**: 全ボードで常時 CBet。ポジション・テクスチャを問わない
- **T2（HS ≥ 20）**: B ≥ 58 なら CBet、B < 58（rainbow・2tone）はチェック
- **T3（HS < 20）**: B ≥ 62 の乾燥ボード限定でブラフ CBet。要求フォールド率 25% が余裕を持って満たされる
- **CBet サイズ**: paired_high → 50%、モノトーン → 75%、その他 → 33%
- **OOP フォールド閾値**: vs33%→HS<15 / vs75%→HS<35（2tone +5、モノトーン −5、paired_high −10 で補正）
- **C 値（ブラフ収益）**: 33%→C=12 / 50%→C=17 / 75%→C=22。SPR≥6 の CR 閾値は HS≥40

詳細は **巻② 第3・4・5・6・7章** で体系的に扱います。本書では「攻守フローの全体像」を示すことを目的としています。
