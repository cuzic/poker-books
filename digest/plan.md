# 迷わないポーカー ダイジェスト 詳細プラン

## 本書の位置づけ

『迷わないポーカー』シリーズ全6巻（約130万字）の暗算式エッセンスを **1 冊 70,000字** に圧縮した中級入門書。

```
シリーズ構成
├── 巻1 プリフロップ                     (約 18 万字、20章)
├── 巻2 フロップ[基礎]                   (約 22 万字、21章)
├── 巻3 フロップ[応用]                   (約 13 万字、19章)
├── 巻4 ターン・リバー[基礎]              (約 20 万字、20章)
├── 巻5 ターン・リバー[応用]              (約 29 万字、20章)
├── 巻6 トーナメント                     (約 28 万字、25章)
└── ダイジェスト版 (本書)                (約 7 万字、21章、5% に圧縮)
```

## 想定読者

- ポーカーのルール・役・ポジション・ベッティング基礎を **知っている** 中級志向
- 「アウツ」「ポットオッズ」「レンジ」程度の言葉は知っているが体系化されていない
- シリーズ全体を 1 冊で把握したい
- 自分に必要な巻を選びたい
- 既読者の復習リファレンス

**完全初心者向けではない**。基本ルールから始めたい方は、まず巻1（プリフロップ）から。

## 本書の役割

1. **シリーズの地図**: 全6巻を 1 冊で見渡せる
2. **中級入門書**: 体系化されていない知識を 70,000 字で整理
3. **既読者の復習**: 全暗算式の早見集
4. **巻別購入の入り口**: 興味を持った巻へ誘導

## 凝縮の方針

各章は次の制約で書く:
- 字数の **70-80%** を「式・係数・判定基準」に使う
- 残りを **1-2 個の代表例 + 元巻への誘導**
- 詳しい導出・実例多数は **元巻に譲る**
- 暗算式そのものは **省略せず厳密に**（係数・判定基準まで）
