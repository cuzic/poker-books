# 巻④「迷わないポーカー④ ターン・リバー[基礎]」詳細プラン

## 本書の位置づけ

シリーズ第④巻、ターン・リバー基礎編。巻①-③ でフロップ判断の土台を築いた読者を対象に、ポストフロップ最終2ストリート（ターン・リバー）の基本概念と4つの暗算式を体系化する。

```
巻① プリフロップ                  ─ Score
巻② フロップ[基礎]                 ─ 簡易レンジスコア / HandScore / 後手スコア（フロップ版）
巻③ フロップ[応用]                 ─ 精密レンジスコア
巻④ ターン・リバー[基礎] (本書)     ─ バレルスコア / α 式 / 後手スコア（ターン版・リバー版）
巻⑤ ターン・リバー[応用]            ─ 3軸統合 / backward induction / 高度戦術
巻⑥ トーナメント                   ─ ICM equity / ICM 補正 / M 値
```

## 本書の4つの核心式

### 1. バレルスコア（ターン攻撃）

```
バレルスコア = FlopType係数 + TurnCard係数
```

ダブルバレルの推奨度を 0〜12 で数値化。フロップのボード分類とターンカード種類から即座に計算。

### 2. α 式（リバー配分）

```
α = ベット ÷ (ポット + ベット)
後手下限確率 = 1 − α
```

リバーでバリューとブラフの最適比率を決める式。

### 3. 後手スコア（ターン版）

```
後手スコア = HandScore + A − 3 − C − M
```

巻② で確立した式の骨格をターンに適用。ドロー加点が生きる。

### 4. 後手スコア（リバー版）

```
後手スコア = HandScore + A − 3 − C − M
```

リバー版は C 拡張（100%=9、150%=11）を含む。
