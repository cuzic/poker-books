# 第7章　ハンドの3層分類（バリュー / ブラフ候補 / チェック）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: リバーに到達した自分のハンドを「バリュー / ブラフ候補 / チェック」の3層に素早く分類する判断軸を習得し、攻撃側（先手）と守備側（後手）の両方で使えるようにする。

---

## 5-1 リバーでの分類は「今」が全て

第4章でレンジ遷移を追跡し、リバー直前の相手レンジを推定する方法を学びました。本章では、その推定結果を前提に「自分のハンドをどの役割に振り分けるか」を体系化します。

ターンまでのハンド評価には「将来価値」が含まれていました。フラッシュドローはまだ完成するかもしれず、ストレートドローはあと1枚で完成します。この将来価値がハンドの現在価値に上乗せされるため、評価が複雑になります。

リバーではこの将来価値が消えます。

```
ターン: ハンドの現在価値 + 将来価値（ドロー成分）
リバー: ハンドの現在価値のみ
```

「現在価値のみ」というシンプルな状況だからこそ、ハンドの役割分類が明確になります。バリューとして機能するか、ブラフとして機能するか、それともチェックが正解か。この3つの選択肢にハンドを振り分けることが、リバーでの攻撃側の中心的な仕事です。

---

## 5-2 3層の定義

### 層1: バリュー（コールされて勝てる）

相手のコールレンジに対して、高い頻度で勝てるハンドです。ベットしたとき、相手がコールしてきても自分が勝ち越せます。

バリューの必要条件は「相手のコールレンジに対して50%以上の確率で勝てること」です。この基準を50%の法則と呼びます。50%を上回れば、コールを求めるたびに期待値が生まれます。50%を下回ると、コールしてくる相手のほうが勝ちやすく、自分のベットが損失になります。

```
バリューの3サブレイヤー:

強バリュー: コールレンジに対して70%以上で勝てる
  → 相手のコールレンジのほぼ全域に勝てる
  → 大きなサイズ（75%〜100%pot 以上）が適切

標準バリュー: コールレンジに対して55〜70%程度で勝てる
  → 相手のコールレンジの半数強に勝てる
  → 標準サイズ（33%〜50%pot）が適切

薄バリュー: コールレンジに対して50〜55%前後の境界
  → 50%の法則をギリギリ上回る程度
  → 小さなサイズ（33%以下）、またはチェックバックとの二択
```

50%の法則は **コールレンジに対する勝率** であって、「相手がどのハンドを持っているか」という特定個別の話ではありません。相手がコールしてくるハンドの集合全体に対して、自分が勝ちと負けを足したときにプラスになれるかどうかが基準です。

### 層2: ブラフ候補（コールで負けるが、フォールドで利益）

コールされると高い確率で負けるハンドです。しかし、相手をフォールドさせることができれば利益になります。

ブラフ候補になるのは次のようなハンドです。

```
ブラフ候補の典型:

外れたフラッシュドロー:
  ドローが完成せず、ショーダウン価値がほぼゼロ
  → 相手のコールレンジにほぼ負ける → ブラフとして最適

外れたストレートドロー:
  フラッシュドロー同様、完成せず弱いハイカード状態
  → ブラフ候補として機能

ハイカード（役なし）:
  ボードにまったく絡まないハンド
  → 最弱クラス → ブラフにするかフォールドの二択

弱いボトムペア（リバーで相対的に弱化したケース）:
  相手のコールレンジに50%未満でしか勝てない場合
  → ブラフの候補になりうる（ただし、チェックバックの方がEV優位なケースも多い）
```

重要な点があります。「コールされると負けるから、何でもブラフできる」という発想は誤りです。ブラフが成立するには、相手がフォールドする頻度が一定以上である必要があります。この頻度の下限がα式から導かれます。α式の詳細は本書第9章で扱います。

### 層3: チェック（中間、ショーダウンバリュー）

バリューを出せるほど強くなく、ブラフとして機能するほど弱くもない、中間のハンドです。

```
チェックになる典型:

中程度のトップペア（弱キッカー）:
  コールレンジに対して50〜55%前後でしか勝てない
  → 薄バリューとの境界 → チェックバックが安全な場合多い

セカンドペア:
  ターン通過後もそこそこ強いが、リバーでコールレンジに負けるケースが増えている
  → ショーダウンを安く目指すためのチェック

ブラフには強すぎる、バリューには弱すぎる：
  ミドルペアやボトムペア（HandScore が低いがゼロではない）
  → ブラフとして打つと本来得られるショーダウン価値を捨てることになる
  → チェックバックしてショーダウンを目指す
```

チェックは「何もしない」ではありません。チェック後に相手がベットしてきたら、コールかフォールドの判断が続きます。チェック後に相手がチェックバックすれば、ショーダウンになります。どちらの展開でも、チェックを選んだこと自体に戦略的な意味があります。

## 5-3 50%の法則の実戦適用

50%の法則は概念としてシンプルですが、実戦では「相手のコールレンジ」が何かを把握する必要があります。

第4章で学んだレンジ遷移の追跡がここで機能します。

```
ステップ1: 相手のコールレンジを推定する
  第4章の4ステップフローで相手のリバー前レンジを確認
  「このサイズのベットに相手がコールするのはどんなハンドか」を考える

ステップ2: 自分のハンドがそのコールレンジに何%で勝つかを概算する
  相手のコールレンジを仮に10手パターンに絞り込む
  そのうち自分が勝てるパターンの数を数える

ステップ3: 50%を上回るかどうかで層を決める
  上回る → バリュー層（サイズを決める）
  下回る → チェック層またはブラフ候補層（ショーダウン価値があるかどうかで二択）
```

厳密な計算より「相手のコールレンジの強い側と弱い側、それぞれに自分が勝てるか」の大まかな把握で十分です。

### ボード別の典型例

**ドライボード（K♣7♦2♠）でのリバー判断**

BTN CBet → BB コール → ターン 9♥ → BB チェック → BTN バレル → BB コール → リバー 3♠

このシーケンスで BTN が保持するハンドと層の分類:

| BTN のハンド | HandScore の目安 | コールレンジへの勝率 | 層 |
|---|---|---|---|
| KK（ターン 9H で変化なし、リバーもそのまま） | 40（セット以上） | 高い（80%以上） | 強バリュー |
| KQ（K-7-2-9-3でTPTK） | 18（TPTK） | 中程度（60〜70%） | 標準バリュー |
| K9（ターン9でK-9の2ペア完成） | 25〜30（2ペア） | 中高（70%前後） | 標準〜強バリュー |
| 77（K-7-2-9-3でセット → フルハウス不成立、セット維持） | 40（セット） | 高い | 強バリュー |
| JT（役なし、ハイカード）| 5 以下 | 低い（20%以下） | ブラフ候補 |
| 98s（9-8、ターンで9がトップペア扱い、リバー3で変化小） | 10〜15（1ペア） | 境界付近 | チェック |

HandScore の基準値（巻2から継承）: TPTK = 18 / TPGK = 15 / TPWK = 10

## 5-4 ハンド役の判定フロー

3層分類に入る前に、自分のハンドの役を正確に把握することが前提です。リバーではボードが5枚揃うため、役の判定漏れが起きやすくなります。

### 役判定の手順

自分のハンド2枚 + ボード5枚 = 合計7枚（最高の5枚を使う）の組み合わせです。

```
役の強さの順序（強い順）:

1. クワッズ（4 of a kind）: 同ランク4枚
2. フルハウス: 3枚 + 2枚
3. フラッシュ: 同スート5枚
4. ストレート: 5枚連続（エース高・ローの両方に注意）
5. スリーカード（トリップス/セット）: 同ランク3枚
6. 2ペア: 2種のペア
7. 1ペア: 同ランク2枚
8. ハイカード: 役なし
```

### 注意が必要なボードパターン

**コネクテッドボード（Broadway の可能性）**

ボードに A-K-Q-J が揃っている場合、T を持つほぼすべてのハンドがストレートを完成させます。

例: ボード A♣K♦Q♣J♠ + ハンド T♠9♦

カード確認: T♠, 9♦, A♣, K♦, Q♣, J♠

ストレートチェック:
- A-K-Q-J-T: T あり → broadway 完成
- K-Q-J-T-9: 9 あり → K-high straight 完成

このハンドは2種類のストレートを持つ最強クラスです。「ドローが外れた」とは判断せず、強バリューとして扱います。

**ペアボード（ボードに同ランク2枚）**

ボードにペアがある場合（例: K-7-2-7）、役なしのハンドでもボードのペアが best 5 に入るため、最低でも1ペアを持ちます。

例: ハンド J♠T♠、ボード K♠7♥2♦7♣3♦

best 5 = K-J-T-7-7 → 7 のペア（ボードのペアを利用）= 1ペア

「役なし」と判断することは誤りです。ペアボードでは必ずボードペアが best 5 に入ります。

**フラッシュボード（同スート4枚以上）**

ボードに同スートが4枚ある場合、自分がそのスートを1枚持っていれば「ナッツフラッシュを持つ可能性のある側」、持っていなければフラッシュを持てない側になります。

フラッシュの判定には必ず5枚同スートが必要です。4枚同スートでもフラッシュではありません。

## 5-5 層ごとのサイズ選択の方向性

3層に分類したあと、各層でどのサイズを選ぶかの方向性を整理します。詳細なサイズ論は本書第14章（ターン専用ベットサイズ）と第12章（IPのリバー攻撃）で扱います。ここでは方向性の概要を示します。

### バリュー層のサイズ選択

バリューの強さによってサイズが変わります。

| バリューの強さ | 目安サイズ | 根拠 |
|---|---|---|
| 強バリュー（70%以上勝てる） | 75%〜100%pot またはそれ以上 | コールレンジ全域に勝てるので大きく打てる |
| 標準バリュー（55〜70%） | 33%〜50%pot | 適度なサイズで相手のコールを引き出す |
| 薄バリュー（50〜55%） | 33%以下またはチェック | 大きくすると相手のコールレンジが絞られ勝率が下がる |

大きなサイズのベットは「相手のコールレンジを絞り込む」効果があります。「75%ベットにコールする相手のハンド」は「33%ベットにコールする相手のハンド」より強いです。薄バリューは大きなサイズで打つと、引き付けられる相手のコールレンジが強くなりすぎて50%の法則を割り込む危険があります。

### ブラフ候補層のサイズ選択

ブラフのサイズは「相手にどれだけフォールドを求めるか」で決まります。

| ブラフのサイズ | α の値 | 相手がフォールドすべき頻度 |
|---|---|---|
| 33%pot | 0.25 | 25% 以上でブラフが成立 |
| 50%pot | 0.33 | 33% 以上でブラフが成立 |
| 75%pot | 0.43 | 43% 以上でブラフが成立 |
| 100%pot | 0.50 | 50% 以上でブラフが成立 |

ブラフは小さなサイズが低リスクに見えますが、相手がフォールドしにくくなります。大きなサイズはフォールドを引き出しやすいですが、コールされたときの損失が大きくなります。第9章で学ぶα式が、この均衡点の計算ツールです。

### チェック層の扱い

チェック層は「ベットしない」という選択です。ただし後手（OOP）としての立場ではなく、先手（IP）としてチェックバックを選ぶ場面を想定しています。

チェックバックの目的は2つです。

1. **ショーダウンを安全に目指す**: 中程度のハンドで不必要なリスクを取らない
2. **レンジを保護する**: チェックバックするレンジに強いハンドを混ぜることで、相手のブラフを抑制する

チェックバックしたからといって、「弱い」と決まるわけではありません。GTO 的には、強いハンドの一部もチェックバックに回す必要があります。

## 5-6 後手側（OOP）での3層活用

攻撃側（先手、IP）だけでなく、守備側（後手、OOP）でも同じ3層の発想が機能します。

相手のベットに対してコール / フォールド / チェックレイズを判断するとき、自分のハンドの層を確認してから判断します。

```
後手側の判断フロー:

相手がリバーベット → 自分のハンドの層を確認:

層1（バリュー系）: コールレンジに入っている可能性が高い
  → コールが基本（強さ次第でチェックレイズ検討）
  → 後手スコアが後手下限スコア（0）以上 → コール

層2（ブラフ候補系）: ショーダウン価値がない
  → フォールドが基本（ただしブラフキャッチャーの役割を担う場合はコール）
  → 後手スコアがマイナス → フォールド

層3（チェック系）: 中程度のショーダウン価値
  → コールとフォールドの境界付近
  → 後手スコアで判断: 0以上 → コール、0未満 → フォールド
```

後手スコアは巻2から継承した式です。

```
後手スコア = HandScore + A − 3 − C − M
  A: ドライ=3 / セミ=2 / ウェット=1
  C: 33%ベット=3 / 50%ベット=5 / 75%ベット=7
  M: HU=0 / 3-way=3 / 4-way以上=6

後手下限スコア = 0
  後手スコア ≥ 0 → コール
  後手スコア < 0 → フォールド
```

リバーでの後手スコアの詳細な適用は本書第13章（OOPのリバー応戦）で扱います。本章では「自分のハンドの層 = 後手スコアの正負に対応する」という対応関係を押さえておいてください。

## 5-7 チェックレイズの候補を見極める

後手（OOP）がチェックレイズ（CR）を検討するのは、後手スコアが非常に高いとき、つまり層1の中でも特に強い場合です。

チェックレイズが有効な条件:

```
1. 自分のハンドが強バリュー層（セット以上、またはナッツ準ナッツ）
2. 相手のベットレンジにブラフが混在しており、CR に対してフォールドしうる
3. 相手のコールレンジに対して自分が高い確率で勝てる
4. ボードのテクスチャが自分のレンジを支持している（Uncapped 状態）
```

CR は「バリューをさらに大きく育てる」か「相手のブラフを排除する」の2つの目的を持ちます。中程度のハンドでの CR は、自分が「層3（チェック）」に属するハンドで CR すると、コールされたときに損失が大きくなります。CR は強バリュー層または特別な状況でのブラフ CR に限定します。

CR の詳細は本書第15章（チェック後の判断）で扱います。

## 5-8 第7章への橋渡し

本章で3層分類の枠組みを整理しました。バリュー / ブラフ候補 / チェックの3層は、リバーのあらゆる判断の出発点です。

しかし3層分類には「どのコンボを選ぶか」という精度の問題が残ります。

たとえば「ブラフ候補が5コンボある。そのうちどれを実際にブラフとして選ぶか」という問いに、3層分類は答えません。同じブラフ候補の中で、どれを選べばフォールドさせやすいかは別の問題です。

この問いに答えるのがブロッカー論です。相手のコールレンジを構成するコンボを「物理的に削る」ことができるハンドを優先してブラフに選ぶことで、同じブラフ行為の成功率が変わります。

次章（第7章）では、ブロッカー加点の概念をリバーの3層分類と組み合わせる方法を整理します。

## ミニクイズ

### 問1

リバーで自分が「外れたフラッシュドロー（A♠9♠ on K♦8♦5♣3♦7♣）」を持っています。このハンドの分類として最も適切なものはどれですか。

なお、ボード K♦8♦5♣3♦7♣ を確認します。  
- スペード: A♠, 9♠ = 2枚  
- ダイヤ: K♦, 8♦, 3♦ = 3枚（フラッシュドローは外れ）  
- 自分の best 5: A-K-9-8-7 = ハイカード（Aハイ）

1. 層1（バリュー）: Aハイでもコールレンジの半数以上に勝てる
2. 層2（ブラフ候補）: コールされるとほぼ負けるためブラフが適切
3. 層3（チェック）: 中程度の強さなのでチェックが最適

### 問2

リバーでバリューベットを判断する「50%の法則」を正しく説明しているものはどれですか。

1. 相手のハンドをランダムに1枚想定して、そのハンドに50%以上で勝てればバリューベット
2. 自分のハンドが全1326コンボの上位50%以上であればバリューベット
3. 相手がベットにコールしてくるハンドの集合全体に対して、自分が50%以上の確率で勝てればバリューベット

### 問3

ボード A♠K♥Q♠J♣2♦（リバー）でハンド T♦9♣を持っています。このハンドの役として正しいものはどれですか。

全カード確認: T♦, 9♣, A♠, K♥, Q♠, J♣, 2♦  
ストレートチェック:  
- A-K-Q-J-T: T あり → broadway 成立?  
- K-Q-J-T-9: 9 あり → K-high straight 成立?

1. 役なし（ハイカード）: T も 9 もボードに絡まない
2. 1ペア: T または 9 がボードとペアになっている
3. ストレート: broadway（A-K-Q-J-T）および K-high straight（K-Q-J-T-9）の両方が成立し、best 5はストレート

---

### 解答

- **問1**: 2（A♠9♠ on K♦8♦5♣3♦7♣でフラッシュドローが外れた場合、ダイヤは3枚（K♦・8♦・3♦）でフラッシュ不成立です。自分のベスト5はA-K-9-8-7のハイカードであり、相手のコールレンジ（ペア以上を持つハンドが主体）に対してほぼ負けます。ショーダウン価値がほぼゼロのため、ブラフ候補として機能します。ただし、α式でブラフが成立する状況かどうかを確認してから実行してください）
- **問2**: 3（50%の法則は「相手のコールレンジ全体に対する勝率」です。相手がコールしてくるハンドの集合を推定し、そのうち自分が勝てる比率が50%以上かどうかを確認します。個別のハンドへの勝率でも、全体コンボ上位50%でもありません）
- **問3**: 3（T♦と9♣を合わせてA♠K♥Q♠J♣2♦のボードで確認します。A-K-Q-J-T: T♦あり → broadway 成立。K-Q-J-T-9: 9♣あり → K-high straight 成立。このハンドはストレートが2種類完成しており、best 5はストレートです。「役なし」や「1ペア」は誤りです。コネクテッドボードでTを持つハンドがstraightになることに注意してください）

> **本章まとめ**
>
> - リバーではハンドを「バリュー / ブラフ候補 / チェック」の3層に分類してから行動を決める
> - バリューの判断基準は「相手のコールレンジに対して50%以上で勝てるか（50%の法則）」
> - ブラフ候補はコールされると負けるが、フォールドさせれば利益になるハンド（主に外れたドロー）
> - チェック層は中程度のショーダウン価値があり、バリューにも明確なブラフにもなりきれないハンド
> - HandScore の基準: TPTK = 18 / TPGK = 15 / TPWK = 10（巻2から継承）
> - ボード読みの注意: コネクテッドボードでのストレート完成、ペアボードでの役昇格、フラッシュは5枚同スート必須
> - 後手側でも同じ3層発想を使い、後手スコア（HandScore + A − 3 − C − M）で0との比較でコール / フォールドを決める

**【GTOとのズレ】**

本章で説明した3層分類は、概念としては GTO のレンジ設計に近いですが、実際のソルバー出力では「厳密な二値」にならず、混合戦略が多用されます。

最もよくあるズレは、**薄バリュー層の扱い**です。50%の法則をギリギリ上回る薄バリューハンドは、GTO 的には「ベット頻度50〜70%、チェック頻度30〜50%」のような混合戦略になることが多くあります。「薄バリューだからベットしない」と完全にチェックに回すと、ベット側のレンジからバリューが薄れすぎてブラフが通りにくくなります。一方、「薄バリューでも必ずベット」という方針は、相手のコールレンジに対してEVがギリギリになります。

もう一つのズレは、**ブラフ候補の選別**です。「外れたドローは全部ブラフできる」という理解は誤りです。GTO 的には、ブラフに選ぶコンボは「ナッツブロッカーを持つもの」「相手のコールレンジを削れるもの」が優先されます。外れたドローの中でも、バリューブロッカー効果のないコンボをブラフに選ぶと、GTO 均衡からズレます。

さらに、**チェック層への恐れ**も典型的なズレです。「中程度のハンドをチェックバックするのは諦め」という感覚は誤りです。GTO 的には、チェックバックにはショーダウン価値の保護という明確な目的があります。チェックバックすることで相手がブラフしにくくなり、逆に自分がコールで勝てる場面が増えます。3層分類を正しく使えば、「チェックは判断の逃げ」ではなく「最適な配分の1つ」と理解できます。
