# 第1章　GTOと暗算式 ─ 本書のアプローチ

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: GTOソルバーの答えをなぜ「暗算式」に圧縮するのかを理解し、本書が提供する4つの暗算式の位置づけと使い方の全体像を把握する。

---

## 1-1 ソルバーの答えは実戦では使えない

ポーカーのGTO（Game Theory Optimal：ゲーム理論的最適戦略）は、ソルバーと呼ばれる計算ソフトで求められます。PioSolverやGTO Wizardといったツールが普及し、中上級者の多くが日常的にソルバー学習を行っています。

ではソルバーを徹底的に学習すれば、実戦でもGTO通りに打てるでしょうか。答えは「ほぼ無理」です。

理由は認知容量の問題です。典型的なターン局面を想像してください。ボードK♠7♦2♣、ターンがA♥という場面で、GTOソルバーはIPプレイヤーのすべてのハンドコンボについて、ベット頻度とチェック頻度を計算します。「AAは高頻度ベット、KKは混合戦略（ベットとチェックを組み合わせる）、AKは高頻度ベット、A7は混合戦略……」という具合に、コンボごとに細かく頻度が分かれます。

実戦では相手のアクション後に数秒で判断しなければなりません。数十〜数百のコンボ頻度を瞬時に参照して実行することは、人間には不可能です。

では強いプレイヤーはどうしているか。彼らはソルバーの細部をすべて記憶しているわけではありません。「このボードタイプではこう動く」というパターンをソルバー学習から抽出し、実戦でそのパターンを使っています。本書が提供するのも、そのパターンを誰でも使えるよう整理した**暗算式**です。

## 1-2 暗算式アプローチの系譜

「式でポーカーを判断する」という発想は、本シリーズで初めて登場したわけではありません。歴史ある先人の試みの上に本書は立っています。

**Chen Formula（2000年代）** は、プリフロップのハンドの強さを数値化した式です。AAなら20点、KKなら12点といった形で、オープンするかフォールドするかの目安を数字で表しました。「正確ではないが、実戦で使える近似」を目指した最初期の試みです。

**Sklansky-Malmuth Hand Groups（1988年）** は、プリフロップのハンドを8グループに分類した体系です。「グループ1は常にオープン、グループ4以下はポジションに注意」という形で、詳細な計算をせずに判断できる**チャンキング（塊として記憶する）**思考を実現しました。

本シリーズは、この系譜の現代版です。巻1のScore（プリフロップ暗算）、巻2の簡易レンジスコアとHandScore（フロップ判断）、巻3の精密レンジスコアと続き、本書ではターン・リバーの4つの暗算式を提供します。違うのは「過去の経験則」ではなく「GTO実測データから逆算して設計した」点です。データと合わない式は採用せず、実際のソルバー解と照合して検証した係数を使います。

シリーズ全体の設計思想をひとことで言えば、「暗算で90%正解を出し、残り10%はソルバー学習で補う」です。実戦の数秒間で「間違っていない方向」を素早く選べることが、プレイ品質向上の最短経路です。

## 1-3 ターン・リバーの暗算が難しい理由

フロップの判断は、巻�・巻3で体系化されました。ターン・リバーの判断がそれより難しい理由は、大きく3つあります。

### 将来ストリートの影響を考える必要がある

フロップでの判断は「フロップで何をするか」の一点に絞られます。しかしターンで判断するとき、頭の中にはリバーがあります。「このハンドはリバーで何になるか」「相手がリバーでオールインしてきたら、今のコールは正しいか」という先読みが、ターン判断に複雑さを加えます。

ドロー手（フラッシュドローやストレートドロー）を持っているとき、ターンでのコールはリバーで完成する期待値込みです。Rule of 2 and 4（巻� 第6章）で学んだとおり、アウツが何枚あるかでエクイティが変わります。フロップより1枚少ないアウツのチャンスしかないターンでは、ポットオッズとエクイティの計算をフロップ以上に注意深く行う必要があります。

### アクション履歴でレンジが絞られている

フロップで配られた直後のレンジは比較的広いです。しかしターンに入るころには、フロップでのアクション（CBet打った・コールした・チェックした、など）によってお互いのレンジが絞られています。

フロップでCBetを打ったIPのレンジには、フロップに当たったバリューハンドとブラフが混在しています。コールしたOOPのレンジには、強い役やドローが中心で、フロップチェックレイズするほど強くないハンドが集まっています。この「フロップ後のレンジの形」を意識した上でターン判断をしないと、正確な判断はできません。レンジ遷移の詳細は第4章で扱います。

### リバーは「確定ゲーム」の論理が必要

リバーはドローが完成するか否かが確定したストリートです。フラッシュドローを持ってターンをコールしたプレイヤーが、リバーでフラッシュを完成できなかった場合、そのハンドのショーダウン価値は大きく下がります。逆に完成した場合は強い役になります。

この「確定性」から、リバーでの攻防はターンとは異なる論理が支配します。バリューベットとブラフの比率をどう設計するか、相手のベットに対してどの頻度でコールするかが、リバー判断の核心です。これを解くのがα式であり、第9章で詳しく扱います。

## 1-4 4つの暗算式の予告

本書の骨格をなす4つの暗算式を一覧で示します。各式の詳細は対応する章で扱いますが、全体像を最初に把握しておくと各章の読み方が変わります。

### 暗算式1: バレルスコア（第8章）

```
バレルスコア = FlopType係数 + TurnCard係数
```

ターンでのダブルバレル（2回目のCBet）を推奨するかどうかを、0〜12の数値で判断する式です。

| 入力 | 係数 |
| --- | --- |
| FlopType係数（ドライ） | 8 |
| FlopType係数（セミ） | 6 |
| FlopType係数（スーテッド） | 4 |
| FlopType係数（コネクテッド） | 3 |
| TurnCard係数（ペア） | 4 |
| TurnCard係数（オーバーカード） | 3 |
| TurnCard係数（ブランク） | 2 |
| TurnCard係数（フラッシュ） | 1 |
| TurnCard係数（コネクター） | 0 |

閾値: バレルスコア ≥ 7 → 積極バレル推奨 / バレルスコア < 7 → ハンド依存

これは巻2の簡易レンジスコア（フロップのレンジCBet頻度を0〜10で予測する式）の自然な拡張です。簡易レンジスコアが「フロップでレンジ全体がどれだけCBetするか」を予測するのに対し、バレルスコアは「ターンでダブルバレルを推奨するか否か」を判断します。フロップのボードタイプとターンカードの2変数で計算できるため、実戦でも即座に使えます。GTO実測データとの照合では、270シナリオで積極バレル推奨かどうかの二値分類と100%一致しています。

### 暗算式2: α式（第9章）

```
α = ベット ÷ (ポット + ベット)
MDF = 1 − α
```

リバーでのバリューベットとブラフの最適比率を決める式です。巻2で学んだMDF概念の裏面として設計されています。

計算例として、ポット100に対して75%ベット（75）を打つ場面を考えると、α = 75 ÷ 175 ≈ 0.43です。これは「先手のブラフが43%以上の頻度でフォールドを取れれば利益になる」という損益分岐点を示します。後手側から見ると、MDF = 1 − 0.43 = 0.57、つまり「少なくとも57%の頻度でコールまたはレイズしないと、相手にブラフし放題を許してしまう」という守りの基準になります。

この式は計算が単純なため、相手のベットサイズを見た瞬間にMDFを算出できます。リバーでバリューとブラフをどの比率で打つべきかの根拠にもなります。

### 暗算式3: 後手スコア（ターン版）（第10章）

```
後手スコア = HandScore + A − 3 − C − M
```

ターンでのコール・フォールド・チェックレイズの判断式です。巻2で確立した後手スコアの骨格（HU前提ではM=0）をそのままターンに適用します。

| 後手スコア | アクション |
| --- | --- |
| ≥ 8 | チェックレイズ検討 |
| 0〜7 | コール |
| 0未満 | フォールド |

係数の意味は巻2と同じです。A係数はボード特性（ドライ=3 / セミ=2 / ウェット=1）、C係数はベット負担（33%=3 / 50%=5 / 75%=7）、M係数はマルチウェイ補正（HU=0 / 3-way=3 / 4-way以上=6）です。

ターン版の特徴は「ドロー加点が生きている」点です。ターンではまだリバーが残っているため、フラッシュドローやストレートドローのHandScoreへの加点（ドロー加点）が有効です。この加点によって、ドロー手でのコールを後手スコアが正しく評価できます。

### 暗算式4: 後手スコア（リバー版）（第11章）

```
後手スコア = HandScore + A − 3 − C − M
```

式の形はターン版と同じですが、リバー固有の2点が異なります。

1点目は**C係数の拡張**です。リバーではオーバーベット（ポット超え）が登場します。ターンまでのC係数は最大75%=7でしたが、リバー版では100%ベット=9、150%ベット=11という拡張係数を使います。

2点目は**ドロー加点の固定**です。リバーではドローが完成したか否かが確定しています。ドローが完成していれば役スコアとして計算し、外れていれば加点しません。「ドロー加点=0」として HandScore を計算し直した上で後手スコアを出すのがリバー版の使い方です。

この2点を覚えれば、後手スコアの骨格はターンもリバーも同じです。新しい式を丸ごと覚え直す必要はありません。

## 1-5 4つの式と攻守の対応

4つの暗算式は攻撃側（先手）と防御側（後手）に対応して使い分けます。

| 式 | 立場 | 主な適用場面 |
| --- | --- | --- |
| バレルスコア | 攻撃側（先手） | ターンでダブルバレルを打つか判断する |
| α式 | 攻撃側（設計）/ 防御側（対応） | リバーのバリュー・ブラフ比率を決める / MDFを計算する |
| 後手スコア（ターン版） | 防御側（後手） | ターンのコール・フォールド・CR を判断する |
| 後手スコア（リバー版） | 防御側（後手） | リバーのコール・フォールド・CR を判断する |

攻撃側の式（バレルスコア）はターン専用であり、リバーでの攻撃は主にα式が担います。α式はリバーのバリュー・ブラフ配分を設計する際に先手が使い、MDFを計算する際に後手が使います。つまりα式は一つの式ですが、使い手によって「設計式」にも「防御式」にもなります。

防御側の式（後手スコア）はターン版とリバー版で係数の使い方が変わるため、分けて学びます。ただし式の骨格は共通なので、ターン版を理解すれば、リバー版は差分だけ覚えれば済みます。

## 1-6 暗算式の限界とソルバーが必要な場面

本書の4つの暗算式はGTOを完全に再現することを目標にしていません。完全再現を目指すならソルバーが最も確実ですが、テーブルでは使えません。本書が目指すのは「GTOの主要な判断方向を、実戦の数秒で計算できる精度で再現すること」です。

暗算式が正確に機能する場面と、限界がある場面を最初に把握しておきましょう。

**暗算式が機能する場面**: ボードタイプとターンカードが明確に分類できる標準的な状況。バレルスコアで言えば、スコアが9以上（ドライ板＋ペアターン）や5以下（コネクテッド板＋コネクターターン）のような、境界から離れた場面では誤差が小さくなります。

**暗算式に限界がある場面**: 境界付近（バレルスコア6〜8）での混合戦略判断、スタック深度が通常から大きく外れる場面、相手が非標準プレイをしている搾取状況、3-betポットやマルチウェイ特有の構造などです。

また、暗算式はレンジ全体の傾向を示すものであり、特定のハンドの精密な頻度を再現しません。「このハンドは73%バレル、あのハンドは41%バレル」という個別頻度は、式では出せません。式が示すのは「この状況では積極バレル推奨（ハンド依存ではない）」という方向性です。

各章末の【GTOとのズレ】コラムで、その章の暗算式と実際のGTOとの誤差が生じやすい場面を具体的に示します。暗算式を使いながら「このコラムの状況に近い場面では注意が必要だ」と判断できるようになることが、本書での学習の最終的な姿です。

## 1-7 本書の使い方

本書は4部16章と付録3章で構成されています。各部の役割は明確に分かれています。

**第I部（第1〜4章）** は概念の土台です。本章でアプローチを確認した後、第2章でターンとリバーの位置づけ、第3章でレンジ強度（Capped vs Uncapped）、第4章でアクションとレンジ遷移を扱います。これらは後続の式と戦術を理解するための基礎概念です。

**第II部（第5〜7章）** はハンドとボードの読み方です。第5章でハンドの3層分類（バリュー/ブラフ候補/弱役）、第6章でターンカードの5分類（ペア・オーバーカード・ブランク・フラッシュ・コネクター）、第7章でブロッカー基礎を扱います。これらは4つの式に入力するための「材料」です。

**第III部（第8〜11章）** が4つの暗算式の核心です。第8章でバレルスコア、第9章でα式、第10章で後手スコア（ターン版）、第11章で後手スコア（リバー版）を順に導出します。式の意味・導出・適用条件を詳しく扱うため、この4章が本書の中心です。

**第IV部（第12〜16章）** は実戦への橋渡しです。第12章でIPの攻撃、第13章でOOPの応戦、第14章でベットサイズ、第15章でチェックビハインドとブラフキャッチを扱い、第16章の基礎ドリル20問で定着を図ります。

第1章から順に読み進めるのが標準ルートです。各章末のミニクイズで理解を確認しながら進め、第16章のドリルで総仕上げをしてください。

## ミニクイズ

### 問1

GTOソルバーの出力が実戦で直接使えない最大の理由はどれですか。

1. ソルバーの計算にはバグが多く、出力が不正確だから
2. ソルバーはコンボ別に数十〜数百の頻度を出力するため、実戦の数秒で参照・実行するのが人間には不可能だから
3. ソルバーは6-max専用に設計されておらず、汎用性が低いから
4. ソルバーの答えは混合戦略が多く、純戦略しか打てないルールのゲームには使えないから

### 問2

本書のバレルスコアは、巻2のどのツールを自然に拡張した式ですか。

1. HandScore
2. CBet統合式（先手スコア）
3. 後手スコア
4. 簡易レンジスコア

### 問3

本書の後手スコア（ターン版）とリバー版で「異なる点」はどれですか。正しいものをすべて選んでください。

1. 式の骨格（HandScore + A − 3 − C − M）が変わる
2. C係数がリバー版では100%ベット=9、150%ベット=11に拡張される
3. ドロー加点がリバー版では使えない（ドロー加点=0として計算する）
4. A係数の設定がリバー版では存在しない

### 解答

- **問1**: 2（ソルバーはコンボ別に細かな頻度を出力する。それを数秒で全参照する人間の認知容量は存在しない。問題はソルバーの精度ではなく、人間側の処理限界にある）
- **問2**: 4（バレルスコアは「フロップのレンジCBet頻度を予測する」簡易レンジスコアに「ターンカードの影響」を加算してターンのバレル判断に拡張した式。詳細は第8章で扱う）
- **問3**: 2と3（骨格の式は同じ。異なるのはC係数の拡張と、ドロー加点を0に固定する点の2つ。A係数はリバー版でも同様に使う）

>
> - GTOソルバーの出力は理論的に正確だが、コンボ別頻度の多さから実戦での直接使用は不可能

> - 暗算式はGTO完全再現ではなく「判断方向の正確な近似」を目標とする。限界は各章末コラムで示す

**【GTOとのズレ】**

本章ではまだ式の中身を扱っていませんが、「暗算式でGTOを90%再現できる」という主張そのものへの疑問に先に答えておきます。

まず、バレルスコアの「270シナリオ100%一致」とは、積極バレル推奨かどうかという二値分類の一致です。「スコア7以上なら積極バレル、7未満ならハンド依存」という二択の判断方向が、GTOデータと一致しているということです。個々のハンドの具体的な頻度（「KQoは67%バレル」など）を再現しているわけではありません。境界付近のスコア（6〜8）では、GTOが混合戦略を採用することが多く、本書の二値判断と実際の頻度にズレが生じます。

次に、後手スコアの限界についてです。後手スコアは係数の足し算という線形の式であるため、ポットサイズの変化やSPRの影響を直接は反映しません。ターン・リバーではフロップに比べてポットが大きくなり、残りスタック（effective stack）が少なくなっているため、コールオッズの感覚がフロップと変わります。式の出力と実際の判断にズレが生じやすい場面の一つです。

これらのズレを知った上で式を使うことが、本書の暗算式を「ツール」として正しく扱う姿勢です。「式が答えを出す」のではなく「式が示す方向を判断の出発点にし、文脈で調整する」という使い方を、各章のドリルと実例を通じて身につけてください。
