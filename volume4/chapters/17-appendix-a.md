# 付録A　式の早見表と係数一覧

> **この付録の使い方**: 本書（第1章〜第16章）の核心をチートシート形式で集約しています。実戦直前に見直すだけで、4つの暗算式と係数を即座に呼び出せます。詳細な解説は各章を参照してください。

## A-1 4つの暗算式

### 式1：バレルスコア（ターン攻撃）

```
バレルスコア = FlopType係数 + TurnCard係数

≥ 7 → 積極バレル（レンジ全体でダブルバレル推奨）
< 7 → ハンド依存（強バリュー・セミブラフのみバレル）
```

詳細 → 第8章

---

### 式2：α式（リバー配分）

```
α = ベット額 ÷ (ポット + ベット額)

αの意味:
  先手のブラフ損益分岐点（ブラフが利益になるための最低フォールド率）
  ベットレンジに占めるブラフの上限比率

MDF = 1 − α（後手の最低防御率）
V:B比率（上限） = (1 − α) : α = ポット : ベット額
```

詳細 → 第9章

---

### 式3：後手スコア（ターン版）

```
後手スコア = HandScore + A − 3 − C − M

≥ 8  → チェックレイズ（CR）検討
0〜7 → コール
< 0  → フォールド

ターンのポイント: ドロー加点あり / A値はターン4枚で再評価
HU前提のときは M = 0（HU前提のため M=0 と必ず注記）
```

詳細 → 第10章

---

### 式4：後手スコア（リバー版）

```
後手スコア = HandScore + A − 3 − C − M

≥ 8  → チェックレイズ（CR）検討（ナッツ近辺のみ現実的）
0〜7 → コール
< 0  → フォールド

リバーのポイント: ドロー加点 = 0（役スコアのみ） / C拡張（100%=9, 150%=11）
```

詳細 → 第11章

## A-2 FlopType係数（バレルスコア用）

| フロップ板タイプ | 係数 | 代表ボード |
|---|---|---|
| ドライ | **8** | K72r、A52r、K83r |
| セミ | **6** | J75r、K93r、T42r |
| スーテッド | **4** | J84ss、T52ss、Q63ss |
| コネクテッド | **3** | T98r、876r、JT9r |

**板タイプ判定クイックガイド**

```
ドライ（3条件すべて）:
  □ レインボー（同スート2枚以下）
  □ 最高ランクと最低ランクの差 ≥ 5（例: K72 → K=13, 2=2, 差=11）
  □ 3枚連続なし
  例: K72r, A52r, Q93r

コネクテッド（いずれか1条件）:
  □ 3枚がスパン3以内（例: 876、T98、JT9）
  例: T98r, 876r, JT9r

スーテッド:
  □ 同スートが2枚以上（フラッシュドロー可能）
  例: J84ss（♥2枚）, T63ss

セミ = 上記3分類のいずれでもない中間ボード
  例: J75r, K93r, T42r
```

## A-3 TurnCard係数（バレルスコア用）

| ターンカード分類 | 係数 | 例 | 特徴 |
|---|---|---|---|
| ペア（フロップと同ランク） | **+4** | K72 + K♥ | IPのナッツアドバンテージ最強化 |
| オーバーカード（OC） | **+3** | K72 + A♠ | IPのプリフロップレンジを強化 |
| ブランク（絡まない中低ランク） | **+2** | K72 + 4♣ | フロップ時点の優位をそのまま継続 |
| フラッシュ（3枚目同スート） | **+1** | J84ss + Q同スート | OOPのFD完成でIP有利が減少 |
| コネクター（ストレート強化） | **+0** | J84 + T | 両者のレンジを同程度強化 |

**ターンカード分類の優先順位**

```
1. ペアか？     → フロップのいずれかのランクと一致する
2. OCか？      → フロップの最高ランクより高い
3. フラッシュか？ → 3枚目の同スートが揃う
4. コネクターか？ → ストレートドローを大きく強化する
5. ブランク      → 上記4つのいずれにも該当しない
```

|---|---|---|---|
| 33% ポット | 0.25（25%） | 0.75（75%） | 3 : 1 |
| 50% ポット | 0.33（33%） | 0.67（67%） | 2 : 1 |
| 75% ポット | 0.43（43%） | 0.57（57%） | 約 7 : 10 |
| 100% ポット | 0.50（50%） | 0.50（50%） | 1 : 1 |
| 125% ポット | 0.56（56%） | 0.44（44%） | 約 4 : 5 |

## A-7 A・C・M係数早見表（後手スコア用）

### A係数（ボード値・ドライ度）

| ボード評価 | A値 | 判断基準 |
|---|---|---|
| ドライ（ペアボード・レインボー不連続） | **3** | フラッシュドローなし・ストレートドロー薄い |
| セミウェット | **2** | 中程度のコネクト性またはスート集中 |
| ウェット（コネクテッド / フラッシュドロー強） | **1** | OESD多数 or フラッシュドロー成立しやすい |

ターンでは4枚ボードで A値を再評価します。フロップの A値をそのまま引き継がないことが重要です。

### C係数（ベット負担）

| ベットサイズ（ポット比） | C値 | MDF |
|---|---|---|
| 33% | **3** | 75% |
| 50% | **5** | 67% |
| 75% | **7** | 57% |
| 100%（ポットサイズ） | **9** | 50% |
| 150%（オーバーベット） | **11** | 40% |

C=9・C=11 はリバー専用の拡張値です（第11章参照）。ターンのオーバーベットでも使用できます（第14章参照）。

### M係数（マルチウェイ補正）

| プレイヤー数 | M値 |
|---|---|
| HU（2名） | **0** |
| 3-way | **3** |
| 4-way以上 | **6** |

HU前提で M を省略する場合は「HU前提のため M=0」と必ず注記します。

## A-8 判断フロー早見表

### ターン（IPが攻撃する場面）

```
Step 1: フロップ板タイプを確認
  ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3

Step 2: ターンカードを分類
  ペア=+4 / OC=+3 / ブランク=+2 / フラッシュ=+1 / コネクター=+0

Step 3: バレルスコアを計算
  バレルスコア = FlopType係数 + TurnCard係数

Step 4: 判定
  ≥ 7 → 積極バレル（レンジ全体でダブルバレル）
  < 7 → ハンド依存（強バリュー・セミブラフのみバレル）
```

### ターン（OOPが応戦する場面）

```
Step 1: ターン後の4枚でA値を再評価
Step 2: ベットサイズからC値を確認（33%=3, 50%=5, 75%=7）
Step 3: HandScoreを評価（役スコア + ドロー加点）
         ターンカードによる役の変化に注意（例: TPTK → 2ペアへの昇格）
Step 4: 後手スコア = HandScore + A − 3 − C − M
  ≥ 8  → CR検討
  0〜7 → コール
  < 0  → フォールド
```

### リバー（IPが攻撃する場面）

```
Step 1: ハンドの3層を確認
  強バリュー（ナッツ近辺）  → 75%〜100%ベット（またはOB）
  標準バリュー（55〜70%勝率）→ 33%〜50%ベット
  弱役・役なし               → チェック（or ブラフ候補）

Step 2: ブラフ選択
  α = ベット額 ÷ (ポット + ベット額) でブラフ上限を確認
  ブロッカー評価（相手のナッツレンジを削るカードを優先）

Step 3: オーバーベット検討条件
  □ レンジがポーラード化している（ナッツ + ブラフ、ミドルなし）
  □ フロップ〜ターンのストーリーが一貫している
  □ リバーカードがIPのレンジを強化している
```

### リバー（OOPが応戦する場面）

```
Step 1: リバーのHandScoreを評価（ドロー加点=0、役スコアのみ）
Step 2: A値（5枚ボードで再評価）
Step 3: 後手スコア = HandScore + A − 3 − C − M
  ≥ 8  → CR検討（ナッツ近辺のみ現実的）
  0〜7 → コール
  < 0  → フォールド
Step 4: ブラフブロッカー確認
  相手のブラフ候補カードを自分が持っていると、相手のベットはよりバリューに偏る。
  このとき自分のコール価値は下がります。
```

## A-9 実戦チェックリスト

**ターン前**

- [ ] フロップ板タイプを4分類で即答できるか
- [ ] ターンカードを5分類で即答できるか
- [ ] バレルスコアを足し算1回で計算したか
- [ ] スコア < 7のとき、自分のHandScoreとセミブラフの有無を評価したか

**リバー前**

- [ ] ターンでのアクション履歴と相手のレンジ変化を把握しているか
- [ ] 自分のハンドが「強バリュー / 標準バリュー / チェックゾーン / ブラフ候補」のどれかを決定したか
- [ ] ベットするなら、α値とV:B比率を確認したか

**相手ベットへの応戦前**

- [ ] 後手スコアを暗算したか（HandScore + A − 3 − C − M）
- [ ] リバーではドロー加点をゼロにしたか
- [ ] ブラフブロッカーの有無を確認したか
- [ ] CR判断はスコア ≥ 8 かつナッツ近辺のみを対象にしたか

**マルチウェイ（3名以上）**

- [ ] M値を加算したか（3-way: M=3、4-way以上: M=6）
- [ ] ブラフ頻度を大幅に下げたか（マルチウェイでブラフは低EV）

---

> **本書の4つの核心式**
>
> - **バレルスコア**: ターン攻撃を足し算1回で判断
> - **α式**: リバーのバリュー / ブラフ配分を数値で設計
> - **後手スコア（ターン版）**: ドロー加点を生かしたターンのディフェンス判断
> - **後手スコア（リバー版）**: C拡張（100%/150%）を含むリバーのディフェンス判断
>
> 4式はすべて同じ思想から生まれています。GTOの複雑な計算を、人間が暗算で回せる精度に圧縮すること。実戦テーブルで迷わなくなることが、本書の唯一の目標です。
