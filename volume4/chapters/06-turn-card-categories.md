# 第6章　ターンカードの5分類

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ターンカード47通りをレンジへの影響パターンで5つに分類し、各分類のGTO実測CBet頻度を把握する。次章（第8章）で学ぶバレルスコアの入力変数「TurnCard係数」の土台を固める。

---

## 6-1 なぜ5分類なのか ─ 離散変数の圧縮

ターンカードは理論上47通り存在します。フロップの3枚を除いた残りのカードすべてが対象です。これを1枚ずつ個別に扱おうとすると、フロップの種類も数百通りあるため、組み合わせ数は膨大になります。

しかし、ポーカー判断に必要な情報は「このターンカードが誰のレンジをどう変えるか」という一点に集約されます。この観点から眺めると、47通りのターンカードは**レンジへの影響パターン**で5種類にまとめることができます。

これが「5分類」の出発点です。個別のカードに反応するのではなく、「このカードはどの分類に属するか」を3秒で判断してから戦略を決める。これが本章から始まる暗算式の第一ステップです。

5分類の根拠となる問いは次のひとつです。

> **「このターンカードは、IPのレンジとOOPのレンジのどちらをより強化するか？」**

IPのレンジをより強化するなら攻撃的になれる。OOPのレンジをより強化するなら慎重になるべきだ。この非対称性を分類が捉えます。

---

## 6-2 第I部の概念との対応

5分類を正しく使うには、第I部で学んだ概念がどう対応するかを理解することが必要です。

第3章では**ナッツアドバンテージ**を学びました。ナッツアドバンテージとは「最強ハンドをより多く保有している側が持つ優位性」です。ターンカードが落ちると、このナッツアドバンテージが更新されます。

第4章では**レンジ遷移**を学びました。各アクション（ベット・チェック・コール等）がレンジをどう変化させるかの法則です。ターンカードが落ちることも、一種のレンジ遷移を引き起こします。

5分類は、この2つの概念をターンカードという変数に適用したものです。

| 分類 | 対応する概念（第I部） | レンジへの主な影響 |
|---|---|---|
| **ペア** | ナッツアドバンテージ（第3章）の更新 | IPのナッツが強化される |
| **オーバーカード（OC）** | ナッツアドバンテージ（第3章）の更新 | 通常はIPの上位ハンドが強化される |
| **ブランク** | ナッツアドバンテージ（第3章）が維持される | フロップ時点の状態が継続 |
| **フラッシュ** | レンジ遷移（第4章）の急変パターン | OOPのドロー成分が大幅に完成する |
| **コネクター** | レンジ遷移（第4章）の急変パターン | ストレートドローが完成・進行する |

ペア・OC・ブランクはナッツアドバンテージの「量的変化」を扱い、フラッシュ・コネクターはレンジ構成の「質的変化」を引き起こします。この違いが5分類の内部構造を説明しています。

---

## 6-2a エクイティアドバンテージとナッツアドバンテージの2軸

ターンカードがレンジ優位性に与える影響は、**2つの独立した軸**で分析できます。この2軸はGTO Wizard「How To Analyze Turn Textures in Poker」で解説されている枠組みです。

| 軸 | 定義 | 判断への影響 |
|---|---|---|
| **エクイティアドバンテージ** | レンジ全体の平均勝率の優位性（どちらのレンジが全体として「勝ちやすいか」） | バレルスコアの基礎となる。エクイティ優位側がCBet頻度を高く保てる |
| **ナッツアドバンテージ** | 最強ハンド（ナッツ）がどちらのレンジに偏るか。定量化は「Δナッツ = IPナッツコンボ − OOPナッツコンボ」（巻② 第11章参照） | サイズ選択の基準となる。ナッツを多く持つ側が大きなベットサイズを使える |

2軸は必ずしも同じ側に向かいません。同一のターンカードで「エクイティはIPが優位、ナッツはOOPが優位」という相殺が起きることがあります。

### 各分類における2軸の方向

| ターンカード分類 | エクイティ優位側 | ナッツ優位側 | 合成効果 |
|---|---|---|---|
| **ペア（高位: 例Kペア）** | IP | IP | IPが両軸で優位 → CBet最高 |
| **ペア（低位: 例2ペア）** | IP | OOPが9xセット等を持つ場合に相殺 | 相殺でも平均90.8%を維持 |
| **オーバーカード（OC）** | IP（Ax/Kx豊富） | IP | IP優位 → 高め |
| **ブランク** | IP（フロップ優位継続） | IP（変化なし） | 現状維持 → 板タイプ依存 |
| **フラッシュ** | OOPのFD完成で低下 | OOP（FD完成=ナッツ候補） | OOP強化 → 低め |
| **コネクター** | OOPのドロー完成で低下 | OOP（ストレート完成=ナッツ候補） | OOP強化 → 低め |

### 具体例で2軸を読む

**ペアターン（例: K♦7♣2♠ → 9♣）**

9♣というカードで、IPのエクイティ優位はほぼ維持されます（フロップのIPレンジが全体的に強い）。一方ナッツ面では、OOPが9xのセット・トリップスを保有するケースが相殺要因となります。しかし実測では平均90.8%と依然として高く、エクイティ優位がナッツの相殺を上回っています。

**フラッシュターン（例: K♠8♥3♥ → 5♥）**

フロップで2-toneのボードなら、フラッシュドロー（FD）をOOPがコールで保持していることがあります。5♥が落ちると、OOPのFDが完成してナッツアドバンテージがOOP側に移動します。さらにIPがフロップをチェックスルーしていた場合、OOPは「予期しないナッツ」を得て大きなベットを放つことができます。

> **「予期しないナッツ」の例**: フロップで弱いFDを持つBBがチェックコール（またはIPのチェックスルー後のチェック）。ターンでフラッシュが完成すると、BBはポーカーでいう「インポジション外でのナッツ」となり、大きなオーバーベットを正当化できます。これが「フラッシュ = チェック頻度が上がる」という実測値の背後にある理由です。

（出典: GTO Wizard「How To Analyze Turn Textures in Poker」）

## 6-3 5分類の定義と判定フロー

各分類を順番に定義します。まず定義を覚え、次節の実測データと照らし合わせることで理解が深まります。

### 分類1: ペア

**定義**: ターンカードのランクが、フロップの3枚のいずれかと一致する。

例: フロップ K♣7♦2♠ にターン 7♥ → ペア（7がフロップにある）

例: フロップ K♣7♦2♠ にターン K♠ → ペア（Kがフロップにある）

ペアターンでは、フロップですでにそのランクのカードを持っていたプレイヤーのハンドが「昇格」します。

- セット → フルハウス
- トリップス → フルハウスまたはクワッズ
- 2ペア → フルハウス
- ワンペア → トリップス

IPはフロップでCBetを打っており、強いハンドも含んでいます。OOPはフロップでコールしており、より弱いレンジが主体です。ペアターンでは、この非対称性がさらに拡大します。

### 分類2: オーバーカード（OC）

**定義**: ターンカードのランクが、フロップ3枚の中の最高位のカードより高いランクである。

例: フロップ K♣7♦2♠（最高位K）にターン A♥ → オーバーカード（AはKより高い）

例: フロップ J♠8♣3♦（最高位J）にターン Q♥ → オーバーカード（QはJより高い）

一般的な状況では、IPのプリフロップオープンレンジには上位ランクのカードが多く含まれます。BTNは6-maxで約45%の広いレンジでオープンしており、そのレンジにはAx・Kx・Qxが豊富に存在します。これに対し、BBのコールレンジはAx等が少ない傾向があります。

ただし後述するように、OCターンは例外ケースが存在する唯一の分類でもあります。

### 分類3: ブランク

**定義**: ペアでもなく、フロップ最高位より高くもなく、さらにストレートドローやフラッシュドローを顕著に進めない中〜低ランクのカード。

例: フロップ K♣7♦2♠ にターン 3♣ → ブランク（Kより低く、ペアでもなく、ストレート/フラッシュにも絡まない）

ブランクターンは「何も変わらない」ターンです。フロップ時点のレンジ優位がそのまま継続します。IPがフロップ時点でナッツアドバンテージを持っていれば、ブランクターンでもそれが維持されます。

ただし「何も変わらない」は板タイプに依存します。ドライボードのブランクは高いCBet頻度を示し、ウェットボードのブランクは相対的に低くなります（後述の実測データを参照）。

### 分類4: フラッシュ

**定義**: フロップにすでに2枚の同スートが存在し、ターンで3枚目の同スートが落ちる。

例: フロップ J♠8♠3♦（スペード2枚）にターン Q♠ → フラッシュ（スペード3枚目）

フラッシュターンでは、フロップでフラッシュドローを持ってコールしていたOOPのハンドが一部「完成」します。OOPのレンジ中のフラッシュドロー成分が強いハンドに変身するため、IPの相対優位が低下します。

モノトーン（3スート揃い）のフロップは別の戦略が適用されます。本書では「フラッシュ」分類は「フロップに同スート2枚 + ターンで3枚目」を指します。

### 分類5: コネクター

**定義**: ストレートを完成させる、またはストレートドロー（OESD・ガットショット）を大幅に進めるカード。

例: フロップ 8♠7♣6♦ にターン 9♥ → コネクター（6-7-8-9のOESDが複数完成）

例: フロップ J♥T♣5♦ にターン 9♦ → コネクター（J-T-9でOESDが形成・進行）

コネクターターンはOOPのドロー成分を強化することが多い分類です。OOPはフロップで広いレンジでコールしており、そのレンジにはストレートドロー系のハンドが豊富に含まれます。コネクターターンでそれらが完成または進行するため、IPの優位が低下します。

---

## 6-4 境界ケースの優先順位

1枚のターンカードが複数の分類に該当することがあります。たとえば、フロップ J♠T♣5♥（スペード1枚）にターン 9♠ が落ちた場合、9はコネクターでもありスペードのスートカードでもあります。

こうした「重複分類」の優先順位は次の通りです。

**優先順位 (高い順)**: ペア > フラッシュ > コネクター > OC > ブランク

ただしこの優先順位は**OOPのレンジへの影響度**で決まります。フラッシュドローとコネクターが同時に完成する場合、OOPのレンジがより大きく強化されるため、より低い係数（フラッシュ=1）を選ぶことで安全側に倒します。

実践的な判断フロー:

```
ステップ1: ターンカードはフロップのいずれかのランクと一致するか？
  → YES → ペア
  → NO  → ステップ2へ

ステップ2: フロップに同スート2枚あり、ターンで3枚目か？
  → YES → フラッシュ
  → NO  → ステップ3へ

ステップ3: ストレートを完成させる、またはOESDを形成するか？
  → YES → コネクター
  → NO  → ステップ4へ

ステップ4: フロップの最高位ランクより高いか？
  → YES → オーバーカード（OC）
  → NO  → ブランク
```

このフローを3秒以内で実行できるようにすることが、実戦でのバレル判断を速くします。

**注記**: OC＋フラッシュの場合（例: フロップ K♠7♣2♣にターン A♣）は、フラッシュよりOCを優先します。Aは特にIPのAx系ハンドを大きく強化するためです。これは一般ルールの例外として覚えてください。

## 6-5 GTO実測データ: 270シナリオの分類別CBet頻度

TexasSolverを使って、BTN vs BB（6-max、100BB、キャッシュゲーム）の30フロップ × 9ターンカード = 270シナリオを実測しました。exploitability（搾取可能性）は全シナリオで0.5%未満に収束しており、GTO解に十分近い結果です。

### 分類別平均CBet頻度（270シナリオ実測）

| ターンカード分類 | 平均CBet% | 最低値 | 最高値 | シナリオ数 |
|---|---|---|---|---|
| **ペア** | **90.8%** | 67.9% | 100.0% | 60 |
| **オーバーカード（OC）** | 76.3% | 53.1% | 97.9% | 53 |
| **ブランク** | 74.6% | 42.0% | 100.0% | 105 |
| **コネクター** | 69.9% | 41.1% | 100.0% | 42 |
| **フラッシュ** | 68.5% | 54.2% | 92.2% | 10 |

（出典: TexasSolver実測、2026-04-23。GTO最適解の近似値）

**最も重要な発見は「ペアが最高」という事実です。**

「ペアターンは危険だからチェックバックすべき」と思っている人は多いでしょう。しかし実測ではペアターンのCBet頻度は平均90.8%と、全分類で断然トップです。最低値でさえ67.9%（後述のAT7ss + 7c）あります。

この誤解を解くことが、本書全体のターン戦略の出発点です。

## 6-6 各分類の実測詳解

### ペアターン（平均90.8%）

ペアターンでIPのCBetが高い理由を、具体的なハンドエボリューションで確認します。

**K♣7♦2♠ + K♠ターン（GTO実測: 100.0%）**

ボードは K-7-2-K（K のペア化）。フロップ時点で IP が持っていた各ハンドの「ターン後の役」を確認します。

- KK → **クワッズ**（K-K-K-K、4 of K's。フロップでセット → ターンで4枚目）
- AK → **トリップス**（K-K-K + A、A キッカー。フロップで TPTK → ターンで3枚目の K）
- K7s → **フルハウス**（K-K-K-7-7、K's full of 7's。フロップで2ペア → ターンで K の3枚目）
- 77 → **フルハウス**（7-7-7-K-K、7's full of K's。フロップでセット → ターンで K の2枚化）
- 22 → **フルハウス**（2-2-2-K-K、2's full of K's。同様）

IPはKxとポケットペアを幅広く保有しており、Kペアターンでそれらがほぼすべて強化されます。OOPのコールレンジには相対的にKxが少ないため、このナッツアドバンテージの非対称性が最大化され、CBet100%となります。

**K♣7♦2♠ + 2♣ターン（GTO実測: 100.0%）**

ボードは K-7-2-2（2 のペア化）。下位カードのペアターンでも、フロップ時点の各ハンドが大きく昇格します。

- KK → **フルハウス**（K-K-K-2-2、K's full of 2's。フロップでセット → 2のペア化でフルハウス）
- 22 → **クワッズ**（2-2-2-2-K、4 of 2's。フロップでセット → ターンで4枚目）
- K2s → **フルハウス**（2-2-2-K-K、2's full of K's。フロップで2ペア → 2の3枚化）
- 77 → **フルハウス**（7-7-7-2-2、7's full of 2's。フロップでセット → 2のペア化）
- AK → **2ペア**（A-K-K-2-2、K's & 2's、A キッカー。ボードの 2-2 ペアが自動的に組み合わさる）

下位カードのペアターンでも、IPのポケットペアやKx系がフルハウス級に大幅昇格し、TPTK 級も2ペアに底上げされます。IPの強いレンジが劇的に強化されるため、CBet100%です。

**例外: AT7ss（スーテッド）+ 7♣ターン（GTO実測: 67.9%）**

これがペアターンの最低値です。いくつかの理由が重なります。

- AT7ssはスーテッドボード。OOPもフラッシュドロー系ハンドを多く保有している。
- 7ターンは「下位カードのペア」。IPの7xハンドも強化されるが、OOPの7xも強化される。
- スーテッドボードのためOOPのコールレンジがより幅広く、7xの含有比率も高い。

それでも67.9%は十分に高く、実戦では「ペアターン = 基本的にバレル」のルールが成立します。

**AT7ss + A♥ターン（GTO実測: 99.7%）**

同じAT7ssでも、Aターン（ペア）では99.7%に跳ね上がります。AはIPのプリフロップレンジに多く含まれ、OOPにはAを広く持っていない（BBのコールレンジはAKやAAをほぼ含まない）ためです。

---

### オーバーカードターン（平均76.3%）

**K♣7♦2♠ + A♥ターン（GTO実測: 86.0%）**

ドライボードへのAターン。IPのBTNレンジにはAx（AK、AQ、AJ等）が豊富に含まれています。OOPのBBコールレンジには相対的にAxが少ない（BBはAを持つ場合3betすることが多い）。よって86.0%と高め。

**K♣7♦2♠ + Q♠ターン（GTO実測: 78.3%）**

QはKより低いため、本来はブランク分類になります（K72rで最高位はK）。同様に確認すると、実際にQはブランクとして分類されています。

**K44 + A♣ターン（GTO実測: 77.4%）**

これがOCターンで注意すべき「例外ケース」です。

K44というボードでは、OOPのBBはフロップでAxを含む広いレンジでコールしています。K44はIPにとって有利なボード（KxやKKが強い）ですが、BBはAxを4xより強いハンドとして保有し続けています。Aターンが落ちると、BBのAxがAペアとなってBBのレンジが一部強化されます。

これがK72r + Aターン（86%）との差を生み出します。

**実用ルール**: OCターンの判断では「そのフロップでOOPがそのランクのハンドを多く持っているか」を確認してください。対称的なボード（両者がそのランクを持ちやすい板）や、3bet非対称ボードではOCターンの効果が弱まります。

---

### ブランクターン（平均74.6%）

**K♣7♦2♠ + 3♣ターン（GTO実測: 91.2%）**

ドライボードのブランクは非常に高い。3というブランクカードが落ちても、K72rでIPが持っていたナッツアドバンテージはそのまま続きます。「何も変わらない = フロップ時点の優位が続く」ということです。

**K44 + 9♥ターン（GTO実測: 96.2〜97.4%）**

K44はドライボード。9はブランク。ドライボードのナッツアドバンテージが完全に維持されるため、97%前後という高い頻度を示します。

**Q♥8♦3♠（スーテッド）+ J♥ターン（GTO実測: 42.0%）**

これがブランク分類の最低値です。Q83ssはスーテッドボード（ダイヤ2枚）。JはQより低いためOCでもペアでもなく、フラッシュ絡みでもないためブランク分類です。

しかしQ83ssというボードでは、OOPのコールレンジに豊富なドロー系ハンドが含まれています。さらにJhというカードは「ストレートドローを進める可能性」を持ちます。Jh自体はブランク判定ですが、板のウェット度により全体の頻度が下がります。

**ブランクの「隠れたドロー強化」**: 形式的にブランクに分類されるカードでも、ウェットなボードでは隣接するランクがストレートドローを微妙に進める場合があります。これが74.6%という平均と、42%〜100%という広い分散の理由です。

---

### コネクターターン（平均69.9%）

**9♠8♣5♦ + 6♣ターン（GTO実測: 架空ボード）**

9-8-5-6のコネクション。OOPがフロップで保有していた7xのガットショットが5-6-7-8-9の完成に近づきます。また7xのOESDも大幅に進行します。このためIPのCBet頻度は下がります。

**実測例: K♠Q♣T♠（KQTss）+ J♦ターン（GTO実測: 41.1%）**

これが全270シナリオの最低値です。

K-Q-T-J というボードでは、A を含むハンド（AK、AQ、AJ等）で A-K-Q-J-T のブロードウェイストレートが完成し、9 を含むハンドでも K-Q-J-T-9 のストレートが完成します。ストレート未完成のハンドも K-Q-J-T の4連続により OESD（A か 9 で完成）となり、IPもOOPも強いストレート系ハンドが豊富に揃います。さらに J 自体は IP も OOP も多く保有するランクのため、IP の「相対的優位」が消えます。この特殊な状況が41.1%という低い値を生み出しています。

**対照例: AAK + Q♠ターン（GTO実測: 100.0%）**

同じコネクター分類でも、AAKというドライ超高位板では100%です。AAKでQが落ちてもIPの優位（AKやAA等の超強ハンド）は揺るがないからです。

コネクターターンの効果は、「コネクションが実際にOOPのドロー完成に直結するかどうか」によって大きく変わります。

---

### フラッシュターン（平均68.5%）

**AT7ss（スペード2枚）+ K♠ターン（GTO実測: 92.2%）**

AT7ssのスーテッドボードにKスペードが落ちた場合。KはAより低いためOCではありませんが、スペードの3枚目です。フラッシュ分類に該当します（OC/フラッシュ重複でフラッシュ優先）。

ただしKという高いランクのカードはIPのレンジも強化します。AT7ssでIPが持っていたKx系ハンドが強化されるため、92.2%という比較的高い値になります。これはフラッシュ分類の中で最も高い値です。

**J♥T♣9♠（JT9ss）+ 8♠ターン（GTO実測: 56.7%）**

JT9ssというウェットなコネクテッドボードに8スペードが落ちた場合。8sは「コネクターかつフラッシュ」の重複ケースです。6-7のハンドで 6-7-8-9-T のストレートが完成し、7 を含むハンド（76、87 等）でも 7-8-9-T-J のストレートが完成します。さらにスペードのフラッシュドローも進行します。OOPのレンジが大きく強化されるため、56.7%と低くなります。

**Q♥8♦3♠（Q83ss）+ J♠ターン（GTO実測: 54.2%）**

これがフラッシュ分類の最低値です。Q83ssのスペード（3とQのスペード、またはスペードのボード）にJスペードが落ちた場合、フラッシュドローが完成します。OOPがコールしていたスペードのドローが一気に完成し、IPの優位が大幅に削られます。

## 6-7 板タイプ × ターンカードの全体マトリクス

270シナリオを板タイプ別に集計すると、次のパターンが浮かび上がります。

### 板タイプ別 分類別平均CBet頻度（TexasSolver実測）

| 板タイプ | ペア | OC | ブランク | コネクター | フラッシュ |
|---|---|---|---|---|---|
| **ドライ** (K72r, K44等) | 98% | 86% | 86% | 91%† | — |
| **セミウェット** (J75r等) | 84% | 65% | 61% | 64% | — |
| **スーテッド** (AT7ss等) | 88% | 77% | 66% | 62% | 69% |
| **コネクテッド** (876r等) | 87% | 73% | 68% | 70% | 61% |

†ドライ板のコネクター91%は、AAKやKK9という超ドライ板が含まれるため高め。これらを除くと実際はより低くなります。

（出典: TexasSolver実測, 270シナリオ。2026-04-23）

このマトリクスから読み取れる法則:

**法則1: どの板タイプでもペアが最高**

縦に見ると、ペア行が常にその板タイプの最高値です。ペアターンの原則「常に高いCBet」はすべての板タイプで成立します。

**法則2: ドライ板はすべての分類で高い**

ドライ板の行は全体的に高い値です。ドライ板でIPが確立したナッツアドバンテージはターンカードによらず維持されます。「ドライ板のバレル = 全自動」というルールが成立します。

**法則3: フラッシュ・コネクターはスーテッド/コネクテッド板で低下**

OOPのドロー系コールが多いスーテッド・コネクテッド板では、フラッシュターン・コネクターターンがOOPを強化するため、CBet頻度が顕著に下がります。

## 6-8 真の決定因子と判断の本質

5分類の背後には、ひとつの単純な原理があります。

> **「ターンカードがIPのレンジをOOPのレンジよりも多く強化するほど、CBet頻度は高くなる」**

この原理で全分類を再解釈できます。

| 分類 | IPへの影響 | OOPへの影響 | 結果 |
|---|---|---|---|
| ペア（高位） | セット→FH等で大幅強化 | コールレンジのKx等は少ない | IP圧倒的優位 → 高CBet |
| OC（通常） | Ax/Kxが多いIPが強化 | BBのAx等は少ない | IP優位 → 高め |
| ブランク | 変化最小 | 変化最小 | フロップの優位が維持 |
| コネクター（ウェット板） | IPのドローも一部完成 | OOPの広いコールの中のドローが完成 | OOPの強化が大 → 低め |
| フラッシュ | バックドア一部完成 | フロップでコールしたFDが完成 | OOPの強化が大 → 低め |

5分類は「誰が得するか」を類型化したものです。実戦では「このターンカードはIPとOOPのどちらにより多くの完成したハンドをもたらすか」という問いに3秒で答える訓練として使います。

## 6-9 次章への橋渡し: TurnCard係数

本章で定義した5分類は、第8章「バレルスコア」の入力変数となります。

バレルスコアの式:

```
バレルスコア = FlopType係数 + TurnCard係数
```

5分類のTurnCard係数（値域と意味）:

| 分類 | TurnCard係数 | 根拠 |
|---|---|---|
| ペア | **4** | 平均90.8%と最高。最も積極的なバレルシグナル |
| OC | **3** | 平均76.3%。IPにとって通常有利 |
| ブランク | **2** | 平均74.6%。中立的。フロップの優位が継続 |
| フラッシュ | **1** | 平均68.5%。OOPのドロー完成でIPの優位が低下 |
| コネクター | **0** | 平均69.9%。OOPのストレート完成で最も慎重に |

係数の設計思想: GTO実測の順位と完全に対応しています。係数の差は「バレル積極度の相対差」を表します。ペア=4とコネクター=0の差が4であることは、「ペアターンはコネクターターンよりもはるかに積極的にバレルできる」という実測を反映しています。

FlopType係数（第8章で詳細を扱います）と組み合わせると:

```
バレルスコア ≥ 7 → 積極バレル（ハンドによらず基本的にCBet）
バレルスコア < 7 → ハンド依存（強いハンドのみCBet）
```

この係数の正確な検証と全17セルのGTO一致率については、第8章で扱います。本章では「5分類がどう係数化されるか」の方向性だけを把握してください。

### 問1

### 問3

次の5つのボード×ターンカードの組み合わせで、GTO実測CBet頻度が最も低くなると予測されるのはどれですか。

2. K♣7♦2♠ + A♥ターン
3. J♥T♣9♠ + 8♥ターン（コネクター）

5. K♣7♦2♠ + 3♣ターン

### 解答

- **問1**: 2（9♣はコネクター。J-T-9という連続により、ストレートドローが複数完成・進行する。クラブはフロップに1枚しかなく、フラッシュ分類にはならない。JT9ssのようなスーテッドボードなら別の話だが、本問はJ♠T♣5♥でスペード1枚のみ）

**【GTOとのズレ】**

本章の5分類は、270シナリオのGTO実測を分類という形で圧縮したものです。圧縮には必ず「情報の損失」が伴います。GTOソルバーは各コンボの期待値を個別に計算しており、分類というラベルで丸めたときに生じる誤差が存在します。

最も大きなズレが出るのは「ブランク」分類です。ブランクの実測値は42%から100%という広い分散を持ちます。これは「何も変わらない」という定義自体が正しくても、板タイプやスタック深度、フロップの先行アクションによって大きく変わるためです。ドライ板のブランクは86%平均と非常に高く、セミウェット板のブランクは61%程度に下がります。ブランクを「中立」と単純に考えると、ドライ板で過剰にチェックバックしてしまうミスが生じます。

もうひとつのズレは「OC分類の例外」です。一般ルールではOCターンはIPに有利ですが、K44のようにOOPがAxを多く持つボードではAターンがOOPを強化します（GTO実測77%）。この例外を知らないと、「Aが落ちたから積極バレルできる」と誤った判断をしてしまいます。

フラッシュ分類の誤差も見逃せません。AT7ss + KsのようにOCとフラッシュが重なるケースでは、実際には92%と高い値が出ます。単純に「フラッシュ = 低い」と判断すると、バリューをチェックバックしてしまうことがあります。5分類はあくまで「平均的な方向性」を示すものであり、個別のハンドのバリュー判断を代替するものではありません。

コネクターとフラッシュの重複ケース（例: JT9ss + 8s = 56.7%）のように、複数の「強化効果」が同時に働く場合は、単一分類よりも実際の値が低くなることがあります。重複ケースでは「安全側」に倒す（より低い係数を使う）判断が合理的です。
