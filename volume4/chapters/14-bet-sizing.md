# 第14章　ベットサイズの基本

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ターンとリバーで使う5段階のベットサイズを、ボード状況とハンドの強さから5秒以内に選べるようになる。α式（第9章）の視点をサイズ選択に組み込み、バリューとブラフで異なる選択ロジックを使い分けられるようにする。

---

## 14-1 ベットサイズが決める2つのこと

ベットサイズを選ぶとき、無意識に「強いから大きく打ちたい」という感覚が出てきます。この感覚は半分正しく、半分間違っています。サイズが決めるのは次の2つです。

**ポットの拡大速度**: 大きなサイズを選ぶほど、ポットが急速に膨らみます。ターンで75%ポットを打つとリバー開始時のSPR（スタック対ポット比）が2〜3に下がり、リバーはほぼオールイン圏になります。第12章で確認した通り、ターンのサイズ選択はリバーの設計でもあります。

**相手のコール率（後手下限確率）**: 第9章のα式が示した通り、サイズが小さいほど相手は広くコールしなければならず、サイズが大きいほど相手は狭いレンジでコールできます。

この2点を踏まえて、サイズ選択の基準を「コールレンジを最大化するか、フォールドレンジを最大化するか」で捉えると、実戦での判断が整理しやすくなります。

## 14-2 ターン・リバーで使う5段階のサイズ

本章で扱うサイズを一覧します。オーバーベット（100%超）は基礎の確認にとどめ、詳細は巻�で扱います。

| サイズ | ポットに対する比率 | α（ブラフ損益分岐点） | 後手下限確率 | V:B比率 |
|---|---|---|---|---|
| 33% | 33/133 | **0.25（25%）** | 75% | 3:1 |
| 50% | 50/150 | **0.33（33%）** | 67% | 2:1 |
| 67% | 67/167 | **約0.40（40%）** | 60% | 3:2 |
| 75% | 75/175 | **0.43（43%）** | 57% | 約4:3 |
| 100% | 100/200 | **0.50（50%）** | 50% | 1:1 |

67%（2/3ポット）はGTOソルバーがしばしば採用するサイズで、50%と75%の中間に位置します。実戦では50%か75%を使い分けることが多く、67%は「どちらでも合理的な局面」での選択肢として意識しておけば十分です。

α式の数値を確認すると、一つの法則が見えてきます。ベットが小さいほどブラフの割合を抑える必要があり（33%ベットではバリューの1/3しかブラフを混ぜられない）、ベットが大きいほどブラフを混ぜやすくなります（100%ベットではバリューと同数のブラフが許容される）。

## 14-3 ターンベットサイズの選び方

ターンではサイズ選択の基準が2つあります。「ターンカードの分類」と「ハンドの強さ」です。第8章のバレルスコアと組み合わせて判断します。

### ペアターンとフラッシュターンは33%が主流

GTO実測（107シナリオ、ポット10BB基準、4択サイズ：3BB/5BB/8BB/15BB）の結果を示します。

| ターンカード分類 | 代表シナリオ | 33%(3BB) | 50%(5BB) | 75%(8BB) | 150%(15BB) |
|---|---|---|---|---|---|
| ペアターン（ドライ） | K72r + K♠ | **57%** | 26% | 15% | 1% |
| ペアターン（セミ） | J75r + J♣ | **47%** | 30% | 18% | 6% |
| ペアターン（コネクテッド） | T98r + T♣ | **57%** | 33% | 10% | 0% |
| コネクターターン（セミ） | J75r + T♣ | 36% | 18% | **37%** | 10% |
| フラッシュターン | 987ss + 6♠ | **72%** | 23% | 3% | 2% |

（出典：GTO実測107シナリオ、exploitability < 0.8%、BTN vs BB SRP想定）

ペアターンでは3シナリオ平均で57%が33%を採用しています。フラッシュターンは72%が33%です。この2つのカテゴリは「小サイズで量を取る」戦略が支配的です。

理由はOOP（後手）のレンジ構成にあります。ペアターンが落ちると、OOPが持つセカンドペアや弱いトップペアが相対的に弱体化します。OOPのほとんどのハンドが降りにくくなっているため、IP（先手）は小サイズで広くコールを集めた方がEVが高くなります。

フラッシュターンで「フラッシュが完成したから大きくベット」という発想は直感的ですが、GTO的には誤りです。フラッシュを持つIPは多くのコールを引き出したいため、33%で広くコールさせる方が得になります。フラッシュを持たないIPは33%のブロッキングベットが機能します。どちらの立場でも小サイズが有利になる構造です。

### OCターンとコネクターターンはハンドで二択

OCターン（K72r + A♠）とコネクターターン（J75r + T♣）は、サイズが二極化します。

OCターンのGTO実測では、33%(38%)と75%+150%(44%)がほぼ拮抗しています。「ターンで強化されたハンドかどうか」がサイズの分岐点です。

```
OCターンのサイズ選択:
  AKが2ペアになった、ポケットAAが更にナッツに近づいた → 75%
  KQがAターンでセカンドペアに格下げされた           → 33%または チェックバック
```

コネクターターン（J75r + T♣）では33%(36%)と75%(37%)がほぼ同数です。ハンドクラスによって戦略が分かれます。

```
コネクターターンのサイズ選択:
  2ペア以上（強いハンド）                    → 75%
  トップペア・セミブラフ（OESD完成など）      → 33〜50%
  ミドルペア以下、空振り                     → チェックバック
```

### 実践的な判断フロー（ターン版）

```
Step 1: ターンカードの分類を確認（第6章）
  ペア / OC / ブランク / フラッシュ / コネクター

Step 2: デフォルトサイズを置く
  ペア         → 33%（量を取る）
  フラッシュ   → 33%（量を取る）
  ブランク     → 33〜50%（板タイプで調整）
  OC           → 「強化されたか?」
                 YES（ナッツ〜2ペアに昇格）→ 75%
                 NO（格下げ・変化なし）    → 33%
  コネクター   → 「ハンドは2ペア以上か?」
                 YES → 75%
                 NO  → 33〜50%

Step 3: SPRとコミットメントを確認
  75%を選んだ場合 → リバーSPRが2〜3になる
                   → 「リバーでも大きくベットし続ける覚悟があるか」
                   YES → 実行
                   NO  → 50%か33%に下げる
```

ターンで75%を選んだ後にリバーでチェックバックすることは、ターンのバリューを損なう最大のミスです。75%を打った瞬間、リバーも打ち続けるコミットメントが必要になります。

## 14-4 リバーベットサイズの選び方

リバーのサイズ選択はターンより単純な部分があります。ドローが完成または失敗に確定しているため、ハンドが「バリューかブラフか」に分類しやすくなります。ここで第9章のα式が直接使えます。

### 実測 ─ リバー IP の第一手は約 76% がチェック

10 種類の代表リバーボード × BTN open vs BB defend で TexasSolver 実測した結果、IP の第一手の選好は次のようになりました（ポット 27BB、スタック 80BB）。

| アクション | 平均採用率 |
|---|---|
| **CHECK** | **76.1%** |
| BET（中サイズ ≈ 50% pot） | 22.1% |
| ALLIN（≈ 300% pot 相当） | 1.8% |

リバーは「チェックが基本」であり、ベットする場合も多くが中サイズに集中します。本節以降のサイズ選択ロジックは、この「ベットすると決めた局面」での話だと押さえてください。リバーの大半のスポットでは、まず**ベットすべきかどうか**の判断が先行します。

### バリューベットのサイズ選択

バリューベットの目的は「コールレンジを最大化すること」です。コールされた時に勝てるハンドで、相手に「コールが損でない」と感じさせる小さなサイズか、「コールが損をしてもコールしてしまう」心理を作り出す大きなサイズかを選びます。

ハンドの強さで分類すると次の目安が出ます。

| ハンドの強さ | 具体例 | 推奨サイズ | 理由 |
|---|---|---|---|
| ナッツ〜準ナッツ | セット、フラッシュ、ストレート | 75%〜100% | 相手のコールレンジが弱くても利益が出る |
| 強バリュー | 2ペア、強TPTK | 50%〜75% | 広いコールレンジから多くを取る |
| 標準バリュー | TPTK、弱い2ペア | 33%〜50% | 薄くコールを引き出す |
| 薄バリュー境界 | トップペア弱キッカー | 33%以下またはチェックバック | コールされると負ける可能性が高い |

ここで「ナッツアドバンテージ」という視点が重要になります（第3章参照）。あなたのレンジにナッツが多く含まれ、相手のレンジにナッツが少ない場面（Uncapped vs Capped の対立）では、大きなサイズを使う権利があります。相手がコールできるハンドが少ないため、大きく打っても相手はフォールドするしかなくなります。

逆に、あなたのレンジが「Capped（上限がある）」で強いハンドを示せない状況では、大きなサイズを打つことができません。OOPがターンのチェックコールで弱さを示した後など、ナッツアドバンテージのない状況では小さなサイズに留める必要があります。

### ブラフのサイズ選択

ブラフの目的は「フォールドレンジを最大化すること」です。ここでα式を使います。

```
α = ベット額 ÷ (ポット + ベット額)

33%ベット → α = 0.25 → 相手はフォールド25%でブラフは損益分岐
50%ベット → α = 0.33 → 相手はフォールド33%でブラフは損益分岐
75%ベット → α = 0.43 → 相手はフォールド43%でブラフは損益分岐
100%ベット → α = 0.50 → 相手はフォールド50%でブラフは損益分岐
```

相手がフォールドしやすい（コールレンジが狭い）状況では、大きなサイズが有効です。相手がフォールドしにくい（コールレンジが広い）状況では、小さなサイズを打って相手のフォールドを引き出す必要はなく、チェックバックが選択肢に入ります。

ブラフとして機能しやすいのはα式で「相手が均衡的にコールしてくるとき、ブラフのEVが最低でもゼロになる」サイズです。フォールドしすぎる相手にはブラフのサイズを上げ、コールしすぎる相手にはブラフを控えてバリューを中心にします。

### リバーにおけるナッツアドバンテージとサイズの関係

リバーでのサイズ選択を一段高い視点でまとめると次の原則になります。

```
ナッツアドバンテージ大（Uncapped vs Capped の状況）
  → 大きなサイズ（75%〜100%）が有効
  → 相手はナッツに対して降りるしかないため、大きくベットする権利がある

ナッツアドバンテージ小（両者のレンジが拮抗）
  → 中程度のサイズ（50%〜67%）がデフォルト

ナッツアドバンテージなし（Capped側がベットする）
  → 小さなサイズ（33%〜50%）に留める
  → 大きく打つと相手の強いハンドしかコールしてこない
```

## 14-5 ターンからリバーへのサイズ計画

ターンとリバーのサイズは連動しています。第12章でも触れましたが、ターンのサイズがリバーのSPRを決め、リバーで打てるサイズの幅が変わります。

### ターン50%後のリバー

ターン50%（ポット10BB、ベット5BB）後のリバー開始状況をシミュレートします。

```
ターン前: ポット10BB、スタック80BB
ターン50%ベット（5BB）→ コール後
リバー開始: ポット20BB、スタック75BB
SPR = 75 ÷ 20 = 3.75
```

リバーSPR 3.75は「オールイン圏に近いが、リバーでまだサイズを選べる」状況です。リバーで75%ポット（15BB）を打てば、残スタック60BBに対してポット50BBとなり、リバーで戦いが完結しやすい水準です。

ターン50%はリバーでも中程度のベット（50〜75%）を打てる設計として使えます。

### ターン33%後のリバー

```
ターン前: ポット10BB、スタック80BB
ターン33%ベット（3.3BB）→ コール後
リバー開始: ポット16.6BB、スタック76.7BB
SPR = 76.7 ÷ 16.6 ≒ 4.6
```

ターン33%後はリバーにスタックが多く残ります。リバーで33%から100%まで幅広いサイズを選べます。ターンで小さく打った場合は「リバーで改めてサイズを選ぶ余地を残す」設計として機能します。

### ターン75%後のリバー

```
ターン前: ポット10BB、スタック80BB
ターン75%ベット（7.5BB）→ コール後
リバー開始: ポット25BB、スタック72.5BB
SPR = 72.5 ÷ 25 ≒ 2.9
```

リバーSPR 2.9はほぼオールイン圏です。リバーで75%（18.75BB）を打てば残スタック53.75BBで、ポットサイズとスタックの差が縮まります。ターン75%を選んだ時点で「リバーも大きく攻め続ける」一体設計が前提です。

### 基礎レベルのデフォルト設計

2つのパターンを覚えておくだけで多くの場面をカバーできます。

```
パターンA（積極型）: ターン50% → リバー75〜100%
  → ナッツ〜準ナッツを持ち、ポットを大きくしたい場面

パターンB（量を取る型）: ターン33% → リバー50〜67%
  → 広いレンジで薄くバリューを積み重ねる場面
```

マルチストリートの精緻な計画（backward induction）については巻�で詳しく扱います。本章では「ターンのサイズがリバーのSPRを設計する」という感覚を持つことが目標です。

## 14-6 ハンドクラス別・ターンサイズ早見表

バレルスコアが積極バレルゾーン（7以上）の前提で、ターンカード分類とハンドクラスを組み合わせた推奨サイズです。

| ハンドクラス | ペアターン | OCターン | ブランクターン | コネクターターン | フラッシュターン |
|---|---|---|---|---|---|
| セット・フルハウス・クワッズ | 33〜50% | 75〜100% | 50〜75% | 75% | 33〜50% |
| 2ペア | 33% | 50〜75% | 33〜50% | 50〜75% | 33% |
| TPTK（強）・強セミブラフ | 33% | 33〜50% | 33〜50% | 33〜50% | 33% |
| TPTK（弱）・ミドルペア | 33%またはCB | 33%またはCB | 33%またはCB | CB | CB |
| 純ブラフ（空振り） | CB | CB | CB（高頻度局面のみ33%） | CB | CB |

CB = チェックバック

ペアターンとフラッシュターンでは「どのハンドクラスでも概ね33%」に収束します。OCターンとコネクターターンでは「強いハンド → 大きいサイズ、弱いハンド → 小さいサイズ or CB」の二択が明確です。

## ミニクイズ

### 問1

BTN vs BB、ドライボード K♥7♣2♠（フロップ）に 5♦（ターン）が落ちました。BTNはフロップで33%CBetをし、BBがコールしています。BTNのハンドは A♣K♦（ターン後の役：トップペアKs、Aキッカー）です。ターンのバレルスコアとベットサイズとして最も適切なものはどれですか。

1. バレルスコア = 10（ドライ8 + ブランク2）。33%。Capped とまでは言えないが、TPTKなら広くコールを集める小サイズが合理的
2. バレルスコア = 11（ドライ8 + OC3）。75%。A♣K♦がA落ちで2ペアになったため大きく打つ
3. バレルスコア = 10（ドライ8 + ブランク2）。75%。TPTKは常に大きく打つべき

### 問2

BTN vs BB、リバー到達。最終ボード J♠8♣5♠2♥A♦（5枚）。ポット 30BB。BTNのハンドは A♠K♥です。BTNがリバーでバリューベットするとき、適切なサイズはどれですか。

（役の確認：A♠, K♥ + J♠, 8♣, 5♠, 2♥, A♦ → A=2枚, K, J, 8, 5, 2。best 5 = A-A-K-J-8 → ワンペアAs、Kキッカー）

1. 75〜100%。ナッツのフルハウスを持っているので最大化
2. 33〜50%。AペアのTPTKレベル。コールレンジを広く残す薄バリュー
3. チェックバック。Aペアはリバーでバリューにならない

### 問3

リバーで50%ポットのベット（ポット40BB、ベット20BB）を打ちました。このとき、αはいくつで、相手の必要フォールド頻度は何%ですか。また、バリューコンボが10個あるとき、最大ブラフ数はいくつですか。

1. α = 0.25、相手のフォールド必要頻度25%、最大ブラフ3個
2. α = 0.33、相手のフォールド必要頻度33%、最大ブラフ5個
3. α = 0.43、相手のフォールド必要頻度43%、最大ブラフ7個

---

### 解答

- **問1**: 1（5♦はK♥7♣2♠のドライ板に対してブランク。5はKより低く、フロップ最高ランクのKを超えないためOCではない。バレルスコア = ドライ8 + ブランク2 = 10 → 積極バレルゾーン。A♣K♦はA♣とK♦で、ボードに既にK♥があるためKが2枚 → best 5 = A-K-K-7-5 → ワンペアKs、Aキッカー。TPTKの範囲内であり、33%で広くコールを集める戦略が合理的。GTO実測でK72r + ブランクターンは33%が56%の頻度で採用されている）

- **問2**: 2（A♠K♥の役はワンペアAs（Aペア、Kキッカー）。ナッツやフルハウスではない。AペアはJ♠8♣5♠2♥A♦のボードで多くの相手ハンドに勝てる可能性があるが、2ペアやセットにはコールされると負ける。コールレンジを広く残す33〜50%の薄バリューが適切。選択肢1はハンドの役を誤っており、選択肢3はAペアをバリューとして使えない判断をしている点で不正確）

- **問3**: 2（α = ベット額 ÷（ポット + ベット額）= 20 ÷（40 + 20）= 20 ÷ 60 = 0.33。ブラフが損益分岐になる（ゼロEVになる）フォールド頻度はα = 0.33 = 33%。相手は67%コールしてくるなら先手のブラフはゼロEV。最大ブラフ数 = 10 × α ÷（1 − α）= 10 × 0.33 ÷ 0.67 ≒ 5個。V:B比率 = 2:1 なので、バリュー10個にブラフ5個）

> **本章まとめ**
>
> - ベットサイズは「コールレンジを最大化するか（バリュー）、フォールドレンジを最大化するか（ブラフ）」で基本方針を決める
> - ターンのペアターン・フラッシュターンは33%が主流（GTO実測：ペア平均57%、フラッシュ72%）
> - OCターンとコネクターターンはハンドクラスで二択。強いハンド → 75%、弱いハンド → 33%orチェックバック
> - リバーのバリューサイズはナッツアドバンテージに比例する。Uncapped側は大きく、Capped側は小さく
> - リバーのブラフはα式で設計。50%ベットならα = 0.33、バリュー10個に対してブラフ5個が上限
> - ターン50%後はリバー75〜100%、ターン33%後はリバー50〜67%がデフォルト設計
> - ターン75%はリバーSPRを3以下にする「オールイン設計」。リバーでもベットする意志が前提

**【GTOとのズレ】**

実戦で最もよく見られるズレは「強いハンドを持つと常に大きく打ちたくなる」という傾向です。フルハウスやセットを持ったとき、直感的に75%以上で打ちたくなります。しかしGTO実測では、ペアターンでセットやフルハウスを持つIPでも33%が主流です。理由は「相手を広くコールさせる方が期待値が高い」からです。大きなサイズは相手のコールレンジを絞り込むため、弱いハンドがすべてフォールドしてしまいます。フルハウスに対して強いハンドしかコールしてこない状況では、バリューの取り出しが限定的になります。

もう一つのズレは「ブラフは小さくベットすれば安全」という誤解です。小さなサイズのブラフはα値が小さく（33%ベットでα = 0.25）、相手がフォールドしてくれる頻度が低くても損益分岐に達します。一見すると「安全なブラフ」に見えますが、相手が75%という高い頻度でコールしてくるため、実際には捕まりやすい状況でもあります。ブラフのサイズは「相手がフォールドしてくれる確率」と「ブラフが捕まったときの損失」のトレードオフで決めるものです。相手のレンジが広い（フォールドしにくい）局面での小サイズブラフは、EV計算上では成立しにくいことがあります。

ターンのサイズ計画とリバーの整合性についても、GTOとの乖離が生じやすい部分です。GTOは「ターンで75%を打ったハンドはリバーでもほぼ100%ベットを継続する」という設計をします。実戦では「ターンで強く打ったが、リバーは怖いからチェックバック」というパターンが頻繁に起きます。この「ターンで打ってリバーで止まる」動きは、ターンのベットを「安価なブラフ」に変えてしまい、バリューを最大化できません。ターンのサイズを選ぶ段階で「リバーも打ち続けるか」を先に決める習慣を作ることが、GTOとのズレを縮める最も効果的な方法です。
