# 第17章　4-betポットのターン戦略 ─ SPR≈0.85でのオールイン判断

<!-- textlint-disable -->
<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 4-betポットのターンで生じるSPR≈0.85（残りスタックがポットより少ない状態）を正確に把握し、IPとOOPそれぞれの「プッシュか、チェックか」「コールか、フォールドか」の判断を暗算式で下せるようになる。

---

## 17-1 4-betポットのSPR推移

本書のこれまでの章では、SRP（シングルレイズポット）を主な舞台として話を進めてきました。BTNがオープンしてBBがコールするSRPでは、フロップ前のSPRは約17で、ターン開始時にはおよそ4〜6程度まで下がります。

4-betポットはまったく異なる数字の世界です。SPRが1を下回ることが珍しくありません。これは判断の枠組み自体を変えます。

まず数字を確認してください。

```
4-betポットのSPR推移（BTN 4-bet 22bb → BB call、100BB想定）:

プリフロップ終了後:
  ポット = 44bb
  残りスタック = 78bb
  SPR = 78 ÷ 44 ≈ 1.77

フロップ 33% CBet → BBコール後:
  CBet額 = 44 × 33% ≈ 14.5bb
  ポット = 44 + 14.5 × 2 = 73bb
  残りスタック = 78 − 14.5 = 63bb
  SPR = 63 ÷ 73 ≈ 0.86

フロップ 50% CBet → BBコール後:
  CBet額 = 44 × 50% = 22bb
  ポット = 44 + 22 × 2 = 88bb
  残りスタック = 78 − 22 = 56bb
  SPR = 56 ÷ 88 ≈ 0.64
```

フロップで33%のCBetをして相手がコールするだけで、ターン開始時のSPRはすでに0.86になります。50%CBetならばSPRは0.64まで下がります。どちらの場合も「残りスタックがポットより少ない」状態、すなわちSPR < 1 の世界に入ります。

SPR < 1 が意味することを言葉にすると、「相手の残り全スタックを1回のベットでリスクにさらせる」状態です。逆から言えば、「あなたが1回ベットすれば実質オールインになる」ということでもあります。

SRP のターン（SPR≈4〜6）では第8章のバレルスコアと第10章の後手スコアを使って判断できました。しかし SPR < 1 になると、33%・50%・75%という通常のベットサイズ概念は意味を失います。残りスタック63bbをポット73bbに投入する行為は、どんな「サイズ」を意図していても実質的にオールインです。

---

## 17-2 SPR < 1 = push か check か の2択

SPR < 1 の世界では、IPのターンアクションは事実上の2択に絞られます。

```
SPR < 1 でのIP選択肢:

プッシュ（all-in bet）:
  スタック全額をベット。コールされればショーダウン。
  → バリューのある手で選ぶ

チェック:
  ベットしない。OOPのアクション待ち。
  → バリューが不十分、または相手のフォールドが期待できない手で選ぶ
```

通常のSRPでよく聞く「33%で様子を見る」「50%でセミブラフを打つ」という発想は、SPR < 1 では機能しません。33%のベットでも63bbの「33%」は約21bbであり、ポット73bbに対してまだしも妥当なサイズに見えますが、その後のリバーには残り42bbしかありません。ターンで小さいサイズを打っても、リバーはほぼ必ずオールイン圧力になります。最初からターンのベット自体をプッシュとして扱うのが、最も合理的な計画です。

また、SPR < 1 では「後でもっと大きく打つ」という計画自体が存在しません。プッシュかチェックか、その2択で今すぐ決着をつける必要があります。

---

## 17-3 IPのプッシュ基準 ─ バリューのみ

IPがプッシュを選ぶべきハンドの基準を整理します。核心は「コールされたときに得をするか」という問いです。

OOPがこのプッシュをコールする際に必要なエクイティは後で詳しく計算しますが、概算で約46%です。逆に言えば、IPがプッシュしたとき、OOPはエクイティ46%以上のハンドでコールしてきます。あなたのハンドがOOPのコールレンジに対して50%以上の勝率を持つかどうかが、プッシュの採算ラインです。

```
IP プッシュ基準（SPR ≈ 0.86 時）:

HS ≥ 65（T1: TPTK以上）→ プッシュ推奨
  例: AA, KK, AK on Kxx, セット等
  理由: OOPのコールレンジに対して60〜70%+ の勝率

HS 55〜64（M+: TPWK・強セカンドペア）→ 状況次第
  例: TPWK, ミドルペアでドロー付き
  理由: 勝率50〜55%程度。ボードテクスチャで判断

HS < 55（M-/T3: セカンドペア以下・空振り）→ チェック
  例: 空振りAhigh, 弱ペア, 単独FD等
  理由: プッシュのフォールドエクイティが低い（後述）
```

第5章で確認したハンドの3層分類（T1・M・T3）と同じ枠組みを使います。SPR < 1 のターンでは、T1（強バリュー）のみプッシュが基本方針です。

---

## 17-4 SPR < 1 ではブラフのフォールドエクイティが低い

SPR < 1 でなぜブラフプッシュが機能しないのかを定量的に確認します。

ブラフが採算に合うためには、相手がフォールドしてくれる確率（フォールドエクイティ）が十分に高い必要があります。必要なフォールドエクイティは次の式で計算します。

```
必要フォールドエクイティ = ベット額 ÷ (ポット + ベット額)

SPR=0.86 の場合（スタック63bb、ポット73bb）:
  必要FE = 63 ÷ (73 + 63) = 63 ÷ 136 ≈ 46%
```

46%のフォールドエクイティが必要、つまりOOPが46%以上の確率でフォールドしてくれないとブラフプッシュは損になります。

しかし現実はこうです。OOPが4-betをコールしてフロップもコールしてきたということは、OOPは強いハンドを持っている可能性が高い状態です。TPTKを持つOOPがIPのプッシュをコールする期待値を計算してみます。

```
OOPがTPTK（equity≈60%）でコールした場合の期待値:
  ポットオールイン後のトータルポット = 73 + 63 × 2 = 199bb
  コールのEV = 0.60 × 199 − 63 = 119.4 − 63 = +56.4bb

OOPがTPWK（equity≈52%）でコールした場合の期待値:
  コールのEV = 0.52 × 199 − 63 = 103.5 − 63 = +40.5bb
```

TPTKやTPWK程度でもコールは期待値プラスです。このクラスのハンドがOOPのレンジに多く含まれている以上、OOPはフォールドしません。46%のフォールドエクイティを達成するのは困難であり、T3（空振り・弱ハンド）によるブラフプッシュは採算が合わないのが実態です。

---

## 17-5 OOPのコール必要エクイティ ─ 46%の暗算

IPがプッシュしてきたとき、OOPがコールかフォールドかを決める基準を整理します。

正確なポットオッズ計算は次のとおりです。

```
正確なポットオッズ計算:
  コール額 = IPの残りスタック = 63bb
  コール後の総ポット = 73 + 63 + 63 = 199bb
  必要エクイティ（正確）= 63 ÷ 199 ≈ 31.7%

簡易計算（実戦での暗算に推奨）:
  必要エクイティ ≈ スタック ÷ (スタック + ポット)
                 = 63 ÷ (63 + 73) = 63 ÷ 136 ≈ 46%
```

2つの計算法で数値が異なることに気づいたでしょうか。正確なポットオッズは約32%、簡易計算は約46%です。この差は「すでにポットに投入したbbの扱い方」の違いによります。

正確な計算は「リバーまで含めた全体のポットオッズ」を反映していますが、コールで即ショーダウンになる SPR < 1 では若干計算の前提が変わります。実戦での暗算では**簡易計算の46%を目安**にすることが実用的であり、安全側（守りめ）の基準としても機能します。

HS とエクイティの対応目安は次のとおりです。

| ハンドクラス | HS目安 | equity目安 | コール判断 |
|---|---|---|---|
| TPTK（例: AK on Kxx） | ≈65 | 60〜65% | コール（46%を超えている） |
| TPWK（例: KT on Kxx） | ≈55 | 50〜55% | コール（ギリギリ圏内） |
| セカンドペア（例: 88 on Kxx） | ≈40 | 35〜40% | フォールド（46%未満） |
| コンボドロー（FD+OESDなど） | 状況による | 50〜60% | コール（ドロー込みで到達） |
| 単独FD（例: ナットフラッシュドロー） | ≈30 | 35〜38% | フォールド（46%未満） |

暗算の実戦手順: 「自分のハンドが相手のレンジに対して50%前後以上のエクイティを持つか」を問いかけてください。不確かなときは46%という数字を目安に、HS55以上（TPWK相当）をコール下限として判断します。

## 17-6 実例で確認する4-betターン判断

仕様で示された4つの例をボードと合わせて確認します。いずれもターン開始時 ポット≈73bb、スタック≈63bb（SPR≈0.86）の想定です。

### 例1: AA on K♣7♦2♠9♥（ターン）

カード確認: A, A, K, 7, 2, 9

- ランク: A×2, K×1, 9×1, 7×1, 2×1
- 役: ワンペア A's（best 5 = A-A-K-9-7）
- ストレート確認: A-K-9-7-2。5連続なし。ストレートなし
- HS: オーバーペア ≈ 75

判断（IP視点）: HS=75はT1。OOPのコールレンジに対して65〜70%の勝率が期待できます。9♥はブランク系のターンカードであり、フロップのレンジ優位を維持しています。プッシュが最善です。

判断（OOP視点）: OOPが88を持つ場合。カード確認: 8, 8, K, 7, 2, 9。ランク: K×1, 9×1, 8×2, 7×1, 2×1。役: ワンペア 8's（best 5 = K-9-8-8-7）。このボードでHSはアンダーペア相当で約40〜42です。コール必要エクイティ46%を満たさないため、フォールドが正解です。

### 例2: KQ on K♣7♦2♠9♥（ターン）

カード確認: K, Q, K, 7, 2, 9（ボード同じ）

- ランク: K×2, Q×1, 9×1, 7×1, 2×1
- 役: ワンペア K's（best 5 = K-K-Q-9-7）、TPTK
- HS: TPTK ≈ 65

判断（IP視点）: HS=65はT1の下限付近。9♥はブランクターンでフロップの板バランスを大きく変えていません。OOPのコールレンジに対して60〜65%の勝率が期待できます。プッシュ推奨です。

### 例3: AK on Q♣5♦4♣3♠（ターン）

カード確認: A, K, Q, 5, 4, 3

- ランク: A×1, K×1, Q×1, 5×1, 4×1, 3×1
- ストレート確認: A-K-Q-5-4-3。5連続候補 → 5-4-3-2-A (wheel)。2が必要 → ボードに2なし → ストレートなし。Q-5はつながらない
- 役: Aハイ（best 5 = A-K-Q-5-4）
- HS: 空振り Aハイ ≈ 20〜25

判断（IP視点）: HSが20程度の空振りハンドです。プッシュしてもOOPのTPWK以上に対して勝率は低く、ブラフプッシュの採算も17-4で確認した通り合いません。チェックが正解です。チェック後にOOPがベットしてきた場合はHSが低いためフォールドも有力です。

### 例4: 88 on K♣7♦2♠9♥（ターン、OOP視点）

上記の例1でOOP側として確認しました。カード確認: 8, 8, K, 7, 2, 9。役: ワンペア 8's（アンダーペア）。HS≈40〜42。IPのプッシュに対するコール必要エクイティ46%を下回るため、フォールドが最善です。

## 17-7 ドローのSPR < 1 判断

SRPのターンでは「ドローをセミブラフで打つ」という判断が第12章で確認されました。SPR < 1 のターンでもドローをどう扱うかは重要な論点です。

コンボドロー（フラッシュドロー+ストレートドロー、equity≈50〜60%）とそれ以外のドローで扱いが異なります。

```
ドロー別のSPR < 1 判断:

コンボドロー（FD+SD、equity ≈ 50〜60%）:
  コール必要エクイティ ≈ 46% を超えている
  OOP: IPのプッシュに対してコール可
  IP: プッシュも選択肢、チェックも選択肢（バリューとしても機能するため）

単独FD（ナットフラッシュドロー、equity ≈ 35〜38%）:
  コール必要エクイティ 46% を下回る
  OOP: フォールド（エクイティ不足）
  IP: プッシュはブラフとして機能しにくい。チェック推奨

単独OESD（equity ≈ 32〜35%）:
  同様にフォールドエクイティ基準を満たさない
  OOP: フォールド
  IP: チェック推奨
```

SPR < 1 の世界では「ターンでドローを育てて、リバーで決着する」という計画が成立しません。残りスタックが少ないため、ターンでコールされればほぼリバーでもオールインになります。つまりドローはターン時点で「今のエクイティで全額リスクを取れるか」を問われます。

コンボドローは46%をクリアするため、OOPでのコールは適切です。単独ドローは46%をクリアしないため、フォールドが合理的です。

## 17-8 フロップコール時点で計画を持つ

4-betポットでフロップをコールするとき、あなたはすでにターンのオールイン判断が迫っていることを意識する必要があります。

```
フロップコール時点の確認事項:

1. ターンでプッシュ or コールできるハンドか？
   → HS ≥ 55（TPWK相当以上）あるいはコンボドロー以上

2. フロップコール後のSPRはいくつか？
   → 相手が33%CBetならSPR≈0.86
   → 相手が50%CBetならSPR≈0.64

3. ターンでプッシュ/コールできないならフロップでのコールは損か？
   → T3（air系）はフロップコール自体を再考する
```

GTO的な分析では、フロップコールのレンジ構成には「ターンのプッシュ/コールが採算に合うハンド」が中心に含まれます。空振り系ハンドでフロップをコールし続けると、ターンでの大量フォールドが必要になり、全体として損失になります。

4-betポットの参加者として最初に学ぶべきことは、「フロップコールはターンのオールインへの同意に近い」という感覚です。

## ミニクイズ

### 問1

4-betポット（ポット73bb、スタック63bb、SPR≈0.86）。BTNハンドはA♥A♣。ボード: K♦8♠3♥、ターン: 7♣。

BTNの最善アクションはどれか。

1. 33%ベット（約24bb）で様子を見る
2. プッシュ（63bb all-in）でバリューを最大化する
3. チェックバックしてリバーで判断する

### 問2

4-betポット（ポット73bb、スタック63bb、SPR≈0.86）。BBハンドは8♣8♦。ボード: K♥Q♠5♣、ターン: 4♦。BTNがオールインを宣言した。

BBの最善アクションはどれか。

1. コール。ポケットペアは強いハンドなのでコールが正しい
2. フォールド。HSが低くコール必要エクイティ46%を満たさない
3. コール。KQと比べて負けているが、5か4を含むストレートの可能性がある

### 問3

4-betポット（ポット73bb、スタック63bb）。BBハンドはJ♣T♣。ボード: K♠9♦4♣、ターン: 8♣。

J♣T♣はこのターンでどのような役（またはドロー状態）になるか。そして、BTNがプッシュしてきた場合BBはどう判断するか。

1. OESDのみ（equity≈17%）。フォールド
2. フラッシュドロー+OESD（コンボドロー, equity≈50〜55%）。コール
3. ストレート完成（equity≈80%+）。コール

---

### 解答

- **問1**: 2（SPR≈0.86ではターンの通常サイズ（33%）はリバー圧力を分散させるだけで非効率です。A♥A♣はオーバーペアでHS≈75。ボード K-8-3-7 に対して: A, A, K, 8, 3, 7 → ランク A×2, K×1, 8×1, 7×1, 3×1 → best 5 = A-A-K-8-7 → ワンペアA's。OOPのコールレンジに対して65〜70%の勝率が期待できます。プッシュが期待値最大のアクションです。選択肢1の「様子を見る」はSPR < 1 には存在しない概念、選択肢3のチェックバックはバリューの機会損失になります）

- **問2**: 2（BBのハンド: 8, 8, K, Q, 5, 4 → ランク K×1, Q×1, 8×2, 5×1, 4×1 → best 5 = K-Q-8-8-5 → ワンペア 8's（アンダーペア）。HS≈40程度。コール必要エクイティ≈46%に対して、アンダーペアのequityは35〜40%程度で届きません。フォールドが最善です。選択肢1は「ペアなら強い」という感覚的判断で、必要エクイティを計算していません。選択肢3のストレート可能性: 8-7-6-5-4 や K-Q-J-T-9 など。4♦ターンで5-4-3-2-A を狙うには A, 3, 2 が必要で 88 からは遠い。8のペア単体では採算コールにはなりません）

- **問3**: 2（ボード: K♠, 9♦, 4♣, 8♣ + ハンド: J♣, T♣。カード確認: J♣, T♣, K♠, 9♦, 4♣, 8♣ → スートクラブ: J♣, T♣, 4♣, 8♣ = 4枚。フラッシュドロー確定（5枚目で完成）。ランク確認: K, J, T, 9, 8, 4。ストレート候補: J-T-9-8-7（7が必要）= OESD（両端が7またはQで完成）。K-J-T-9-8 は J と K が非連続（Q が抜けている）→ ガットショット。OESD+フラッシュドロー = コンボドロー。equity≈50〜55%。コール必要エクイティ46%をクリアするためコールが最善です。選択肢1は「OESDのみ」という誤分類で、フラッシュドローを見落としています。選択肢3はストレート完成を主張していますが、J-T-9-8 の4連続はOESDであり完成ではありません）

---

> **本章まとめ**
>
> - 4-betポットでフロップをコールすると、ターン開始時のSPRは≈0.86になる（フロップ33%call後）
> - SPR < 1 では通常のサイズ概念は無効。IPの選択肢は「プッシュ（全額オールイン）」か「チェック」の2択になる
> - IPのプッシュ基準: HS ≥ 65（TPTK以上）でバリュープッシュ。HS < 55（T3・空振り）はチェック
> - OOPのコール基準: 必要エクイティ≈46%（簡易計算）。TPTK（HS≥65）はコール、セカンドペア以下（HS<55）はフォールド
> - SPR < 1 ではブラフのフォールドエクイティが不足する。OOPはコミット傾向が強くフォールドしにくい
> - コンボドロー（equity≈50〜60%）はコール圏内。単独FDやOESD単体は46%に届かずフォールド

---

**【GTOとのズレ】**

本章で示した「HS ≥ 65でプッシュ、HS < 55でチェック」は実戦判断のための簡略基準です。GTO的な分析（Pio Solver、BTN vs BB 4-betポット）では、IPのプッシュ頻度はSPR < 1 の時点で全レンジの85〜90%に達するとされています。つまり理論上はかなり多くのハンドでプッシュが選ばれます。

この乖離の主な原因は、残りスタックが少ない状況での「チェックして次のストリートに先送りする」コストの高さです。チェックバックをしても、リバーはほぼ必ずオールイン圧力がかかります。であれば今すぐプッシュしてポットを取りに行くほうが、多くのハンドでEVが最大化されます。

一方で、ブラフプッシュ比率についてはGTOでも15〜20%程度に抑えられています。これは本章の主張「ブラフのフォールドエクイティが低い」と整合しています。OOPがコミット傾向のためブラフが機能しにくく、純粋な空振りでのプッシュは損失になります。

実戦で最も多いミスは、SPR < 1 になった後もSRPと同じ判断基準（バレルスコアやターンカード分類）を使い続けることです。SPR < 1 の世界ではターンカードの分類よりも「プッシュしてコールされたとき勝てるか」という純粋なエクイティ比較が判断の主軸になります。4-betポットに参加する前に「このハンドはターンのオールインを正当化できるか」を確認する習慣を持ってください。
