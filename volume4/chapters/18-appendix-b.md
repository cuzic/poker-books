# 付録B　用語集

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **この付録の使い方**: 本書（巻④）で使う用語を五十音順とアルファベット順で集約しています。巻④で新たに導入した用語を中心に収録し、巻①〜3の既出用語（HandScore、簡易レンジスコア、ポットオッズ、Rule of 2 and 4など）は「継承用語セクション」で定義を再掲しています。

---

## 【五十音順】

---

### ア行

#### α（アルファ）

先手（ベット側）がブラフを打ったとき、そのブラフが利益になるための最低フォールド率。「ブラフの損益分岐点フォールド率」とも言い換えられます。

```
α = ベット額 ÷ (ポット + ベット額)
```

ベットサイズが決まれば、この式から一意に計算できます。αを中心に、MDF・V:B比率が決まります。詳細 → 第9章

#### α式（アルファしき）

αの計算式全体を指す呼称。リバーのバリューとブラフの最適配分を設計するために使います。"Alpha式"という表記は本書では使いません。詳細 → 第9章

#### アンキャップド（Uncapped） → 「Uncappedレンジ」を参照

#### オーバーベット

ポットサイズ（100%）を超えるベット。125〜150%以上のサイズを指すことが多いです。Uncappedかつポーラード化（二極化）されたレンジを持つ側が、相手のコール判断を難しくするために使います。後手スコアのC値は C=9（100%）・C=11（150%）で対応します。詳細 → 第14章

---

### カ行

#### Cappedレンジ（キャップドレンジ）

ナッツ（そのボードで最強のハンド）が含まれていない、または非常に少ないレンジ。アクション上の理由でナッツが別のアクションに振り分けられた結果として生まれます。典型的な発生パターンは「フロップCBetをコールしたOOP」や「ターンでチェックバックしたIP」です。Cappedなレンジはオーバーベットへの対応が困難であり、相手から搾取されやすいです。詳細 → 第3章

#### ガットショット

5枚のうち中央のランクが1つ抜けているストレートドロー。4アウツ（完成に必要なカードが4枚）です。OESD（8アウツ）と混同しないよう注意してください。

#### キャップドレンジ → 「Cappedレンジ」を参照

---

### サ行

#### セミブラフ

現時点では役が弱い（または役なし）ですが、ドローを持っており、将来カードが完成すれば強い役になれるハンドでのブラフ。ガットショット・OESD・フラッシュドローがセミブラフの候補になります。純粋なブラフ（アウツゼロ）と区別します。

---

### タ行

#### ダブルバレル

フロップでCBetを打ったIPが、ターンでも続けてベットするアクション。バレルスコアを使ってハンド選択なし（積極バレル）かハンド依存かを判定します。詳細 → 第8章・第12章

#### チェックバック

IPがフロップまたはターンでOOPのチェックを受けて、ベットせずにチェックを返すアクション。本書ではターンのチェックバックを「SDV保護」「トラップ（スロープレイ）」「レンジバランス」の3用途に分類します。詳細 → 第12章・第15章

#### 遅延CBet（ちえんシーベット）

フロップでチェックバックしたIPが、ターンでOOPのチェックを受けて初めてベットに出る戦略。フロップのレンジ優位がターンカードで強化された際（OCターンやペアターン等）や、ポジション優位を生かした中長期的な戦略として用います。詳細 → 第12章

#### ドンクベット

OOP（アウトオブポジション）のプレイヤーが、IPのアクションを待たずに先手でベットするアクション。GTOの観点では正当な戦略として再評価されており、特定の条件下（IPのレンジがCappedなとき、レンジ優位が逆転した場面）で有効です。詳細 → 第13章

#### ドロー加点

HandScoreを構成する3要素のひとつ。フラッシュドロー・OESD・ガットショット・バックドアドローのアウツ数に応じて HandScoreに加算される値。フロップとターンでは加算しますが、リバーではドロー加点 = 0 です（役スコアのみ）。詳細 → 第5章・巻⑤ 第5章

---

### ナ行

#### ナッツアドバンテージ

両者のレンジを比較したとき、一方が最強ハンド（ナッツ）をより多く保有している優位性。ナッツアドバンテージを持つ側は大きいベットサイズを使いやすく、相手にとってはコール判断が難しくなります。ターンカードが落ちるたびに更新されます。詳細 → 第3章・第6章

---

### ハ行

#### バレルスコア

ターンでIPがCBet（バレル）を打つかどうかを判定する暗算式。フロップの板タイプを示すFlopType係数とターンカードのレンジへの影響を示すTurnCard係数の足し算で求めます。

```
バレルスコア = FlopType係数 + TurnCard係数
```

FlopType係数: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
TurnCard係数: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0

270シナリオのGTOソルバー実測から導出された係数であり、全17セルのGTO判定と一致します。詳細 → 第8章

#### ハンドエボリューション

ターンカードやリバーカードが落ちることで、ハンドの役が変化すること。「フロップでAKがTPTKだったが、ターンのペアカードでボードがペアになり AKが2ペアに昇格する」などがその例です。ストリートをまたぐたびに役を更新して評価することが基本で、「フロップ時点の役がそのまま続く」という思い込みは典型的な誤りです。詳細 → 第6章

#### ハンドの3層分類

本書でリバーのバリューベット判断に使うハンドの分類体系。強バリュー（ナッツ近辺、ナッツアドバンテージあり）・標準バリュー・ブラフ候補（役なし・弱役）の3層に分けます。詳細 → 第5章

#### 後手スコア（ごてスコア）

相手のベットに対してコール / チェックレイズ / フォールドを判断する式。巻②で導入した式の骨格をターン・リバーに適用します。

```
後手スコア = HandScore + A − 3 − C − M

≥ 8  → チェックレイズ（CR）検討
0〜7 → コール
< 0  → フォールド
```

ターン版とリバー版の違いはドロー加点の有無（ターンでは加算、リバーでは0）とC値の定義域（リバーは100%=9、150%=11を追加）です。詳細 → 第10章・第11章・巻② 第13章

#### MDF（ごてかげん）

先手のベットに対して後手（コール側）が守らなければならない最低防御水準の概念。文脈に応じて以下の3通りに使い分けます。

| 用語 | 用途 |
|---|---|
| **MDFライン** | しきい値・境界として語るとき（「ラインを下回ると...」） |
| **MDF** | 具体的な% 数値として語るとき（「57%」など） |
| **後手スコアの境界値** | 後手スコアの式における判断境界として語るとき（スコア=0の境界） |

```
MDF = 1 − α = ポット ÷ (ポット + ベット)
```

75%ベットならMDF ≈ 57%、50%ベットなら ≈ 67%、33%ベットなら ≈ 75%。本書では「MDF」という表記は使いません。詳細 → 第9章

---

### マ行

#### マルチウェイバリューライン

3人以上のマルチウェイポットでバリューベットとして機能するための最低ハンド強度。HUと比べて1段階以上高い強度が必要になります。

```
HU    : トップペア（状況依存）でもバリューベット可
3-way : 2ペア以上が最低バリューライン
4-way+: セット以上が大ベットのライン
```

詳細 → 第13章

---

### ラ行

#### レンジポーラード化（二極化）

レンジの構成が「ナッツ（非常に強いハンド）」と「ブラフ（非常に弱いハンド）」の二極に偏り、中間のハンドが少ない状態。ポーラード化（二極化）されたレンジはオーバーベットが有効で、相手にとってはコール判断が難しくなります。

## 【アルファベット順】

---

### 一覧

#### A係数（ボード値）

後手スコアの式に含まれるボードのドライ度係数。ドライ=3 / セミウェット=2 / ウェット=1。ターンでは4枚ボードで再評価します。巻②から継承。詳細 → 付録A・巻②

#### C係数（ベット負担）

後手スコアの式に含まれるベットサイズ係数。33%=3 / 50%=5 / 75%=7 / 100%=9 / 150%=11。C=9・C=11 は巻④で追加した拡張値です。詳細 → 付録A・第11章

#### Cappedレンジ → 五十音順「キャップドレンジ」を参照

#### EV（期待値）

Expected Value。ある行動を繰り返したときの平均的な利益（BB単位）。GTO戦略のゴールはEVを最大化することです。

#### FD（フラッシュドロー）

Flush Draw。フラッシュ（5枚同スート）完成に1枚足りない状態。アウツ数 = 9（同スートが残り9枚）。HandScoreのドロー加点 = +13。リバーでは完成 or 未完成の役スコアのみで評価します。

#### FlopType係数

バレルスコアの計算に使う、フロップ板タイプを示す係数。ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3。詳細 → 第8章・付録A

#### HandScore（ハンドスコア）

ハンドの強さを 0〜50 で数値化する指標。後手スコアの中核を成す値です。

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
```

巻②で導入し、巻③で精密化されました。詳細 → 第5章・付録A・巻⑤ 第5章

#### HU（ヘッズアップ）

Heads-Up。2人のプレイヤーによる対戦。M係数 = 0。本書でHU前提で式を使う場合は「HU前提のため M=0」と必ず注記します。

#### IP（インポジション）

In Position。ベットラウンドで後にアクションするプレイヤー（位置的有利）。通常はプリフロップのアグレッサー側。

#### M係数（マルチウェイ補正）

後手スコアの式に含まれるマルチウェイ補正係数。HU=0 / 3-way=3 / 4-way以上=6。プレイヤー数が増えるほど「最強ハンドである確率」が下がるため、ディフェンス閾値を引き上げる効果を持ちます。巻②から継承。詳細 → 付録A・巻②

#### OESD（オープンエンドストレートドロー）

Open Ended Straight Draw。4枚連続のカードがあり、両端いずれかが落ちるとストレートが完成するドロー。アウツ数 = 8。HandScoreのドロー加点 = +12。

#### OOP（アウトオブポジション）

Out of Position。ベットラウンドで先にアクションするプレイヤー（位置的不利）。通常はプリフロップのコーラー側（フロップ以降はBB等）。

#### OC（オーバーカード）ターン

フロップの最高ランクより高いターンカード（A・K・Qなど）。プリフロップオープンレイザー（IP）のレンジに豊富に含まれるため、IPのレンジを強化する傾向があります。TurnCard係数 = +3。詳細 → 第6章

#### Rule of 2 and 4（ルールオブ2アンド4）

アウツ数から勝率を概算する方法（Phil Gordon 由来）。アウツ × 2 で1ストリート分の勝率%、× 4 で2ストリート分の勝率%。巻② 第6章で導入。

```
例: OESD（8アウツ）
  ターン→リバー: 8 × 2 = 16%
  フロップ→リバー: 8 × 4 = 32%
```

#### SPR（スタック対ポット比）

Stack-to-Pot Ratio。現在のスタック ÷ 現在のポット。コミット判断の基準。通常のシングルレイズドポット（SRP）ではフロップ開始時のSPR ≈ 17、3betポットではSPR ≈ 4〜5。SPRが低いほどコミット判断が早く訪れます。巻②から継承。

#### SRP（シングルレイズドポット）

Single Raised Pot。プリフロップで1回のレイズとコールだけで形成されたポット。フロップ開始時のポットは約6BB（6-max・100BBスタック前提）。

#### TPGK（トップペアグッドキッカー）

Top Pair Good Kicker。トップペア + 中程度以上の強いキッカー。例: KQ on K72。HandScore ≈ 15。

#### TPTK（トップペアトップキッカー）

Top Pair Top Kicker。トップペア + そのボードで最強のキッカー。例: AK on A72。HandScore ≈ 18。

#### TPWK（トップペアウィークキッカー）

Top Pair Weak Kicker。トップペア + 弱いキッカー。例: K5 on K72。HandScore ≈ 10。

#### TurnCard係数

バレルスコアの計算に使う、ターンカードのレンジへの影響を示す係数。ペア=+4 / OC=+3 / ブランク=+2 / フラッシュ=+1 / コネクター=+0。詳細 → 第8章・付録A

#### Uncappedレンジ

ナッツ（そのボードで最強のハンド）を含む可能性があるレンジ。プリフロップのオープンレイザー、フロップのCBet打者、フロップのCR打者のレンジは原則としてUncappedです。Uncappedなレンジを持つプレイヤーはオーバーベットを含む攻撃的なラインを実行できます。詳細 → 第3章

#### V:B比率

バリュー : ブラフ 比率。ベットレンジ中のバリューコンボ数とブラフコンボ数の比率。α式から上限が決まります。

```
V:B比率（上限）= (1 − α) : α = ポット : ベット額
例: 75%ベット → α=0.43 → V:B上限 ≈ 57% : 43%
```

詳細 → 第9章・付録A

## 【巻①〜3 継承用語（定義再掲）】

---

### 一覧

#### 簡易レンジスコア

ボード全体のCBet頻度を 0〜10 で予測するマクロモデル。ストレート要素・フラッシュ要素・ハイボードリスクを入力とします。フロップのレンジCBet頻度の予測値であり、ドライ度そのものではないことに注意してください。

```
簡易レンジスコア = 10 − ストレート要素 − フラッシュ要素 − ハイボードリスク
≥7: ドライ / 4〜6: セミウェット / ≤3: ウェット
```

巻②で導入。巻④では主に板タイプの分類（A係数の決定）に使います。

#### 先手スコア

IPのCBet判断式。巻②で導入。

```
先手スコア = HandScore + A − M
≥ 7 → ベット（33%基準）
< 7 → チェックバック
```

巻④ではバレルスコアがターン攻撃の主要式となりますが、先手スコアは第1章・第3章の概念整理で参照します。

#### 後手スコア（フロップ版）

相手のフロップCBetに対するコール / CR / フォールド判断式。巻② 第13章で導入。

```
後手スコア = HandScore + A − 3 − C − M
  C: 33%=3 / 50%=5 / 75%=7
≥ 8 → CR検討 / 0〜7 → コール / < 0 → フォールド
```

巻④（ターン版・リバー版）はこの式の骨格を継承し、ドロー加点の有無とCの定義域を調整します。

#### CBet統合式

巻②で導入したフロップのCBet判断式。本書では直接使いませんが、バレルスコアの設計思想の基礎になっています。

#### ブロッカー加点

HandScoreを構成する3要素のひとつ。相手のナッツハンドを構成するカードを自分が持っていると、HandScoreに+2〜+3が加算されます。第7章（ブロッカー基礎）で詳しく扱います。

#### 精密レンジスコア

簡易レンジスコアを精密化したCBet頻度予測モデル。外れ値ボードを吸収します。巻③で導入。巻④でも参照しますが、式の詳細は巻③を参照してください。

#### 役スコア

HandScoreを構成する3要素のひとつ。ハンドの役（ペア・2ペア・セット・ストレート・フラッシュ・フルハウス・クワッズなど）に対応する固定値。巻⑤ 第5章で導入。付録A（HandScore早見表）も参照。

#### ポットオッズ

コール判断の基礎数値。コール額 ÷ 最終ポット（コール後のポット合計）で計算します。ポットオッズが必要勝率を上回ればコールが合理的です。巻①で導入。

```
例: ポット100、相手ベット50
  コール額=50、最終ポット=200
  ポットオッズ = 50 ÷ 200 = 25%
  → 25%以上の勝率があればコールが正当
```
