## C-1 シリーズ全体の構造

『迷わないポーカー』シリーズは、テキサスホールデムの意思決定をストリートごとに体系化しています。各巻は独立した一冊として読めますが、概念と式が巻をまたいで継承・拡張される関係にあります。

| 巻 | タイトル | 中心テーマ | 状態 |
|---|---|---|---|
| **巻①** | プリフロップ | ハンド評価とオープン / フォールドの判断 | 既刊 |
| **巻②** | フロップ[基礎] | CBet頻度・サイズ・ディフェンスの基礎フレーム | 既刊 |
| **巻③** | フロップ[応用] | レンジ推定・精密化・相手への搾取 | 既刊 |
| **巻④** | ターン・リバー[基礎]（本書） | バレルスコア・α 式・後手スコア両版 | 本書 |
| **巻⑤** | ターン・リバー[応用] | 3軸統合・backward induction・高度戦術 | 既刊 |
| **巻⑥** | トーナメント | ICM equity / M 値 / ICM 補正 | 既刊 |

## C-2 各巻の暗算式マップ

各巻が提供する暗算式を一覧にします。本書（巻④）の式はすべて巻②・巻③の式の延長として設計されています。

### 巻①の暗算式

```
オープンスコア = H + L + ボーナス − ペナルティ
  H: 高い方のカード値（A=14, K=13, …, 2=2）
  L: 低い方のカード値
  ボーナス: ペア+10, スーテッド+3, コネクター+1, ギャップ2以内+0.5
  ペナルティ: ギャップ4以上−1, 両方9未満−1
  判定しきい値（6-max）: UTG≥24 / MP≥22 / CO≥21 / BTN≥18 / SB≥22

3betスコア:
  Score₃ = H + 0.5L + B + S + C − G − R

ポットオッズ:
  必要勝率 ≈ コール額 ÷ 最終ポット

セットマイニングの目安:
  コール額 × 15 ≤ 相手スタック
```

### 巻②の暗算式

```
簡易レンジスコア（0〜10, CBet頻度予測）:
  簡易レンジスコア = 10 − ストレート要素 − フラッシュ要素 − ハイボードリスク
  ≥7: ドライ / 4〜6: セミウェット / ≤3: ウェット

HandScore（ハンドの強さ 0〜50）:
  HandScore = 役スコア + ドロー加点 + ブロッカー加点
  役スコア例: セット以上=30 / OP=20 / TPTK=18 / TPGK=15 / TPWK=10

CBet統合式（フロップCBet判断）:
  CBetスコア = HandScore + (簡易レンジスコア − 5) + ポジション係数

先手スコア（IPのCBet判断）:
  先手スコア = HandScore + A − M
  A: ドライ=3 / セミ=2 / ウェット=1  M: HU=0 / 3-way=3 / 4-way+=6
  ≥7: ベット（33%基準） / <7: チェックバック

後手スコア（ディフェンス判断）:
  後手スコア = HandScore + A − 3 − C − M
  C: 33%=3 / 50%=5 / 75%=7
  ≥8: CR検討 / 0〜7: コール / <0: フォールド

MDF:
  α = ベット額 ÷ (ポット + ベット額)
  MDF = 1 − α
  例: 75%ベット → α=0.43 → MDF=57%
```

### 巻③の暗算式

```
精密レンジスコア（簡易レンジスコアの精密化）:
  外れ値ボードを吸収したCBet頻度予測モデル
  簡易レンジスコアの延長線上にあり、9マスマトリクスに直結する

HandScore精密化:
  巻②のHandScoreを相手レンジ・ポジション・SPRを加味して補正
```

### 巻④の暗算式（本書）

```
バレルスコア（ターン攻撃）:
  バレルスコア = FlopType係数 + TurnCard係数
  FlopType: ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
  TurnCard: ペア=4 / OC=3 / ブランク=2 / フラッシュ=1 / コネクター=0
  ≥7: 積極バレル（全レンジCBet推奨） / <7: ハンド依存

α 式（リバー配分）:
  α = ベット額 ÷ (ポット + ベット額)
  MDF = 1 − α
  V:B比率（上限）= ポット : ベット額

後手スコア（ターン版）:
  後手スコア = HandScore + A − 3 − C − M
  C: 33%=3 / 50%=5 / 75%=7
  ドロー加点あり / A値はターン4枚で再評価

後手スコア（リバー版）:
  後手スコア = HandScore + A − 3 − C − M
  C拡張: 100%=9 / 150%=11 を追加
  ドロー加点 = 0（役スコアのみ）
```

## C-3 本書の4式が「何を継承し何が新しいか」

本書の4つの暗算式は、それぞれ巻②・巻③の特定の式を直接的な起点として設計されています。以下の表で対応関係を確認してください。

| 巻④の式 | 巻②/3の起点 | 継承している部分 | 巻④で新しい部分 |
|---|---|---|---|
| **バレルスコア** | 簡易レンジスコア（板タイプ分類） | 板タイプをドライ/セミ/スーテッド/コネクテッドに分類する考え方 | ターンカード係数（+0〜+4）を追加して「ターン後の攻撃適正」を1値で表す。270シナリオのGTO実測から係数を検証。 |
| **α 式** | MDF（α = ベット ÷ ポット+ベット） | 計算式そのもの。巻②で既にMDFとして使用 | リバーのバリュー/ブラフ配分を設計する主役として前面に出す。V:B比率との接続を明示。 |
| **後手スコア（ターン版）** | 後手スコア フロップ版（巻② 第13章・第16章） | 式の骨格：HandScore + A − 3 − C − M。閾値（≥8 / 0〜7 / <0）。係数の定義（A・C・M）。 | ターンカードによるHandScoreの更新方法（ハンドエボリューション）を詳説。A値をターン4枚で再評価する手順。 |
| **後手スコア（リバー版）** | 後手スコア フロップ版（巻② 第16章） | 式の骨格（同上）。C=3/5/7の定義。 | C拡張（C=9 / C=11）でオーバーベットへのディフェンスに対応。ドロー加点=0ルール。 |

**重要な確認事項**: 後手スコアの式の形（HandScore + A − 3 − C − M）は巻②から変わっていません。覚え直す必要はなく、巻②で学んだフレームがそのままターン・リバーに通用します。変わるのは入力値（HandScoreとA値のストリートごとの更新方法）と、C値の定義域（リバーのC拡張）だけです。

## C-5 読書ルートの推奨

### ルートA：シリーズ順に読む（推奨）

```
巻①（プリフロップ）
  ↓ ハンド評価の基礎・ポットオッズを習得
巻②（フロップ基礎）
  ↓ 簡易レンジスコア・HandScore・CBet統合式・後手スコアを習得
巻③（フロップ応用）
  ↓ 精密レンジスコア・レンジ推定・搾取を習得
巻④（ターン・リバー基礎）← 今ここ
  ↓ バレルスコア・α 式・後手スコア（ターン版・リバー版）を習得
巻⑤（ターン・リバー応用）
  3軸統合・backward induction・高度戦術
```

このルートが最も滑らかです。各巻の概念が次巻の土台になっているため、前巻の式に迷うことなく本書を読み進められます。

### ルートB：巻④から始めたい場合

巻④から読む場合、最低限必要な前提知識は以下のとおりです。

**巻②（フロップ基礎）から必須の概念**:

- **HandScore**: 手の強さを数値化する式（役スコア + ドロー加点 + ブロッカー加点）
- **簡易レンジスコア**: ボードのドライ度を0〜10で評価し、板タイプを分類する式
- **後手スコア**: 相手のベットに対するコール / CR / フォールドの判断式
- **ポットオッズ**: コール額 ÷ 最終ポットで計算する必要勝率
- **Rule of 2 and 4**: アウツ数から勝率を概算する方法
- **SPR（スタック/ポット比）**: コミット判断の基準

**巻③（フロップ応用）から推奨の概念**:

- **精密レンジスコア**: 外れ値ボードの補正方法
- **9マスマトリクス**: ハンドクラスとボードタイプを掛け合わせた判断表

巻③は必須ではありませんが、第14章（ベットサイズ）や巻⑤の高度戦術では巻③の「レンジポラライゼーション」の概念が背景にあります。

### ルートC：特定テーマだけを深掘りしたい場合

**ターンの攻撃判断だけを習得したい**

第1章 → 第3章（Capped/Uncapped）→ 第6章（ターンカード5分類）→ 第8章（バレルスコア）→ 第12章（IPの攻撃）→ 第16章（ドリル：ターン10問）

**リバーのバリュー/ブラフ設計だけを習得したい**

第5章（ハンドの3層分類）→ 第9章（α 式）→ 第7章（ブロッカー基礎）→ 第12章（IPの攻撃のリバー部分）→ 第16章（ドリル：リバー10問）

**ディフェンス判断だけを習得したい**

第10章（後手スコア ターン版）→ 第11章（後手スコア リバー版）→ 第13章（OOPの応戦）→ 第16章（ドリル）

## C-6 用語の変遷と統一

シリーズを通じて用語が精密化されてきた箇所があります。本書を読む際に参考にしてください。

| 概念 | 旧表記（巻②時点） | 巻④での表記 | 変更の理由 |
|---|---|---|---|
| 最低ディフェンス頻度 | MDF | MDF（3系統） | 「守る」文脈・「頻度」文脈・「スコア」文脈で使い分けるために3系統化 |
| ボード評価指標 | BoardScore | 簡易レンジスコア | CBet頻度予測モデルとしての本質を名称に反映 |
| 精密版ボード評価 | BDM v5 | 精密レンジスコア | 簡易との対比を明確にするため |

**「MDF」の3系統**:

- **MDFライン**: しきい値・境界として語る場合（「ラインを下回ると...」）
- **MDF**: 具体的な% 数値を語る場合（「75%ベット時のMDFは57%」）
- **後手スコアの境界値**: 後手スコアの式の出力と比較する場合（「後手スコアが後手スコアの境界値を超えればコール」）

いずれも同じ概念の、文脈に応じた表現です。数値は常に「MDF = 1 − α」から計算できます。

## C-7 シリーズの暗算式の連鎖

巻①〜4の式は、より精密な判断へと連鎖する構造を持っています。どの巻の式も「入力を単純化して出力を出す」という設計思想は共通しています。

```
【巻①】プリフロップ判断
  オープンスコア → どのハンドでフロップに進むか
     ↓
【巻②】フロップ判断（基礎）
  簡易レンジスコア → 板タイプ（A 係数）の決定
  HandScore（役スコア + ドロー加点 + ブロッカー加点）→ ハンド強度の数値化
  CBet統合式 / 先手スコア → IPの攻撃判断
  後手スコア → OOPのディフェンス判断
     ↓
【巻③】フロップ判断（応用）
  精密レンジスコア → 外れ値ボードへの対応
  9マスマトリクス → レンジ×ボードの体系的整理
     ↓
【巻④】ターン・リバー判断（本書）
  バレルスコア = FlopType係数 + TurnCard係数 → ターン攻撃の判断
  α 式 = ベット ÷ (ポット + ベット) → リバーのバリュー/ブラフ配分
  後手スコア（ターン版）→ ターンのディフェンス判断
  後手スコア（リバー版）→ リバーのディフェンス判断
     ↓
【巻⑤以降】応用・統合
  3軸統合 / backward induction / トーナメント対応
```

巻②の後手スコアと本書の後手スコアは同じ式です。式の形は変わらず、適用するストリートとHandScoreの入力値が変わります。巻②で学んだ判断フローがそのままターン・リバーに通用するということを、本書を読む前に確認しておいてください。

> **付録Cまとめ**
>
> - シリーズは巻①（プリフロップ）→ 巻②（フロップ基礎）→ 巻③（フロップ応用）→ 巻④（本書）の順に積み上がる。
> - 本書の4式（バレルスコア・α 式・後手スコアターン版・後手スコアリバー版）はすべて巻②の式の継承・拡張であり、式を覚え直す必要はない。
> - 巻④から読み始める場合は、巻②のHandScore・簡易レンジスコア・後手スコア・ポットオッズ・SPRを事前に把握しておくと理解が大幅に速まる。
> - 「MDF」は巻②の「MDF」と同じ概念を3系統の表現に整理したもの。MDF という表記は本書では使わない。
