# 第4章　アクションとレンジ遷移

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 各アクションがレンジをどう変化させるかを体系化し、フロップからターン・リバーへの「レンジ遷移」を3ストリートにわたって追跡できるようにする。これにより「今この局面で相手が何を持っているか」を素早く推定する土台を築く。

---

## 4-1 アクションはレンジの履歴である

第3章ではCapped（ナッツが少ないレンジ）とUncapped（ナッツを含むレンジ）という概念を学びました。本章ではその状態が「どのアクションのシーケンスによって決まるか」を、フロップからリバーまでの3ストリートにわたって体系化します。

ポーカーの各アクションは単なる意思決定ではありません。アクションを選ぶたびに、自分のレンジに関する情報が相手に開示されます。逆に、相手のアクション履歴から相手のレンジを絞り込むことができます。これを「アクション = レンジの履歴」と捉えてください。

```
プリフロップ前: 両者のレンジ = 全ハンド（1326コンボ）

BTNオープン   → BTNレンジが約45%に絞られる
BBコール      → BBレンジが約45%に絞られる

フロップCBet  → BTN: Uncapped（バリュー＋ブラフ）
フロップコール → BB: Capped（中強度の集合）

ターンCBet    → BTN: さらにバリューヘビー化
ターンコール   → BB: 弱ハンドが除外され、より強い中強度に収束

リバー前:     両者のレンジが最も絞り込まれた状態に到達
```

ストリートが進むほどレンジが収束し、相手の「最もあり得るハンド群」が浮かび上がります。この収束プロセスを「レンジ遷移」と呼びます。

---

## 4-2 5つのアクション別レンジ変化

各アクションがレンジをどう変化させるかを整理します。

### ベット（攻撃開始）

ベットを打つと、ベット側のレンジは「バリューハンド＋ブラフ」にポーラード化（二極化）します。同時に、相手の弱いハンドがフォールドしてレンジから除外されます。GTOの観点では、ベットレンジはバリューとブラフのバランスが必要です。バリューだけでベットすると相手はフォールドしやすくなり、ブラフが増えすぎると相手はコールで搾取できます。

**レンジへの影響**: ベットした側はUncapped化する。相手の弱ハンドはレンジから除外される。

### チェック（パスまたは罠）

チェックは必ずしも弱さを意味しません。チェックを選んだプレイヤーのレンジには「中強度」と「トラップ（スロープレイ）」が混在します。両者がチェックした場合は特殊で、双方のレンジに強いハンドが少ない「両者Capped」状態になります。このとき次のストリートの主導権は「ターンカードで改善した側」が得ます。

**レンジへの影響**: チェックした側はCapped寄りになる。スロープレイの例外あり。

### コール（ついていく）

コールはレンジを「中強度」に収束させます。強いハンド（ナッツ → レイズが推奨）と弱いハンド（フォールドが推奨）の双方がレンジから除外されるためです。コールが続くと中強度はさらに絞り込まれます。フロップコール → ターンコールと重なると「ターンまでコールし続けられる強度を持つハンド」のみが残ります。コールはCapped状態を維持するアクションです。

**レンジへの影響**: コールした側はCapped維持。ストリートを重ねるほど中強度に収束する。

### レイズ（強さの主張）

レイズはレンジを「ナッツ＋一部ブラフ」にポーラード化し、Uncapped状態を生み出します。フロップのチェックレイズ（CR）を例にとると、BBがCRを打つとき、そのレンジはセット・強い2ペア・強いドロー（ナッツ級）とブラフCRで構成されます。中強度の1ペアはCRには向かわず、コールかフォールドに振り分けられます。チェックレイズを受けたIPがコールで返した場合は「3-betするほど強くない中強度以上」に絞られ、CR後はBBがUncapped・IPがCapped気味という非対称状態が生まれます。

**レンジへの影響**: レイズした側はUncapped化する。受けてコールした側はCapped気味になる。

### フォールド（降りる）

フォールドはそのプレイヤーのレンジ遷移を終了させます。残ったプレイヤーの観点では「相手がフォールドしなかった = 最低強度を超えている」という情報が各ストリートで蓄積されます。複数ストリートのコール継続は、それだけ相手のレンジが絞り込まれていることを意味します。

## 4-3 フロップ → ターンの遷移

フロップのアクションシーケンスがターン開始時のレンジ状態を決めます。主な組み合わせを整理します。

| フロップのアクションシーケンス | BTNの状態 | BBの状態 |
|---|---|---|
| CBet → コール | Uncapped | Capped |
| チェックバック → チェック | Capped | Capped |
| CBet → チェックレイズ → コール | Capped気味 | Uncapped |
| CBet → チェックレイズ → 3-bet → コール | Uncapped | Uncapped |

最も頻繁に起きるのは「CBet → コール」のパターンです。このときBTNがUncapped、BBがCappedという非対称状態でターンに入ります。

ターンに1枚のカードが落ちると、フロップのコールレンジが「フィルタリング」されます。ドライボードK♠7♦2♣の後にターンA♥が落ちた例を考えます。フロップでBBのコールレンジにいた「Ax（オーバーカード）」はターンでトップペアに昇格します。逆にKx（トップペア）はA落ちで相対的に弱化します。ターンAは「BBのレンジを強化するカード」であり、BTNのダブルバレルには慎重さが必要です。一方、同じボードにターン3♦（ブランク）が落ちた場合はBBのコールレンジにほぼ変化がなく、BTNのUncappedアドバンテージが維持されます。具体的な判断基準は第8章のバレルスコアで扱います。

## 4-4 ターン → リバーの遷移と4シーケンス

ターンのアクション後のリバー開始状態を、代表的な4パターンで整理します。

### シーケンスA: IPが全ストリートでアグレッサー（3バレル）

```
フロップ: BTN CBet → BBコール  →  BTN: Uncapped / BB: Capped
ターン:   BTNバレル → BBコール
  → BTN: Uncapped維持（バリューヘビー化）
  → BB: 弱ハンド除外 → 強い中強度（TPTK・2ペア・完成ドロー等）に収束
```

2ストリートコールし続けたBBは「コール判断を繰り返せる強度」があったということです。リバーでのBBは強い中強度が主体であり、ブラフへの耐性が高い状態です。

### シーケンスB: ターンでOOPがチェックレイズ

```
フロップ: BTN CBet → BBコール  →  BTN: Uncapped / BB: Capped
ターン:   BTNベット → BBチェックレイズ → BTNコール
  → BTN: Capped気味（CRに3-betしなかった）
  → BB: Uncapped（ターンCR = ナッツ＋ブラフのポーラード化）→ 主導権逆転
```

### シーケンスC: フロップ・ターン両者チェック

```
フロップ: BTNチェックバック → BBチェック  →  BTN: Capped / BB: Capped
ターン:   BBチェック → BTNチェックバック（または遅延CBet）
  → 両者チェック: BTNがさらにCapped強化
  → 遅延CBet: BTNがUncappedを意志表示
```

両者チェック展開では、リバーのドンクベットがBBから出やすくなります。「チェックしてきたIPは弱い」という読みが成立しやすいためです。

### シーケンスD: ターンCR後にBBが主導権を持つ

```
フロップ: BTN CBet → BBコール  →  BTN: Uncapped / BB: Capped
ターン:   BTNベット → BBチェックレイズ → BTNコール
  → BTN: Capped気味  / BB: Uncapped（シーケンスBと同じターン後の状態）
リバー:   BBが主導権を持ち、ナッツバリュー＋ブラフのポーラード化
```

BBがリバーで積極的に動ける立場になります。BTNはシーケンスAとは逆の立場として、Cappedレンジで受け身の対応を迫られます。

## 4-5 実戦での4ステップ追跡フロー

ここまでの内容を実戦で使うための4ステップフローです。

```
ステップ1: プリフロップのアクションからベースレンジを確認
  「BTNオープン ≈ 45%」「BBコール ≈ 45%」
  「3-betポット = BTNの3-betレンジ vs BBのコールレンジ」

ステップ2: フロップのアクションでCapped/Uncappedを更新
  CBet:              BTN → Uncapped
  BBコール後:        BB → Capped
  BBチェックレイズ後: BB → Uncapped、BTNコール後 → Capped気味
  チェックバック:    BTN → Capped

ステップ3: ターンのアクションでさらに更新
  BTNバレル:        BTNのブラフが減少（バリューヘビー化）
  BBコール:         BBの弱ハンドが減少（中強度に収束）
  BTNチェックバック: BTNのCapped化が進行
  BBドンクベット:   BBのUncapped化が進行

ステップ4: リバーで「残ったレンジ」で判断
  相手の残レンジ:  何が最もあり得るか
  自分のレンジ:    今のアクションは相手にどう見えるか
  EV比較:         コール / フォールド / ベットのどれが最大か
```

このフローを実戦で回す習慣が、ターン・リバーの判断精度を上げる最短ルートです。自分のハンドの強さだけで判断せず「今この局面で両者のレンジがどこに到達しているか」を出発点にすることが核心です。具体的にどのアクションを選ぶかは第III部（第11章〜第15章）で扱います。

## ミニクイズ

### 問1

BTNがフロップCBet → ターンCBet → リバーでチェックという展開をとりました。このBTNのリバーレンジとして最も正確な記述はどれですか。

1. バリューハンドのみ（2ストリートベットしたため弱いハンドは残っていない）
2. ナッツに近いハンドと諦めたブラフが混在し、プロテクト目的の中間強度ハンドは少ない
3. 中間強度ハンドが主体（ショーダウン目的でチェックバックした）
4. 完全に弱いレンジ（リバーでチェックするのは諦めのサイン）

### 問2

BTNがフロップをチェックバック、ターンでBBもチェックした状況です。ここでBTNが遅延CBetを選んだ場合、そのレンジとして最も正確な記述はどれですか。

1. 非常に弱いブラフのみ（チェックバック = 弱いため、遅延CBetはすべてブラフ）
2. フロップで打たない理由があった中強度以上のハンドが中心（トップペア・ミディアム強度等）
3. ナッツのみ（チェックバックでスロープレイしていた）
4. どんなハンドでも等確率で遅延CBetを打つ

### 問3

BBがフロップcheckコール → ターンcheckコール → リバーでドンクベットという展開をとりました。このBBのリバーレンジとして最も正確な記述はどれですか。

1. 弱いハンドが主体（2ストリートコール後のドンクベットはブラフが多い）
2. 中程度の強さのハンドが主体（コール継続の延長でベットしている）
3. 強い役（セット・ストレート・フラッシュ等）が中心。ブラフは少ない
4. レンジの判断はできない（ドンクベットは読みにくい）

---

### 解答

- **問1**: 2（2ストリートのベットは「バリュー＋ブラフ」のポーラード化で構成されています。リバーでのチェックには「バリューでリバーも打てるほど強くはない中強度」と「2ストリートブラフを追いかけるのを諦めた」ハンドが残ります。プロテクト目的の中間強度はリバーでも何らかのアクションをとることが多く、チェックには残りにくいです）
- **問2**: 2（フロップのチェックバックは完全に弱いレンジではなく、フロップで打たない理由があった中強度のハンドが含まれます。ショーダウン志向の1ペアや一部スロープレイが残っており、ターンで相手もチェックしてきた場面でBTNが遅延CBetを選ぶのは、このレンジから攻撃を開始するパターンです）
- **問3**: 3（フロップとターンで2回コールし続けたBBは、中強度以上の強度を持つハンドに絞られています。そのBBがリバーでドンクベットを打つのは「さらに強化された」シグナルです。ターンまでのコール継続で弱ハンドはすでに除外されており、リバードンクベットはセット・ストレート・フラッシュといった完成役が中心になります。ブラフが完全に0ではありませんが、頻度は低いです）

> **本章まとめ**
>
> - 各アクションはレンジに情報を刻印する: ベット→ポーラード化（Uncapped化）、コール→中強度収束（Capped維持）、チェック→中強度またはトラップ、レイズ→Uncapped化
> - Capped/Uncappedの状態はアクションの積み重ねで決まり、各ストリートで更新される
> - 最頻パターン「CBet → コール」ではBTN: Uncapped、BB: Cappedがターン・リバーへのデフォルト状態として続く
> - 代表的な4シーケンス（全IPアグレッサー / ターンBB CR / 両者チェック / ターンCR後逆転）でリバー前の状態は大きく異なる
> - 2ストリート全コールした相手のレンジは「強い中強度主体」であり、ブラフへの耐性が高い
> - 4ステップの実戦フローでレンジ遷移を追跡し、リバーで「残ったレンジ」を判断の出発点にする

---

**【GTOとのズレ】**

GTOはすべてのアクションシーケンスで精密なレンジ遷移を計算しています。実戦での最大の「GTOとのズレ」は、レンジ遷移を追跡せずに自分のハンドの強さだけで判断することです。

典型例を挙げます。BTNがフロップでチェックバックし、ターンでもBBがチェックした状況を想像してください。「自分はKTで1ペア = 中程度だから様子を見よう」と判断してしまうプレイヤーがいます。しかしGTO的には、この状況では両者がCapped化しているため、遅延CBetが有効な場面と維持すべき場面が混在します。レンジ遷移を無視した判断は「なぜそのアクションを選ぶか」の根拠を失います。

もう1つの典型的なズレは、「2ストリートコールした相手は弱い」という思い込みです。実際には2ストリートコールレンジは「強い中強度」に収束しており、ブラフへの耐性が高い状態です。「相手がたくさんコールしているから弱い」と誤読してリバーブラフを打つと、コールされて損失が積み重なります。

「相手が今どのレンジを持っているか」を4ステップで継続的に更新する習慣こそが、GTOとの差を縮める最も重要なスキルです。第5章以降で学ぶ暗算式は、この習慣が前提にある状態で初めて正しく機能します。
