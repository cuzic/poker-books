## 本書の主題 ─ 4つの暗算式で最終2ストリートを攻略する

フロップは「ゲームの文脈を決めるストリート」です。しかしチップが最も大きく動くのはターンとリバーです。この2枚によってフロップでの優劣は反転することもあれば、決定的に固まることもあります。ポットが膨らむほど、判断ミスの損失は大きくなります。

本書では、この2ストリートを4つの暗算式で判断します。

**バレルスコア**は、ターンのダブルバレル推奨度を数値化します。**α式**は、リバーのバリュー・ブラフ配分を決める式です。**後手スコア（ターン版）**は、巻2の後手スコアをターンに適用したものです。**後手スコア（リバー版）**は、C係数の拡張とドロー加点の固定をリバー専用に加えたものです。

4つの式を一枚にまとめると、こうなります。

```
バレルスコア = FlopType係数 + TurnCard係数
α           = ベット ÷ (ポット + ベット)
MDF = 1 − α
後手スコア   = HandScore + A − 3 − C − M
```

## 本書で導入する4つの暗算式

各式の形と用途を本文に入る前に確認しておきます。

### バレルスコア（第8章）

```
バレルスコア = FlopType係数 + TurnCard係数

FlopType係数:  ドライ=8 / セミ=6 / スーテッド=4 / コネクテッド=3
TurnCard係数:  ペア=4 / オーバーカード=3 / ブランク=2 / フラッシュ=1 / コネクター=0
閾値: ≥ 7 → 積極バレル推奨 / < 7 → ハンド依存
```

巻2の簡易レンジスコアをターンカードの影響まで拡張した式です。

### α式（第9章）

```
α           = ベット ÷ (ポット + ベット)
MDF = 1 − α

例: 75%ベット → α ≈ 0.43 → MDF ≈ 57%
```

巻2のMDF概念をリバーのバリュー・ブラフ配分に応用した式です。

### 後手スコア（第10章・第11章）

```
後手スコア = HandScore + A − 3 − C − M

≥ 8: チェックレイズ検討 / 0〜7: コール / < 0: フォールド
```

巻2で確立した式の骨格をターンとリバーにそれぞれ適用します。ターン版ではドロー加点が生き、リバー版ではC係数の拡張と「ドロー加点=0」への固定が加わります。

## 想定読者

本書は以下のような読者を想定しています。

**シリーズ読者で、ターン・リバーの基礎を体系化したい方。** フロップ判断の体系がターン・リバーにどう引き継がれるかを知りたい方に向けています。式の骨格は共通なので、巻2の使い方を理解していれば本書の拡張は自然に追えます。

**巻�（フロップ基礎）読了済みの中級者。** ターン・リバーに入ると「なんとなく」の判断が増えがちです。本書はその「なんとなく」を式に変えることを目的としています。具体的な実例と20問のドリルで実戦投入可能なレベルまで仕上げます。

**巻�（応用編）に進む前の基礎固めをしたい方。** 3軸統合・backward induction・高度なオーバーベット戦術は巻5で扱います。本書で4式を先に習得しておくと、応用の議論が格段に追いやすくなります。

## 巻�〜3 との接続

本書は巻�〜3で確立した式をターン・リバーに拡張します。以下は習得済みとして扱います（復習は付録Cを参照）。

```
簡易レンジスコア ─ フロップのレンジCBet頻度予測（0〜10）
精密レンジスコア ─ 簡易版を精密化したモデル（巻�）
HandScore       ─ ハンドの強さ指標（0〜50）
後手スコア（フロップ版）
                ─ HandScore + A − 3 − C（HU前提）/ + M（全般）
A 係数          ─ ドライ=3、セミ=2、ウェット=1
C 係数          ─ 33%=3、50%=5、75%=7
M 係数          ─ HU=0、3-way=3、4-way+=6
Rule of 2 and 4 ─ アウツ × 2（1ストリート）、× 4（2ストリート）
ポットオッズ     ─ コール額 ÷ 最終ポット
MDF        ─ シリーズ共通用語（MDF は使わない）
```
