# 第12章　IPの攻撃 ─ ターン・リバー基礎

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: IPがターンとリバーで持つ攻撃の選択肢を体系化し、第8章のバレルスコアと第9章のα式を実戦に適用できるようになる。

---

## 12-1 IP攻撃の基本フレーム

IP（インポジション）とは、相手の後ろからアクションできるポジションのことです。BTN（ボタン）が最も典型的なIPポジションです。ポストフロップでは、相手のアクションを見てから判断できるという優位性があります。

ターンとリバーでのIP攻撃は、ストリートが違っても共通の3択に整理できます。

```
IP攻撃の3択:

選択肢 A: バリューベット / ダブルバレル
  強いハンドで攻撃を続ける。コールされても利益になる。

選択肢 B: ブラフ / セミブラフ
  弱いハンドまたはドローで攻撃する。フォールドさせることで利益を生む。
  ※ セミブラフはターン限定（ドローが残っている段階のブラフ）

選択肢 C: チェックバック
  ベットしない。ショーダウンを目指す、またはトラップを仕掛ける。
```

ターンとリバーでこの3択を使い分けるための判断式は、すでに学習済みです。ターンは第8章のバレルスコア、リバーは第9章のα式です。本章ではこれらの式を実際のハンドと組み合わせて使います。

2つのストリートで判断の骨格は同じですが、重要な違いが1つあります。ターンにはセミブラフという選択肢が存在しますが、リバーには存在しません。リバーではドローが完成または失敗に確定しているため、「コールされても将来の改善に期待する」余地がなくなります。

## 12-2 ターン IP攻撃 ─ ダブルバレル基礎

ダブルバレルとは、フロップでCBetを打った後、ターンでも続けてベットすることです。単純に繰り返すだけではなく、ターンカードとフロップの板タイプに応じて、打つべきか控えるべきかを判断する必要があります。

この判断に使う式が、第8章で学んだバレルスコアです。

```
バレルスコア = FlopType係数 + TurnCard係数

FlopType係数:
  ドライ       = 8
  セミ         = 6
  スーテッド   = 4
  コネクテッド = 3

TurnCard係数:
  ペア             = 4
  オーバーカード（OC） = 3
  ブランク         = 2
  フラッシュ       = 1
  コネクター       = 0

判定:
  バレルスコア ≥ 7 → 積極バレル（レンジ全体でCBet推奨）
  バレルスコア < 7 → ハンド依存（強いハンドのみCBet）
```

バレルスコアが7以上の「積極バレルゾーン」では、持っているハンドの強弱に関係なく、レンジ全体として攻撃を継続するのが均衡的な戦略です。これはGTO実測270シナリオで、この閾値が全17セルでGTOの積極/消極バレル分類と一致したことで裏付けられています（第8章参照）。

### ダブルバレルの実例

**状況**: BTN vs BB、100BBキャッシュゲーム。フロップ K♦7♣2♠（ドライ）、BTNが33%（2BB）CBet、BBがコール。ターン前ポット: 10BB。

ターン: A♥（オーバーカード）

バレルスコア計算:
- FlopType: ドライ → 係数 8
- TurnCard: A♥。K♦7♣2♠ の最高ランクはK。A♥はKを上回るオーバーカード → 係数 3
- バレルスコア = 8 + 3 = **11** → 積極バレルゾーン

積極バレルゾーンなので、BTNはレンジ全体として攻撃を継続します。ただし、個別のハンドによってはチェックバックの方が合理的な場合もあります。

ハンド別の判断を確認します（ボード: K♦, 7♣, 2♠, A♥）。

BTNハンド A♠K♠の場合:
- カード確認: A♠, K♠ + K♦, 7♣, 2♠, A♥ → A×2, K×2, 7, 2
- 役: 2ペア A's & K's（best 5 = A-A-K-K-7）
- 判断: 強バリュー → ターン50〜75%ベット

BTNハンド K♣Q♦の場合:
- カード確認: K♣, Q♦ + K♦, 7♣, 2♠, A♥ → A×1, K×2, Q, 7, 2
- 役: ワンペア K's（best 5 = A-K-K-Q-7）、フロップのTPTKがAターンでセカンドペアに格下げ
- 判断: バレルスコア11でも、このハンドはA落ちで弱体化。チェックバックが現実的な選択

BTNハンド A♣5♦の場合:
- カード確認: A♣, 5♦ + K♦, 7♣, 2♠, A♥ → A×2, K, 7, 5, 2
- 役: ワンペア A's（best 5 = A-A-K-7-5）
- 判断: トップペア弱キッカー → 50%薄バリューベット

バレルスコアは「レンジ全体として攻撃すべき状況かどうか」を示す指標です。個別ハンドの強さとターンでの役変化を確認してから最終判断を下してください。

### ダブルバレルのサイズ選択

標準的なサイズ選択の基準を示します。

| ハンドクラス | ターンサイズ | 理由 |
|---|---|---|
| ナッツ〜準ナッツ（セット・2ペア以上） | 75%以上 | ポットを大きくしてSPRを下げる |
| トップペア良キッカー（TPTK） | 50% | 薄バリューを取りつつリスクを管理 |
| セカンドペア〜ミッドペア | 33%またはチェック | SDV（ショーダウンバリュー）保護優先 |
| セミブラフ（OESD・FD） | 50〜75% | フォールドエクイティを最大化 |
| 純ブラフ（空振り） | バレルスコア ≥ 7なら50% | 高頻度局面でのみ実行 |

フロップで33%（1/3ポット）CBetをした後はターン50%が標準です。フロップ33%後にターンも33%を続けると、リバーへ持ち込めるスタックが大きくなりすぎて、リバーでの圧力が弱まります。

## 12-3 ターン IP攻撃 ─ 遅延CBet

遅延CBetとは、フロップでチェックバックをしたIPが、ターンでOOPがチェックした後に先手でベットすることです。通常のダブルバレルとは異なる判断ロジックが必要です。

最大の違いは**レンジの意味**です。フロップでCBetをしたIPは「ナッツもブラフも含む幅広い攻撃」を示しています。一方、フロップでチェックバックをしたIPは「中強度のハンドまたはバックドアドロー」が主体と読まれます。ターンでベットすれば「ターンカードで改善した、または改善したように見せる」ストーリーになります。

### 遅延CBetが有効な状況

遅延CBetは「OOPに不利なターンカード」と「IPが改善した局面」が重なった時に機能します。

**OOPのレンジを弱化させるターンカード**:

```
例: K♦7♣2♠ フロップでBTNがチェックバック後
   ターン A♥（OC）、OOPがチェック

→ BBのKx（フロップトップペア）がA落ちでセカンドペアに格下げ
→ BBはOCのAをフォールド方向にプレッシャーを受ける
→ BTNのAx（遅延CBetの主力）が強化
→ 遅延CBetが有効な局面
```

**IPのバックドアドローが完成したターンカード**:

```
例: A♠6♣3♦ でBTNがチェックバック
   BTNハンド T♠9♠（バックドアスペードFD）
   ターン 7♠（スペード3枚目）

→ T♠9♠はフラッシュドロー完成（ナッツに近い）
→ 遅延CBetセミブラフが有効
```

逆に、コネクターターンやフラッシュターンはOOPのドロー系ハンドを強化します。これらの局面では遅延CBetよりチェックバック継続が推奨です。

### 遅延CBetのサイズ

遅延CBetはフロップでチェックバックしているため、ポットがダブルバレルの場合より小さいことに注意します。6-max SRP想定では、フロップチェックバック後のターン前ポットは6BB（プリフロップ分のみ）です。フロップCBet後の10BB（CBet分が加算）より小さいため、50〜75%ポットのサイズが標準です。

## 12-4 ターン IP攻撃 ─ チェックバック

ターンでのチェックバックは「失敗」ではありません。3つの明確な目的があります。

### 目的1: SDV保護（ショーダウンバリュー保護）

中強度のハンドで、ベットして得られるバリューよりも「チェックでリバーへ持ち込む」方が期待値が高い状況です。

典型例は「バレルスコアが高い（積極バレルゾーン）のに、個別ハンドがターンカードで弱体化した」ケースです。

```
例: K♦7♣2♠ フロップでCBet後
   ターン A♥（OC）、バレルスコア = 8 + 3 = 11（積極バレルゾーン）

   BTNハンド K♣Q♠（ワンペア K's）
   → フロップのTPTKがAターンでセカンドペアに格下げ
   → ベットしてコールされると、多くの場合相手のAx（Aペア）に負ける
   → チェックバックでリバーのショーダウンを目指す
```

### 目的2: トラップ（スロープレイ）

ナッツまたはそれに近い強ハンドを持ちながら、あえてチェックバックして相手のブラフを誘う戦略です。第3章で学んだUncappedレンジの強みを活かします。IPのチェックバックレンジには「ナッツが隠れている可能性」があり、OOPはIPの弱さを読みすぎるリスクがあります。

ただしトラップには「相手がリバーで攻撃してくれない」リスクが伴います。相手のレンジがすでに弱いと判断される場合は、ターンでバリューベットする方が期待値は高いことが多いです。

### 目的3: 攻撃の放棄

バレルスコア < 7（ハンド依存ゾーン）かつHandScoreが低い場合は、単純に攻撃を諦めるチェックバックです。空振りのブラフを続けることは損失を拡大するだけです。ショーダウンでわずかに勝てる可能性だけを残して、次のストリートへ移行します。

| バレルスコア | ハンドクラス | 推奨アクション |
|---|---|---|
| ≥ 7（積極） | ナッツ〜準ナッツ | バリューベット（75%+） |
| ≥ 7（積極） | TPTK | バリューベット（50〜75%） |
| ≥ 7（積極） | セミブラフ（OESD・FD） | セミブラフベット（50%） |
| ≥ 7（積極） | SDV系（セカンドペア等） | チェックバック（SDV保護） |
| < 7（依存） | TPTK以上 | バリューベット（33〜50%） |
| < 7（依存） | 強ドロー | 強ドローのみベット |
| < 7（依存） | それ以下 | チェックバック（攻撃放棄） |

## 12-5 リバー IP攻撃 ─ バリューベット

リバーでの基本は「コールされて勝てるか」という問いです。バリューベットの成立条件は「相手のコールレンジに対して50%以上の確率で勝てること」です。これは第9章で確認した原則です。

### HandScoreによる3層分類

リバーに到達した時点で、自分のハンドを3層に振り分けます。

```
強バリュー（HandScore ≥ 20）: コールレンジに対して70%以上の確率で勝てる
  → 75%〜100%ポットのベット
  例: セット、フラッシュ、ストレート、2ペア以上

標準バリュー（HandScore 10〜19）: コールレンジに対して55〜70%程度で勝てる
  → 33%〜50%ポットのベット
  例: TPTK、良い2ペア

薄バリュー（HandScore 6〜9）: コールレンジに対して50〜55%前後の境界
  → 33%以下またはチェックバック
  例: トップペア弱キッカー、ミドルペア
```

### リバーバリューベットの実例

**状況**: BTN vs BB、100BBキャッシュゲーム。

最終ボード: K♠, T♥, 7♣, 5♣, 2♦（全5枚）

ボード読み確認:
- フラッシュ確認: ♣が2枚（T♣は存在せず、ここでは7♣と5♣）。ハンドに♣を加えても合計4枚以下 → フラッシュ不成立
- ストレート確認: K-T-7-5-2。5連続が成立するか確認 → K-Q-J-T-9、T-9-8-7-6などのどれも5連続にならない → ストレートなし
- ペアボード確認: 全ランク1枚ずつ → ペアボードなし

BTNハンド K♣Q♠（best 5 = K♣, K♠, Q♠, T♥, 7♣ → ワンペアK's、Qキッカー）:
- BBのコールレンジにはKT、K7（2ペア）、77（セット）なども含まれるが、KQ以下のKペアに対しては多くの場面でQキッカーが機能する
- コールレンジに対して概ね60〜70%程度の勝率が見込める → 標準バリュー
- 判断: 50%〜75%ポットのバリューベット

### サイズ選択の基準

| ハンドの強さ | ベットサイズ |
|---|---|
| ナッツ〜準ナッツ（セット以上） | 75%〜100%ポット |
| 強バリュー（強い2ペア、TPTK） | 50%〜75%ポット |
| 標準バリュー（TPTK、弱い2ペア） | 33%〜50%ポット |
| 薄バリュー境界（50%前後） | 33%以下またはチェックバック |

大きなサイズのベットは「相手のコールレンジを絞り込む」効果があります。薄いバリューに大きなサイズを選ぶと、コールしてくる相手のハンドが強くなるため勝率が下がります。薄バリューには小さなサイズを選ぶ理由はここにあります。

## 12-6 リバー IP攻撃 ─ ブラフ

リバーでブラフが機能するためには、相手がフォールドしてくれることが必要です。「どのくらいブラフを混ぜられるか」はα式（第9章）で計算します。

```
α = ベット額 ÷ (ポット + ベット額)

ブラフ上限数 = バリューコンボ数 × α ÷ (1 − α)

サイズ別のブラフ上限の目安:
  33%ポット → バリューコンボ数の約1/3がブラフ上限
  50%ポット → バリューコンボ数の約1/2がブラフ上限
  75%ポット → バリューコンボ数の約3/4がブラフ上限
  100%ポット → バリューコンボ数とほぼ同数がブラフ上限
```

### ブラフ候補の選び方（基礎）

同じ強度のコンボが複数あるとき、どれをブラフとして選ぶかが問題になります。基礎レベルでの優先順位は次のとおりです。

| 優先度 | ブラフ候補のタイプ |
|---|---|
| 高 | ショーダウン価値がほぼゼロで、相手のナッツ系コンボをブロックできるコンボ |
| 中 | 外れたフラッシュドロー（特にAハイのナッツスート） |
| 中 | 外れたストレートドロー |
| 低 | 弱いミドルペア（わずかにショーダウン価値がある） |
| 非推奨 | ショーダウン価値のある中程度のハンド |

ブロッカーの詳細は第7章で確認済みです。本章では「ショーダウン価値がほぼゼロのコンボを優先する」という基礎原則だけを押さえてください。

### リバーブラフの実例

**状況**: BTN vs BB、最終ボード K♥, 7♦, 2♣, Q♥, 9♥。ポット40BB。

ボード読み確認:
- ♥の枚数: K♥, Q♥, 9♥ = 3枚 → ボード単体ではフラッシュ不成立。相手が♥を2枚持てばフラッシュ完成
- ストレート確認: K-Q-9-7-2。5連続なし → ストレートなし
- ペアボード: 全ランク1枚ずつ → ペアボードなし

BTNハンド A♦J♣:
- カード確認: A♦, J♣, K♥, 7♦, 2♣, Q♥, 9♥ → ランク A, K, Q, J, 9, 7, 2（7枚）
- 役: best 5 = A♦, K♥, Q♥, J♣, 9♥ → Aハイ（ペアなし）、ショーダウン価値は非常に限定的

75%ポットベット（30BB）のα値: 30 ÷ (40 + 30) = 30 ÷ 70 ≈ 0.43

A♦を持つことで相手のAx系バリュー（AK、AQのA♦を含むコンボ）を削れます。ショーダウン価値がほぼゼロのAハイは、ブラフとして適切なコンボです。

## 12-7 リバー IP攻撃 ─ チェックバック

リバーでのチェックバックにも3つの目的があります。ターンのSDV保護（次のストリートへ持ち込む価値）とは意味合いが異なり、リバーは「配分の最終判断」としてのチェックバックです。

### 目的1: 薄バリューの保護

コールレンジに対して50〜55%程度しか勝てない「薄いバリュー」ハンドは、ベットせずにチェックバックすることで2つの利点があります。

**利点A**: 相手がリバーで仕掛けてきたブラフに対してコールして利益を得られる場合があります。

**利点B**: チェックバックするレンジに中程度のハンドが含まれることで、相手はIPのチェックを一方的な弱さとして利用しにくくなります。

### 目的2: トラップ

ナッツ級のハンドであえてチェックし、相手の後続ベットを待つ戦略です。相手が攻撃的なプレイヤーであるほど、トラップの期待値が高くなります。

### 目的3: 攻撃の放棄

バリューとしても弱く、ブラフとしても向かない中間ハンドは、チェックバックで現在のポットを守ります。

```
攻撃の放棄が適切な状況:
  - 相手のコールレンジに50%未満の確率でしか勝てない
  - ブロッカー効果が弱く、ブラフとしての成立根拠もない
  → チェックバックで「今のポット」を確保
```

## 12-8 ターンからリバーへの基本的な流れ

ターンで打った後、リバーでどう判断するかを基礎レベルで整理します。

### 「ターンで打ったハンドはリバーでも打ちやすい」

ターンでバリューベットをしたハンドは、リバーでも引き続きバリューとして打てることが多いです。ターンのバレルでポットが膨らんでいるため、リバーのバリューベットにはより高い頻度でコールが付いてきます。

逆に、ターンでセミブラフを打ったハンドがリバーでドローを外した場合は、「ブラフに切り替えるか」「チェックバックするか」を判断し直す必要があります。

基礎レベルの判断フローを示します。

```
ターンバレル後のリバー判断（基礎版）:

Step 1: リバーカードでハンドの役を再確認
  → ストレート・フラッシュ等の完成/失敗を確認

Step 2: バリューとして成立するか
  → 相手のコールレンジに50%以上勝てる → バリューベット
  → 50%を下回る → ブラフかチェックバックへ

Step 3（ブラフかチェックバックか）:
  → α式でブラフ枠があり、ショーダウン価値がほぼゼロ → ブラフ
  → どちらにも当てはまらない → チェックバック
```

### 遅延CBet後のリバー

遅延CBet（フロップチェックバック → ターンベット）を打った後のリバーは、通常のダブルバレル後よりポットが小さい状態から始まります。リバーでのバリューベット頻度は高いですが、ブラフを打つ際はα値を確認してサイズを選んでください。

より詳細な「ターン→リバーの連動設計」（backward induction）については、巻5で扱います。本書では「ターンの判断がリバーの判断に影響する」という認識を持った上で、各ストリートを独立して基礎判断することに集中してください。

## ミニクイズ

### 問1

BTN vs BB、フロップ K♦7♣2♠（ドライ）でBTNがCBet、BBがコール。ターン 5♠（ブランク）が落ちた。BTNのハンドは A♠K♥。バレルスコアを計算し、推奨アクションを選んでください。

1. バレルスコア = 11（ドライ8 + OC3）。A♠K♥は2ペアに昇格。バリューベット75%
2. バレルスコア = 10（ドライ8 + ブランク2）。A♠K♥はTPTK。バリューベット50%
3. バレルスコア = 10（ドライ8 + ブランク2）。A♠K♥の役をターン込みで確認してからサイズを決める

### 問2

BTN vs BB、フロップ A♦9♣8♥（セミ）でCBet後BBコール。ターン K♠（OC）が落ちた。BTNハンド A♠Q♦。リバー 2♣（ブランク）が落ちた。BTNはリバーで何を選ぶか。

1. バリューベット50〜75%。A♠Q♦はトップペア+Qキッカー。リバー2♣はどちらのレンジにも影響しない
2. チェックバック。ターンのKで相手のKxが強化されているため、バリューベットは難しい
3. ブラフ75%。A♠Q♦はリバーでブラフに使うべきハンド

### 問3

BTN vs BB、フロップ J♠8♣5♠（スーテッド）でCBet後BBコール。ターン Q♠（フラッシュ）が落ちた。BTNハンド A♣K♦。バレルスコアと推奨アクションを選んでください。

1. バレルスコア = 5（スーテッド4 + フラッシュ1）。ハンド依存ゾーン。A♣K♦はオーバーカード2枚だがHandScoreが低い → チェックバック
2. バレルスコア = 7（スーテッド4 + OC3）。積極バレルゾーン。A♣K♦でダブルバレル
3. バレルスコア = 5（スーテッド4 + フラッシュ1）。ハンド依存ゾーンだがA♣K♦は強いのでバリューベット

---

### 解答

- **問1**: 3（5♠はK♦7♣2♠に対してブランク。5はKより低く、フロップの最高ランクを上回らないためOCではない。バレルスコア = ドライ8 + ブランク2 = **10** → 積極バレルゾーン。A♠K♥の役確認: A♠, K♥ + K♦, 7♣, 2♠, 5♠ → K×2, A, 7, 5, 2。best 5 = A-K-K-7-5 → ワンペアK's（Aキッカー）。フロップのTPTKはAがなければK's pair。ターン5♠でAは出ていない。K♠Q♦ではなくA♠K♥なのでA kicker付きのTPTK = 薄バリューよりは強い → 50%バリューベットが妥当。選択肢3が正しいのは「役を確認してからサイズを決める」というプロセスを正しく踏んでいるから）

- **問2**: 1（ボード A♦, 9♣, 8♥, K♠, 2♣。BTNハンド A♠Q♦。カード確認: A♠, Q♦, A♦, 9♣, 8♥, K♠, 2♣ → A×2, K, Q, 9, 8, 2。best 5 = A-A-K-Q-9 → ワンペアA's（Qキッカー）。ターンKで相手のKxが強化されているが、BTNのAパーはKxに勝る。コールレンジに対してA-A-K-Q-9は多くの場面で60〜70%程度の勝率を持つ → バリューベット50〜75%が適切。選択肢2は「ターンのKで相手が強化された」という点を重視しすぎており、BTN自身のAペアの強さを軽視している）

- **問3**: 1（Q♠はJ♠8♣5♠のスーテッド板にとって「フラッシュ」ターン。スペードが4枚目になりフラッシュが完成する可能性が大幅に上昇するカード。TurnCard係数 = フラッシュ = 1。バレルスコア = スーテッド4 + フラッシュ1 = **5** → ハンド依存ゾーン。A♣K♦はスペードを持たないため、フラッシュ完成の恩恵がない。HandScoreはオーバーカード2枚のみ（ペアなし）= 低い。ハンド依存ゾーン + 低HandScore → チェックバックが推奨。選択肢2はTurnCardの分類を誤っている）

> **本章まとめ**
>
> - IPのターン・リバー攻撃は共通の3択（バリュー/ブラフ/チェックバック）に整理できる
> - ターンのダブルバレルはバレルスコア（第8章）で判断。スコア ≥ 7 → 積極バレル、< 7 → ハンド依存
> - 遅延CBetはOOPに不利なターンカード（OC/ペア）とIPの改善が重なった局面で有効
> - チェックバックにはSDV保護・トラップ・攻撃放棄の3用途があり、どれも「失敗」ではない
> - リバーのバリューベットは「コールレンジに50%以上勝てること」が成立条件。強さに応じて33〜100%+のサイズを選ぶ
> - リバーのブラフはα式（第9章）でバリューコンボ数からブラフ上限を逆算して設計する
> - ターンで打ったハンドはリバーでも打ちやすい傾向があるが、リバーカードで役と状況を再確認してから判断する

**【GTOとのズレ】**

バレルスコアは「レンジ全体として打つべき状況かどうか」を判断する指標です。実際のGTOでは、積極バレルゾーン（スコア ≥ 7）でも個別コンボが100%ベットになるわけではありません。強いバリューハンドはほぼ100%ベットですが、セカンドペアや弱いアンダーペアはチェックバック頻度が上がります。本章で示した「バレルスコア ≥ 7でもSDVハンドはチェックバック」という原則は、GTOの個別コンボ判断と整合しています。

実戦で最も多い「GTOとのズレ」は、ターンのチェックバックが過剰になることです。「ウェットボードだから」「ターンが悪いから」という感覚でチェックバックを選びすぎると、フォールドエクイティを活かせる局面を損失します。バレルスコアで確認してから判断する習慣が重要です。

リバーのバリューベットについても、GTO的には「コールレンジに50%以上勝てるか」という基準よりも細かい計算（各コンボのEVを全レンジとの相互作用で計算）が行われます。特に「薄バリュー」と「チェックバック」の境界ハンドは、相手のレンジ構成によって判断が変わります。「50%」という基準は実用的な目安ですが、相手のコールレンジを過大または過小に評価すると、誤った判断になることがあります。実戦では「相手が何をコールしてくるか」を具体的にイメージしてから判断してください。

遅延CBetについては「フロップCBetをしなかったから何もできない」と思い込むプレイヤーが多い傾向があります。フロップでの選択とターンでの選択は切り離して考えることが大切です。OOPに不利なターンカードが落ち、OOPがチェックしてきた局面では、遅延CBetが明確なプラスEVのアクションになります。
