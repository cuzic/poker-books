# 第11章　後手スコア（リバー版）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 巻2で導入した後手スコアをリバー専用に調整し、コール・チェックレイズ・フォールドを数値で判断できるようになる。

---

## 11-1 後手スコアの復習と「リバー問題」

巻2（フロップ基礎編）で導入した後手スコアは、相手のベットに対するディフェンス判断を数値化した式です。まず式を確認してください。

```
後手スコア = HandScore + A − 3 − C − M

A（ボード値）: ドライ=3 / セミウェット=2 / ウェット=1
C（ベット負担）: 33%=3 / 50%=5 / 75%=7
M（マルチウェイ補正）: HU=0 / 3-way=3 / 4-way以上=6

後手スコア ≥ 8 → チェックレイズ（CR）検討
後手スコア 0〜7 → コール
後手スコア < 0 → フォールド
```

この式は巻2でGTOソルバー実測との照合を経ており、フロップでの一致率は高い水準を保っています。本書 第10章ではこの式をターンに拡張し、A係数の4枚評価とHandScoreの役進化追跡という2点を主な調整点として加えました。

本章のリバー版も、20 ボード × 2 レンジ（balanced / tight）の TexasSolver 実測検証を経ています。**75% ポットベットに対する MDF（最低防御頻度）はバランス型レンジで実測 0.55（理論値 0.571 から ±0.025 の範囲）に収まり**、α 式と後手スコアのリバー拡張が GTO の挙動と整合することが確認できています。詳細は本章末の【GTO とのズレ】で扱います。

本章で問うのは「リバーでもこの式を使えるか、どう修正するか」です。

リバーには、フロップ・ターンと決定的に異なる1点があります。それは**ドローが消滅する**ことです。フロップやターンでは、フラッシュドローやストレートドローが「将来価値」としてHandScoreに加算されていました。リバーではそれが成立しません。すべてのドローは完成か外れかが確定しています。

この「ドロー消滅」という事実がリバー版後手スコアの調整の中心です。加えて、リバーでは先手がオーバーベット（ポット以上のベット）を多用するため、C係数の拡張も必要になります。

## 11-2 HandScoreのリバー版評価 ─ ドロー加点をゼロに

HandScoreは「役スコア + ドロー加点 + ブロッカー加点」の3項目で構成されます。

フロップ・ターンでは、ドロー加点が大きな役割を果たします。フラッシュドロー（9アウツ）なら約13点、OESD（8アウツ）なら約12点が加算されます。この加点は巻2第9章のRule of 2 and 4（アウツ × 2 ≒ 1ストリート分の勝率%）を保守的に丸めた係数（アウツ × 1.5）から計算されます。

リバーでは、ドロー加点の計算根拠が消えます。「次のカードで完成する可能性」が存在しないからです。

```
フロップ/ターンのHandScore: 役スコア + ドロー加点 + ブロッカー加点
リバーのHandScore: 役スコア + ブロッカー加点（ドロー加点 = 0）
```

ドロー加点をゼロにした後、役スコアは「完成後の役」か「外れた後の役」で再評価します。

| ドローの状態 | リバーのHandScore評価 |
|---|---|
| FD（フラッシュドロー）が完成 | フラッシュ = 役スコア25前後 |
| FDが外れ、他の役もなし | ハイカード = 役スコア0 |
| OESDが完成 | ストレート = 役スコア30 |
| OESDが外れ、ペアもなし | ハイカード = 役スコア0 |
| ドロー持ちかつトップペア、ドローは外れ | トップペア = 役スコア10〜18（キッカー次第） |

ドロー加点の消滅は、HandScoreを劇的に変化させます。ターンでフラッシュドロー加点込みHandScore = 15前後だったハンドが、リバーでFDが外れるとHandScore = 0に落下します。逆に、FDが完成すれば一気に25前後に上昇します。

**具体例: FD外れのHandScore変化**

ターン: ボード K♠7♦2♣5♠（スペード2枚）で A♠9♠ を保有（フラッシュドロー進行中）。
HandScore（ターン時点）: 役なし(0) + FD加点(13) = 約13

リバー: Q♦（スペードなし）が落ちた。
HandScore（リバー時点）: A high = 役スコア0、ドロー加点0 → **HandScore = 0**

この変化を後手スコアに反映するとこうなります。

```
ターン（75%ベット、A=2（セミ）、C=7、HU）:
  後手スコア = 13 + 2 − 3 − 7 − 0 = 5 → コール

リバー（75%ベット、A=2（セミ）、C=7、HU）:
  後手スコア = 0 + 2 − 3 − 7 − 0 = −8 → フォールド
```

ターンでコールが成立していたハンドが、リバーでFDが外れると明確なフォールドになります。この変化は「ドローが外れたらフォールド」という直感をスコアで裏付けるものです。

## 11-3 A係数のリバー版評価 ─ 5枚ボード全体で再評価

フロップでA係数（ボード値）を3枚で評価し、ターンで4枚全体で再評価したように、リバーでは**5枚ボード全体**でA係数を再評価します。

```
リバーのA係数（5枚ボード評価）:
  5枚がドライ（ペアボード・散開rainbow・ストレート/FD不成立）= 3
  5枚がセミウェット = 2
  5枚がウェット（フラッシュ完成/ストレート完成形・多数ドロー形成） = 1
```

注意すべきポイントは、リバーカードが落ちることで5枚ボードの性格が変わる場合があることです。

**例1: ドライボードの維持**
ボード K♠7♦2♣A♥Q♦（リバー完成）。散開rainbow、ストレートもフラッシュドローもなし。A=3（ドライ維持）。

**例2: フラッシュ完成によるウェット化**
ボード K♥7♥2♣A♥9♥（リバー）。ハート4枚がボードに出現し、フラッシュが完成している状態。相手のハート×2があればフラッシュ成立。A=1（ウェット）。

**例3: ペアボードの評価**
ボード K♠7♦2♣7♥Q♦（リバー）。7のペアが含まれるがそれ以外は散開。ストレートドロー的な連続性もなし。A=3（ドライ）。ただし、ボードペア（7-7）がある場合、ナッツアドバンテージはIPに偏りやすいことに注意します。

**5枚ボードのA値判定早見表**

| ボード構成 | A値 | 理由 |
|---|---|---|
| K♠7♦2♣A♥Q♦（散開rainbow） | 3 | 5枚ドライ |
| K♠7♦2♣7♥Q♦（ペアボード） | 3 | ペアはドライ要因 |
| K♥7♥2♣5♠9♥（ハート3枚） | 2 | フラッシュ可能性あり（セミ） |
| K♥7♥2♣5♥9♥（ハート4枚） | 1 | フラッシュ完成環境（ウェット） |
| J♥T♠9♦8♣7♦（ストレート完成形） | 1 | 多くのハンドがストレート完成（ウェット） |

フラッシュが「完成している」ボードではA=1を適用します。フラッシュが「完成する可能性がある」ボード（スート3枚）ではA=2を適用するのが基本です。

## 11-4 C係数のリバー版拡張 ─ 100%と150%への対応

巻2でC係数は33%=3、50%=5、75%=7という3段階で設計されました。リバーでは先手がオーバーベット（ポットサイズ以上のベット）を多用するため、C係数を拡張する必要があります。

C係数は後手下限確率から逆算されて設計されています。

```
C値設計の根拠（後手下限確率との対応）:

33%ベット: 後手下限確率 = ポット/(ポット+ベット) = 75%、C=3
50%ベット: 後手下限確率 = 67%、C=5
75%ベット: 後手下限確率 = 57%、C=7
100%ベット: 後手下限確率 = 50%、C=9（リバー専用拡張）
150%ベット: 後手下限確率 = 40%、C=11（リバー専用拡張）
```

C=9とC=11はリバー専用の拡張値です。これらはC=7までと同じ設計思想（後手下限確率からの逆算）で決まります。

**リバーC係数早見表（完全版）**

| ベットサイズ | 後手下限確率（1−α） | C値 | コールできるHandScoreの目安（A=3、HU） |
|---|---|---|---|
| 33%ポット | 75% | 3 | HandScore ≧ 3 |
| 50%ポット | 67% | 5 | HandScore ≧ 5 |
| 75%ポット | 57% | 7 | HandScore ≧ 7 |
| 100%ポット | 50% | 9 | HandScore ≧ 9 |
| 150%ポット | 40% | 11 | HandScore ≧ 11 |

重要なのは、C係数は**ポットサイズではなくベット比率に依存する**点です。ポットが10BBでも30BBでも、ベット比率が75%であればC=7です。この「ポット不変性」のおかげでリバーでも同じC係数テーブルを使えます。

リバーで相手が150%オーバーベットを打ってきた場合、後手スコアはC=11の重みを受けます。HandScoreが10以下のハンドはほぼフォールドになります。これはGTO的に正しい方向性です。大サイズのベットに対しては守れるハンドを絞り込むことが合理的です。

## 11-5 後手スコアのリバー版完全形

フロップ版との比較で、リバー版の調整点をまとめます。

```
後手スコア（共通式）: = HandScore + A − 3 − C − M

【フロップ版】
  HandScore = 役スコア + ドロー加点 + ブロッカー加点
  A = 3枚ボードで評価
  C = 33%=3 / 50%=5 / 75%=7

【ターン版（本書 第10章）からの変更点】
  A = 4枚ボード全体で再評価（フロップA値を引き継がない）
  HandScore = ターンカード後の役で更新

【リバー版（本章）の調整点】
  HandScore = ドロー加点をゼロに（ショーダウン価値のみ）
  A = 5枚ボード全体で再評価
  C = 100%=9 / 150%=11 を追加で使用
  CR閾値（スコア≥8）であっても、コールされて勝てるかを追加確認する
  M = HU前提のためM=0（3-wayではM=3を追加）
```

**リバー後手スコアの判断分岐（HU前提）**

```
後手スコア ≥ 8 → CR検討（ただし「コールされて勝てるか」を確認）
後手スコア 0〜7 → コール
後手スコア < 0 → フォールド
```

この判断分岐はフロップ・ターンと同じです。ただしリバーでは「スコア≥8でCR」の条件に追加チェックが入ります。コールされた場合に相手のバリューに勝てないならCRは誤りです。詳細は7-7で説明します。

## 11-6 リバーでの実戦例 ─ ドライボード3パターン

具体的な局面でリバー版後手スコアを体験します。共通設定として6-max、BTN vs BB（HU、M=0）、100BB、キャッシュゲームを前提とします。

### 実例1: ドライボード + FD外れ（相手の75%ベット）

**ボード**: K♠7♦2♣A♥Q♦（5枚、散開rainbow）
**ポット**: 約30BB、BTNが75%ベット（約22BB）
**BBのハンド**: 9♠8♠

役判定を確認します。ハンド 9♠8♠ + ボード K♠7♦2♣A♥Q♦ で5枚連続を確認します。ランク: 9, 8, K, A, Q, 7, 2。A-K-Q-9-8のうち連続するのは最大でQ-9-8の3枚止まりで、ストレートは不成立です。ボードペアもありません（すべてのランクが1枚ずつ）。スペードはボードに1枚（K♠）と手に2枚（9♠8♠）の計3枚でフラッシュ不成立。HandScore = 0（ハイカード）。

```
A = K♠7♦2♣A♥Q♦（散開rainbow） = 3（ドライ）
C = 75%ベット = 7
M = HU = 0

後手スコア = 0 + 3 − 3 − 7 − 0 = −7 → フォールド
```

外れたドローがハイカードまで落ちた場合、後手スコアは大きなマイナスになります。「ドローが外れたらフォールド」という直感を式で裏付けた形です。

### 実例2: ドライボード + FD完成（相手の75%ベット）

**ボード**: K♥7♥2♣A♥9♥（5枚、ハート4枚）
**ポット**: 約30BB、BTNが75%ベット（約22BB）
**BBのハンド**: Q♥J♦（ハートのフラッシュ1枚Q♥）

役判定: Q♥J♦ + K♥7♥2♣A♥9♥。ハートの枚数: ハンドに1枚（Q♥）+ ボードに4枚（K♥, 7♥, A♥, 9♥）= 合計5枚。5枚同スート = フラッシュ完成。best 5 = A♥K♥Q♥9♥7♥（Aハイフラッシュ）。ただし A♥はボードにあり自分の手には Q♥ のみです。役はフラッシュ（≈役スコア25）。HandScore = 25。

A値: ハート4枚のウェットボード → A=1。

```
後手スコア = 25 + 1 − 3 − 7 − 0 = 16 → CR推奨
```

FDが完成してフラッシュを持った場合、後手スコアはCR域の中央以上になります。ただし相手がナッツフラッシュ（A♥含み）を持つ場合に負けることに注意します。本章のスコア計算はその確率を直接考慮しないため、リバーCRでの「コールされて勝てるか確認」（7-7で説明）が必要です。

### 実例3: ペアボード + 相手の150%オーバーベット

**ボード**: K♠7♦2♣7♥Q♦（5枚、7のペア含む）
**ポット**: 約20BB、BTNが150%オーバーベット（約30BB）
**BBのハンド**: K♣J♠（Kのペア）

役判定: K♣J♠ + K♠7♦2♣7♥Q♦。ランク: K, J, K, 7, 2, 7, Q。Kが2枚（K♣とK♠）、7が2枚（7♦と7♥）、残りQ, J, 2が1枚ずつ。best 5 = K-K-7-7-Q（2ペア、K's & 7's、Qキッカー）。HandScore = 22（2ペア、巻2基準）。

A値: ペアボード（7-7）は散開扱い → A=3（ドライ）。ストレート連続性なし、フラッシュ要素なし。

```
C = 150%ベット = 11

後手スコア = 22 + 3 − 3 − 11 − 0 = 11 → コール（CR域より下）
```

150%オーバーベットに対してもHandScore=22の2ペアはコール範囲に入ります。スコア11はコール域の上限に近く、「薄いコール」です。相手のオーバーベットに含まれるバリュー（フルハウス・クワッズ等）の比率次第では、フォールドが正解になる場合もあります。

### 実例4: ウェットボード + トップペア（相手の50%ベット）

**ボード**: J♥T♠9♦8♣Q♦（5枚、コネクテッド）
**ポット**: 約25BB、BTNが50%ベット（約12BB）
**BBのハンド**: A♠K♦

役判定: A♠K♦ + J♥T♠9♦8♣Q♦。ランク: A, K, J, T, 9, 8, Q。A-K-Q-J-T の5連続が成立します（Aをhighとして使用）。A♠K♦のブロードウェイストレート完成。HandScore = 30（ストレート以上）。

A値: J♥T♠9♦8♣Q♦は5枚がほぼ連続（5連続から多数のストレート完成）→ A=1（ウェット）。

```
C = 50%ベット = 5

後手スコア = 30 + 1 − 3 − 5 − 0 = 23 → CR推奨
```

ブロードウェイストレートはHandScore=30で後手スコアが大きくプラスになります。コネクテッドボードでのCR推奨です。ただしこのボードではKJ・KT・AT等も多数ストレート完成しており、ナッツ同士の対決になりえます。相手のレンジとストレート完成の可能性を確認した上でCRを実行します。

## 11-7 リバーCRの特殊性 ─ コールされて勝てる必要

後手スコアがCR域（≥8）に入ったとき、フロップ・ターンとリバーでは追加確認の内容が異なります。

フロップ・ターンでは、スコア≥8であれば多くの場合CRが合理的です。コールされても「ドローが完成する可能性」があるため、強くないハンドでもCRが機能する局面があります。

リバーでは、CRしてコールされると「その場でショーダウン」になります。ドローの価値はもう存在しません。したがって、**リバーでCRを選ぶハンドは「コールされても相手のバリューに勝てること」が必須条件**です。

**リバーCRの追加確認フロー**

```
Step 1: 後手スコアを計算し、≥8であることを確認
Step 2: 相手のCRコール候補ハンドを推定する
  （相手は「コールに値するほど強いハンド」でコールしてくる）
Step 3: 自分のハンドが、相手のCRコール候補に対して勝てるか確認
  → 勝てる → CR実行
  → 負ける → コールに格下げ
```

**具体例: Kペアでのリバーに CR は合理的か**

ボード K♠7♦2♣A♥Q♦（ドライ、A=3）、BTNが75%ベット（C=7）、BBの手がK♣J♣（Kのペア、HandScore=15）。

```
後手スコア = 15 + 3 − 3 − 7 − 0 = 8 → CR境界
```

スコア=8はCR境界です。しかしKペアのみでリバーCRを打つのは合理的ではありません。BTNの75%ベットレンジには AA・KK・AK・AQ・KQ等の強い2ペア以上が多く含まれており、CRしてコールされた場合に負けることが多い。

このケースでは「後手スコア=8だがコールに留める」が実戦的な正解です。CR境界のスコアに対して「コールされて勝てるか」を確認し、勝てないならコールを選ぶ習慣を持つことが重要です。

**リバーCRに向くハンドの例**

同じ局面でBBがK♣Q♣（2ペア、KsとQs、HandScore=22）を持つ場合を考えます。

```
後手スコア = 22 + 3 − 3 − 7 − 0 = 15 → CR推奨
```

K♣Q♣でのリバーCRは合理的です。BTNの75%ベットにCRしてコールされた場合、A-K-Q-J-T等のストレートや、フルハウスには負けますが、それ以外のKペア・Qペア・2ペア系には勝てます。相手がコールできるハンドの多くに対してエクイティアドバンテージがあれば、CRのEVがプラスになります。

## 11-8 後手下限ラインとの連携

後手スコアで個別ハンドを判断した後、レンジ全体が後手下限ラインを満たしているかを確認する必要があります。

後手下限確率（1−α）は「後手がどれだけのレンジを守るべきか」の最低ラインです。この確率を大きく下回ると、相手はブラフで期待値プラスを取り続けられます。

**後手下限確率と後手スコアの連携確認**

```
例: 相手が75%ポットをベット
  α = 0.43、後手下限確率（1−α）= 0.57

後手スコアで後手下限確率を満たしているか確認:
  後手スコア ≥ 0 のハンドをコールレンジに集める
  → コールレンジのコンボ数 ÷ 総コンボ数が0.57以上か確認
  → 下回る場合: スコアがわずかにマイナスのハンドを一部コールに混ぜる
```

特に注意が必要なのは**33%の小サイズベット**への対応です。33%ベットの後手下限確率は75%と高く、後手スコアが0以下のハンドも一部コールに含める必要が出ます。スコア−1〜−3程度のハンドをコールに混ぜる「後手下限調整」が必要です。

一方、75%以上の大サイズベットに対しては後手下限確率が57%以下に下がるため、後手スコア≥0のハンドだけでも後手下限を満たせることが多くなります。

**ベットサイズ別の後手下限確率とC値の対応（リバー完全版）**

| ベットサイズ | α | 後手下限確率（1−α） | C値 | 後手下限調整目安 |
|---|---|---|---|---|
| 33%ポット | 0.25 | 75% | 3 | スコア−3までコール気味 |
| 50%ポット | 0.33 | 67% | 5 | スコア−2までコール気味 |
| 75%ポット | 0.43 | 57% | 7 | スコア0以上をコール |
| 100%ポット | 0.50 | 50% | 9 | 強いハンドのみコール |
| 150%ポット | 0.60 | 40% | 11 | ナッツ近辺のみコール |

75%以上の大サイズに対しては後手下限ラインの確認より「このハンドで本当に勝てるか」というショーダウン価値の検証が優先します。

## 11-9 ブロッカーによる微調整と次章への橋渡し

本章で学んだ後手スコアはHandScore・A・C・Mという変数で決まります。これらの変数では捉えられない「枝葉の調整」がブロッカー効果です。

後手スコアが境界付近（スコアが−2〜2程度）のハンドに対して、ブロッカーが判断を微調整します。

**コール方向への微調整（バリューブロッカー）**

相手のバリューのキーカードを自分が持つ場合、相手のバリュー密度が下がり、相手のベットがよりブラフに偏ります。後手スコアが境界付近のハンドでコールがわずかに有利になります。

**フォールド方向への微調整（ブラフブロッカー）**

相手のブラフのキーカードを自分が持つ場合、相手のブラフが物理的に減少します。相手のベットがよりバリューに偏り、コールの期待値が下がります。後手スコアが境界付近のハンドでフォールドがわずかに有利になります。

ブロッカーの詳細な使い方は本書巻5 第5章で扱います。本章の後手スコアは「ブロッカー修正なしのベースライン」として使い、巻5 第5章の微調整を加えることで精度を高めます。

## ミニクイズ

### 問1

BTN vs BB（HU）、100BB。5枚ボード K♠7♦2♣A♥5♦（散開rainbow、A=3）。ポット約25BB、BTNが100%ポットベット（25BB）。BBの手は J♠T♠（ハンドとボードで役確認: J♠T♠ + K♠7♦2♣A♥5♦、ランクはA・K・J・T・7・5・2、5連続はなし、スペードはボードのK♠と手のJ♠T♠の計3枚でフラッシュ不成立）。役なし（ハイカード）、HandScore=0。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = −9 → フォールド
2. 後手スコア = −3 → フォールド
3. 後手スコア = 3 → コール

### 問2

同じ局面（ドライ、A=3、HU）でBBが 7♦8♦ を持つとします。ボード K♠7♦2♣A♥5♦ での役判定: 7♦は手にありますがボードの7♦と重複しているため同カードの使用不可です。ハンドを 7♣8♦ に変更して考えます。ボードに7♦があるため、7♣8♦ + K♠7♦2♣A♥5♦ で7が2枚（7♣と7♦）→ 7のペア（セカンドペア）。HandScore = 8。BTNが100%ポットベット（C=9）。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = −1 → フォールド
2. 後手スコア = 2 → コール（薄い）
3. 後手スコア = 5 → コール

### 問3

ウェットボード。5枚ボード A♥K♥Q♥J♠T♦（ハート3枚）。ポット約20BB、BTNが75%ベット（C=7）。BBの手が 9♥8♦。役判定: 9♥8♦ + A♥K♥Q♥J♠T♦、ランクはA・K・Q・J・T・9・8。A-K-Q-J-T-9-8から5連続を確認: A-K-Q-J-T（broadway）、K-Q-J-T-9、Q-J-T-9-8 = 3種類のストレートが成立。最も強いのはK-Q-J-T-9（K-highストレート）かA-K-Q-J-T（broadway）か。9♥8♦でA-K-Q-J-Tのブロードウェイストレートはhand内にAもKもないため不成立。K-Q-J-T-9はhandに9♥があり成立（board K♥Q♥J♠T♦ + hand 9♥ → K-highストレート完成）。HandScore=30（ストレート完成）。A=2（ハート3枚、セミウェット）、C=7、M=0。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 17 → CR推奨（さらにフラッシュドローも確認が必要）
2. 後手スコア = 22 → CR推奨
3. 後手スコア = 30 → CR推奨

---

### 解答

- **問1**: 1（後手スコア = 0 + 3 − 3 − 9 − 0 = −9 → フォールド。HandScore=0のハイカードは100%ベット（C=9）に対して大幅マイナスになり、明確なフォールド。外れたドローや役なしハンドはリバーの大サイズベットに対してほぼ守れない）

- **問2**: 1（後手スコア = 8 + 3 − 3 − 9 − 0 = −1 → フォールド。HandScore=8のセカンドペアは100%ベット（C=9）に対してマイナス1になり、フォールドが基本。ただし後手下限調整の観点からスコア−1は「フォールドとコールの境界」に近く、相手の頻度次第でコール気味にする余地もある）

- **問3**: 2（後手スコア = 30 + 2 − 3 − 7 − 0 = 22 → CR推奨。9♥8♦でK-highストレートが完成しHandScore=30。A=2（セミウェット）、C=7（75%ベット）でスコア22はCR域の中央以上。さらに9♥を持つことでフラッシュドロー（ハート）も1枚保有しているが、リバーではドロー加点は計算に含まれない。ストレートの完成がHandScore=30として反映されている）

---

> **本章まとめ**
>
> - リバー版後手スコアはフロップ・ターン版と同じ式（HandScore + A − 3 − C − M）を使うが、3点を調整する
> - 調整点1: HandScoreからドロー加点をゼロにする（ドローは完成か外れかが確定済み）
> - 調整点2: A係数を5枚ボード全体で再評価する（フロップやターンのA値を引き継がない）
> - 調整点3: C係数を拡張する（100%ベット=C9、150%ベット=C11）
> - リバーCRはスコア≥8に加えて「コールされて勝てるか」の追加確認が必要
> - 後手下限ラインとの連携: 特に33%小サイズベットでは後手下限確率75%を満たすためスコア−3までのハンドをコールに混ぜる
> - ブロッカーによる微調整は巻5 第5章で詳解する

**【GTOとのズレ】**

後手スコアはGTOソルバー出力を「式に圧縮した近似」であり、リバーでは特有のズレが生じます。

最大のズレは**リバーCR判断の精度**です。後手スコアがCR域（≥8）に入っても、GTOソルバーはそのハンドのコンボ単位でCRの期待値を計算します。人間が後手スコアを適用するとき、同じHandScoreのハンドが「コールされて勝てるか」という個別判断を省略することが多いです。特に2ペア以下のハンドでリバーCRを選ぶ場合、相手のコール候補ハンドに対するエクイティを確認していないことが多く、過剰なCRが期待値マイナスになります。GTOはCRの際に「コールされて利益が出る強さのハンドにだけCRを割り当てる」という精密な配分を行います。

次のズレは**ウェットリバーボードでのA係数評価**です。フラッシュが完成しているボード（A=1）でのベット対応を後手スコアで計算すると、A=1という低い値がHandScoreを大きく押し下げます。しかしGTOの実態は、フラッシュ完成ボードでの「フラッシュを持つ後手」と「フラッシュを持たない後手」で扱いが全く異なります。後手スコアはその区分けを自動的には行わないため、「フラッシュ完成ボードでフラッシュを持たない中程度のハンド」に対してコールを指示してしまう誤りが生じます。フラッシュ完成ボードでは、自分がフラッシュを持つかどうかで判断が大きく変わることを意識する必要があります。

また、**ペアボードでのナッツアドバンテージ**の扱いもズレを生む要因です。ペアボード（例: K-7-7や9-9-2）では、IPのナッツ（フルハウス・クワッズ）が多く、OOPの後手スコアが高く出ても「相手のナッツに対する脆弱性」をスコアは直接反映しません。後手スコアがコール域（5〜7）に出た場合でも、ペアボードではIPが頻繁にオーバーベットを打ってくるため、実際のEVがスコアが示すよりも低くなる場合があります。

さらに**33%小サイズベットへの過剰フォールド**も実戦的な課題です。後手スコアを機械的に適用すると、スコアが0未満のハンドをすべてフォールドしてしまいます。しかし33%ベットの後手下限確率は75%と高く、スコアが−1〜−3程度のハンドもコールに混ぜなければなりません。式だけに従うと、相手の小サイズベットに対して守り不足になり、継続的に搾取されます。

### TexasSolver による実測検証（10 ボード × 2 レンジ）

リバー版後手スコアの妥当性を、TexasSolver で 10 種類の代表ボード × balanced/tight の 2 レンジで実測しました。**75% ポットベット**に対する OOP の MDF（最低防御頻度）は次の通りです。

| ボード型 | balanced レンジ MDF | tight レンジ MDF |
|---|---|---|
| Adry（A 高ドライ） | 0.561 | 0.372 |
| Kdry（K 高ドライ） | 0.572 | 0.232 |
| BoardTrips（ボードトリップス） | 0.569 | 0.180 |
| TwoPair（2 ペアボード） | 0.566 | 0.379 |
| FlushDone（フラッシュ完成） | 0.548 | 0.466 |
| FullHouseable（フルハウス可能） | 0.525 | 0.364 |
| FourStraight（4 連続ボード） | 0.545 | 0.515 |
| LowStraight（低ストレート完成） | 0.556 | 0.499 |
| StraightDone（ストレート完成） | 0.523 | 0.518 |
| Monotone（モノトーン） | 0.565 | 0.483 |
| **balanced 平均** | **0.553** | — |
| **tight 平均** | — | **0.401** |

理論値 0.571（α=0.4286）に対し、**balanced レンジでは平均 0.553（誤差 −0.018）と高い一致**を示します。一方 tight レンジ（実戦で BB が「弱め」に守る場合）では平均 0.401 と大幅に低く、特にペア／トリップス系の硬いボードで防御頻度が極端に下がる傾向（BoardTrips tight = 0.180、Kdry tight = 0.232）が見られます。

これは「α 式の理論値はバランス取れたレンジ前提」「レンジが偏ると MDF も大きくシフト」という重要な実戦的示唆です。本書のスコア式はこの両極の中間にあたる「平均的なレンジ」を想定しており、相手のレンジが極端な場合は別途エクスプロイト調整が必要です。

オールイン（≈300% ポットベット相当）でも理論 MDF=0.252 に対し balanced 0.256、tight 0.212 と整合します。この実測検証により、**リバー版 C 係数（100%=9、150%=11）の理論的拡張は GTO 実装と矛盾しない**ことが確認できました。
