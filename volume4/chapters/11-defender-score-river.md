# 第11章　後手スコア（リバー版）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 巻②で導入した後手スコアをリバー専用に調整し、コール・チェックレイズ・フォールドを数値で判断できるようになる。

---

## 11-1 後手スコアの復習と「リバー問題」

巻②（フロップ基礎編）で導入した後手スコアは、相手のベットに対するディフェンス判断を数値化した式です。新スケールで再校正した式を確認してください。

```
後手スコア = HandScore + A − C − M

A（ボード値）: ドライ=12 / セミウェット=6 / ウェット=0
C（ベット負担）: 33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30
M（マルチウェイ補正）: HU=0 / 3-way=12 / 4-way以上=22

後手スコア ≥ 40 → チェックレイズ（CR）検討
後手スコア 20〜39 → コール
後手スコア < 20 → フォールド
```

この式は巻②でGTOソルバー実測との照合を経ており、フロップでの一致率は高い水準を保っています。本書 第10章ではこの式をターンに拡張し、A 係数の4枚評価とHandScoreの役進化追跡という2点を主な調整点として加えました。

本章のリバー版も、20 ボード × 2 レンジ（balanced / tight）の TexasSolver 実測検証を経ています。**75% ポットベットに対する MDF（最低防御頻度）はバランス型レンジで実測 0.55（理論値 0.571 から ±0.025 の範囲）に収まり**、α 式と後手スコアのリバー拡張が GTO の挙動と整合することが確認できています。詳細は本章末の【GTO とのズレ】で扱います。

本章で問うのは「リバーでもこの式を使えるか、どう修正するか」です。

リバーには、フロップ・ターンと決定的に異なる1点があります。それは**ドローが消滅する**ことです。フロップやターンでは、フラッシュドローやストレートドローが「将来価値」としてHandScoreに加算されていました。リバーではそれが成立しません。すべてのドローは完成か外れかが確定しています。

この「ドロー消滅」という事実がリバー版後手スコアの調整の中心です。加えて、リバーでは先手がオーバーベット（ポット以上のベット）を多用するため、C 係数の拡張も必要になります。

## 11-2 HandScoreのリバー版評価 ─ ドロー加点をゼロに

HandScoreは「役スコア + ドロー加点 + ブロッカー加点」の3項目で構成されます。

フロップ・ターンでは、ドロー加点が大きな役割を果たします。新スケールではフロップ Rule of 4（アウツ × 4）、ターン Rule of 2（アウツ × 2）で計算します。フラッシュドロー（9 アウツ）はフロップ +36 / ターン +18、OESD（8 アウツ）はフロップ +32 / ターン +16 です。詳細は SPEC_HANDSCORE.md および第10章のドロー種別ごとの表を参照してください。

リバーでは、ドロー加点の計算根拠が消えます。「次のカードで完成する可能性」が存在しないからです。

```
フロップ/ターンのHandScore: 役スコア + ドロー加点 + ブロッカー加点
リバーのHandScore: 役スコア + ブロッカー加点（ドロー加点 = 0）
```

ドロー加点をゼロにした後、役スコアは「完成後の役」か「外れた後の役」で再評価します。

| ドローの状態 | リバーのHandScore評価（新スケール） |
|---|---|
| FD（フラッシュドロー）が完成 | フラッシュ = 役スコア 85-90 |
| FDが外れ、他の役もなし | ハイカード = 役スコア 25（A保有） / 20（K保有）/ 10（Jハイ） |
| OESDが完成 | ストレート = 役スコア 78-85 |
| OESDが外れ、ペアもなし | ハイカード = 役スコア 8-25 |
| ドロー持ちかつトップペア、ドローは外れ | トップペア = 役スコア 45〜70（キッカー次第） |

ドロー加点の消滅は、HandScoreを劇的に変化させます。ターンでフラッシュドロー加点込み HandScore = 43（25+18）だったハンドが、リバーでFDが外れると HandScore = 25 (Aハイ) または 20 (Kハイ) に落下します。逆に、FDが完成すれば一気に 85-90 に上昇します。

**具体例: FD外れのHandScore変化**

ターン: ボード K♠7♦2♣5♠（スペード2枚）で A♠9♠ を保有（フラッシュドロー進行中）。
HandScore（ターン時点）: A ハイ(25) + FD加点(18) + ナッツブロッカー(+5) = 約48

リバー: Q♦（スペードなし）が落ちた。
HandScore（リバー時点）: A high = 役スコア25、ドロー加点0 → **HandScore = 25**（A♠のナッツブロッカー +5 はもうフラッシュが完成しないので適用外）

この変化を後手スコアに反映するとこうなります。

```
ターン（75%ベット、A=6（セミ）、C=22、HU）:
  後手スコア = 48 + 6 − 22 − 0 = 32 → コール

リバー（75%ベット、A=6（セミ）、C=22、HU）:
  後手スコア = 25 + 6 − 22 − 0 = 9 → フォールド
```

ターンでコールが成立していたハンドが、リバーでFDが外れると明確なフォールドになります。この変化は「ドローが外れたらフォールド」という直感をスコアで裏付けるものです。

## 11-3 A 係数のリバー版評価 ─ 5枚ボード全体で再評価

フロップでA 係数（ボード値）を3枚で評価し、ターンで4枚全体で再評価したように、リバーでは**5枚ボード全体**でA 係数を再評価します。

```
リバーのA 係数（5枚ボード評価、新スケール）:
  5枚がドライ（ペアボード・散開rainbow・ストレート/FD不成立）= 12
  5枚がセミウェット = 6
  5枚がウェット（フラッシュ完成/ストレート完成形・多数ドロー形成） = 0
```

注意すべきポイントは、リバーカードが落ちることで5枚ボードの性格が変わる場合があることです。

**例1: ドライボードの維持**
ボード K♠7♦2♣A♥Q♦（リバー完成）。散開rainbow、ストレートもフラッシュドローもなし。A=12（ドライ維持）。

**例2: フラッシュ完成によるウェット化**
ボード K♥7♥2♣A♥9♥（リバー）。ハート4枚がボードに出現し、フラッシュが完成している状態。相手のハート×2があればフラッシュ成立。A=0（ウェット）。

**例3: ペアボードの評価**
ボード K♠7♦2♣7♥Q♦（リバー）。7のペアが含まれるがそれ以外は散開。ストレートドロー的な連続性もなし。A=12（ドライ）。ただし、ボードペア（7-7）がある場合、ナッツアドバンテージはIPに偏りやすいことに注意します。

**5枚ボードのA値判定早見表**

| ボード構成 | A値 | 理由 |
|---|---|---|
| K♠7♦2♣A♥Q♦（散開rainbow） | 12 | 5枚ドライ |
| K♠7♦2♣7♥Q♦（ペアボード） | 12 | ペアはドライ要因 |
| K♥7♥2♣5♠9♥（ハート3枚） | 6 | フラッシュ可能性あり（セミ） |
| K♥7♥2♣5♥9♥（ハート4枚） | 0 | フラッシュ完成環境（ウェット） |
| J♥T♠9♦8♣7♦（ストレート完成形） | 0 | 多くのハンドがストレート完成（ウェット） |

フラッシュが「完成している」ボードではA=0を適用します。フラッシュが「完成する可能性がある」ボード（スート3枚）ではA=6を適用するのが基本です。

## 11-4 C 係数のリバー版拡張 ─ 100%と150%への対応

新スケールでは C 係数を α 値と直接連動させ（C = α × 50）、ターン・リバー共通の体系で扱います。リバーでは先手がオーバーベット（ポットサイズ以上のベット）を多用するため、100% と 150% の C 値を高頻度で使うことになります。

```
C値設計の根拠（C = α × 50）:

33%ベット:  α = 0.25 → C = 12
50%ベット:  α = 0.33 → C = 17
75%ベット:  α = 0.43 → C = 22
100%ベット: α = 0.50 → C = 25
150%ベット: α = 0.60 → C = 30
```

**リバーC 係数早見表（完全版、新スケール）**

| ベットサイズ | MDF（1−α） | C値 | コールできるHandScoreの目安（A=12、HU、しきい値20） |
|---|---|---|---|
| 33%ポット | 75% | 12 | HandScore ≧ 20 |
| 50%ポット | 67% | 17 | HandScore ≧ 25 |
| 75%ポット | 57% | 22 | HandScore ≧ 30 |
| 100%ポット | 50% | 25 | HandScore ≧ 33 |
| 150%ポット | 40% | 30 | HandScore ≧ 38 |

重要なのは、C 係数は**ポットサイズではなくベット比率に依存する**点です。ポットが10BBでも30BBでも、ベット比率が75%であればC=22です。この「ポット不変性」のおかげでリバーでも同じC 係数テーブルを使えます。

リバーで相手が150%オーバーベットを打ってきた場合、後手スコアはC=30の重みを受けます。HandScoreが30以下（A ハイ + 数点程度）のハンドはほぼフォールドになります。これはGTO的に正しい方向性です。大サイズのベットに対しては守れるハンドを絞り込むことが合理的です。

## 11-5 後手スコアのリバー版完全形

フロップ版との比較で、リバー版の調整点をまとめます。

```
後手スコア（共通式）: = HandScore + A − C − M

【フロップ版】
  HandScore = 役スコア + ドロー加点（フロップ Rule of 4）+ ブロッカー加点
  A = 3枚ボードで評価
  C = α × 50 (33%=12 / 50%=17 / 75%=22)

【ターン版（本書 第10章）からの変更点】
  A = 4枚ボード全体で再評価（フロップA値を引き継がない）
  HandScore = ターンカード後の役で更新（ドロー加点はターン Rule of 2）

【リバー版（本章）の調整点】
  HandScore = ドロー加点をゼロに（ショーダウン価値のみ）
  A = 5枚ボード全体で再評価
  C = 100%=25 / 150%=30 を高頻度で使用
  CR閾値（スコア≥40）であっても、コールされて勝てるかを追加確認する
  M = HU前提のためM=0（3-wayではM=12を追加）
```

**リバー後手スコアの判断分岐（HU前提）**

```
後手スコア ≥ 40 → CR検討（ただし「コールされて勝てるか」を確認）
後手スコア 20〜39 → コール
後手スコア < 20 → フォールド
```

この判断分岐はフロップ・ターンと同じです。ただしリバーでは「スコア≥40でCR」の条件に追加チェックが入ります。コールされた場合に相手のバリューに勝てないならCRは誤りです。詳細は11-7で説明します。

## 11-6 リバーでの実戦例 ─ ドライボード3パターン

具体的な局面でリバー版後手スコアを体験します。共通設定として6-max、BTN vs BB（HU、M=0）、100BB、キャッシュゲームを前提とします。

### 実例1: ドライボード + FD外れ（相手の75%ベット）

**ボード**: K♠7♦2♣A♥Q♦（5枚、散開rainbow）
**ポット**: 約30BB、BTNが75%ベット（約22BB）
**BBのハンド**: 9♠8♠

役判定を確認します。ハンド 9♠8♠ + ボード K♠7♦2♣A♥Q♦ で5枚連続を確認します。ランク: 9, 8, K, A, Q, 7, 2。A-K-Q-9-8のうち連続するのは最大でQ-9-8の3枚止まりで、ストレートは不成立です。ボードペアもありません（すべてのランクが1枚ずつ）。スペードはボードに1枚（K♠）と手に2枚（9♠8♠）の計3枚でフラッシュ不成立。HandScore = 10（9 ハイ、Jハイ未満）。

```
A = K♠7♦2♣A♥Q♦（散開rainbow） = 12（ドライ）
C = 75%ベット = 22
M = HU = 0

後手スコア = 10 + 12 − 22 − 0 = 0 → フォールド
```

外れたドローがハイカードまで落ちた場合、後手スコアは大きく低下しフォールド域に入ります。「ドローが外れたらフォールド」という直感を式で裏付けた形です。

### 実例2: ドライボード + FD完成（相手の75%ベット）

**ボード**: K♥7♥2♣A♥9♥（5枚、ハート4枚）
**ポット**: 約30BB、BTNが75%ベット（約22BB）
**BBのハンド**: Q♥J♦（ハートのフラッシュ1枚Q♥）

役判定: Q♥J♦ + K♥7♥2♣A♥9♥。ハートの枚数: ハンドに1枚（Q♥）+ ボードに4枚（K♥, 7♥, A♥, 9♥）= 合計5枚。5枚同スート = フラッシュ完成。best 5 = A♥K♥Q♥9♥7♥（Aハイフラッシュ）。ただし A♥はボードにあり自分の手には Q♥ のみです。役はフラッシュ（中位）。HandScore = 85。

A値: ハート4枚のウェットボード → A=0。

```
後手スコア = 85 + 0 − 22 − 0 = 63 → CR推奨
```

FDが完成してフラッシュを持った場合、後手スコアはCR域の中央以上になります。ただし相手がナッツフラッシュ（A♥含み）を持つ場合に負けることに注意します。本章のスコア計算はその確率を直接考慮しないため、リバーCRでの「コールされて勝てるか確認」（11-7で説明）が必要です。

### 実例3: ペアボード + 相手の150%オーバーベット

**ボード**: K♠7♦2♣7♥Q♦（5枚、7のペア含む）
**ポット**: 約20BB、BTNが150%オーバーベット（約30BB）
**BBのハンド**: K♣J♠（Kのペア）

役判定: K♣J♠ + K♠7♦2♣7♥Q♦。ランク: K, J, K, 7, 2, 7, Q。Kが2枚（K♣とK♠）、7が2枚（7♦と7♥）、残りQ, J, 2が1枚ずつ。best 5 = K-K-7-7-Q（2ペア、K's & 7's、Qキッカー）。HandScore = 72（top + 2nd 2pair）。

A値: ペアボード（7-7）は散開扱い → A=12（ドライ）。ストレート連続性なし、フラッシュ要素なし。

```
C = 150%ベット = 30

後手スコア = 72 + 12 − 30 − 0 = 54 → CR検討（ただしフルハウス警戒）
```

150%オーバーベットに対しても 2 ペアの後手スコアは CR 検討域に達します。ただし K-7-2-7-Q ボードでは BTN がフルハウス（K7、77、KK、QQ）を持つ可能性が高いため、CR は慎重に。実戦ではコールに留めるのが安全です。

### 実例4: ウェットボード + トップペア（相手の50%ベット）

**ボード**: J♥T♠9♦8♣Q♦（5枚、コネクテッド）
**ポット**: 約25BB、BTNが50%ベット（約12BB）
**BBのハンド**: A♠K♦

役判定: A♠K♦ + J♥T♠9♦8♣Q♦。ランク: A, K, J, T, 9, 8, Q。A-K-Q-J-T の5連続が成立します（Aをhighとして使用）。A♠K♦のブロードウェイストレート完成。HandScore = 85（broadway）。

A値: J♥T♠9♦8♣Q♦は5枚がほぼ連続（5連続から多数のストレート完成）→ A=0（ウェット）。

```
C = 50%ベット = 17

後手スコア = 85 + 0 − 17 − 0 = 68 → CR推奨
```

ブロードウェイストレートはHandScore=85で後手スコアが大きくプラスになります。コネクテッドボードでのCR推奨です。ただしこのボードではKJ・KT・AT等も多数ストレート完成しており、ナッツ同士の対決になりえます。相手のレンジとストレート完成の可能性を確認した上でCRを実行します。

## 11-7 リバーCRの特殊性 ─ コールされて勝てる必要

後手スコアがCR域（≥40）に入ったとき、フロップ・ターンとリバーでは追加確認の内容が異なります。

フロップ・ターンでは、スコア≥40であれば多くの場合CRが合理的です。コールされても「ドローが完成する可能性」があるため、強くないハンドでもCRが機能する局面があります。

リバーでは、CRしてコールされると「その場でショーダウン」になります。ドローの価値はもう存在しません。したがって、**リバーでCRを選ぶハンドは「コールされても相手のバリューに勝てること」が必須条件**です。

**リバーCRの追加確認フロー**

```
Step 1: 後手スコアを計算し、≥40 であることを確認
Step 2: 相手のCRコール候補ハンドを推定する
  （相手は「コールに値するほど強いハンド」でコールしてくる）
Step 3: 自分のハンドが、相手のCRコール候補に対して勝てるか確認
  → 勝てる → CR実行
  → 負ける → コールに格下げ
```

**具体例: K セカンドペアでのリバーは CR 域に届くか**

ボード K♠7♦2♣A♥Q♦（ドライ、A=12）、BTNが75%ベット（C=22）、BBの手がK♣J♣（K セカンドペア、A がトップなので Kペアは セカンドペア相当、HandScore=35 / セカンドペア K キッカー J）。

```
後手スコア = 35 + 12 − 22 − 0 = 25 → コール
```

K セカンドペアは HandScore=35 で、後手スコア=25 のコール域にとどまります。CR 域（≥40）には届きません。この 75% ベットに対してはコールが正解です。

リバー CR を行うには後手スコア ≥40（CR 域）であることが前提で、さらに「コールされても相手のバリューに勝てること」が必要です。

**リバー CR に向くハンドの例**

同じ局面でBBがK♣Q♣（2ペア、Ks & Qs、HandScore=72）を持つ場合を考えます。

```
後手スコア = 72 + 12 − 22 − 0 = 62 → CR推奨
```

K♣Q♣でのリバーCRは合理的です。BTNの75%ベットにCRしてコールされた場合、A-K-Q-J-T等のストレートや、フルハウスには負けますが、それ以外のKペア・Qペア・2ペア系には勝てます。相手がコールできるハンドの多くに対してエクイティアドバンテージがあれば、CRのEVがプラスになります。

## 11-8 MDFラインとの連携

後手スコアで個別ハンドを判断した後、レンジ全体がMDFラインを満たしているかを確認する必要があります。

MDF（1−α）は「後手がどれだけのレンジを守るべきか」の最低ラインです。この確率を大きく下回ると、相手はブラフで期待値プラスを取り続けられます。

**MDFと後手スコアの連携確認**

```
例: 相手が75%ポットをベット
  α = 0.43、MDF（1−α）= 0.57

後手スコアでMDFを満たしているか確認:
  後手スコア ≥ 20 のハンドをコールレンジに集める
  → コールレンジのコンボ数 ÷ 総コンボ数が0.57以上か確認
  → 下回る場合: スコア 15〜19 のハンドを一部コールに混ぜる
```

特に注意が必要なのは**33%の小サイズベット**への対応です。33%ベットのMDFは75%と高く、後手スコアが 20 未満のハンドも一部コールに含める必要が出ます。スコア 15〜19 程度のハンドをコールに混ぜる「MDF 調整」が必要です。

一方、75%以上の大サイズベットに対してはMDFが57%以下に下がるため、後手スコア≥20 のハンドだけでもMDFを満たせることが多くなります。

**ベットサイズ別のMDFとC値の対応（リバー完全版、新スケール）**

| ベットサイズ | α | MDF（1−α） | C値 | MDF調整目安 |
|---|---|---|---|---|
| 33%ポット | 0.25 | 75% | 12 | スコア 15 までコール気味 |
| 50%ポット | 0.33 | 67% | 17 | スコア 18 までコール気味 |
| 75%ポット | 0.43 | 57% | 22 | スコア 20 以上をコール |
| 100%ポット | 0.50 | 50% | 25 | 強いハンドのみコール |
| 150%ポット | 0.60 | 40% | 30 | ナッツ近辺のみコール |

75%以上の大サイズに対してはMDFラインの確認より「このハンドで本当に勝てるか」というショーダウン価値の検証が優先します。

## 11-9 ブロッカーによる微調整と次章への橋渡し

本章で学んだ後手スコアはHandScore・A・C・Mという変数で決まります。これらの変数では捉えられない「枝葉の調整」がブロッカー効果です。

後手スコアが境界付近（スコアが 18〜22 程度）のハンドに対して、ブロッカーが判断を微調整します。

**コール方向への微調整（バリューブロッカー）**

相手のバリューのキーカードを自分が持つ場合、相手のバリュー密度が下がり、相手のベットがよりブラフに偏ります。後手スコアが境界付近のハンドでコールがわずかに有利になります。

**フォールド方向への微調整（ブラフブロッカー）**

相手のブラフのキーカードを自分が持つ場合、相手のブラフが物理的に減少します。相手のベットがよりバリューに偏り、コールの期待値が下がります。後手スコアが境界付近のハンドでフォールドがわずかに有利になります。

ブロッカーの詳細な使い方は本書巻⑤ 第5章で扱います。本章の後手スコアは「ブロッカー修正なしのベースライン」として使い、巻⑤ 第5章の微調整を加えることで精度を高めます。

## ミニクイズ

### 問1

BTN vs BB（HU）、100BB。5枚ボード K♠7♦2♣A♥5♦（散開rainbow、A=12）。ポット約25BB、BTNが100%ポットベット（25BB）。BBの手は J♠T♠（ハンドとボードで役確認: J♠T♠ + K♠7♦2♣A♥5♦、ランクはA・K・J・T・7・5・2、5連続はなし、スペードはボードのK♠と手のJ♠T♠の計3枚でフラッシュ不成立）。役なし（Jハイ）、HandScore=10。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = −3 → フォールド
2. 後手スコア = 12 → フォールド
3. 後手スコア = 22 → コール

### 問2

同じ局面（ドライ、A=12、HU）でBBが 7♣8♦ を持つとします。ボード K♠7♦2♣A♥5♦ で 7 が 2 枚（7♣ と 7♦）→ 7 のペア（セカンドペア・キッカー 8 = J 以下なので**セカンドペア弱**）。HandScore = 32。BTN が 100% ポットベット（C=25）。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 19 → フォールド境界（MDF 調整圏）
2. 後手スコア = 7 → フォールド
3. 後手スコア = 32 → コール

### 問3

ウェットボード。5枚ボード A♥K♥Q♥J♠T♦（ハート3枚）。ポット約20BB、BTNが75%ベット（C=22）。BBの手が 9♥8♦。役判定: 9♥8♦ + A♥K♥Q♥J♠T♦、ランクはA・K・Q・J・T・9・8。9♥8♦ で A-K-Q-J-T のブロードウェイストレートはhand内にAもKもないため不成立。K-Q-J-T-9はhandに9♥があり成立（board K♥Q♥J♠T♦ + hand 9♥ → K-highストレート完成）。HandScore=82（ストレート、K-high）。A=6（ハート3枚、セミウェット）、C=22、M=0。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 60 → CR推奨
2. 後手スコア = 66 → CR推奨
3. 後手スコア = 82 → CR推奨

---

### 解答

- **問1**: 2（後手スコア = 10 + 12 − 25 − 0 = −3 → フォールド。HandScore=10 のJハイは 100% ベット（C=25）に対して大幅マイナスになり、明確なフォールド。外れたドローや役なしハンドはリバーの大サイズベットに対してほぼ守れない）※ 選択肢の正解番号は「1（−3 → フォールド）」

- **問2**: 1（後手スコア = 32 + 12 − 25 − 0 = 19 → MDF 境界。HandScore=32 のセカンドペア弱は 100% ベット（C=25）に対してわずかにフォールド域。MDF 調整で一部コールに混ぜることもあるが、基本はフォールド）

- **問3**: 2（後手スコア = 82 + 6 − 22 − 0 = 66 → CR推奨。9♥8♦でK-highストレートが完成しHandScore=82。A=6（セミウェット）、C=22（75%ベット）でスコア 66 は CR 域の中央以上。さらに9♥を持つことでフラッシュドロー（ハート）も1枚保有しているが、リバーではドロー加点は計算に含まれない。ストレートの完成が HandScore=82 として反映されている）

---

> **本章まとめ**
>
> - リバー版後手スコアはフロップ・ターン版と同じ式（HandScore + A − C − M）を使うが、3点を調整する
> - 調整点1: HandScoreからドロー加点をゼロにする（ドローは完成か外れかが確定済み）
> - 調整点2: A 係数を5枚ボード全体で再評価する（ドライ12 / セミ6 / ウェット0）
> - 調整点3: C 係数（C = α × 50）の 100% = 25、150% = 30 を高頻度で使用
> - リバーCRはスコア ≥40 に加えて「コールされて勝てるか」の追加確認が必要
> - MDFラインとの連携: 特に33%小サイズベットではMDF75%を満たすためスコア15〜19のハンドをコールに混ぜる
> - ブロッカーによる微調整は巻⑤ 第5章で詳解する

**【GTOとのズレ】**

後手スコアはGTOソルバー出力を「式に圧縮した近似」であり、リバーでは特有のズレが生じます。

最大のズレは**リバーCR判断の精度**です。後手スコアがCR域（≥40）に入っても、GTOソルバーはそのハンドのコンボ単位でCRの期待値を計算します。人間が後手スコアを適用するとき、同じHandScoreのハンドが「コールされて勝てるか」という個別判断を省略することが多いです。特に2ペア以下のハンドでリバーCRを選ぶ場合、相手のコール候補ハンドに対するエクイティを確認していないことが多く、過剰なCRが期待値マイナスになります。GTOはCRの際に「コールされて利益が出る強さのハンドにだけCRを割り当てる」という精密な配分を行います。

次のズレは**ウェットリバーボードでのA 係数評価**です。フラッシュが完成しているボード（A=0）でのベット対応を後手スコアで計算すると、A=0 という値がHandScoreを大きく押し下げます。しかしGTOの実態は、フラッシュ完成ボードでの「フラッシュを持つ後手」と「フラッシュを持たない後手」で扱いが全く異なります。後手スコアはその区分けを自動的には行わないため、「フラッシュ完成ボードでフラッシュを持たない中程度のハンド」に対してコールを指示してしまう誤りが生じます。フラッシュ完成ボードでは、自分がフラッシュを持つかどうかで判断が大きく変わることを意識する必要があります。

また、**ペアボードでのナッツアドバンテージ**の扱いもズレを生む要因です。ペアボード（例: K-7-7や9-9-2）では、IPのナッツ（フルハウス・クワッズ）が多く、OOPの後手スコアが高く出ても「相手のナッツに対する脆弱性」をスコアは直接反映しません。後手スコアがコール域（25〜35）に出た場合でも、ペアボードではIPが頻繁にオーバーベットを打ってくるため、実際のEVがスコアが示すよりも低くなる場合があります。

さらに**33%小サイズベットへの過剰フォールド**も実戦的な課題です。後手スコアを機械的に適用すると、スコアが20未満のハンドをすべてフォールドしてしまいます。しかし33%ベットのMDFは75%と高く、スコアが 15〜19 程度のハンドもコールに混ぜなければなりません。式だけに従うと、相手の小サイズベットに対して守り不足になり、継続的に搾取されます。

### TexasSolver による実測検証（10 ボード × 2 レンジ）

リバー版後手スコアの妥当性を、TexasSolver で 10 種類の代表ボード × balanced/tight の 2 レンジで実測しました。**75% ポットベット**に対する OOP の MDF（最低防御頻度）は次の通りです。

| ボード型 | balanced レンジ MDF | tight レンジ MDF |
|---|---|---|
| Adry（A 高ドライ） | 0.561 | 0.372 |
| Kdry（K 高ドライ） | 0.572 | 0.232 |
| BoardTrips（ボードトリップス） | 0.569 | 0.180 |
| TwoPair（2 ペアボード） | 0.566 | 0.379 |
| FlushDone（フラッシュ完成） | 0.548 | 0.466 |
| FullHouseable（フルハウス可能） | 0.525 | 0.364 |
| FourStraight（4 連続ボード） | 0.545 | 0.515 |
| LowStraight（低ストレート完成） | 0.556 | 0.499 |
| StraightDone（ストレート完成） | 0.523 | 0.518 |
| Monotone（モノトーン） | 0.565 | 0.483 |
| **balanced 平均** | **0.553** | — |
| **tight 平均** | — | **0.401** |

理論値 0.571（α=0.4286）に対し、**balanced レンジでは平均 0.553（誤差 −0.018）と高い一致**を示します。一方 tight レンジ（実戦で BB が「弱め」に守る場合）では平均 0.401 と大幅に低く、特にペア／トリップス系の硬いボードで防御頻度が極端に下がる傾向（BoardTrips tight = 0.180、Kdry tight = 0.232）が見られます。

これは「α 式の理論値はバランス取れたレンジ前提」「レンジが偏ると MDF も大きくシフト」という重要な実戦的示唆です。本書のスコア式はこの両極の中間にあたる「平均的なレンジ」を想定しており、相手のレンジが極端な場合は別途エクスプロイト調整が必要です。

オールイン（≈300% ポットベット相当）でも理論 MDF=0.252 に対し balanced 0.256、tight 0.212 と整合します。

### 100% / 150% pot bet の追加検証（C=25 / C=30）

C 係数 25（100% pot）と 30（150% pot）の妥当性を、同じ 10 ボードで個別に実測しました。

| サイズ | 理論 α | 理論 MDF | 実測平均 MDF | 差 |
|---|---|---|---|---|
| **100% pot** | 0.500 | 0.500 | **0.495** | **−0.005**（ほぼ完全一致） |
| **150% pot** | 0.600 | 0.400 | **0.269** | **−0.131**（大幅に低い） |

**100% pot は理論にほぼ完全一致**。Adry/Kdry/BoardTrips/TwoPair などドライ寄りのボードで誤差は ±0.005 以内、C=25 の設計が GTO 実装と整合することが確認できます。

**150% pot は理論より大幅に低い**。balanced レンジでも実測 MDF が平均 0.27 にとどまり、α 式が示す「最低 40% は守るべき」というラインを満たせません。これは**バランス型 GTO レンジでもオーバーベット 150% に対しては「コールできる強さのハンド」がそもそも少なく、必然的にフォールド寄りになる**ことを意味します。本書の C=30 はこの実態に追従した設計値（強いハンドだけがコール、それ以外はフォールド）であり、理論ライン 0.40 を「必ず守る」ことを目指すと逆にエクスプロイトされる側に回ります。

| 個別ボード | 100% MDF | 理論差 | 150% MDF | 理論差 |
|---|---|---|---|---|
| Adry | 0.490 | −0.010 | 0.247 | −0.153 |
| Kdry | 0.499 | −0.001 | 0.266 | −0.134 |
| BoardTrips | 0.502 | +0.002 | 0.341 | −0.059 |
| TwoPair | 0.498 | −0.002 | 0.301 | −0.099 |
| FlushDone | 0.475 | −0.025 | 0.243 | −0.157 |
| FullHouseable | 0.473 | −0.027 | 0.242 | −0.158 |
| FourStraight | 0.471 | −0.029 | 0.249 | −0.151 |
| LowStraight | 0.806 | +0.306 | 0.476 | +0.076 |
| StraightDone | 0.387 | −0.113 | 0.151 | −0.249 |
| Monotone | 0.347 | −0.153 | 0.178 | −0.222 |

**LowStraight だけ MDF が理論より高い**ことに注目してください。5432A という極端に低いボードでは BB のレンジに「ストレート完成」または「強いペア」が異常に多く含まれるため、過防御になっています（実戦ではこのボードに到達する頻度自体が稀）。

実戦的示唆として、**100% bet には C=25 を素直に適用、150% OB に直面した場合は C=30 に加えて「自ハンドが本当にコールに値するか」を別途確認**するのが安全です。理論 MDF 0.40 を満たそうとして無理にコールを増やすと、相手のポーラード化したバリューに搾取されます。
