# 第10章　後手スコア（ターン版）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 巻②で導入した後手スコアをターン・リバー用に再校正し、コール/チェックレイズ/フォールドを数値で判断できるようになる。

---

## 10-1 巻②の後手スコアを振り返る

巻②（フロップ基礎編）では、相手のCBetに対するディフェンス判断を**後手スコア**という式で数値化しました。本章ではその式をターン・リバーへと拡張します。

まず式を確認してください。

```
後手スコア = HandScore + A − 3 − C − M

A（ボード値）: ドライ=3 / セミウェット=2 / ウェット=1
C（ベット負担）: 33%=3 / 50%=5 / 75%=7
M（マルチウェイ補正）: HU=0 / 3-way=3 / 4-way以上=6

後手スコア ≥ 8 → チェックレイズ（CR）検討
後手スコア 0〜7 → コール
後手スコア < 0 → フォールド
```

この式は巻②でGTOソルバー実測20件に対して90%の一致率を持ちます。フロップ上の検証済みのフレームワークです。

本章で問うのは「ターン・リバーでもこの式はそのまま使えるか？」です。

---

## 10-2 後手スコアと本書 第9章 α 式の関係

後手スコアを理解するうえで、α 式（本書 第9章で扱う先手の設計式）との対比が重要です。

```
α 式（先手の視点）:
  α = ベット額 ÷ (ポット + ベット額)
  → 先手にとってブラフが損益分岐するための最低フォールド率

後手スコア（後手の視点）:
  後手スコア = HandScore + A − 3 − C − M
  → 後手にとってコール/フォールド/CRが有利かを数値で決める
```

α 式は「先手がどれだけブラフを入れられるか」の設計ツールです。後手スコアは「後手がそのベットに対してどう応じるか」の判断ツールです。両者は**表裏の関係**にあります。

先手がα 式を使ってバリュー比率を設計し、後手が後手スコアを使ってディフェンス範囲を決める。この二者の計算が噛み合うことで、ポットは均衡に向かいます。

MDF（1−α）との対応を整理すると、こうなります。

```
MDF（レンジ全体の最低防御率）:
  = 1 − α
  = ポット ÷ (ポット + ベット)

後手スコア（個別ハンドの判断）:
  = HandScore + A − 3 − C − M
  ≥ 0 → そのハンドをコールレンジに含める
  < 0 → そのハンドをフォールドレンジに含める
```

MDFは「レンジ全体で何%守るか」を指定します。後手スコアは「このハンドを守るレンジに含めるかどうか」を個別に判断します。両者は別の問いに答えており、どちらか一方で十分ではありません。実戦では後手スコアを個別ハンドに適用し、結果としてMDFが自然に満たされることを目指します。

## 10-3 C 補正のメカニズム ─ なぜ%ベースか

C（ベット負担）の値がなぜ33%=3、50%=5、75%=7という設計なのかを理解しておくことで、ターン・リバーへの拡張の根拠が明確になります。

CはHandScoreのスケールと合わせるための「変換係数」です。HandScoreは0〜30の範囲で手の強さを表します。このスケールに対し、「ベットが大きいほど守りにくくなる」という圧力を同じスケールの数値として表現するためにCが設計されています。

C値の設計はMDFから逆算されています。

```
C = (1 − MDF) × 調整係数

33%ベット → MDF = P/(P+B) = 75%、C = 3
50%ベット → MDF = 67%、C = 5
75%ベット → MDF = 57%、C = 7
```

重要なのは、**CはポットとベットのPOT 比率から決まる**という点です。絶対額ではなくベット比率（%ポット）に連動します。

したがって、ターンでポットが12BBになっていても、ベット比率が同じ75%であればC=7のままです。リバーでポットが25BBになっていても、75%ベットならC=7です。ポットサイズの変化はCの値を変えません。

これがC値の「ポート不変性」です。ターン・リバーでも同じC値テーブルを使える根拠がここにあります。

## 10-4 ターン版の調整点 ─ A値の4枚評価

フロップ後手スコアとターン後手スコアの最大の違いは、**A値（ボード値）の評価対象**です。

フロップのA値はフロップの3枚で評価します。ターンのA値はターン後の4枚すべてで評価し直します。

```
A値の評価基準（ターン版）:
  4枚ボードがドライ（ペアボード・散開rainbow）= 3
  4枚ボードがセミウェット = 2
  4枚ボードがウェット（コネクテッド/フラッシュドロー形成）= 1
```

なぜA値を再評価するのか。ターンカードが落ちることでボードのウェット度が変化するからです。

具体例で確認します。

**フロップ K♠7♦2♣（ドライ, A=3）にターン 5♠ が落ちた場合**

ターン前: K♠7♦2♣（3枚ドライ、A=3）
ターン後: K♠7♦2♣5♠（4枚）

5♠の影響を検討します。スペードが2枚になった（K♠と5♠）。A=2（セミウェット）に下がります。

後手スコアの計算でこの変化を反映します。

```
フロップ時:  後手スコア = HandScore + 3 − 3 − C
ターン時:   後手スコア = HandScore + 2 − 3 − C
差:  −1（ターンでスコアが1点下がる）
```

ターンカードがウェット要素を加えた場合、後手のディフェンス判断が厳しくなります。逆に、ドライボードにさらにドライなターンカード（ペアや散開カード）が落ちた場合はA値を維持またはさらに高く評価します。

**4枚ボードのA値判定早見表**

| フロップ | ターンカード | 4枚評価 | A値 |
|---|---|---|---|
| K♠7♦2♣（ドライ） | ブランク（3♣等） | K♠7♦2♣3♣（ドライ維持） | 3 |
| K♠7♦2♣（ドライ） | ペア（7♥） | K♠7♦2♣7♥（ペアボード） | 3 |
| K♠7♦2♣（ドライ） | フラッシュ（5♠） | K♠7♦2♣5♠（セミ） | 2 |
| J♥8♠3♦（セミ） | コネクター（9♣） | J♥8♠3♦9♣（ウェット） | 1 |
| J♥8♠3♦（セミ） | ブランク（2♣） | J♥8♠3♦2♣（セミ維持） | 2 |

この再評価がターン版のA値処理の核心です。「フロップのA値をそのままターンに引き継がない」という点を必ず意識してください。

## 10-5 リバー版の調整点 ─ ドロー成分の消滅とC拡張

リバーでは後手スコアにさらに重要な調整が必要です。それはHandScoreの評価方法の変化とC値の拡張です。

### HandScoreのリバー版評価

フロップ・ターンでは、HandScoreは「現在の役スコア」に「ドロー加点」を含めて計算します。ドロー加点とは「アウツ数 × 1.5」の加点で、フラッシュドローは約13点、OESDは約12点が加算されます。係数 1.5 は巻② 第8章の **Rule of 2 and 4**（アウツ × 2 ≒ 1 ストリート分の勝率%）を保守的に丸めた値で、「ドロー完成時のバリュー」と「現状のショーダウン価値」を一括して点数化するために使います。

リバーではドローが完成したか外れたかが確定しています。したがって**リバーのHandScoreはショーダウン価値のみ**で評価します。

```
フロップ/ターンのHandScore: 役スコア + ドロー加点
リバーのHandScore: 役スコアのみ（ドロー加点=0）

ドロー成分の扱い:
  完成した → 完成後の役スコアでHandScoreを計算（FD完成=フラッシュとして評価）
  外れた  → 役スコアのみ（HandScore大幅低下）
```

外れたドローがリバーで後手スコアを大きく押し下げる理由がここにあります。

**具体例**

ターン: K♠7♦2♣5♠ でフラッシュドロー（スペード）を持っていた A♠8♠（HandScore ≈ 13 = 役なし+FD加点）

リバー: Q♦（スペードなし）が落ちた場合

リバーのHandScore: Aハイのみ = 役スコア0、ドロー加点なし → HandScore ≈ 0

後手スコア = 0 + A − 3 − C → 中〜大サイズのCに対してほぼマイナス → フォールド推奨

一方、リバーが 9♠ だった場合：フラッシュ完成（Aハイフラッシュ）→ HandScore ≈ 25前後 → 後手スコアが大幅に上昇 → コール〜CR推奨

### リバーのC値拡張：150%ベット

本書 第9章で学ぶ α 式の通り、リバーではオーバーベット（150%以上）が先手の重要な戦術です。C値をオーバーベットに対応させるため、リバー版では拡張C値を使います。

```
C値（ターン・リバー共通ベースライン）:
  33%ベット → C = 3
  50%ベット → C = 5
  75%ベット → C = 7

リバー専用拡張:
  100%ベット（ポットサイズ） → C = 9
  150%ベット（オーバーベット） → C = 11
```

C=9、C=11はリバー専用の拡張値です。これらはMDFとの対応から計算されています。

```
100%ベット: MDF = 50%、C = 9
150%ベット: MDF = 40%、C = 11
```

リバーで相手がオーバーベットを打ってきた場合、後手スコアはC=11の重みがかかります。HandScoreが低いハンドはほぼすべてフォールドになります。これはGTO的に正しい方向性です。リバーの大サイズベットに対しては、コールできるハンドを絞り込むことが防御の合理的な形です。

## 10-6 ターンディフェンスの実例 ─ ドライ板での複数ハンド比較

具体的な局面で後手スコアを各ハンドに適用し、「コール/CR/フォールド」の分岐を体験します。

**局面設定**

- BTN vs BB（HU）、100BB、6-maxキャッシュゲーム
- フロップ K♠7♦2♣（ドライ、フロップA=3）
- BTN が1/3ポットCBet → BB がコール
- ポット約12BB。ターン 7♥（ペアカード）
- BTN が75%ポットベット（約9BB）
- 共通パラメータ: A=3（K-7-2-7のペアボード、ドライ維持）、C=7（75%ベット）、M=0（HU）

**ハンド別の後手スコア一覧**

K-7-2-7 はペアボードのため、ボードの 7-7 がすべての best 5 に入ります。各ハンドの実際の役を正確に評価します。

| BBの手 | ターン後の役（best 5） | HandScore | 後手スコア | 判断 |
|---|---|---|---|---|
| K♣J♦ | 2 pair K's & 7's, J キッカー（K-K-7-7-J） | 15 | 15+3−3−7=**8** | CR境界 |
| 7♣8♣ | トリップス 7（7-7-7-K-8） | 25 | 25+3−3−7=**18** | CR推奨 |
| A♠K♥ | 2 pair K's & 7's, A キッカー（A-K-K-7-7） | 22 | 22+3−3−7=**15** | CR推奨 |
| 2♦3♣ | 2 pair 7's & 2's, K キッカー（K-7-7-2-2） | 12 | 12+3−3−7=**5** | コール（薄い） |
| J♣T♣ | 1 pair (board の 7's), K-J-T キッカー | 8 | 8+3−3−7=**1** | コール（境界） |

**ペアボードの hand evaluation 注意点**

K-7-2-7 のようなペアボードでは、どんなハンドも best 5 にボードの 7-7 が入ります。「役なし」「空振り」と評価するのは誤りで、最低でも 1 pair (board's 7's) が成立しています。Kx 系・7x 系のハンドはボードペアと組み合わさってさらに強い役（2 pair やトリップス）に昇格します。

**KJ の詳細判断**

K♣J♦ は「2 pair K's & 7's, J キッカー」（ペアボード昇格）で HandScore = 15。後手スコア=8 はCR検討の下限です。しかし 7 ペアターン（BTNのナッツアドバンテージが最大化されるカード）という文脈を加味します。

- BTNのUncappedレンジにKK（フルハウス）・77（クワッズ）・K7（フルハウス）が含まれている
- KJ が CR を打った場合、BTN にリレイズされるとフォールドせざるを得ない
- CR−フォールドはコールよりも期待値が低い局面になりやすい

このハンドは「後手スコア=8 だがコールに留める」が実戦的な正解です。CR境界のスコアに対して、「相手のナッツが大幅に強化されるターン」ではコールを優先する習慣を持つことが重要です。

**トリップス 7（7♣8♣）の詳細判断**

7♣8♣ + K♠7♦2♣7♥ のboardで、自分の 7♣ + ボードの 7♦ + 7♥ = 3 of 7's = トリップス。HandScore = 25。後手スコア=18 はCR域の中央付近。BTNの75%ベットに対してCRを選びます。

トリップスは BTN が KK を持つ場合のフルハウス（K's full of 7's）には負けますが、BBの 7♣8♣ で作るトリップス 7 は BTN の Kx ハンドには勝てます。ただし、BTNが KK を持つ確率は低く（6 コンボ以下）、バリューの多くに勝てるためCRが有利です。

**ペアターンの防御総括**

BTN vs BB での K-7-2-7 ターン（ペア）は、GTOソルバー実測でBTNのCBet頻度が100%に近い局面です（第8章バレルスコア: ドライ8+ペア4=12 → 積極バレル）。BBの75%ベットに対する後手スコアを俯瞰すると、HandScore22以上のハンドがCR、HandScore8〜21がコール、HandScore7以下がフォールドという構造になります。

## 10-7 リバーディフェンスの実例 ─ ベットサイズ別の判断変化

リバーでの後手スコアの使い方を、ベットサイズを変えて確認します。

**局面設定**

- フロップ K♠7♦2♣（ドライ）→ ターン A♥（OC）→ BBがコール継続
- リバー: Q♦（ブランク、ストレート不絡み）
- 5枚ボード: K♠7♦2♣A♥Q♦
- ポット約30BB

**5枚ボードのA値評価**

K♠7♦2♣A♥Q♦。散開rainbow、ストレートもフラッシュドローもなし。A=3（ドライ）。

**BBの各ハンドのHandScore（リバー版）**

ドロー加点はゼロ。ショーダウン価値のみで評価します。

| BBの手 | 役（5枚ボード） | HandScore | 補足 |
|---|---|---|---|
| K♣J♣ | Kのワンペア（Jキッカー） | 15 | Jはボードになし |
| A♥9♦ | Aのワンペア（A-Qの2ペア） | 22 | ボードのKQもあるが自分のA有利 |
| K♠Q♠ | Kペア+Qペア（2ペア） | 22 | K-Q-K-Q-2ペア判定 |
| 8♣7♣ | 7のペア（セカンドペア） | 8 | 相対的に弱い |
| 3♦4♠ | 役なし（ハイカード） | 0 | 外れ |

**ベットサイズ別の後手スコア（BBの手=K♣J♣、HandScore=15）**

```
50%ベット（C=5）:   後手スコア = 15+3−3−5−0 = 10 → コール
75%ベット（C=7）:   後手スコア = 15+3−3−7−0 = 8  → コール（CR境界）
100%ベット（C=9）:  後手スコア = 15+3−3−9−0 = 6  → コール
150%OB（C=11）:    後手スコア = 15+3−3−11−0 = 4  → コール（薄い）
```

50%から150%まで、Kペアは一貫してコール域に留まります。ただしスコアは10→4と低下し、150%オーバーベットに対するコールは「薄いコール」です。

**75%ベット時のCR検討**

スコア=8はCR検討の境界です。しかしKペアのみでリバーCRを打つのは合理的ではありません。BTNの75%ベットレンジには AA・AK・AQ等の強い2ペア以上が多く含まれており、CRしてコールされた場合の期待値がマイナスになります。

リバーCRは「コールされても勝てる強いハンド」に限定します。Kペアでのリバーコールは正当ですが、Kペアでのリバーチェックレイズは過剰な攻撃です。

**外れたドローのフォールド**

BBがスペードのフラッシュドローを持っていた場合（例: 9♠8♠、ターンで FD だったが、リバーで 5 枚目のスペードが落ちず外れ、しかもストレートにも絡まない）を確認します。

```
9♠8♠ + ボード K♠7♦2♣A♥Q♦:
  役: ハイカード（best 5 = A-K-Q-9-8、Aハイ）
  HandScore = 0（役なし、ドロー加点なし、ボードペアもなし）
後手スコア = 0 + 3 − 3 − 7 − 0 = −3 → フォールド
```

ターンでフラッシュドロー加点があったハンドは、リバーで FD が外れて役にも絡まない場合、ハイカードまで落ちます。後手スコアは大幅に低下し、フォールドが明確になります。「ドローが外れたらフォールド」という直感をスコアで裏付けることができます。

**broadway 完成の見落としを避ける**

なお、リバーボード K♠7♦2♣A♥Q♦ で BB が J-T を持っていた場合（例: J♠T♠）、ハンドとボードの組み合わせで A-K-Q-J-T の **broadway ストレートが完成** します（hand の T と board の A-K-Q-J で 5 連続）。これは「外れたフラッシュドロー」ではなく「ストレート完成」です。

```
J♠T♠ + ボード K♠7♦2♣A♥Q♦:
  役: ブロードウェイストレート（A-K-Q-J-T）
  HandScore = 30（ストレート以上、巻② 基準）
後手スコア = 30 + 3 − 3 − 7 − 0 = 23 → チェックレイズ推奨
```

リバーで HandScore を再計算する際、特に AKQJ や KQJT を含むボードでは、**T や 9 を含むハンドが broadway / K-high straight に化ける**ことに注意が必要です。「FD 外れ」と直感した瞬間に、ストレートが成立していないかを確認する習慣を持ってください。

**フラッシュ完成の例**

別の例として、ターン後のボードが K♠Q♠2♣5♠（同スート 3 枚）で、BB が J♠T♠ を持ってリバー 8♠（4 枚目のスペード）が落ちた場合を考えます。

```
J♠T♠ + ボード K♠Q♠2♣5♠8♠:
  スペードの枚数: ボード 4 + ハンド 2 = 6 枚 → フラッシュ完成
  best 5 spades: K♠-Q♠-J♠-T♠-8♠ = キングハイフラッシュ
  HandScore ≈ 25（フラッシュ、巻② 基準）
A 値: 5 枚ボードに同スート 4 枚以上 → ウェット = 1
後手スコア = 25 + 1 − 3 − 7 − 0 = 16 → チェックレイズ推奨
```

同じ J♠T♠ でも、ボード構成次第で「フォールド」「コール」「CR 推奨」と判定が大きく変わります。リバーで毎回 HandScore を再評価することの重要性がここに表れています。

## 10-8 MDFラインとの連携

後手スコアとMDF（1−α）は別の問いに答えますが、整合させる必要があります。

MDFが示す「レンジ全体の防御率」を後手スコアで満たせているかを確認する手順を整理します。

**確認の手順**

1. 相手のベットサイズからαとMDF（1−α）を計算する
2. 後手スコアを各ハンドに適用し、スコア≥0のハンドをコールレンジに収集する
3. コールレンジのコンボ数 ÷ 全ハンドコンボ数を概算し、MDFと比較する
4. 大きく下回る場合はフォールド境界（スコアがわずかにマイナス）のハンドを一部コールに混ぜる

33%ベットの場合の具体例で見てみます。

```
33%ベット:
  α = 0.25
  MDF（1−α）= 0.75（75%コール以上が必要）

後手スコア確認:
  スコア ≥ 0 のハンドを集めた結果、全コンボの65%だった場合
  → 75%に到達していない
  → スコア −1〜−3 のハンドから一部をコールに混ぜる（MDF調整）
```

これが巻②の「33%ベット時は後手スコアが−3まではコール気味、−4以下はフォールド」というルールの根拠です。ターン・リバーでも同様の調整が必要になる場合があります。

特に**33%の小サイズベット**に対しては、後手スコアがわずかにマイナスのハンドも一部コールに混ぜてMDFを守ることを意識してください。

**ベットサイズ別のMDFとC値の対応一覧**

後手スコアのCとMDFの対応を一表にまとめます。実戦ではMDFを意識しながら後手スコアを使います。

| ベットサイズ | α（フォールド分岐） | MDF（1−α） | C値 | MDF調整目安 |
|---|---|---|---|---|
| 33%ポット | 25% | 75% | 3 | スコア −3 までコール気味 |
| 50%ポット | 33% | 67% | 5 | スコア −2 までコール気味 |
| 75%ポット | 43% | 57% | 7 | スコア 0 以上をコール |
| 100%ポット | 50% | 50% | 9 | 強いハンドのみコール |
| 150%ポット | 60% | 40% | 11 | ナッツ近辺のみコール |

この表を見ると、75%以上のベットに対してはスコア0のハンドからコールレンジを構成してもMDFを自然に満たせる場合が多いことがわかります。一方、33%の小サイズに対してはMDFが75%と高く、スコアがマイナスのハンドも一部動員する必要が出ます。

ターンの実戦ではBTNが33%の小サイズを打つことが多い状況（ドライ板でのレンジベット）に特に注意が必要です。「後手スコア = 0 未満 → 全部フォールド」という単純な適用は、33%ベットに対して守り不足になる可能性があります。

**MDFライン（MDF）を数値で確認する習慣**

実戦でMDF確認が必要な典型場面：

- 相手が33%以下の小サイズで打ってきた場合
- 相手のベットが毎回同じサイズで繰り返される場合（パターン化している相手）
- 自分のコールレンジが薄い（HandScoreが低いハンドが多い）局面

逆に、75%以上の大きなベットに対してはMDFよりも「このハンドで本当に勝てるか」というショーダウン価値の検証が優先します。75%以上のベットに対してMDFを意識するよりも、後手スコアに従ったハンド別判断の方が精度が高くなります。

セカンドペア:    8

**ターン版の補足事項**

## 10-10 フロップ・ターン・リバーの後手スコア比較

3ストリートにわたって後手スコアがどう変化するかを、同じハンドで追います。これにより「ターン・リバー版の調整点」が視覚的に明確になります。

**ハンド: A♣K♥（TPTK）（BTN vs BB、6-max、100BB）**

フロップ K♠7♦2♣（ドライ）。BTNが50%CBet。

```
フロップ後手スコア（AK = TPTK, HandScore=18）:
  = 18 + 3 − 3 − 5 − 0
  = 13 → チェックレイズ推奨（CR域）
```

フロップではHandScore=18（TPTK、A キッカー）でCRが有利です。

ターン 5♥（ブランク、ドライ維持）。BTNが75%ベット。

```
ターン後手スコア（AK = TPTK 維持, HandScore=18）:
  A = K-7-2-5 ブランクターン、ドライ維持 = 3
  = 18 + 3 − 3 − 7 − 0
  = 11 → CR推奨（やや弱い）
```

ターンでもブランクが落ちて TPTK が維持されますが、75% ベットの C=7 の重みで後手スコアが押し下げられます。

リバー 3♣（ブランク）。BTNが50%ベット。

```
リバー後手スコア（AK = TPTK, HandScore=18, ドロー加点ゼロ）:
  A = K-7-2-5-3（ドライ維持）= 3
  = 18 + 3 − 3 − 5 − 0
  = 13 → CR推奨
```

リバーでは50%ベットに戻るためC=5になり、スコアは13のCR域に戻ります。

| ストリート | HandScore | A | C | 後手スコア | 判断 |
|---|---|---|---|---|---|
| フロップ（CBet 50%） | 18（TPTK） | 3 | 5 | 13 | CR推奨 |
| ターン5♥（75%） | 18（TPTK） | 3 | 7 | 11 | CR推奨（やや弱） |
| リバー3♣（50%） | 18（TPTK） | 3 | 5 | 13 | CR推奨 |

この追跡で見えることは、**ターンの75%ベットが最も後手スコアを押し下げる**ということです。HandScore が一定（TPTK = 18）でも、C 値が 5 → 7 → 5 と U 字型に動くため、ターンで 2 ポイント分のスコアが下がります。「ターンの大サイズベットが最大の負担」という感覚はこの C の動きから来ています。ターンのベットサイズ判断（第11章で詳解）が、後手のディフェンス構造に直接影響します。

**A値変化の追跡例**

別のハンドとして、フロップ J♥8♠3♦（セミ、レインボー）でのK♠Q♥（2OC + BDFD）を追います。

フロップ J♥8♠3♦（セミ、A=2）。BTN33%CBet。

```
フロップ後手スコア（K♠Q♥ = 2OC + BDFD, HandScore = 0+9+4 = 13）:
  = 13 + 2 − 3 − 3 − 0
  = 9 → CR境界〜コール
```

KとQはJより高いランクの2OCで、K♠は8♠と同スートのためバックドアフラッシュドロー（BDFD）も持ちます。HandScore は 2OC=9 + BDFD=4 = 13 となります。

ターン 9♣（コネクター）。J-8-9 でストレートドローの可能性が増えます。

```
4枚ボード J♥8♠3♦9♣: コネクター進行 → A=1（ウェット）
ターン後KQの役: ガットショット（T で K-Q-J-T-9 ストレート完成、4 outs） + 2OC残存
  HandScore = 0 + 9 (2OC) + 6 (ガットショット) = 15（上限15点のキャップに収まる）
BTN が50%ベット（C=5）

ターン後手スコア:
  = 15 + 1 − 3 − 5 − 0
  = 8 → CR境界（実戦ではコール）
```

注: KQ が J-8-3-9 ボードで取れるストレートは「K-Q-J-T-9」のみで、これは T が必要なガットショット（4 outs）です。OESD（8 outs、4 連続が成立する場合）ではありません。K-Q-J-9 は 4 連続ではなく、T が抜けたためギャップ存在のガットショット止まりです。

ターンでA値が2→1に下がり、HandScoreが13→15に上昇したことで、後手スコアは9→8とわずかに低下しました。Aが下がる影響と、HandScoreが上がる影響が打ち消し合った結果です。

フロップ→ターンでA値が変化することが、後手スコアの計算に直接影響を与えます。「4枚ボードでA値を再評価する」の重要性を理解してください。

## 10-11 後手スコアの整理と次章への橋渡し

本章で学んだターン・リバー版後手スコアを整理します。

**後手スコアの完全版（ターン・リバー対応）**

```
後手スコア = HandScore + A − 3 − C − M

【ターン版の特記事項】
  A = 4枚ボード全体で評価し直す（フロップのA値を引き継がない）
  HandScore = ターンカードによる役進化後で評価する
  C = ベット比率（%ポット）から決まる。ポットサイズに依存しない

【リバー版の特記事項】
  HandScore = ドロー加点ゼロ。ショーダウン価値のみ
  C = 100%ベット: C=9 / 150%ベット: C=11 を追加で使用
  CR閾値（スコア≥8）であっても、ハンドが相手バリューに勝てるかを確認する

【C値の全テーブル】
  ターン・リバー共通: 33%=3 / 50%=5 / 75%=7
  リバー専用拡張:     100%=9 / 150%=11

【A値の維持/変化ルール】
  フロップのA値をターンで引き継ぐのではなく、4枚全体で再判定する
  ウェット要素（スーテッドやコネクター）が加わる場合はA値を下げる
  ペアターンやブランクターンはA値を維持またはドライ方向に評価する

【M 値の扱い（HU前提）】
  本書の基本設定はBTN vs BB（HU）のためM=0
  3-wayの局面ではM=3を加算する（CR閾値が実質11に上昇）
```

**後手スコアの判断フロー（実戦用）**

```
Step 1: 相手のベットサイズからCを決める
Step 2: 4枚ボードのA値を評価する（ターン）または5枚で再評価（リバー）
Step 3: 自分のHandScoreを確認する（ターン後の役を正確に反映）
Step 4: 後手スコア = HandScore + A − 3 − C を計算する
Step 5: スコアに応じてアクションを選択する
  ≥ 8 → CR検討（ただしハンドがCRに値するか確認）
  0〜7 → コール
  < 0 → フォールド（33%ベット時はMDFに注意）
```

**次章（第8章ブロッカー論）への接続**

後手スコアはHandScore・A・C・Mという変数で決まります。しかしこれらの変数では捉えられない「枝葉の調整」があります。それがブロッカー効果です。

たとえば後手スコアが7（コール域）のハンドでも、自分が相手のナッツフラッシュの一部をブロックしている場合（例：A♣を持ちフラッシュ完成ボードで相手のナッツフラッシュA♣x♣を阻害）、後手スコアを0.5〜1点分だけ上方修正できます。逆に相手のブラフを自分がブロックしている場合（フラッシュボードで自分がフラッシュカードを持ち相手のブラフキャンディダートを潰している）は、後手スコアを下方修正します。

第8章では、後手スコアの「ブロッカーによる枝葉修正」を扱います。本章の後手スコアは「ブロッカー修正なしのベースライン」として使い、第8章の修正を加えることで精度を高める設計です。

### 問1

BTN vs BB（HU）。フロップ K♠7♦2♣（ドライ）でBTNがCBet、BBがコール。ターン A♥（OCターン）。ポット約12BB。BTNが75%ポットベット（約9BB）を打った。BBの手は 7♣6♥（セカンドペア7のみ。ターン後HandScore=8、ドロー加点なし）。4枚ボード K-7-2-A はドライ評価のままA=3とします。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 1 → コール（薄いが範囲内）
2. 後手スコア = −1 → フォールド
3. 後手スコア = 4 → コール（余裕あり）

### 問2

同じターン局面（K♠7♦2♣A♥、A=3、C=7、HU）でBBが A♥9♥（Aターンで2ペアに昇格、HandScore=22）を持つ場合、後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 15 → コール
2. 後手スコア = 15 → チェックレイズ推奨
3. 後手スコア = 22 → チェックレイズ推奨

### 問3

リバーで5枚ボードが K♠7♦2♣A♥Q♦（ドライ、A=3）になった。ポット約30BB。BTNが150%オーバーベット（約45BB）を打った。BBの手は K♣J♣（Kのワンペア、HandScore=15、ドロー加点なし）。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 4 → コール（薄いが範囲内）
2. 後手スコア = −4 → フォールド
3. 後手スコア = 8 → チェックレイズ検討

- **問1**: 1（後手スコア = 8+3−3−7−0 = 1 → コール域の下限。7ペアのセカンドペアは薄いコールだが、後手スコアが0以上のためコール範囲に含まれる。フォールドとの境界に近いため、相手の頻度や読みを加味して判断する）

> - 後手スコア = HandScore + A − 3 − C − M は巻②から継承。ターン・リバーでも式の形は変わらない

> - 次章（第8章）でブロッカー効果による後手スコアの枝葉修正を扱う

**【GTOとのズレ】**

後手スコアはGTOソルバーの出力を「式に圧縮した近似」です。実戦での精度は約90%（フロップ実測基準）ですが、残り10%には重要な例外パターンが含まれます。

最も大きなズレが生じるのは、**リバーのCR判断**です。後手スコアがCR域（≥8）に入っても、ハンドクラスが「コールされた場合に相手のバリューに負けてしまう」状況でCRを実行するのはGTO的に誤りです。GTOソルバーはCR候補ハンドを「コールされて相手に負けないハンド」に絞り込みます。後手スコアはその絞り込みを自動的には行いません。リバーでCR域のスコアが出たら「コールされたとき相手のバリューに勝てるか」という追加チェックが必要です。

また、**ペアターン後のディフェンス判断**でも実戦的なズレが生じます。ペアターンはIPのナッツアドバンテージが最大化されるため（第5章・第8章で確認したGTO実測、ペアターンの平均CBet=90.8%）、OOPの後手スコアが高く出ても「相手がナッツ（フルハウス・クワッズ）を持っていた場合のリスク」が高まります。後手スコアは平均的なレンジを前提にした計算なので、個別のハンドで「自分が相手のナッツに対してどれだけ弱いか」を意識した調整が必要です。

もうひとつの実戦的なズレは**MDFとの乖離**です。後手スコアを機械的に適用すると、特に33%の小サイズベットに対して守り不足になる場合があります。後手スコアがわずかにマイナスのハンドを一部コールに混ぜる「MDF調整」を意識的に行う必要があります。式の判断だけに頼ると、小サイズベットへの過剰フォールドという搾取されやすいパターンに陥ります。

また、**ターンとリバーでの式の同一性**が引き起こすズレもあります。後手スコアはフロップと同じ式をターン・リバーに適用しますが、ストリートが進むにつれてHandScoreの変動幅が大きくなります。フロップでは「TPTKならHandScore=18」という比較的安定した評価ができますが、ターン・リバーではドローの完成/外れ、役の昇格・降格により同じハンドでも局面によってHandScoreが0から30まで大きく変わります。この変動を正確に追えない場合、後手スコアが実態と乖離します。

ターン・リバーで後手スコアを使う際の実戦的なチェックリストを整理します。

```
後手スコア計算後の追加チェック:

□ C値は正しいか？（ポットサイズではなくベット比率から決める）
□ A値はターンカード後の4枚全体で再評価したか？（フロップのA値を引き継いでいないか）
□ リバーでHandScoreのドロー加点をゼロにしたか？（ドローは完成/外れで再評価）
□ 33%ベットに対してMDF（75%）を満たしているか？（MDF調整が必要か）
□ CR域（≥8）のハンドでCRを実行する場合、コールされて勝てるか？（リバー限定）
□ ペアターンでCRを選ぶ場合、相手のフルハウス・クワッズへの対応を考えたか？
```

この6点を習慣的にチェックすることで、後手スコアの計算ミスと適用ミスの大部分を防げます。GTOソルバーが自動的に行っている計算の精度には届きませんが、実戦での判断精度を大幅に高められます。
