# 第10章　後手スコア（ターン版）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 巻②で導入した後手スコアをターン・リバー用に再校正し、コール/チェックレイズ/フォールドを数値で判断できるようになる。

---

## 10-1 巻②の後手スコアを振り返る

巻②（フロップ基礎編）では、相手のCBetに対するディフェンス判断を**後手スコア**という式で数値化しました。本章ではその式を HandScore（0〜100）に合わせて再校正し、ターン・リバーへと拡張します。

まず式を確認してください。

```
後手スコア = HandScore + A − C − M

A（ボード値）: ドライ=12 / セミウェット=6 / ウェット=0
C（ベット負担）: 33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30
M（マルチウェイ補正）: HU=0 / 3-way=12 / 4-way以上=22

後手スコア ≥ 40 → チェックレイズ（CR）検討
後手スコア 20〜39 → コール
後手スコア < 20 → フォールド
```

旧式の "− 3"（ベースライン補正）は A 値に吸収しました。HandScore は equity % 相当（0〜100）を使います。GTO 整合性 92.6% の検証済みフレームワークです。

本章で問うのは「ターン・リバーでもこの式はそのまま使えるか？」です。

---

## 10-2 後手スコアと本書 第9章 α 式の関係

後手スコアを理解するうえで、α 式（本書 第9章で扱う先手の設計式）との対比が重要です。

```
α 式（先手の視点）:
  α = ベット額 ÷ (ポット + ベット額)
  → 先手にとってブラフが損益分岐するための最低フォールド率

後手スコア（後手の視点）:
  後手スコア = HandScore + A − C − M
  → 後手にとってコール/フォールド/CRが有利かを数値で決める
```

α 式は「先手がどれだけブラフを入れられるか」の設計ツールです。後手スコアは「後手がそのベットに対してどう応じるか」の判断ツールです。両者は**表裏の関係**にあります。

先手がα 式を使ってバリュー比率を設計し、後手が後手スコアを使ってディフェンス範囲を決める。この二者の計算が噛み合うことで、ポットは均衡に向かいます。

MDF（1−α）との対応を整理すると、こうなります。

```
MDF（レンジ全体の最低防御率）:
  = 1 − α
  = ポット ÷ (ポット + ベット)

後手スコア（個別ハンドの判断）:
  = HandScore + A − C − M
  ≥ 20 → そのハンドをコールレンジに含める
  < 20 → そのハンドをフォールドレンジに含める
```

MDFは「レンジ全体で何%守るか」を指定します。後手スコアは「このハンドを守るレンジに含めるかどうか」を個別に判断します。両者は別の問いに答えており、どちらか一方で十分ではありません。実戦では後手スコアを個別ハンドに適用し、結果としてMDFが自然に満たされることを目指します。

## 10-3 C 補正のメカニズム ─ なぜ%ベースか

C（ベット負担）の値がなぜ33%=12、50%=17、75%=22 という設計なのかを理解しておくことで、ターン・リバーへの拡張の根拠が明確になります。

C は HandScore のスケールと合わせるための「変換係数」です。HandScore は 0〜100（equity % 相当）の範囲で手の強さを表します。このスケールに対し、「ベットが大きいほど守りにくくなる」という圧力を同じスケールの数値として表現するために C が設計されています。

C 値の設計は α 式から逆算されています（「C = α × 50」）。

```
C = α × 50 = (1 − MDF) × 50

33%ベット → α = 0.25 → C = 12.5 → 12
50%ベット → α = 0.33 → C = 17（≈ 16.5）
75%ベット → α = 0.43 → C = 21.5 → 22
100%ベット → α = 0.50 → C = 25
150%ベット → α = 0.60 → C = 30
```

重要なのは、**Cはポットとベットの比率から決まる**という点です。絶対額ではなくベット比率（%ポット）に連動します。

したがって、ターンでポットが12BBになっていても、ベット比率が同じ75%であればC=22のままです。リバーでポットが25BBになっていても、75%ベットならC=22です。ポットサイズの変化はCの値を変えません。

これがC値の「ポット不変性」です。ターン・リバーでも同じC値テーブルを使える根拠がここにあります。

## 10-4 ターン版の調整点 ─ A値の4枚評価

フロップ後手スコアとターン後手スコアの最大の違いは、**A値（ボード値）の評価対象**です。

フロップのA値はフロップの3枚で評価します。ターンのA値はターン後の4枚すべてで評価し直します。

```
A値の評価基準（ターン版）:
  4枚ボードがドライ（ペアボード・散開rainbow）= 12
  4枚ボードがセミウェット = 6
  4枚ボードがウェット（コネクテッド/フラッシュドロー形成）= 0
```

なぜA値を再評価するのか。ターンカードが落ちることでボードのウェット度が変化するからです。

具体例で確認します。

**フロップ K♠7♦2♣（ドライ, A=12）にターン 5♠ が落ちた場合**

ターン前: K♠7♦2♣（3枚ドライ、A=12）
ターン後: K♠7♦2♣5♠（4枚）

5♠の影響を検討します。スペードが2枚になった（K♠と5♠）。A=6（セミウェット）に下がります。

後手スコアの計算でこの変化を反映します。

```
フロップ時:  後手スコア = HandScore + 12 − C
ターン時:   後手スコア = HandScore + 6 − C
差:  −6（ターンでスコアが6点下がる）
```

ターンカードがウェット要素を加えた場合、後手のディフェンス判断が厳しくなります。逆に、ドライボードにさらにドライなターンカード（ペアや散開カード）が落ちた場合はA値を維持またはさらに高く評価します。

**4枚ボードのA値判定早見表**

| フロップ | ターンカード | 4枚評価 | A値 |
|---|---|---|---|
| K♠7♦2♣（ドライ） | ブランク（3♣等） | K♠7♦2♣3♣（ドライ維持） | 12 |
| K♠7♦2♣（ドライ） | ペア（7♥） | K♠7♦2♣7♥（ペアボード） | 12 |
| K♠7♦2♣（ドライ） | フラッシュ（5♠） | K♠7♦2♣5♠（セミ） | 6 |
| J♥8♠3♦（セミ） | コネクター（9♣） | J♥8♠3♦9♣（ウェット） | 0 |
| J♥8♠3♦（セミ） | ブランク（2♣） | J♥8♠3♦2♣（セミ維持） | 6 |

この再評価がターン版のA値処理の核心です。「フロップのA値をそのままターンに引き継がない」という点を必ず意識してください。

## 10-5 リバー版の調整点 ─ ドロー成分の消滅とC拡張

リバーでは後手スコアにさらに重要な調整が必要です。それはHandScoreの評価方法の変化とC値の拡張です。

### HandScoreのリバー版評価

フロップ・ターンでは、HandScoreは「現在の役スコア」に「ドロー加点」を含めて計算します。ドロー加点は **Rule of 2 / Rule of 4 直接適用**で計算します。フロップではアウツ × 4（フラッシュドロー +36、OESD +32）、ターンではアウツ × 2（FD +18、OESD +16）です。Rule of 2 and 4（巻② 第8章）は「アウツ × 2 ≒ 1 ストリート分の勝率%」で、HandScore が equity % 相当のため直接 outs に対応させます。

リバーではドローが完成したか外れたかが確定しています。したがって**リバーのHandScoreはショーダウン価値のみ**で評価します。

```
フロップ/ターンのHandScore: 役スコア + ドロー加点
リバーのHandScore: 役スコアのみ（ドロー加点=0）

ドロー成分の扱い:
  完成した → 完成後の役スコアでHandScoreを計算（FD完成=フラッシュとして評価）
  外れた  → 役スコアのみ（HandScore大幅低下）
```

外れたドローがリバーで後手スコアを大きく押し下げる理由がここにあります。

**具体例**

ターン: K♠7♦2♣5♠ でフラッシュドロー（スペード）を持っていた A♠8♠（HandScore ≈ 25 + FD加点 18 + ナッツブロッカー +5 = 48 ≈ Aハイ + FD）

リバー: Q♦（スペードなし）が落ちた場合

リバーのHandScore: Aハイのみ = 役スコア25、ドロー加点なし → HandScore ≈ 25

後手スコア = 25 + A − C → 中〜大サイズのCに対してほぼフォールド域に近い

一方、リバーが 9♠ だった場合：フラッシュ完成（Aハイフラッシュ）→ HandScore ≈ 90 → 後手スコアが大幅に上昇 → コール〜CR推奨

### リバーのC値拡張：150%ベット

本書 第9章で学ぶ α 式の通り、リバーではオーバーベット（150%以上）が先手の重要な戦術です。C 値を α と直結させ、ターン・リバー共通の体系で扱います。

```
C 値（ターン・リバー共通、C = α × 50）:
  33%ベット  → α = 0.25 → C = 12
  50%ベット  → α = 0.33 → C = 17
  75%ベット  → α = 0.43 → C = 22
  100%ベット → α = 0.50 → C = 25
  150%ベット → α = 0.60 → C = 30
```

リバーで相手がオーバーベットを打ってきた場合、後手スコアは C=30 の重みがかかります。HandScore が低いハンドはほぼすべてフォールドになります。これは GTO 的に正しい方向性です。リバーの大サイズベットに対しては、コールできるハンドを絞り込むことが防御の合理的な形です。

## 10-6 ターンディフェンスの実例 ─ ドライ板での複数ハンド比較

具体的な局面で後手スコアを各ハンドに適用し、「コール/CR/フォールド」の分岐を体験します。

**局面設定**

- BTN vs BB（HU）、100BB、6-maxキャッシュゲーム
- フロップ K♠7♦2♣（ドライ、フロップA=3）
- BTN が1/3ポットCBet → BB がコール
- ポット約12BB。ターン 7♥（ペアカード）
- BTN が75%ポットベット（約9BB）
- 共通パラメータ: A=12（K-7-2-7のペアボード、ドライ維持）、C=22（75%ベット）、M=0（HU）

**ハンド別の後手スコア一覧**

K-7-2-7 はペアボードのため、ボードの 7-7 がすべての best 5 に入ります。各ハンドの実際の役を正確に評価します。

| BBの手 | ターン後の役（best 5） | HandScore | 後手スコア | 判断 |
|---|---|---|---|---|
| K♣J♦ | 2 pair K's & 7's, J キッカー（K-K-7-7-J） | 72 | 72+12−22=**62** | CR推奨 |
| 7♣8♣ | トリップス 7（7-7-7-K-8） | 85 | 85+12−22=**75** | CR推奨 |
| A♠K♥ | 2 pair K's & 7's, A キッカー（A-K-K-7-7） | 75 | 75+12−22=**65** | CR推奨 |
| 2♦3♣ | 2 pair 7's & 2's, K キッカー（K-7-7-2-2） | 68 | 68+12−22=**58** | CR検討 |
| J♣T♣ | 1 pair (board の 7's), K-J-T キッカー | 32 | 32+12−22=**22** | コール |

**ペアボードの hand evaluation 注意点**

K-7-2-7 のようなペアボードでは、どんなハンドも best 5 にボードの 7-7 が入ります。「役なし」「空振り」と評価するのは誤りで、最低でも 1 pair (board's 7's) が成立しています。Kx 系・7x 系のハンドはボードペアと組み合わさってさらに強い役（2 pair やトリップス）に昇格します。

**KJ の詳細判断**

K♣J♦ は「2 pair K's & 7's, J キッカー」（ペアボード昇格）で HandScore = 72。後手スコア=62 はCR推奨域です。しかし 7 ペアターン（BTNのナッツアドバンテージが最大化されるカード）という文脈を加味します。

- BTNのUncappedレンジにKK（フルハウス）・77（クワッズ）・K7（フルハウス）が含まれている
- KJ が CR を打った場合、BTN にリレイズされるとフォールドせざるを得ない
- CR−フォールドはコールよりも期待値が低い局面になりやすい

このハンドは「後手スコア=62 でも、相手のナッツが大幅に強化されるターン」ではコール優先という調整が必要です。CR域のスコアでも、ナッツ非対称性が極端な局面では一段下げる習慣を持ってください。

**トリップス 7（7♣8♣）の詳細判断**

7♣8♣ + K♠7♦2♣7♥ のboardで、自分の 7♣ + ボードの 7♦ + 7♥ = 3 of 7's = トリップス。HandScore = 85。後手スコア=75 は CR 域の中央付近。BTNの75%ベットに対してCRを選びます。

トリップスは BTN が KK を持つ場合のフルハウス（K's full of 7's）には負けますが、BBの 7♣8♣ で作るトリップス 7 は BTN の Kx ハンドには勝てます。ただし、BTNが KK を持つ確率は低く（6 コンボ以下）、バリューの多くに勝てるためCRが有利です。

**ペアターンの防御総括**

BTN vs BB での K-7-2-7 ターン（ペア）は、GTOソルバー実測でBTNのCBet頻度が100%に近い局面です（第8章バレルスコア: ドライ8+ペア4=12 → 積極バレル）。BTNの75%ベットに対する後手スコアを俯瞰すると、HandScore 65 以上のハンドが CR、HandScore 30〜64 がコール、HandScore 30 未満がフォールドという構造になります。

## 10-7 リバーディフェンスの実例 ─ ベットサイズ別の判断変化

リバーでの後手スコアの使い方を、ベットサイズを変えて確認します。

**局面設定**

- フロップ K♠7♦2♣（ドライ）→ ターン A♥（OC）→ BBがコール継続
- リバー: Q♦（ブランク、ストレート不絡み）
- 5枚ボード: K♠7♦2♣A♥Q♦
- ポット約30BB

**5枚ボードのA値評価**

K♠7♦2♣A♥Q♦。散開rainbow、ストレートもフラッシュドローもなし。A=12（ドライ）。

**BBの各ハンドのHandScore（リバー版）**

ドロー加点はゼロ。ショーダウン価値のみで評価します。

| BBの手 | 役（5枚ボード） | HandScore | 補足 |
|---|---|---|---|
| K♣J♣ | Kのワンペア（Jキッカー、セカンドペア相当）| 35 | A がトップなので K はセカンドペア |
| A♥9♦ | Aのワンペア（TPMK、9キッカー）| 50 | A がトップで TPMK |
| K♠Q♠ | 2 ペア（K's & Q's、Aキッカー）| 75 | top + 2nd 2pair |
| 8♣7♣ | 7のペア（セカンドペア弱）| 32 | 相対的に弱い |
| 3♦4♠ | 役なし（ハイカード Aなし）| 10 | 外れ |

**ベットサイズ別の後手スコア（BBの手=K♣J♣、HandScore=35）**

```
50%ベット（C=17）:   後手スコア = 35+12−17−0 = 30 → コール
75%ベット（C=22）:   後手スコア = 35+12−22−0 = 25 → コール
100%ベット（C=25）:  後手スコア = 35+12−25−0 = 22 → コール（薄い）
150%OB（C=30）:     後手スコア = 35+12−30−0 = 17 → フォールド
```

50%から100%までは K セカンドペアでコール域に留まります。150%オーバーベットでは後手スコアが 17 と 20 を割り、フォールドが妥当になります。

**75%ベット時のCR検討**

スコア=25 はコール域の中位です。K セカンドペアでリバーCRを打つのは合理的ではありません。BTNの75%ベットレンジには AA・AK・AQ等の強い2ペア以上が多く含まれており、CRしてコールされた場合の期待値がマイナスになります。

リバーCRは「コールされても勝てる強いハンド」（HandScore≥65 が目安）に限定します。

**外れたドローのフォールド**

BBがスペードのフラッシュドローを持っていた場合（例: 9♠8♠、ターンで FD だったが、リバーで 5 枚目のスペードが落ちず外れ、しかもストレートにも絡まない）を確認します。

```
9♠8♠ + ボード K♠7♦2♣A♥Q♦:
  役: ハイカード（best 5 = A-K-Q-9-8、Aハイ）
  HandScore = 25（A ハイ、ドロー加点なし、ボードペアもなし）
後手スコア = 25 + 12 − 22 − 0 = 15 → フォールド
```

ターンでフラッシュドロー加点があったハンドは、リバーで FD が外れて役にも絡まない場合、A ハイ程度まで落ちます。後手スコアは 20 を割り込み、フォールドが明確になります。

**broadway 完成の見落としを避ける**

なお、リバーボード K♠7♦2♣A♥Q♦ で BB が J-T を持っていた場合（例: J♠T♠）、ハンドとボードの組み合わせで A-K-Q-J-T の **broadway ストレートが完成** します。

```
J♠T♠ + ボード K♠7♦2♣A♥Q♦:
  役: ブロードウェイストレート（A-K-Q-J-T）
  HandScore = 85（A ハイストレート、broadway）
後手スコア = 85 + 12 − 22 − 0 = 75 → チェックレイズ推奨
```

リバーで HandScore を再計算する際、特に AKQJ や KQJT を含むボードでは、**T や 9 を含むハンドが broadway / K-high straight に化ける**ことに注意が必要です。

**フラッシュ完成の例**

別の例として、ターン後のボードが K♠Q♠2♣5♠（同スート 3 枚）で、BB が J♠T♠ を持ってリバー 8♠（4 枚目のスペード）が落ちた場合を考えます。

```
J♠T♠ + ボード K♠Q♠2♣5♠8♠:
  スペードの枚数: ボード 4 + ハンド 2 = 6 枚 → フラッシュ完成
  best 5 spades: K♠-Q♠-J♠-T♠-8♠ = キングハイフラッシュ
  HandScore ≈ 85（K ハイフラッシュ、中位 +）
A 値: 5 枚ボードに同スート 4 枚以上 → ウェット = 0
後手スコア = 85 + 0 − 22 − 0 = 63 → チェックレイズ推奨
```

同じ J♠T♠ でも、ボード構成次第で「フォールド」「コール」「CR 推奨」と判定が大きく変わります。リバーで毎回 HandScore を再評価することの重要性がここに表れています。

## 10-8 MDFラインとの連携

後手スコアとMDF（1−α）は別の問いに答えますが、整合させる必要があります。

MDFが示す「レンジ全体の防御率」を後手スコアで満たせているかを確認する手順を整理します。

**確認の手順**

1. 相手のベットサイズからαとMDF（1−α）を計算する
2. 後手スコアを各ハンドに適用し、スコア ≥ 20 のハンドをコールレンジに収集する
3. コールレンジのコンボ数 ÷ 全ハンドコンボ数を概算し、MDFと比較する
4. 大きく下回る場合はフォールド境界（スコア 15〜19）のハンドを一部コールに混ぜる

33%ベットの場合の具体例で見てみます。

```
33%ベット:
  α = 0.25
  MDF（1−α）= 0.75（75%コール以上が必要）

後手スコア確認:
  スコア ≥ 20 のハンドを集めた結果、全コンボの65%だった場合
  → 75%に到達していない
  → スコア 15〜19 のハンドから一部をコールに混ぜる（MDF調整）
```

ターン・リバーでも同様の調整が必要になる場合があります。

特に**33%の小サイズベット**に対しては、後手スコアがわずかに 20 未満のハンドも一部コールに混ぜてMDFを守ることを意識してください。

**ベットサイズ別のMDFとC値の対応一覧**

後手スコアのCとMDFの対応を一表にまとめます。実戦ではMDFを意識しながら後手スコアを使います。

| ベットサイズ | α（フォールド分岐） | MDF（1−α） | C値 | MDF調整目安 |
|---|---|---|---|---|
| 33%ポット | 25% | 75% | 12 | スコア 15 までコール気味 |
| 50%ポット | 33% | 67% | 17 | スコア 18 までコール気味 |
| 75%ポット | 43% | 57% | 22 | スコア 20 以上をコール |
| 100%ポット | 50% | 50% | 25 | 強いハンドのみコール |
| 150%ポット | 60% | 40% | 30 | ナッツ近辺のみコール |

この表を見ると、75%以上のベットに対してはスコア 20 のハンドからコールレンジを構成してもMDFを自然に満たせる場合が多いことがわかります。一方、33%の小サイズに対してはMDFが75%と高く、スコアが 20 未満のハンドも一部動員する必要が出ます。

ターンの実戦ではBTNが33%の小サイズを打つことが多い状況（ドライ板でのレンジベット）に特に注意が必要です。「後手スコア < 20 → 全部フォールド」という単純な適用は、33%ベットに対して守り不足になる可能性があります。

**MDFライン（MDF）を数値で確認する習慣**

実戦でMDF確認が必要な典型場面：

- 相手が33%以下の小サイズで打ってきた場合
- 相手のベットが毎回同じサイズで繰り返される場合（パターン化している相手）
- 自分のコールレンジが薄い（HandScoreが低いハンドが多い）局面

逆に、75%以上の大きなベットに対してはMDFよりも「このハンドで本当に勝てるか」というショーダウン価値の検証が優先します。75%以上のベットに対してMDFを意識するよりも、後手スコアに従ったハンド別判断の方が精度が高くなります。

後手スコアを正確に使うには、HandScoreの値とハンドクラスの対応を暗記しておく必要があります。巻②の定義を確認し、ターン・リバー版の補足を加えます。

**HandScore基準値（フロップ・ターン共通）**

```
フルハウス:                    92
フラッシュ:                    85-90
ストレート:                    78-85

2ペア:                         68-78
オーバーペア (高/中/低):       68-78
TPTK:                          70
TPGK（Q キッカー）:             66
TPMK:                          50
TPWK:                          45
セカンドペア:                  32-42
アンダーペア:                  35-45
ボトムペア:                    32
A ハイ:                        25
K ハイ:                        20
完全空振り:                    8

ドロー加点:
  フロップ (Rule of 4): アウツ × 4
    FD: +36 / OESD: +32 / ガットショット: +16
  ターン (Rule of 2): アウツ × 2
    FD: +18 / OESD: +16 / ガットショット: +8
  バックドア (固定): BDFD +5 / BDSD +2
```

**ターン版の補足事項**

ターンでは役が進化します。ハンドエボリューションを正確に反映したHandScoreを使います。

```
フロップ: セット（KK on K72r）→ HandScore = 92（top set）
ターン7: フルハウス（KK-7 ペア化）→ HandScore = 92（セット以上を維持）

フロップ: TPTK（AK on K72r）→ HandScore = 70
ターンA: 2ペア（AK on K72A）→ HandScore = 78（top 2 pair）

フロップ: OESD（98 on JT3r）→ HandScore = 8 + 32 = 40（ドロー加点込み）
ターンQ: ストレート完成（98 on JTQ3）→ HandScore = 78（mid ストレート）
ターンブランク: OESD継続 → HandScore = 8 + 16 = 24（ターン Rule of 2）
```

HandScoreはターンカードによって大きく変動します。後手スコアを計算する前に「ターンカードが自分のハンドをどう変化させたか」を正確に確認してください。

**ターンでのHandScore注意点**

| 状況 | 誤った評価 | 正しい評価 |
|---|---|---|
| TPTK（フロップ）→ 2ペア（ターン） | HandScore 70 のまま | HandScore 78 に上げる |

| ドロー（フロップ）→ ターンで外れ | フロップのドロー加点を維持 | ターン Rule of 2 で再計算 |
| ドロー（フロップ）→ ターンで完成 | ドロー加点を維持 | 完成後の役スコアに更新 |

## 10-10 フロップ・ターン・リバーの後手スコア比較

3ストリートにわたって後手スコアがどう変化するかを、同じハンドで追います。これにより「ターン・リバー版の調整点」が視覚的に明確になります。

**ハンド: A♣K♥（TPTK）（BTN vs BB、6-max、100BB）**

フロップ K♠7♦2♣（ドライ）。BTNが50%CBet。

```
フロップ後手スコア（AK = TPTK, HandScore=70）:
  = 70 + 12 − 17 − 0
  = 65 → チェックレイズ推奨（CR域）
```

フロップではHandScore=70（TPTK、A キッカー）でCRが有利です。

ターン 5♥（ブランク、ドライ維持）。BTNが75%ベット。

```
ターン後手スコア（AK = TPTK 維持, HandScore=70）:
  A = K-7-2-5 ブランクターン、ドライ維持 = 12
  = 70 + 12 − 22 − 0
  = 60 → CR推奨
```

ターンでもブランクが落ちて TPTK が維持されますが、75% ベットの C=22 の重みで後手スコアが押し下げられます。

リバー 3♣（ブランク）。BTNが50%ベット。

```
リバー後手スコア（AK = TPTK, HandScore=70, ドロー加点ゼロ）:
  A = K-7-2-5-3（ドライ維持）= 12
  = 70 + 12 − 17 − 0
  = 65 → CR推奨
```

リバーでは50%ベットに戻るためC=17になり、スコアは65のCR域に戻ります。

| ストリート | HandScore | A | C | 後手スコア | 判断 |
|---|---|---|---|---|---|
| フロップ（CBet 50%） | 70（TPTK） | 12 | 17 | 65 | CR推奨 |
| ターン5♥（75%） | 70（TPTK） | 12 | 22 | 60 | CR推奨 |
| リバー3♣（50%） | 70（TPTK） | 12 | 17 | 65 | CR推奨 |

この追跡で見えることは、**ターンの75%ベットが最も後手スコアを押し下げる**ということです。HandScore が一定（TPTK = 70）でも、C 値が 17 → 22 → 17 と U 字型に動くため、ターンで 5 ポイント分のスコアが下がります。「ターンの大サイズベットが最大の負担」という感覚はこの C の動きから来ています。

**A値変化の追跡例**

別のハンドとして、フロップ J♥8♠3♦（セミ、レインボー）でのK♠Q♥（2OC + BDFD）を追います。

フロップ J♥8♠3♦（セミ、A=6）。BTN33%CBet。

```
フロップ後手スコア（K♠Q♥ = K ハイ + BDFD, HandScore = 20 + 5 = 25）:
  = 25 + 6 − 12 − 0
  = 19 → コール（境界）
```

KとQはJより高いランクの2OCで、K♠は8♠と同スートのためバックドアフラッシュドロー（BDFD）も持ちます。HandScore は K ハイ 20 + BDFD 5 = 25 となります（「2OC」自体は加点しません）。

ターン 9♣（コネクター）。J-8-9 でストレートドローの可能性が増えます。

```
4枚ボード J♥8♠3♦9♣: コネクター進行 → A=0（ウェット）
ターン後KQの役: ガットショット（T で K-Q-J-T-9 ストレート完成、4 outs）
  HandScore = 20 (Kハイ) + 8 (4 outs × 2、Rule of 2) = 28
BTN が50%ベット（C=17）

ターン後手スコア:
  = 28 + 0 − 17 − 0
  = 11 → フォールド
```

注: KQ が J-8-3-9 ボードで取れるストレートは「K-Q-J-T-9」のみで、これは T が必要なガットショット（4 outs）です。OESD（8 outs）ではありません。

ターンでA値が6→0に下がり、HandScoreが25→28に上昇しても、後手スコアは19→11と大きく低下しました。「ウェット化したターン」では Kハイ + ガットショット程度では守れない構造が明確になります。「4枚ボードでA値を再評価する」の重要性を理解してください。

## 10-11 後手スコアの整理と次章への橋渡し

本章で学んだターン・リバー版後手スコアを整理します。

**後手スコアの完全版（ターン・リバー対応）**

```
後手スコア = HandScore + A − C − M

【ターン版の特記事項】
  A = 4枚ボード全体で評価し直す（フロップのA値を引き継がない）
  HandScore = ターンカードによる役進化後で評価する（0〜100）
  ドロー加点 = アウツ × 2（Rule of 2 直接）
  C = ベット比率（%ポット）から決まる。ポットサイズに依存しない

【リバー版の特記事項】
  HandScore = ドロー加点ゼロ。ショーダウン価値のみ
  C = 100%ベット: C=25 / 150%ベット: C=30 を高頻度で使う
  CR閾値（スコア≥40）であっても、ハンドが相手バリューに勝てるかを確認する

【C値の全テーブル（C = α × 50）】
  33%=12 / 50%=17 / 75%=22 / 100%=25 / 150%=30

【A値の維持/変化ルール】
  フロップのA値をターンで引き継ぐのではなく、4枚全体で再判定する
  ドライ=12 / セミ=6 / ウェット=0
  ウェット要素（スーテッドやコネクター）が加わる場合はA値を下げる
  ペアターンやブランクターンはA値を維持またはドライ方向に評価する

【M 値の扱い（HU前提）】
  本書の基本設定はBTN vs BB（HU）のためM=0
  3-wayの局面ではM=12を加算する（CR閾値が実質52に上昇）
```

**後手スコアの判断フロー（実戦用）**

```
Step 1: 相手のベットサイズからCを決める（α × 50）
Step 2: 4枚ボードのA値を評価する（ターン）または5枚で再評価（リバー）
Step 3: 自分のHandScoreを確認する（ターン後の役を正確に反映）
Step 4: 後手スコア = HandScore + A − C を計算する
Step 5: スコアに応じてアクションを選択する
  ≥ 40 → CR検討（ただしハンドがCRに値するか確認）
  20〜39 → コール
  < 20 → フォールド（33%ベット時はMDFに注意）
```

**次章（第11章 後手スコアリバー版）への接続**

本章の後手スコアはターン専用の設計です。リバーに入るとドローが完成か不発に確定するため、HandScoreの計算基準が変わります。ターンで「NFD+ボトムペア」だったハンドは、リバーでフラッシュが外れるとHandScoreが大きく下がり、コール域から外れることがあります。逆にフラッシュが完成すればHandScoreが跳ね上がりCR域に入ります。

第11章では、後手スコアのリバー版を扱います。式の形（HandScore + A − C − M）は変わりませんが、HandScoreの計算基準（ドロー加点の除去）がターン版と異なるため、同じハンドでも判断が変わります。本章の後手スコアを「ターン版ベースライン」として使い、第11章のリバー調整を加えることで精度を高める設計です。

### 問1

BTN vs BB（HU）。フロップ K♠7♦2♣（ドライ）でBTNがCBet、BBがコール。ターン A♥（OCターン）。ポット約12BB。BTNが75%ポットベット（約9BB）を打ちました。BBの手は 7♣6♥（セカンドペア7のみ。ターン後HandScore=32、ドロー加点なし）。4枚ボード K-7-2-A はドライ評価のままA=12とします。後手スコアはいくつか、正しい判断はどれですか。

2. 後手スコア = 11 → フォールド
3. 後手スコア = 32 → コール（余裕あり）

同じターン局面（K♠7♦2♣A♥、A=12、C=22、HU）でBBが A♥9♥（Aターンで Aペアに昇格、A がトップなので TPWK 相当 = HandScore=60（42+9×2））を持つ場合、後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 50 → コール
2. 後手スコア = 50 → チェックレイズ推奨
3. 後手スコア = 60 → チェックレイズ推奨

### 問3

リバーで5枚ボードが K♠7♦2♣A♥Q♦（ドライ、A=12）になりました。ポット約30BB。BTNが150%オーバーベット（約45BB）を打ちました。BBの手は K♣J♣（K セカンドペア、HandScore=35、ドロー加点なし）。後手スコアはいくつか、正しい判断はどれですか。

1. 後手スコア = 17 → フォールド
2. 後手スコア = −10 → フォールド
3. 後手スコア = 40 → チェックレイズ検討

> **本章まとめ**
>
> - 後手スコア = HandScore + A − C − M は巻②から継承。ターン・リバーでも式の形は変わらない
> - HandScore は equity % 相当（0〜100）。判定閾値は ≥40 / 20-39 / <20
> - ターン版の主要変更点: A値を4枚ボード全体で再評価する。HandScoreをターン後の役で更新する
> - リバー版の主要変更点: HandScoreからドロー加点を除去する（ショーダウン価値のみ）。C値 100%=25、150%=30 を高頻度で使う
> - C値（ベット負担）はポットサイズではなくベット比率（%ポット）に依存する。C = α × 50 で計算
> - 本書 第9章 α 式は先手の設計ツール、後手スコアは後手の判断ツール。両者は表裏の関係にある
> - 次章（第11章）でリバー専用に調整した後手スコアを扱う

**【GTOとのズレ】**

後手スコアはGTOソルバーの出力を「式に圧縮した近似」です。実戦での精度は約90%（フロップ実測基準）ですが、残り10%には重要な例外パターンが含まれます。

最も大きなズレが生じるのは、**リバーのCR判断**です。後手スコアがCR域（≥40）に入っても、ハンドクラスが「コールされた場合に相手のバリューに負けてしまう」状況でCRを実行するのはGTO的に誤りです。GTOソルバーはCR候補ハンドを「コールされて相手に負けないハンド」に絞り込みます。後手スコアはその絞り込みを自動的には行いません。リバーでCR域のスコアが出たら「コールされたとき相手のバリューに勝てるか」という追加チェックが必要です。

また、**ペアターン後のディフェンス判断**でも実戦的なズレが生じます。ペアターンはIPのナッツアドバンテージが最大化されるため（第5章・第8章で確認したGTO実測、ペアターンの平均CBet=90.8%）、OOPの後手スコアが高く出ても「相手がナッツ（フルハウス・クワッズ）を持っていた場合のリスク」が高まります。後手スコアは平均的なレンジを前提にした計算なので、個別のハンドで「自分が相手のナッツに対してどれだけ弱いか」を意識した調整が必要です。

もうひとつの実戦的なズレは**MDFとの乖離**です。後手スコアを機械的に適用すると、特に33%の小サイズベットに対して守り不足になる場合があります。後手スコアが 15〜19 のハンドを一部コールに混ぜる「MDF調整」を意識的に行う必要があります。式の判断だけに頼ると、小サイズベットへの過剰フォールドという搾取されやすいパターンに陥ります。

また、**ターンとリバーでの式の同一性**が引き起こすズレもあります。後手スコアはフロップと同じ式をターン・リバーに適用しますが、ストリートが進むにつれてHandScoreの変動幅が大きくなります。「TPTK なら HandScore=70」という基準が、ターン・リバーではドローの完成/外れ、役の昇格・降格により同じハンドで局面によって 25 から 95 まで大きく変動します。この変動を正確に追えない場合、後手スコアが実態と乖離します。

ターン・リバーで後手スコアを使う際の実戦的なチェックリストを整理します。

```
後手スコア計算後の追加チェック:

□ C値は正しいか？（C = α × 50 で計算、ベット比率から決める）
□ A値はターンカード後の4枚全体で再評価したか？（ドライ12 / セミ6 / ウェット0）
□ リバーでHandScoreのドロー加点をゼロにしたか？（ドローは完成/外れで再評価）
□ 33%ベットに対してMDF（75%）を満たしているか？（MDF調整が必要か）
□ CR域（≥40）のハンドでCRを実行する場合、コールされて勝てるか？（リバー限定）
□ ペアターンでCRを選ぶ場合、相手のフルハウス・クワッズへの対応を考えたか？
```

この6点を習慣的にチェックすることで、後手スコアの計算ミスと適用ミスの大部分を防げます。GTOソルバーが自動的に行っている計算の精度には届きませんが、実戦での判断精度を大幅に高められます。
