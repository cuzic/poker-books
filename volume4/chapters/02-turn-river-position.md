# 第2章　ターンとリバーの位置づけ

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ポストフロップ最終2ストリートであるターンとリバーの構造的特性を整理し、共通点と決定的な違いを理解することで、本書全体の暗算式がどのストリートで何を解くのかを把握する。

---

## 2-1 ポストフロップ最終2ストリート

テキサスホールデムはプリフロップからリバーまで4つのストリートで構成されます。

```
プリフロップ → フロップ → ターン → リバー
（手札配布）　（ボード3枚）（ボード4枚目）（ボード5枚目）
```

フロップで方向性が決まり、ターンで情報が更新され、リバーで決着がつきます。実戦でのチップの損益の大部分はターンとリバーで生まれます。フロップのCBetは比較的安価なプローブですが、ターンのダブルバレルとリバーのファイナルベットは1ハンドあたりのチップ移動量が格段に大きくなります。

本書が扱うのはこの最終2ストリートです。第1章で紹介した4つの暗算式——バレルスコア、α 式、後手スコア（ターン版とリバー版）——がターンとリバーそれぞれの問いに答えます。

本章では「ターンとはどういうストリートか」「リバーとはどういうストリートか」をまず整理します。個別の暗算式は第6章以降で扱うため、本章では概念的な位置づけに絞ります。

---

## 2-2 ターンの位置づけ ─ 将来カードがある最後のストリート

ターンは4枚目のボードカードが落ちるストリートです。残りカードはリバーの1枚だけになります。

この「残り1枚」という事実が、ターンをポーカーの全ストリートの中で最も「重い」判断ストリートにしています。

フロップでは残り2枚のカードがあります。まだゲームは長く、現時点の判断の影響が分散されます。リバーでは残りカードがゼロです。判断は「現在のハンドで何をするか」に集中し、構造はシンプルになります。ターンはその中間であり、かつ特殊です。

```
ターン判断 = 現在のハンド価値 + リバーで起きることの予測
リバー判断 = 現在のハンド価値のみ
```

リバーを予測しながら現在の判断をしなければならない点が、ターンの難しさの中核です。

### SPRの低下とターンの重み

フロップからターンに移行するとき、ポットは大きくなり、スタックは消費されています。SPR（Stack-to-Pot Ratio：残スタックとポットの比率）はフロップ開始時より低下します。

6-max、100BB、BTN vs BB のシングルレイズポット（SRP）を例にとります。フロップCBetを1/3ポット（約2.3BB）で打ち、BBがコールした場合、ターン開始時のポットは約12BB、残スタックは約95BBになります。

```
フロップ開始時: SPR ≈ 97 ÷ 7 ≈ 14
ターン開始時:  SPR ≈ 95 ÷ 12 ≈ 8
```

SPRが14から8に低下しました。ハーフポットのベットを2回打てば、ポットはおよそ48BB程度になりスタックも大幅に減ります。実戦でポットコミット（降りられない）圏に入るまでの余裕が急速に縮まっています。

このSPRの変化が、ターンの判断に大きな重みをもたらします。フロップでは「次がターン、その次がリバー」と2ストリートの余裕がありました。ターンでは次のリバーが最後です。一手一手のコストが高くなり、間違いの代償も大きくなります。

### ターンカードがレンジを動かす

ターンに落ちるカードは双方のレンジを更新します。フロップで自分がセカンドペアだったハンドが、ターンカードによってトップペアに昇格する場合があります。相手のドローが完成する場合もあります。ナッツアドバンテージが入れ替わる場合もあります。

ターンカードが双方のレンジにどう影響するかを判断するための体系として、本書は5分類を用います（第6章で詳述）。ペアリング、オーバーカード、フラッシュカード、コネクター、ブランクの5種です。このカード分類がバレルスコアの係数にも反映されています。

ターンカードが変わるたびに判断の前提も変わります。これが「予測コストが最も高いストリート」としてのターンの構造です。

## 2-3 リバーの位置づけ ─ 確定ゲーム

リバーは5枚目のボードカードが落ちる最終ストリートです。これ以上カードは増えません。

この「もうカードが落ちない」という事実が、リバーを「確定ゲーム」にします。

### エクイティの二値化

フロップやターンでは、ハンドの価値は「現在の強さ」と「将来強くなる確率」の両方を含んでいます。巻② 第6章で学んだ Rule of 2 and 4（アウツ × 2 で1ストリート分の勝率を概算する手法）は、この「将来性」を計算する道具でした。フラッシュドローはターンで約19%、OESDは約17%の確率で改善します。この改善期待値がコールの根拠になります。

リバーではこの計算がまったく変わります。

リバーが落ちた瞬間、すべてのドローは「完成した」か「失敗した」かに確定します。フラッシュドローが完成したなら強いハンド、失敗したなら弱いハンドです。中間はありません。

```
ターン時点のエクイティ = 現在の勝率 + ドロー改善の期待値（流動的）
リバー時点のエクイティ = 現在の勝率のみ（確定的）
```

この変化を「エクイティの二値化」と呼びます。ハンドの価値が「勝てるか、勝てないか」にほぼ収束するのです。

### セミブラフが消滅する

ターンで重要な役割を果たすのがセミブラフです。セミブラフとは、現在は相手に負けているが、ドローが完成すれば勝てるハンドでのベットです。フォールドエクイティ（フォールドさせればすぐにポットを得る）とドローエクイティ（コールされてもリバーで勝てる）の両方を持ちます。

リバーではこの構造が崩れます。ドローが外れたプレイヤーがベットする場合、コールされれば必ず負けます。「コールされても将来的に勝てる」という成分がゼロです。

```
セミブラフ = フォールドエクイティ + ドローエクイティ
リバーでのドロー外れベット = フォールドエクイティ + 0（ドローエクイティなし）
```

後者は純粋なブラフです。セミブラフという概念はリバーに存在しません。すべてのベットは「コールされても勝てるバリューベット」か「コールされると負けるブラフ」かのどちらかに分類されます。

### 確定がもたらす精密さの要求

確定ゲームは判断をシンプルにするように見えます。しかし実際は逆です。「将来性があるからとりあえず続ける」という逃げ道がなくなり、「今このハンドで正しいアクションは何か」を正面から問われます。

ドローを持って打ったブラフがリバーで外れた場合、そのハンドで引き続き攻めるのか、チェックしてショーダウン価値を守るのかを決めなければなりません。ターンとリバーの連続した意思決定において、リバーが「最終答案」を要求するのです。

## 2-4 ターンとリバーの共通点

両ストリートには重要な共通点があります。

### フロップを受けた意思決定

ターンもリバーも、フロップでの行動を踏まえた意思決定です。フロップのアクション履歴——CBet・チェックバック・コール・チェックレイズ——が両ストリートの判断の起点になります。

巻② 第13・16章で学んだ後手スコアの骨格（`HandScore + A − C − M`、新スケール）はターンとリバーの両方で機能します。HU 前提（M=0）では A 係数と HandScore の組み合わせが防御判断を決めます。これは巻②から継承された概念です。

### レンジ強度の追跡

第1章で確認したCapped/Uncappedのレンジ強度は、ターンとリバーで引き続き追跡します。

フロップでCBetした側はUncapped（ナッツを含む可能性あり）、チェックバックした側はCapped（強いハンドが一部抜けている）というのが基本です。この性質はターンに持ち越されます。さらにターンのアクション履歴によって更新されたレンジ強度が、リバーに持ち越されます。

どちらのストリートでも「誰がナッツアドバンテージを持っているか」を追跡することが判断の前提です。

### HandScoreによるハンド評価

フロップで学んだ HandScore（新スケール 0〜100、equity % 相当の尺度で測るハンドの強さ指標）は、ターンとリバーの判断でも中核を担います。

ただし、ストリートが進むとHandScoreの構成が変わる点に注意が必要です。ドロー加点は「将来の改善期待値」を含みます。ターンではまだドロー加点が有効ですが、リバーではドローが完成か失敗かに確定するため、ドロー加点の意味が変わります。この変化については第9章（後手スコア・ターン版）と第11章（後手スコア・リバー版）で詳述します。

### ディフェンス判断の構造

相手のベットに対してコールするかフォールドするかを決める後手スコアの構造は、ターンとリバーで共通しています。

```
後手スコア = HandScore + A − C − M（HU 前提: M=0）

後手スコア ≥ 40 → チェックレイズ検討
後手スコア 20〜39 → コール
後手スコア < 20 → フォールド
```

巻②から継承したこの骨格は、ターン版とリバー版でそれぞれ係数の扱いが調整されます（ドロー加点の扱い方と、リバー特有のブロッカー補正）。構造が同じであることがターン・リバーの学習コストを大幅に下げます。

## 2-5 ターンとリバーの決定的な違い

共通点が多い両ストリートですが、将来カードの有無が決定的な違いを生みます。

| 項目 | ターン | リバー |
| :--- | :--- | :--- |
| 将来カード | あり（1枚残る） | なし（確定ゲーム） |
| ドロー成分 | エクイティとして機能する | 完成か失敗に確定し消滅 |
| セミブラフ | 有効（フォールドEV + ドローEV） | 存在しない |
| ベットの分類 | バリュー / セミブラフ / ブラフ | バリュー / ブラフ（二択のみ） |
| リバー予測 | 必要 | 不要（現在価値のみ） |
| SPRの変化 | フロップから低下、次でさらに低下 | 最終局面、変化なし |
| 暗算式 | バレルスコア（第7章） | α 式（第8章） |

### 将来カードがあることの意味（ターン）

ターンでのベット判断は、リバーで何が起きるかを予測した上で行います。バリューとして使えるハンドがリバーにも残るか、ブラフとして機能するハンドがα 式の比率を満たすか、相手のコールラインがリバーでどこになるか。これらをターンの時点で概算してからベットを打ちます。

この「1ストリート先を見越した判断」が、ターンを単純なフロップの延長ではなく、独立した戦略レイヤーにしています。

### 将来カードがないことの意味（リバー）

リバーでは予測が不要です。今のハンドと相手のレンジを比較し、バリューかブラフかを判断するだけです。

ただし、その判断が精密でなければなりません。セミブラフという緩衝材がないリバーでは、「弱いハンドで打ったベットがコールされた場合、ハンド価値ゼロで大きなポットを失う」という最悪ケースが常に潜んでいます。ブラフの本数をα 式で管理し、バリューとの比率を保つことが必要です。

また、ドローが完成または失敗することで、ターンまで見えなかった相手のハンドの正体が明らかになる場合があります。フラッシュカードがリバーに落ちたとき、相手のチェックコール→チェックレイズという行動パターンが「フラッシュ完成」を示唆するかもしれません。リバーではボードの変化が最終的なレンジ絞り込みを完了させます。

## 2-6 本書での扱い

本書（基礎編）では、ターンとリバーを独立したストリートとして順番に習得します。

第II部（第6〜10章）で暗算式を導入します。第6・7章でターンのバレルスコアを、第8章でリバーのα 式を、第9章で後手スコアのターン版とリバー版の違いを扱います。

第III部（第11〜15章）でターンの戦術を扱います。IPのダブルバレル判断、OOPの応戦、ベットサイズ選択、オーバーベットを順に取り上げます。

第IV部（第16〜21章）でリバーの戦術を扱います。IPのバリュー/ブラフ配分、OOPのディフェンス、チェックバック後のリバー判断、オーバーベット、ポットコミットメントを扱います。

### ストリートをまたぐ統合判断について

「ターンでのベットサイズをリバーのスタックから逆算して決める」「ターンでチェックしてリバーで攻める2ストリート計画を立てる」という統合判断の技術は存在します。これをbackward induction（後ろ向き帰納）と呼びます。

本書の基礎編では、各ストリートの判断を独立して精度を上げることを優先します。backward inductionの体系的な扱いは巻⑤（応用編）で行います。

ただし、ターンとリバーの関係を意識すること自体は本書でも欠かせません。第2章から第5章の概念編では、両ストリートの位置づけを整理します。戦術章で実例を扱う際も、ターン判断が次のリバーにどう影響するかを適宜参照します。

## ミニクイズ

### 問1

6-max、100BB、BTN vs BBのシングルレイズポットで、フロップCBetを1/3ポットで打ちBBがコールしました。フロップ開始時のSPRはおよそ14でした。ターン開始時のSPRとして最も近い値はどれですか。

1. SPR 約 14（変化なし）
2. SPR 約 8
3. SPR 約 4

---

### 問2

ターンでフラッシュドローを持つ相手がベットしてきました。相手がコールされても将来的に勝てるという成分（ドローエクイティ）を持ってベットしている場合、このベットを何と呼びますか。

1. バリューベット
2. セミブラフ
3. ブラフ

---

### 問3

リバーでのベット判断がターンより精密さを要求される理由として最も正確なものはどれですか。

1. リバーではポットが大きいため、リスクが高くなるから
2. セミブラフという選択肢がなくなり、すべてのベットがバリューかブラフに二分されるから
3. リバーではGTOがブラフを禁止しているから

---

### 解答

- **問1**: 2（ターン開始時のポットは約12BB、残スタックは約95BB。SPR = 95 ÷ 12 ≈ 8。フロップ開始時のSPR約14から大きく低下しています。この低下がターンの「重み」の根拠です）
- **問2**: 2（現在は相手に負けているが、ドローが完成すれば勝てる状態でのベットをセミブラフと呼びます。フォールドエクイティとドローエクイティの両方を持つため、セミブラフとして機能します）
- **問3**: 2（セミブラフが消滅するため、すべてのベットは「コールされても勝てるバリュー」か「コールされると負けるブラフ」かのどちらかになります。この二分がブラフの本数管理の精密さを要求します。α 式によるバリュー/ブラフ比率の管理がリバーで特に重要になる理由です）

---

> **本章まとめ**
>
> - ターンとリバーはポストフロップの最終2ストリートで、実戦のチップ移動の大部分がここで発生する
> - ターンの本質は「将来カード1枚が残った状態での判断」であり、リバーで何が起きるかを予測しながら動く
> - リバーの本質は「もうカードが落ちない確定ゲーム」であり、エクイティが二値化し、セミブラフが消滅する
> - 両ストリートの共通点は、フロップからのレンジ強度（Capped/Uncapped）の追跡とHandScore・後手スコアによる判断軸
> - 決定的な違いは「将来カードの有無」。ターンはリバー予測が必要だが、リバーは現在価値のみで判断する
> - 本書の基礎編は各ストリートを独立して習得し、統合判断（backward induction）は巻⑤応用編で扱う

**【GTOとのズレ】**

本章で「ターンはリバー予測が必要」と述べましたが、GTOソルバーはその予測を「可能なすべてのリバーカードに対する期待値の平均」として計算します。13ランク × 4スート = 最大52枚のうち、残りのカードそれぞれについてリバーのゲームツリーを解き、その期待値を平均したものがターンの最適行動の根拠です。人間が暗算でこれを再現することはできません。

本書の暗算式が採用する近似は「代表的なシナリオだけを想定する」方法です。ペアリング・オーバーカード・フラッシュカード・ブランクという5分類で、影響の大きなシナリオを代表させます。これでGTOとのズレが生じる場面は主に2つです。

1つ目は、同じカード分類でも特定のランクで影響が大きく変わる場合です。たとえばブランクカードでも、そのランクが相手レンジのAハイやKハイをトップペアに変えるかどうかで影響が変わります。代表値としての分類係数は平均的には機能しますが、ボード特有の例外は拾えません。

2つ目は、リバーでのポーラード化とブロッキングベットの判断です。「ポーラード化が強制される」というリバーの原則は正しいのですが、GTOは状況によって小サイズの混合ベット（ブロッキングベット）も用います。「リバーはバリューかブラフの二択」という本章の整理は大原則として機能しますが、その例外をGTOが採用している場面も実戦では現れます。これらの例外については第16〜19章の戦術編で補足します。
