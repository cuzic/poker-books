# 第16章　ターンでの状況別調整 — 相手タイプと SB vs BB

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->
<!-- textlint-disable -->

> **本章のゴール**: フロップで学んだ相手タイプ別エクスプロイット（巻③第13章）をターンに適用し、Fish・Station・Nit・LAGそれぞれに最適なバレル判断を身につける。あわせて SB vs BB 特有の OOP ターン戦略を習得する。

---

## 16-1 ターンでエクスプロイットを強める理由

ポーカーで「相手の偏りを利用する」という考え方は、フロップで学んだとおりです。しかしターンでは、フロップよりもエクスプロイットの量を大きくできます。理由は2つあります。

1つ目は**サンプル情報の蓄積**です。フロップのアクション（コール・フォールド・レイズ）を見ることで、相手のハンドの強度と傾向がひとつ絞られます。Fish がフロップをコールしてきた時点で「弱いハンドでもコールしている可能性が高い」という情報が追加されます。

2つ目は**ポットが大きくなること**です。ターン時点でポットはフロップより膨らんでいます。相手の偏りを正確に利用できれば、1ストリートあたりの利益が大きくなります。逆に誤った判断をすればフロップ以上に損失が拡大します。

巻③第13章で確立した「タイプ識別スコア」の考え方を、まず確認しておきます。

```
タイプ識別の目安（VPIP / PFR / Fold to CBet%）:

Fish:    VPIP>40%, PFR<15%, フォールド率<40%  → 広くコール、ブラフほぼなし
Station: VPIP>35%, PFR<10%, フォールド率<35%  → 何でもコール、わずかにブラフ
Nit:     VPIP<20%, PFR<15%, フォールド率>65%  → タイト参加、ベット=強い
LAG:     VPIP>30%, PFR>25%, フォールド率<50%  → 広く攻撃、ブラフ多い
```

フロップでの調整量の目安も引き継ぎます。実績ハンド数が100以上あれば±10の調整、50〜100ならば±5の調整、50未満ならば GTO ベースを維持するという原則は、ターンでも同じです。

本章ではフロップの調整を「ターンに移植」しつつ、ターン特有の事情（ドローの成否・ポットサイズ・残りストリート数）を加味していきます。

## 16-2 vs Fish / Station — バリュー最大化

Fish と Station の共通点は「フォールドしないこと」です。フロップでコールしてきた Fish が、ターンでも引き続き弱いハンドを持ち続けてコールしてくることが多い傾向があります。この環境では、ブラフの期待値が著しく低下します。

### ターン barrel 閾値の引き上げ

ブラフの損益分岐点となる折り畳みエクイティ（フォールドエクイティの最低ライン）は、33% ベットの場合で約 25% です。Fish のフォールド率が 20% を下回っている場合、ブラフベットは期待値がマイナスになります。

```
標準 barrel 閾値（HU、blank/OC ターン）: HandScore ≥ 20

vs Fish / Station へのターン barrel 閾値調整:

  barrel 閾値: +10 → HandScore ≥ 30（バリューのみ barrel）
  T3 ブラフ barrel: 全面禁止（Fish はコールしてくるためブラフは −EV）
  barrel サイズ: 75%ポット以上（コールしてくれるので大きく打つ）
```

HandScore ≥ 30 という水準はおおよそ「セカンドペア以上」に相当します。ターンでトップペア・良キッカー（TPTK）やセット、2ペアを持っていれば積極的にバリューを取りに行く局面です。

### サイズ引き上げの理由

Fish は「ポットオッズを計算しない」傾向があります。33% ベットでも 75% ベットでも同じようにコールしてくる場合、大きなサイズを選ぶほど期待値が上がります。フロップで 33% を使っていたならば、ターンでは 75% へ引き上げることを検討してください。

### 実例: AKs on Kc,7d,2s,9h（vs Fish）

ボード: K♣, 7♦, 2♠, 9♥（ターン後）

ハンド確認:

- カード: A♠, K♠ + K♣, 7♦, 2♠, 9♥ → A×1, K×2, 9, 7, 2
- 役: ワンペア K's（Aキッカー）、best 5 = A-K-K-9-7

HandScore の評価: TPTK（Aキッカー付きトップペア） = 約 55〜65 程度。Fish 相手の閾値 ≥ 30 をクリアしています。75% ポットのバリューベットが推奨です。

### 実例: 65s on Kc,7d,2s,9h（vs Fish）

ハンド確認:

- カード: 6♠, 5♠ + K♣, 7♦, 2♠, 9♥ → K, 9, 7, 6, 5, 2
- 役: ハイカード（ペアなし）
- ストレート確認: 5-6-7-8-9 → 8 が欠けているため未完成（OESD: 4-8 で補う 8 outs）
- HandScore: ドロー加点はあるものの、ペアなし = 約 15〜20 程度

Fish 相手の閾値 ≥ 30 を**下回ります**。この T3 相当のハンドは barrel 禁止です。チェックバックしてリバーでドローの完成を確認してください。

### Fish が CR / レイズしてきた場合

Fish は「コールが多いがレイズは稀」です。Fish がターンでレイズや CR を仕掛けてきた場合は、強いバリューハンドを持っている可能性が通常より高まります。この局面ではコールまたはフォールドに切り替え、再レイズは慎重に検討してください。

## 16-3 vs Nit — ブラフ最大化

Nit の弱点は「フォールドしすぎること」です。フォールド率が 65% を超えている場合、33% ベットに対してブラフの期待値はプラスになります（必要フォールドエクイティ 25% を大きく上回るため）。

### ターン barrel 閾値の引き下げ

```
vs Nit へのターン barrel 閾値調整:

  barrel 閾値: −5 → HandScore ≥ 15（T2 下位も barrel 対象）
  T3 ブラフ barrel: blank/OC ターンなら検討可能
  barrel サイズ: 33%（小サイズで Nit を誘い込む）
```

HandScore ≥ 15 という水準は「セカンドペア・弱いミドルペア」も含みます。フロップでは打てなかった薄いバリューや弱いドローも、Nit 相手ならターンで barrel の候補になります。

### サイズを小さく保つ理由

Nit に対して大きなサイズを選ぶと、フォールドされる確率は上がりますが「フォールドされれば勝ち」であるため期待値は得られます。しかし 33% のような小サイズには「Nit が薄いコールをしてくれる可能性が生まれる」という追加の利点があります。小サイズで打ち続けることで、Nit のコールレンジが広がり、後のストリートでもバリューを取れる局面が増えます。

また、Nit に 33% で barrel した場合でも、フォールド率が 65% であれば十分に期待値はプラスです。

### Nit が CR / レイズしてきた場合

Nit は「コールが多く、CR はナッツ相当のみ」という傾向があります。Nit がターンで CR や再レイズをしてきた場合は、本物の強ハンドと判断して即フォールドが原則です。Nit の弱点を利用するエクスプロイットは「Nit がパッシブな局面」でのみ機能します。

## 16-4 vs LAG — バランスとブラフキャッチ

LAG（ルースアグレッシブ）は「ブラフが多い」のが特徴です。LAG が相手の場合、自分がベットする場面より「相手のベットをどう捌くか」という防御局面の質が重要になります。

### 自分の barrel 調整（LAG に対して）

LAG は 3-bet やチェックレイズ（CR）を多用します。こちらが barrel を打ったとき、LAG に強い反撃をされるリスクがあります。

```
vs LAG へのターン barrel 閾値調整:

  barrel 閾値: 通常（HandScore ≥ 20）か少し絞る（+5 → HandScore ≥ 25）
  T3 ブラフ barrel: 削減（LAG の 3-bet を受けると逃げ場がなくなる）
  barrel サイズ: 標準の 33%（LAG の CR リスクを抑えるため大サイズは避ける）
```

T3 のブラフを削減する理由は「LAG がブラフで返してくる可能性」です。LAG に 3-bet されたとき、こちらのブラフは続行できません。ブラフ barrel の期待値が、LAG の反撃リスクで相殺されてしまうためです。

### OOP での fold threshold 引き下げ（LAG に対して）

LAG が barrel してきた場合は、広くコールする方向に調整します。

```
OOP fold threshold 調整（vs LAG）:

  通常の fold threshold を −10 引き下げ
  例: vs 33% ベットの通常閾値 HandScore < 20 → HandScore < 10 でもコール検討
  例: vs 75% ベットの通常閾値 HandScore < 35 → HandScore < 25 でもコール検討
```

LAG のベットには弱いハンドが多く含まれています。「折り畳みすぎること」が最大の損失源です。HandScore が 10〜20 程度の「ブラフキャッチャー」ゾーンのハンドも、LAG 相手なら積極的にコールの候補に入れてください。

### OOP での CR チャンス（vs LAG）

LAG が barrel してきた場面で、自分が HandScore ≥ 75 程度（T1 強ハンド + ドロー加点込み）を持っている場合は CR が高期待値です。LAG の barrel レンジには弱いハンドが多く、強ハンドで CR すると相手のブラフ部分はフォールドせざるを得ません。

## 16-5 相手タイプ別まとめ表

3タイプの調整をまとめます。

| タイプ | ターン barrel 閾値 | barrel サイズ | OOP fold threshold | 備考 |
|---|---|---|---|---|
| Fish / Station | +10 → HandScore ≥ 30 | 75%ポット以上 | +10（さらに守る） | T3 ブラフ禁止 |
| Nit | −5 → HandScore ≥ 15 | 33%（小サイズ） | +5（Nit のベット=強い） | CR/レイズは即フォールド |
| LAG | 通常〜+5（25まで） | 33%（標準） | −10（広くコール） | CR は HandScore ≥ 75 で積極 |

この表は巻③第13章のフロップ版を「ターン用に微調整」したものです。フロップよりもエクスプロイット量をやや大きくできますが、基本的な方向性は変わりません。サンプルが少ない（50ハンド未満）相手には GTO ベースを維持してください。

## 16-6 SB vs BB — OOP ターン戦略の特殊性

SB（スモールブラインド）と BB（ビッグブラインド）の対戦は、6-max キャッシュの中でも特殊なパターンです。SB は OOP のまま全ストリートを戦います。BTN vs BB と比較すると、SB は位置的不利が解消されません。

### HU 平均との比較

```
ターン barrel 頻度の比較:

HU 平均（BTN vs BB など IP が SB 側ではない場合）: 約 85%
SB vs BB ターン barrel（SB が IP を持たない OOP 側）: 約 50%

差: 約 35pt の大幅低下
```

この 35pt の差は「OOP の不利」そのものです。SB は自分からアクションしなければならないため、BBが「情報を見てから動ける」という優位を常に持っています。

### ボード別の SB ターン barrel 頻度

ボードのタイプによって、SB が barrel できる頻度は大きく変わります。

```
ボード別 SB ターン barrel 頻度の目安:

A/K-high ドライボード（blank ターン）: 約 65%
  → SB のレンジ優位が継続。A や K は SB の 3-bet レンジに多い

low/connected board（blank ターン）: 約 40%
  → BB のレンジが当たりやすいボード。SB は barrel を控える

SC（スーテッドコネクター）/FC（フラッシュコンプリート）ターン: 約 25%
  → OOP × ドロー完成は SB に特に不利。最も barrel を控える局面

PB（ペアボード）ターン: 約 55%
  → IP（BB）のナッツアドバンテージが生じる分、やや上昇
```

### turn_tag 別の SB barrel 閾値調整

ターンカードのタイプ（turn_tag）に応じて、SB の barrel 閾値を調整します。

```
turn_tag 別 SB barrel 閾値（SB vs BB 専用）:

blank/OC high board: HandScore ≥ 25（標準 ≥20 に OOP 補正 +5）
blank/OC low board:  HandScore ≥ 30（BB のレンジ優位を考慮してさらに絞る）
SC / FC ターン:      HandScore ≥ 70（T1 強ハンドのみ。ドロー完成局面は危険）
PB ターン:           HandScore ≥ 25（IP のナッツアドバンテージを考慮しつつ標準水準）
```

### 実例: KQo on Kc,7d,2s,5d（SB vs BB、blank ターン）

ボード: K♣, 7♦, 2♠, 5♦（ターン後）

ハンド確認:

- カード: K♥, Q♥ + K♣, 7♦, 2♠, 5♦ → K×2, Q, 7, 5, 2
- 役: ワンペア K's（Qキッカー）、best 5 = K-K-Q-7-5
- フラッシュ確認: ♦が K♣, 7♦, 2♠, 5♦ → 実際には K♣（クラブ）, 7♦, 2♠, 5♦。♦は7♦と5♦の2枚。♥は K♥と Q♥の2枚。フラッシュ不成立。
- ターンカード 5♦: K♣7♦2♠ のフロップに 5♦ が落ちた。フロップの最高ランクは K。5 は K より低くオーバーカードではない → blank / OC low board 扱い

turn_tag = blank / OC high か low か: K-high ボードですが 5 は low カード。SB vs BB の「blank/OC high board」（A/K-high）に該当します。閾値は HandScore ≥ 25。

KQo の HandScore はトップペア・Qキッカーで約 50〜55 程度。HandScore ≥ 25 を十分クリアしているため、SB はこのハンドで barrel 可能です。ただし OOP のため、サイズは 33〜50% 程度に抑えて BBの CR リスクを管理します。

## 16-7 SB チェック後に BB がベットした場合

SB vs BB の局面で、SB がチェックした後に BB がベットしてきた場合（遅延アグレッション）は、特別な fold threshold 調整が必要です。

BB がターンでベットを選んだということは「BBがチェックのチャンスを使わずに先手を取る理由がある」を意味します。BB の delayed bet にはバリュー傾向が強いことが多く、SB はここでの薄いコールを控える必要があります。

```
SB チェック → BB ベット時の SB fold threshold 調整:

vs BB 33% ベット: fold threshold = 20 − 5 = 15
  通常の OOP fold threshold（vs 33%: HandScore ≥ 20 でコール）から −5 引き下げ
  → HandScore ≥ 15 以上のハンドもコール対象に含める

vs BB 75% ベット: fold threshold = 40 − 5 = 35
  通常の OOP fold threshold（vs 75%: HandScore ≥ 40 でコール）から −5 引き下げ
  → HandScore ≥ 35 以上のハンドもコール対象に含める
```

「通常より広く守る」方向の調整です。「−5 引き下げ」の意味は「より低い HandScore でもコール可能になる」ことを指します。BB の delayed bet は SB のチェックを「弱み」として攻撃しているため、SB が薄いコールをするとパターン化されて搾取されます。

### SB チェック → BB チェックの場合

SB がチェックし、BB もチェックバックした場合はリバーへ移行します。SB は引き続き OOP のままリバーで先に行動しなければなりません。SB の OOP 不利はターンでは解消されず、リバーまで持ち越されます。

## ミニクイズ

### 問1

BTN vs BB のターン。ボードは K♣7♦2♠4♥（blank ターン）。BTN（IP）のハンドは A♣2♣。相手は明らかな Fish（フォールド率 20%以下）。BTN の推奨アクションは次のどれですか。

1. Fish はコールしてくれるので A♣2♣でブラフ barrel。75% ポット
2. A♣2♣の HandScore は低く（ペアは 2 のボトムペア程度）、Fish 相手の閾値 ≥ 30 を下回る可能性が高い。チェックバック
3. A♣2♣はバックドアフラッシュドローがあるため、積極的に barrel。33% ポット

### 問2

SB vs BB のターン。ボードは 9♣8♦7♥6♠（connected ターン）。SB はフロップで CBet し BB がコール。ターンで SB がチェックすると、BB が 75% ポットをベットしてきた。SB のハンド A♦K♦。SB の推奨アクションは次のどれですか。

1. A♦K♦はオーバーカード2枚でショーダウン価値が高い。BB のベットにコール
2. BB の delayed 75% ベットは fold threshold = 35 が基準。A♦K♦の HandScore（オーバーカード2枚のみ）は ≤ 20 程度でフォールド
3. A♦K♦はナッツへのストレートドローがある。チェックレイズ

### 問3

BTN vs BB のターン。ボードは K♠T♦5♣3♥（blank ターン）。相手は明確な Nit（フォールド率 70%以上）。BTN（IP）のハンドは Q♣J♣。BTN の推奨アクションは次のどれですか。

1. Q♣J♣はペアもなく HandScore が低い。Nit 相手でも閾値 ≥ 15 を下回る → チェックバック
2. Nit はフォールドするので Q♣J♣でブラフ barrel。33% ポットで小さく打つ
3. Nit 相手だから大きく打つ。75% ポットのブラフ barrel

---

### 解答

- **問1**: 2（A♣2♣の役確認: A♣, 2♣ + K♣, 7♦, 2♠, 4♥ → ランク A, K, 7, 4, 2×2。best 5 = A-K-7-4-2-2 → ワンペア 2's。ボトムペアは HandScore が低く、Fish 相手の barrel 閾値 HandScore ≥ 30 を下回ります。Fish はコールしてくるため、ボトムペアでのブラフ barrel は −EV です。チェックバックが正解。選択肢1はブラフが Fish 相手に機能しないことを無視しています。選択肢3はバックドアフラッシュドローの加点があっても閾値を満たせません）

- **問2**: 2（ボード 9♣8♦7♥6♠ はコネクテッドかつ 4 連続ボードです。A♦K♦の役確認: A♦, K♦ + 9♣, 8♦, 7♥, 6♠ → ランク A, K, 9, 8, 7, 6。best 5 のストレート確認: A-K-Q-J-T 不成立（Q-J-T 欠け）。K-high: K-Q-J-T-9 → Q, J, T が欠けている。9-8-7-6-5 → 5 が欠けている。A♦K♦は役なし（Aハイ）。HandScore は約 10〜15 程度。BB の delayed 75% ベット時の fold threshold = 40 − 5 = 35。HandScore ≤ 20 はこれを大きく下回るためフォールドが正解。選択肢3は 9♣8♦7♥6♠ にストレートドローを期待していますが、A♦K♦は 9-8-7-6 の連続には絡まないため不正確です）

- **問3**: 2（Q♣J♣の役確認: Q♣, J♣ + K♠, T♦, 5♣, 3♥ → ランク K, Q, J, T, 5, 3。best 5 のストレート確認: K-Q-J-T-9 → 9 が欠けている → 未完成（Q♣J♣は OESD: A か 9 で完成ではなく、9 一枚で K-Q-J-T-9 が完成 = ガットショット扱い）。ペアなし = HandScore はドロー加点込みでも 15〜20 程度。Nit 相手の barrel 閾値は HandScore ≥ 15 ですので、ちょうど境界です。Nit のフォールド率 70% は 33% ベットの必要フォールドエクイティ 25% を大きく上回るため、33% ポットのブラフ barrel は期待値プラスになります。サイズを 75% に引き上げる選択肢3は誤りです。Nit に大サイズを打つとフォールドは増えますが「誘い込む効果」が失われ、Nit がコールする薄い局面を逃します）

---

> **本章まとめ**
>
> - Fish / Station 相手では ターン barrel 閾値を +10 引き上げ（HandScore ≥ 30）、ブラフは全面禁止、サイズは 75% 以上でバリューを最大化する
> - Nit 相手では barrel 閾値を −5 引き下げ（HandScore ≥ 15）、33% の小サイズでブラフを増やして誘い込む。Nit の CR/レイズは即フォールド
> - LAG 相手では通常〜+5 の barrel 閾値を維持しつつ T3 ブラフを削減し、OOP での fold threshold を −10 引き下げて広くコール・積極 CR を狙う
> - SB vs BB のターン barrel 頻度は HU 平均 85% より約 35pt 低い約 50%。OOP 不利がターン以降も継続する
> - SB のボード別 barrel 閾値: A/K-high blank → HandScore ≥ 25、low/connected → ≥ 30、SC/FC ターン → ≥ 70、PB ターン → ≥ 25
> - SB チェック → BB 75% ベットの fold threshold = 35（通常 40 から −5 の守り補正）

**【GTO とのズレ】**

本章で扱った相手タイプ別エクスプロイットは、GTO から意図的に乖離させる戦略です。GTO は相手が均衡戦略を取ることを前提としているため、Fish や Nit のような偏りがある相手に対してそのまま適用すると EV を取り逃します。しかし、エクスプロイットには注意すべきリスクが2つあります。

1つ目は「タイプ判断の誤り」です。50 ハンド未満しか観察していない相手に対して Fish 判定を下すと、たまたまタイトなセッションだった Reg を Fish と誤認することがあります。サンプルが少ないうちは GTO ベースを維持し、調整は実績に基づいて段階的に行ってください。

2つ目は「エクスプロイットが読まれる」リスクです。これは主に上級者 LAG に対して当てはまります。「LAG のベットには広くコールする」と決め打ちすると、LAG が実際にバリューを持っている局面でも薄くコールしすぎることがあります。LAG への fold threshold 引き下げはあくまで「LAG のブラフに対する期待値向上」が目的です。具体的なハンドの HandScore で最終判断してください。

SB vs BB については、GTO の実際のソルバーでは SB の barrel 頻度がボードによって大きく変動します。本章で示した「約 50%」「約 65%」などの数値は傾向の目安であり、特定のボードでは大きく異なることがあります。とくに A/K-high でも非常にコネクテッドなボード（A-K-Q など）では SB の barrel 頻度が目安より低くなる傾向があります。「high board = barrel 積極的」という原則は参考にしつつも、実際のボード構造に応じた判断を心がけてください。
