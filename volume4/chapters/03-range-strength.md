# 第3章　レンジ強度（Capped vs Uncapped）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 「Capped レンジ」と「Uncapped レンジ」がなぜ生まれるかを理解し、ターンとリバーの両ストリートで「誰が大きく打てるか」を判断するための概念的な土台を築く。

---

## 3-1 レンジ強度という概念

巻①で学んだ「レンジ」の概念を出発点にします。レンジとは、あるプレイヤーがある場面でとりうるハンドの集合です。ポーカーの思考の中心は、相手の 1 枚のハンドを当てることではなく、相手のレンジ全体の形を把握することです。

レンジには 2 つの独立した軸があります。

**軸1: 幅（ワイドかタイトか）**

BTN のオープンレンジは 6-max で概ね 40〜50% 程度のワイドなレンジです。UTG は約 14〜17% 程度のタイトなレンジです。幅とはレンジが何%のハンドを含むかという「量」の話です。

**軸2: ナッツの含有量（Uncapped か Capped か）**

幅とはまったく独立して、「そのレンジが最強ハンド（ナッツ）を含んでいるかどうか」という「質」の軸があります。この軸をレンジ強度と呼びます。

- **Uncapped（アンキャップド）レンジ**: ナッツを含む可能性があるレンジ。どんな強いハンドも保有しうる状態
- **Capped（キャップド）レンジ**: ナッツが含まれない、または非常に少ないレンジ。一定以上の強さのハンドがほぼ排除された状態

「ワイドだが Capped」という状況が実戦で頻出します。この非対称性がターン・リバーでの攻撃力の非対称性を生み出しています。

---

## 3-2 アクション履歴がレンジ強度を決める

Uncapped か Capped かはアクション履歴によって決まります。プレイヤーが選ぶアクションはハンドの強さに応じて分岐します。その分岐の結果として、各アクションを選んだレンジのナッツ含有量が変化します。

**Uncapped レンジが生まれる主な場面**

- BTN がプリフロップでオープンライズ: AA・KK・AK を含む Uncapped
- IP がフロップで CBet: ナッツもブラフも混在する GTO 設計のため Uncapped
- OOP がフロップの CBet に対してチェックレイズ（CR）: ナッツを含む積極的なアクション

**Capped レンジが生まれる主な場面**

- OOP がフロップ CBet にコール: セット・強いストレートは CR 方向に振り向けられ、コールレンジのナッツが薄くなる。AA・KK もプリフロップ 3-bet 済みでほぼ不在
- IP がフロップをチェックバック: AA・KK・セット等のナッツがあれば多くの場合 CBet を選ぶため、チェックバックはナッツが少ないことを示すシグナル
- 複数ストリートをコールし続けたプレイヤー: コールを選ぶたびに「レイズするほどではない」という情報を蓄積し、ナッツが薄くなっていく

---

## 3-3 ターンでのレンジ強度の更新

フロップのアクション履歴がターン開始時のレンジ強度の初期値を決めます。そこにターンカードの影響が加わり、レンジ強度が更新されます。

### フロップ後の典型的な状態

BTN vs BB の SRP（シングルレイズポット）でフロップ CBet → BB コールという履歴があれば、ターン開始時はおよそ次の状態です。

```
BTN: Uncapped（AA・KK・セット等を含む CBet レンジ）
BB:  Capped（プリフロップ 3-bet 済みの AA・KK 不在、フロップ CR に強いハンドを使った残り）
```

### ターンカードがハンドを進化させる

ターンに 1 枚のカードが落ちることで、各ハンドの役が変化します。この変化を正確に把握することがレンジ強度の追跡に不可欠です。

ドライボード K♠7♦2♣ の後にターン 7♥ が落ちた場合（ボード K♠7♦2♣7♥）、各ハンドは次のように更新されます。

| ハンド | フロップ時の役 | ターン後の役 |
|---|---|---|
| KK | セット（K が 3 枚） | フルハウス（K's full of 7's） |
| 77 | セット（7 が 3 枚） | クワッズ（7 が 4 枚） |
| K7 | 2ペア | フルハウス（7's full of K's） |
| AK | TPTK（K のペア） | 2ペア（K と ボードの 7-7） |

このペアターンで BTN のナッツ（KK のフルハウス、77 のクワッズ）は BB のコールレンジより BTN に多く残っています。BTN の Uncapped 優位はターン後も維持されます。

ターンカードが落ちるたびに「自分と相手のハンドがどう変化したか」を追跡することが、レンジ強度の更新の精度を決めます。「KK はフルハウスに昇格した」「AK は 2ペアになった」という変化の見落としが判断のズレを生みます。

### 両者チェックで両者 Capped が生まれる

フロップで BTN がチェックバック、BB もチェックした場合は特殊な状況になります。BTN がチェックバックした時点で BTN は Capped 寄りになり、BB が先手ベットをしなかった場合も強いハンドを即座に積極化しなかったという情報が刻まれます。結果として両者ともに Capped 寄りのレンジになります。

この状況ではターンカードが「どちらのレンジをより強化するか」が重要な争点になります。具体的な判断は第12章で扱います。

## 3-4 リバーでのレンジ強度の到達点

リバーに到達するまでに、プリフロップからターンまで 3 ストリートの情報が蓄積されています。この蓄積がリバー開始時のレンジ強度を決めます。

### 「3ストリート全コール」のレンジ分析

リバーで重要なシナリオが「相手が 3 ストリート全コール」の状況です。BB が BTN の CBet（フロップ）とバレル（ターン）に 2 回コールしてリバーに到達した場合、BB のレンジは次のように絞られています。

```
プリフロップコール:    AA・KK はほぼ 3-bet 済みで排除
フロップ CBet コール:  セット・強いストレートは CR 方向に振り向けられる
ターンバレルコール:    ターン CR を使わなかった。ナッツ系は薄い
リバー到達時点:       ナッツが非常に少ない Capped レンジ
                    TPTK・2ペア・コンプリートしたドローが主体
```

この Capped レンジに対して BTN は大きくベットする権利を持ちます。BTN は各ストリートで CBet・バレルを続けることで Uncapped を維持しており、この非対称性が BTN のリバー攻撃力の根拠です。

ただし「3 ストリート全コール = 完全に弱い」ではありません。ドローが完成した場合（フラッシュやストレートが完成）、コールし続けていた相手がリバーでナッツ級ハンドを持つことがあります。「ナッツが薄いが、完成したドローには注意が必要」と読むのが正確です。

### ナッツアドバンテージとブラフのバランス

リバーでナッツアドバンテージを持つ側が大きくベットできる理由は 2 つあります。

1 つ目は相手へのプレッシャーです。ナッツを多く含む側が大きくベットしてきたとき、Capped なレンジの相手はナッツで対抗する手段が乏しいです。「これはナッツかもしれない」という不確実性を抱えながらコールしなければなりません。

2 つ目はバリューとブラフのバランスです。ブラフを適切に混ぜるためにはバリューハンドが必要です。ナッツアドバンテージを持つ側はバリューが豊富なため、ブラフを適切な比率で混ぜたポーラード化（二極化）されたレンジを設計できます。Capped な側はバリューが足りないため、大きなサイズでのベットが設計しにくくなります。

```
ナッツアドバンテージ高（Uncapped）:
  バリュー豊富 → ブラフも適切に混ぜられる → 大きなベットが成立

ナッツアドバンテージ低（Capped）:
  バリュー不足 → 大きなベットはアンバランス → 中〜小サイズが適切
```

この構造がリバーの α 式（第9章）とブロッカー論（第7章）の前提になります。

## 3-5 「誰が大きく打てるか」の判断フロー

Capped/Uncapped とナッツアドバンテージの組み合わせで、ターン・リバーで「誰が大きく打てるか」が決まります。

| 状態の組み合わせ | 実戦的な意味 |
|---|---|
| 自分 Uncapped・相手 Capped | 大きくベットする権利がある |
| 自分 Capped・相手 Uncapped | 大きくベットしにくい。コールか中サイズが中心 |
| 両者 Capped | 中サイズ。大きなポーラード化は難しい |
| 両者 Uncapped | ナッツアドバンテージが高い側が大きく打てる |

実戦での確認フロー:

1. **自分のレンジを評価する**: CBet・レイズ・CR を積極的に打ってきた → Uncapped 寄り。コール一辺倒、チェックバックが多い → Capped 寄り
2. **相手のレンジを評価する**: 相手が複数ストリートをコールし続けた → Capped 寄り。相手が CR・レイズ等を取った → Uncapped
3. **ナッツアドバンテージを確認する**: このボードでのナッツ（セット・フルハウス・フラッシュ・ストレート等）をどちらのレンジが多く含むか
4. **アクションの方向性を決める**: 上の表に照らし合わせる

具体的な数値判断はバレルスコア（第8章）・α 式（第9章）・後手スコア（第10・11章）が行います。本章の役割は「なぜこの構造が生まれるか」という概念の把握です。

## ミニクイズ

### 問1

BTN がプリフロップオープン、BB がコール。フロップ A♥9♦2♣ で BTN が CBet を打ち、BB がコールしました。ターン開始時のレンジ強度について、正しい説明はどれですか。

1. 両者ともに Uncapped（フロップ CBet とコールでレンジ強度は変化しない）
2. BTN: Uncapped、BB: Capped（BB は AA を 3-bet 済みでほぼ持たず、セット等は CR に使った残りのレンジ）
3. BTN: Capped、BB: Uncapped（BB がコールで強いハンドを温存しているため）
4. 両者ともに Capped（フロップ後はどちらもナッツが排除される）

### 問2

リバーまで「3 ストリート全コール」をしてきた BB のレンジについて、最も正確な説明はどれですか。

1. 強いハンドを温存していたため、リバーでナッツを持っている可能性が高い
2. ナッツが非常に薄い Capped レンジ。ただし完成したドロー（フラッシュ・ストレート）には注意が必要
3. コールを繰り返したことはレンジ強度に影響しない
4. コール一辺倒なのでブラフは一切含まれない

### 問3

BTN vs BB の SRP、フロップ K♠7♦2♣ で BTN が CBet を打ち、BB がコール。ターンに 7♥ が落ちました（ボード K♠7♦2♣7♥）。BTN が保有する KK のターン後の役として正しいものはどれですか。

1. セット（KK はボードに変化がないためセットのまま）
2. フルハウス（ボードの 7 が 2 枚になることで K が 3 枚・7 が 2 枚のフルハウスに昇格）
3. クワッズ（KK でクワッズになる）
4. 2ペア（ターンカードにより降格する）

---

### 解答

- **問1**: 2（BTN の CBet レンジには AA・セット等のナッツが含まれるため Uncapped。BB は AA を 3-bet 済みでほぼ保有せず、フロップ CR に強いハンドを使った残りのため、コールレンジはナッツが薄く Capped）
- **問2**: 2（各ストリートでコールを選んだことは「そのストリートでレイズするほどではない」という情報を蓄積し、Capped 化を進める。ただし「コール継続が合理的だったドロー系ハンドが完成した」ケースは別扱いが必要）
- **問3**: 2（KK はボード K♠7♦2♣7♥ に対して、K×3枚 + 7×2枚 = フルハウス（K's full of 7's）に昇格する。セットのままではない。77 はクワッズ、K7 はフルハウス（7's full of K's）に昇格する点も合わせて確認しておくとよい）

---

> **本章まとめ**
>
> - レンジには「幅（ワイド/タイト）」と「ナッツの含有量（Uncapped/Capped）」の 2 つの独立した軸がある
> - Uncapped レンジはナッツを含む可能性があるレンジ（CBet した IP、CR した OOP など）
> - Capped レンジはナッツが少ないレンジ（CBet にコールした OOP、チェックバックした IP など）
> - 「ワイドだが Capped」は実戦で頻出する。BB のフロップコールレンジがその典型
> - ターンカードは各ハンドの役を更新し、ナッツアドバンテージの配分を変える。ハンドエボリューションの正確な追跡が必要
> - リバーまでのアクション蓄積（特に「3 ストリート全コール」）は Capped 化を進める。ただし完成ドローには注意
> - 「誰が大きく打てるか」は Uncapped/Capped の組み合わせとナッツアドバンテージで決まる

---

**【GTOとのズレ】**

GTO ソルバーは Capped/Uncapped を厳密に計算して戦略を設計します。実戦でのズレは主に 3 つのパターンで生じます。

1つ目は「自分が Capped なのに大きく打ってしまう」パターンです。フロップをチェックバックした後のターンや、複数ストリートをコールし続けた後のリバーから大きくベットすると、GTO 的には「そのレンジからの大きなベットはほぼない」とみなされます。Capped 状態からの大きなベットは相手にコールを誘うだけになりやすく、中〜小サイズが推奨されます。

2つ目は「相手が Capped なのに攻め切れない」パターンです。相手が 3 ストリート全コールしており、自分がナッツ級ハンドを持っているにもかかわらず、「もしかしたら強いかも」と萎縮して小さくベットしたり、チェックしたりするケースです。ナッツアドバンテージを持ちながらバリューを取り逃がします。

3つ目は「ターンカードによるハンドエボリューションの見落とし」です。K♠7♦2♣ フロップ後に 7♥ が落ちたとき、KK が「フルハウスに昇格した」という変化を見落とし「セットのまま」と扱ってしまうと、強さを過小評価することになります。ターンカードが落ちたら自分と相手のハンドがどう変化したかを確認する習慣が、この誤差を減らします。
