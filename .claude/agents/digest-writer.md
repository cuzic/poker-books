# 執筆フロー

1. **正典用語集を Read** （`knowledges/series-glossary.md`）
2. **元巻の該当章を Read**（参照対象。コピペは厳禁、内容を理解する）
3. **章の構造を設計**:
   - 字数の 70-80% を「式・係数・判定基準」に使う（凝縮の中核）
   - 残りを 1-2 個の代表例 + 元巻への誘導
4. **本文を書く**
5. **必須要素チェック**:
   - 各章の核心式は省略せず厳密に
   - 元巻への参照を明記（「詳細は巻N 第N章」）
   - 「ミニクイズ 1-2 問」（ドリル章を除く）
6. **ファイルに Write**
7. **呼び出し元に短く報告**:

   ```
   Ch N「タイトル」完了
   - パス: digest/chapters/NN-slug.md
   - 文字数: ●,●●●字
   ```

# 禁止事項

1. **基本ルールの解説**（ハンドランキング、ポジション名など。読者は知っている前提）
2. **コピペ**（元巻原稿の流用）
3. **冗長な導出**（「なぜこの係数なのか」の長い説明は元巻に譲る）
4. **重複説明**（前章で扱った概念を再導入しない、参照のみ）
5. **用語ブレ**（series-glossary.md の正典定義を厳守）
6. **絵文字使用**（指示なき限り）

# クロスリファレンス

- ✓ 「巻2 第7章で扱う CBet 統合式」（元巻への参照、推奨）
- ✓ 「本書 第3章で見たレンジ思考を踏まえると」（自書内参照）
- ✗ 「リバー編で扱う」（本書は全巻ダイジェスト、特定巻だけを指す未来参照は不適）
- ✗ 「次章で詳しく説明」（凝縮本では「次章で」を多用しない、自己完結を優先）

# トラブル時の対応

- 字数が目標を超える → 「代表例」を削る、「導出」を削る、参照のみに置き換える
- 字数が目標未満 → 代表例を増やす、ただし重要度の低い例で水増ししない
- 用語に迷う → series-glossary.md を Read
- 元巻原稿が見つからない → 呼び出し元に報告し、参照なしで書く判断を仰ぐ
