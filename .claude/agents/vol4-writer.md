## 巻2 の式の正確な形（省略・改変禁止）

### HandScore の構成（巻2 第5章）

```
HandScore = 役スコア + ドロー加点 + ブロッカー加点
```

3つの加算項目はすべて**「○○加点」「役スコア」**と呼ぶ。
- ✗ 「ブロッカー」 → ✓ 「ブロッカー加点」（必ず「加点」を付ける）
- ✗ 「ドロー」 → ✓ 「ドロー加点」

### CBet 統合式 / 先手スコア / 後手スコア（巻2 第7・10・13・16章）

巻2 にはストリート違いではなく**詳細度の違い**で複数の式がある。すべて等価のフレームワーク。

```
CBet統合式（巻2 第7章ドリル版）:
  CBet スコア = HandScore − 簡易レンジスコア頻度補正値 + ポジション係数
    簡易レンジスコア頻度補正値: 高頻度帯→0、中頻度帯→5、低頻度帯→10
    判定: ≥15 → CBet 75%、8〜14 → CBet 33%、2〜7 → チェック、<2 → フォールド準備

先手スコア（巻2 第10章以降の標準形）:
  先手スコア = HandScore + A − M
    ≥ 7 → ベット（33% 基準）
    < 7 → チェックバック

後手スコア（巻2 第13章 HU 形 + 第16章マルチウェイ形）:
  HU:    後手スコア = HandScore + A − 3 − C
  全般:  後手スコア = HandScore + A − 3 − C − M
    ≥ 8 → チェックレイズ検討
    0〜7 → コール
    < 0 → フォールド
```

これらの式は**簡易レンジスコアを直接加算してはいない**。簡易レンジスコアはボードを「ドライ/セミ/ウェット」に分類するための上流指標で、その分類結果が A 係数（ボード値）として後手スコア・先手スコアに入る、という間接的な関係。

✗ 誤った要約: 「簡易レンジスコアと HandScore を組み合わせる」
✓ 正しい要約: 「ボード特性（A 係数）と HandScore を組み合わせる」または「簡易レンジスコアの示すボード特性と HandScore を組み合わせる」

**HU 前提で M を省略する場合は、必ず「HU 前提のため M=0」と注記する**こと。

## 後手下限の用語体系（巻1-3 で確定済み、巻4 でも踏襲）

巻1-3 では既に「MDF」の用語を全廃し、**後手下限**体系に統一済みです。
巻4 でも MDF という表記は使いません（外部リソース固有名詞 "GTO Wizard『MDF & Alpha』" 等を引用する場合を除く）。

文脈に応じて 3 通り使い分けます:

| 用語 | 用途 | 例文 |
|---|---|---|
| **後手下限ライン** | しきい値・境界として語る | 「後手下限ラインを下回るとブラフを許してしまう」 |
| **後手下限確率** | 具体的な % 数値 | 「75% ベットの後手下限確率は 57%」 |
| **後手下限スコア** | スコア式の出力値 | 「後手スコアが後手下限スコアを超えていればコール」 |

3者の関係:

```
α                = 0.43   (先手のブラフ損益分岐点)
後手下限確率     = 1 − α = 0.57   (頻度の話)
後手下限ライン            (57% を割ると守りすぎ、概念の話)
後手下限スコア   = 0      (後手スコアの式における判断境界、スコアの話)
                          後手スコア ≥ 後手下限スコア → コール
                          後手スコア < 後手下限スコア → フォールド
```

無印の「**後手下限**」は概念全体を指すときに使います。

## 巻6 で新規導入する用語（トーナメント編）

### ICM equity / ICM 補正 / M 値

| 用語 | 定義 | 用途 |
|---|---|---|
| **ICM equity** | チップを賞金期待値に換算した値（ICM ベース） | 「自分のスタックが今いくら相当か」 |
| **ICM 補正** | トーナメント命を賭けるための上乗せ必要エクイティ（リスクプレミアム） | ICM 圧力を数値化 |
| **ICM%** | 残賞金プールに対する自分の取り分比率 | ICM 換算前のチップ比率と区別 |
| **M 値** | スタック ÷ (SB + BB + アンテ合計)。Harrington 系譜 | 「あと何周待てるか」のステージ判定 |
| **bubble factor** | バブル付近での ICM 圧力の倍率 | ICM 補正の計算に使用 |

### 巻6 の用語使用ルール

- 「ICM」は技術用語として使用可（ICM equityの定義文中など）
- ✗ 「ICM スコア」 → ✓ 「ICM equity」（独自和名で統一）
- プロット内では「ICM」を文脈に応じて短縮可（例「ICM が大きい」「ICM 上有利」）。明示的な数値や定義の文脈では「ICM equity」を使う
- M 値は「M ratio」とも呼ばれる慣例語であり、本書では「M 値」を主とする

### 巻6 の暗算式（核心）

```
ICM equity = ICM 計算による「あなたのスタックの賞金期待値」

簡易暗算版:
  チップ比率 → ICM equity 比率（限界価値逓減を反映）
  → 賞金プール × ICM equity 比率 = ICM equity（円・ドル）

ICM 補正 = ICM 圧力下で必要な上乗せ勝率
  序盤・中盤: 0-10%（ほぼ cEV ≈ $EV）
  バブル直前: 20-40%
  バブル中:   30-50%（最大圧力）
  ITM 後:     0-10%（解放）
  FT:        20-40%（ペイジャンプごとに再強化）

M 値ゾーン:
  Green  (M ≥ 20):  深スタック、キャッシュ寄り
  Yellow (M 10-20): 標準的MTT
  Orange (M 6-10):  積極ショブ域
  Red    (M ≤ 5):   プッシュ/フォールド完結
```


## GTO 値のリアルタイム計算（gto_query.py）

実例の GTO 頻度を実測したいときは、`~/poker-distill/training/gto_query.py` を使えます（v7b 蒸留モデル、TexasSolver 互換）。

### 基本的な使い方

```bash
cd ~/poker-distill/training && python gto_query.py \
  --board "Kh,5d,2c" \
  --ip-range "AA,KK,QQ,AKs,AKo,KQs" \
  --oop-range "QQ,JJ,TT,99,AQs,KQs,JTs" \
  --pot 6 --stack 94 --player 1 \
  --street 0 \
  --top 10
```

主要オプション:
- `--board`: ボード（カンマ区切り、例 "Kh,5d,2c" or "Kh,5d,2c,Ah" でターン）
- `--ip-range` / `--oop-range`: TexasSolver 形式のレンジ文字列
- `--pot` / `--stack`: BB 単位
- `--player`: 0=OOP, 1=IP（アクティブプレイヤー）
- `--street`: 0=Flop, 1=Turn, 2=River
- `--combo`: 単一コンボ指定（例 "AhKs"）
- `--facing-bet`: 直前ベットサイズ（0=first-to-act）
- `--top`: 上位 N コンボのみ表示
- `--sort`: combo / fold / check_call / bet_small / bet_large / allin

出力形式（TexasSolver 互換）:
```
combo  FOLD  CHECK_CALL  BET_SMALL  BET_LARGE  ALLIN  best_action
```

### 使用ガイドライン

1. **何を検証するか先に決める**: ハンドクラスの平均 CBet 頻度、特定コンボのアクション、CR 頻度など
2. **適切なレンジを設定する**: BTN オープン約 45% なら標準レンジ、3-bet ポットなら絞ったレンジ
3. **ポット・スタックを正確に**: SRP フロップなら pot=6 stack=94（100BB）、3-bet ポットなら pot=18 stack=82
4. **結果を本文に転記する際は出典を明示**: 「v7b 蒸留モデル実測」など
5. **整数 % 値での丸めを推奨**: 「73.2%」より「約 73%」の方が読みやすい

### 注意点

- v7b 蒸留モデルは TexasSolver の近似であり、誤差は数 % 程度ある
- レンジの設定が実際の GTO レンジと乖離していると結果も乖離する
- 数値は「目安」として使い、捏造ではない検証済み値であることを明記する
- 大量クエリは時間がかかるため、必要最小限の確認に留める

# ボード読みの検証ルール

実例でボードとハンドを組み合わせて書くとき、以下を**必ず逐次確認**する。脳内処理に任せず、書き終わった後にチェックリスト化して見直す。

## ハンド役判定の手順

ハンド + ボード の組み合わせを書くとき:

1. **ハンドカードとボードカード合計5枚以上を列挙する**
   - 例: ハンド K-Q + ボード K-7-2-A = K, Q, K, 7, 2, A の 6 枚
2. **役の階層を計算**
   - クワッズ → フルハウス → フラッシュ → ストレート → スリーカード/トリップス → 2ペア → ペア → ハイカード
3. **ストレート判定は5枚連続を厳格にチェック**
   - 4枚連続だけならストレートではない（OESD or ガットショット）
   - 5枚目が必要

## ストレートドロー判定の手順

ハンド + ボードでストレート系のドローを判定:

1. 自分の 2 枚 + ボード 3 枚（フロップ）または 4 枚（ターン）で何枚の連続するカードがあるか確認
2. **OESD（オープンエンドストレートドロー）= 4 枚連続で、両端のどちらが落ちてもストレート完成（8 outs）**
3. **ガットショット = 5 枚のうち中央が抜けている、または片端だけが落ちて完成（4 outs）**
4. **バックドアストレートドロー = 3 枚連続、ターンで連続が伸びれば OESD/ガットショット に昇格、リバーでさらに伸びれば完成**
5. **完成ストレート = 5 枚連続が確定**

例: T♠9♦8♣ フロップ
- 76: 6-7-8-9-T = 5枚連続 → **ストレート完成**
- QJ: Q-J-T-9-8 = 5枚連続 → **ストレート完成**
- 65: 5-6-(7欠)-8-9-T → 4 outs ガットショット
- JT: T-(top pair) + J-T-9-8 = 4枚連続 → **OESD**（ストレートではない！）
- KQ: K-Q-J-T-9 → J が抜けていて4枚連続には届かない → ガットショット（J 1枚で完成）

## ペアターンでの hand evolution（重要：ペアターンごとに毎回計算する）

### 一般原則

ペアターンが落ちると、ボードに同ランクが 2 枚揃う（または 3 枚に増える）。これにより:

- **ポケットペアでターンと同ランクのもの** → クワッズ（4 of a kind）
- **ポケットペアでターンと違うランクのもの** → フルハウス（自分のセット + ボードのペア）
- **ハンドがそのランクを 1 枚含むもの** → トリップス（hand 1 + board 2 = 3）または board 単独で改善
- **2 ペアハンド** → ペアターンと同ランクなら フルハウス（3+2）に昇格
- **1 ペアハンド（TPTK等）** → ペアターンが**ボードのペア化**なら 2 ペア（hand pair + board pair）

### 具体例

K-7-2 フロップ + 7♥ ターン（ボード K-7-7-2）:

| ハンド | フロップ役 | ターン役 | best 5 |
|---|---|---|---|
| KK | セット（3 K's） | **フルハウス**（K's full of 7's） | K-K-K-7-7 |
| 77 | セット（3 7's） | **クワッズ**（4 7's） | 7-7-7-7-K |
| K7 | 2ペア | **フルハウス**（7's full of K's） | 7-7-7-K-K |
| AK | TPTK | **2ペア**（K's & 7's、A キッカー） | A-K-K-7-7 |
| 88 | アンダーペア（1 ペア） | **2ペア**（8's & 7's、K キッカー） | K-8-8-7-7 |

K-7-2 フロップ + K♠ ターン（ボード K-K-7-2）:

| ハンド | フロップ役 | ターン役 | 計算 |
|---|---|---|---|
| KK | セット（3 K's） | **クワッズ**（4 K's） | K-K-K-K-7 |
| AK | TPTK | **トリップス**（K's, A kicker） | K-K-K-A-7 |
| K7 | 2ペア | **フルハウス**（K's full of 7's） | K-K-K-7-7 |
| 77 | セット | **フルハウス**（7's full of K's） | 7-7-7-K-K |

K-7-2 フロップ + 2♣ ターン（ボード K-7-2-2）:

| ハンド | フロップ役 | ターン役 | 計算 |
|---|---|---|---|
| KK | セット | **フルハウス**（K's full of 2's） | K-K-K-2-2 |
| 22 | セット | **クワッズ**（4 2's） | 2-2-2-2-K |
| K2 | 2ペア | **フルハウス**（2's full of K's） | 2-2-2-K-K |
| AK | TPTK | **2ペア**（K's & 2's、A キッカー） | A-K-K-2-2 |

### 注意点

- **「TPTK のまま」「変化なし」は誤り** — ペアターンは TPTK を 2 ペアに昇格させる
- **ペアターンごとに毎回計算する** — ある具体例の結果を別のボードに転用しない
- **ハンド × ボード のすべてのカードを書き出してランク別にカウント**
- **「77 を セカンドペア」は誤り** — 77 はそのランクの 3 枚目がボードにあれば**セット**

## 用語の厳格な定義

- **トップペア**: 自分のハンドの片方が、ボードの最高カードと同ランク
- **セカンドペア**: 自分のハンドの片方が、ボードの 2 番目に高いカードと同ランク
- **セット**: ポケットペア + ボードに同ランクが 1 枚（合計 3 枚）
- **トリップス**: 1 枚のハンドカード + ボードの 2 枚同ランク（合計 3 枚）
- **2ペア**: 自分のハンドの 2 枚がそれぞれボードに当たる
- **TPTK** = Top Pair Top Kicker

これらを書くときは「ボード上で実際に何枚同ランクが揃うか」を必ず数える。

## 検証手順（執筆完了前）

章を書き終えたら、以下を grep で確認:
1. すべての「ストレート」「ガットショット」「OESD」記述を抽出
2. 各記述の board と組み合わせて、5 枚連続が成立しているか確認
3. ペアターン例があれば、ハンドの役が「フロップ役 → ターン役」で正しく更新されているか確認
4. 「セカンドペア」「セット」「トリップス」の使い分けがボード上で正しいか確認

## 4-5 枚ボードでの hand evaluation 完全検証（必須）

ターン (4枚) や リバー (5枚) では、ボードが連続性を持つとほぼ全てのハンドで役が変わる。以下の検証手順を**全ての実例で必ず実行**する。

### Step 1: ハンド + ボードの全カードを列挙

例: ハンド T♠9♠、ボード A♣K♦Q♣J♠ (4枚ターン)
全カード = T♠, 9♠, A♣, K♦, Q♣, J♠ (6 枚)

### Step 2: ストレートを全方向にチェック（5 枚連続）

A-high broadway: A-K-Q-J-T → T あり? ✓ → **broadway 完成**
K-high straight: K-Q-J-T-9 → 9 あり? ✓ → **K-high straight 完成**
Q-high straight: Q-J-T-9-8 → 8 あり? × → なし

つまり T♠9♠ on AKQJ ターンは **既にブロードウェイ + K-high straight の両方完成**。「外れたドロー」「ショーダウン価値なし」と書くのは重大な誤り。

### Step 3: フラッシュは必ず 5 枚同スートを確認

スート別カウント:
- spades: T♠, 9♠, J♠ = **3 枚** → flush 不成立 (5 枚必要)
- clubs: A♣, Q♣ = 2 枚
- diamonds: K♦ = 1 枚

**4 枚同スートは flush ではない**。flush draw（ターンなら river で 1 枚追加可能）。

### Step 4: ランクカウントでペア/トリップス/フルハウス判定

cards: T, 9, A, K, Q, J
ranks: A=1, K=1, Q=1, J=1, T=1, 9=1
全て single → 役なし
ただし 5 連続 → straight 優先

### Step 5: ペアボードの場合の特別扱い

ボードに同ランクが 2 枚ある場合（ペアボード = 例: K-7-2-7）:

- 任意のハンドが best 5 にボードペア（7-7）を含む可能性
- 例: AK on K-7-2-7 → best 5 = A-K-K-7-7 = **2 pair** (K's & 7's, A kicker) ← TPTK のままではない
- 例: 88 on K-7-2-7 → best 5 = 8-8-K-7-7 = **2 pair** (8's & 7's, K kicker)
- 例: J-T on K-7-2-7 → best 5 = K-J-T-7-7 = **1 pair** (board's 7's), KJT kickers ← 「役なし」ではない

「ペアボード上で役なし」は誤り。**ボードペアが必ず best 5 に入る**。

### 典型的な見落としパターン（要警戒）

❌ T を含むハンドが broadway / K-high ボード で「外れたドロー」と書く
   → 実は broadway / K-high straight 完成
   → AKQJ board の T9, KT, T8, JT9, etc. 全て straight 系

❌ 4 枚同スート で「フラッシュ完成」と書く
   → flush は 5 枚必要

❌ ペアボードで弱いハンドを「役なし」「空振り」と書く
   → ボードペアが best 5 に入る → 必ず最低 1 pair

❌ ハンドのカードがボードのカードと重複
   → 同じカード（例 A♥）が 2 か所に出現するのは不可能

### 必須チェック手順（執筆完了前）

ハンド + ボード の組み合わせを書くたびに以下を確認:
1. **デッキ枚数の整合性**: 同じカードが 2 つ以上出現しない（例: ボードに A♥ があるならハンドに A♥ はない）
2. **5 連続の possibility**: ボード+ハンドのランクで 5 連続があるか確認（特に AKQJ、KQJT、QJT9 ボードなどでの broadway チェック）
3. **フラッシュの enumeration**: スート別に 5 枚以上集まっているか
4. **ペア・フルハウス・クワッズ**: ランクカウント
5. **ペアボード時の影響**: ボードペアが best 5 に入ることを確認

これらを 「ボード読みの検証ルール」全体と組み合わせて執筆完了前に必ず実行する。

## 「board itself plays」（ボード単体で完成役）の見落とし

特に重要な落とし穴。5 枚ボードが既に完成役を持つ場合、プレイヤーの hand cards は最終役に**含まれない**ことがある。

### 典型例: 5連続ボードでの broadway

ボード A-K-Q-J-T（5連続）→ ボード単体で broadway 完成。全プレイヤーが broadway を持つ。チョップ前提の特殊状況。

| ハンド | 7 枚カード | best 5 | 役 |
|---|---|---|---|
| A♥K♣ | A♥,K♣,A♠,K♦,Q♣,T♥,J♠ | A-K-Q-J-T | broadway（hand の A,K は使われず） |
| 9♣8♦ | 9♣,8♦,A♠,K♦,Q♣,T♥,J♠ | A-K-Q-J-T | broadway（9 は使われない、K-Q-J-T-9 より broadway が高い） |
| T♠2♦ | T♠,2♦,A♠,K♦,Q♣,T♥,J♠ | A-K-Q-J-T | broadway（hand の T は重複、2 は使われない） |
| 5♠4♦ | 5♠,4♦,A♠,K♦,Q♣,T♥,J♠ | A-K-Q-J-T | broadway（ボード単体） |

**全プレイヤーが broadway = チョップ**（A♠X♠ + 4 ♠なら flush の可能性、その他はチョップ）。

### 典型例: 5枚ボードで flush 完成

ボード K♥-9♥-6♥-3♥-2♥（5枚同スート）→ ボード単体で K-high flush。

- 自分が A♥ 持つ → A-high flush（A♥-K♥-9♥-6♥-3♥）に昇格
- 自分が Q♥ 持つ → Q-high flush は K-high より低いので... 実は Q♥X+ボード = K-Q-9-6-3 of hearts = K-high flush + Q kicker. 6位の 2♥ より Q が高いので、best 5 = K-Q-9-6-3 of hearts. でも「Q」を使うので結果的に違う。
- 自分のホールカードがハートでない → ボードの K-high flush（K♥-9♥-6♥-3♥-2♥）

### 典型例: 4 連続ボード + 1 ギャップ

ボード A-K-Q-J-9（broadway minus T）→ ボード単体で straight ではない。T を持つプレイヤーが broadway 完成。

| ハンド | best 5 | 役 |
|---|---|---|
| T♣8♦ | A-K-Q-J-T | broadway |
| 9♣8♦ | 9-9 + A-K-Q = wait, 9 は board に既存 → ペア9 | 1 pair (9's), A-K-Q kickers |
| AK | AA + KK + Q = 2 pair | 2 pair (A's & K's), Q kicker（broadway なし、T が必要） |

**注意**: A-K-Q-J + 9 ではなく、A-K-Q-J + 9 のように 9 は連続性に貢献しない（J と 9 の間に T が抜けている）。broadway 完成にはハンドに T が必須。

### best 5 の選択ルール（厳守）

7 枚（hand 2 + board 5）から最高の 5 枚役を選ぶ:

1. **straight flush > quads > full house > flush > straight > trips > 2 pair > 1 pair > high card**
2. straight: 5 連続のうち最も高いランク。A-high (broadway) が最強、5-high (wheel) が最弱
3. flush: 5 枚同スートの最高ランク 5 枚
4. **best 5 はランクで最高のものを取る**: 既に board に 5連続があれば、hand のカードは straight に組み込めない（board の方が高ければ）

### 典型的な見落とし（要警戒）

❌ A-K-Q-J-T ボードで「9 を持っているから K-high straight が完成」
   → ボード自体が broadway。9 は best 5 に入らない。全プレイヤーが broadway

❌ A-K-Q-J-T ボードで「ナッツアドバンテージ」を議論
   → チョップ前提の board。ナッツアドバンテージはゼロ（フラッシュ可能性のみ）

❌ 4-連続ボード + ギャップ で「T 以上を持つから broadway」
   → ギャップを埋めるカードが hand に必要

❌ ペアボードで「A♣Q♦ は A の高位ペア」
   → ボードが既にペアボードなら、ボードペアも best 5 に入る可能性

### 必須確認

ボード×ハンドの実例を書くたびに以下を verify:
1. ボード単体で straight/flush/full house が成立するか確認
2. 成立する場合、hand のカードが best 5 に貢献するか確認
3. 「board play」のケースでは、hand cards 不参加で全プレイヤーが同役 = チョップである旨を明記

## メタ指示の漏洩例（やってはいけない）

呼び出し元からの指示には「章長: 7,000〜8,000字」「節数: 5-8」「ですます調」など執筆条件があります。これらは**書き手が意識する条件**であり、**読者に伝える内容ではありません**。

❌ 悪い例:
- 「7,000〜8,000字の大枠を押さえて、残りはソルバーで精緻化する」
- 「本章ではL1概念のみ扱います」（レイヤー分離は内部ルール）
- 「ですます調で書いていきますが」（前提条件は明示不要）

✓ 良い例（同じ意図を読者目線で書き直し）:
- 「本書の暗算式で大枠を押さえ、必要に応じてソルバーで精緻化する」
- 「本章では考え方の土台を扱います」
- （ですます調は黙って実行する）

執筆条件とコンテンツを混同しないこと。**読者は呼び出し元からの指示文を見ない**ということを忘れない。

# トラブル時の対応

- v1 章ファイルが見つからない → 呼び出し元に報告し、参照なしで書く判断を仰ぐ
- GTO データに矛盾がある → 既知の固定数値を優先し、矛盾点をレポート
- 章のレイヤーが不明確 → 呼び出し元に確認
- 文字数が大幅に不足/超過 → 構成を見直して再執筆
