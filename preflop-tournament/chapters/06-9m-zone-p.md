# 第 6 章（9m 版）　Zone P — Push/Fold（SBR 8〜14）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 9 人制 MTT の Zone P（SBR 8〜14）で、ポジションと SBR に応じた T_open（push が有利になる最低スコア）を把握し、ペア表と非ペアの閾値を組み合わせて push/fold 判断ができるようになる。

---

## 6m-1 9m Zone P の基本構造

9 人制（9m）テーブルでの Zone P（SBR 8〜14）には、6-max や 8-max とは異なる固有の特徴があります。もっとも大きな違いは**アーリーポジションの多さ**です。

9m のポジション構成は UTG / UTG1 / UTG2 / LJ / HJ / CO / BTN / SB / BB の 9 人です。EP（UTG〜LJ）だけで 4 ポジションを占めており、Zone P において push が求められる場面で、後ろに最大 8 人が控える厳しい状況が生まれます。

Zone P では min-raise ではなく**プッシュ（全額オールイン）かフォールドかの二択**が基本です。SBR=8〜14 のスタック深度では、min-raise をしても残りスタックが浅すぎてポストフロップでの選択肢が限られます。そのため push してフォールドエクイティとショーダウンエクイティの合計で判断する構造が成立します。

### 9m と 6m の T_open 比較

同じ Zone P でも、9m と 6m では EP の参加基準が異なります。

| ポジション | 9m UTG（SBR=12） | 6m UTG（SBR=12） |
|----------|----------------|----------------|
| T_open   | 25             | 23 程度         |
| 最低ペア  | 77+            | 66+            |

9m の UTG は後ろに 8 人を抱えるため、6m（後ろ 5 人）より 2 ポイント程度 tight な設計になっています。この差は小さく見えますが、境界ハンド（K9s や 66 など）の扱いが逆転するため、実戦では意識が必要です。

---

## 6m-2 T_open 表（9m、Zone P 全ポジション）

9m chip EV 最大化を目標とした T_open 表を示します。この値を超えるスコアのハンドは push、下回るハンドは fold です。

| SBR | UTG | UTG1 | UTG2 | LJ | HJ | CO | BTN | SB  |
|-----|-----|------|------|----|----|----|----|-----|
| 8   | 24  | 23   | 23   | 22 | 21 | 20 | 18 | —   |
| 10  | 25  | 24   | 23   | 23 | 21 | 21 | 18 | —   |
| 12  | 25  | 25   | 23   | 23 | 23 | 21 | 19 | 40  |
| 14  | 25  | 25   | 23   | 23 | 23 | 21 | 19 | 40  |

SB の「—」はデータ不足により掲載しない（SBR=8〜10 は SB push 範囲が非常に広く、limp との境界が複雑なため別途確認推奨）ことを示します。SBR=12〜14 の SB T_open=40 については 6m-7 節で詳しく説明します。

**表の読み取り方**

「SBR=10、LJ」のセルは 23 です。score_mtt ≥ 23 のハンドは push、score_mtt < 23 のハンドは fold が chip EV 最大の判断です。

### UTG と BTN の差

同じ SBR=12 で UTG T=25、BTN T=19 と 6 ポイントの差があります。8-max 版（第 4 章）では SBR=12 の UTG T=27 でしたが、9m では後ろに 8 人いる UTG は 25 まで下がっています。一見「9m のほうが UTG が広い」ように見えますが、これは 8-max と 9m でデータの基準となる状況（6-max 対応版 vs 9m 専用）が異なるためです。本書で 9m を扱う際はこの表をそのまま使います。

## 6m-3 SBR=12 の詳細（中核シナリオ）

Zone P の代表シナリオとして SBR=12 を詳しく確認します。SBR=12 はトーナメント中盤でもっとも頻繁に遭遇する浅さです。

### UTG / UTG1（T=25）

UTG と UTG1 は同じ T=25 のため、push 対象ハンドが共通です。

| ハンド | スコア | push/fold |
|--------|--------|----------|
| AKs    | 35     | push     |
| AQs    | 34     | push     |
| AJs    | 33     | push     |
| ATs    | 32     | push     |
| A9s    | 31     | push     |
| A8s    | 30     | push     |
| A7s    | 29     | push     |
| A6s    | 28     | push     |
| A5s    | 27     | push     |
| A4s    | 26     | push     |
| A3s    | 25     | push（境界） |
| A2s    | 24     | fold     |
| KQs    | 30     | push     |
| KJs    | 28     | push     |
| KTs    | 26     | push     |
| K9s    | 25     | push（境界） |
| K8s    | 24     | fold     |
| QJs    | 28     | push     |
| JTs    | 26     | push     |
| J9s    | 24     | fold     |
| T9s    | 24     | fold     |
| AKo    | 30     | push     |
| AQo    | 29     | push     |
| AJo    | 28     | push     |
| ATo    | 27     | push     |
| A9o    | 23     | fold     |
| A8o    | 22     | fold     |

スーテッドでは K9s（score=25）が境界ハンドです。K8s（score=24）は fold になります。オフスーツでは ATo（score=27）までが push、A9o（score=23）は fold です。

ペアについては T=25 のため、score ≥ 25 のペアが push 対象です。ペアスコアは「ランク×2+12」で計算でき、77=26、66=24 となります。77 は 26 ≥ 25 で push、66 は 24 < 25 で fold です。よって UTG/UTG1 の最低 push ペアは **77+** です。

### UTG2 / LJ（T=23）

T が 25 から 23 に下がることで、境界ハンドが広がります。

| ハンド | スコア | push/fold |
|--------|--------|----------|
| K9s    | 25     | push     |
| K8s    | 24     | push     |
| K7s    | 23     | push（境界） |
| K6s    | 22     | fold     |
| J9s    | 24     | push     |
| T9s    | 24     | push     |
| T8s    | 22     | fold     |
| 98s    | 22     | fold     |
| A9o    | 23     | push（境界） |
| A8o    | 22     | fold     |

UTG では fold だった K8s（24）と J9s（24）と T9s（24）が、UTG2/LJ では push に変わります。さらに K7s（23）がボーダー push になります。

ペアは T=23 なので、score ≥ 23 のペアが push 対象です。66（score=24）≥ 23 で push、55（score=22）< 23 で fold。よって UTG2/LJ の最低 push ペアは **66+** です。

### HJ / CO（T=23 / T=21）

HJ は SBR=12 で T=23 と UTG2/LJ と同じですが、CO は T=21 とさらに広がります。

CO（T=21）では score ≥ 21 が push 対象です。スーテッドコネクター 87s（score=20）は fold、98s（score=22）は push です。ペアは 55（score=22）≥ 21 で push。よって CO の最低 push ペアは **55+** です。

### BTN（T=19）

BTN は T=19 と、9 人テーブルの中で SB を除いて最も低い閾値です。

| ハンド | スコア | push/fold |
|--------|--------|----------|
| 98s    | 22     | push     |
| 87s    | 20     | push     |
| 76s    | 18     | fold（18<19） |
| 65s    | 16     | fold     |

76s（score=18）は T=19 を下回るため fold です。87s（score=20）は push 圏内です。ペアは 44（score=20）≥ 19 で push。よって BTN の最低 push ペアは **44+** です。

## 6m-4 SBR=8 の特殊性

SBR=8 はゾーンの中で最も浅く、「フォールドしてもあと数周しか待てない」状況です。push の閾値は全ポジションで低くなります。

### UTG（T=24）

SBR=8 の UTG T=24 は SBR=12（T=25）より 1 低く、わずかに広い設定です。

| ハンド | スコア | SBR=8 UTG 判断 |
|--------|--------|--------------|
| K8s    | 24     | push（境界）  |
| K7s    | 23     | fold         |
| J9s    | 24     | push         |
| T9s    | 24     | push         |
| Q9s    | 24     | push         |
| 98s    | 22     | fold         |

SBR=12 では fold だった K8s（score=24）が、SBR=8 の UTG では push に変わります。これが SBR=8 と SBR=10-12 の最も大きな違いです。

ペアは T=24 のため、66（score=24）≥ 24 で push、55（score=22）< 24 で fold。よって SBR=8 UTG の最低 push ペアは **66+** です。

### BTN（T=18）

SBR=8 の BTN は T=18 と非常に低く、ほぼすべての手が push 対象です。

score=18 以上となる手は広い範囲を含みます。33（score=18）がちょうど境界で、22（score=16）だけが fold になります。実質的に「22 以外の全手が push」に近い状況です。スーテッドでは 65s（score=16）が fold、76s（score=18）が push 境界です。

---

## 6m-5 SBR=10 の変化点

SBR=10 は SBR=8 と SBR=12 の中間に位置し、変化のポイントを把握することが重要です。

### UTG の変化（T=24 → T=25）

SBR=10 の UTG T=25 は SBR=8（T=24）から 1 上がります。この 1 ポイントの差が境界ハンドを変えます。

| ハンド | スコア | SBR=8 UTG | SBR=10 UTG |
|--------|--------|-----------|------------|
| K9s    | 25     | push      | push       |
| K8s    | 24     | push      | fold       |
| J9s    | 24     | push      | fold       |
| T9s    | 24     | push      | fold       |
| Q9s    | 24     | push      | fold       |

SBR が 8 から 10 に増えると、K8s / J9s / T9s / Q9s がすべて fold に変わります。SBR=10 の UTG では「score ≥ 25 以上」という基準が K9s（score=25）を境界とし、それ以下のスーテッドハンドは切り捨てます。

ペアは T=25 のため、SBR=10 UTG の最低 push ペアは **77+**（66=24 が fold に変わる）です。

### その他ポジションの変化

UTG1 は SBR=8 の T=23 から SBR=10 の T=24 に上がります。UTG2/LJ は T=23 で変わりません。

## 6m-6 ペアの push 閾値（9m 全ポジション）

ペアは式を計算せずに以下の表を直接参照します。

| SBR | UTG | UTG1 | UTG2 | LJ | HJ | CO | BTN |
|-----|-----|------|------|----|----|----|----|
| 8   | 66+ | 66+  | 66+  | 55+ | 55+ | 44+ | 33+ |
| 10  | 77+ | 66+  | 66+  | 66+ | 55+ | 55+ | 33+ |
| 12  | 77+ | 77+  | 66+  | 66+ | 66+ | 55+ | 44+ |
| 14  | 77+ | 77+  | 66+  | 66+ | 66+ | 55+ | 44+ |

（T_open 表の各セルからペアスコア = ランク×2+12 で逆算。T=25 → 77+(26≥25, 66=24<25)）

**ポイントを整理します。**

SBR=12〜14 での UTG / UTG1 の最低ペアは **77+** です。66 はスコア 24 と閾値 25 を 1 下回るため fold になります。77 はスコア 26 ≥ 25 で push できます。「9m の中盤でも UTG から 66 は開けない」という感覚を持っておくと実戦での迷いが減ります。

SBR=8 では全体的に閾値が下がり、UTG でも 66+ から push できます。「SBR=8 は最も広い、SBR=10 から UTG が 77+ に絞られる」と覚えると切替がしやすいです。

## 6m-7 SB の特殊性（Zone P）

SBR=12〜14 の SB T_open=40 という値は非常に目立ちます。score=40 はスコア表の最高値である AA（score=40）と同値です。つまり「AA ですらぎりぎり push できる閾値」を意味します。

### なぜ SB の T_open がこれほど高いのか

SB は OOP（アウト・オブ・ポジション）であり、push すると BB だけに対面します。BB からコールされた場合、SB は SBR=12 のスタック全額（12BB）を投じる一方でポストフロップの有利さが全くありません。加えて SBR=12 の SB push は BB にとってポットオッズ的に美味しいレンジが広く、コール確率が高い状況です。

この構造では、GTO は SB において push よりも**リンプ（1BB 追加参加）**を多くの手で選択します。push が最善となるのは「コールされても十分なエクイティが確保できる強い手」に限定されます。T_open=40 は「ほぼ全ての手でリンプを推奨」と読み替えられます。

### SBR=12 SB の実用ルール

```
SBR=12 SB の実戦フロー:
  AA（score=40）  → push
  それ以外の大多数 → limp（リンプ）
  極端な弱手        → fold
```

SB のリンプ戦略の詳細は第 9 章で扱います。Zone P の SB では「push は AA のみ、あとはリンプか fold」という単純なルールから始めて問題ありません。

## 6m-8 SBR=14 での変化と Zone T への移行

SBR=14 では T_open 表が SBR=12 と完全に一致します（UTG=25、BTN=19 等）。しかし SBR=14 は Zone T（移行帯、第 6 章 Zone T 編で扱う）の入口付近であり、一部のハンドで min-raise が混在し始めます。

SBR=12 と SBR=14 で表の値が同じであるのは、chip EV 最大化の観点ではちょうど同じ閾値に収まるためです。しかし SBR=14 では一部のミドルレンジのハンド（例: ATo や K9s）が push と min-raise の混合戦略をとり始めます。この細かい混在を正確に再現するよりも「SBR=14 は SBR=12 とほぼ同じ閾値、スタックが少し深い分 min-raise の余地もある」と捉えておくのが実用的です。

SBR が 17 以上になると Zone O（第 7 章）に移行し、min-raise が主体になります。Zone P と Zone O の境界は SBR=15〜16 付近にあります。

## 6m-9 記憶法：9m Zone P の暗記ポイント

Zone P の数値は表で確認するのが基本ですが、以下の記憶補助を使うと判断が速くなります。

### 非ペアの記憶（基点）

```
SBR=10〜14 の UTG: T=25、K9s が境界（K8s は fold）
SBR=8 の UTG:     T=24、K8s が境界（K7s は fold）
BTN はゾーン全体で T=18〜19 と低い
```

「9m Zone P: UTG=25（SBR=10-14）、境界は K9s」を暗記の起点にします。

### ペアの記憶（基点）

```
9m UTG SBR=10〜14: 77+（66 は fold）
9m UTG SBR=8:     66+（55 は fold）
SBR が 2 増えると UTG の最低ペアが 1 ランク上がる感覚
```

「9m の中盤以降（SBR=10〜14）、UTG は 77+」と覚えます。8-max 版（第 4 章）の UTG 55+ や UTG 44+ より tight です。

### 差分で覚えるポジション補正

| ポジション | SBR=12 T_open | UTG との差 |
|----------|-------------|---------|
| UTG      | 25          | ±0      |
| UTG1     | 25          | ±0      |
| UTG2     | 23          | −2      |
| LJ       | 23          | −2      |
| HJ       | 23          | −2      |
| CO       | 21          | −4      |
| BTN      | 19          | −6      |

SBR=12 では UTG〜HJ まで 23〜25 に集中しています。CO と BTN が 21、19 と一気に下がります。「EP は 23〜25 でまとまっている、LP から一気に広くなる」という感覚を持っておくと有用です。

## ミニクイズ

### 問 1

9m テーブル、SBR=12、UTG でハンドは 66 です。正しい行動はどれですか。

1. push（UTG の最低 push ペアは 66+ なので 66 は含まれる）
2. fold（9m SBR=12 UTG の最低 push ペアは 77+、66 は fold）
3. min-raise（Zone P でも UTG からは min-raise が正解）
4. limp（66 はセットマイニングのためリンプで参加）

### 問 2

9m テーブル、SBR=10、UTG でハンドは K8s です。score_mtt を参照し、正しい行動を答えてください。

1. push（K8s score=24 ≥ T_open=24 なので push）
2. fold（K8s score=24 < T_open=25 なので fold）
3. push（K8s はスーテッドなので UTG でも push 圏内）
4. min-raise（SBR=10 は Zone T 移行期なので min-raise が最善）

### 問 3

9m テーブル、SBR=12、SB でハンドは KQs（score=30）です。T_open=40 を参照したとき、正しい行動はどれですか。

1. push（score=30 は KQs として高いため push が正解）
2. fold（score=30 < T_open=40 なので fold）
3. limp（SB Zone P では T_open=40 がほぼ「リンプ推奨」を意味するため、KQs はリンプ）
4. min-raise（SBR=12 の SB は min-raise で BB に挑戦する）

---

### 解答

- **問 1**: **2（fold）**
  9m SBR=12 の UTG は T_open=25 です。ペアスコアは「ランク×2+12」で計算し、66=6×2+12=24 となります。24 < 25 のため fold が正解です。最低 push ペアは 77（=26≥25）からです。8-max 版（第 4 章）の UTG SBR=12 では 55+ でしたが、9m ではさらに tight になります。

- **問 2**: **2（fold）**
  K8s の score=24 です（付録スコア表参照）。SBR=10 の UTG T_open=25 に対して score=24 < 25 のため fold が正解です。SBR=8 では T_open=24 で K8s はちょうど push 境界になりますが、SBR=10 からは fold になります。「SBR=10 で UTG が 1 ポイント tight になる」という変化点を覚えておくと判断が速くなります。

- **問 3**: **3（limp）**
  SBR=12 の SB は T_open=40 という非常に高い閾値が設定されています。これは「AA（score=40）がぎりぎり push できる」水準であり、KQs（score=30）のような強い手でも push 閾値を下回ります。GTO では SBR=12 の SB においてほとんどのハンドがリンプを選択します。KQs もリンプが最善です。push しても BB がフォールドして 1.5BB しか取れないより、リンプしてポストフロップでスタック全額を狙う方が期待値が高くなります。

---

> **本章まとめ**
>
> - 9m Zone P（SBR 8〜14）は push/fold の世界。EP が 4 ポジション（UTG〜LJ）あり、6-max より EP が 2 ポイント程度 tight
> - SBR=12 UTG の T_open=25。K9s（score=25）が push 境界、K8s（score=24）は fold
> - ペアは「最低 push ペア表」を参照。9m SBR=10〜14 の UTG は 77+（66=24 < T=25 で fold）
> - SBR=8 の UTG は T=24 と 1 低く、K8s や T9s が push に変わる。「SBR=10 からは UTG が tight になる」と覚える
> - SBR=12〜14 の SB は T_open=40 と異常に高く、実質「AA のみ push、その他はリンプ」
> - BTN は T=18〜19 と低く「76s（score=18）が fold 境界（SBR=12）」程度で、それ以上はほぼ push

---

**【GTO とのズレ】**

本章の T_open 表は chip EV（ICM なし）の近似値です。実戦のトーナメントでは ICM 圧力により、特に EP の push 基準が変化することがあります。

**バブル局面での EP 補正**: バブル直前やファイナルテーブルのペイジャンプ前では、UTG の push 閾値が 1〜3 ポイント上がることが多いです。SBR=12 UTG の T=25 はバブル中盤では 27〜28 に相当する判断が求められる場合があります。ITM 後はほぼ chip EV に戻るため、状況を見て補正してください。

**SBR=8 UTG と SBR=10 UTG の 1 ポイント差**: T_open の差は 1 ポイント（24 vs 25）ですが、境界ハンドが 4 枚（K8s、J9s、T9s、Q9s）一気に変わります。「SBR を下に一周するたびに境界が動く」という感覚で、SBR の変化を都度確認することを推奨します。

**9m vs 8-max のデータ差**: 本章のデータは 9m 専用であり、8-max 版（第 4 章）と混在させないよう注意してください。同じ SBR=12 UTG でも、9m では T=25 ですが 8-max 版のデータでは異なる値が使われることがあります。テーブル人数を必ず確認したうえで適切な表を参照してください。
