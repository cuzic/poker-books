# 第 4 章　EP の Push 判断（UTG/UTG1）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: Zone P（SBR=8〜14）における UTG と UTG1 の push 基準を理解し、SBR ごとに適切な push/fold 判断ができるようになる。

---

## 4-1 EP push の難しさ

Zone P のほかのポジション（CO/BTN/SB）と比べると、UTG の push 基準は格段に厳しいです。

BTN は後ろに誰もいない分、弱い手でも push してフォールドエクイティを得られます。しかし UTG の後ろには 7 人が控えており、そのうちの誰かに強い手でコールされるリスクが常にあります。それだけでなく、8 人全員にフォールドされた場合の利益（1.5BB 程度）に対して、コールされたときの期待損失が大きいため、エッジのある手に絞ることが必要です。

BTN の T_push が 13〜14 なのに対し、UTG の T_push は SBR=12 の時点で 27 まで上がります。同じ Zone P でも、EP と LP では 10 ポイント以上の差があることを念頭に置いてください。

## 4-2 SBR 別 T_push（UTG 非ペア）

GTO Wizard MTTGeneral の実測データをもとに整理した UTG の push 閾値（非ペア）を示します。

| SBR | T_push（非ペア） | 最低 push ペア | 精度 |
|-----|----------------|--------------|------|
| 8   | 22（Ax 優先・後述） | 22+（全ペア）| 93% |
| 10  | 25.5            | 44+          | 99% |
| 12  | 27              | 55+          | 95% |
| 14  | 25（一部 min-raise 混在） | 66+ | 96% |

スタックが浅い SBR=8 では、閾値が 22 と低く設定されます。SBR=10 では 25.5 に上がり、SBR=12 でピークの 27 に達します。そして SBR=14 では 25 に戻ります。この一見不思議な動きには、SBR=14 で min-raise 行動が混在し始めるという構造的な理由があります（詳しくは 4-5 節で説明します）。

## 4-3 SBR=8 の特殊ルール

SBR=8 の UTG は閾値 T_push=22 ですが、スコア 22 以上のハンドをすべて push すると正確ではありません。K-medium suited（K8s スコア 24、T8s スコア 24）などが実際には fold となる場面があり、スコア式の精度は 93% にとどまります。

これはなぜでしょうか。SBR=8 は極めてスタックが浅く、push してコールされると「7BB vs 7BB のオールイン」に近い状況になります。K8s や T8s のような中程度のスーテッドコネクターは、相手がコールしてきた際のエクイティが十分でないため、GTO は fold を選択することがあります。

**SBR=8 UTG の実用的な暗記法**:

スコア閾値で考えるより、以下のリストで覚えるほうが実戦的に正確です。

| カテゴリ | 具体的なハンド |
|---------|-------------|
| Ax 全手 | A2o〜AKo、A2s〜AKs（すべて push） |
| Broadway strong | KJo+、KQs、KJs |
| スーテッドコネクター high | QTs、JTs |
| ペア | 22+（全ペア） |

つまり「Ax 全手 + KJo 以上のブロードウェイ + JTs/QTs + ペア全部」という暗記で SBR=8 の UTG push 範囲を約 93% の精度でカバーできます。K8s や T8s はスコア的には閾値を超えますが、このリストには含まれないため fold にしてください。

## 4-4 SBR=10 と SBR=12 の push リスト

SBR=10 と SBR=12 は、UTG の T_push が精度よく機能するゾーンです。T_push=25.5（SBR=10）および T_push=27（SBR=12）をそのまま使えます。

**SBR=10（T_push=25.5、精度 99%）の push 確定ハンド（主要 non-pair）**:

| ハンド | スコア | push の根拠 |
|--------|--------|------------|
| AKs    | 37     | 確定 |
| AQs    | 35     | 確定 |
| AJs    | 33     | 確定 |
| AKo    | 32     | 確定 |
| KQs    | 32     | 確定 |
| ATs    | 31     | 確定 |
| AQo    | 30     | 確定 |
| KJs    | 30     | 確定 |
| QJs    | 30     | 確定 |
| JTs    | 28     | 確定 |
| KTs    | 27.5   | 確定 |
| AJo    | 28     | 確定 |
| T9s    | 26     | 確定（スコア 26 > 25.5） |
| KJo    | 25     | 折れる（スコア 25 < 25.5） |
| ATo    | 27     | 確定 |

KJo はスコア 25.0 と閾値 25.5 を下回るため、SBR=10 UTG では fold です。ATo（スコア 27）は push 圏内に入ります。

**SBR=12（T_push=27、精度 95%）の push 確定ハンド（主要 non-pair）**:

| ハンド | スコア | SBR=12 UTG 判断 |
|--------|--------|----------------|
| AKs    | 37     | push |
| AQs    | 35     | push |
| AJs    | 33     | push |
| AKo    | 32     | push |
| KQs    | 32     | push |
| ATs    | 31     | push |
| AQo    | 30     | push |
| KJs    | 30     | push |
| QJs    | 30     | push |
| JTs    | 28     | push |
| AJo    | 28     | push |
| KTs    | 27.5   | push（ぎりぎり） |
| T9s    | 26     | fold |
| ATo    | 27     | fold |
| KJo    | 25     | fold |
| A9s    | 27     | fold（スコア 27 = 閾値で混在） |

A9s はスコア 27 とちょうど閾値に位置します。SBR=12 のデータでは A9s は fold の方向です。「スコア 27 以上は push、27 以下は fold」と覚えるとき、スコア 27 ちょうどは保守的に fold としておくのが安全です。

## 4-5 SBR=14：push vs min-raise の分岐

SBR=14 は Zone T（移行帯）の入り口であり、UTG で min-raise が混在し始めます。T_push の閾値（push が多数を占める最低スコア）は 27.5 ですが、T_open（raise + push が 50% 超の最低スコア）は 25 まで下がります。

つまり SBR=14 の UTG では：
- **スコア ≥ 28（純 push）**: push が最善
- **スコア 25〜27（min-raise 混在）**: min-raise が最善
- **スコア < 25**: fold

実際のアクション別分類を示します。

| アクション | 代表ハンド | スコア |
|-----------|----------|--------|
| **純 push** | AKo, AQo, KQs, KJs, QJs, JTs, AJo, KTs | 28〜37 |
| **min-raise** | AKs（混在）, A9s, A8s, A7s, A5s, T9s, K9s | 25〜27 |
| **fold** | A3s 以下, QJo 以下, K8s 以下 | < 25 |

この構造の解釈として、「強すぎる手（KQs、AJo 等）は push で相手全員を排除し、エクイティを確定させる」「やや弱い手（A9s, T9s 等）は min-raise でポストフロップを戦う余地を残す」という二段階判断です。

SBR=14 で min-raise を選ぶ手は、push すると 14BB というサイズがやや大きく、コールされたときにエクイティを確定させる前提が崩れる手です。一方で fold するほど弱くもないため、2BB min-raise でポストフロップへ進む価値があります。

**SBR=14 UTG 判断フロー**:

```
score_mtt(h) ≥ 28 → push
score_mtt(h) = 25〜27 → min-raise
score_mtt(h) < 25 → fold
```

## 4-6 UTG1 との差

UTG1 は UTG の直後に位置し、後ろに 6 人がいます。UTG より 1 ポジション有利なため、T_push は UTG より 1〜2 ポイント広く設定されます。

| SBR | UTG T_push | UTG1 T_push | 差 |
|-----|-----------|------------|-----|
| 8   | 22        | 22         | 0   |
| 10  | 25.5      | 24         | 1.5 |
| 12  | 27        | 24         | 3   |
| 14  | 25（open閾値） | 24（open閾値） | 1   |

SBR=8 ではほぼ同じですが、SBR=10〜12 では差が 1.5〜3 ポイント開きます。

UTG1 の push 範囲は UTG より広くなるため、例えば SBR=12 では UTG が fold にしていた KJo（スコア 25）が UTG1 では push になります。ただし、UTG1 も EP であることには変わらないため、BTN や CO に比べれば依然として大幅に tight です。

UTG1 の具体的な push リスト（SBR=12、T_push=24）:

| ハンド | スコア | UTG1 SBR=12 判断 |
|--------|--------|----------------|
| JTs    | 28     | push |
| AJo    | 28     | push |
| KTs    | 27.5   | push |
| ATo    | 27     | push |
| T9s    | 26     | push |
| A9s    | 27     | push |
| KJo    | 25     | push |
| QJo    | 25     | push |
| K9s    | 25     | push |
| ATo    | 27     | push |

UTG1 は UTG では fold だった ATo（スコア 27）や T9s（スコア 26）を push できます。

## 4-7 EP push の実戦フロー

UTG/UTG1 の push 判断をまとめると、以下のフローで処理できます。

**Step 1: ペアかどうか確認**

ペアは最低オープンペア表を参照します（第 3 章参照）。

| SBR | UTG 最低 push ペア | UTG1 最低 push ペア |
|-----|-----------------|------------------|
| 8   | 22+             | 22+              |
| 10  | 44+             | 33+              |
| 12  | 55+             | 44+              |
| 14  | 66+             | 55+              |

**Step 2: 非ペアの場合 score_mtt を計算**

第 1 章の手順で score_mtt を計算します。

**Step 3: SBR と閾値を照合**

| SBR | UTG 判断  | UTG1 判断 |
|-----|----------|----------|
| 8   | score ≥ 22 → push（ただし Ax 優先リスト参照） | score ≥ 22 → push |
| 10  | score ≥ 25.5 → push | score ≥ 24 → push |
| 12  | score ≥ 27 → push | score ≥ 24 → push |
| 14  | score ≥ 28 → push / 25〜27 → min-raise | score ≥ 24 → push / < 24 → fold |

SBR=8 の UTG だけ特殊ルールが必要なことに注意してください。それ以外の SBR では score_mtt と閾値の比較のみで判断できます。

## ミニクイズ

### 問 1

SBR=12、UTG で KTs を持っています。score_mtt を計算し、push すべきかどうか答えてください。

1. スコア 27.5 → push
2. スコア 26.5 → fold
3. スコア 25.5 → fold
4. スコア 28.5 → push

### 問 2

SBR=10、UTG で ATo を持っています。正しい行動はどれですか。

1. fold（T_push=25.5 なので ATo のスコア 27 は push 圏内だが ATo は fold）
2. push（score_mtt=27 ≥ T_push=25.5）
3. min-raise（SBR=10 では min-raise が最善）
4. fold（ATo は常に UTG で fold）

### 問 3

SBR=8 UTG の push 範囲として、正しい説明はどれですか。

1. score_mtt ≥ 22 なら全ハンドを push してよい
2. K8s（スコア 24）と T8s（スコア 24）は score ≥ 22 なので push
3. 「Ax 全手 + KJo 以上 + JTs/QTs + ペア全部」で暗記し、K8s/T8s は fold
4. SBR=8 では push 範囲が最も広く、ほぼ全ハンドを push できる

---

### 解答

- **問 1**: 1（スコア 27.5 → push）
  KTs: H=13, L=10, スーテッド, gap=3。13 + 10 = 23、スーテッドボーナス +5 → 28、gap=3 で -0.5 → **27.5**。SBR=12 UTG の T_push=27 を超えるため push。

- **問 2**: 2（push）
  ATo: H=14, L=10, オフスーツ, gap=4（A なのでペナルティ不適用）。14 + 10 = 24、オフスーツ: L=10 ≥ 10 なので無罰、A-ブロッカー +3 → **27**。スコア 27 ≥ T_push=25.5 なので push。

- **問 3**: 3
  SBR=8 UTG は score=22 が閾値だが、K8s/T8s（スコア 24）など K-medium suited は実際には fold するケースがある。「Ax 全手 + KJo 以上 + JTs/QTs + ペア全部」のリスト暗記が実用的。1 と 2 は K8s/T8s を誤って push させるため不正解。4 は UTG の説明として逆。

---

> **本章まとめ**
>
> - UTG の T_push は SBR=8: 22 → SBR=10: 25.5 → SBR=12: 27 → SBR=14: 25（min-raise 混在）と変化する
> - SBR=8 UTG は「Ax 全手 + KJo 以上 + JTs/QTs + ペア全部」の暗記リストを使う（K8s/T8s は fold）
> - SBR=12 UTG は T_push=27 で精度 95%。KTs（27.5）は push、T9s（26）は fold
> - SBR=14 は移行帯。スコア ≥ 28 は push、25〜27 は min-raise、< 25 は fold の三分割
> - UTG1 は UTG より 1〜3 ポイント広め（SBR=12 で T_push=24）

---

**【GTO とのズレ】**

本章の閾値はすべて chip EV（ICM なし）の GTO Wizard MTTGeneral データを基準にしています。実際のトーナメントでは、ICM 圧力（残りスタック・プライズプール構造）によって EP の push 基準がさらに厳しくなります。

特にバブル局面（ ITM 圏外のプレイヤーが数人残っている状況）やファイナルテーブルのペイジャンプ前後では、UTG での push 範囲を 1〜2 ポイント引き上げる（閾値を厳しくする）ことを推奨します。例えばバブル中盤では、SBR=12 UTG の push 閾値が 27 から 29 程度になる場合があります。この補正は ICM ソフトウェア（GTO Wizard Elite など）で確認できますが、実戦の経験則として「ICM 圧力が高いほど EP は tight に」と覚えておけば十分です。

また、UTG1 との差は SBR が高いほど広がります。SBR=12 では UTG が T_push=27、UTG1 が T_push=24 と 3 ポイントの差があります。同じ Zone P でもポジション 1 つの差が大きいため、UTG か UTG1 かを確認してから閾値を参照してください。8-max テーブルではカット差が特に意味を持ちます。
