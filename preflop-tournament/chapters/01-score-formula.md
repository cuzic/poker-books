# 第 1 章　MTT スコア式

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: MTT 専用スコア式の計算手順を理解し、任意のハンドのスコアを暗算で求められるようになる。

---

## 1-1 キャッシュゲームと MTT で式が変わる理由

本シリーズのプリフロップ編では、キャッシュゲーム向けのスコア式を使っていました。MTT でも同じ式が使えれば話は早いのですが、実際には大きな設計変更が必要です。

最大の差異は**ポットオッズの構造**です。現代の MTT では BB アンテが標準化されており、毎ハンドのポットに「誰も意図して入れていない」死に金が増えています。このためポットオッズが常時改善しており、キャッシュゲームより 3〜4 ポイント広いハンドまで参加価値が生まれます。

もう一点が **K-ブロッカーの無意味化**です。キャッシュゲームのスコア式には K が含まれるハンドへのボーナスがありましたが、MTT の RFI（Raise First In）判断ではブロッカー効果はほぼゼロです。ブロッカーが活きるのは 3-bet 判断や相手のナッツレンジを崩す場面であり、単純なオープン判断には関係しません。GTO Wizard の実測でも、K7s は UTG SBR=25 で高い fold 率を示し、K-ブロッカーを評価した場合の予測と大きく乖離します。

さらに**フェースカードの gap 評価**を精緻化する必要があります。K・Q・J を含むスーテッドハンドは、低ランクカードとのギャップが大きくなっても一定の価値を保つ性質があります。この性質を反映するために、本書のスコア式では K・Q・J ごとに gap のペナルティ上限（gap cap）を導入しました。

これらの設計変更をまとめたのが本書のスコア式です。

---

## 1-2 式の設計工夫

### ペアのボーナスを +12 に設定した理由

ペアスコアを `H + L + 12` としたのは、66 の扱いから逆算しています。
H=L=6 のとき `6+6+12=24`。SBR=25 の UTG 閾値（24）と一致し、
GTO Wizard の実測（66 は UTG SBR=25 で 100% オープン最善）と整合します。

+11 では 24 未満になり 66 が誤フォールドになります。+12 がちょうど境界です。

55（score=22）は閾値 24 を下回るため、式の判定ではフォールドになります。
しかし GTO 実測では約 98% オープンです。この境界例外は後述の注記で補います。

### K/Q/J スーテッドに gap cap を設けた理由

K・Q・J を含むスーテッドハンドは、低ランクカードとのギャップが大きくなっても
ポストフロップでの柔軟性を一定程度保ちます。gap を無制限にペナルティとすると
K5s や J6s などを過小評価することになります。

そこで gap ペナルティに上限（cap）を設けました。

| 高いカード | gap cap |
|---------|---------|
| A       | 0（ペナルティなし） |
| K       | 2 |
| Q       | 3 |
| J       | 4 |
| T 以下  | cap なし（gap 全額） |

offsuit には gap cap を適用しません。offsuit は suited より実現価値が低く、
cap を設けるとオープン範囲が過剰に広がるためです。

---

## 1-3 スコア式の全体像

式の構造はシンプルです。ハンドをペアと非ペアに分けて計算します。

```
ペア:
  score = H + L + 12
  （例: 77 → 7+7+12=26、66 → 6+6+12=24）

suited（スーテッド）:
  score = H + L + 5 - gap_cap + A-ブロッカー(+3)

offsuit（オフスーツ）:
  score = H + L - (L<10 なら -3) - gap + A-ブロッカー(+3)
  ※ gap 計算から A を除外（A を含む hand は gap ペナルティなし）
```

H = 高い方のカードの数値、L = 低い方のカードの数値です。カードの数値は A=14、K=13、Q=12、J=11、T=10、9〜2 はそのままです。

**gap の定義**: gap は「H と L の間に何枚カードが入るか」です。KQ（隣接）は gap=0、KJ（1 枚入る）は gap=1、KT は gap=2 となります。数式では `gap = H - L - 1` です。

---

## 1-4 非ペアの計算手順（5 ステップ）

暗算は次の順番で行います。

### Step 1: H + L を計算

2 枚のカードの数値を足します。

- KJs → 13 + 11 = **24**
- T9s → 10 + 9 = **19**
- AKo → 14 + 13 = **27**

### Step 2: スーテッドなら +5、オフスーツかつ L < 10 なら -3

スーテッド（同スーツ）のハンドには +5 を加えます。

- KJs → 24 + 5 = **29**
- T9s → 19 + 5 = **24**

オフスーツで低い方のカードが 9 以下（L < 10）なら -3 を引きます。L が T（10）以上なら無処理です。

- AKo → L=K=13、L ≥ 10 なので無処理 → **27**
- A9o → L=9 < 10 なので -3 → 27 - 3 = **24**（次に A-ブロッカーを加える）

### Step 3: gap 補正を適用

suited の場合は gap_cap を引きます。offsuit（A 以外）の場合は gap をそのまま引きます。

**suited の gap_cap（上の表を参照）**:

- KJs: gap=1、K → cap=min(1,2)=1 → 29 - 1 = **28**
- T9s: gap=0（連続）、T 以下 → cap=0 → 24 - 0 = **24**
- K8s: gap=4、K → cap=min(4,2)=2 → 13+8+5-2 = **24**

**offsuit（A 以外）の gap**:

- KQo: gap=0、-0 → 24+1 - 0 = そのまま
- KJo: gap=1 → 23（次の小節の計算例を参照）

**A を含む offsuit は gap ペナルティなし**です。

### Step 4: A-ブロッカーボーナスを加算

ハンドに A が含まれる場合、+3 を加えます。

- AKs: A あり → +3（AKs の最終スコアは 35）
- A9o: +3 → 24 + 3 = **27**... 待って、Step 2 で 24 にしたので再計算

改めて整理します：

- A9o: 14+9=23、L=9<10 なので -3 → 20、A あり +3 → **23**

### Step 5: 確認（小カードペナルティの再確認）

offsuit の場合、L < 10 のペナルティは Step 2 で適用済みです。A2s など A ローの suited については A-ブロッカーボーナスがそのまま適用されます（本書のスコア式では A2s のような A-low suited に追加ペナルティはありません）。

## 1-5 計算例 3 つ（境界ハンド）

### 例 1：K8s（UTG 境界の代表例）

```
H=13（K）、L=8、スーテッド
Step1: 13 + 8 = 21
Step2: スーテッド +5 → 26
Step3: gap = 13-8-1 = 4、K → gap_cap = min(4,2) = 2 → 26 - 2 = 24
Step4: A なし → 変化なし
スコア: 24
```

UTG SBR=25 の閾値 24 と同値です。GTO Wizard の実測でも K8s は UTG で 100% オープン。K8s と K7s の間には明確な境界があります。

### 例 2：T9s（コネクターの代表例）

```
H=10（T）、L=9、スーテッド
Step1: 10 + 9 = 19
Step2: スーテッド +5 → 24
Step3: gap = 10-9-1 = 0（連続）、T 以下 → gap_cap = 0 → 24 - 0 = 24
Step4: A なし → 変化なし
スコア: 24
```

### 例 3：KJo（ブロードウェイオフスーツの代表例）

```
H=13（K）、L=11（J）、オフスーツ
Step1: 13 + 11 = 24
Step2: L=J=11 ≥ 10 なのでオフスーツペナルティなし → 24
Step3: gap = 13-11-1 = 1、offsuit なので gap をそのまま引く → 24 - 1 = 23
Step4: A なし → 変化なし
スコア: 23
```

## 1-6 ペアの扱い

ペアはスコア式で閾値比較するのではなく、**最低オープンペア表**を直接参照します。スコア式を使うこともできますが、以下の表を暗記する方が実戦的です。

```
ペアスコア = H + L + 12
AA: 14+14+12 = 40
KK: 13+13+12 = 38
QQ: 12+12+12 = 36
JJ: 11+11+12 = 34
TT: 10+10+12 = 32
99: 9+9+12   = 30
88: 8+8+12   = 28
77: 7+7+12   = 26
66: 6+6+12   = 24
55: 5+5+12   = 22
44: 4+4+12   = 20
33: 3+3+12   = 18
22: 2+2+12   = 16
```

なぜ +12 なのでしょうか。66 のスコアが 24 になることで、SBR=25 の UTG 閾値（24）とぴったり一致します。GTO Wizard の実測でも 66 は UTG SBR=25 で 100% オープンが確認されており、+12 という設計が正確です。

55 は `5+5+12=22` となり、GTO 実測の 98% オープンに対してスコアが閾値をわずかに下回ります。この 55 だけは**例外ハンド**として暗記してください。「55 は UTG でもオープン」が実戦ルールです。

## 1-8 式の精度と境界ハンドの注記

本書のスコア式の精度は全 8 SBR × 全ポジション × 10,478 手の検証で **93.6%** です。

### 主な残差（GTO と乖離するハンド）

残差のほとんどは以下の 2 つのパターンに集中します。

**パターン 1：55（GTO 98% open → 式では 22 で折れる）**

55 だけ、式のスコアが実戦最善手より保守的になります。「55 は UTG でもオープン」と補足ルールで覚えてください。

**パターン 2：KJo・QJo（GTO 境界 → 式では 23 で閾値以下）**

KJo と QJo のスコアは 23 です。SBR=25 の 9-max UTG では閾値 24 をわずかに下回ります。しかし GTO Wizard では KJo・QJo の UTG オープン率は 100% です。これらも補足ルールで「KJo・QJo は UTG でもオープン」と覚えてください。

6-max の UTG では閾値が 22 に下がるため、KJo・QJo（スコア 23）は問題なく閾値を超えます。9-max 専用の注意点です。

### 式の強みと限界

式の強みは「境界ハンドを 1 点単位で正しく分離できる」ことです。K8s（24）と K7s（23）、T9s（24）と 98s（22）などの境界が実測と一致しています。

限界は A を含むオフスーツ弱手（A7o〜A9o など）です。スコア上は閾値付近になりますが、GTO ではほぼ 100% フォールドが最善です。「A を含む offsuit で L が 9 以下は UTG でフォールド」を補足ルールとして持っておくと安全です。

4. A-ブロッカーボーナスが +5 である

### 解答

- **問 1**: 3（24）
  H=13、L=8、suited。13+8=21、+5→26、gap=13-8-1=4、K→cap=min(4,2)=2、26-2=**24**。

- **問 2**: 2
  ペアボーナスが +12、K/Q/J suited に gap cap（K≤2、Q≤3、J≤4）を設定しています。offsuit は gap cap なし。A-ブロッカーは suited/offsuit 共通で +3。

- **問 3**: 2（23）
  H=14（A）、L=9、offsuit。14+9=23、L=9<10 なので -3 → 20、A あり +3 → **23**。gap は A 含む offsuit には適用しません。

---

> **本章まとめ**
>
> - ペアスコア: `H + L + 12`（AA=40、KK=38、66=24、55=22）
> - suited: `H + L + 5 - gap_cap + A→+3`。gap_cap は A=0、K≤2、Q≤3、J≤4、T以下=gap全額
> - offsuit: `H + L - (L<10→-3) - gap + A→+3`。A 含む offsuit は gap ペナルティなし
> - gap の定義は「H − L − 1」（連続ハンドは gap=0）
> - 補足ルール: 55 は UTG でもオープン。9-max UTG の KJo・QJo もオープン
> - 全体精度 93.6%。残差は 55、KJo/QJo（9m UTG）、Axo 弱手（補足ルールで吸収）

---

**【GTO とのズレ】**

本書のスコア式の最大の乖離源は、A を含むオフスーツ弱手（A7o〜A9o）です。スコア式では 21〜23 となり 9-max UTG の閾値 24 を下回るため「フォールド」と判定されます。GTO Wizard の実測でも UTG SBR=25 でほぼ 100% フォールドが確認されており、式の判定と実測が一致しています。ただし HJ 以降の後期ポジションでは閾値が下がるため、A7o〜A9o がオープン圏に入る場面も出てきます。ポジションごとの閾値は第 3 章（9-max Zone O）と第 7 章（6-max Zone O）で扱います。

もう一つの注意点は 55 と KJo/QJo の扱いです。これらは式の上では閾値付近または閾値以下になりますが、GTO では UTG でもオープンが最善です。本書では「補足ルール」として明示していますが、実戦では式のスコアだけを信じて折らないように注意してください。

本書の閾値はすべて chip EV 最大化（ICM なし）の前提で設計されています。バブル付近やファイナルテーブルのペイジャンプ前後では、ICM 圧力によって最適なオープン範囲が保守方向にずれます。第 12 章以降の ICM 編でこの補正を扱いますが、本章の数値は「通常局面の基準値」として位置づけてください。
