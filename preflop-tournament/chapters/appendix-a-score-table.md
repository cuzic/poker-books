# 付録 A: MTT スコア早見表

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **使い方**: ハンドのスコアを素早く確認するための参照表です。スーテッドとオフスーツを別表にしています。行が H（高い方のカード）、列が L（低い方のカード）です。ペアは別表で掲載しています。スコアを閾値と比較してオープン可否を判断します。

---

## A-1 スコア式フォーミュラ（要約）

```
ペア:
  score = H + L + 12
  例: 77 → 7+7+12 = 26、66 → 6+6+12 = 24

suited（スーテッド）:
  score = H + L + 5 - gap_cap + A-ブロッカー(+3)
  gap_cap: A→0 / K→min(gap,2) / Q→min(gap,3) / J→min(gap,4) / T以下→gap全額

offsuit（オフスーツ）:
  score = H + L - (L<10 なら 3) - gap + A-ブロッカー(+3)
  ※ A を含む hand は gap ペナルティなし
```

H = 高い方のカードの数値、L = 低い方のカードの数値（A=14、K=13、Q=12、J=11、T=10、9〜2 はそのまま）。gap は「H と L の間に何枚カードが入るか」（例: KJ → gap=1、KT → gap=2）。

## A-2 T_open 閾値一覧（SBR=25）

スコアをこの閾値と比較してオープン可否を判断します。

| ポジション | T_open | 対象ハンドの目安 |
|-----------|--------|----------------|
| UTG       | 24     | QQ 以上（ペア）、または AQs/AJs/KQs 以上（非ペア） |
| HJ        | 20     | 66 以上（ペア）、または A9s/KJs 以上 |
| CO        | 19     | 55 以上（ペア）、または A8s/K9s 以上 |
| BTN       | 16     | 22 以上（ペア）、または A2s/K2s 以上 |
| SB        | 22     | 77 以上（ペア）、または ATs/KTs 以上 |

ペアは式で求めたスコアと閾値を比較しますが、小ペア（55〜22）の実戦的な扱いは付録 B の最低オープンペア表も参照してください。

## A-8 ポジション別オープン可能ハンド一覧（参照用）

### UTG（T_open = 24）

**suited（スコア ≥ 24）**: AKs〜A2s（35〜24）、KQs〜K9s（30〜25）、QJs・QTs（28・26）、JTs（26）、T9s（24）
**offsuit（スコア ≥ 24）**: AKo〜ATo（30〜27）、KQo（25）のみ

UTG suited の境界: T9s（24）が下限、98s（22）は NG。K8s（24）はギリギリ可。
UTG offsuit の境界: ATo（27）が Ax の下限（A9o=23 は NG）、KQo（25）が K 系で唯一可。

### HJ（T_open = 20）

**suited に追加**: K8s以下（K9s までは UTG 可）→ K6s（22）まで。Q9s以下→ Q7s（21）まで。J9s（24）以下→ J7s（20）まで。T9s（24）〜 T7s（20）まで。98s（22）・97s（20）・87s（20）が追加
**offsuit に追加**: KTo（21）・KJo（23）・QJo（23）・QTo（21）・JTo（21）が追加

### CO（T_open = 19）

suited に追加: Q6s（20）・J6s（18、NG）→ Q6s まで。T6s（18、NG）→ T7s（20）が下限。96s（18、NG）→ 97s（20）が下限。K5s（21）まで追加。

### BTN（T_open = 16）

**suited（スコア ≥ 16）**: K2s（18）以上すべて。Q2s（16）。J2s（14、NG）→ J3s（15、NG）→ J4s（16）まで。T5s（16）。98s〜96s（22〜18）。87s〜85s（20〜16）。76s〜75s（18・16）。65s（16）
**offsuit（スコア ≥ 16）**: Ax 系はすべて（A2o=16 が下限）。K9o（16）。Q9o（16）。J9o（16）・T9o（16）。KQo〜KTo（25〜21）

---

> **付録 A まとめ**
>
> - ペアは H+L+12 で求め、閾値と比較します。66（スコア=24）が UTG の境界です
> - suited は gap_cap により K〜J 高のスコアが安定します（T 以下は gap 全額）
> - offsuit は L<10 で -3 が入るため、L=9 のハンドでスコアが急落します
> - A 高 suited はすべて A-ブロッカー +3 のため BTN より深いポジションでも幅広く使えます
> - K9o（16）・J9o（16）・T9o（16）が BTN の境界ハンド群です
> - ATo〜A9o 間（27 → 23）、KTo〜K9o 間（21 → 16）にスコアの断絶があります
