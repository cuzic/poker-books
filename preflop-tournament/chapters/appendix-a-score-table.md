# 付録 A: MTT スコア v4 早見表

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **使い方**: ハンドのスコアを素早く確認するための参照表です。スーテッド（同スーツ）とオフスーツ（異スーツ）を別表にしています。行が H（高い方のカード）、列が L（低い方のカード）です。ペアはスコア計算不要のため、別途ペアスコア表を設けています。

---

## A-1 v4 フォーミュラ（要約）

```
非ペア:
  基本       : H + L
  スーテッド  : +5
  オフスーツ  : -3（L < 10 のみ。KJo/ATo/QJo など L≥10 は無罰）
  gap=1      : +2
  gap=2      : +1
  gap=3      : -0.5
  gap=4      : -1.5 / gap=5 : -2 / gap≥6 : -3（A 以外）
  A-ブロッカー: +3（L≤3 はさらに -2）
  低カード補正: H<9 かつ L<9 → -1

ペア（スコア計算不要）:
  H + L + 10（AA は +3, KK は +2 追加）
```

gap は「H − L」で計算します（例: AK は 14−13=1 なので gap=1）。A を含む手は gap ≥ 4 のペナルティを適用しません。

## A-5 主要閾値との対応（UTG SBR=25）

T_open=22.5 を基準に、スーテッドハンドの可否を確認できます。

**スーテッドで UTG オープン可（スコア ≥ 22.5）**:
- Ax 系: AKs, AQs, AJs, ATs, A9s, A8s, A7s, A6s, A5s, A4s（以上スコア 22 以上。A3s/A2s は 23/22 で境界付近）
- Kx 系: KQs, KJs, KTs, K9s, K8s（以上スコア 24 以上）。K7s（22）は T_open=22.5 をわずかに下回り **fold**
- Qx 系: QJs, QTs（30/28）。Q9s（25.5）以上 OK。Q8s（23.5）以上 OK
- Jx 系: JTs（28）, J9s（26）以上 OK
- Tx 系: T9s（26）, T8s（24）以上 OK。T7s（21.5）は **fold**
- 小スーテッド: 98s（24）, 97s（22）, 87s（21）以下は fold

**オフスーツで UTG オープン可（スコア ≥ 22.5）**:
- AKo（32）, AQo（30）, AJo（27.5）, ATo（27）
- KQo（27）, KJo（25）, KTo（22.5）（境界）
- QJo（25）, QTo（23）, JTo（23）
- A9o（23）は式上では超えるが GTO では fold（Axo 弱手問題）

---

> **付録 A まとめ**
>
> - スーテッド表（78 手）とオフスーツ表（91 手）で全 169 手をカバー
> - ペアはスコア計算不要。付録 B の最低オープンペア表を直接参照
> - 式の限界: Axo 弱手（A9o〜A5o）はスコアが高くても EP では fold
> - K7s（スコア 22）は UTG T_open=22.5 をわずかに下回る境界ハンド
> - 0.5 刻みのスコアは四捨五入せず正確に使う（境界判断に影響する）
