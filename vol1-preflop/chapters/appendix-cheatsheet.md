# 付録　チートシート（1 枚）

## スコア式

```
Score = H + L
      + pair_bonus    （ペア）
      + suit_bonus    （スーテッド）
      − min(gap, gap_cap)
      + a_bonus       （A-high）
```

## 係数

| | pair | suit | gap_cap | a |
|---|---|---|---|---|
| **Cash** | **13** | **7** | **4** | **4** |
| **MTT** | **19** | **7** | **5** | **5** |

Cash → MTT の変化: **pair +6** のみです（他はほぼ同じです）

|---|---|---|

## オープナー vs 3-bet

| 判断 | 閾値 |
|---|---|
| 4-bet | **Score ≥ 37** |
| コール | **31 ≤ Score < 37** |
| フォールド | **Score < 31** |

---

## スクイーズ（マルチウェイ）

```
T_squeeze = T_3bet（vs オープナー） + 3 × N_callers
```

N_callers = オープナー以外でコールした人数です。BB defense の `T_3bet` 列を使います（vs UTG=36 / HJ=34 / CO=30 / BTN=28）。

**例**: BB スクイーズ vs UTG open + BTN cold call (N=1) → T_squeeze = 36 + 3 = **39**

## 暗記必須 境界ハンド（混合戦略帯）

GTO が混合戦略を取り、公式の予測が外れやすい 17 ハンドです（Cash 6-max）。閾値に近いので暗記をおすすめします。

**BB vs BTN open（T_call=18 周辺）**: K2s, Q4s, J6s, T6s, 96s, 86s, 75s, 54s, J7o, T8o
**BB vs CO open（T_call=20 周辺）**: K4o, Q7s, J8s, T8s, 98o
**SB RFI（T_open=22 周辺）**: A2o, K7o

これら 17 ハンドは「Score ± 1〜2 で判定が逆転する」帯です。本文 ch11 を参照してください。
