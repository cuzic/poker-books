# 付録　チートシート（1 枚）

## スコア式

```
Score = H + L
      + pair_bonus    （ペア）
      + suit_bonus    （スーテッド）
      − min(gap, gap_cap)
      + a_bonus       （A-high）
```

## 係数

| | pair | suit | gap_cap | a |
|---|---|---|---|---|
| **Cash** | **13** | **7** | **4** | **4** |
| **MTT** | **19** | **7** | **5** | **5** |

Cash → MTT の変化: **pair +6** のみ（他はほぼ同じ）

## BB defense 補助ルール

スーテッドハンドの T_call を **−2** する（より広くコール）

## ICM 補正（T_open への加算）

| フェーズ | 補正 |
|---|---|
| ChipEV | ±0 |
| PCT50 | +1 |
| PCT25 / Bubble | +1〜2 |
| FT | +1〜2 |

## 9max 補正

T_open を **+1** する（全ポジション共通）

## 次に読む書籍

本書でプリフロップの判断を体系化したら、次はポストフロップへ進みましょう。

**Postflop の戦略を学ぶには:**

- **Vol2 (Cash + 簡易版)**: Cash 100bb での暗算可能な Light UCBS / DCBS。HP・DP・CBS の 3 値で 5〜7 秒以内に cbet / 守備を判定します。
- **Vol3 (MTT + 精緻版)**: MTT 全 depth (25〜200bb) と 3-bet ポットを完全カバーする Full UCBS-v2 (13 context)。

**推奨学習ルート:**

| プレイスタイル | 学習順序 |
|---|---|
| Cash プレイヤー | Vol1 → **Vol2** → (Vol4 エクスプロイト) |
| MTT プレイヤー | Vol1 → **Vol3** → (Vol4 エクスプロイト) |
| 両方やる | Vol1 → Vol2 → Vol3 → Vol4 |

Vol2 で使う HP / DP / CBS / 型 1〜7 の概念は、本書第 12 章 12.5 節で先取り定義しています。
