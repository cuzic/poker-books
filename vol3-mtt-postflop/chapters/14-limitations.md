# 第14章 苦手領域と限界——MTT 100bb とストレート完成 turn

UCBS-v2 はすべての状況を同精度で予測できるわけではありません。
本章では WRMSE 20%+ の context を率直に示し、精度が低い理由と実戦での対処法を解説します。
限界を知ることがフレームワークを正しく使う第一歩です。

## 精度帯の分布——WRMSE が示す信頼性マップ

UCBS-v2 の 13 context と DCBS の 4 context の精度（WRMSE）を帯別に整理します。
WRMSE（Weighted Root Mean Square Error）は予測頻度と GTO 実測値の差を重み付きで測った指標です。
値が小さいほど精度が高く、GTO に近い予測ができます。

| 精度帯 | 目安 | 該当 context |
|---|---|---|
| **< 10%（極良）** | 誤差 10pt 以内 | mtt_3bp_50bb（8.62%）、mtt_25bb_turn_btn（7.02%） |
| **10-15%（良）** | 誤差 15pt 以内 | mtt_50bb（12.96%）、mtt_3bp_100bb（13.37%）、mtt_200bb（14.10%）、mtt_50bb_turn（14.44%）、mtt_25bb（15.46%） |
| **15-20%（許容）** | 誤差 20pt 以内 | cash_100bb（16.43%）、cash_turn（16.11%）、mtt_3bp_25bb（18.65%） |
| **20%+（注意）** | 誤差 20pt 超 | mtt_100bb（21.95%）、mtt_3bp_20bb（23.08%）、mtt_100bb_turn（26.95%） |

全体の平均 WRMSE は約 16% です。
「注意」帯の context は方向判断の参考とし、exact な頻度値には依存しないことを推奨します。

## MTT 100bb の wide cbet 問題

mtt_100bb（WRMSE 21.95%）は MTT depth 系列の中で唯一の「注意」帯 context です。

精度が低い根本原因は **MTT6mSimple tree の wide cbet 特性**にあります。
GTO Wizard の Simple tree では 100bb 付近において以下の現象が起きます。

1. **サイズが 2 択のみ**: Simple tree は 33% と 116% の 2 サイズしか許容しません。このため GTO は「どちらか一方に大きく振る」極端な頻度配分になります。
2. **100bb で wide cbet 顕著**: 100bb 付近では「中程度の強さのハンドでもほぼ 33% でベット」という傾向が現れ、通常の polarize 戦略と異なります。
3. **UCBS-v2 の CBS 構造と不整合**: CBS に基づいてハンドを弁別する UCBS-v2 に対し、「ほぼ全ハンドで bet」という wide cbet パターンは構造的に合いません。

**実戦での対処策**:

- 計算結果の頻度値を「bet か check か」の**方向判断**にのみ使う
- 40-60% の計算結果が出た場合は「どちらでも良い（mixed）」と判断する
- mtt_50bb（WRMSE 12.96%）や cash_100bb（16.43%）と比較して感覚を補正する
- WRMSE ±21pt を意識し、60% の計算結果は「39%-81% の範囲」として解釈する

## ストレート／フラッシュ完成 turn の特殊性

ターン turn context（Tier 4）の中でも、特定のターンカードが来た場合に精度が大きく下がります。

| ターンカード | ボード例 | WRMSE | 理由 |
|---|---|---:|---|
| 通常のターン | Ks7d2c → 9h | 3-5% | UCBS-v2 が良好に適合 |
| **ストレート完成** | KJT → Q（Q でストレート完成） | **28%** | Q で全 hand の相対評価が逆転 |
| **ストレート完成** | T98r → 7（7 でストレート完成） | **19%** | 7 でミドル hand が激変 |

ストレート完成ターンで精度が落ちる理由は、UCBS-v2 が **HP テーブルを静的**に参照するためです。

通常の HP テーブルでは top_pair = HP 7、set = HP 8 ですが、
ストレート完成ターンでは「ストレートを持つかどうか」が戦略の支配的な要因になります。
この「ハンド評価の逆転」は現行の HP/DP テーブルでは対処できません。

**フラッシュ完成ターン**も同様の問題が発生します（3 枚同スーツ → 4 枚同スーツ）。
ただし UCBS-v2 では turn context に mono_conf_down フラグがないため、
フラッシュ完成ターンの特殊処理は現状のフレームワーク外です。

**実戦での対処**: ストレート/フラッシュ完成ターンカードが来た場合は UCBS-v2 を信頼せず、
GTO のデフォルトである「完成役なら check、ミスした手は bet」の基本に立ち返ることを推奨します。

## フレームワーク外の状況——スコープと注意点

UCBS-v2 および DCBS が**対象外**とする状況を明示します。
これらの状況では本書のフレームワークを直接適用できません。

| 状況 | 理由 | 代替アプローチ |
|---|---|---|
| **マルチウェイポット（3人以上）** | 全 context がヘッズアップ前提。相手が複数いると頻度が大きく変わる | ハンドレンジを引き絞り、バリューハンドのみ bet |
| **OOP からの bet（donk bet / lead）** | UCBS-v2 は IP cbet 専用、DCBS は BB defense 専用 | Vol2 ch05 の OOP defense フレームワークを参照 |
| **SB vs BB（BTN open なし）** | pos_lift は BTN/CO/HJ/UTG/SB の 5 種で設計されているが、SB は OOP cbet として特殊 | SB lift を適用しつつ WRMSE に大きめの余裕を持つ |
| **ターン以降の 3rd barrel** | Tier 4 はフロップ → ターンの 2nd barrel まで。リバーへの 3rd barrel は未対応 | Vol4/Vol5 のリバー章を参照 |
| **リンプポット** | 全 context が raise-first-in または 3-bet pot 前提 | スモールポットとして保守的な判断をする |

これらスコープ外の状況は読者が混乱しやすい点です。
本書の UCBS-v2 は「BTN/CO/HJ/UTG IP cbet + BB defense（ヘッズアップ）」の
**フロップ〜ターン**に特化した精緻なツールです。
範囲を超えた使い方は精度保証の対象外となることを必ず認識してください。

## Light vs Full の trade-off——Vol2 への誘導

Full UCBS-v2（本書）と Light UCBS v2（Vol2）の使い分けをまとめます。

| 比較項目 | Light UCBS v2（Vol2） | Full UCBS-v2（本書 Vol3） |
|---|---|---|
| Context 数 | 5（Cash/MTT-short/MTT-deep/3BP/Turn） | 13（depth 別 4 種 + 3BP 4 種 + Turn 4 種 + Cash） |
| 暗記数値 | 共通 18 + 25 セル = **43 数値** | 共通 18 + 13×6 = **96 数値** |
| 計算ステップ | CBS → band → base (5 context) | CBS → conf → dir → size → base → 5 補正 |
| 苦手領域 | MTT depth の細かい差が出ない | 同上 + mtt_100bb 精度低 |
| 推奨シーン | 実戦でのクイック判断・初学者 | 詳細スタディ・context 別の深い理解 |

MTT 序盤（100bb）は両フレームワークとも精度が低め（Light: mtt_deep も 100bb を含むため）です。
この領域では Light と Full の差が小さく、Vol2 の Light フレームワークで十分な場合があります。

**推奨**: MTT 序盤（100bb 付近）の実戦では Vol2 の Light UCBS v2（mtt_deep context）を使い、
スタディ目的で Full UCBS-v2 の 100bb context と比較する、という使い分けが実用的です。

## まとめ：UCBS-v2 の限界認識 4 ポイント

本章の要点を 4 点にまとめます。

1. **WRMSE 20%+ context は 3 つ**: mtt_100bb（21.95%）、mtt_3bp_20bb（23.08%）、mtt_100bb_turn（26.95%）。これらは方向判断のみに使う。
2. **100bb 精度低の根因は MTT6mSimple**: wide cbet 特性が CBS 構造と合わない。50bb や 200bb を参照して補正する。
3. **ストレート/フラッシュ完成ターンは別処理**: KJT+Q（WRMSE 28%）、T98r+7（19%）など完成役ターンでは UCBS-v2 の信頼性が大きく低下する。
4. **スコープはヘッズアップ IP cbet + BB defense**: マルチウェイ・OOP bet・リバーはフレームワーク外。別途対処が必要。
