# vol4 MTT ポストフロップ：本書スコープ宣言

*Task #18 / 設計フェーズ / 2026-05-22*

本書「迷わないポーカー vol4 MTT ポストフロップ」は中級者が **暗算で回せる判断フロー** を提供することを目的とします。そのため、扱う範囲を以下に明示し、対象外の領域は別書または将来版に委ねます。

---

## 1. 本書がカバーする範囲（スコープ内）

| 軸 | 範囲 |
|---|---|
| ゲーム形態 | MTT（マルチテーブルトーナメント）、BBアンテあり |
| 人数 | 6-max を基本（9-max も SBR 換算で流用可） |
| ポット形態 | **SRP（シングルレイズドポット）** = HU フロップ |
| 関与人数 | **HU（ヘッズアップ）2-way** |
| SBR | **10〜40+**（SPR≈3〜10+） |
| ストリート | フロップ・ターン・リバー |
| ポジション | IP（BTN/CO）vs OOP（BB/SB）が主軸 |
| ステージ | 序盤・中盤・バブル・FT（ICM 補正で表現） |

---

## 2. 本書がカバーしない範囲（スコープ外）

### 2-1. マルチウェイ（3人以上の関与）

- **理由**: マルチウェイの GTO 解は 2-way の 3〜5 倍の解析時間と暗記量を必要とし、「暗算で回せる判断フロー」という本書の設計思想に合いません。
- **代替**: 第11章で **暗算用の補正ルール**（コミット HS +10〜15、ブラフ CBet 禁止）のみ提示し、深掘りはしません。詳細解は別書または vol2 のマルチウェイ章を参照。
- **読者への指示**: マルチウェイに直面したら「コミット閾値を 1 段引き上げる」ことだけ覚えれば実戦は十分回ります。

### 2-2. 3BP（3ベットポット）ポストフロップ詳細

- **理由**: 3BP は SPR が極端に浅く（SBR20 で SPR≈2、SBR15 で SPR≈1.4）、判断軸が「コミット or 降り」の 2 値に潰れます。SRP のフレームワークと別系統で論じるには情報量が不足し、また第10章で要点を 1 章にまとめれば十分です。
- **代替**: 第10章「3BP ポストフロップ」で **コミットラインの 1 段引き下げ（SPR2-3: HS≥30）** と **CBet サイズ縮小（小サイズ or 全イン）** のみ提示します。
- **読者への指示**: 3BP に直面したら「SRP の SPR を半分にした」と思って、コミット閾値を 1 段下げて打てば十分です。

### 2-3. SBR<10（Very Short Stack）

- **理由**: SBR<10 ではフロップでベットすると事実上オールインとなり、「ベットサイジング選択」が消えます。プリフロップで決着すべき場面が大半で、postflop 専書での扱いは限定的になります。
- **代替**: 第6章「Very Short」で **「TP 以上はコミット、それ以外はチェック/フォールド」の 1 ルール** のみ提示します。
- **読者への指示**: SBR<10 になったらプリフロップで Push/Fold を決め切る方針が正解です（vol3 参照）。

### 2-4. 4BP（4ベットポット）

- **理由**: 4BP は SBR=20 で SPR≈1 を切り、フロップ着地でほぼ全イン確定です。判断要素がないため本書では扱いません。
- **対応**: 4BP に到達したら「フロップ着地 = 全イン」とだけ覚えれば実戦は十分です。

### 2-5. SB vs BB（リンプ・コール・3ベット）の特殊系

- **理由**: 6-max での SB vs BB は頻度として高くなく、また OOP/IP の主役は BTN/CO vs BB です。
- **対応**: 既存章で BTN vs BB の枠組みを SB vs BB にも適用可能と明記し、別章は設けません。

## 3. スコープ判断の優先順位

本書の章立てで「どこに踏み込むか」を判断するときの基準：

1. **読者が実戦で遭遇する頻度** が高い → 含める
2. **判断フローが暗算可能** か → 暗算不可なら省略
3. **vol2 / vol3 のフレームワーク再利用** で済むか → 再利用可なら省略（参照のみ）
4. **GTO データで明確な答え** が出るか → 出なければ「+X 引き上げ」程度に丸める
