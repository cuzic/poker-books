# SB vs BB シナリオ設計（フロップ＋ターン）

*Task #4/#10/#24/#25 改訂 / 新フレームワーク準拠 / 2026-05-22*

対象: vol4 MTT ポストフロップ
preflop_actions: `F-F-F-F-F-F-R3-C`（SBR25 / SBR20）
役割: **SB = OOP 先手** / **BB = IP 守備**
フロップポット: 約 7 BB（SB open 3 BB + BB call 2 BB + ante 2 BB）
SPR 目安: SBR25 → 約 7.5 ／ SBR20 → 約 5.7

---

## 新フレームワーク（本書統一の判断式）

本シナリオも `framework.md` の **3 軸統合式** に従います。

```
hand_equity  ≥  required_equity  →  ベット / コール
hand_equity  <  required_equity  →  フォールド（セミブラフ除く）

required_equity  =  α(b)  +  ICM 補正  +  ポジション補正

α(b):       1/4=17%  1/3=20%  1/2=25%  2/3=29%  pot=33%
ICM 補正:   序盤 0  中盤 +4  バブル +10  FT +15
ポジ補正:   IP -2  OOP +2
```

ハンドカテゴリ（5 分類）:

| カテゴリ | 例 | フロップ equity | 行動の動機 |
|---------|----|----------------|-----------|
| **Nutted** | セット / 2 ペア / overpair / TPTK | 70%+ | バリューベット |
| **Thin value** | TP 弱 K / 2nd pair / underpair | 50–65% | **保護ベット**（時間とともに equity 下落） |
| **SDV** | 3rd pair / 中位ポケット / 強 A-high | 40–50% | 安くショーダウン狙い、チェック |
| **Semi-bluff** | FD (36%) / OESD (32%) / FD+GS (48%) | 30–60% | フォールド equity と equity 実現 |
| **Air** | バックドアすら無し | <20% | フォールド or プロテクトブラフ |

> **SB の特殊性**: SB は **OOP** ですが、フロップでアクションを先に取れる（preflop で raiser だったため）。よって「フロップ CBet で主導権を維持する／チェックで BB に主導権を譲る」の選択が IP CBet とは性質が違います。

## F01S: SB CBet（SBvsBB フロップ）

### 状況判断: SB の特殊事情

SB は OOP のため、**保護ベットの重要性が IP より高い**:
- BB は IP として実現率 +5–10% の優位を持つ → Thin value がチェックされると BB に有利な選択肢を与える
- SB の Nutted は薄く（A 比率が BTN より低い）、Thin value 中心のレンジ → 「打たないと損する」プレッシャーが強い

| カテゴリ | 例 | 行動の動機（SB 視点） |
|---------|----|--------------------|
| Nutted | overpair / TPTK | バリュー＋プロテクション |
| Thin value | TPMK / 2nd pair / underpair | **保護ベット必須**: OOP 実現不利を相殺 |
| SDV | 3rd pair / 中位ポケット | チェック多め、ただし型6/7 はベット混合 |
| Semi-bluff | FD / OESD / FD+GS | レンジバランスのためベット混合 |
| Air | — | チェック or レンジ防衛ブラフ |

### 必要エクイティ（自分が CBet するとき）

SB は OOP のため、「自分がベットする」場合の hand_equity 閾値は IP より高くなります（ポジション補正 OOP +2%）。

| サイズ | α | ICM 中盤 (+4%) | OOP 補正 (+2%) | 合計 |
|--------|---|----------------|---------------|------|
| T1=20% (b=0.2) | 14.3% | 18.3% | 20.3% | **20.3%** |
| T2=33% (b=0.33) | 19.9% | 23.9% | 25.9% | **25.9%** |
| T3=75% (b=0.75) | 30.0% | 34.0% | 36.0% | **36.0%** |

→ Nutted (70%+) と Thin value (50%+) はどちらも全サイズで超過。SDV (40–50%) は T1=20% でぎりぎり可、T3 では不可。

### GTO データ要約

| ボード型 | SB CBet% SBR25 | SB CBet% SBR20 | 主要サイズ SBR25 | 主要サイズ SBR20 |
|---------|--------------:|--------------:|-----------------|-----------------|
| 型1 ハイドライ Ks7d2c | 66 % | **80 %** | 33 %（25%超） | 33 %（53%） |
| 型2 ハイウェット Qh8d3s | 65 % | 70 % | 33 % | 33 %（42%） |
| 型3 ロードライ Jd7s5c | 61 % | **49 %** | **100 %（22%）** | **75 %（30%）** |
| 型4 ローウェット Th9s8d | 60 % | **35 %** | 20 % | 20 %／75% mix |
| 型5 モノトーン Ah9h5h | 60 % | 78 % | 20 % | **20 %（57%）** |
| 型6 ペア高 AsAcKd | 66 % | **87 %** | 20 % | **20 %（56%）** |
| 型7 ペア低 7s7d2c | **76 %** | 80 % | 33 % | **33 %（56%）** |

**カテゴリ別ベット率（SBR25）の解釈**:

| 型 | Nutted bet | Thin value bet | Air bet | 解釈 |
|----|-----------|----------------|---------|------|
| 型1 | 77/88% | 64/80% | 62/77% | Nutted+Thin value で約 70%、Air はレンジ防衛で 60%+ |
| 型2 | 78/79% | 62/71% | 62/67% | 同上、ウェット気味で全体的に小さい |
| 型3 | 77/65% | 59/52% | 55/41% | **Thin value が弱い**（OOP 実現不利大）→ チェック増 |
| 型4 | 76/56% | 45/19% | 59/32% | **Thin value 殆ど打てない**（CR リスク） |
| 型5 | 76/88% | 57/77% | 58/75% | レンジ全体で薄ベット |
| 型6 | — | 59/86% | 69/87% | Air もレンジで強気（A 板で BB の弱 A を fold させる） |
| 型7 | 82/83% | 86/95% | 75/79% | **Thin value 過剰打ち**（オーバーペア・underpair が CR バリューに） |

**観察**:
- SBR20 で多くの板で CBet 頻度が**上がる**（型1/型5/型6/型7）。SPR が浅いと OOP が pot をコミット気味に取りに行く（保護ベット強化）。
- 例外は型3/型4 → SBR20 ではむしろ**チェック多用**（BB の CR が増える＆実現価値が落ちる）。
- 型6 ペア高はバリュー薄い前提の**超ハイ頻度 CBet**（87% @SBR20）。レンジ全体が前進。

### 決定フロー（3 ステップ）

#### Step 1: ハンドカテゴリ → equity 推定

ウェット板（型2/4/5）は equity × 0.85 補正、ドライ（型1/3/6/7）はそのまま。

#### Step 2: required_eq を算出

中盤（SBR20）、自分が T2=33% pot で CBet する場合:
```
required_eq(IP fold equity 期待) ≈ α(0.33) + ICM = 19.9 + 4 = 23.9%
hand_equity 閾値 ≈ α + ICM + OOP補正 = 19.9 + 4 + 2 = 25.9%
```

#### Step 3: equity ≥ required_eq か？

```
IF Nutted (≥70%): 全板で 75%+ ベット
ELIF Thin value (50–65%):
   型1/2/5/6/7 → 保護ベット（70%+）
   型3/4 → **チェック寄り**（CR リスク＋OOP 実現不利、equity 下落が早い）
ELIF SDV (40–50%):
   型6/型7 → ベット混合（ペア板で fold equity 取れる）
   他 → チェック
ELIF Semi-bluff (32–48%):
   レンジバランスで混合（型6 で 87%、型3 で 41% などばらつき）
ELIF Air (<20%):
   型6/型7 → レンジ防衛ベット
   他 → チェック
```

### サイズの板別ロジック

| ボード型 | 推奨サイズ | 暗算根拠 |
|---------|----------|----------|
| 型1/型2（ハイ系） | **33% pot** | 二重ターゲット（強板で広く小サイズ） |
| 型3/型4（ロー系） | **チェック多用＋大きく打つときは 75%** | コネクト板は OOP 不利→ポラライズ |
| 型5（モノトーン） | **20% pot** | レンジ全体を薄く |
| 型6（ペア高） | **20% pot** | ナッツ希少＝blocker bet |
| 型7（ペア低） | **33% pot** | ペアが希少＝強気でレンジベット |

### SPR 補正

- **SPR ≥ 6（SBR25 相当）**: 上表のとおり
- **SPR < 6（SBR20 相当）**:
  - 型1/型5/型6/型7 → **頻度 +10〜+25%**（保護ベット強化、コミット気味）
  - 型3/型4 → **チェック寄り**（型4 は CBet 35% まで落ちる）

### BTN vs BB との主要差分

| 観点 | BTN vs BB | SB vs BB |
|------|-----------|----------|
| CBet 全頻度 | 平均 78% | 平均 66% |
| 型3 ロードライ | 53%（IP） | **61%（OOP）** ※OOP のほうが高い |
| 型1 ハイドライ | 80%（IP） | 66%（OOP） |
| サイズ感 | ハイ系 33%、ロー系も 33% 中心 | **ロー系で 75〜100% 大サイズが増える** |
| BB Fold | 平均 45% | 平均 **20%**（call が多い） |
| BB CR | データなし | **平均 9%**（型3 で 18%） |

**核となる差分**:
1. **BB の防御が桁違いに固い**（fold 20% vs 45%）。理由: SB レンジ全体が BTN より弱い & ポット 7BB vs 5.5BB で BB のオッズが良い。
2. **CR が出る**（特に型3 ロードライで 18%）。BTN vs BB ではほぼゼロ。
3. **ロー板の SB はサイズをポラライズ**: 大きく打つかチェックの 2 択（中間サイズが消える）。

### 暗記ポイント（3 つ）

1. **SB の CBet は BTN より 10〜15% 低い**（66% vs 78%）。BB の防御が固いことを忘れない。
2. **ロー板（型3/型4）は SBR20 でチェック寄り**（型4 は 35% まで落ちる）。Thin value の保護ベットが equity 不足。
3. **ペア板（型6/型7）は SBR20 で頻度爆上げ**（86〜87%）。20% pot のレンジ薄ベットでナッツ威圧。

## F02S: BB defense（SBvsBB フロップ守備）

### 状況判断: BB は IP defender

BB は IP で「fold / call / CR」の 3 択。SB のレンジが BTN より弱いため、required_eq が低く設定でき、**フォールド頻度が下がります**。

| カテゴリ | 行動 | 理由 |
|---------|------|------|
| Nutted (TP+) | call または CR | 板により CR コア（型3=49%, 型4=22%） |
| Thin value | **call 90%+** | required_eq 20% を equity 50–65% で楽勝 |
| SDV | call（型7 例外で CR） | プロテクションコール |
| Semi-bluff (FD/OESD) | call 主体、CR 候補 | equity 32–36% で MDF 達成 |
| Air | fold 30–37% | required_eq 20% に届かない |

### 必要エクイティ（コール側、IP 補正 −2%）

| サイズ | α | ICM 中盤 (+4%) | IP 補正 (−2%) | 合計 |
|--------|---|----------------|--------------|------|
| T1=20% | 14.3% | 18.3% | 16.3% | **16.3%** |
| T2=33% | 19.9% | 23.9% | 21.9% | **21.9%** |
| T3=75% | 30.0% | 34.0% | 32.0% | **32.0%** |

→ BB は IP のため、required_eq が SB より低い。Thin value 全部 + SDV 上端 + Semi-bluff 全部がコール圏。

### GTO データ要約

| ボード型 | BB Fold% SBR25 | BB Call% SBR25 | BB Raise% SBR25 | F% SBR20 | C% SBR20 | R% SBR20 |
|---------|--------------:|--------------:|---------------:|---------:|---------:|---------:|
| 型1 ハイドライ | 19 | 74 | **7** | 20 | 80 | 0 |
| 型2 ハイウェット | 19 | 73 | **8** | 19 | 78 | 2 |
| 型3 ロードライ | 18 | 64 | **18** | 19 | 63 | **18** |
| 型4 ローウェット | 22 | 67 | **11** | 23 | 65 | **12** |
| 型5 モノトーン | 23 | 77 | 1 | 23 | 77 | 0 |
| 型6 ペア高 | 22 | 77 | 1 | 23 | 77 | 0 |
| 型7 ペア低 | 16 | 71 | **13** | 17 | 73 | 10 |

> **MDF と整合**: SB の 33% pot CBet に対する MDF = 75%（fold ≤25%）。実 fold% は 16–23% で MDF 達成。**範囲全体のコール傾向が IP（BTN）defense 比でかなり広い**。

### カテゴリ別防御（SBR25 抜粋、HS バケット）

| 型 | Nutted Call/Raise | Thin value Call/Raise | Air Fold/Call/Raise |
|----|------------------|----------------------|--------------------|
| 型1 | 84 / 16 | 96 / 4 | 32 / 63 / 5 |
| 型3 | **51 / 49** | 84 / 16 | 30 / 59 / 11 |
| 型4 | 78 / 22 | 90 / 10 | 37 / 54 / 9 |
| 型7 | 88 / 12 | **29 / 71** | 18 / 73 / 9 |

### 決定フロー（3 ステップ）

```
Step 1: ハンドカテゴリ → equity 推定
Step 2: required_eq = α + ICM - 2(IP補正)
        T2=33%、中盤 → 19.9 + 4 - 2 = 21.9%
Step 3: equity ≥ required_eq か？
        Nutted (70%+) → CR 候補 or call
        Thin value (50–65%) → 楽勝 call
        SDV (40–50%) → call（型7 例外で CR）
        Semi-bluff (32–48%) → call、強FD は CR ブラフ候補
        Air (<20%) → fold
```

### CR 板の識別（重要）

**CR を発生させるべき板**:
- 型3 ロードライ Jd7s5c（Nutted→49% CR）→ オーバーペア（AA/KK/QQ）＋セット
- 型4 ローウェット Th9s8d（Nutted→22% CR）→ オーバーペア＋強ドロー
- 型7 ペア低 7s7d2c（**Thin value→71% CR**）→ オーバーペア（プロテクション）

> **型7 の特殊性**: SB の CBet レンジには A-high が多く、BB のオーバーペア（88+）は equity 70%+ の **相対 Nutted** に昇格。Thin value 帯から CR される異常値。

**CR を出さない板**:
- 型5 モノトーン → ほぼゼロ（リドロー困難）
- 型6 ペア高 → ほぼゼロ（SB レンジに AK/AQ が多い）

### BTN vs BB との主要差分

| 観点 | BTN vs BB | SB vs BB |
|------|-----------|----------|
| 全体 Fold | 平均 45% | 平均 **20%** |
| CR | データ無（IP想定） | 平均 **9%**、型3 で 18% |
| 型6 ペア高 | F=67% | **F=22%** |
| 型7 ペア低 | F=44% | **F=16%** |

**差分の理由**:
1. **ポット 7BB vs 5.5BB**（BB のオッズが良い→required_eq 低い）
2. **SB レンジが BTN より弱い**（BTN は 45% range、SB は raise-only ~24%＋mix）
3. **CR の脅威**（BB が後手なので、CR でレンジ全体に圧をかけられる）

### 暗記ポイント（3 つ）

1. **BB は SB のフロップに対しほぼ降りない**（fold 平均 20%）。Thin value 以上は call 確定、Semi-bluff も大半 call。
2. **CR は 3 板で出す**: 型3（Nutted から）、型4（Nutted から）、**型7（Thin value から！）**
3. **モノトーン／ペア高では CR なし**（純粋にコール一択）

## T01S: SB バレル（ターン）

### 状況判断: ターンで equity がどう変わるか

ターンは「ハンドカテゴリの軌跡」が変わる重要ストリート。**ターンカードによって自分のカテゴリが昇格／降格する**ことを最初に評価します。

| ターンカード型 | カテゴリ変動 | 例 |
|-------------|------------|-----|
| **TA+**: ペア追加/ナッツ完成 | Thin value → Nutted | K72r → 7 turn でセカンドペア→セット |
| **Blank**: 変化なし | カテゴリ維持、equity 自然下落 | K72r → 4 turn |
| **TA−**: オーバーカード/ドロー完成 | Nutted → Thin value、Thin value → SDV | K72r → A turn で BB の Ax が刺さる |

### 必要エクイティ（ターンバレル側、OOP 補正 +2%）

| サイズ | α | ICM 中盤 (+4%) | OOP 補正 (+2%) | 合計 |
|--------|---|----------------|---------------|------|
| T2=50% | 25.0% | 29.0% | 31.0% | **31.0%** |
| T3=75% | 30.0% | 34.0% | 36.0% | **36.0%** |

→ ターンでは pot が大きく、required_eq も上がる。Nutted (70%+) と Thin value (50–65%) の上端のみがバレル EV+。SDV (40–50%) と Semi-bluff は equity が「微妙」になる。

### GTO データ要約（ブランクターン）

`mtt_sb_bb_SBR{25,20}.json` の各レコードは「ブランクターン 1 枚」のみ収録（例: K72r flop → 4h turn）。よってターン継続バレルは **TA フレームワーク**（vol4 共通）を SB vs BB 用に校正して使う。

参考: `mtt_turn_barrel_*.json` は BTN vs BB（IP）データ。SB は OOP のため**頻度はやや下げる**が、トリガー条件は流用可能。

`mtt_turn_barrel_SBR25.json` 型1（Ks7d2c → 4h ブランク）で BTN IP の barrel が **1.2%（=チェック）**、ペア化（7h）で **78%**、OC（Ah）で **0%**。OOP（SB）はさらにブランクで打たない傾向が強い。

### 決定フロー（3 ステップ）

#### Step 1: ターンカードの TA 分類

```
TA+ ターン:
  - フロップ最高カードのペア化（K72 → K turn）
  - 自分のセカンドペアをセット化（K72 → 7 turn で 77）
  - ナッツドローの完成（FD ナッツ持ち時のフラッシュ完成）

TA− ターン:
  - オーバーカード（K72 → A turn）
  - 連携ストレート完成（J95 → 8 turn）

Blank ターン:
  - 上記以外（K72 → 4 turn など）
```

#### Step 2: ハンドカテゴリの更新

ターンカードでハンドカテゴリを再判定:
- フロップで Thin value (TPMK) → TA+ で Nutted、TA− で SDV、Blank で Thin value 維持（ただし equity は -5%）
- フロップで Semi-bluff (FD) → ターンで完成すれば Nutted、ハズレで Air

#### Step 3: equity ≥ required_eq か？

```
TA+ ターン:
  Nutted (70%+) → バレル 75%+
  Thin value (50–60%) → 保護バレル 50%
  Air → セミブラフ＋ドロー (FD+GS=48%) で打つ

Blank ターン:
  Nutted → バレル 50%（小サイズ）
  Thin value → **チェック多用**（equity 下落で required_eq に届かない）
  Air → チェック

TA− ターン:
  Nutted → 小サイズ or チェック（pot コミット回避）
  他 → チェック
```

### ハンドフィルター（SB OOP 特化）

| カテゴリ | TA+ ターン | Blank | TA− ターン |
|---------|-----------|-------|-----------|
| Nutted (≥70%) | **打つ 75%+** | **打つ 50%（小サイズ）** | **小サイズ or チェック** |
| Thin value (50–65%) | **打つ 50%** | **チェック多用** | **チェック** |
| Semi-bluff (32–48%) | **二枚目バレル** | **チェック** | **チェック（断念）** |
| SDV/Air | チェック | チェック | チェック |

### SB 固有の調整

- **OOP なので頻度は IP 比 −10〜−15%**
- **ターンサイズ: 50% pot 基準**（IP の 75% より小さく）
- **CR 守備**: BB のターン CR は SBR25 で 10% 超 → バリューは大きく、ブラフは諦め

### BTN vs BB との主要差分

1. **頻度は SB の方が低い**（OOP のため）
2. **サイズも小さめ**（50% 中心 vs IP の 75%）
3. **TA− ターン（オーバーカード）でほぼ完全に諦める**（IP より早く撤退）

### 暗記ポイント（3 つ）

1. **TA+ で打つ／TA− で諦める** は IP 同様。ただし SB はサイズを 1 段小さく。
2. **ブランクターンは Nutted のみ継続**（Thin value は equity 下落で fold equity 取れず）。
3. **BB の CR 警戒**: ターン CR を食らったらブラフは全捨て、Nutted も TPTK 未満は降りる。

## T04S: SB Probe（フロップで X-X 後のターン）

### 状況判断: X-X line が示唆するもの

フロップで「SB チェック → BB チェック」となった後のターンで SB が先手で打つベット。BB がチェックバックしたということは、BB のレンジは **強くない**（強ければ IP でバリューベット）。

| BB チェックバック後の BB レンジ推定 | 構成 |
|--------------------------------|------|
| Air | 大量（チェックは BB の主戦略） |
| SDV (third pair など) | 一部 |
| Thin value 中位 | 少量 |
| Nutted | ほぼ無し（フロップで bet していた） |

→ ターン SB probe は**「BB の Air を fold させる」セミブラフ＋「BB の SDV/Thin value 下端を悲鳴的に降ろさせる」二段構え**。

### 必要エクイティ（probe 側）

ターンで pot ≈ 7BB、20% bet → 1.4BB。BB の必要 fold% = 20/(100+20+20) = 14.3% → α=14.3%。
中盤 OOP 補正で hand_equity 閾値 ≈ 14.3 + 4 + 2 = **20%**。

→ Nutted/Thin value 全部 + SDV/Semi-bluff の一部が probe EV+。

|---------|---------------:|---------------:|-----------|
| 型1 ハイドライ | 31 | 38 | 20% |
| 型2 ハイウェット | 23 | 29 | 20% |
| 型3 ロードライ | 23 | 31 | 20% |
| 型4 ローウェット | **39** | **41** | 20% |
| 型5 モノトーン | 38 | 28 | 20% |
| 型6 ペア高 | **59** | **56** | 20% |
| 型7 ペア低 | 34 | 46 | 33% |

**HS バケット別 probe（SBR25）**:

| 型 | Nutted | Thin value | Air |
|----|-------:|-----------:|----:|

### 決定フロー（3 ステップ）

#### Step 1: 「フロップ X-X」が示唆するもの

- BB は強くない（強ければターン IP でリードする局面ほぼ無し）
- SB のレンジはチェックしたぶん相対的にマージナル中心

#### Step 2: ハンドカテゴリ → equity 推定

X-X 後は **両者のレンジが弱体化**。SB の Thin value は実質「相対 Nutted」に近い equity を持つ。

#### Step 3: equity ≥ required_eq (20%) か？

| ボード型 | 推奨 | 理由 |
|---------|------|------|
| 型6 ペア高 | **必ず probe**（59%）。20% pot | BB の弱 K/9 オフを刈る。Air もブラフ |
| 型4 ローウェット | **probe 推奨**（39〜41%） | OESD/FD ターン化で Semi-bluff が EV+ |
| 型7 ペア低 | **probe**（特に SBR20 で 46%） | BB レンジに 2nd pair が少なく、Nutted+Thin value 強気 |
| 型1/型2/型3 | **二重ベット**: Nutted は probe、Thin value/Air は様子見 | 構造的にバリュー薄 |
| 型5 モノトーン | **抑え気味**（SBR20 で 28%） | フラッシュ完成リスクで required_eq 高 |

### 暗記ポイント（3 つ）

1. **型6 ペア高は SB probe の最優先板**（59%、20% pot）。BB のミドル～弱ペアを刈る。
2. **probe サイズは 20% pot が基本**（型7 のみ 33%）。required_eq 20% を最小化するため。
3. **モノトーンは probe 控えめ**（後ろにフラッシュ補完される）。

## T05S: BB Delayed CBet（フロップ X-X 後のターン、BB が先手）

### 状況判断: BB が IP として再度先手を取る局面

フロップ「SB チェック → BB チェック」→ ターン「SB チェック」→ **BB が先手**で bet/check の選択。

BB はフロップでチェックバックを選んでいるため、レンジは**ほぼ Air + SDV + 少量の Thin value**。Nutted ならフロップで bet していたはず。

### 必要エクイティ（BB DCBet 側）

| サイズ | α | ICM 中盤 (+4%) | IP 補正 (−2%) | 合計 |
|--------|---|----------------|--------------|------|
| 20% | 14.3% | 18.3% | 16.3% | **16.3%** |
| 33% | 19.9% | 23.9% | 21.9% | **21.9%** |

低 required_eq でも、BB レンジの **大半が Air** なので、頻度自体は低い（打てる手がそもそも少ない）。

### GTO データ要約

| ボード型 | BB DCBet% SBR25 | BB DCBet% SBR20 | 主要サイズ |
|---------|---------------:|---------------:|-----------|
| 型1 ハイドライ | 8 | 6 | 20% |
| 型2 ハイウェット | 7 | 7 | 20% |
| 型3 ロードライ | 7 | 12 | 33% |
| 型4 ローウェット | **11** | **17** | 33% |
| 型5 モノトーン | 11 | 5 | 20% |
| 型6 ペア高 | **13** | 5 | 20% |
| 型7 ペア低 | 7 | 9 | 20% |

**HS バケット別 DCBet（SBR25）**: 全板で Nutted 88%+、Thin value 80%+、Air 80%+。**頻度の母数は小さいが、打つときは強い**（レンジ全体が Air で薄められているため、Value 比率は高い）。

### 決定フロー（3 ステップ）

#### Step 1: 全体頻度の理解

BB の delayed CBet は **平均 9% と低い**。打てる手が少ない（フロップで Nutted は bet していた）。

#### Step 2: 「打つときの基準」

X-X line でターンに賭けるべき条件:
1. **明確な Value がある**（top pair 以上）
2. **板の構造が変化**（型4 ローウェットでターンで構造が変わったなど）
3. **BB のレンジが SB より強い**（型6 ペア高で BB の Ax レンジ優位）

#### Step 3: 板別の指針

| ボード型 | 指針 |
|---------|------|
| 型4 ローウェット | **DCBet 推奨**（17% @SBR20）。OESD/FD 完成で打つ。33% pot。 |
| 型6 ペア高 | **DCBet 推奨 SBR25**（13%）。BB が AK でトップキッカー有り。 |
| 型1/型2/型5/型7 | **抑制**（5〜8%）。チェックバック多用。 |

### ハンドフィルター

| カテゴリ | DCBet 比率 | 行動 |
|---------|-----------|------|
| Nutted (TP+) | 80–90% | 積極的にバリュー |
| Thin value | 大半チェック（80%+） | equity 微妙、レンジ全体で薄ベット |
| SDV | チェック | プロテクト不要、ショーダウン |
| Air | チェック（型4/型6 で稀にブラフ） | レンジ防衛 |

### 暗記ポイント（3 つ）

1. **BB DCBet は基本「打たない」**（平均 9%）。チェックバック前提。
2. **打つのは型4/型6**（17% / 13%）。他は 10% 以下。
3. **打つときは Nutted 主体**（Thin value 以下は 80%+ チェック）。

## 全体まとめ: SB vs BB の意思決定フレームワーク

### フロップ（SB OOP 先手）

1. **CBet は BTN 比 −10〜−15%**（平均 66%）。BB の defense が固いため、required_eq の整合性で頻度が落ちる。
2. **サイズは板で決まる**:
   - ハイ系（型1/2/5/6）→ 20〜33% pot
   - ロー系（型3/4）→ 75% pot or check（ポラライズ）
   - ペア板（型6/7）→ 20% pot（blocker bet）
3. **BB はほぼ降りない**（fold 平均 20%）→ BB の required_eq は IP 補正 −2% で 16–22%、Thin value 以上は楽勝コール。
4. **BB の CR を 3 板で警戒**: 型3（Nutted→49%）、型4（Nutted→22%）、型7（**Thin value→71%**）

### ターン（X-X 後の駆け引き）

| シナリオ | 頻度 | サイズ | 適用条件 |
|---------|-----:|-------|---------|
| T01S（SB バレル）| TA+ で打つ | 50% pot | Nutted+Thin value 上端、ブランクは Nutted のみ |
| T04S（SB probe）| 30〜60% | 20% pot | 型6 最優先、型5 控えめ |
| T05S（BB DCBet）| 5〜17% | 20–33% | 型4/型6 のみ、Nutted 主体 |

### SPR 補正サマリ

- **SBR25（SPR≈7.5）**: 基本値どおり
- **SBR20（SPR≈5.7）**:
  - ハイ系/ペア板の CBet **頻度 +10〜+25%**
  - ロー系の CBet **頻度 −15%**（CR リスク大）
  - probe/DCBet は **微増**（pot 取り合い）

### 暗記すべき差分（BTN vs BB との比較）

1. **fold 半分**（45%→20%）→ BB の required_eq が低い
2. **CR 出現**（型3/型4/型7）→ BB の Nutted/Thin value 上端は CR コア
3. **ロー板でポラライズサイズ**（75%／チェックの 2 択）→ Thin value の保護ベットが不可能
4. **ペア板で頻度爆上げ**（SBR20 で 86〜87%）→ Air のレンジ防衛で全体的に薄ベット

- Thin value: second_pair / underpair
- SDV: third_pair / low_pair
- Semi-bluff: FD/OESD/FD+GS（HS バケットでは ace_high/king_high + draw 判定）
- Air: ace_high / king_high / queen_high / no_made_hand / high_card（ドローなし）
