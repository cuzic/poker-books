# サイジング決定ロジック（横断・最優先）

*Task #13 / 設計フェーズ / 2026-05-22 / 統一フレームワーク改訂版*

本書全体で **「何 % ベットするか」** を **「ハンドカテゴリ × 目的」** の 2 軸で決める標準フロー。`designs/framework.md` の統一判断式 `hand_equity ≥ α(b) + ICM補正` を前提に、サイズは **目的（バリュー回収／フォールドエクイティ獲得）から逆算** します。

---

## 1. 設計思想の転換

### 1-1. 旧ロジック（ボード型 × HS × SPR）

ボード型でサイズを固定し、HS と SPR で微調整していた。GTO 整合は取れるが、**「なぜそのサイズか」が説明されない**。

### 1-2. 新ロジック（カテゴリ × 目的）

ハンドの **5 カテゴリ**（Nutted / Thin value / SDV / Semi-bluff / Air）と **ベットの目的** からサイズを逆算する：

| カテゴリ | equity | 目的 | 必要サイズ |
|---------|--------|------|-----------|
| **Nutted** (70%+) | 相手レンジ全体に EV+ | 最大バリュー回収 | 大（2/3〜pot） |
| **Thin value** (50〜65%) | 相手の弱いレンジだけに EV+ | 薄バリュー＋プロテクト | 中（1/3〜1/2） |
| **SDV** (40〜50%) | ショーダウンで勝てる | チェック主体 | （ベットしない） |
| **Semi-bluff** (30〜40%) | フォールドエクイティ獲得 | α ＞ 相手 fold で採算 | 中〜大（1/2〜2/3） |
| **Air** (<20%) | レンジ防衛で混合 | ブラフ採算 | 中（1/2） |

> **核心**: サイズは **「最も多く呼んでもらうサイズ × カテゴリ目的」** で決まる。Nutted が大きく打てるのは「相手の弱いレンジでも降ろさず呼ばせたい」から。Thin value が小さく打つのは「相手のさらに弱いハンドだけから取りたい」から。

## 2. 基本サイズ 4 種（暗算用ラベル）

| ラベル | サイズ | α（コール必要 eq） | 用途 |
|-------|--------|---------------------|------|
| **S（Small）** | 25〜33% | 17〜20% | Thin value / ハイドライ merged |
| **M（Medium）** | 50% | 25% | Semi-bluff 標準 / Nutted ターン |
| **L（Large）** | 67〜75% | 29〜30% | Nutted フロップ / ブラフリバー |
| **OB（Over-bet）** | 100〜150% | 33〜38% | リバー Nutted / 強ポラ |

> 暗算用に **S / M / L / OB の 4 択** だけ覚えれば十分。

---

## 3. ストリート × カテゴリ × サイズ標準表

### 3-1. フロップ

| カテゴリ | 推奨サイズ | 理由 | GTO 検証 |
|---------|-----------|------|---------|
| Nutted | **L (67%)** | 相手の Thin value/SDV/Air を全部呼ばせる | overpair/TP 91% bet |
| Thin value | **S (33%)** | 相手の SDV/Air だけから取る、Nutted から CR 食らわない | 2nd pair 76% / underpair 72% |
| SDV | チェック | equity 確保、降ろされたくない | 3rd pair 58% bet（M 多め） |
| Semi-bluff | **M (50%)** | α=25% > Air fold 期待値、equity bonus 込み | Ahigh+BD 69% |
| Air | **M (50%)** または check | レンジ防衛、merged サイズに合流 | no_made_hand 79% |

> **なぜサイズが目的で決まるか**: Nutted を S で打つと「相手の Air までコール採算（α=20% < Air equity 15%）」となり、薄い手から取り損ねる。逆に Thin value を L で打つと相手の Nutted のみコールしてきて負ける（リバース・インプライド）。

### 3-2. ターン

| カテゴリ | 推奨サイズ | 理由 |
|---------|-----------|------|
| Nutted | **M (50%)〜L (67%)** | フロップで広く呼ばれたレンジから引き続き取る |
| Thin value | **S (33%)** | リバーで巻き返される前に小さく取る |
| SDV | チェック | リバーまで生かす |
| Semi-bluff | **L (67%)** | フォールドエクイティ最大化、α=29% で相手の SDV を降ろす |
| Air（純ブラフ） | **L (67%)** | semi-bluff と同サイズで撹乱 |

> **ターンの特徴**: フォールドエクイティが目的の Semi-bluff は **フロップより大きく** 打つ。リバー到達時の equity 実現率が下がるため、ターンで降ろし切る価値が上がる。

### 3-3. リバー

| カテゴリ | 推奨サイズ | 理由 |
|---------|-----------|------|
| Nutted | **L (75%)〜OB (pot+)** | equity ≈100%、最大バリュー、ブラフ捕獲 |
| Thin value | **S (33%)〜M (50%)** | 薄バリュー、相手の SDV から取る |
| SDV | チェック・コール | バリューベットしない |
| ブラフ（旧 Semi-bluff のミス完成） | **L (75%)〜OB** | α=30〜38% でバリューとサイズ揃える、ポラライズ |

> **暗算ルール**: 「リバーは **ポラライズなら L／OB、マージナルなら S／M**」。ブラフはバリューと同サイズで打つことが鉄則。

Thin val  S(33%)   S(33%)   S-M

## 5. ボード型補正（旧ロジックからの継承）

ボード型は **「カテゴリの出現頻度」を変える** ため間接的にサイズ分布に影響する：

| ボード型 | Nutted/Thin の出現傾向 | サイズ分布の傾向 |
|---------|---------------------|---------------|
| 型1 ハイドライ | merged、Thin value 多い | **S 主体**（Thin が支配） |
| 型2 ハイウェット | Nutted と Air が両極化 | S 多め、Nutted は L |
| 型3 ロードライ | IP がレンジ優位、Air 多い | **L 主体**（ポラ化、Deep のみ） |
| 型4 ローウェット | Semi-bluff 多発 | M 主体 |
| 型5 モノトーン | Nutted vs Air の二極 | M 主体（A♥ブロッカー有無で頻度分け） |
| 型6 ペア高 | Air 多い、Nutted 厚 | S 主体 |
| 型7 ペア低 | Air 多い | S 主体 |

> **ボード型はサイズを直接決めない**。カテゴリの構成比を介して間接的に決まる。

---

## 6. SPR 補正（コミット圏での収束）

SPR が浅くなるとサイズの選択肢が **「中庸 → 両極」** に収束する。これは framework.md の `required_equity = α(b) + ICM` 式で α が大きくなるほど Semi-bluff の採算が厳しくなるため：

| SPR | 採用カテゴリ | サイズ傾向 |
|-----|------------|-----------|
| ≥8 (Deep) | 全カテゴリ機能 | カテゴリ別早見表通り |
| 5-6 (Middle) | Semi-bluff 縮小 | **M に集約**（カテゴリ識別が薄れる） |
| 3-4 (Short) | Nutted / Air の二極 | M-L または AI |
| <2 (Very Short) | コミット or check | **AI のみ** |

> **暗算ルール**: 「SPR が浅いほどサイズの選択肢が消える」。

---

## 7. ICM ステージ補正

`framework.md` の ICM 補正は **サイズではなく頻度（カテゴリ選択）** に効く：

| ステージ | サイズ変更 | 頻度変更 |
|---------|----------|---------|
| 序盤 | なし | 標準 |
| 中盤 | なし | Air ブラフ -10% |
| バブル | なし | Air ブラフ -30%、Thin value -20% |
| FT | なし | Air ブラフ -50%、Thin value -40% |

> **理由**: ICM 補正は **コール側の required_equity** を上げる（バブル +12%、FT +20%）。攻撃側はサイズを変えずに **ブラフ頻度を削減** することで EV を最大化する。

---

## 8. サイジング決定フロー（暗算用 5 ステップ）

```
1. 自分の手のカテゴリを判定（Nutted/Thin/SDV/Semi-bluff/Air）
2. 早見表（節 4）から基本サイズを取得
3. SPR で集約（Middle 以下なら M、VeryShort なら AI）
4. ICM ステージで頻度補正（バブル以降は Air ブラフ削減）
5. ボード型は最終確認（カテゴリと矛盾しなければ早見表通り）
```

## 10. OOP のチェックレイズサイズ

CR サイズは **OOP のカテゴリ** から決まる：

| OOP カテゴリ | CR 頻度（vs 33% bet） | CR サイズ |
|------------|---------------------|----------|
| Nutted (TP+) | 59% | 3〜3.5x |
| Thin value (2nd pair) | 26% | 3x |
| SDV | 14%（混合） | 3x |
| Semi-bluff (Ahigh+BD) | 13% | 3〜3.5x |
| Pure Air | 12%（バランス） | 3.5x |

> CR は **「Nutted + Air」の二極** で構成。サイズは 3〜3.5x ベットで統一（カテゴリで分けない）。

## 11. 例外規則（覚えておく価値あり）

### 11-1. セット（Nutted 内のサブカテゴリ）はサイズが特殊

GTO 実測で **セットだけ bet 頻度 63%**（他の Nutted は 90%+）。**スローレイ → ターンで取り返す** ことが多く、サイズも S を混ぜる：

```
セットの目的: ターン以降の implied odds 確保
→ フロップ S (33%) または check
→ ターンで L で取り返す
```

### 11-2. モノトーン板（型5）は A♥ブロッカーで分ける

サイズ統一（M 33-50%）だが、頻度を **A♥ 持ちなら 98%、A♥ なしなら 50%** と分ける。これはブロッカー × カテゴリの相互作用：

- A♥ あり = ナッツブロッカー（Semi-bluff/Air 寄り）→ 高頻度ブラフ
- A♥ なし = Thin value 主体 → サイズ S（薄バリュー）

### 11-3. SPR<2 は「ベット = オールイン」

サイズ選択がなくなる。**check or AI の 2 値**。カテゴリでの分岐も Nutted (push) / Air (check) に二極化。

## 12. 旧 HS 閾値との対応

旧サイジング表は「カテゴリの代用品」として再解釈：

| 旧サイズ判定（HS） | 新カテゴリ | 推奨サイズ |
|-----------------|----------|-----------|
| HS≥65 → L | Nutted | L |
| HS 50-64 → M | Thin value | S |
| HS 35-49 → check | SDV | check |
| HS<35 + 強FD → M | Semi-bluff | M-L |
| HS<35 → check or bluff | Air | M (merged) または check |

> **整合**: 旧 L (75%) → Nutted、旧 M (50%) → Semi-bluff、旧 S (33%) → Thin value という対応。ボード型は **カテゴリ分布の代用** だった。
