# フロップ CR 後のターン継続ロジック（OOP equity judgment）

*Task #17 / 設計フェーズ / 2026-05-22 / 統一フレームワーク改訂版*

OOP がフロップで CR（チェックレイズ）し、IP がコールした後の **ターン継続戦略** を `hand_equity ≥ α(b) + ICM補正` の判断式で再定式化します。CR を通した OOP は **ハンドカテゴリが Nutted/Air に二極化** しており、ターンの判断は「CR 後のレンジ内 hand_eq」を起点に行います。

---

## 1. 設計思想の転換

### 1-1. 旧ロジック（バレルスコア継承）

```
継続スコア = TA + ハンドカテゴリ補正
≥7 で継続、≤4 でギブアップ
```

→ ハンドのカテゴリ補正は付けていたが、**「なぜそのカテゴリで継続するか」が equity 単位で説明されない**。

### 1-2. 新ロジック（CR 後の equity judgment）

```
CR を通した後の OOP の hand_eq:
  バリュー CR を通した → Nutted（hand_eq 70%+）
  ブラフ CR を通した → Air（hand_eq <20%）

ターンでの判断:
  hand_eq ≥ required_eq(α + ICM) → ベット継続
  hand_eq < required_eq           → チェック・降り（ブラフは諦め）
```

→ **CR レンジの二極化**（merged-polar）が新フレームと完璧に整合。

---

## 2. CR-continuation の前提シナリオ

| 項目 | 内容 |
|------|------|
| ストリート | フロップ CR → IP コール → ターン |
| ポジション | OOP（BB/SB）がアクション主導 |
| ポット形態 | SRP（3BP では CR 自体が稀） |
| SBR/SPR | SBR≥20（SPR≈6+）が主対象 |

> SBR<20 では CR 自体が封印（merged レンジ + 浅 SPR）されるため、本ロジックは Deep/Middle 専用。

---

## 3. フロップ CR レンジ（vol2 から引き継ぎ）

OOP のフロップ CR レンジは大きく 2 系統（merged-polar 構造）：

### 3-1. バリュー系（Nutted カテゴリ）

| ハンド | フロップ hand_eq | カテゴリ |
|--------|----------------|---------|
| トップセット | 90%+ | Nutted |
| ミッドセット | 85%+ | Nutted |
| ボトムセット | 80%+ | Nutted |
| ツーペア | 75% | Nutted |
| オーバーペア (QQ+) | 75% | Nutted |
| ナッツFD + TP（コンボ）| 60% | Nutted（実現高）|

### 3-2. ブラフ系（Semi-bluff/Air カテゴリ）

| ハンド | フロップ hand_eq | カテゴリ |
|--------|----------------|---------|
| GS + BD-FD | 22% | Semi-bluff |
| BD-FD + オーバーカード | 18% | Semi-bluff |
| ナッツブロッカー (A♥A♣型) | 10% | Air |
| 単純な BD | 15% | Air |

CR 後のターン継続は **「Nutted がポット維持・拡大、Air がギブアップ」** の二極化が原則。

---

## 4. CR 通過後の equity 再評価

### 4-1. CR を通した相手レンジの想定

IP が CR にコールしてきたレンジ：
- Nutted (TP+/オーバーペア)
- 強ドロー（ナッツFD）
- セット以上

→ IP のレンジは hand_eq 50%+ の手で構成（fold equity 大）。

### 4-2. OOP の hand_eq（CR 通過後）

| OOP の手 | CR 前 hand_eq | CR 通過後 hand_eq | カテゴリ更新 |
|---------|--------------|-----------------|------------|
| セット | 90% | 80%（強いレンジ vs ） | Nutted 維持 |
| ツーペア | 75% | 65% | Nutted 下限 |
| オーバーペア | 75% | 60% | Thin value 上位 |
| ナッツFD + TP | 60% | 55% | Thin value |
| GS+BD ブラフ | 22% | 15% | Air |
| 単純ブラフ | 10% | 5% | Air |

> **ポイント**: Nutted は CR 通過後も Nutted（70%+ 維持）。Air は Air（<20% のまま）。Thin value（オーバーペア等）が **境界線で判断が難しい**。

---

## 5. ターン継続フロー（暗算用）

```
1. ターンカードを観察
2. ターン後の hand_eq を更新（カテゴリ）
3. ターンで required_eq = α(継続サイズ) + ICM + ポジション補正(+2 OOP) を算出
4. hand_eq ≥ required_eq → ベット継続
5. hand_eq < required_eq → チェック（または降り）
```

---

## 6. ターン継続の判断式（カテゴリ × ターンカード）

### 6-1. ターンカードによる hand_eq の変動

| ターンカード | Nutted (CR通過) | Thin value | Air |
|------------|---------------|-----------|------|
| ペア化（フロップにペア追加） | 維持（80%）| 微低下（55%） | 維持（5%） |
| ブランク（既存維持） | 維持（80%）| 維持（60%） | 維持（10%） |
| FD 完成 | 微低下（75%） | 低下（45%） | 上昇（20%、FD あれば） |
| SD 完成 | 微低下（75%） | 低下（45%） | 上昇（20%、SD あれば） |
| オーバーカード（A/K） | 微低下（75%） | 大幅低下（35%）| 上昇（15-20%） |

### 6-2. CR 後の標準ターンサイズと required_eq

CR 後のターンベットサイズ（節 7）と中盤での required_eq（OOP +2%）：

| サイズ | α | ICM(+3) | OOP(+2) | required_eq |
|--------|---|---------|---------|-------------|
| M (50%) | 25% | 28% | **30%** | 30% |
| L (75%) | 30% | 33% | **35%** | 35% |
| AI（残スタック≤pot）| 33-50% | 36-53% | **38-55%** | 38-55% |

### 6-3. ターン継続判定（中盤、M サイズ、req=30%）

| カテゴリ | hand_eq | M (req 30%) | L (req 35%) | AI (req 45%) |
|---------|---------|-------------|-------------|--------------|
| Nutted (CR通過、80%) | 80% | 継続 | 継続 | 継続 |
| Thin value (60%) | 60% | 継続 | 継続 | 継続（ボーダー） |
| Air (5-20%) | 5-20% | ブラフ採算次第 | ブラフ採算次第 | ブラフ非採算 |

> **観察**: Nutted/Thin value は **ターンで常にベット継続**。Air はサイズ次第で「IP が降りる確率」とのトレードオフ。

## 7. ターン継続サイズ

### 7-1. SBR × CR 後のサイズ表

| SBR | フロップポット | ターン残スタック | 推奨サイズ | 理由 |
|-----|-------------|---------------|-----------|------|
| 30+ | ≈12BB | ≈53BB | **M (50%)** | SPR=4.5 → Nutted で薄バリュー回収 |
| 25  | ≈12BB | ≈43BB | **M (60%)** | SPR=3.5 → M-L 境界 |
| 20  | ≈12BB | ≈33BB | **L (75%)** | SPR=2.7 → コミット予告 |
| 15  | ≈12BB | ≈23BB | **AI** | SPR=1.5 → 全イン受容 |

> **暗算ルール**: 「SBR が浅いほど大サイズ・最終的に AI」。

### 7-2. バリュー vs ブラフでのサイズ統一

- Nutted・Air ともに **同じサイズ** を使う（polarized レンジ）
- サイズで分けると相手に情報が漏れる
- 例外: 「ナッツ vs ナッツ近辺」のみオーバーベット検討
  - 理由: Nutted で hand_eq 95%+、required_eq に大幅な余裕

## 9. IP（CR を受けた側）の対応

CR 後のフロップで IP がコールした場合のターン対応：

### 9-1. IP のコールレンジ

CR にコールするハンド（hand_eq ≥ required_eq）：
- TP 以上（hand_eq 50%+）→ Thin value/Nutted
- ナッツドロー（強FD/OESD）→ Semi-bluff
- セット以上 → Nutted（CR コール後にスローレイ含む）

### 9-2. ターンでの IP 判断（OOP がバレルしてきた場合）

| IP のカテゴリ | hand_eq | OOP M バレル (req 30%) | OOP L バレル (req 35%) | OOP AI (req 45%) |
|------------|---------|----------------------|----------------------|------------------|
| Nutted (TPTK+) | 70%+ | コール/レイズ | コール | コール |
| Thin value (TP) | 50-65% | コール | コール（タイト）| フォールド |
| Semi-bluff（ドロー）| 30-40% | コール（ボーダー）| フォールド | フォールド |

### 9-3. OOP がチェックしてきた場合の IP

| IP のカテゴリ | アクション |
|------------|----------|
| Nutted | M〜L でバリューベット |
| Thin value | M で薄バリューベット（OOP の Air を降ろせる）|
| SDV | チェックバック |

> **暗算ルール**: 「CR コール後の Thin value は基本コール、Semi-bluff はターンで降り受容」。

---

## 10. ICM 補正（CR-continuation）

### 10-1. ステージ別 OOP の継続判断（M バレル、SBR≥25）

| ステージ | required_eq (M バレル、OOP+2) | Nutted 継続 | Thin value 継続 | Air ブラフ採算 |
|---------|---------------------------|-----------|---------------|-------------|
| 序盤 | 27% | 100% | 95% | 100% |
| 中盤 | 30% | 100% | 90% | 95% |
| バブル | 39% | 90%（薄バリューはチェック） | 70% | 50% |
| FT | 47% | 70%（バリューでもチェック可） | 30% | 0% |

> **暗算ルール**: 「バブル以降は CR-continuation の Thin value とブラフを大幅削減」。

### 10-2. なぜ バブル/FT でバリューも控えるか

- バブル時の required_eq = 39%（M バレル）
- Thin value（hand_eq 60%）≥ 39% は満たすが、**IP のコール側 required_eq も上昇** → IP が降りすぎる → バリューが取れない
- 結果として **「打って取る価値」が下がり、check-call で十分** になる

## 11. リバーへの接続

CR → ターン継続 → リバーに到達した時：

| OOP の手 | hand_eq | リバー required_eq | アクション |
|---------|---------|-------------------|-----------|
| Nutted（セット以上）| 85-95% | α(L)+ICM = 32-40% | バリューベット L (75%) |
| Thin value（TPTK）| 65-75% | 同上 | バリューベット M (50%、薄バリュー) |
| Thin value（TPMK）| 55% | 同上 | チェック・コール |
| ブラフ完遂（Air、TA+ 継続中）| <10% | フォールド時 EV ≥ ブラフ EV のとき | ブラフベット L (75%、α 式に従う) |
| ブラフギブアップ | <5% | — | チェック・降り |

### 11-1. α 式によるリバーブラフ比率

```
ブラフ : バリュー = 1 : 1（pot 比 1/2 のとき）
ブラフ : バリュー = 1 : 1.5（pot 比 1.0 のとき）
ブラフ : バリュー = 1 : 2（pot 比 1.5 のとき、オーバーベット）
```

MTT 補正でバブル時は ブラフ × 0.7、FT 時は ブラフ × 0.5。

## 12. CR 自体の判断（vol2 復習）

CR を打つか否かは vol2 のフロップ CR 戦略：

| ボード | CR 頻度（OOP） | 主カテゴリ |
|--------|--------------|----------|
| 型3 ロードライ | 19〜26% | Nutted + Semi-bluff |
| 型4 ローウェット | 25〜30% | Nutted + Semi-bluff |
| 型7 ペア低 | 28% | Nutted（トリップス）+ Air |
| 型1 ハイドライ | 11% | 限定的（A 含むレンジで弱い）|

MTT 環境では **SBR≥20 のみ CR を維持**、SBR<20 では CR 封印（コール or 降りの 2 値）。理由: SPR が浅くなると required_eq が高く、CR 後のターン継続が機能しなくなる。

## 13. 旧バレルスコアとの対応

旧表のバレルスコア継続条件は新フレームで以下に対応：

| 旧バレルスコア ≥ 7 | 新フレーム条件 |
|-------------------|--------------|
| バリュー系 + TA+ | Nutted (hand_eq 80%+) + 維持/上昇 → 継続 |
| バリュー系 + TA- | Nutted (hand_eq 80%+) + 微低下 → 継続（required_eq に余裕）|
| ブラフ系 + TA+ | Air (hand_eq <20%) + IP fold 期待 → ブラフ採算で継続（30%混合）|
| ブラフ系 + TA- | Air + IP fold 期待低 → ギブアップ |

> 旧スコアは「カテゴリ × ターンカード」の合成だった。新フレームでは **「CR 後 hand_eq の更新 → required_eq 比較」** で同じ結論が出る。

## 14. CR-continuation 早見表（暗算用 1 枚）

```
CR 通過後のカテゴリ:
  バリュー CR → Nutted (hand_eq 80%+)
  ブラフ CR → Air (hand_eq <20%)

継続条件:
  hand_eq ≥ required_eq = α(continuation サイズ) + ICM + OOP補正(+2%)

継続サイズ:
  SBR≥25 → M (50-60%)、SBR=20 → L (75%)、SBR=15 → AI

カテゴリ別継続:
  Nutted    : 全 TA で継続
  Thin value: TA+ で継続、TA- で check-call
  Air      : TA+ のみ継続（頻度 20-30%）

ICM 補正:
  バブル: Thin value 継続率 -20%、Air ブラフ -50%
  FT  : Thin value 継続率 -70%、Air ブラフ -100%

リバー α 式:
  ブラフ:バリュー = 1:1（M）/ 1:1.5（pot）
  バブル係数 × 0.7、FT 係数 × 0.5
```
