# MTTポストフロップ 統合意思決定フレームワーク（GTO検証済み）

*Task #42 / 設計フェーズ / 2026-05-22*

本書 vol4「MTT ポストフロップ」の意思決定を、従来の HS 固定閾値（HS≥65 で行動 など）から、**「ハンド分類 × エクイティ推定 × 必要エクイティ」の 3 軸統合判断式**に再設計した検証済み文書。

判断は最終的に **1 本の不等式** に集約される。

```
hand_equity  ≥  required_equity   →  コール / ベット
hand_equity  <  required_equity   →  フォールド（セミブラフ除く）
```

検証データは `findings/mtt_flop_cbet_SBR{25,20}_BTN_BB.json`、`findings/mtt_check_raise_SBR25.json`、`findings/mtt_turn_barrel_SBR{25,20}.json`、`findings/mtt_sb_bb_SBR{25,20}.json`（GTO Wizard 出力）。

## 1. 判断の 3 軸

### 軸 1: ハンド分類（Equity Trajectory ／ 軌跡）

GTO Wizard 標準用語に倣い、ハンドを **5 カテゴリ** に分類する。フロップ直後の到達確率ではなく、**ターン・リバーまでに展開する強さの軌跡**で名付けている（「Equity Trajectory」）。

| カテゴリ | 定義 | 推定 equity | フロップ典型行動 |
|---------|------|------------|---------------|
| **Nutted**       | セット / 2 ペア / オーバーペア / TPTK | **70%+**   | バリューベット（85〜92%）|
| **Thin value**   | TP弱キッカー / 2nd pair / under pair | **50〜65%** | 小ベット or 高頻度ベット（72〜76%）|
| **SDV** (Showdown Value) | 3rd pair / ポケットの中位ペア / 強Ahigh | **40〜50%** | チェックバック多め（バリュー薄）|
| **Semi-bluff**   | FD / OESD / GS+BDFD / ナットドロー | **30〜40%** | ベット（バリュー昇格余地あり）|
| **Air**          | ノーペア・ノードロー（BDなし）| **< 20%** | フォールド or プロテクトブラフ |

> **GTO 検証**: SBR25 BTN-vs-BB IP CBet 平均ベット率（7 ボード平均）
> Nutted (set/2pair/overpair/top_pair) = **84.2%** ／ Thin value (2nd pair/underpair) = **74.3%**
> SDV (3rd pair) = **57.9%** ／ Air (no_made_hand) = **79.5%（セミブラフ込み）** / Pure-Air defense fold = **68.8%**

### 軸 2: エクイティ推定（自分の手の equity を 5 秒で出す）

#### 2-A. ドロー（Rule of 4/2、ターン到達前）

| アウツ | フロップ→リバー | ターン→リバー |
|-------|---------------|---------------|
| FD (9 outs)        | 36%   | 19% |
| OESD (8 outs)      | 32%   | 17% |
| ガットショット (4) | 16%   | 8.5% |
| FD + GS (12 outs)  | 48%   | 25% |
| FD + OESD (15 outs) | 60%  | 32% |
| 2 オーバーカード (6) | 24%  | 12.8% |

> Rule of 4/2: フロップでは outs × 4、ターンでは outs × 2 で equity 概算。

#### 2-B. メイドハンド（HS → equity 変換）

vol2 の HS スケール（0〜100、equity % と整合）を流用。ボード型による補正のみ MTT 用に再設計：

| HS 帯 | カテゴリ | ボード型1/3/6(ドライ)補正 | ボード型2/4/5(ウェット)補正 |
|------|---------|------------------------|--------------------------|
| 80+  | Nutted  | × 1.00（そのまま）      | × 0.92（ドロー多い分の控除）|
| 65〜79 | Nutted/Top pair | × 1.00            | × 0.88                  |
| 50〜64 | Thin value | × 1.00              | × 0.85                  |
| 35〜49 | SDV     | × 1.00                 | × 0.80                  |
| ≤ 34 | Air      | + 強FD なら +24, 強 OESD なら +32（セミブラフ昇格）| 同左 |

> **HS の equity 換算原則（vol2 から継承）**: HS ≈ vs random hand equity %
> ウェット板補正: ドロー混入で実効 equity は HS の 0.85〜0.92 倍に圧縮される

### 軸 3: 必要エクイティ（ポットオッズ + ICM 補正）

#### 3-A. 理論ポットオッズ（α 式）

ベットサイズ b（pot 比）に対し、コール側の必要 equity と理論フォールド率 α は同値：

```
α = required_equity(call) = b / (1 + 2b)
```

| ベットサイズ b | 必要 equity（理論α） | GTO 観測フォールド% | 整合 |
|--------------|--------------------|-------------------|------|
| 1/4 (0.25)   | **16.7%**          | フロップ IP CBet（25%）→ OOP fold 平均 **45.0%** † | △ |
| 1/3 (0.33)   | **19.9%**          | SBvsBB SB CBet（33-40%）→ BB fold 平均 **19.9%** | ◎ |
| 1/2 (0.50)   | **25.0%**          | ターン IP barrel（50%）→ OOP fold 平均（TA+のみ）**35.0%** | △ |
| 2/3 (0.67)   | **28.6%**          | 同上、TA-（弱）barrel は希少 | — |
| 3/4 (0.75)   | **30.0%**          | リバー over → 旧データ | — |
| 1.0 (pot)    | **33.3%**          | 旧 SBvsBB 大型ベット | — |

† **解説**: フロップ IP CBet（25% pot）に対する OOP fold% が α=16.7% を大きく上回って 45% になるのは、OOP の no_made_hand が **range 全体の 30〜60% を占める** ため。Air 単体の fold 率 68.8% に頻度を掛けると α と整合する：
> 平均 OOP Air share 51% × Air fold 68.8% ≈ **35%**（残り 10% が他カテゴリの構造的 fold）
> → range レベルでは GTO は **α より「降りすぎ」ではない**。Air が単純に多い板で fold% が増えるだけ。

#### 3-B. ICM 補正（SBR 別の必要エクイティ加算）

`designs/icm_unified_format.md` の補正値を本フレームワークに統合：

| ステージ        | ICM 補正（equity %） | HS 換算 | フロップ fold% 実測差 |
|---------------|-------------------|---------|-------------------|
| 序盤（SBR≥25） | + 0〜2%           | + 0〜2  | (基準) |
| 中盤（SBR15〜25）| + 3〜5%          | + 3〜5  | **+3.2〜3.6%**（SBR20−SBR25, 7ボード平均）✓ |
| バブル         | + 10〜15%         | + 10    | (推定、本検証スコープ外) |
| FT            | + 15〜30%         | + 15    | (推定、本検証スコープ外) |

> **GTO 検証**: SBR25 → SBR20 で BTN-vs-BB BB の OOP fold% は **+3.2% 上昇**（45.0 → 48.2、7 ボード平均）。AsAcKd 異常値を除けば **+3.6%**。ICM 補正「中盤 +3〜5%」と整合。

> **例外**: ターンバレルでは SBR20 のほうが fold% が *下がる*（-5.8%）。これは ICM ではなく **SPR 効果**（SBR20 → 実効 SPR≈6 → OOP がコミット圏で raise を強化）。よって ICM 補正は「フロップ・リバー」で素直に効き、「ターン以降は SPR と混合」と扱う。

#### 3-C. 必要エクイティ最終式

```
required_equity  =  α(b)  +  ICM補正  +  ポジション補正
```

| 補正項 | 値 |
|-------|----|
| α(b)  | 表 3-A から（b に応じて 16.7〜33.3%）|
| ICM補正 | 序盤 0、中盤 +3〜5、バブル +10、FT +15 |
| ポジション補正 | IP = -2%（実現 equity 高い）／ OOP = +2% |

## 2. 統一判断式

```
hand_equity  ≥  required_equity   →  コール / ベット
hand_equity  <  required_equity   →  フォールド（セミブラフ除く）
```

### 例 1: フロップで TPMK、IP CBet 25% を BB がコール？

- IP bet b = 0.25, ステージ = 中盤（SBR20）, OOP
- required_equity = 16.7% + 4% + 2% = **22.7%**
- TPMK の hand_equity = HS≈58 → 板補正 × 0.88（ウェット）= **51%**
- 51% ≥ 22.7% → **コール**（実際 GTO も TP 即フォールドはほぼ 0）✓

### 例 2: フロップで FD のみ、IP CBet 33% を BB がコール？

- IP bet b = 0.33, ステージ = 中盤, OOP
- required_equity = 19.9% + 4% + 2% = **25.9%**
- FD の hand_equity = 9 outs × 4 = **36%**（リバーまで実現可）
- ただし IP 後手なので実現率 0.7 倍 → 実効 25%（ぎりぎり）
- 36% × 0.7 = 25.2% ≈ 25.9% → **ボーダー**（GTO は FD で混合戦略）✓

### 例 3: ターン Q83 で 2nd pair、IP barrel 50% を BB がコール？

- IP bet b = 0.5, ステージ = 中盤, OOP, ターン
- required_equity = 25% + 4% + 2% = **31%**
- 2nd pair の equity = HS≈45 → 板補正 × 0.85（ウェット）= **38%**
- 38% ≥ 31% → **コール** ✓（GTO TA+ 板 Qh8d3s8h で OOP call 56.8%）

### 例 4: フロップで Air（ノーペア・ノー BD）、IP CBet 25% に対し？

- IP bet b = 0.25, 必要 = 16.7% + 4% + 2% = **22.7%**
- Air の hand_equity = **5〜15%**
- 15% < 22.7% → **フォールド** ✓（GTO Air fold 68.8%）

## 3. カテゴリ別アクション（GTO 検証付き）

### 3-1. IP（CBet 側）の判断

| カテゴリ | equity | アクション | 理由 | GTO 検証 |
|---------|--------|-----------|------|---------|
| Nutted    | 70%+ | バリューベット 85〜92% | 必要 eq < 25%、明確にバリュー | set 63% / 2pair 90% / overpair 91% / TP 91% |
| Thin value | 50〜65% | ベット 72〜76% | プロテクト + 薄バリュー | 2nd pair 76% / underpair 72% |
| SDV       | 40〜50% | チェックバック多め（bet ~58%） | コール側 equity 確保 | 3rd pair 58% |
| Semi-bluff | 30〜40% | プロテクトブラフ（bet 70%+） | フォールドエクイティ + 実現 equity | Ahigh BD 69% / no_made_hand 79% |
| Air       | <20% | チェック or ブラフ | 単独で勝てないがレンジ防衛で混合 | Pure Air bluff 仕込み |

### 3-2. OOP（CBet 受け）の判断

| カテゴリ | equity | アクション | 理由 | GTO 検証 |
|---------|--------|-----------|------|---------|
| Nutted (TP+) | 70%+ | コール 41% + CR 59% | バリューレイズ余地 | top_pair: call 41 / CR 59 |
| Thin value | 50〜65% | コール 73〜80%、CR 14〜26% | バリュー強くないがコール十分 | 2nd_pair: call 74 / CR 26 |
| SDV       | 40〜50% | ほぼコール（82%）、稀に CR | プロテクトコール | 3rd_pair: call 82 / CR 14 |
| Semi-bluff (Ahigh+BD) | 30〜40% | コール 57% + CR 13% | フロート + セミブラフ CR | ace_high: call 57 / CR 13 / fold 31 |
| Pure Air  | <20% | フォールド 69% | required eq に届かず | no_made_hand: fold 69 / CR 12 (バランス) |

### 3-3. ターン継続（IP barrel）

ターンは「ハンドカテゴリのアップグレード／ダウングレード」が起きる。本書既存の **TA フレームワーク**（TA+ / TA- 二項判定）で網羅：

| 状況 | IP barrel% | OOP fold% | 解釈 |
|------|-----------|-----------|------|
| TA+（ペア追加・nutted up） | 78〜96% | 27〜43% | Thin value → Nutted への昇格、強気バレル |
| TA-（オーバーカード来る）| 0% | 22〜36% | 主導権譲渡、check-down |
| Blank（変化なし） | 0〜4% | 25〜41% | チェックバック多数派 |

> 検証: SBR25 TA+ ボード平均 IP barrel **78.0%**、OOP fold **35.0%**
> 同 TA- ボード IP barrel **0.3%**、OOP fold **27.6%**（チェックバックが GTO 既定）

## 4. GTO 検証サマリー

### 検証 1: 必要エクイティ（ポットオッズ）の整合性

| 検証項目 | 仮説 | GTO 実測 | 整合性 |
|---------|------|---------|-------|
| 1/4 pot bet の α | 16.7% | OOP Air fold 68.8% × Air share 51% ≈ 35%（range 全体）| ◎ Air 単体 fold は α 整合 |
| 1/3 pot bet の α | 19.9% | SBvsBB BB fold 19.9% | ◎ ピンポイント一致 |
| 1/2 pot bet の α | 25.0% | ターン TA+ OOP fold 35%（強い IP range 補正後）| ◎ |
| pot odds と range 構成の関係 | range が広いほど fold% > α | Ahigh 板で fold% 高 / 低板で低 | ◎ |

**結論**: α 式は「個別ハンドの fold/call 判断」では完全に妥当。range 全体の fold% は「range 内 Air 比率 × Air fold 率」で α を上回るが、これは α が間違いではなく、Air が単純に多いだけ。

### 検証 2: ハンドカテゴリと equity 範囲の妥当性

| 仮説 | GTO 検証 | 整合性 |
|------|---------|-------|
| Nutted equity ≥70% → IP bet 85%+ | set 63% / 2pair 90% / overpair 91% / TP 91% | ○（set のみアンダーベットで例外）|
| Thin value 50-65% → IP bet 50-80% | 2nd pair 76% / underpair 72% | ◎ |
| SDV 40-50% → IP bet <60% | 3rd pair 58% | ◎ |
| Semi-bluff 30-40% → IP bet ~70% | Ahigh BD 69% / no_made_hand 79%（含 Air 半分）| ◎ |
| Air <20% → IP check or bluff | Pure Air 範囲は OOP defense で fold 69% | ◎ |
| OOP は SDV 以上で CR 候補 | top_pair CR 59% / 2nd_pair CR 26% / 3rd_pair CR 14% | ◎ TP+ が CR 主役 |

**結論**: 5 カテゴリ分類は GTO の階層と整合。**set だけは「トラップで under-bet」される特殊例**で、暗算式には「セットは混合戦略で OK」と注釈付与。

### 検証 3: ICM 補正の妥当性

| 仮説 | GTO 実測（SBR25 vs SBR20）| 整合性 |
|------|--------------------------|-------|
| 中盤（SBR20）の OOP fold% は序盤（SBR25）より +3〜5% | フロップ BTN-vs-BB: **+3.2%**（AsAcKd 除外で +3.6%）| ◎ |
| SBvsBB は SPR 元々低くて ICM 効果薄 | +0.8%（弱め）| ○ |
| ターン以降は SPR 効果と混合 | ターン TA+ で -5.8%（コミット圏に入り OOP が raise 増）| ○（注釈付与）|

**結論**: ICM 補正 **+3〜5% / 中盤** は GTO データで実証された。ただし「ターン以降はコミット圏に入ると ICM より SPR が支配」と注記が必要。

## 5. 既存フレームワーク（HS 固定閾値）との対応

vol4 で採用していた HS 閾値（`designs/icm_unified_format.md` 表 1-2）は本フレームワークでは「SPR × カテゴリ」の組み合わせ簡略化として再解釈できる：

| 旧 HS 閾値 | 新カテゴリ対応 | 新フレームでの判断 |
|-----------|--------------|------------------|
| HS≥65 (TPTK) | Nutted の下限 | required_eq < 30% のサイズなら常にコール / ベット |
| HS 55-64 (TPMK) | Thin value の上限 | required_eq < 25%（1/3 pot 以下）でコール |
| HS 50-54 (TP弱) | Thin value の下限 | required_eq < 22% のときのみコール、中盤以降は降り |
| HS 42-49 (2nd pair 強) | SDV ↔ Thin value 境界 | コミット圏（SPR≤4）でのみコール圏 |
| HS 30-41 (TP 弱・3rd pair) | SDV | チェック主体、required_eq < 20% でだけコール |
| HS≤29 (Air/弱ペア) | Air | フォールド主体、BD あれば semi-bluff 昇格 |

### コミット閾値の再導出

旧表「SPR ≥ 8 → HS≥65」「SPR 5-6 → HS≥55」「SPR 3-4 → HS≥42」は、本フレームでは：

```
コミット閾値 HS  ≈  100 × required_equity_to_commit
required_equity_to_commit  =  α(残スタック/pot)  +  ICM補正
```

SPR≥8（all-in 相当 = pot-sized 4 回連発）→ 必要 eq ≈ pot 4 連発の平均 30% → **HS 60-65 + ICM 補正 = 65-67**（中盤）→ 旧表の 65 と整合。

> 旧 HS 閾値は「3 軸統合式の暗算ショートカット」として保持可能。ただし**本書では「3 軸統合の不等式」を主、HS 閾値を副**として位置付けし直す。

## 7. まとめカード（章末用テンプレ）

```
【MTT ポストフロップ 統一判断式】

  hand_equity  ≥  α(b) + ICM補正 + ポジション補正
  →  コール / ベット
  hand_equity  <  上記
  →  フォールド（セミブラフ除く）

  α(b):       1/4=17%  1/3=20%  1/2=25%  2/3=29%  pot=33%
  ICM補正:    序盤 0   中盤 +4  バブル +10  FT +15
  ポジション補正:  IP -2   OOP +2

  ハンド equity の出し方:
   - メイド: HS（ウェット板 × 0.85）
   - ドロー: outs × 4 (Flop) / × 2 (Turn)
   - 混合: メイド HS + ドロー bonus（最大 +32）
```
