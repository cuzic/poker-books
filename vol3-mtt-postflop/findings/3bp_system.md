# 3BPポストフロップ専用システム（CBS非対応）

## なぜCBSが機能しないか

3BP（スリーベットポット）はSPR≈2-3。低SPRでは：
- セット・ストレート・ツーペアが**スローコール/チェックレイズ**を選ぶ → CBSが予測する「強手=ベット」が逆転
- CBS精度: 52.7%（ほぼランダム）

原因: CBS は「ハンドが強いほどベット」と仮定するが、3BPではナッツがチェックするため単調性が崩れる。

---

## 3BP専用システム設計

### ポジション分離が前提

3BPは IP（コール側）と OOP（3ベット側）で戦略が**正反対**になる。

---

## OOP（3ベット側が先手）: 「ナッツだけチェック」

```
ナッツ → CHECK（チェックレイズ狙い）
それ以外 → CBet（レンジCBet ~75%）
```

### OOP ナッツ定義（CHECK対象）

| ハンド | 実測OOP CBet% | 理由 |
|------|------------|------|
| セット | 46.7% | チェックレイズ/スロープレイ |
| ツーペア | 47.2% | チェックレイズ/スロープレイ |
| ストレート | 35.4% | 同上 |
| フルハウス | — | 同上 |
| クアッズ | — | 同上 |

**トリップスはCBet（96.9%）**: ボードにペアがある状態でトリップスを持つとスロープレイ価値が低い。

### OOP 非ナッツ（CBet対象）

| カテゴリ | 実測avg | 行動 |
|---------|--------|-----|
| オーバーペア | 96.2% | CBet強 |
| トップペア | 92.3% | CBet強 |
| アンダーペア | 91.9% | CBet（プロテクション） |
| エアー | 87.0% | CBet（ブラフ） |
| Aハイ | 79.5% | CBet |
| Kハイ | 74.9% | CBet |
| セカンドペア | 71.4% | CBet |
| サードペア | 70.1% | CBet |
| ローペア | 47.9% | 混合 |

**実測GTO CBet平均: 74.5%（非ナッツ）**

### 精度

```
OOP 3BP専用システム: 74.0%（CBSの52.7%から+21pt）
```

## IP（コール側）: 「アーチ型ベット」

3BP IPでは U字型（強手と弱手がチェック、中間がベット）：

```
弱手（エアー〜ローペア）→ CHECK（撤退/混合）
価値帯（サードペア〜トリップス）→ BET（プロテクション・バリュー）
トラップ帯（オーバーペア以上・セット・ストレート）→ CHECK（スロープレイ）
例外: 弱手+OESD → BET（エクイティ主導）
```

### IP カテゴリ詳細（ドローなし）

| カテゴリ | ハンド | 実測avg | 行動 |
|--------|------|--------|-----|
| **撤退帯** | エアー・Aハイ・Kハイ・ローペア | 41.0% | CHECK |
| **価値帯** | サードペア・セカンドペア・アンダーペア・トップペア・ツーペア・トリップス | 65.7% | BET |
| **トラップ帯** | オーバーペア・セット・ストレート・FH・クアッズ | 37.7% | CHECK |

### IP ドロー補正

| 弱手+ドロー | 実測avg | 行動 |
|----------|--------|-----|
| no_draw | 41.0% | CHECK |
| GS | 34.2% | CHECK |
| FD | 39.4% | CHECK |
| **OESD** | **57.4%** | **BET（エクイティ主導）** |
| コンボ | 38.9% | CHECK |

**弱手+OESDだけベット**: 強いエクイティ（ストレート完成確率）でプロテクション。他ドローはCHECK。

### 精度

```
IP 3BP専用システム: 69.7%（CBSの52.7%から+17pt）
```

## 全体精度まとめ

| システム | 精度 |
|---------|-----|
| CBS（旧来、全シナリオ同一） | 52.7% |
| **3BP専用（OOP+IP分離）** | **71.5%** |
| SRP CBS v3（参考） | ~72% |

3BP専用システムはSRP CBSと同等の精度を達成。

## 書籍用 判断カード（第11章）

### OOP（3ベット側）
```
ナッツ（セット・ツーペア・ストレート）→ CHECK（チェックレイズ）
それ以外 → CBet（約75%）
```

### IP（コール側）
```
Step 1: 手牌の強さを判定
  強すぎ（オーバーペア・セット・ストレート以上）→ CHECK（トラップ）
  丁度よい（サードペア〜トリップス）→ BET
  弱すぎ（エアー〜ローペア）→ CHECK（諦め）

Step 2: ドロー補正（弱手のみ）
  弱手 + OESD → BET に変更（エクイティ主導）
  その他ドロー → 変更なし
```

## 理論的背景

### なぜIPのオーバーペアがチェックか

SPR≈2-3ではオーバーペアは「もう勝てるレンジ」。チェックして相手にブラフさせる方が期待値が高い。ベットすると弱手がフォールドして価値が取れない。

### なぜOOPがほぼ全部ベットか

3ベット側はプリフロップで「レンジ優位」を主張している。ポストフロップでもその優位性を継続するため、ほぼ全域でCBetを打つ（ポーラライズドCBet + 非ナッツはすべてCBet）。ナッツだけ例外的にチェックレイズでスタックを取りに行く。
