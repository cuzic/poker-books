# フロップCBet 確信度システム（二系統設計）— v3検証済み版

## 設計思想

「どちらに打つか（方向）」と「どれくらいの頻度で打つか（確信度）」を分離する。

```
方向判定 = CBS（HP+DP）と閾値の比較
確信度   = CBS距離（|CBS - 閾値|）+ ボード型補正
```

## 確信度ルール（書籍向け）— v3

### Step 1: 方向判定（CBS）

```
CBS = HP + DP
BTN: CBS≥5 → ベット方向  CBS<5 → チェック方向
SB/LIMP: CBS≥7 → ベット方向  CBS<7 → チェック方向
```

### Step 2: 距離で確信度を判断

**距離 = |CBS - 閾値|**

| 距離 | 確信度 | ボード型確認 |
|-----|------|----------|
| ≥ 3 | **HIGH** | 不要（83%+正解率） |
| 2 | ボード型確認 | 必要 |
| 0-1 | ボード型確認 | 必要 |

### Step 3: ボード型で確信度決定

| ボード型 | 距離0-1 | 距離2 | 注意 |
|--------|--------|------|-----|
| **型1（エースドライ）** | **HIGH** | **HIGH** | 距離2でも信頼できる |
| **型7（ペアボード）** | **HIGH** | MID | 距離=0のみHIGH、距離=1はLOW⚠ |
| 型5（断絶高） | MID | MID | — |
| **型3（OESD連続）** | **LOW** | MID | 距離0-1は混合 |
| **型4（ローウェット）** | **LOW** | MID | 距離0-1は混合 |

**⚠ 型7（ペアボード）の特別注意**: 距離=1（CBSが閾値から1点差）のときは確信度LOW。  
実測では「チェック方向」と判定される手牌がペアボードでもベット94%という逆転が頻発する。

## CBS距離 × ボード型 → 方向判定正解率（BTN実測）

| 距離 | 型1(ドライ高) | 型3(OESD) | 型4(ローWET) | 型5(断絶) | 型7(ペア板) |
|-----|-------------|----------|------------|---------|----------|
| **0-1** | **89%** | 66% | 42% | 52% | **86%** |
| 2 | 65% | 49% | **85%** | **82%** | 40% |
| **≥3** | **78%** | **87%** | **95%** | **90%** | **79%** |

**型7（ペアボード）の距離=2が40%**: ペアボードは距離=2でも不安定。MID止まりが適切。

## 確信度の論理的背景

### なぜ型3（OESD）は確信度が低いか

型3ボードは双方のレンジに多くのドローが含まれるため：
- IP側もOOP側も強いドローを持ちやすい（レンジバランスが均衡）
- GTOはボード固有のブロッカー効果・スーテッド枚数に依存した細かい解を出す
- CBSのような単純な手牌スコアでは捉えられない

### なぜ型7（ペアボード）の距離=1は逆転するか

ペアボード（KK8, AA7など）では：
- ボードにペアが存在するため、手牌のランクによるエクイティ差が増幅する
- CBSが閾値より1低い（例: CBS=4 < 5）場合でも、GTO実測でベット94%という逆転が起きる
- 原因: Kハイ（旧HP=4）がAAやKKのペアボードで「ボードを上回る可能性」から高頻度ベットを好む

**この問題はKハイのHP=5への修正（v3）で大部分が解消された。**

## 具体例（v3）

### 例1: BTN Kハイ + no_draw（KK8ペアボード）

```
HP=5, DP=0, CBS=5, 距離=0, 型7
Step3: 型7×距離0 → HIGH
結論: ベット方向 HIGH確信 → 79%
実測: 61%（Kハイ全体平均）
```

### 例2: BTN セカンドペア + GS（T98連続型）

```
HP=5, DP=1, CBS=6, 距離=1, 型3
Step3: 型3×距離0-1 → LOW
結論: ベット方向 LOW確信 → 58%
```

### 例3: BTN トップペア + FD（A72ドライ）

```
HP=7, DP=2, CBS=9, 距離=4, 型1
Step2: 距離≥3 → HIGH（ボード型確認不要）
結論: ベット方向 HIGH確信 → 79%
```

## vol2との接続

確信度システムはvol2のボード7分類と直接連携する：
- vol2で「型3（OESD連続型）はレンジバランスが難しい」→ 確信度低
- vol2で「型1（エースドライ）はIP有利」→ 確信度高
- 同じボード分類を使うため、読者は追加暗記不要
