# フロップCBet 2段階境界値フレームワーク（GTO実測設計）

## 設計思想

GTO Wizard MTT データ（6,367ハンド×シナリオデータポイント）から導出。  
「HS < T_check → チェック（≈20%ベット）、HS ≥ T_bet → ベット（≈80%ベット）」  
という2段階境界値として設計し直した版。

---

## 核心発見：シナリオによって構造が全く異なる

### High RA（BTN/CO先手、RAS ≥ 65%）：**チェックゾーンがない**

| 手牌（ドローなし） | HS | CBet% |
|-----------------|-----|-------|
| no_made_hand    | 15 | **86%** ← エアーがベット！ |
| ace_high        | 28 | 70% |
| third_pair      | 45 | 57% |
| second_pair     | 55 | 68% |
| top_pair        | 68 | 94% |
| set             | 82 | 63% ← スロープレイで低下 |
| trips           | 86 | 99% |

→ **全ハンドが50-94%でベット。チェック推奨ラインは事実上なし。**  
→ 唯一の例外: セット/フルハウス（スロープレイ混在で40-65%に低下）

---

### Low/Mid RA（SB先手SRP・コールドコール）：**標準2閾値**

| 手牌（ドローなし） | HS | SRP_SB実測 |
|-----------------|-----|-----------|
| ace_high        | 28 | **27%** ← 20%境界 |
| third_pair      | 45 | **23%** ← 20%境界 |
| second_pair     | 55 | 38% |
| top_pair        | 68 | **72%** ← 80%境界 |

→ T_check ≈ 45（サードペア以下チェック）、T_bet ≈ 65（トップペア以上ベット）

---

### VLow RA（リンプ先手、RAS < 35%）：**タイト2閾値**

| 手牌（ドローなし） | HS | LIMP実測 |
|-----------------|-----|---------|
| ace_high        | 28 | **22%** ← 20%境界 |
| third_pair      | 45 | 29% |
| top_pair        | 68 | 63% |
| two_pair        | 78 | **87%** ← 80%境界 |

→ T_check ≈ 30（エースハイ以下チェック）、T_bet ≈ 75（2ペア以上ベット）

---

## 確定: 覚える2段階境界値

| RA クラス | 代表シナリオ | T_check | T_bet | 覚え方 |
|---------|-----------|---------|-------|--------|
| **High** (RAS≥65%) | BTN/CO先手 | なし | HS≥50 | **全ベット**（セット以上はミックス） |
| **Mid/Low** (RAS 35-65%) | SB先手・cc | **45** | **65** | **45/65** ← 2値 |
| **VLow** (RAS<35%) | リンプ先手 | **30** | **75** | **30/75** ← 2値 |

### 2組だけ覚える

```
標準シナリオ (SB先手・cc):    HS < 45 → チェック   HS ≥ 65 → ベット
リンプシナリオ (LIMP先手):    HS < 30 → チェック   HS ≥ 75 → ベット
BTN/CO先手:                  [全ベット、セット以上はチェック混在]
```

## vol2 HS との対応

| HS帯 | 手牌例 | 標準(45/65) | リンプ(30/75) |
|------|--------|-----------|-------------|
| ≥75 | 2ペア以上 | ベット | **ベット** |
| 68-74 | トップペア・オーバーペア | ベット | 混合 |
| 55-67 | セカンドペア・TP弱 | 混合 | 混合 |
| 45-54 | サードペア・アンダーペア | 混合 | 混合 |
| 28-44 | ローペア・エースハイ | **チェック** | 混合 |
| <28 | エアー（ドローなし） | チェック | **チェック** |

---

## ドロー補正

ドローボーナス（vol2準拠）を加算したHS_adjでも同じ閾値を適用：

| ドロータイプ | HS補正 | 効果 |
|-----------|--------|------|
| BDFD (2枚) | +0 | 変化なし |
| ワンカードBD | +3 | 微小効果 |
| ガットショット | +8 | サードペア→ボーダーに |
| FD | +12 | エースハイ→混合域に |
| OESD | +15 | サードペア→ベット域に |
| コンボドロー | +20 | エアー→ベット域に |

---

## GTO逸脱度

| シナリオ | WRMSE | 適合度 |
|---------|-------|--------|
| LIMP (2閾値 30/75) | **23.9%** | 良好 |
| SRP_SB (2閾値 45/65) | **25.8%** | 良好 |
| BTN SRP (全ベット) | 30.8% | 許容（混合戦略による固有誤差） |

残差はGTO固有のrandomization（HS内でのハンド別変動）によるもので、  
単純閾値ルールの理論的限界に近い。

---

## 実用判断フロー

```
Step 1: シナリオ判定
  BTN/CO開き → 「全ベット方針」（セット以上だけ注意）
  SB開き     → 「45/65」2閾値適用
  リンプ     → 「30/75」2閾値適用

Step 2: HS + ドローボーナス = HS_adj 計算

Step 3: 判定
  HS_adj ≥ T_bet → ベット推奨 (≈80%)
  HS_adj < T_check → チェック推奨 (≈20%)
  その間 → 混合戦略（頻度ベース、SPR/ICMで微調整）
```
