## Phase 1：SBR 別コミットライン（最重要）

**問い：フロップで「コミット（残りスタックの 50%以上を投入）」に踏み切るのは HS 何以上か？**

### 設定方法

GTO Wizard → MTT General（9-max、BBアンテあり）→ Postflop → BTN open vs BB call（SRP）

### 測定する SBR

- SBR=30（≈60BB）
- SBR=25（≈50BB）
- SBR=20（≈40BB）
- SBR=15（≈30BB）
- SBR=10（≈20BB）

### 測定するボードタイプ（vol2 の 7分類から代表）

| 型 | 代表ボード | FlopType |
|---|---------|---------|
| 型1 ハイドライ | K♠7♦2♣ | dry |
| 型2 ハイウェット | Q♠8♦3♠ | wet |
| 型4 ローウェット | T♠9♠8♦ | connected |

### 記録する内容

各（SBR × ボード）の組み合わせで：

1. **BTN（IP・CBet側）**：どのハンドクラスでオールインに向かうか
   - バリューベット → コールに対してさらにレイズ → オールイン？
   - フロップで「コミット的」な行動（ポット75%以上のベット）を打つ最低 HS

2. **BB（OOP・ディフェンス側）**：どのハンドクラスで CR → コミットするか
   - チェックレイズ後、BTNのレイズに対してオールインする最低 HS

### 期待する成果

```
SBR=25（SPR≈8）: コミット HS ≥ ?（仮説: 65）
SBR=20（SPR≈6）: コミット HS ≥ ?（仮説: 55）
SBR=15（SPR≈4.5）: コミット HS ≥ ?（仮説: 42）
SBR=10（SPR≈3）: コミット HS ≥ ?（仮説: 30）
```

## Phase 2：ICM 補正値の定量化（最重要）

**問い：ステージが変わると、コール・フォールド判断がどれだけタイトになるか？**

### 設定方法

同一ハンド・同一ボードを以下のステージで比較する。

**比較基準：Chip-EV（ICMなし）** vs 各ステージの ICM ソリューション

### 測定シナリオ

**共通設定**
- BTN open 2.5BB → BB call（SRP）
- SBR=20（≈40BB）固定
- ボード：Q♠7♦2♣（型1 ハイドライ、代表的ニュートラルボード）
- BTN が 50% CBet → BB の対応を比較

**ステージ別設定**

| ステージ | GTO Wizard の設定 | 目標 ICM 圧力 |
|--------|----------------|------------|
| 序盤 | Chip-EV モード（= early stage 近似） | +1〜2% 仮説 |
| 中盤 | MTT General、残り 40% プレイヤー | +3〜5% 仮説 |
| バブル | MTT General、残り 15% / ITM直前 | +10〜15% 仮説 |
| FT 9人 | MTT FT 9-handed | +15〜25% 仮説 |
| FT 3人 | MTT FT 3-handed | +20〜30% 仮説 |

### 記録する内容

BB（ディフェンス側）について：

1. TP（例：Q♠8♦）のコール頻度（chip-EV vs 各ステージ）
2. マージナルTP（例：Q♠5♦）のコール頻度
3. セカンドペア（例：7♠6♦）のコール頻度
4. エアー（例：A♥3♥ＦＤなし）のフォールド頻度

### 期待する成果

```
各ステージで「コールが消えるハンド境界線（HS 値）」を測定し、
chip-EV 基準からの乖離幅（= ICM 補正値）を算出する。

例：
  chip-EV: HS≥30 でコール
  バブル:  HS≥45 でコール
  → ICM補正 ≈ +15%（HS 換算 +15）
```

## Phase 3：バブルにおけるビッグスタックの CBet 拡大量

**問い：バブルでビッグスタックがエアーでも CBet を打てるのはどのボードか？**

### 設定方法

- ビッグスタック（≥2× average chip、SBR≥30）vs ショートスタック（SBR=10〜15）
- バブル設定（MTT General、bubble モード）
- 比較：同設定の chip-EV

### 測定するボードタイプ（7型すべて）

各ボードで：

- Chip-EV：エアー CBet 頻度（%）
- バブル ICM：エアー CBet 頻度（%）
- 差分（バブル拡大幅）

## Phase 4：マルチウェイポストフロップのコミット閾値

**問い：3way以上でコミットするのは通常より HS いくつ上か？**

### 設定方法

- BTN open → CO call → BB call（3way）
- SBR=20 固定
- ボード：K♠7♦2♣（型1）と T♠9♠8♦（型4）

### 比較

- ヘッズアップ（BTN vs BB）のコミットライン
- 3way のコミットライン
- 差分（= toc.md の +10〜15 仮説を検証）

## Phase 6：リバーα式のバブル補正

**問い：バブルでのブラフ頻度はα×何倍になるか？**

### 設定方法

- 3ストリートのバリュー/ブラフ比率をリバーで計測
- SBR=20、型1 ハイドライ、リバーブランク

### 比較

- chip-EV：α（例: 33%ベットなら α≈25%）のブラフ頻度
- バブル ICM：同ベットサイズのブラフ頻度

### 期待する成果

```
バブルでのブラフ频度 = α × X%
（仮説: X ≈ 0.6〜0.7、つまり 30〜40% 削減）
```
