# 『迷わないポーカー』シリーズ

テキサスホールデムを**暗算で判断できる**初級〜上級向けの全 6 巻シリーズ＋ダイジェスト版。

## 書籍一覧

### ① プリフロップ — 覚えなくていいレンジの考え方

- **対象**：ポーカーを始めたばかり〜レンジ表の暗記で挫折した経験者
- **核となる式**：`Score = H + L + ボーナス − ペナルティ`（基本スコア式）、`Score₃ = H + 0.5L + B + S + C − G − R`（3ベットスコア式）
- **目次**：全 22 章 ＋ 付録 12 セクション（0、A〜I、K、L）
- **公開**：https://gistpreview.github.io/?a263151bbdee0ac9cbaa4a4e97483edb
- **ソース**：[`preflop/`](./preflop/)

### ② フロップ[基礎] — 秒で決まるボード判断

ボードを読み、簡易レンジスコアで判断するフロップ戦略。

- **対象**：プリフロップ編を読了した初級者〜中級者手前
- **核となるフレームワーク**：
  - 7 型ボード分類 + 型別アクションプラン（第 3〜4 章）
  - `簡易レンジスコア チェックリスト`（4 ステップで CBet 頻度 % を出力、第 8 章）
  - `HandScore`（役 + アウツ × 1.5 + ブロッカー、0〜50、第 9 章）
  - 9 マスマトリクス（簡易レンジスコア × HandScore、第 10 章）
- **目次**：全 19 章 ＋ 付録
- **ソース**：[`flop/`](./flop/)

### ③ フロップ[応用] — 相手のレンジを読んで搾取する

レンジ推定・クセ読み・搾取の上級戦略。

- **対象**：②を完全習得、NL200 以上の上級志向プレイヤー
- **核となるフレームワーク**：
  - `BDM v5`（4 項減算式、R²=0.914）
  - 17 型ボード分類、混合戦略 R1-R6
  - HUD 4 タイプ × 8 例の搾取カタログ、メタゲーム、タイミングテル
- **目次**：全 17 章 ＋ 付録
- **ソース**：[`flop-advanced/`](./flop-advanced/)

### ④ ターン・リバー[基礎] — 4つの暗算式でポストフロップを判断

ターンとリバーの基本判断を 4 つの暗算式（バレルスコア、α 式、後手スコア両版）で。

- **対象**：②を読了、ターン・リバーの基本概念と暗算式を独立して習得したい読者
- **核となる式**：
  - `バレルスコア = FlopType係数 + TurnCard係数`（ターン攻撃）
  - `α = ベット ÷ (ポット + ベット)`、`後手下限確率 = 1 − α`（リバー配分）
  - `後手スコア = HandScore + A − C − M`（ターン版・リバー版、新スケール 0-100 equity %）
- **目次**：全 16 章 ＋ 付録 3 本
- **ソース**：[`volume4/`](./volume4/)

### ⑤ ターン・リバー[応用] — 3軸統合と backward induction

過去レンジ × 現在のターンカード × リバー予測の 3 軸を統合する応用編。

- **対象**：④を読了、3軸統合・backward induction・高度戦術を習得したい読者
- **核となるフレームワーク**：
  - 3軸統合（forward × current × backward）
  - backward induction（リバーから逆算するターン設計）
  - ブロッカー実戦選択、オーバーベット、リバーCR、ポットコミットメント
- **目次**：全 16 章 ＋ 付録 3 本
- **ソース**：[`volume5/`](./volume5/)

### ⑥ トーナメント — ICM とM 値で迷わないトーナメント判断

キャッシュ用の式を ICM 補正でトーナメント版に拡張。

- **対象**：トーナメントを攻略したい読者（巻①〜⑤ を読了推奨）
- **核となる式**：
  - `ICM equity`（chip → \$EV 換算、Malmuth-Harville）
  - `ICM 補正`（リスクプレミアム、bubble factor − 1.0）
  - `M 値 = スタック ÷ (SB + BB + アンテ合計)`（ステージ判定）
- **付属ツール**：[`scripts/icm_calc.py`](./scripts/icm_calc.py)（ICM 計算器）
- **目次**：全 21 章 ＋ 付録 3 本
- **ソース**：[`volume6/`](./volume6/)

### ダイジェスト — 全6巻を1冊で見渡す暗算式の地図

シリーズ全 6 巻（約 130 万字）の暗算式エッセンスを 1 冊約 70,000 字に圧縮した中級入門書。

- **対象**：シリーズ全体の地図を短時間で掴みたい中級者、各巻の橋渡しを求める読者
- **収録範囲**：プリフロップの Score 式 → フロップの簡易レンジスコア・HandScore・後手スコア → ターンのバレルスコア → リバーの α 式 → 3軸統合・backward induction → トーナメントの ICM equity・M 値（10 以上の暗算式を網羅）
- **目次**：全 18 章 ＋ 付録 3 本
- **ソース**：[`digest/`](./digest/)

## 共通の設計思想

1. **暗算で回せる判断フロー**：Chen Formula、Sklansky Hand Groups の系譜を現代 GTO データで再設計
2. **境界暗記のハイブリッド**：式で 9 割、境界ハンドは GTO 最善手を暗記
3. **6-max、100BB、キャッシュゲーム**を基本想定
4. **各章末に【GTOとのズレ】コラム**：簡易式の限界を率直に示す

## ビルド方法

```bash
# 個別ビルド（HTML/EPUB/site すべて）
bun run scripts/build.ts --book preflop --format all
bun run scripts/build.ts --book volume4 --format all
bun run scripts/build.ts --book volume6 --format all

# 全冊一括
bun run build:site

# EPUB のみ
bun run build:epub
```

成果物は `dist/<book>/`（HTML / XHTML / EPUB / site）。

GitHub Actions で `main` への push 時に自動ビルド・GitHub Pages デプロイ。
`workflow_dispatch` で Dropbox に EPUB をアップロード可能（`DROPBOX_REFRESH_TOKEN` 等の secrets 設定要）。

## シリーズの位置づけ

本シリーズは以下の系譜に連なります。

- **Chen Formula**（Bill Chen、2000 年代）：ハンド数値化の原型
- **Sklansky-Malmuth Hand Groups**（1988 年）：チャンキング思考
- **Matthew Janda『Applications of No-Limit Hold'em』**（2013 年）：レンジ思考
- **Michael Acevedo『Modern Poker Theory』**（2019 年）：ソルバー時代の体系書
- **本シリーズ**：暗算で回せる形にアップデート

レンジ表の丸暗記で挫折した経験のあるすべてのプレイヤーへ。
