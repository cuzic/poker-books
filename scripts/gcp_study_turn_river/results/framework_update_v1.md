## 5. フレームワーク改訂案

### 5.1 ターン CBet 新ルール

```
■ ターンバレル（OOP check 後）
  サイズ: 33% ポット（全 texture 共通）

  T1(TP+/overpair/set): 常にベット（100%）
  T2(2OC/OESD等):       常にベット（全 texture 71-100%）
  T3(air/gutshot):
    - pair turn → 常にベット（96-100%）
    - blank/overcard turn → ほぼ常にベット（80-93%）
    - connector turn → 高頻度ベット（65-82%）

  ■ 現行フレームワークからの変更:
    × 旧: T2 はB≥58、T3 はB≥70 でのみベット
    ○ 新: ターンでは texture に依らず全ハンドで高頻度ベット
           唯一の例外: connector ターン + 低 B texture → やや頻度低下
```

### 5.2 OOP 防御新ルール

```
■ ターンの防御フォールド閾値（OOP check → IP 33%bet 後）
  vs 33% ポット: 20-33% がフォールド（低connected は最大フォールド）
  vs 50% ポット: 26-42% がフォールド
  vs 75% ポット: 38-52% がフォールド

  ■ Texture 別調整:
    rainbow_connected: fold +5-10%（最もフォールドしやすい）
    rainbow_lowconn:   fold -5-8% （最もコール多い）
    その他: 基準値使用
```

### 5.3 リバー ファーストベット新ルール

```
■ リバー ファーストベット（OOP check → IP）
  全体: 43-49% ベット（均一）
  サイズ: 50-75% ポット（分析待ち）

  ブラフ率が高い（≥60%）ケース:
    - mono board（フラッシュ完成リバー）
    - rainbow_connected（ストレート完成リバー）
    - 2tone_conn（コネクテッドリバー）

  バリューヘビー（bluff ≤40%）ケース:
    - paired_high/low
    - rainbow_q
```
