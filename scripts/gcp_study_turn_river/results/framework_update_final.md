## 4. 書籍・poker-drill への改訂提案

### 4.1 巻4・巻5 ターンバレルルール（改訂版）

```
■ ターンバレル（OOP check 後、IP の行動）

【旧ルール（廃止）】
  T1: 常にベット
  T2: B ≥ 58 でベット
  T3: B ≥ 70 でベット

【新ルール】
  ベットサイズ: 33% ポット（全 texture 共通）

  ペア・セット等の強い手（T1）: 常にベット
  2オーバーカード（T2）      : 常にベット（全 texture 66-99%）
  エア（T3）                 : 基本ベット（全 texture 78-99%）

  例外（チェック推奨）:
    - コネクタターン + 低 B（2tone/rainbow, connector card）
      例: 7♣6♦2♠ + 5♥（2tone, connector turn） → T3 チェック ~40%
    - ドロー拒否したいケースは check-raise 選択肢も
```

### 4.2 フロップ T3 閾値修正

```
【旧】T3 フロップ CBet: B ≥ 70
【新】T3 フロップ CBet: B ≥ 67

  追加対象: rainbow_connected（KQJr, QJTr等）
  → T3 air が 40-64%（平均56%）でベット → bet 推奨に格上げ
```

### 4.3 リバー ファーストベット追加

```
【新規】リバー IP ファーストベット（OOP check 後）:
  頻度: 44-49%（全 texture ほぼ均一）
  サイズ: 50-75% ポット（混合使用）
  paired_high は 75-100% 傾向
  
  バリュー/ブラフ比（大まかな目安）:
    bluff 多め（60%超）: mono・rainbow_connected・2tone_conn
    bluff 少なめ（40%未満）: paired_high/low・2tone_ak
```
