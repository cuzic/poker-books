# 第09章　マルチストリート展望

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> フロップでの判断は、フロップだけで完結しません。
> ターンとリバーをどう戦うかを「先読み」してから、フロップの最善手を選ぶ必要があります。
> 本章では SPR（スタック・ポット比率）を使ったマルチストリート設計の考え方を学びます。

---

## 9-1　フロップ判断は「3ストリートの設計図」

ポーカーは 1 手単位で最善手を選ぶゲームではありません。
フロップ・ターン・リバーという 3 つのストリートを通じた「線」として判断することが重要です。

### なぜ先読みが必要か

たとえばフロップで 33% CBet を選んだとします。
コールされた後、ターン・リバーでもベットできる余裕（スタック）があるかを確認しておかなければ、途中で打つ手がなくなることがあります。

逆に、フロップで 75% CBet を打つと、ターンで追加ベットした時点でスタックが残り少なくなり、相手をオールインへ追い込む「コミットメント」状態が早めに来ます。

```
マルチストリート設計の考え方:
  フロップでのサイズ選択 → ポット・スタックの変化 → ターン以降の選択肢
  先読みなしにフロップ単体で判断すると、後から動けなくなる
```

---

## 9-2　SPR（スタック・ポット比率）の復習

**SPR**（Stack-to-Pot Ratio）とは、現在のスタックをポットで割った値です。
Vol2 で学んだとおり、SPR の大小がコミットメントの基準を決めます。

```
SPR = 残りスタック ÷ 現在のポット

例: SRP（シングルレイズドポット）フロップ後
  スタック = 97bb（初期 100bb - オープン 3bb）
  ポット = 6bb（BTN 3bb + BB 3bb）
  SPR = 97 ÷ 6 ≈ 16（大 SPR）
```

大 SPR ではまだ 3 ストリート全部使う余裕があります。
小 SPR では早めにオールインを意識した判断が必要です。

---

## 9-3　フロップ CBet サイズとターン後の SPR

フロップで CBet したあと、コールされたときの SPR がどう変化するかを確認します。

### 33% CBet の場合

```
フロップ 33% CBet（2bb）:
  IP ベット: 2bb
  ポット変化: 6bb + 2bb(IP) + 2bb(OOP コール) = 10bb
  スタック変化: 97bb - 2bb = 95bb（IP 側）
  ターン開始時 SPR = 95 ÷ 10 = 9.5
```

ターン SPR が約 9.5 という状態は「まだ余裕がある」状態です。
T1 も T2 もターンでベットを検討できます。

### 75% CBet の場合

```
フロップ 75% CBet（4.5bb）:
  ポット変化: 6bb + 4.5bb(IP) + 4.5bb(OOP コール) = 15bb
  スタック変化: 97bb - 4.5bb = 92.5bb（IP 側）
  ターン開始時 SPR = 92.5 ÷ 15 ≈ 6.2
```

ターン SPR が約 6.2 になります。
ここでターン 75% ベット（約 11bb）を打つと、リバー SPR ≈ 2 になりオールインが視野に入ります。

### 3bet ポット（3BP）の場合

3bet ポットでは最初からポットが大きく、SPR が低い状態でフロップを迎えます。

```
3bet ポット（pot=30bb, スタック=70bb）:
  フロップ SPR ≈ 70 ÷ 30 ≈ 2.3（小 SPR）
  フロップ 75% CBet（22.5bb）後の SPR ≈ 1.0（ほぼコミット）
```

3BP ではフロップ 75% CBet だけでコミット状態になります。
T2（HS 20〜64）のハンドで 3BP を戦う場合は、フロップ時点で「リバーまで全スタックを使うか」を意識する必要があります。

---

## 9-4　フロップサイズ別の「未来設計」

フロップ CBet のサイズ選択は、その後のストリート構造を規定します。

### 33% CBet の「3ストリート設計」

```
33% フロップ CBet の未来:
  ターン SPR ≈ 9.5 → ターンで 33% ベット可能
  ターン 33% 後の SPR ≈ 6〜7 → リバーでも中〜大サイズ可能
  3ストリートすべてで判断の余地がある

  適したハンド:
    T1（HS ≥ 65）: 3ストリートでバリューを積み上げる
    T2（HS 20〜64）: ターンでドロー改善を確認してから継続/撤退を判断
    T3（HS < 20）: フロップで相手をフォールドさせたいが、ターンで諦めてもよい
```

### 75% CBet の「2ストリート設計」

```
75% フロップ CBet の未来:
  ターン SPR ≈ 6.2 → ターン 75% でリバーはほぼオールイン
  2ストリートでコミットメントに持ち込む構造
  T1 限定の戦略。T2 以下はフロップで判断できるハンドのみ

  適したハンド:
    T1 上位（HS ≥ 65 かつナッツ確率高い）: 2ストリートで全スタック獲得を狙う
    T2 は 75% 後にターンで困る可能性が高い
    T3 ブラフ: 乾燥ボード（B ≥ 62）でフォールドを引き出してワンショット勝負
```

## 9-5　ドローハンドのマルチストリート計画

フラッシュドロー（FD）や OESD（オープンエンドストレートドロー）を持つ T2/T3 ハンドは、マルチストリートの計画が特に重要です。

### セミブラフの構造

セミブラフとは「現時点ではブラフ（役がない）だが、ターンかリバーで改善する可能性があるベット」です。

```
セミブラフの例: J♣T♣ on Q♣8♣4♦（2トーン）
  現在の役: 役なし（Q ハイ）
  ドロー: OESD（J-T-Q-8、7か Kで完成）+ FD（♣フラッシュドロー）
  HS ≈ 42（OESD: +12, FD: +13, 役なし: 0）

マルチストリート計画:
  フロップ CBet → ターンで FD/OESD 改善なら継続バリューベット
  フロップ CBet → ターンで改善なしならチェックバックまたはフォールド
  フロップ チェック → ターンでフラッシュ完成 → バリューベット
```

### ドロー miss のケース

ドローが外れた場合（ターンでもリバーでも改善しなかった場合）、どう対処するかも計画の一部です。

```
ドロー miss の処理:
  フロップ CBet → ターン miss → チェックバック → リバーで判断
  フロップ チェック → ターン miss → チェック継続またはリバーブラフ
  SPR が小さいならブラフを打っても追いかけやすい
  SPR が大きいならドロー miss はおとなしく撤退が多い
```

## 9-6　AK on K72r のマルチストリート計画例

具体的な例で確認します。SRP のフロップ（pot=6bb、stack=97bb）を想定します。

**ボード**: K♣7♦2♠（ドライ rainbow、B=62）
**ハンド**: A♠K♠（TPTK、HS ≈ 71、T1）

```
フロップ:
  AK on K72r は T1（TPTK、HS ≈ 71）
  乾燥ボードで IP ナッツアドバンテージ大
  → 33% CBet（2bb）が標準的な選択

  コールされた後:
    ポット = 10bb、スタック = 95bb、SPR = 9.5

ターン（例: 5♦ ブランクターン）:
  AK はまだ TPTK のまま。ボードに変化なし
  SPR = 9.5（余裕あり）
  → 継続 CBet 33〜50%（3〜5bb）が有力

リバー（例: J♣）:
  K-J-7-5-2 ボード。AK は TPTK のまま（Kペア + A キッカー）
  ストレートやフラッシュの完成なし
  → バリューベット 50〜75%（リバーはやや大きくしてバリューを最大化）
```

3ストリートを通じて T1 のバリューを積み上げる設計の典型例です。

## ミニクイズ

### 問1

SRP フロップ（pot=6bb、stack=97bb）で IP が 33% CBet（2bb）、OOP がコールしました。
ターン開始時の SPR はいくつですか？

1. SPR ≈ 5
2. SPR ≈ 9.5
3. SPR ≈ 16

### 問2

3bet ポット（pot=30bb、stack=70bb）でフロップを迎えました。
この状況で IP が 75% CBet（22.5bb）を打った後、リバーまで到達するとどのような状態になりますか？

1. SPR が約 6〜7 程度で、リバーでもまだ選択肢が多い
2. SPR がほぼ 1 以下になり、ほぼコミットメント状態になる
3. スタックに余裕が大きく、3ストリート全部使える

### 問3

フラッシュドロー（FD）を持つ T2 ハンドで、フロップ CBet 後にターンでドローが外れました。
この場合の一般的な対処として最も適切なものはどれですか？

1. SPR が大きければ、ターン miss でもリバーまで全ベットを継続する
2. SPR が大きければ、ターン miss ではチェックバックなどで撤退が多い選択肢になる
3. ドロー miss は常に即フォールドが正解

---

### 解答

- **問1**: **2. SPR ≈ 9.5** が正解。33% CBet（2bb）コール後のポットは 10bb、スタックは 95bb（97 - 2）。SPR = 95 ÷ 10 = 9.5 です。
- **問2**: **2. ほぼコミットメント状態** が正解。フロップ 75% CBet（22.5bb）後のポットは 75bb、スタックは 47.5bb。ターンでさらに 75% ベットすればスタックはほとんどなくなります。3BP では小 SPR のためコミットが早く来ます。
- **問3**: **2. 撤退が多い選択肢** が正解。SPR が大きいとき（SRP など）はドロー miss 後に無理してベットを継続するより、チェックバックで次のストリートを安く見るほうが多くの局面で合理的です。SPR が小さいときはブラフを打って一気にコミットを目指すケースもあります。

---

> **本章まとめ**
>
> - フロップ判断は「3ストリートの設計図」を先に描いてから行う。
> - 33% CBet 後のターン SPR ≈ 9.5（余裕あり）、75% CBet 後のターン SPR ≈ 6.2（コミット近い）。
> - 33% CBet は T1/T2 が 3ストリート全部使える「余裕ある設計」に向く。
> - 75% CBet は T1 上位がターン・リバーで一気に押し込む「2ストリート設計」に向く。
> - ドロー（FD/OESD）はターンで改善したら継続、miss なら SPR に応じて撤退か勝負を決める。
> - 3bet ポットは SPR が低く（約 2〜3）、フロップ時点でコミットメントを意識した判断が必要。

---

**【GTO とのズレ】**

本章の SPR 計算と設計指針は実戦的な目安ですが、GTO はポットの構造だけでなくレンジ全体のエクイティを見てターン・リバーの頻度を決定します。
T2 ハンドが「ターン miss で全撤退」と固定的に行動すると、相手に読まれてエクスプロイトされる可能性があります。
GTO 均衡ではターン miss でも一定の頻度でベット継続（ブラフバレル）が含まれるため、巻④・巻⑤でターン・リバーを学ぶ際にその割合を確認してください。
