## 巻2 からのブリッジ

巻2第17章で相手タイプを **Nit / TAG / LAG / Fish** の4分類で粗く扱い、各タイプに対して「CBet頻度を増やす / 減らす」の定性的な戦略を示しました。

第III部ではこれを**連続値**で精密化します。HUD統計（VPIP、PFR、AFqなど）の7指標から、E (Exploit) 補正値を連続的に算出し、巻2の9マスマトリクスの頻度を微調整します。

## 10-1　HUD 統計 7 指標

### 基本指標 3 つ

1. **VPIP (Voluntarily Put Money in Pot)**: ポットに自発的に参加した頻度
   - 標準 (6-max 100BB): 22-25%
   - Nit: ≤ 16%、TAG: 18-25%、LAG: 28-35%、Fish: 35%+

2. **PFR (Pre-Flop Raise)**: プリフロップでレイズした頻度
   - 標準： 18-22%
   - VPIPとの関係： VPIP/PFR比が1.1-1.3が理想的 (TAG)

3. **AFq (Aggression Frequency)**: アグレッシブアクションの頻度
   - 標準： 40-55%
   - Nit: ≤ 30%、TAG: 40-55%、LAG: 55-75%、Fish: ≤ 25%

### 応用指標 4 つ

1. **3Bet%**: プリフロップで3betする頻度
   - 標準： 5-9%

2. **Fold vs CBet%**: CBetに対してフォールドする頻度
   - 標準： 55-65%

3. **CBet%**: 自分がCBetする頻度
   - 標準 (IP): 55-65%、(OOP): 25-35%

4. **Check-Raise%**: チェックレイズする頻度
   - 標準： 8-12%

## 10-2　サンプル数と信頼性

HUD統計は**サンプル数**で信頼性が決まります。

### 収束目安

```
VPIP、PFR: 100-200 ハンドで概ね収束
AFq: 200-300 ハンドで収束
3Bet%: 500 ハンド以上
Fold vs CBet%: 500 ハンド以上
Check-Raise%: 1,000 ハンド以上
```

### サンプル不足での扱い

```
< 500 ハンド: VPIP/PFR のみ参照、他は「標準値」と仮定
500-1000: 基本 3 指標 + 3Bet% を参照
1000+: 全指標を使ったエクスプロイト
```

### フロップ特化統計は要注意

「CBet on J-high flops」のような特化統計は、サンプル200以下では**ほぼ無意味**。細分化しすぎるとサンプルが足りなくなる。

---

## 10-3　VPIP-PFR ギャップ ― パッシブ度の指標

### 定義

```
Gap = VPIP − PFR
```

Gapが大きいほど **「コールするがレイズしない」** 傾向 → パッシブ。

### Gap 別のプレイヤー像

| Gap | プレイヤー像 |
|:---:|------|
| 2-4% | 理想的 TAG (ほぼすべてをレイズで開く) |
| 5-7% | 標準、TAG だが一部コールドコール |
| 8-12% | 少しパッシブ、コールドコール多め |
| 13%+ | **Fish** (コール中心、レイズ少) |

### Gap を使ったエクスプロイト

```
Gap 大 (Fish 寄り):
  - 相手の 3bet は強い (プレミアム) → フォールド
  - 相手のコールに対して バリューを厚く → 広くバリューベット

Gap 小 (TAG/LAG 寄り):
  - 相手の 3bet にブラフも含まれる → 4bet コール基準を緩める
  - 相手のコールはレンジが広い → ドロー系セミブラフ推奨
```

---

## 10-4　E 補正式の構築

### 3 指標合成式

巻2の9マスマトリクスの頻度に、HUD統計からの補正値Eを加えます。

```
E = V_score × 0.4 + P_score × 0.4 + A_score × 0.2

V_score = (相手の VPIP − 22) / 10
  (標準 22%、10% 差で 1.0 スコア)

P_score = (相手の PFR − 18) / 10
  (標準 18%、10% 差で 1.0 スコア)

A_score = (相手の AFq − 45) / 20
  (標準 45%、20% 差で 1.0 スコア)
```

### E の範囲と意味

```
E = -1.5 〜 +1.5 が通常範囲

E = -1.5 (Nit、FIsh パッシブ)  → 相手はブラフ少 → 自分のブラフを削減、相手のベットにフォールド
E = 0 (TAG、標準)             → 補正なし、GTO に近い対応
E = +1.5 (LAG、超アグレ)       → 相手はブラフ多 → ブラフキャッチ増、サイズ調整
```

### フロップでの具体補正

9マスマトリクスの頻度をEで調整：。

```
調整後の CBet 頻度 = 基本頻度 + E × (サイズ係数)

サイズ係数:
  33% CBet: ±5%
  50% CBet: ±8%
  75% CBet: ±10%
```

例： E = -1（Nit寄り）で基本75% CBet → 75% − 10% = **65% CBet** に下げる。

---

## 10-5　フロップ型別の E 補正強弱

E補正の効き方は、**フロップの型**で異なります。

### 型別の補正強度

| フロップ型 | E の効き | 理由 |
|:---:|:---:|------|
| 型1 (ハイ×ドライ) | **強い** | ブラフの幅が大きい型なので、相手タイプで最適頻度が変わる |
| 型2 (ハイ×ウェット) | 中 | ブラフはドロー付きのみ、タイプの影響中程度 |
| 型3 (ロー×ドライ) | 中 | BB のディフェンスが広い、タイプで微妙に変わる |
| 型4 (ロー×ウェット) | 弱 | ほぼ決定論、タイプの影響小 |
| 型5 (モノトーン) | 弱 | 固定 20% でほぼ動かない |
| 型6 (ペア+高キッカー) | 中 | ブラフの余地あり、タイプで調整 |
| 型7 (ペア、そのほか) | 強い | K44 のような特殊ボードはタイプで大きく変わる |

### 強タイプボードでの使い方

型1と型7はEの効きが大きい → タイプ別の頻度差が20% になることも。

```
型1 K72r、基本 85%:
  Nit (E = -1.2): 85% − 12% = 73%
  TAG (E = 0): 85%
  LAG (E = +1.0): 85% + 10% = 95%
```

型1ではNit相手にCBet頻度を10% 以上下げる。これが決定論との大きな差。

## 10-6　実戦ケース 12 問 (粗い vs 精密)

巻2の粗い分類と、巻3の精密E補正の差を12例で比較。

### ケース 1: Nit 相手の K72r、自ハンド AJ

```
巻2 粗い:
  - Nit → CBet 頻度増やす、75% 打つ
  - → CBet 75%

巻3 精密:
  - E = -1.0 (VPIP 15%、PFR 12%、AFq 30%)
  - 型1 × Nit → 頻度 85% − 10% = 75%、サイズ調整なし
  - 自ハンド TPGK は CBet 対象 (高頻度 × 強)
  - → CBet 50% (Nit 相手は 75% より 50% でコール範囲が広がる)
```

### ケース 2: LAG 相手の K72r、自ハンド AQo (BDFDなし、弱)

```
巻2 粗い:
  - LAG → ブラフ減らす
  - AQo 弱ハンド → チェック

巻3 精密:
  - E = +1.2 (VPIP 32%、PFR 26%、AFq 65%)
  - 型1 × LAG → 頻度 85% + 12% = 97% (ほぼ押し) だが、個別ハンドは E で調整
  - AQo は レンジの下位 → LAG 相手はブラフキャッチされやすい
  - → チェック (粗いとも一致)
```

### ケース 3-12 (概要)

各ケースでE = -1のNitとE = +1のLAGで判断が異なる状況を想定。一般原則：。

- Nit相手： **広くブラフキャッチ不要、自分のブラフを減らす、大サイズベットはフォールド**
- LAG相手： **ブラフキャッチ増、自分のブラフは選別、チェックレイズ誘引**
- Fish相手： **ブラフ封印、バリューを厚く、広くバリューベット**

## 10-7　ライブポーカーでの代用法

HUDが使えないライブでは、1オービット（5-6ハンド）の観察でVPIPを推定。

### 1 オービット 5 項目チェックリスト

```
1. 何ハンドに参加したか? (VPIP 推定)
2. そのうち何回レイズしたか? (PFR 推定)
3. フロップで何回 CBet したか? (CBet% 推定)
4. チェックレイズを 1 回でも見たか? (CR% 推定)
5. ショーダウンで何を見せたか? (レンジ質)
```

### ライブでの E 補正の粗い推定

```
5 ハンド中:
  0-1 ハンド参加 + 積極レイズ → Nit (E = -1.0)
  2-3 ハンド参加 + 多彩 → TAG (E = 0)
  3-4 ハンド参加 + CBet 多 → LAG (E = +0.5〜+1.0)
  4+ ハンド参加 + コール中心 → Fish (E = -1.0、パッシブ補正)
```

ライブでは観察精度が低いため、補正量も30% 程度に抑える（HUDの場合の0.7倍）。

## 10-8　巻2 コールステーション E 補正の訂正

巻2第17章で「コールステーション → E = -3」と記述していましたが、本章の連続値で再定義すると：。

### 訂正の根拠

コールステーション（Fishパッシブ）の特性：。

- VPIP高い → V_score > 0
- PFR低い → P_score < 0
- AFq低い → A_score < 0

合成したEは：。

```
E = 0.5 × 0.4 + (-1.0) × 0.4 + (-1.0) × 0.2 = -0.4
```

つまりE = -0.4程度で、「-3」ほど極端ではない。

### 訂正後の戦略

```
コールステーション (E = -0.4):
  - 自分のブラフを 減らす (5-10%)
  - バリューを厚く (サイズを 50% → 75% に上げる)
  - 広くバリューベット (TPWK でも打つ)
```

巻2の「E = -3」は「ブラフを激減させる」という方向性は正しかったが、数値は誇張気味でした。本章の連続値で修正。

## 10-9　動的な E の更新

Eは固定値ではなく、**動的に変化**します。

### 変化要因

```
セッション内で相手が変化 → E も変化
  - 相手が長時間プレイで疲れる → パッシブ化 (E 低下)
  - 相手が負けていて Tilt → アグレ化 (E 上昇)
  - 相手がラグり後に戻ってくる → 一時的に弱化
```

### 更新の頻度

- **10-20 ハンドごと**に相手のプレイを再評価
- 明確な変化（チェックレイズ連発、コール続き）を察知したら即E調整

### 動的調整の限界

過度な動的調整は自分のプレイを揺らがせる。**「15 ハンドで E = -1 → +0.5」のような急変は避け**、穏やかな更新を心がける。

---

## 10-10　HUD 統計の落とし穴

### 落とし穴 1: サンプル不足

500ハンド未満での判定は信頼性低い。「この相手はVPIP 40% だからFish」と200ハンドで決めつけると誤る。

### 落とし穴 2: セッション固有のバイアス

ある日のセッションだけ異常にアグレ（Tilt中、酔っている）な場合、長期HUD統計と一致しない。

### 落とし穴 3: 相手のレベル認識

HUDを見ていることを相手が知っている場合、**逆テル**（意図的に崩れた統計を出す）の可能性あり。レベル3以上のプレイヤーには警戒 （第13章メタゲーム）。

---

## 🎴 ライブポーカーでの代用法

ライブでは HUD は使えませんが、**1 オービット (5-6 ハンド) の直接観察**で E 補正相当の情報を得られます。

### 5 項目チェックリスト (1 オービット観察)

1. **何ハンドに参加したか?** → VPIP 推定 (オービット中 2/6 なら VPIP 33%)
2. **そのうち何回レイズしたか?** → PFR 推定
3. **フロップで何回 CBet したか?** → CBet 傾向
4. **チェックレイズを 1 回でも見たか?** → CR 頻度 (0 なら Nit or Fish 寄り)
5. **ショーダウンで何を見せたか?** → レンジ質の直接観測

### ライブ用の粗い E 推定

```
5 ハンド中:
  0-1 ハンド参加 + 積極レイズ → Nit (E ≈ -1.0)
  2-3 ハンド参加 + バランス型 → TAG (E ≈ 0)
  3-4 ハンド参加 + CBet 多 → LAG (E ≈ +0.5〜+1.0)
  4+ ハンド参加 + コール中心 → Fish (E ≈ -0.4、パッシブ補正)
```

### ライブでは補正量を 30% 減

ライブ観察は精度が低いため、本章の E 補正を **0.7 倍** にして適用。過度な搾取は避ける。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: HUD 統計さえあれば正確にエクスプロイトできる。

**✅ 正解**: サンプル 500 未満の HUD 統計には大きなノイズがある。少サンプルでは標準値を前提にした判断を優先すべきで、統計値を無条件に信用するとかえって判断が歪む。

## 章のまとめ

- HUD 7指標 (VPIP/PFR/AFq/3Bet/Fold vs CB/CB/CR) で相手を連続値評価
- E補正式： E = V×0.4 + P×0.4 + A×0.2（範囲 -1.5 〜 +1.5）
- フロップの頻度をEで調整（サイズごとに ±5-10%）
- 型別のE効きは型1/型7で強い
- ライブでは1オービット観察でEを粗く推定
- 巻2の「コールステーションE = -3」はE = -0.4に訂正

## ミニクイズ

### 問 1

**相手の HUD 統計: VPIP 18%、PFR 15%、AFq 38%**。Eを計算してください。

<details>
<summary>解答</summary>

```
V_score = (18 - 22) / 10 = -0.4
P_score = (15 - 18) / 10 = -0.3
A_score = (38 - 45) / 20 = -0.35

E = -0.4 × 0.4 + (-0.3) × 0.4 + (-0.35) × 0.2
  = -0.16 - 0.12 - 0.07 = -0.35
```

**答え: E = -0.35 (Nit 寄りの TAG)**

VPIP 18% はNitの境界だが、3つの指標合成でE = -0.35。軽いNit補正を加える。

</details>

### 問 2

**相手の HUD: VPIP 34%、PFR 28%、AFq 65%**。Eとフロップ戦略の修正は？

<details>
<summary>解答</summary>

```
V_score = (34 - 22) / 10 = +1.2
P_score = (28 - 18) / 10 = +1.0
A_score = (65 - 45) / 20 = +1.0

E = 1.2 × 0.4 + 1.0 × 0.4 + 1.0 × 0.2
  = 0.48 + 0.40 + 0.20 = +1.08
```

**答え: E = +1.08 (LAG)**

戦略： LAG相手では、。

- ブラフキャッチを増やす (MDF +10%)
- 自分のブラフは減らす（特にBDFDなしエアー）
- チェックレイズ誘引が機能しやすい

</details>

### 問 3

**相手の HUD: VPIP 45%、PFR 12%、AFq 22%** (Fish)。Eは？

<details>
<summary>解答</summary>

```
V_score = (45 - 22) / 10 = +2.3
P_score = (12 - 18) / 10 = -0.6
A_score = (22 - 45) / 20 = -1.15

E = 2.3 × 0.4 + (-0.6) × 0.4 + (-1.15) × 0.2
  = 0.92 - 0.24 - 0.23 = +0.45
```

**答え: E = +0.45 (Fish、パッシブ気味だが参加率高)**

戦略： Fish相手では。

- ブラフ封印（フォールドしない）
- バリュー厚く（サイズ大、ストリート伸ばし）
- 広くバリューベット（TP弱キッカーでも打つ）

VPIPが高すぎるのでParadoxically Eがプラスになる。パッシブ成分は **個別の AFq 補正** で扱う。

</details>
