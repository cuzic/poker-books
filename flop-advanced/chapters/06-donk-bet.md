# 第06章　ドンクベット

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ドンクベットが機能する条件と危険なケースを理解し、GTO 的に使える限られた場面を判断できるようになる。

---

## 6-1　ドンクベットとは何か

**ドンクベット（donk bet）** とは、OOP（アウトオブポジション）のプレイヤーが、フロップのチェックを経ず、またはIPがチェックバックした後のターンで先にベットする行動です。

名前の由来は「donkey（ロバ）」——つまり最適でない動きをする初心者を指す俗語からきています。
かつてはドンクベットはほぼ全て悪いプレイとみなされていました。
しかし現代の GTO 研究では、**特定の条件を満たすボードでは一定頻度でドンクベットが均衡に含まれる**ことが明らかになっています。

ドンクベットの基本的な流れ：

```
【パターン1：フロップでのドンクベット】
  フロップ: OOP が先にベット（チェックせずに）

【パターン2：ターンでのドンクベット（より一般的）】
  フロップ: OOP チェック → IP チェックバック
  ターン:  OOP が先にベット
```

本章では主に「IP がフロップでチェックバックした後のターンでの donk bet」を扱います。
フロップからの donk bet は GTO ではさらに限定的な頻度となります。

---

## 6-2　ドンクベットが機能する条件

ドンクベットが高いEVを持つのは、**OOP のレンジが IP よりも明確にアドバンテージを持つ状況**に限られます。

GTO 的に機能するドンクベットの主な条件：

```
条件1: OOP のレンジがボードに特に有利
  例: BB（OOP）vs BTN（IP）、フロップ A♣2♦3♠
  BB のレンジ: A2s・A3s・23s・45s など低カードが豊富
  → トップペア・2ペア・ストレート系が BB に偏っている
  → BTN のプリフロップレンジには A23 系が少ない

条件2: ロー・コネクテッドボード（5-6-7、4-5-6 タイプ）
  BB のレンジ: 低いペア + ドローが多い
  BTN のレンジ: 高カードが中心でこのボードは当たりにくい
  → BB のレンジアドバンテージが大きい

条件3: IP がフロップでチェックバックした後（弱いレンジ確定）
  IP がチェックバックした = 強いハンドがない可能性が高い
  → ターンで OOP がベットする EV が上がる
```

逆に**ドンクベットが逆効果になるケース**：

```
A-K-Q high など IP（BTN）のレンジが有利なボード:
  BTN は AK・AQ・KQ など高カードが豊富
  BB のレンジはこのボードに当たりにくい
  → ドンクベットは OOP の弱さを宣伝するだけになる

IP が高頻度で CBet するボード（B≥62）:
  IP がほぼ必ずベットするため、OOP は check-raise の方が情報を得られる
  → ドンクは先手を失う上にポットコントロールも難しい
```

## 6-3　ドンクベットのサイズ選択

ドンクベットのサイズは、目的と相手の想定アクションによって変えます。

### スモールドンク（25〜33%ポット）

```
目的: 情報収集 + 弱いレンジとのポット構築
使い所:
  - IP の後ろにある手がわからない段階での見極め
  - 相手がよくフォールドするボードでの頻度的なベット
  - OOP が自分のハンド強度に確信がない場合

メリット: IP にとってコールのコストが安く情報を得やすい
デメリット: OOP の受けるリスクが IP の3bet時に大きくなる
```

### ミディアムドンク（50〜75%ポット）

```
目的: バリュー（セット・2ペア）のポット拡大
使い所:
  - ナッツクラスのハンドで相手がコールしそうなとき
  - 相手のコールレンジが広いボードでのバリューベット

メリット: 強いハンドでのポット拡大が最大化しやすい
デメリット: IP がレイズしてきた場合のリスクが大きい
```

### ラージドンク（100%以上）

```
目的: ブラフ遮断 or ナッツ確定のポットオーバーベット
GTO では非常に稀。OOP のナッツアドバンテージが圧倒的な限定場面のみ。
```

実戦では**スモールからミディアム（25〜50%）が最も扱いやすい**サイズです。
IP の3bet や大きなレイズへの対応コストが抑えられます。

## 6-4　ドンクベット vs チェック-コール vs チェック-レイズの比較

同じ状況でドンクベットとその他の選択肢を比較します。

```
【シナリオ】SRP BB vs BTN、フロップ 6♣5♦4♠、BB は 2ペア（65s）保有

選択肢1: check → IP CBet → OOP call（チェック-コール）
  メリット: IP のCBetサイズが小さければコールが安く済む
  デメリット: ポットが大きくならず、バリューを最大化できない
  IP の情報: IP のCBet頻度・サイズからレンジを推測できる

選択肢2: check → IP CBet → OOP raise（チェック-レイズ）
  メリット: ポットを大きくできる。IP のチェックバックを防げる
  デメリット: IP がチェックバックした場合、ターンまでアクション遅延
  IP の情報: OOP のCRレンジを読まれやすい

選択肢3: donk bet（先にベット）
  メリット: OOP がポットサイズをコントロールできる。IP の2バレルを防げる
  デメリット: IP のCR（レイズ）リスクがある。IP がフォールドして利益が薄れることも
  IP の情報: OOP の先制ベット＝強いハンドと読まれやすい
```

IP がCBetすると想定されるボードでは、チェック-レイズの方が情報収集できて効果的です。
IP がチェックバックしそうなボード（弱いレンジ、B値が低いボードなど）では、donk bet でポット構築を狙う選択が有効になります。

---

## 6-5　実例：ドンクベットが有効な場面

**場面1**：BB vs BTN、フロップ A♣2♦3♠（pot=6bb）、BBがフロップでチェック、BTNがチェックバック

```
ターンカード: 5♠（ボードが A-2-3-5 に）

BTN がチェックバックした意味:
  BTN は強いハンドを持っていない可能性が高い（CBetを控えた弱めのレンジ）

BB のレンジ:
  A2s・A3s: 2ペアor トップペア完成
  45s: ストレート完成（2-3-4-5-A）
  23s: 2ペア維持

BB の判断:
  この状況では BB のレンジアドバンテージが大きい。
  donk bet（25〜33%）でポットを構築しつつ、BTN のコールレンジを試す。
```

**場面2**：BB vs BTN、フロップ 7♣6♦5♠（pot=6bb）、BBがフロップチェック、BTNがチェックバック

```
ターンカード: 2♠（ボードが 7-6-5-2 に）

BTN チェックバックの意味:
  BTN はストレートを持っていない可能性が高い

BB のレンジ:
  87s・98s: ストレート完成または強いドロー（OESDなど）
  55・66・77: セット完成、ターンカードはほぼブランク

BB の判断:
  OOP のレンジが有利。donk bet（33〜50%）で圧力をかける。
```

## 6-6　ドンクベットのリスクと管理

ドンクベットには固有のリスクがあります。

### リスク1：IP の3bet（ドンクに対するレイズ）

IP がドンクベットに対してレイズしてくる場合があります。
特にスモールドンクに対してIP が3bet してくると、OOP はコールまたはフォールドを迫られます。
このリスクを軽減するには、**レイズされても対抗できるハンド強度（2ペア以上）でドンクする**ことが重要です。

```
ドンクした後にIP がレイズしてきた場合の判断目安:
  セット・ストレート: 4bet またはオールインで対抗可
  2ペア: コールまたは4bet でポットオッズを考慮
  1ペア・ドロー: フォールド検討（レイズは強いハンドのシグナル）
```

### リスク2：IP がフォールドして利益が薄れる

ドンクベットのサイズが大きいほど IP はフォールドしやすくなります。
バリューハンドでドンクしても IP がフォールドすれば最大利益を得られません。
スモールドンクで IP のコールを誘う方が長期的な EV が高いことがあります。

### リスク3：OOP のレンジが弱く見える

IP がCBetしなかった後にドンクベットすると、「チェックバックを見て動き出した弱いレンジ」と読まれることがあります。
IP がドンクに対して積極的に3betしてくるアグレッシブなプレイヤーには特に注意が必要です。

## 6-7　ドンクベットの実戦での位置づけ

GTO の観点では、ドンクベットの頻度は全体の約5〜15%程度が目安とされています（詳細は巻④ターン・リバー編で扱います）。
ほとんどの状況では**チェック-コールかチェック-レイズ**がデフォルトです。

ドンクベットを使う判断フローは次のとおりです。

```
ドンクベット判断フロー（ターンでの場面）:

Step1: フロップで IP はチェックバックしたか？
  NO（IP がCBetした）→ ドンクではなくチェック-コール/CR を選ぶ
  YES（IP がチェックバック）→ Step2へ

Step2: このボードで OOP のレンジアドバンテージはあるか？
  なし（高カードボード）→ チェックが基本、強ハンドのみ donk 検討
  あり（低コネクテッド・A23タイプ）→ Step3へ

Step3: ドンクするハンドは2ペア以上か？
  YES → donk bet（33〜50%）
  NO（1ペア・ドローのみ）→ チェックで様子見が基本
```

## ミニクイズ

### 問1

ドンクベットが最も機能しやすいボードタイプはどれですか？

1. A-K-Q high のドライボード
2. BBのレンジに低いペア・ストレートドローが豊富な低コネクテッドボード（5-6-7など）
3. BTNが常にCBetする高CBet率のボード
4. モノトーンボード

### 問2

IP がフロップでチェックバックした後のターンで OOP がドンクベットする理由として正しいものはどれですか？

1. IP に強いハンドがあると思うから、先制ベットで情報を得たい
2. IP が弱いレンジ（チェックバック後）のため、OOP がポットをコントロールしやすい状況になっている
3. チェック-レイズよりドンクベットの方が常にEVが高い
4. IPのCBetを防ぐためだけに打つ

### 問3

ドンクベット後に IP が3bet してきた場合、フォールドを検討すべき典型的なハンドはどれですか？

1. セット（ヒット数最多の役）
2. ストレート完成
3. 1ペア単体（ドローなし）
4. 2ペア

---

### 解答

- **問1**: **2**（低コネクテッドボードは BB のレンジに低ペア・ストレートドロー・2ペアが豊富で、BTN のレンジが当たりにくい。OOP のレンジアドバンテージが機能する典型的なボード）
- **問2**: **2**（IP のチェックバックは弱いレンジのシグナル。OOP がドンクでポットを構築すると IP に強いハンドがなければフォールドまたはコールが迫られる。OOP に有利な状況をドンクで活かす）
- **問3**: **3**（1ペア単体では IP の3betに対してエクイティが不十分。フォールドが適切。セット・ストレート・2ペアはコールまたは4betで対抗できる）

---

> **本章まとめ**
>
> - ドンクベットは OOP のレンジアドバンテージが圧倒的な場合に限って機能する高度な技術
> - 機能するボード：低コネクテッド（5-6-7など）・A-2-3型・IP がチェックバックした後のターン
> - 機能しないボード：A-K-Q high ドライ・IP が高頻度CBetするボード（B≥62）
> - 推奨サイズ：25〜50%。スモールドンクで IP のコールを誘い、情報収集が安全
> - GTO頻度は約5〜15%（参考値）。デフォルトはチェック-コール/チェック-レイズ

---

**【GTOとのズレ】**

実戦では「IP がチェックバックしたから弱いはず」という判断で過剰にドンクベットする傾向があります。
しかし IP がチェックバックした理由は多様で、レンジ保護の狙いでのチェックバックも含まれます。
ドンクベットの多用はレンジが読まれやすくなるため、チェック-コールやチェック-レイズとの使い分けが重要です。
★ドンクベットの詳細な GTO 頻度は巻④（ターン・リバー基礎編）で扱います。
