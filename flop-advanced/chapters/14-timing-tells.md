## 14-1　タイミングテル (オンライン) の基礎

### 4 分類

オンラインポーカーで観察できる主要なタイミングパターン：。

```
1. インスタントベット (即 bet、< 1 秒)
2. 長考後のベット (3 秒以上タンク)
3. インスタントコール (即コール)
4. 長考後のコール (タンクコール)
```

各パターンに心理的背景があります。

### タイミングテルを使う 3 つの原則

```
原則 1: サンプル 5 回以上で採用
原則 2: 複数のテル (サイズ + タイミング + 履歴) で裏付け
原則 3: 補助情報として使う (メインは GTO + HUD)
```

---

## 14-2　インスタントベット (< 1 秒)

### 心理的背景

ベットを即決する = **事前に決めていた**。

```
シナリオ A: 事前にバリューを決めていた
  → 強いハンド (セット、AA) で「打つつもり」
  
シナリオ B: 事前にブラフを決めていた
  → レンジベット (33% range bet) の一部
```

### 判定の目安

```
サイズ 33% + インスタント: Range bet の一部 (Nit/TAG)
  → V:B 比は巻② 通り (バリュー 15%、ブラフ 45%)

サイズ 75% + インスタント: 強いバリュー (セット、オーバーペア)
  → バリュー 70%+

オーバーベット + インスタント: ほぼナッツ確定
  → バリュー 90%
```

### 対抗戦略

```
インスタント 75% CBet: TPTK 以下 フォールド
インスタント オーバーベット: セット以下 フォールド
インスタント 33% CBet: 普段通り (情報少)
```

---

## 14-3　長考後のベット (3 秒以上)

### 心理的背景

タンクした後のベット = **難しい判断をしている**。

```
シナリオ A: 中強度ハンドで迷っている
  → 弱 TP、ミドルペア、BDFD 付きの 空振り
  
シナリオ B: 強いハンドだが サイズに迷う
  → セット vs TP、大きく打つか小さく打つか

シナリオ C: 純粋ブラフを決心
  → 「ブラフか、チェックか」で 3 秒タンク → ブラフ
```

### 判定の目安

```
サイズ 33% + タンク: 中強度ハンド or タンクブラフ
  → V:B 比 1:1 (標準より ブラフ比率 増)

サイズ 75% + タンク: 迷うバリュー or タンクブラフ
  → V:B 比 1:1-1.5 (通常の 2:1 より ブラフ増)

サイズ オーバーベット + タンク: 決心ブラフの可能性
  → バリュー 50%、ブラフ 50%
```

### 対抗戦略

```
タンク 75% CBet: ブラフキャッチ余地あり、TPGK でコール
タンク オーバーベット: 広くブラフキャッチ (A ブロッカー系推奨)
```

---

## 14-4　インスタントコール

### 心理的背景

即コール = **自動的にコール決定**。

```
シナリオ A: ドロー (オッズが合うから自動コール)
  → フラッシュドロー、OESD
  
シナリオ B: 強めのハンドで自信あり
  → TPTK、オーバーペア
  
シナリオ C: 弱すぎてタンクせず諦めコール
  → ボトムペア、A ハイ
```

### 判定の目安

```
33% ベットへのインスタントコール: ドロー多、V:B 1:3
  → ターンで カードが落ちたら注意 (ドロー完成警戒)

75% ベットへのインスタントコール: 強めのハンド (TP 以上)
  → 相手の レンジは絞り込まれる
```

### 対抗戦略

```
相手のインスタントコール後、ターンで ドローが 完成するカード (♠ や 8)
  → 相手のレンジに ドロー完成 込み、慎重に

ブランクターン (相手のドロー外れ): さらに バレルで圧力
```

---

## 14-5　長考後のコール

### 心理的背景

タンクコール = **損切り思考** or **微妙なハンド**。

```
シナリオ A: TPWK や ミドルペアで「折るか否か」迷う
  → 弱 TP、7X on 7K2
  
シナリオ B: ブラフキャッチを決心
  → A ブロッカー付き A ハイ
  
シナリオ C: インプライドを狙うドロー
  → 「ドロー完成したら大きく勝てる」と計算
```

### 判定の目安

```
33% ベットへのタンクコール: 弱 TP、ミドルペア
  → 次のストリートで 小さく打って バリュー

75% ベットへのタンクコール: TPGK or ブラフキャッチ
  → 次のストリートで 慎重、サイズ落とす
```

### 対抗戦略

```
相手のタンクコール後:
  - 次のストリート: 相手のレンジが 「中強度」と判明
  - 自分がバリュー: 小さめサイズで引き続き押す
  - 自分がブラフ: 相手がコールしたハンドは 降りにくい → ブラフ停止
```

## 14-6　タイミングテルの活用上の注意

### 注意 1: ネットワーク遅延

オンラインでは**回線遅延**でタイミングがズレることがある。「インスタント」と見えても、実は相手が0.5秒考えている可能性。

### 注意 2: 自動タイマー

多くのポーカーサイトは「タイムバンク」機能がある。相手がタイムバンクを発動している = 大きな判断。

### 注意 3: マルチテーブル

相手が複数テーブルをプレイしている場合、タイミングは**ほかのテーブルの状況**にも影響される。

### 注意 4: 自己テル

自分のタイミングも相手から見られている。**意識的にタイミングを揃える**（即決 / タンク10秒など）ことで自己テルを減らす。

## 14-7　ライブポーカーの物理テル

### 4 つの観察カテゴリ

ライブポーカーで観察できる主要なテル：。

```
1. 呼吸
2. チップ操作
3. 視線
4. 微小表情
```

### 呼吸

```
深く落ち着いた呼吸: バリュー (落ち着きを装う)
浅く早い呼吸: 緊張 (ブラフ or 極めて強い)
呼吸の停止: 集中 (強いハンド)
```

### チップ操作

```
整えるような繰り返し: 思考中、境界判断
一気に前へ: 決断済み、強いか完全ブラフ
「丁寧にスタック」: バリュー (時間稼ぎ、余裕を見せたい)
「雑にベット」: 意図的な攻撃、ブラフの可能性
```

### 視線

```
ポットに視線: バリュー計算中
相手を見つめる: 強気な態度 (演技、通常ブラフ)
目を逸らす: 弱い、ブラフキャッチされたくない
```

### 微小表情

```
瞬間的な口の動き: 情報漏れ
目の動きの止まり: 集中 (強いハンド)
眉の動き: 意識的な演技の可能性
```

## 14-8　ライブテルの信頼性

### 信頼性の高い順

```
高 → 低:
1. 呼吸の急変
2. チップの持ち方 (ベット直前)
3. 視線の方向
4. 微小表情
```

呼吸は意識で制御が難しく、最も信頼性が高い。微小表情は文化差が大きく、最も信頼性が低い。

### サンプル要件

ライブテルも**5 回以上の観察**が前提。1-2回での決めつけは誤読の元。

### 著作権への配慮

物理テルの詳細はZachary Elwood *Reading Poker Tells* (2012) やJoe Navarro *Read 'Em and Reap* (2006) などの専門書が詳しい。本書は戦略本として**補助情報の扱い**のみを示し、詳細な解剖は避けます。

## 14-9　テル統合の実戦例

タイミング + サイズ + 履歴 +（ライブなら）物理の複合観察：。

### 例 1: オンライン TAG の境界判断

```
状況: TAG 相手、K72r、相手 BTN が CBet 50% (+2 秒タンク)
自ハンド: 77 (アンダーペア)

サイズ判定: 50% (中庸、bluff キャッチ余地)
タイミング判定: タンク = 中強度ハンド or タンクブラフ
  → V:B 比 1:1 想定
  → 77 のコール価値: Bluff キャッチ 50%、負け 50%
  → 後手下限確率 67% も考慮 → **コール**
```

### 例 2: ライブ Fish の大きなベット

```
状況: Fish 相手、オーバーベット 120%、インスタント
自ハンド: AA on T72r

サイズ判定: オーバーベット = ほぼナッツ
タイミング判定: インスタント = 事前決定
物理テル (ライブ):
  - 相手 深呼吸 → 強い確信
  - チップ一気に前 → 決断済み
  → AA も危険、TT や 77 のセットの可能性
  → **タンクフォールド寄り**
```

### 例 3: オンライン LAG のブラフキャッチ

```
状況: LAG 相手、ターン 75%、相手タンク 5 秒
自ハンド: KQ (TPWK)

サイズ判定: 75% = ポーラード化、LAG なら ブラフ比率 高い
タイミング判定: タンク → タンクブラフ or 迷うバリュー
  LAG のタンクは ブラフ多い (TAG より)
  → V:B 比 1:1.5 (ブラフ 60%)
  → KQ でキャッチ価値あり
  → **コール**
```

## 14-10　自己テル対策

自分が漏らすテルを最小化：。

### オンラインでの自己テル対策

```
1. 毎ベットで 同じタイミング (1-2 秒で決める)
2. タイムバンクを使うタイミングを固定
3. マルチテーブルでも テーブルごとに一定ペース
```

### ライブでの自己テル対策

```
1. 呼吸を一定に保つ (吸って 4 秒、吐いて 4 秒)
2. チップ操作を 毎ハンド同じパターンに
3. 視線をカードに固定 (相手を見ない)
4. 帽子・サングラスで表情隠し (合法)
```

## 🎴 ライブ中心のプレイヤー向け: 本章の重点配分

本章はオンラインのタイミングテル (14-2〜14-6 節) とライブの物理テル (14-7〜14-9 節) の両方を扱いますが、ライブ中心の読者は**後半に重心を置く**ことを推奨します。

### ライブベテランのための読書順序

```
Step 1: 14-7 節 (物理テル 4 カテゴリ) から読み始める
Step 2: 14-8 節 (信頼性順) で呼吸・チップ・視線・表情の優先度を把握
Step 3: 14-9 節 (統合例) の 2 番目 (ライブ Fish の大きなベット) を精読
Step 4: 14-6 節 (活用ルール、5 回以上サンプル) に戻って原則確認
Step 5: 14-2〜14-5 (オンラインタイミング) は飛ばして OK、必要時に戻る
```

### ライブでの補完: サイジング × 物理テルの統合

ライブではオンラインのタイミング情報は得にくいため、**サイジング (第8章) + 物理テル (本章後半)** の 2 軸で判断します。

```
相手が大きく打ってきた + 呼吸浅い → ブラフ寄り (コール or レイズ検討)
相手が大きく打ってきた + 呼吸深く落ち着く → バリュー確定 (フォールド寄り)
相手が小さく打ってきた + チップ雑 → レンジベット、通常通り
相手が小さく打ってきた + チップ丁寧 → 誘引狙い (要警戒)
```

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: 物理テルを観察すれば常に相手のハンドがわかる。

**✅ 正解**: 物理テルは補助情報にすぎない。サンプル 5 回以上の観察を積み重ね、サイズや過去の履歴と三角測量することで初めて判断精度が上がる。単一のテルだけで結論を出すのは危険。

## ミニクイズ

### 問 1

**TAG 相手がフロップで インスタント 75% CBet**。自ハンドAK (TPTK)。コールorフォールド？

<details>
<summary>解答</summary>

```
サイズ 75% + インスタント = 強いバリュー確定 (事前決定)
相手 TAG のインスタント 75%: バリュー 80%+ 推定
  セット、オーバーペア、TPTK (自分と同等)

AK は TPTK として相手と同等 or 負け
  → 境界判断

サイズが 75% オーバーベットならフォールド、75% ポット以下なら コール寄り
```

**答え: 境界、75% ポットなら コール、それ以上なら フォールド**

</details>

### 問 2

**LAG 相手がターンで タンク 5 秒後にオーバーベット 120%**。自ハンドKQ（TPGK + BDFDあり）。コール？

<details>
<summary>解答</summary>

```
オーバーベット + タンク = 決心ブラフの可能性
LAG のタンクオーバーベット: V:B 比 1:1 ~ 1:1.5 (ブラフ多め)
  → ブラフ確率 50-60%

KQ はブラフには勝つ、バリューには負ける
後手下限確率 for オーバーベット = 40-45%
  → ブラフキャッチ価値あり

**コール** (KQ のブロッカー + BDFD で ブラフキャッチ成功率上昇)
```

**答え: コール**

</details>

### 問 3

**ライブポーカー、相手が 大きく深呼吸してから CBet 75%**。自ハンドKK（オーバーペア、T72r）。

<details>
<summary>解答</summary>

```
サイズ 75% = 強いバリュー候補
物理テル: 深呼吸 = 落ち着きを装う = 強いハンドの証拠

相手の想定レンジ: セット、オーバーペア
  AA, KK はカード上ブロック (自分 KK)
  → TT (セット) の可能性高い

自分 KK は TT に 4 アウツ (K 引き)
  → エクイティ 10% 以下

**フォールド寄り** (特に大ポットなら)
```

**答え: フォールド or 超慎重コール**

物理テルは補助情報だが、深呼吸 + サイズ大 + タイプで判断を決める。

</details>

**【GTOとのズレ】**

本章のタイミングテルと物理テルは、サイズや HUD 統計には現れない「時間情報」「身体情報」を読む技術です。GTO は完全情報ゲームの均衡解として、相手の思考時間や呼吸を一切モデル化しません。インスタント 75% CBet を「バリュー 80%+」と読んで AK をフォールドする判断も、タンクオーバーベットを「ブラフ 50%」と読んで KQ をコールする判断も、GTO 解からの逸脱に分類されます。逸脱が +EV になるのは、5 回以上の観察で相手のタイミング癖が確定している場合に限られます。

ズレが大きく出るのは、サンプル不足での決めつけと、回線遅延・マルチテーブルなどのノイズが混じる場面です。GTO 解では「タンクコールはコールレンジ全体の平均」として扱われますが、実戦の TAG のタンクコールは TPGK や中強度ハンドに偏ります。この偏りを利用したリバーの小サイズバリューは GTO 推奨より +0.5 BB の EV を取れますが、相手がマルチテーブルでほかのテーブルを処理していただけなら、読みは外れて -1 BB になります。物理テルも文化差や演技で 30% 程度は誤読の余地があります。

実戦では、テルを「単独の決め手」ではなく「サイズ + 履歴 + HUD と組み合わせる第 4 の補助情報」として扱います。タイミングと物理の両方が同じ方向（例: タンク + 浅い呼吸 = ブラフ寄り）を指すときだけ GTO から逸脱し、片方だけ、サンプル 5 回未満、またはネット遅延を疑う場面では GTO 基準に戻すのが安全です。
