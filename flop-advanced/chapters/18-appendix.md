## 付録 B　精密レンジスコア 完全係数表 (拡張版)

巻②付録Dの係数表をそのまま踏襲しつつ、本書の第1章で扱った根拠データを付加した完全版。

### 基本式

```
CBet% = 90 − HighCardDeficit − TextureCost − SuitPenalty − Extra
        (ペアは override、monotone は 18% 固定)
```

### HighCardDeficit 表

| トップ | 減算 | 根拠 (実測平均) |
| :---: | :---: | :---: |
| A | 0 | top=A 平均 89% |
| K | 0 | top=K 平均 84% |
| Q | 5 | top=Q 平均 75% |
| J | 35 | top=J 平均 46% |
| T | 35 | top=T 平均 40% |
| 9 | 35 | top=9 平均 40% |
| 8 以下 | 30 | top ≤8 平均 52% |

### TextureCost 表

| max_diff | top ≤ 8 | top 9 rain | top 9 2tone | top T 2tone | top T rain | top J | top Q+ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| ≥ 8 (散開) | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 5-7 (中程度) | 5 | 5 | 5 | 5 | 5 | 5 | 5 |
| 3-4 (2連+G) | 5 | 15 | 15 | 15 | 15 | 15 | 25 |
| ≤ 2 (連続3) | 5 | 10 | 20 | 15 | 20 | 25 | 30 |

### SuitPenalty

| スート構造 | 減算 |
| :---: | :---: |
| rainbow | 0 |
| 2-tone | 10 |
| monotone | override → 18% 固定 |

### Extra 4 ルール

| ルール | 条件 | 追加減算 | 対象ボード例 |
| :---: | --- | :---: | --- |
| E1 | mid=T かつ top≥Q かつ rainbow | -15 | KT5r, QT3r, AT2r |
| E2 | 3 枚とも T 以上 かつ 2-tone | -10 | KQTss, QJTss, AKJss |
| E3 | top=A/K/Q + mid=T + 2-tone + low<T | -15 | AT7ss, KJ4ss |
| E4 | top=Q かつ mid<T かつ 2-tone | -10 | Q83ss, Q72ss |

### Pair Override 表 (8 パターン) ―― 2 次元拡張

CBet 頻度（overall）と、GTO 実測から抽出した「Value 圧」「Bluff 圧」の 2 次元値を併記。**型 7a の特殊性**（強ハンドでも 40% チェックバック）が読み取れる。

| パターン | overall | Value 圧 | Bluff 圧 | 解釈 | 根拠ボード |
| --- | :---: | :---: | :---: | --- | --- |
| AA ペア (AA-X) | 90% | ~1.00 | 高 | 強→必ず bet、ブラフ豊富 | AA7, AAK |
| KK ペア (KK-X) | 85% | ~1.00 | 中 | 強→ほぼ bet | KK4, KK9, KKJ |
| QQ ペア (QQ-X) | 80% | ~1.00 | 中 | QQ6 で実測 81.9% | QQ3, QQT |
| ミドルペア (TT-88) | 75% | ~0.95 | 中 | – | TT5, 995, 883 |
| ローペア (77 以下) | 70% | **1.00** | **0.27** | 強は確定 bet、ブラフ控えめ | 772, 665, 553 |
| **A/K + ローペア (ペア ≤7)** | **43%** | **0.60** | **0.39** | **強でも 40% チェック (slowplay)** | K44, A33, A55 |
| A/K + 中ペア (ペア 8-T) | 78% | ~0.91 | ~0.56 | 強は bet、weak も bluff | A99, K88, A88 |
| Q/J ハイ + ローペア | 55% | ~0.85 | 中 | – | Q33, J55 |

**注**:

- **Value 圧** = HandScore≥14 のハンドが bet される確率
- **Bluff 圧** = HandScore≤4 のハンドが bet される確率
- overall ≈ 0.25 × Value 圧 + 0.75 × Bluff 圧（強ハンド比率 ≈25%）
- **型 7a (K44 系) の overall 43% が低い理由**は「Value 圧が 0.60 まで下がる」こと:強ハンド（A、ペア、トリップス相当）でも保護目的でチェックバックする頻度が高い

### A/K + ローペア型の戦略的解釈

K44 のような「A/K 高 + 低ペア」では:

- **PFA のレンジ**:オーバーペア（QQ-77）、A 高 (AK-AT)、トップペア (KQ-K9) が中心
- **問題**:オーバーペアもトップペアも、相手のスローブレイ（K x、4 x）に bet すると **stacks off** リスク
- **GTO 解**:強ハンドの一部をチェックバック（Value 圧 0.60）+ ブラフをやや増やす（Bluff 圧 0.39）= overall 43%

これは **「PFA が静かに bet する」型 1b（K72r 等、Value 圧 1.0）とは戦略構造が異なる**。同じ overall 60% でも、内部のポーラード化（二極化）の度合いが違えばプレイの実装が変わる。

### 残存外れ値

**965r のみ**（|残差| ≥ 15のボード）:

- GTO実測： 60%
- 精密レンジスコア予測： 40%
- 残差： +20%
- 原因： 9-6-5のmiddle=6は通常のロー連続と異なる特殊ドライ

追加ルールでさらに精度を上げる余地はあるが、現段階では実用上の影響は小さい。

### この表から分かる重要な戦略パターン

1. **型 1a / 1c / 2a / 2f**: Value 圧 1.0 + Bluff 圧 0.1 以下 = **「強ハンドはほぼ全 bet、ブラフは控えめ」の linear 戦略**。 broadway 2-tone や middle 系 wet ボード
2. **型 1b**: Value 圧 1.0 + Bluff 圧 0.57 = **「強ハンド全 bet + ブラフも豊富」のポーラード戦略**。 A/K 高ドライ
3. **型 4a / 5b / 7a**: Value 圧 < 0.8 = **「強ハンドでもチェックバックする保護的戦略」**
   - 4a (T98ss 系): wet 連続のため、オーバーペアも危険でチェック頻度が高い
   - 5b (mono-low): 既にナッツが効きにくいモノトーン、bluff も bet も控えめ
   - **7a (K44 系): もっとも特殊**。stacks off リスクで slowplay 多い
4. **型 7b** (A99): Value 0.91 + Bluff 0.56 = K88 や A99 のように **「中ペアでも overall 78% 出る (= K44 とは別物)」**

```

巻② 型2 (ハイ×ウェット) → 2a, 2c, 2f
巻② 型3 (ロー×ドライ) → 3d
巻② 型4 (ロー×ウェット) → 3c, 4a, 4b, 4c, 4d

```

| :---: | :---: | :---: | :---: | :---: | :---: |
| VPIP | 22-25% | ≤16 | 18-25 | 28-35 | 35+ |

### E 補正式 (再掲)

```
E = V_score × 0.4 + P_score × 0.4 + A_score × 0.2

V_score = (相手 VPIP − 22) / 10
P_score = (相手 PFR − 18) / 10
A_score = (相手 AFq − 45) / 20

E の範囲: -1.5 〜 +1.5
```

### サンプル別の信頼性

```
< 200 ハンド: 主要 3 指標は使わない、標準値と仮定
200-500: VPIP, PFR のみ信頼
500-1000: 基本 3 指標を採用、Fold vs CB も参照
1000+: 全指標を使ったエクスプロイト
```

### 相手タイプ 5 分類詳細 (境界値を含む)

```
Nit:        VPIP ≤16, PFR ≤13, AFq ≤30
  サブ分類: Super Nit (VPIP ≤12), Regular Nit (VPIP 13-16)

TAG:        VPIP 18-25, PFR 15-22, AFq 40-55
  サブ分類: Tight TAG (VPIP 18-21), Standard TAG (VPIP 22-25)

  サブ分類: Loose LAG (VPIP 32-35), Standard LAG (VPIP 28-31)

  サブ分類: Passive Fish (AFq ≤20), Calling Station (AFq ≤15)
```

## 付録 E　プレイヤータイプ別 搾取チートシート

第11章の32例を要約した1ページサマリー。

### Nit 相手 (E ≈ -1.0)

```
基本方針: ブラフ増、過剰フォールド、3bet ブラフ活用

ブラフ頻度:
  CBet ブラフ: 50 → 70-80% (特に 33% サイズ)
  3bet ブラフ: 5 → 10-15%

ディフェンス:
  相手の 33% CBet: MDFライン 通り (75%)
  相手の 75% CBet: ほぼフォールド (MDF 無視)
  相手の オーバーベット: 完全フォールド (TPTK でも)

サイズ:
  自分のバリュー: 標準 (33-75%)
  自分のブラフ: 小-中 (33-50%)、大サイズ無駄
```

### TAG 相手 (E ≈ 0)

```
基本方針: GTO 近い対応、境界で R2 ランダム化、メタゲーム活用

ブラフ頻度:
  CBet ブラフ: 標準 (40-50%)
  3bet ブラフ: 標準 (5-8%)

ディフェンス:
  MDFライン 通り、サイズ別に計算
  境界ハンドで R2 適用

サイズ:
  標準、サイズ 2 択 (R4) を使う
```

### LAG 相手 (E ≈ +1.0)

```
基本方針: ブラフ減、ブラフキャッチ増、チェックレイズ誘引

ブラフ頻度:
  CBet ブラフ: 50 → 20-30% (LAG はコール多)
  3bet ブラフ: 5 → 3-5% (コールバックされる)

ディフェンス:
  相手の 33% CBet: 広くコール (MDF確率 +10%)
  相手の 75% CBet: MDF確率 +10%、ブラフキャッチ積極
  相手のトリプルバレル: コールダウン

サイズ:
  バリュー薄く (LAG はコール前提)
  サイズ大きく (LAG はコールする)
```

### Fish 相手 (E varies)

```
基本方針: ブラフ封印、バリュー厚、広くバリューベット

ブラフ頻度:
  CBet ブラフ: 50 → 10% (Fish は降りない)
  3bet ブラフ: 5 → 0% (完全封印)

ディフェンス:
  相手のコール: 自分のバリューを信じる
  相手のレイズ: ほぼナッツ確定、フォールド

サイズ:
  バリュー: 75% 以上、3 ストリートフル
  薄いバリュー: TP 弱キッカーでも打つ
  Fish は ShowDown Value を軽視 → 広く バリュー
```

## 付録 F　メタゲーム理論の古典引用

### Sklansky の Fundamental Theorem of Poker

> 「プレイヤーは、相手のハンドを知っているかのように打つべき。そこから外れるほど、相手は利益を得る」

**解釈**: 相手のレンジを精密に読めば読むほど、自分のEVが上がる。

### Harrington のレベル思考

> 「レベル 1: 自分のハンド。レベル 2: 相手のハンド。レベル 3: 相手が自分のハンドをどう読むか。レベル 4 以上は通常過剰」

**解釈**: 対戦相手より1レベル上を目指す原則。レベル4+ は自滅の元。

### Janda の搾取枠組み

> 「GTO は防御戦略。搾取は攻撃戦略。相手の弱点に集中して攻める」

**解釈**:「すべての弱点を攻めない」。最大の弱点を集中的に搾取。

### Galfond の動的頻度

> 「戦略は静的ではない。各ハンドで微妙に調整するのが上級者」

**解釈**: メタゲームの核心。イメージ構築と利用の循環。

### Chen & Ankenman のコンボ論

> 「ポーカーは情報不完全ゲーム。確率論で最適化できる部分と、できない部分を区別せよ」

**解釈**: コンボ計算とブロッカー効果は数学的に解ける。メタゲームは数学を超える領域。

## 付録 G　よくある誤解 Q&A 上級編

### Q1: 精密レンジスコア の係数は全部覚えるべきか

**A**: 実戦では不要。5つの重要型（型2c、型2e、型4d、型7a、型7b）だけ覚えればR² 0.90相当の精度。残りは巻②の7型で近似可能。

### Q2: 混合戦略 R1-R6 はすべて同時に使う

**A**: いいえ。R1は常時、R2は境界セルのみ、R3は常時、R4はベット確定時、R5は高頻度×強、R6はディフェンス時。適用範囲が分かれている。

### Q3: メタゲームは全相手に使える

**A**: いいえ。レベル2以上の相手（TAG、上級LAG）にのみ有効。Fish/Nitにはメタゲーム無意味。

### Q4: HUD なしでエクスプロイトできる

**A**: 可能だが精度が落ちる。1オービット（5-6ハンド）観察で粗いE推定、補正量は30% 減らす。

### Q5: 「搾取しすぎ」と「GTO に戻るべき」の境界は

**A**: 相手が5ハンド以上自分のブラフをコール、自分のパターンが読まれた兆候 → 即GTO復帰。

### Q6: 17 型と 7 型、どちらで運用

**A**: 巻②読者は7型で十分。NL200+ の上級者は17型で +5-10% のEV上乗せ。

### Q7: 「タイミングテル」と「物理テル」の優先度は

**A**: オンライン = タイミング主体、ライブ = 物理 + タイミング + サイズの統合。

### Q8: レベル 3 以上は本当に不要

**A**: 対プロ戦 (NL1000+) では必要。それ以下ではFPSのリスクが上回る。

### Q9: 3bet ポットでも 精密レンジスコア は使える

**A**: 使えるが、SPRが低いため **+5% の補正** を加える。4betポットは別モデル（次巻で扱う）。

### Q10: 「5 ハンドで相手タイプ判定」は本当に可能

**A**: 粗い判定のみ。正確なタイプ判定は50-100ハンド、エクスプロイト発動は200+ ハンド推奨。

### Q11: 精密レンジスコア（第1章）と 17 型分類（第4章）は両方覚える必要があるか

**A**: いいえ、片方で十分です。両者は同じ 30 ボードの GTO 実測データから作られた **「式」と「表」の 2 表現**で、解いている問題は同じ（簡易レンジスコアの外れ値吸収）です。

- 数式が得意 / 拡張性重視 → **第1章のみ**（任意ボードへ外挿可、巻④ バレルスコアへ滑らかに接続）
- パターン認識が得意 / ライブで瞬発判断 → **第4章のみ**（型を引くだけ、付録 C のチートシート 1 枚で運用可）
- 中級ステップアップ → 第1章の係数 10 個 + 第4章 4-7 節の **優先 5 型** だけ覚える折衷

両方を完全暗記するのは負担対効果が悪いので、自分の認知スタイルに合う方を選んでください。詳しくは各章冒頭のナビボックスを参照。

## 付録 K　GTO とのズレ 統合マップ

各章末「GTO とのズレ」コラムの内容を全章横断で整理。本書の道具がどの方向に・どの程度・なぜ GTO から外れるかを 1 表で俯瞰できる。

### ズレの 4 つの源泉

本書の判断フロー（簡易レンジスコア / HandScore / 9 マスマトリクス）は GTO の連続混合戦略を **離散決定論モデル** に圧縮している。ズレは次の 4 源泉に分解できる:

| 源泉 | 説明 | 影響レイヤー |
| --- | --- | --- |
| **A. 離散化** | 連続値 → 階段状（HandScore = 整数刻み）| HandScore / 9 マス |
| **B. 単一決定** | 混合戦略 → 単一アクション（決定論）| 9 マス全体、CBet サイズ |
| **C. モデル簡略化** | 全レンジ vs レンジ → 4 項減算式 | 簡易/精密レンジスコア |
| **D. シナリオ前提** | BTN vs BB SRP 100bb cash 専用 | 全章 |

### 主要なズレ一覧（章別）

| 章 | ズレの内容 | 方向 | 影響度 |
| --- | --- | :---: | :---: |
| 巻② ch6 (アウツ) | アウツ × N の単一公式は不可能、種別ごとに係数が異なるため表ベース | – | 設計済 ✅ |
| 巻② ch9 (HandScore) | 離散整数 vs 連続エクイティ。HS=15 と HS=18 の中間が存在しない | A | 中 |
| 巻② ch10 (9 マスマトリクス) | 単一アクション vs 混合戦略。GTO の 50/50 を「片方に丸める」 | B | 中 |
| 巻② ch11 (CBet サイズ) | 33%/50%/75% の 3 択 vs ソルバー連続サイズ | A+B | 小 |
| 巻② ch12 (GTO 乖離本章) | レンジアドバンテージ・ナッツアドバンテージの 2 軸を本書は単一頻度に圧縮 | C | 大 |
| 巻② ch13 (後手スコア) | C 係数の段階値（3/5/7/9/11）vs ソルバー連続応答 | A | 小 |
| 巻② ch14 (CR・ドンク) | OOP のドンクベット頻度を本書は省略（GTO は微量に使う） | C | 小 |
| 巻② ch16 (マルチウェイ) | M=3/M=6 の経験則補正 vs 厳密 multi-way solver | C+D | 大（要件次第） |
| 巻② ch17 (相手タイプ) | E 補正の 4 分類 vs HUD 連続値 | C | 小（巻③ ch10 で精密化） |
| 巻② ch18 (動的レンジ) | 「サイズ→HS 帯」の 2 区分 vs ベイズ更新の連続分布 | C | 中（巻③ ch7 で精密化） |
| 巻③ ch1 (精密レンジスコア) | 30 ボード内挿精度 R²=0.914、外れ値 965r で +20% | C | 小 |
| 巻③ ch3 (精密 HandScore) | 整数刻みのブロッカー +5/+3/+2 vs 連続効果 | A | 小 |
| 巻③ ch4 (17 型) | 同型内 ±5-10% の分散（型 2c で 12 ポイント） | A | 中 |

### ズレが大きい場面・小さい場面

#### 🟢 ズレが小さい場面（本書の式で十分）

- **ハイ × ドライボード（型 1b）の TPTK**:GTO もほぼ常に bet。離散化の影響なし
- **モンスタードロー（FD+OESD）のセミブラフ**:GTO 100% bet、本書も同じ
- **明らかな弱ハンド（HS < 4）の対 75% CBet**:GTO もフォールド推奨、本書も同じ
- **ヘッズアップ SRP 100bb cash の標準シナリオ**:本書の主要対象範囲

#### 🟡 ズレが中程度（注意要）

- **境界ハンド（HS 13-15、6-8）**:0.5% 単位の混合が GTO 解、本書は 1 アクションに丸める
- **ウェットボード上の TP 系**:GTO は混合戦略多用、本書は決定論
- **2-tone ボードでの BDFD ハンド**:微小ブロッカーの寄与を本書は粗く扱う
- **17 型の境界（type 2a/2c の中間 max_diff=4 など）**:離散判定で型が変わる

#### 🔴 ズレが大きい場面（本書の式を信頼しない）

- **マルチウェイポット**:M 補正は経験則。3-way 以上は別途 solver 推奨
- **3bet/4bet ポット**:本書のレンジスコアは 2.5x SRP 前提。10-15% シフト
- **ICM がかかるトーナメント終盤**:本書はキャッシュ前提、巻⑥ で扱う
- **type 7a (K44 系) や type 5b (mono-low)**:Value 圧 < 0.8 で本書の 1 次元出力では捉えきれない（付録 J 参照）
- **965r 系のロー連続 rainbow**:精密レンジスコアでも 40% 予測に対し実測 60%、+20% 外す

### 構造的なズレの方向（系統バイアス）

本書は次の方向に**保守寄り（タイト寄り）に偏る**傾向があります:

1. **ブラフ頻度を低めに見積もる**:GTO は弱ハンドでも一定割合 bet、本書はチェック寄り
2. **オーバーペアを過大評価**:特に型 4 ウェットで GTO はチェック多用、本書は -8 補正で対応するが粗い
3. **混合戦略の境界セルで全エッジ消失**:第2章 R1-R6 のランダム化ルールで補完

### 上達ロードマップ（ズレを段階的に埋める）

```
[初級] 巻② I 部の 21 マス
  ↓ ズレ大だが実戦投入可能
[基礎] 巻② II 部の 9 マス + HandScore
  ↓ 主要ズレを解消、EV ロス 0.5 BB/100
[応用] 巻③ I 部の精密化（R² 0.914）
  ↓ 30 ボード内ではほぼ完全
[上級] 巻③ III 部の搾取・節調整
  ↓ HUD・タイミング・物理テル
[完全 GTO] ソルバー直接（GTO Wizard / TexasSolver）
  ↓ 但し EV 改善は微小（< 0.5 BB/100）
```

実戦的には **基礎レベル（HandScore + 9 マス）で EV ロス 0.5 BB/100** に抑えられるため、応用以降は「**さらに精度を求める読者向けの選択肢**」と位置づけられます。

### ズレを意識すべき場面（実戦のチェックリスト）

- [ ] このスポットはマルチウェイ/3bet ポット?（本書の前提外）
- [ ] このハンドは HandScore の境界（13-15 や 6-8）?（混合戦略ゾーン）
- [ ] このボードは 17 型の境界?（type 2a/2c の middle 系など）
- [ ] このボードは型 7a/5b/4a のような Value 圧低下型?（強ハンドでもチェックバック）
- [ ] 相手は HUD で大きく外れたタイプ?（E 補正必要）

これらに 1 つでも該当すれば、本書の決定論的アクションを採用しつつ、**±10-20% の幅で柔軟に動く**ことを推奨します。

## 付録 J　2 次元 BoardScore（上級者向け）

本付録は、書籍本文の overall CBet 頻度（精密レンジスコア / 17 型平均）を **2 つの独立軸**に分解する研究的補足。**本文の理解には不要**だが、以下の読者には有益:

- 「なぜ K44 は overall 43% なのに、よく見るとプレイ感覚が他の 43% ボードと違うのか」を解明したい上級者
- ソルバー学習を通じて 17 型の内部構造に踏み込みたい読者

### H′-1　なぜ overall は不十分か

精密レンジスコアの出力は **overall CBet 頻度**（PFA がレンジ全体の何 % を bet するか）。これは便利だが、内部の戦略構造を捨象する:

- 同じ overall 60% でも「強→ 100% bet、弱→ 47% bluff」のパターンと
- 「強→ 60% bet、弱→ 40% bet（平準化）」のパターンでは
- **実装するベットラインが全く違う**

### H′-2　2 つの独立軸

GTO ソルバーの per-(board, holding) アクションデータから、各ボードに 2 つの量を計算できる:

```
Value 圧 = HandScore≥14 のハンドが bet される確率
          (= 強ハンドをどれだけ bet で扱うか)
Bluff 圧 = HandScore≤4  のハンドが bet される確率
          (= 弱ハンドでブラフする頻度)
```

そして近似的に:

```
overall_CBet ≈ 0.25 × Value 圧 + 0.75 × Bluff 圧
```

(係数 0.25 は強ハンドのレンジ占有率の概算)

つまり **overall は Bluff 圧の比重が大きい**。同じ overall でも Value 圧が違うとプレイ感が変わる。

### H′-3　代表ボードでの 2 次元値

| ボード | 型 | overall | Value 圧 | Bluff 圧 | 戦略パターン |
| --- | --- | :---: | :---: | :---: | --- |
| K72r | 1b | 91% | 1.00 | 0.57 | **ポーラード型（高）**: 強→必ず bet、ブラフ豊富 |
| JsKs5d | 1a | 21% | 1.00 | 0.07 | **Linear**: 強→ bet、弱→ ほぼ check |
| AcKs7d | 1c | 36% | 1.00 | 0.12 | **Linear**: 1c の典型 |
| QcAdKh | 2f | 38% | 1.00 | 0.19 | **Linear**: ブラフ控えめ |
| Td6h4h | 4c | 26% | 0.83 | 0.11 | **Mid-Value**: 強もたまにチェック |
| Js8d3c | 3d | 63% | 1.00 | 0.46 | **Polarized + ブラフ多**: ロー散開で BB レンジが薄い |
| 6s8d7c | 4d | 66% | 0.83 | 0.36 | **連続 wet**: 強もたまにチェック、ブラフは中 |
| **5c5dAh (≈K44)** | **7a** | **47%** | **0.60** | **0.39** | **Pot control**: 強もチェック多、ブラフも控えめ |
| Ad8d3d | 5b | 4% | 0.50 | 0.00 | **撤退**: monotone でほぼ全 check |

### H′-4　Pair Override 表の 2 次元拡張

[付録 B の Pair Override 表](#付録-b-精密レンジスコア-完全係数表-拡張版) 参照。重要点:

- **AA/KK/QQ ペア** (型 6a/6b/6c): Value 圧 ~1.0、強ハンドはほぼ常に bet
- **A/K + 中ペア (型 7b)**: Value 圧 0.91、Bluff 圧 0.56 → 「中ペアでもアドバンテージあり」
- **A/K + ローペア (型 7a)**: Value 圧 **0.60** → 「強ハンドでも保護のためチェックする」
- ロー単独ペア (型 6d): Value 圧 1.0、Bluff 圧 0.27 → 「強→ bet、ブラフ控えめ」

### H′-5　書籍読者向けの実用ルール

精密レンジスコアの 2 次元拡張版として:

```
P(strong_bet) = 100 - StrongPenalty
  StrongPenalty:
    - 型 7a (A/K + 低ペア):   -40
    - 型 5b (mono-low):       -25
    - 型 4a (low-T 連続 2t): -20
    - 型 5a (mono-broadway):  -15 (推定)
    - その他:                   0

P(bluff_bet) = 90 - HighCardDeficit - TextureCost - SuitPenalty - Extra
              (現行精密レンジスコア式と同じ)

CBet_overall = 0.25 × P(strong_bet) + 0.75 × P(bluff_bet)
```

これで **型 7a の 43%** という低い overall も、Value 圧 0.60 を経由して自然に表現できる。

### H′-6　現状のデータ範囲と限界

- 22 ボードでの実測値で、完全 17 型カバレッジには至っていない
- HandScore 帯（≥14、≤4）で条件付けた比率は信頼できる範囲
- 追加検証で Value 圧 / Bluff 圧の係数を全 17 型に拡張する余地あり

本付録の値は研究的補足であり、本文の判断には 1 次元の overall（精密レンジスコア / 17 型代表値）で十分です。
