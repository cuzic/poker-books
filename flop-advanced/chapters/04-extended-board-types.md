# 第4章　ボード型の超細分化 ― 7 型から 17 型へ

<!-- textlint-disable -->

<!-- markdownlint-disable MD033 MD036 MD040 MD060 -->

> 「同じ『型2 (ハイ×ウェット)』でも、Q83ss は 55%、KQTss は 35%。20 ポイントの差を 1 つの型に押し込むと、どちらかで必ず外す」

---

## 読者ペルソナ別の読み方

- **A (中級ステップアップ組)**: 17 型全部を覚える必要はない。優先 5 型 (4-4 節) だけ暗記すれば十分。
- **B (ソルバー派)**: 17 型の GTO 平均値と BDM v5 予測の誤差を全型で確認し、残差分析に活用する。
- **C (ライブベテラン)**: 7 型 + 例外 5 型のハイブリッド運用 (4-7 節) が実戦で最も現実的な運用法。

---

## 巻2 からのブリッジ

巻2第3章で、ボードを **7 型** に分類しました。

```
型1: ハイ × ドライ      (K72r, A82r)
型2: ハイ × ウェット    (Q83ss, KQTss, KJ9r)
型3: ロー × ドライ      (J75r, 876r, 632r)
型4: ロー × ウェット    (T98ss, 987ss, JT9ss)
型5: モノトーン         (AKQmono, 987mono)
型6: ペア (ハイ+高キッカー) (AAK, KK9, QQT)
型7: ペア (そのほか)    (772, K44, A99)
```

この7型で巻2のD3はフロップ判断の90% をカバーできます。しかしGTO実測を詳しく見ると、**同じ型内で頻度が 20 ポイント分散する**ケースがあります。

例えば型2（ハイ×ウェット）内部：。

- Q83ss: 55%
- AT7ss: 60%
- KJ9r:  55%
- KQTss: **35%** ← 20ポイントも低い
- QJ9r:  50%

KQTssは「3枚ともT以上」の特殊なbroadway 2-toneで、ほかの型2ボードと本質的に違います。7型でまとめて扱うと、この20ポイントを型の「代表値」で代用することになり、どの代表値を選んでも外れます。

本章では7型を **17 型に細分化** し、型内分散を吸収します。これはBDM v5（第1章）と同じアプローチで、巻2の暗算モデルを超えて精密化する道具です。

## 4-1　7 型の内部分散を実測する

### 型 2 (ハイ×ウェット) 内部の分散

30ボードのGTO実測を型2に属するもので並べ直すと：。

| ボード | 判定条件 | GTO 実測 |
|-------|---------|:------:|
| AT7ss | A-high + 2-tone、mid=T | 60% |
| Q83ss | Q-high + 2-tone、mid=8 | 55% |
| KJ9r  | K-high + 高ボード連続 rainbow | 55% |
| QJ9r  | Q-high + 高ボード連続 rainbow | 50% |
| KQTss | K-high + 2-tone + 全 broadway | 35% |

最大60%（AT7ss）から最小35% (KQTss) まで **25 ポイント分散**。型2の平均（55% 程度）で代用すると、KQTssで20ポイント外す。

### 型 4 (ロー×ウェット) 内部の分散

| ボード | 判定条件 | GTO 実測 |
|-------|---------|:------:|
| 987ss | 9-high + 連続3枚 + 2-tone | 30% |
| JT9ss | J-high + 連続3枚 + 2-tone | 25% |
| JT8ss | J-high + 連続3枚 + 2-tone | 30% |
| T98ss | T-high + 連続3枚 + 2-tone | 35% |
| T98r  | T-high + 連続3枚 + rainbow | 40% |
| T87r  | T-high + 連続3枚 + rainbow | 45% |
| 965r  | 9-high + 連続 + rainbow | **60%** |
| 876r  | 8-high + 連続3枚 + rainbow | **42%** |
| 632r  | 6-high + 連続 + rainbow | **62%** |

最大62%（632r）から最小25% (JT9ss) まで **37 ポイント分散**。この差は「トップカードのランク」と「スートパターン」の相互作用で生まれます。

### 型4 の内部相関

```
top J × 2-tone: 25-30% (最も低い)
top T × 2-tone: 35% (中程度)
top T × rainbow: 40-45% (高め)
top 9 以下 × rainbow: 42-62% (高いが分散大)
```

つまり型4は実質 **3-4 種類のサブ型**に分かれます。

### 7 型 → 17 型のマッピング

巻2の7型と17型の対応：。

```
型1 (ハイ×ドライ) → 1a, 1b, 2e (middle=T の rainbow を再分類)
型2 (ハイ×ウェット) → 2a, 2c, 2f
型3 (ロー×ドライ) → 3d
型4 (ロー×ウェット) → 3c, 4a, 4b, 4c, 4d
型5 (モノトーン) → 5a, 5b
型6 (ペア+高キッカー) → 6a
型7 (ペア、そのほか) → 6d, 7a, 7b
```

型4が5サブ型に分裂するのが最大の特徴。ロー連続ボードの多様性を反映します。

### 巻2 との差分 (何が変わったか)

主要な変化：。

1. **型1 の分裂**: 1b（rainbow、85-90%）と1a (2-tone、55%) を分離。2-toneで頻度が30ポイント下がる。
2. **型2 の分裂**: 2c (broadway 2-tone、35%) は2a/2fと扱いが違う。KQTssのような「全broadway」は 📕 控えめ扱いに。
3. **型4 の 5 分割**: ロー連続の微妙な違いを吸収。4d（ロー rainbow）は意外とドライで50% ベットできる。
4. **型7 の分裂**: 7a（K44系）は45% の特殊扱い、7b （A99系） は76% と高頻度。

## 4-4　「覚える価値のある」詳細型

17型を全部暗記するのは負担が大きい。**特にインパクトの大きい 5 型** を覚えると、巻2の7型から大幅に精度が上がります。

### 優先的に覚える 5 型

1. **型2c (broadway 2-tone)**: 3枚ともT以上で2-tone。代表KQTss、QJTss、KJTss。
   - 巻2では「ハイ×ウェット55%」だが、実際は **35% と 20 ポイント低い**
   - BBのコネクター密度とfrash drawの重複が原因
   - **🎯 → 📕 控えめモード** に変更

2. **型2e (middle=T rainbow)**: middleがTのrainbow、top A/K/Q。代表KT5r、QT3r、AT4r。
   - 巻2では「ハイ×ドライ85%」だが、実際は **70% と 15 ポイント低い**
   - BBのKT/QT/JT/T9コンボが密で意外と刺さる
   - **⚡ 全開 → 🎯 高頻度 (50%)** に下げる

3. **型4d (ロー連続 rainbow)**: J以下トップで連続、rainbow。代表965r、876r、632r。
   - 巻2では「ロー×ウェット30%」だが、実際は **48-62% と 20 ポイント以上高い**
   - PFAもBBもヒットしない「特殊ドライ」
   - **🛡️ 撤退 → 🤔 意外なドライ (50%)** に上げる

4. **型7a (A/K + ローペア)**: K44、A33、Q44など。
   - 巻2では「ペア72%」だが、実際は **43% と 30 ポイント低い**
   - K44問題として第1章で詳述
   - **⚡ → 🎯 特殊ペア (33%)** に下げる

5. **型7b (A/K + 中ペア)**: A99、K88、A88など。
   - 巻2では「ペア75%」でだいたい合う
   - ただし型7aとの差（33ポイント差）を混同しないこと
   - 確認用に覚える

### この 5 型で何%改善するか

30ボード中、上記5型に該当するボードは：。

- 型2c (KQTss): 1
- 型2e（KT5r）: 1 (仮想）
- 型4d (965r, 876r, 632r): 3
- 型7a (K44): 1
- 型7b (A99): 1

計7ボード。30ボード中7で補正を加えると、**R² が 0.873 → 0.90 程度まで改善**します（BDM v5の完全版0.914には届かないが、暗記量は半分で済む）。

## 4-5　「覚えなくていい」詳細型

残り12型 (17 − 5 = 12) は巻2の7型で近似できるので、暗記の優先度は低い。

### 軽視してよい型の代表

- **型1a (high-dry-2tone)**: 1例のみ (Q83ss)。巻2の「ハイ×ウェット55%」で大体合う
- **型3c/3d (ロー×ドライ)**: 既に巻2で55% 扱い。微差は無視
- **型4a/4b (ロー連続 2-tone)**: 巻2の「ロー×ウェット30%」で十分
- **型5a/5b (モノトーン)**: 巻2の「20%」一律で十分

暗記の優先度は「**残差が 15 ポイント以上ある型**」のみ。そのほかは巻2のまま運用。

## 4-6　17 型の判定フロー

実戦で17型を即座に判定する手順：。

```
Step 1: 巻2 の 7 型判定
  → 型5 (モノトーン) or 型6/7 (ペア) → 詳細型へ
  → 型1-4 → 下記 Step 2-4

Step 2: トップカードを A/K/Q vs J 以下 で分類

Step 3: スート構造を rainbow vs 2-tone で分類

Step 4: 「特殊条件」を確認
  - middle = T? (型2e または 4a)
  - 全 3 枚が T 以上? (型2c)
  - max_diff が 3-4 で top ≥ T? (高ボード連続 → 型2f)
  - ペアでトップ A/K + ペア≤7? (型7a)
```

実戦ではStep 2 + Step 3で7-8割は7型のどれかに特定。Step 4で「覚える価値のある5型」に入ったかだけ確認。

## 4-7　ハイブリッド運用 (7 型 + 5 例外)

すべての読者に17型を覚えることを強制するのは非現実的。代わりに推奨する運用：。

### 基本: 巻2 の 7 型で判定

90% の状況で7型の判定とアクションプランで対応。巻2のD3マトリクス通り。

### 例外: 覚えた 5 型に該当したら補正

フロップを見て、以下のチェックを1秒で実行：。

- ☑「3枚ともT以上 + 2-tone」? → 型2c、📕 控えめに切り替え
- ☑「middle = Tのrainbow、top A/K/Q」? → 型2e、🎯 高頻度 (50%) に切り替え
- ☑「ロー連続rainbow」? → 型4d、🤔 50% ベットでもOK
- ☑「トップA/K + ローペア（ペア≤7）」? → 型7a、🎯 33% に下げる
- ☑「トップA/K + 中ペア（ペア8-T）」? → 型7b (巻2のペアプラン通りなので実質確認のみ）

5つの「例外チェック」を加えるだけで、R² 0.873 → 0.90相当の精度が得られます。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: BDM v5 を使うには 17 型全部を覚えないといけない。

**✅ 正解**: 優先 5 型 (型2c/2e/4d/7a/7b) だけで R² 0.90 相当の精度が得られる。残り 12 型は巻2 の 7 型で近似可能であり、完全暗記は必須ではない。

---

## 章のまとめ

- 巻2の7型は同一型内で20-35ポイントの頻度分散がある
- 17詳細型に細分化することで分散を吸収
- 特に覚える価値があるのは5型（型2c、型2e、型4d、型7a、型7b）
- 残り12型は巻2の7型で近似可能
- 7型 + 5例外のハイブリッド運用で暗記負荷を抑えつつ精度向上
- 完全な17型運用はBDM v5（第1章）に到達

次章（第5章レンジ推定の基礎）から第II部の核心「レンジ推定」に入ります。相手のコンボを数え、ブロッカーで絞り込む手法を学びます。

## ミニクイズ

### 問 1

**フロップ: K♣Q♣T♦**。このボードは17型のどれか、またアクションプランは？

<details>
<summary>解答</summary>

- トップK、middle Q、low T。全3枚T以上 + 2-tone (♣♣)
- → **型2c (high-broadway-2tone)**
- プラン： 📕 控えめbroadway、強ハンド（セット以上）でCBet 33%、それ以外チェック

巻2では「ハイ×ウェット = 55%」だが、実際は35% と20ポイント低い。型2cを認識できれば、強ハンド以外を押し付けない判断ができる。

</details>

### 問 2

**フロップ: 9♣6♣5♦**。このボードは17型のどれか？

<details>
<summary>解答</summary>

- トップ9、max_diff=4、2-tone (♣♣)、非ペア、非モノトーン
- J以下（ロー）、連続 (max_diff 3-4)、2-tone
- → **型3c (low-mid-2tone)** or **型4b (low-sub9-2tone)**
- max_diff=4は型4の境界だが、連続3枚 (max_diff≤2) ではないので厳密には型3c
- プラン： 🤔 控えめ2-tone、強ハンドで33%、それ以外チェック

注： 965はGTO実測60% で、型3c/4bの平均30-50% よりも高い特殊ケース。第1章で扱った「965r問題」のボード。

</details>

### 問 3

**フロップ: A♦9♦9♣**。このボードは17型のどれか、またアクションプランは？

<details>
<summary>解答</summary>

- ペアボード（9-9）、トップA （A/Kハイ)、ペア9 （8-Tの範囲）
- → **型7b (AK-high-midpair)**
- プラン： 🎯 中程度、強ハンドで50%、中ハンドで33%、弱ハンドはチェック

巻2のペア表で「A/Kハイ + 中ペア（ペア8-T）→ 75%」と合致。特に暗記の優先度は高くない。

</details>
