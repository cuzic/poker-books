# 第11章　マルチウェイのフロップ戦略

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> 3人以上でフロップを迎えるマルチウェイポットでは、SRP（シングルレイズドポット）とは戦略が大きく変わります。
> ブラフが機能しにくくなる一方、強いハンドのバリューは増大します。
> 本章ではマルチウェイ特有のCBet基準の調整と、守備側の考え方を学びます。

---

## 11-1　マルチウェイでブラフが通らない理由

SRP（シングルレイズドポット）の標準的な BTN vs BB（2人対戦）では、相手の 1 人がフロップにヒットしている確率は概ね 30〜35% 程度です。
しかしプレイヤーが増えると、「誰かがヒットしている」確率は急増します。

### ヒット確率の増加

```
フロップに「誰かが強いハンドを持つ」概算確率:
  HU（2人）:   約 30〜35%（1人がヒット）
  3way（3人）: 約 50〜55%（2人のうち誰かがヒット）
  4way（4人）: 約 60〜70%（3人のうち誰かがヒット）

「強いハンド」= T1（HS ≥ 65、セット・2ペア・TPTK以上）として推定
```

3way では半分以上の確率で誰かが T1 ハンドを持ちます。
この状況でブラフを打っても、その T1 保有者がコールするため期待値がマイナスになりやすいです。

### フォールドエクイティの急落

HU では相手 1 人の「フォールドするかどうか」だけを考えれば済みます。
しかし 3way では「2 人ともフォールドする」確率が必要になります。

```
ブラフ成功に必要な条件（3way の場合）:
  2 人が同時にフォールドする確率 = P(A fold) × P(B fold)

  例: 各プレイヤーが 50% の確率でフォールドするボード:
    HU の成功率 = 50%
    3way の成功率 = 50% × 50% = 25%（半分に低下）

  実戦では「後ろのプレイヤーが残っている」という状況がブラフの期待値を大きく下げる
```

## 11-2　マルチウェイでの CBet 頻度目安

プレイヤー数が増えると、GTO の CBet 頻度は段階的に低下します。

### 頻度の目安

```
CBet 頻度の目安（GTO 推定）:
  HU（2人）:   約 70%（積極的 CBet）
  3way（3人）: 約 40〜45%（大幅低下）
  4way（4人）: 約 25〜35%（さらに低下）
```

さらに、ボードテクスチャによっても大きく変わります。

```
3way での ボード別 CBet 頻度目安:
  ドライ rainbow（K72r など）: 約 50〜55%
    理由: ドローが少なく誰かがヒットする確率が相対的に低い
  ウェット 2トーン（J84cc など）: 約 35〜40%
    理由: ドローが多く、誰かがFD/OESDを持つ確率が高い
  モノトーン（987 全同スート）: 約 20〜25%
    理由: フラッシュドローを誰かが必ず近い確率で持つ
  ペア high ボード（K44r など）: 約 38〜42%
    理由: ペアに当たるハンドは少ないが、慎重さは必要
```

## 11-3　マルチウェイ CBet の実践基準

マルチウェイでは、CBet をするかどうかの閾値を調整します。

### CBet 閾値の調整式

Vol2 で学んだ CBet 判定では、HS スコアをボードスコア（B）と比較していました。
マルチウェイでは閾値を上乗せします。

```
マルチウェイ CBet 閾値調整:
  3way: 閾値 +5
  4way: 閾値 +10

例: vs 33% CBet の場合の基本フォールド閾値 15 の場合:
  HU:   HS ≥ 15 でコール（閾値 15）
  3way: HS ≥ 20 でコール（閾値 20 = 15 + 5）
  4way: HS ≥ 25 でコール（閾値 25 = 15 + 10）
```

### ハンドティア別の CBet 判断

```
3way での CBet 判断（ドライ rainbow ボード基準）:

T1（HS ≥ 65）: CBet を積極的に検討
  - セット・2ペア・TPTK 以上: バリューを積み上げる
  - ウェットボードでも T1 は CBet が基本

T2（HS 20〜64）: 基本はチェック。例外的にのみ CBet
  - HS ≥ 45 かつドライボードの場合のみ CBet を検討
  - ウェットボード・モノトーンでは T2 もチェックが安全

T3（HS < 20）: 原則チェック
  - マルチウェイではブラフのフォールドエクイティが低い
  - 例外: T3 でも OESD+FD のコンボドロー（HS ≥ 35 程度）は CBet 候補

実戦簡易ルール:
  3way なら「T1 のみ積極 CBet」と割り切る
  4way なら「セット・2ペア以上（HS ≥ 70〜75）のみ CBet」と考える
```

## 11-4　マルチウェイでのポジションの重要性

HU でも重要なポジションですが、マルチウェイではその価値がさらに高まります。

### IP（イン・ポジション）の利点

マルチウェイで BTN（ボタン）などの IP ポジションを持つ場合、多くの情報を集めてから判断できます。

```
IP の利点（マルチウェイ）:
  1. 他プレイヤーのアクションを見てからベットを決められる
  2. 前のプレイヤーがベットすれば、IP はコール/レイズの判断が楽になる
  3. OOP プレイヤーが互いに守備コストを負担し合う → IP がより有利に
```

実戦では、BTN で T2 のハンドを持っているとき、OOP プレイヤーが先にチェックしてからチェックバックを選ぶことで「タダでターンカードを見る」という選択肢があります。
これは HU でも有効ですが、マルチウェイでは OOP 側のプレイヤーが複数いるため、この恩恵が大きくなります。

### OOP（アウト・オブ・ポジション）の難しさ

OOP でマルチウェイのフロップを戦うのは、HU 以上に難しくなります。

```
OOP の課題（マルチウェイ）:
  1. ベットしても「後ろのプレイヤーが残っている」リスク
  2. コールして後ろからレイズされる「コール → レイズ → 挟まれ」のリスク
  3. チェックすると複数プレイヤーが情報を持てる

OOP での実戦原則（3way 以上）:
  T1: CBet または check-raise（CR）を検討
  T2: 基本チェック → コール（ただし後ろのプレイヤーのアクションを見て）
  T3: チェック → フォールド準備
```

## 11-5　マルチウェイで CBet を受けたときの守備

マルチウェイで IP から CBet を受けた OOP の守備戦略を整理します。

### コールの際の特別なリスク

HU のコールとマルチウェイのコールは性質が異なります。
3way 以上では「コールした後、さらに後ろのプレイヤーが raise する」リスクがあります。

```
3way での「コール → 後ろのレイズ」シナリオ:
  例: BTN（IP）が 33%（2bb）CBet
    CO（OOP 1）がコール（2bb）
    BB（OOP 2）がレイズ（例: 6bb）
    → CO は 4bb 追加が必要（コールした額の 3 倍追加）

  この状況で T2 程度のハンドでコールしていた CO は困難に
  → 3way 以上では「後ろのプレイヤーが残っている」コールは HS 基準を上げる
```

### OOP 守備の基準（マルチウェイ版）

```
3way での OOP 守備（vs 33% CBet）:
  T1（HS ≥ 65）: コールまたは CR
  T2 上位（HS 45〜64）: コールを検討（後ろのプレイヤーのアクション次第）
  T2 下位（HS 20〜44）: 原則フォールド（後ろのリスクを考慮）
  T3（HS < 20）: フォールド

4way での OOP 守備:
  T1（HS ≥ 65）のみコール/CR
  T2 以下: 原則チェック → フォールド
```

## 11-6　マルチウェイの具体例

### 例 1：ドライボードで T1 CBet

**状況**: BTN vs CO vs BB の 3way、pot=9bb（3bb × 3）
**ボード**: K♣7♦2♠（ドライ rainbow、B=62）
**BTN ハンド**: A♠K♠（TPTK、HS ≈ 71、T1）

```
判断:
  - マルチウェイ CBet 閾値: HU の 70% → 3way で約 50%
  - T1 なのでドライボードでは CBet が有効
  - サイズ: 33%（3bb）が推奨（広いレンジをカバーしつつコスト低）
  → CBet 33%（3bb）を選ぶ
```

### 例 2：ウェットボードで T2 のチェック

**状況**: BTN vs CO vs BB の 3way、pot=9bb
**ボード**: J♣8♣4♦（2トーン、B=50）
**BTN ハンド**: A♥Q♥（役なし、HS ≈ 25、T2 下位）

```
判断:
  - このボードで T2 下位のハンドを CBet すると:
    OOP の誰かがフラッシュドロー・ペアで守り続けやすい
    マルチウェイ閾値（3way: +5 = HS ≥ 20）に辛うじて届くが…
    後ろのプレイヤーのリアクションのリスクが高い
  - HS ≈ 25（T2 下位）かつウェットボードかつ 3way
  → チェックバックが安全
```

## ミニクイズ

### 問1

3way（3人）のポットでフロップを迎えました。
HU（2人）と比べた場合の CBet 頻度の変化として最も正しい説明はどれですか？

1. HU より頻度が上がる（3人のうち弱いプレイヤーが増えるため）
2. HU より頻度が大幅に下がる（誰かが強いハンドを持つ確率が高まるため）
3. 変化はほとんどない（プレイヤー数は CBet 判断に影響しない）

### 問2

3way（3人）のポット、ドライ rainbow ボード（B=62）で vs 33% CBet のコール基準はどれですか？
（HU の基本フォールド閾値を HS ≥ 15 とします）

1. HS ≥ 15（HU と同じ）
2. HS ≥ 20（3way 補正 +5 を加算）
3. HS ≥ 10（マルチウェイは守りやすくなるため閾値を下げる）

### 問3

マルチウェイ（3way 以上）での T3（HS < 20）ハンドの基本的な行動方針として最も正しいものはどれですか？

1. マルチウェイでも乾燥ボードなら T3 ブラフが積極的に使える
2. 原則チェック → フォールド準備。例外は OESD+FD のコンボドローなど高エクイティの場合のみ
3. T3 はどんな状況でも常に即フォールドする

---

### 解答

- **問1**: **2. HU より頻度が大幅に下がる** が正解。3way では誰かが強いハンドを持つ確率が約 50〜55% に上昇し、ブラフが通りにくくなります。GTO 推定ではHU 約 70% → 3way 約 40〜45% と低下します。
- **問2**: **2. HS ≥ 20** が正解。3way では閾値に +5 の調整を加えます（基本 15 + 3way補正 5 = 20）。後ろのプレイヤーがレイズしてくるリスクも考慮すると、弱い T2（HS 15〜19）はフォールドが安全です。
- **問3**: **2. 原則チェック → フォールド準備** が正解。マルチウェイでは 2 人のフォールドが同時に必要なため、T3 ブラフのフォールドエクイティが大幅に下がります。ただし OESD+FD などのコンボドロー（HS ≥ 35 程度）はセミブラフとして例外的に CBet の候補になります。

---

> **本章まとめ**
>
> - マルチウェイでは「誰かが強いハンドを持つ確率」が急増し、ブラフが通りにくくなる。
> - CBet 頻度の目安: HU 約 70% → 3way 約 40〜45% → 4way 約 25〜35%。
> - CBet 閾値調整: 3way は +5、4way は +10。T1（HS ≥ 65）のみを CBet の基本とする。
> - ウェット 2トーン・モノトーンボードでは 3way でも CBet をさらに絞る（HS ≥ 70〜75 程度）。
> - OOP での守備: T2 下位は「後ろのプレイヤーがレイズしてくる」リスクを考慮してフォールドを増やす。
> - IP（BTN など）はマルチウェイでも情報優位が大きく、チェックバックで安くターンを見る選択肢が有効。

---

**【GTO とのズレ】**

本章の CBet 頻度目安（3way: 約 40〜45%）と閾値調整（+5/+10）は理論的な推定値と実測の平均をもとにした目安です。
GTO では相手レンジの具体的な構成・ボードテクスチャ・スタック深度によって細かく変わります。
特に「4way で HS ≥ 70 のみ CBet」という単純なカットラインは過度な簡略化であり、実際の GTO は T1 の中でも強さに応じて頻度が異なります。
巻④・巻⑤でターン・リバーを学ぶ際に、マルチウェイのダイナミクスをより精緻化してください。
