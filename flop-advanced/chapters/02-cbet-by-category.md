# 第02章　ハンドカテゴリ別 CBet 分析

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: GTO 実測データを使ってハンドカテゴリ（T1/T2/T3）ごとの CBet 頻度を確認し、巻②の 3 ルールがデータと一致していることを検証する。

---

## 2-1　カテゴリ別 CBet 率とは何か

巻②では「T1 は常時ベット、T2 は B ≥ 58 でベット、T3 は B ≥ 62 でベット」という 3 ルールを学びました。本章ではこのルールを GTO ソルバーの実測データで検証します。

検証に使うデータは pot=10bb（フロップ CBet 後のポットを想定）、accuracy=30 の設定で取得した複数ボードの GTO 行動分布です。各ボードで「オーバーペア（T1）」「トップペア（T1）」「2 オーバーカード（T2）」「エアー（T3）」の 4 カテゴリに分けて CBet 率を計測しています。

なお「カテゴリ」は役スコアを基準に分類しています。セット・オーバーペア・TPTK などは HS ≥ 65 のため T1、AQ などの 2 オーバーカードは 2OC ボーナス込みで HS≥20 のため T2、役なしエアーは T3 です。

---

## 2-2　ドライ A/K-high ボードのデータ

**K♣7♦2♠（rainbow_ak, B=62）の実測データ**

| カテゴリ | CBet 率 |
|---|---|
| オーバーペア（AA など、T1） | 99.9% |
| トップペア（AK、KQ など、T1） | 99.8% |
| エアー（T3） | 100.0% |
| 全カテゴリ集計 | 99.9% |

このボードでは T1 はもちろん、T3（エアー）も 100% CBet しています。これは第 00 章で説明したレンジ優位の直接的な結果です。BTN の全レンジがこのボードで BB より有利なため、たとえエアーでも CBet することで期待値がプラスになります。

**A♣7♦2♠（rainbow_ak, B=62）の実測データ**

| カテゴリ | CBet 率 |
|---|---|
| トップペア（AA/AK など） | 98.4% |
| エアー | 99.2% |
| 全カテゴリ集計 | 98.6% |

A-high ボードでも同様のパターンが見られます。A72r では BTN が AA（トリップスに近い）や AK（TPTK）を多く持ち、圧倒的なレンジ優位があります。

---

## 2-3　ミドルストレングスボードのデータ

**Q♣5♦3♠（rainbow_q, B=58）の実測データ**

| カテゴリ | CBet 率 |
|---|---|
| オーバーペア（AA/KK/QQ など、T1） | 92.9% |
| トップペア（AQ、KQ など、T1） | 85.6% |
| 2 オーバーカード（AK on Q53r、T2） | 100.0% |
| エアー | 97.8% |
| 全カテゴリ集計 | 95.6% |

注目すべき点が 2 つあります。

第一に、トップペアの CBet 率が 85.6% に下がっています。K72r では 99.8% でしたが、Q53r ではやや低下します。理由は Q-high ボードでは BB のレンジに Ax や K-high などが多く、トップペアのコールオッズが悪くなる状況が生じるためです。トップペアを持っていても、弱キッカーの場合は混合戦略（ベット/チェックを混ぜる）になることを GTO は示しています。

第二に、2OC（2 オーバーカード、AK on Q53r）が 100% CBet しています。AK は Q53r に対して AK のどちらも Q より上なので 2OC ボーナスが付き、HS = A-high(25) + 2OC(24) = 49 となって T2 になります。T2 かつ B=58（境界値）なので CBet するのが正解で、GTO もこの方向性と整合しています（このボードで AK が EV プラスのベットになることと、本書の 2OC 設計の考え方が一致します）。

---

## 2-4　2tone（フラッシュドロー含む）ボードのデータ

**J♣8♣4♦（2tone, B=50）の実測データ**

| カテゴリ | CBet 率 |
|---|---|
| オーバーペア（AA/KK など、T1） | 97.1% |
| トップペア（AJ など、T1） | 91.7% |
| 2 オーバーカード（AK on J84fd、T2: HS≈55） | 97.7% |
| エアー | 95.4% |
| 全カテゴリ集計 | 93.1% |

2tone ボードになると全カテゴリで CBet 率が若干低下します。B=50 のため、巻②の T2 ルールでは「チェック」が推奨されましたが、実際には T2 の CBet も相当頻度で発生しています。

理由は 2 つあります。第一に、BB のフラッシュドローや OESD がエクイティを持つため、一部のハンドはチェック/コールに回ります。第二に、AK on J84fd は AK の 2 枚がともに J を上回るため 2OC ボーナスが付き HS が上がり T2 の上限付近となります。加えて AK はバックドアFD の可能性もあり（+6）、HS ≈ 55 で T2 の上位域に位置します。GTO が 97.7% CBet するのは、T2 上位の CBet が高頻度で正当化される好例です（T1 ではありません）。

**A♣T♣7♦（2tone_ak, B=56）の実測データ**

| カテゴリ | CBet 率 |
|---|---|
| トップペア（AA/AT など、T1） | 89.2% |
| エアー | 91.5% |
| 全カテゴリ集計 | 90.3% |

A-high 2tone では全体 CBet 率が 90.3% に低下します。AcTc7d はモノトーンに近い状況でフラッシュドローが多く、BB のレンジに FD が多く含まれます。これが CBet 率を引き下げる要因です。

## 2-5　ペアボードのデータ

**K♣4♦4♠（paired_high, B=83）の実測データ**

| カテゴリ | CBet 率 |
|---|---|
| オーバーペア（AA/KK など、T1） | 99.8% |
| トップペア（AK、KQ など、T1） | 99.8% |
| エアー | 100.0% |
| 全カテゴリ集計 | 99.9% |

ペアボードでは CBet 率が最高水準になります。K44 のようなペアボードでは BTN のレンジに KK（フルハウス）、44（クワッズ）、AA（オーバーペア）が含まれます。BB がセット/フルハウスでコールできる頻度は非常に低いため、BTN は高い頻度でベットを成立させられます。フォールドエクイティも高く、エアーも 100% ベットが成立します。

---

## 2-6　データから導かれる 3 つの知見

実測データを整理すると 3 つの知見が得られます。

**知見 1：T1 は全ボードで 85%+ CBet**

オーバーペア・トップペア・セットのような T1 ハンドは、どのボードでも 85% 以上の頻度で CBet します。「T1 は常時ベット」という巻②のルールは GTO データと整合しています。

**知見 2：2OC（T2 上位）は 97〜100% CBet**

AK on Q53r（2OC ボーナス込みで T2）は 100% CBet でした。これは巻②の 2OC 設計の考え方と方向性が一致することを示しています。2 枚ともトップカードを上回るハンドはベットが高頻度で正当化されます。

**知見 3：エアー（T3）の CBet はボードに依存**

K72r でのエアー 100%、Q53r での 97.8% は T3 ブラフが成立しています。しかし 2tone ボード（J84fd）では 95.4% まで低下します。T3 ブラフの可否は fold_vs33 の高さに依存します（第 03 章で詳述）。

---

## 2-7　CBet サイズ ── 実測と簡易モデルの差

巻②では「paired_high は 50%、mono は 75%、その他は 33%」というサイズルールを紹介しました。GTO 実測では実際のサイズ分布は次のようになっています。

| ボード | 33% ベット比率 | 75% ベット比率 |
|---|---|---|
| K♣7♦2♠（rainbow_ak） | 54.9% | 45.0% |
| K♣4♦4♠（paired） | 61.3% | 38.6% |
| A♣7♦2♠ | 66.0% | 32.6% |
| Q♣5♦3♠ | 58.5% | 37.1% |
| Q♣8♣3♦（2tone） | 72.6% | 23.6% |
| J♣8♣4♦（2tone） | 73.4% | 19.5% |
| A♣T♣7♦（2tone） | 67.2% | 23.1% |

実測では 2tone ボードほど 33% ベットの比率が上がっています。33% ベットは「ワイドレンジを維持しながら安く情報収集する」機能を持ちます。2tone では BB がフラッシュドローを持っている頻度が高く、大きなベットでリスクをとるよりも小さなベットで圧をかけるほうが EV が高くなります。

実戦上の対応としては、dry ボードでは 75% を基準にして 2tone では 33% を増やすという調整が合理的です。巻②の簡易モデルは大まかな近似ですが、2tone では 33% を主体に切り替えることで GTO により近い結果が出ます。

## ミニクイズ

### 問 1

Q♣5♦3♠（B=58）で AK を持っています。AK は Q53r での役スコアは A-high（25）です。2OC ボーナスを適用した HS は何点になりますか。また CBet すべきですか。

1. HS = 25、CBet しない（T3 かつ B=58）
2. HS = 49、CBet する（T2 かつ B=58 は境界でベット）
3. HS = 65、CBet する（T1）
4. HS = 25 + 2OC ボーナス = 49、B=58 は T3 でブラフ成立

### 問 2

K♣7♦2♠（B=62）でエアー（T3）の CBet 率が 100% になる主な理由はどれですか。

1. GTO はブラフを増やしすぎる傾向があるから
2. K72r は BTN のレンジが圧倒的に優位で、エアーも CBet することで相手のフォールドを引き出せるから
3. エアーは弱いハンドなのでチェックすべきだが、GTO は例外的
4. K72r では相手は必ずフォールドするから

### 問 3

J♣8♣4♦（2tone, B=50）で CBet をする場合、33% と 75% のどちらのサイズが GTO に近いですか。

1. 75%（ドローに高いプレッシャーをかけるべき）
2. 33%（2tone ではワイドレンジを維持する小ベットが主流）
3. 両者まったく同じ
4. どちらもダメで、チェックすべき

---

### 解答

- **問 1**: 2（AK は A と K がともに Q を上回るため 2OC ボーナス +24 が適用され、HS = 25 + 24 = 49 で T2 になります。B=58 は T2 のベット境界値なので CBet します）
- **問 2**: 2（K72r は BTN のレンジ優位が圧倒的で、BB がフォールドしやすい状況です。エアーでも CBet することで相手のフォールドエクイティを利用でき、全体の期待値がプラスになります）
- **問 3**: 2（GTO 実測では J84fd のような 2tone ボードで 33% ベットが 73.4% を占めます。ドローを持つ BB のエクイティが高い状況では大きなサイズより小さなサイズでレンジを広く維持するのが効率的です）

---

> **本章まとめ**
>
> - T1（オーバーペア・TPTK）は全ボードで 85%+ CBet：「T1 常時ベット」の実証
> - 2OC（AK on Q53r）は 100% CBet：巻②の 2OC ボーナス設計と GTO の方向性が整合
> - ペアボード（K44）では全カテゴリ 99%+ CBet：最高レンジ優位ボードの典型
> - 2tone ボードでは 33% ベットが主流（73%前後）：簡易モデルは rough な近似
> - エアーの CBet は fold_vs33 の高さに連動：詳細は第 03 章

---

**【GTOとのズレ】**

実戦では T1 を「遅い」チェックバックで保護しようとするプレイヤーが多いです。しかし GTO は T1 をほぼ全て CBet します。また 2tone ボードで大きなサイズ（75%）を選びすぎると、BB のドローに対してバランスが崩れます。2tone では 33% ベットを積極的に選ぶことで EV を改善できます。
