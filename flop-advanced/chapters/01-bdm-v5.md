## 巻② からのブリッジ

巻② 第8章で **簡易レンジスコア チェックリスト** を学びました。

```
Step 1: モノトーン？ → 70%（33% サイズ固定）
Step 2: ペア？      → ペア表
Step 3: ウェット判定 (連続3枚 / 2-tone / 高ボード連続)
Step 4: トップ A/K/Q × ウェット で 4 マス判定
            ドライ  ウェット
   ハイ    85%     55%
   ロー    55%     30%
```

10個の数字でR² 0.806（257ボード実測）、RMSE 4.8%。これだけで実戦の9割はカバーできる優秀なモデルです。

> **精密レンジスコア と先手/後手スコアの役割分担**
>
> 精密レンジスコア（およびその前身 簡易レンジスコア）は「このボードで IP のレンジ全体が何 % 程度 CBet するか」という **マクロ（レンジ）レベルの予測**モデルです。
>
> 一方、巻② 第16章の **先手スコア = HandScore + A − M** と **後手スコア = HandScore + A − C − M**（HU 時は M=0）は「自分のこの手で何をするか」という **ミクロ（個別ハンド）レベルの判断式**です。
>
> 2つは役割が異なります。精密レンジスコア が「このボードは 75% ベット戦略」と言っていても、手が弱ければ先手スコアが低くチェックバックが正解になります。逆に 精密レンジスコア が「55% 戦略」のボードでも、強いハンド（HS ≥ 65）なら先手スコアが高くベットが正当化されます。**本書では両者を組み合わせて使います**。

しかし巻② 第8章の5-7節で触れた通り、**5 つの外れ値ボード**が残っています。A82r (-33%)、J84ss (-20%)、K95r (+5%、境界)、KT5r (+15%)、KQTss (+20%)。この5つに共通する何かがあるはず。

巻②の付録Dに「精密レンジスコア完全係数表」として、これらの外れ値を吸収する精密モデルの最終形だけを載せました。本章では、**その係数表がどこから来たのか**を、著者の試行錯誤とともに追体験します。

## 📘 本章（精密レンジスコア = 式）と第4章（17 型 = 表）の関係

本章と第4章は、**同じ 30 ボードの GTO 実測データから同じ問題を解いている、2 つの表現**です。両方を完全に習得する必要はありません。

### 何が同じか

- **元データ**:30 ボードの GTO ソルバー実測
- **目的**:簡易レンジスコアの外れ値（A82r、KQTss など 5 ボード）の吸収
- **出力**:IP プリフロップアグレッサーの CBet 頻度（%）

### 何が違うか

| 観点 | 本章 精密レンジスコア（**式**） | 第4章 17 型分類（**表**） |
| --- | --- | --- |
| 表現 | 連続式（90 − 4 項減算） | 離散テーブル（型 → 代表値） |
| 暗記対象 | 係数 10 個 | 型定義 17 個 |
| 出力 | 0〜90% の連続値 | 17 段階の離散値 |
| 未知ボード | 外挿可能（係数で計算） | 近い型に当てはめて近似 |
| 境界ボード | 滑らか | 値が飛ぶ可能性あり |
| 拡張 | 巻④ バレルスコアへ滑らかに接続 | チートシート化が容易 |

### 本章を選ぶべき読者

- 数式が苦にならない / 任意ボードに即時対応したい
- 巻④ のバレルスコア（同じ式モデル）へ滑らかに繋げたい
- 拡張性・GTO 整合性を重視したい

### 本章を飛ばして第4章で済ませてよい読者

- 暗算ステップを増やしたくない / ライブで瞬発判断したい
- 17 型のパターン認識のほうが覚えやすい

つまり、**式が好きなら本章、表が好きなら第4章**を選んでください。両方必須ではありません。

## 1-1　「簡易レンジスコア が外した 5 つのボード」から始まった

簡易レンジスコアの検証に使った30ボードの中で、誤差10% 以上の外れ値は次の5つでした。

| ボード | 簡易レンジスコア 予測 | GTO 実測 | 残差 | ざっくりした型 |
|-------|:------:|:-------:|:----:|:--------------|
| A82r  |  55%  |  88%    | **-33** | A-high + 散開 + 2-tone |
| J84ss |  30%  |  50%    | -20 | J-high + 2-tone |
| KT5r  |  85%  |  70%    | +15 | middle=T の rainbow |
| KQTss |  55%  |  35%    | **+20** | 全 broadway + 2-tone |
| K95r  |  85%  |  80%    | +5 (境界) | middle=9 の rainbow |

パッと見で5つに共通点はありません。A-highとJ-high、broadwayと散開、rainbowと2-toneが混在する。残差の符号も**プラス・マイナス両方**にあり、「簡易が高めに見積もる場合」と「低めに見積もる場合」が両方存在します。

しかし「なぜ簡易レンジスコアが外すか」を1つずつ見ていくと、簡易レンジスコアの4マス（トップ高低 × ウェット/ドライ）では **取りこぼしている構造**があることが見えてきました。

### A82r が 簡易レンジスコア で 55% なのはなぜか

簡易レンジスコアのウェット判定は「連続3枚 / 2-tone / 高ボード連続」のいずれか。A82rは ♠♠♦ なので2-toneに該当 → ウェット扱い。トップAでハイなので55%。

しかし実測は88%。**A ハイに 2-tone でも、フロップの max_diff が 11 と大きく散開していれば、PFA のレンジアドバンテージがフル機能する**。簡易レンジスコアは2-toneだけでウェット扱いしたのが行き過ぎ。

### KT5r が 簡易レンジスコア で 85% なのはなぜか

max_diff = 8でウェット条件のいずれにも該当しない → ドライ扱い。トップKでハイなので85%。

しかし実測は70%。**middle に T があると、BB の KT/QT/JT/T9 コンボが急激に増える**。簡易レンジスコアは「散開か連続か」だけを見てmiddleカードの位置を無視していた。

### KQTss が 簡易レンジスコア で 55% なのはなぜか

K-Q-T (♣♣♦) は max_diff = 3、♣♣ の 2-tone なのでウェット判定。トップ K でハイなので **ハイ × ウェット = 55%**。

しかし実測は **35%** で、簡易が **20 ポイント高め**にズレます。理由は「**3 枚すべてが T 以上の "全 broadway 2-tone"**」という構造です。

- BB のディフェンスレンジには **KT/KJ/QJ/QT/JT** といったトップペア／セカンドペアのコンボがほぼ全部直撃します
- さらに **AJ/J9/T9** などストレート系ドローも BB 側に密に存在
- PFA のナッツ優位は残るものの、**BB のヒット率が高すぎて高頻度 CBet が回らない**

簡易レンジスコアは「トップが高い + 2-tone」までは見ていますが、**「3 枚とも broadway」という構造**を独立に評価していないため、broadway 2-tone を一般のハイ × ウェットと同列に扱ってしまいます。これが 20 ポイントのズレの正体です。

## 1-2　5 つの外れ値を 3 次元に分解する

5つのボードの共通構造を探るため、30ボード全体の「簡易レンジスコア予測からのズレ」を3つの軸で並べ直しました。

### 軸 1: トップカード別のズレ

```
top = A:  平均 +10.5  (4 ボード)  ← 簡易レンジスコア は低く予測しがち
top = K:  平均  +4.2  (4 ボード)
top = Q:  平均  +0.5  (2 ボード)
top = J:  平均  -7.5  (2 ボード)  ← 簡易レンジスコア は高く予測しがち
top = T:  平均  +2.3  (3 ボード)
top ≤ 9:  平均  +3.8  (5 ボード)  ← 意外と 簡易レンジスコア は低め予測
```

Aが突出して高く、Jが突出して低い。**A と J の間に段差**がある。簡易レンジスコアの「ハイ (A/K/Q)」まとめがやや雑で、A/K/Q内部の微差が出ていない。

### 軸 2: スート構造別のズレ

```
rainbow:   +3.3  (20 ボード)
2-tone:    -4.2  (8 ボード)   ← 簡易レンジスコア は高めに予測しがち
monotone:  +2.7  (2 ボード)
```

2-tone全体で平均 -4.2% の高めズレ。ただしこれは**条件付き**。top=Aの2-tone（A82r）は +33%、top=Jの2-tone (J84ss) は -20% と、**トップカードと 2-tone の組合せで符号が反対**に動く。

### 軸 3: max_diff (連続性) 別のズレ

```
max_diff ≤ 2:  -3.5  (7 ボード)  ← わずかに 簡易レンジスコア 高め
max_diff 3-4: +2.1  (6 ボード)
max_diff 5-7: +4.8  (3 ボード)  ← 簡易レンジスコア 低め
max_diff ≥ 8: +5.5  (14 ボード) ← 簡易レンジスコア 低め (特に散開ドライ)
```

散開 (max_diff ≥ 8) で簡易レンジスコアが低めに予測する傾向。これは **トップ A/K で散開なら 簡易レンジスコア の 85% より実測が高い**ケースが多いため。

### 3 軸が独立に動いている

3つの軸をそれぞれ見ると、**独立にズレの方向が決まっている**ように見えます。

- トップカード： Aに近いほど簡易レンジスコア予測を上げるべき、Jに近いほど下げるべき
- スート構造： 2-toneならトップと掛け合わせて判定、単独では扱えない
- 連続性： 散開で簡易レンジスコアより高く、連続でわずかに低く

**簡易レンジスコア の 4 マス**では、これらの3軸を「ハイvsロー」「ウェットvsドライ」の2カテゴリに潰しているため、微妙な差分が吸収されきらない。

## 1-3　「90 から引く」発想の誕生

3軸の独立性に気づいたとき、モデルの構造を **カテゴリ分類** から **連続減算** に変える案が浮かびました。

### PFA のデフォルトは 90%

何も特別な事情がなければ、プリフロップアグレッサー (PFA) のCBet頻度は90% に近い。K72rやA72rで91% / 90% という実測がその証拠。これを **基準値**とします。

### 「下げる理由」があるときだけ下げる

```
CBet% = 90 − (下げる理由の合計)
```

「下げる理由」を3次元それぞれに係数として割り当てる：

1. **HighCardDeficit**: トップカードがA/K以外のときに引く
2. **TextureCost**: ウェットなほど引く（連続性 × トップカードの相互作用）
3. **SuitPenalty**: 2-toneなら引く
4. **Extra**: ブロードウェイ複合など特殊パターンで追加で引く

そして、ペアボードは**特殊構造**なのでoverrideテーブル、モノトーンは **70% 固定（33% サイズ）**で即終了。

この発想で4項減算式 **精密レンジスコア** が生まれました。

## 1-4　HighCardDeficit の係数を置く

### トップカード別の実測から逆算

ペアボード（型6・型7）とモノトーン（型5）はoverride／固定値で別系統に処理するため、ここでは **それらを除いた18ボードのsubset**でトップカード別に整理します。

```
top = A:  平均 89.0%  (4 ボード)
top = K:  平均 84.0%  (6 ボード、ペア含む)
top = Q:  平均 75.0%  (3 ボード)
top = J:  平均 46.0%  (2 ボード)
top = T:  平均 40.0%  (3 ボード)
top = 9:  平均 40.0%  (3 ボード)
top = 8 以下: 平均 52.0% (5 ボード)
```

トップがA/Kで84-89%、Qで75%、J以下で急激に40% 台に落ちる。**Q と J の間に大きな段差**。

90を基準にした減算値：

```
A: 0    (90 から引かない)
K: 0    (ほぼ A と同等)
Q: 5    (平均 75 へ、ただし ペア Q53r が 85 で引き上げ)
J: 35   (平均 55 近辺まで落とす、ただし他の項でも引くので)
T: 35
9: 35
8 以下: 30
```

### J 以下で突然 30-35 引く理由

A/K/QはプリフロップレイザーのレンジにAX/KX/QXコンボが密。これらをフロップのトップがブロックするため、PFAのレンジ優位がフル機能します。

J以下になると様相が一変。**BB のディフェンスレンジに JT/T9/98 などのコネクターが密に入っている**。ここがフロップのトップに直撃するため、PFAの優位が消えます。

### 8 以下が 30 (J/T/9 より 5 少ない) 理由

実測を見ると：

```
632r: 62%  (8 以下ロー連続)
876r: 42%  (8 以下ロー連続)
```

J/T/9トップより少し高めの頻度を維持。これは「**PFA も BB もヒットしない、特殊なドライ感**」。8以下でHighCardDeficitを30に抑え、ほかの項の減算も弱めに設定することでこの差を吸収します。

## 1-5　TextureCost の「トップ × 連続性」マトリクス

連続性の影響は、トップカードと強く相互作用します。

### 連続 3 枚 (max_diff ≤ 2) の実測

```
top ≤ 8 (632r):           62%  ← ほぼドライ扱い
top = 9 rainbow (965r):   60%  ← こちらも特殊ドライ
top = 9 2-tone (987ss):   30%  ← 急に低下
top = T 2-tone (T98ss):   35%
top = T rainbow (T98r):   40%
top = J 2-tone (JT8ss):   30%
top = Q+ 2-tone (KQTss):  35%
```

**トップが高くなるほど連続 3 枚のペナルティが大きくなる**。PFAのナッツレンジが薄くなる一方、BBのストレート密度が上がるため。

### TextureCost の表

| max_diff | top ≤ 8 | top 9 rain | top 9 2t | top T 2t | top T rain | top J | top Q+ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| ≥ 8 (散開)     |  0 |  0 |  0 |  0 |  0 |  0 |  0 |
| 5-7 (中程度)    |  5 |  5 |  5 |  5 |  5 |  5 |  5 |
| 3-4 (2連+G)    |  5 | 15 | 15 | 15 | 15 | 15 | 25 |
| ≤ 2 (連続 3 枚) |  5 | 10 | 20 | 15 | 20 | 25 | 30 |

この「トップ × 連続性」マトリクスが精密レンジスコアの肝。12マスですが、左上（top≤8は常に5）と右下 （top Q+ は常に最大） を覚えれば、中央は推測で埋まります。

## 1-6　SuitPenalty は単純、でも寄与が最大

スート構造の処理は最小限：

```
rainbow:   0
2-tone:   10
monotone: override → 18% 固定 (他の式を全部無視)
```

たった3行。しかし **Ablation 分析で SuitPenalty の寄与度が最大**（R² で -0.263）であることが判明しました。

### SuitPenalty を無効化した 精密レンジスコア の精度

| 状態 | R² | MAE |
|------|:---:|:---:|
| 完全 精密レンジスコア | **0.914** | **5.27** |
| − SuitPenalty | 0.651 | 8.60 |
| − Pair override | 0.764 | 7.37 |
| − Extra | 0.840 | 6.93 |

SuitPenaltyを外すとR² が0.651まで低下（簡易レンジスコアの0.806から大きく後退）。**モノトーン override + 2-tone ペナルティの 2 行**が、精度の柱を支えています。

### なぜそんなに効くか

30ボード中2-toneは8個、モノトーンは2個。計10ボード（全体の3割）で正しい扱いをするだけでR² が0.26も動く。逆に言えば、**フラッシュ構造を甘く見ると致命的に外す**ということです。

モノトーンの70% 固定は、著者のGCP TexasSolver実測（257ボード）でmonoトーン平均70.5%（broadway系66%、low系74%）という実測を代表値として採用した値。ここをゼロから4項式で計算しようとするとむしろ精度が下がる。だから **override** で即終了。

## 1-7　Extra 4 ルール ― 局所的な外れ値の補正

ここまでの3項 (HighCardDeficit + TextureCost + SuitPenalty) でR² = 0.840に到達。残り0.074ポイントがExtra 4ルールの寄与です。

### Extra が発動する 4 つの条件

```
Rule E1: middle = T かつ top ≥ Q かつ rainbow
         → 追加 -15    例: KT5r, QT3r

Rule E2: 3 枚とも T 以上 かつ 2-tone
         → 追加 -10    例: KQTss, QJTss

Rule E3: top = A/K/Q + middle = T + 2-tone + low < T
         → 追加 -15    例: AT7ss, KJ4ss

Rule E4: top = Q かつ middle < T かつ 2-tone
         → 追加 -10    例: Q83ss
```

30ボードのうち4ボードでしか発動しません (KT5r, KQTss, AT7ss, Q83ss)。**局所的な外れ値の修正**です。

### Extra の寄与が小さい理由

30ボード × 4発動 = サンプルが少ないため、AblationのR² 影響は -0.073に留まります。しかし、**発動した 4 ボードの外れ値は 15-30% から 5% 以内に収まる**劇的な効果があります。

### Extra を設計した思考プロセス

E1 (middle=T × top≥Q × rainbow) が最初に見つかりました。KT5rの実測70% に対し、3項式では85% を予測していた。共通パターン「middleにブロードウェイカードが挟まっているrainbow」に着目。

- K **T** 5r、Q **T** 3r、K **T** 2r ... 確かに実測は70% 前後で一貫
- このパターンはBBがKT, QT, JT, T9のコンボを密に持つため

E2（全broadway 2-tone）、E3 (A/K/Q + mid=T 2-tone)、E4 (Q-high 2-tone) も同様のパターン発見で追加されました。

### ただし E4 は過剰補正気味

Q83ssでE4が -10を引きますが、実測55% に対し精密レンジスコアは65% を予測。5% の過剰補正が残ります。次版（v6）ではE4を緩める （-5に） 案も検討中。

## 1-8　Pair Override ― 「特殊構造」のための別式

ペアボードだけは4項減算式ではなく、**7 パターンの固定値表**で処理します。

```
AA ペア (AA-X):                   90%    例: AA7, AAK, AA3
KK ペア (KK-X):                   85%    例: KK4, KK9, KKJ
QQ ペア (QQ-X):                   80%    例: QQ3, QQT
ミドルペア (TT-88):                75%    例: TT5, 995
ローペア (77 以下):                68%    例: 772, 665
A/K ハイ + ローペア (ペア ≤5):     45%    例: K44, A33
A/K ハイ + 中ペア (ペア 6-T):      76%    例: A99, K88
Q/J ハイ + ローペア:               55%    例: Q33, J55
```

AA/KK/QQをペアランク別に分離することで、旧来の「ハイペア+低キッカー=50%」という誤差の大きい分類を廃止しています。GTO Wizard実測ではKK-X平均≈90%（33%サイズ換算でKK9=80%、KK低キッカー≈90%）のため、KKペア=85%は全KKXボードの良い近似です。

### なぜ override が必要か

**K44 問題**: K44は「ペアが4、キッカーがK」という特殊構造。4項減算式で計算すると、トップのKをA/K-highとして扱い、HighCardDeficit = 0、TextureCost = 0（散開）、SuitPenalty = 0 (rainbow) → 90% 予測。しかし実測は43%。

原因： K44は「PFAのレンジにK4o/K4sが存在しない」ため、トップのKがフロップで機能しない。**レンジが直撃していない**。4項減算式の前提である「トップカード = PFAのレンジヒット」が崩れる。

**解決**: ペアボードは4項減算式を無視し、「ペアのランク」で固定値を割り当てる。K44は「A/Kハイ + ローペア」= 45%（実測43% とほぼ一致）。

### 8 パターンで 30 ボード中 5 ボードを捕捉

| ボード | 予測 | 実測 | 誤差 |
|-------|:----:|:----:|:----:|
| AAK | 90% | 85% | +5 |
| KK9 | 85% | 80% | +5 |
| 772 | 68% | 70% | -2 |
| K44 | 45% | 43% | +2 |
| A99 | 76% | 78% | -2 |

すべて誤差3% 以内。**ペア override の寄与**（Ablationで -0.150）は、K44一個でExplainできます。

```
CBet% = 90 − HighCardDeficit − TextureCost − SuitPenalty − Extra
        (ペアは override、monotone は 18% 固定)
```

詳細係数は巻②付録Dおよび本書付録Bに掲載。ここでは完成品の精度だけ示します。

## 1-10　設計思想の再確認

精密レンジスコアの構造を振り返ると、3つの原則が見えます。

### 原則 1: 独立な次元は独立に扱う

トップカード / スート / ペアは独立な軸。これを1つのスコアに押し込まない。

### 原則 2: 特殊構造は特殊扱い

モノトーンとペアボードは、4項減算式の対象から外して固定値や固定テーブルで処理する。「一般式 + 例外」より「例外を最初に処理」の方が精度が出る。

### 原則 3: データから帰納、演繹では逆算しない

係数 (A/K=0, Q=5, J=35, T=35...) は実測データから帰納して決めたもの。理論から「JはAより弱いから20にしよう」などと演繹すると外れる。

## 1-11　965r が語る「モデルの外」

精密レンジスコアで残る唯一の外れ値 **965r**。

- GTO実測： 60%
- 精密レンジスコア予測： 40%
- 残差： **+20%**

9-6-5はロー連続rainbow。精密レンジスコアでは「top=9連続3枚rainbow」でTextureCost = 10を引き、HighCardDeficit = 35も引くので90 − 35 − 10 − 0 = 45%（境界の ± で40-45% の揺らぎ）。

### 仮説 1: 「特殊ドライ」

9-6-5は連続3枚に見えて、max_diff = 4。OESD密度は高いが、65s/76s/87sはコンボ数が少ない。PFAもBBもヒットしない「**ドライ寄りのロー連続**」。

類似ボード：

- 876r: 実測42%（精密レンジスコア 50%、+8の外れ）
- 632r: 実測62% (精密レンジスコア 55%、+7)
- 965r: 実測60% (精密レンジスコア 40%、+20)

3ボード中2ボードは5-10% の誤差だが、965rだけ +20% の大きい外れ。なぜか。

### 仮説 2: 6 がトップミドル

9-6-5のmiddleカード6が低すぎる。通常のロー連続（T98, 987）ではmiddleが8-9で、BBのコネクター (T9s, 98s) を密に巻き込む。しかし6がmiddleだとBBのレンジに6周辺の密度が少ない。

### 仮説 3: 4-4-1 構造

9と6の差が3 (middle-gap)、6と5の差が1。ギャップ配分が3-1と不均等。これがGTOにとって特殊な構造を生む可能性。

### v6 候補

次版では以下を検討：

- ロー連続 (max_diff 3-4、top ≤ 9) を「連続」「散開」の2つに細分化
- middleカードのギャップ配分（均等vs偏り）を新軸として導入
- 新しい「Extra E5」: top=9 + middle ≤ 6で追加 +10の補正

ただしこれらは30ボードでは検証できません。より多くのGTOデータ（100-200ボード）を入手してから再検討します。

**✅ 正解**: 主要 5 項 (E1-E4 と pair override) で全ボードの約 90% をカバーできる。残りの外れ値ボードは 簡易レンジスコア の近似値で十分対応可能であり、完全暗記は必須ではない。

## 章のまとめ

- 巻②の簡易レンジスコア (R² 0.806) が外した外れ値ボードを深掘りした結果、**トップカード / スート / ペア の 3 独立次元**が見えた
- **「90 から引く」** 発想で、4項減算式に再編した
- HighCardDeficit（トップ）+ TextureCost （連続性×トップ） + SuitPenalty (2-tone/mono) + Extra (broadway 4ルール) の4項
- ペアは7パターンoverride、モノトーンは18% 固定
- R² 0.914に到達、外れ値は965rの1つのみ
- 965rはモデルの構造的限界を示唆、v6で再設計候補

### 補足: 1 次元の限界と 2 次元 BoardScore

本章の精密レンジスコアは **overall CBet 頻度** という 1 次元出力を予測する。書籍本文の理解にはこれで十分だが、**型 7a (K44 系) のように overall 43% でも内部構造が他の 43% ボードと異なる**ケースがある。

具体的には、各ボードでの戦略は本来 **「Value 圧」（強ハンドの bet 率）と「Bluff 圧」（弱ハンドの bet 率）** の 2 軸に分解できる:

- 型 1b (K72r): Value 圧 1.00 + Bluff 圧 0.57 → **積極ブラフ型**
- 型 7a (K44): Value 圧 **0.60** + Bluff 圧 0.39 → **強ハンドもチェックバックする保護型**

この 2 次元構造は精密レンジスコアでは捉えきれない。詳細は **付録 J「2 次元 BoardScore（上級者向け）」**を参照。

次章（第2章混合戦略R1-R6）では、9マスマトリクスの境界セルで読まれないようにランダム化する6つのルールを扱います。

## 次章への橋

精密レンジスコアは「レンジ全体のCBet頻度」を精密化するモデルです。個別ハンドのアクション判定は、巻② 第10章の9マスマトリクスと組み合わせて使います。

```
Step A: 精密レンジスコア でレンジ頻度 %
Step B: HandScore で自ハンド強度
Step C: 9 マスマトリクス でアクション
```

第2章では、9マスの「境界セル」（全体の40-50%）で、決定論を揺らすためのR1-R6混合戦略ルールを扱います。

**【GTOとのズレ】**

精密レンジスコアは30ボードのGTO実測から逆算した4項減算式です。R² 0.914、MAE 5.3まで到達しましたが、これは「**30 ボード内での内挿精度**」であり、GTOソルバーの真の最適頻度との完全一致ではありません。本書の係数（HighCardDeficit、TextureCost、SuitPenalty、Extra）はあくまで30ボードの平均的な振る舞いを近似する道具です。

ズレが顕著に出るのは、まず965rに代表される **「ロー連続 rainbow の特殊ドライ」**。精密レンジスコアは40% を予測しますが実測は60% で、20% の外れが残ります。次に、**プリフロップサイズが 2.5x 以外**のケース。係数は2.5xオープン前提で校正されており、3betポットや4betポットではナッツ密度が変わるためレンジ全体のCBet頻度も10-15% シフトします。さらに、**HUD でわかる相手の傾向**（フォールド頻度、レンジ広さ）はモデルに含まれません。

実戦では、精密レンジスコアの値を「**±5% の幅を持つ目安**」として扱うのが安全です。HandScoreが境界（HS 60-72）にいるハンドだけ精密化を効かせ、それ以外は簡易レンジスコアの4マスで十分。65% と70% の差で迷うより、9マスマトリクスで決定論的に動き、第2章のR1-R6で揺らす方がEVは安定します。
