## 巻② からのブリッジ

巻③の最終章です。精密レンジスコア（B-score / BDM-v5）・混合戦略 R1-R6・相手タイプ別エクスプロイト・レンジ読み・4-bet ポット・チェックレイズを1問ずつ取り上げます。

各問は「問題文（状況と問い）→ 解答（根拠式 + 行動）」の形式で、自分でアクションを決めてから解答を見てください。

## ドリル 6 問

### 問1　精密レンジスコア（BDM-v5 スコア）

**BTN オープン、BB コール、フロップ K♠T♦4♣（rainbow、middle=T）。IPの CBet 推奨頻度はいくつですか？**

1. 85%（簡易レンジスコア、ハイ×ドライ）
2. 70%（精密レンジスコア、E1 補正 −15%）
3. 55%（ハイ×ウェット扱い）
4. 40%（ペアボード扱い）

<details>
<summary>解答</summary>

**答え: 2（70%）**

根拠式:
```
簡易レンジスコア: ハイボード（K）× ドライ（rainbow）= 85%
精密レンジスコア補正: middle=T かつ top=K → E1（middle コネクター）= −15%
→ 85% − 15% = 70%（中頻度帯）
```

K♠T♦4♣ は「top=K のハイボード」に見えますが、T が middle に入ることで連続性が生まれます。精密レンジスコアの E1 補正を適用しないと 85% と過大評価します。これが簡易レンジスコアでは吸収できない「外れ値ボード」のパターンです。

</details>

---

### 問2　相手タイプ別エクスプロイト（E 補正）

**BTN vs BB の SRP。フロップ K♠7♦2♣（ドライ）。自ハンド A♣K♦（TPTK、HS=68）。相手 HUD: VPIP 38%、PFR 22%、AFq 35%（LAG）。どのアクションが最も搾取的ですか？**

1. チェック（相手のブラフを誘い、コールで対応）
2. CBet 33%（小さく打って相手のコールを集める）
3. CBet 75%（LAG のコール率の高さを利用してバリューを最大化）
4. CBet 50%（標準サイズで中立的に打つ）

<details>
<summary>解答</summary>

**答え: 3（CBet 75%）**

根拠式:
```
精密レンジスコア: K♠7♦2♣ は補正なし → 85%（高頻度帯）
9マス: 高頻度 × 強（HS=68）→ バンドA（CBet 確定）
R4 サイズ: LAG（コール率高）× TPTK → サイズ最大化 → 75%
E 補正: LAG は AFq 35%、相手コール率が TAG より高い → バリューは厚く打つ
```

LAG はコール率が高いため、HS=68 の TPTK では 75% CBet でバリューを最大化します。チェック（選択肢1）は EV が下がります。

</details>

---

### 問3　レンジ読み（ベイズ更新）

**BTN オープン、BB コール（HUD: VPIP 26%、PFR 18% → TAG）。フロップ A♥K♦Q♣（rainbow、全 broadway）。BB がドンクベット（50% ポット）を打ってきた。BB の想定レンジとして最も可能性が高いのはどれですか？**

1. AK（2 ペア）やセット → 強バリュー中心
2. JT（ストレート完成）→ ナッツ中心
3. 中程度のワンペア（A7 など）→ プロテクトベット
4. ブラフ（KT、QJ など）→ ブラフドンク中心

<details>
<summary>解答</summary>

**答え: 2（JT ストレート完成、ナッツ中心）**

根拠:
```
JT on A♥K♦Q♣ = T-J-Q-K-A の broadway ストレート完成（ナッツ）
TAG（VPIP 26%/PFR 18%）はブラフドンクが少ない → 50% ドンクはほぼバリュー
```

第7章ベイズ更新: BB のドンクベットサブレンジは強バリューに偏ります。JT（ナッツ）+ AK/AQ（2ペア上位）が主体です。

</details>

### 問4　4-betポットのフロップ判断

**BTN 4-bet（34BB ポット）、BB コール。SPR ≈ 1.94。フロップ Q♠7♦2♣（ドライ）。自ハンド A♠A♥（HS=78）。正しいアクションはどれですか？**

1. チェック（スロープレーしてリバーでバリューを取る）
2. 小ベット（25% ポット）でコントロール
3. 75% ポットベット（コミット計画、HA≥50 でオールイン誘導）
4. レンジベット（33% ポット、全レンジで均一に打つ）

<details>
<summary>解答</summary>

**答え: 3（75% ポットベット、コミット計画）**

根拠式（第15章）:
```
SPR ≈ 1.94: 4-bet ポット = 「別ゲーム」
コミット閾値: HS ≥ 50 でフロップオールイン計画が正当化される
HS = 78（AA オーバーペア最高値）→ 閾値を大幅に超える
行動: 75% CBet → 相手がコールすればターンオールイン、
      相手がレイズすればコールインまたはオールイン
```

SPR ≈ 1.94 では小ベットでのコントロールは機能しません。相手が続けてベットすれば結局オールインになるからです。75% CBet でコミット計画を明確にするほうが EV が上がります。

</details>

### 問5　チェックレイズの条件

**BTN vs BB（SRP）。フロップ T♥9♠8♦（ウェット、型4）。自ハンド 7♦6♦（OOP、ストレート完成）。BTN が 75% CBet を打ってきた。正しいアクションはどれですか？**

1. コール（ストレートを隠してリバーで大きく稼ぐ）
2. フォールド（ウェットボードで BTN の CBet は強バリューだから）
3. チェックレイズ 2.5倍（ストレートナッツでレイズして EVを最大化）
4. ミニレイズ（相手の反応を見てから次を考える）

<details>
<summary>解答</summary>

**答え: 3（チェックレイズ 2.5 倍）**

根拠:
```
自ハンド: 7♦6♦ on T♥9♠8♦
  7-8-9-T-6... 6-7-8-9-T = 6-high straight 完成（ナッツ候補）
  ボード: T-9-8-7-6 が揃う → 7♦6♦ は 6-high straight = **ナッツ**

BTN が 75% CBet: 型4 ウェットボードでも 75% は強バリュー or セミブラフ
自分がナッツを持つ場合: チェックレイズで EV 最大化

チェックレイズの条件（第3章応用）:
  - ナッツ / ナッツ近接のハンドで相手が大きいサイズを打ってくる場合
  - ポット 6BB × BTN の 75%（4.5BB）= ポット 10.5BB
  - CR 2.5 倍 = 約 11BB → 相手に降りられるリスクを減らしつつポットを大きくする
```

76s on T98 はナッツ確定。相手がすでにベットしているのでチェックレイズが最も EV の高いラインです。コールは1ストリート分のバリューを逃します。

</details>

### 問6　総合判断（精密 HS + タイプ + B-score）

**3-bet ポット（SB 3-bet → BTN コール）。pot=18BB、SPR ≈ 4.6。フロップ A♠K♦5♣（rainbow）。自ハンド Q♠Q♥（IP、BTN）。相手 SB は Nit（VPIP 14%、PFR 12%）。相手は 75% CBet を打ってきた。正しいアクションはどれですか？**

1. コール（QQ はオーバーペアだからコールで十分）
2. レイズ（QQ はブロッカーがあるのでブラフレイズ）
3. フォールド（相手 Nit の 75% CBet はほぼ AK / AA / KK / AK = 強バリュー確定）
4. コールして、ターンの相手の行動次第で決める

<details>
<summary>解答</summary>

**答え: 3（フォールド）**

根拠:
```
後手スコア = HS + A − C − M
  = 55 + 12（ドライ A係数）− 22（75% CBet の C 係数）− 0（HU M=0）= 45
SPR 3-5 のコール閾値: ≥ 60 → コール。後手スコア 45 < 60 → フォールド推奨
さらに Nit はブラフがほぼない → エクスプロイト補正でコール基準が上がる → フォールド確定
```

「QQ はオーバーペアだからコールできる」は SRP での感覚です。3-bet ポットで Nit 相手の 75% CBet はほぼ強バリューのみ。後手スコアと Nit 補正の両方がフォールドを指します。

</details>

**【GTOとのズレ】**

本章の6問は巻③の枠組み（精密レンジスコア + R1-R6 + E 補正 + 後手スコア）に基づく推奨アクションであり、ソルバーが出力する GTO 解そのものではありません。問2の「CBet 75%」も、純 GTO 解では「50% と 75% を混合」という出力になることがあります。ドリルでは高速判断のために「1つの推奨アクション」を示していますが、実戦では混合戦略の頻度を意識した打ち分けがより GTO 的です。

問6の後手スコア計算では「係数の絶対値」よりも「閾値との比較」が重要です。後手スコアの係数（A・C・M）はスケール設計であり、ソルバーの EV と1対1には対応しません。「後手スコアが閾値を大きく下回る」場合はフォールド推奨という使い方が、誤差を最小化する運用方法です。
