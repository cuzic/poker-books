## 読者ペルソナ別の読み方

- **A (中級ステップアップ組)**: 難易度 A・B のみ (25 問) に挑戦する。C・D は後回しにしてよい。
- **B (ソルバー派)**: 難易度 D の 10 問で自分の EV ロスを測定する。合格ラインは正答率 70%。
- **C (ライブベテラン)**: 実戦で出やすい状況に絞って 15-20 問選んで解き、自分の弱点型を発見する。

## 巻② からのブリッジ

巻③の最終章。第1-16章で学んだ全道具を使って、50の実戦問題を解きます。難易度別（A=初級/B=中級/C=上級/D=プロ）で各10-15問。

### 各問の解答形式

```
A プラン: 簡易レンジスコア + 9マスマトリクス のみ (巻② の知識)
B プラン: + 精密レンジスコア + R1-R6 (第1-2章)

D プラン: + レンジ推定 + エクスプロイト + メタゲーム (第5-14章)
```

各問で4つのプランのどれが最適かを判定します。

## 17-1　難易度 A 問題 (初級、10 問)

### 問 A1

**BTN オープン、BB コール、フロップ K♦7♠2♣、自ハンド A♥K♠ (IP)、相手 TAG (E = 0)**。アクション？

<details>
<summary>解答</summary>

```
Step 1: 簡易レンジスコア → ハイ×ドライ = 85% (高頻度)
Step 2: HS → TPTK = 18 (強)
Step 3: 9マス → 高頻度×強 → CBet 75%
Step 4: 相手 TAG、E = 0 → 補正なし
```

**答え: CBet 75%**

</details>

### 問 A2

**BTN オープン、BB コール、フロップ 9♥8♠7♦、自ハンド K♣K♦ (IP)、相手 TAG**。

<details>
<summary>解答</summary>

```
Step 1: 簡易レンジスコア → 型4 ロー×ウェット = 30% (低頻度)
Step 2: HS → オーバーペア 20 (強)、型4 補正 -8 = 12 (中扱い)
Step 3: 9マス → 低頻度×中 → チェック
```

**答え: チェック**

オーバーペアでも型4ウェットは慎重。

</details>

### 問 A3-A10

ボードと自ハンドを与えて、巻②の基本プラン（簡易レンジスコア + 9マス）で解く8問。各自30秒以内で解答。

例：。

- A3: 自ハンド77 on K72r (IP) → CBet 33%
- A4: 自ハンドAQ（空振り）on K72r → CBet 33% （BDFDあり） またはチェック
- A5: 自ハンドJJ on 987ss → チェック（型4補正）
- A6: 自ハンドAA on AKQmono → 20%（モノトーン固定）
- A7: 自ハンドKK on K44 → ペアoverrideでKK ≥ QQ + kicker 4 < 8 → 50%（ただしKKはトリップス、CBet 75%）
- A8: 自ハンド22 on Q83ss → アンダーペア、中ハンド → チェック
- A9: 自ハンドKJ on K♠T♦5♣ → 型2e（middle=T）→ CBet 50% (精密レンジスコアで -15補正）
- A10: 自ハンド87s on J♠T♠9♦ → ガットショット + BDFD → 中、33% セミブラフ

## 17-2　難易度 B 問題 (中級、15 問)

精密レンジスコアやR1-R6の知識を使う問題。

### 問 B1

**BTN オープン、BB コール、フロップ Q♥T♣6♦ (middle=T rainbow)、自ハンド A♣J♣ (IP、TPGK 型)、相手 TAG**。

<details>
<summary>解答</summary>

```
Step 1: 簡易レンジスコア → ハイ×ドライ (max_diff=6、高連続条件 NG) = 85%
Step 2: 精密レンジスコア → middle=T、top=Q、rainbow → Extra E1 (-15) 発動
  → 正しい頻度は 85% − 15% = 70%
Step 3: HS → AJ は BB に対して AJ 勝ち、ただしレンジ上位
Step 4: 9マス → 中頻度×強 → CBet 50% (巻② 75%、精密レンジスコア 調整で 50%)
```

**答え: CBet 50%**（精密レンジスコア補正による減少）

</details>

### 問 B2

**BTN オープン、BB コール、フロップ K♣Q♠T♦ (全 broadway 2-tone? これは rainbow。本問は KQTss と仮定)、自ハンド A♠A♥ (オーバーペア)、IP**。

<details>
<summary>解答</summary>

```
Step 1: 簡易レンジスコア → ハイ×ウェット = 55%、精密レンジスコア → E2 (全 broadway 2-tone) -10 = 45%
Step 2: HS → AA オーバーペア 20、ただしストレート可能 (AK、AJ、JT9 等) で危険
  → 型2c 補正 -5 = 15 (強境界)
Step 3: R5 (チェックレンジ保護): A♠ が ♠ なので CBet 継続 (R5 は ♣♦ ならチェック)
Step 4: 9マス → 中頻度×強 → CBet 50%
```

**答え: CBet 50%**

精密レンジスコア E2で頻度調整、R5適用でCBet継続。

</details>

### 問 B3

**R2 を使った境界判断: K72r で AQo (空振り + BDFD なし)、IP、相手 TAG。自ハンドの高い方のスートは A♣**。

<details>
<summary>解答</summary>

```
簡易レンジスコア → 85% (高頻度)
HS → 空振り 0、BDFD なし = 0 (弱)
R1 → 高頻度×弱 = バンド B (混合)
R3 → レイザー × ハイボード → 1 段階アグレッシブ → バンド A (ベット確定)
R2 → 高い方 A♣ → ♣ だが R3 で確定なので R2 不要

ただし A♣ なら R2 でチェック、A♠♥ なら CBet の混合も可能
R3 が優先で バンド A 確定

→ **CBet 33%**
```

**答え: CBet 33%**（R3優先、ブラフ継続）

</details>

### 問 B4-B15 (概略)

12問の中級問題を省略形で列挙：。

- B4: 精密HandScore、K♠Q♠4♦ でA♠J♦ → HS 20（ナッツFD + ブロッカー）、ベット推奨
- B5: 17型判定、K♣Q♣T♦ → 型2c（全broadway 2-tone）の対応

## 17-3　難易度 C 問題 (上級、15 問)

レンジ推定 + エクスプロイト + メタゲームを統合する問題。

### 問 C1

**相手 (HUD 800 ハンド、VPIP 14%、PFR 12%、AFq 28% = Nit)、BTN オープン → SB 3bet (9BB) → BTN コール (3bet ポット、SPR 4.8)、フロップ K72r、自ハンド A♦Q♦ (空振り、BDFD なし)**。

<details>
<summary>解答</summary>

```
Step 1: プリフロップレンジ推定 (第6章)
  - 相手 SB 3bet レンジ: Nit → 極めて狭い (QQ+/AK、まれに A5s)
  - 約 40 コンボ

Step 2: フロップ K72r での相手レンジ分析 (第5章)
  - セット: KK (3)、77 (3)、22 (3) = 9 コンボ
  - TPTK: AK (12) = 12 コンボ
  - オーバーペア: AA (6)、QQ (6) = 12 コンボ
  - ブラフ A5s: 4 コンボ (ブロック減で 3)
  - 合計 約 36 コンボ

Step 3: 相手の想定アクション
  - 3bet ポットで 相手 (Nit) は 80%+ CBet
  - 3bet ポット + 低 SPR → 大サイズ (75%+)

Step 4: 自分の判断
  - AQ は相手レンジに対して 10% エクイティ以下
  - Nit 相手の 大 CBet = 強バリュー確定
  
→ **フォールド** (CBet に対して)、事前に 3bet コールも見直すべき
```

**答え: フォールド**

巻②なら「AQ TPGKはコール」と考えがち。巻③の精密分析で実はAQは空振りでエクイティ10% 以下と判明。

</details>

<details>
<summary>解答</summary>

```
Step 1: 3bet ポット、SPR 4.8、型4 ロー×ウェット
Step 2: 相手 LAG の 3bet レンジ: ブラフ多い (A5s、K8s 等)
  バリュー 40%、ブラフ 60%
Step 3: 自ハンド AK → ガットショット + オーバーカード、HS 11 (中)
Step 4: 9マス → 低頻度×中 → チェック
Step 5: LAG 補正 → 相手はブラフ継続、チェックコールで ブラフキャッチ

→ **チェックコール** (次のストリートで相手のバレルを迎え撃つ)
```

**答え: チェックコール (LAG のアグレ誘引)**

**状況**: BTNオープン、BBコール、フロップK♠Q♠T♣、自ハンドA♣A♥（オーバーペア、IP）。

<details>
<summary>解答</summary>


## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: ドリル 50 問を一気に解けば最も効果的に学習できる。

**✅ 正解**: 週 10-15 問のペースで解き、間違えた問題を該当章に戻って復習するサイクルが最も定着しやすい。一気に解くと疲労で判断精度が落ち、復習も不十分になる。

**【GTOとのズレ】**

本章のドリル 50 問は、巻③ 全 16 章を統合する実戦演習です。各問の「正解」は本書の枠組み（簡易レンジスコア + 9 マスマトリクス + 精密レンジスコア + R1-R6 + E 補正 + メタゲーム）に基づく推奨アクションであり、ソルバーが出力する GTO 解そのものではありません。問 A1 の CBet 75% も、問 D1 の CBet 75% も、ソルバー上では混合戦略（50% CBet と 50% チェックの併用）が GTO 最適という場合があり、ドリル正解とソルバー解で 5-10% の頻度差が生じます。

ズレが大きく出るのは、混合戦略が密に使われる境界ハンド（難易度 B の問 B1-B3 など）と、相手タイプを織り込んだ難易度 D の問題です。本章の解答は「タイプ別に 1 つの推奨アクションを示す」形式で、ソルバーのように「CBet 33% を 60%、チェックを 40% で混ぜる」という出力にはなりません。ドリル化のトレードオフとして、判断を高速化する代わりに、混合戦略の精密さを 1 段階犠牲にしています。問 D1 で「CBet 75%」と覚えても、実戦では 50% と 75% を 30/70 で混ぜるほうが GTO 的に正解な場面があります。

実戦では、ドリル正解を「初期値」として身につけ、3-5 ハンド先のレビューでソルバーと突き合わせて補正します。正解率 85% を超えたら、混合戦略の頻度を意識した「CBet 75% を 70%、チェックを 30%」という打ち分けに進むのが、ドリル化のトレードオフを乗り越える次のステップです。
