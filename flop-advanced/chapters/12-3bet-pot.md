# 第12章　3-bet ポットのフロップ戦略

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 3-bet ポットでは SPR が約 5 に下がり、通常の SRP とはまったく異なる判断が求められます。3-bettor がレンジ全体で小サイズベットを打ち続ける理由と、コール側がどこでコミットするかを、SPR の数値から逆算して理解できるようになりましょう。なお BTN vs BB（BB が 3-bet）では 3-bettor の BB が OOP になります。ポジションは状況によって変わる点に注意してください。

---

## 12-1　3-bet ポットは「別ゲーム」

通常の SRP（シングルレイズポット）は、BTN が 2.5bb でオープンして BB がコールすると pot = 5.5〜6bb、スタック約 97bb、SPR ≈ 16 前後です。

3-bet ポットはここから大きく変わります。

```
BTN open 2.5bb → BB 3-bet to 9bb → BTN call:
  pot  = 9 + 9 + 0.5（SB）≈ 18.5bb
  stack ≈ 91bb
  SPR  ≈ 91 / 18.5 ≈ 4.9
```

SPR が 16 から 5 へと 3 分の 1 以下に下がります。この差がフロップでの判断を根本から変えます。

SRP では「セット以上でオールインを計画」が目安でしたが、3-bet ポットでは TPTK（トップペア・トップキッカー）でさえ 2 ストリートでコミットに近い判断を迫られます。

### SPR とコミット閾値の対応

| 状況 | SPR 目安 | コミット閾値の目安 |
|:---|:---:|:---|
| SRP（通常ポット） | ≈ 16 | セット・2ペア以上 |
| 3-bet ポット | ≈ 5 | TPTK（HS ≥ 65）以上 |
| 4-bet ポット | ≈ 2 | TPTK 以上でオールイン計画 |

3-bet ポットで「コミット」とは、2 ストリートでほぼスタックが消える計算です。

---

## 12-2　3-bettor の range bet 戦略

> **ポジションの注意**: BTN open → BB 3-bet → BTN call の場合、3-bettor（BB）がフロップで OOP（先行動）になります。以下では「3-bettor」を主体として解説しますが、具体的なポジションは状況によります。UTG open → BTN 3-bet → UTG call なら 3-bettor（BTN）が IP です。

3-bet した側のレンジは QQ+、AKs、AQs など強力なプレミアムハンドが多く含まれます。このため、ほぼすべてのボードでレンジ上の優位を保ちます。

GTO の実測（GTO Wizard 参照）では、3-bet ポットでの CBet 頻度は高く、dry rainbow（K♣7♦2♠）で約 87%、wet 2-tone（J♣T♦5♣）でも約 76% です。

3-bettor に有効な戦略は「range bet（レンジベット）」です。バリューかブラフかを細かく分けずに、全ハンドでほぼ均一に小サイズ（33%）のベットを打ち続けます。

### range bet が有効な理由

1. **レンジ優位が全ボードで継続**: IP のプレミアムレンジはどのボードでもエクイティが高い。
2. **OOP の対応を難しくする**: ブラフとバリューが分離していないため、OOP はフォールドの根拠を見つけにくい。
3. **SPR = 5 での小サイズは効率的**: 33% ベットでも 2 ストリートでスタックが尽きる設計になる。

```
SPR ≈ 5 での 33% CBet 後の SPR 推移:
  フロップ pot=18.5bb、33% CBet = 6.2bb
  OOP コール後: pot ≈ 31bb、stack ≈ 85bb → SPR ≈ 2.7
  ターン 33% CBet = 10.2bb
  OOP コール後: pot ≈ 51bb、stack ≈ 75bb → SPR ≈ 1.5
  → リバーでほぼコミット
```

33% の range bet を 2 ストリート継続するだけで、リバーでは残りスタックがポット以下になります。

---

## 12-3　CBet サイズ選択：3-bet ポットでは小サイズが主流

SRP では 75% のベットサイズを多用することがありますが、3-bet ポットでは様相が変わります。

### 3-bet ポットでのサイズ選択

| ボードテクスチャ | 推奨サイズ | 理由 |
|:---|:---:|:---|
| Dry rainbow（K♣7♦2♠） | 33% | range bet、全ハンド均一 |
| 2-tone（J♣T♦5♣） | 33〜50% | ドローにチャージしつつ range bet |
| Monotone（9♠7♠4♠） | 50% | フラッシュドローへの圧力 |

SRP では 75% を使う場面でも、3-bet ポットでは 33〜50% が中心になります。理由は 2 つあります。

第一に、すでにポットが大きいため小サイズでもポットオッズ的に OOP に圧力をかけられます。第二に、大サイズを打つとターンでコミットが早く来すぎてレンジが読まれやすくなります。

### T3 ブラフの条件緩和

SRP では T3 ブラフは B ≥ 62（A/K-high rainbow）のドライボードのみ有効でした。3-bet ポット（SPR ≈ 5）では**この条件が B ≥ 55 程度に緩和**されます。

理由は SPR の低下による「フォールドエクイティの増大」です。OOP（コール側）は SPR=5 の状況で多くのハンドがコミット計画を立てにくく、ウェットな 2tone ボードでも強い手がなければフォールドしやすくなります。33% ブラフ時の損益分岐フォールド率は約 25% であり、3-bet ポットでは BB がこの閾値を超えてフォールドするボードが増えます。

| ブラフ T3 条件 | SRP（B≥62） | 3-bet pot（B≥55） |
|:---|:---:|:---:|
| Dry rainbow A/K-high（B=62） | ✓ | ✓ |
| Rainbow Q-high（B=58） | ✗ | ✓ |
| Rainbow（B=55） | ✗ | ✓（境界） |
| 2-tone（B=50） | ✗ | ✗ |

---

## 12-4　コール側の守備計画

3-bet をコールした OOP のレンジも決して弱くはありません。TT〜QQ、AQs、AJs+、KQs などのスペキュラティブハンドが含まれ、ボードによっては OOP がレンジ優位を持つこともあります。

### ボード別 OOP の立場

- **A-high ボード（A♣7♦2♠）**: IP の AK/AQ が当たる一方、OOP も AQ/AJs をコールしていることがある。両者の AK/AQ が拮抗する状況。
- **K-high dry ボード（K♣7♦2♠）**: IP の KK/KQ が有利。OOP はポットオッズを考慮してコールを広めに設計。
- **Low ボード（7♣4♦2♠）**: IP のレンジは A/K ハイが多く、ボードにヒットしにくい。OOP のポケットペア（55〜TT）が有利に機能する。

### SPR = 5 での OOP コール基準

```
SPR 3-5 のコール閾値:
  コール: HS ≥ 20（後手スコアの目安）
  CR:    HS ≥ 60（SPR 3-5 の場合、CR 閾値が上がる）
  フォールド: HS < 20
```

> **CR 閾値が上がる理由**: SPR ≈ 5 では、CR（3× ベット）した後の残り SPR が 1〜2 となりほぼ自動的にオールインが続きます。つまり CR = コミット決断に等しいため、SRP（SPR ≥ 6）の CR 閾値 HS ≥ 40 より高い HS ≥ 60 が必要です。SPR が低いほど「CR するとオールインを断れない」状況が早く来るため、CR 閾値は SPR に反比例して上がります。

SPR = 5 では、TPTK（HS ≈ 65）以上がバリューでコールする基準です。TPWK（HS ≈ 45 程度）はポットオッズ次第のコール候補ですが、ターンでコミットできるかを事前に見極めてから判断します。

## 12-5　コミットラインの把握

3-bet ポットで最も重要な概念が「コミットライン」です。ある時点でコールすると、ターン・リバーでオールインを断れない状況になることを指します。

### 2 ストリートでコミットする計算

```
フロップ 50% CBet コール後の SPR 推移:
  フロップ pot=18.5bb、50% CBet = 9.3bb
  OOP コール後: pot ≈ 37bb、stack ≈ 82bb → SPR ≈ 2.2

SPR < 3 → ターンでほぼオールインが発生
TPTK（HS≥65）でコールした時点で「ターンでオールイン」の覚悟が必要
```

具体例で確認しましょう。

> **例：AA on K♣7♦2♠（dry rainbow）、3-bet ポット**
>
> pot = 18.5bb、IP が 33%（6.2bb）CBet
> HS = AA（オーバーペア）≈ 80（T1）
> SPR ≈ 5、SPR 3-5 の CR 閾値 = 60
> HS=80 ≥ 60 → CR も検討できるが、コールでターンでの大きなベットへの対応を計画するのも有力。
>
> **例：TT on A♣7♦2♠（dry rainbow）、3-bet ポット**
>
> pot = 18.5bb、IP が 33%（6.2bb）CBet
> HS = TT（アンダーペア）≈ 40〜45（セカンドペア相当の強さだが、セットに改善する潜在的なエクイティを持つ）
> SPR ≈ 5、コール閾値 = 20
> HS=40 ≥ 20 → コール候補だが、ターンで Aヒット後のバレルに耐えられるか再考が必要。

セット（HS ≈ 85 以上）はフロップでの CR が最も有効で、ポット全体を最大化します。SPR = 5 ではセットが「フロップで CR してターンでオールイン」という 2 ストリート計画が成立します。

---

## 12-6　3-bet ポットのサマリー

Vol2（巻②）で学んだ 9 マスマトリクスの判断軸はそのまま使えますが、3-bet ポットでは次の 3 点を常に意識してください。

1. **IP は range bet（33%）が基本**: プレミアムレンジでほぼ全ハンドでベット。
2. **コミットラインを早めに計算**: フロップコールの時点でターンのオールイン計画を立てる。
3. **OOP の CR 閾値は高め（HS ≥ 60）**: SPR = 5 では浅いハンドでの CR は危険。

```
3-bet ポット フロップ判断フロー（IP）:
  SPR ≈ 5 を確認
  → ほぼ全ボードで 33% range bet を検討
  → 2-tone / monotone → 33〜50%
  → T1/T2 問わず打ち続ける（OOP の対応を読んでから調整）

3-bet ポット フロップ判断フロー（OOP）:
  SPR ≈ 5 を確認
  → HS ≥ 20 → コール計画（ターンでの継続を確認）
  → HS ≥ 60 → CR を検討
  → セット（HS ≥ 85）→ フロップ CR で 2 ストリート計画
  → HS < 20 → フォールド
```

## ミニクイズ

### 問1

BTN が 2.5bb オープン → BB が 9bb 3-bet → BTN コールで 3-bet ポットが成立しました。
フロップ時の pot と SPR の組み合わせとして最も近いものはどれですか？（SB の 0.5bb を含む）

1. pot ≈ 12bb、SPR ≈ 8
2. pot ≈ 18.5bb、SPR ≈ 5
3. pot ≈ 27bb、SPR ≈ 3

### 問2

3-bet ポット（SPR ≈ 5）で IP が dry rainbow ボードに 33% CBet を打つ主な理由はどれですか？

1. ブラフしか含まれていないため、小サイズで損失を抑える
2. プレミアムレンジで range bet を打ち、OOP の対応を難しくするため
3. 相手のレンジが弱いため、どのサイズでもフォールドを取れるから

### 問3

3-bet ポット（pot=18.5bb、SPR≈5）で OOP が TPTK（HS≈65）を持っています。
IP の 33% CBet（約 6.2bb）に対してコールした場合、ターンの pot と SPR はおよそいくつになりますか？

1. pot ≈ 20bb、SPR ≈ 4.5
2. pot ≈ 31bb、SPR ≈ 2.7
3. pot ≈ 45bb、SPR ≈ 1.3

---

### 解答

- **問1**: **2. pot ≈ 18.5bb、SPR ≈ 5** が正解。BTN の 9bb + BB の 9bb + SB の 0.5bb = 18.5bb。スタック ≈ 91bb。SPR = 91 ÷ 18.5 ≈ 4.9。
- **問2**: **2. プレミアムレンジで range bet を打ち、OOP の対応を難しくするため** が正解。IP は QQ+/AKs 等のプレミアムレンジを持つため、バリュー・ブラフを区別せず全ハンドで打つことで OOP の対応コストを最大化できます。
- **問3**: **2. pot ≈ 31bb、SPR ≈ 2.7** が正解。フロップ pot 18.5bb + CBet 6.2bb + OOP コール 6.2bb = 約 31bb。スタック ≈ 85bb。SPR = 85 ÷ 31 ≈ 2.7。

---

> **本章まとめ**
>
> - 3-bet ポットは pot ≈ 18.5bb、SPR ≈ 5 と SRP の 3 分の 1 以下のスタック比になる。
> - 3-bettor はプレミアムレンジを活かして 33% の range bet が基本戦略（BTN vs BB では 3-bettor の BB が OOP）。
> - CBet サイズは SRP より小さく、dry rainbow で 33%、2-tone で 33〜50% が主流。
> - OOP のコール基準は HS ≥ 20、CR 閾値は SPR = 5 では HS ≥ 60 に上昇。
> - フロップコールの時点でターンのコミット計画を立てることが必須。

---

**【GTO とのズレ】**

本章で示した「33% range bet」は GTO 均衡に近い戦略ですが、実際には IP がわずかに判断を分けることもあります。dry rainbow での IP CBet 頻度は GTO 実測で約 87% であり、100% ではありません。OOP 側も A-high ボードや low ボードではレンジ優位が逆転することがあり、donk bet が成立する場合があります。これらの細部は巻④（ターン・リバー編）で扱います。
