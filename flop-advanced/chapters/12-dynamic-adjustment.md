> 「相手は止まっているわけではない。3-4 ハンドごとに戦略を変える。こちらも止まれない」

---

## 読者ペルソナ別の読み方

- **A (中級ステップアップ組)**: 3-4 ハンド単位の変化に気づいたら、まず観察を続けるだけでよい。動かないことも選択肢のひとつ。
- **B (ソルバー派)**: 12-4 節のカウンターアジャストのレベル思考を把握し、レベル 4 以上による自滅を避ける。
- **C (ライブベテラン)**: 数ハンドの観察で相手の変化を察知する。HUD なしでも 12-1 節の 5 ステップが使える。

## 巻② からのブリッジ

巻② 第17章では相手タイプを**静的**に扱いました。第11章で4タイプ × 8例の搾取を学びました。本章では、**相手が戦略を変える**状況で、自分も戦略をリアルタイムで変える動的プロセスを扱います。

## 12-1　観察 5 ステップ

相手の変化を察知するには、**毎ハンド 5 秒の観察**を習慣化します。

### Step 1: プリフロップのアクション

```
VPIP の変化: いつもより参加率が高い? 低い?
サイズ: オープンサイズが変わった?
ポジション: どのポジションでどう動いたか
```

### Step 2: フロップの CBet 選択

```
CBet したか? サイズは? タイミングは?
先ほどのハンドと比べてパターンが変わったか?
```

### Step 3: 相手のベットへの反応

```
フォールド頻度が変わった?
コール比率が増えた?
チェックレイズが出た?
```

### Step 4: ショーダウンの内容

```
勝ったハンド: 何で勝った? (V/B 比の推定)
負けたハンド: どの程度まで追いかけたか
```

### Step 5: 相手の表情・発言 (ライブのみ)

```
勝った後: 悔しがる? 喜ぶ? (Tilt 予兆)
負けた後: 愚痴? 黙る? 激昂?
```

### 観察結果の統合

5つのステップを5ハンド分集めると、相手の**今のモード**が見える。

---

## 12-2　タイプ変化の典型パターン

プレイヤーは3つの方向に変化しがち：

### 変化 A: Tilt (連敗、負けの直後)

```
症状:
  - VPIP/PFR 急上昇 (+5-15%)
  - 大きいベット、オーバーベット急増
  - フォールド激減

→ LAG 寄りに変化 (E +0.5 〜 +1.5)
```

### 変化 B: 保守化 (勝った後、時間が経過)

```
症状:
  - VPIP 低下
  - CBet 頻度低下
  - タイトなコール

→ Nit 寄りに変化 (E -0.5 〜 -1.0)
```

### 変化 C: 疲労 (長時間プレイ、終盤)

```
症状:
  - パッシブ化 (コール増、レイズ減)
  - CBet 頻度は変わらないがサイズが小さくなる
  - 損切りが早くなる

→ Fish 寄り (ただし パッシブ、E -0.3 程度)
```

### 変化は 5-10 ハンドで顕在化

上記3パターンは瞬時には起きない。5-10ハンドで「あれ、変わった？」と気づくレベル。

---

## 12-3　3-4 ハンド単位の戦略変更

自分の戦略は **3-4 ハンド単位**で変更します。

### なぜ 3-4 ハンドか

- 1ハンドでの変更： 相手に察知されやすい、自分のパターンが崩れる
- 10ハンド以上： 相手がさらに変わっている可能性、遅い

3-4ハンドが「**変化を織り込む + 相手に察知されない**」のバランス。

### 戦略変更の具体例

**例: 相手が Tilt を始めた**

```
ハンド 1-3: 相手のアグレ増加を観察
ハンド 4-6: 自分のブラフを削減、相手の CBet/3bet に広くコール
ハンド 7-10: さらに LAG 対応、ブラフキャッチを増やす
ハンド 11+: 相手が落ち着いたら元に戻す
```

**例: 相手が保守化**

```
ハンド 1-3: 相手の参加率低下を観察
ハンド 4-6: 自分の CBet ブラフを増やす (Nit 相手の戦略)
ハンド 7-10: 3bet ブラフも追加
```

---

## 12-4　カウンターアジャスト

相手がこちらの調整を察知して、**さらに調整してくる**ことがあります。これを「カウンターアジャスト」と呼びます。

### 相手のカウンターアジャストのサイン

```
自分が「ブラフキャッチを増やした」(LAG 相手) 後:
  相手のサイン: ブラフを減らす、バリューを増やす
  → 相手も「読まれた」と気づいて調整

対応: 自分の調整を逆戻し、バリュー志向に戻る
```

### レベル調整のサイクル

```
レベル 1: 自分のハンド
レベル 2: 相手のハンド
レベル 3: 相手が考える自分のハンド (= 自分が調整した戦略)
レベル 4: 相手の調整を読む (= 相手のカウンターアジャスト)
```

**レベル 4 以上は危険**。双方が読み合いで迷走し、本来の確率判断を失う。巻③ 第13章で詳述するメタゲームの原則。

---

## 12-5　動的調整の 6 ケース

具体的なハンド経過例を6つ示します。

### ケース 1: 相手 Tilt 後の搾取

```
ハンド 1: BTN vs BB、BB が バッドビート (セット vs ストレート)
ハンド 2-3: BB が VPIP 急上昇 (40%+)、1 オーバーベット
ハンド 4: 自分 BTN、AKo → 通常 Raise 2.5x
  BB 3bet 9BB → ブラフ確率 60%+
  4bet で圧力? or コール?

→ **コール** (ブラフキャッチ + ポストで圧力)
ターン以降: BB の CBet アグレを広くコール

結果: BB の 2 ストリート バレル → 自分のコールで勝ち 20BB+
```

### ケース 2: 相手のサイズ変更を察知

```
ハンド 5 まで: 相手 TAG、CBet 33% 中心
ハンド 6: 相手 CBet 75% (サイズ変更)
観察: 相手は 75% を使い始めた = ポーラード化モードに移行?

自分の対応:
  - 相手の 33% には広くコール (慣習通り)
  - 相手の 75% には タイト (ナッツ率増加仮説)
```

### ケース 3: LAG のアグレ疲れ

```
ハンド 1-10: LAG、VPIP 35%、頻繁に 3bet
ハンド 11-15: LAG が負けが込む → 参加率 20% に低下

観察: LAG が **保守化** している
  → 自分の対応: LAG 対策 (ブラフ減、広くコール) を停止
  → Nit 対策に移行 (ブラフ増、相手のベットは フォールド)
```

### ケース 4: ショーダウンからの情報

```
ハンド N: 相手が 33% CBet → ターン 50% → リバー 75% → ショーダウン A♠5♠ (ブラフ)
  → 相手はトリプルバレルブラフを撃つ LAG タイプと判明

ハンド N+3: 同じ相手が同じサイズ系列でベット
  → 自分のハンドが TPGK 以上なら トリプルバレルでもコールダウン
```

### ケース 5: 「5 回目の同じパターン」

```
相手が 「K72r で CBet 33% → ターン チェック」を 4 回繰り返した
5 回目、同じボードで同じ系列

観察: 相手はこのパターンで 弱い (2 nd ストリートに行けない)
  → 自分は弱いハンドでも ドンクベット (ターン) で押す
  → 相手はチェックしてるので、ドンクにフォールドしがち
```

### ケース 6: メタゲーム (逆調整)

```
長い対戦で、自分が 「タイトイメージ」を構築 (勝てるハンドしか見せない)
相手がこのイメージを認知し、ブラフを減らし始める

自分の対応: タイトイメージを利用
  - ブラフ 3bet を増やす (相手がフォールドする)
  - ブラフ CBet も効果的 (相手がコールしにくい)
```

## 12-6　動的調整の落とし穴

### 落とし穴 1: 過剰反応

1-2ハンドの変化で戦略変更は早すぎる。5ハンド以上の統計的有意を待つ。

### 落とし穴 2: 自分の調整が崩れる

相手に合わせて調整しすぎると、**自分のベースライン**（GTOに近い戦略）が乱れる。調整は「微調整」に留める。

### 落とし穴 3: レベル 4 以上の迷走

```
自分: 相手がこう思ってる (Lv 3)
相手: 自分がそう思っていると相手が考えている (Lv 4)
自分: それを相手が知っていると... (Lv 5)
```

無限にループすると混乱し、単純な確率判断に戻せなくなる。**レベル 3 まで**に限定するのが鉄則。

### 落とし穴 4: 疲労による判断低下

長時間の動的調整は頭を使う。**1 時間ごとに 5 分休憩**してリセット。

---

## 12-7　動的調整の 3 原則

実戦での鉄則：

### 原則 1: 変化の証拠は 3 ハンド以上

```
1 ハンドの異常: 偶然の可能性
2 ハンドの変化: パターンかも
3 ハンド以上: 戦略変更候補
5 ハンド以上: 確実な変化、戦略変更
```

### 原則 2: 調整は小さく、広く

```
小さく: 5-10% の頻度調整、サイズ 1 段階変更
広く: 複数のスポット (CBet 頻度 + ディフェンス 後手下限 + チェックレイズ) で調整
```

### 原則 3: 変化を見失ったら リセット

```
「今の相手がどのタイプか わからなくなった」
→ 即 GTO (9 マスマトリクス) に戻る
→ 観察をやり直す
```

## 12-8　実戦統合フロー

動的調整を含めた1ハンドのフロー:

```
Step 1: プリフロップ、相手のアクションを観察 (過去 5 ハンドと比較)
Step 2: 変化があれば タイプを再評価、E を更新
Step 3: フロップ、巻② の 9 マスマトリクス で基本アクション
Step 4: E 補正 (第10章) でサイズ/頻度を調整
Step 5: 動的変化があれば Step 4 をさらに微調整
Step 6: アクション実行、相手の反応を観察 (Step 1 に戻る)
```

### 具体例: 30 分間のセッション

```
ハンド 1-10: 相手を観察、TAG と判定、標準戦略
ハンド 11-15: 相手のバッドビート後、アグレ増加を察知
ハンド 16-20: LAG 対応 (ブラフキャッチ増) に移行
ハンド 21-25: 相手が落ち着く、標準に戻す
ハンド 26-30: 新しい情報 (相手が 50% ベット頻用) → 新しいモデルを構築
```

## 🎴 ライブポーカーでの代用法

HUD が使えないライブでも、本章の動的調整は **より強力に機能**します (HUD がない分、対面の観察情報が集中するため)。

### ライブ特有の観察ポイント

オンラインの HUD 統計に代わる、ライブで取れる情報:

```
1. 相手が手を見た直後の表情変化 (1 秒以内)
2. チップスタックの整え方 (強いハンドほど丁寧)
3. 視線 (ポット凝視 / 相手凝視 / 遠い目)
4. 呼吸の深さ (深い = 落ち着きを装う = 強い)
5. ベットタイミング (即 / 考えた後)
```

### ライブ版の動的変化察知

```
相手が Tilt を始めるサイン:
  - 口数が増える (怒り・不満)
  - チップ操作が荒くなる
  - サイズが普段より大きくなる
  → 数ハンドで LAG 化、巻③ 第11章 の LAG 対応へ

相手が疲労・保守化するサイン:
  - 会話が減る
  - フォールドスピードが速くなる
  - CBet を省略する
  → Nit 化、ブラフ増やす
```

### ライブ 3 原則 (HUD なし版)

1. **バックグラウンド観察** — 自分が参加していないハンドもショーダウンまで追う
2. **3 ハンド単位の変化察知** — HUD なら数値、ライブなら行動パターン
3. **物理的な「変化」に敏感** — 姿勢変化、飲み物のタイミング等も情報

オンラインより察知しやすいが、**相手からも自分が観察されている**ことを忘れない。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: 相手の変化を察知したらすぐに戦略を変えるべきだ。

**✅ 正解**: 3 ハンド以上の証拠を待つ必要がある。1-2 ハンドの変化は偶然の範囲であり、早まった変更は自分の戦略を不必要に崩すことになる。

## 章のまとめ

- 相手は3-4ハンド単位で戦略を変える、自分も動的対応
- 変化の3パターン： Tilt（LAG化）、保守化（Nit化）、疲労（Fish化）
- 観察5ステップで変化を察知
- 調整は3ハンドの証拠、5-10% の微調整
- カウンターアジャスト（相手の再調整）はレベル3までに留める
- 迷ったらGTO（9マスマトリクス）にリセット

次章（第13章メタゲーム）では、読みの読みの読みを扱い、長期対戦でのダイナミクスを学びます。

## ミニクイズ

### 問 1

**相手が 10 ハンドで VPIP 25%、PFR 20% (TAG)。ハンド 11 でバッドビート、ハンド 12-15 で VPIP 40%、3bet を 2 連発**。どう判断？

<details>
<summary>解答</summary>

```
変化の兆候: 4 ハンドで VPIP 40%、通常の TAG から大きくずれる
→ Tilt (LAG 化) の可能性高い

戦略変更:
  - ブラフキャッチ増やす (AQ, KJ 等のコールを緩める)
  - 自分のブラフを減らす
  - 3bet コール範囲を広げる (QQ, JJ, AK, AQs)
```

**答え: LAG 対応に移行**

</details>

### 問 2

**相手が勝ち続けた後、ハンド 20-25 で CBet 頻度が 65% → 35% に低下**。どう対応？

<details>
<summary>解答</summary>

```
変化: 保守化 (Nit 化)
推測: 勝ちを守りたい心理

戦略変更:
  - Nit 相手のブラフを増やす (33% CBet ブラフ拡大)
  - 相手の CBet (頻度低い) はバリュー確定扱い → タイトフォールド
  - 3bet ブラフ頻度を増やす (相手のコール減)
```

**答え: Nit 対応に移行**

</details>

### 問 3

**自分がブラフを 3 ハンド連発、相手が 2 回目からブラフキャッチでコール**。どうすべき？

<details>
<summary>解答</summary>

```
状況: 相手がこちらの調整 (ブラフ増) を察知、カウンターアジャスト (ブラフキャッチ増)

対応オプション:
  - オプション A: ブラフを減らし、バリュー強化 (相手がコールしてくるのでバリューを厚く)
  - オプション B: レベル 4 に進むか? → 危険、レベル 3 に留める

最善: オプション A、ブラフを減らしてバリューを取る
  → 相手の「ブラフ多い」イメージを維持しつつ、バリューで搾取
```

**答え: ブラフを減らしてバリュー強化**

レベル4の迷走を避け、レベル3（相手が自分をLAGと思っている）を利用してバリューを取る。

</details>

**【GTOとのズレ】**

本章の動的調整は「相手が GTO から外れて変化している」という前提に立ちます。GTO そのものは静的な均衡解であり、相手の変化に追随する仕組みを持ちません。つまり本章の 3-4 ハンド単位の戦略変更は、純粋な GTO とは別軸の搾取アプローチであり、相手がレベル 3 以上の思考者だと「自分の動的調整がカウンターアジャストされる」リスクを伴います。

ズレが大きいのは、Tilt 検出と保守化検出の境界です。本章では「3 ハンド以上の証拠で戦略変更」と推奨していますが、GTO 派の相手は意図的にサイズや頻度を揺らして「擬似 Tilt」を演出することがあり、本章の 5 ステップ観察では誤検知が発生します。実際、4-5 ハンドの VPIP 急上昇を Tilt と誤読して LAG 対応に移行した結果、相手のバリューレンジに撃ち込まれる事故は珍しくありません。

実戦では、動的調整を「Fish と中級者まで」に限定し、上級者には GTO ベースライン（簡易レンジスコア + 9 マスマトリクス）を維持するのが安全です。迷ったら GTO にリセットするという原則 3 は、レベル 4 以上の迷走を避けるための最重要ルールであり、動的調整の限界を認める本章の核心でもあります。
