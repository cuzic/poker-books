## 巻② からのブリッジ

第10-14章で搾取戦略とメタゲームを学びました。これらはGTOから**意図的に外れる**戦略です。本章では「いつGTOから外れるべきか」「いつGTOに戻るべきか」の基準を明確にします。

---

## 15-1　GTO とエクスプロイトの役割

### GTO の役割

```
GTO = 「相手が何をしても、自分の EV が最大化される均衡戦略」

特徴:
  - 守備的 (搾取されない)
  - 相手タイプを問わない
  - 均衡に到達するまでに計算量が膨大
```

### エクスプロイト (搾取) の役割

```
エクスプロイト = 「相手の特定の弱点を攻める戦略」

特徴:
  - 攻撃的 (最大 EV を狙う)
  - 相手タイプ依存
  - 自分が搾取される可能性あり (相手が調整してくると)
```

### 2 つの戦略の役割分担

```
「相手が GTO に近い → 自分も GTO (守備優先)」
「相手が GTO から外れている → 自分はエクスプロイト (攻撃優先)」
```

この原則が第III部（搾取戦略）の根底にあります。

---

## 15-2　GTO から外れる 5 条件

エクスプロイトを発動する判断基準：

### 条件 1: 相手の弱点が明確

```
相手の HUD 統計から特定の弱点が見える:
  - Fold vs CBet 75% (過剰フォールド) → CBet ブラフ増
  - AFq 25% (パッシブ) → ブラフキャッチ封印、バリュー厚
  - VPIP 48% (Fish) → ブラフ封印
```

### 条件 2: 相手のサンプルが十分

```
500 ハンド以上: 統計が収束、エクスプロイト可能
200-500: 主要 3 指標のみ信頼、軽いエクスプロイト
< 200: 不十分、GTO 推奨
```

### 条件 3: 相手の調整能力が低い

```
レベル 0-1 (Fish、Nit): 固定戦略、エクスプロイト効果大
レベル 2 (TAG): 時々調整、慎重なエクスプロイト
レベル 3+ (上級): カウンターアジャスト可能、エクスプロイト危険
```

### 条件 4: EV の期待値が明確

```
エクスプロイトで想定 EV が +1 BB/100 以上 → 実行
想定 EV が 0.5 BB/100 以下 → GTO 継続 (リスク見合わない)
```

### 条件 5: 自分が調整を続けられる

```
相手が調整してきた場合、自分も再調整できるか?
Yes → エクスプロイト実行
No (疲労、複雑すぎる) → GTO 継続
```

---

## 15-3　GTO に戻る 5 条件

エクスプロイトを**止める**基準：

### 条件 1: 相手が変化した

```
相手の HUD 統計や戦略が変わった
→ 過去のエクスプロイトは無効
→ 観察期間 (5-10 ハンド) の間は GTO
```

### 条件 2: 自分のエクスプロイトがキャッチされた

```
相手が自分の調整を見抜いた
→ さらに調整するとレベル 4+ 迷走
→ GTO に戻り、相手も落ち着くのを待つ
```

### 条件 3: 相手の EV 補正が不正確と判明

```
「Nit と思っていたが、実は TAG」「LAG と思っていたが、実は Tilt 中」
→ タイプ推定が誤り、エクスプロイト無効
→ GTO 基準に戻し、再観察
```

### 条件 4: 予期しない状況

```
マルチウェイ、3bet ポット、オールイン状況など、想定外のシナリオ
→ GTO + 保守的判断
```

### 条件 5: 疲労・集中力低下

```
長時間プレイ、勝ちすぎ/負けすぎで判断が歪む
→ エクスプロイトは高度な判断、GTO に戻って単純化
```

---

## 15-4　「搾取しすぎ」の危険

エクスプロイトを過度に行うと、**逆に搾取される**。

### 搾取しすぎのサイン

```
1. 特定の相手に対してブラフ頻度 80%+ → 相手が気づいてコールダウン
2. Fish 相手にバリュー薄く打ち続ける → 相手が突然レイズ (実は強いハンド)
3. メタゲームで 自分のイメージを変化させすぎ → 読まれる
```

### 搾取しすぎの検知

```
相手の反応を 5 ハンド観察:
  - 自分のブラフが キャッチされ始めた
  - 相手のコール率が 明らかに上がった
  - ショーダウンで相手のレンジが変わっている
→ 搾取しすぎ、GTO に戻る
```

---

## 15-5　GTO と エクスプロイトの境界判断

### 判断ツリー

```
Step 1: 相手のサンプル 500+ ハンドか?
  No → GTO
  Yes → Step 2

Step 2: 相手の HUD 統計に明確な偏りか?
  No → GTO
  Yes → Step 3

Step 3: 相手のレベルは 1-2 か?
  3+ → エクスプロイトは慎重に、レベル 3 まで
  0-2 → エクスプロイト可能

Step 4: EV +1 BB/100 以上の見込みか?
  No → GTO
  Yes → エクスプロイト実行
```

---

## 15-6　GTO から外れる頻度

ハンドあたりのGTO / エクスプロイト比率の目安：

| 相手レベル | GTO | エクスプロイト |
|:---:|:---:|:---:|
| レベル 0 (Fish) | 20% | 80% |
| レベル 1 (初級) | 30% | 70% |
| レベル 2 (TAG) | 60% | 40% |
| レベル 3 (上級) | 80% | 20% |
| レベル 4+ (プロ) | 95% | 5% |

**低レベル相手ほどエクスプロイト**、**高レベル相手ほど GTO**。

---

## 15-7　実戦での統合プロセス

1ハンドの判断プロセス：

```
Step 1: 巻② の 9 マスマトリクスで 基本アクションを決定
  → これが GTO 近似 (均衡戦略)

Step 2: 相手のタイプ判定 (第10章 E 補正)
  → エクスプロイトの余地を評価

Step 3: E 補正をアクション/サイズに適用
  → 基本アクション +/- 5-15%

Step 4: メタゲーム要素を検討 (第13章)
  → 相手のイメージ、自分のイメージ、レベル調整

Step 5: タイミングテル等で微調整 (第14章)
  → 相手のベットタイミングから レンジを絞る

Step 6: 最終アクション実行

Step 7: 相手の反応を観察 → 次のハンドへ
```

### 各 Step の時間配分 (実戦 30 秒)

```
Step 1 (簡易レンジスコア + 9マス): 5 秒
Step 2 (E 補正確認): 3 秒
Step 3 (調整): 3 秒
Step 4 (メタゲーム): 5 秒
Step 5 (テル): 4 秒
Step 6 (実行): 2 秒
Step 7 (観察): 次のハンドへ
合計: 22 秒 + ゆとり 8 秒
```

## 15-8　「GTO 使うのはズルいか」への回答

ポーカーコミュニティには時々「GTOはつまらない」「エクスプロイトこそ真のポーカー」という意見があります。

### 両方必要な理由

```
GTO なしでエクスプロイト: 相手のカウンターアジャストで搾取される
エクスプロイトなしで GTO: 相手の明白な弱点を逃す、EV 不足

両方持っていることが「上級者」の条件
```

### GTO は「座標系」

GTOは絶対的な判断ではなく、「どこから自分が逸脱しているか」の座標系。エクスプロイトはGTO座標からの偏差。

## 15-9　初心者がよくやる誤り

### 誤り 1: GTO を覚える前にエクスプロイトを試す

```
「Nit 相手にブラフ増」を学んだ初心者:
  → 相手が実は TAG だった → ブラフキャッチされて負け
  → GTO を知らないので、正しい位置に戻れない
```

**対策**: 巻②のGTO基礎を完全習得してから巻③のエクスプロイトへ。

### 誤り 2: 相手を一度タイプ分類したまま変えない

```
「相手は 50 ハンドで Nit と判定」→ その後 500 ハンド Nit のまま扱う
相手が Tilt で LAG 化しても気づかない
→ ブラフ連発で 全部キャッチされる
```

**対策**: 10ハンドごとに相手のタイプを再評価（第12章の動的調整）。

### 誤り 3: メタゲームのレベル 4+ 迷走

```
「相手は自分がブラフしてると思っているから、自分はあえてチェック...」
→ 相手は 何も考えていない → 自分のチェックでバリュー損失
```

**対策**: レベル3まで、サンプル30+ で発動。

### 誤り 4: テルだけで判断

```
「相手が長考した = ブラフだ」→ フォールドする代わりに コール
→ 実は 難しいバリュー判断 (中強度) でタンク、コール損失
```

**対策**: テルは補助情報、サイズ + 履歴 + HUDと組み合わせて使う。

## 15-10　章のまとめ

- GTOは守備、エクスプロイトは攻撃、両方必要
- GTOから外れる5条件： 弱点明確 / サンプル十分 / 調整能力低 / EV期待値明確 / 自分の調整力
- GTOに戻る5条件： 相手の変化 / キャッチ / 推定誤り / 予期外状況 / 疲労
- レベル別のGTO/エクスプロイト比率： Fish 20/80、TAG 60/40、プロ95/5
- 実戦30秒で7ステップ判断
- 初心者の誤り： GTO未完成でエクスプロイト、固定分類、レベル4+ 迷走、テルだけ依存

次章（第16章ハンドレビューの手順）では、自分のプレイを標準化された手順で改善する方法を学びます。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: GTO は完璧な戦略だから常に GTO で打てばよい。

**✅ 正解**: GTO は防御均衡であり、搾取から守る戦略。相手が GTO から外れているときにエクスプロイトしないと EV を取りこぼす。相手のレベルと統計に応じて GTO とエクスプロイトを使い分けることが最大利益につながる。

## ミニクイズ

### 問 1

**相手 (HUD 200 ハンド)、VPIP 22%、PFR 18% (TAG 相当)**。エクスプロイト発動かGTO継続か？

<details>
<summary>解答</summary>

```
Step 1: サンプル 500+ か? → 200 で不十分
Step 2: 偏りは? → 22/18 は標準的 (TAG)、大きな偏りなし
Step 3: レベル判定は? → TAG (レベル 2)

判断:
  - サンプル不十分
  - 偏りが小さい
  - レベル 2 で エクスプロイトは慎重

→ **GTO 継続** (巻② の 9 マスマトリクス通り)
```

**答え: GTO 継続**

サンプル不足 + TAGはGTOで対応が最適。

</details>

### 問 2

**相手 (HUD 800 ハンド)、VPIP 48%、PFR 10%、AFq 22% (Fish)**。エクスプロイト戦略は？

<details>
<summary>解答</summary>

```
Step 1-5 全て ✓:
  - サンプル十分
  - 明確な偏り (VPIP 超過、パッシブ)
  - レベル 0-1
  - Fish 搾取で +3-5 BB/100 の EV 期待

エクスプロイト:
  - ブラフ封印 (Fish は降りない)
  - バリュー厚 (サイズ 50% → 75%)
  - 広くバリューベット (TPWK でも打つ)
  - Fish のレイズには敬意 (ほぼナッツ)
```

**答え: フルエクスプロイト (Fish 対応)**

</details>

### 問 3

**5 連続ハンドで自分のブラフがキャッチされた**。どう対応？

<details>
<summary>解答</summary>

```
状況: 搾取しすぎのサイン (相手がカウンターアジャスト)

対応:
  - GTO に戻る (ブラフ頻度を 標準に)
  - 相手の調整を 5-10 ハンド観察
  - 自分のイメージを 再構築 (ルーズ→タイトに)
  - バリューを厚く取る期間 (メタゲーム、第13章)
```

**答え: GTO 復帰、バリュー強化期**

レベル3までのメタゲームとして、ルーズイメージを利用してバリューを取る。

</details>

**【GTOとのズレ】**

本章は「GTO とエクスプロイトを使い分ける」枠組みそのものを扱いました。本章の前提として、GTO はソルバーが出力する均衡解を指しますが、実戦のソルバーは「相手のレンジが GTO 通り」「サイズツリーが固定」「マルチウェイなし」という強い仮定の上で動いています。レベル別 GTO/エクスプロイト比率（Fish 20/80、TAG 60/40、プロ 95/5）も、実測ではなく経験則の目安であり、ソルバーが直接出力する数値ではありません。

ズレが大きく出るのは、相手のサンプル 200-500 ハンドの「中間帯」と、3bet ポット・マルチウェイ・低 SPR などソルバーのカバー外の状況です。本章 Step 4 の「EV +1 BB/100 以上で実行」という基準も、ソルバーが直接示す値ではなく、過去のハンドデータから逆算した推定です。サンプル 300 ハンドで Nit 判定した相手が実は LAG だった場合、エクスプロイトの EV 推定は +1 BB のつもりが -2 BB になります。Step 1-7 の 30 秒判断も、複雑なスポット（4bet ポット、マルチウェイ）では時間が足りません。

実戦では、本章の比率表と判断ツリーを「初期値」として使い、相手の反応 5 ハンドごとに比率を再調整します。迷ったら GTO に戻る原則を徹底し、エクスプロイトは「明確な弱点 + サンプル 500+ + EV +1 BB 以上の見込み」が揃ったときだけ発動するのが、本章の枠組みを安全に運用するコツです。
