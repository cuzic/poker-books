## 巻②・巻③前半からのブリッジ

巻②ではSRP（シングルレイズポット、SPR≈9）のCBet戦略を学びました。第3章では3-betポット（SPR≈4.9）への拡張として、TPTK（HS≥65）でのコミット計画を扱いました。本章は4-betポット（SPR≈1.77）へのさらなる拡張です。

SPRが下がるほど「コミットに必要なハンド強度」も下がります。SRPでは「セット以上でオールイン」が目安でしたが、3-betポットでは「TPTK以上でコミット計画」、そして4-betポットでは「TPTK以上でフロップオールイン」が正当化されます。この感覚の違いを本章で完全に整理します。

## 15-1　4-betポットは「別ゲーム」：SPRの違いがすべてを変える

### SPR三段階の比較

まず、ポットタイプごとのSPRを確認します。

```
SRP  (シングルレイズ): SPR ≈ 9   → コミット目安: セット以上
3bet pot:            SPR ≈ 4.9  → コミット目安: TPTK以上でバリュー計画
4bet pot:            SPR ≈ 1.77 → コミット目安: TPTK以上でオールイン計画
```

SPRが半分以下になるたびに、「コミットしてよいハンド強度」が大きく下がります。4-betポットでは、トップペアが「オールインを正当化する手」になります。

### 標準的な4-betポットのSPR計算

6-max、100BBスタートのBTN vs BBを例に取ります。

```
BTN open 2.5bb → BB 3-bet 9bb → BTN 4-bet 22bb → BB call:
  pot  = 22 + 22 = 44bb  (SBのアンティは簡略計算で無視)
  stack = 100 - 22 = 78bb
  SPR  = 78 / 44 ≈ 1.77
```

4-betサイズが変わるとSPRも変動します。

| 4-betサイズ | pot | stack | SPR |
|:-----------:|:---:|:-----:|:---:|
| 18bb | 36bb | 82bb | ≈ 2.3 |
| 22bb | 44bb | 78bb | ≈ 1.77 |
| 28bb | 56bb | 72bb | ≈ 1.29 |

現代の6-maxでは22bb前後の4-betが標準的なため、フロップSPR≈1.77を基準として話を進めます。

### フロップ1ストリートでSPRはどう変わるか

SPR≈1.77の状態でフロップ33% CBetが起きてOOPがコールすると、スタックとポットがどう動くか見てみます。

```
フロップ 33% CBet = 44bb × 33% ≈ 14.5bb（約15bb）

コール後:
  pot   = 44bb + 15bb + 15bb = 74bb
  stack = 78bb - 15bb = 63bb
  SPR   = 63 / 74 ≈ 0.85
```

SPR≈0.85はスタックがポットを下回っている状態です。ターンはもはやポットサイズのベットすら「オールイン」に近く、**push/foldの2択しか残りません**。これが4-betポットを「別ゲーム」と呼ぶ理由です。フロップのアクションを「1ストリート分の情報集め」として使う余裕はほとんどなく、フロップ時点で「コミットするか降りるか」を決断しなければなりません。

## 15-2　IPのrange bet戦略：なぜ全ハンドで打つのか

### 4-bettorのレンジ特性

4-betポットに持ち込んだIP（4-bettor）のレンジはQQ+・AKs・AQs程度に絞り込まれています。これはどのフロップテクスチャが来ても、IPがレンジ全体として強い位置に立つことを意味します。

```
IPレンジ（4-bettor）: QQ+, AKs, AQs 中心
→ K72r: AA/KK/QQがオーバーペア、AKはTPTK
→ A72r: AA/AK/AQがA系の強ハンド、KK/QQは若干劣位
→ 987cc: QQ+がオーバーペア、AKs/AQsはドロー+オーバーカード
```

**どのボードでもIPの平均ハンド強度はOOPを大きく上回ります。**

### range betが最善な理由

SPR≈1.77では、ブラフとバリューを打ち分けることに大きな意味がなくなります。

```
理由1: OOPのポットオッズが常に有利
  33% CBet に対し、OOPはポットの25%を払うだけでコール可能
  → 相手は広くコールするため、ブラフを「バレる」心配が薄れる

理由2: IPのレンジ優位が全ボードで成立
  全ハンドで33%を打ってもEV+になるほど、IPのレンジが強い
  → 「エクイティを持っていないハンド」がIPレンジにほぼ存在しない

理由3: 全ハンド統一サイズでOOPの対応を困難にする
  「強いから大きく」「弱いから小さく」のパターンが読まれない
  → range betはハンド強度と無相関にするバランス戦略
```

### CBetサイズ選択

range betといっても、ボードテクスチャによって最適サイズは変わります。

| ボードテクスチャ | 推奨サイズ | 理由 |
|:---:|:---:|:---|
| dry rainbow（K72r等） | 33% | range bet全ハンド、ドロー課金不要 |
| 2tone / connected | 33〜50% | ドローにチャージ、バリューも取る |
| monotone / 高連結 | 50〜75% | フラッシュ完成ボードで価値回収、ドロー保護 |

実戦上の目安としては「**4-betポットでは基本33%、wet boardは50%に上げる**」と覚えておけば十分です。

### GTO参照データ

GTO Wizard（BTN vs BB 4-betポット）によれば、IPのCBet頻度は次の通りです。

```
dry board（K72r）: CBet ≈ 95%+ ← range betに近い全頻度
wet board（987cc）: CBet ≈ 90%  ← 若干のチェックが残る
```

ほぼ全ボードでCBet頻度が90%を超えており、「range bet」という表現が実態に即しています。SRPのCBet頻度（ドライ65〜85%程度）と比べると、4-betポットでは明確にベット頻度が跳ね上がっています。

## 15-3　OOPの守備：コール後の計画が最重要

### 「コール後の計画」を先に立てる

OOPが4-betをコールした時点で、すでにコミット寄りの意思決定が始まっています。フロップで「とりあえずコール」を繰り返すと、ターンで46%のエクイティが要求される push/fold に足がすくむことになります。

フロップで判断する際は「**ターンでpushできるか否か**」を先に考えることが重要です。

### OOPのフロップ判断フロー

```
Step 1: 自分のHS（ハンドスコア）を計算する
Step 2: HS ≥ 65（T1: TPTK以上）か？
  → YES: コール計画でターンpush/fold
  → NO: Step 3へ

Step 3: HS 40-64（T2: セカンドペア〜TPWK）か？
  → YES: ポットオッズを確認
           33% CBetのコール = pot×25%の投資で、コール後SPR≈0.85
           ターンでpushするには約46%のエクイティが必要
           → 46%以上のエクイティ見込みがある場合のみコール
  → NO: Step 4へ

Step 4: HS < 40（T3: Air系）
  → フォールド（ターンでpushできない = コールする意義がない）
```

### ターンのpush/fold条件

フロップで33% CBetをコールした後のターン必要エクイティを計算します。

```
ターンのpot_odds計算:
  stack = 63bb、pot = 74bb
  コール額 = stack（残り全部）
  必要エクイティ = stack / (stack + pot) = 63 / (63 + 74) ≈ 46%

HS別の期待エクイティ:
  T1（TPTK以上, HS≥65）: エクイティ ≈ 55-80% → コール条件クリア
  T2（セカンドペア〜TPWK, HS 40-64）: エクイティ ≈ 35-55% → 境界付近
  T3（Air系, HS<40）: エクイティ ≈ 10-35% → コール不可
```

T2（セカンドペア〜TPWK）は「境界付近」であり、ターンで46%を超えるエクイティを持てるかどうかはボードによって変わります。フロップ段階でT2のハンドを持っている場合は、相手レンジとの相性（キッカー優位、スーテッド等）も考慮してフォールドを選びやすくなります。

## 15-4　コンボドローは強いプッシュ手

### コンボドローのエクイティ

フラッシュドロー＋ストレートドロー（以下、コンボドロー）は4-betポットで特別な地位を持ちます。JcTc on 9c8c3dのようなハンドは、AAに対してさえ55〜60%のエクイティを持ちます。

```
JcTc vs 9c8c3d（4-betポット）:
  FD（フラッシュドロー）: アウト 9枚
  OESD（両面ストレートドロー）: アウト 8枚（FDと重複除く実質6枚程度）
  合算エクイティ: vs AA ≈ 57%
```

### コンボドローのプッシュEV計算

フォールドエクイティ（FE）を30%と仮定してEVを計算します。

```
push EV = FE × pot + (1-FE) × equity × (stack + pot)
        = 0.30 × 44 + 0.70 × 0.57 × (78 + 44)
        = 13.2 + 0.70 × 0.57 × 122
        = 13.2 + 48.7
        = 48.6bb

比較: コールしてターンpush EV（仮定）≈ 40-45bb
→ フロップ即プッシュが+EV
```

コールされても57%のエクイティがあるため「コールされると困る」ハンドではありません。フォールドされれば44bbのポットを獲得、コールされても勝率有利という「win-win」の構造が成立します。

### 単独FDの判断

FDのみ（エクイティ≈35%）の場合はどうなるでしょうか。

```
push EV（単独FD）= 0.30 × 44 + 0.70 × 0.35 × 122
                = 13.2 + 29.9
                = 43.1bb

コールしてターンpush EV ≈ 37-40bb
→ プッシュが若干有利だが、コール選択肢も残る
```

単独FDは「フロッププッシュ」か「コールしてSPR≈0.85でターンpush」かの2択になります。どちらを選んでもEV差は小さく、実戦では**FEが高い相手（Nit気味）ならプッシュ、FEが低い相手（LAGやFish）ならコールが若干有利**になります。

### ドロー系の重要な原則

SPR≈1.77では、「チェックで1枚見る」戦略が大きく損をします。

```
❌ コンボドローでコール → ターンでまたコール → リバーで降りる
  → 3ストリートを消費してエクイティを実現できない

✅ フロップで即プッシュ（またはフォールド）
  → エクイティ未実現リスクをゼロにする
  → フォールドエクイティと実エクイティを同時に活用
```

「見せてもらって判断する」という通常ポットの思考法は、4-betポットでは機能しません。

## 15-5　代表6シナリオ詳解

### シナリオ1: AA on Kc7d2s（IP、4-betポット）

```
状況: IP（BTN）、AA、K72 rainbow
HS:  オーバーペア（Kヒットなし）≈ 75
SPR: 1.77

判断: 33% range bet
理由: T1（HS≥65）→ range bet対象
     ターンでも全ハンドベット継続
     OOPがKヒット（AKs等）を持つ可能性があるが、IP優位は揺るがない

アクション: CBet 33%、ターン継続push
```

### シナリオ2: KK on Ac7d2s（IP、4-betポット）

```
状況: IP（BTN）、KK、A72 rainbow
HS:  オーバーペア（Aヒット）≈ 65
     ※ OOPのレンジにAKs/AQsが多く含まれる
SPR: 1.77

判断: 33% range bet
理由: IPレンジアドバンテージ維持のためrange bet
     KKがAヒットに負けていても、range betによる
     フォールドエクイティ+EQが上回る
     OOPがAKs/AQsを持つ場合でもSPR=1.77なら
     「コール後ターンpush」の構造に持ち込める

アクション: CBet 33%（降りない）
```

### シナリオ3: AKs on Qc5d4c（IP、4-betポット）

```
状況: IP（BTN）、AKs、Q54 2tone（クラブ）
HS:  BDFD（バックドアフラッシュドロー）+ オーバーカード ≈ 50程度
SPR: 1.77

判断: 33% range bet
理由: AKsはIPのレンジの主力、BDFD込みでエクイティ確保
     range bet対象（HS関係なく全ハンドCBet）
     OOPコール後SPR≈0.86 → ターン判断

アクション: CBet 33%
```

### シナリオ4: QQ on Ac7d2s（IP、4-betポット）

```
状況: IP（BTN）、QQ、A72 rainbow
HS:  Aオーバーカードに対してセカンドペア扱い ≈ 65
     ※ Aヒットハンドに劣位
SPR: 1.77

判断: 33% range bet
理由: IPレンジアドバンテージを使ったrange bet
     QQがAKsに劣位でも、全ハンドbetの一部として打つ
     相手のコールに対してはターンのSPR≈0.85で判断

アクション: CBet 33%
```

### シナリオ5: TT on Kc5d4r（IP、4-betポット）

```
状況: IP（BTN）、TT、K54 rainbow
HS:  アンダーペア（K未ヒット）≈ 42
     Kヒットハンドに劣位、ただしIPレンジアドバンテージあり
SPR: 1.77

判断: 33% range bet（全ハンドCBetの一部として）
理由: SPR=1.77ではFEが十分あり、TT単独でもrange betがEV+
     ただしOOPのコールには注意（KKやAK）
     ターンでKが来た場合は慎重な判断が必要

アクション: CBet 33%
```

### シナリオ6: JTs on 9c8c3d（OOP、4-betポット）

```
状況: OOP（BB）、JcTc、9c8c3d wet board
HS:  コンボドロー（FD+OESD）≈ 94
     エクイティ vs AA ≈ 57%
SPR: 1.77

判断: フロップ即プッシュ（オールイン）
理由: コンボドローはSPR≈2でのプッシュが最善
     push EV ≈ 48.6bb > コールしてターンpush ≈ 40bb
     フォールドエクイティ + 高エクイティの「二重取り」

アクション: オールイン（フロップpush）
```

## 15-6　SPR別コミット基準の統一表

ここまでの内容を整理します。SPRとコミット基準の関係をまとめると次の通りです。

| SPR | ポットタイプ | コミット目安HS | 備考 |
|:---:|:---:|:---:|:---|
| ≈9 | SRP | HS≥80（セット以上） | 2ペアはコミット不可が多い |
| ≈4.9 | 3-betポット | HS≥65（TPTK以上） | バリュー計画でコール→プッシュ |
| ≈1.77 | 4-betポット | HS≥65（TPTK以上） | フロップでオールイン計画 |
| ≈1.77 | 4-betポット（拡張） | HS≥55（TPWK以上） | OOP条件・エクイティ次第で検討 |

4-betポットでは「SPR<2ゾーン」として、通常の3-betポット基準（HS≥65でコミット計画）よりもさらに踏み込んで、**フロップ段階でオールインを視野に入れた判断**が求められます。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解1**: 4-betポットでもSRPと同じ判断基準（セット以上でコミット）を使う。

**✅ 正解1**: SPR≈1.77ではTPTK（HS≥65）以上でコミットが正当化されます。セット以上を待っているとコミット機会を大幅に損ないます。

---

**❌ よくある誤解2**: 4-betポットのIPはバリューハンドだけCBetする。

**✅ 正解2**: IPはrange bet（全ハンドで33%）が最善です。ブラフ/バリューを区別して打ち分けることよりも、全ハンドで統一サイズを打つ方がOOPの対応を困難にします。

---

**❌ よくある誤解3**: フロップでコールした後、ターンでハンドを見て判断できる。

**✅ 正解3**: フロップで33% CBetをコールした後のSPRは≈0.85です。ターンは「残りスタックがポットより少ない」状態であり、事実上push/foldの2択しかありません。「ターンを見て判断する」という発想そのものを4-betポットでは捨てる必要があります。

---

## 章のまとめ

- **4-betポットSPR≈1.77はフロップ後すぐにSPR<1に落ちる「別ゲーム」**
- **IPはrange bet（33%全ハンド）**: SPR=1.77ではブラフ/バリュー区別が不要で、全ハンド統一サイズが最善
- **OOPはフロップで「ターンpush可能か」を先に判断**: T1（HS≥65）ならコール計画、T2は46%エクイティ確認、T3はフォールド
- **コンボドロー（FD+SD）はフロップ即プッシュが最善**: EV≈48.6bbでコール選択より優位
- **3-betポットとの違い**: SPRが半分以下→コミット判断はより積極的に、「見せてもらう」余裕はゼロ
- **単独FD**: push or コール → ターンpushのどちらでも可、FEで選択

次章（第16章）では、4-betポットよりさらに複雑な「マルチウェイポット」のフロップ戦略を扱います。プレイヤーが3人以上いる場合にどうSPRとハンド強度を評価するかを学びます。

## ミニクイズ

### 問1

**4-betポット（SPR≈1.77）、自分はOOP（BB）、自ハンドKJo、フロップK♥7♦2♣（K72 rainbow）**。IPが33% CBetを打ってきた。アクションは？

<details>
<summary>解答</summary>

```
KJo on K72r:
  HS: TPTK（K + Jキッカー）= HS≈70 → T1
  
Step 1: HS≥65（T1）→ コール計画でターンpush/fold

コール後SPR≈0.85。ターンpushに必要なエクイティ≈46%。
KJo vs IPレンジ（QQ+/AKs/AQs）のエクイティ ≈ 50-55%（TPTK）

→ コール、ターンでpush計画
```

**答え: コール（ターンpush計画）**

KJoのTPTKは4-betポットでコミット範囲に入ります。ターンでpushすることを前提にフロップをコールします。

</details>

### 問2

**4-betポット（SPR≈1.77）、自分はIP（BTN）、自ハンドAQo、フロップ9♠8♦7♣（978 connected rainbow）**。アクションは？

<details>
<summary>解答</summary>

```
AQo on 978r:
  HS: オーバーカードのみ、ボードに何もヒットしていない
  ただし IPは4-betポットでrange bet戦略

→ range bet（33%全ハンド）の一部として打つ
  FEが十分あるため（OOPは T2以下がフォールド）
  AQoでも33% CBetがEV+
```

**答え: CBet 33%（range bet）**

エアー同然のAQoでも、4-betポットのIPは33% range betを打ちます。OOPのコールにはターンでAかQがヒットするか判断します。

</details>

### 問3

**4-betポット（SPR≈1.77）、自分はOOP（BB）、自ハンドAcJc（Aハイ＋FD）、フロップA♠9♣6♣（A96 with FD）**。IPが33% CBetを打ってきた。アクションは？

<details>
<summary>解答</summary>

```
AcJc on A♠9♣6♣:
  AヒットでTP + FD（フラッシュドロー）
  HS: TPTK(A+J) + FD = HS≈75-80 → T1かつコンボドロー性あり

T1（HS≥65）かつFD → コンボドロー的判断
  コール計画でターンpush: EV≈標準コンボドローより高い
  フロップ即プッシュも検討圏:
    エクイティ vs AAなど ≈ 65%+
    push EV = 0.30×44 + 0.70×0.65×122 ≈ 13.2 + 55.5 = 68.7bb

→ フロッププッシュ or コール（どちらもEV+）
  実戦ではコール寄り（AヒットのTPTK+FDはターンでも強い）
```

**答え: コール（ターンpush計画）またはフロップpush**

AのTPTKにFDが付いているため、4-betポットでは積極的なアクションが正当化されます。コールしてターンでの継続pushが最もシンプルな戦略です。

</details>

**【GTOとのズレ】**

本章の「range bet（33%全ハンド）」という単純化は、4-betポットのIPのGTO戦略を約85〜95%の精度で表現しています。GTO Wizardのデータでは、dry boardでのCBet頻度は95%+とほぼ全ハンドですが、wet boardでも90%前後であり、「全ハンドで打つ」という原則はほぼ正しいと言えます。

ただし、本章で単純化している点がいくつかあります。まず、CBetサイズについてです。本章では「dry=33%、wet=50%」と2段階に区切りましたが、GTO解析では33%が最多の選択である一方、75%以上はmonothoneボードや特定のコンボドロー対応時のみ使用されます。monotoneボードで75%を打つかどうかは、IPのレンジにナッツフラッシュが含まれる割合によって変わり、本章の表では反映しきれていません。

次に、OOPのコール基準についてです。本章は「HS≥65でコール」と二値化しましたが、GTO解析ではOOPのフロップコール頻度は50〜55%程度に設定されており、T2（HS 40〜64）の一部もコールします。これはポットオッズ（33% CBetに対して25%の投資で参加可能）が広めのコールを許容するためです。ただしT2のコールはターンでのpush/fold判断を前提にした計画的コールであり、本章のフローは「ターンでpushできるか」という核心を正しく捉えています。

コンボドローのEV計算についても、本章はFE（フォールドエクイティ）を30%固定で計算しています。実際のFEは相手のコール頻度によって大きく変動し、LAGやFish相手ではFEが下がってコール計算になることがあります。コンボドローでプッシュを選ぶ際は、相手のプレイヤータイプも加味することで、より正確な判断ができます。
