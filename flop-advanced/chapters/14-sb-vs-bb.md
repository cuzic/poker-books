# 第14章　SB vs BB — ブラインド対決のフロップ

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: SB vs BB は「プリフロップのアグレッサーがフロップで OOP になる」唯一の状況です。BTN vs BB とまったく異なる力学が働くこのシチュエーションを理解し、SB（OOP）と BB（IP）それぞれのフロップ戦略を習得しましょう。

---

## 14-1　SB vs BB が特殊な理由

通常のシングルレイズポット（SRP）では、プリフロップで最後にレイズした側（PFR）がフロップで IP（後に行動する有利な立場）を持ちます。BTN vs BB であれば、BTN がオープンして BB がコールするため、フロップでは BTN が IP、BB が OOP です。

SB vs BB はこれが逆転します。

```
プリフロップ: SB レイズ → BB コール（SRP 成立）
フロップ:    SB が先に行動 → OOP
            BB が後に行動 → IP
```

PFR（SB）が OOP になる唯一のポスト構造が SB vs BB です。この「アグレッサーがポジション不利」という逆転が、フロップ戦略を大きく変えます。

### ポット構造の確認

```
SB 2bb レイズ → BB コール（1bb 追加）:
  pot = 2 + 2 = 4bb（BB は 1bb = 2bb へ、SB は 2bb）
  ※ アンテなしの場合
  stack ≈ 98bb（SB）/ 98bb（BB）
  SPR ≈ 98 / 4 ≈ 24.5

実際にはビッグブラインド分を含めると:
  SB 2.5bb レイズ → BB call 1.5bb（合計 2.5bb）:
  pot ≈ 5bb, stack ≈ 97.5bb → SPR ≈ 19.5
```

SPR は BTN vs BB（≈ 16〜19）と同程度で、スタック的な深さは似ています。しかしポジションが逆のため、CBet の考え方が大きく変わります。

---

## 14-2　SB の CBet 頻度：BTN より 20pt 低い

BTN vs BB でのフロップ CBet 頻度は約 68%（GTO Wizard 実測）です。これに対して SB vs BB での SB の CBet 頻度は約 50% です。この差は「OOP であること」から来ています。

### OOP でベットするコスト

IP がベットする場合、相手のリアクションを最後に見られるため、レイズされたらフォールド、コールされたらターンへ、という追加情報を得ながら判断できます。

OOP がベットする場合、ベット後に BB がレイズしてきたとき、BB の後ろに「さらにアクションを続ける余地（ポジション優位）」があります。OOP は常に先に行動するため「情報を先に開示するコスト」を払い続けます。

このため SB の CBet 頻度は BTN より低く、約 50% が GTO 均衡に近い値です。

### ボード別 SB CBet 頻度（GTO Wizard 参照）

| ボードテクスチャ | SB CBet 頻度（目安） | 理由 |
|:---|:---:|:---|
| A-high dry（A♣7♦2♠） | ≈ 70% | SB のレンジに AK/AQ/AA が多い |
| K-high dry（K♣7♦2♠） | ≈ 60% | SB の KK/KQ がヒットしやすい |
| Low connected（5♣4♦3♠） | ≈ 35% | BB の小ペア・コネクターが有利 |
| Low paired（7♣7♦2♠） | ≈ 45% | BB の低ポケットが多い |
| Monotone（9♠8♠6♠） | ≈ 30% | OOP でフラッシュドロー警戒が難しい |

BTN と異なり、SB は low board（7 以下がトップ）では CBet を大幅に控えます。

---

## 14-3　ボード別レンジ有利の判定

SB vs BB でどちらがレンジ優位を持つかは、ボードテクスチャに強く依存します。

### SB が有利なボード

SB のプリフロップレンジは比較的タイトで、BTN のレンジに近い組成を持ちます。

```
SB 有利ボード:
  A-high: AK/AQ/AA が SB レンジに高密度で含まれる
  K-high: KK/KQ が SB レンジに多い
  → SB は積極的に CBet（T1/T2 でベット）
```

### BB が有利なボード

BB は非常に広いレンジでディフェンスするため、小さいランクのペアやコネクターを多く保有します。

```
BB 有利ボード:
  Low board（2〜7トップ）: BB の 22〜77 等の小ポケットが当たりやすい
  Connected board（JT9, 876 等）: BB のコネクターが OESD/2ペアに
  → SB は CBet を控え、T1 のみ打つか チェック
```

実例で確認しましょう。

> **例：SB が A♥J♦ を保有、ボード 5♣4♦3♠**
>
> B ≈ 55（low connected rainbow）、HS = A-high + 2OC ≈ 49 → T2
> しかし BB はこのボードでコネクターや小ペアを多く保有している。
> SB は OOP のため T2 でのベットは不利 → **チェックが有力**
>
> **例：SB が K♠Q♣ を保有、ボード K♣7♦2♠**
>
> B = 62（rainbow A/K-high）、HS = TPTK ≈ 65 → T1
> SB のレンジは K high ボードでレンジ優位 → **CBet 33%〜50%**

---

## 14-4　SB の CBet サイズ：33% が主体

BTN vs BB では 75% CBet が多用されますが、SB vs BB では 33% が CBet サイズの中心です。

OOP でのベットは IP への情報開示コストがあるため、小サイズで情報を最小化しながらポットを維持するアプローチが有効です。

```
SB の CBet サイズ基準:
  T1（HS≥65）: 33〜50%（バリューでも大サイズを控える）
  T2（HS 20-64）: 33%（小サイズで情報コストを下げる）
  T3（HS<20）: B≥62 の dry ボードのみ 33%
  wet / low board: チェックが基本
```

75% 以上のサイズを SB から OOP でベットすると、BB に「強いハンド確定」のシグナルを与えすぎてしまい、BB はフォールドまたはナッツでの CR のみを選択します。結果として SB のバリューを最大化できません。

---

## 14-5　BB（IP 側）の戦略

BB はフロップで IP という有利な立場を持ちますが、広いレンジでコールしているため「ナッツの密度が低い」側面もあります。

### BB の donk bet（ドンクベット）

SB vs BB では BB の donk bet（フロップで IP から先にベットする異例のアクション）の頻度が、BTN vs BB よりも高くなります。

```
BTN vs BB での BB donk 頻度: ≈ 5%
SB vs BB での BB donk 頻度:  ≈ 15〜25%（low board で増加）
```

BB が donk bet をしてくるのは「自分のレンジ優位があるボード」です。Low board や connected board でこの傾向が強くなります。

### BB のフロップ判断

```
BB（IP）の SB CBet に対する対応:
  T1（HS≥65）: コールまたは CR を検討
  T2（HS 20-64）: コール（SPR ≥ 6 のためコール閾値 HS≥20 を適用）
  T3（HS<20）: フォールド（vs 33% CBet でも HS<15 でフォールド）
  CR 閾値: HS≥40（SRP 標準、SPR≥6）
```

BB が CR を打てるボードは、自身のレンジが優位な low board や connected board です。A/K-high ボードでは SB のレンジが強いため、BB の CR は慎重に行います。

---

## 14-6　SB の CBet 後の守備計画

SB が CBet した後に BB からレイズ（CR）を受けた場合の対応は、SRP の標準判断より厳しくなります。

```
SB が 33% CBet → BB が CR を打った場合:
  T1（HS≥65）: コールが主体（セット/2ペアは 3-bet 検討）
  T2（HS 20-64）: ほぼフォールド（OOP + CR = 不利な状況）
  T3（HS<20）: フォールド確定

SB が CBet → BB がコール → SB のターンアクション:
  SB は OOP のためターンでも「チェックが先」になる
  T1: ターンもベット（バレル継続）
  T2: ターンはチェック → BB がベットしてきたら状況次第
```

SB は OOP という構造上、フロップ CBet を「1 ストリート限定の情報ベット」として打つことが多く、ターンでのバレルは BTN より少なくなります。

## ミニクイズ

### 問1

SB vs BB での最大の特徴として正しいものはどれですか？

1. SB は常にフロップで最初に行動するため、BTN より有利
2. PFR（SB）がフロップで OOP になる唯一の SRP 構造
3. BB はプリフロップでコールしているため、常に弱いレンジを持つ

### 問2

SB vs BB でボードが 5♣4♦3♠（low connected）のとき、SB が A♥K♦ を持っています。
最も適切なフロップ戦略はどれですか？

1. AK は T1 なので、常に 75% CBet を打つ
2. BB が low board でレンジ優位を持つため、SB はチェックが有力
3. SB は OOP なので、どんなボードでも CBet してはいけない

### 問3

SB vs BB で、BB が SB の 33% CBet に対してチェックレイズしてきました。
SB のハンドは HS=45（TPGK 程度）です。最適な判断はどれですか？

1. HS≥40 で CR 閾値を超えているため、コールして続ける
2. SB は OOP + BBのCR に直面しており、T2 ではほぼフォールドが有力
3. SPR が高いためコールしてターンで情報収集すべき

---

### 解答

- **問1**: **2. PFR（SB）がフロップで OOP になる唯一の SRP 構造** が正解。SB がプリフロップのアグレッサーでありながら、フロップでは先に行動する OOP の立場になります。これが SB vs BB の最大の特徴です。
- **問2**: **2. BB が low board でレンジ優位を持つため、SB はチェックが有力** が正解。5♣4♦3♠ は BB の広いコールレンジ（小ペア・コネクター）が当たりやすいボードです。AK は T1 ですが、レンジ不利のボードで OOP から大サイズを打つのは EV が低下します。
- **問3**: **2. SB は OOP + BB の CR に直面しており、T2 ではほぼフォールドが有力** が正解。SB は OOP という立場上、BB の CR に対して T2 でコールし続けることはストリートを重ねるごとに不利が積み重なります。HS=45 は CR 閾値（HS≥40）をわずかに超えますが、SB の OOP という条件を加味するとフォールドが安全です。

---

> **本章まとめ**
>
> - SB vs BB は PFR（SB）が OOP になる唯一の SRP 構造。ポジションの逆転が戦略を大きく変える。
> - SB の CBet 頻度は約 50%（BTN の 68% から −18pt）。A/K-high ボードで高く、low/connected ボードで大幅低下。
> - SB の CBet サイズは 33% が主体。OOP での 75%+ は情報開示コストが高い。
> - BB の donk bet は SB vs BB で多発（low board で 15〜25%）。BTN vs BB の 5% より高い。
> - SB が CBet 後に BB から CR を受けた場合、T2（HS<65）はほぼフォールドが安全。

---

**【GTO とのズレ】**

SB vs BB のフロップ戦略は GTO でも複雑な混合戦略が現れます。

①**逸脱量**: 本章の「SB CBet ≈ 50%」はボード別に 35〜65% の幅があります。高カード rainbow（K♣7♦2♠ 等）では SB が 60%+ CBet する一方、コネクテッド（9♣8♦7♠ 等）では 35% 程度に下がります。「50%」という平均値は個別ボードでは 15% 以上ズレる場合があります。

②**最も差が出るボード**: Broadway コネクテッド（K♣Q♦J♠ など）では SB が T1 以外をほぼチェックしますが、GTO では一部の T2 ハンドも CBet に混ぜます。このボードで SB が過度にチェックすると、BB がターンでドンクベットやフリーカード取得で搾取できるようになります。

③**本書の簡易化で損するシナリオ**: 低ボード（8♣5♦3♠ 等）で SB が T3 をほぼチェックすると「SB のチェック = 弱い」というリードを BB に与えます。BB は SB チェック後のターンで積極的にドンクベットし、SB の SDV 保護ハンドを圧迫できます。「low board は全チェック」という単純適用はこのリスクを持ちます。また BB のフロップ donk 頻度は GTO 解析ツールによって差があり、15〜25% は上限側の目安です。
