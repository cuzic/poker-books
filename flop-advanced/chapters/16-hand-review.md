- **B (ソルバー派)**: 16-4 節の優先度付けで大きいミスから改善し、ソルバー結果を数値で管理する。

## 16-1　レビューの 4 つの目的

### 目的 1: GTO との乖離を測る

自分のプレイがGTOからどれだけ外れているかを定量化。ソルバー (PioSolver, GTO Wizard) でEVロスを算出。

### 目的 2: 搾取の精度を確認

相手タイプに対するエクスプロイト戦略が正しく機能したか。勝ったハンド / 負けたハンドの内訳を分析。

### 目的 3: メタゲームの検証

自分のイメージ戦略が相手に正しく伝わり、適切に利用されたか。

### 目的 4: タイプ判定の精度向上

自分の相手タイプ判定が正しかったか。ショーダウンの結果と照合。

## 16-3　ハンドヒストリーエクスポート

### PokerTracker 4 での例

```
Step 1: プレイしたサイトからハンドヒストリー自動取得 (設定済み)
Step 2: セッション一覧から 分析したいセッションを選択
Step 3: エクスポート → GTO Wizard 形式 or テキスト
```

### 自動タグ付け

```
- 「大ポット」のハンドを自動抽出 (100 BB 以上)
- 「勝敗が接戦」のハンド (EV +/- 5 BB)
- 「境界判断」のハンド (CBet 頻度 40-60% 帯)
```

### 週次エクスポート

```
週末に 1 週間分のハンドをまとめてエクスポート
→ 1 セッションで 20-30 ハンドのレビュー
→ 1 ハンドあたり 5-10 分
```

## 16-4　ソルバーへの投入手順

```
Step 1: ハンドヒストリーからボード、アクションを入力
Step 2: ソルバーの「ソリューション」タブを開く
```

```
Step 2: ボード、ベットツリーを構築
Step 3: ソルバー実行 (数分-数時間)
Step 4: 自分のハンドのアクション EV 比較
```

## 16-5　EV ロスの測定

### EV ロスの定義

```
EV ロス = GTO 推奨アクションの EV - 自分のアクションの EV

例:
  GTO 推奨: CBet 75% (EV = +1.5 BB)
  自分:     チェック (EV = +0.9 BB)
  EV ロス = +0.6 BB
```

### EV ロスの分類

```
EV ロス 0-0.2 BB: 許容範囲 (境界判断、どちらでも可)
EV ロス 0.2-0.5 BB: 軽微、気をつけるべき
EV ロス 0.5-1.0 BB: 明確なミス、要復習
EV ロス 1.0+ BB: 大きなミス、原因究明
```

### 1 セッションでの平均 EV ロス

```
優秀なプレイヤー: 平均 EV ロス < 0.3 BB/ハンド
中級者: 平均 EV ロス 0.5-0.8 BB/ハンド
初級者: 平均 EV ロス 1.0+ BB/ハンド
```

## 16-6　乖離ハンドのピックアップ

全ハンドを完璧にレビューするのは時間不足。**改善優先度**をつけてピックアップします。

### 優先度 1: EV ロス 1.0+ BB のハンド

```
- 即座に復習
- 原因究明 (なぜ GTO から外れたか)
- 類似スポットを次回に備えて記憶
```

### 優先度 2: 大ポットのハンド (100 BB+)

```
- 影響度が大きい
- ミスすると bankroll が揺らぐ
- 特にリバーの判断
```

### 優先度 3: 繰り返し起きる状況

```
「K72r で CBet 75%」を 1 週間で 15 回プレイした
→ 15 回分の一貫性を見る
→ パターン化できるスポットを特定
```

### 優先度 4: 新しいエクスプロイト戦略の検証

```
「Fish 相手にバリュー厚」を 実践した
→ 実際に +EV だったか?
→ 想定した通りに機能したか?
```

## 16-7　改善の 5 サイクル

### サイクル 1: プレイ

```
本書の戦略を実践 (1-2 時間、50-100 ハンド)
→ 毎ハンドで Step 1-7 (第15章) を実行
```

### サイクル 2: エクスポート

```
セッション後、ハンドヒストリーをエクスポート
→ 優先度タグ付け (上述の 4 優先度)
```

### サイクル 3: レビュー

```
翌日、時間を取って 20-30 ハンドを レビュー
→ 大きいミスを 3-5 件特定
→ 各ミスの原因を記録
```

### サイクル 4: 学習

```
ミスの原因が:
  - 「タイプ判定が誤った」→ 第10章を再読
  - 「メタゲームが浅かった」→ 第13章を再読
  - 「テルを読み違えた」→ 第14章を再読
```

### サイクル 5: 次回プレイに反映

```
レビュー後の次のセッションで、特定した改善点を意識的に実行
→ 類似スポットで正しく対応
→ サイクル 1 に戻る
```

## 16-8　週次・月次レビュー

### 週次レビュー (30 分)

```
- 今週の総 EV ロス
- 最大の 3 ミス
- 改善のトレンド (先週と比べて)
- 次週の焦点
```

### 月次レビュー (1 時間)

```
- 月間の勝ち額 (BB/100 基準)
- 新しく習得したスキル
- まだ改善が必要なスポット
- 来月の学習計画
```

### 四半期レビュー (2 時間)

```
- 年間プランとの整合
- レート移動判断 (上のレートに上がるか?)
- bankroll 管理の再評価
- 目標設定
```

## 16-9　レビューの落とし穴

### 落とし穴 1: レビューしすぎ

```
1 ハンドに 1 時間かけて深掘り
→ 他のハンドに時間が使えない
→ 全体が改善しない
```

**対策**: 1ハンド10分以内で切り上げる。深掘りは**学習プロジェクト**として別途。

### 落とし穴 2: 感情的にレビュー

```
「このハンドで負けた、バッドビートだ」
→ 冷静な判断分析ができない
```

**対策**: プレイ直後ではなく、翌日以降にレビュー。距離を置く。

### 落とし穴 3: 結果 outcomes にこだわる

```
「このハンドで負けたから間違っていた」
→ 実は +EV の正解プレイでも、短期で負けることはある
```

**対策**: 判断プロセスを重視。EVが +なら正解、結果は独立。

### 落とし穴 4: GTO 盲信

```
「GTO が言うから正しい」
→ GTO はディフェンス均衡、エクスプロイトの余地を見逃す
```

**対策**: GTOを基準にしつつ、エクスプロイト余地を併せて分析。

## 🎴 ライブポーカー・ソフトなしでのハンドレビュー

ソフト (PokerTracker、GTO Wizard 等) が使えない読者でも、**紙のノートと記憶だけ**で本章の 5 サイクルを実行できます。

### 紙ベースのレビュー手順 (1 セッション 30 分)

```
Step 1: セッション終了直後、印象に残った「大ポット 3 ハンド」を書き出す
  - ボード、自分のハンド、相手のアクション、自分の判断、結果

Step 2: 各ハンドで「もし別の判断をしたら」を 2 パターン想定
  - 例: 75% CBet した → もし 50% だったら? チェックだったら?

Step 3: 巻2 の D3 + 9マスマトリクスで「理論値」を再現
  - 紙上で計算: D3 頻度 %、HandScore、マトリクスのマス

Step 4: 自分の判断と理論値のズレを言語化
  - 「理論はチェックだったが、自分は 33% CBet した。相手が LAG だったからブラフキャッチ増を狙った」

Step 5: 判断の根拠 (相手タイプ、メタゲーム) が妥当だったか自己評価
  - 妥当なら EV 0、不当ならミス、追加学習ポイントを記録
```

### ライブでの「ノート術」

```
セッション前: 新しいテーブルの相手全員 (6 人) の VPIP/PFR を粗く推定
  → 1 行/人のメモ

セッション中: 重要ハンド (大ポット、相手のスロープレー等) を簡易記録
  → 「ハンド#3: BTN 相手 KQo、K72r で 75% CBet 被ったがコール、ターンチェック、リバー 300% ベット → フォールド」

セッション後: 上記メモを元に 3-5 ハンドを再現
  → ソフト不使用でも重要なスポットはカバー可能
```

### ソフトなしの欠点と補い方

```
欠点: 正確な EV ロス定量化ができない
補い方: ハンドを「+EV だった / -EV だった / 境界」の 3 分類で管理

欠点: 相手タイプの HUD 統計が取れない
補い方: メモに「VPIP 推定 30%、3bet 1 回見た」などの観察値を記録

欠点: ソルバー解との比較ができない
補い方: 週 1 回、友人やコミュニティと「この判断どう思う?」を共有
```

ソフト派と同じ速度では学習できないが、**継続できる仕組み**を作ることが重要。3 ヶ月継続すれば、ソフト派の 1 ヶ月分の学習量は確保できます。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: 全ハンドをレビューすれば最も効率よく上達できる。

**✅ 正解**: 優先度 1 (EV ロス 1.0+ BB) と優先度 2 (大ポット) に集中することが重要。全ハンドを見ようとすると疲れて継続できなくなる。選択と集中によって学習効果が最大化される。

## 章のまとめ

- レビューの4目的： GTO乖離 / 搾取精度 / メタゲーム / タイプ判定

## ミニクイズ

### 問 1

**ハンドレビューで「K72r で AK を 75% CBet → BB コール → ターン 5 で 50% CBet → BB 3bet コール → リバー 2 でチェック → BB ベット → フォールド」のハンド**。EVロスの可能性は？

<details>
<summary>解答</summary>

```
GTO 推奨シナリオ:
  - フロップ 75% CBet: AK TPTK なら 推奨 (GTO 一致)
  - ターン 5 で 50% CBet: ブランクターン、AK は TP 維持、推奨 50%
  - リバー 2 でチェック: AK は依然 TP、リバーでチェックは妥当
  - BB ベットにフォールド: 相手のベットレンジ次第

評価ポイント:
  - もし BB のリバーベットレンジが V:B 比 1:1 (オーバーベット) だったら
    → AK でコールが +EV、フォールドは EV ロス
  - もし V:B 比 2:1+ (通常サイズ) だったら
    → AK でフォールドが妥当

→ **BB のベットサイズとタイプで EV ロス評価が変わる**
```

**答え: EV ロスは サイズとタイプ次第。大サイズ (オーバーベット) で TAG 相手 → コールが推奨、ここでフォールドは EV ロス 0.5-1.0 BB 程度**

</details>

### 問 2

**ハンドレビューで「Fish 相手に 78s で CBet ブラフ → フォールド」のハンド**。評価は？

<details>
<summary>解答</summary>

```
Fish 相手へのブラフ:
  - Fish は降りない傾向
  - 78s ブラフは 多くの場合 EV マイナス

評価: **EV ロスの可能性高い** (0.5-1.0 BB)

改善案:
  - Fish 相手はブラフ封印
  - 78s なら チェック or フォールド
```

**答え: EV ロス確認のためにソルバーで分析、結果 Fish 相手にブラフは EV 負なので チェック推奨**

</details>

### 問 3

**週次レビュー: 10 セッションで 平均 EV ロス 0.4 BB/ハンド**。次の学習焦点は？

<details>
<summary>解答</summary>

```
0.4 BB ロス = 中級レベル (軽微-ミス境界)

改善のヒント:
  - 全ハンドの中で、大きい EV ロス (1.0+ BB) の 10 ハンドをピックアップ
  - 共通パターンがあるか確認 (特定のボード? 特定のサイズ?)
  - そのパターンに絞って 翌週学習

候補:
  - K72r 系 (ハイ×ドライ) での CBet 頻度
  - ウェットボードでの境界判断
  - リバーの MDF 判定
```

**答え: 大 EV ロス 10 ハンドのパターン特定 → 該当章 (第1-4章 or 第10-14章) を再読**

</details>
