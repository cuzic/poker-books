## 8-1　なぜサイズに情報が漏れるのか

### GTO 混合戦略の再現不可能性

GTOソルバーは「AAで60% CBet、40% チェック」「AAでのサイズは30% が50%、70% が75%」という複雑な混合を計算します。

人間がこれを再現するには：。

- 全ハンドに対して「この頻度で打つ」を記憶する必要
- ランダマイザー（時計、カード値）を常時使う
- 相手に読まれないよう**完璧に実行**

これは事実上不可能。99% のプレイヤーはサイズ選択に偏りがあります。

### 偏りの典型パターン

プレイヤーが無意識に漏らす傾向：。

1. **「強い時大きく」**: ナッツを大きく打つ癖（アマチュア特有）
2. **「強い時小さく」**: ナッツを小さく打って引きつける癖（経験者）
3. **「弱い時大きく」**: ブラフで圧力かける癖 (LAG)
4. **「弱い時小さく」**: ブラフでリスク限定する癖 (nit)

相手がどのタイプかを観察で特定できれば、サイズからレンジを絞れます。

## 8-2　CBet サイズ 4 区分の解剖

### 33% CBet (small, range bet)

**GTO の意図**: 広いレンジから薄く打つ、保護 + 少ないブラフ予算。

**レンジ構成**（理想的）:。

- バリュー 15-20%
- 中強度40-50%
- ブラフ30-40%

**実戦での偏り**:

- **「小さく打つ = 弱い」と勘違いするプレイヤー**: バリュー軽視、ブラフ過多
- **標準的プレイヤー**: GTOに近い
- **経験者**: GTOよりバリューを薄め、さらにrange bet寄り

### 50% CBet (medium)

**GTO の意図**: 中間サイズ、バリューとドロー保護の両立。

**レンジ構成**（理想的）:。

- バリュー 40%
- 中強度25-30%
- ブラフ30-35%

**実戦での偏り**:

- 50% を頻用するプレイヤーは少ない（GTOでは稀）
- 50% を使うプレイヤーは**慣例的**（「中間を取る」思考）、情報が出やすい

### 75% CBet (large, polarized)

**GTO の意図**: ポラライズ（ナッツ + 完全ブラフ）

**レンジ構成**（理想的）:。

- バリュー 55-60%
- 中強度10-15%
- ブラフ25-35%

**実戦での偏り**:

- **「大きく打つ = 強い」プレイヤー**: バリュー過多 (90%)、ブラフほぼなし
  - 対抗： タイトコール（TPGK以上）、ブラフキャッチャー控えめ
- **経験者**: GTO通りのpolarization、ブラフを込める

### オーバーベット (100-150%)

**GTO の意図**: 極めてポラライズ（ナッツor完全ブラフ）

**レンジ構成**:

- バリュー 40-50%
- ブラフ50-60%
- 中間ほぼなし

**実戦での偏り**:

- 使うプレイヤーが限られる（経験者のみ）
- 使う場合はかなりGTOに近い
- ただしライブ / 低レートでは**オーバーベット = ナッツ**のプレイヤーが多い

## 8-4　12 のサイジングテル典型パターン

GTO Wizardや実戦観察から、よく見られる12の具体パターン：。

### 1. 「強い時大きく」タイプ

```
33% CBet → ブラフまたは中強度
75% CBet → ナッツ確定
```

対抗： 75% CBetに対してTPGK以下をフォールド、33% CBetに対して広くコール。

### 2. 「強い時小さく」タイプ (経験者)

```
33% CBet → セット含む polarized
75% CBet → 中強度ハンド (TPGK、オーバーペア)
```

対抗： 逆パターン。33% は警戒、75% はブラフキャッチ候補。

### 3. 「BTN の 33% range bet」

```
BTN が K72r で 33% CBet → 標準的、特に情報なし
相手タイプ観察を重視
```

### 4. 「BB からの 33% ドンク」

```
ドンクはレンジが弱い → 33% なら特にブラフ過多
バリュー:ブラフ = 1:2 (ブラフ多め)
```

対抗： 広くコールして次のストリートに任せる。

### 5. 「ウェットボードでの 75%」

```
T98ss で 75% → 強いバリューが必要、通常セット以上
V:B 比 3:1 (ナッツ重視)
```

対抗： TPGK以下フォールド、ナッツブロッカー付きでブラフキャッチ。

### 6. 「ドライボードでの 75%」

```
K72r で 75% → ポラライズ、V:B 2:1
中強度の TPGK もコール対象
```

### 7. 「ターン大サイズ、フロップ 33%」

```
ターンで急に大きくするプレイヤー = ドロー完成 or バリュー狙い
対抗: ナッツキャッチ + 読み
```

### 8. 「フロップ大きい、ターン小さい」

```
フロップ 75% → ターン 33% = 情報を取りに行く (調整的)
多くの場合、プレイヤーがバリューを延ばしたいが、サイズを落として誘引
対抗: バリューをフォールドせずキャッチ
```

### 9. 「常に 50%」

```
50% を固定で使うプレイヤーは思考停止型
レンジは GTO と大きく乖離、ブラフもバリューも中間
対抗: 広く防衛
```

### 10. 「大きくて早い (タンクなし) ベット」

```
事前決定型 = 強いバリュー (計算済み)
対抗: 敬意、TPWK 以下フォールド
```

### 11. 「タンクしてから小さく」

```
判断に迷った結果の弱いベット
中強度 or ブラフ多い
対抗: コール + 次のストリート観察
```

### 12. 「オーバーベットのタンク後」

```
長考オーバーベット = ナッツ級、思考を装うブラフ、または弱ナッツ迷い
対抗: プレイヤー履歴次第、一般的にはフォールド
```

## 8-5　タイミングテル (オンライン)

サイズと合わせて、**ベットのタイミング**も情報源。

### 4 タイプの オンライン タイミング

**1. インスタントベット (即 bet)**

```
示唆: 事前決定 (強いバリュー or 事前ブラフ)
判定: 強いバリューの可能性高い (60-70%)
対抗: タイトに対応
```

**2. 長考後のベット (3 秒以上)**

```
示唆: 難しい判断 (中強度 or 境界)
判定: バリュー 30%、中強度 40%、ブラフ 30%
対抗: 境界での 後手下限ライン 通り
```

**3. インスタントコール**

```
示唆: ドロー (自動的にコール決定) or 自信ある弱TP
判定: ドロー 60%、バリュー 20%
対抗: バリューを延ばす (次ストリートで)
```

**4. 長考後のコール**

```
示唆: 損切り思考 (TPWK やミドルペアで迷ってコール)
判定: 中強度 60%、バリュー 25%
対抗: 次ストリートで弱いバリューを追加
```

### タイミングテルの使い方

**記録する**: 相手が各状況で何秒使ったかを数える（少なくとも頭の中で）。
**パターン認識**: 5回以上観察したら**傾向として採用**、それ未満は参考程度。
**逆テル**: 自分のタイミングも観察されている前提で、意図的に揺らす。

## 8-6　ライブポーカーのボディランゲージ

ライブでは**物理的なテル**が加わります。ただし本書は戦略本なので、深入りしすぎず戦略に使える範囲で。

### 主な観察ポイント 4 カテゴリ

**1. 呼吸**

```
深呼吸 → バリュー (落ち着きを装う、実は強い)
浅く早い → 緊張 (ブラフ or 極めて強い、どちらか)
```

**2. チップ操作**

```
整えるような繰り返し → 考えている (境界)
一気に前へ → 決断済み (強いか完全ブラフ)
```

**3. 視線**

```
ポットに視線 → バリュー計算中
相手を見つめる → 強気 (通常ブラフ多い、演技)
```

**4. 微小表情**

```
瞬間的な口の動き → 情報漏れ
目の動きの止まり → 集中 (強いハンド)
```

### 注意: 戦略本としての節度

物理テルは（a）実際には読みづらい （b） 逆利用される (c) 文化・個人差が大きい。戦略道具として**補助情報**程度に扱う。本書で細かいtellの分類はしません。詳細はZachary Elwood *Reading Poker Tells* 等の専門書を参照。

## 8-7　テルの活用ルール

### 活用の 5 原則

1. **サンプル 5 回以上**: 1回の観察で決めつけない
2. **複数テル確認**: サイズ + タイミング + 履歴の3軸で裏付け
3. **自分のテルチェック**: 自分も同じパターンを出していないか
4. **相手のレベル判定**: レベル2以上のプレイヤーには逆テルあり（第13章）
5. **補助情報として使う**: メインはGTO、テルは微調整

### ダメな使い方

- 1回の観察で戦略変更
- タイミングだけで決定（サイズ情報無視）
- 「なんとなく」で相手を読む
- 自分のテルを無視

## 8-8　実戦統合

サイジングテルをコアの判断に組み込む流れ：。

```
Step 1: 巻� の 簡易レンジスコア + 9 マスで基本アクション決定
Step 2: 相手タイプ判定 (第10章 HUD)
Step 3: サイジングテルで レンジ微調整
Step 4: 結果のアクション

例: 相手 BTN の 75% CBet on K72r
  Step 1: 自ハンド AJo (TPGK)、基本 後手下限確率 57% → コール寄り
  Step 2: 相手 = Nit (CB 頻度低)
  Step 3: Nit の 75% = 70-80% ナッツ → 自ハンドは負け濃厚
  Step 4: **フォールド** (後手下限 を無視)
```

Step 3の「Nitの75% = ナッツ」という情報がなければ、TPGKでコールしていた。これが1 BB/100のEV差を生みます。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: 大きいサイズほど強いハンドのサインだ。

**✅ 正解**: GTO では逆の場合もある。75% オーバーベットはブラフが多く混合されており、33% レンジベットこそが幅広いレンジで使われる。サイズの意味は相手のタイプと文脈によって異なるため、単純な「大きい=強い」の解釈は危険。

## ミニクイズ

### 問 1

**相手 BTN (タイプ Nit、VPIP 13%) が K72r で 75% CBet**。自分BBでAJo (TPGK)。アクションは？

<details>
<summary>解答</summary>

```
Step 1: 巻� 後手下限: 75% CBet に対して 後手下限確率 57% → AJo はコール対象
Step 2: 相手 = Nit
Step 3: Nit の 75% CBet = ナッツ密度 70-80%
  → 相手は KK/AA/AK/77/22/KQ のみで打っている可能性高い
  → AJo は これらほぼ全てに負ける
Step 4: 後手下限 を無視して **フォールド**
```

**答え: フォールド**

Nit相手では後手下限ラインより相手のレンジ質を優先。対戦1時間で1-2 BBのEV上昇。

</details>

### 問 2

**相手 BTN (タイプ LAG、VPIP 32%) が K72r で 33% CBet**。自分BBで55（アンダーペア）。アクションは？

<details>
<summary>解答</summary>

```
Step 1: 33% CBet の 後手下限確率 = 75% → 広く防衛
Step 2: 相手 = LAG、ブラフ頻度高い
Step 3: LAG の 33% CBet = ブラフ比率 40-50%
  → 相手の約半分がブラフ (A ハイ、ブロッカー付きエアー)
  → 55 はそれらに勝つ
Step 4: **コール**
```

**答え: コール**

LAG相手では後手下限ラインをやや緩めて広くコールしてブラフキャッチ。55は弱TP相当の扱い。

</details>

### 問 3

**相手 CO (タイプ不明、まだ観察 3 ハンドのみ) がフロップ J95r で オーバーベット (ポット 120%)**。自分BTNでTT（オーバーペア）。アクションは？

<details>
<summary>解答</summary>

```
Step 1: オーバーベットの 後手下限確率 = 40-45%
Step 2: 相手タイプ不明 (3 ハンドでは判定不能)
Step 3: オーバーベットは一般的に V:B 比 1:1 (ナッツ + 完全ブラフ)
  - ナッツ: JJ (セット)、99 (セット)、55 (セット)、J9 (2 ペア) = 約 10 コンボ
  - ブラフ: KQ (オーバー + ガットショット)、AT, A5 等 = 約 10 コンボ
  TT は ナッツ 10 に負け、ブラフ 10 に勝ち
  エクイティ: 50%
Step 4: **境界、コール寄り**
  ただし相手タイプ不明なのでフォールドも正当化
  観察を 5-10 ハンドに伸ばすまで タイトに対応する戦略が合理的
```

**答え: 境界判断、タイプ判明までタイト (フォールド寄り)**

オーバーベットは情報が極ポラライズ。タイプがわかるまでは防衛的に。

</details>

**【GTOとのズレ】**

本章の 16 パターン（4 サイズ × 4 タイプ）の示唆は、人間プレイヤーがサイズに偏りを持つことを前提にしています。GTO はそもそも各サイズで V:B 比を理論的に固定するため、「サイズからレンジを読む」こと自体が成立しません。本章の手法は「相手が GTO から外れている」という前提に依存しており、その前提が崩れる相手（経験豊富なソルバー派）には効きません。

ズレが大きいのは、TAG タイプの 50% CBet や 75% CBet です。TAG は GTO に近いため、サイズからの情報量が小さく、本章の表で「V:B 比 2:1」と推定しても実際は 1.8:1 から 2.3:1 の範囲で揺れます。一方 Nit や Fish の極端なサイズ（オーバーベット）では本章の示唆がよく効き、ナッツ密度 90% という推定が 1 BB/100 の EV 差を生みます。

実戦では、本章のサイジングテルを「相手のレベルが 2 以下のとき」に限定して使うのが安全です。サンプル 5 回以上で傾向を確認してから採用し、相手のレベルが上がってきたと感じたら、サイズ情報を切ってベースライン（簡易レンジスコア）に戻すのが鉄則です。
