## 読者ペルソナ別の読み方

- **A (中級ステップアップ組)**: ベイズ更新の式は覚えなくてよい。簡易式 (アクション前コンボ × 頻度) だけ理解する。
- **B (ソルバー派)**: 7-3 節のサイズ別レンジ示唆を定量的に内在化し、V:B 比の連鎖を追跡する。
- **C (ライブベテラン)**: 7-7 節の「20 秒ベイズ更新」手順を実戦で使う。数式の理解は不要。

## 巻2 からのブリッジ

巻2 第18章では「CBetサイズ → 相手の HandScore帯（H1/H2/H3）を大まかに読む」という入門的な逆読みを学びました。75% CBet → H3中心、33% CBet → H2中心、チェックバック → H1中心という3区分です。

本章はその**精密版**です。

- 「相手がCBetした」→ 相手のレンジが「CBetするハンド」の確率分布に絞られた
- 「相手がチェックした」→ 相手のレンジが「チェックするハンド」の確率分布に絞られた

この絞り込みを**ベイズ更新**と呼び、本章では4サイズ区分・連鎖更新を含む実戦形式で扱います。

---

## 7-1　ベイズ更新の基本式

### 理論的な式

```
事後確率 P(ハンド | アクション) = P(アクション | ハンド) × P(ハンド) / 正規化定数
```

読み下すと：。

```
「相手があるアクションを取った後、その相手が特定のハンドを持っている確率」
 = 「相手がそのハンドでそのアクションを取る確率」 × 「相手がそのハンドを持っていた元の確率」
   / 全体の正規化
```

### 実戦での簡易化

ポーカーの実戦では、上記を3つの数字で計算します。

```
アクション後のレンジ = アクション前のレンジ × アクション頻度 / 全体のアクション頻度
```

**例**: BBのレンジが500コンボ、CBet 50% する場合：。

```
BB の CBet レンジ = 500 × 0.50 = 250 コンボ
BB のチェックレンジ = 500 × 0.50 = 250 コンボ
```

これだけ。「相手がどのハンドでCBetするか / チェックするか」の知識があれば、250コンボを特定できます。

## 7-2　CBet してきた相手のレンジ更新

### 例: BTN が K72r で CBet 75%

BTNのオープンレンジ（660コンボ）から、フロップ突入直後のレンジは約600コンボ （ボードと衝突して減少）。

**CBet するハンド**:

- セット (KK, 77, 22): 9コンボ
- TPTK (AK): 12コンボ
- TPGK (KQ, KJ): 32コンボ
- オーバーペア (AA): 6コンボ
- アンダーペア (QQ, JJ): 12コンボ
- 強ブラフ（A♠Q♠, A♠J♠ のBDFD）: 6コンボ
- 弱ブラフ（そのほかの空振り + BDFD）: 20コンボ

合計CBetレンジ： **約 100 コンボ**（全体600の17%）

待って、これではCBet頻度が低すぎる。実測ではK72rでBTNは91% CBetする。計算を見直す。

### 正しい計算: 巻2 第8章 簡易レンジスコア の頻度から逆算

K72rは簡易レンジスコアで85%（高頻度）。

```
CBet レンジ コンボ数 = 全レンジ × 簡易レンジスコア 頻度
                  = 600 × 0.85 = 510 コンボ
```

つまりBTNは600コンボのうち **510 コンボで CBet** する。残り90コンボがチェック。

### CBet レンジの内訳

510コンボの内訳：。

- **バリュー**: セット + TP + オーバーペア = 80コンボ
- **中強度**: アンダーペア + ブロッカー付き空振り = 150コンボ
- **ブラフ**: BDFD + 弱ハンド = 280コンボ

### チェックレンジの内訳

90コンボの内訳：。

- トラップ（モンスター）: セットの一部 (3-5コンボ）
- 強オーバーペア（まれ）: AAの一部 (1-3コンボ）
- 弱ハンド（完全エアー、ブロッカーなし）: 残り80+ コンボ

**チェックレンジの 85% は弱ハンド**。チェックした相手からはほとんど価値が取れない。

## 7-3　サイジング別のレンジ示唆

CBetのサイズ（33%/50%/75%/オーバーベット）で、示唆されるレンジの質が違います。

### 33% CBet (レンジベット)

```
意図: 広いレンジから薄く打つ (range bet)
レンジ構成: バリューと中強度とブラフの混合
  バリュー 15%、中 40%、ブラフ 45%
特徴: ブラフが多い、ナッツ密度低い
対抗: ブラフキャッチで広くコール、後手下限確率 75% を満たす
```

### 50% CBet (中庸)

```
意図: バリューとドロー保護の両立
レンジ構成: バリュー強調、ブラフ 30-35%
特徴: 大きめサイズ、やや polarized
対抗: 後手下限確率 67%、境界ハンドはコール
```

### 75% CBet (大サイズ)

```
意図: ポラライズ (ナッツ + 完全ブラフ)
レンジ構成: バリュー 55%、ブラフ 30-40%
特徴: 中強度ハンドが少ない、V:B 比 1.5:1-2:1
対抗: 後手下限確率 57%、TPWK は微妙、TPGK 以上でコール
```

### オーバーベット (100%+)

```
意図: 極めてポラライズ (ナッツ以外 = 純粋ブラフ)
レンジ構成: バリュー 40-50%、ブラフ 50-60%
特徴: 中間ハンドほぼなし
対抗: 後手下限確率 50%、ナッツブロッカー + プライムキャッチャーで防衛
```

### 例: K72r で 33% CBet と 75% CBet の違い

**33% CBet のレンジ**:

- バリュー（セット + TPTK）: 21コンボ
- 中強度（AA, QQアンダーペア、 K-TP）: 80コンボ
- ブラフ（BDFD, Aブロッカー）: 150コンボ
- 合計： **251 コンボ**、ナッツ密度約8%

**75% CBet のレンジ**:

- バリュー: 21コンボ
- 中強度： 30コンボ（TPGKのみ）
- ブラフ： 50コンボ
- 合計： **101 コンボ**、ナッツ密度約20%

同じ相手、同じフロップでも、**サイズでナッツ密度が 2.5 倍違う**。これがサイジングテルの基礎（第8章で深掘り）。

## 7-4　チェック後の絞り込み

「相手がチェックした」という情報も、レンジを絞ります。

### チェックすべきハンド

標準的なチェックレンジは：。

- **強ハンドの一部 (R5 適用、第2章参照)**: ナッツセット、モンスター
- **中強度の一部**: 弱TP、ミドルペアの一部
- **弱ハンド全般**: ブロッカー弱いエアー、BDFDなし

### チェックレンジの強弱分布

K72rでBTNがチェックした場合（90コンボ）:。

```
ナッツ (R5 トラップ): 5 コンボ (5%)
中強度 (弱 TP、ミドルペア): 15 コンボ (17%)
弱ハンド: 70 コンボ (78%)
```

**78% は弱ハンド**。つまりBTNがチェックしたらBBは広くブラフできる（相手の78% が弱い）。

### プロービング (次ストリートでのベット)

次のターンでBBがベット（ドンクベット / プローブベット）すると、相手の弱ハンドからフォールドを取れる可能性が高い。これが「**IP がチェック → OOP がプローブ**」の定量的な理論。

---

## 7-5　チェックレイズの示唆

相手がCBetに対してチェックレイズすると、レンジが劇的に絞られます。

### チェックレイズのレンジ構成

```
バリュー (V): セット以上、ナッツレベル
ブラフ (B): ドロー + セミブラフ、完全ブラフは少ない

典型的な V:B 比: 2:1 (BB 側から)
  バリュー: セット 6-8 コンボ、トップ 2 ペア 6 コンボ (ボード依存)
  ブラフ: ナッツドロー (FD+OESD) 4-6 コンボ
```

### 例: K72r で BB がチェックレイズ

```
BB の CBet コールレンジ (BTN の 75% CBet に対して) = 250 コンボ
このうちチェックレイズに回すのは: 約 5-10% = 15-25 コンボ

  バリュー: KK (6 − 3 = 3)、77 (3)、22 (3) = 9 コンボ
  ブラフ: AQ♠ (4)、AJ♠ (4) = 8 コンボ
```

V:B比9:8 ≈ 1.1:1、思ったよりブラフ比率が高い（K72rではバリューが少ないため、ブラフを多めに入れてバランスする）。

### チェックレイズ後の対応

自分のハンドがTPTK (AK) の場合：。

- バリュー 9コンボに負けor同等
- ブラフ8コンボに勝利
- エクイティ： 9 × 20% + 8 × 80% = 8.2 ≈ 48%（一勝一敗の境界）

**境界判断**: コールするかフォールドするか。相手タイプ次第で決まる（R6、第10章）。

## 7-6　連鎖的なベイズ更新

フロップでレンジが絞られたあと、**ターン**でもさらに絞られます。

### 例: K72r フロップ → ターン Q

フロップBTN CBet 75% → BBコール
フロップ時点のBBレンジ： 250コンボ（CBetをコールしたハンド）

ターンでQが開く：。

**BB のターンアクション**:

- CBet継続（バレル）: 約40-50% でBBはチェック、BTNが再CBet
- ターンチェック： BBレンジの60-70% は弱化（Qオーバーカードで）

ターンでのBBの「コール」レンジはさらに絞られ、最終的にリバーで80コンボ程度になります。

### 情報のカスケード

各ストリートで40-50% ずつ絞り込まれるため：。

- フロップ突入： 500コンボ
- フロップCBetコール： 250コンボ
- ターン継続コール： 130コンボ
- リバーコール： 70コンボ

**4 ストリートで 500 → 70 (14%)** まで絞り込まれる。これが実戦で「相手のハンドがだんだん見えてくる」感覚の定量化。

## 7-7　実戦での 20 秒ベイズ更新

フロップで相手がCBetしてきたら、20秒で次を計算：。

```
Step 1: プリフロップの相手レンジ (第6章) = X コンボ
Step 2: CBet 頻度 (簡易レンジスコア 予測) = Y% → CBet レンジ = X × Y コンボ
Step 3: CBet レンジの内訳 (V:B 比を推定)
  - バリュー (セット + TP + オーバーペア): コンボ数
  - 中強度 (アンダーペア + 弱 TP): コンボ数
  - ブラフ (BDFD + オーバーカード): コンボ数
Step 4: 自分のハンドが相手のレンジに対して どのエクイティを持つか
```

### 具体例: BTN オープン、BB コール、K72r、BB が 33% リード (ドンク)

```
Step 1: BB のレンジ = 730 コンボ
Step 2: BB のリード頻度 = 通常稀、5-10% → 約 50 コンボ
Step 3: BB のリードレンジ内訳
  - バリュー: KK (3)、22 (3) = 6 コンボ
  - ブラフ: ストレートドロー、FD 外れ = 15-20 コンボ
  - 中強度: 7-TP = 5 コンボ
  - 合計 約 30 コンボ
Step 4: 自分が AK (TPTK) なら、相手の 30 コンボに対して
  - セット (6 コンボ) に負け
  - それ以外 (24 コンボ) に勝ち
  - エクイティ: 6 × 0% + 24 × 90% = 22/30 ≈ 73%
```

BBのドンクに対してAKはエクイティ73%、コールまたはレイズが妥当。

## 7-8　巻2 との接続

本章のベイズ更新は、巻2の後手下限計算と組み合わせます。

### 後手下限 の精密化

後手下限 は「どの程度守ればブラフに搾取されないか」の理論値。本章のベイズ更新で「相手のベットレンジのV:B比」を出せば、後手下限ライン を必ず満たすハンドを選別できます。

### 例: K72r で相手が 33% CBet、後手下限確率 75%

```
相手の CBet レンジ 250 コンボ中:
  - バリュー 80 (32%)
  - ブラフ 170 (68%)

自分の防衛レンジ: 730 × 75% = 547 コンボ (後手下限)
  → 広くコール、弱ハンドでもブラフキャッチ
```

相手のブラフ68% は高め。後手下限ラインを厳守すれば +EV。

---

## 7-9　ベイズ更新の限界

### 1. 相手のレンジモデルの精度

「相手はCBetレンジにAA-JJを含む」という前提が間違っていれば、計算結果も狂う。相手タイプ（第10章）による調整が必要。

### 2. 混合戦略の扱い

GTOは「AAを70% CBet、30% チェック」などの混合。自分のモデルが決定論的だと、実測とズレる。

### 3. サンプル数

1ハンドの観察でレンジを絞ると誤差が大きい。数十ハンド観察して傾向を掴む必要がある（第10章HUD統計、第13章メタゲーム）。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: チェックしてきた相手は弱い。

**✅ 正解**: チェックレンジの約 85% は確かに弱ハンドだが、残り 15% にセットなどのトラップが混ざる。チェックされたからといって無条件に強くベットすると、この 15% に対して大きな EV ロスを被る。

---

## 章のまとめ

- ベイズ更新 = アクション前のレンジ × アクション頻度
- K72rでBTNは600 → 510コンボに絞り込まれる (CBet 85%)
- CBetサイズ (33%/75%) でナッツ密度が2.5倍違う
- チェック後のレンジは78% が弱ハンド → プローブ推奨
- チェックレイズはV:B比1:1-2:1、コール境界はタイプ次第
- 4ストリートで500 → 70コンボ (14%) まで絞り込み可能
- 実戦では20秒でStep 1-4を実行

次章（第8章サイジングテル）では、相手のサイズ選択から漏れる情報を読み解きます。

## ミニクイズ

### 問 1

**相手 BTN がオープン (レンジ 600 コンボ)、BB が Q83ss で 50% CBet**（簡易レンジスコア中頻度帯、55% 程度の頻度と仮定）。BTNのCBetレンジのコンボ数は？

<details>
<summary>解答</summary>

```
CBet レンジ = 600 × 0.55 ≈ 330 コンボ
```

**答え: 約 330 コンボ**

残り270コンボがチェック。Q83ssではウェット寄りなので、CBetレンジはややポラライズ（セット + ブラフ + TPGK）で構成される。

</details>

### 問 2

**相手 BB が K72r で 75% CBet**。BBのレンジが730コンボ、CBet頻度が28%（OOP側）のとき、CBetレンジのナッツ （セット） 密度は？

<details>
<summary>解答</summary>

```
CBet レンジ = 730 × 0.28 ≈ 205 コンボ

ナッツ (セット):
  - KK: 6 - 3 = 3 (BB が KK を 3bet せずコールしてる前提)
  - 77: 3
  - 22: 3
  合計 9

ナッツ密度: 9 / 205 ≈ 4.4%
```

**答え: ナッツ密度 約 4.4%**

BBのCBetはOOPなのでバリュー薄く、主にブロッカー付きブラフ（K7s、A♠Q♠ 等）が多い。BTNはこのCBetに対して幅広くコール/レイズで対応できる。

</details>

### 問 3

**K72r で BB がチェックレイズ**。BBのフロップ ディフェンス レンジ500コンボ中、CR頻度が8% のとき、CRレンジのバリュー:ブラフ比が2:1なら、それぞれのコンボ数は？

<details>
<summary>解答</summary>

```
CR レンジ全体 = 500 × 0.08 = 40 コンボ

V:B 比 2:1 → バリュー 2/3、ブラフ 1/3
  バリュー: 40 × 2/3 ≈ 27 コンボ (セット + TPTK 級)
  ブラフ: 40 × 1/3 ≈ 13 コンボ (FD, BDFD, ストレートドロー)
```

**答え: バリュー 27、ブラフ 13**

BBのレンジ全体の8% しかCRしないが、そのうち2/3がバリュー。コール境界はタイト（TPTK以上でコール、TPGK以下は慎重）。

</details>

**【GTOとのズレ】**

本章のベイズ更新は「アクション前のレンジ × アクション頻度」で事後レンジを近似します。GTO が出力する事後レンジは、ハンドごとに異なる混合頻度（AAは70% CBet、KKは100% CBetなど）で計算されており、私たちの式は全ハンドを同じ頻度で扱う点で粗くなります。K72r の CBet レンジ 510 コンボという推定も、実際は ±50 コンボの誤差を含みます。

ズレが大きく出るのは、混合戦略が密に使われる境界ハンドです。AA や KQ のように「CBet と チェック を 50/50 で打ち分ける」ハンドは、本章の式では片方に寄せた推定になり、相手のチェックレンジ内のセット密度を 5% と読んでいたら実は 12% だった、という誤差が起きます。チェックレイズ後の V:B 比 1:1 という推定も、実際は 1.3:1 から 0.7:1 の幅で揺れます。

実戦では、本章の事後レンジを「中央値の推定」と捉え、ナッツ密度を ±5% の幅で見積もるのが安全です。境界判断（TPGK でコールかフォールドか）では、相手タイプ（第10章 E 補正）を加味してから決めると、ベイズ更新の誤差を吸収できます。
