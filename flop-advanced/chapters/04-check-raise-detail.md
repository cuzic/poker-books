# 第04章　チェックレイズ詳細

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: ボードテクスチャ別にチェックレイズの適切な頻度と対象ハンドを判断できるようになる。

---

巻②の第08章でチェックレイズ（CR）の骨格を学びました。
本章ではその内容をさらに深掘りし、「どのボードでどの頻度で」「どのハンドを使って」CRを打つかを整理します。

---

## 4-1　CR の基本メカニズムを再確認する

CR とは、OOP（アウトオブポジション）のプレイヤーがフロップでチェックし、IP（インポジション）のCBetに対してレイズを重ねるアクションです。

この流れを図解すると次のとおりです。

```
OOP: check
IP:  bet（CBet）
OOP: raise ← これがチェックレイズ
```

CR には2つの目的があります。

**目的1——バリューの最大化**：セット・2ペアなど強いハンドを持つとき、CRでポットを膨らませます。IP にチェックバックされるとターンまでアクションが遅れますが、CR ならそれを防げます。

**目的2——ブラフ（半ブラフ）**：フラッシュドロー（FD）や OESD（オープンエンドストレートドロー）を持つとき、CR を打つことで IP の CBet を牽制しつつ、エクイティが残っているためフォールドしても損害が小さくなります。

2つの目的を同時に達成できるボード、具体的にはウェットな 2トーンやコネクテッドボードで CR は最も効果的に機能します。

---

## 4-2　標準 CR サイズとポットへの影響

CR の標準サイズは「IP のベット額の3倍」です。

SRP（シングルレイズドポット）での例を示します。

```
【フロップ pot=6bb、IP が33%（2bb）CBetした場合】

  OOP CR to 6bb（= 3 × 2bb）
  ポット: 6 + 2 + 6 = 14bb
  IP の追加コール: 6 − 2 = 4bb
  IP のポットオッズ: 4 ÷ (14 + 4) ≒ 22%

【IP が75%（4.5bb）CBetした場合】

  OOP CR to 13.5bb（= 3 × 4.5bb）
  ポット: 6 + 4.5 + 13.5 = 24bb
  IP の追加コール: 13.5 − 4.5 = 9bb
  IP のポットオッズ: 9 ÷ (24 + 9) ≒ 27%
```

CR後のポットオッズが22〜27%であることに注目してください。
これは IP に「エクイティ22〜27%以上のハンドでないとコールできない」という高い基準を突きつけます。
セット・2ペア・ナッツドロー複合でなければ IP は苦しい状況です。

また CR 後のスタック/ポット比（SPR）も意識しましょう。

```
33%CR後（pot=14bb）: 残りスタック ≒ 88bb → SPR ≒ 6.3（ラージ）
75%CR後（pot=24bb）: 残りスタック ≒ 80.5bb → SPR ≒ 3.4（ミディアム）
```

75%ベットへの CR では SPR が一気に下がり、ターンでほぼコミット判断が迫られます。
CR を打つ前に「ターンでどう行動するか」まで計画しておくことが重要です。

## 4-3　ボードテクスチャ別 CR 頻度の目安

CR の頻度はボードテクスチャによって大きく変わります。
これはブラフ CR の候補（FD・OESD）がボードによって増減するためです。

### ドライ rainbow（K72r, A82r タイプ）

CR 頻度の目安：GTO実測 **11〜17%**（K72r: 10.5%、A82r: 17.1%）

ドライボードでは FD や OESD が少なく、ブラフ CR の候補に乏しいです。
CR できるのは主にセット・2ペアのみとなります。
IP は「CR されたらほぼバリュー」と読めるため、CR のバリューは比較的高く、IPは慎重にフォールドを検討します。

### ウェット 2トーン（Q8c3d, J8c4d タイプ）

CR 頻度の目安：GTO実測 **14〜18%**（Q85fd: 14.4%、JT5r: 16.1%、KQTr: 17.9%）

FD と OESD がブラフ CR 候補として機能します。
IP がコールしても OOP 側にエクイティが残るため、ブラフ CR のリスクが限定的です。
バリュー CR とブラフ CR が混在する典型的な環境です。

### モノトーンボード（全3枚同スート）

CR 頻度の目安：GTO実測 **15%**（K75m: 15.1%）

フラッシュ完成ハンドとフラッシュドローの両方がCR候補に入ります。
IP は常にフラッシュの可能性を意識しなければならないため、CR への対応が難しくなります。

### コネクテッド・セミブロードウェイ（T98, JT5 タイプ）

CR 頻度の目安：GTO実測 **19〜26%**（T86r: 18.6%、987r: 25.7%）

ストレートドロー（OESD・ガットショット）がブラフ CR 候補として豊富です。
セット・2ペアのバリューにストレートドローのブラフが加わり、レンジの幅が広がります。

| ボードタイプ | GTO実測 CR% | ブラフ候補 |
|:---|:---:|:---|
| ドライ rainbow（K72r等） | 11〜17% | セット・2ペアのみ |
| ウェット 2トーン / FD | 14〜18% | FD・OESD |
| モノトーン | 15% | フラッシュ完成・FD |
| コネクテッド | 19〜26% | OESD・ガットショット |
| ペア板 high（KK7r） | 15% | セット・フルハウス |
| ペア板 mid/low（774r） | 28% | エア（trip偽装）も多用 |

GTO実測: 15ボード TexasSolver 解析（BTN vs BB、6BBポット、100BB）。

## 4-4　HS 別の CR ハンド選択

### バリュー CR（常にCR優先）

HS 85以上のハンドはほぼ常にCR候補です。

```
セット（HS 90前後）:
  → 常に CR 候補。ポット拡大を最優先する。

2ペア（HS 72前後）:
  → 常に CR 候補。ターンでボードがペアになるとフルハウスに昇格する可能性も。

フラッシュ完成（モノトーンボード）:
  → 強力なバリューとして CR 推奨。
```

### 混合戦略（CR or コール）

HS 65〜84のハンドは CR とコールを状況に応じて使い分けます。

```
TPTK+ナッツFD（HS 70〜85程度）:
  → ウェットボードでは CR が有力。ドライボードではコールを選ぶことも多い。

2ペア（SPR < 3 の場合）:
  → コミット判断に近いため、オールインを見越したCRが適切。
```

### ブラフ CR（エクイティを担保にしたブラフ）

HS 40〜64で、強いドローを持つハンドがブラフ CR 候補です。

```
ナッツFD（9アウツ、HS 50前後）:
  → ウェットボードでの代表的なブラフCR候補。
  → ターンでフラッシュが完成すれば強いバリューに転換する。

OESD（8アウツ、HS 44前後）:
  → コネクテッドボードでのブラフ CR 候補。

コンボドロー（FD+OESD、HS 65〜70程度）:
  → エクイティが高く、ほぼ常に CR 候補。バリューCRに近い扱いができる。
```

### CR を避けるべきハンド

```
弱いペア単体（HS 30程度）:
  → バリューが薄い上にブラフとしても弱い。コールかフォールドが適切。

ガットショットのみ（HS 32程度）:
  → 4アウツのみではCRのリスクに見合わない。コールで様子見が基本。
```

## 4-5　CR 後のターン計画

CR を打った後は、IP がコールした場合の「ターン計画」が重要です。

### SPR 別の行動方針

CR 後の SPR は、ターンでの行動を規定します。

```
SPR ≥ 6（33% CBetへのCR後）:
  まだ大きなポットには至っていない。
  ターンでの追加バレルやチェックレイズの余地がある。

SPR 3〜5（75% CBetへのCR後）:
  コミット判断が近づいている。
  バリューハンドは積極的にバレルし、ブラフは慎重に。

SPR < 3:
  ほぼコミット状態。強いハンドはオールインを視野に入れる。
```

### ターンカードによる計画変更

CRを打った後、ターンカードによって計画を柔軟に変える必要があります。

- **FDが完成するターン（フラッシュカード落下）**: バリューCRが引き続き有効。ブラフCRはフラッシュ否定になる可能性に注意。
- **ブランクターン（両者のレンジに影響しないカード）**: 当初の計画通りにバレルを継続するか判断する。
- **ボードペアのターン**: 相手のセット/フルハウスの可能性が増加。バリューのみ継続が原則。

CR を打つ際には、主なターンカードのシナリオを事前に頭の中で整理しておくことが望ましいです。

## 4-6　実例：ウェット 2トーンボードでの CR判断

**場面**: SRP、BB vs BTN、フロップ Q♣8♣5♦（pot=6bb）

IP（BTN）が2bb（33%）CBetを打ってきたとします。

OOP（BB）の手持ちハンドごとに判断を整理します。

```
A♣K♣（ナッツFDのみ、HS 50程度）:
  ブラフ CR 候補。フラッシュドローが9アウツあり、ターンで完成すれば強い。
  CR to 6bb が合理的。

Q♠8♠（2ペア、HS 72程度）:
  バリュー CR。セットには負けるが2ペアは十分な強さ。
  CR to 6bb で積極的にポットを大きくする。

7♣6♣（FD+OESD コンボドロー、HS 65〜70程度）:
  ほぼバリュー CR に近いコンボドロー。フラッシュ完成（9アウツ）またはストレート完成（8アウツ）の計17アウツ。
  CR to 6bb で積極的に動く。

J♣T♣（FD+オーバーカード、HS 46程度）:
  ブラフ CR 候補。9アウツのFDに加え、Jのオーバーカード価値もある。
  ウェットボードでCR可。

K♦J♦（オーバーカード2枚のみ、HS 10程度）:
  ブラフ CR の候補としては弱い。エクイティが低すぎる。
  フォールドまたは稀にコールが基本。
```

## ミニクイズ

### 問1
フロップ K♣7♦2♠（ドライ rainbow）で OOP がCRを打つ場合、主な対象ハンドはどれですか？

1. FD・OESD のブラフ候補が多い
2. セット・2ペアのバリュー CR がほぼ全て
3. どんなハンドでも均等にCRする
4. この種のボードではCRしない

### 問2
IP が33%（2bb）CBetしてきた場合、標準CRサイズ（3×）での CR後のポットはいくらですか？（フロップ pot=6bb の場合）

1. 10bb
2. 12bb
3. 14bb
4. 18bb

### 問3
ブラフ CR として最も適切なハンドはどれですか？

1. 弱いペア（ガットショットなし、HS 25程度）
2. ナッツFD（9アウツ、HS 50前後）
3. トップペア単体（FDなし）
4. ボトムペア単体

---

### 解答

- **問1**: **2**（ドライ rainbow ではFDやOESDが少なく、ブラフ CR 候補に乏しい。セット・2ペアのバリュー CR がほぼ全てとなる）
- **問2**: **3**（6bb + 2bb + 6bb = 14bb。OOP は6bb にレイズし、ポットは14bbになる）
- **問3**: **2**（ナッツFDはエクイティが高く（約36%の勝率）、CR に失敗してもリスクが限定的。これがブラフ CR の理想的な候補）

---

> **本章まとめ**
>
> - CR はバリュー CR（セット・2ペア）とブラフ CR（FD・OESD）の2種類を組み合わせて使う
> - CR 頻度はボードテクスチャに依存し、ドライ11〜17%・ウェット2トーン14〜18%・コネクテッド19〜26%（GTO実測）
> - 標準CRサイズは3×IPのベット額。CR後のポットオッズは約22〜27%
> - CR後の SPR を計算し、ターン計画を事前に立てておくことが重要
> - ブラフ CR の最良候補はナッツFD・OESD・コンボドローなど、エクイティが高いハンド

---

**【GTOとのズレ】**

実戦では CR に対して IP が過剰にフォールドするケースがあります。
このとき、本来ブラフ CR 候補ではない中位ハンド（TPTK単体など）でも CR が高 EV になる局面があります。
ただし相手がこれに気づくとコール頻度を上げてくるため、中長期的にはバリュー：ブラフのバランスを保つことが重要です。
今回示した CR 頻度の数値は 15 ボード GTO 解析の実測値（TexasSolver、BTN vs BB、6BB ポット）です。
