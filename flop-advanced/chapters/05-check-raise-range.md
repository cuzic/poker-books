# 第05章　チェックレイズレンジ構築

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: CR レンジをポーラー構造で設計し、バリューとブラフのバランスを保ちながら IP にとって対応困難なレンジを構築できるようになる。

---

前章では CR の頻度とハンド選択の基礎を学びました。
本章ではさらに進んで「CR レンジ全体をどう構築するか」という設計の視点を扱います。
レンジ設計の考え方は、個別のハンドの判断よりも一段高い視点です。

---

## 5-1　CR レンジが「ポーラー」でなければならない理由

GTO の観点では、CR レンジは**ポーラー構造**（ナッツとブラフの2極）が理想とされます。

**ポーラーとは何か**

ポーラーレンジとは、最も強いハンド（ナッツクラス）と、ブラフ（エクイティを持つドロー等）だけで構成されたレンジです。
中位ハンド（TPTK単体など）は含めないことが基本です。

```
ポーラー CR レンジのイメージ:
  上位: セット / 2ペア / フラッシュ完成  ← バリュー
  下位: FD / OESD / コンボドロー       ← ブラフ（エクイティ保持）
  除外: TPTK単体 / 中位ペア単体         ← 含めない
```

**中位ハンドを CR から除外する理由**

中位ハンド（TPTK など）を CR に含めると、IP は比較的広い「TP以上」のハンドでコールできるようになります。
レンジ全体として「CR = TP以上に弱いハンドに負けない」という強さが保ちにくくなります。

逆にポーラー化することで、IP の「コールできるハンドの平均強度」が上がり、それでも対応が難しい状況を作れます。
バリュー側は IP のコールに対して十分な勝率があり、ブラフ側はエクイティで自衛できているためです。

## 5-2　CR レンジの3層構造

CR レンジを「常時CR・混合・ブラフ」の3層に分けて考えます。

### Layer 1——常時CR（HS 85以上）

```
セット / トリップス（HS 90前後）:
  常にCR。ポット拡大が最優先目標。

2ペア（HS 72前後）:
  常にCR。コールに比べてポット構築のメリットが大きい。

フラッシュ完成（モノトーンボードで保有）:
  強力なバリューとして常にCR推奨。
```

### Layer 2——混合戦略（HS 65〜84）

```
TPTK + ナッツFD（HS 75〜90程度）:
  50%CR / 50%コール が目安の混合戦略。
  CR でポットを大きくしつつ、コールでショーダウンバリューも守る。

TPTK単体（FDなし、HS 65程度）:
  CR するメリットが薄い。コールが基本。SPR < 3 なら別途検討。
```

### Layer 3——ブラフ CR（HS 40〜64で強いドロー保有）

```
ナッツFD（9アウツ、HS 50前後）:
  ウェットボードでの第一候補。フラッシュ完成（ターン or リバー）でバリューに転換できる。

OESD（8アウツ、HS 44前後）:
  コネクテッドボードでの候補。ドライボードでは候補外。

コンボドロー（FD+OESD、HS 65〜70程度）:
  エクイティが高くほぼLayer1に近い。常にCR候補。

ナッツブロッカー+弱いハンド:
  レアケース。IP のナッツレンジを阻害できる場合の限定的な候補。
```

## 5-3　バリュー：ブラフの比率と計算

CR レンジのバランスは、IP のポットオッズと期待されるフォールド率から逆算できます。

### IP のポットオッズ

標準CR（3×ベット）後、IP が追加コールするためのポットオッズは約22%です（前章参照）。

```
IP が正しくコールするには: IP のエクイティ ≥ 22%
```

IP がこの条件を満たしてコールしてくる前提で、OOP が均衡するためには次の比率が目安となります。

### 均衡の近似

```
IP の fold 率が高い場合（例：50%フォールド）:
  ブラフ ÷ (バリュー + ブラフ) ≒ 50%
  → バリュー 1：ブラフ 1

IP の fold 率が低い場合（例：30%フォールド）:
  ブラフ ÷ (バリュー + ブラフ) ≒ 30%
  → バリュー 2〜3：ブラフ 1

実用近似: バリュー 2〜3 コンボに対してブラフ 1 コンボ
```

ドライボードでは IP が CR に対してフォールドしやすい（バリュー CR しか想定できない）ため、ブラフ CR の頻度を上げても成立します。
ウェットボードでは IP はドロー込みでコールしやすいため、ブラフ比率を下げて「強いドロー（コンボドロー・ナッツFD）のみ」にブラフ CR 候補を絞ります。

## 5-4　ブラフ CR のハンド選択優先順位

ブラフ CR 候補を選ぶ際の優先順位を明確にします。

### 優先順位1：コンボドロー（FD＋OESD）

最もリスクが小さく、エクイティが最大（約40〜50%）のブラフ CR 候補です。
失敗してもエクイティで自衛でき、成功すれば大きなポットを取れます。

### 優先順位2：ナッツFD（9アウツ）

ブラッシュ CR の定番候補です。
約35%のエクイティがあり、IP にコールされてもフラッシュ完成で挽回できる可能性があります。
ナッツFD を優先するのは、ドローが完成したとき最強の役になるためです。
非ナッツFDではターンでフラッシュが完成してもナッツに負けるリスクが残ります。

### 優先順位3：OESD（8アウツ）

約30%のエクイティがあります。
ドライボードでは OESD の数自体が少ないため、コネクテッドやウェットボードでの候補となります。

### 優先順位4：ナッツブロッカー＋弱いハンド（エア）

純粋なエアでのブラフ CR は原則として避けます。
ただしナッツブロッカー（相手のナッツハンドを妨害するカードを保有する場合）を持つ弱いハンドは、限定的にブラフ CR の候補になり得ます。

### CR ブラフから除外すべきハンド

```
ガットショット単体（4アウツ）:
  エクイティが約16%しかなくリスクに見合わない。コールまたはフォールド。

弱いペア単体（HS 25〜30程度）:
  ショーダウンバリューはあるが、CRブラフとしては薄い。コールが適切。

非ナッツFD:
  フラッシュが完成してもナッツでない可能性がある。ナッツFDより優先度が低い。
```

## 5-5　ボード別の CR レンジ調整

同じハンドでも、ボードテクスチャによってCRに含めるかどうかが変わります。

### ドライ K-high（K♣7♦2♠ タイプ）の場合

```
OOP の視点:
  CR バリュー: 77（セット）/ K7s・K2s（2ペア）/ K7o等（2ペア）
  CR ブラフ: FD なし → ガットショット（65s等）は推奨しない
  → CR はほぼバリューのみ。GTO実測 **11%**（K♣7♦2♠: cr_vs33=10.5%）

IP から見た CR レンジの読み:
  → OOP の CR = ほぼセット・2ペア。TPTK でも慎重にコール。
```

### ウェット 2トーン（Q♣8♣5♦ タイプ）の場合

```
OOP の視点:
  CR バリュー: Q8s（2ペア）/ QQ・88・55（セット）
  CR ブラフ: A♣K♣・A♣J♣（ナッツFD） / J♣9♣（OESD+FD） / 7♣6♣（コンボドロー）
  → バリュー2〜3：ブラフ1 の比率で構成可能。GTO実測 **14%**（Q♣8♣5♦: cr_vs33=14.4%）

IP から見た CR レンジの読み:
  → セット・2ペア + FD/OESD が混在。TPTK+FD 以上でコールを検討できる。
```

### モノトーンボード（K♠7♠2♠ タイプ）の場合

```
OOP の視点:
  CR バリュー: スペードでフラッシュ完成済みのハンド / セット（KK・77・22）
  CR ブラフ: スペードのFD（ナッツFD 優先） 
  → フラッシュ保有 or FD が CR の中心。GTO実測 **15%**（K♠7♠5♠: cr_vs33=15.1%）

IP から見た CR レンジの読み:
  → フラッシュ保有の可能性が高い。フラッシュなら必ずコール、それ以外は慎重。
```

## 5-6　IP 側の CR 対応戦略

OOP から CR を受けた IP は、そのレンジを読んで行動します。

IP が常にフォールドするなら、OOP のブラフ CR は利益を出し続けます。
IP が常にコールするなら、OOP のブラフ CR は損をし続けます。
均衡では IP は約50〜70%コールレートを維持します。

IP がCR に対してコールすべきハンドの目安：

```
ドライボード（CR = ほぼバリュー）:
  → TPTK 以上でコール検討（セット以外は悩む）

ウェット 2トーン（CR = バリュー + FD/OESD 混在）:
  → 2ペア以上でコール。TPTK+FD でもコール検討可。

モノトーン（CR = フラッシュ + FD 混在）:
  → フラッシュ保有なら必ずコール。それ以外はほぼフォールド。
```

## ミニクイズ

### 問1
CR レンジを「ポーラー構造」にする際、含めるべきハンドの組み合わせはどれですか？

1. セット・2ペア（バリュー）＋ TPTK単体（中位）
2. セット・2ペア（バリュー）＋ FD・OESD（ブラフ）
3. FD・OESD（ブラフ）のみ
4. TPTK 以上のハンドを全てCR

### 問2
ウェット 2トーンボードでのCRレンジにおける、バリューとブラフの近似比率として正しいものはどれですか？

1. バリュー 10：ブラフ 1
2. バリュー 2〜3：ブラフ 1
3. バリュー 1：ブラフ 2
4. バリュー 1：ブラフ 1

### 問3
ブラフ CR の優先順位として最上位になるハンドはどれですか？

1. ガットショット単体（4アウツ）
2. 非ナッツFD（9アウツだがナッツでない）
3. コンボドロー（FD＋OESD、約40〜50%エクイティ）
4. 弱いペア単体（ドローなし）

---

### 解答

- **問1**: **2**（ポーラー構造はナッツクラスのバリューとエクイティを持つブラフで構成する。TPTK単体は中位ハンドのため除外するのが基本）
- **問2**: **2**（ウェットボードでは IP がコール頻度を上げるため、ブラフを絞ってバリュー2〜3：ブラフ1が均衡に近い比率）
- **問3**: **3**（コンボドローはエクイティが最大で、失敗してもリスクが限定的。ブラフ CR 候補の中で最も安定した選択肢）

---

> **本章まとめ**
>
> - CR レンジはナッツ（セット・2ペア）＋ブラフ（FD・OESD）のポーラー構造が基本
> - 中位ハンド（TPTK単体）は CR から除外し、コールレンジに割り当てる
> - ブラフ比率の目安はバリュー2〜3：ブラフ1。IP のフォールド率に応じて調整する
> - ブラフ CR 優先順位：コンボドロー > ナッツFD > OESD > ナッツブロッカー付きエア
> - ドライボードでは CR がほぼバリューのみ、ウェットボードではブラフ混入が自然

---

**【GTOとのズレ】**

実戦では「強いハンドだから CR したい」という直感で TPTK を CR レンジに含めがちです。
しかし TPTK を CR に含めると IP は「TP 以上でコールすれば勝てる」という広いコールレンジを持てるようになります。
中位ハンドのCRは短期的に機能しても、IP がアジャストすると搾取の的になりやすい点に注意してください。
★CR レンジの詳細な GTO 比率は CR study 完了後に確認・更新予定です。
