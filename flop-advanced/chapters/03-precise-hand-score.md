## 読者ペルソナ別の読み方

- **A (中級ステップアップ組)**: ブロッカー加点 +2-5 の感覚だけ掴む。ディスブロッカーの詳細は後回しにしてよい。
- **B (ソルバー派)**: ブロッカー効果の数値 (+2.78%、-5.93%) と HandScore の加点を対応させて定量検証する。
- **C (ライブベテラン)**: 型別補正表 (3-5 節) を覚えればライブでの即判断に使える。

## 巻② からのブリッジ

巻② 第9章でHandScoreを、第5章・第10章で「強/中/弱」の3分類を学びました。HandScore は 0-100 の equity % スケールで表現します。

```
強ハンド (HS ≥ 65): TPTK, セット, オーバーペア, 完成役
中ハンド (HS 35-64): TPMK, セカンドペア強, FD単独, ガットショット, アンダーペア
弱ハンド (HS < 35):  TPWK, セカンドペア弱, ボトムペア, BDFD+Aハイ, 空振り
```

9マスマトリクスはこの3分類で運用可能。ただし境界（HS 30-35 や 60-65）に挟まったハンドを扱う場面で、3分類では情報が落ちます。

本章ではHandScoreを **連続スコア** として精緻化し、以下の3軸を加えます。

1. **ドロー加点の細分化**（フロップ FD +36、OESD +32、ナッツ性による上乗せ）
2. **ブロッカー**（相手のナッツをどれだけブロックするか、定量）
3. **ディスブロッカー**（相手のフォールドレンジを減らさないか、の逆利用）

---

## 3-1　なぜ精緻化するのか

### 「強/中/弱」3 分類の粗さ

30ボード × 169ハンドを巻②の3分類で整理すると、**同じ分類内で EV が 3-8% 違うケース** が多数現れます。

| ボード | ハンド A | ハンド B | 分類 | EV 差 |
|-------|:------:|:------:|:----:|:---:|
| K72r  | AKo | AQo+BDFD | 共に「弱」 | +5% (A ブロッカー効果) |
| T98ss | 98 | 76 | 共に「中」 | +8% (トップ vs ボトム 2 ペア) |
| J75r  | AJ (TPGK) | JT (TPTK) | 共に「強」 | +4% (キッカー差) |

3分類では **A ブロッカー** や **キッカー差** を吸収できない。この差を式に乗せるのが本章の目的です。

### 巻② と巻③ の HandScore の関係

本章の精密HandScoreは、巻② の計算を **上書きしない**。巻② の式はそのまま有効で、本章は「さらに 3-10 点を足したり引いたりする補正」を加えます。

```
精密 HandScore = 巻② HandScore + 精密ドロー補正 + ブロッカー ± ディスブロッカー + 型別補正
```

巻② の役スコア（TPTK=70, TPGK=62, TPMK=50, TPWK=45, セカンドペア=42, ボトムペア=32 等）を baseline として、本章では:

1. **ドロー加点の精密化**(ナッツドローへの上乗せ、BDFD の細分化)
2. **ブロッカーの定量化**(ナッツフラッシュブロッカー +5 等)
3. **ディスブロッカー**(逆効果として -1〜-2)
4. **型別補正**(ウェットボードでオーバーペアが弱体化する等)

の 4 観点で巻② のスコアを精緻化します。

## 3-2　ドロー加点の精密化

巻② のドロー加点表（フロップ FD+OESD +52 / OESD +32 / FD +36 / ガットショット +16 等、Rule of 4 準拠）はそのまま有効。本章では「ナッツ性」「ブロッカー特性」を加味して **+3〜+8 のオフセット**を加えます。

### 精密ドロー加点表（フロップ、Rule of 4）

| ドロー種別 | アウツ | 巻② 加点 | 精密加点 | 差分 |
|---------|:------:|:------:|:------:|:---:|
| モンスタードロー (FD+OESD+TP) | 13+TP | +52 + TP | +55 + TP | +3 |
| FD + OESD（裸、モンスター）| 13 | +52 | +52 | 0 |
| FD + ガットショット | 12 | +48 | +48 | 0 |
| OESD（裸）| 8 | +32 | +32 | 0 |
| フラッシュドロー（FD）| 9 | +36 | +36 | 0 |
| **ナッツ FD（A ハイ同スート）**| 9 | +36 | **+44** | **+8** |
| ガットショット（裸）| 4 | +16 | +16 | 0 |
| 2 オーバーカード | 6 | +24 | +24 | 0 |
| **ナッツ BDFD（A 同スート 1 枚）**| ~3 | +5 | **+8** | **+3** |
| BDFD（一般）| ~3 | +5 | +5 | 0 |
| 弱 BDFD（キッカー J 以下）| ~3 | +5 | +3 | -2 |
| BDSD（バックドアストレート）| ~3 | +2 | +2 | 0 |

注: HandScore は equity % のため、上限 100 でクランプされる。ターンでは Rule of 2 (× 2)、リバーでは 0 に切り替える。

### 主要な変更点（精密化）

1. **ナッツ FD に +8 の上乗せ**:A♠ を持っていて ♠ フラッシュドローがあれば、ナッツフラッシュ完成時の EV が 5-8% 高い（実測）。equity 換算で +8 ポイント反映

2. **ナッツ BDFD（A♠ + ボード ♠ 1 枚）に +3 の上乗せ**:ナッツブロッカーとして将来 ♠ ドロー完成時に勝てる。+8 に引き上げ

3. **弱 BDFD の控えめ加点**:6♦ を持っていて ♦ BDFD の場合、ナッツブロッカーとしての価値が薄い。+3 に下げる

4. **モンスター + TP のフル加点**:既に TPTK と FD+OESD を持つ「モンスター + TP」は +3 の加算で +55 + TP として扱う（HS 上限 100 でクランプ）

### BDFD の再定義

巻②では「BDFD = 一律 +5」でしたが、精密版では「ナッツBDFD」「TP BDFD」「弱BDFD」の3階に分けます。

- **ナッツ BDFD**: A♠ を持ち、ボード ♠ 1枚 → +8
- **TP BDFD**: K♠ を持ち、ボード ♠ 1枚 → +5
- **弱 BDFD**: 6♠ を持ち、ボード ♠ 1枚 → +3

ナッツカードがスーテッドだと価値が上がるのは、フラッシュ完成時に負けない（ナッツブロッカー）+ フォールドエクイティが上がるため。

### 精密ドロー加点のテスト

**例: AQ♠ on K♠72♦r**

- 巻②: A ハイ 25 + BDFD 5 = 30
- 精密： A ハイ 25 + ナッツBDFD 8 + Aブロッカー 2（後述）= 35

HandScore 30（弱境界）と 35（中境界）では、9マスマトリクスで別のセルに入るためアクションが変わる場合があります。

## 3-3　ブロッカーの定量

ブロッカーは「自分の2枚が、相手のナッツやトップレンジのコンボを減らす効果」。巻②では +5（ナッツブロッカー）/ +3 （上位セット） の一律加点でした。精密化では **ブロッカー対象と効果量** を分離します。

### ブロッカーの 3 分類

1. **ナッツブロッカー**（A♠ onフラッシュ可能ボード）: +5
2. **トップカードブロッカー**（A on A-highボード）: +2-3
3. **ストレートナッツブロッカー**（J onストレート可能ボード）: +2-3

### ブロッカーの定量化

30ボードの実測から、ブロッカーがEVに与える影響は：

| ブロッカー | ブロック対象 | ブロック量 | HandScore 加点 |
|---------|---------|:------:|:------:|
| A (A ハイボード) | AA/AX のTP | 25-40% 削減 | +2 |
| A♠ (♠ フラッシュ可能ボード) | ナッツフラッシュ A♠X♠ | **100%** 削減 | **+5** |
| K (K ハイボード) | KK のセット | 50% 削減 | +3 |
| J/T (JTx ストレート可能) | ナッツ AQ/Q9 | 部分削減 | +2-3 |
| セットブロッカー (手に 2 枚) | 相手のセット | 3 通り → 1 通り | +3 |

### 最大の効果: ナッツフラッシュブロッカー

ボードが **モノトーン**（3枚同スート）や **2-tone でターンにフラッシュ完成** のシナリオで、A♠ を持つ効果は劇的。

- ボードK♠ 9♠ 2♠ でA♠ 持ち → 相手のナッツフラッシュA♠X♠ コンボ0個に
- 本来6コンボあるナッツフラッシュを全消し
- ブラフの成功率が +5〜8% 上昇

→ 精密HandScoreで **+5**（巻②の +5 をそのまま、ただし重複加算なしの最大値ルールを厳格化）

### ブロッカーの判定フロー

```
Step 1: ボードがフラッシュ可能 (2-tone 以上) か?
        YES かつ A♠/K♠/Q♠ (その同スート) を持つ → +5 (ナッツ)
Step 2: ボードがストレート可能 (連続 3 枚 or 高ボード連続) か?
        YES かつ ストレートナッツのカード を持つ → +2-3
Step 3: トップカードを自分が持っているか?
        YES → +2
Step 4: 持っているセットを形成できるカードが他にあるか?
        YES → +3
```

ルール: 重複加算なし、上記の最大値のみを採用。

## 3-4　ディスブロッカー ― ブロッカーの逆利用

ブロッカーの表側は「相手のナッツを減らす」。裏側が「ディスブロッカー = **相手のフォールドハンドを減らさない**」。

### ディスブロッカーの考え方

ブラフで成功するためには、相手がフォールドしやすいハンドを多く持っている必要があります。自分が持つ2枚が、相手の「フォールドする弱い手」をブロックしないほど、**相手のフォールドレンジが豊富**なまま。

### 具体例: フラッシュボードでのブラフ

ボードK♠ 9♠ 2♠ でブラフしたい場合：

**ブラフ A**: 手にQ♠5♠（♠ 2枚持ち）

- 自分が ♠ を2枚持つ → ボード ♠ 3枚 + 自分2枚 = 5枚
- 残り ♠ 8枚、相手が ♠ ドロー（弱いフォールド候補）を持つ確率が低い
- **ディスブロッカーとして悪い**（弱い ♠ 持ちをブロック）

**ブラフ B**: 手にJ♦T♦（♠ 持っていない）

- 相手の ♠ 2枚持ち（= フォールド候補のスペードドロー外れ）を全く邪魔しない
- 相手は多くのスペード外れを持っている可能性
- **ディスブロッカーとして良い**（弱い手をアンブロック）

### ディスブロッカーの点数化

| 条件 | 精密 HandScore 補正 |
|------|:------:|
| 相手の弱い手のカードを 1 枚持つ | -1 |
| 相手の弱い手のカードを 2 枚持つ | -2 (ブラフ EV 低下) |
| 相手の弱い手をアンブロック (持たない) | 0 (基準) |

「ディスブロッカーが悪い」場合にマイナス補正を入れる、という控えめな運用にします。

### ブロッカーとディスブロッカーの二重条件

最良のブラフ候補：

```
✓ 相手のバリュー (ナッツ) をブロック
✓ 相手のフォールド候補 (弱い手) をアンブロック
```

両方満たすとEVが +8-10% 上がります。K♠92♠ でQ♠J♦（♠ のナッツに近いをブロック + ♦ で弱いドローをアンブロック）が典型。

## 3-5　型別の HandScore 補正

同じ役でも、**ボードの型によって HandScore の意味が変わる**。

### 型1 (ハイ×ドライ) での オーバーペア

K72rでJJ（オーバーペア）:

- 役 72（オーバーペア中）
- ブロッカーなし
- **型1 × 強扱い**: HandScore 72 = 強、9マスマトリクスで高頻度×強 → CBet 75%

### 型4 (ロー×ウェット) での オーバーペア

987ssでJJ（オーバーペア）:

- 役 72
- ストレート完成 (65, 76, JT) に負ける可能性あり
- **型4 補正**: HandScore 72 → 実質 47（中扱い）、9マスマトリクスで低頻度×中 → チェック

### 型別補正表

| 型 | 役スコアへの補正 | 理由 |
|:---:|:--------:|------|
| 型1 (ハイ×ドライ) | 0 | 基準 |
| 型2 (ハイ×ウェット) | -10 (強ハンドのみ) | ストレート/フラッシュに負けるリスク |
| 型3 (ロー×ドライ) | -8 (強ハンドのみ) | BB のコネクターが刺さる可能性 |
| 型4 (ロー×ウェット) | -25 (強ハンドのみ) | オーバーペア下位扱いに |
| 型5 (モノトーン) | -35 (フラッシュ未完成時) | フラッシュ完成手なら無補正 |
| 型6 (ペア + 高キッカー) | +5 (強ハンドのみ) | トリップス以上が強化される |
| 型7 (ペア、そのほか) | 0 | 基準 |

注: 補正値は HandScore (0-100 equity %) における equity ポイント。

### 補正の適用範囲

補正は **強ハンド (HS ≥ 65) のみ** に適用。中/弱ハンドは変更しない（既に低いので下げる意味がない）。

### 具体例

- 982rでQQ: 役 72、型3補正 -8 → HS 64（中境界、強寄り）→ CBet 50%（中頻度×強）
- T98ssでTT（セット）: 役 88、型4だがセットは補正対象外 → HS 88 → CBet 50%
- 987monoでAA（オーバーペア、フラッシュ未完成）: 役 78、型5補正 -35 → HS 43 （中） → チェック

## 3-6　精密 HandScore の完成式

全要素を統合した最終式：

```
精密 HandScore = 基本役スコア (0-95、equity %)
              + 精密ドロー加点 (フロップ アウツ × 4、ターン × 2、リバー 0)
              + ブロッカー (+2 〜 +5、最大値のみ)
              − ディスブロッカー (0 〜 -2)
              + 型別補正 (-35 〜 +5)
              (上限 100 でクランプ)
```

### 計算手順

```
Step 1: 巻② HandScore を計算 (基本役 + 粗ドロー加点 + 粗ブロッカー)
Step 2: ドロー種別を特定し、精密加点に差し替え
Step 3: ブロッカーを個別に評価して加点
Step 4: ディスブロッカーを個別に評価して減点
Step 5: ボード型を特定し、型別補正を加える
```

実戦ではStep 1の巻② HandScoreを出した後、Step 2-5を追加で確認する流れ。通常のプレイでStep 5まで全部やる必要はなく、**境界ハンド (HS 60-72) のみ精密化**で十分です。

## 3-7　実戦例 10 ハンド

### 例 1: AQ♠ on K♠7♦2♣ IP

```
巻② HandScore:
  役 25 (A ハイ) + BDFD 5 + A ブロッカー 2 = 32

精密 HandScore:
  役 25 + ナッツ BDFD 8 (A♠ on ♠ボード) + ♠ ナッツブロッカー 5 = 38
```

巻②では「弱境界 (32)」、精密では「中 (38)」。9マスマトリクスで高頻度×中 → CBet 33% に格上げ。

### 例 2: JT on 987ss (OESD、♠♠♦)

```
巻② HandScore:
  役 10 (J ハイ) + OESD +32 = 42

精密 HandScore:
  役 10 + OESD +32 + ストレートナッツブロッカー +2 (T は 6-7-8-9-T のナッツの一部) = 44
  型4 補正: 中ハンドなので 0
```

**HS 44 (中、強寄り)**。OESD はメイドハンド級（GTO bet 90.5%）として強扱い。型4ウェットでも積極的に bet 候補。

### 例 3: 98 on 987r (ツーペア、トップ & 2nd)

```
巻② HandScore:
  役 75 (2 ペア top + mid) = 75

精密 HandScore:
  役 75 + 型4 補正 -25 = 50
```

型4補正で **強 (75) → 中 (50)**。ストレートに負ける可能性がある状況を反映。

### 例 4: TT on 987ss (セット)

```
巻② HandScore:
  役 88 (mid セット) = 88

精密 HandScore:
  役 88 (セットは型4 補正対象外) = 88
```

セットはウェットボードでもバリューを維持。

### 例 5: AK♦ on K♠7♦2♠ (TPTK + BDFD)

```
巻② HandScore:
  役 70 (TPTK) + BDFD 5 = 75

精密 HandScore:
  役 70 + ナッツ BDFD 8 (A♦ 持ちで ♦ BDFD、ナッツ寄り) = 78
  ※ ブロッカーは BDFD 加点に内包されるため、ここでは追加なし
```

ほぼ同じ。TPTKは十分強い。

### 例 6: 98♠ on Q♠J♠8♦ (第2ペア + ナッツ FD)

```
巻② HandScore:
  役 32 (セカンドペア、キッカー 9 = J 以下) + FD 36 = 68

精密 HandScore:
  役 32 + FD 36 (ナッツ FD ではない) + 型2 補正 -10 (ハイ×ウェット、強ハンドのみ適用なのでここは 0) = 68
  ※ HS 65 以上で強寄り、型2 補正の閾値運用次第
```

ほぼ巻② と同等。**HS 68 (強境界)**。フラッシュドロー主導の準強ハンド。

### 例 7: A♠5♠ on K♠Q♠3♦ (ナッツ FD)

```
巻② HandScore:
  役 25 (A ハイ) + FD 36 + A ブロッカー 2 = 63

精密 HandScore:
  役 25 + 通常 FD 36 + ♠ ナッツブロッカー 5 + ナッツ FD ボーナス 8 = 74
  (上限 100 内)
```

**HS 63 → 74** の大幅アップ。これは強ハンド級（TPTK 並）の強さ。9マスで強扱いに格上げ。

### 例 8: KQo on 9♠8♠7♦ (2 オーバー、ガットショット)

```
巻② HandScore:
  役 20 (K ハイ) + ガットショット +16 (4 outs × 4) = 36
  ※ 2 オーバーカードは KQ vs ボード 9-8-7 で実質的にオーバーカード扱い

精密 HandScore:
  役 20 + ガットショット +16 = 36
  型4 補正: 中ハンドなので 0
  HS = 36 (中バケツ)
```

ガットショット単独で **HS 36**(中バケツ)。GTO 上の bet 頻度 63.4% と整合（TPMK の 23.5% より積極的）。

### 例 9: 77 on 7K2r (トップトリップス)

```
巻② HandScore:
  役 85 (Trips) = 85

精密 HandScore:
  役 85 + 型6 補正 +5 (ペア+高キッカー、ただし 7K2 は非ペアボード扱い) = 85
  ※ 7-K-2 はペアではないため、これはセット相当として処理
```

ペアボード上のトリップスは最強級（85-92）。

### 例 10: JJ on Q♣9♣6♣ (モノトーン、オーバーペア、フラッシュ未完成)

```
巻② HandScore:
  役 72 (オーバーペア中) = 72

精密 HandScore:
  役 72 + 型5 補正 -35 (モノトーン、フラッシュ未完成) = 37
```

モノトーンでのオーバーペアは弱く扱う。HS 37（中）で、9マスで低頻度×中 → チェック確定。

## 3-8　Ablation ― 精密化の寄与度

巻② HandScoreと精密HandScoreの精度差を、30ボード × 169ハンドで実測：

| モデル | 9 マスマトリクス との一致率 | EV ロス (BB/100) |
|-------|:------:|:---:|
| 巻② HandScore | 81% | 1.5 |
| + 精密ドロー加点 | 84% | 1.2 |
| + ブロッカー精密化 | 88% | 0.9 |
| + ディスブロッカー | 89% | 0.8 |
| **+ 型別補正 (完全版)** | **92%** | **0.5** |

精密化でEVロスが1.5 → 0.5 BB/100に減少（ゴードン・オッズ分析）。1時間100ハンドなら、**1 時間で 1 BB の EV 上昇**に相当します。

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: ディスブロッカーは相手のハンドを妨げるので加点になる。

**✅ 正解**: ディスブロッカーは**減点** (-1〜-2) になる。相手がフォールドしやすいハンドをブロックするため、ブラフ成功率が下がる。ブロッカーとディスブロッカーは逆向きの効果を持つ点に注意が必要。

---

## 章のまとめ

- 巻②の「強/中/弱」3分類（H3 ≥65 / H2 35-64 / H1 <35）は境界で情報が落ちる。精密HandScoreで 3-8 点単位の微差を拾う
- ドロー加点をナッツ性で精密化:**ナッツ FD +44 / ナッツ BDFD +8** で +3〜+8 の上乗せ
- ブロッカーを対象別に定量化。ナッツフラッシュブロッカー (A♠) は +5 の最大値
- ディスブロッカーは逆効果として −1〜−2 のマイナス補正
- 型別補正で型4ウェットのオーバーペアは HS −25（強 → 中境界へ）
- 精度: 9 マスとの一致率 81% → 92%、EV ロス 1.5 → 0.5 BB/100
- 9 マスとの一致率は精密化で 81% → 92% に上昇

次章（第4章ボード型の超細分化）では、簡易レンジスコアの7型 → 17型への拡張で、同じ型内の微差を吸収します。

## ミニクイズ

### 問 1

**フロップ: K♠Q♠4♦** で自ハンド **A♠J♦**（ナッツFD + ガットショット）。精密HandScoreを計算してください。

<details>
<summary>解答</summary>

```
役: 25 (A ハイ)
ドロー: FD 9 アウツ + ガットショット 4 アウツ = 計 12 アウツ
  → 精密「FD + ガットショット」 +48 (12 outs × 4)
ブロッカー:
  - A♠ は ♠ ナッツフラッシュブロッカー → +5 (最大値、重複加算なし)
ディスブロッカー: J♦ は ♦ を持っていない (弱いドローをアンブロック) → 0
型: 型2 (ハイ×ウェット)、補正なし (中ハンドなので)

精密 HandScore = 25 + 48 + 5 + 0 + 0 = 78 (強扱い、上限 100)
```

**答え: HS 78 (強扱い)**

巻②では役 25 + FD 36 = 61 で中境界だったのが、精密で 78 にアップ。ナッツFD + ガットショットは実は強ハンド級のEVを持つ。

</details>

### 問 2

**フロップ: 9♥8♥7♦** で自ハンド **A♦A♣**（オーバーペア）。精密HandScoreを計算してください。

<details>
<summary>解答</summary>

```
役: 78 (オーバーペア高 AA)
ドロー: なし
ブロッカー: A は相手の A をブロックするが、A-high ボードではないので 0
ディスブロッカー: ♦♣ は ♥ ボードの弱いドローをアンブロック → 0
型: 型4 (ロー×ウェット)、強ハンド補正 -25

精密 HandScore = 78 + 0 + 0 + 0 - 25 = 53
```

**答え: HS 53 (中扱い)**

型4補正でAAが中ハンド扱いに落ちる。9マスマトリクスでは低頻度×中 → チェック。

</details>

### 問 3

**フロップ: J♠9♠3♦** で自ハンド **T♦7♦**（ガットショット）。精密HandScoreを計算してください。

<details>
<summary>解答</summary>

```
役: 10 (T ハイ)
ドロー: ガットショット (4 アウツ) → +16 (Rule of 4)
ブロッカー: T はナッツストレート (KQT) のナッツブロッカー → +2-3
ディスブロッカー: 7♦ と T♦ は ♠ を持たない (相手のフラッシュドロー外れをアンブロック) → 0
型: 型2 (ハイ×ウェット、ストレート可能)、補正なし (中ハンドなので)

精密 HandScore = 10 + 16 + 3 + 0 + 0 = 29
```

**答え: HS 29 (中、弱境界)**

ガットショット単独は積極的に bet 候補（GTO 上 63% bet）。HS 29 は中バケツの下端で、9 マスの「中頻度×中」に該当し、CBet 33% が標準。

</details>

**【GTOとのズレ】**

精密HandScoreはブロッカー・ディスブロッカー・型別補正を3-25点単位で加減する離散モデルです。ナッツフラッシュブロッカーA♠ で +5、型4ウェットの強ハンドで -25 のように整数刻みで処理しますが、**GTO ソルバーは連続値で EV を扱います**。同じHS 50でもボード × 相手レンジの組合せでEVは数%単位で変動し、本書の整数加点はあくまで主要因子の捕捉が目的です。

ズレが具体的に出るのは、**複数のブロッカーが重なった場合**。A♠ + K♠ の両方を持つハンドでナッツフラッシュ100% ブロックは確実ですが、加点を「+5 + +3」で加算するか「+5 のみ（最大値）」で重複を控えめに見るかの判定が難しい。新仕様では「重複加算なし、最大値のみ」を採用しているため過大評価は抑えられますが、ボーダーケースで微妙な差が残る場合があります。また、ディスブロッカーの -1〜-2 はリバーのブラフ判断には効きますがフロップでは寄与が小さく、**ストリート別の重み**は本書では未調整です。

実戦では、精密HandScoreの値を「**±5 点の幅**」で受け取るのが安全です。HSが境界（30-40や60-70）に入ったハンドだけ詳細補正を効かせ、明確に強い（HS 80 以上）または明確に弱い（HS 25 以下）ハンドは巻②のHandScoreで十分。9マスマトリクスのセル境界を跨がない限り、整数差はアクションを変えません。
