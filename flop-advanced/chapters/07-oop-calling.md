# 第07章　OOP コーリングレンジ

> **本章のゴール**: OOP が IP の CBet に対してコールすべきかを HandScore とフォールド閾値テーブルで素早く判断し、コールレンジ全体の設計まで理解できるようになる。

巻②の第06章でフォールド閾値テーブルの基本を学びました。
本章ではその続きとして「コールレンジはどう構成するか」「後手下限確率（MDF）との関係はどうなっているか」を掘り下げます。

## 7-1　コール判断の3ステップ

OOP が IP の CBet に直面したとき、次の3ステップで判断します。

```
Step1: HandScore（HS）を計算する
  HS = 役スコア + ドロー加点 + ブロッカー加点

Step2: フォールド閾値と比較する
  閾値は「ベットサイズ × ボードテクスチャ」で決まる
  HS ≥ 閾値 → コールまたはCR候補
  HS < 閾値 → フォールド

Step3: CR 条件を確認する
  HS ≥ 40 かつ SPR ≥ 6 → CR も選択肢
  HS < 40 → コールのみ（CR は薄い）
```

Step2で「コール可」と判断したハンドの中から、さらに「CR かコールか」を Step3で分けます。

## 7-2　フォールド閾値テーブルの復習

巻②第06章で示したフォールド閾値テーブルを再掲します。

### 基本閾値（標準 rainbow ボード）

| ベットサイズ | 後手下限確率 | HS フォールド閾値 |
|:---:|:---:|:---:|
| 33%ポット | 75% | HS < 15 でフォールド |
| 50%ポット | 67% | HS < 25 でフォールド |
| 75%ポット | 57% | HS < 35 でフォールド |

### ボードテクスチャ補正（巻②第06章）

| ボードテクスチャ | 補正値 |
|:---|:---:|
| 2トーン（2スート） | +5 |
| モノトーン（全同スート） | −5 |
| ペアボード（B=71 または B=83） | −10 |

**実例の閾値計算**：

```
ボード K♣7♦2♠（ドライ rainbow）:
  vs 33%: 閾値 = 15（補正なし）
  vs 75%: 閾値 = 35

ボード Q♣8♣5♦（ウェット 2トーン）:
  vs 33%: 閾値 = 15 + 5 = 20
  vs 75%: 閾値 = 35 + 5 = 40

ボード K♣4♦4♠（ペアボード）:
  vs 33%: 閾値 = 15 − 10 = 5
  vs 75%: 閾値 = 35 − 10 = 25
```

## 7-3　コールレンジの構成要素

閾値を超えてコール（または CR）できるハンドのクラスを整理します。

### T1クラス（HS 85以上）——常にコールまたはCR

```
セット / トリップス:
  → 常にコール以上（CR推奨）。フォールドはまずない。

フラッシュ完成（モノトーンボードで5枚同スート）:
  → 常にコール以上。

2ペア:
  → 常にコール。SPR ≥ 6 なら CR も積極的に検討。
```

### T2クラス（HS 40〜84）——コール主体、CR も選択肢

```
TPTK / オーバーペア（FDなし）:
  → HS 65前後。閾値を大幅に上回る。コールが基本。
  → ウェットボードではCR も選択肢（HS ≥ 40 + SPR ≥ 6 で判断）。

FD（ナッツFD 9アウツ）:
  → HS 50前後。閾値を上回ればコール。ウェットボードでは CR も検討。

OESD（8アウツ）:
  → HS 44前後。閾値を上回ればコール。

セカンドペア + ドロー:
  → HS 40〜50程度。コールで守備継続。
```

### T3クラス（HS 10〜39）——閾値次第でフォールド多め

```
TPWK（トップペア弱キッカー）:
  → HS 30〜40程度。vs 33%なら多くの場合コール。vs 75%では閾値に引っかかりやすい。

アンダーペア / セカンドペア単体:
  → HS 20〜35程度。ドライボードでは閾値超えだが、ウェットでは慎重に。

ガットショット単体:
  → HS 32程度。vs 33%のみコール可能なことが多い。vs 75%ではフォールド。
```

## 7-4　GTO 実測値との比較

巻②の GTO 研究データから得られた fold_vs33（33%CBet に対するフォールド率）を確認します。

```
【GTO 実測データ（pot=10bb, BTN vs BB）】

K♣7♦2♠（ドライ rainbow, B=62）:
  fold_vs33 = 46.2%
  → 閾値モデルから期待: 約25%フォールド
  → 実測が大幅に高い（46.2%）

Q♣5♦3♠（Q-high rainbow, B=58）:
  fold_vs33 = 19.2%
  → 閾値モデルから期待: 約25%フォールド
  → 実測は低い（19.2%）

K♣4♦4♠（ペアボード, B=83）:
  fold_vs33 = 45.7%
  → 閾値モデルから期待: 約15%フォールド（閾値5のため）
  → 実測は高い（45.7%）

Q♣8♣5♦（2トーン, B=50）:
  fold_vs33 = 19.0%
  → 閾値モデルから期待: 約25%フォールド
  → 実測は低い（19.0%）

J♣8♣4♦（2トーン J-high, B=50）:
  fold_vs33 = 14.5%
  → 閾値モデルから期待: 約25%フォールド
  → 実測は最低水準（14.5%）
```

## 7-5　MDF 違反の解釈：なぜ K72r で BB は多くフォールドするか

後手下限確率（MDF: Minimum Defense Frequency）とは、IP のブラフが利益ゼロになる最低守備率です。

```
vs 33%ベット: MDF = 75%（= フォールド ≤ 25%）
vs 75%ベット: MDF = 57%（= フォールド ≤ 43%）
```

K♣7♦2♠での BB の fold_vs33 = 46.2% は MDF（25%フォールド以下）を大幅に超えています。
「BB が守りすぎているのか？」という疑問が湧きます。

**GTO 的な解釈**：

```
K72r ボードでの BTN のアドバンテージ:
  BTN のオープンレンジ: AA・KK・AKs・AKo など K-high が豊富
  BB の defenseレンジ: ワイドで多くの手が K に当たらない

BTN の CBet が almost 100%（B=62 → 約99%）:
  バリューハンドの密度が非常に高い
  BB がコールして勝てるハンドが少ない

→ BB のフォールドが増えるのは搾取（exploitable）ではなく、IP のナッツアドバンテージが大きいための GTO 的結果
```

MDF はあくまでも「均等なレンジ対均等なレンジ」を想定した指標です。
現実のボード × レンジの組み合わせでは、MDF を大幅に下回ったり超えたりすることがあります。

**実戦での使い方**：

```
K/A-high ドライボード（K72r, A82r）:
  BB の多くのハンドが「ただの高カード不一致」になる
  → フォールド 40〜50% でも GTO に近い可能性がある
  → 中途半端なコールを減らし、強いハンドのみ守備

Q/J-high やウェット 2トーン（Q53r, J84fd）:
  BB のレンジにドロー + 低ペアが豊富
  → フォールド 15〜20% でも MDF を守れている
  → より多くのハンドでコール継続が適切
```

## 7-6　ボード別コールレンジの実例

具体的なボードで、コールレンジを構成するハンドを整理します。

### K♣7♦2♠（ドライ rainbow）vs BTN の33%CBet

```
コール可能なハンド（HS ≥ 15）:
  KK（セット, HS 90）, K7s（2ペア, HS 78）, K2s（2ペア, HS 78）:
    → 常にコール、CR を強く検討

  AKo（TPTK, HS 65）:
    → コール（CR はドライボードでは薄い）

  77（セット, HS 85+）:
    → コール、CR を強く検討（HS ≥ 40 を大幅に超える）

  65s（OESD っぽいが 7-6-5 未完成）:
    → K72 ボードでは連続性がなくOESDは難しい。HS 10程度 → フォールド

フォールド:
  JTo（HS 10程度）: K との差が大きく→ フォールド
  52o（HS 5程度）: ほぼエア → フォールド
```

### Q♣8♣5♦（ウェット 2トーン）vs BTN の33%CBet（閾値 = 20）

```
コール可能なハンド（HS ≥ 20）:
  T♣9♣（FD + ストレートドロー複合、HS 65〜70程度）:
    → コール。CR も積極的に検討（HS ≥ 40、SPR ≥ 6）

  A♣K♣（ナッツFD + オーバーカード、HS 50程度）:
    → コール。CR ブラフ候補。

  Q♦8♦（2ペア だが スート違いのため FD なし, HS 75程度）:
    → コール。CR も選択肢。

  J♣T♣（FD + ストレートドロー、HS 46程度）:
    → コール。CR ブラフ候補。

フォールド:
  7♦4♦（HS 15程度、2トーン補正後でも閾値20未満）:
    → フォールド
```

## 7-7　CR と コールの分岐判断

コール基準（HS ≥ 閾値）を満たしたハンドのうち、どれを CR にするか。

```
CR 優先（HS ≥ 40 かつ SPR ≥ 6）:
  セット・2ペア・コンボドロー・ナッツFD:
    → バリュー CR またはブラフ CR として積極的にCR

コール（CRには薄い、HS 20〜39 程度）:
  TPWK・セカンドペア・ドロー単体（ガットショットなど）:
    → エクイティはあるが CR のリスクに対して薄い

SPR < 3 の特例:
  SPR < 3 ではCR = ほぼコミット
  → HS ≥ 75（2ペア以上）のみ CR 推奨
  → HS < 75 ならコールが無難
```

## ミニクイズ

### 問1

K♣7♦2♠（ドライ rainbow）で IP（BTN）が33%（2bb）CBetしてきました。BB の手は J♣T♣です。HS が10程度の場合、正しい判断はどれですか？

1. コール（中位ハンドなので守備すべき）
2. チェックレイズ（ブラフ CR として機能する）
3. フォールド（HS 10 < 閾値 15 のため）
4. 状況に関係なくコール

### 問2

後手下限確率（MDF）に関する記述として正しいものはどれですか？

1. MDF を下回るフォールドは全て搾取可能な間違いである
2. ナッツアドバンテージが大きいボードでは、MDF を大幅に超えるフォールドが GTO に近い可能性がある
3. 33%ベットの MDF は50%（半分を守ればよい）
4. MDF を守るには常に50%以上のハンドをコールしなければならない

### 問3

Q♣8♣5♦（ウェット 2トーン）での CR に最も適したハンドはどれですか？

1. K♦J♦（オーバーカード2枚のみ、FDなし）
2. 7♦4♦（役なし、ドローなし）
3. A♣K♣（ナッツFD + オーバーカード2枚）
4. 2♥2♦（ポケット2、HS 15程度）

---

### 解答

- **問1**: **3**（HS 10 は閾値 15 を下回るためフォールドが正解。K72r ドライボードでは BB のレンジに当たりにくく、J♣T♣はこのボードでショーダウンバリューが薄い）
- **問2**: **2**（MDF はレンジが均等な場合の理論値。IP がナッツアドバンテージを持つ高 CBet 率ボード（K72r など）では、BB が多くフォールドするのが GTO 的に正しい場合がある）
- **問3**: **3**（A♣K♣はナッツFD（9アウツ）+ オーバーカードを持つ。HS 50前後で閾値 20 を大幅に超え、ブラフ CR 候補として理想的。フラッシュ完成時に最強役になる点も重要）

---

> **本章まとめ**
>
> - コール判断は「HS 計算 → 閾値比較 → CR か コールか」の3ステップで行う
> - フォールド閾値はボードテクスチャで補正：2トーン+5、モノトーン−5、ペアボード−10
> - K/A-high ドライボードでは fold_vs33 が約40〜46%（GTO 実測）——MDF より高くても正しい
> - ウェット 2トーンでは fold_vs33 が約14〜19%——多くのドロー+ペアでコール継続が適切
> - HS ≥ 40 かつ SPR ≥ 6 のハンドは CR を積極的に検討する。SPR < 3 なら 2ペア以上のみ CR

---

**【GTOとのズレ】**

実戦では K-high ドライボードで「AQo 持っているからコールしよう」と守りすぎる傾向があります。
GTO 実測では K72r で BB の fold_vs33 が約 46% と示されており、AQo（HS 25程度）は多くの場合フォールドが正しい選択です。
「強そうなハンドだから」という直感より、HS と閾値の比較に従うことが長期的に損失を防ぎます。
