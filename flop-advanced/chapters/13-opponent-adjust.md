# 第13章　相手タイプ別エクスプロイト — フロップ攻守両面

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: GTO は「相手も最善を尽くす」前提の均衡解です。実戦の相手は必ず偏りを持ちます。本章では Fish・Station・Nit・LAG の 4 タイプの傾向を数値で捉え、IP 側（CBet）と OOP 側（ディフェンス）の両面で判断を調整する方法を学びます。

---

## 13-1　なぜ GTO だけでは EV を捨てるか

GTO（ゲーム理論的最適解）は、相手が完全に均衡戦略を取ることを前提とした解法です。しかし実戦でそのような相手はほとんど存在しません。

重要な原則は「相手の偏りを逆用しない行為が EV ロスになる」ということです。

- **Fish がフォールドしない**: GTO 基準でブラフを打ち続けると EV が損失
- **Nit がフォールドしすぎる**: GTO 基準でブラフを打たないと EV が損失

エクスプロイトとは「相手の実際のフォールド率が GTO の均衡値（α）からどれだけズレているかを捉え、その分だけ戦略を曲げる」行為です。

### α と実際のフォールド率

ブラフの損益分岐点 α は、ベットサイズによって決まります。

```
vs 33% CBet: α = 33 ÷ (100 + 33) ≈ 25%
vs 75% CBet: α = 75 ÷ (100 + 75) ≈ 43%
```

相手の実際のフォールド率が α より低ければブラフは損失（-EV）です。α より高ければブラフは利益（+EV）です。

```
ブラフ EV（簡略）:
  EV = fold_rate × pot − (1 − fold_rate) × bet_amount

Fish の fold_rate vs 33% ≈ 15%（α=25% より低い）:
  EV = 0.15 × 6 − 0.85 × 2 = 0.9 − 1.7 = −0.8bb（-EV: ブラフ禁止）

Nit の fold_rate vs 33% ≈ 65%（α=25% より高い）:
  EV = 0.65 × 6 − 0.35 × 2 = 3.9 − 0.7 = +3.2bb（+EV: ブラフ増加）
```

## 13-2　4タイプの識別指標

相手のタイプを HUD 統計（VPIP / PFR / Fold to CBet%）で識別します。

| タイプ | VPIP | PFR | Fold to CBet | 特徴 |
|:---|:---:|:---:|:---:|:---|
| **Fish** | 40%+ | 15%未満 | 40%未満 | 広く参加、ほとんどフォールドしない |
| **Station** | 35%+ | 10%未満 | 35%未満 | 何でもコール、ほぼブラフなし |
| **Nit** | 20%未満 | 15%未満 | 65%超 | タイトに参加、ベット = 強い手 |
| **LAG** | 30%+ | 25%+ | 50%未満 | 広く攻撃的、ブラフが多い |
| **Reg** | 22〜30% | 18〜25% | 45〜55% | GTO に近い標準的プレイ |

サンプルハンド数も重要です。信頼性に応じて 3 段階で調整します。

```
サンプルによるエクスプロイト調整量の目安:
  50ハンド未満:   GTO 基準を維持（統計は参考程度）
  50〜99ハンド:   小幅調整（±5 程度）。大きな方向性は掴めるが誤差が多い
  100ハンド以上: 本格的なエクスプロイト調整（±10 など上記基準を適用可）
```

---

## 13-3　Fish・Station への攻撃最適化（IP 側）

Fish と Station の共通点は「フォールドしない」ことです。この特性に対して、IP の最適戦略は「バリューを最大化してブラフを削る」です。

### ブラフを削る理由

Fish の fold_rate ≈ 15%、Station の fold_rate ≈ 20% は、どちらも α（25〜43%）を下回ります。T3 ハンドでのブラフ（pure bluff）は-EVです。打てば打つほど損をします。

### バリューサイズを上げる理由

Fish・Station はポットオッズを計算せずにコールします。相手が「コールする確率が高い」なら、バリューハンドのベットサイズを大きくすればするほど EV が増加します。

```
vs Fish の IP 戦略調整:
  T1（HS≥65）: CBet を 75% pot に拡大（バリュー最大化）
  T2（HS 30-64）: CBet 50% pot（薄いバリューも大きく）
  T3（HS<20）: CBet 禁止（fold_rate < α → 純ブラフは-EV）

vs Station の IP 戦略調整:
  T1: 75% pot（Station はポットオッズを無視する）
  T2（HS≥30）: 50% pot でも CBet（コール率が高い相手に薄く届く）
  T3: 禁止（Station はほぼコールするため pure bluff は損）
```

ターンでも同様の戦略を継続します。Fish・Station はターンでも「コールし続ける」傾向があるため、バリューバレルの EV がさらに高まります。

---

## 13-4　Fish・Station への守備最適化（OOP 側）

Fish がベットしてきた場合は「バリューが強い」シグナルです。Fish はブラフをほとんど打たない傾向があるため、CBet = 強いハンドと解釈できます。ただしプレイヤーによっては広くベットする Fish もいるため、ショーダウンデータが溜まるまでは断言せず参考値として扱ってください。

### fold threshold の引き上げ

```
vs Fish CBet（通常より fold threshold を +10）:
  vs 33% 通常のフォールド閾値 HS<15 → HS<25 でフォールド
  vs 75% 通常のフォールド閾値 HS<35 → HS<45 でフォールド

vs Station CBet（+5 の調整）:
  vs 33% 通常閾値 HS<15 → HS<20
  vs 75% 通常閾値 HS<35 → HS<40
```

Fish がベットしてきたのに TPWK（HS ≈ 40）でコールするのは、EV が薄い危険な判断です。Fish のベットに CR を打っても、Fish はフォールドしないうえに強いハンドを持つことが多いので CR も禁物です。

### チェックバックを活用する

Fish が CBet してこなければ「弱めのハンドか、もしくは何も持っていない」可能性があります。この場合、OOP は弱いハンドでもショーダウンバリューを守るためにチェックバックを誘えます。

---

## 13-5　Nit への攻撃最適化（IP 側）

Nit の fold_rate ≈ 65% は α（25%）を大幅に上回ります。ブラフ EV が高い状況です。

### ブラフ閾値の緩和とサイズの縮小

```
vs Nit の IP 戦略調整:
  T2 CBet 閾値: 通常 B≥58 → B≥53 に緩和（T2 下位も打てる）
  T3 ブラフ閾値: 通常 B≥62 → B≥55 に緩和（Nit なら dry board でブラフが通る）
  CBet サイズ: 33% pot に縮小（Nit は大サイズに対しフォールドしやすくなるが誘いにくい）
```

T1（HS≥65）も 33% に抑えるのがポイントです。Nit に大サイズでバリューを打つと、Nit はナッツ以外をフォールドしてしまい取れる額が減ります。33% で誘う方が EV が高くなります。

### Nit の CR には即フォールド

Nit が CR（チェックレイズ）または 3-bet をしてきた場合は本物の強ハンドがほぼ確実です。T1 でも安易にコールせず、TPTK 以下はフォールドを検討します。

---

## 13-6　Nit への守備最適化（OOP 側）

Nit がベットするのは強いハンドだけです。Nit の CBet = T1 相当以上と解釈できます。

```
vs Nit CBet（fold threshold +5）:
  vs 33% 通常閾値 HS<15 → HS<20
  vs 75% 通常閾値 HS<35 → HS<40
  CR 閾値: HS≥80 のみ（ナッツ相当でないと CR は危険）
```

Nit がチェックしてきた場合は逆に「弱いハンドか、あるいは待ち伏せ（トラップ）」の 2 択です。どちらの場合も、OOP はターンのアクションまで情報収集を優先します。

---

## 13-7　LAG への攻守最適化

LAG は「ブラフが多い」が弱点です。最適戦略は「LAG のブラフに乗る」ことで、OOP 側での調整が特に重要になります。

### OOP（守備側）の対 LAG 調整

```
vs LAG CBet（fold threshold −10）:
  vs 33% 通常閾値 HS<15 → HS<5 程度までコール（ほとんどコール）
  vs 75% 通常閾値 HS<35 → HS<25 でコール
  CR: HS≥40 で積極的に（LAG のブラフに CR でペナルティを与える）
```

LAG のブラフに乗るため、HS=15〜40 のブラフキャッチャーとしての機能を最大化します。LAG が打ち続けてきても、HS≥20 があれば諦めずにコールを継続するのが EV 的に優れます。

### IP（攻撃側）の対 LAG 調整

```
vs LAG での IP CBet 調整:
  T3 ブラフ: 削減または禁止（LAG が 3-bet で返してくるリスク）
  CBet サイズ: 50% に抑える（LAG の逆 CR を招きにくくする）
  T1 バリュー: 通常通り打つが、LAG の CR には TPTK 以下でフォールドも検討
```

LAG はブラフも多いが、バリューの 3-bet/CR も多い相手です。IP でのブラフ削減と、バリューに対する LAG の逆攻撃への対応が合わせて必要です。

---

## 13-8　4タイプ調整表のまとめ

各タイプへの調整をまとめます。

| タイプ | IP CBet 閾値 | IP サイズ | OOP fold 閾値 | OOP CR |
|:---|:---|:---:|:---|:---|
| **Fish** | T1 のみ（T2 は HS≥30 に引き上げ） | 75% | +10 | 禁止 |
| **Station** | T1 + T2 上位（HS≥30） | 50〜75% | +5 | 通常通り |
| **Nit** | T2 拡大（B≥53）、T3 拡大（B≥55） | 33% | +5 | HS≥80 のみ |
| **LAG** | 通常。T3 ブラフは削減 | 50% | −10 | HS≥40 で積極的 |

注意点として、相手のサンプルが 50 ハンド未満の場合は GTO 基準を維持します。50〜99 ハンドでは ±5 程度の小幅調整にとどめます。100 ハンド以上が揃ってから上記の ±10 調整を適用します。統計の信頼性が低い段階でエクスプロイトを大きく振りすぎると、誤読のコストが大きくなります。

> **非対称な調整幅の根拠**: Fish の OOP fold 閾値が +10、Nit が +5 という非対称性は、偏りの大きさに比例しています。Fish の fold_rate ≈ 15% は α（25%）より 10pt 低く、ブラフが大きなマイナスになります。Nit の fold_rate ≈ 65% は GTO 均衡（約 50%）より 15pt 高いものの、Nit に対してはブラフを増やす方向（攻撃側）の調整が主軸であり、OOP 側守備は +5 の小幅調整で十分です。LAG の -10 は「広くコールする」方向への対応で、fold_rate ≈ 45% が α（25%）より高い（まだブラフが通る）ためキャッチャーとして機能します。

## ミニクイズ

### 問1

Fish（VPIP=45%、Fold to CBet=18%）と対戦中です。
IP からフロップで T3 ハンド（HS=12）で CBet を打つことを検討しています。
最も適切な判断はどれですか？

1. Fish はフォールドしないためブラフは-EV。CBet は打たない
2. Fish は判断力がないためどんなサイズでも CBet が+EV
3. 33% の小サイズなら Fish 相手でもブラフが成立する

### 問2

Nit（VPIP=17%、Fold to CBet=70%）と対戦中です。
IP で T2 ハンド（HS=40、B=56）を持っています。
通常の判断では「B < 58 のためチェック」ですが、Nit 相手での最適な判断はどれですか？

1. 通常通りチェックバックする（Nit でも CBet 閾値は変わらない）
2. Nit の fold_rate が高いため、33% CBet が+EV になる可能性がある
3. Nit 相手では 75% の大サイズ CBet が最も EV が高い

### 問3

LAG（VPIP=35%、PFR=28%）が IP から 75%（4.5bb）CBet を打ってきました。
OOP のハンドは HS=25（TPWK 程度）です。通常のフォールド閾値は「HS<35 でフォールド」ですが、対 LAG での適切な判断はどれですか？

1. 通常通り HS=25 < 35 のためフォールド
2. LAG は fold threshold を −10 調整するため、HS=25 はコール候補になる
3. LAG 相手では HS に関係なくすべてのハンドをコールすべき

---

### 解答

- **問1**: **1. CBet は打たない** が正解。Fish の fold_rate ≈ 18% は α（25%）を下回るため、ブラフの EV は負になります。T3 の pure bluff は Fish 相手では打つほど損をします。
- **問2**: **2. 33% CBet が+EV になる可能性がある** が正解。Nit の fold_rate ≈ 70% は α（25%）を大幅に上回ります。通常の CBet 閾値 B≥58 を B≥53 に緩和することで、T2 下位でも CBet が正当化されます。ただし 75% 大サイズは Nit がフォールドしてしまい、誘いの効果が薄れます。
- **問3**: **2. LAG は fold threshold を −10 調整するため、HS=25 はコール候補になる** が正解。LAG の fold_rate は低く、ブラフも多いため、通常より広くコールする方が EV が高まります。ただし全ハンドをコールするのは過剰調整です。

---

> **本章まとめ**
>
> - エクスプロイトとは「相手の fold_rate が α から外れた量を、戦略の調整量に変換すること」。
> - Fish・Station：IP はバリューサイズを 75%+ に上げてブラフを削除。OOP は fold 閾値を+10。
> - Nit：IP はブラフ閾値を緩めサイズを 33% に縮小。OOP は Nit の CR に対して即撤退。
> - LAG：OOP は fold 閾値を−10 にして広くコール・積極的な CR。IP はブラフを削減。
> - サンプル目安: 50ハンド未満→GTO維持 / 50〜99→小幅調整(±5) / 100以上→本格調整(±10)。

---

**【GTO とのズレ】**

エクスプロイト調整の数値（±10 など）はあくまで実戦的な目安です。GTO では相手タイプが変わっても均衡戦略を保つのが理論的な最善ですが、そのためには相手のレンジを完全に把握する必要があります。実戦では不完全な情報の中でエクスプロイトを行うため、過剰調整によって逆にエクスプロイトされるリスクもあります。Nit に大量のブラフを打ち続けると、Nit がトラップを始める可能性があります。調整量は控えめ（±5 程度）から始めて観察することを推奨します。
