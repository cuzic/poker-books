## 読者ペルソナ別の読み方

- **A (中級ステップアップ組)**: レベル 0-3 まで理解する。レベル 4 以上は封印し、FPS を防ぐ 13-7 節を最優先で読む。
- **B (ソルバー派)**: 古典理論 (Sklansky, Harrington) の引用と実戦例をつなげて精緻化する。
- **C (ライブベテラン)**: 長期的なヘッズアップや固定メンバーのリングゲームでメタゲームを実践する。13-6 節の 6 例を活用する。

## 巻② からのブリッジ

巻②では「自分のハンド」と「相手のレンジ」の2つの情報で判断しました。本章では、**3 つ目の軸** ―「**相手が考える自分のレンジ**」を導入します。

相手との長期対戦では、あなたのプレイスタイル（タイト / ルーズ、ブラフ多 / 少）が相手に**イメージ**として認知されます。このイメージを利用（または逆手に取る）のがメタゲームです。

---

## 13-1　メタゲームの定義とレベル

### メタゲームとは

```
メタゲーム = 「相手との長期的な関係性の中で、戦略を動的に調整する枠組み」

GTO = 「守備の均衡」
メタゲーム = 「相手の均衡からの逸脱を攻撃するオフェンス」
```

### レベル 0-4+ の階層

```
レベル 0: ランダムプレイ (思考なし)
レベル 1: 自分のハンドだけで判断 (初心者)
レベル 2: 相手のハンド/レンジを推定して判断 (中級)
レベル 3: 相手が自分のハンドをどう推定しているかを考慮 (上級)
レベル 4: 相手が「自分がそう考えている」と考えているかを考慮 (プロ)
レベル 5+: 無限に深くなる (迷走の原因)
```

### 標準的プレイヤーの分布

```
レベル 0-1: 初心者、Fish (60% の相手)
レベル 2: 中級、TAG (30% の相手)
レベル 3: 上級 (8% の相手)
レベル 4+: プロ (2% の相手、プロ対戦のみ)
```

**多くの相手 (低レート) はレベル 2 以下**。レベル3以上のメタゲームは高レート・対プロ戦で意味を持ちます。

---

## 13-2　レベル調整の原則

### 原則: 相手の 1 レベル上を目指す

```
相手 レベル 0 → 自分 レベル 1 (ハンドの強さだけで対応)
相手 レベル 1 → 自分 レベル 2 (相手のレンジを読む)
相手 レベル 2 → 自分 レベル 3 (相手が自分をどう読んでいるか)
相手 レベル 3 → 自分 レベル 4 (メタメタゲーム)
```

### 1 レベル上を目指す理由

- 相手より1レベル上： 相手の思考を超えられる
- 相手より2レベル以上上： 過剰、相手が追いつけないので逆手に取られる
- 相手と同レベル： 均衡、どちらも搾取できない

### 典型例

**例 1: レベル 1 相手 (Fish)**

```
相手: 「自分の AA でコールする」
自分のレベル 2: 「相手は A を持ってるから CBet で引き下げる」
自分のレベル 3 は不要: 相手は「自分が AA を持ってるのを相手は知っている」と考えない
→ レベル 2 で十分
```

**例 2: レベル 2 相手 (TAG)**

```
相手: 「自分のレンジは 60% で、これくらい」
自分のレベル 3: 「相手は自分のレンジを 60% と見ている、だからブラフ込みで 70% まで押せる」
```

## 13-3　履歴に基づくイメージ構築

長期対戦で、自分のプレイスタイルが相手に「イメージ」として定着します。

### タイトイメージ

```
過去 100 ハンドで:
  - ショーダウン: プレミアムハンドばかり
  - 4bet を ほぼしない
  - ブラフはキャッチされない

→ 相手のイメージ: 「このプレイヤーはタイト、ブラフしない」
```

### タイトイメージの利用

```
ブラフの成功率が上がる:
  - 3bet ブラフで相手がフォールド
  - CBet で相手がフォールド
  - オーバーベットが効く
```

### ルーズイメージ

```
過去 100 ハンドで:
  - ブラフが複数回キャッチされる
  - プレミアムでないハンドでショーダウン
  - アグレッシブにプレイ

→ 相手のイメージ: 「このプレイヤーはルーズ、ブラフ多い」
```

### ルーズイメージの利用

```
バリューが上がる:
  - 相手はコールしやすい
  - バリューを厚く取れる
  - オーバーベットバリューも機能
```

## 13-4　ブラフ露見後の 3 パターン

ブラフが見破られ、相手がコールしてあなたが負けた場合：

### パターン A: 露見を活かす (タイト化)

```
ブラフ露見 → 次のハンドから タイト化
  - CBet を減らす
  - 3bet も減らす
  - 相手: 「このプレイヤーはブラフで負けた後、締めてくる」と予測

→ 自分: その先で ブラフ再開 (相手が油断している)
```

### パターン B: 逆張り (さらにブラフ強化)

```
ブラフ露見 → さらに ブラフ増
  - 次のハンドも CBet
  - 3bet ブラフ継続

→ 相手: 「このプレイヤーはブラフを連発している」
→ バリューベットの成功率が上がる (相手がコールしやすい)
```

### パターン C: 静止 (変化なし)

```
ブラフ露見 → 平常運転
  - 何も変えない
  
→ 相手: 情報を読みにくい
→ メタゲームが成立しない
```

### どれを選ぶか

```
相手 レベル 2: パターン A (タイト化 → 騙し)
相手 レベル 3: パターン B (ブラフ連発 → 露見想定)
相手 レベル 4+: パターン C (読みの読みが無意味)
```

## 13-5　古典理論からの引用

メタゲーム理論の源流：

### Sklansky の基本定理 (*The Theory of Poker*)

> 「プレイヤーは、相手のハンドを知っているかのように打つべき」

相手のレンジ全体を知る = レベル2。情報が多ければ多いほど**均衡に近づける**という原則。

### Harrington のメタゲーム (*Harrington on Hold'em*)

> 「ハンドの EV は、単体では決まらない。あなたの過去のプレイとの相関で決まる」

**イメージの蓄積が EV を決める**という洞察。タイトイメージは特定のハンドのEVを上げ、ルーズイメージは下げる。

### Janda の搾取枠組み (*Applications of No-Limit Hold'em*)

> 「GTO は防御、搾取は攻撃。搾取では相手の明らかな弱点に集中して攻める」

「すべての弱点を攻めない」。最大の弱点に集中する。

### Galfond の動的頻度 (*GFX*)

> 「戦略は静的ではない。各ハンドで微妙に調整するのが上級者」

毎ハンド5-10% の動的調整で、長期的に相手を上回る。

## 13-6　具体例 6 パターン

### 例 1: タイトイメージで ブラフ 3bet

```
状況: 過去 30 ハンドで 3bet ゼロ、ショーダウンは KK/AK のみ
自分 BTN、CO オープン、自ハンド 76s (弱)

GTO 判断: コール or フォールド
メタゲーム判断: **3bet ブラフ** (相手は タイト と認識、フォールド率高い)

結果: 3bet $9 → 相手 フォールド → +$4 ポット獲得
```

### 例 2: ブラフ露見後のバリュー集中

```
状況: 前ハンドで A5s ブラフ露見、相手が 「ブラフ多い」イメージ
自分 BTN、次のハンドで AA

GTO 判断: 標準的に 3bet プッシュ
メタゲーム判断: オーバーベットバリュー (相手がコールしやすい心理)

結果: 3bet $12 → 相手コール → フロップ K72r で 75% CBet → ターン チェック → リバー オーバーベット $150
相手がコール → +$170 (通常の $60 より +110)
```

### 例 3: ルーズイメージ時の バリュー強化

```
状況: 過去 20 ハンドで ブラフ 3 回キャッチ、相手の認識「ルーズ」
自ハンド: セット

GTO 判断: 標準的なバリュー (50-75%)
メタゲーム判断: オーバーベット (相手が コールする心理)

結果: リバー $150 オーバーベット → 相手 TPWK でコール → +$150
```

### 例 4: ショーダウンからの逆搾取

```
状況: 相手が 75% CBet で 3 連続バレル、ショーダウンで AK (バリュー、ブラフではなかった)

→ 相手は「大きいサイズ = バリュー」を使う 人
→ 自分の対応: 相手の 大サイズには タイト、小サイズには 広くコール

結果: 相手の 75% フロップにフォールド、相手の 33% フロップにコール
  ブラフキャッチで +EV
```

### 例 5: コールステーション対策

```
状況: 相手が Fish、毎ハンド TP 以下でもコール、ブラフしない
自分: ルーズイメージ構築 (ブラフをあえて見せる)

結果: 自分のバリューハンドで 相手が コール → +EV
ブラフは使わない (損失減)
```

### 例 6: 長期対戦 HU での逆利用

```
状況: 長時間ヘッズアップ対戦、互いにレベル 3 まで到達
自分のイメージ: 「タイト」 (相手が認識)

メタゲーム: **意図的に ブラフを見せる** → ルーズイメージに転換
次の 10 ハンドで バリューを厚く取る

結果: 短期的にブラフ 1 回損失、しかしその後 10 ハンドでバリュー大幅回収
```

## 13-7　FPS (ファンシープレイシンドローム) の回避

### FPS の定義

```
FPS = 「上級者が メタゲームに深入りしすぎて、本来の確率判断を失う状態」
```

症状：

- 「相手は自分がブラフしてると思ってるから、ナッツでチェック」
- 「相手がブラフキャッチすると思うから、さらに大きくベット」
- 読み合いで無限ループに陥り、単純な判断ができない

### FPS の典型失敗

```
状況: 自分 TPTK、相手が 3 回連続 フォールド (タイトイメージ構築)
自分の思考: 「次は相手がブラフキャッチしたい心理、だからチェック」

実際: 相手は 特に何も考えていない → 自分のチェックが バリュー損失
```

### FPS の回避

```
原則 1: レベル 3 以上に深入りしない
原則 2: 相手のレベルを見極め、1 レベル上まで
原則 3: 判断に迷ったら GTO (9 マスマトリクス) に戻る
```

### 「読み」の検証

メタゲームを発動する前に自問：

```
- 相手が本当にレベル 2 以上か? (サンプル 50+ ハンドでの観察)
- 相手の過去のアクションと矛盾しないか?
- 純粋な確率判断と比べて EV が高いか?
```

3問にYESでなければ、**メタゲーム発動を見送る**。

---

## 13-8　メタゲームのサンプル要件

メタゲームは**長期対戦**で機能。サンプル要件：

```
最低: 30 ハンド (相手のベースラインが見えた)
推奨: 50-100 ハンド (タイプが確定、変動も把握)
完璧: 200+ ハンド (レベル 3 読みが可能)
```

**30 ハンド未満ではメタゲーム禁止**。純粋なGTO + E補正で対応。

---

## 13-9　レベル 1 相手への警告

メタゲーム（特にレベル3戦略）は、**レベル 1 以下の相手には無効**です。

### 相手がレベル 1 の場合

```
相手: 自分のハンドしか考えない (Fish、初心者)

自分のレベル 3 戦略:
  - タイトイメージで ブラフ 3bet → 相手: ハンドが弱いからフォールド、これは偶然
  - ルーズイメージで バリュー厚 → 相手: ハンドが強いからコール、これも偶然

→ メタゲームは機能しない (相手が情報を使っていない)
```

### Fish/Nit 相手の正解

```
相手 Fish: レベル 2 (バリュー厚、ブラフ封印)
相手 Nit: レベル 2 (ブラフ増、過剰フォールド)
相手 TAG: レベル 3 (メタゲーム発動)
相手 LAG: レベル 3 (メタゲーム + ブラフキャッチ)
```

## 13-10　メタゲームの落とし穴 (再掲)

### 落とし穴 1: FPS (自滅)

上述のFPS。レベル3+ で迷走。

### 落とし穴 2: サンプル不足での断定

30ハンド未満でメタゲーム発動 → 誤った読み → 損失。

### 落とし穴 3: 相手の変化を見失う

メタゲームは固定的なイメージ前提。相手が戦略変更してると、古いメタゲームは無効（第12章で警告済み）。

### 落とし穴 4: 自分のイメージを間違える

```
自分が思う自分のイメージ: 「タイト」
相手が思う自分のイメージ: 「ルーズ」 (見てる場面が違う)
```

自分のイメージは**相手視点**で構築する。過去10-20ハンドで相手が見たアクションだけを材料にする。

---

## ❌ よくある誤解 / ✅ 正解

**❌ よくある誤解**: メタゲームはすべてのプレイヤーに対して有効だ。

**✅ 正解**: メタゲームはレベル 2 以上の相手にのみ有効。Fish や Nit は相手のイメージを考慮せずプレイするため、メタゲームを仕掛けても意味がない。相手のレベルを見極めてから発動する。

## ミニクイズ

### 問 1

**相手 TAG、過去 40 ハンドで 3bet を 2 回、両方ショーダウンで AA/KK (タイトイメージ)**。自分BTN、相手COオープン、自ハンド87s（弱）。どうする？

<details>
<summary>解答</summary>

```
メタゲーム判断:
  - 相手のタイトイメージを自分も共有している? → いや、相手のタイトイメージは相手側の話
  - **自分のタイトイメージが相手に認識されているか?**
    - 過去 40 ハンドで 自分は 3bet ゼロ or プレミアムのみ 3bet

もし自分もタイトイメージを構築しているなら:
  - **3bet ブラフ** が機能する可能性
  - 相手 (TAG、レベル 2-3) は「自分 (BTN) の 3bet = プレミアム」と思う
  - フォールド率高い

**答え: 3bet ブラフ (87s)**

ただし自分がルーズイメージを持っているなら、フォールドが無難。自分のイメージを正確に認識することが前提。

</details>

### 問 2

**相手 Fish (VPIP 48%)、過去 20 ハンドで 相手の バリューコール 5 回**。自分のブラフをキャッチされやすい。どうする?

<details>
<summary>解答</summary>

```

相手タイプ： Fish = レベル1以下
メタゲーム： **無効**（相手は考えていない）

戦略： レベル2で対応。

- ブラフ封印
- バリュー厚く（TPWK、セカンドペアでも打つ）
- サイズ大きく（Fishはコールする）

```

**答え: メタゲーム無効、Fish 対応 (ブラフ封印 + バリュー厚)**

Fish 相手にタイトイメージ/ルーズイメージは無意味。

</details>

### 問 3

**レベル 3 相手 (プロ級)、長期対戦 200 ハンド、自分のイメージは タイト**。自分 TPTK で 75% CBet。相手の反応を想定?

<details>
<summary>解答</summary>

```

レベル3相手の思考：

- 「BTNのタイトプレイヤーが75% CBet」
- 「強ハンドの可能性高い」
- ただし、「BTNは時々 75% でブラフもする（ポーラード化）」も認識

予想される反応：

- TPGK以上： タイトコール（相手のタイト読みで）
- TPWK: フォールド
- ブラフキャッチ候補： Aブロッカーなどを持つ場合のみコール

```

**答え: レベル 3 相手は タイトコール、TPTK は バリュー取れる**

レベル 3 では相手が「自分のイメージ」を織り込んでコール/フォールドを決める。タイトイメージを持つ自分は、バリューを取りやすい。

</details>

**【GTOとのズレ】**

本章のメタゲームは「相手との長期的な関係性」を前提に戦略を動かす枠組みです。一方の GTO は、目の前の 1 ハンドの均衡解だけを与えます。GTO はイメージや過去 100 ハンドの履歴を一切参照しないため、タイトイメージを利用した 3bet ブラフや、ルーズイメージを利用したオーバーベットバリューは、すべて GTO 解からの逸脱に分類されます。逸脱が +EV になるのは、相手がレベル 2 以上で自分のイメージを織り込んでくる場合に限られます。

ズレが大きく出るのは、長時間ヘッズアップや固定メンバーのリングゲームです。GTO は毎ハンドを独立試行として扱いますが、実戦では「3 ハンド前にブラフ露見した」事実が次の手の EV を 0.5 BB から 1.5 BB の幅で動かします。レベル 3 相手なら、自分のタイトイメージを利用したブラフ 3bet で +1 BB 程度の EV を取れる場面でも、GTO ソルバーは「フォールド推奨」と出力します。逆にサンプル 30 ハンド未満で発動すると、GTO 逸脱が読み違いで -2 BB の損失になります。

実戦では、相手のレベルと自分のイメージのサンプル数で「GTO に戻る / メタゲームを発動する」の境界を決めます。相手がレベル 1 以下、サンプル 30 未満、自分のイメージが曖昧なら GTO 寄りに戻し、レベル 2-3 で 50 ハンド以上の蓄積があるときだけメタゲームを乗せるのが安全です。FPS を避けるには、迷ったら 9 マスマトリクスに戻ることを徹底します。
