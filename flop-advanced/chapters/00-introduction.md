> 「巻2 までで D3 + 9 マスマトリクスをマスターした読者へ。本書は上級の 3 方向 (精密化・レンジ推定・搾取) を、それぞれ違うペースで学べるように設計した」

---

## 本書の位置づけ

本書は 4 巻シリーズ『ゼロから勝てるテキサスホールデム』の **第 3 巻、フロップ上級編** です。

| 巻 | タイトル | 状態 |
| --- | --- | --- |
| 巻1 | プリフロップは計算で勝つ | 既刊 |
| 巻2 | フロップは構造で勝つ | 既刊、D3 + 9 マスマトリクス |
| **巻3** | **フロップは読み合いで勝つ (本書)** | **精密化 + レンジ推定 + 搾取** |
| 巻4 | ターン・リバー編 (仮題) | 執筆予定 |

本書は巻2 を完全習得した読者向けです。9 マスマトリクスで CBet を打てる前提で、**GTO を超えて相手を読み、搾取する**道具を提供します。

---

## 3 人の読者像を想定した

本書は**抽象度が高い章**と**実戦密度が濃い章**が混在します。読者によって読む順序が変わります。次の 3 タイプを想定しました。

### タイプ A: 中級ステップアップ組

```
30 代会社員、NL50-100 で安定してプラス収支、巻2 をマスター済み。
数式は苦手だが、実戦で使える道具をさらに加えたい。
メタゲームは FPS (上級者の自滅) が気になる慎重派。
平日 30 分の学習時間。
```

### タイプ B: ソルバー派の技術志向

```
20 代後半、副業またはプロ候補、NL200-500。
GTO Wizard を日常的に使う、PioSolver も触れる。
数字の根拠を常に確認したい。反論しがち。
週末 10 時間の集中学習。
```

### タイプ C: ライブ/混合タイプのベテラン

```
40 代、10 年以上のプレイ経験、ライブ中心。
HUD は使うが依存しない、メタゲームと物理テルは得意。
ソルバーに時間を割けない。実戦で即使いたい。
自由時間は多いが集中は 1 時間まで。
```

## 3 つの読書ルート

### ルート A: 「最短 5 章」ルート (中級ステップアップ組向け)

```
第1章 BDM v5
  → 第4章 ボード型の超細分化
  → 第5章 レンジ推定の基礎
  → 第11章 プレイヤータイプ別の搾取
  → 第17章 総合ドリル
```

**狙い**: 巻2 の D3 を BDM v5 に精密化、ボード型を 17 に細かくする、搾取の基礎を覚える、ドリルで定着。**5 章だけ読めば実戦投入できる**水準。

**省略してよい章** (余裕ができたら):
- 第2章 (混合戦略 R1-R6): FPS リスクがあるので慎重派は最後に
- 第12-14章 (動的調整・メタゲーム・テル): 経験を積んでから
- 第15-16章 (ソルバー): 必要になってから

---

### ルート B: 「数値精密化」ルート (ソルバー派向け)

```
第1章 BDM v5
  → 第2章 混合戦略 R1-R6
  → 第9章 レンジ vs レンジの衝突分析
  → 第10章 HUD E 補正
  → 第15章 ソルバー vs 実戦
  → 第17章 総合ドリル
```

**狙い**: 係数の根拠を抑え、混合戦略で精度を最大化、ソルバーとの乖離を定量管理。**6 章で巻3 の理論的最大値を獲得**。

**重点付録**: 付録 B (BDM v5 完全仕様)、付録 D (HUD 統計詳細表) を先に読んでから本文に戻ると根拠がわかる。

---

### ルート C: 「実戦派」ルート (ライブベテラン向け)

```
第1章 BDM v5
  → 第4章 ボード型の超細分化
  → 第11章 プレイヤータイプ別の搾取
  → 第13章 メタゲーム
  → 第14章 タイミングテル・物理テル
  → 第17章 総合ドリル
```

**狙い**: BDM v5 は暗算できる範囲で、搾取・メタゲーム・物理テルを中心に実戦力を底上げ。**6 章でライブ力が飛躍的に向上**。

**スキップ推奨**: 第10章 (HUD E 補正) は HUD を使わない読者には不要。各章の「ライブ版」ボックスを参考に。

## 全章構成 (全 17 章 + 付録)

### 第I部　モデルの精密化 (4 章)

1. BDM v5 完全解説 — 4 項減算式、Ablation 分析
2. 混合戦略 R1-R6 — 9 マスの境界セルをランダム化
3. 精密 HandScore — ブロッカー・ディスブロッカーの定量
4. ボード型の超細分化 — 7 型 → 17 型への拡張

### 第II部　レンジ推定 (5 章)

5. レンジ推定の基礎 — コンボ計算、ブロッカー効果
6. プリフロップからの推定 — ポジション × アクション × スタック
7. フロップアクションによる絞り込み — ベイズ更新の実戦化
8. サイジングテルからの推定 — 16 パターンの示唆
9. レンジ vs レンジの衝突分析 — EQ/Nut アドバンテージの分離

### 第III部　クセ読みと搾取 (5 章)

10. HUD 統計ベースの E 補正 — 4 分類から連続値へ
11. プレイヤータイプ別の搾取戦略 — 32 例カタログ
12. 動的調整 — 3-4 ハンド単位での戦略変更
13. メタゲーム — レベル 0-4+ の読み合い
14. タイミングテル・物理テル — オンラインとライブ

### 第IV部　統合と実戦 (3 章)

15. ソルバー vs 実戦 — GTO から外れる基準
16. ハンドレビューの手順 — 乖離分析と改善
17. 総合ドリル 50 問 — 全章統合の実戦演習

### 付録

A. 参考文献・謝辞 / B. BDM v5 完全係数表 / C. 17 型判定早見表 / D. HUD 統計詳細表 / E. タイプ別チートシート / F. 古典引用 / G. Q&A 上級編 / H. 出典 / I. 検証スクリプト

## 本書で約束すること

- 巻2 との一貫性を保ち、D3 + 9 マスマトリクスは否定しない
- BDM v5 の係数は 30 ボードの GTO 実測データから**帰納的に**導出した
- エクスプロイトの推奨はすべて「相手のサンプル 200+ ハンド」が前提
- メタゲーム (第13章) はレベル 2 以上の相手にのみ有効、Fish/Nit には無意味と明示
- 各章冒頭に 3 ペルソナ別の「読み方メモ」を置き、迷ったら **ルート A** から読む

## 読書前のチェック

次の質問に「はい」と答えられるか、確認してから本書に進んでください。

1. 巻2 第8章の D3 チェックリストを暗算で実行できる?
2. 巻2 第10章の 9 マスマトリクスでアクションを即答できる?
3. HandScore (巻2 第9章) を「強/中/弱」の 3 段階で分類できる?
4. NL10-NL200 で、長期的にプラス収支を達成している (または近づいている)?

3 つ以上「はい」なら本書の読者として適切です。不安なら巻2 を復習してください。
