# 第15章　4-bet ポットのフロップ戦略（本書の集大成）

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: 4-bet ポットは SPR ≈ 1.77 という極めて浅いスタック比になります。「TPTK でコミット」が正当化されるこの状況の論理を理解し、IP の range bet 戦略と OOP のターン push/fold 計画を組み合わせた実戦判断ができるようになりましょう。本章は巻③の集大成であり、巻④（ターン・リバー編）への橋渡しでもあります。

---

## 15-1　4-bet ポットの数値を把握する

4-bet ポットは、プリフロップのベット合戦が 4 回行われた結果です。

```
標準的な 4-bet ポット（BTN vs BB、100BB スタート）:
  BTN open 2.5bb → BB 3-bet to 9bb → BTN 4-bet to 22bb → BB call:
    pot = 22（BTN）+ 22（BB）+ 0.5（SB）≈ 44.5bb
    stack = 100 − 22 = 78bb
    SPR = 78 ÷ 44.5 ≈ 1.75
```

SRP（SPR ≈ 16）と 3-bet ポット（SPR ≈ 5）、そして 4-bet ポット（SPR ≈ 1.75）の差は歴然です。

### SPR の違いがコミット閾値を変える

| 状況 | SPR 目安 | 「コミット」するハンド強度 |
|:---|:---:|:---|
| SRP | ≈ 16 | セット・2ペア以上（HS ≈ 75+） |
| 3-bet ポット | ≈ 5 | TPTK 以上（HS ≥ 65） |
| 4-bet ポット | ≈ 1.75 | TPTK 以上（HS ≥ 65）でフロップ オールイン計画 |

SRP では「セット以上でオールイン」が目安でしたが、4-bet ポットでは「TPTK 以上でフロップからオールイン計画」になります。

---

## 15-2　フロップ 1 ストリートでターンが push/fold になる

4-bet ポットの核心は「フロップを通過するだけでターンが push/fold になる」ことです。

### SPR 推移の計算

```
フロップで IP が 33% CBet（14.7bb）、OOP がコール:
  pot after call = 44.5 + 14.7 + 14.7 ≈ 74bb
  stack remaining ≈ 78 − 14.7 = 63.3bb
  SPR ターン = 63.3 ÷ 74 ≈ 0.86
```

SPR < 1 になると「残りスタックがポットより少ない」状態です。ターンは「全部入れる or 降りる」の 2 択になります。

```
ターンで push するための必要エクイティ:
  必要エクイティ = stack ÷ (stack + pot) = 63.3 ÷ (63.3 + 74) ≈ 46%
```

ターンで OOP がオールインするためには、約 46% のエクイティが必要です。これはセカンドペア（HS ≈ 50 前後）ではほぼ達成できない水準で、TPTK（エクイティ約 55〜65%）以上が条件になります。

---

## 15-3　IP（4-bettor）の range bet 戦略

4-bet した側（IP）のレンジは QQ+、AKs、AQs など「プレミアムの中のプレミアム」です。ほぼすべてのボードで IP がレンジ優位を持ちます。

GTO Wizard の実測では、4-bet ポットでの IP CBet 頻度は dry board（K♣7♦2♠）で約 95% 以上に達し、wet board（9♣8♣3♦）でも約 90% です。

### range bet が 4-bet ポットで最も機能する理由

```
4-bet ポット（SPR≈1.75）での 33% CBet:
  bet = 14.7bb（33% of 44.5bb）
  OOP のポットオッズ = 14.7 ÷ (44.5 + 14.7 + 14.7) = 14.7 ÷ 73.9 ≈ 20%
  OOP はエクイティ 20% 以上でコール可能 → 広くコールできる
```

OOP が広くコールできる状況で、IP がブラフとバリューを分けて打つ意味は薄くなります。SPR = 1.75 では「フォールドエクイティ」よりも「レンジ全体でエクイティを使い続ける」アプローチが効率的です。

全ハンドで 33% を打つ range bet により、OOP は「フォールドするか、ターンで push するか」の 2 択を常に迫られます。

### CBet サイズ選択

| ボードテクスチャ | 推奨サイズ | 理由 |
|:---|:---:|:---|
| Dry rainbow（K♣7♦2♠） | 33% | range bet、全ハンド均一 |
| 2-tone（J♣T♦5♣） | 33〜50% | ドローにチャージ |
| Monotone（9♠8♠4♠） | 50〜75% | フラッシュドロー完成確率が高い |

---

## 15-4　OOP（コール側）の守備計画

OOP は 4-bet をコールした時点で「コミットに近い意思決定」を済ませています。

### フロップでのコール基準

```
OOP の 4-bet ポット フロップ対応:
  vs 33% CBet（pot odds ≈ 20%）:
    HS ≥ 65（T1: TPTK 以上）→ コール計画（ターンで push を見越す）
    HS 40-64（T2: セカンドペア〜TPWK）→ ポットオッズ的にはコール候補
    HS < 40（T3: ウィーク系）→ フォールド（ターンで push できない）
```

T2 でのコールを検討する場合でも「ターンで push できるか」を必ず確認します。セカンドペア（HS ≈ 50）がターンで push するためには 46% のエクイティが必要ですが、対 T1 相手への 2 ペア以下ではエクイティが足りないことが多いです。

実戦では T1（HS ≥ 65）のみをコール計画として、T2 以下はフロップでフォールドするのが安全です。

---

## 15-5　コンボドロー = 即 push の手

4-bet ポットで例外的に強いアクションが取れるのがコンボドロー（フラッシュドロー + ストレートドロー）です。

### コンボドローの EV 計算

```
コンボドロー例: J♣T♣ on 9♣8♣3♦（4-bet ポット SPR≈1.75）
  エクイティ: FD（9アウト）+ OESD（8アウト）≈ 55〜60%（vs AA/KK）
  ※ アウツの重複があるため単純合算より少し低い

push EV の計算（FE = フォールドエクイティ）:
  push EV = FE × pot + (1−FE) × equity × (pot × 2)
  FE ≈ 30% として:
    EV = 0.30 × 44.5 + 0.70 × 0.57 × 89
       = 13.4 + 35.5 ≈ 48.9bb

コールして後続する場合の EV（概算）:
  call EV = 0.57 × 89 − 14.7（コール費用）≈ 36.2bb

push EV（48.9bb）> call EV（36.2bb）→ 即 push が優位
```

フォールドエクイティとエクイティを合算すると、即 push が単なるコールを上回ります。SPR = 1.75 という浅さが、コンボドローの push を正当化する鍵です。

### 単独 FD（フラッシュドローのみ）の場合

エクイティ ≈ 35% の単独 FD では、即 push と call して SPR ≈ 0.86 でターンに進む選択がほぼ互角です。ターン push での EV が手前のコストを回収できるため、コールも成立します。

## 15-6　本書の集大成：SRP から 4-bet ポットへ

巻②と巻③を通じて学んだフレームワークを、ポット構造の違いで整理します。

### T1/T2/T3 × SPR のマトリクス

| ハンド層 | SRP（SPR≈16） | 3-bet（SPR≈5） | 4-bet（SPR≈1.75） |
|:---|:---|:---|:---|
| **T1（HS≥65）** | バリューベット。多ストリート計画 | バリューコール。2 ストリートでコミット | フロップからオールイン計画 |
| **T2（HS 20-64）** | ボードによりベット/チェック | コール候補（コミットできるか確認） | ほぼフォールド（ターンで push できない） |
| **T3（HS<20）** | B≥62 のみブラフ | フォールドが基本 | フォールド（コンボドローは例外） |

この表が示すように、SPR が下がるにつれてハンドの選別が厳しくなります。

### 状況別フォールド閾値一覧（vs 33% CBet）

各章で個別に学んだフォールド閾値を一つの参照表に整理します。

| 状況 | vs 33% 閾値 | vs 75% 閾値 | 出典章 |
|:---|:---:|:---:|:---:|
| HU・標準（SRP、rainbow） | HS < 15 | HS < 35 | 巻②第06章 |
| 2tone 補正（+5） | HS < 20 | HS < 40 | 巻②第06章 |
| mono 補正（−5） | HS < 10 | HS < 30 | 巻②第06章 |
| ペアボード補正（−10） | HS < 5 ≈ 全コール | HS < 25 | 巻②第06章 |
| マルチウェイ 3way（+5） | HS < 20 | HS < 40 | 第11章 |
| マルチウェイ 4way（+10） | HS < 25 | HS < 45 | 第11章 |
| vs Fish（+10） | HS < 25 | HS < 45 | 第13章 |
| vs Nit（−5） | HS < 10 | HS < 30 | 第13章 |
| 3-bet ポット（SPR≈5、+5） | HS < 20 | HS < 40 | 第12章 |
| 4-bet ポット（SPR≈1.75） | T1（HS≥65）のみ守備 | — | 本章 |

「ペアボード補正 −10」を適用すると vs33% 閾値が HS < 5 となりますが、HS の最低値は 10（役なし・ドローなし）のため、この状況では実質的に全ハンドコール域になります。

この表を手元に置いておけば「今は何ウェイで、相手タイプはどうで、ポット構造はどれか」を組み合わせて閾値を即座に決定できます。

### 巻④（ターン・リバー編）への橋渡し

フロップの判断はターンとリバーへの準備です。

- **SRP でのフロップ 33% CBet** → ターン SPR ≈ 9 → 3 ストリート使える設計
- **3-bet ポットでのフロップ 33% CBet** → ターン SPR ≈ 2.7 → 2 ストリートでコミット
- **4-bet ポットでのフロップ 33% CBet** → ターン SPR ≈ 0.86 → 1 ストリートで終了

巻④ではターンカードが落ちた後にレンジがどう変化するか、そしてリバーでのベット配分（α 式）をどう使うかを学びます。フロップで作った「ハンドの役割」がターン・リバーで活きる場面を、より深く掘り下げます。

## ミニクイズ

### 問1

4-bet ポット（BTN 4-bet 22bb → BB コール）でのフロップ開始時の pot と SPR として、最も近い値はどれですか？

1. pot ≈ 27bb、SPR ≈ 3.6
2. pot ≈ 44bb、SPR ≈ 1.75
3. pot ≈ 60bb、SPR ≈ 1.0

### 問2

4-bet ポットで IP が dry rainbow ボードに 33% CBet を打ち、OOP がコールしました。
ターン開始時の SPR はおよそいくつですか？

1. SPR ≈ 2.5（まだ十分に深い）
2. SPR ≈ 0.86（ターンは push/fold）
3. SPR ≈ 0.3（フロップコールでほぼオールイン）

### 問3

4-bet ポット（SPR≈1.75）で OOP が J♣T♣ on 9♣8♣3♦（コンボドロー）を持っています。
IP の 33% CBet に対して最も EV が高いアクションはどれですか？

1. チェックレイズしてターンを待つ（SPR が低いためチェックレイズは禁物）
2. コールして SPR≈0.86 のターンで push する
3. フロップで即 push（フォールドエクイティ + エクイティの合算が最大）

---

### 解答

- **問1**: **2. pot ≈ 44bb、SPR ≈ 1.75** が正解。BTN 22bb + BB 22bb + SB 0.5bb ≈ 44.5bb。スタック = 78bb。SPR = 78 ÷ 44.5 ≈ 1.75。
- **問2**: **2. SPR ≈ 0.86（ターンは push/fold）** が正解。フロップで 33% CBet（約 14.7bb）をコールした後、pot ≈ 74bb、残スタック ≈ 63bb。SPR = 63 ÷ 74 ≈ 0.85。ターンは「残りスタック < ポット」の push/fold ゾーンです。
- **問3**: **3. フロップで即 push** が正解。コンボドロー（FD + OESD）はエクイティ約 55〜60% を持ち、フォールドエクイティを加算した push EV がコール EV を上回ります。SPR = 1.75 という浅さがコンボドローの即 push を最大限に活かせます。

---

> **本章まとめ**
>
> - 4-bet ポットは pot ≈ 44bb、SPR ≈ 1.75 という極めて浅い状況。
> - IP（4-bettor）はプレミアムレンジで range bet（33%）が基本。3-bet ポットと同じ原則。
> - フロップ 33% CBet をコールすると、ターン SPR ≈ 0.86 の push/fold ゾーンに突入する。
> - OOP のターン push に必要なエクイティ ≈ 46%。T2 以下はフロップでフォールドが安全。
> - コンボドロー（FD + SD）はフロップ即 push が最善（フォールドエクイティ + エクイティの合算）。
> - 本書で学んだ T1/T2/T3 × SPR の枠組みが、巻④ターン・リバー編への土台になる。

---

**【GTO とのズレ】**

4-bet ポットの「range bet」戦略は GTO 均衡に近い強力な戦略ですが、IP がすべてのハンドで等しく打つわけではありません。GTO 実測では dry ボードで 95%+、wet ボードでも 90% 前後であり、わずかにチェックが混入します。また OOP のフロップコール基準（T1 のみ）も GTO では一部 T2 でのコールが存在します。本書の基準はシンプルさを優先した実戦的な近似値です。ソルバーで精緻化する際は、具体的なボードとレンジの組み合わせで数値を確認してください。
