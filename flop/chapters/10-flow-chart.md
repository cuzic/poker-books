> **本章のゴール**: 第01章〜第09章で学んだ全フレームワークを「IP の 5 ステップ」と「OOP の 3 ステップ」の 2 本柱に統合し、フロップ判断を暗算 5 秒以内で回せるフローとして定着させる。

## 10-1　なぜ「フローチャート」で締めくくるか

第01章〜第09章では、ボードスコア B、ハンドスコア HS、ティア分類（T1/T2/T3）、CBet 閾値、サイズ選択、フォールド閾値、C 値、チェックレイズ、チェックバックという 9 つのトピックをそれぞれ独立して学びました。

本章の目的は「分解して学んだ知識を 1 本のフローに統合する」ことです。

暗記が得意でない方でも、フロー（手順）を体で覚えることはできます。最初は各ステップを意識しながら確認し、繰り返すうちに全体が自動化されます。このフロー全体が「迷わないポーカー」の核心です。

## 10-2　IP の 5 ステップフロー（CBet 攻撃判断）

### フロー全体図

```
[フロップ発生]
     |
     v
STEP 1: Board Score B を計算
  9ルールで B を決定（1秒以内）
     |
     v
STEP 2: Hand Score HS を計算
  役スコア + ドローボーナス(NFD+33/FD+30/OESD+24/GS+12/BDFD+6) + 2OC ボーナス
     |
     v
STEP 3: Tier 判定
  HS ≥ 65 → T1（常にベット）
  HS ≥ 20 → T2（B ≥ 58 でベット）
  HS < 20 → T3（B ≥ 62 でベット）
     |
     v
STEP 4: CBet サイズ選択
  B=70（mono）→ 75% ポット
  2tone/rainbow_connected/paired（B=50〜83 の湿系）→ 50% ポット
  dry rainbow（B ≤ 62）→ 33% ポット
     |
     v
STEP 5: C 値検証（任意、余裕があれば）
  33%ベット → C=12 / 75%ベット → C=22
  HS < C × 2 → ベット根拠薄い（参考）
```

### 各ステップのポイント

**STEP 1：Board Score B の計算（第01章）**

9 つのルールを優先順位で適用します。覚え方は「ペア最強（83）、モノ（70）、レインボー系（55〜67）」です。

| テクスチャ | B 値 |
|---|---|
| ペアボード × トップ T 以上 | 83 |
| ペアボード × トップ T 未満 | 71 |
| モノトーン | 70 |
| レインボー × spread ≤ 3 × J 以上トップ | 67 |
| レインボー × A/K トップ | 62 |
| 2トーン × A/K トップ | 56 |
| レインボー × Q トップ | 58 |
| レインボー | 55 |
| 2トーン | 50 |

**STEP 2：Hand Score HS の計算（第02章）**

```
HS = 役スコア + ドローボーナス + 2OC ボーナス（+BDFD）

役スコア: セット以上=85 / オーバーペア(AA-QQ=80/JJ-TT=75/99-=70) / 2ペア=75 / TPTK=65 / TPGK=60
          TPMK=55 / TPWK=50 / セカンドペア強=42 / セカンドペア弱=38
          ボトムペア=30 / A-high=25 / K-high=20 / Q-high=15 / エアー=10

ドローボーナス（固定値）:
  NFD=+33（A-high フラッシュ）/ FD=+30 / OESD=+24 / GS=+12 / BDFD=+6

2OC ボーナス: 両ホールカードがボード最高ランク超え → +24（フロップのみ）
```

**STEP 3：Tier 判定 + CBet 判断（第03・04章）**

```
T1（HS ≥ 65）: 全ボードで CBet → STEP 4 へ
T2（HS ≥ 20）: B ≥ 58 なら CBet / B < 58 ならチェック
T3（HS < 20）: B ≥ 62 なら CBet / B < 62 ならチェック
```

「T2 がチェックするのは 2トーン（B=50）とレインボー（B=55）のみ」と覚えれば十分です。

**STEP 4：サイズ選択（第05章）**

```
B=70（モノトーン）                          → 75% ポット
2tone/rainbow_connected/paired（湿系）      → 50% ポット
dry rainbow（B ≤ 62、2tone/connected 以外） → 33% ポット（レンジベット）
```

簡易基準: mono→75%、2tone・rainbow_connected・paired→50%、dry rainbow（B≤62）→33%。

## 10-3　OOP の 3 ステップフロー（防御判断）

```
[IP が CBet してきた]
     |
     v
STEP 1: ベットサイズを確認
  33%: α=0.25 / MDF=75% / 閾値ベース=15
  75%: α=0.43 / MDF=57% / 閾値ベース=35

     |
     v
STEP 2: フォールド閾値を補正
  基本閾値 + テクスチャ補正

  補正表:
    2トーン    : +5（ドロー豊富、守備しやすい）
    モノトーン  : −5（フラッシュ恐怖、守備しにくい）
    ペアボード  : −10（トリップス恐怖、守備しにくい）
    レインボー  : 補正なし

  例: vs 75% ベット on 2トーン → 35 + 5 = 40 → HS < 40 でフォールド

     |
     v
STEP 3: HS と閾値を比較
  HS ≥ 閾値 → コール（またはチェックレイズ候補）
  HS < 閾値 → フォールド

  チェックレイズ（第08章）:
    HS ≥ 40（SRP: SPR≥6）→ CR を積極的に検討
    FD/OESD on wet board → CR ブラフ候補（巻③で深掘り）
```

## 10-6　暗算フローを体で覚えるための練習法

### 3 段階の習熟ステップ

**ステップ 1：各項目を数字で確認しながらプレイ（最初の 10 セッション）**

フロップが出たら手元のメモを見ながら B、HS、Tier を計算します。試合をリアルタイムで止めることはできませんが、練習テーブル（低レートやプレイマネー）で 1 手ずつ確認する作業です。

目標: B を 1 秒で出せるようにする。

**ステップ 2：HS 計算の自動化（次の 50 セッション）**

STEP 1（B 計算）が直感化したら、STEP 2（HS 計算）の速度を上げます。役スコアを即座に思い浮かべ、ドローボーナスを加算する練習を繰り返します。

目標: HS を 2 秒で計算できるようにする。

**ステップ 3：フロー全体の無意識化（その後）**

STEP 1 と STEP 2 が自動化されると、STEP 3（Tier 判定）以降は自然に処理されます。「このボードと手の組み合わせなら、ほぼ反射的に判断が出る」状態を目指します。

## 10-7　フロー統合の実例 3 パターン

### 実例 1：強い手 × 乾燥ボード（典型的ベット）

> **ハンド**: A♥K♠ / **ボード**: K♣7♦2♠

- STEP 1: レインボー × A/K トップ → **B = 62**
- STEP 2: TPTK（役スコア=65）+ ドロー加点なし + 2OC なし = **HS = 65**（厳密には TPTK で A がオーバーカード 1 枚だが計算簡略）
- STEP 3: HS = 65 ≥ 65 → **T1 → 常にベット**
- STEP 4: B = 62 < 70 → **33% ポット（2bb）**
- OOP フォールド: 閾値 = 15、約 46% がフォールド

**結論**: 33% でベット。T1 × 乾燥ボードの典型。

---

### 実例 2：T1 の手 × 2トーンボード（ベット）

> **ハンド**: A♦Q♥ / **ボード**: Q♣8♥5♦（2トーン）

- STEP 1: 2トーン（A/K トップではない Q トップ）→ **B = 50**
- STEP 2: TPTK（役スコア=65）= **HS = 65** → T1
  （TPTK の HS=65 なので T1 に入ります）
- STEP 3: HS = 65 ≥ 65 → **T1 → 常にベット**
- STEP 4: 2トーンボード → **50% ポット（3bb）**

**結論**: T1 はボード問わずベット。2トーンでも 50% でベットします。

---

### 実例 3：弱い手 × レインボーボード（チェックバック）

> **ハンド**: K♣Q♠ / **ボード**: 9♥7♦2♠（レインボー）

- STEP 1: レインボー（9高）→ **B = 55**
- STEP 2: K-high（役スコア=20）+ 2OC ボーナス（両カードがボード最高の 9 を超える → +24）= **HS = 44** → T2
- STEP 3: T2 × B = 55 < 58 → **チェックバック**

**結論**: T2 でもレインボーボードではチェックバック。OOP のフォールド率が低いためです。

## 10-8　巻③・巻④・巻⑤への橋渡し

本書でカバーした内容は「フロップの基礎」です。本書のフレームワークを習得した後は、次のステップが待っています。

### 巻③（フロップ応用）で学ぶこと

- レンジ優位（精密分析）による CBet 判断の精密化
- 混合戦略（T1 を 100% ベット以外にすることの根拠）
- チェックレイズのレンジ設計
- ブロッカーとブラフキャッチ

### 巻④（ターン・リバー基礎）で学ぶこと

- ターンカードによる手の変化（hand evolution）
- バレルスコア（2バレル / 3バレル判断式）
- リバーでのバリュー配分

### 巻⑤（ターン・リバー応用）で学ぶこと

- 3軸統合判断（forward × current × backward induction）
- ターン・リバーのオーバーベット
- ブロッカー実戦

**本書のフロー（B → HS → Tier → CBet → Size）はすべての続編の基礎**です。ターンでも HS 計算（アウト×2 に変わる）と Tier 判定の原則は同じです。本書のフローを徹底的に身体化させてから先に進むことを強く勧めます。

## ミニクイズ

### 問1

A♣8♦ / K♥7♠3♦（レインボー）でフロップが落ちました。IP として正しい判断を選んでください。

（1）B=62（rainbow_ak）、HS=25（A-high）→ T3 × B=62 ≥ 62 → ベット 33%
（2）B=55（rainbow）、HS=25（A-high）→ T3 × B<62 → チェックバック
（3）B=62（rainbow_ak）、HS=65（TPTK）→ T1 → ベット 75%
（4）B=55（rainbow）、HS=44（T2）→ T2 × B<58 → チェックバック

### 問2

OOP として、相手（IP）が 75% ポットのベットを打ってきました。ボードは J♥9♦5♣（レインボー）。あなたのハンドは Q♠T♠（OESD）。フォールド閾値を計算し、コールかフォールドか判断してください。

（1）閾値 = 35（補正なし）、HS = 15 + 24 = 39 ≥ 35 → コール
（2）閾値 = 40（2トーン補正 +5 を誤適用）、HS = 15 + 24 = 39 < 40 → フォールド
（3）HS = 15 のみ（ドローを無視）、15 < 35 → フォールド
（4）どんな手でも 75% ベットにはフォールドが安全

### 問3

本書で学んだ CBet フローを最も正確に表しているのはどれですか？

（1）強い手は常にベット、弱い手はチェック
（2）HS と B の 2 要素で CBet 判断を行い、サイズはボードテクスチャで決める
（3）ポジションがあれば常にベットする
（4）OOP のフォールド率を見てベットサイズを変える

---

### 解答

- **問1**: （1）　A♣8♦ on K♥7♠3♦ → A はボード最高カードの K を超えるオーバーカード 1 枚ですが、8 は K より低いので「両カードがボード最高ランク超え」という 2OC ボーナスの条件を満たしません。HS = A-high（25）→ T3。ボードは レインボー × A/K トップ なので B=62。T3 × B=62 ≥ 62 → ベット 33% が正解です。
- **問2**: **（1）** が正解。レインボーボードへの補正はゼロです（2トーン補正 +5 は誤適用）。vs 75% の閾値ベースは 35。Q♠T♠ on J♥9♦5♣ → 役なし（Q-high=15）+ OESD（Q-J-T-9 の4連続、K か 8 で完成 → +24）= HS=39。HS=39 ≥ 閾値35 → コール。OESD ボーナスを無視すると HS=15 < 35 でフォールドになるため、ドロー計算が判断を左右します。
- **問3**: （2）　本書の CBet フローは「HS（Tier）× B（Board Score）の 2 軸判断」が核心です。単に「強い手をベット」ではなく、HS と B の組み合わせによる閾値比較が本書のアプローチです。

> **本章まとめ**
>
> - IP の 5 ステップ: B 計算 → HS 計算 → Tier 判定 → CBet 判断 → サイズ選択
> - T1（HS ≥ 65）: 常にベット / T2（HS ≥ 20）: B ≥ 58 でベット / T3（HS < 20）: B ≥ 62 でベット
> - OOP の 3 ステップ: ベットサイズ確認 → フォールド閾値補正 → HS と比較
> - フロー全体を体得するには「STEP 2（HS 計算）の自動化」が鍵
> - 本書のフローは巻③〜⑤のすべての基礎として機能する

**【GTO とのズレ】**

本書のフローは GTO との整合率が約 92.6% です。主なズレは 3 点あります。第一に、T1 の「常にベット」原則——GTO では TPTK を一部チェックバックに混ぜます。第二に、サイズ選択——本書の 3 分類（mono→75% / 2tone・connected・paired→50% / dry rainbow→33%）は GTO が混在させる 50% や 66% の細かいバリエーションを捨象しています。第三に、OOP の CR 頻度——本書はシンプルに「HS ≥ 40（SPR≥6）なら CR 検討」としていますが、GTO では FD や OESD の CR ブラフも大量に含まれます。これらの精密化は巻③で扱います。
