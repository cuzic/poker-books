# 第05章　CBet サイズ選択

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: CBet するとき、3種類のサイズ（33% / 50% / 75%）のうちどれを選べばよいかを、ボードテクスチャから即決できるようにします。

---

前章でCBetをすべきかどうかを判断する「黄金律」を習得しました。CBetを実行すると決まったら、次はサイズを決める番です。「とりあえず 33%」で毎回済ませていませんか？　実はボードの性質によって最適サイズが変わり、サイズを誤ると EV（期待値）をじわじわ失います。

本章では GTO ソルバー実測（TexasSolver、pot=10、44 シナリオ）に基づいて、「dry rainbow → 33%」「2tone / connected / paired → 50%」「mono → 75%」という3分類を解説します。

---

## 5-1 なぜサイズを 3 つに絞るか

GTO は実際には 33% / 50% / 75% / 100% 以上を状況に応じて混在させます。しかし実戦では判断速度が求められるため、本書では 3 択に圧縮します。

この3択で発生する EV ロスは 1〜2% 以内に収まることが知られています。プロやGTO研究者ほど多くのサイズオプションを使いますが、初中級者の段階では「3択を正確に選ぶ」ことの方が「4択以上を曖昧に使う」よりも有益です。

**CBet サイズ決定ルール（GTO 準拠）**

```
mono（B=70、全スーツ統一）             → 75%
paired_high（B=83、ペアボード高）      → 50%
その他すべて（B ≤ 67）                → 33%
```

GTO 実測の分布（44 シナリオ）を見ると、全体で 33% の使用率が 69.4%、75% が 23.2% であることがわかります。dry rainbow ボード 30 枚に絞ると 33% の使用率は 71.0%（構成比 78%）まで上がります。つまり、「最もよく使われるサイズは 33%」というのが GTO の答えです。

---

## 5-2 33% が正解のボード：dry rainbow

**B ≤ 67 の非モノトーン・非ペアボード高ボード**（例：K♣7♦2♠、Q♦5♣3♠、A♠5♦2♣、J♠T♦8♣）は dry rainbow / rainbow 系に分類します。

これらのボードで IP は**レンジベット（range bet）**を行います。レンジベットとは、ハンドの強弱に関係なく保有するすべてのレンジにベットする戦略です。なぜ全ハンドにベットできるかというと、K72 レインボーのようなボードでは IP（BTN）の方が BB よりも Kx・高ペアなどの強いハンドを多く持っているからです。

全ハンドにベットするなら、サイズは「小さくする」のが均衡解です。理由は次の通りです。

```
大サイズ（75%）でベットする場合:
  バリューハンドと混ぜられるブラフの量が多く必要
  → ブラフが足りないとバランスが取れない
  → 相手は「大サイズ = バリュー寄り」と読める

小サイズ（33%）でベットする場合:
  全レンジ（T1/T2/T3）をバランスよく混ぜやすい
  → 相手はフォールドか対応かの判断が難しくなる
  → IP がレンジ全体で EV を確保しやすい
```

GTO 実測では dry rainbow の 33% 使用率が 78% に達します。「干いたボードは小さく全面ベット」が正解です。

**ポット計算（SRP、pot=6bb、標準）**

```
33% CBet: bet = 2bb → コール後の pot = 10bb、stack ≈ 96bb
SPR（スタック ÷ ポット）= 96 ÷ 10 = 9.6
```

SPR（スタック・ポット・レシオ）は 9.6 なので、ターンでもさまざまなサイズを選べます。複数ストリートの計画を立てる余裕があります。

---

## 5-3 50% が正解のボード：2tone / connected / paired

ドロー系の脅威がある中程度の湿ったボードでは、50% のベットサイズが均衡解に近づきます。

**対象テクスチャ**

| テクスチャ | 例 | B 値 |
|---|---|---|
| 2tone（2スーツ同色） | J♥7♥2♣ | 50 |
| rainbow_connected（連続系、top≥J） | J♠T♦8♣ | 67 |
| paired_low（低ランクペア） | 7♠7♦3♣ | 60〜80 |
| paired_high（高ランクペア） | K♣K♦7♠ | 83 |

**なぜ 50% か**

これらのボードでは OOP（BB）がフラッシュドローやストレートドローを保有しています。33% では相手にドローに対する「安いコール」を与えすぎます。75% では T2/T3 のブラフコストが高くなりすぎ、均衡ベット量を確保しにくくなります。50% がその中間で、ドローにコストをかけつつバランスを保てるサイズです。

AKs on K♣7♣2♠（2tone_ak、B=56）で 50% をベットした場合のポット計算は次の通りです。

```
50% CBet: bet = 3bb → コール後の pot = 12bb、stack ≈ 94bb
SPR = 94 ÷ 12 ≈ 7.8
```

33% より SPR が小さくなり、ターンでのコミット感が増します。ドロー系のハンドにはこのコストが効きます。

**paired_high の注意点**

K♣K♦7♠ のような高ペアボードは B=83 で数値が高いですが、サイズは 50% が適切です。このボードでは BB が KK（クワッズ）や K7（フルハウス）などナッツ級ハンドを持っている可能性は低いものの、A-high キッカーやポケットペアなど守りやすいハンドが多く残ります。大サイズで無理に押すよりも、50% で守備を維持させながらポットを育てる方が均衡に近い選択です。

---

## 5-4 75% が正解のボード：mono（モノトーン）

全スーツが統一されたボード（例：7♠5♠2♠）は mono と呼ばれます。このテクスチャでは 75% の大サイズが均衡解です。

**なぜ大サイズか**

mono ボードでは、BB がフラッシュドロー（9アウツ）を多く保有しています。33% のような小サイズでは、フラッシュドローに対してポットオッズがよくなりすぎます（コール額÷最終ポット = 2÷8 ≒ 25%、フラッシュドローの勝率は次の1ストリートで約 36%）。IP がエクイティ優位を守るには、ドローにコストをかけて「正しいフォールドを強いる」ことが重要です。

```
75% CBet: bet = 4.5bb → コール後の pot = 15bb、stack ≈ 91.5bb
SPR = 91.5 ÷ 15 ≈ 6.1
```

SPR が 6.1 と低めになるため、ターンでのベットは「コミット宣言」に近くなります。この状況を事前に意識して、ターンでもベットし続けられる強いハンド（T1）や、強力なドロー（コンボドロー）を持っているときに 75% CBet を選びましょう。

**77 on 7♠5♠2♠ の例**

77 はセット（HS=85）で T1 です。しかも 7♠ は相手のフラッシュドローを「ブロック」する効果があります（相手の 7 スーツ保有コンボを減らす）。このような状況では 75% CBet でポットを大きく育てることが最善です。

---

## 5-5 サイズとポット計算の早見表

SRP（pot=6bb）でのベット額とターン到達時のスタック・ポット・SPR をまとめます。

| サイズ | bet 額 | コール後 pot | stack | SPR |
|---|---|---|---|---|
| 33% | 2bb | 10bb | 96bb | 9.6 |
| 50% | 3bb | 12bb | 94bb | 7.8 |
| 75% | 4.5bb | 15bb | 91.5bb | 6.1 |

SPR が大きいほどターン以降に判断の余裕があります。33% CBet ならターンでも 33% / 50% / 75% などサイズを選べます。75% CBet ではターン SPR が 6 前後となり、コミット判断が近くなります。

**サイズ選択のまとめ**

| ボードテクスチャ | B 値 | CBet サイズ | 戦略意図 |
|---|---|---|---|
| dry rainbow | < 62 | 33% | レンジベット・均衡維持 |
| 2tone | 50 | 50% | ドローにコスト |
| rainbow_connected | 67 | 50% | ストレートドローにコスト |
| paired_high | 83 | 50% | ナッツ恐怖・均衡維持 |
| mono | 70+ | 75% | フラッシュドローに高コスト |

---

## 5-6 T1 強ハンドは大サイズも可

ルール外の例外として、T1 の強いハンド（セット、2ペア、フルハウスなど）は、ボードテクスチャに関係なく 75% のオーバーサイズを使うことができます。

たとえば K♣7♦2♠（dry rainbow）で 77（セット、HS=85）を持つ場合、通常ルールでは 33% です。しかし 75% でベットして相手に「払いすぎのコール」を強いることも EV が高い選択肢です。ただし 75% を使いすぎると「大サイズ = 強いハンド」と読まれてしまいます。T1 であっても基本は 33% を守りつつ、時折 75% を混ぜる程度が均衡的です。

---

## 5-7 OOP フォールド率と GTO 整合性

GTO ソルバー実測では、CB サイズ別の BB フォールド率も確認されています。

```
OOP（BB）のフォールド率（GTO 実測）:
  vs 33%: 26.9%  ≈ 理論的後手下限確率 25%（33% サイズ）
  vs 75%: 45.2%  ≈ 理論的後手下限確率 43%（75% サイズ）
```

後手下限確率（MDF：Minimum Defense Frequency の補数）は「相手がブラフを利益なしにするために最低限守らなければならないコール率」です。GTO 実測の数値が後手下限確率とほぼ一致しており、ソルバーがバランスの取れたサイズを使っていることがわかります。

この結果は本書のサイズルールがGTOと整合していることを支持しています。

## ミニクイズ

### 問 1

BTN vs BB の SRP フロップです。ボードは Q♦5♣3♠（dry rainbow、B=58）、あなたは BTN で AA（HS=80、T1）を持っています。正しい CBet サイズはどれですか。

A. 33%（dry rainbow なのでレンジベット）
B. 50%（T1 強ハンドなので中サイズ）
C. 75%（AA なので大サイズで育てる）
D. チェックバック（T1 でも dry でチェック）

### 問 2

ボードは K♥9♥3♣（2tone、B=50）、BTN で AKs（HS=71、T1）を持っています。正しいサイズはどれですか。

A. 33%（T1 は常に小サイズ）
B. 50%（2tone なので中サイズ）
C. 75%（TPTK なのでバリューを最大化）
D. チェックバック（AKs は微妙なので慎重に）

### 問 3

75% CBet が最も適切なボードテクスチャはどれですか。

A. K♣7♦2♠（B=62、rainbow_ak）
B. J♥7♥2♣（B=50、2tone）
C. 7♠5♠2♠（B=70、mono）
D. 9♠8♦7♣（B=55、rainbow_connected）

---

### 解答

- **問 1**: **A**（Q53r は dry rainbow。T1 強ハンドでも基本は 33% のレンジベット。たまに 75% を混ぜることも可だが、標準は 33%）
- **問 2**: **B**（K♥9♥3♣ は 2tone。ドローにコストをかける 50% が正解。33% では相手のハートドローにポットオッズを与えすぎる）
- **問 3**: **C**（mono ボードは全スーツ統一でフラッシュドロー多数。75% で高コストをかけるのが正解。A は dry rainbow → 33%、B は 2tone → 50%、D は rainbow_connected → 50%）

---

> **本章まとめ**
>
> - サイズは「dry rainbow → 33%」「2tone / connected / paired → 50%」「mono → 75%」の3択で判断する。
> - dry rainbow での 33% はレンジベット戦略。GTO 実測で 78% の確率で使用される最多サイズ。
> - 2tone や connected では 50% でドローにコストをかけながら均衡を保つ。
> - mono では 75% でフラッシュドローに高コストを強いる。
> - T1 強ハンドは基本ルール通りのサイズを守りつつ、時折大サイズを混ぜることができる。
> - サイズが変わるとターン SPR が変わる（33% → SPR=9.6 / 75% → SPR=6.1）ため、マルチストリートの計画と合わせて考える。

---

**【GTO とのズレ】**

GTO は paired_high ボードで 50% と 75% を状況に応じて混在させます。本章では「paired_high は 50%」と単純化しましたが、バリューハンド（T1 強）が 75% を使う場面もあります。実戦ではこの点でズレが生じやすいですが、50% を基本に守ることで大きなマイナスは生じません。
