## 本書の位置づけ

本書は 4 巻シリーズ『迷わないポーカー』の**第 2 巻、フロップ[基礎]編**です。

| 巻 | タイトル | 内容 |
| --- | --- | --- |
| ① | プリフロップ — 覚えなくていいレンジの考え方 | プリフロップの意思決定、ハンドスコア、ポジション |
| **②** | **フロップ[基礎] — 秒で決まるボード判断 (本書)** | **フロップの型判定、CBet の頻度/サイズ/判定** |
| ③ | フロップ[応用] — 相手のレンジを読んで搾取する | 精密レンジスコア、混合戦略、レンジ推定、搾取 |
| ④ | ターン・リバー — 引きと脅しの使い分け (執筆予定) | ターン・リバーの統合戦略 |

本書は **初心者・中級者向け** に設計されています。上級者向けの精密モデル (精密レンジスコア)、混合戦略は巻③（フロップ[応用]）で、ターン・リバーは巻④・⑤で扱います。本書の付録Dに精密レンジスコアの完全係数表のみ掲載しているため、上級の方も次巻までの参考資料として利用できます。

## 本書の 3 段階学習法

本書の読者は次の3段階のいずれかに該当します。自分のレベルに合わせて読み方を選んでください。

### 初心者 (第I部・第1〜7章)

**対象**: フロップで「何をしていいか分からない」が多い人。プリフロップ編は読了済み。

**学習内容**:

- ボードを **7 型**に分類する（第3章）
- 型別の **アクションプラン**を覚える（第4章）
- 自分のハンドを **強/中/弱**に分ける（第5章）

**到達目標**: フロップを見たら5秒で「型 → プラン → アクション」が引ける。覚える数字は **5-10 個だけ**。

**想定期間**: 平日30分 × 1週間。

### 中級 (第II部・第8〜18章)

**対象**: 第I部を習得済み。具体的な %で考えられるようになりたい人。

**学習内容**:

- **簡易レンジスコア チェックリスト**でCBet頻度 %を算出（第8章）
- **HandScore** を精緻化（第9章）
- **9 マスマトリクス**でアクション決定（第10章）
- ベットサイズ、MDF、SPR、マルチウェイ、3betポット、相手タイプ別調整

**到達目標**: GTOソルバーと誤差6% 以内で一致する判断ができる。6-max 100BBキャッシュのSRP全局面に対応。

**想定期間**: 第I部の後、平日30分 × 3-4週間。

### 上級への接続 (第19章)

本書最終章は「ここまでで何ができるようになったか」のまとめと、巻③への橋渡しです。

### 2 つの道（読者の選択肢）

**A. 離散派の道（「型」で覚える）**

```
ch3 7 型 → ch4 21 マス → 実戦投入可能（最短コース）
```

パターン認識・暗記で動きたい人向け。**ライブで瞬発判断する**のに最適。

**B. 連続派の道（「式」で考える）**

```
ch8 簡易レンジスコア → ch9 HandScore → ch10 9 マス → 実戦投入可能
```

% で柔軟に判断したい人向け。**3-bet ポットや異シナリオへの拡張性**が高い。

### 推奨ルート（標準）

```
ch3-4（離散の入門で勘を掴む） → ch8-10（連続版で精密化） → ch11 以降（補正と拡張）
```

両派を**段階的に身に着ける**のが標準。ch3-4 で動けるようになったら、すぐ ch8-10 で精密化 → 上級の章へ。

各章の冒頭に「**現在地**」のミニ地図がある。例:


これで「いま自分はマップのどこにいるか」を一目で確認できる。

## フロップ用語ミニマム

本書で頻繁に登場する用語を先にまとめます。詳しくは付録Hの用語集を参照してください。

### アクション

- **CBet (Continuation Bet)**: プリフロップレイザーがフロップで最初に打つベット
- **チェック**: ベットせずにアクションを相手に回すこと
- **チェックレイズ**: チェックの後、相手のベットにレイズ
- **ドンクベット**: BBなどOOPからレイザーに対して打つベット

### ポジション

- **IP (In Position)**: 相手より後に行動できる。BTN/CO等
- **OOP (Out of Position)**: 相手より先に行動する。SB/BB等

### ボード構造

- **レインボー**: 3枚とも異なるスート
- **2-tone**: 3枚のうち2枚が同スート
- **モノトーン**: 3枚とも同スート
- **連続3枚**: ランクの最大差が2以内

### 役

- **TP (Top Pair)**: ボードの最高ランクとペアを作った状態
- **TPTK / TPGK / TPWK**: トップペア + トップ/グッド/ウィークキッカー
- **オーバーペア**: ボードの最高カードより高いポケットペア
- **セット**: ポケットペアがボードで3枚目を引いた
- **OESD**: 両端ストレートドロー（8アウツ）
- **FD**: フラッシュドロー（9アウツ）

### 状況

- **SRP (Single Raised Pot)**: プリフロップで1人がレイズ、コールされたポット
- **3bet ポット**: プリフロップで3-bet（リレイズ）されたポット
- **マルチウェイ**: 3人以上残っているポット
- **SPR (Stack-to-Pot Ratio)**: フロップ時点のスタック ÷ ポット

## 目標到達点

本書を読了した読者が手にするものは：

- 6-max 100BBキャッシュのフロップ判断で **GTO との誤差 6% 以内**
- 7型のボード分類 + アクションプラン（初心者編）で **即座に動ける**
- 簡易レンジスコア + 9マスマトリクス（中級編）で **% で柔軟に調整できる**
- 覚える数字は **10-20 個**、ロジックは **5-7 個** の軽量な道具

これでNL10からNL200程度のオンラインキャッシュで安定して勝率プラスを目指せます。NL500以上を目指す読者は、巻③の精密レンジスコア・混合戦略、巻④・⑤のターン・リバー戦略へ進んでください。

それでは第1章に進みましょう。
