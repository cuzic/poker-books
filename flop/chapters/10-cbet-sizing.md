# 第10章　CBet サイズの選択（33% / 75% / 150%）

<!-- markdownlint-disable MD033 MD036 MD040 MD060 -->
<!-- textlint-disable preset-ja-technical-writing/no-mix-dearu-desumasu -->
<!-- textlint-disable preset-jtf-style/4.2.9.ダッシュ(-) -->

> 「ベットするかどうかは第7〜9章で決めた。次の問いは『いくらで打つか』だ。このサイズひとつで、相手がコールするかフォールドするかが大きく変わる」

## 本章の焦点

第7〜9章では「CBetを打つかどうか」をCBet統合式によって判断する方法を学びました。CBet統合式が「打つ」という結論を出したとき、次に向き合うべき問いがあります。それが**ベットサイズの選択**です。

同じ「打つ」という判断でも、ポットの33% と75% では相手への圧力がまったく異なります。小さく打てば多くの相手が降りず、コールが増えます。大きく打てば降りやすくなりますが、コールされたときのリスクも増えます。サイズはただの数字ではなく、レンジ全体に送るメッセージです。

本章では現代ポーカーで標準とされる3段階のサイズ――**33%（レンジベット）・66〜75%（ポラライズ）・150%+（オーバーベット）**――を体系的に学びます。それぞれの使いどころと、その背後にある原則を理解することで、あなたのフロップCBetは「とりあえずハーフポット」から卒業できます。

---

## 10-1　サイズ選択の2軸原則

GTO Wizardの分析によれば、CBetサイズを決める主なドライバーは2つです。

### 軸1：ナッツアドバンテージ → サイズを決める

**ナッツアドバンテージ**とは、そのボードで「最強の役（ナッツ）」を自分がどれだけ多く持っているかの優位性です。

- **自分がナッツを多く持つ**：大きいサイズを使う
- **相手がナッツを多く持つ**：小さいサイズか、チェック

たとえば、BTN vs BBでK-7-2レインボーのボードを考えます。BTNはAK、KK、AAのようなプレミアムハンドをオープンレンジに含みます。一方、BBのコールレンジにはそのような超強ハンドが少ないです。このボードではBTNに明確なナッツアドバンテージがあるため、大きいサイズを選びやすくなります。

### 軸2：レンジアドバンテージ → 頻度を決める

**レンジアドバンテージ**とは、自分のレンジ全体の平均エクイティが相手より高い状態です。

- **レンジアドバンテージが大きい**：ベット頻度が上がる
- **レンジアドバンテージが小さい**：チェック頻度が上がる

重要なのは、**レンジアドバンテージは「頻度」を決め、ナッツアドバンテージは「サイズ」を決める**という分業です。この2軸を混同すると、強いハンドを小さく打ったり、レンジ優位を過信して大きく打ちすぎたりする誤りが生じます。

### ブレークイーブンフォールド率との関係

サイズが大きくなるほど、ブラフが成立するために必要なフォールド率は上がります。以下の計算式でサイズごとのブレークイーブンフォールド率を把握しておきましょう。

```
ブレークイーブンフォールド率 = ベット額 ÷ (ポット + ベット額)
```

| サイズ | ブレークイーブンフォールド率 | 相手の必要ディフェンス率 |
|--------|--------------------------|----------------------|
| 33% ポット | 25% | 75% |
| 50% ポット | 33% | 67% |
| 75% ポット | 43% | 57% |
| 100% ポット | 50% | 50% |
| 150% ポット | 60% | 40% |

33% のベットはわずか25% がフォールドするだけでブラフが損益分岐に達します。つまり、小さいベットは安価なブラフが可能になります。一方、150% のオーバーベットは60% のフォールド率が必要です。大きいベットには相手のレンジにほとんどナッツがないという条件が必要になります。

## 10-2　33%（レンジベット）：ドライボードの主力

### 何が起きているか

33% のレンジベットは、**ドライ・非コネクテッドボードで全レンジを高頻度でベットする戦略**です。ポーカーソフト（ソルバー）がドライボードで最もよく使うサイズであり、現代の標準的なアプローチになっています。

ベット頻度は65〜80% と高く、サイズは小さいです。一見「弱そうなベット」に見えますが、これには明確な論理があります。

- **相手に不利なポットオッズを押しつける**：33% のベットをコールするには、相手はポットの25%（ポットオッズ1:3）のエクイティが必要です。ボードを外した相手はこれを満たせないためフォールドします。
- **ブラフのコストが低い**：空振りのハンドでCBetするとき、ポットの33% のリスクで済みます。ブレークイーブンは25% のフォールド率なので、少し降りてくれるだけで採算が合います。
- **バリューとブラフを区別しない**：強い手と弱い手を同じサイズで打つため、相手はあなたのハンドを読みにくくなります。

### 適切な場面

33% のレンジベットが最も効果的なのは以下の場面です。

**ドライハイカードボード（K72r、A83r）**

ストレートドローもフラッシュドローもない静的なボードです。相手がフロップでドローを持つ可能性が低く、次のターン・リバーでエクイティが逆転しにくいです。このため、小さいベットで幅広いハンドをベットし、レンジアドバンテージを安く行使できます。

**ペアードボード（99x、KKx、AAx）**

ペアードボードでは両者のレンジにトリップス（スリーオブアカインド）が存在します。ナッツアドバンテージが一方に集中しないため、小さいサイズで高頻度ベットが最適です。頻度の目安はAAx ≒ 100%、KKx ≒ 85%、TTx ≒ 70% です。

**具体例：KQ / ボード K-7-2 レインボー（K72r）IP**

```
BoardScore = 10（完全ドライ）
HandScore  = TPTK 18
CBet 統合式 = 18 + (10 − 5) + 3 = 26 → CBet 75%

※ CBet 統合式は「打つか否か」を決める。
  サイズはボードがドライなので 33% に下げて採用する。
```

このケースではどちらのサイズでも「打つ」という判断は変わりません。ただし、K72rでは相手のレンジにナッツ（ナッツフラッシュ、ナッツストレート）がないため、小さいサイズで高頻度に打つほうが長期的なEVが高くなります。

## 10-3　66〜75%（ポラライズ）：ウェットボードでドロー否定

### 何が起きているか

66〜75% の中サイズは、**コネクテッドやウェットなボードで相手のドローを高いコストにする**ための戦略です。

ウェットボードでは、相手のレンジに多くのフラッシュドロー・ストレートドローが存在します。これらのドローが実現すると、あなたの強いハンドが逆転を食らいます。ドローを降ろすためには十分なサイズが必要です。

ベット頻度はドライボードと比べて大きく下がります（30〜50%）。なぜなら、ウェットボードでは相手もナッツを多く持つため、安易にベットすると相手のチェックレイズやレンジアドバンテージに対抗できないからです。打つ回数は絞り、打つ際はサイズを大きくする――これがポラライズ戦略の本質です。

### 適切な場面

**コネクテッドボード（T98、J97、876）**

「T98」のような3連番ボードでは、相手のレンジにストレートドロー・フラッシュドロー・コンビネーションドローが豊富です。GTO Wizardの分析では、このようなボードでIPのCBetサイズは**ポットの約 71%** が推奨されます。一方、頻度は約30〜40% に落ちます。

**ウェットツートーン（K♥J♥7♦）**

フラッシュドローのあるハイボードです。KJ、KQなどのトップペア系も相手のレンジに存在するため、ナッツアドバンテージは限定的です。しかしフラッシュドローを抱える相手に安いコールを許すと長期的に損をします。66〜75% で打ち、ドローに正しいオッズ以上のコストを払わせます。

**具体例：AJ / ボード A♠T♥9♥（ツートーン） IP**

```
BoardScore = 10 − 3（連続） − 2（ツートーン） = 5（セミウェット）
HandScore  = TPTK 18 + BDFD なし = 18
CBet 統合式 = 18 + (5 − 5) + 3 = 21 → CBet 75%

→ サイズも 75% を維持する（ドロー否定が必要なウェット要素あり）
```

このボードにはTJ、89、QJなど多数のドローが存在します。相手がそれらを持つ場合、正しいポットオッズを払わせるために66〜75% のサイズが機能します。GTO WizardのデータではA♠T♥9♥ でのIP CBetはサイズ2/3ポット、頻度約37% が標準です。

## 10-4　150%+ オーバーベット：特殊状況

### 何が起きているか

オーバーベットはポットを超えるサイズでのベットです。これは強い主張――「私のレンジはあなたのレンジを圧倒している」――を意味します。

ブレークイーブンフォールド率は60% 以上になります。つまり、相手の60% 以上がフォールドしなければブラフとして成立しません。これほど高いフォールド率が見込めるのは、**相手のレンジに最強ハンドがほとんど存在しない場面**だけです。

### 適切な場面

**BTN vs BB のハイボード（AK6r など）**

ボタンのオープンレンジにはAK、KK、AAなどのプレミアムハンドが多く含まれます。BBのコールレンジには、これらのプレミアムハンドはほとんど存在しません（3betしている可能性が高いため）。

A-K-6レインボーのフロップを考えます。BTNはこのボードでセット以上のナッツを多数持ち、BBはそれに対抗できる強いハンドが少ないです。BTNがオーバーベットを選ぶと、約62% のBBがフォールドします。残りのコールレンジも弱いハンドに限定されるため、バリューとフォールドエクイティの両方が機能します。

**「今のストリートに価値が集中している」脆弱な強ハンド**

AAやAKsはオーバーベットしません。これらは将来のターン・リバーでもバリューが持続するため、3ストリートにわたって均等に価値を回収できます。

一方、**JJ や TT のオーバーペアは 9-8-7 などのコネクテッドボードでは将来の価値が低下**します。ターンやリバーで相手がストレートやフラッシュを完成させると、JJのバリューは急落します。このようなハンドは今のストリートでできるだけ多くの価値を取る必要があるため、オーバーベットが機能します。

```
将来のストリートで価値が低下するハンド + ナッツアドバンテージ圧倒的 = オーバーベット好機
```

### 注意点

オーバーベットは誤用すると大きなマイナスをもたらします。相手のレンジを正確に把握できない段階では、まず33% と75% の2サイズを使いこなすことを優先してください。オーバーベットは「150% CBet統合式スコアが ≥ 30かつ相手のレンジにナッツがほぼない」と判断できる場面に限定します。

## 10-5　ウェットネス・パラボラ

ボードの「ウェットネス（湿り度）」とサイズの関係は、直感に反して単純な比例ではありません。**放もの線（パラボラ）状の関係**になります。

GTO Wizardが提唱する「ウェットネス放もの線」の概念を図示すると以下のようになります。

```
サイズ
  ↑
75%|         ●コネクテッド
  |       ●   ●
33%|    ●         ●
25%| ●               ●
  +──────────────────→ ウェットネス
    ドライ  中間  超ウェット
    (K72)  (KJ7) (T98)  (モノトーン)
```

### ドライボード → 小さいベット（33%）

K-7-2レインボーのような完全ドライボードでは、両者のレンジにドローがほとんどないです。小さいベットで幅広く価値を回収できます。

### 中程度ウェットボード → 大きいベット（66〜75%）

K♥J♥7♦ やT-9-8のようなコネクテッド・ツートーンボードでは、相手のドローを否定するために大きいサイズが必要です。このゾーンが最もサイズが大きくなります。

### 超ウェット（モノトーン） → 再び小さいベット

モノトーン（3枚同スーツ）ボードは逆説的に**小さいサイズ（25〜33%）かつ頻度大幅低下**が推奨されます。

なぜ超ウェットで小さくなるのでしょうか。モノトーンボードでは両者のレンジにフラッシュが含まれます。フラッシュを持っているプレイヤーがベットしても、相手がフラッシュを持つ場合は降りません。また、フラッシュを持ってベットすると、相手がフラッシュドローを降ろせても、そのドローはすでにあなたのハンドでブロックされているため大きなフォールドエクイティを期待できません。

モノトーンボードでは無理にポットを膨らませず、小さいサイズでエクイティを守るアプローチがGTO的に正しいです。

## 10-6　ボード別クイックリファレンス表

実戦でサイズを素早く選ぶための早見表です。IP（インポジション、有利なポジション）での標準値を示します。

| ボードタイプ | 代表例 | IP サイズ | IP 頻度 | 選択理由 |
|------------|--------|----------|---------|---------|
| ドライハイカード | K72r、A83r | 33% | 65〜80% | レンジアド大・ナッツアド限定・ドローなし |
| コネクテッド | T98、J97 | 66〜75% | 30〜40% | ドロー否定・ポラライズ必須 |
| モノトーン | K♥9♥5♥ | 25〜33% | 大幅低下 | 両レンジにフラッシュ・ポット肥大リスク |
| ペアード | 99x、K7K | 33% | 70〜100% | 両レンジにトリップス・ナッツ差小 |
| ウェットツートーン | K♥J♥7♦ | 66〜75% | 40〜50% | フラッシュドロー否定・ポラライズ |
| ロウカード乾燥 | 842r、532r | 66% | 50〜65% | IP のレンジアド大・相対的ウェット中 |

### 判断フロー

フロップを見たらまずBoardScoreを計算し、以下のフローでサイズを決めます。

```
BoardScore を計算する
      ↓
  ≥ 7（ドライ）→ 33%、高頻度
      ↓
  4〜6（セミウェット）→ 66〜75%、中〜低頻度
      ↓
  ≤ 3（超ウェット）→ チェック優先
      ↓ ただし
  モノトーン → 25〜33%、低頻度（パラボラ例外）
      ↓
  ナッツアドが圧倒的かつ将来価値が低下 → 150%+ 検討
```

---

> **補足（第27章への接続）**: 本章の33%と75%の2択はボードのドライ度で決める固定的な運用ですが、同じサイズを毎回使うとパターンが読まれます。第27章のR4（サイズ2択）では、NutsAdv（ナッツアドバンテージ）の簡易判定とR2（スート判定）を組み合わせることで、同じハンドでも33%と75%を自然に混在させる方法を扱います。

## 【GTOとのズレ】ソルバーは多段階混合サイズを使う

本章では3段階のサイズ（33% / 75% / 150%）を紹介しました。これは実戦での判断を簡略化したヒューリスティックです。実際のソルバー（GTO計算ソフト）はより複雑な戦略を採用しています。

### ソルバーの実態

ソルバーは1つのボードで複数のサイズを**混合**して使います。たとえばK72rでは33%：45%、75%：55% のように、2サイズを異なる頻度でランダムに選択します。これにより相手はサイズからハンド強度を逆算できなくなります。

また、ソルバーが使うサイズの数もボードによって変わります。ドライボードでは1〜2サイズ、コネクテッドボードなら3サイズ以上を混在させることもあります。

### 本書が3段階に簡略化する理由

- リアルタイムの判断に複数サイズの混合戦略は実行が難しい
- 初・中級者の段階では「どのサイズを選ぶか」の原則を定着させることが優先される
- 3段階ヒューリスティックはGTOの80〜90% 程度の精度を再現できる

GTOとの乖離が大きいのは「セミウェットボードでソルバーがサイズ混合を多用する」場面です。4〜6のBoardScore帯では、本書の66〜75% 一択が最適ではない場合があります。しかし初・中級者の段階では、この誤差より「サイズを考えずにハーフポットで固定する」ことによる誤差のほうが大きいです。まず3段階を正確に使えるようになることを目指してください。

---

## まとめ

- サイズ選択の2軸は「ナッツアドバンテージ → サイズ」「レンジアドバンテージ → 頻度」
- **33%（レンジベット）**：ドライ・ペアードボードで高頻度、ブラフのコスト低減
- **66〜75%（ポラライズ）**：コネクテッド・ウェットボードでドロー否定、低頻度
- **150%+（オーバーベット）**：ナッツアドが圧倒的かつ将来価値が低下する特殊状況
- **ウェットネス放もの線**：ドライ→小、中間→大、超ウェット（モノトーン）→小
- ソルバーは多段階混合サイズを使うが、本書は3段階に簡略化している

## ミニクイズ

**問題1**

ボード：7♠4♥2♣（レインボー、完全ドライ）、IP（ボタン）でのCBetに最も適したサイズはどれですか。

1. 25% ポット
2. 33% ポット
3. 75% ポット
4. 150% ポット

<details>
<summary>解答</summary>

**2. 33% ポット**

完全ドライのローボードです。BoardScoreは高く（ドロー要素ゼロ）、IPはレンジアドバンテージを持ちます。33% の高頻度ベットで安価にレンジアドバンテージを行使します。

</details>

---

**問題2**

ボード：T♥9♠8♠（コネクテッド、スーテッド2枚）、あなたはIPでオーバーペアのJJを持っています。最もサイズ選択として適切な記述はどれですか。

1. JJはナッツ級なので33% で安く高頻度に打つ
2. ウェットボードでドローが多いため66〜75% で打つ
3. モノトーンに近いので25% で打つ
4. 超強ハンドなのでオーバーベット150% を選ぶ

<details>
<summary>解答</summary>

**2. 66〜75% で打つ**

T98はコネクテッドボードの典型例です。相手のレンジにはOESD（両面ストレートドロー）やフラッシュドロー・コンビネーションドローが豊富に含まれます。JJはオーバーペアですがターン・リバーでアウトストライプされる可能性が高く、今のストリートで適切なコストを払わせる必要があります。66〜75% がこの局面の標準サイズです。

</details>

---

**問題3**

ブレークイーブンフォールド率の計算式を使って、75% ポットのベットに対するブレークイーブンフォールド率を求めてください。ポットを100とします。

<details>
<summary>解答</summary>

```
ブレークイーブンフォールド率 = ベット額 ÷ (ポット + ベット額)
                            = 75 ÷ (100 + 75)
                            = 75 ÷ 175
                            ≈ 0.43（43%）
```

75% ポットのブラフが損益分岐に達するには、43% 以上のフォールド率が必要です。33% ベット（ブレークイーブン25%）と比べて、より多くのフォールドが必要になることがわかります。

</details>
