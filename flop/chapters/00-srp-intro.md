# はじめに　フロップを制するとは ── SRP 標準状況

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> 本書は「フロップの判断を暗算で回す」ための一冊です。ボードを4ステップで数値化し、手の強さを式に代入するだけで、CBet するかしないか、コールするかフォールドするかを決められます。

---

## なぜ SRP を最初に学ぶのか

テキサスホールデムのハンドのうち、実際にフロップへ進む大半は**SRP（シングルレイズポット）**です。SRP とは、1人がオープンレイズし、1人がコールして進んだ状況を指します。3-bet ポットや 4-bet ポットより圧倒的に頻度が高く、実戦で最も多く直面するシナリオです。

本書では、SRP の標準状況として **BTN（ボタン）が 3bb でオープンし、BB（ビッグブラインド）がコールする** ケースを基本に据えます。このシナリオを軸にすることで、全判断式の「基点」を一つに固定できます。

他のポジション（UTG vs BB、CO vs BB など）でも同じ式を使えますが、まず BTN vs BB で感覚をつかむことが上達への近道です。

---

## SRP 標準状況の数値を押さえる

フロップでの判断を式に代入するには、ポット額とスタック額を正確に把握しておく必要があります。BTN vs BB の SRP では次の数値が基本になります。

```
BTN open 3bb + BB call 3bb = pot 6bb
実効スタック = 100 − 3 = 97bb

フロップ CBet 33% でベット: bet ≒ 2bb → pot=10bb、stack=95bb（コール後）
フロップ CBet 75% でベット: bet ≒ 4.5bb → pot≒15bb、stack≒92bb（コール後）
```

**pot=6bb、stack=97bb** がフロップの出発点です。ここから CBet を打ち、コールされるとターンの基点は **pot=10bb（33% CBet の場合）** になります。巻④と巻⑤がターン・リバーを扱う際にも、この pot=10bb を「ゴールデン標準」として参照します。

### SPR（スタック／ポット比）を確認する

SPR（Stack-to-Pot Ratio）とは、残りスタックをポットで割った値です。SPR が大きいほどポストフロップの余地が大きく、SPR が小さいほど早い段階でスタック全体が賭かります。

| 状況 | スタック | ポット | SPR |
|------|---------|-------|-----|
| SRP フロップ（CBet 前） | 97bb | 6bb | 約 16 |
| 33% CBet コール後 | 95bb | 10bb | 約 9.5 |
| 75% CBet コール後 | 92bb | 15bb | 約 6 |

本書の式は SPR≥6（大スタック）を前提に設計されています。SPR が 3 以下になる状況（3-bet ポット等）では補正が必要です（第15章）。

## 5 ステップフロー：フロップ判断の全体像

本書の判断は、次の **5 ステップ** で完結します。各ステップは後続の章で詳しく解説しますが、まず全体の流れを把握してください。

```
Step 1: B（ボードスコア）を計算する        ← 第1章
Step 2: HS（ハンドスコア）を計算する       ← 第9章
Step 3: Tier（ハンドの格）を判定する       ← 第5章
Step 4: CBet の判断を下す                 ← 第10章
Step 5: CBet サイズを選ぶ                 ← 第11章
```

各ステップはすべて暗算で処理できます。慣れれば 3 秒以内に判断が出ます。

### Step 1 ─ B を計算する

B（ボードスコア）は、フロップの 3 枚が**IP（イン・ポジション）側にどれだけ有利か**を 0〜100 の数値で表します。B が高いほどコンティニュエーションベット（CBet）が機能しやすく、低いほど OOP（アウト・オブ・ポジション）側が ドローや強いハンドを豊富に持ちます。

第1章では「9 つのルール」によって B を素早く計算する方法を習得します。

### Step 2 ─ HS を計算する

HS（ハンドスコア）は、自分のハンドの強さを 0〜50 で表します。計算式は次のとおりです。

```
HS = 役スコア + ドロー加点 + ブロッカー加点
```

「役スコア」はペア・セット・ストレートなどの役の強さ、「ドロー加点」はアウツに応じた期待値、「ブロッカー加点」は相手のナッツを妨害するカードへの加点です。第9章で完全な計算表を習得します。

### Step 3 ─ Tier を判定する

本書では HS の値に応じてハンドを 3 つの格（Tier）に分類します。

| Tier | HS の範囲 | 代表的なハンド |
|------|-----------|--------------|
| T1（強い） | 65 以上 | セット、2ペア、ナッツドロー、TPTK+FD |
| T2（中程度） | 20〜64 | TPTK、オーバーペア、強いドロー |
| T3（弱い） | 19 以下 | 弱いペア、ガットショット、空振り |

T1 はほぼ常にベット、T2 はボードによってベットかチェックかが変わり、T3 はボードが非常にドライなときだけベットします。

### Step 4 ─ CBet の判断を下す

Tier と B を組み合わせて CBet するかしないかを決めます。

```
T1 → CBet（ほぼ常に）
T2 → CBet if B ≥ 58
T3 → CBet if B ≥ 62
```

T2 の閾値 58 と T3 の閾値 62 は、本書を通じて何度も登場する重要な数値です。今の時点では「そういう数字がある」と覚えておくだけで十分です。

### Step 5 ─ CBet サイズを選ぶ

CBet をすると決まったら、次はサイズです。本書では主に 33%、50%、75% の 3 種類を使います。

```
モノトーン（3枚同スート）ボード → 75%
2トーン・コネクテッド・ペアボード → 50%
ドライレインボー → 33%
```

サイズの細かい選択基準は第11章で扱います。

---

## OOP 側の守備フロー

あなたが BB（OOP 側）で CBet を受ける立場のときは、次のフローで判断します。

```
1. HS を計算する
2. 相手のベットサイズに応じた基本閾値を確認する
   - vs 33% CBet: 閾値 = 15
   - vs 75% CBet: 閾値 = 35
3. HS < 閾値 → フォールド
4. HS ≥ 閾値 → コール（あるいは HS ≥ 40+ かつ SPR≥6 ならチェックレイズも）
```

この守備フローは第13章・第14章で詳しく解説します。閾値には「2トーンボードは +5」「ペアボードは −10」といった補正もありますが、まずは上の基本値を使えば十分です。

## GTO 検証済みの精度について

本書の式は、GTO ソルバー実測データと照合しています。

- 簡易レンジスコア：GTO との相関 R² ≈ 0.873、平均誤差 ±6.0%
- CBet 閾値（T2→B≥58、T3→B≥62）：GTO CBet 率 90〜100% のボードで一致
- 代表的なボードでの GTO CBet 率：K72r ≒ 99.9%、Q53r ≒ 95.6%

完全な GTO とのズレは各章末の【GTOとのズレ】コラムで都度説明します。式は「暗算で回せる精度」を優先しているため、境界付近のハンドでは 5〜10% 程度の判断差が生じることがあります。

---

## 【GTOとのズレ】

本書の 5 ステップフローは、GTO の複雑な混合戦略を「T1/T2/T3 × ボードスコア」という簡略化で代替しています。GTO は同一ハンドでもベット頻度を 40〜60% の混合にすることが多く、本書の「閾値を超えたら常にベット」という判断は GTO より少し単純化されています。この差が実戦 EV に与える影響は、NL50 以下の環境では 0.1bb/100 未満と推計されています。

## 章のまとめ

- SRP 標準状況は BTN vs BB、pot=6bb、stack=97bb が出発点
- 33% CBet でコールを受けると pot=10bb になり、これがターン計算の基点
- 5 ステップフロー：B → HS → Tier → CBet → Size で全判断が完結
- T1（HS≥65）は常にベット、T2（HS 20〜64）は B≥58 でベット、T3（HS<20）は B≥62 でベット
- OOP 守備は vs 33% なら閾値 15、vs 75% なら閾値 35 をまず使う

## ミニクイズ

### 問1

BTN が 3bb オープン、BB がコールしてフロップへ。このとき pot とスタックはそれぞれいくらですか？

A. pot=5bb、stack=98bb  
B. pot=6bb、stack=97bb  
C. pot=7bb、stack=96bb  
D. pot=6bb、stack=100bb

### 問2

HS（ハンドスコア）が 45 のハンドの Tier はどれですか？

A. T1  
B. T2  
C. T3  
D. Tier 分類は HS では行わない

### 問3

T2 ハンドで CBet を打つ基本の B 閾値はいくつですか？

A. 50  
B. 55  
C. 58  
D. 62

---

### 解答

- **問1**：B。BTN が 3bb 使い、BB が 3bb コールするため pot=6bb。実効スタックは 100−3=97bb。
- **問2**：B。T2 は HS が 20〜64 の範囲。HS=45 は T2 に該当します。
- **問3**：C。T2 は B≥58 で CBet します。B≥62 は T3 の閾値です。
