# 第07章　C 値：どれだけ押すか

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> CBet を打つとき、あなたはどのサイズを選んでいますか？
> 「なんとなく 33%」「強そうだから 75%」では長期的に EV を取りこぼします。
> 本章では、ベットサイズの「圧力の強さ」を数値化した **C 値（コミットメント係数）** を習得します。
> C 値は「このベットが相手に要求するフォールドの度合い」を HandScore のスケールに乗せた指標です。
> ブラフが成立するかどうかの判定式として使えます。

---

## 7-1　α（アルファ）とは何か

CBet を打つとき、ブラフが収益的かどうかはベットサイズで決まります。
ブラフが収益ゼロになる「損益分岐点のフォールド率」を α（アルファ）と呼びます。

```
α（ブラフの要求フォールド率）= bet / (pot + bet)

【計算例】
  pot = 6bb、bet = 2bb（33%）の場合:
  α = 2 / (6 + 2) = 2/8 = 0.25 = 25%

  pot = 6bb、bet = 4.5bb（75%）の場合:
  α = 4.5 / (6 + 4.5) = 4.5/10.5 ≈ 0.43 = 43%
```

α の意味を具体的に言い換えると次のようになります。
「相手が 25% 以上フォールドすれば、このブラフはプラス EV になる」。
つまり、**α が小さいほどブラフが成立しやすく**、小サイズの CBet はブラフ向きです。

---

## 7-2　C 値の定義

α はパーセンテージとして扱いやすいですが、HandScore（0〜50 スケール）と直接比較できません。
そこで α を HS スケールに乗せた指標として **C 値** を定義します。

```
C 値 = floor(α × 50)  ← 切り捨て（round ではない）

【代入表】
  33% ベット  → α = 0.25   → 0.25×50=12.5 → C = 12
  50% ベット  → α = 0.33   → 0.33×50=16.5 → C = 16（≒17 で暗記可）
  75% ベット  → α = 0.43   → 0.43×50=21.5 → C = 21（≒22 で暗記可）
  100% ベット → α = 0.50   → 0.50×50=25.0 → C = 25
  150% ベット → α = 0.60   → 0.60×50=30.0 → C = 30
```

実戦では計算を省き、C 値（12 / 17 / 22 / 25 / 30）を直接暗記してください。

C 値の直感的な意味は「このベットを正当化するために、相手のレンジから何ポイント分フォールドさせる必要があるか」です。

- C=12（33%）: 相手に 12 ポイント分のハンドを降ろせれば収支がプラスになる。
- C=22（75%）: 相手に 22 ポイント分のハンドを降ろす必要がある。より強いハンドが必要。

**暗記する 2 点**: 実戦では 33% と 75% の 2 サイズをメインに使います。

```
33%  → C = 12（低圧力、ブラフしやすい）
75%  → C = 22（高圧力、バリューに偏る）
```

---

## 7-3　C 値の使い方：ブラフの成否判定

C 値は、次のシンプルな判定式で使います。

```
C 値 > IP の想定する OOP HS平均  → ブラフが収益的
C 値 ≤ IP の想定する OOP HS平均 → バリューベットが必要
```

より実用的には、「OOP の HS 分布の中央」と C 値を比べます。
もし相手がほとんど HS の低いハンドを持つ状況（例: 乾燥 K-high で OOP は当たりが少ない）なら、C=12（33%）でも多くをフォールドさせられます。

### 具体例：乾燥 K-high ボードでの CBet

**ボード: K♣7♦2♠（rainbow）、SRP pot=6bb**

IP（BTN）の視点: OOP（BB）のレンジで K に当たるのは KQs, KJs, KTs, KQo, KJo 程度。
BB の平均 HS はこのボードで低くなります（多くのハンドが当たらず HS ≈ 0〜10）。

- **33% CBet（C=12）**: OOP のレンジ大半が HS < 12 → 多くフォールド → ブラフが成立
- **75% CBet（C=22）**: 必要フォールドが増えるが、ボードが乾燥しているためブラフは引き続き有効

この場合、33% の range bet（全ハンドでベット）が GTO 的に均衡します（第5章・11章参照）。

## 7-4　SPR 別チェックレイズ閾値

C 値は単体で使うだけでなく、SPR（スタック・ポット・レシオ）と組み合わせてチェックレイズ（CR）の成否を判断できます。

SPR = スタック残高 ÷ ポット額（フロップ到達時）

SRP の標準フロップでは SPR ≈ 16 前後ですが、3-bet ポットでは SPR ≈ 3〜5 になります。

```
SPR 別 CR（チェックレイズ）判断閾値:

  SPR ≥ 6  → CR 閾値: HS ≥ 40   （大スタック、CR 頻度が高い）
  SPR 3〜5 → CR 閾値: HS ≥ 60   （中スタック、CR はほぼバリューのみ）
  SPR < 3  → CR 閾値: HS ≥ 75   （短スタック、CR ≈ オールイン）
```

### 閾値の意味

**SPR ≥ 6（通常の SRP フロップ）**

スタックが深いため、CR してもオールインにはならず、ターン・リバーで継続できます。
HS ≥ 40（セット・2ペア・OESD・ナッツFD 程度）でCR が選択肢に入ります。

**SPR 3〜5（3-bet ポット後のフロップ）**

ポットがすでに膨らんでいるため、CR すると大きなポットになります。
HS ≥ 60 程度の強いハンド（セット・ナッツドロー複合等）でないと CR のリスクが割に合いません。

**SPR < 3（極端に浅いスタック）**

CR がほぼオールインを意味します。
HS ≥ 75（セット以上、非常に強いハンド）でのみ CR を選択します。

### SPR の計算

```
SRP フロップ:
  スタック = 97bb、ポット = 6bb → SPR = 97/6 ≈ 16（≥ 6: 通常 CR 閾値 40）

33% CBet 後のターン到達時:
  スタック = 95bb、ポット = 10bb → SPR = 95/10 = 9.5（まだ深い）

3-bet ポット フロップ:
  スタック = 82bb、ポット = 30bb → SPR = 82/30 ≈ 2.7（< 3: CR ≈ オールイン）
```

## 7-5　C 値とブラフ EV の関係

C 値の背後にある数学を確認しましょう。
変数を 2 つに分けて整理します。

- **α_break**（損益分岐フォールド率）= bet / (pot + bet)：固定値、ベットサイズから計算
- **f**（実際のフォールド率）：相手の実際の行動。ボードとレンジによって変動

```
EV(ブラフ) = f × pot − (1 − f) × bet

f > α_break のとき EV > 0（ブラフ成功）
f < α_break のとき EV < 0（ブラフ失敗）
f = α_break のとき EV = 0（ブレイクイーブン）
```

C 値はこの α_break を HandScore スケールに変換したものです。
「C 値より HS が低いハンドをフォールドさせられるか（f > α_break か）」という視点で使います。

### 具体的なブラフ EV 計算

**ボード: K♣7♦2♠、pot=6bb、33% bet（C=12）**

α_break = 25%、OOP の実際のフォールド率 f = 50% と仮定します。

```
EV(ブラフ) = 0.50 × 6 − 0.50 × 2 = 3 − 1 = 2bb（プラス EV）
f(50%) > α_break(25%) → EV > 0 ✓
```

OOP のフォールド率が実際に 40〜46% というデータ（第6章参照）から、K72r での 33% ブラフは EV > 0 が確認できます。

## 7-6　ベットサイズ選択に C 値を活かす

CBet サイズを選ぶ際、次の考え方が有効です。

**ハンドが強い（バリュー目的）場合**

強いハンドは相手に弱いハンドでコールしてもらいたいです。
C 値が低い（小サイズ）ほどコールを得やすいですが、ポットを大きくしにくいです。
セット・強い2ペアなら、33% で広くコールを誘うか、75% でポットを膨らませるか選びます。
ボードが乾燥しているなら 33%（range bet）、ウェットなら 75% が多いです（第11章参照）。

**ハンドが弱い（ブラフ目的）場合**

ブラフなら C 値が低い方が相手のフォールドを要求する割合が低く成立しやすいです。
33%（C=12）は相手に 25% のフォールドを要求するだけなので、ブラフが通りやすいです。
ただし、相手がコールしてきた場合のリスクが残ります。

**まとめ**

```
目的      → サイズ → C 値
バリュー  → 33% or 75% → C=12 or C=22
ブラフ    → 33%         → C=12（低リスク）
マージナル→ 33% or チェック → 状況次第
```

## 7-7　主要ベットサイズの C 値一覧と実戦ガイド

| ベットサイズ | C 値 | 後手下限確率 | 実戦での使い所 |
|:---:|:---:|:---:|:---|
| 33% ポット | 12 | 75% | ドライ rainbow でのレンジ CBet、ブラフ CBet |
| 50% ポット | 17 | 67% | 2トーン・コネクテッド・ペアボード |
| 75% ポット | 22 | 57% | モノトーン・強バリュー・ターン継続重視 |
| 100% ポット | 25 | 50% | ポット拡大狙い、ターン SPR 圧迫 |
| 150% ポット | 30 | 40% | オーバーベット（ターン・リバー中心、本書は概要のみ） |

実戦で主に使うのは 33% と 75% の 2 サイズです。
「ドライなら 33%、ウェットなら 75%」という第5章のルールに加え、C 値の視点から「相手のフォールドをどれだけ要求しているか」を意識してください。

## ミニクイズ

### 問1

C 値の定義式として正しいのはどれですか？

1. C = bet / pot
2. C = floor(α × 50)（α = bet / (pot + bet)）、実戦では 12/17/22/25/30 を暗記
3. C = HS − 後手下限スコア

### 問2

IP が 75% ポットをベットした場合の C 値と後手下限確率の組み合わせとして正しいのはどれですか？

1. C=22、後手下限確率 57%
2. C=17、後手下限確率 67%
3. C=25、後手下限確率 50%

### 問3

SRP フロップ（pot=6bb、スタック=97bb、SPR≈16）でチェックレイズを検討しています。
このとき CR の HS 閾値はいくつですか？

1. HS ≥ 75（SPR < 3 の基準を適用）
2. HS ≥ 60（SPR 3〜5 の基準を適用）
3. HS ≥ 40（SPR ≥ 6 の基準を適用）

---

### 解答

- **問1**: **2. C = round(α × 50)** が正解。α はブラフの要求フォールド率で、それを 50 倍して HS スケールに乗せたものが C 値です。
- **問2**: **1. C=22、後手下限確率 57%** が正解。75% ポットでは α ≈ 0.43、C = round(0.43×50) = 22、後手下限確率 = 1 − 0.43 = 57%。
- **問3**: **3. HS ≥ 40** が正解。SRP フロップ SPR ≈ 16 は「SPR ≥ 6」のカテゴリーに入るため、CR 閾値は HS ≥ 40 です。

---

> **本章まとめ**
>
> - α = bet / (pot + bet) は「ブラフの損益分岐フォールド率」。
> - C 値 = round(α × 50) は α を HS スケールに変換した指標。
> - 主要 C 値: 33%→12 / 50%→17 / 75%→22 / 100%→25 / 150%→30。
> - 実戦の暗記 2 点: 33%→C=12 / 75%→C=22。
> - SPR 別 CR 閾値: SPR≥6→HS≥40 / SPR3〜5→HS≥60 / SPR<3→HS≥75。

---

**【GTO とのズレ】**

C 値は数学的に定義された指標であり、計算自体に GTO との誤差はありません。
ただし「C 値を上回るハンドはすべてベット、下回るハンドはチェック」という単純な使い方は GTO から外れます。
GTO では、バリューハンドでもチェックバックしてレンジバランスを保ったり、ブラフでも特定の強いコンボは CR を誘うためにベットしたりします。
C 値は「ブラフが数学的に成立するか」の一次判断であり、レンジ全体の構成は別途考慮が必要です。
