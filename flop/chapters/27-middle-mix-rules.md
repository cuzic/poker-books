# 第27章　固定を揺らす ― CBet の揺らしとサイズ2択

> **本章の目標**: 第9章〜第26章で学んだ「単一しきい値による0/1判断」をフロップに拡張し、CBet の境界付近で意図的に判断を揺らす6つのルール（R1〜R6）を習得します。暗算可能な整数演算のまま、搾取されにくいプレイに近づけます。

第26章では GTO ソルバーへの橋渡しとして、ツールや書籍のロードマップを示しました。本章はその橋を渡り始める前の「最後の仕上げ」です。本書の CBet 統合式は非常に有効なフレームワークですが、ひとつ根本的な問題が残っています。**「境界で常に同じサイズ・同じ行動をする」ことは、注意深い相手に搾取されます**。

本章ではこの問題をフロップ版として整理し、6つのルールで解決します。プリフロップ版（前作第21章）で学んだ R1・R2・R3・R5・R6 をフロップに適用し、さらにフロップならではの **R4（サイズ2択）** を新たに加えます。

---

## 27-1　なぜフロップこそ揺らすべきか

### CBet が機械化しやすい場所

プリフロップはポジションごとにレンジが比較的固定されており、観察眼のある相手には読まれやすいとはいえ、レンジの幅は一定あります。しかしフロップは違います。

CBet 統合式（第9章）を忠実に使うと、「スコア 13〜19 なら必ず 33% でベット、20 以上なら必ず 75% でベット」という決定論的なパターンが生まれます。対戦経験のある相手は、数十ハンドの観察で次のことを学習します。

- 「あの人は K ハイドライボードで必ず小さく CBet する」
- 「コネクテッドボードでチェックしたら弱い手しか持っていない」
- 「75% CBet を打ってきたときはほぼセット以上」

この学習が成立すると、相手はあなたのサイズからハンドを逆算して最適な対応を取れます。

### フロップに搾取スポットが多い理由

第9章で扱ったように、フロップは CBet 統合式の「境界」が最も頻繁に登場するストリートです。HandScore と BoardScore の組み合わせで CBet スコアが 11〜21 の範囲に収まるハンドは全体の 40〜50% に達します。プリフロップの境界スポットよりはるかに多いのです。

境界スポットが多いほど、決定論的な判断は搾取されやすくなります。

### 本章で扱う R1〜R6 の概観

本章では以下の6つのルールを導入します。前作第21章の R1・R2・R3・R5・R6 と同じ定義を使いますが、フロップの文脈に合わせた具体例を加えます。R4 はフロップ版の目玉として本章で初めて登場します。

| ルール | 内容 | 前作との関係 |
|--------|------|------------|
| **R1** | CBet スコアを3バンド化（T+2 / T−2） | 前作と同一定義 |
| **R2** | スート判定による疑似混合 | 前作と同一定義 |
| **R3** | RangeAdv 補正（+R）をフロップに適用 | 前作と符号が一部反転 |
| **R4** | サイズ2択（33% or 75%）の簡易判定 | **フロップ版で新規導入** |
| **R5** | チェックレンジ保護（強ハンドの一部チェック） | 前作から継承・深化 |
| **R6** | MDF ±10% 補正 | 前作と同一定義 |

## 27-2　CBet スコアの3バンド化（R1）

### 既存しきい値の確認

第9章の CBet 統合式の判定は次の4段階です。

```
CBet スコア = HandScore + (BoardScore − 5) + ポジション係数

≥ 20 → CBet 75%
13〜19 → CBet 33%
7〜12 → チェック
< 7 → チェック・フォールド準備
```

この4段階の中で「境界」として特に重要なのは、**20（75% / 33% の境）** と **13（33% / チェックの境）** の2本のしきい値です。

### R1 の定義

R1 では、これら2本のしきい値をそれぞれ T+2 / T−2 の「帯」に広げます。

```
しきい値 T = 20（75% / 33% の境）

Score ≥ 22（T+2）       → 強バンド：100% CBet 75%
18〜21（T−2 〜 T+1）   → 混合ゾーン：R2 で決定
Score ≤ 17（T−3）      → 弱バンド：R4 の 33% を検討

しきい値 T = 13（33% / チェックの境）

Score ≥ 15（T+2）       → 強バンド：100% CBet 33%
11〜14（T−2 〜 T+1）   → 混合ゾーン：R2 で決定
Score ≤ 10（T−3）      → 弱バンド：チェック確定
```

### 3バンド表（CBet 統合式版）

| CBet スコア | 判定バンド | アクション |
|-------------|-----------|----------|
| **≥ 22** | 強バンド（75%境界） | CBet 75% 確定 |
| 18〜21 | 混合ゾーン（75%境界） | R2 で CBet 75% or 33% |
| **≥ 15** | 強バンド（33%境界） | CBet 33% 確定 |
| 11〜14 | 混合ゾーン（33%境界） | R2 で CBet 33% or チェック |
| **≤ 10** | 弱バンド | チェック確定 |

スコアが 18〜21 の範囲にあるハンドは、R2（次節）でサイズを決めます。スコアが 11〜14 の範囲にあるハンドは、R2 で「CBet するかチェックするか」を決めます。

### 既存ルールとの互換性

R1 を使わない場合、引き続き従来の4段階で判断して構いません。強バンドと弱バンドは従来の判断と完全に一致しており、変化するのは混合ゾーンのみです。

## 27-3　スート判定ミックスのフロップ版（R2）

### R2 の定義

前作第21章と完全に同一です。混合ゾーンに入ったハンドは、**自分のハンドの高い方のカードのスートで行動を決定**します。

```
♠（スペード）または ♥（ハート）  → アクション側（CBet / ベットサイズ大）
♣（クラブ）または ♦（ダイヤ）   → 受動側（チェック / ベットサイズ小）
```

「高い方のカード」は2枚のうちランクが大きい方です。ポケットペアは左手で持っているカードを基準にします。

### フロップ版での適用場面

R2 をフロップで使う場面は主に2つです。

**場面1：CBet するかチェックするか（11〜14 の混合ゾーン）**

スコアが 11〜14 の場合、高い方のカードが ♠♥ なら CBet 33%、♣♦ なら チェックです。

例：A♦8♠ on K♥7♣2♦（CBet スコア = 0 + 5 + 3 = 8、ただし BDFD あり +4 = 12）

このハンドはスコア 12 で混合ゾーン（11〜14）に入ります。A（高い方のカード）が ♦ なので受動側 → **チェック**。同じハンドで A♠8♣ であれば → **CBet 33%**。

**場面2：サイズを 75% にするか 33% にするか（18〜21 の混合ゾーン）**

スコアが 18〜21 の場合、高い方のカードが ♠♥ なら CBet 75%、♣♦ なら CBet 33% です。この判断は R4（次節）とも組み合わせます。

### なぜ「読まれない」のか

フロップの組み合わせは 1,755 通りあります。そこにハンドのバリエーション（169 種）とポジション（5 パターン）を掛け合わせると、あなたの判断が分岐するパターンは数十万通りになります。相手が観察できるのはその一部に過ぎず、スート判定のルールを知らない限り、パターンを解析することは現実的に不可能です。

## 27-4　RangeAdv を CBet スコアに足す（R3）

### フロップ版 R3 の定義

前作の R3 はプリフロップの 3bet スコアに対して「相手のオープンポジションの強さ」で補正を入れるものでした。フロップ版では**ボードのテクスチャと自分の立場（プリフロップのレイザーかコーラーか）** で補正します。

```
R3 補正値：
  +2 … ハイカードフロップ（A / K / Q が1枚以上）× 自分がプリフロップのレイザー側
  +2 … ローカードフロップ（全て J 以下）× 自分がプリフロップのコーラー側
  −2 … ハイカードフロップ × 自分がコーラー側
  −2 … ローカードフロップ × 自分がレイザー側
   0 … その他（中程度のボード、判断つかず）
```

修正後の CBet スコア：
```
CBet スコア（修正）= HandScore + (BoardScore − 5) + ポジション係数 + R3
```

### 符号が反転する理由

プリフロップでは、UTG からのオープンは「相手のレンジが強い = 自分の 3bet が効きにくい = R = +2（しきい値が実質上がる）」という補正でした。フロップでは視点が変わります。

- **ハイカードフロップ × レイザー側**：AK や KK がレンジに多いレイザーは、K♠7♦2♣ のようなボードで有利です。レンジアドバンテージがあるため、CBet スコアに +2 を足して「より積極的に CBet する」方向に動かします。

- **ハイカードフロップ × コーラー側**：BB や SB のコールレンジは A 高ハンドが少なく、ハイカードボードで不利です。CBet スコアに −2 を足して「より慎重に」方向に動かします。

- **ローカードフロップ × コーラー側**：逆に 7♣6♣4♦ のような低いボードでは、BB のコールレンジ（66、44、54s など）が刺さります。コーラー側に +2。

- **ローカードフロップ × レイザー側**：レイザーのハイカードレンジは低いボードに刺さりにくく、−2。

### 「ハイカード」「ローカード」の判定

実戦で素早く判定するための目安です。

| フロップ最高ランク | 分類 |
|----------------|------|
| A、K、Q が1枚以上 | ハイカードフロップ |
| J 以下（J 含む） | ローカードフロップ |

J がトップカードの場合は「ローカード」扱いにします。J は Broadway ではありますが、レイザーのプレミアムレンジ（AK、AQ、KK、QQ など）には直接刺さりにくいためです。

### 具体例：K72 レインボー（レイザー側）

```
BoardScore = 10（K72r: 完全ドライ）
HandScore = 10（トップペア・弱キッカー、K5）
ポジション係数 = +3（IP）
R3 = +2（ハイカードフロップ × レイザー側）

CBet スコア = 10 + (10 − 5) + 3 + 2 = 20
```

旧スコアは 18 でしたが、R3 を適用すると 20 に達します。スコア 20 は 18〜21 の混合ゾーンです。次のステップで R2 を適用します。

### 具体例：764 ツートーン（コーラー側 BB）

```
BoardScore = 6（764tt: セミウェット）
HandScore = 8（セカンドペア、76s の場合）
ポジション係数 = 0（OOP）
R3 = +2（ローカードフロップ × コーラー側）

CBet スコア = 8 + (6 − 5) + 0 + 2 = 11
```

BB がセカンドペアを持つローカードボードです。旧スコアは 9 でしたが、R3 適用で 11 の混合ゾーン（11〜14）に入ります。

## 27-5　サイズは2択（R4、本章の目玉）

### なぜサイズを揺らすのか

第10章で解説した CBet サイズの原則は「ドライ → 33%、セミウェット → 66〜75%、超ウェット → 小サイズ」という構造でした。この枠組み自体は正しいのですが、ひとつ問題があります。**「ドライボードは常に 33%」が固定化すると、相手はサイズからボードとハンドを特定できます**。

同じハンドで時に 33%、時に 75% を打ち分けることで、相手はサイズからの逆算を断念せざるを得なくなります。

### R4 の定義

CBet を打つことが決まったら、次の判定でサイズを選びます。

```
NutsAdv（ナッツアドバンテージ）の簡易判定：

  自分レンジに上位10%ナッツが多い（レイザー × ハイカードボード等）
    → 75% を選ぶ（R2 と組み合わせる場合は R2 を優先）

  ボードが相手レンジに有利（コーラー × ハイカード等）
  または拮抗している
    → 33% を選ぶ
```

### 「上位10%ナッツ」の暗算目安

上位10%ナッツとは「セット以上、または最強フラッシュ、または最強ストレート」を指します。実戦での判定は「このボードで最強の役を自分が何コンボ持っているか、相手より多いか」という1回の直感確認です。

具体的な目安を示します。

| ボードの状況 | 自分の立場 | NutsAdv 判定 |
|------------|-----------|------------|
| K♠7♦2♣ レインボー | レイザー（BTN） | 有利（KK/77/22/AK 多数） → 75% |
| K♠7♦2♣ レインボー | コーラー（BB） | 不利（KK は BTN に多い） → 33% |
| T♥9♠8♦ コネクテッド | レイザー | 拮抗（ストレート完成は両レンジに） → 33% |
| 7♦6♣4♠ レインボー | コーラー（BB） | 有利（66/44/54s は BB に多い） → 75% |
| A♥T♥3♦ ツートーン | レイザー（BTN） | 有利（AA/AT/AK 多数） → 75% |

### 同じハンドでサイズを混ぜる意味

R4 と R2 を組み合わせると、同じハンド（例：KQ on K72r）でも状況次第で 75% と 33% の両方が登場します。これは「KQ は常に 75%」という固定パターンを壊します。

例：CBet スコアが 20（混合ゾーン 18〜21）のとき

- K♠Q♥ on K♥7♣2♦：K（高い方）が ♠ → アクション側 → **75%**
- K♣Q♦ on K♥7♣2♦：K（高い方）が ♣ → 受動側 → **33%**

同じ KQ でも、スートによってサイズが変わります。

### 33% と 75% の計算

実戦での暗算方法を整理します。

```
ポットを P とする：

33%（ポット÷3）：
  例 P=60bb → 60÷3 = 20bb

75%（ポット÷2 + ポット÷4）：
  例 P=60bb → 30 + 15 = 45bb
  または「P×3÷4」≒ P × 0.75：60 × 3 ÷ 4 = 45bb
```

÷3 と ÷4 のみで完結するため、暗算可能です。

## 27-6　チェックレンジの保護（R5）

### チェックは弱さのシグナルではない

現代ポーカーで最も頻繁に犯されるミスのひとつは「レイザーがフロップでチェックした = 弱いハンド」という等式の思い込みです。しかし GTO では、強いハンドの一部を意図的にチェックします。この理由は2つです。

1. チェックレンジにナッツを混在させることで、相手は安易な CBet に対してチェックレイズを仕掛けにくくなります。
2. トラップに回すことで、相手のコンティニュエーションベットや遅いバレルを誘い込み、大きなポットを作れます。

### R5 のフロップ版定義

前作と同一の定義です。

| ハンド形 | スーテッド | オフスート |
|---------|-----------|----------|
| AA〜QQ | 100% CBet（バリュー継続） | **スート判定でチェック候補**（♣♦ならチェック） |
| AK | 100% CBet | **50% チェック（スート判定で近似）** |

スーテッドのプレミアムハンドは、ドロー価値も含めてバリュー CBet で最大化します。オフスートの強ハンドは、ポストフロップでも十分強いため、一部をチェックに回してレンジを守ります。

### AKo トラップのフロップ進行例

状況：UTG が AKo でプリフロップからコールし（R5 適用でチェック・トラップ選択）、BTN vs BB の SRP に参加しました。フロップは A♣8♦5♦（BoardScore = 8 − 2 = 6、ツートーン）。

- AKo のトップ2（AAやKKではなくAKなのでTPTKに近い形）：HandScore = 18
- CBet スコア = 18 + (6 − 5) + 0（OOP）= 19

スコア 19 は混合ゾーン（18〜21）ですが、今回は A♣K♦（A が ♣）のため R2 で受動側 → チェック。

相手 BTN が 33% CBet を打ってきます。あなたはフロップチェックコール → ターンで K♥ が落ちてトップ2ペア完成 → BTN のターン CBet に対してレイズ。

「チェック = 弱い」と思い込んでいた相手は、レイズに対応できずに高いコストでコールを続けます。これが R5 の効果です。

### 「チェック＝弱い」を壊す

R5 を使わない場合、あなたのチェックレンジは中程度以下のハンドで構成されます。相手は「チェックしたら弱い」と確信し、ターンで機械的にバレルを打ってきます。

R5 で強ハンドの一部をチェックに回すと、相手はあなたのチェックを安易に攻撃できなくなります。これは MDF（後述）の観点からも重要です。

## 27-7　MDF ±10% とチェックレイズ耐性（R6）

### 基本 MDF の復習

第13章で学んだ MDF（Minimum Defense Frequency）の計算式です。

```
MDF = 1 − ベット額 ÷ （ポット + ベット額）
```

サイズ別の基本 MDF は次のとおりです。

| ベットサイズ（対ポット比） | 必要エクイティ（ポットオッズ） | 基本 MDF |
|------------------------|--------------------------|---------|
| 33% | 20% | **75%** |
| 50% | 25% | 67% |
| 75% | 30% | **57%** |
| 100% | 33% | 50% |

本章の文脈では、33% と 75% の2サイズが中心なので、MDF は 75% と 57% の2つを覚えておけば十分です。

### R6 の定義

基本 MDF に対して、相手のプレイスタイルで ±10% 補正します。定義は前作と同一です。

```
相手がバリュー寄り（ロック型、大サイズ・低頻度ベット）
  → MDF −10%（より多くフォールドしてよい）

相手がブラフ寄り（LAG 型、連打・小サイズ繰り返し）
  → MDF +10%（より広くディフェンスが必要）

判断つかず
  → 基本 MDF をそのまま使用
```

### サイズ別 R6 適用後 MDF 表

| ベットサイズ | 基本 MDF | バリュー寄り補正 | ブラフ寄り補正 |
|------------|---------|--------------|-------------|
| 33% | 75% | 65% | 85% |
| 75% | 57% | 47% | 67% |
| 100% | 50% | 40% | 60% |

**実戦での使い方**：相手の 75% CBet に直面したとき、相手がタイト（VPIP 15% 前後）なら MDF 47% → 53% フォールドしてよい。相手が LAG（VPIP 30% 超）なら MDF 67% → 33% しかフォールドできません。

### チェックレイズへの対応

R6 はディフェンス側の補正でしたが、チェックレイズを行う側にも応用できます。

相手の CBet に対してチェックレイズを選ぶ場合、相手が大サイズ（75%）で打ってきているとき、相手のレンジはバリュー寄りに絞られます。この場合はチェックレイズの期待値が下がるため、よりナッツに近いハンドに限定します（ブラフチェックレイズの閾値を上げる）。

逆に相手が小サイズ（33%）で Range CBet を打ってきている場合、レンジはバリューからブラフまで広く、チェックレイズのセミブラフが通りやすくなります。第14章のチェックレイズ判定（HandScore 20 以上でバリュー、12 以上でセミブラフ候補）に、このフィルターを加えてください。

## 27-8　マルチウェイでの揺らし

### 混合の効果が薄れる理由

第18章で説明したように、マルチウェイでは CBet の基本方針が大きく変わります。本章の R1〜R6 も例外ではありません。

混合戦略の目的は「相手があなたのパターンを読めなくする」ことです。ヘッズアップでは1人の相手に対して混合効果が最大化されますが、マルチウェイでは複数の相手が異なる角度から観察します。

### マルチウェイでの混合が弱い理由

**ブロック効果の薄れ**：ヘッズアップでは、あなたが ♠ を持つことで相手の ♠ コンボが減ります。3人以上になると、ブロック効果は分散して希薄になります。スート判定（R2）の「疑似ランダム性」もブロック構造と無関係になります。

**ドラフト効果**：マルチウェイでは、1人がコールするだけでポットに残ります。ブラフを混合ゾーンで打っても、「全員フォールド」する確率が大幅に下がります。混合戦略の「フォールドエクイティ」部分が機能しにくくなります。

### マルチウェイは決定論寄りで OK

3人以上のマルチウェイでは、本章の R1〜R4 の適用を控え、従来の決定論的な基準（CBet スコア ≥ 20 のみ 75%、それ以下は 33% か チェック）に戻ることを推奨します。

具体的には第18章で示した補正を優先してください。

```
マルチウェイの補正（第18章の再掲）：
3-way：スコア閾値を +5 引き上げる
4-way：強いバリュー（セット以上）またはナッツドロー以外はチェック
```

R5（チェックレンジ保護）と R6（MDF ±10%）はマルチウェイでも有効です。チェックレンジへの強ハンド混入と相手タイプへの MDF 補正は、プレイヤー数に関わらず機能します。

### 既存第18章との整合

本章の R1〜R4 はヘッズアップ SRP を主な適用対象とします。マルチウェイでは第18章のガイドラインが優先されます。この棲み分けを覚えておいてください。

## 27-10　練習問題（10問）

### 問1

**ボード：A♣8♦3♥（BoardScore = 8、ツートーン）**

あなたはプリフロップのレイザー、IP（BTN）です。ハンドは K♠J♦（空振り + バックドアストレート可能性）。HandScore = 0 とします。

R3 を適用した CBet スコアを計算し、何バンドに入るかを答えてください。

**解答**

```
CBet スコア（基本）= 0 + (8 − 5) + 3 = 6
R3: ハイカードフロップ（A あり）× レイザー側 → +2

修正後 = 6 + 2 = 8
```

修正後スコア 8 は弱バンド（≤ 10）の 8 です。**チェック確定**です。R2 の適用は不要です。

### 問2

**ボード：K♥7♣2♦（BoardScore = 10、ドライ）**

あなたはプリフロップのコーラー、OOP（BB）です。ハンドは 7♠2♣（ボトム2ペア）。HandScore = 30（ツーペア扱い）とします。

R3 を適用した CBet スコアを計算し、何バンドに入るかを答えてください。

**解答**

```
CBet スコア（基本）= 30 + (10 − 5) + 0 = 35
R3: ハイカードフロップ（K あり）× コーラー側 → −2

修正後 = 35 − 2 = 33
```

スコア 33 は強バンド（≥ 22）。**CBet 75% 確定**。スーテッドかどうかに関わらず積極的にベットします。

### 問3

**ボード：9♠8♣4♦（BoardScore = 3、ウェット）**

あなたはプリフロップのコーラー、OOP（BB）です。ハンドは 9♦8♥（ツーペア）。HandScore = 30 とします。

R3 を適用した CBet スコアを計算し、何バンドに入るかを答えてください。R3 の判定も含めてください。

**解答**

```
CBet スコア（基本）= 30 + (3 − 5) + 0 = 28
R3: ローカードフロップ（全て 9 以下）× コーラー側 → +2

修正後 = 28 + 2 = 30
```

スコア 30 は強バンド。**CBet 75% 確定**。低いボードでコーラー側のツーペアは R3 が後押しします。

### 問4

**ボード：T♠9♦7♣（BoardScore = 5、セミウェット）**

あなたはプリフロップのレイザー、IP（BTN）です。ハンドは A♥K♣（空振り）。HandScore = 0 とします。

R1・R3 を適用して最終判断を出してください。

**解答**

```
CBet スコア（基本）= 0 + (5 − 5) + 3 = 3
R3: ローカードフロップ（T、9、7 は全て J 以下）× レイザー側 → −2

修正後 = 3 − 2 = 1
```

スコア 1 は弱バンド（≤ 10）。**チェック確定**。AK はこのボードで何も作れておらず、レイザー側がローカードフロップでは不利なため、R3 がさらに悪化させます。

### 問5

**ボード：K♦J♥5♠（BoardScore = 6、セミウェット）**

あなたはプリフロップのレイザー、IP（BTN）です。ハンドは Q♠T♣（ガットショット）。HandScore = 6（ガットショット約 4 アウツ × 1.5 = 6）とします。

CBet スコアを計算し、R1 でのバンドを判断してください。次に R2 が必要な場合は適用し（Q♠ のスートで判断）、最終アクションを示してください。

**解答**

```
CBet スコア（基本）= 6 + (6 − 5) + 3 = 10
R3: ハイカードフロップ × レイザー側 → +2

修正後 = 10 + 2 = 12
```

スコア 12 は混合ゾーン（11〜14）です。R2 で判断します。Q（高い方のカード）が ♠ → アクション側 → **CBet 33%**。

Q♣ や Q♦ であればチェックです。

### 問6

**ボード：A♠7♦2♣（BoardScore = 10、ドライ）**

相手（BTN）が 75% CBet を打ってきました。相手は LAG 傾向（VPIP 30%、PFR 25%）です。あなたのポジションは OOP（BB）。基本 MDF と R6 適用後の MDF を計算してください。

**解答**

```
基本 MDF = 1 − 75 ÷ (100 + 75) = 1 − 75/175 ≒ 57%

R6: 相手はブラフ寄り（LAG）→ +10%

最終 MDF = 57% + 10% = 67%
```

あなたのレンジの上位 67% でディフェンスする必要があります。33% しかフォールドできません。A2 以上のヒット済みハンドは基本的にコールします。

### 問7

**ボード：K♣T♦5♠（BoardScore = 7、ドライ境界）**

あなたはプリフロップのレイザー、IP（BTN）です。ハンドは QQ（オーバーペア）。HandScore = 20 とします。

R4 を適用してサイズを決めてください。NutsAdv の判定も含めて説明してください。

**解答**

```
CBet スコア = 20 + (7 − 5) + 3 = 25（強バンド）
```

CBet は確定です。次に R4 でサイズを判定します。

K♣T♦5♠ はハイカードボード。レイザー側（BTN）のレンジには KK、TT、AA、KQ 等のナッツが多数あります。コーラー側（BB）は KK や TT を持っている場合もありますが、全体的にレイザー側がナッツ優位です。

### 問8

**ボード：9♣8♥7♦（BoardScore = 5、セミウェット）**

あなたはプリフロップのレイザー、IP（BTN）です。ハンドは JJ（オーバーペア）。HandScore = 20 とします。

R3 と R4 を適用してサイズを決めてください。

**解答**

```
CBet スコア（基本）= 20 + (5 − 5) + 3 = 23
R3: ローカードフロップ × レイザー側 → −2

修正後 = 23 − 2 = 21
```

スコア 21 は混合ゾーン（18〜21）。R2 でサイズを仮決定しますが、続けて R4 も確認します。

R4 での NutsAdv 判定：9♣8♥7♦ はコネクテッドボード。コーラー（BB）のレンジに 65s、T9s、T8s などのストレート完成ハンドが多く、ナッツアドバンテージは拮抗または BB 寄りです。

R4 → **33% を選ぶ**。R2 で ♠♥ ならば 33% 確定、♣♦ ならばチェックです。

### 問9

**ボード：A♥K♣Q♦（BoardScore = −1、超ウェット）**

あなたはプリフロップのレイザー、IP（BTN）です。ハンドは AA（セット）。HandScore = 30 とします。

R5 の観点から、チェックを選ぶべき状況があるか検討してください。AA はオフスートと仮定します。

**解答**

```
CBet スコア（基本）= 30 + (−1 − 5) + 3 = 27
R3: ハイカードフロップ × レイザー側 → +2

修正後 = 27 + 2 = 29（強バンド）
```

セットなのでスコアは高く、CBet は積極的に打てます。しかし R5 を確認します。

AA のオフスートの場合、R5 では「♣♦ の AA はチェック候補」です。A♣A♦ のような形であれば、チェックを選ぶ価値があります。

A♥K♣Q♦ のような超ウェットボードでは、相手のレンジに J-T（ストレート）や K-J などが多く、チェックしてドローを引き込んでからレイズする方がポットを大きくできます。R5 と超ウェットボードの特性が合致するスポットです。

### 問10

**ボード：7♣6♠5♦（BoardScore = 3、ウェット）**

あなたはプリフロップのコーラー（BB）、OOP です。相手 BTN が 33% CBet を打ってきました。相手はロック傾向（VPIP 15%、PFR 13%）。あなたのハンドは 8♥7♦（ペア + ストレートドロー）で HandScore = 4 + 12 = 16 とします。

R6 を適用した MDF と、チェックレイズを検討すべきかを判断してください。

**解答**

```
基本 MDF（33% CBet）= 1 − 33 ÷ (100 + 33) = 1 − 33/133 ≒ 75%

R6: 相手はバリュー寄り（ロック）→ −10%

最終 MDF = 75% − 10% = 65%
```

あなたは 65% のレンジでディフェンスすれば十分です。35% フォールドできます。

チェックレイズの検討：HandScore = 16 は第14章の「ドロー加点 12 以上でセミブラフ候補」に該当します。8♥7♦ は OESD（8アウツ）を持ち、7♣6♠5♦ でトップペアも維持しています。

相手がロック型で 33% の小サイズ CBet を打ってきているため、チェックレイズのブラフはやや通りにくい傾向があります（ロックは強い手で継続する傾向）。ここではコールして、ターンの状況次第でセミブラフを考えるのが安全です。

## 27-11　【GTOとのズレ】第27章版

### 本章の修正でどれくらい GTO に近づくか

R1〜R6 を導入することで、第9章〜第26章の単純スコア式が持っていた GTO とのズレが部分的に縮まります。

**改善が見込まれる点**

1. **境界 CBet の頻度ズレが半減する**：R1 と R2 で混合ゾーンを設けると、境界スコアのハンドは約 50% の確率で CBet し、50% でチェックします。GTO が推奨する「40〜60% の混合」に有意に近い近似です。

2. **サイズのパターンが崩れる**：R4 を使うことで、同じボード・同じハンドでも 75% と 33% が混在します。GTO ソルバーが指摘する「サイズからのハンド逆算」を防ぐ効果があります。

3. **チェックレンジが強化される**：R5 でプレミアムハンドの一部をチェックに回すと、相手は機械的なターンバレルを打ちにくくなります。第14章のチェックレイズとも連動して、OOP の防御力が上がります。

4. **RangeAdv の反映**：R3 でハイカード/ローカードボードの有利不利を補正することで、第9章の統合式が持っていた「全ボードで同一の (BoardScore − 5) 項」の粗さが縮まります。

### 残るズレ

本章の修正後も、以下のズレは残ります。

**頻度の粒度が粗い**：スート判定による疑似混合は 50:50 固定です。GTO が推奨する 37:63 や 45:55 という細かい頻度を再現することはできません。特に R4 のサイズ判断は「どちらを多く使うか」まで指定しておらず、GTO の「サイズ比率」を完全に再現できていません。

**レンジ構築の非連続性**：本書のスコア式は個別ハンドを独立に評価します。GTO では「レンジ全体のバリュー/ブラフ比率」「ブロッカー効果」「チェックバックレンジのバランス」を同時に最適化します。この多次元最適化は、本章の加減算近似では再現できません。

**ターン・リバーへの引き継ぎ**：本章のルールはフロップに特化しています。ターンでカードが落ちた後、新しい BoardScore と HandScore を再計算して判断し直す必要があります。フロップでの混合戦略がターンの最適戦略と連続していない点が残ります。

### 第26章ロードマップとの接続

第26章で紹介した GTO Wizard の「Aggregate Reports」を使うと、特定のポジション・ボードでの CBet 頻度とサイズ分布を確認できます。本章の R1〜R6 を習得した後、GTO Wizard で「自分の修正後の判断と GTO の差分」を5〜10 スポット確認することを推奨します。

具体的には次のような確認が有効です。

1. K72r での BTN CBet：GTO は何% の頻度で 33% を使い、何% で 75% を使うか
2. T98ss での BTN CBet：R3（−2）適用後のスコアと GTO の実際の頻度を比較
3. ローカードボード（764r）での BB ドンクベット：R3 補正の方向性が GTO と合っているか

これらの確認を通じて、本書の近似がどのスポットで GTO に近く、どのスポットで乖離するかを肌で学べます。

### どこまで許容するか

本書の哲学は「暗算可能な近似で、致命的なミスを除く」です。R1〜R6 を全て適用した後も、GTO との EV ギャップは存在します。しかし、そのギャップが問題になるのは「相手が本章のルールを解析できる」場合だけです。

マイクロからミドルステークスの多くの相手は、あなたのスート判定パターンを 100 ハンド以内に解析できません。実戦では、理論的な GTO とのズレより「相手の誤りから得る利益」の方が圧倒的に大きいのです。

本章のルールに慣れたら、第26章のロードマップに従って GTO ソルバーへと進んでください。そのとき、本章で学んだ「R1〜R6 の感覚」が、ソルバーの出力を読み解く直感の土台になります。

## 章のまとめ

- 決定論的な CBet 判断は、境界で機械化しやすく搾取されやすい
- **R1（3バンド化）**：しきい値 T±2 で混合ゾーンを設ける。強バンドと弱バンドは既存の判断と一致する
- **R2（スート判定）**：混合ゾーンでは高い方のカードのスートで行動を決定する。♠♥ はアクション側、♣♦ は受動側
- **R3（+R 補正）**：ハイカードフロップ × レイザー側は +2、コーラー側は −2。ローカードフロップは逆符号
- **R4（サイズ2択）**：NutsAdv 判定で 75% か 33% を選ぶ。ナッツ多数なら 75%、拮抗なら 33%
- **R5（チェックレンジ保護）**：オフスートの AA〜QQ および AK の一部をチェックに回す。「チェック＝弱い」を壊す
- **R6（MDF ±10%）**：相手がブラフ寄りなら +10%、バリュー寄りなら −10% の補正を MDF に加える
- マルチウェイでは R1〜R4 の効果が薄れる。第18章のガイドラインを優先し、R5・R6 のみ適用する
- 全ルールは独立に使える。まず R1 だけ覚え、慣れたら R4、R3、R5・R6 と段階的に導入してよい
- これらの修正後も GTO との頻度ズレは残る。実戦では相手の誤りからの利益が理論ギャップを上回る
- 第26章ロードマップと本章は「本書の最終到達点」を形成する。次のステップは GTO ソルバーへ

### 問D

R4（サイズ2択）で 75% を選ぶ条件はどれですか。

1. 自分のレンジに上位10%ナッツが少ない
2. 自分のレンジに上位10%ナッツが多い
3. ボードが拮抗している

---

### 解答

- **問A**：2（混合ゾーン。18〜21 が 75%/33% の混合ゾーン。スコア 19 はこの範囲）
- **問B**：1（♠ と ♥ がアクション側。前作第21章と同一定義）
- **問C**：1（+2。ローカードフロップはコーラー側に有利なため、スコアを上げる方向）
- **問D**：2（ナッツが多い側が大サイズを選ぶ。GTO の「ナッツアドバンテージ → サイズ」原則と一致）
