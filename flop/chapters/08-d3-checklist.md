## 導入　―― なぜ「%」で答えるのか

フロップが配られた瞬間、経験豊富なプレイヤーは瞬時に「ここは全レンジ押し」「ここは選択的に」と判断します。その「選択的」とは具体的に何%を指すのか。感覚では答えられても、数字で答えられない人が大半です。

本章では **簡易レンジスコア チェックリスト** という4ステップの暗算手順で、フロップが配られてから数秒以内に **CBet 頻度（%）** を算出できるようにします。出力が数字なので、自分の判断を再現でき、他者と議論でき、後からの振り返りで検証できます。

簡易レンジスコアの精度はGTOソルバーの実測値（257ボード）と比較して **R² = 0.806**（決定係数）、誤差の平均は **±4.8%** です。これは「ほぼGTOと一致する」と言ってよい水準です。なお、GTOとの比較詳細は本章末のコラム、および付録で検証できます。

フロップの組み合わせはスートの等価性を考慮すると **1,755 通り**に絞られますが、簡易レンジスコアは本質的には「**10 個の数字**」だけで、この1,755通りすべてに近似解を与えます。ここを徹底して覚えることが本書全体の基礎になります。

## 8-1　「90% から引いていく」という発想

簡易レンジスコアの中核にあるのはシンプルな思想です。

> プリフロップアグレッサー（PFA）は、コールドコール / 3ベットされなかった時点で、フロップでもアグレッションの **権利** を握っている。原則は **高頻度 CBet**。下げる理由があるときだけ下げる。

実測で言えば、何も特別な事情がないときPFAのCBet頻度は **90% 近く**になります。簡易レンジスコアはこの90% を起点に、「下げる理由」が見つかるごとに減算していく設計です。

簡易レンジスコアは、現実のGTO頻度が **トップカード**・**スート構造**・**ペアの有無** という互いに独立な3次元で動く事実を素直に反映します。「ウェット度」という単一の軸ではこの3次元を捉えきれないため、簡易レンジスコアは4ステップの **分岐判定** でボードを個別に扱います。

## 8-2　Step 1 ── モノトーンなら即 70%（小サイズ）

```
Step 1: 3 枚とも同じスートか？
```

答えがYESなら、それ以上考えずに **CBet 頻度 = 70%（サイズ 33% 固定）** です。モノトーンボードは全フロップの約 **5%** にすぎませんが、扱いを正確に覚えることで機会損失を防げます。

### なぜモノトーンは 70%（小サイズ）なのか

著者のGTO実測（257ボード）では、モノトーンの BTN CBet 平均は **70.5%** でした。これはレインボー（約55%）や 2tone（約50%）を大幅に上回り、ペアードボード（約75%）に次ぐ高頻度帯です。

理由は次の2点です：
- **フロップ完成フラッシュは5〜6%程度**にすぎません。大半の相手はフラッシュドロー保有か、フラッシュ無関係の役のみです。
- **相手はチェックレイズしにくい**構造です。フラッシュドロー保有者はコールが最適行動で、チェックレイズするとフラッシュ完成が確定してしまいます。

このため「小サイズ（33%）で広いレンジのまま押し続ける」のが GTO の正解です。簡易レンジスコアは **70% 固定（33% サイズ）** で近似します。

## 8-3　Step 2 ── ペアボードは「5 パターン表」で一発

```
Step 2: ペアボードか？
```

答えがYESなら、次の5パターン表で頻度が一発で決まります。

| パターン                              | 頻度  | 例                |
| ------------------------------------ | ----- | ---------------- |
| AA ペア（AA-X）                       | 100%  | AA7, AAJ, AAK    |
| KK ペア（KK-X）                       | 90%   | KK4, KK9, KKJ    |
| QQ ペア（QQ-X）                       | 80%   | QQ3, QQT         |
| 中低ペア (TT 以下)                    | 72%   | TT5, 995, 772, 77K |
| A/K ハイ + ローペア (ペア ≤ 5)        | 45%   | K44, A33, K22    |
| A/K ハイ + 中ペア (ペア 6-T)          | 75%   | A99, K88, A88    |

### パターンの読み方

ペアボードは「**トップの 2 枚がペアか、最下位の 2 枚がペアか**」で性格が分かれます。

- **「AA ペア」**（AA7, AAK）は、PFAのレンジにAAが唯一入っており、BB側にトリップスがほぼ存在しない絶対的なレンジ優位。**100%** 近いレンジベットが最適です。
- **「KK ペア」**（KK4, KK9）は、AAと同様にBBのトリップス確率が極めて低い。キッカーの高低にかかわらず **90%** が目安です。GTO Wizard実測ではKK9 ≈ 80%、KK2 ≈ 95%+ 程度ですが、90%で統一して記憶します。
- **「QQ ペア」**（QQ3, QQT）は、BBのレンジにQが一定入るため少し下がり **80%**。
- **「中低ペア」**（TT以下）は JJ / TT / 99 / 88 / 77... と幅広く、GTO平均で **70〜72%** 程度に収まります。
- **「A/K ハイ + ローペア」**（K44, A33）は、ペア（≤5）を共有している状態で **PFA レンジが弱い**特殊局面。**45%** まで落ちます。
- **A/K + 中ペア (A99)** は中間的な頻度で **75%** 程度です。

### なぜ K44 は 45% で KK9 は 90% か

同じKを含むボードでも、**「KKペア（GTO 90%）」と「K高 + 44ペア（GTO 43%）」** では47ポイントの差があります。K44ではBBのレンジにも4x（K44のキッカー4）が一定数あり、PFAの相対的な強さが弱まります。KK9ではBBがトリップスを持てる確率が極めて低く、PFAが圧倒的レンジ優位を持ちます。

## 8-4　Step 3 ── 「ウェット」を定義する

モノトーンでもペアでもない、最も多くのフロップ（全体の約70%）はここに進みます。次の判定です。

```
Step 3: このボードは「ウェット」か？
```

簡易レンジスコアにおける「ウェット」は、以下のいずれかに該当するボードと定義します。

| ウェット条件           | 意味                                          | 例                |
| -------------------- | --------------------------------------------- | ---------------- |
| **① 連続3枚**         | 3 枚の最大ランク差が 2 以内                     | 987, T98, JT9, 654 |
| **② 2-tone**          | 3 枚のうち 2 枚が同じスート（♠♠♦ など）         | K♠T♠5♣, A♥8♥3♦    |
| **③ 高ボード連続**    | 最大ランク差 4 以内かつトップが T 以上           | KT5, QJ8, JT6    |

いずれにも該当しない場合が **ドライ**です。

### なぜこの 3 条件なのか

**連続3枚**はストレートドローのコンボ数が爆発的に増えます（例：987ではOESDが48コンボ以上）。BBのディフェンスレンジが追いつく典型パターンです。

**2-tone**（全フロップの **約 56%**、過半数を占めます）はフラッシュドローが成立するすべての局面で、残り同スートが11枚あるため、相手が保有できるフラッシュドローは実質 **30 コンボ前後**。侮れない密度です。

**高ボード連続**（KT5、QJ8など）は、トップが高い2連+ギャップでもBBがKJ, QJ, JT, KTなどのコンボを豊富に持つため、ドライに見えて実はレンジ優位が薄くなります。

---

## 8-5　Step 4 ── トップカード × ウェット で一発決定

ここまでで「モノトーンでない」「ペアでない」ことが確定し、ウェット/ドライの二分類もできました。最後のステップで頻度が決まります。

```
Step 4: トップカードは A/K/Q か？
```

| トップカード                  | ドライ | ウェット |
| ---------------------------- | ---- | ------ |
| **ハイ (A / K / Q)**          | 85%  | 55%    |
| **ロー (J 以下)**             | 55%  | 30%    |

たった **4 マス**です。

### なぜトップカードがここまで効くのか

残差分析から最大の発見でした。同じ「ウェット度が中程度」のボードでも、トップA/K/QとJ以下で **CBet 頻度が 30 ポイントも違う**のです。

- **トップ A/K**: PFAはプリフロップでAXコンボを豊富に持つ（AA, AK, AQ, AJ, AT, AXsなど）。ボードのトップがA/Kだとレンジ全体が直撃する。
- **トップ Q**: A/Kほどではないが、AQ・KQ・QQのコンボが多く、ほぼ同等。
- **トップ J 以下**: BBのディフェンスレンジにはJT, JT9, T9, 98などのコネクターが大量に入っている。ここが直撃するためBBはコンボでPFAに追いつく。

## 8-6　4 ステップ全体像

以上をまとめると、簡易レンジスコア チェックリストは次のフローチャートになります。

```
┌─────────────────────────────────────┐
│ Step 1: モノトーン？ ──YES──→ 70%      │
│                   NO                │
│          ↓                          │
│ Step 2: ペア？ ──YES──→ ペア表         │
│              NO                     │
│          ↓                          │
│ Step 3: ウェット判定                  │
│   (連続3枚 / 2-tone / 高ボード連続)   │
│          ↓                          │
│ Step 4: トップ A/K/Q？               │
│                                     │
│         ドライ  ウェット              │
│   ハイ   85     55                  │
│   ロー   55     30                  │
└─────────────────────────────────────┘
```

このチャートは**フロップが配られてから 5 秒以内**に実行できるよう設計されています。慣れれば2秒で %が出ます。

## 8-7　代表的フロップ 10 例での実習

具体的な計算で理解を固めましょう。すべてのボードに対して4ステップを機械的に実行します。

### 例1　K♠7♦2♣（超ドライ）

```
Step 1: モノトーン？ → NO (3スート)
Step 2: ペア？       → NO
Step 3: ウェット？    → 連続3枚 NO / 2-tone NO / 高ボード連続 NO → ドライ
Step 4: トップ K (ハイ) × ドライ → 85%
```

**答え: 85%**（GTO実測91%、誤差 −6%）。理想的なCBetボード。相手にドローがほぼなく、PFAがレンジ優位を最大限に活かせます。

---

### 例2　A♠8♠3♦（ツートーン、Broadway A）

```
Step 1: NO
Step 2: NO
Step 3: 2-tone ✓ → ウェット
Step 4: トップ A (ハイ) × ウェット → 55%
```

……と簡易レンジスコアは答えますが、これは **GTO 実測 88%** に対して −33% という大きな誤差を出します。

ここが簡易レンジスコアの**限界の典型例**です。Aハイで2-toneのドライは、BBがフラッシュドローを持ってもPFAのレンジ優位が強すぎて結局押せます。精密版の精密レンジスコアではこのケースに **+15** の追加補正を入れますが、暗算モデルではあえて捨てています（詳細は次巻）。

初学者の方は **「A/K 2-tone で middle が 8 以下 かつ low が 7 以下」は例外的に高頻度（85%）で押してよい**と1つだけ記憶してください。

---

### 例3　K♠T♦5♣（2ギャップ、Broadway）

```
Step 1: NO
Step 2: NO
Step 3: 最大ランク差 8、2-tone NO、連続3枚 NO、高ボード連続 (max_diff=8 > 4) → NO
         → ドライ
Step 4: トップ K (ハイ) × ドライ → 85%
```

**答え: 85%**（GTO実測70%、誤差 +15%）。KT5はmiddleがTであるためBBがKT, QT, JT, T9などを豊富に持ち、見た目のドライさの割にBBがぶつかります。精密レンジスコアでは `middle=T × top≥Q rainbow` で **−15 補正**を追加しますが、簡易レンジスコアでは **73%** 程度に脳内で補正するのが実用的。

---

### 例4　J♦8♣4♦（2ギャップ、ツートーン）

```
Step 1: NO
Step 2: NO
Step 3: 2-tone ✓ → ウェット
Step 4: トップ J (ロー) × ウェット → 30%
```

**答え: 30%**（GTO実測50%、誤差 −20%）。ここは簡易レンジスコアが若干控えめすぎますが、「J以下のウェットは低頻度」の方針は正しい方向です。

### 例5　Q♣J♦9♠（連続2枚＋Broadway）

```
Step 1: NO
Step 2: NO
Step 3: 最大ランク差 3、高ボード連続 (top=Q, max_diff=3 ≤ 4 & top≥T) ✓ → ウェット
Step 4: トップ Q (ハイ) × ウェット → 55%
```

**答え: 55%**（GTO実測50%、誤差 +5%）。ほぼ一致。

### 例6　9♥8♥7♦（連続3枚、ツートーン）

```

Step 3: 連続3枚 ✓ → ウェット
Step 4: トップ 9 (ロー) × ウェット → 30%
```

**答え: 30%**（GTO実測30%、誤差0）。完全一致。簡易レンジスコアの連続3枚+ロートップの扱いがGTOと整合している典型例。

### 例7　J♠T♠9♦（連続3枚、ツートーン、Broadway）

## 8-8　覚える数字 10 個

簡易レンジスコアを実戦で使うために暗記すべき数字は、以下の **10 個**だけです。

### マトリクスの 4 マス

```
         ドライ  ウェット
  ハイ    85%    55%
  ロー    55%    30%
```

### ペア 6 パターン

```
AA ペア               → 100%
KK ペア               → 90%
QQ ペア               → 80%
中低ペア（TT 以下）    → 72%
A/K + ローペア（≤5）  → 45%
A/K + 中ペア（6-T）   → 75%
```

### 特殊1パターン

```
モノトーン → 70%（33% サイズ固定）
```

**合計 10 数字**。これだけで全フロップ1,755通りに対して **R² 0.81** の精度でCBet頻度を答えられます。

## 8-9　簡易レンジスコア が捉えないもの

簡易レンジスコアは実用精度を優先して作られた暗算モデルであり、次の要素は意図的に捨てています。

1. **ポジション差**: IP vs OOPでCBet頻度は変動しますが、簡易レンジスコアは **IP（PFA側）**を想定しています。SB vs BBのOOP場面では全般に頻度が10ポイント程度下がります（第10章参照）。
2. **自ハンドの強度**: 簡易レンジスコアは「レンジ全体の何%をベットするか」を答えます。自分の **特定のハンド** でベットすべきかは、第9章の役割分類と第10章の統合判定で判定します。
3. **SPR（スタックポットレシオ）**: 深いスタックでは頻度が若干下がります。第15章で補正を学びます。
4. **3-bet ポット**: レンジが狭まるため挙動が変わります。第16章で扱います。
5. **マルチウェイ**: 3人以上ではCBet頻度が大きく下がります。第16章で別モデルを示します。

これらの要素は後続章で順次足していきます。簡易レンジスコアは「**単なる SRP の HU で IP**」という最も基本的なセッティングの近似式です。本書の残り24章は、この **簡易レンジスコア に何を足していくか** を示す本です。

## 【GTO との検証】コラム

本章の簡易レンジスコアモデルは、著者の GTO 実測データ（257 ボード）と照合検証されています。

| モデル                        | R²    | RMSE    | 覚える数字 |
| ---------------------------- | ----- | ------- | -------- |
| **簡易レンジスコア 暗算モデル（本章）**      | **0.806** | **4.8%** | **10 個** |
| 精密レンジスコア 精密モデル（次巻）    | 0.914 | 3.5%  | 約 25 個  |

簡易レンジスコアは10個の数字だけで、257ボードのGTO実測値の81% を決定係数R² として再現します。さらに5% の精度向上を求めるなら、次巻で精密レンジスコア（精密版、R² = 0.914）を学びます。

検証の完全詳細、外れ値分析、係数の導出過程は付録に記載しています。

- **Step 2**: ペア？　→ 5パターン表（45 / 50 / 72 / 75 / 80%）
- **Step 3**: ウェット判定（連続3枚 / 2-tone / 高ボード連続）
- **Step 4**: トップA/K/Q × ウェットの4マスマトリクス（85 / 55 / 30 / 55）
- 覚える数字は全部で **10 個**
- GTO実測との再現精度は **R² = 0.806、RMSE = 4.8%**（257ボード）
- さらに精密化したい読者は付録Dの **精密レンジスコア** 係数表を参照（R² = 0.914、詳細は次巻）

### 問1

**フロップ：Q♥J♥8♣**

Step 2: ペア？ → NO

T-9（OESD）・K-T（OESD）・9-7（ガットショット）など多くのドローが存在し、フラッシュドローも絡むため、レンジ全体の約半分だけベットし、残りはチェックに回します。

### 問3

**フロップ：6♥5♥4♦**

簡易レンジスコアでCBet頻度を算出してください。

<details>
<summary>解答</summary>

```
Step 1: NO
Step 2: NO
Step 3: 連続3枚 (6-5-4, max_diff=2) ✓ → ウェット
Step 4: トップ 6 (ロー) × ウェット → 30%
```
