> 「フロップの組み合わせは 1,755 通り。しかし本当に覚えるべきは 7 種類だけだ」

---

## 導入　―― 1,755 通りを 7 つにまとめる

フロップで配られるボードは、2枚の手札を除いた50枚から3枚を選ぶ組み合わせです。スートの等価性を考慮しても **1,755 通り**。これを全部覚えるのは不可能です。

しかし実戦で必要なのは「どう動くか」です。動き方が同じなら、ボードは同じ型として扱ってよい。本書は経験則とGTO実測の検証から、**実戦で動き方が分かれる 7 つの型**にボードを分類します。

この章の目標はただひとつ。**フロップが配られた瞬間に、7 型のどれかを 5 秒で言えるようになる**こと。それができれば、次章の「型別アクションプラン」が即座に引けます。

---

## 3-1　分類の 3 つの軸

7型への分類は、次の3軸の組み合わせで決まります。

### 軸1: トップカードが「ハイ」か「ロー」か

- **ハイ**: トップカードがA / K / Q
- **ロー**: トップカードがJ以下 (T/9/8/7/6/5/4/3/2)

この境界は「プリフロップアグレッサー（PFA）のレンジが直撃するか」で決まります。A/K/QはPFAのレンジ（AA、AK、AQ、KQ、QQなど）に強くフィットします。J以下だとBBのディフェンスレンジ（JTo、T9s、98sなど）にフィットし、PFAの優位が薄れます。

### 軸2: 「ウェット」か「ドライ」か

次のいずれかに該当する → **ウェット**

| 条件 | 意味 | 例 |
| --- | --- | --- |
| 連続3枚 | 3枚の最大ランク差が 2 以内 | 987、T98、JT9、654 |
| 2-tone | 3枚のうち 2 枚が同じスート (♠♠♦ など) | K♠T♠5♣、A♥8♥3♦ |
| 高ボード連続 | 最大ランク差 4 以内かつトップが T 以上 | KT5、QJ8、JT6 |

いずれにも該当しない → **ドライ**

### 軸3: 「特殊ボード」の扱い

次は独立して特殊カテゴリ：。

- **モノトーン**（3枚とも同じスート）
- **ペアボード**（3枚のうち2枚が同ランク）

これらはウェット/ドライの軸とは別系統で扱います。

---

## 3-2　7 つの型

3つの軸を組み合わせて、次の7型に分類します。

| 型 | 判定条件 | 代表例 | 別名 |
| --- | --- | --- | --- |
| **型1: ハイ × ドライ** | トップ A/K/Q + バラバラ + レインボー | K72r、A82r、Q53r | *最強のカモボード* |
| **型2: ハイ × ウェット** | トップ A/K/Q + ウェット条件のいずれか | Q83ss、KQTss、KJ9r | *油断するな* |
| **型3: ロー × ドライ** | トップ J 以下 + バラバラ | J75r、T62r、876r | *地味に難しい* |
| **型4: ロー × ウェット** | トップ J 以下 + ウェット条件のいずれか | T98ss、987ss、JT9ss | *撤退の相場* |
| **型5: モノトーン** | 3 枚とも同スート | A♥K♥Q♥、9♠8♠7♠ | *要注意ボード* |
| **型6: ペア (ハイ+高キッカー)** | ペアが QQ/KK/AA + キッカー 8 以上 | AAK、KK9、QQT | *PFA 最強* |
| **型7: ペア (そのほか)** | ペアボードでかつ型6 以外 | 772、A99、K44、TT5 | *様子見* |

---

## 3-3　7 型判定の 4 ステップ

フロップを見たら、次の4ステップで即座に型を決めます。

```
Step 1: 3 枚が同じスート？    → YES: 型5 モノトーン
Step 2: 2 枚が同じランク？     → YES: 型6 or 型7 (後述)
Step 3: トップは A/K/Q？      → YES: 型1 or 型2
                              → NO: 型3 or 型4
Step 4: 「ウェット」条件に該当？
       (連続3枚 / 2-tone / 高ボード連続)
       → YES: 型2 または 型4
       → NO:  型1 または 型3
```

### ペアボード (Step 2 がYES) の内訳

ペアボードはさらに2つに分岐：。

- **型6**: 最上位の2枚がペア + キッカー ≥ 8（例： AAK, KK9, QQT, QQ8）
- **型7**: それ以外のすべてのペアボード（KK4, QQ3, A99, 772, TT5, K44など）

## 3-4　代表例 10 問で型判定を練習

### 例1: K♠7♦2♣

```
Step 1: 3 スート (♠♦♣) → モノトーンではない
Step 2: ペアなし
Step 3: トップ K (ハイ)
Step 4: ウェット条件なし (max_diff=11 大、2-tone なし、高連続なし)
  → 型1: ハイ × ドライ
```

### 例2: Q♥J♥8♣

```
Step 1: NO
Step 2: NO
Step 3: トップ Q (ハイ)
Step 4: 2-tone (♥♥) ✓ → ウェット
  → 型2: ハイ × ウェット
```

### 例3: J♦7♠5♣

```
Step 1: NO
Step 2: NO
Step 3: トップ J (ロー)
Step 4: ウェット条件なし (max_diff=6、rainbow、高連続 NO)
  → 型3: ロー × ドライ
```

### 例4: T♠9♠8♦

```
Step 1: NO
Step 2: NO
Step 3: トップ T (ロー)
Step 4: 連続3枚 (max_diff=2) + 2-tone、どちらもウェット条件 ✓
  → 型4: ロー × ウェット
```

### 例5: A♥K♥Q♥

```
Step 1: 3 枚すべて ♥ → モノトーン
  → 型5: モノトーン
```

### 例6: A♠A♣K♦

```
Step 1: NO
Step 2: A ペア、キッカー K (≥ 8) ✓
  → 型6: ペア (ハイ+高キッカー)
```

### 例7: 7♠7♣2♦

```
Step 1: NO
Step 2: 7 ペア、キッカー 2 → 型6 条件 (QQ+ + 高キッカー) に非該当
  → 型7: ペア (その他)
```

### 例8: K♦4♣4♠

```
Step 1: NO
Step 2: 4 ペア、トップ K。
        「ハイペア (QQ+) + 高キッカー」には非該当 (ペアが 4)
  → 型7: ペア (その他)
```

### 例9: 9♣6♣5♦

```
Step 1: NO
Step 2: NO
Step 3: トップ 9 (ロー)
Step 4: 連続3枚 (max_diff=4 …ウェット条件のうち「連続3枚」は max_diff≤2、今回は 4 なので NG)
        2-tone (♣♣) ✓ → ウェット
  → 型4: ロー × ウェット
```

### 例10: Q♠J♦9♣

```
Step 1: NO
Step 2: NO
Step 3: トップ Q (ハイ)
Step 4: 連続3枚は max_diff=3 なので厳密にはウェット条件「連続3枚(≤2)」に該当しない。
        しかし「高ボード連続 (max_diff ≤ 4 かつ top ≥ T)」に該当 ✓
  → 型2: ハイ × ウェット
```

## 3-5　型判定で迷いやすい境界

### 迷い1: max_diff = 3 や 4 のボード

連続3枚（max_diff ≤ 2）ではないが「高ボード連続 (≤ 4 & top ≥ T)」に当たるか判定が必要。**トップが T 以上なら該当、9 以下なら非該当**。

- KQ8 (max_diff=5): トップはKだがmax_diff>4なので非該当 → ドライ
- QJ8 (max_diff=4): トップQ、max_diff=4 → 該当、ウェット
- 965 (max_diff=4): トップ9なので非該当 → ウェット条件は2-toneだけで判定

### 迷い2: 2-tone の扱い

rainbowか2-toneかは必ず確認。2-toneだけでウェット確定。モノトーン（3枚同スート）は別枠。

### 迷い3: ペアのランク

ペアのランクとキッカーの両方を見る必要があります。

- AAK: ペア=A（≥Q）、キッカー=K (≥8) → 型6
- AA2: ペア=A、キッカー=2 (<8) → 型7
- 772: ペア=7 (<Q) → キッカー問わず型7
- K44: ペア=4 (<Q) → キッカー問わず型7

---

## 3-6　7 型の頻度分布

1,755通りのフロップが7型にどれくらい分かれるかの目安です。

| 型 | 全体に占める割合 | 頻度 |
| --- | --- | --- |
| 型1: ハイ × ドライ | 約 12% | よく出る |
| 型2: ハイ × ウェット | 約 18% | 最頻 |
| 型3: ロー × ドライ | 約 8% | やや少 |
| 型4: ロー × ウェット | 約 22% | 非常に多い |
| 型5: モノトーン | 約 5% | 少ない |
| 型6: ペア (ハイ+高キッカー) | 約 3% | 少ない |
| 型7: ペア (そのほか) | 約 14% | 中程度 |
| そのほか境界 | 約 18% | - |

型2と型4で全体の4割を占めます。つまり実戦では「ハイ × ウェット」「ロー × ウェット」の扱いに最も習熟するべきです。

## 章のまとめ

- 1,755通りのフロップは、実戦の動き方で **7 型**に収まる
- 判定は4ステップ（モノトーン？　→ ペア？　→ トップの高低 → ウェット？）
- 各型の代表例を10個覚えれば、実戦で5秒で型が決まる
- 次章では「型1つに対して1つのアクションプラン」を学ぶ

次章に進めば、このフロップの型判定だけで具体的な行動が決まります。
