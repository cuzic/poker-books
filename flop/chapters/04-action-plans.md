## 導入　―― 型 ✕ ハンド強度 = アクション

第3章でフロップを **7 つの型**に分類しました。本章ではこの型それぞれに、**ハンド強度ごとのアクション**を対応させます。

本書の初心者編で覚える指示はシンプルです：

```
型を判定 → その型のプランを引く → 自分のハンド強度のアクションを取る
```

% も統合式も、ここでは登場しません。型とハンド強度だけで決まります。「%」を使った柔軟な判断は第II部（第8章以降）で扱います。本章までが第I部で、ここまで読めば実戦投入可能です。

---

## 4-1　ハンド強度の 3 段階

まず自分のハンドを3段階に分類します。これは本書のHandScore（第5章で詳述）の簡易版です。

| 強度 | 定義 | 具体例 (K♠7♦2♣ 上で) |
| --- | --- | --- |
| **強** | トップペア以上、ドローなしでも勝ち筋が明確 | KQ, AK, KK, 22 (セット), AA (オーバーペア) |
| **中** | アンダーペア、セカンドペア、ボトムペア、強めのドロー | 77, 88, 55, JT (BDSD), A7 (ミドルキッカー TP) |
| **弱** | ハイカードのみ、BDFD や BDSD のみ、完全エアー | QJ, AQ (A ハイだけ), 54 (何もない) |

詳細な計算方法は第5章で扱います。本章ではざっくり「**トップペア以上なら強、ペアまでいかないが勝ち筋があれば中、何もなければ弱**」と覚えれば十分です。

## 4-2　7 型別のアクションプラン早見表

これが本書の第I部の **核心ページ**です。フロップを見たら型判定して、この表を引くだけ。

| 型 | プラン名 | 強 | 中 | 弱 |
| --- | --- | --- | --- | --- |
| 型1: ハイ × ドライ | ⚡ **全開モード** | CBet 75% | CBet 33% | CBet 33% (半分) or チェック (半分) |
| 型2: ハイ × ウェット | 🎯 **狙い撃ちモード** | CBet 50% | CBet 33% (ドロー付きのみ) | チェック |
| 型3: ロー × ドライ | 🤔 **控えめモード** | CBet 50% | CBet 33% (ペア以上のみ) | チェック |
| 型4: ロー × ウェット | 🛡️ **撤退モード** | CBet 50% (セット以上) | チェック | チェック |
| 型5: モノトーン | 📕 **見送りモード** | CBet 50% (ナッツ級のみ) | チェック | チェック |
| 型6: ペア (ハイ+高キッカー) | ⚡ **全開モード** | CBet 33% (強弱問わずほぼ全レンジ) | CBet 33% | CBet 33% (ほぼ全レンジ押し) |
| 型7: ペア (そのほか) | 🎯 **中程度モード** | CBet 50% | CBet 33% | チェック (強ブロッカーあれば 33%) |

## 4-3　各プランの詳細と実戦例

### ⚡ 全開モード (型1, 型6)

PFAのレンジアドバンテージが最大化される型。**レンジ全体で押す**のが正解です。

#### 型1: ハイ × ドライ (例: K72r, A82r, Q53r)

```
強ハンド: CBet 75% ポット
  → TPTK, オーバーペア, セット などで最大バリューを取る
中ハンド: CBet 33% ポット
  → アンダーペア, 弱 TP でも押す。レンジ優位があるので通る
弱ハンド: CBet 33% (混合 50%) または チェック (混合 50%)
  → 純粋エアーでも半分はブラフで押す
  → BDFD やオーバーカードのブロッカーがあれば押す優先度が上がる
```

**実戦例**: K72rでAQs（Aハイ + BDFD）
→ **CBet 33% ブラフ**。空振りだがレンジ全体が押している以上、自分もその列に乗る。

#### 型6: ペア (ハイ + 高キッカー、例: AAK, KK9, QQT)

```
全ハンド: CBet 33% (小サイズで全レンジ押し)
  → ペアボードは PFA のオーバーペア/トリップスが強く、レンジアドバンテージ最大
  → サイズは 33% 固定でOK。大きく打つ必要なし
```

**実戦例**: AAKで76s（空振り + OESD気味）
→ **CBet 33%**。AAKでBBが負ける場面多数、ブラフでも高いEV。

---

### 🎯 狙い撃ちモード (型2, 型7)

レンジ優位は残るが、BBにもヒットが入る型。**選別して押す**。

#### 型2: ハイ × ウェット (例: Q83ss, KQTss, KJ9r)

```
強ハンド: CBet 50% ポット
  → TPTK, オーバーペア, セット。
  → 75% は打たない (ウェットなので相手がフォールドしてくれず、コール+ドロー完成リスクを上げる)
中ハンド: CBet 33% (ドロー付きに限定)
  → OESD, FD, ガットショット+ハイカードなど、何かしらドローを持っていれば
  → ドローなしの中ハンド (アンダーペアだけ) はチェック
弱ハンド: チェック
  → 純粋エアーはチェック。ブラフしない
```

**実戦例**: KQTssでQJ (TP + OESD)
→ **CBet 50%**。TPTKで中サイズ、相手のドローにプロテクションしつつバリュー取り。

#### 型7: ペア (そのほか、例: 772, K44, A99)

```
強ハンド: CBet 50%
  → トリップス、ハイポケット、TP 以上
中ハンド: CBet 33%
  → ミドルペア、弱 TP
弱ハンド: チェック (ブロッカー強ければ 33%)
  → AK のような強オーバーカードはブラフ候補
  → その他エアーはチェック
```

**実戦例**: 772でA8o（Aハイ）
→ **チェック**。Aハイだけでは弱い。772のペアボードは中頻度で、弱ハンドを押す必要性が薄い。

---

### 🤔 控えめモード (型3)

ロー + ドライ。一見攻めやすそうだが、BBにコネクターが多くヒットしている可能性あり。**選別して押す**。

#### 型3: ロー × ドライ (例: J75r, T62r, 876r)

```
強ハンド: CBet 50%
  → トップペア以上のみ。75% は大きすぎ
中ハンド: CBet 33% (ペア以上のみ)
  → 弱 TP、ミドルペア、アンダーペアまで
  → 単なるオーバーカードは含まない
弱ハンド: チェック
  → ロー側ではブラフの成功率が下がる (BB が弱い手を持っていてもコールしやすい)
```

**実戦例**: J75rでA3s（Aハイ + BDFD）
→ **チェック**。AハイだけでBDFDは弱い。ロー側はブラフ回収率が悪い。

---

### 🛡️ 撤退モード (型4)

ロー + ウェット。レンジ優位なし + ドロー密度高。**強ハンドで中サイズ、それ以外はチェック**。

#### 型4: ロー × ウェット (例: T98ss, 987ss, JT9ss)

```
強ハンド: CBet 50% (セット以上のみ)
  → オーバーペアは実はここで危ない (相手のストレート完成率高い)
  → セット、ストレート、フラッシュだけを強ハンドとして扱う
中ハンド: チェック
  → オーバーペアも含めてチェック推奨
  → 強ドロー (OESD+FD) も混合でチェック、ビッグに突っ込まない
弱ハンド: チェック
  → 絶対にブラフしない
```

**実戦例**: T98ssでKK（オーバーペア）
→ **チェック**。オーバーペアでも相手の98, 87, JTなどに負けている確率が十分ある。コントロールを優先。

---

### 📕 見送りモード (型5)

モノトーン。BBのフラッシュドロー保有率が高く、大きなベットは回収率が悪い。**ナッツ級のみ小さく**。

#### 型5: モノトーン (例: A♥K♥Q♥, 9♠8♠7♠)

```
強ハンド: CBet 50% (ナッツ級、フラッシュ完成級のみ)
  → フラッシュ完成 (トップフラッシュ)、ストレートフラッシュ
  → ブロードウェイモノトーンで AA/KK など単なる役は慎重に
中ハンド: チェック
弱ハンド: チェック
```

**実戦例**: A♥K♥Q♥ でJ♠T♠（ストレート完成）
→ **CBet 50%**。K, Q, Aのフラッシュが来てもストレートは強い。

---

## 4-4　混合戦略 (弱ハンドの扱い方)

「型1（ハイ×ドライ）の弱ハンド → CBet 33% 半分 / チェック半分」の「**半分**」の意味を明確にします。

### どうやって半分に分けるか

**ブロッカー / BDFD 有無**で分けるのが最も素直な方法です。

- BDFDあり / オーバーカードがブロッカーとして働く → **ブラフ側 (33% CBet)**
- BDFDなし / ブロッカー弱い → **チェック側**

### 具体例: K72r で空振りのハンド群

- AQs（Aハイ + BDFD, A/QでBBのAx/Qxをブロック）→ **ブラフ**
- AQo（オフスート、BDFDなし）→ **チェック**
- 54s（まったく関係ないスーテッドコネクター）→ **チェック**
- 98s（BDFDはあるがA/Kをブロックしない）→ **混合、任意の基準 (例: スペードなら押す)**

### 「毎回同じにしないこと」の重要性

対戦経験のある相手は、あなたのハンドを観察学習します。毎回AQsでCBet、毎回AQoでチェックすると、パターンが読まれます。定期的に逆をやる（AQoでも打つ、AQsでチェック）ことで搾取耐性が上がります。この議論は巻③の「混合戦略R1-R6」で深めます。

## 4-5　OOP (SB/BB) の場合の補正

ここまでの表は **IP (BTN, CO)** が前提です。OOP (SB vs BB) のとき、簡易レンジスコアのCBet頻度推定から **10% を差し引いた値**で頻度帯を判定します。

| 簡易レンジスコア 頻度 | IP 判定 | OOP 補正後 | OOP 頻度帯 |
| --- | --- | --- | --- |
| 85% | 高頻度 | 75% | 高頻度（変わらず） |
| 70% | 高頻度 | 60% | 中頻度 |
| 55% | 中頻度 | 45% | 中頻度（変わらず） |
| 30% | 低頻度 | 20% | 低頻度（変わらず） |

### 理由

GTO Wizardのデータでは、BTN（IP）のCBet頻度は53-64%、SB (OOP) のCBet頻度は55〜60% 程度とIPと大差ありません。SB はレンジアドバンテージで OOP の不利を補うため、簡易レンジスコア値から約10% 引いた頻度を目安にします。

### 具体例

BB vs 3ハンドコール（マルチウェイ）でK72r、自分はAK (TPTK)

- IPなら「型1 × 強 = CBet 75%」
- **OOP マルチウェイ** なら50% まで下げる、または33%（マルチウェイ補正は第16章参照）

## 4-6　7 型の記憶術

5つのアクション名（⚡全開 / 🎯狙い撃ち / 🤔控えめ / 🛡️撤退 / 📕見送り）で覚えると早い。

### 覚え方1: プラン名の強度で並べる

```
強 ← ⚡全開モード (型1, 型6)
  ↓   🎯狙い撃ち (型2, 型7)
  ↓   🤔控えめ (型3)
  ↓   🛡️撤退 (型4)
弱 ← 📕見送り (型5)
```

### 覚え方2: 「高いカードがあるか」で分ける

```
A/K/Q あり かつ ドライ → 全開
A/K/Q あり かつ ウェット → 狙い撃ち
J以下 かつ ドライ → 控えめ
J以下 かつ ウェット → 撤退
モノトーン → 見送り
ペア (強)  → 全開 (小サイズ)
ペア (弱)  → 中程度
```

### 覚え方3: シンプルな言葉で

- ⚡ 全開：「ここは押さなきゃ損」
- 🎯 狙い撃ち：「中ぐらいに、選んで押す」
- 🤔 控えめ：「強いのだけ押す」
- 🛡️ 撤退：「ほぼチェック」
- 📕 見送り：「諦めろ」

## 4-7　21 マスから 9 マスへ ―― 第II部への橋渡し

本章の早見表（7 型 × 3 強度 = 21 マス）は、第3章の従来手法（7 型分類）にハンド強度を掛け合わせた**入門レシピ**です。実戦に投入できる最低限の解像度を提供しています。

ただし**21 マスでは粒度が荒い**ため、次のような場面で迷いが残ります。

- 型1 ハイ × ドライの「弱」ハンドを CBet 33% するか、チェックするか（混合の判断）
- 型1 と 型2 の境界（K83 rainbow vs Q83ss など）の扱いの差
- 同じ「中」でも、TP と弱TP で本当に同じアクションでよいのか

**第II部（第8〜第10章）** ではこれを次のように精緻化します。

| 章 | 道具 | 役割 |
| --- | --- | --- |
| 第8章 | 簡易レンジスコア | CBet 頻度を **連続 %** で出す（GTO 整合 R² = 0.873）|
| 第9章 | HandScore | ハンド強度を **0〜50 の連続値** で出す |
| 第10章 | 9 マスマトリクス | 上記 2 つを掛け合わせ、可変サイズで判定 |

### 7 型と 9 マスで判定が変わる例

**フロップ K♠8♠3♦、自分は AQs（IP、BTN open vs BB call）**

#### 7 型アクションプラン（本章）の判定

- 型2 ハイ × ウェット（K83、♠♠ で 2-tone）→ 🎯 狙い撃ちモード
- AQs はオーバーカード + BDFD のみ → 弱ハンド（TP 未満）
- 型2 × 弱 → **チェック**

#### 9 マスマトリクス（第10章）の判定

- 簡易レンジスコア = 約 80%（高頻度帯。トップ K + 2-tone は GTO 上 75〜85% で打つ）
- HandScore ≈ 9（A 高 +2、BDFD +4、BDSD +0、ブロッカー +3）→ H1 帯
- 高頻度 × H1 → **CBet 33%（小サイズで頻度押し）**

7 型では「ウェットだから弱ハンドはチェック」と一律処理しますが、9 マスでは「相手のディフェンスが薄い高頻度帯では弱ハンドも 33% で押す」という GTO 寄りの判断が出ます。**同じボード・同じハンドでも、精度を上げると判定が変わる**わけです。

### 何が同じで、何が改善されるか（要約）

- **同じ**：ボードと自分のハンド強度から動きを決める基本骨格
- **違う**：離散カテゴリ → 連続 %、固定アクション → 可変サイズ・混合頻度
- **改善**：境界ボードの扱いが滑らかになり、相手の傾向に応じた微調整ができ、巻③以降の精密モデルへつながります

第I部のレシピで素早く動き、第II部のスコアで精度を上げる ―― この二段階で実戦力を仕上げてください。

## 章のまとめ

- 7 型それぞれに、**ハンド強度ごとの具体的なアクション**が決まっている
- 強 / 中 / 弱の分類は「TPTK 以上 / ペア or ドロー / それ以外」でざっくり判定
- ⚡全開 / 🎯狙い撃ち / 🤔控えめ / 🛡️撤退 / 📕見送りの 5 つのプラン名で全 7 型をカバー
- OOP では「一段階控えめ」に
- ここまでで **初心者は実戦投入可能**。迷ったら本章の表を引くだけ
- 21 マスは離散だが速い。第II部の **9 マス × 連続%** は精密だが計算ステップを要する。両方を状況で使い分ける

## ミニクイズ

### 問1

**フロップ: A♠8♠3♦ (型判定は前章参照: 型1 ハイ×ドライ)**

あなたのハンドは **KQo**（IP、BTNオープン対BBコール）。アクションを答えてください。

<details>
<summary>解答</summary>

- 型1のプラン → ⚡ 全開モード
- KQoはAハイに当たって何もない。AK/AQ/AJなどにも負けている → 弱ハンド（BDFDもなし）
- 型1 × 弱： CBet 33%（半分）またはチェック（半分）
- KQoはオーバーカードブロッカーが弱い（K/QでBBのKX/QXを多少ブロック）→ **ブラフ寄り、CBet 33%**

**答え: CBet 33%**（または半々でチェック）

</details>

---

### 問2

**フロップ: 9♣8♣7♠ (型判定: 型4 ロー×ウェット)**

あなたのハンドは **TT** (IP)。アクションを答えてください。

<details>
<summary>解答</summary>

- 型4のプラン → 🛡️ 撤退モード
- TTはオーバーペアだが、9-8-7のウェットボードで65, 76, JT, T9など多くのハンドに負けている可能性あり
- セット/ストレート級ではない → 強ハンドとしては扱わない
- 型4 × 中（せいぜい中ハンド）: チェック

**答え: チェック**

「オーバーペアだから75% 打てる」は型1・型6での話。型4では一段控える。

</details>

---

### 問3

**フロップ: Q♠Q♦T♣ (型判定: 型6 ペア ハイ+高キッカー)**

あなたのハンドは **5♥4♥**（BBコール後、IPで見たフロップ）。アクションを答えてください。

<details>
<summary>解答</summary>

- 型6のプラン → ⚡ 全開モード（小サイズ33%）
- 54は完全エアー、ドローもなし → 弱ハンド
- 型6 × 弱： CBet 33%（ほぼ全レンジ押し）

**答え: CBet 33%**

型6はPFAのレンジアドバンテージが極端に強い状況。弱ハンドでも小サイズブラフが通りやすい。

</details>
