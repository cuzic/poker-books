# 第08章　チェックレイズ入門

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> チェックレイズ（CR）は OOP のプレイヤーが持つ最も強力な武器の一つです。
> チェックして相手がベットしてきたところにレイズを重ねることで、ポットを大きく膨らませたり、相手の継続を難しくしたりできます。
> 本章では CR の 2 つの目的・標準サイズ・使うべきボードとハンドの条件を学びます。
> 詳細な GTO データや発展的な CR 戦略は巻③で扱います。本章は概論として骨格をつかんでください。

---

## 8-1　チェックレイズの 2 つの目的

CR には大きく 2 つの目的があります。

### 目的 1：バリューの最大化

セット・2ペアなど強いハンドを持つとき、チェックしてから IP のベットにレイズすることでポットを大きくできます。
IP が CBet しなかった場合（チェックバック）はターンで再アクションできます。

CR の利点は「IP が守備（コール）するコストを大幅に引き上げる」点にあります。
IP が CBet → OOP CR という流れで、IP は CR にコールするかフォールドするかを迫られます。

### 目的 2：レンジ保護（ブラフ CR）

バリュー CR だけでは「CR = 強いハンド」と読まれてしまい、IP が常にフォールドするようになります。
適度にブラフ CR を混ぜることで、IP はドロー系ハンドにも対処しなければならなくなります。

ブラフ CR に適したハンドは、フラッシュドロー（FD）や OESD（オープンエンドストレートドロー）など、**エクイティが高く将来の改善が期待できるハンド**です。

```
CR の 2 目的:
  1. バリュー CR: セット / 2ペア → ポット拡大 / IP に高コスト要求
  2. ブラフ CR:   FD / OESD    → レンジ保護 / IP の CBet を抑制
```

2 つの目的が同時に達成できるボード（ウェット 2 トーンなど）で、CR は最も効果的に機能します。

---

## 8-2　標準 CR サイズとポットオッズ

CR のサイズは「3× IP のベット」が標準です。

### 標準 CR の計算

```
標準 CR サイズ = 3 × IP のベット額

例: SRP フロップ（pot=6bb）で IP が 33%（2bb）CBet した場合:
  OOP CR to 6bb（= 3 × 2bb）
  ポットの動き: 6 + 2（IP bet）+ 6（OOP raise）= 14bb
  IP の追加コール額: 6 − 2 = 4bb
  IP のポットオッズ: 4 / (14 + 4) = 4/18 ≈ 22%
  → IP はエクイティ 22% 以上が必要

例: IP が 75%（4.5bb）CBet した場合:
  OOP CR to 13.5bb（= 3 × 4.5bb）
  ポットの動き: 6 + 4.5 + 13.5 = 24bb
  IP の追加コール: 13.5 − 4.5 = 9bb
  IP のポットオッズ: 9 / (24 + 9) = 9/33 ≈ 27%
```

標準 CR の 22〜27% というポットオッズは、IP に対して「セット以上か強いドロー複合でないとコールできない」という圧力をかけます。

### サイズ選択の考え方

| CR サイズ | 効果 | 使い所 |
|:---|:---|:---|
| 3× IP bet（標準） | IP に 22〜27% オッズ要求 | 最も一般的 |
| 4〜5× IP bet | IP にフォールド率が上がる | より強い手でバリュー最大化 |
| オールイン | IP を即オールイン判断に追い込む | SPR < 3、強ハンド確定 |

## 8-3　CR レンジの構成

CR はバリューとブラフを混ぜて使います。

### バリュー CR

強いハンド（セット・2ペア・TP+強ドロー複合）でポットを大きくします。

```
バリュー CR の例:
  セット (HS = 85):                常に CR 候補
  2ペア (HS = 75):                 CR or コール（ボードによる）
  TPTK + NFD (HS ≈ 95〜98):        ウェット板では CR が有力
```

### ブラフ CR

FD・OESD などエクイティの高いドローでブラフ CR を打ちます。

```
ブラフ CR の例（ウェット 2トーン・モノトーンボードで有力）:
  ナッツ FD (HS ≈ 50〜60):         CR ブラフ候補
  OESD (HS ≈ 40〜55):             CR ブラフ候補（改善時のバックアップ）
  FD + ガットショット:             複合ドロー = 強力なブラフ CR
```

### バリュー:ブラフの比率

§ 8-2 の計算から、標準 CR（3× bet）では IP のポットオッズは約 22〜27% です。
IP がこのオッズでコールを検討する均衡では、OOP の CR レンジにブラフが約 25〜30% 含まれている状態が均衡点です。
つまり **CR バリュー 3 コンボに対してブラフ 1 コンボ（3:1）** が均衡の目安になります。

```
近似の目安:
  CR バリュー 3 コンボにつき CR ブラフ 1 コンボ

例: 2トーン K-high ボードで:
  CR バリュー: KK (セット), K7s (2ペア), K♣Q♣ (TPTK+FD) = 3 コンボ
  CR ブラフ:  J♣T♣ (FD+OC), A♣5♣ (ナッツFD+ガット) = 1 コンボ
```

この比率は概算であり、実際の GTO 比率は具体的なボードとスタック深度によって変わります（巻③で詳細を扱います）。

## 8-4　CR を使うべきボードと避けるべきボード

ボードテクスチャによって CR の有効性が大きく変わります。

### CR が機能するボード（ウェット系）

```
2トーン (例: K♣8♦5♣, J♣9♦7♣):
  → FD・OESD が多くブラフ CR 候補が豊富
  → OOP の CR 頻度: 概算で約 15〜25%（wet board）

モノトーン (例: K♠7♠2♠):
  → ブラフ CR は難しいが、バリュー CR（セット・FD）は有効
  → フラッシュドロー保有で CR が強力な選択肢
```

### CR を避けるべきボード（ドライ系）

```
Dry rainbow (例: K♣7♦2♠):
  → FD・OESD が少なくブラフ CR 候補が乏しい
  → CR はほぼバリュー（セット・2ペア）のみ
  → セット以外はコールまたはフォールドが多い
  → OOP の CR 頻度: 概算で約 5〜17%（dry board。K72r: 約 10.5%、A82r: 約 17.1% が GTO 実測値）
```

### ペアボード

```
ペアボード (例: K♣K♦7♠, 7♣7♦2♠):
  → OOP がセットを持つ頻度が低い
  → CR バリューが限定的。コールが主体
  → IPがAKなどでベットしてくる場合、コールで情報収集が有効
```

## 8-5　CR に直面した IP の対応

CR を打った後、IP はどのように反応するでしょうか。

```
IP の CR 対応:
  ポットオッズ = 22〜27%（標準 CR の場合）

  T1 ハンド (HS ≥ 65, TPTK 以上):  コールが主体
  T2 ハンド (HS 20〜65):          フォールドが多い（強い T2 はコール）
  T3 ハンド (HS < 20):            フォールドが主体
```

このことは、OOP の CR が profitable（EV > 0）になる理由を示しています。
IP のハンドの大部分が T2・T3 に属するため、CR に対してフォールドする IP の割合は高くなります。
特にドライボードで IP がレンジ CBet（全ハンドでほぼベット）している場合、T3 のハンドが多く混入しており、CR フォールドが増えます。

## 8-6　HS 閾値と CR の判断

第7章で学んだ SPR 別 CR 閾値を使ってCR を判断します。

```
SRP フロップ（SPR ≈ 16, SPR ≥ 6 カテゴリー）:
  CR 閾値: HS ≥ 40

判断:
  HS ≥ 40 かつ wet/2トーン ボード → CR を積極的に検討
  HS ≥ 40 かつ dry ボード         → コールが主体（CR はセット・2ペアのみ）
  HS < 40                        → コール or フォールド（CR は原則なし）
```

### 具体例

**例 1：7♣7♦ on K♣7♦2♠（dry rainbow）、IP が 33%（2bb）CBet**

- HS: セット（7-7-7）= 役スコア 85 + ドロー加点なし = **HS = 85**
- CR 閾値（SPR ≥ 6）: 40
- HS=85 ≥ 40: 閾値を大幅に超えており、ドライ rainbow でも CR が最有力の選択。

**例 2：A♣Q♥ on Q♣8♣5♦（2トーン）、IP が 50%（3bb）CBet**

- HS: TPTK（Q ペア + A キッカー）= 役スコア 65 + ナッツFD（A♣ + Q♣8♣ = 3クラブ = NFD）= +33 → **HS = 98**
- CR 閾値: 40
- HS=98 ≥ 40: 閾値を大幅に超えており、2トーンボードでの CR が最有力の選択。

**例 3：J♣T♣ on Q♣8♣5♦（2トーン）、IP が 50%（3bb）CBet**

- HS: 役なし（Q-high ボードで JT は当たらず）+ OESD（J-T-Q-8 で two-way、8 out） = +12
  ナッツFDに近い FD（♣ドロー）= +13。複合で +15（キャップ）
  HS ≈ 15
- CR 閾値: 40
- HS=15 < 40: 通常コールが有力。ブラフ CR の候補ではあるが、単独では閾値未達。

**例 4：A♠K♠ on K♣4♦4♠（ペアボード）、IP が 50%（3bb）CBet**

- HS: TPTK（K-K-K-A-4 の best 5 = トリップス？）
  確認: ハンド A♠K♠、ボード K♣4♦4♠ → best 5 = A-K-K-4-4 = **2ペア（K's & 4's、A キッカー）**
  役スコア: 2ペア ≈ 20 + ドロー加点なし = HS ≈ 20
- CR 閾値: 40
- HS=20 < 40: コールが主体。ペアボードで AK は強いが、IP がフルハウスを持つ場合の警戒必要。

## 8-7　CR の全体フロー

フロップで IP に CBet を受けたとき、CR を検討する手順をまとめます。

```
【CR 判断フロー】

1. SPR を確認
   SPR ≥ 6 → CR 閾値 = 40
   SPR 3〜5 → CR 閾値 = 60
   SPR < 3  → CR 閾値 = 75

2. HS を計算

3. HS ≥ CR 閾値 かつ ボードが wet / 2トーン → CR を検討
   HS ≥ CR 閾値 かつ ボードが dry           → コールが主体
   HS < CR 閾値                             → コールまたはフォールド

4. CR を選んだ場合: 標準サイズは 3× IP bet
```

## ミニクイズ

### 問1

SRP フロップ（pot=6bb、SPR ≈ 16）で IP が 33%（2bb）CBet。
OOP のハンドはセット（HS = 85）。
CR 閾値は HS ≥ 40 です。このとき CR の判断として正しいのはどれですか？

1. HS=85 ≥ 40 なので CR 閾値を満たし、CR が有力
2. セットでも dry board では CR より コールが有力
3. HS に関係なく全ハンドで CR が最善

### 問2

2トーンボード（K♣7♣2♠）で OOP がブラフ CR を打つのに適したハンドはどれですか？

1. J♦T♦（2 オーバーカード、rainbow フロップでドローなし）
2. A♣5♣（バックドアFD + A ハイ）
3. K♦Q♦（TPTK、ドローなし）

### 問3

IP が 75%（4.5bb）CBet してきた場合、OOP の標準 CR サイズはいくつですか？（pot=6bb）

1. CR to 9bb（2 × 4.5bb）
2. CR to 13.5bb（3 × 4.5bb）
3. CR to 18bb（4 × 4.5bb）

---

### 解答

- **問1**: **1. CR が有力** が正解。セットの HS = 85 は閾値 40 を大幅に超えています。SPR ≥ 6 の SRP フロップでは HS ≥ 40 で CR を積極的に検討します。
- **問2**: **2. A♣5♣** が正解。A♣5♣ は K♣7♣2♠ ボードで A-high かつナッツFD（♣）を持ち、ブラフ CR に適したエクイティ（フラッシュ完成約 35%）を持ちます。J♦T♦ はこのボードでドローがなくブラフ CR に不向きです。K♦Q♦ は TPTK でバリュー CR やコールが有力で、ブラフ CR の候補ではありません。
- **問3**: **2. CR to 13.5bb（3 × 4.5bb）** が正解。標準 CR = 3× IP ベットです。4.5bb × 3 = 13.5bb。

---

> **本章まとめ**
>
> - CR（チェックレイズ）の目的は 2 つ: バリュー最大化（セット・2ペア）とレンジ保護（FD・OESD ブラフ）。
> - 標準 CR サイズ = 3× IP のベット額（IP に 22〜27% ポットオッズを要求）。
> - CR 閾値（SPR ≥ 6）: HS ≥ 40。セット(85)・2ペア(75)・TPTK+NFD(≈95) はいずれも閾値を大幅に超える。
> - ウェット・2トーンボードで CR が最も機能し、ドライ rainbow では CR はほぼバリューのみ。
> - CR バリュー 2〜3 コンボにつき CR ブラフ 1 コンボが目安の比率。

---

**【GTO とのズレ】**

本章の CR 閾値（HS ≥ 40）と「3× IP ベット」標準サイズは実践的な目安ですが、GTO は CR 頻度・サイズともにボードとスタック深度によって細かく変わります。
特にドライ K-high ボードでの CR 頻度は GTO 実測で約 5〜17%（K72r: 10.5%、A82r: 17.1%）と幅があり、ウェット板では約 14〜26% に増加します（巻③の 15 ボード TexasSolver 実測値）。
CR バリュー:ブラフの比率も均衡値からズレると IP に対応されやすくなるため、巻③の詳細データで精緻化することを推奨します。
