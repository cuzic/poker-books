> **本章の目標**: 第9章の基本式と第27章のR1〜R6の上に、マルチウェイ補正（M）・SPR補正・Exploit補正（E）・3betポット補正（3bP）の4項を加えた「完全統合式」を提示します。暗算の限界を正直に示しつつ、プロ領域への橋渡しとなる実用フレームワークを習得します。

## 28-1　なぜ「完全版」が必要か

### 基本式（第9章）の限界再整理

第9章のCBet統合式は非常に強力な出発点でした。

```
CBet スコア = HandScore − BoardScore + ポジション係数
```

この3項の式で、フロップ判断の大部分をカバーできます。しかし設計上の前提が明確に存在します。**ヘッズアップのSRP（シングルレイズドポット）**という前提です。

第9章の9-5節では3つの限界を明記しています。

1. **限界1**：レンジ全体のバランスは反映されない
2. **限界2**：マルチウェイには直接適用できない
3. **限界3**：3betポットでは係数調整が必要

これらの限界は「知っているが手をつけていない問題」として、読者の頭の片隅に残り続けます。本章はその問題に正面から取り組みます。

### 中級R1〜R6（第27章）でカバーできたこと・まだできていないこと

第27章のR1〜R6は、基本式の「境界問題」を解決しました。

**カバーできたこと**

- R1（3バンド化）：しきい値付近での決定論的パターンを崩した
- R2（スート判定）：疑似混合戦略で搾取耐性を確保した
- R3（RangeAdv補正）：ハイカード/ローカードフロップの有利不利を反映した
- R4（サイズ2択）：ナッツアドバンテージに基づくサイズ選択を実装した
- R5（チェックレンジ保護）：強ハンドの一部チェックで搾取耐性を向上した
- R6（MDF ±10%）：相手タイプ別のディフェンス調整を加えた

**まだカバーできていないこと**

- プレイヤー数の変化（3-way、4-way）への体系的な対応
- SPR（スタック深度）の変化に対する連続的な補正
- 相手タイプ（Nit/コールステーション/アグレ）を式に組み込む統合
- 3betポットの構造的違いの明示的な反映

第27章末尾にも記した通り、「マルチウェイではR1〜R4の効果が薄れる」という問題は未解決のままです。

### 本章の位置づけ：プロ領域への橋渡し

本章は本書の最終章のひとつとして、**暗算可能な近似の限界点**を正直に示します。

Level 1（基本式のみ）は完全に暗算で回せます。Level 2（R1〜R6追加）もほぼ暗算で対応できます。しかし本章のLevel 3（M/SPR/E/3bP追加）は、状況認識のボトルネックが生じます。4項すべてを毎ハンド全力で計算することは、現実的に難しいです。

だからこそ「全部覚える必要はない。使える項から足していく」という指針が重要になります。本章の目標は「完全な式を提示すること」と「それをどこまで使うかを自分で判断できるようにすること」の両立です。

## 28-2　完全統合式の全体像

### 式を一行で提示

```
CBet スコア = HandScore − BoardScore + Position
              + R3 + M + SPR + E + 3bP
```

この式が本書の「完全版」です。各項の意味を以下に整理します。

### 各項の名前・記号・意味

| 記号 | 名前 | 意味 | 参照章 |
|------|------|------|--------|
| HandScore | ハンドスコア | フロップでの手の強さ（役・ドロー・ブロッカー） | 第8章 |
| −BoardScore | ボードスコア減点 | ウェット度の減点（高いほどCBetしにくい） | 第5章 |
| Position | ポジション係数 | IP +3、OOP 0 | 第9章 |
| R3 | RangeAdv補正 | ハイカード/ローカード × レイザー/コーラーの補正 | 第27章 |
| M | マルチウェイ補正 | プレイヤー数に応じた減点 | 本章 28-3 |
| SPR | スタック深度補正 | 実効スタック ÷ ポットによる補正 | 本章 28-4 |
| E | Exploit補正 | 相手タイプ別の補正 | 本章 28-5 |
| 3bP | 3betポット補正 | 3betポット・4betポットでの補正 | 本章 28-6 |

### 判定しきい値（基本と同一）

完全版でもしきい値は変えません。基本式と同じ4段階を使います。

```
≥ 15 → CBet 75%（強ハンドで価値最大化）
8〜14 → CBet 33%（軽いサイズで幅広く）
2〜7 → チェック（後続ストリートで判断）
< 2 → チェック・フォールド準備
```

しきい値を固定することで、Level 1からLevel 3への移行がシームレスになります。追加項（M、SPR、E、3bP）はスコアを上下させるだけで、判定の枠組みは変わりません。

## 28-3　M：マルチウェイ補正

### 定義

Mはプレイヤー数に応じてスコアから引く補正項です。しきい値を実質的に引き上げる効果と等価です。

```
M（マルチウェイ補正）：

  ヘッズアップ（自分 + 相手1人）: M = 0
  3-way（自分 + 相手2人）:       M = −3
  4-way 以上（自分 + 相手3人以上）: M = −5
```

### 根拠：第18章との整合

第18章（マルチウェイのフロップ）で示したデータを振り返ります。

GTO Wizardの解析によれば、ヘッズアップのCBet頻度は約18%（ポットサイズ）ですが、3-wayでは約1.3%まで激減します。チェック頻度はヘッズアップ比で+11ポイント増加します。

この頻度低下を「しきい値の実質的な引き上げ」として式に組み込んだのがM項です。3-wayでM = −3は「スコアが3点低い状態でCBetしている」と等価であり、「33% → チェック」のしきい値付近のハンドをチェックに転換させます。

4-way以上でM = −5は「強バリューかナッツドロー以外はチェック」という第18章の指針と整合します。スコア8〜14のセカンドペア相当のハンドは4-wayで8〜14−5 = 3〜9となり、チェック域か境界付近に収まります。

### 暗算での覚え方

「相手1人増えるごとにスコアから3引く」という直感が近似として機能します。

- ヘッズアップ：M = 0（1-way加算なし）
- 3-way：M = −3（相手が1人増えた）
- 4-way：M = −5（相手がさらに増えた、やや小さめ）

厳密には線形ではありませんが、「3人目以降は効果が逓減する」という感覚を持っておくと、5-way以上でもM ≈ −6〜−7として近似できます。

### 例題1：3-wayでの変化

**状況**：KQ on K72r、IP（BTN）、3-way（BTN vs SB vs BB）

```
HandScore = 15（TPTK）
BoardScore = 0（K72r ドライ）
Position = +3（IP）
R3 = +2（ハイカード × レイザー）

【基本スコア（ヘッズアップ想定）】
CBet スコア = 15 − 0 + 3 + 2 = 20
→ 強バンド、CBet 75%

【M適用後（3-way）】
CBet スコア = 20 + M = 20 − 3 = 17
→ 依然として強バンド（≥ 17）、CBet 75% 継続
```

KQのTPTKはK72rの3-wayでも積極的にCBetできます。M = −3で3点落ちても強バンドに留まります。

### 例題2：3-wayでチェックに転換するケース

**状況**：JT on K72r、IP（BTN）、3-way

```
HandScore = 0（空振り）+ 9（2オーバーカード補正なし、JTはK72で2オーバーなし）
         = 0（空振り）
BoardScore = 0（K72r ドライ）
Position = +3（IP）
R3 = +2（ハイカード × レイザー）

【基本スコア（ヘッズアップ想定）】
CBet スコア = 0 − 0 + 3 + 2 = 5
→ チェック域（2〜7）

【M適用後（3-way）】
CBet スコア = 5 − 3 = 2
→ チェック（下限付近）
```

ヘッズアップでも空振りはチェック域でしたが、3-wayではさらに2まで下がります。チェックの判断がより確実になります。

## 28-4　SPR：スタック深度補正

### 定義

SPRは「実効スタック ÷ フロップ時点のポット」で計算します（第17章参照）。SPR補正項はその値に応じてスコアを調整します。

```
SPR補正項：

  SPR ≤ 3（浅い）:    SPR = +2
    ワンペアでもスタックオフ想定、攻めやすい
  SPR 3〜6（中低）:    SPR = 0（中立）
    3betポットの標準的な値
  SPR 6〜15（深い）:   SPR = −1
    標準SRPの大部分、やや慎重に
  SPR ≥ 15（超深い）: SPR = −3
    セット以上でないと大きなポットは避ける
```

### 根拠：第17章との整合

第17章（SPR戦略）で示した通り、SPR ≤ 3ではトップペアトップキッカー（TPTK）が自動的なスタックオフハンドになります。この「攻めやすさ」をSPR = +2として式に組み込みます。

逆にSPR ≥ 15のディープスタック環境では「ワンペア系ハンドの価値が大幅に低下」します。第17章で示した通り、AToはSPR 13以上でスタックオフ不可レベルまで価値が落ちます。これをSPR = −3として反映します。

SPR 6〜15を−1とした理由は、標準SRP（100bb開始でSPR ≈ 17.7）の「大部分」を包含するためです。実際のSRP学習の多くがこの帯域で行われており、本書の基本式はこの帯域向けに設計されています。微小な減点（−1）は「基本式はSPR中程度を想定しており、やや深い場合は慎重に」という意味です。

### 例題：同じハンドでSPR 3とSPR 15の判断差

**状況**：KQ on K72r、IP（BTN）、ヘッズアップ、R3 = +2。

```
基本スコア = 15 − 0 + 3 + 2 = 20

【SPR 3（浅いスタック）の場合】
完全統合スコア = 20 + M(0) + SPR(+2) = 22
→ CBet 75%（積極的に価値を最大化）

【SPR 15（超深いスタック）の場合】
完全統合スコア = 20 + M(0) + SPR(−3) = 17
→ CBet 75%（強バンドだが、ターン・リバーのプランが必要）
```

両者ともCBet 75%ですが、スコアの差（22 vs 17）は「プレイの積極性」の違いを示しています。SPR 3では強引に押し切れるのに対し、SPR 15では強バンドでもポストフロップの慎重なプランが必要です。

さらに弱いハンドで比較すると差が明確になります。

```
HandScore = 10（トップペア・弱キッカー）で同ボード

基本スコア = 10 − 0 + 3 + 2 = 15

【SPR 3】: 15 + 2 = 17 → CBet 75%
【SPR 15】: 15 − 3 = 12 → CBet 33%（サイズが下がる）
```

SPR 3では強気にCBet 75% を打てますが、SPR 15では33% の小サイズに抑えて慎重に進めるべきです。

## 28-5　E：Exploit補正（相手タイプ別）

### 定義

E（Exploit補正）は相手のプレークセが判明している場合に追加する補正項です。

```
E（Exploit補正）：

  ナッツ型ニット（フォールド率高、VPIP 12〜18）: E = +3
  コールステーション（フォールド率低、VPIP 40+）: E = −3
  アグレッシブ・チェックレイザー（AFq 高）:      E = −2
  パッシブ・リアクティブ（コールはするがレイズなし）: E = +2
  タイプ不明 / 初見:                             E = 0
```

### 根拠：第20章との整合

第20章（相手タイプとスタック深度によるしきい値調整）で詳細に扱った内容を、式の補正項として数値化したものです。

第20章ではNitへの対応として「しきい値を8→3まで引き下げ、エアを含む幅広いレンジでCBetを実行する」と述べました。これをE = +3として式に組み込みます。「スコアが3点上がった状態でプレイしている」と等価です。

コールステーションはフォールドしてくれないため「ブラフCBetは完全にEVマイナス」です。これをE = −3で表現します。スコアが3点下がることで、ブラフ域のハンドがチェック域に転換します。

アグレッシブ・チェックレイザーへのE = −2は「このタイプはCBetに対してチェックレイズを多用するため、CBetのリスクが高い」という調整です。コールステーションより緩い補正にとどめるのは、フォールドもある程度期待できるためです。

### 判定の方法

**統計（HUD あり）の場合**

| 統計 | Nit/Tight | 標準 | Loose |
|------|-----------|------|-------|
| VPIP | 12〜18% | 19〜28% | 30%+ |
| PFR | 8〜14% | 15〜22% | 22%+ |
| FtCBet（CBetに対するフォールド率） | 60%+ | 45〜60% | 〜45% |
| AFq（アグレッションフリーケンシー） | 〜30% | 30〜50% | 50%+ |

FtCBet（フォールドツーCBet）が60% 超ならE = +3（ニット判定）が有効です。FtCBet 40% 以下でコールが多ければE = −3（コールステーション判定）を適用します。

**統計なしの場合（ライブ・観察）**

2〜3ハンドの観察でタイプを推定します。

- 何度もコールして最後に弱いハンドをショーダウン → コールステーション疑い（E = −3候補）
- フロップで何も作れていないのに即フォールド → Nit疑い（E = +3候補）
- CBetに頻繁にチェックレイズ → アグレッシブ（E = −2候補）

初見や判断つかない場合はE = 0（調整なし）で基本式に任せます。

### 例題1：Nit相手へのブラフCBet

**状況**：AJ（空振り）on K72r、IP（BTN）、ヘッズアップ、相手はNit（FtCBet 72%）

```
HandScore = 0（空振り）+ 9（2オーバーカード）= 9
BoardScore = 0（K72r ドライ）
Position = +3（IP）
R3 = +2（ハイカード × レイザー）

基本スコア = 9 − 0 + 3 + 2 = 14
→ CBet 33%（混合ゾーン）

E適用後（Nit、E = +3）:
完全スコア = 14 + 3 = 17
→ CBet 75%（強バンド）
```

通常は33% のRange CBetに相当するスコアが、Nit相手ではE = +3で17に上昇し、75% の積極的CBetが正当化されます。Nit相手ではブラフも大きいサイズで打てます。

### 例題2：コールステーション相手での戦略転換

**状況**：77 on A52r、IP（BTN）、ヘッズアップ、相手はコールステーション（VPIP 55%）

```
HandScore = 6（アンダーペア）
BoardScore = 0（A52r ドライ）
Position = +3（IP）
R3 = +2（ハイカード × レイザー）

基本スコア = 6 − 0 + 3 + 2 = 11
→ CBet 33%（弱寄りの33%帯）

E適用後（コールステーション、E = −3）:
完全スコア = 11 − 3 = 8
→ CBet 33%（下限ギリギリ、チェックも選択肢）
```

ヘッズアップでは33% CBetが選択肢でしたが、コールステーション相手ではE = −3でスコア8の境界まで下がります。このハンドではCBetのフォールドエクイティがゼロに近く、バリューも薄いため、チェックで情報を得るラインが優ります。

## 28-6　3bP：3betポット補正

### 定義

3bPは3betポット・4betポットの構造的な違いを補正する項です。

```
3bP（3betポット補正）：

  通常 SRP（シングルレイズドポット）: 3bP = 0
  3betポット OOP（OOPから3betした場合）: 3bP = +2
  3betポット IP（IPから3betした場合）:   3bP = +1
  4betポット:                          3bP = +3
```

### 根拠：第19章との整合

第19章（3betポット、低SPR戦略）で示した通り、3betポットではSPRがSRPの約1/4（SPR ≈ 4.4）まで低下します。このSPR低下は「OOPの不利が縮小する」効果をもたらします。

通常OOPではPosition = 0（IP +3に対して不利）です。しかし第19章では「3betポットではOOPでも高頻度CBetが正しいことが多い」と述べました。この補正をOOP側に3bP = +2として数値化します。

IP側（3bP = +1）はOOPほど恩恵が大きくないものの、低SPR環境では「1〜2ベットでオールインに届く」ためセミブラフの価値が上昇します。この効果を+1で表現します。

4betポットはさらに低SPR（SPR ≈ 1.5程度）となり、ほぼすべてのトップペア以上でコミット必至です。3bP = +3はこの「攻めやすさ」を反映します。

### 例題：77 on A32r、3betポットOOP

**状況**：77 on A32r、OOP（BB）、3betポット（SBが3betを呼んだ）

```
HandScore = 6（アンダーペア）
BoardScore = 0（A32r ほぼドライ）
Position = 0（OOP）
R3 = +2（ハイカード × コーラー側... ではなく3betコーラー側）
    → 実際にはR3の符号は3bet側の立場で判断。ここでは0とします。

基本スコア = 6 − 0 + 0 + 0 = 6
→ チェック（2〜7域）

3bP適用後（3betポット OOP、3bP = +2）:
完全スコア = 6 + 2 = 8
→ CBet 33%（下限ラインに到達）
```

通常SRPではチェックが妥当なアンダーペアが、3betポットではSPRの低さゆえにCBet 33%の下限に到達します。ブラフCBetとしての機能が生まれます。

## 28-7　R3 再掲（本章での位置づけ）

### 本章単独で完全版を使えるようにする

第27章を読んでいない読者でも本章単独で完全統合式を使えるよう、R3の定義を再掲します。

```
R3（RangeAdv補正）：

  ハイカードフロップ（A/K/Q が1枚以上）× プリフロップのレイザー側: +2
  ハイカードフロップ × コーラー側:                               −2
  ローカードフロップ（全て J 以下）× コーラー側:                 +2
  ローカードフロップ × レイザー側:                               −2
  その他（中程度のボード、判断つかず）:                            0
```

「ハイカード」はフロップ最高ランクがA/K/Qのいずれかを指します。Jは「ローカード」扱いです。

この補正の直感は「自分のレンジがボードに刺さっているか否か」です。プリフロップのレイザーはハイカードが多いため、ハイカードボードで有利（+2）です。コーラー（BB等）はローカードを多く持つため、ローカードボードで有利（+2）です。

数値は変えていません。第27章と完全に同じ定義です。

## 28-8　完全統合式の段階的適用

### 3つのレベル

完全統合式を一度に全部習得する必要はありません。使える項から足していく段階的なアプローチを推奨します。

```
Level 1（初級）: HandScore − BoardScore + Position のみ
  → 第9章の基本式。暗算で完結。フロップ判断の80% をカバー。

Level 2（中級）: + R3（+ R1/R2/R4/R5/R6 から選択）
  → 第27章の追加。境界スポットで搾取耐性が上がる。
  → R3だけなら暗算可。R1〜R6全部は状況次第。

Level 3（上級）: + M + SPR + E + 3bP
  → 本章の追加。プロ領域への近似。
  → 状況認識（プレイヤー数、SPR、相手タイプ、ポット種類）がボトルネック。
```

### どこまで暗算できるか

Level 2までは本質的に暗算可能です。R3は「ハイカードフロップでレイザーなら+2」という1行の判定で完結します。

Level 3の4項目は、それぞれが「状況認識」を要求します。

- **M**：プレイヤー数を数える（1秒）
- **SPR**：スタックとポットを比較する（5秒）
- **E**：相手のタイプを思い出す（瞬時、ただし事前観察が必要）
- **3bP**：ポット種類を確認する（瞬時）

M・3bPは素早く確認できます。SPRは事前に計算しておく習慣が必要です。Eは相手観察の質に依存します。

「全部覚える必要はない。使える項から足していく」という指針は、上達の順序としても正しいものです。Level 1 → Level 2 → Level 3は、習熟度に応じた自然な学習ステップです。

### 各レベルでカバーできる状況

| レベル | 主な対応状況 | カバー率（概算） |
|--------|------------|---------------|
| Level 1 | ヘッズアップ SRP、標準スタック | 約 60% |
| Level 2 | + 境界スポット、レンジアドバンテージ考慮 | 約 75% |
| Level 3 | + マルチウェイ、SPR変化、相手搾取、3betポット | 約 85〜90% |

残りの10〜15% はGTOソルバーの領域です。

## 28-9　完全例題5本

各例題では**基本スコア → R3適用後 → 完全統合スコア**の3段階でスコアを提示します。

### 例1：KQ on K72r、3-way、ニット相手（E=+3）

**状況**

- ハンド：KQ（TPTK近い強さ）
- ボード：K72r（完全ドライ、BoardScore = 0）
- ポジション：IP（BTN）
- プレイヤー数：3-way（BTN vs SB vs BB）
- 相手タイプ：SBはNit（FtCBet 68%）、BBは不明

```
HandScore = 15（TPTK レベル）
BoardScore = 0（K72r ドライ）
Position = +3（IP）

【基本スコア】
CBet スコア = 15 − 0 + 3 = 18 → CBet 75%

【R3適用後】
R3 = +2（ハイカード × レイザー）
スコア = 18 + 2 = 20 → CBet 75%（強バンド）

【完全統合スコア】
M = −3（3-way）
E = +3（SBがNit。BBは不明のため E/2 ≈ +1 として近似、
        または保守的に相手全体でE = +2 を採用）
SPR = 0（SRPで100bb、SPR ≈ 17 → 6〜15 帯で −1）

最終スコア = 20 − 3 + 2 − 1 = 18 → CBet 75%
```

3人いてもKQのTPTKはK72rで積極的なCBet 75%が正当化されます。Nit相手のE補正がM補正を相殺し、スコアは強バンドに留まります。実戦ではSB（Nit）からのコールは弱く、BBからコールがあれば真の勝負という構図になります。

### 例2：JJ on T98ss、ヘッズアップ、低SPR（SPR=+2）、アグレ相手（E=−2）

**状況**

- ハンド：JJ（オーバーペア）
- ボード：T98ss（ウェット、BoardScore = 7）
- ポジション：IP（BTN）
- SPR：2（ショートスタック環境または4betポット後）
- 相手タイプ：アグレッシブ・チェックレイザー

```
HandScore = 20（オーバーペア）
BoardScore = 7（T98ss ウェット）
Position = +3（IP）

【基本スコア】
CBet スコア = 20 − 7 + 3 = 16 → CBet 75%（強バンド上限付近）

【R3適用後】
R3 = −2（ローカード × レイザー）
スコア = 16 − 2 = 14 → CBet 33%（中立域）

【完全統合スコア】
M = 0（ヘッズアップ）
SPR = +2（SPR ≤ 3 浅い）
E = −2（アグレ・チェックレイザー）
3bP = 0（SRP）

最終スコア = 14 + 0 + 2 − 2 + 0 = 14 → CBet 33%
```

R3適用でスコア14（33%域）になったJJは、低SPR（+2）とアグレ相手（−2）が相殺してスコア14を維持します。CBet 33%が妥当です。

ただし注意点があります。T98ssでのJJはチェックレイザーに対してCBetすると、セミブラフのチェックレイズを誘発するリスクがあります。スコアが33%域でも、このボードではチェックでフリーカードを与えながら相手の行動を見る判断も合理的です。式は判断の入口であり、最終決定は文脈を加味します。

### 例3：77 on A32r、3betポットOOP（3bP=+2）、コール好き相手（E=−3）

**状況**

- ハンド：77（アンダーペア）
- ボード：A32r（ほぼドライ、BoardScore = 0）
- ポジション：OOP（BB）
- ポット種類：3betポット（BBが3bet、BTNがコール）
- 相手タイプ：コーリングステーション

```
HandScore = 6（アンダーペア）
BoardScore = 0（A32r）
Position = 0（OOP）

【基本スコア】
CBet スコア = 6 − 0 + 0 = 6 → チェック域

【R3適用後】
R3 = 0（ハイカード × 3betコーラーの立場は明確でないため 0）
スコア = 6 + 0 = 6 → チェック域

【完全統合スコア】
M = 0（ヘッズアップ）
SPR = 0（3betポットSPR ≈ 4.4 は 3〜6 帯で中立）
E = −3（コーリングステーション）
3bP = +2（3betポット OOP）

最終スコア = 6 + 0 + 0 − 3 + 2 = 5 → チェック域
```

3betポットOOPの構造補正（+2）をコールステーション補正（−3）が上回り、スコアは5でチェック域に留まります。A32rでアンダーペアでは、コールしてくれる相手に対してブラフは機能しません。チェックして相手の行動を見るのが正解です。

### 例4：AK on 652r（ローカードフロップ）、レイザー側（R3=−2）、4-way（M=−5）

**状況**

- ハンド：AK（空振り、2オーバーカード）
- ボード：652r（ローカード、BoardScore = 0）
- ポジション：IP（CO）
- プレイヤー数：4-way（CO vs BTN vs SB vs BB）

```
HandScore = 0（空振り）+ 9（2オーバーカード）= 9
BoardScore = 0（652r 完全ドライ）
Position = +3（IP）

【基本スコア】
CBet スコア = 9 − 0 + 3 = 12 → CBet 33%（下限付近）

【R3適用後】
R3 = −2（ローカード × レイザー側）
スコア = 12 − 2 = 10 → CBet 33%（境界）

【完全統合スコア】
M = −5（4-way）
SPR = −1（SRP 6〜15 帯）
E = 0（タイプ不明）
3bP = 0（SRP）

最終スコア = 10 − 5 − 1 = 4 → チェック域（2〜7）
```

4-wayのM = −5がスコアを10から4へと急落させます。ローカードボードでのR3（−2）も加わり、AKの2オーバーカードは4-wayでは完全にチェック域です。

これは第18章の指針「4-way以上では強いバリューかナッツドロー以外はチェック」と一致します。AKの2オーバーカードは4-wayでエクイティ40%前後であり、3人全員をフォールドさせる確率は非常に低いため、ブラフCBetは期待値マイナスです。

### 例5：QQ on J74hh、SPR 15（SPR=−3）、HUDなし（E=0）、2.5betポットOOP

**状況**

- ハンド：QQ（オーバーペア）
- ボード：J74hh（ツートーン、BoardScore = 2）
- ポジション：OOP（SB）
- SPR：15（150bbディープスタック環境）
- HUD統計なし（ライブカジノ）
- ポット種類：2.5betポット（通常SRPに近い構造）

```
HandScore = 20（オーバーペア）
BoardScore = 2（J74hh ツートーン）
Position = 0（OOP）

【基本スコア】
CBet スコア = 20 − 2 + 0 = 18 → CBet 75%（強バンド）

【R3適用後】
R3 = −2（ハイカード × レイザー側だが OOP の SB = コーラー的立場も）
  → ここでは J がトップカード（ローカード扱い）のため
     R3 = 0（J 以下はローカード、レイザー側は −2 だが J は境界）
  → 保守的に R3 = 0 で計算
スコア = 18 + 0 = 18 → CBet 75%

【完全統合スコア】
M = 0（ヘッズアップ）
SPR = −3（SPR ≥ 15 超深い）
E = 0（HUDなし）
3bP = 0（SRP）

最終スコア = 18 + 0 − 3 + 0 + 0 = 15 → CBet 75%（下限ギリギリ）
```

SPR = −3の影響でスコアは18から15へ下がり、75% しきい値のギリギリになります。J74hhのツートーンボードでは相手がハーツのフラッシュドロー（例：AhKh、Th9h）を持つ可能性があります。

スコア15は「CBet 75%判定」ですが、実際にはR1の混合ゾーン（13〜16）に入ります（第27章との連携）。R2を適用してQ（高い方）のスートが ♠♥ なら75%、♣♦ なら33% というサイズ選択が有効です。

ディープスタック（SPR 15）ではQQのオーバーペアがリバーでフラッシュに負けるリスクが高く、ポットサイズを抑制しながら進める選択肢もあります。式は「75%域」を示していますが、ディープスタックのマルチストリートプランとして33%でポット管理するラインも合理的です。

## 28-10　【GTOとのズレ】完全版でも残る限界

### M/SPR/E/3bPは線形近似

本章で統合した4項（M、SPR、E、3bP）は、すべて**線形の加減算**として設計されています。しかしGTOソルバーが行う最適化は非線形です。

例えば、3-wayでM = −3という設定は「相手が1人増えると一定量CBetしにくくなる」という線形の仮定に基づいています。実際のGTOでは、ボードのテクスチャ・両者のレンジ構成・SPRが組み合わさった非線形な最適解が存在します。K72rの3-wayとT98ssの3-wayでは、M = −3が適切に機能するケースと過補正になるケースが混在します。

### ストリートを跨ぐプランニングは本書の範疇外

完全統合式はフロップの判断を対象としています。ターンでカードが落ちた後のスコアは再計算が必要です。「フロップでのM、SPR、Eの値をターンに引き継ぐ」設計にはなっていません。

GTO的な意思決定では「フロップのアクションがターン・リバーの期待値にどう影響するか」というマルチストリートの展開を最初から考慮します。本書のフロップ単発スコアは、この多ストリート最適化を捨象しています。

### 混合戦略はR2で近似するが、GTO頻度には届かない

第27章のR2（スート判定）で50:50の疑似混合を実装しました。GTOが推奨する「37%のCBet、63%のチェック」のような非等分の混合頻度は再現できていません。

また、完全統合式にM、SPR、E、3bPを加えた後も、これらの項が「同じハンドを何%の確率でCBet・何%でチェックするか」という混合頻度を変えるわけではありません。項の値がスコアを変化させ、バンドが変われば行動が変わりますが、GTO的な「37%CBet」のような細かい頻度制御は実装されていません。

### 本書の到達点としての位置づけ

本書が達成したことを正直に整理します。

**達成したこと**

- フロップの主要判断（CBet頻度・サイズの大枠）を暗算可能な式で近似した
- ヘッズアップSRPの約60%、Level 3適用で約85〜90%の状況に対応した
- マルチウェイ・SPR変化・相手タイプ・3betポットの4要素を定量的に組み込んだ
- GTOとのズレを各章で正直に示した

**達成できなかったこと（意図的に捨象）**

- レンジ全体のバランス最適化
- マルチストリートのプランニング
- 非線形なGTO最適解の再現
- 混合頻度の細かい制御

本書の哲学は「暗算可能な近似で、致命的なミスを除く実用線」です。完全統合式はその実用線の最高水準です。ここから先はGTOソルバー（第26章のロードマップ参照）の世界です。

本書を卒業したあなたには、完全統合式という「地図」が手に入っています。その地図がGTOという「実際の地形」とどこで一致し、どこで外れるかを理解した状態で、ソルバーを使う準備が整っています。
