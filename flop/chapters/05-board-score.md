# 第5章　ボードテクスチャを数値化する（BoardScore）

<!-- markdownlint-disable MD033 MD036 MD040 MD060 -->
<!-- textlint-disable preset-ja-technical-writing/no-mix-dearu-desumasu -->

> 「このボードはドライですか、ウェットですか？」と聞かれて答えられるなら、次の問いに答えてください。「では、どのくらいウェットですか？」

---

## 導入　―― ボードを数字で語る理由

フロップが配られると、経験豊富なプレイヤーは瞬時に「このボードはCBetしやすい」「ここは慎重に」と判断します。その判断は直感に見えますが、じつは **コネクティビティ（繋がり）** と **スーテッドネス（同スート性）** という2つの軸で測れる構造的な評価です。

本章ではその評価を **BoardScore** という数値として定量化します。BoardScoreは本書3式の最初の式であり、フロップ判断の出発点となります。スコアを計算すれば「なぜCBetするのか、しないのか」を感覚ではなく根拠で説明できるようになります。

なお、フロップの組み合わせはスートの等価性を考慮すると **1,755 通り** に絞られます。22,100通りのように見える膨大な場面も、パターンを分類すれば十分に学習可能な数に収まります。この事実がボードテクスチャ研究の出発点です。

---

## 5-1　BoardScore の式

本書独自のBoardScore式は次のとおりです。

```
BoardScore = ストレート要素 + フラッシュ要素 + ハイボード要素
```

**スコアが高いほどウェット（湿潤）で、CBetが通りにくい状態です。スコアが低いほどドライ（乾燥）で、CBetが通りやすい状態を表します。**

式の構造はシンプルです。ストレートドローの危険度・フラッシュドローの危険度・ハイカードによるレンジ構造の複雑さを加算します。危険要素がないボードはスコア0（またはマイナス）に近づきます。

スコアの上限は理論上 **+11**（連続3枚+モノトーン+Broadway2枚以上で +5+5+1）です。ペアボードは −1の補正があるため、理論上の下限は **−1** です。この下限はキャップせず、マイナスになり得ることを本書では明記します。

---

## 5-2　ストレート要素

ストレート要素は、相手がストレートドロー（OESDやガットショット）を持ちやすいかどうかを評価します。3枚のランクが密集しているほど加算幅が大きくなります。

| ランク構成 | 加算 | 例 |
|---|---|---|
| 連続3枚（差が1ずつ） | +5 | 9-8-7、J-T-9 |
| 連続2枚＋ギャップ1以内 | +3 | K-Q-8（KQ連続＋8はギャップ）、Q-J-9 |
| 1〜2ギャップ（最大ランク差が2〜3） | +2 | K-J（間にQ）、K-T（間にJ・Q）、J-8（間に9・10）、9-7（間に8） |
| 完全バラバラ | 0 | K-7-2、A-8-3 |

「連続2枚＋ギャップ1以内」の判定は少し迷いやすいので補足します。これは3枚のうち2枚が連続していて、残り1枚が2つのランク以内に収まる場合です。K♠Q♣8♦ であればKQが連続していて8は独立しているため、この式では「1ギャップ」扱いではなく「連続2枚＋ギャップ」と判断します。

### なぜ連続3枚は +5 なのか

9-8-7のようなボードでは、T-6（OESD）・J-T（OESD）・6-5（OESD）という形で、相手がオープンエンドストレートドローを持てるハンドのコンボ数が合計で **48 コンボ以上** に達します。OESDは8アウトを持ち、フロップからリバーまでの完成率は約31.5% です。これだけ多くの相手がドローを持つ状況では、大きなCBetは意味をなしません。

---

## 5-3　フラッシュ要素

フラッシュ要素は、フラッシュドローやフラッシュ完成の危険度を評価します。

| スート構成 | 加算 | 例 |
|---|---|---|
| 3枚同マーク（モノトーン） | +5 | A♥T♥4♥、J♠6♠4♠ |
| 2枚同マーク（ツートーン） | +2 | K♠T♦5♠、J♦8♣4♦ |
| レインボー（3スート全異なる） | 0 | K♠7♦2♣、9♥8♣7♦ |

### スート分布の実態

実際のフロップ分布は次のとおりです（1,755通りベース）。

| スート構成 | 割合 |
|---|---|
| レインボー | 約 40% |
| ツートーン | 約 56% |
| モノトーン | 約 5% |

ツートーンボードが **過半数** を占めることが重要です。日常的に遭遇するフロップの大半にフラッシュドローの可能性があります。ツートーンのフロップでは、残り同スートが11枚あるため、相手が保有できるフラッシュドローのコンボは理論上55コンボ（実質約30コンボ）になります。

モノトーンは全フロップの約5% にすぎませんが、戦略的インパクトは大きく特別扱いが必要です。モノトーンでは相手が既にフラッシュを完成させている確率が5〜8% あり、さらに25〜30% の相手がフラッシュドローを保有します。

---

## 5-4　ハイボード要素

ハイボード要素は、ブロードウェイカード（T・J・Q・K・A）が複数並ぶことで相手のレンジが強化される効果と、ペアボードが逆にドライ化する効果を評価します。

| 条件 | 加算 |
|---|---|
| Broadway 2枚以上（KQ9、AJ8 など） | +1 |
| ペアボード（77K など） | **−1**（ドライ化） |
| 上記いずれでもない | 0 |

Broadwayカードが2枚以上あるとき、相手のプリフロップレンジにフィットしやすいハンドが増えます。BBはプリフロップでKJo・KTo・QJoなどを広く守備するため、ハイボードでのレンジアドバンテージが縮小します。

一方、ペアボードは逆の効果をもたらします。ペアのランクが2枚使われているため、そのランクを軸にするストレートドローのコンボが大幅に減少します。また、相手がトリップスを持てるのはそのランクのホールカード2枚分のみで、大きなハンドが入りにくい構造になります。この「静的化」効果を −1として表現します。

---

## 5-5　ドライ・セミウェット・ウェットの判定しきい値

BoardScoreの計算後、次のしきい値でボードの性質を判定します。

| スコア | 判定 | CBet の基本方針 |
|---|---|---|
| **≤ 3** | **ドライ** | 33% ポット程度の小サイズで高頻度 CBet |
| **4〜6** | **セミウェット** | 選択的に 50〜75% サイズで CBet |
| **≥ 7** | **ウェット** | 基本はチェック。超強ハンドのみ大きく CBet |

このしきい値はGTO Wizardのデータと整合しています。ドライボードではCBet頻度が高く、超ウェットボードではCBet頻度が下がります。詳細は後述の【GTOとのズレ】コラムを参照してください。

---

## 5-6　代表的フロップ 10 例の BoardScore 計算

具体的な計算で理解を固めましょう。

### 例1　K♠7♦2♣（超ドライ）

```
ストレート要素: 完全バラバラ → 0
フラッシュ要素: レインボー → 0
ハイボード要素: Broadway 1枚のみ → 0

BoardScore = 0 + 0 + 0 = 0
```

判定：**ドライ**。理想的なCBetボードです。相手にドローがほぼなく、プリフロップアグレッサーがレンジ優位を最大限に活かせます。

---

### 例2　A♠8♠3♦（ツートーン、Broadway A）

```
ストレート要素: 完全バラバラ → 0
フラッシュ要素: ♠2枚 → +2
ハイボード要素: A のみ（Broadway 1枚） → 0

BoardScore = 0 + 2 + 0 = 2
```

判定：**ドライ**。Aの存在でプリフロップレイザーのレンジ優位は大きく、ツートーンでも頻繁にCBetできます。

---

### 例3　K♠T♦5♣（2ギャップ、Broadway）

```
ストレート要素: K-T（差3、間にJ・Q）→ 2ギャップ → +2
フラッシュ要素: レインボー → 0
ハイボード要素: K・T の Broadway 2枚 → +1

BoardScore = 2 + 0 + 1 = 3
```

判定：**ドライ（境界）**。ギリギリドライ寄りのセミウェットです。

---

### 例4　J♦8♣4♦（2ギャップ、ツートーン）

```
ストレート要素: J-8（差3、間に9・10）→ 2ギャップ → +2
フラッシュ要素: ♦2枚 → +2
ハイボード要素: Broadway 1枚のみ → 0

BoardScore = 2 + 2 + 0 = 4
```

判定：**セミウェット**。フラッシュドローとガットショットが絡む中程度のボードです。

---

### 例5　Q♣J♦9♠（連続2枚＋ギャップ1、Broadway）

```
ストレート要素: Q-J 連続＋9（ギャップ1以内）→ +3
フラッシュ要素: レインボー → 0
ハイボード要素: Q・J の Broadway 2枚 → +1

BoardScore = 3 + 0 + 1 = 4
```

判定：**セミウェット**。K-T（OESD）やT-8（ガットショット）など多くのドローが存在します。

---

### 例6　9♥8♥7♦（連続3枚、ツートーン）

```
ストレート要素: 連続3枚 → +5
フラッシュ要素: ♥2枚 → +2
ハイボード要素: Broadway なし → 0

BoardScore = 5 + 2 + 0 = 7
```

判定：**ウェット（境界）**。相手にOESDが多数あり、さらにフラッシュドローも絡む難しいボードです。

---

### 例7　J♠T♠9♦（連続3枚、ツートーン、Broadway）

```
ストレート要素: 連続3枚 → +5
フラッシュ要素: ♠2枚 → +2
ハイボード要素: J・T の Broadway 2枚 → +1

BoardScore = 5 + 2 + 1 = 8
```

判定：**ウェット**。ストレートドロー・フラッシュドロー・Broadwayカードの三重苦です。

---

### 例8　A♥K♥Q♥（連続3枚、モノトーン、Broadway）

```
ストレート要素: 連続3枚 → +5
フラッシュ要素: モノトーン → +5
ハイボード要素: Broadway 3枚（A・K・Q） → +1

BoardScore = 5 + 5 + 1 = 11
```

判定：**超ウェット（最大値）**。フラッシュ完成・ストレート完成・Broadwayの三重ヒット。このボードでCBetできる役はロイヤルフラッシュか最上位のフルハウスのみです。

---

### 例9　7♦7♣K♥（ペアボード、バラバラ）

```
ストレート要素: バラバラ → 0
フラッシュ要素: レインボー → 0
ハイボード要素: ペアボード → −1（Broadway K が1枚あるが、ペアルールが優先）

BoardScore = 0 + 0 + (−1) = −1
```

判定：**ドライ（下限）**。ペアボードはストレートドローのコンボが激減し、最もドライな構造になります。理論上の下限値 −1です。

---

### 例10　T♥9♠8♣（連続3枚、レインボー）

```
ストレート要素: 連続3枚 → +5
フラッシュ要素: レインボー → 0
ハイボード要素: T のみ → 0

BoardScore = 5 + 0 + 0 = 5
```

判定：**セミウェット**。連続3枚ながらレインボーのため、フラッシュドローがなく「ウェット」にはなりません。ストレートドローだけに注意すればよい、比較的管理しやすいボードです。

---

## 【GTOとのズレ】コラム

BoardScoreはGTOソルバーの出力を簡略化した近似です。実際のGTOと比べると、いくつかのズレが存在します。

### CBet サイズは「放物線」を描く

GTO Wizardのデータによると、CBetサイズはボードのウェット度に対して放物線（パラボラ）を描きます。

```
ドライ（Score 0〜3）→ 小サイズ（33%ポット）高頻度
セミウェット（4〜6）→ 大サイズ（75〜130%ポット）中頻度
超ウェット（≥ 7）  → 小サイズ（33%ポット）低頻度
```

超ウェットボードで再び「小サイズ」になる点が直感と異なります。超ウェットでは相手のコールレンジの約29% がストレート・フラッシュ（60% 以上のエクイティ）で構成されるため、大きなベットは逆効果です。

### SplitSuit の 12 カテゴリーとの対応

Gareth James（SplitSuit Poker）は1,755通りを12カテゴリーに分類しています。頻度上位5カテゴリーは次のとおりです。

| カテゴリー | 頻度 | BoardScore の傾向 |
|---|---|---|
| ペアボード（Paired boards） | 16.94% | ドライ寄り（≤ 3） |
| K/Q+ローカード2枚 | 16.22% | セミウェット〜ドライ |
| 2 Broadway + ローカード | 13.90% | セミウェット |
| J/T+ローカード2枚 | 13.61% | セミウェット |
| A+Broadway+ローカード | 9.27% | セミウェット〜ドライ |

上位5カテゴリーで全フロップの約70% を占めます。この5種類でBoardScoreの運用を練習すれば、大部分の実戦に対応できます。

### Upswing Poker の6分類との対応

Upswing Pokerは「レインボー×ディスコネクテッド」「ペアボード」「ツートーン×コネクテッド」などの6分類を提示しています。BoardScoreとの対応関係は次のとおりです。

| Upswing 分類 | 代表 BoardScore |
|---|---|
| レインボー・ディスコネクテッド（ドライ） | −1〜2 |
| ペアボード | −1〜2 |
| レインボー・コネクテッド | 3〜5 |
| ツートーン・ディスコネクテッド | 2〜4 |
| ツートーン・コネクテッド | 5〜7 |
| モノトーン | 5〜11 |

### BoardScore が捉えられないもの

BoardScoreはボードの形（テクスチャ）だけを評価します。次の要素は考慮されていません。

1. **レンジアドバンテージ**：どちらのプレイヤーのレンジがより強くフィットするか
2. **ポジション**：IPとOOPでは同じボードでも最適アクションが異なる
3. **SPR（スタックポットレシオ）**：スタックの深さによる戦略変化
4. **ナッツアドバンテージ**：最強ハンドの所持率の非対称性

これらの要素は第9章のCBet統合式で組み込まれます。BoardScoreはあくまで「ボードの形だけ」を測る最初のレンズです。

---

## 章のまとめ

- **BoardScore = ストレート要素 + フラッシュ要素 + ハイボード要素**
- ストレート要素：連続3枚 +5 ／ 連続2枚＋ギャップ1以内 +3 ／ 1〜2ギャップ +2 ／ バラバラ0
- フラッシュ要素：モノトーン +5 ／ ツートーン +2 ／ レインボー 0
- ハイボード要素：Broadway 2枚以上 +1 ／ ペアボード −1 ／ そのほか0
- スコアが高いほどウェット。ドライほどスコアは低く、ゼロまたはマイナスになります
- スコア ≤ 3でドライ、4〜6でセミウェット、≥ 7でウェット
- ツートーンは全フロップの約56% を占め、最も頻繁に登場するスート構成です
- GTOでは超ウェットボードでCBetサイズが再び小さくなる「パラボラ」が観察されます
- BoardScoreはボード形状のみを評価します。レンジ・ポジション・SPRは後続の式で補完します
