# 第03章　T1/T2/T3 ティアシステム

<!-- markdownlint-disable MD026 MD033 MD036 MD040 MD060 -->

> **本章のゴール**: HS の値を使って手を T1・T2・T3 の 3 段階に分類し、ボードスコア（B）と組み合わせて CBet の可否を 1 ステップで判断できるようになる。

---

## 3-1　3 段階分類の全体像

前章で計算した HS を、次の 3 段階に当てはめます。

```
T1：HS ≥ 65　→　強いメイドハンド
T2：HS ≥ 20　→　ミドルハンド（有望手を含む）
T3：HS < 20　→　弱い手・ブラフ候補
```

この分類を覚えれば「自分の手が今どの立場にあるか」が一目でわかります。次節からは各ティアが CBet 判断でどう使われるかを説明します。

---

## 3-2　T1：常にベット

T1（HS ≥ 65）は、どのフロップボードでも CBet が最善になるほど強い手です。セット・オーバーペア（AA〜QQ）・TPTK など、ポットを育てる価値のある役がここに入ります。

**T1 がすべてのボードでベットできる理由**

T1 の手は相手のコールレンジ（TP 以下）よりも強いエクイティを持っています。ベットしてコールされても期待値がプラスになりやすいため、チェックでエクイティを遊ばせるのは損です。また T1 の存在をチェックレンジに混ぜると、相手に「CBet を省略しても安全」と学習させる副作用があります。

T1 ではベットサイズの選択が次の問題になりますが、それは第5章で扱います。本章では「T1 = CBet 確定」と覚えてください。

**T1 の代表例（K♣7♦2♠ ボード）**

| ハンド | HS | 役 |
|---|---|---|
| 7♥7♠ | 85 | セット |
| AA | 80 | OP高 |
| A♥K♥ | 71 | TPTK + BDFD |
| K♣Q♦ | 65 | TPTK |

---

## 3-3　T2：ボードスコアで判断

T2（HS ≥ 20）は強くも弱くもない「ミドルゾーン」です。単独では CBet を正当化できませんが、ボードが乾燥していれば相手がコールしにくくなるため CBet が成立します。

**判断式**

```
T2 の CBet 条件：B ≥ 58
  → YES：CBet
  → NO ：チェック
```

B = 58 のボード（rainbow Q-high）がちょうど境界です。ここより B が高ければ CBet、低ければチェックです。

**なぜ B = 58 が境界か**

B の値別に「T2 のベット推奨」をまとめると次のようになります。

| B 値 | テクスチャ例 | T2 のアクション |
|---|---|---|
| 83 | ペアボード（K-K-X） | CBet |
| 70 | モノトーン | CBet |
| 67 | レインボー連続（J-T-8r） | CBet |
| 62 | レインボー A/K-high | CBet |
| 58 | レインボー Q-high | CBet（境界） |
| 56 | 2 トーン A/K-high | チェック |
| 50 | 2 トーン（一般） | チェック |
| 55 | レインボー J 以下 | チェック |

T2 がチェックを選ぶのは実質的に「2 トーン」と「レインボー J 以下」の 2 パターンだけです。多くのボードで T2 もベットを打てると理解してください。

**T2 の代表例**

| ハンド | ボード | B | HS | CBet? |
|---|---|---|---|---|
| K♣T♦ | K♣7♦2♠ | 62 | 55（TPMK） | CBet（B ≥ 58） |
| A♥Q♠ | K♣7♦2♠ | 62 | 25（A-high） | CBet（B ≥ 58） |
| A♦Q♣ | 9♠8♦7♣ | 55 | 49（A-high + 2OC） | チェック（B < 58） |
| J♠T♦ | Q♣9♣3♦ | 50 | 44（エアー + OESD + BDFD） | チェック（B < 58） |

A♥Q♠ on K♣7♦2♠ は 2OC ボーナスが**成立しない**ことに注意してください。Q は K より低いので条件を満たさず、HS = 25（A-high）のみです。それでも B = 62 ≥ 58 なので T2 として CBet できます。

---

## 3-4　T3：乾燥ボード限定のブラフ

T3（HS < 20）は役もドローも乏しい純ブラフ候補です。チェックして相手にタダでターンカードを引かせるより、ドライなボードでベットしてフォールドを狙う方が期待値が高くなる場面があります。

**判断式**

```
T3 の CBet 条件：B ≥ 62
  → YES：CBet（乾燥ボード限定ブラフ）
  → NO ：チェック
```

**B ≥ 62 の意味**

B = 62 はレインボー A/K-high ボードです。このボードでは OOP（相手）が持てるドロー種類が少なく、高頻度でフォールドが取れます。33% ベット時のフォールド要求率は約 25% ですが、ドライ K-high ボードでは OOP フォールド率が 40〜50% に達するため、T3 ブラフが十分に利益を出せます。

反対に 2 トーンやレインボー J 以下（B < 62）では OOP がドローやエクイティを保持しやすく、ブラフが機能しません。T3 はここではチェックして次のストリートを待ちます。

**T3 の代表例**

| ハンド | ボード | B | HS | CBet? |
|---|---|---|---|---|
| J♣T♥ | K♣7♦2♠ | 62 | 16（air + BDFD） | CBet（B ≥ 62） |
| 6♥5♦ | K♣7♦2♠ | 62 | 10（air） | CBet（B ≥ 62） |
| 6♥5♦ | Q♣9♣3♦ | 50 | 10（air） | チェック（B < 62） |

J♣T♥ on K♣7♦2♠ は HS = 16（エアー 10 + BDFD 6）で T3 です。しかし B = 62 ≥ 62 なのでブラフとして CBet できます。このブラフはターンで K の 2 枚目が落ちたときや A が落ちたときに「コンティニュー」できるバックドアエクイティを持っています。

---

## 3-5　3 ティアを統合した判断フロー

実戦では次の 2 ステップで CBet を決めます。

```
STEP 1：HS を計算 → ティア決定
  HS ≥ 65  → T1：CBet 確定
  HS ≥ 20  → T2：STEP 2 へ
  HS < 20  → T3：STEP 2 へ

STEP 2：B を確認
  T2 かつ B ≥ 58 → CBet
  T2 かつ B < 58 → チェック
  T3 かつ B ≥ 62 → CBet（ブラフ）
  T3 かつ B < 62 → チェック
```

このフローを覚えれば、どのハンドでも「CBet か チェックか」を数秒で判断できます。

---

## 3-6　ボーダーラインのハンドを確認する

**HS = 65（T1/T2 の境界）**

T1 と T2 の境界は HS = 65 です。TPTK がちょうどこのラインに入ります。TPTK に BDFD（+6）が加わると HS = 71 となり、余裕を持って T1 に入ります。TPMK（55）は T2 です。

**HS = 20（T2/T3 の境界）**

T2 の下限は HS = 20 です。この設定には重要な意味があります。

HS = 20 の代表例は「K-high エアー」（役スコア = 20）です。また 2OC が成立しないハンドで役スコアが 10〜15 のとき、BDFD（+6）を加えても HS = 16 となり T3 に留まります。

一方、A-high エアー（25）に 2OC ボーナス（+24）が加わると HS = 49 となり T2 に分類されます。これが「2OC ボーナスの価値」です。旧来の H1/H2/H3 システムでは H2 の下限が 35 前後に設定されていたため、HS = 25〜34 の 2OC ハンドが「弱い手」として一律に扱われていました。しかし GTO データは 2OC ハンドがレインボー A/K-high ボードで積極的に CBet していることを示しており、T2 下限を 20 に拡張することでその動きを正確に再現できます。

**T2 下限 = 20 で何が変わるか**

| ハンド | ボード | 旧分類（H2下限35） | 新分類（T2下限20） |
|---|---|---|---|
| A♥Q♠ on K♣7♦2♠ | B=62 | H1（弱手→チェック） | T2（B≥58→CBet） |
| A♥J♦ on 9♠8♦7♣ | B=55 | H1（弱手→チェック） | T2（B<58→チェック） |
| A♥Q♠ on 9♠8♦7♣ | B=55 | H1（弱手→チェック） | T2（B<58→チェック） |

旧システムでは「A♥Q♠ on K-high レインボー」がチェックになっていましたが、実際には 40〜50% 程度の頻度で CBet するのが GTO 最適です。新ティアシステムはこの差を埋めています。

---

## 3-7　実戦での暗算スピードを上げるコツ

T1/T2/T3 の判定で最も時間がかかるのは「HS の計算」です。以下のヒントで計算を速くできます。

**強いメイドハンドはすぐ T1 と判断する**

セット（85）、オーバーペア（70〜80）、TPTK（65）はすべて T1 です。計算不要で即 CBet と判断できます。

**2OC ボーナスの判定を先に行う**

エアーハンドのとき、まず「両手札がボードのトップを上回るか」を確認します。上回れば +24 が加わるため T2 確定になります（A-high 25 + 24 = 49 ≥ 20）。上回らなければ BDFD の有無のみが問われます。

**T3 のチェック頻度を予測する**

T3 がベットできるのは「ペアボード・モノトーン・レインボー A/K-high・レインボー連続」のみです。それ以外は自動的にチェックと決めておくと判断が速くなります。

## ミニクイズ

### 問1

K♥Q♣ on Q♠9♦3♣ のとき、ティアと CBet 判断はどれですか。ただし B = 55（rainbow）とします。

1. T1 → CBet
2. T2 → CBet（B ≥ 58）
3. T2 → チェック（B < 58）
4. T3 → チェック

### 問2

A♣3♦ on K♠8♦7♣ のとき、ティアと CBet 判断はどれですか。ただし B = 62（rainbow A/K-high）とします。

1. T3 → チェック（B < 62）
2. T2 → CBet（B ≥ 58）
3. T3 → CBet（B ≥ 62）
4. T1 → CBet

### 問3

次の 4 ハンドのうち、T1 に分類されるものはどれですか。ボードは J♣7♦2♠（rainbow、B = 55）です。

1. A♠K♣（HS = 49）
2. K♠K♣（HS = 80）
3. 8♣6♦（HS = 10）
4. A♠9♦（HS = 25）

---

### 解答

- **問1**: 3（解説：K♥Q♣ on Q♠9♦3♣ は Q♣ がボードの Q♠ とペア = トップペア。キッカーは K なので TPGK（60）。ドロー加算なし。HS = 60 → T2（65 未満）。B = 55 < 58 なのでチェックです）
- **問2**: 2（解説：A♣3♦ on K♠8♦7♣ はノーペア。役スコアは A-high = 25。3 はボードに 7 や 8 があり 8 < 3... 3 もボードにない。2OC：A（>K）✓ですが 3（<K）なので 2OC 不成立。BDFD もなし（suit が揃わない）。HS = 25 → T2（≥20）。B = 62 ≥ 58 → CBet。正解は 2 です）
- **問3**: 2（解説：K♠K♣ は J♣7♦2♠ ボードで J より高い K のオーバーペア（AA〜QQ 相当）で HS = 80 → T1 です。1 の A♠K♣ は A（>J）と K（>J）の両方がボードのトップカードを上回るので 2OC（+24）が成立し HS = 25 + 24 = 49 → T2 です。4 の A♠9♦ は 9（<J）なので 2OC 不成立で HS = 25 → T2 です）

---

> **本章まとめ**
>
> - T1（HS ≥ 65）は全ボードで CBet
> - T2（HS ≥ 20）は B ≥ 58 のとき CBet、B < 58 のときチェック
> - T3（HS < 20）は B ≥ 62 の乾燥ボードのみ CBet（ブラフ）
> - T2 下限を 20 に設定することで 2OC ハンドが正しく「有望手」として分類される
> - 判断フローは「HS 計算 → ティア決定 → B との比較」の 2 ステップ

---

**【GTOとのズレ】**

本章のティアシステムは GTO の CBet 判断と約 90% の整合性を持ちますが、ミックス戦略（例：T2 が 60% CBet）を「する/しない」の 2 択に丸めているため、ボーダーライン付近のハンドで最大 20〜30% 程度の頻度ズレが生じます。実戦では大きな問題になりませんが、精密な最適化を目指す場合は巻③のレンジ優位（精密分析）を参照してください。
