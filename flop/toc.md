## 本書の中核：3つの数式

### 式1：BoardScore（ボードのドライ度指標）

```
BoardScore = 10 − ストレート要素 − フラッシュ要素 − ハイボードリスク

ストレート要素（相手がストレートを作れる並び）
  連続3枚（例：987、JT9）           : −5
  連続2枚＋ギャップ1以内（KQx など）  : −3
  1ギャップ（例：9-7、K-J）          : −2
  完全バラバラ                      : 0

フラッシュ要素
  3枚同マーク（フラッシュ完成、モノトーン）: −5
  2枚同マーク（ドロー可）            : −2
  レインボー                       : 0

ハイボードリスク
  Broadway 2枚以上（KQ9、AJ8 など）: −1
  ペアボード（77K など）           : +1（静的化でドライ寄せ）
```

判定しきい値：
- **BoardScore ≥ 7**：ドライ（小さめ CBet 33% で高頻度）
- **4〜6**：セミウェット（選択的 CBet 50〜75%）
- **≤ 3**：ウェット（基本チェック、超強ハンドのみ大きく CBet）

### 式2：HandScore（フロップでの手の強さ）

```
HandScore = 役スコア + ドロー加点 + ブロッカー

役スコア（確定した役）
  セット以上                 : 30
  オーバーペア                : 20
  トップペア・トップキッカー（TPTK）: 18
  トップペア・良キッカー（A/K/Q）  : 15
  トップペア・弱キッカー        : 10
  セカンドペア                : 8
  アンダーペア（ポケット）      : 6
  ボトムペア                 : 4
  ハイカードのみ              : 0

ドロー加点 = アウツ数 × 1.5（切り捨て、最大 +15 でキャップ）
  BDFD（3 outs 実効）              : +4
  ガットショット（4 outs）          : +6
  2オーバーカード（6 outs）          : +9
  OESD / ダブルガットショット（8）    : +12
  フラッシュドロー（9 outs）          : +13
  FD + ガットショット（12 outs）     : +15（キャップ）
  FD + OESD（15 outs モンスタードロー）: +15（キャップ）

ブロッカー
  ナッツブロッカー（A on 三枚スペードボード）: +3
  上位セットブロッカー              : +2
```

### 式3：CBet 判定の統合式

```
CBet スコア = HandScore + (BoardScore − 5) + ポジション係数

ポジション係数
  IP（ボタン、CO 側）: +3
  OOP（ブラインド側）: 0

判定
  ≥ 20 → CBet 75%（強ハンドで価値最大化）
  13〜19 → CBet 33%（軽いサイズで幅広く）
  7〜12 → チェック（後続ストリートで判断）
  < 7 → チェック・フォールド準備
```

## 各章の狙いと具体例

### 第I部　フロップの基礎

#### 第1章　フロップで EV の振れ幅が最大化する
- **狙い**：プリフロップで絞ったハンドがフロップで「化けるか死ぬか」決まる
- **具体例**：AKo が K 高ボードと 2-7-4 ボードで EV が激変
- **【GTOとのズレ】**：ストリート別 EV 寄与度の GTO 分析

#### 第2章　本書を読むための用語
- **狙い**：前作の用語に加えて、フロップ固有の概念を導入
- **具体例**：SPR、CBet、BDFD、モノトーン、ペアード、レンジアドバンテージ、ナッツアドバンテージ、後手下限

#### 第3章　プリフロップから受け継ぐレンジ
- **狙い**：前作の閾値を「相手推定ツール」として再利用
- **具体例**：
  - UTG オープンレンジ → 平均 HandScore 20（強め）
  - BTN オープンレンジ → 平均 HandScore 10（広め）
  - 3bet ポットでのレンジキャップ構造
  - 4bet ポットでのレンジ（QQ+、AK）
- **【GTOとのズレ】**：GTO Wizard の原則「プリフロップレンジ優先、ボードテクスチャはサブ」

#### 第4章　初級者がやりがちなフロップのミス（新設）
- **狙い**：読者の「あるある」を刺激して本書を自分ごと化
- **具体例**：
  - 弱いトップペアでオールイン
  - CBet の過剰適用（全フロップで CBet してしまう）
  - ウェットボードでの過度なベットサイズ
  - チェックレイズで降りられない
  - OOP でのドンクベット乱用
- **【GTOとのズレ】**：GTO 的にも明確な誤りとされるパターンのデータ

#### 第5章　ボードテクスチャを数値化する（BoardScore）
- **狙い**：式1を導入。ボードを 0〜10 で分類
- **具体例**：K72r=10、QJ9rr=3、AKQss=−1

#### 第6章　アウツとエクイティ（Rule of 2 and 4）
- **狙い**：ドロー加点の数学的裏付け
- **具体例**：OESD は 8 outs × 2 = 16%（1ストリート）、×4 = 32%（2ストリート）
- **拡張版**：アウツ×3 + 9（10 outs 以上での誤差補正）

### 第II部　CBet の判断

#### 第7章　CBet の3つの目的
- **具体例**：バリュー（セット）、ブラフ（空振りでレンジ有利）、プロテクション（TP）

#### 第8章　HandScore
- **具体例**：KQ on K72r → TPGK 15 / AT on 987ss → OESD+FD モンスタードロー 15

#### 第9章　CBet 統合式の全体像
- **具体例**：KQ on K72r IP → 15 + (10−5) + 3 = 23 → CBet 75%

#### 第10章　CBet サイズの選択
- **具体例**：ドライで 33%、ウェットで 75%、モンスターで 150% オーバーベット

#### 第11章　この式が GTO と外れるところ：CBet 編
- **具体論点**：Range CBet（高頻度小サイズ）の存在、レンジごとの細かい最適化

### 第III部　CBet を受ける側の判断

#### 第12章　ポットオッズと防衛感覚（後手下限 軽量化版）
- **狙い**：「過剰フォールドしない感覚」を、計算式なしに伝える
- **具体例**：33% ポットベットに対しては「3回に2回はコール／レイズ」と覚える
- 厳密な 後手下限確率 式は補足コラムに格下げ

#### 第13章　コール／フォールドの境界：実効エクイティ
- **具体例**：TP 弱キッカー vs 大きな CBet → フォールド
- OOP での実現率低下（0.6〜0.8）を再掲

#### 第14章　チェックレイズの簡易判定
- **具体例**：セットでのバリューレイズ、ナッツフラッシュドローでのセミブラフ

#### 第15章　ドンクベット対応（軽量化）
- **狙い**：「自分ではドンクしない」＋「打たれたときの対応」に限定
- **具体例**：ドンクベットはタイト相手の「フラッシュ完成」「セット」の可能性

#### 第16章　この式が GTO と外れるところ：対 CBet 編
- **具体論点**：混合戦略、レンジ全体でのディフェンス構築

### 第IV部　コンテクスト調整

#### 第17章　SPR による戦略の切り替え
- **具体例**：SPR 3 未満でコミット必至、SPR 6 超でポストフロップ機動力

#### 第18章　マルチウェイのフロップ
- **具体例**：CBet 頻度激減、ナッツ必要性上昇、プレイヤー増加時のベット絞り

#### 第19章　3ベットポット（低 SPR）―初級後半向け
- **狙い**：SRP マスター後に進む
- **具体例**：3bet ポットで SPR 約 4、CBet 頻度 70%+

#### 第20章　相手タイプとスタック深度によるしきい値調整
- **具体例**：タイト相手にはブラフ CBet 増、ルースにはバリュー CBet 増

### 第V部　応用と実戦定着

#### 第21章　相手のレンジを数式で動的に推定する
- **狙い**：本書の3式を相手側にも適用
- **具体例**：UTG が K72 フロップで CBet → 相手の HandScore 推定

#### 第22章　レンジアドバンテージとナッツアドバンテージの判定
- **具体例**：UTG vs BB on K72（UTG 有利）、vs on 987ss（BB 有利）

#### 第23章　20問ドリル
- **狙い**：3式の運用を身体化
- **具体例**：各問 BoardScore → HandScore → 統合 → アクション決定

### 第VI部　次への橋渡し

#### 第24章　1枚チートシート
- **具体例**：ボード別 CBet 頻度表、HandScore 早見、アウツ早見

#### 第25章　ターン・リバーへのブリッジ
- **狙い**：本書範囲外の予告
- **具体例**：Delayed CBet、Double Barrel の伏線、リバーの 2 分岐

#### 第26章　フロップから GTO へ：学習ロードマップ
- **具体例**：GTO Wizard のフロップ解析、PIOsolver 入門、次の3冊
