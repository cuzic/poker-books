# 『迷わないポーカー② フロップ[基礎]』執筆プロジェクト

## プロジェクト概要

書籍『迷わないポーカー② フロップ[基礎] ―秒で決まるボード判断―』の執筆を管理するディレクトリ。

## 本書の位置づけ

前作『迷わないポーカー① プリフロップ』の姉妹編。プリフロップ編の読者が「フロップでどう判断するか」に進むためのステップ。NL10〜NL200 程度のオンラインキャッシュで安定して勝率プラスを目指せる初級〜中級者向け。上級者向けの精密モデル（精密レンジスコア）、混合戦略 R1〜R6、ターン・リバーは姉妹編『迷わないポーカー③ フロップ[応用]』へ譲る。

## 本書のコア・ツールキット

実装上は「**3 階層の判断ツール**」で構成する。

### ツール 1：ボード 7 型分類（第 3〜4 章）

フロップを 7 つの型（型1〜型7）に分類し、型別のアクションプランで CBet/Check の方針を即決する。初級者の入門レイヤー。

### ツール 2：簡易レンジスコア チェックリスト（第 8 章）

```
4 ステップで CBet 頻度（%）を出力する暗算手順
ステップ1：トップカードの位置（A/K/Q vs J 以下）
ステップ2：スート構造（rainbow / 2-tone / monotone）
ステップ3：ペア有無 / ストレート密度
ステップ4：補正（ロートップ・連続3枚など）
```

- 出力：CBet 頻度の % を 0〜90% で算出
- 暗記すべき数字は 10 個だけ
- GTO ソルバー実測との R² ≈ 0.873、平均誤差 ±6.0%
- 詳細係数表は付録 D（精密レンジスコア完全係数表）で巻③へつなぐ

### ツール 3：HandScore（第 9 章）

```
HandScore = 役スコア + ドロー加点 + ブロッカー（0〜50）

役スコア:
  セット以上 30 / OP 20 / TPTK 18 / TP良キッカー 15
  TP弱キッカー 10 / セカンドペア 8 / アンダーペア 6 / BP 4 / 空振り 0

ドロー加点 = アウツ × 1.5（キャップ +15）:
  BDFD 3 outs +4 / ガットショット 4 outs +6 / 2オーバー 6 outs +9
  OESD 8 outs +12 / FD 9 outs +13 / モンスター 12+ outs +15

ブロッカー: +2 〜 +3
```

### ツール 4：9 マスマトリクス（第 10 章）

「簡易レンジスコア（CBet頻度帯）× HandScore（H3/H2/H1）」の 3×3 マトリクスで CBet 判定。

```
H3（HandScore ≥ 25）：強ハンド
H2（HandScore 13〜24）：中堅
H1（HandScore < 13）：弱・空振り
```

### ツール 5：先手スコア（第 10 章）と後手スコア（第 13 章）

```
先手スコア = HandScore + A
A（ボード値）: ドライ=3、セミ=2、ウェット=1
判定: ≥7 → ベット / <7 → チェック

後手スコア = HandScore + 防衛補正
コール / フォールド / レイズの 3 択を数値で判定（第 13 章）
```

## 執筆方針

- 文体：ですます調、1 文 150 字以内、読点 3 個以内
- 章標準構造：導入 → 本文 → 【GTOとのズレ】コラム → まとめ → ミニクイズ → 出典
- スコア値は GTO Wizard / poker-coaching の公開チャートと照合して微調整
- シリーズ表記：他巻参照は **「巻③」「巻④」**のように丸数字を使う
