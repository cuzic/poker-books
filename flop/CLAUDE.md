# 『フロップは構造で勝つ』執筆プロジェクト

## プロジェクト概要

書籍『フロップは構造で勝つ ―ボードを読み、式で判断する―』の執筆を管理するディレクトリ。

## 本書の位置づけ

前作『プリフロップは計算で勝つ』の姉妹編。プリフロップ編の読者が「フロップでどう判断するか」に進むためのステップ。

## 本書の3つの数式

### 式1：BoardScore（0〜10、ドライ度指標）

```
BoardScore = 10 − ストレート要素 − フラッシュ要素 − ハイボードリスク
```

- ストレート要素：連続3枚 −5、連続2枚＋ギャップ1以内 −3、1ギャップ −2
- フラッシュ要素：3枚同マーク −5、2枚同マーク −2
- ハイボードリスク：Broadway 2枚以上 −1、ペアボード +1

判定：
- ≥7 ドライ、4〜6 セミウェット、≤3 ウェット

### 式2：HandScore（手の強さ 0〜50）

```
HandScore = 役スコア + ドロー加点 + ブロッカー

役スコア:
  セット以上: 30、OP: 20、TPTK: 18、TP良キッカー: 15
  TP弱キッカー: 10、セカンドペア: 8、アンダーペア: 6、BP: 4、空振り: 0

ドロー加点 = アウツ数 × 1.5（キャップ +15）:
  BDFD 3 outs: +4
  ガットショット 4 outs: +6
  2オーバー 6 outs: +9
  OESD 8 outs: +12
  FD 9 outs: +13
  モンスタードロー 12+ outs: +15

ブロッカー: +2〜+3
```

### 式3：CBet 統合式

```
CBet スコア = HandScore + (BoardScore − 5) + ポジション係数

ポジション係数: IP +3、OOP 0

判定:
  ≥ 20 → CBet 75%
  13〜19 → CBet 33%
  7〜12 → チェック
  < 7 → チェック・フォールド準備
```

## 執筆方針

- 文体：ですます調、1文150字以内、読点3個以内
- 章標準構造：導入→本文→【GTOとのズレ】コラム→まとめ→ミニクイズ→出典
- 3式の数値は執筆過程で GTO Wizard 等のソルバーデータと照合して微調整

## ビルド

```bash
bash ../scripts/build.sh flop
```

## 執筆ワークフロー（前作から継承）

1. リサーチ並列化（章ごとに Researcher エージェント起動）
2. 章ごと執筆（Writer）
3. 全章レビュー（Reviewer、Devil's Advocate）
4. ファクトチェック（計算・エクイティ値・出典URL）
5. 境界ハンドの暗記リスト作成（付録F）
6. HTML ビルド・gistpreview 公開
