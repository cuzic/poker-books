# フロップ戦略の原案メモ（執筆中に追加する）

## 3つの数式（確定版）

### 式1：BoardScore

```
BoardScore = 10 − ストレート要素 − フラッシュ要素 − ハイボードリスク
```

- ストレート要素
  - 連続3枚（987、JT9）: −5
  - 連続2枚＋ギャップ1以内（KQ8、QJ9など）: −3
  - 1ギャップ（K-J、9-7）: −2
  - 完全バラバラ: 0
- フラッシュ要素
  - 3枚同マーク: −5
  - 2枚同マーク: −2
  - レインボー: 0
- ハイボードリスク
  - Broadway 2枚以上: −1
  - ペアボード: +1（ドライ化）

判定：
- ≥ 7：ドライ（CBet 33% 高頻度）
- 4〜6：セミウェット（選択的 CBet 50〜75%）
- ≤ 3：ウェット（基本チェック）

### 式2：HandScore

```
HandScore = 役スコア + ドロー加点 + ブロッカー
```

役スコア：
- セット以上: 30
- オーバーペア: 20
- TPTK: 18
- TP良キッカー（A/K/Q）: 15
- TP弱キッカー: 10
- セカンドペア: 8
- アンダーペア（ポケット）: 6
- ボトムペア: 4
- 空振り: 0

ドロー加点 = アウツ数 × 1.5（キャップ +15）：
- BDFD（3 outs 実効）: +4
- ガットショット（4）: +6
- ダブルガットショット（8）: +12
- OESD（8）: +12
- 2オーバーカード（6）: +9
- FD（9）: +13
- FD + ガットショット（12）: +15（キャップ）
- OESD + FD（15）: +15（キャップ）

ブロッカー：
- ナッツブロッカー（A on 3枚スペードボード等）: +3
- 上位セットブロッカー: +2

### 式3：CBet 統合式

```
CBet スコア = HandScore + (BoardScore − 5) + ポジション係数
```

ポジション係数：IP +3、OOP 0

判定：
- ≥ 20 → CBet 75%
- 13〜19 → CBet 33%
- 7〜12 → チェック（後続で判断）
- < 7 → チェック・フォールド準備

## 検証例（執筆途中）

### K♠ 7♦ 2♣（超ドライ）

BoardScore = 10 − 0 − 0 − 0 = **10**

自分 K♣Q♣：
- HandScore = TPクイーンキッカー = 15 + BDFD +4 = 19
- IP なら CBet = 19 + (10−5) + 3 = 27 → **CBet 75%**

自分 5♥4♥：
- HandScore = 空振り = 0
- IP なら CBet = 0 + 5 + 3 = 8 → **チェック**

### 9♥ 8♥ 7♦（ウェット）

BoardScore = 10 − 5 − 2 − 0 = **3**

自分 T♠J♠：
- HandScore = OESD = 0 + 12 = 12（アウツベース）
- IP なら CBet = 12 + (3−5) + 3 = 13 → **CBet 33%**

自分 A♥K♥：
- HandScore = 0（空振り）+ 2オーバー 9（6 outs × 1.5）= 9
- IP なら CBet = 9 + (3−5) + 3 = 10 → **チェック**
