# 進捗チェックリスト

各項目を生徒が理解・実行できるかを段階的に確認します。

## ステップ1：基本概念（第0章〜第2章）

- [ ] SPR を計算できる
- [ ] 後手下限確率 を 33%/50%/75%/100% ベットで答えられる
- [ ] ボードテクスチャ 3 分類（ドライ・セミウェット・ウェット）を区別できる
- [ ] ペア呼称（TP/2P/BP/OP/UP）を 3 種類のボードで識別できる

## ステップ2：BoardScore（第5章）

- [ ] ストレート要素 4 パターンを判定できる
- [ ] フラッシュ要素 3 パターンを判定できる
- [ ] ハイボード要素（Broadway 2枚以上 / ペアボード）を判定できる
- [ ] 代表 10 フロップの BoardScore を 10 秒以内に算出できる

## ステップ3：HandScore（第8章）

- [ ] 役スコア 6 段階（セット/OP/TPTK/TPGK/TPWK/セカンドペア等）を即答できる
- [ ] アウツ数 × 1.5 の計算（BDFD=+4、ガットショット=+6、OESD=+12 等）を即答できる
- [ ] フラッシュドローのアウツ数（9 アウツ）から +13 を計算できる
- [ ] 代表 10 ハンドの HandScore を 10 秒以内に算出できる

## ステップ4：CBet 統合式（第9章）

- [ ] 基本式 `Hand − Board + Pos` で代表 10 ハンドを判定できる
- [ ] 4 段階判定（75%/33%/チェック/フォールド準備）を区別できる
- [ ] ポジション係数（IP = +3、OOP = 0）を即答できる

## ステップ5：中級 R1〜R6（第27章）

- [ ] R1 の 3 バンド化（強バンド ≥ 17 / 混合ゾーン 13〜16 / 弱バンド 9〜12）を適用できる
- [ ] R2 のスート判定（♠♥ → アクション / ♣♦ → 受動）を機械的に実行できる
- [ ] R3 の RangeAdv 補正（ハイカード × レイザー = +2 等）をボード × 役割で判定できる
- [ ] R4 の NutsAdv からサイズ 2 択（75% or 33%）を選べる
- [ ] R5 のチェックレンジ保護（AA〜QQ の ♣♦ スートをチェック）を実行できる
- [ ] R6 の 後手下限ライン ±10% を相手タイプで調整できる

## ステップ6：上級 完全統合式（第28章）

- [ ] M 補正を人数別に適用できる（HU = 0 / 3-way = −3 / 4-way = −5）
- [ ] SPR 補正を 4 帯域で適用できる（≤3 = +2 / 3〜6 = 0 / 6〜15 = −1 / ≥15 = −3）
- [ ] E 補正（HUD 統計または観察ベース）を算出できる
- [ ] 3bP 補正を SRP / 3bet ポット / 4bet ポットで区別できる（0 / −2 / −4）
- [ ] 5 例題の完全統合式スコアを 2 分以内に計算できる

## ステップ7：実戦適用

- [ ] 1000 ハンドプレイで Level 1 を忠実に実行できた
- [ ] 500 ハンドプレイで Level 2 を忠実に実行できた
- [ ] 100 ハンドプレイで Level 3 を忠実に実行できた
- [ ] ソルバー（GTO Wizard）で自分のプレイを 10 スポット復習した
