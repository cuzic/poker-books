# Level 2 ワークシート（R1〜R6 適用）

<!-- markdownlint-disable MD036 MD040 MD056 MD060 -->
<!-- textlint-disable preset-ja-technical-writing/no-exclamation-question-mark -->
<!-- textlint-disable preset-ja-technical-writing/no-mix-dearu-desumasu -->

**指示**：各問題でまず基本 CBet スコアを計算し、R1〜R6 を適用して最終判断を出してください。

**R1 バンド定義（3バンド化）**

- 強バンド：スコア ≥ 17（CBet 確定）
- 混合ゾーン：スコア 13〜16（R2 でスート判定）
- 弱バンド：スコア 9〜12（CBet 33% か R2 で判断）
- チェックゾーン：スコア 2〜8
- フォールドゾーン：スコア < 2

**R2 スート判定**：混合ゾーンでは高いランクのカードのスートを見る。♠/♥ → アクション側（CBet）、♣/♦ → 受動側（チェックまたは小サイズ）

**R3 RangeAdv 補正**：ハイカード × レイザー = +2、ローカード × レイザー = −2、ハイカード × コーラー = −2、ローカード × コーラー = +2

**R4 サイズ**：NutsAdv あり（レイザー × ハイカード / コーラー × ローカード）→ 75%、それ以外 → 33%

## 問1

- ボード：K♠7♦2♣（BoardScore = 0）
- あなたのハンド：K♥5♦（TPWK：HandScore = 10）
- 役割：レイザー（BTN、IP）
- SPR：8

**計算欄**

- 基本 CBet スコア = ___
- R3 補正（ハイカード × レイザー）= ___
- 修正後スコア = ___
- R1 バンド = ___
- R2 判定（混合ゾーンの場合、K のスート = ♥ → ♠/♥）= ___
- R4 サイズ = ___
- 最終判定：___

**解答**：基本スコア = 10 − 0 + 3 = 13（混合ゾーン）。R3：ハイカード × レイザー = +2。修正後 = 15（混合ゾーン上限）。R2：K♥ → ♥ なので CBet 確定。R4：NutsAdv あり（レイザー × ハイカード）→ 75%。最終 → **CBet 75%**

- 役割：レイザー（BTN、IP）
- SPR：9

（フラッシュドロー：9アウツ × 1.5 = 13、上限 15 未満なのでそのまま適用）

**計算欄**

- 基本 CBet スコア = ___
- R3 補正 = ___
- 修正後スコア = ___
- R1 バンド = ___
- R4 サイズ = ___
- 最終判定：___

**解答**：基本スコア = 13 − 4 + 3 = 12（弱バンド）。R3：ハイカード × レイザー = +2。修正後 = 14（混合ゾーン）。R2：A♦ → ♦ なのでチェック側。→ **チェック**

（補足：FD は NutsAdv を高めるが、R2 でスートが ♣♦ のため受動的行動が推奨）

## 問7

- ボード：6♠5♥4♣（BoardScore = 5）
- あなたのハンド：A♠A♦（オーバーペア：HandScore = 20）
- 役割：レイザー（BTN、IP）
- SPR：8

R5 のチェックレンジ保護の観点から判断してください。

**計算欄**

- 基本 CBet スコア = ___
- R3 補正（ローカード × レイザー）= ___
- 修正後スコア = ___
- R5 考慮（AA、スートが ♠♦ → チェック候補）= ___
- 最終判定：___

**解答**：基本スコア = 20 − 5 + 3 = 18（強バンド）。R3：ローカード × レイザー = −2。修正後 = 16（混合ゾーン）。R5：AA でスートが ♠♦（♣♦ではない）→ CBet 継続。R2：A♠ → ♠ なので CBet 確定。R4：NutsAdv なし（レイザー × ローカード）→ 33%。最終 → **CBet 33%**

## 問9

- ボード：8♠7♦6♣（BoardScore = 5）
- あなたのハンド：T♥9♦（OESD：HandScore = 0 + 12 = 12）
- 役割：レイザー（BTN、IP）
- 相手：LAG（VPIP 30%、R6 で 後手下限ライン +10% 適用）
- SPR：9

R6：相手が LAG の場合 後手下限ライン +10%（相手がコールしやすい → CBet の価値が下がる → CBet 判断を慎重に）

**計算欄**

- 基本 CBet スコア = ___
- R3 補正（ローカード × レイザー）= ___
- R6 考慮（相手 LAG → 境界では CBet 控えめ）= ___
- 最終判定：___

**解答**：基本スコア = 12 − 5 + 3 = 10（弱バンド）。R3：ローカード × レイザー = −2。修正後 = 8（チェックゾーン境界）。R6：相手 LAG で境界スポット → CBet の回収期待値が下がる → **チェック**（または小サイズ 33% の選択肢も残す）
