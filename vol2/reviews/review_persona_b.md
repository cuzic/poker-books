# レビュー：ペルソナB（森 健一・GTO研究者）

## 総評（★1〜5）
★★★☆☆

GTO Wizardを日常使いする立場から言えば、「式の精度と限界の開示度」という点でギリギリ合格ライン。各章末の【GTOとのズレ】コラムは誠実さの点で評価できる。しかしHandScoreの導出根拠、DrawBonusの「+5ナッツボーナス」、フォールド閾値テーブルとMDFの対応付けなど、数値の裏付けが不十分な箇所が複数あり、GTOを知っている読者ほど「どこから来た数字か？」と手が止まる。式同士の整合性にも軽微なズレがある。上級者への導線は一部あるが、「この先どう精度を上げるか」の具体的方法論が弱い。

---

## 良かった点（3〜5点）

- **【GTOとのズレ】コラムの誠実さ**: 全章にコラムが配置されており、「H3の100%CBetは簡易化」「ターンディフェンスの15〜20%はGTO最善手と異なる」など、ズレの大きさを具体的なパーセンテージで開示しているものが多い。逃げていない姿勢を評価する。
- **バレルスコアの導出根拠の明示**: 第7章でTexasSolverの395ボードを用いたGTOデータ解析から閾値7を導出した旨を明記している。実測値に基づいた説明として信頼性がある。
- **α式・V:B比率の数学的整合性**: 第9章のα = ベット÷(ポット+ベット)、V:B=(1-α):αの導出は数学的に正確であり、GTO均衡理論の本質を正しく表現している。
- **SPR別コミット閾値の概念**: 第4章・第6章でSPRに応じて判断基準が変わることを整理した点は、実践的なGTO思考と整合している。

## 改善すべき点（優先度順）

### ★★★ 必須修正（式・数値の誤り・論理破綻）

**[ch01 / DrawBonus] NFDの「+5ナッツボーナス」の根拠が不透明**

- 問題箇所: 第1章 §1-3「NFDのDrawBonusが9×4+5=41となる理由はナッツボーナス（+5）にある…GTO分析から実測した結果、+5点が妥当という結論」
- 問題: GTO Wizardで確認すると、NFDとノンナッツFDのエクイティ差はボードによって2〜8%程度幅がある。「+5で妥当」という根拠となるGTOデータや計算過程が一切示されていない。「GTO分析から実測」という表現は読者を誤解させる可能性がある。
- 改善案: 具体的なボードと実測エクイティ値を1〜2例提示するか、「近似値として±3の誤差がある」と限界を明示する。

**[ch06 / フォールド閾値] HS閾値とMDFの対応関係の論理が不完全**

- 問題箇所: 第6章 §6-2「HS閾値は『MDFに基づいてコールできる下位レンジの境界』をGTOデータから逆算したもの」「OOPはHS15以上の手を保有するレンジを全体の約75%持っているよう設計」
- 問題: HS=15という境界値が「SRPでIPが33%CBetするボードでのOOPレンジ構成の約75%パーセンタイル」であることが主張されているが、その根拠となるレンジ構成データが示されていない。さらにボードタイプによってOOPコールレンジの分布は大きく異なるため、単一の閾値15では精度が大幅に落ちる。型1ドライと型4ローウェットでは閾値が実質的に変わるはずだが、本書では型依存の補正がない（テクスチャ補正はあるが、基本閾値自体がボード型非依存）。
- 改善案: 「閾値はボード型によって5〜10ポイント変動するが、簡易化のため平均値を採用している」という注記を追加し、型1と型4の閾値の実態差を例示する。

**[ch06/appendix / MDF計算の矛盾] フォールド閾値表とリバーコール表の非対称**

- 問題箇所: §6-2フォールド閾値（33%→HS<15でフォールド）と §A-8後手フォールド閾値（33%→HS≥45でコール）
- 問題: フロップでは「HS<15でフォールド」（=HS≥15でコール）なのに、リバーでは「HS≥45でコール」と大きくかけ離れている。DrawBonus=0のリバーでHS15のハンドは役なし相当であり、フロップでHS15=コール可というフロップ側の閾値が低すぎるのか、リバー側が高すぎるのかが読者には判断できない。【GTOとのズレ】コラムで部分的に言及されているが、同書内でのHS値の意味の不統一として明示的に整理すべき問題。
- 改善案: 「フロップのHS≥15はDrawBonusによってHSが膨張しているため、DrawBonus込みで15以上なら実質エクイティ15%弱以上を意味する。リバーのHS≥45はDrawBonus=0の純粋エクイティ45%以上を意味する。同じHSの数字でも意味が異なる」という説明を §6-2またはチートシートに追記する。

**[ch10 / リバー後手コール表] 数値の内部矛盾**

- 問題箇所: §10-2「33%（α=25%）→HS≥45が目安」
- 問題: α=25%は「コール必要最低エクイティ25%」を意味する。リバーでHS≈エクイティ%であるなら、コール最低ラインはHS≥25のはず。なぜHS≥45に設定されているか説明がない。チートシートA-8も「33%→HS≥45」となっており、αの理論値（25%）と15ポイント乖離している。
- 推定原因: 実戦では相手がブラフのみでなくバリューも混ぜているため、ポットオッズだけではなく勝率も考慮した実効コール基準を採用した可能性があるが、その説明が一切ない。
- 改善案: 「α=25%はブラフに対するコール基準であり、実際は相手レンジにバリューが混在するため実効コール基準はHS≥45に引き上げている」という説明を明示する。または理論と実践値の乖離を【GTOとのズレ】で整理する。

### ★★ 推奨修正（精度・誠実さ・過剰単純化）

**[ch01 / ボード7分類] 分類境界の曖昧さ**

- 問題箇所: §1-1 判定基準表「型1: top≥Q かつ rainbow かつ spread>3」
- 問題: J♠7♦2♣はtop=J（Q未満）でありspreadi=5（>3）でrainbowだが、「セミドライ」なのか「ロードライ」なのか。本分類では型3「ロードライ: top<Q かつ rainbow かつ spread>3」に該当するが、バレルスコア表では「セミドライ（top<Q rainbow）」という別名が使われている。同一概念に2つの名前が存在して混乱を招く。
- 改善案: バレルスコアの「セミドライ」と型3ロードライが同じものであることを明示的にリンクする一文を両章に追加する。

**[ch03 / OOPコラム] 「1〜3%の損失」の根拠が不明**

- 問題箇所: §GTOとのズレ「これらのズレが期待値にして1〜3%の損失であり…」
- 問題: OOPが100%の頻度でH3を毎回CBetする場合のEV差が1〜3%であるという数字の根拠が示されていない。第4章コラムにも「33%レンジベットと比較すると1〜2%程度低下」とあるが、同様に根拠不明。GTOソルバーで実測したのか、理論的に推定したのかが不透明。
- 改善案: 「特定ボード（K72r等）でのTexasSolver実測値」と明記するか、「概算」という但し書きを追加する。

**[ch05 / マルチウェイヒット確率] 数値の根拠が不透明**

- 問題箇所: §5-1 表「HU（2人）: 約30〜35%、3ウェイ: 約50〜55%、4ウェイ: 約60〜70%」（注記あり）
- 問題: 注記に「H3相当（HS≥65）として推定した概算値」とある点は評価できるが、推定の根拠となった計算式や前提（レンジ幅、ボードテクスチャなど）が示されていない。GTO Wizardで典型ボードの実測をすれば検証可能だが、読者が独自に検証できる情報が不足している。
- 改善案: 「BTNオープン2.5bb、全員コールという前提でのモデル値」などの前提条件を明示する。

**[ch07 / バレルスコア係数] FlopType係数の設定根拠がやや薄い**

- 問題箇所: §7-2「FlopType係数は相手がフロップでどれだけコネクトしやすいかの逆数を表している。ドライボード…係数を+8と最大に設定」
- 問題: 係数の間隔（8/6/4/3）が均等でなく、なぜ8-6-4-3という特定の値なのかが説明されていない。バレルスコアの閾値7との対応からある程度推測できるが、係数の設計思想の説明が不足している。
- 改善案: 「閾値7を下回るボード×ターンカードの組み合わせがGTO的にチェック最適となるように係数を設計した」という設計思想の一文を追記する。

**[ch08 / ターンディフェンス] H2のフロー閾値の根拠**

- 問題箇所: §8-3「H2のターンディフェンス判断フロー: SPR≥6→HS≥50でコール、SPR3〜5→HS≥55、SPR<3→HS≥60」
- 問題: SPRによって閾値が5ずつ上がる理由が説明されていない。「コールするとポット比率が急増する」という定性的説明はあるが、HS50→55→60という5点刻みの設定根拠がない。
- 改善案: 「SPRが下がるとリバーコミット圧力が高まるため、ターンコールの実効コストが増加する。具体的にはSPR3〜5環境でのターンコール後リバーポットは…」という計算例を追加する。

### ★ 軽微（表記・整合性・構成）

**[ch01/ch07] 「ドライ」定義の不統一**

- ch01のボード型定義では「型1=top≥Q かつ rainbow かつ spread>3」「型3=top<Q かつ rainbow かつ spread>3」を別型として扱う。
- ch07バレルスコア表では「ドライ（top≥Q rainbow）+8」「セミドライ（top<Q rainbow）+6」として区別。
- 同じ4パターン分類でも対応が暗黙的で、初見の読者には混乱を招く可能性がある。チートシートA-6にも両方の用語が混在している。

**[ch03 / 例題 問3] 解答の説明が矛盾気味**

- 問題箇所: §3-9 問3の解答「型4 × H3 → チェック（チェックレイズ狙い）。型4のOOPルールではH3のみ33%CBetが可能なルールです。ただし…チェックレイズの方が期待値が高い」
- 問題: 「33%CBetが可能」と言いながら「チェックを選んで誘う方針を推奨」という二段構えの解説で、初読では「結局どちらが正しいのか」が分かりにくい。
- 改善案: 「ルール上は33%CBet可能だが、このボード特性からチェックレイズ待ちを推奨」という順序で明確に整理する。

**[ch09 / コンボ計算例] ツーペアのコンボ数が不正確**

- 問題箇所: §9-2「ツーペア（例：AKでA-K-xボード）：AK×AKの組み合わせ」→§9-6-2「バリューコンボ（TS以上）：AKo=12コンボ + セット（AA/KK/77）≈9コンボ = 約21コンボ」
- 問題: AKoは4×3=12コンボ（一般的にAKoはオフスート12コンボ）。しかしAKsは4コンボ追加で合計16コンボになるはず。なぜAKsが除外されているのか（またはツーペアにならないのか）説明がない。A-K-7-2-9ボードでAKsはAKoと同様にツーペアを形成するため、ブロッカーとして除外する理由があれば明示が必要。
- 改善案: 「AKs（4コンボ）も含め合計16コンボ、または前のストリートのアクション履歴から一部スーテッドが除外されている場合は…」という補足を追加する。

**[付録A-4 / CBet早見表] ch02の決定表との不整合**

- 問題箇所: 付録A-4表「ドライ（型1・型3）→Vバケット（H3）→33%」「ウェット（型2・型4）→Vバケット→50〜75%」
- 問題: ch02の決定表ではSRP型1H3は75%となっているが、A-4では「ドライ→33%」となっており、2章の記述と矛盾する。付録がまとめとして使えない。
- 改善案: 付録を章の内容と一致させる。「IP/OOPで異なる」ことを付録内で明記するか、IP用とOOP用で表を分けて掲載する。

## ペルソナからの一言

「各章末の【GTOとのズレ】コラムを書いてくれたことは正直に評価します。『式で嘘をついている箇所はどこか』を確認しながら読んでいましたが、コラムが自分でそれを先回りして指摘している構成はGTO研究者にとっては誠実に映ります。

ただし一番引っかかったのはHandScoreの数値体系の内部矛盾です。フロップのHS閾値15とリバーのHS閾値45が『同じHS値』として混在しているのに説明が薄い。DrawBonusで膨らんだHSと、DrawBonus=0のリバーHSを同じ軸で管理しているため、読者が混乱するのは当然です。

もし続巻やVol3以降を出すなら、『DrawBonusあり（フロップ/ターン）のHSと、DrawBonus=0（リバー）のHSを別の名前で呼ぶか、対応関係を図示する』だけでかなり整理されると思います。あと、NFDの+5という数値は、もし実測値であれば具体的なボード名と計測値を1行でいいので載せてほしいです。GTO Wizardで即検証できる数字が一つあるだけで、このシリーズへの信頼度が大きく上がります。」
