# 付録　計算式早見表

本付録は全10章の核心公式を1ページにまとめた横断参照表です。
実戦中に迷ったときは、まずこの表で該当する式を確認してください。
各節に「使い方のポイント」を添えてあります。

---

## A-1　統一スコア式（プリフロップ）

**Score = (base × 1.2 + suited補正) − gap ペナルティ**

| 要素 | 計算方法 |
|---|---|
| base | ペア：ランク値 × 2　　非ペア：高カードランク + 低カードランク |
| ×1.2 | base に 1.2 を掛ける（端数切り捨て） |
| suited補正 | スーテッド：+6　　オフスーテッド：+0 |
| gap ペナルティ | gap=1：−2、gap=2：−4、gap=3以上：−5 |

**例：A♠K♦（AKo）**　base = 14+13 = 27、×1.2 = 32、gap=0 → Score = 32

**例：J♥9♥（J9s）**　base = 11+9 = 20、×1.2 = 24、suited+6 = 30、gap=1（−2）→ Score = 28

**使い方のポイント：** Scoreがポジション別T_openを上回ればオープン（第2章参照）。スーテッドボーナス+6の効果は大きく、例えばJToがScore 26でも、J♠T♠ならScore 32になり、T_open(BTN)=18を大きく超えます。

---

## A-2　T_open（ポジション別オープン閾値）

| ポジション | T_open | 目安RFI% |
|---|---|---|
| UTG | 24 | 約20% |
| HJ | 22 | 約25% |
| CO | 20 | 約30% |
| BTN | 18 | 約40% |
| SB | 22 | 約25%（OOP補正） |

**SBはOOP補正でBTNより厳しい**。BB vs オープン時はScore_BB = Score + suitedボーナス + 差補正を計算して判断します。
Score_BB ≥ T_3bet で3ベット候補。T_3bet のポジション別値は BTN vs UTG ≈ 32 などが基準です。

**使い方のポイント：** ポジションが後ろになるほどT_openが下がり、広いレンジでオープンできます。BTNではScore 18以上の大部分のハンドがオープン対象になりますが、UTGではScore 24以上の比較的プレミアムなハンドに絞ります。

## A-3　HandScore式

**HS = R（役スコア） + D（DrawBonus）**

**HS ≈ エクイティ%（リバー、D=0）**

| バケット | HandScore範囲 | 典型ハンド例 | 先手方針 |
|---|---|---|---|
| H3（強） | 65 以上 | セット、2ペア、TPTK以上、ナッツドロー | 積極ベット |
| H2（中） | 35〜64 | ミドルペア、弱トップペア、セカンドペア＋ドロー | 状況依存 |
| H1（弱） | 34 以下 | 空振り、弱ドロー、アンダーペア（弱） | チェック/ブラフ候補 |

### 役スコア（R）の主要値

| 役 | 代表例 | 役スコア（R） |
|---|---|---|
| ナッツフラッシュ（完成）| A♠K♠ / K♠7♠2♠ | 95 |
| トップセット | KK / K♠7♦2♣ | 88〜90 |
| セカンドセット | 77 / K♠7♦2♣ | 85 |
| ツーペア（TPTK×TP2） | K♥7♦ / K♠7♦2♣ | 75 |
| TPTK | K♥Q♦ / K♠7♦2♣ | 66 |
| TPmidキッカー | K♥9♦ / K♠7♦2♣ | 58〜62 |
| TP弱キッカー | K♥5♦ / K♠7♦2♣ | 50〜55 |
| オーバーペア（AA） | A♥A♦ / K♠7♦2♣ | 78 |
| ミドルペア | 9♥9♦ / K♠7♦2♣ | 40〜46 |
| ボトムペア | 2♥2♦ / K♠7♦2♣ | 28〜34 |

### DrawBonus（D）の主要値

| ドロー | アウツ | フロップD | ターンD |
|---|---|---|---|
| ナッツFD（NFD） | 9 | +41（9×4+5） | +23（9×2+5） |
| フラッシュドロー | 9 | +36（9×4） | +21（9×2） |
| OESD | 8 | +32（8×4） | +16（8×2） |
| FD + OESD | ≈15 | +52（複合） | +26 |
| ガットショット | 4 | +16（4×4） | +8（4×2） |
| バックドアFD | − | +5 | − |

**使い方のポイント：** HS計算は「役スコア（R）+ DrawBonus（D）」の単純加算です。フロップでOESD（R=0）+FD（R=0）のコンボドローを持った場合、D=+52でHS=52、H2中位に相当します。

## A-4　フロップCBetサイズ × バケット早見表

| ボード型 | Vバケット（H3, HS≥65） | Mバケット（H2, HS35〜64） | Bバケット（H1, HS≤34） |
|---|---|---|---|
| ドライ（型1・型3） | 33% | 33%またはチェック | チェック |
| ウェット（型2・型4） | 50〜75% | チェック推奨 | チェック |
| モノトーン（型5） | 50% | チェック推奨 | チェック |
| ペア高（型6） | 33% | チェック推奨 | チェック |
| ペア低（型7） | 33% | 33%またはチェック | チェック |

ウェットボードでMバケットがチェックを選ぶ理由は、ドローが多い場面でベットしてもコールレンジが強くなりやすいためです。
ウェットボードでのMバケットCBetは「逆選択」が起きやすく、H3のみベットする戦略が期待値を守ります。

## A-5　フォールド閾値テーブル（フロップディフェンス）

| ベットサイズ | MDF | HS閾値（SRP）| HS閾値（3BP）| HS閾値（4BP）|
|:---:|:---:|:---:|:---:|:---:|
| 33% | 75% | HS<15 → FOLD | HS<20 → FOLD | HS<25 → FOLD |
| 50% | 67% | HS<25 → FOLD | HS<30 → FOLD | HS<40 → FOLD |
| 75% | 57% | HS<35 → FOLD | HS<40 → FOLD | HS<50 → FOLD |

**ボードテクスチャ補正：** 2トーン+5 / モノトーン−5 / ペアボード−10

**使い方のポイント：** まず「SRP・3BP・4BP」でベース閾値を確認し、ボードテクスチャ補正を加減算します。例えばSRP・50%ベット・2トーンボードなら閾値は25+5=30になります。

## A-6　バレルスコア式（ターン継続判断）

**BarrelScore = FlopType係数 + TurnCard係数**

### FlopType係数

| FlopType | 係数 | 代表例 |
|---|---|---|
| ドライ（top≥Q rainbow） | +8 | K♠7♦2♣ |
| セミドライ（top<Q rainbow） | +6 | J♦7♠5♣ |
| スーテッド/2-tone | +4 | Q♠8♦3♠ |
| コネクテッド | +3 | T♠9♠8♦ |

### TurnCard係数

| TurnCard | 係数 | 理由 |
|---|---|---|
| ペアカード（ボードと同ランク） | +4 | 相手レンジを改善しない |
| オーバーカード（ボードトップ超え） | +3 | 相手コールレンジを弱化 |
| ブランク（中間ランク・役立たず） | +2 | 変化なし |
| フラッシュカード | +1 | FD保有者が強化されるリスク |
| コネクター（ストレート系） | +0 | ドロー完成リスク最大 |

### 判断基準

| バレルスコア | 全レンジCBet | サイズ |
|---|---|---|
| ≥7 | ○ | 33%（均一）|
| <7 | ✗ | チェック（H3のみCBet検討）|

**使い方のポイント：** フロップが決まった時点でFlopType係数を確定させ、ターンカードを見た瞬間にTurnCard係数を加算します。例えばK♠7♦2♣（+8）にブランクターン（+2）が落ちたら10です。即座に「全レンジ33%バレル」と判断できます。

## A-7　α式とV:B比率（リバーバリュー:ブラフ管理）

**α = ベット ÷（ポット + ベット）**

| ベットサイズ | α | 最適V:B | ブラフ上限の計算 |
|---|---|---|---|
| 33% | 25% | 3:1 | バリューコンボ ÷ 3 |
| 50% | 33% | 2:1 | バリューコンボ ÷ 2 |
| 75% | 43% | 4:3 | バリューコンボ × 3 ÷ 4 |
| 100% | 50% | 1:1 | バリューコンボ × 1 |

**手順：**
1. バリューコンボ数を数える（ツーペア以上 = 何コンボ？）
2. V:Bでブラフ上限を計算
3. ブロッカー持ち・空振りドローをブラフ枠に投入

**使い方のポイント：** バリューコンボが多い場合は33〜50%の小サイズで広くコールを集め、バリューコンボが少ない場合は75〜100%の大サイズでブラフ枠を増やします。ブラフは「ショーダウン価値ゼロ → ナッツブロッカーあり → ストレートブロッカーあり」の順に優先します。

---

## A-8　後手フォールド閾値（リバーディフェンス）

| 相手ベットサイズ | コール最低HS | ウェット補正後 |
|---|---|---|
| 33%（α=25%）| HS≥45 | HS≥50 |
| 50%（α=33%）| HS≥50 | HS≥55 |
| 75%（α=43%）| HS≥60 | 補正なし |
| 100%（α=50%）| HS≥65 | 補正なし |

リバーではDrawBonus=0のためHS ≈ エクイティ%です。
表の数値はエクイティ%の目安として直読できます。
ウェットボードでは相手のバリューレンジが広くなるため、コール閾値を約5ポイント引き上げて対応してください。

**使い方のポイント：** HS65以上（H3）は全てのサイズにコール可能です。HS45〜64（H2）はベットサイズ次第でコール/フォールドが変わります。HS44以下（H1）は33%ベットのみコール検討で、それ以上のサイズは基本フォールドです。

## A-10　フローチャート概略（全ストリート）

```
プリフロップ
 └─ Score ≥ T_open → オープン（ポジション別）
 └─ Score_BB ≥ T_3bet → 3ベット候補

フロップ（先手）
 └─ H3(HS≥65) → CBet（ボード型でサイズ決定）
 └─ H2(HS35-64) → ボード型で判断（ドライ→33%、ウェット→チェック）
 └─ H1(HS≤34) → チェック（ブラフ条件あればベット）

フロップ（後手）
 └─ HS ≥ フォールド閾値（SPR・サイズ・ボード補正後）→ コール/CR
 └─ HS < 閾値 → フォールド

ターン（先手）
 └─ BarrelScore = FlopType係数 + TurnCard係数
 └─ ≥7 → 全レンジ33%バレル
 └─ <7 → チェック（H3のみCBet検討）

ターン（後手）
 └─ H3(HS≥65) → コール/場合によってCR
 └─ H2(HS35-64) → SPR依存（SRP:HS≥50 / 3BP:HS≥55 / 4BP:HS≥60）
 └─ H1(HS≤34) → フォールド

リバー（先手）
 └─ V(HS≥70) → ベット（サイズはバリューコンボ数で調整）
 └─ M上位(HS55-69) → ドライ→33%ベット / ウェット→チェックバック
 └─ M下位(HS35-54) → チェックバック（逆選択回避）
 └─ B(HS≤34) → ブラフ条件確認（V:B上限・ブロッカー・ストーリー）→ ベット or チェック

リバー（後手）
 └─ HS ≥ α相当値（ベットサイズ別） → コール/CR
 └─ HS < α相当値 → フォールド
```

## A-11　係数まとめ（暗記用）

| 係数 | 内容 | 値 |
|---|---|---|
| FlopType（バレルスコア） | ドライ/セミ/スーテッド/コネクテッド | 8/6/4/3 |
| TurnCard（バレルスコア） | ペア/OC/ブランク/フラッシュ/コネクター | 4/3/2/1/0 |
| α（ブラフ損益分岐） | 33%/50%/75%/100%ベット | 25%/33%/43%/50% |
| V:B（最適比率） | 33%/50%/75%/100%ベット | 3:1/2:1/4:3/1:1 |
| MDF（後手下限頻度） | 33%/50%/75%/100%ベット | 75%/67%/57%/50% |

**FlopType係数の暗記：** ドライほど高い。「8-6-4-3」とそのまま暗記。
**TurnCard係数の暗記：** ペアが4（最高）、コネクターが0（最低）。「4-3-2-1-0」。
**α の暗記：** 33%→25%、50%→33%（切り上げ）、75%→43%、100%→50%。
