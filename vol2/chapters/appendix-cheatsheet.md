# 付録　計算式早見表

本付録は全10章の核心公式を1ページにまとめた横断参照表です。実戦中に迷ったときは、まずこの表で該当する式を確認してください。

---

## A-1　統一スコア式（プリフロップ）

**Score = (base × 1.2 + suited補正) − gap ペナルティ**

| 要素 | 計算方法 |
|---|---|
| base | ペア：ランク値 × 2　　非ペア：高カードランク + 低カードランク |
| ×1.2 | base に 1.2 を掛ける（端数切り捨て） |
| suited補正 | スーテッド：+6　　オフスーテッド：+0 |
| gap ペナルティ | gap=1：−2、gap=2：−4、gap=3以上：−5 |

**例：A♠K♦（AKo）**　base = 14+13 = 27、×1.2 = 32、gap=0なのでペナルティなし → Score = 32

**例：J♥9♥（JTs相当）**　base = 11+9 = 20、×1.2 = 24、suited+6 = 30、gap=1（−2）→ Score = 28

---

## A-2　T_open（ポジション別オープン閾値）

| ポジション | T_open |
|---|---|
| UTG | 24 |
| HJ | 22 |
| CO | 20 |
| BTN | 18 |
| SB | 22 |

**SBはOOP補正でBTNより厳しい。** BB vs オープン時はScore_BB = Score + suitedボーナス + 差補正を計算して判断。Score_BB≥T_3bet で3ベット候補。

---

## A-3　HandScore式

**HS = R + DrawBonus（フロップ・ターン）**

**HS ≈ エクイティ%（リバー、DrawBonus=0）**

| 分類 | HandScore | 意味 |
|---|---|---|
| H3（強） | ≥65 | バリューベット・コールレイズ |
| H2（中） | 35〜64 | 状況依存（ミックス判断） |
| H1（弱） | ≤34 | チェック・フォールド・ブラフ候補 |

R（相対強度スコア）の目安：ナッツ=100、トップセット=90、ツーペア=75、TPTK=65、TP弱キッカー=55、中ペア=40、底ペア=25。

## A-4　CBetサイズ × バケット早見表

| ボード型 | Vバケット（H3） | Mバケット（H2） | Bバケット（H1） |
|---|---|---|---|
| ドライ（型1・型3） | 33% | 33%またはチェック | チェック |
| ウェット（型2・型4） | 50〜75% | チェック推奨 | チェック |
| モノトーン | 50% | チェック推奨 | チェック |
| ペア板 | 33% | チェック推奨 | チェック |

ウェットボードでMバケットがチェックを選ぶ理由は、ドローが多い場面でベットしてもコールレンジが強くなりやすいためです。

---

## A-5　バレルスコア式（ターン継続判断）

**BarrelScore = T + F + E**

| 項目 | 内容 | 加点 |
|---|---|---|
| T（テクスチャー） | ターンカードが自レンジに有利 | +2〜+4 |
| F（フラッシュ/ストレートドロー） | ドロー継続でナッツが増える | +1〜+3 |
| E（エクイティ） | 自ハンドのエクイティ≥50% | +1〜+3 |

**閾値：BarrelScore ≥ 7 → バレルベット推奨**

BarrelScore < 7 の場合はチェックまたはギブアップを優先してください。

---

## A-6　α式とV:B比率

**α = ベット ÷（ポット + ベット）**

| ベットサイズ | α | 最適V:B | ブラフ上限の計算 |
|---|---|---|---|
| 33% | 25% | 3:1 | バリューコンボ ÷ 3 |
| 50% | 33% | 2:1 | バリューコンボ ÷ 2 |
| 75% | 43% | 4:3 | バリューコンボ × 3 ÷ 4 |
| 100% | 50% | 1:1 | バリューコンボ × 1 |

**手順：** バリューコンボ数を数える → V:Bでブラフ上限を計算 → 上限コンボ分だけブロッカー持ちや空振りドローをブラフに投入。

---

## A-7　後手フォールド閾値（ベットサイズ別）

| 相手ベットサイズ | コール最低HS | ボードがウェット時の補正 |
|---|---|---|
| 33%（α=25%） | HS≥45 | +5（HS≥50に引き上げ） |
| 50%（α=33%） | HS≥50 | +5（HS≥55に引き上げ） |
| 75%（α=43%） | HS≥60 | 補正なし |
| 100%（α=50%） | HS≥65 | 補正なし |

リバーではDrawBonus=0のためHS ≈ エクイティ%です。表の数値はエクイティ%の目安として直読できます。ウェットボードでは相手のバリューレンジが広くなるため、コール閾値を約5ポイント引き上げて対応してください。

---

## A-8　フローチャート概略（全ストリート）

```
プリフロップ
 └─ Score ≥ T_open → オープン
 └─ Score_BB ≥ T_3bet → 3ベット

フロップ
 └─ H3(HS≥65) → CBet
 └─ H2(HS35-64) → ボード型で判断
 └─ H1(HS≤34) → チェック / ブラフ候補

ターン
 └─ BarrelScore ≥ 7 → バレル継続
 └─ BarrelScore < 7 → チェック or ギブアップ

リバー（先手）
 └─ V(HS≥70) → ベット
 └─ M(HS35-69) → チェックバック推奨（IP）
 └─ B(HS≤34) → ブラフ条件確認 → ベット or チェック

リバー（後手）
 └─ HS ≥ コール閾値 → コール
 └─ HS < コール閾値 → フォールド
```
