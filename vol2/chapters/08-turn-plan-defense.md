# 第8章　ターンレンジ計画とディフェンス

ターンでの判断ミスは「今この瞬間だけを考えてしまう」ことから生まれます。

**具体例で考えましょう。** あなたはターンでQ♥Q♦を持っており、ボードはK♠7♣2♦-3♥（ドライ）です。リバーで何をしたいかを先に考えます——相手のレンジにKxが多く自分は2番手なら、リバーはチェックダウンでショーダウン勝ちを狙いたい。そのためにはターンをチェックバックして無駄にポットを膨らませないことが最善です。これが**リバーから逆算する**ということです。

正しいアプローチはリバーで何をしたいかを先に決めてから、ターンで取るべき行動を選ぶことです。
フロップまでのアクション履歴によって自分と相手のレンジが大きく絞られているため、ターン時点のレンジを正確に把握することが逆算の出発点となります。

ターンは「アクション情報が積み重なって初めてわかる」ストリートです。
フロップのCBet・コール・チェックバックという3種類のアクションそれぞれが、双方のレンジを大きく絞り込みます。
その情報を使ってリバー計画を立てることが、ターンを「瞬間の判断」から「連続戦略の一部」に変えます。

## 8-1　レンジ逆算フレームワーク

| ステップ | 内容 |
|---|---|
| 1. フロップ文脈確認 | プリフロップレンジ × フロップアクション → 現在レンジを絞る |
| 2. ナッツアドバンテージ再評価 | ターンカード後に優位がどちらにあるか |
| 3. リバー計画 | ブラフ/バリューの比率（α式）を見越して行動 |

ステップ1では、フロップアクションを元に「どのハンドが残っているか」を整理します。
フロップCBetにコールした相手はエアーの弱いハンドの多くを脱落させており、ターン開始時のOOPレンジはHS35以上のマージナル以上が主体になります。

ステップ2では、ターンカードが双方のナッツアドバンテージをどう変えたかを評価します。
オーバーカードターンはIPレンジにとっては通常プラスですが（AKやAQを多く含むため）、OOPレンジがKxを多く保有している場合は逆転することもあります。

ステップ3では、リバーで何をするかを先に決めます。
「リバーでバリューベットしたい」なら今ターンでポットを大きくしてリバーのベットサイズを準備します。
「リバーで安全にショーダウンしたい」ならターンはチェックかスモールベットでポット管理します。

### フロップアクション別レンジ推定（目安）

| フロップ展開 | ターン開始時の IP レンジ | OOP レンジ |
|---|---|---|
| IP CBet → OOP コール | マージナル以上（バリュー中心） | マージナル以上（HS≥35） |
| IP チェックバック | SDV中心（HS 35〜55） | 全レンジ残存 |
| IP CBet → OOP チェックレイズ | バリュー 必要 | バリュー のみ |
| IP CBet → OOP フォールド | マージナル以上（バリュー中心） | （降りた） |

「IP CBet → OOP コール」後のターンは、IPがバレルを打ちやすいように見えますが実際には難しい局面です。
OOPがフロップCBetに対してコールを選んだということは、弱いエアーハンドはすでに脱落しており、残存レンジはHS35以上のマージナル以上が中心になります。
相手のレンジが絞られて強くなっているため、ターンでのバレル成功率はフロップCBet時と比べて低下しており、第7章のバレルスコアで閾値7以上を満たすボードに限って継続することが重要です。

フロップでIPがチェックバックを選んだ場合、IPの残存レンジはSDV（HS35〜55）中心であることが相手にも推測されます。
SDV中心のレンジは完成ハンドの比率が高くナッツが少ないため、相手はターンで積極的なベットやレイズによって降ろしにくる攻撃的戦略を取ることが利益的になります。
この搾取に備えるには、チェックバックを選ぶ時点でリバーまでのSDV戦略を意識しておくことが求められます。

## 8-2　ナッツアドバンテージとターンカード

ターンカードの種類によって、どちらのレンジが強化されるかが変わります。
この「相対的なナッツアドバンテージの変化」が、ターンの攻守判断に直結します。

### ターンカード別のナッツアドバンテージ変化

| ターンカード | IPへの影響 | OOPへの影響 | バレル判断への示唆 |
|---|---|---|---|
| オーバーカード（A, K等） | ブロードウェイ系が強化 | コールレンジが弱化 | IP有利（バレル推奨） |
| ペアカード | セット保有者のみ強化 | コールレンジ中位が弱化 | IP有利（バレル推奨） |
| ブランク（役に立たない中間ランク） | 変化小 | 変化小 | IPアドバンテージ維持 |
| フラッシュカード | FD完成者が強化 | FD保有OOPが強化 | IP不利気味（バレル慎重） |
| コネクター | ストレート完成者が強化 | ドロー保有OOPが強化 | IP不利（バレル非推奨） |

例えばK♠7♦2♣フロップ後にA♥（オーバーカード）がターンで落ちた場合：
IPのレンジにはAKo・AKsなど強いAx系が含まれており、これらがターントップペア（Aトップ）を追加します。
一方OOPのコールレンジはKxが多く、Axでコールしているケースは限られます。
このナッツアドバンテージの逆転がIPのバレルを正当化します。

## 8-3　ターンディフェンス判断

### ターン OOP フォールド閾値テーブル

| 相手ベットサイズ | MDF | HS フォールド閾値（SRP）| HS フォールド閾値（3BP）|
|:---:|:---:|:---:|:---:|
| 33%（小バレル） | 75% | HS ≥ 20 | HS ≥ 25 |
| 50%（中バレル） | 67% | HS ≥ 30 | HS ≥ 35 |
| 75%（大バレル） | 57% | HS ≥ 40 | HS ≥ 45 |
| 100%（ポットサイズ） | 50% | HS ≥ 50 | HS ≥ 55 |

※ ターン閾値はフロップより高い。フロップCBetをコールして残存したレンジはマージナル以上が主体のため、相対的なHS分布が上昇しているため。

ターンのフォールド閾値がフロップより約5〜10高い理由は、フロップCBetをコールしたことでレンジが絞られているためです。フロップでエアーのほとんどがフォールドしているため、ターン開始時のOOPレンジはHS20〜65のマージナル以上が中心になります。この分布の中で上位MDF%を守るとHS閾値が上昇します。

| 状況 | アクション |
|---|---|
| ターンバレル33% × バリュー | コール（SDV）|
| ターンバレル33% × マージナル | SPR依存（コール/フォールド）|
| ターンバレル33% × エアー | フォールド |
| ターンバレル75%超 × バリュー以上 | コール/レイズ |

ターンでコールすると、ほぼ確実にリバーでのベットに直面します。
フロップCBet→ターンバレルと打ってきた相手がリバーで突然チェックするケースは全体の30%未満にとどまるため、コールは「リバーも戦う覚悟」とセットで考える必要があります。

SPRが低い（3BP・4BP環境ではSPR3〜5程度）場合、マージナルでターンコールを選ぶとリバーのポット比率が大きくなり、降りると損失が膨らみます。
具体的には、ターンコール後にリバーでポットサイズのベットを受けると、コールに必要なエクイティは約33%に達します。
マージナル（HS35〜64）は多くの場合ショーダウンバリューは持ちますが、33%エクイティを安定して確保できないシナリオでは、ターン時点でのフォールドが期待値を守る正解です。

バリュー（HS65以上）でのターンコールは、リバーでのバリューベットやブラフキャッチを見据えた積極的な選択です。
相手のバレルが33%サイズであればα（ブレイクイーブン折り畳み率）は約25%になり、バリューのエクイティはそれを十分に上回ります。
ターンバレルが75%を超える大きなサイズの場合はαが約43%まで上がるため、バリューの中でもナッツ寄りのハンドでコール、またはレイズで応戦するラインを検討します。

### マージナルでのコール/フォールド判断フロー

マージナル（HS35〜64）はターン最大の判断難所です。
以下のフローで判断します：

```
マージナルのターンディフェンス判断
├─ SPR ≥ 6（SRP）
│   ├─ HS ≥ 50 → コール
│   └─ HS < 50 → フォールド
├─ SPR 3〜5（3BP）
│   ├─ HS ≥ 55 → コール
│   └─ HS < 55 → フォールド
└─ SPR < 3（4BP）
    ├─ HS ≥ 60 → コール（コミット気味）
    └─ HS < 60 → フォールド（コミットを避ける）
```

マージナルの下限（HS35〜45）でSPRが低い場合は、フロップのコールが失敗だった可能性があります。
このような場面でさらにターンコールを選ぶとスタック全体がリスクにさらされるため、フォールドでリセットする判断が長期的に見て収益的です。

## 8-4　チェックレイズとリバー計画

ターンでのチェックレイズはフロップCRより稀ですが、有効な場面があります。
具体的には「ターンで強くヒットした（セット→フルハウスなど）」か「フロップでチェックバックされた後OOPが主導権を取り返す」場面です。

OOPがチェックレイズを検討できる条件：

1. **ターンヒットでバリュー上位に昇格した場合**（例：フロップのミドルペアがターンでセットになった）
2. **フロップチェックバック後のターンリード**（相手のSDVレンジを攻める）
3. **ドローが完成したかつ相手がバレルを打った場合**（フラッシュ完成でCR）

CRサイズはターンでもCBet×2.5〜3倍を基準とします。
ただしターンCRはより大きなリスクを伴うため、確実にバリュー上位（HS70以上）のハンドでのみ実行するのが原則です。

## 8-5　例題（auto-generated）

| ハンド | ボード | HS（バケット）| ボード型 | ポット種別 | 答え |
|---|---|---|---|---|---|
| A♥K♦ | K♠7♦2♣-3♥ | 70（強（バリュー））| 型1: ハイ×ドライ | SRP（HU, SPR≈18） | CBET |
| Q♥Q♦ | T♠8♦5♣-K♥ | 45（中（マージナル））| 型2: ハイ×ウェット | SRP（HU, SPR≈18） | CHECK |
| 9♥9♦ | 9♠7♣3♦-7♥ | 88（強（バリュー））| 型3: ロー×ドライ | SRP（HU, SPR≈18） | CR（OOP） |
| A♥J♦ | A♠K♠8♠-Q♠ | 62（中（マージナル））| 型5: モノトーン | SRP（HU, SPR≈18） | FOLD |

**解説**

例題①のA♥K♦（HS≈70、バリュー）は、フロップK♠7♦2♣でトップペアトップキッカーを形成しています。
ドライフロップ×ブランクターン（3♥）のバレルスコアは+8+2=10で閾値を大きく超えており、IPからのバレルが正当化されます。
逆算するとリバーでも続けてバリューを取れるナッツ相当のハンドであるため、ターンのベットはリバーブランクが落ちた時のさらなるバリューベット計画と一体です。

例題②のQ♥Q♦（HS≈45、マージナル）は、フロップT♠8♦5♣でオーバーペアを持っていますが、ターンK♥が登場しています。
K♥のオーバーカードターンはFlopType（コネクテッド+3）にOC係数+3を加えてスコア6となり、閾値7を満たしません。
さらに相手のコールレンジにはKx（トップペア）が多く含まれており、マージナルのオーバーペアでバレルを打つとレイズされるリスクが高くなります。
ここではチェックでショーダウンを目指し、相手のベットに対してはSPR18の状況でマージナルとしてコールを検討するレンジ計画が適切です。

例題③の9♥9♦（HS≈88、バリュー上位）は、フロップ9♠7♣3♦でセットを持ち、ターン7♥でフルハウスに昇格しています（9-9-9-7-7のフルハウス）。
OOP立場でIPがバレルを打ってきた場合、フルハウスでのチェックレイズが最善です。
ターンCRサイズは相手のCBet×2.5〜3倍を基準とし、相手のドローに高いオッズを要求します。
なお、ターン7♥はペアカードであり、バレルスコア上はIPが打ちやすい状況ですが、こちらのフルハウスはその攻撃に対して最強の返し手です。

例題④のA♥J♦（HS≈62、マージナル上位）は、A♠K♠8♠のモノトーン（スペード3枚）フロップ後にQ♠のターンです。
A♥J♦はボードとスーツが合っておらず、フラッシュの可能性ゼロです。
ターンQ♠で相手がスペードフラッシュを完成させている可能性が高く、マージナル上位でもコールは損失に繋がりやすいです。
モノトーン−5補正を適用すると、75%ベットに対する閾値は35−5=30のところ、ターンQ♠でさらに相手レンジが強化されるため事実上フォールドが妥当です。

## 8-5-2　例題の補足（フロップアクション別）

ターンでの判断はフロップのアクション履歴によって大きく変わります。
以下に「フロップ展開別のターン判断例」を追加します。

**ケース1：IP CBet → OOP コール 後のターン（最も標準的なケース）**

フロップ：A♠K♦7♣（型1、ドライ）、SRP、IPがCBetしてOOPがコール。
ターン：5♥（ブランク）
バレルスコア：FlopType+8 + TurnCard+2 = 10 → 全レンジCBet

OOPのコールレンジはAx（TP）中心であり、ターンブランクで大きな変化はありません。
IPのレンジにはAK・AQ・A-setが含まれており、ナッツアドバンテージはIPが維持しています。
バレルスコア10の全レンジCBetが合理的です。

**ケース2：IP チェックバック後のターン（相手がリード）**

フロップ：T♠9♦7♣（コネクテッド）、IPがチェックバック。
ターン：K♥、OOPがリードベット（50%）。

IPのチェックバックでIPのレンジはSDV（HS35〜55）中心と読まれています。
OOPはKxを保有している可能性が高く、ターンK♥でリードしてくるケースはTP以上が多いです。
IPのSDVレンジ（HS40〜55）はKxに対して不利なため、相手のリードに対してはバリュー以上でコール、マージナル以下はフォールドを検討します。

**ケース3：OOP CR → IP コール 後のターン（IPが受けた側）**

フロップ：Q♠7♣3♠（型2、ウェット）、OOPがCRしてIPがコール。
ターン：2♦（ブランク）

OOPのCRはバリュー（HS≥65）のバリューCRが多く、IPコールはバリューの強いハンドです。
ターンブランクでは両者のレンジ構成が変化しにくく、OOPが続けてベットしてくる可能性が高いです。
IPはバリュー（セット等）でコールまたはレイズ、マージナル以下はフォールドの二択です。

## 8-6　まとめ：ターンの判断フロー

ターンでの判断をまとめると以下のフローになります：

```
ターン判断フロー（IP先手）
1. フロップアクションを確認してレンジを絞る
2. バレルスコアを計算（FlopType係数 + TurnCard係数）
   ≥7 → 全レンジ33%CBet
   <7 → チェック（バリューのみCBet検討）
3. リバー計画を確定
   バリュー → リバーもCBet予定
   エアー/ブラフ → リバーカード次第で継続/ギブアップ

ターン判断フロー（OOP後手）
1. 相手バレルのサイズ確認 → αを計算
2. 自分のHSをバケット分類
   バリュー（HS≥65）→ コール、場合によってCR
   マージナル（HS35〜64）→ SPR依存（上表参照）
   エアー（HS≤34）→ フォールド
3. ターンコールの場合、リバー計画を立てる
```

この2方向のフローを繰り返し練習することで、ターン判断のパターン認識が身に付きます。

### 【GTOとのズレ】

GTOはターンディフェンスをストリートの中で最も複雑なものとして扱っており、ポジション・レンジ優位・ドロー構成の三要素が複雑に絡み合います。
GTO最適解ではマージナルであっても特定のボードではコールが優位になる場合があり、また同じバリューでも相手のバレルサイズによってはレイズが期待値最大になることもあります。

特にGTOとの乖離が大きいのはナッツアドバンテージの評価です。
GTOはレンジ全体の「ナッツ保有頻度の差」を精密に計算してベット/チェックを決定しますが、本書のバレルスコアはその計算をFlopType+TurnCard係数の加算で近似しています。
ターンカードがOOPのレンジを「均一に」強化したり弱化したりするわけではないため、特定のコンボ数が多いボードでは近似誤差が大きくなることがあります。

本書はこの複雑さをシンプル化するため、バリューコール・マージナルをSPR依存・エアーフォールドという三分類に整理していますが、約15〜20%のケースでGTO最善手と異なる選択を推奨することになります。
正確度より一貫性を優先した設計であることを理解したうえで、慣れてきたらSPRやターンカードのテクスチャーを加味した微調整を取り入れていきましょう。
