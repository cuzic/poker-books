# 第10章　リバー先手・後手アクション

リバーは全5枚のコミュニティカードが出揃い、ドローが完成または失敗に終わる最終ストリートです。
エクイティが確定するため、先手はVMBバケットで「バリュー・ミックス・ブラフ」を打ち分け、後手はHandScoreとポットオッズを照合してコールかフォールドを決めます。
ここまで積み上げた計算式の集大成として、すべての判断を一本のフローにまとめてください。

リバーはターンと異なり「ドローの決着」が判断に大きく影響します。
フロップからずっと保有していたFDがリバーで完成した → バリューに昇格
ターンまでのOESDがリバーで空振りに終わった → ブラフ候補に転落
このような「ハンドのバケット変化」を認識することが、リバー判断の第一歩です。

## 10-1　VMBバケット

> **フロップのH3/H2/H1とリバーのV/M/Bの対応**：リバーではDrawBonus=0のためHSの意味が変わります。フロップでH3（HS≥65）だったハンドはリバーでVバケット（HS≥70）に対応し、フロップのH2がMバケット（HS 35〜69）に、H1がBバケット（HS<35）に相当します。同じ数値でも「フロップ時のHS」と「リバー時のHS」では含まれるドロー加点が異なるため直接比較はできませんが、大まかな対応関係として覚えておいてください。

| HandScore | バケット | 先手方針 |
|---|---|---|
| 70〜100 | V（バリュー） | ベット（サイズ問わず） |
| 35〜69 | M（ミックス） | ボードとサイズで判断 |
| 0〜34 | B（ブラフ候補） | ベット or チェック（ブラフ検討） |

VバケットはHS≥70の強いハンドで、相手レンジに対して約70%以上の勝率を持ちます。
強いハンドは積極的にポットを膨らませ、より弱いハンドからコールを引き出すことが最優先のため、ベットサイズを問わず常にベットします。

Mバケット（HS 35〜69）は最も判断が難しい領域です。
ベットすれば自分より強いハンドのみコールされ逆選択が生じる場合があり、チェックによってポットを守る選択も有力になります。
ボードが相手レンジ有利なら特にチェックバックが推奨されます。

BバケットはHS≤34で自力での勝ちが期待できず、ショーダウンバリューがほぼゼロです。
第9章のブロッカー条件とV:B上限を満たす場合はブラフに転換し、条件を満たさない場合はチェックして勝負を諦めてください。

### Mバケットの詳細判断

Mバケット（HS35〜69）の判断フローは以下のとおりです：

```
Mバケット（HS35〜69）リバー先手判断
├─ HS 55〜69（M上位）
│   ├─ ドライボード（型1・型3） → ベット33%（薄いバリュー）
│   ├─ ウェットボード（型2・型4） → チェック（逆選択回避）
│   └─ 相手がウィーク（チェックバック連続等）→ ベット33%
└─ HS 35〜54（M下位）
    ├─ 相手のレンジが弱い（リバーチェック後）→ ベット33%（ブラフに近い薄バリュー）
    └─ 相手がポット管理中 → チェック（ショーダウン優先）
```

Mバケット上位（HS55〜69）のドライボードベットは「薄いバリュー」として機能します。
例えばK♠7♦2♣のドライボードでTPmidキッカー（HS=58）を保有している場合、相手がH1のブラフキャッチャーよりも弱いハンドでコールする可能性があります。
このような「相手の弱いコールレンジ」が想定できる場面でMバケット上位のベットを選択します。

## 10-2　後手ディフェンス

| 相手ベットサイズ | コール条件（HandScore）|
|---|---|
| 33%（α=25%）| HS≥45 が目安 |
| 50%（α=33%）| HS≥50 が目安 |
| 75%（α=43%）| HS≥60 が目安 |
| 100%（α=50%）| HS≥65（H3）必要 |

リバーではドローが完成または失敗した後のためDrawBonus=0となり、HS ≈ エクイティ%に近づきます。
コール基準のHS値は実際のエクイティ%の目安として読んでください。

後手の判断はシンプルです。
相手の50%ベットに対してコールが得になる最低勝率はα=33%なので、HS≥50（≈エクイティ50%）以上で守れます。
33%の小ベットならHS≥45で守れるため、H2の下限近くまでディフェンスレンジを広げられます。
100%のポットサイズベットは要求勝率が50%に跳ね上がり、HS≥65（H3）が必要になります。

ベットサイズが大きいほど相手のレンジにバリューが集中する傾向があるため、コール条件も厳しくなることを覚えておいてください。

### HS≈エクイティ%の理解

リバーではDrawBonus=0のため、HSは役スコアRと等しくなります。
役スコアは「全ボードとハンドの組み合わせの中でのパーセンタイル」に相当します。

例：A-K-7-2-9ボードでのA♥K♦（ツーペア）
このボードでツーペアを持っているとすると、対戦相手が持てるハンドの多くはトップペア以下です。
HS=78はこのボードで「約78%の相手ハンドに勝てる」という近似を表しています。

リバーではエクイティとHSの乖離が最小化されるため、後手ディフェンス表の数値を「エクイティ%に必要な下限」として直接読めます。

## 10-3　チェックビハインドとブラフキャッチ

### チェックビハインド（IP）

ベット権をあえて使わず、SDVハンドや弱手でポット管理します。

| 状況 | チェックビハインド推奨理由 |
|---|---|
| Mバケット（HS 35〜64） | ベット → 弱手のみコールの逆選択を避ける |
| ボードが相手レンジ有利 | ブラフ期待値 < チェックバック期待値 |
| 相手がCRしやすいスタック | 被CR時の損失 > ベット収益 |

IPのチェックビハインドはMバケット手でポットを守る重要な技術です。
ベットすれば相手レンジの上位のみが残り、自分のハンドが相対的に弱くなる逆選択が発生します。
チェックバックであれば相手の弱いハンドもショーダウンへ連れてこられ、HS35〜64の中強度ハンドが持つ実際のエクイティを回収できます。

逆選択（adverse selection）の具体例を確認します。
A♠K♦7♣2♥9♠のボードでIPがA♥J♦（HS=64）を保有してベットした場合：
- コールする相手のレンジ：AKo/AKs（ツーペア）、AQ（T ペア）、セット
- フォールドする相手のレンジ：Jペア、弱いAx、空振り

コールしてくるのは自分が負けているハンドが多く、フォールドするのは自分が勝っているハンドです。
これが逆選択であり、HS64でのベットはEVマイナスになります。

### ブラフキャッチ（OOP）

相手のベットをブラフと判断してコールすることです。
コール判断 ≈ ポットオッズ × ブラフ頻度（第9章α式参照）。
αが低い（小ベット）ほどブラフ混入率が高くキャッチしやすいです。

OOPのブラフキャッチはMDF（Minimum Defense Frequency、第6章参照）と連動します。
33%の小ベットはV:B=3:1のためブラフが約25%含まれており、相手のブラフ頻度が高くキャッチしやすい局面です。
逆に100%ベットはブラフが約50%に制限されますが、ベット自体のサイズが大きいため慎重な判断が必要です。
H3近くの強いハンドを持たない限り安易なコールは避けてください。

**ブラフキャッチのコツ**：
相手のベットサイズが「そのハンド強度に対してなぜこのサイズを使うか」を考えます。
75%ベットは「強いハンドかブラフ」の二択になりやすく、相手が50%ベットを使わないことでヒントが得られることがあります。
ただしこれは「相手のテルを読む」という発展的な技術です。まずはHS閾値を守ったコール判断を優先してください。

## 10-4　例題（auto-generated）

**先手:**

| ハンド | ボード | HS（バケット）| ボード型 | ポット種別 | 答え |
|---|---|---|---|---|---|
| A♥K♣ | A♠K♦7♣2♥9♠ | 78（強（H3））| 型2: ハイ×ウェット | SRP（HU, SPR≈18） | BET 50% |
| A♥J♦ | A♠K♦7♣2♥9♠ | 64（中（H2））| 型2: ハイ×ウェット | SRP（HU, SPR≈18） | CHECK（チェックバック） |
| 9♠8♠ | A♣K♥7♦2♣4♠ | 10（弱（H1））| 型1: ハイ×ドライ | SRP（HU, SPR≈18） | BET 75%（ブラフ） |

**後手:**

| ハンド | ボード | HS（バケット）| ボード型 | ポット種別 | 答え |
|---|---|---|---|---|---|
| A♥K♣ | A♠K♦7♣2♥9♠ | 78（強（H3））| 型2: ハイ×ウェット | SRP（HU, SPR≈18） | CR |
| Q♥J♦ | A♠K♦7♣2♥9♠ | 20（弱（H1））| 型2: ハイ×ウェット | SRP（HU, SPR≈18） | FOLD（vs 50%ベット） |

**解説**

先手①（A♥K♣ / A♠K♦7♣2♥9♠）：ツーペアのHS=78、Vバケットです。
50%ベットを打てばH2以下のハンドからコールを引き出せ、ポット拡大が期待できます。
相手コールレンジはAJ・AT・Kx等のワンペアであり、ツーペアのHS78はそれらに安定して勝てます。

先手②（A♥J♦ / A♠K♦7♣2♥9♠）：トップペアジャックキッカーのHS=64、Mバケットです。
IPがここでベットすると、負けている2ペア以上のみコールされるため逆選択が発生します。
チェックバックでショーダウンに回す選択が無難です。

先手③（9♠8♠ / A♣K♥7♦2♣4♠）：OESD失敗・空振りでHS=10、Bバケットです。
ブラフ条件：ショーダウン価値ゼロ、ブロッカー効果あり（9・8でストレートの一部をブロック）。
ドライボードでIPが打ちやすいストーリーライン（Ax保有を表現）があり、75%ブラフを選択します。
ただしV:B比率内のブラフ枠が残っている場合に限り打てます。

後手①（A♥K♣ / A♠K♦7♣2♥9♠ + 相手ベット）：ツーペアのHS=78で、コール基準（100%ベットでもHS≥65）を大きく超えています。
相手がバリューベットを打ってきた場合、チェックレイズ（CR）でポットを最大化します。
CRサイズはCBet×2.5〜3倍が基準です。

後手②（Q♥J♦ / A♠K♦7♣2♥9♠ + 相手50%ベット）：空振りに近くHS=20、H1です。
50%ベットのコール基準はHS≥50であり、HS20<50のためフォールドが正解です。

## 10-4-2　リバーCRの判断基準

後手（OOP）のチェックレイズはリバーでも有効な武器です。
ただしリバーCRはターン・フロップのCRとは性質が異なります。

リバーCRの目的は「ブラフを阻止する」エクイティ否定ではなく、「バリューを最大化する」ことと「ブラフにコストを課す」ことの2点です。

| 状況 | リバーCR判断 | サイズ目安 |
|---|---|---|
| HS≥75（ナッツクラス） | CR積極推奨 | 相手ベット × 3〜4倍 |
| HS65〜74（H3上位） | CR検討 | 相手ベット × 2.5倍 |
| HS35〜64（H2）| コール（CRは稀） | − |

リバーCRサイズがターンより大きくなる理由は、リバーにはドローがないため「フォールドさせたい」より「コールさせたい」が優先されるからです。
大きなCRは相手のブラフを「採算割れ」に追い込みますが、相手のバリューもコールさせられます。
ナッツクラスのCRでは「相手がコールすることもウェルカム」なため、大きなサイズでも問題ありません。

### ブラフキャッチCR（稀な高度技術）

OOPがHSは低いが「相手がブラフだと確信できる」場合にCRする「ブラフキャッチCR」は高度な技術です。
相手の betting line（フロップCBet → ターンバレル → リバー大ベット）が「バリューより多いブラフ」を示唆している場合に有効です。
ただしこの判断には相手のレンジ読みの精度が必要であり、本書の初中級者向けフローでは「HS≥65でCR、それ以下はコールかフォールド」に簡略化しています。

## 10-5　全ストリート統合フロー

本書で学んだ各章の計算式は、プリフロップからリバーまでの一本のフローに統合されます。

```
統合判断フロー
1. プリフロップ: Score ≥ T_open → オープン
   Score_BB ≥ T_3bet → 3ベット候補

2. フロップ（先手）: HS + ボード型 → CBetサイズ決定
   フロップ（後手）: HS ≥ フォールド閾値 → ディフェンス

3. ターン（先手）: BarrelScore ≥ 7 → 全レンジ33%バレル
   ターン（後手）: H3→コール / H2→SPR依存 / H1→フォールド

4. リバー（先手）: VMBバケット → ベット/チェック
   α式でV:B管理 → ブラフ上限確認
   リバー（後手）: HS ≥ α相当値 → コール
```

このフローを繰り返し使うことで、各ストリートの判断が独立した計算ではなく「前のアクションの続き」として自然につながっていきます。

## 10-5-2　実戦でのフロー活用例

統合フローを実際のハンドに適用した例を確認します。

**ハンド例：BTN vs BB（SRP）**

```
プリフロップ：BTN オープン（K♥Q♦、Score=31）→ BB コール
フロップ：K♠8♦3♣（型1、ドライ）
  → H3（HS≈66）→ CBet 33%
ターン：5♥（ブランク）
  → バレルスコア：8+2=10 → 全レンジ33%バレル
リバー：J♠
  → K♠8♦3♣5♥J♠、K♥Q♦でHS≈60（H2、Mバケット）
  → ドライボード（型1）× Mバケット上位 → ベット33%
```

このハンドではフロップ→ターン→リバーと3ストリート連続してベットを打っています。
K♥Q♦はTPTKに近い手であり、一貫したバリューラインを取ることで相手の弱いKxからコールを引き出します。

**ハンド例：BTN vs BB（フロップチェックバック後）**

```
プリフロップ：BTN オープン（A♥J♦）→ BB コール
フロップ：K♠T♠9♦（型4、ローウェット）
  → H1（HS≈15、ドローなし）→ チェックバック
ターン：4♥（ブランク）
  → バレルスコア：3+2=5 → チェック（H1のためCBetなし）
リバー：2♣
  → ボードK-T-9-4-2、A♥J♦でHS≈15（H1）
  → ブラフ条件確認：ブロッカー（Aブロック）あり、V:B上限確認
  → ブラフ条件を満たせばベット75%（Aを表現）、満たさなければチェック
```

このケースはフロップチェックバック後にブラフ機会を探るラインです。
ドライターン・ドライリバーで相手が弱いと判断できる場合は、A♥J♦のAブロッカーを使ったブラフが有効です。

## 10-6　ポット管理の原則

リバーを含む全ストリートで「ポット管理」は重要なスキルです。
ポット管理とは「自分のハンド強度に見合ったサイズでポットを拡大または抑制すること」を指します。

**大きなポットを好む場面（Vバケット）：**
- セット以上のナッツクラスを保有している
- 相手がコールを選びやすい（相手がH2で粘っている）
- ドライボードで相手が「弱いがコールできる」手を持ちやすい

**小さなポットを好む場面（Mバケット）：**
- 自分のH2ハンドが逆選択リスクを抱えている
- ウェットボードで相手のドローが完成した可能性が高い
- 3BPなど深い局面でコミットを避けたい

チェックビハインドはMバケットにおけるポット管理の中心技術です。
ベット権を行使しないことで「ポットを小さく保ちながらショーダウン価値を回収する」選択が可能になります。

## 10-7　ドロー別リバーアクション早見表

フロップやターンで保有していたドローがリバーで完成・失敗した場合のアクションをまとめます。

| ドロー状態 | リバーアクション | HandScore | 先手方針 |
|---|---|---|---|
| NFD完成（ナッツフラッシュ） | バリューベット | HS≈95 | ベット50〜75% |
| フラッシュ完成（非ナッツ） | バリューベット | HS≈85 | ベット50% |
| OESD完成（ストレート） | バリューベット | HS≈90 | ベット50〜75% |
| ガットショット完成 | バリューベット | HS≈85 | ベット50% |
| NFD失敗（空振り） | ブラフ候補 | HS≈0〜5 | ブラフ条件確認（優先度高）|
| OESD失敗（空振り） | ブラフ候補 | HS≈0〜5 | ブラフ条件確認（優先度高）|
| ガットショット失敗 | ブラフ候補 | HS≈0〜5 | ブラフ条件確認 |
| バックドアFD失敗 | ブラフ候補（低優先）| HS≈0〜5 | ブラフ上限で判断 |

「完成 → バリュー」と「失敗 → ブラフ候補」という変化はリバー判断の核心です。
特に空振りOESDは「ショーダウン価値ゼロ・ブロッカーあり」のためブラフ最優先候補になります。

### ドローを保有したままコールしていた場合

フロップやターンでドローを保有してコールしていた場合、リバーでドローが完成すると「バリューラインに切り替わる」という変化が起きます。
この切り替えを意識することで、リバーの先手判断がスムーズになります。

例：フロップでFD+ガットショット（HS≈50、H2）でコール
→ ターンでFD継続（HS≈40、H2下位）でコール
→ リバーでフラッシュ完成（HS≈85、V）
→ バリューベット50%が最善

ドローが失敗した場合はその逆です。
→ リバーで空振り（HS≈5、B）
→ ブラフ条件確認（ブロッカー・V:B上限）→ 条件次第でブラフまたはチェック

### 【GTOとのズレ】

リバーのGTO解析はブロッカー効果やレンジ構成が複雑に絡み合います。
本書はブロッカーの個別評価や混合戦略の頻度管理を省略し、VMBバケットとHS閾値によるバイナリ判断を採用しています。

実際のGTOでは同じHS値でも保有カードのブロッカー効果によって判断が変わる場面がありますが、その精度向上は上級者向けのステップとして残してあります。
特に大きな乖離が生じるのは「Mバケット上位（HS55〜69）のベット判断」です。
GTOはこの帯域でボード・ブロッカー・相手レンジの三要素を組み合わせた複雑な混合戦略を取り、単純な「ベット/チェック」では表現できません。
本書の「ドライボード→ベット、ウェットボード→チェック」という近似は、この複雑さを大きく省略しており、EV差は約3〜7%程度になります。

まずはVMBと後手ディフェンス表を使いこなすことを優先してください。
ブロッカー判断の精緻化は本書を一通り習得した後の応用ステップとして取り組んでいただくと効果的です。
