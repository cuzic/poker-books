# 第2章　ライブでのタイプ診断：行動編

*対象: 🔰🎯*

> 行動は嘘をつきません。
> 「何を打ったか」より「いつ降りたか」が、タイプを語ります。

---

## ライブ診断は「行動 × タイミング × サイズ × ライン」の合成

ライブには HUD がありません。代わりに、相手の**行動パターン**を直接観察することができます。本章では「行動」の側面に絞って診断軸を整理します。サイズ・タイミング・ラインは次章 (第 3 章) で扱います。

観察の優先順位をまとめると、以下のようになります。

1. **プリフロップで分類**: オープン頻度、リンプ頻度、3bet 頻度、fold の速さ
2. **ポストフロップで分類**: Cbet 頻度、ベット側継続性、圧力への反応
3. **ショーダウンを記録**: 見せた手が最大の証拠
4. **タイミングで補完**: 即アクション vs 長考のパターン

---

## 1. プリフロップで分類する

### オープン頻度

「何ハンドに 1 回参加するか」を数えてみましょう。

| オープン頻度 | 推定タイプ |
|---|---|
| 5 ハンドに 1 回未満 (VPIP < 10%) | ニット |
| 5 ハンドに 1 回 (VPIP 12〜18%) | TAG |
| 3 ハンドに 1 回 (VPIP 25〜33%) | LAG |
| 半分以上 (VPIP 50%+) | コーリングステーション or マニアック |

ライブで 5 ハンド観察には約 10 分かかります。30 ハンド (1 時間) で大まかなタイプは判別できるようになりますので、焦らず時間をかけてみてください。

### リンプ頻度

リンプ (大幅以外のフラットコールでプリフロップ参加) の有無は、強力な分類軸です。

- **リンプなし**: 参加するときは必ずレイズ → ニット / TAG / LAG
- **リンプ多発**: フラットコールで参加 → コーリングステーション
- **混在**: 弱い手はリンプ、強い手はレイズ → 中級者、サイズテルの可能性

リンプが見えたら「コーリングステーション候補」とメモすることをおすすめします。

### 3bet 頻度

プリフロップの 3bet (リレイズ) 頻度について見ていきましょう。

- 3bet 一度もなし (50 ハンド観察) → ニット / コーリングステーション
- 3bet 5〜10% → TAG
- 3bet 10%+ → LAG / マニアック

3bet のサイズも観察してみます。3bet が常に大きい (ポット比 4 倍以上) → ナッツ寄り、3bet がプリフロップ raise の 2.5 倍程度 → ブラフ込み (LAG) という具合です。

### fold の速さ

オープンに対する fold のタイミングをチェックしてみましょう。

- 即 fold (相手が考えずに捨てる) → ニット寄り、fold 範囲が広い
- 長考 fold → 境界ハンド、TAG / LAG 寄り
- call も fold もしない長考 → 弱いキャッシュゲーム経験者

---

## 2. ポストフロップで分類する

### Cbet 頻度と継続性

フロップでベット側 (preflop raiser) の Cbet 頻度について、以下のように分類できます。

| Cbet 頻度 | 推定タイプ |
|---|---|
| < 40% | ニット (強い手だけ Cbet) |
| 50〜65% | TAG (バランス取り) |
| 70%+ | LAG / マニアック |

**継続性** (フロップで bet→ターンも bet) も大切です。

- 1 バレル止まり (フロップ Cbet → ターン check) → ブラフ Cbet 主体 (LAG / TAG)
- 2 バレル継続 → バリュー寄り (TAG / ニット)
- 3 バレル継続 → ナッツ寄り or マニアック

### 圧力をかけられたときの反応

あなたがチェックレイズした、または raise した場面での相手の反応を見てみましょう。

- 即 fold → ニット / TAG (適切な fold)
- call → コーリングステーション / LAG (中強度ハンドも降りない)
- リレイズで反撃 → LAG / マニアック (4bet も辞さず)

### ドンクベットの有無とパターン

ドンクベット (call 側がフロップで先制 bet) の有無は、強力な分類軸です。

- ドンクベットなし → ほとんどのタイプ (TAG / LAG / ニット)
- ドンクベットあり (小サイズ) → コーリングステーション (弱いトップペアで「とりあえず打つ」)
- ドンクベットあり (大サイズ) → ナッツ 2 強化型 (セット・ストレート)、または LAG のブラフ
- ドンクベットの頻度が高い (3 回以上/50 ハンド) → 個性的なプレイヤー、メモを取ることをおすすめします

## 3. ショーダウンを記録する

ショーダウン (リバーまで進んでハンドが公開される場面) は、**タイプ診断の最大の証拠**です。

### 記録すべき項目

| 項目 | 例 |
|---|---|
| ハンド番号 | #15 |
| 相手の手 | K♠J♦ |
| ボード | K♣8♦5♥-2♠-Q♥ |
| アクション | フロップ Cbet → ターン check → リバー call |
| 推定 | TAG (適切な値で薄バリュー) |

### ショーダウンから読み取れること

以下のポイントをチェックしてみましょう。

- **見せた手の強さ vs アクション** で「sizing 過剰 / fold 過剰 / bluff 多発」を判定
- 弱い手 (セカンドペア・A ハイ) でリバーまで来た → コーリングステーション
- ブラフを見せた → LAG (頻度判定が可能)
- 強い手 (セット・ツーペア) でスロープレイ → トラップ志向 (TAG / LAG)

### ショーダウン頻度自体が情報

ショーダウンの**頻度**も、タイプ指標になります。

- ショーダウンがほぼゼロ → fold 多 (ニット) or bet で終わる (LAG)
- ショーダウン頻繁 → call 多 (コーリングステーション)
- 弱い手のショーダウン → コーリングステーション / LAG (薄 call)

---

## 4. タイミングで分類する

タイミング (即アクション vs 長考) は補助軸ですが、強い情報源です。

### 即アクション

| アクション | 即アクションの意味 |
|---|---|
| bet/raise | 事前に決めていた (強い確信 or マニュアル化された判断) |
| check | 価値がないと即判断 (弱い、または考える必要なし) |
| call | パターン化された call (コーリングステーション) |
| fold | 弱すぎる、または何も考えていない |

即 bet/raise はパターンが多く、強い手とブラフの両方があります。タイプで判断しましょう。

### 長考

| 長考の意味 | タイプ |
|---|---|
| 本物の迷い (ドロー、ボーダーライン) | 中級者 (TAG) |
| call か raise の選択肢で迷う | 上級者 (LAG / TAG) |
| 意図的な長考で誘う | 上級者 (TAG / LAG) |
| 単に遅い | 初心者 (タイプ不明) |

上級者は意図的に長考することで弱さを隠す場合があります。同じ相手の長考パターンを記録し、平均から外れた場面を疑ってみてください。

---

## 5. 行動パターンの「組み合わせ」で確定する

単一の軸では誤分類が起こる可能性があります。複数の軸を組み合わせて確定させましょう。

### 確定パターン例

**ニット確定**:

- VPIP < 15% + リンプなし + Cbet < 40% + 3bet ほぼなし + ショーダウンで強い手ばかり

**コーリングステーション確定**:

- VPIP > 40% + リンプ多 + 圧力に call 続ける + ショーダウンで弱い手あり

**LAG 確定**:

- VPIP 25〜35% + 3bet 10%+ + Cbet 70%+ + 圧力にリレイズ + ブラフを見せた

**マニアック確定**:

- VPIP > 50% + ポストフロップほぼ毎回 bet + 4bet/5bet も辞さず + サイズ滅茶苦茶

**TAG 確定**:

- VPIP 16〜22% + 適切な Cbet + 圧力に適切に fold + ショーダウンでバリュー手

---

## 6. 「タイプが変わる」場合

タイプは固定ではありません。次の場面で行動が変わることがあります。

### チルト

バッドビート後にマニアック化するプレイヤーは多いです。20〜30 ハンド観察した後、敗北を 1〜2 回経験した時点で行動を再観察してみましょう。

- 参加率急上昇 → マニアック化
- サイズ拡大 → ブラフ多発
- 即 bet 連発 → 自暴自棄

### 疲れ

長時間 (5 時間+) プレイした後はタイトになる傾向があります。集中力が落ち、難しい判断を避けて fold を選びやすくなります。

### スタック変化

- ショートスタック (20bb 以下) → プッシュフォールドモード (どのタイプも変容)
- ビッグスタック (200bb+) → 慎重になる (TAG/LAG)
- 大勝後 → ルース化 or タイト化 (個人差)

タイプが変わったら、その時点から再分類することをおすすめします。古いメモは破棄するか、「過去のタイプ」として保留しておくといいでしょう。

---

## まとめ

- プリフロップ: オープン頻度・リンプ・3bet・fold の速さ
- ポストフロップ: Cbet 頻度・継続性・圧力反応・ドンクベット
- ショーダウン: 見せた手とアクションの組み合わせがタイプの最大の証拠
- タイミング: 即アクション / 長考は補助軸
- 複数の軸を組み合わせて確定する
- チルト・疲れ・スタックでタイプは変わる

次章 (第 3 章) ではサイズ・タイミング・ライン・身体・会話の 5 種類のテルを信頼度順に整理します。本書最重要章です。
