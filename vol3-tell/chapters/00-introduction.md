# 序章　GTO の外側で稼ぐ

*対象: 🔰💻🎯*

> 相手が偏っているなら、こちらも偏っていい。
> 大事なのは、偏りの方向と量を間違えないことです。

---

## 「負けない戦略」と「稼ぐ戦略」は別物

GTO（Game Theory Optimal、ゲーム理論最適）は、相手が均衡戦略を取っている前提で組まれた「負けない戦略」です。GTO 対 GTO の対戦では双方の EV はゼロサムになり、期待利益は生まれません。

収益が生まれるのは、相手が GTO から逸脱したときだけです。現実のテーブルに座る相手は、ほぼ全員が GTO から大きく逸脱しています。コールしすぎる相手、降りすぎる相手、ブラフしすぎる相手——こうした偏りを無視して GTO で返し続けることは、稼げる機会を自ら捨ててしまう行為です。

エクスプロイト（exploit）とは、相手の偏りを観察し、その偏りに乗じて EV を最大化する戦略です。偏りが大きい相手ほど、エクスプロイトで得られるリターンは大きくなります。

GTO ソルバー の実測データによれば、相手の偏りに合わせて戦略を最適化することで、ハンドあたり 0.8〜1.4 bb の追加 EV が得られます。6-max ライブで 1 時間 30 ハンドをこなすと、1 セッション 5 時間で 120〜210 bb の差になります。月単位で積み重なると、エクスプロイトの有無が黒字プレイヤーと赤字プレイヤーを分ける分岐点になります。

---

## MATCHA の判定軸は「均衡値」

本シリーズの読者は、以下の式と閾値を学んでいるはずです。

**Vol1 (MATCHA Formula) のプリフロップスコア**:

```
Score = H + L + ペアボーナス + スーテッドボーナス + ブロッカー − ペナルティ
```

T_open は UTG=24 / HJ=22 / CO=20 / BTN=18 / SB=22 です。

**Vol2 (MATCHA Framework) のポストフロップ**:

5 つの判定軸 (レンジ分布 / ハンドストレングス / ベットサイジング / SPR / エクイティバケット) を 12 cells grid に流し込み、Score 値から `raise / call / fold` を決定します。

これらの数値はすべて「均衡値」です。GTO に近い相手に対して搾取されずに戦えるよう設計されています。ですが、相手が均衡から外れているなら、こちらも外れていい——むしろ外れるべきです。

たとえばコーリングステーション (call 過剰の相手) が多いテーブルでは、BTN の T_open を 18 から 15〜16 に下げ、バリューハンドの参加範囲を広げると追加 EV が取れます。逆にマニアック (ほぼ全 bet・全参加の相手) が左隣にいる場合は、T_open を 18 から 26〜28 まで引き上げます。

本書はこの「閾値の移動」と「MATCHA 判定軸の歪め方」を体系的に扱います。

## エクスプロイトの核心：方向と量を間違えない

閾値を動かすこと自体は難しくありません。難しいのは、方向と量を正確に判断することです。

**方向の誤りは、何もしないより損になります。**

同じ「call しすぎる相手」に対しても、間違った方向に調整すると損失になってしまいます。コーリングステーションに対してブラフを増やすのは誤った方向の調整です。相手は call してくれるからこそ、ブラフは成立しません。正しい方向はバリューベットを増やし、ブラフをゼロに近づけることです。

間違えた方向への調整は、GTO を忠実に守るよりも大きな損失をもたらします。

**量の過剰調整も危険です。**

GTO ソルバー の分析によれば、相手の call 頻度が 2% 変化するだけでブラフの最適頻度は劇的に変わります。「少しの偏りでも大きな調整が正当化される」一方で「調整しすぎると自分が搾取される側に回る」リスクもあります。

本書では各章末に「やりすぎ注意」のコーナーを設け、過剰調整の落とし穴を具体例と数値で示します。

## 4 段階フロー：テル → タイプ判定 → MATCHA 軸の歪め → アクション

本書が提案するエクスプロイトの実行フローを整理します。

```
ステップ 1：テル観察 (行動 / サイズ / ライン / タイミング / 身体 / 会話)
         ↓
ステップ 2：タイプ判定 (ニット / TAG / LAG / コーリングステーション / マニアック)
         ↓
ステップ 3：MATCHA 判定軸の歪め (レンジ分布 / エクイティバケット / 形勢)
         ↓
ステップ 4：アクション決定 (T_open シフト / Score シフト / sizing 変更)
```

この 4 ステップは順番が大切です。ステップ 3 (MATCHA 軸の歪め) をスキップして即座にアクションを変えることは、診断なしに薬を処方するようなものです。相手の偏りが特定できていれば、調整値は自然と決まります。

ステップ 4 は一度決めたら終わりではありません。ショーダウンや行動の変化によって偏りの推定が更新されたら、その都度調整し直します。エクスプロイトは「設定して忘れる」ものではなく、セッションを通じて継続的に更新するプロセスです。

## 会話：タイプを知ることが先決だと気づいた瞬間

ある夜のライブゲームでのことです。

🔰 **真田**は BTN でポケットナインを持ってオープンしました。BB の 🎯 **岡田**がフラットコールし、フロップは A♠K♦7♣。岡田がチェックすると、真田は迷わず 3/4 ポットのベットを打ちました。岡田は call します。

「ハンドストレングスはミドルペア、ボードは A 含みでオーバーカード 2 枚。MATCHA でいうと劣勢のブラフキャッチ域だな」と真田は内心で後悔しながら、ターンの 2♥ を見ます。岡田がまたチェックします。

真田は続けてセカンドバレルを打ちました。岡田はまた call します。リバーで A♥ が落ちると、岡田が大きく bet してきました。真田は長考した末に fold しました。

セッション後、真田は隣にいた 💻 **林**に話しかけました。

「あの場面、ハンドストレングスとレンジ分布を整理して打ったんですが…フロップの判断は合っていたんでしょうか？」

林は少し考えてから言いました。「計算の前に、岡田さんがどんなプレイヤーかを確認するべきでした。あの時間帯、岡田さんはずっと call を繰り返していましたよね。レイズは一度もなかった。」

真田はハッとしました。確かにそうでした。岡田は着席してからの 1 時間、ほとんどすべてのハンドで call していました。

林が続けます。「コーリングステーションが相手なら、ブラフベットは使いません。相手は call してくれるんです。打つとしたらバリューだけです。A♠K♦7♣ のフロップで 99 はバリューではないので、チェックバックが正解でした。」

岡田が聞いていて笑いながら言いました。「正直に言うと、私は今日ずっと call していました。理由はどうでもよくて、call していた、それが事実です。それを 1 周で読み取れれば、式を当てはめる前に答えが出ます。」

真田は静かに頷きました。

「式を知っている。閾値も覚えている。でもその前に、相手が誰かを知らなければ、式を向ける方向が分からない…」

そのことに、真田はそのセッションで初めて気づいたのでした。

## エクスプロイトと GTO を使い分ける

GTO を捨ててエクスプロイトだけで戦えばいいか、というと、そうではありません。エクスプロイトと GTO は目的に応じて使い分けるものです。

相手のタイプが分からない序盤、あるいは相手が TAG でほぼ GTO 近似の行動をしている場合は、GTO に近い均衡戦略が最善です。相手の偏りが特定できていないのに閾値を動かすのは、誤った方向への調整を招くリスクがあります。

相手のタイプが確認でき、偏りが明確になった時点から、エクスプロイトに切り替えます。ニット相手が確認できた BTN では T_open を 18 から 13〜14 まで下げ、コーリングステーション相手が確認できたポストフロップではブラフをゼロにする——このように、相手ごとに設定を変えていきます。

6-max テーブルでは 6 人それぞれが異なるタイプであることがほとんどです。実際のテーブルでは、左隣がニット、右隣がコーリングステーション、正面がマニアックということも起こります。それぞれの相手に対して個別の閾値を設定し、ハンドごとに「今の相手は誰か」を確認してから式を当てはめる——これがエクスプロイトの実体です。

## 本書の使い方：タイプを診断してから該当章を開く

本書は診断から始まります。エクスプロイトは「相手のタイプが分かってから始まる」ものです。タイプを確認せずに調整を始めると、方向を誤るリスクが高まります。

**第 1 部「診断」(第 1〜4 章)**: 5 つのプレイヤータイプ定義、ライブとオンラインでの見分け方、テル (行動 / サイズ / ライン / 身体 / 会話) の信頼度、診断の落とし穴。観察の精度がエクスプロイトの精度を決めます。

**第 2 部「タイプ別エクスプロイト」(第 5〜10 章)**: 5 つの逸脱軸を導入し、タイプ別に T_open シフト、MATCHA 判定軸の歪め方、ターン・リバーの調整を扱います。本書の中核です。

**第 3 部「状況別エクスプロイト」(第 11〜14 章)**: プリフロップ・フロップ・ターン・リバーのストリート別調整。ch11 はベット側／コール側の 2 視点で再編されています。

**第 4 部「テーブル全体の EV 管理」(第 15〜18 章)**: 席選び、ルース・ビッグベット卓攻略、アイソレート、ゲーム環境の維持。

**第 5 部「精度向上と実戦」(第 19〜22 章)**: 観察ノート、過剰調整の罠、オンライン特有のエクスプロイト、ハンドクイズ 25 問。

## 観察ノートを手元に置いて読む

本書を最も効果的に使う方法は、実際のセッションと並行させることです。

読書中に「このタイプに似たプレイヤーが昨日テーブルにいた」と思ったら、そのプレイヤーについて 3 点を記録してください。

1. 仮タイプ (ニット / TAG / LAG / コーリングステーション / マニアック)
2. 自分が実施した調整 (T_open を何に変えたか、ブラフを増減したかなど)
3. 結果：機能したか、しなかったか、分類を修正すべきか

この記録が積み重なると、自分の分類精度の傾向が見えてきます。「コーリングステーションを過剰に TAG と分類している」「ニットの bet を尊重しすぎている」といった自分固有のバイアスを発見することが、精度改善の出発点です。

第 19 章で観察ノートのテンプレートと早見表を提供します。

エクスプロイトは知識ではなく習慣です。本書を読んで「なるほど」と思っても、実戦で繰り返し使わなければ定着しません。10 ハンドに 1 回でいいので、「今の相手のタイプは何か」「閾値を動かすべきか」と自問する習慣をつけてみてください。

## まとめ

- GTO は「搾取されない」戦略であり、「最大限稼ぐ」戦略ではありません
- 相手が GTO から逸脱しているなら、こちらも逸脱することで追加 EV (0.8〜1.4 bb/hand) が得られます
- 本書の Score 閾値・判定軸はすべて「均衡値」——タイプに応じて意図的に動かします
- エクスプロイトの核心は「方向」と「量」を誤らないことです
- 実行は 4 ステップ：テル観察 → タイプ判定 → MATCHA 軸の歪め → アクション
- 本書はタイプを診断してから該当章を読む設計になっています

次章では 5 つのプレイヤータイプを定義し、オンラインとライブそれぞれでの識別方法を解説します。
