# 付録A　VPIP/PFR 読み取り早見表

---

## 主要 HUD 統計の解釈

### VPIP (Voluntarily Put In Pot)

プリフロップで自発的にポットに金を入れた頻度です。

| VPIP | 解釈 | タイプ候補 |
|---|---|---|
| < 12% | 極タイト | 純ニット |
| 12〜18% | タイト | ニット / TAG タイト寄り |
| 19〜25% | 標準 | TAG |
| 26〜35% | やや広い | TAG ルース寄り / LAG |
| 36〜45% | 広い | LAG / CS |
| 46〜60% | 極広い | CS / マニアック |
| > 60% | 超極広い | マニアック |

### PFR (Pre-Flop Raise)

プリフロップでレイズした頻度です。

| PFR | 解釈 |
|---|---|
| < 8% | 極パッシブ |
| 8〜14% | パッシブ |
| 15〜22% | 標準アクティブ |
| 23〜30% | アクティブ |
| 31〜40% | 高アクティブ |
| > 40% | 極アクティブ |

### VPIP - PFR 差

パッシブ度の指標です。

| 差 | 解釈 |
|---|---|
| 0〜3 | アグレッシブ (TAG / LAG / マニアック) |
| 4〜8 | やや混在 |
| 9〜15 | パッシブ寄り |
| > 15 | コーリングステーション確定 |

## サンプル数別信頼度

| サンプル数 | 信頼度 | 推奨アクション |
|---|---|---|
| < 30 | 仮分類のみ | 極端 shift 禁止 |
| 30〜100 | 大まかな分類 | mild shift OK |
| 100〜300 | タイプ確定 | 標準 shift OK |
| 300+ | サブ分類 | extreme shift OK |

---

## ライブでの代替指標

HUD がないライブでの推定方法です。

| 指標 | 観察方法 |
|---|---|
| VPIP 代替 | 5 ハンドに何回参加するか × 4 で % 換算 |
| PFR 代替 | リンプなしの参加 / 全参加 |
| Cbet 代替 | open に対するフロップ bet 頻度 |
| FoldToCBet 代替 | 圧力受けの fold 頻度 |
| AFq 代替 | アクティブ / パッシブの感覚 |

20〜30 ハンド観察で大まかな数値推定ができます。
