# 第16章　ルース・ビッグベットテーブルの攻略

*対象: 🔰🎯💻*

> 参加率高 × 大 bet 多発のテーブルは、最大の収益源でもあり最大の地雷です。
> マルチウェイ・ポット中心で、ハンド選択が全てを決めます。

> 対応 poker-drill: `matcha_exploits_multiway` (3+ way pot シミュレーション)

---

## 構造の理解：参加率高 + 大 bet では何が起きているか

「ルース・ビッグベットテーブル」とはこんな状況です：

- VPIP 平均 35〜50% (テーブル全体で広く参加)
- 平均 bet サイズ 75〜150% (大きめ)
- マルチウェイ pot 多発 (3〜5way 標準)
- LAG / マニアック / コーリングステーション混在

### よく起きる現象

1. **マルチウェイ pot 多発**: 3〜5way で進みます。フロップ Cbet が機能しません
2. **大 pot 化**: ポットがスタック比 50%+ に膨らみます
3. **オールイン頻発**: ストレート/フラッシュ完成時に jam します
4. **分散大**: 1 セッションで ±200bb の振れが出ます
5. **EV 大**: 長期では大きく勝てます

### 心理的な落とし穴

- 「みんな参加してるから自分も」→ レンジ拡大しすぎ
- 「大 bet されても call」→ ブラフキャッチ過剰
- 「マルチウェイでブラフ通る」→ 通りません (call 多)

冷静な判断が必須です。

---

## ビッグベッターの位置別戦略

テーブルに「ビッグベッター」(LAG / マニアック) がいる場合の戦略をお伝えします。

### 右隣 (IP) の場合: ATM 戦略

ビッグベッターが hero の右にいる = hero は IP です。

**戦略**: 「ATM 戦略」(チェックして打たせる)

1. プリフロップで広めに call (IP でフィッシュから取れます)
2. フロップ check → ビッグベッターが打ってくれます
3. 中強度ハンドで call、強い手で raise します

例: BTN hero TT、CO マニアック open、hero call、フロップ K72 → CO Cbet → hero call (call で TT は十分です)

### 左隣 (OOP) の場合: T_open 大幅引き上げ・席替え検討

ビッグベッターが hero の左 = hero は OOP です。

**戦略**: T_open を大幅引き上げ (+5〜10)、ハンドを絞ります

- BTN (右隣 LAG): T_open=18 → 22〜25
- CO (左 LAG/マニアック): T_open=20 → 25〜30
- 席替えを最優先で検討しましょう

---

## マルチウェイポットへの対応

3way 以上のポットでは、heads-up とは戦略が異なります。

### ハンド選択：post で価値があるか

MW で価値の高いハンドをまとめました：

| ハンド種 | 価値 (MW) | 理由 |
|---|---|---|
| **スーテッドコネクター** (T9s, 87s) | ★★★ | ストレート / フラッシュでナッツになります |
| **スモールペア** (22-66) | ★★★ | set でナッツ、Equity 大 |
| **ミディアムペア** (77-99) | ★★ | overcard 多発、注意が必要 |
| **A 含むスーテッド** (A5s-AKs) | ★★ | A ハイ board + nut flush で強い |
| **大きいオフスーツ** (AK, AQ) | ★ | post で middling、kicker 競合 |
| **小さいオフスーツ** | ✗ | 価値なし |

MW 用ハンドは **ナッツ完成可能性** が最重要です。

### 3way 以上は MATCHA バリューモードのみ

MW では以下を心がけましょう：

- **バリューモードのみ**: ナッツ近のみ bet/raise
- **ブラフ生成 0%**: 3way で fold equity 不足、ブラフ通りません
- **ショーダウンモード拡大**: check で安く見せて回収
- **ブラフキャッチ縮小**: MW のターン bet はバリュー確率高い

### サイズ

MW のサイズは heads-up より **大きめ** (75〜100%) がおすすめです。理由は：

- 複数相手から call 期待値で push します
- ナッツの場合は full pot で取りに行きます
- bluff 不要なので小さく刻む意味がありません

---

## ポットオッズによる call 判断

MW では call 判断が複雑です。**期待値** の計算が必須です。

### 基本式

```
Equity (必要) = bet / (pot + bet + opponent_responses)
```

例: pot 30bb、相手 bet 20bb (1 人)、call 10bb → 必要 Equity = 20% (heads-up)

MW で 2 人が call の場合 → 必要 Equity = 12〜15% (期待値で多人数から回収)

### ドローでの MW call

- フラッシュドロー (9 outs): フロップで Equity 35% → MW でも call OK です
- OESD (8 outs): Equity 31% → MW で call OK です
- ガットショット (4 outs): Equity 17% → MW なら状況による
- バックドアドロー: MW では call しません (期待値不足)

---

## ターン・リバー：バリュー集中、ブラフ半減

MW でのターン・リバーは **バリュー集中** を心がけます。

### ターンでの方針

- 強い手 (ナッツ近) → 75〜100% bet で push します
- 中強度ハンド (TPTK) → check call or 小 bet
- ドロー → check call (バリュー bet にしません)
- エア → check fold

### リバーでの方針

- 完成バリュー (ストレート, フラッシュ) → 75〜150% bet
- 中強度 (オーバーペア, TPTK) → 慎重に (3 人いる場合は check call)
- エア → check fold

ブラフは原則 0% です。例外として heads-up に縮退した場合のみブラフ検討してください。

---

## テーブル選択の最終判断

ルース・ビッグベットテーブルに残るかの判断基準をお伝えします。

### 残るべきテーブル

- フィッシュ (CS / マニアック) が 2 人以上
- hero がスタックでカバー
- hero のポジション良 (BTN / CO 主体)
- 平均 pot サイズが hero のスタックの 20%+ (= フィッシュ多)

### 離れるべきテーブル

- LAG / マニアック が左隣で席替え不可
- hero がショートスタック (50bb 以下)
- 全員 TAG 化している
- 分散に耐えられない (バンクロール余裕なし)

### バンクロール管理

ルース・ビッグベットテーブルは **分散が大きい** です。
- 通常: 20 buy-in 推奨
- ルース・ビッグベット卓専用: **30〜40 buy-in** をおすすめします

バンクロール不足のままでは正しい判断 (call / fold) ができません。恐怖でブレてしまいます。

## 具体例

### 例 1: マルチウェイ post でのスーテッドコネクター

**状況**: BTN マニアック open 5bb、SB call、BB hero call (7♥6♥)、CO call (4way)
フロップ: 9♦8♣5♠ (OESD + BDFD)

BB hero check → SB check → CO check → BTN マニアック bet 75% (15bb to 20bb pot)

判定:
- BB hero Equity: OESD (8 outs) + BDFD ≈ 35%
- 必要 Equity (heads-up 計算): 30%
- MW (2 人 fold 想定): heads-up と同じ → call OK です
- 全員 call すれば後続多数 → call で MW 維持します

結論: **call** (Equity 十分、MW 維持)

### 例 2: ビッグベッター左隣で T_open 引き上げ

**状況**: CO hero、BTN マニアック (左隣)、テーブル全体ルース

通常 CO T_open=20、ハンド A8s (Score=22) → open OK
**マニアック左隣**: CO T_open=25 → A8s (Score=22) は不参加します

ハンド絞って QQ+/AK のみ open しましょう。

### 例 3: MW でのオーバーペア慎重

**状況**: 4way pot、フロップ K♣8♠4♦、hero JJ (pocket pair、overcard あり)

通常 (heads-up): bet 50%
**MW**: check します (誰かに K があり、bet で raise されると loss です)

check call で minimum 損失に抑えて、もし誰も持ってなければ ターンで bet を検討します。

---

## ⚠️ やりすぎ注意

### マルチウェイでのブラフ禁止

どんなに「ナッツ board」「scare card」「相手が弱そう」でも、3way 以上ではブラフは原則 0% です。例外はありません。

### 大 pot 化への警戒

ルース・ビッグベット卓は pot が大きくなりがちです。スタック 100bb で pot 50bb までは正常、80bb 超えたらコミット域 (リバーで折りにくくなります)。

早めの段階で「コミットするか / 降りるか」を決めましょう。半端な call 続行は最悪です。

### 分散の心理影響

-200bb / +300bb の振れは精神に来ます。冷静さを失った時点でエクスプロイトは機能しません。

- 大負け後: 即セッション中断しましょう
- 大勝後: 慢心に注意、判断を緩めません
- 連敗: 分類が間違っている可能性、再評価しましょう

---

## まとめ

- ルース・ビッグベット卓は最大の収益源、最大の地雷です
- ビッグベッターが右隣 → ATM 戦略 (check → call)
- ビッグベッターが左隣 → T_open 大幅引き上げ、席替え推奨
- MW ではスーテッドコネクター・スモールペア優先
- **MW でブラフ禁止**、バリュー集中
- ポットオッズで MW call 判断
- バンクロール余裕 30〜40 buy-in がおすすめです
