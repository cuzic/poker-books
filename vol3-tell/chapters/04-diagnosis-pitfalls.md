# 第4章　タイプ診断の落とし穴

*対象: 💻🎯*

> 誤分類した上でのエクスプロイトは、エクスプロイトしないより損です。

---

## 落とし穴の全体像

タイプ診断には体系的な失敗パターンがあります。本章では 6 つの主要な落とし穴を整理します。

1. サンプル不足での確信
2. タイプの状況変化を見落とす
3. LAG とマニアックの混同
4. コーリングステーションと TAG ルースの混同
5. テル単独での判断
6. 確認バイアス (最初の判断を支持する情報だけ覚える)

---

## 1. サンプル不足での確信

最も多い失敗です。3〜5 ハンドの観察で「ニットだ」「マニアックだ」と決めつけてしまうケースですね。

### 必要なサンプル数

| 判定したい内容 | 必要サンプル |
|---|---|
| 大まかな分類 (タイト vs ルース) | 30 hands |
| タイプ確定 (5 分類) | 100 hands |
| サブ分類 (LAG vs マニアック等) | 300 hands |
| 極端な分類 (純ニット / 純マニアック) | 100+ hands |

ライブで 100 hands は約 3 時間です。ライブセッションが 5 時間として、最初の 1〜2 時間は「仮分類」のフェーズと割り切る必要があります。

### 「短いサンプルでの極端判定」を避けましょう

30 hands 未満で次の極端判定はおすすめしません：

- T_open を 5 以上動かす (例: 18 → 13)
- bluff 頻度を 50%pt 以上動かす
- レンジ分布の見立てを「極端 2 極化」と確定する
- vs CR 補正を「相手の CR は確実にナッツ」と固定する

短サンプル時は **マイルドなシフト (±2〜3)** に留めてください。

---

## 2. タイプの状況変化を見落とす

タイプは固定ではありません。同じ相手でも状況で変容します。

### 主要な変容トリガー

| トリガー | 変容方向 |
|---|---|
| バッドビート直後 | チルト → マニアック化 |
| 連勝後 | 自信過剰 → LAG 化 (ルース・アグレ寄り) |
| 連敗後 | 萎縮 → ニット化 |
| 長時間プレイ (5h+) | 疲労 → ニット化 |
| ショートスタック化 (20bb 以下) | プッシュフォールド戦略 (元タイプ問わず) |
| ビッグスタック (200bb+) | 慎重化 (TAG 寄り) |
| アルコール摂取 | ルース化 (個人差大) |
| 時間帯 (深夜) | ルース化 (疲労込み) |

### 「変容を検知する」観察ルーティン

20 ハンドごとに以下を確認します：

- 参加率の急変 (前 20 hands と比較)
- サイズの急変 (平均サイズの拡大 or 縮小)
- ライン傾向の急変 (Cbet 頻度の上昇など)

急変が見えたら **再観察モード** に切替えましょう。古い分類は「過去のタイプ」として保留し、新規分類を開始してください。

---

## 3. LAG とマニアックの混同

両者は「ルース・アグレッシブ」で似ていますが、エクスプロイト戦略が異なります。

### 違いの判別軸

| 軸 | LAG | マニアック |
|---|---|---|
| VPIP | 25〜35% | 45〜65%+ |
| PFR | 20〜28% | 30〜45%+ |
| 4bet 受けの反応 | バリューのみ 4bet 継続、ブラフは fold | ブラフでも 5bet jam |
| サイズ感 | 状況に応じて使い分け | 滅茶苦茶 (40% → 200% を混在) |
| バリューラインの存在 | ある (見えにくいが) | ない (全部 bet) |
| スロープレイの可能性 | あり | ほぼなし |

### 判別のキー: 4bet 受けの反応

最も明確な判別軸は **「hero が 4bet したときの反応」** です。

- LAG: バリュー (KK+, AK) でのみ 5bet jam、ブラフは fold です
- マニアック: ブラフでも 5bet jam します (フォールドエクイティと判断する余裕がない)

1 回でも「LAG が 4bet で fold」を見たら、LAG 確定です。「マニアックが 4bet で 5bet jam」を見たら、マニアック確定ですよ。

### 誤分類のコスト

LAG をマニアックと誤分類すると、ブラフキャッチを過剰に使い、LAG のバリューラインに引っかかります (loss: 大)。マニアックを LAG と誤分類すると、トラップ (スロープレイ) が機能せず、ブラフだと誤判定して払ってしまいます (loss: 中)。

## 4. コーリングステーションと TAG ルースの混同

一見ルース (VPIP 30%+) でも、内訳がポジション別に分かれている「スキル系ルース」プレイヤーがいます。

### スキル系ルースの内訳

| ポジション | VPIP |
|---|---|
| UTG | 15% |
| CO | 40% |
| BTN | 65% |
| BB | 80% (defense 含む) |

全体平均 VPIP=50% だが、内訳はポジションに応じてタイト。これは TAG 近似で、エクスプロイトしにくい上級者です。

### コーリングステーションとの違い

| 軸 | スキル系ルース (TAG 近似) | コーリングステーション |
|---|---|---|
| PFR | 30〜40% (高い) | 8〜15% (低い) |
| フロップでの fold | 早い | 遅い (call 続ける) |
| ショーダウン頻度 | 低い | 高い |
| リンプ | なし | 多発 |
| 圧力への反応 | 適切に fold | call 続ける |

判別キー: **「フロップでの fold の早さ」と「ショーダウン頻度」** です。スキル系ルースは適切に fold します。

---

## 5. テル単独での判断

身体テルや会話テルを単独で信頼するのは危険です。

### 単独テル信頼のコスト

例: 「相手がリバーで手が震えた」→ ブラフだと判断して call → 実は強い手 (緊張は強でも弱でも起こります)

1 つのテルが提供する情報は **+5〜10% の確率補正** に過ぎません。これだけで決定的な判断はできませんね。

### 複合判断の作法

判断は「**プレイタイプ ＋ サイズテル ＋ タイミングテル ＋ ライン**」の合成で下してください。

| 単独情報 | 信頼度補正 |
|---|---|
| プレイタイプ単独 | 30〜50% |
| + サイズテル一致 | +10% (合計 40〜60%) |
| + タイミングテル一致 | +10% (合計 50〜70%) |
| + ライン整合 | +10% (合計 60〜80%) |
| + 身体テル | +5% (合計 65〜85%) |
| + 会話テル | +5% (合計 70〜90%) |

身体・会話テルは「最後の補強」として機能します。これらだけで判断するのは方向ミスを招きやすいです。

---

## 6. 確認バイアス

最初の判断を支持する情報だけ記憶し、反証する情報を無視する傾向がありますね。観察ノートで対抗しましょう。

### 確認バイアスの典型例

- 「ニットだと思った」→ 相手の fold ばかり覚えている (call を忘れます)
- 「マニアックだと思った」→ 相手の bet ばかり覚えている (check を忘れます)
- 「ブラフしてくる相手」→ 過去のブラフ事例ばかり覚えている

### 対抗策

1. **観察ノートに反証も書く**: 「ニット候補だが、ターンで coffee call があった」など
2. **3〜4 ショーダウンで確定**: 1〜2 のサンプルでは確信しないでください
3. **ハンドごとに「タイプを再確認」**: ハンドごとに「今の相手のタイプは何か」と自問してみます
4. **他のプレイヤーの意見**: ライブで隣の人 (信頼できる人) に「あの人どう思う？」と聞いてみるのもおすすめです

---

## まとめ：「誤分類のコスト」の階層

| 失敗パターン | コスト |
|---|---|
| サンプル不足で極端判定 | 大 (10〜30 bb/100 hands) |
| タイプ変容を見落とす | 中 (5〜15 bb/100 hands) |
| LAG/マニアック混同 | 大 (10〜25 bb/100 hands) |
| テル単独信頼 | 中〜大 (1 ハンドで 50bb 損も) |
| 確認バイアス | 中 (5〜10 bb/100 hands、ジワジワ) |

エクスプロイトの精度は **診断の精度** に依存します。診断の落とし穴を意識的に避けることが、エクスプロイト戦略の前提条件になります。
