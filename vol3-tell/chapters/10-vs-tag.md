# 第10章　vs TAG (タイトアグレッシブ)

*対象: 💻🎯*

> TAG の本質：GTO 近似。エクスプロイトしにくいです。
> ポットを小さく保ち、微小な判断逸脱を探していきましょう。

**主な逸脱軸: ⑤判断逸脱の微小な誤りを探す**

---

## 見分け方

### 行動的特徴

- GTO 近似の行動です。MATCHA の通りに動いています
- 偏りが見えにくいです
- サイズ・ライン・タイミングが均一化されています
- ショーダウンで「バランスの取れた手」を見せます（バリューもブラフも）

### HUD 統計の目安

| 統計 | TAG 域 |
|---|---|
| VPIP | 16〜22% |
| PFR | 13〜20% |
| 3bet | 5〜9% |
| CBet % | 55〜65% |
| FoldToCBet | 40〜50% |
| WTSD | 24〜28% |
| W$SD | 50〜55% |

### 5 軸チェック

- ① レンジ: GTO 近似 (偏り小です)
- ② 頻度: GTO 近似です
- ③ サイズ: 均一化され、状況に応じた選択がされています
- ④ ポジション: 適切に使い分けられています
- ⑤ 判断: **微小な逸脱のみ** ← 本書のターゲットです

---

## 基本方針：エクスプロイトを「しない」が基本です

TAG 相手にエクスプロイトを **過剰適用** してしまうと、TAG の方が hero の偏りを認識して逆用します。基本は **GTO 通り**の方針を守りましょう。

プリフロップ閾値も **変更なし** です（T_open, T_3bet, T_4bet すべて通常値）。

---

## ポストフロップ：TAG の微小な逸脱を探す

TAG にも完璧な GTO はありません。観察ポイントを絞って、微小な偏りを探していくのが良いでしょう。

| 観察ポイント | 均衡値目安 | 偏りの判断 |
|-----------|----------|-----------|
| Cbet 率 (ボード混在型) | 60〜70% | 80% 超 → C ベットしすぎです → チェックレイズを増やしましょう |
| FoldToCbet (mixed board) | 40〜45% | 55% 超 → fold しすぎです → ブラフ Cbet を増やしましょう |
| リバーブラフ頻度 | 33% 前後 | 10% 以下 → fold しやすいです（over fold） |
| Turn Cbet 率 | 50〜60% | 35% 以下 → 1 バレル止まりです → ターンプローブが有効です |
| CR 受け fold | 30〜40% | 50%+ → CR ブラフは +EV です |
| ドンクベットへの反応 | (raise/call mix) | 全部 call → ドンク = 弱バリューの認識ミスです |

### 偏りを発見したらどう動かすか

1. **Cbet しすぎ TAG** → こちらの CR を 5%pt 増やします（CR ブラフを追加）
2. **fold しすぎ TAG** → ブラフ Cbet を 10%pt 増やし、サイズは小さく（33%）で済みます
3. **リバーブラフ不足 TAG** → こちらのブラフキャッチを 5%pt 縮小します（over fold 対応）
4. **1 バレル止まり TAG** → ターンで bet 戻します（相手 check = 弱い信号）
5. **CR fold 多 TAG** → SB/BB defense で CR ブラフを追加します

### 微小調整の現実

TAG 相手の調整は **微小** です（±5%pt 程度）。極端なシフトは方向ミスを招き、TAG の真の GTO ラインに支払うことになってしまいます。

> 📝 **コラム：TAG と戦う必要のないテーブルを選ぶ**
>
> TAG が多いテーブルは EV 争奪戦のコストが高いです。フィッシュ（CS / マニアック）がいるテーブルへ移動を検討するのがおすすめです。
> 卓選びはエクスプロイト技術より重要です（第 15 章で詳述します）。

---

## TAG への対応：「ポットを小さく保つ」

TAG とのポット拡大は EV ゼロ近傍です（お互い GTO 近似）。**ポットを小さく保つ** ことで、自分の分散を抑えつつ、フィッシュ相手の EV を温存できます。

### 具体的な戦術

- **3bet を絞ります**: バリュー 3bet のみ（TT+/AK）、ブラフ 3bet は避けましょう
- **Cbet サイズ**: 33%/50% を中心にします
- **ターンプローブ**: TAG が check した時のみにしましょう
- **オーバーベットなし**: TAG にはオーバーベット（125%+）は通りにくいです
- **ブラフキャッチは慎重に**: 中強度ハンドは call で済ます方が安全です（raise しない）

---

## スキル系ルース（見かけルース、実は TAG 近似）

VPIP 50% 前後でも勝ち続けているプレイヤーの正体です。

### 内訳の特徴

| ポジション | VPIP |
|---|---|
| UTG | 15% |
| MP/HJ | 22% |
| CO | 40% |
| BTN | 65% |
| SB | 50% |
| BB | 80% (defense) |

全体平均 50% ですが、ポジション別ではタイトです。

### 見分け方

- **PFR**: 30〜40%（高めで、TAG 範囲を超えています）
- **フロップでの fold**: 早いです（適切な fold）
- **ショーダウン頻度**: 低いです（call で見に行きません）
- **CR 頻度**: 適度です（8〜12%）
- **4bet 受けの反応**: バリューでのみ継続します（LAG ではありません）

### 対応

TAG 準拠の対応をしましょう：
- ブラフを絞ります
- ポットを小さく保ちます
- 3bet は絞ります（バリューのみ）
- スロープレイは控えめにします

**誤分類（LAG だと思った場合）** のコスト: ブラフキャッチを広げすぎて、スキル系ルースのバリューに支払うことになってしまいます。

---

## 具体例

### 例 1: BTN vs TAG BB

**状況**: BTN open 2.5bb、TAG BB call、フロップ K♣8♦4♠

**GTO**: BTN Cbet 50%
**TAG 相手**: Cbet 50%（調整なし、GTO 通り）

観察ポイント: TAG が fold したか call したかを見ます。fold なら「TAG の K-high board defense」がやや tight 寄りの可能性があります。次回以降、Cbet を 60% に微調整してみるのが良いでしょう。

### 例 2: TAG の Cbet しすぎ発見

**状況**: TAG CO open 2.5bb、hero BB call、フロップ T♣6♠2♦

TAG CO が 75% Cbet を 5 回中 5 回実測 → 80%+ でC ベットしすぎの可能性があります。
- フロップ CR ブラフを 3 ハンドに 1 回追加するのを試します
- サイズは標準（3.5x）で、TAG の即 fold を期待します
- 機能しないなら TAG の Cbet 過剰は誤検知の可能性があります（サンプル不足）

### 例 3: スキル系ルース判定

**状況**: VPIP=52% プレイヤー、PFR=35%、フロップで適切に fold

判定: スキル系ルース（TAG 近似）です
対応: GTO 通り、エクスプロイトはせず、ポット小を心がけます

誤判定リスク: LAG と誤分類してしまうと、ブラフキャッチで loss が出ます。判定確信度が低い場合は **GTO 準拠** が安全です。

---

## まとめ

- TAG はエクスプロイトしません（基本 GTO 通り）
- 微小な判断逸脱のみ狙いましょう（Cbet 過剰、CR fold 多、リバーブラフ不足など）
- 微小調整は ±5%pt までにしましょう
- **TAG が多いテーブルは EV が薄い → 卓選びで回避するのがおすすめです**
- スキル系ルース（VPIP 50%+ でも実は TAG）に気をつけましょう
- ポットを小さく保つことを大切にします
