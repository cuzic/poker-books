# 第 0 章　ポストフロップを 5 秒で解く

## 0.1 本書は「1 つの式」でポストフロップを解きます

本書では、 ポストフロップ判断を **1 つの公式 + 12 個の数字 + DEF 閾値補正 + 11 の例外ルール** に圧縮してしまいます。

```
Score = Grid[カテゴリ][board] + DV × mult[street]
      + 2 × オーバーカード + 4 × pot − 2 × bs

if Score ≥ 43: レイズ
elif Score ≥ 14: コール
else:                  フォールド
```

この公式の名前は **MATCHA Score** です。

## 0.2 暗記項目は 56 個です

| 項目 | 数 |
|------|---:|
| 公式: 12 cells Grid + 加算式 | 13 |
| DEF 閾値補正: vs CR/Donk 時 T_raise=49 (通常 43) | 1 |
| 例外: 11 ルール (huge_loss 5 + 確実 cell 3 + Turn CR 専用 2 + River Donk 1) | 11 |
| 境界ハンド (sub-family × カテゴリ の outlier) | ~30 |
| ポット補正 + スタック補正 | ~8 |
| **計** | **~64 項目** |

## 0.3 公式の精度について

GTO データ全 **154,216 spots** で検証した結果は以下の通りです：

| 指標 | 値 |
|---|---:|
| avg loss (BB) | **0.3587** |
| huge% (>5 BB) | **1.49%** |
| Grid cells | **12** |
| カテゴリ 数 | **4** |

特に **4BP では huge% を 0.53%** に抑制できました。 4BP を含む統合 audit での最大の成果です。

## 0.4 「5 秒で解く」 とはどういうことでしょうか

公式は加算と引き算だけです。 9 + 6 + 2 = 17 のような単純な暗算で済みます。
熟練者は 5 秒、 慣れた読者なら 10 秒で答えが出るようになります。

### 暗算手順 (3 ステップ)

1. **カテゴリ と board を判定** → Grid から数字を 1 つ拾う (12 cells のどれか)
2. **加算項を足します** (DV × mult、 2 × overcards、 4 × pot)
3. **減算項を引いて** (2 × bs)、 閾値 14 / 43 と比較します

### 具体例

board: Kh 7c 2d (dry)、 hand: AhTh、 street: flop、 pot: SRP、 bs: med_100p

- カテゴリ = エア (no_made_hand)
- Grid[エア][dry] = **3**
- DV = 0 (no draw)、 0 × 3 = 0
- oc = 1 (A > K)、 2 × 1 = **2**
- pot = SRP = 0、 4 × 0 = 0
- bs = med_100p = 2、 −2 × 2 = **−4**
- Score = 3 + 0 + 2 + 0 − 4 = **1**
- 1 < 14 → **フォールド**

## Cash/MTT note

本書 MATCHA Score は **Cash 100bb と MTT chipEV (25/50/100/200bb)** で同じ形です。 ante / rake / sizing の差はありますが Score 公式は共通です。 詳細は第 21 章で 1 ページ早見表をご用意しています。

## この章で覚える項目 (3 items)

1. 公式: `Score = Grid + DV × mult + 2×oc + 4×pot − 2×bs`
2. 閾値: ≥ 43 レイズ / ≥ 14 コール / それ未満フォールド
3. 暗算手順: カテゴリ+board で Grid → 加算 → 減算 → 比較
